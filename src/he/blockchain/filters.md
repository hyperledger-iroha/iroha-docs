# פילטרים {#filters}

מסנן זרמי אירועים צר ומצבים תפעול.
פילטר האירועים הוא `EventFilterBox`, אשר יכול להתאים למשפחות האירועים האלה:

- `Pipeline`
- `Data`
- `Time`
- `ExecuteTrigger`
- `TriggerCompleted`

השתמשו בחילטר הצמוד ביותר שמתאים לזרם העבודה.
`DataEventFilter::Any` הם שימושיים לדיאגנסטיקה, אבל הם עושים כל אירוע
לשלם את עלות ההצלה או התאמת המנוי.

## פילטר אירועים נתונים {#data-event-filters}

`DataEventFilter` מתאים אירועים נתונים בספר ההוצאות.

| תופעה | משפחת האירועים |
| --- | --- |
| `Any` | כל אירוע נתונים |
| `Peer` | אירועים במחזור החיים של עמיתים |
| `Domain` | אירועי מחזור החיים של תחום ונתונים מטא |
| `Account` | מחזור החיים של החשבון, מטא-מנתונים, פרופיל זיהוי ואירועים של זהות |
| `Asset` | אירועים של סכום נכסים ונתונים מטא |
| `AssetDefinition` | תופעת חיים, מדיניות ופעילויות מטא נתונים |
| `Nft` | NFT אירועים של מחזור החיים ונתונים מטאטא |
| `Rwa` | אירועי מחזור החיים של נכסים בעולם האמיתי |
| `Trigger` | אירועי מחזור החיים של המניע ונתונים מטאטא |
| `Role` | אירועים במחזור החיים של תפקידים |
| `Configuration` | אירועי תיקון שרשרת |
| `Executor` | אירועי פעלת זמן |
| `Proof` | אירועים של מחזור החיים של אימות הראיות |
| `Confidential` | אירועי נכסים סודיים |
| `VerifyingKey` | אירועי רישום של מפתח לאמת |
| `RuntimeUpgrade` | אירועי שיפור בזמן ההפעלה |
| `Soradns` | פתרון אירועי ממשל תיווך |
| `Sorafs` | SoraFS אירועי אימות שער |
| `SpaceDirectory` | תיקון החלל מונפסט אירועים מחזור החיים |
| `Escrow` | אירועים גלויים במחזור החיים של אבטחת נכסים מקומיים |
| `Offline` | אירועי הסדרים מקוונים |
| `Oracle` | אירועי תזמון Oracle |
| `Social` | אירועי תמריץ ויראליים |
| `Bridge` | אירועי גשר |
| `Governance` | אירועי ממשל כאשר תכונת השלטון מופעלת |

רוב פילטורים בטון מאפשרים גם ID מתאים ומסכה של אירועים.
לדוגמה, פילטר נכסים יכול להתאים נכס אחד או סוג של אירועים נכסים.
בעוד מסנן ההדק יכול להתאים להדק ID ומערכת אירועי תירוץ.

## פילטרים של צינורות {#pipeline-filters}

פילטרים של צינורות מתאימים לאירועים של עיבוד כגון בלוק, עסקה, מיזוג,
וירועים של עדים.
לוחית הנתונים, ומפעילים המגיבים למצב של הצינור במקום נתוני ספרים
חפצים.

## פילטרים מפעילים {#trigger-filters}

המפעילים מאחסנים את מצבם כ `EventFilterBox`. פעלת ההדק גם
חנויות:

- מופעל
- מדיניות חזרה
- חשבון של הסוכנות
- מדיניות ניסיון חוזר של תפעול זמן אופציונלית
- נתונים

לרשות ההפעיל יש את הרשאות הנדרשות על ידי המוצא.
מעדיפים חשבונות טכניים מוקדמים עבור תפעילים חיים ארוכים.

## פילטרים שאלים {#query-filters}

פילטרים שאלורים נפרדים מהפילטרים של אירועים.
תמיכה בעובדות ובוחרים. השתמשו בצרכים ספציפיים למשאלה SDK
אז הכניסה של הסינון תואמת את סוג ההוצאת של החיפוש.
