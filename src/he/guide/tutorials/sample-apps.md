# דגימות וריצפיות {#samples-and-recipes}

ה- Iroha מאגר המקור מכיל SDK מתכונים ושיטות בדיקה שמעקבות את
אותו תיקון כמו הערך.

## JavaScript מתכונים {#javascript-recipes}

[`javascript/iroha_js/recipes`](https://github.com/hyperledger-iroha/iroha/tree/main/javascript/iroha_js/recipes)
מכיל דוגמאות ממוקדות לחיבור של עסקאות דטרמיסטיות, Nexus אפליקציה
העברות, NFT ושינוי חשבונות, ISO זרימות גשר, ו Torii הזרם.
כל מתכון מסמך בין אם הוא פועל מקוון או זקוק לחיים Torii נקודת סוף.

## Swift ו-iOS {#swift-and-ios}

שימוש `IrohaSwift/Tests/IrohaSwiftTests` עבור דוגמאות שמבחינות עם הזרם
Swift SDK. תראו. [Swift ו-iOS](/he/guide/tutorials/swift.md) עבור חבילה ועבורות
תכנון.

## Android {#android}

עבור חדש Android עבודה, להשתמש Kotlin-הראשון `core-jvm`, `client-android`, ו
`offline-wallet-android` מודולים המתוארים ב:
[Kotlin, Android, ו- Java](/he/guide/tutorials/kotlin-java.md). ה- Kotlin SDK הוא
נקודת ההתחלה הקנוניקה של Android צרכנים.
