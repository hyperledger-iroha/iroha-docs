# מתכוני פיתוח יישומים ב־Iroha 3 {#iroha-3-application-cookbook}

פתחו עבור Iroha 3 באמצעות מתכונים קטנים שניתן לאמת, המתחילים ברשת הבדיקה Taira ומשאירים את הרשת הראשית Minamoto לקריאה בלבד. כל מתכון מציין אם מדובר בקריאה ציבורית, בכתיבה רגילה מחשבון ממומן, או בפעולה המחייבת הרשאה. הפקודות משתמשות במזהי החשבון הנוכחיים מסוג I105, בבחירת עמלה מפורשת ובהתנהגות השמורה בקומיט Iroha [`c8c872461e92f04325c350cdd952f4276e96f9dc`](https://github.com/hyperledger-iroha/iroha/tree/c8c872461e92f04325c350cdd952f4276e96f9dc).

התחילו ב־[חיבור ל־Taira](./connect-to-taira.md). המתכון הזה מממן את החותם ושומר את נכס העמלה שבו משתמשים שוב מתכוני שורת הפקודה. לעולם אל תעתיקו ID של נכס עמלה מהתיעוד הזה: קראו אותו ממדיניות ה־faucet הנוכחית של Taira.

## רמות גישה {#access-levels}

- **ציבורי** — אין צורך בחותם או בהרשאת רשת.
- **מוכן לכתיבה** — השתמשו בחשבון בדיקה ממומן של Taira, במשלם עמלה מפורש ובנכס העמלה הנוכחי שמדיניות ה־faucet מפרסמת.
- **נדרשת הרשאה** — Taira חייבת להעניק את ההרשאה הנקובה בסביבת הריצה או את מרחב השמות שבפיקוח הממשל. השתמשו ברשת מקומית שנוצרה כאשר הרשאה זו אינה זמינה; הצלחה מקומית אינה מעניקה סמכות ב־Taira.

אף מתכון כאן אינו שולח כתיבה ל־Minamoto.
