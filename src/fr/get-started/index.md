# Iroha 3 {#iroha-3}

Iroha 3 est la plateforme Hyperledger Iroha de première version. Elle prend en charge les réseaux auto-hébergés et le modèle de déploiement multi-espaces de données SORA Nexus à partir d'une seule base de code déterministe.

À un niveau élevé, Iroha 3 combine :

- exécution et stockage déterministes
- la Machine Virtuelle Iroha (IVM) pour les contrats intelligents portables
- Norito comme le format de sérialisation canonique
- les APIs Torii destinées aux clients, aux opérateurs et aux applications
- Sumeragi consensus avec disponibilité obligatoire des données et diffusion fiable
- comptes canoniques sans domaine avec des alias lisibles par l’homme liés séparément
