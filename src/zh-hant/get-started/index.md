# Iroha 3 {#iroha-3}

Iroha 3 是首次發佈的 Hyperledger Iroha 支持自主託管的網絡和多數據空間 SORA Nexus 基於一個確定性代碼基礎的部署模型.

在高水平上, Iroha 3 結合:

- 確定性執行和存儲
- Iroha 移動智能合同虛擬機 (IVM)
- Norito 作爲法典電線格式
- Torii 用於客戶端,運營商和應用程序面向 APIs
- Sumeragi 與強制性的數據可用性和可靠的廣播達成一致
- 沒有域名的可信賬戶,具有單獨綁定的人類可讀的號
