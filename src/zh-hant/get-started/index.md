# Iroha 3 {#iroha-3}

Iroha 3 是首次釋出的 Hyperledger Iroha 支援自主託管的網路和多資料空間 SORA Nexus 基於一個確定性程式碼基礎的部署模型.

在高水平上, Iroha 3 結合:

- 確定性執行和儲存
- Iroha 移動智慧合同虛擬機器 (IVM)
- Norito 作為規範序列化格式
- Torii 用於客戶端,運營商和應用程式面向 APIs
- Sumeragi 與強制性的資料可用性和可靠的廣播達成一致
- 沒有域名的可信帳戶,具有單獨繫結的人類可讀的號
