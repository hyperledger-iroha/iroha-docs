# 公共和私人區塊鏈 {#public-and-private-blockchains}

Iroha 可以在各種配置中運行.作爲您自己的網絡的管理員,您決定哪個執行者和許可政策確定交易是否被接受

常見的配置文件是私人授權網絡和更開放的公共網絡.這兩者都通過基因狀態和執行程序政策進行配置,而不是通過單獨的節點二進制.

下面我們概述了這兩種使用情況的主要區別.

## 許可證 {#permissions}

在公共區塊鏈中,大多數賬戶都有相同的權限.在私人區塊鏈上,大部分帳戶被假定除非明確授予相關許可,否則無法在獲得權限之外做任何事情.

::: 信息

查看 [專用部分關於許可證](/zh-hant/blockchain/permissions.md)的詳細信息.

:::

## 同齡人 {#peers}

在公共區塊鏈中,同行錄取是鏈條政策的一部分.對於私人區塊鏈來說,部署通常將可信賴的同行設置定在配置和生成中.

::: 信息

查看[同行管理](peer-management.md)詳細信息.

:::

## 登記賬戶 {#registering-accounts}

根據您決定如何設置[創始區塊 (`genesis.json`) ](genesis.md),註冊賬戶的過程可能是兩種方式之一.

選擇的執行器定義了哪些權限檢查適用.您可以在創始中賦予默認的 [權限代幣](/zh-hant/blockchain/permissions.md)來塑造一個私人,管理員管理的網絡或更開放的網絡.一旦這些權限被激活後,帳戶註冊過程是不同的.

在註冊賬戶方面,公共區塊鏈和私人區塊鏈有以下不同:

- 在公共區塊鏈中,任何人都應該能夠註冊一個帳戶[^1].所以,理論上,你所需要的只是一個合適的客戶端,一種方法來生成一個支持的算法的私鑰,以及允許政策接受註冊.

- 在私人區塊鏈中,您可以設置帳戶的任何過程:可能是通過特定賬戶提交註冊說明,或者通過其他詳情要求的智能合同.在私人區塊鏈中,只能在特定的日期註冊新賬戶,或者僅限於非可選 (有限) 代幣.

- 在典型的私人區塊鏈中,即沒有任何獨特的賬戶註冊過程中的區塊鏈,你需要一個賬戶,才能註冊另一個帳戶.

默認許可證驗證器涵蓋典型的私人區塊鏈使用情況.

::: 信息

公共模式和私有模式是政策配置文件,而不是單獨的節點二進制. 在運行開放網絡之前,請檢查您發送的執行器和創始權限

:::

查看 [指令](/zh-hant/blockchain/instructions.md#un-register)的部分,瞭解有關 `Register<Account>`指令的更多細節.

[^1]: `Register<Account>`爲常規,無域名的 `AccountId`創建賬本狀態;域名路由和姓氏分別管理.
