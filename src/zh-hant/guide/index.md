# 指南 {#guide}

在構建,運營或與 Iroha 整合時使用此節目.開始為第一個客戶端使用 SDK 教程,然後在與共享網路部署之前轉向最佳實踐和操作員參考.

## 部分 {#sections}

|部分|用它來|
| ------------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------- |
| [SDK 教程](/zh-hant/guide/tutorials/) |語言特定的客戶端設定和應用程式樣本|
| [最好的實踐](/zh-hant/guide/best-practices/) |開發,部署,運營,安全和釋出的生產指南|
| [配置和管理](/zh-hant/guide/configure/overview.md) |當地對等節點配置,創世,客戶端配置,鍵和對等節點管理 |
| [安全性](/zh-hant/guide/security/) |關鍵處理,運營安全, VPNs,欺詐監控和許可衛生 |
| [高階運營](/zh-hant/guide/advanced/metrics.md) |測量表,效能檢查,混沌測試,熱充電和裸金屬操作|

## 建議的路徑 {#recommended-path}

1. [安裝 Iroha 3](/zh-hant/get-started/install-iroha.md)和 [啟動本地網路](/zh-hant/get-started/launch-iroha.md).
2. 選擇一個 [SDK 教程](/zh-hant/guide/tutorials/),並提交一個小交易.
3. 審查 [應用開發](/zh-hant/guide/best-practices/application-development.md) 和 [資料建模](/zh-hant/guide/best-practices/data-modeling.md) 在制定申請之前 API.
4. 在執行共享或生產網路之前,使用 [網路部署](/zh-hant/guide/best-practices/network-deployment.md), [操作](/zh-hant/guide/best-practices/operations.md)和 [安全與訪問](/zh-hant/guide/best-practices/security-and-access.md).
5. 在從本地開發推廣到 Taira, Minamoto 或其他現場部署時,遵循 [發布準備](/zh-hant/guide/best-practices/release-readiness.md).
