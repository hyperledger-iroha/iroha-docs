## 推薦的路徑 {#recommended-path}

1. [裝置 Iroha 3](/zh-hant/get-started/install-iroha.md) 及其他
   [啟動本地網絡](/zh-hant/get-started/launch-iroha.md).
2. 選擇一個 [SDK 學習教程](/zh-hant/guide/tutorials/) 並將一塊小的子
   這項交易.
3. 檢查
   [應用程式的發展](/zh-hant/guide/best-practices/application-development.md)
   及其他 [數據建模](/zh-hant/guide/best-practices/data-modeling.md) 在之前
   制定申請 API.
4. 使用 [網路部署](/zh-hant/guide/best-practices/network-deployment.md),
   [活動](/zh-hant/guide/best-practices/operations.md), 及其他
   [安全與使用權](/zh-hant/guide/best-practices/security-and-access.md)
   在運行共享或生產網絡之前.
5. 接下來 [準備釋放](/zh-hant/guide/best-practices/release-readiness.md)
   在從本地發展推廣到 Taira, Minamoto, 或是其他
   實際部署.
