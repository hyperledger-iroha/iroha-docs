# 標本和食譜 {#samples-and-recipes}

其他國家 Iroha 源存儲包含 SDK 檢測的配方和試驗套件
這種變更與節點相同.

## JavaScript 菜食譜 {#javascript-recipes}

[`javascript/iroha_js/recipes`](https://github.com/hyperledger-iroha/iroha/tree/main/javascript/iroha_js/recipes)
包含對決交易批量的專注範例, Nexus 應用程式
轉讓, NFT 還有帳戶的回覆, ISO 橋流量,以及 Torii 這樣的電視劇,
每個食譜都記錄不管它是無線運行, Torii 這就是最後一點.

## Swift 和iOS {#swift-and-ios}

使用 `IrohaSwift/Tests/IrohaSwiftTests` 對於目前的證實範例
Swift SDK. 請看 [Swift 和iOS](/zh-hant/guide/tutorials/swift.md) 對於包裝和橋
這樣的情況,

## Android {#android}

新的使用者 Android 工作,使用 Kotlin- 首先, `core-jvm`, `client-android`, 及其他
`offline-wallet-android` 在下列描述的模組
[Kotlin, Android, 和Java](/zh-hant/guide/tutorials/kotlin-java.md). 其他國家 Kotlin SDK 是的
該法典的起點是 Android 消費者.
