# 公共密鑰加密 {#public-key-cryptography}

公共密鑰加密提供了安全通信和數據保護的手段,使得安全在線交易,加密電子郵件通信等活動能夠進行.

公共密鑰加密技術採用一對加密密鑰公鑰和私鑰,以創建通過網上網絡傳輸信息的高度安全方法.

很容易從私鑰中做出公共密鑰,但相反是相當困難的,如果不是不可能的.這讓事情保持安全.你可以自由地分享你的公鑰,而不冒險你的私鑰,它仍然安全.

## 加密和簽名 {#encryption-and-signatures}

公共密鑰加密允許個人發送加密信息和數據,這些信息只能由預期接收者擁有相應的私鑰來解碼.換句話說,公鑰作爲鎖,而私鑰作爲一個真正的獨特密鑰來解鎖加密的數據.

這種加密過程不僅確保了敏感信息的隱私和機密性,而且還確定了發送者的真實性.通過將發送人的私鑰與公鑰結合起來,創建了一個數字簽名.這種簽名作爲一個數字認證蓋章,驗證發送人的身份和傳輸數據的有效性.任何持有公共密鑰的人都可以驗證創辦交易的人是否使用您的私鑰.

## 客戶端的鑰匙 {#keys-on-the-client-side}

每筆交易都必須由一個賬戶權威機構簽署.該機構的私鑰或控制器材料必須保持祕密,因此客戶端軟件負責安全存儲和簽字.

::: 警告

所有客戶端都是不同的,但平文客戶端配置僅適合開發和控制測試網絡.生產集成應使用祕密管理器,硬件支持的關鍵存儲或其他審計簽名界限.

:::

登記新帳戶需要生成控制器材料,例如Ed25519鍵對,並將公開部分提交給網絡. 從該賬戶後續的交易必須通過相匹配的私鑰或配置的帳戶控制器政策簽署.

爲了使公鑰加密有效地工作,在需要指定新密鑰時避免重複使用密鑰.雖然沒有什麼阻止你這樣做,但公共密鑰是公開的,這意味着如果攻擊者看到相同的公鑰被使用,他們會知道私鑰也是相同的.

雖然私鑰與密碼略有不同,但建議要儘可能隨機使用它們,永遠不要將它們存儲在未加密的狀態下,也不會在任何情況下與任何人分享.
