# 安全原則 {#security-principles}

組織和個人使用者必須共同努力, Iroha 這篇文章也介紹了此次合作的基本原則.

## 安全一般原則 {#general-security-principles}

1. 使用一個 [虛擬私人網路](./vpn.md) (VPN):

    - 在使用公共網絡上, <abbr title="Virtual Private Network">VPN</abbr> 建立一個安全的連接,

2. 使用防火牆保護網路:

    - 透過設置防火牆來強化家庭和/或辦公網絡,

3. 確保物理和數位信息安全:

    - 保護包含敏感資訊的物理文件在安全位置,並確保數碼文檔加密并存儲於密碼保護的資料中.

4. 定期備份資料:

    - 這樣,如果你失去你的數據或有什麼問題, 你就可以快速恢復一切. 儲存這些備份在你通常保存的不同安全的地方.

## 對個人使用者來說的安全原則 {#security-principles-for-individual-users}

1. 採用強固的認證規則:

    - 使用所有帳戶的強固且獨特密碼.

    - 請不要再使用密碼.

    - 預設 <abbr title="Two-Factor Authentication">2FA</abbr> 在可能情況下. <abbr title="Two-Factor Authentication">2FA</abbr> 不僅需要密碼, <abbr title="One-Time Password">OTP</abbr>, 或是第三方基于應用程序的身份認證 (例如Google Authenticator).

    - 避免使用 SMS 沒有任何保證, SMS 例如: Android 應用程式不能僅限於只能接觸專為其目的的訊息.

2. 在數碼溝通時要小心:
    - 建立一個電子郵件客戶端,以簽名和驗證所有收到的電子郵件的簽名.
    - 關閉兩者 HTML 來自未知或未經驗證地址的消息和外部資源加載.

    - 了解常見的魚技巧,

    - 建立一個電子郵件客戶端,以簽名和驗證所有收到的電子郵件的簽名.

3. 保護個人資料:

    - 當與陌生人溝通時, 特別是在電話或網路上,

    - 請自主調查你與他們溝通的個人或組織,

    - 請注意您在社交媒體上分享的個人信息,

## 組織安全原則 {#security-principles-for-organisations}

1. 制定明确的安全政策和程序:

    - 為所有處理敏感數據的員工制定明确的安全政策和協議. 徹底訓練員工遵守這些指南,減輕疏忽行動的風險.

    - 確保所有員工都能使用安全政策,並定期審核和更新以反映改變的安全環境.

    - 提供安全政策的範例和情景, 使他們更容易理解及可操作.

2. 培養員工意識:

    - 培養員工了解數據和運營安全措施.

    - 鼓勵員工及時報導任何可疑行為或安全問題.

3. 保護物理基礎設施:

    - 限制伺服器和基礎設施的物理入境.

    - 確保監控措施定期進行審核和更新,以符合不断變化的安全需求.

    - 考慮對敏感區域進行生物測量接入控制,

4. 部署安全監測:

    - 實行全面的安全監控系統,檢查活動和識別潛在安全漏洞.

    - 執行自動警報,即時通知安全人員任何不尋常或未經授權的行為.

    - 考慮使用機器學習算法,

    - 請聘用員工或指定人員監督數據庫安全,識別,追蹤和解決軟體漏洞,並定期檢查關鍵機器是否存在未被授權的軟件,不列入批准清單.

5. 進行重複的安全審查:

    - 進行常規的安全審查,以評估漏洞,並確認已建立的安全措施符合公認的標準和規則.

    - 請聘請外部安全專家定期進行評估,

6. 實施一個接入控制系統:

    - 建立基于角色的權利控制系統, 以確保員工只能獲得所需資源和資訊.

7. 接受持續改善:

    - 認識安全是一種持續的過程. 維持安全措施的持續評估,並積極提升這些措施,以應對新興的威脅和挑戰.

    - 考慮建立一個反循環, 鼓勵員工提供安全改進的建議,
