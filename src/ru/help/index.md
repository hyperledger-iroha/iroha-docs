# Получить поддержку {#receive-support}

Время от времени у вас могут возникать вопросы о Iroha, которые вы хотели бы обсудить подробно с другими. Существует три способа быстро связаться с нашим сообществом: Telegram, Discord и GitHub.

Сообщество использует [Телеграм](https://t.me/hyperledgeriroha) и [LF Decentralized Trust Discord](https://discord.gg/hyperledger) для общения. Используйте канал `iroha` для вопросов по проекту.

Наконец, вы можете [создать проблему GitHub](https://github.com/hyperledger-iroha/iroha/issues/new/choose), будь то запрос на обновление документации, предложение для основной команды или найденная вами ошибка.
