# Iroha 3 Кулинарная книга приложений {#iroha-3-application-cookbook}

Строить против Iroha 3 с маленькими, проверяемыми рецептами, которые начинаются с Taira тестовая сеть и держать Minamoto только для чтения в основной сети. В каждом рецепте указано, является ли он общедоступным для чтения, обычное письмо с финансируемым счетом или операция с ограничением по разрешениям. Команды используют текущие I105 идентификаторы аккаунтов, явный выбор комиссии и проверенное поведение в Iroha окончательная версия протокола [`0010c5a70039eac101a4846499ba9ceaf43eb65c`](https://github.com/hyperledger-iroha/iroha/tree/0010c5a70039eac101a4846499ba9ceaf43eb65c).

Начните с [Подключиться к Taira](./connect-to-taira.md). Он создает конфигурацию клиента и метаданные комиссии, которые повторно используются в рецептах командной строки. Никогда не копируйте идентификатор актива комиссии из этой документации: получите его из текущего ответа сервиса финансирования тестовой сети Taira.

## Уровни доступа {#access-levels}

- Публичный — не требуется криптографическая подпись или разрешение сети.
- Готово к записи — используйте финансируемый тестовый аккаунт Taira, явного плательщика комиссии и текущий актив для оплаты комиссии, возвращаемый сервисом финансирования тестовой сети.
- Требуется разрешение — Taira должен предоставить указанному программному обеспечению разрешение на выполнение или управляемое пространство имен. Используйте сгенерированную локальную сеть, когда такое разрешение недоступно; локальный успех не предоставляет полномочия Taira.

Ни один рецепт из кулинарной книги не отправляет запись на Minamoto.
