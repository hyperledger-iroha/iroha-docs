# Iroha 3 Книга применения {#iroha-3-application-cookbook}

Постройте против Iroha 3 с помощью небольших, проверяемых рецептов, которые начинаются на тестовой сети Taira и сохраняют Minamoto только для чтения в основной сети. Команды используют текущий I105 учетный запись IDs, ясный выбор сборов и поведение, зарегистрированное на Iroha обязательство [`0010c5a70039eac101a4846499ba9ceaf43eb65c`](https://github.com/hyperledger-iroha/iroha/tree/0010c5a70039eac101a4846499ba9ceaf43eb65c).

Начните с [Свяжитесь с Taira](./connect-to-taira.md). Он создает конфигурацию клиента и метаданные о сборах, которые повторно используются рецептами командной строки. Никогда не копируйте актив сборов ID из этой документации: выводите его из текущего ответа на трубку Taira.

## Уровни доступа {#access-levels}

- Общественный  Не требуется разрешение на подписание или сеть.
- Подготовка к записи  используйте финансируемый тестовый счет Taira, явный плательщик сборов и текущий актив сборов, возвращенный краном.
- Разрешение требуется  Taira должен предоставить разрешение на время выполнения или регулируемое пространство имен. Используйте генерированную локальную сеть, когда эта грант не доступна; местный успех не предоставляет Taira полномочия.

Никакой рецепт из кулинарных книг не отправляет письмо в Minamoto.
