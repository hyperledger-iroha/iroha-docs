# Фильтрации {#filters}

Фильтр узких потоков событий и условий запуска.
фильтр событий `EventFilterBox`, которые могут совпадать с этими семействами мероприятий:

- `Pipeline`
- `Data`
- `Time`
- `ExecuteTrigger`
- `TriggerCompleted`

Используйте самый узкий фильтр, который соответствует потоку работы.
`DataEventFilter::Any` Они полезны для диагностики, но они делают все события
оплачивать расходы на задействование или соответствие абонентов.

## Фильтра событий данных {#data-event-filters}

`DataEventFilter` совпадает с событиями данных книги.

| Вариант | Семейство событий |
| --- | --- |
| `Any` | Любое событие данных |
| `Peer` | События жизненного цикла сверстников |
| `Domain` | События жизненного цикла домена и метаданных |
| `Account` | жизненный цикл счета, метаданные, псевдонимы и события идентичности |
| `Asset` | События баланса активов и метаданных |
| `AssetDefinition` | Определение активов жизненный цикл, политика и события метаданных |
| `Nft` | NFT события жизненного цикла и метаданных |
| `Rwa` | События жизненного цикла активов в реальном мире |
| `Trigger` | События жизненного цикла триггеров и метаданных |
| `Role` | События жизненного цикла роли |
| `Configuration` | События конфигурации в цепочке |
| `Executor` | События выполнителя времени запуска |
| `Proof` | События жизненного цикла проверки доказательств |
| `Confidential` | Конфиденциальные события активов |
| `VerifyingKey` | События регистра проверяющего ключа |
| `RuntimeUpgrade` | События по обновлению рабочего времени |
| `Soradns` | События по управлению резюме решений |
| `Sorafs` | SoraFS события по соблюдению стандартов шлюзов |
| `SpaceDirectory` | Пространственный каталог манифестирует событиями жизненного цикла |
| `Escrow` | Прозрачные события жизненного цикла депозитных активов |
| `Offline` | События по расчету в офлайн режиме |
| `Oracle` | События по передаче данных Oracle |
| `Social` | Вирусные события стимулирования |
| `Bridge` | Мероприятия по мосту |
| `Governance` | События управления, когда функция управления включена |

Большинство бетонных фильтров также позволяют ID и маску для событий.
Например, фильтр активов может соответствовать одному активу или одному классу событий в активах.
в то время как фильтр запуска может совпадать с запускающим ID и набор атрибутов.

## Фильтрации трубопроводов {#pipeline-filters}

фильтры трубопровода соответствуют процессу, например блокировки, транзакции, слияния,
Используйте их для оперативных подписей, блочной обработки
панели управления и триггеры, которые реагируют на состояние трубопровода, а не на данные книги
объекты.

## Фильтры для триггеров {#trigger-filters}

Триггеры хранят свое состояние как `EventFilterBox`. Также действие запуска
магазины:

- исполняемый
- политика повторения
- учетный счет органа
- опциональная политика повторной попытки запуска времени
- метаданные

Власть запуска должна иметь разрешения, требуемые исполняемым.
Предпочитаю специальные технические отчеты для длительного действия триггеров.

## Запросные фильтры {#query-filters}

Запросные фильтры отделены от фильтров событий.
Поддержка предикатов и селекторов. SDK
так что вход фильтра совпадает с типом выхода запроса.
