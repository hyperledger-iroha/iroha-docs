# Мир {#world}

`World` является глобальной организацией, которая содержит другие организации. `World`
состоит из:

- Iroha [параметры конфигурации](/ru/guide/configure/client-configuration.md)
- зарегистрированные сверстники
- зарегистрированные домены
- зарегистрировано [триггеры](/ru/blockchain/triggers.md)
- зарегистрировано
  [роли](/ru/blockchain/permissions.md#permission-groups-roles)
- зарегистрировано
  [Определения разрешений](/ru/blockchain/permissions.md#permission-tokens)
- токены разрешения для всех счетов
- [цепь валидаторов времени запуска](/ru/blockchain/permissions.md#runtime-validators)

Когда домены, равные лица или роли зарегистрированы или не зарегистрировались, `World`
является целью (не) регистрации
[инструкции](/ru/blockchain/instructions.md).

## Kura Сохранение {#kura-storage}

_Кура_ является Iroha Он хранит подписанные блоки и

Kura хранилище основывается на [`kura.store_dir`](/ru/reference/peer-config/params.md#param-kura-store-dir).
В этом корне блокируются данные по полосе или сегменту.

| Путь | Цель |
| --- | --- |
| `blocks/<segment>/blocks.data` | Совместные Norito- с закрепленными подписями. |

| `blocks/<segment>/blocks.count.norito` | Устойчивый маркер обязательств, записывающий количество вкладов блока-индекса, которые безопасны для использования. |
| `blocks/<segment>/da_blocks/` | Выведенные блочные полезные грузы, хранящиеся снаружи `blocks.data` когда бюджетный диск выводит старые тела из горячего файла. |
| `blocks/<segment>/pipeline/sidecars.norito` и `sidecars.index` | Боковые машины для восстановления трубопровода по высоте блока. |
| `blocks/<segment>/pipeline/roster_sidecars.norito` и `roster_sidecars.index` | Недавние боковые машины с обязательным списком, используемые для синхронизации блоков и повторного воспроизведения. |
| `merge_ledger/<segment>.log` | Записи с объединением, выровненные с обязательными блоками. |
| `commit-rosters.norito` | Сохранение сертификатов обязательства и контрольных пунктов для проверки подтверждающих действия за последние блоки. |
