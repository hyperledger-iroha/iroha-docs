# События {#events}

События выделяются, когда в блокчейне происходят определенные вещи, например,
создается новый счет или блокируется.
событий:

- события трубопровода
- события данных
- события времени
- trigger события исполнения

## События по трубопроводу {#pipeline-events}

События трубопровода выпускаются, когда транзакции представляются, выполняются или
событие трубопровода содержит следующую информацию:
тип субъекта, вызвавшего событие (транзакцию или блок), его хэш
Статус может быть `Validating` (в процессе проверки),
`Rejected`, или `Committed`. Если организация была отклонена, причина
предоставляется отказ.

### Попробуй . Taira {#try-it-on-taira}

Проверьте, установлен ли поток событий общественного трубопровода:

```bash
curl -fsSI https://taira.sora.org/v1/events/sse \
  | sed -n '1,12p'
```

Для снимка, который вы можете проверить без открытия потока, читайте недавно
сделки с исследователями:

```bash
curl -fsS 'https://taira.sora.org/v1/explorer/transactions?page=1&per_page=5' \
  | jq '{pagination, txs: [.items[] | {hash, block, status, executable}]}'
```

Откройте SSE маршрут в терминале, когда вам нужны живые события:

```bash
curl -fsS -N https://taira.sora.org/v1/events/sse
```

Если транзакции не будут отправлены, пока поток открыт, команда может остаться
тихо, хотя маршрут здоровый.

## События данных {#data-events}

События данных выпускаются, когда происходит изменение, связанное с данными в регистре таких
как равные, домены, счета, активы, определения активов, NFTs, триггеры,
роли, конфигурация в цепочке, состояние исполнителя, доказательства, конфиденциальные активы;
мосты или SORA/Nexus- специфические объекты.
[фильтры событий данных](./filters.md#data-event-filters).

## События во времени {#time-events}

Временные события выпускаются, когда мировоззрение готово к решению
[Временные триггеры](./triggers.md#time-triggers).
