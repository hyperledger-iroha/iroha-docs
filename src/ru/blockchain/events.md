# События {#events}

События выпускаются, когда происходят определенные вещи в блокчейне, например, создается новый аккаунт или блокируется.

- события в трубопроводе
- события данных
- события времени
- trigger события исполнения

## События по трубопроводу {#pipeline-events}

События трубопровода выпускаются, когда транзакции подаются, выполняются или обязаны к блоку.Событие трубопроводов содержит следующую информацию: тип организации, вызвавшей событие (транзакция или блок), его хэш и статус. Статус может быть `Validating` (продолжающаяся валидация), `Rejected` или `Committed`. Если организация была отклонена, указывается причина отказа.

### Попробуй на Taira {#try-it-on-taira}

Проверьте, установлен ли поток событий общественного трубопровода:

```bash
curl -fsSI https://taira.sora.org/v1/events/sse \
  | sed -n '1,12p'
```

Чтобы получить кратковременный снимок, который вы можете проверить без открытия потока, читайте недавние транзакции исследователя:

```bash
curl -fsS 'https://taira.sora.org/v1/explorer/transactions?page=1&per_page=5' \
  | jq '{pagination, txs: [.items[] | {hash, block, status, executable}]}'
```

Откройте маршрут SSE в терминале, когда вам нужны живые события:

```bash
curl -fsS -N https://taira.sora.org/v1/events/sse
```

Если транзакции не подаются, пока поток открыт, команда может оставаться тихой, даже если маршрут является здоровым.

## События с данными {#data-events}

События данных выпускаются, когда происходит изменение, связанное с данными бухгалтерского учета, такими как сверстники, домены, учетные записи, активы, определения активов, NFTs, триггеры, роли, конфигурация в цепочке, состояние исполнения, доказательства, конфиденциальные активы, мосты или объекты, специфические для SORA/Nexus. Такие типы событий используются в фильтрах событий данных [](./filters.md#data-event-filters).

## События во времени {#time-events}

Временные события выделяются, когда взгляд на мировое состояние готов справиться с временными триггерами [](./triggers.md#time-triggers).

## События, вызывающие исполнение {#trigger-execution-events}

События выполнения триггера выпускаются при исполнении инструкции [`ExecuteTrigger`](./instructions.md#executetrigger). События завершения триггера выделяются после завершения действия триггеры.
