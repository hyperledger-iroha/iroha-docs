# События {#events}

Типизированные уведомления о событиях отправляются, когда происходят определённые события в блокчейне, например, создаётся новый аккаунт или выполняется финализация блока. Существуют разные типы событий:

- программное обеспечение для обработки событий рабочего процесса
- события данных
- уведомления о событиях на основе времени
- инициировать события выполнения

## рабочий процесс обработки событий программного обеспечения {#pipeline-events}

События рабочего процесса обработки программного обеспечения генерируются, когда транзакции отправляются, выполняются или завершены в блоке. Событие рабочего процесса обработки программного обеспечения содержит следующую информацию: тип сущности, вызвавшей событие (транзакция или блок), её криптографический хэш и статус. Статус может быть либо `Validating` (проверка в процессе), `Rejected` или `Committed`. Если объект был отклонён, указывается причина отклонения.

### Запустите этот рабочий процесс на Taira {#try-it-on-taira}

Проверьте, что поток событий рабочего процесса обработки общедоступного программного обеспечения смонтирован:

```bash
curl -fsSI https://taira.sora.org/v1/events/sse \
  | sed -n '1,12p'
```

Для снимка данных, который вы можете проверить без открытия потока, прочитайте недавние транзакции в обозревателе:

```bash
curl -fsS 'https://taira.sora.org/v1/explorer/transactions?page=1&per_page=5' \
  | jq '{pagination, txs: [.items[] | {hash, block, status, executable}]}'
```

Откройте маршрут SSE в терминале, когда вам нужны живые события:

```bash
curl -fsS -N https://taira.sora.org/v1/events/sse
```

Если во время открытия потока не будут отправлены транзакции, команда может оставаться тихой, даже если маршрут работает нормально.

## События данных {#data-events}

События данных генерируются, когда происходит изменение, связанное с данными распределенного реестра блокчейна, такими как сетевые узлы, домены, аккаунты, активы, определения активов, NFTs, триггеры, роли, конфигурация в цепочке, состояние исполнителя, доказательства, конфиденциальные активы, мосты или объекты, специфичные для SORA/Nexus. Эти типы событий используются в [фильтры событий данных](./filters.md#data-event-filters).

## уведомления о событиях на основе времени {#time-events}

оповещения о событиях на основе времени испускаются, когда обзор состояния мира готов обработать [временные триггеры](./triggers.md#time-triggers).

## События выполнения триггера {#trigger-execution-events}

События выполнения триггера испускаются, когда [`ExecuteTrigger`](./instructions.md#executetrigger) инструкция выполняется. События завершения триггера испускаются после окончания действия триггера.
