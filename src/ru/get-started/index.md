# Iroha 3 {#iroha-3}

Iroha 3 - это первый выпуск Hyperledger Iroha Платформа.
сети, размещенные самостоятельно, и многопространство данных SORA Nexus модель развертывания с
одна детерминистическая кодовая база.

На высоком уровне, Iroha 3 сочетает:

- детерминистическое исполнение и хранение
- в) Iroha Виртуальная машина (IVM) для портативных смарт-контрактов
- Norito как канонический формат провода
- Torii для клиента, оператора и приложения APIs
- Sumeragi консенсус с обязательной доступностью данных и надежным вещанием
- Канонические учетные записи без доменов с отдельно связанными человекочитаемыми псевдонимами
