и Iroha 3 узел потребляет подписанный Norito файл транзакции.

## Файлы {#files}

Вышестоящий репозиторий отправляет манифест по умолчанию по адресу `defaults/genesis.json`.
Kagami-сгенерированные сети записывают свой собственный манифест и подписанную транзакцию в
выходной каталог:

```bash
cargo run --bin kagami -- localnet --peers 4 --out-dir ./localnet
```

Сгенерированный `README.md` в этот каталог записывает точные файлы и запускает
команды для выбранного профиля.

## Одноранговая конфигурация {#peer-configuration}

Коллеги указывают на подписанную транзакцию генезиса в `[genesis]` раздел
`config.toml`:

```toml
[genesis]
file = "./genesis.signed.nrt"
public_key = "ed0120..."
```

Все узлы в сети должны согласовать подписанную транзакцию генезиса и
Открытый ключ генезиса.

## Подписание Бытия {#signing-genesis}

Если вы редактируете манифест вручную, проверьте и подпишите его перед запуском одноранговых узлов:

```bash
cargo run --bin kagami -- genesis validate ./genesis.json
cargo run --bin kagami -- genesis sign ./genesis.json \
  --private-key-file "$GENESIS_PRIVATE_KEY_FILE" \
  --out-file ./genesis.signed.nrt
```

`GENESIS_PRIVATE_KEY_FILE` должен быть режимом, принадлежащим владельцу.`0600`, однозвенный
обычный файл, содержащий один канонический мультихэш закрытого ключа и финальный
новая строка. Kagami отвергает символические ссылки и никогда не принимает необработанные частные данные о происхождении.
ключ в командной строке.

Для NPoS или Nexus профили, включая топологию и BLS Доказательства владения
требуется созданным профилем. Kagami `localnet`, `wizard`, и профиль
команды генерации обрабатывают эти детали автоматически.

## Повторное совершение Бытия {#recommitting-genesis}

Одноранговый узел фиксирует генезис только тогда, когда его хранилище пусто.Чтобы проверить новый генезис в
одноразовую локальную сеть, остановите узлы, удалите созданный ими каталог состояний,
и начнем с нового подписанного генезиса.Не заменяйте Genesis на работающем двигателе.
сети, если только каждый валидатор не координирует одну и ту же миграцию.
