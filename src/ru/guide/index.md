# Руководство {#guide}

Используйте этот раздел при создании, эксплуатации или интеграции с
Iroha. Начнем с SDK Учебные пособия для первого клиента, затем перейти к
передовые практики и ссылки оператора перед развертыванием против совместного
Сеть.

## Разделы {#sections}

| Раздел                                                      | Используйте его для                                                                                                                  |
| ------------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------- |
| [SDK Учебные пособия](/ru/guide/tutorials/)                           | Конфигурация клиента для языка и образец приложений                                                                      |
| [Лучшие практики](/ru/guide/best-practices/)                     | Руководство, ориентированное на производство, группировано по разработке, моделированию данных, развертыванию, операциям, безопасности и готовности к выпуску |
| [Конфигурация и управление](/ru/guide/configure/overview.md) | Местная конфигурация сверстников, генезис, конфигурации клиента, ключи и управление сверстниками                                          |
| [Безопасность](/ru/guide/security/)                                 | Ключевое управление, операционная безопасность. VPNs, мониторинг мошенничества и гигиена разрешений                                          |
| [Усовершенствованные операции](/ru/guide/advanced/metrics.md)            | Установки, проверка производительности, испытания хаоса, перезагрузка на горячем воздухе и эксплуатация с голой металлом                                            |

## Рекомендуемый путь {#recommended-path}

1. [Установка Iroha 3](/ru/get-started/install-iroha.md) и
   [запустить локальную сеть](/ru/get-started/launch-iroha.md).
2. Выберите [SDK Учебное пособие](/ru/guide/tutorials/) и представить небольшую
   транзакции.
3. Обзор
   [Разработка приложений](/ru/guide/best-practices/application-development.md)
   и [Моделирование данных](/ru/guide/best-practices/data-modeling.md) ранее
   формирование заявки API.
4. Использование [Развертывание сети](/ru/guide/best-practices/network-deployment.md),
   [Операции](/ru/guide/best-practices/operations.md), и
   [Безопасность и доступ](/ru/guide/best-practices/security-and-access.md)
   перед запуском совместной или производственной сети.
5. Следуйте [Готовность освобождения](/ru/guide/best-practices/release-readiness.md)
   при продвижении от местного развития до Taira, Minamoto, или другой
   - Прямое развертывание.
