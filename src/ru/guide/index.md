# Руководство {#guide}

Используйте этот раздел при создании, эксплуатации или интеграции с Iroha. Начните с учебников SDK для первого клиента, а затем перейдите к лучшим практикам и справочникам оператора перед развертыванием против общего сети.

## Разделы {#sections}

|Раздел|Используйте его для |
| ------------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------- |
| [SDK Руководство](/ru/guide/tutorials/) |Настройка клиента на языке и образец приложений |
| [Лучшие практики](/ru/guide/best-practices/) |Руководство по производству, сгруппированное по разработке, моделированию данных, развертыванию, операциям, безопасности и готовности к выпуску |
| [Конфигурация и управление ](/ru/guide/configure/overview.md) |локальная конфигурация сверстников, генезис, конфигурации клиента, ключи и управление сверстниками |
| [Безопасность](/ru/guide/security/)|Управление ключами, эксплуатационная безопасность, VPNs, мониторинг мошенничества и гигиена разрешений |
| [Продвинутые операции](/ru/guide/advanced/metrics.md) |Показатели, проверка производительности, испытания хаоса, перезагрузка на горячем воздухе и работа с голым металлом |

## Рекомендуемый путь {#recommended-path}

1. [Установка Iroha 3](/ru/get-started/install-iroha.md) и [запустить локальную сеть](/ru/get-started/launch-iroha.md).
2. Выберите учебник [SDK](/ru/guide/tutorials/) и отправьте небольшую транзакцию.
3. Пересмотр [Развитие приложений](/ru/guide/best-practices/application-development.md) и [Моделирование данных](/ru/guide/best-practices/data-modeling.md) перед формированием заявки API.
4. Используйте [ Сетевое развертывание](/ru/guide/best-practices/network-deployment.md), [Операции](/ru/guide/best-practices/operations.md) и [Безопасность и доступ](/ru/guide/best-practices/security-and-access.md) перед запуском совместной или производственной сети.
5. Следуйте [Release Readiness](/ru/guide/best-practices/release-readiness.md) при продвижении из местной разработки в Taira, Minamoto или другую прямую развертывание.
