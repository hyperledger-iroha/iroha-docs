# Обеспечение безопасности {#security}

При использовании Iroha или любой другой блокчейн-книги для этого вопросабезопасность имеет первостепенное значение для финансовых организаций, поскольку она формирует основу доверия в отрасли, где конфиденциальные финансовые данные и транзакции являются рутинными. Успешное нарушение безопасности, совершенное злонамеренной стороной, может привести к разрушительным последствиям для вас.

### Навигация {#navigation}

В этом разделе вы узнаете о различных аспектах обеспечения безопасности своей сети Iroha .

- [Принципы безопасности](./security-principles):

Основные принципы безопасности, которые могут быть приняты лицами и организациями для защиты своих данных и уменьшения шансов на утечку информации.

- [Виртуальные частные сети](./vpn.md):

Как использовать VPN для ограничения доступа между партнерами, Torii, а также оператора в частных или консорциумных развертываниях.

- [Операционная безопасность](./operational-security.md):

Лучшие практики для обеспечения безопасности повседневных операций вашей сети, включая контроль доступа, мониторинг, реагирование на инциденты, использование браузеров и т. д.

- [Контроль за мошенничеством](./fraud-monitoring.md):

Как использовать учетные записи событий, запросов, разрешений и операционных сигналов для обнаружения подозрительных действий и сохранения доказательств реакции.

- [Паролевая безопасность](./password-security.md):

Глубокое погружение в энтропию паролей, создание сильных паролей и избежание уязвимостей паролей.

- [Криптовалюты с открытым ключом ](./public-key-cryptography.md):

Введение в общедоступную криптографию ключей, шифрование, подписи и их роль в установлении безопасной коммуникации в блокчейн.

  - [Генерация криптографических ключей](./generating-cryptographic-keys.md):

Инструкции о том, как генерировать криптографические ключи и использовать `kagami` (поддерживающий инструмент, отправленный вместе с Iroha).

  - [Сохранение криптографических ключей](./storing-cryptographic-keys.md):

Лучшие практики для обеспечения безопасности ваших криптографических ключей с помощью различных подходов, которые также могут быть объединены.
