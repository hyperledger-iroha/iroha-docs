# Безопасность пароля {#password-security}

Пароли могут защищать консоли операторов, секретные хранилища, резервные копии и локальные ключевые файлы. Пароль является лишь одним средством защиты. Используйте его вместе с безопасным хранением ключей, контролем доступа и многофакторной аутентификацией, где это возможно.

## Используйте уникальные сгенерированные пароли {#use-unique-generated-passwords}

- Создавайте разные пароли для каждой учётной записи и окружения.
- Используйте менеджер паролей для создания и хранения длинных случайных паролей.
- Используйте многословную парольную фразу только тогда, когда её слова выбраны случайным образом из достаточно большого списка.
- Не включайте в пароли имена, даты, адреса, цитаты, комбинации клавиш и повторно используемые фрагменты.
- Используйте сгенерированный службой токен или криптографический ключ вместо пароля, введенного человеком, если служба поддерживает этот метод.

Длина и непредсказуемость имеют большее значение, чем декоративные замены. Добавление одного символа к предсказуемому слову не делает результат безопасным.

## Защитите аккаунты с паролем {#protect-password-based-accounts}

- Включите многократную аутентификацию, устойчивую к фишингу, там, где она доступна.
- Применяйте ограничения по частоте запросов, политику блокировки и оповещения при повторных неудачных попытках аутентификации.
- Отправляйте пароли только через аутентифицированные, зашифрованные каналы.
- Храните пароли и коды восстановления вне логов, командных строк, репозиториев исходного кода, конфигурационных файлов, тикетов и чатов.
- Храните серверные проверочные данные пароля с использованием функции хэширования пароля с солью и высокой затратностью по памяти, а также с параметрами, соответствующими развертыванию.

## Хранение, восстановление и замена {#storage-recovery-and-replacement}

- Используйте проверенный менеджер паролей с зашифрованными, протестированными резервными копиями.
- Храните коды восстановления отдельно от устройства, которое они восстанавливают. Защищённая офлайн бумажная копия может быть подходящей для материалов восстановления.
- Ограничьте доступ к экспортам менеджеров паролей и резервным носителям.
- Замените пароль после предполагаемого раскрытия, несанкционированного повторного использования или события, требующего замены пароля в соответствии с политикой.
- Проверьте процедуры восстановления учётных записей до запуска в промышленной среде.

::: warning

Пароль, который разблокирует закрытый ключ, не может сделать безопасной открытую копию этого ключа. Если есть подозрение на раскрытие закрытого ключа, следуйте процедурам замены или отзыва ключа в системе развертывания.

:::
