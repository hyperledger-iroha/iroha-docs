# `iroha3d` CLI {#iroha3d-cli}

`iroha3d` является стандартным демоном сети Iroha 3. Пакет Cargo называется `irohad`, поэтому запускайте бинарный файл из рабочей копии исходного кода с помощью:

```shell
cargo run -p irohad --bin iroha3d -- --config path/to/config.toml
```

Для публичного тестнета Taira образ релиза использует `iroha3d_taira`. Он принимает тот же CLI, но дополнительно обеспечивает канонический профиль цепочки Taira, валидатора, хранилища и подписи времени выполнения. Проверьте конфигурацию Taira без раскрытия учетных данных времени выполнения программного обеспечения следующим образом:

```shell
iroha3d_taira --sora \
  --config /etc/iroha/taira/config.toml \
  --check-config
```

Используйте канонический профиль Taira с подставленными оператором значениями: шаблон в репозитории всё ещё содержит заполнители развёртывания. При проверке Taira не подменяйте его общими настройками SORA Nexus или производственными настройками SoraFS.

## `--config` {#arg-config}

- Тип: путь к файлу
- Псевдоним: `-c`

Путь к [конфигурация сетевого узла](/ru/reference/peer-config/index.md).

## `--genesis-manifest-json` {#arg-genesis-manifest-json}

- Тип: путь к файлу

Опциональный технический манифест генезиса блокчейна JSON, используемый для проверки консенсуса.

## `--check-config` {#arg-check-config}

Проверьте разрешённую конфигурацию и доступный материал генезиса блокчейна, затем выйдите, не привязывая сетевые сокеты.

## `--json` {#arg-json}

- **Тип:** флаг
- **Требуется:** `--check-config`

Вывести значения совместимости этой сборки и конфигурации одним объектом Norito JSON вместо строки `Ready` или `Pending`.

## `--check-storage` {#arg-check-storage}

- **Тип:** флаг
- **Несовместим с:** `--check-config`

Проверить хранилище Kura и новейший снимок остановленного узла декодерами этой сборки в режиме только чтения, вывести результат одним объектом Norito JSON и завершиться с ненулевым кодом при ошибке. Проверка захватывает блокировку корня хранилища Kura, поэтому отказывается работать с хранилищем, которым владеет запущенный узел. Она никогда не изменяет хранилище и не открывает секреты, доступные только во время исполнения.

## `--check-replay` {#arg-check-replay}

- **Тип:** флаг
- **Несовместим с:** `--check-config`, `--check-storage`

Повторно исполнить копию хранилища остановленного узла этой сборкой и вывести результат одним объектом Norito JSON. Команда копирует блоки во временный каталог, восстанавливает там новейший снимок либо заново исполняет подписанный генезис, затем повторно исполняет все последующие блоки. Она завершается с ненулевым кодом, если блок не воспроизводит свой сертифицированный результат или отсутствует необходимое тело блока; команда никогда не записывает в исходное хранилище и не открывает секреты, доступные только во время исполнения.

## `--require-genesis-inrou-deployment-authority` {#arg-require-genesis-inrou-deployment-authority}

- **Тип:** идентификатор учётной записи
- **Требуется:** `--check-config`

При автономной проверке требовать, чтобы эта зарегистрированная учётная запись сохранила полномочия развёртывания SoraCloud после исполнения точного подписанного генезиса.

## `--sumeragi-assert-fresh-key` {#arg-sumeragi-assert-fresh-key}

- **Тип:** флаг

Только при этой загрузке заявить, что ключи консенсуса узла никогда не подписывали сообщения этой цепочки. Sumeragi ведёт для каждого ключа запись безопасности и при её отсутствии ничего не подписывает, пока не получит доказательство, что запись не была утрачена. Передайте этот флаг один раз при первой загрузке нового ключа и никогда не используйте его после потери данных.

## `--trace-config` {#arg-trace-config}

- Тип: флаг
- Окружающая среда: `TRACE_CONFIG`

Включите трассировку журналов при чтении и разборе слоев конфигурации.

## `--config-blake3` {#arg-config-blake3}

- Тип: 64-значное шестнадцатеричное BLAKE3 криптографическое значение хэша
- Требуется: `--config`

Требовать, чтобы байты файла конфигурации соответствовали предоставленному значению криптографического дайджеста. Файл с привязкой к целостности должен быть уплощённым; он не может содержать `extends`.

## `--terminal-colors` {#arg-terminal-colors}

- Тип: Boolean, передаётся как `--terminal-colors=true` или `--terminal-colors=false`
- По умолчанию: обнаружение возможностей терминала
- Окружающая среда: `TERMINAL_COLORS`

Управление выводом цвета ANSI.

## `--language` {#arg-language}

- Тип: строка

Переопределите язык системы, используемый для сообщений демона.

## `--sora` {#arg-sora}

- Тип: флаг
- Окружающая среда: `IROHA_SORA_PROFILE`

Включить профиль SORA Nexus для SoraFS, рукопожатия SoraNet и консенсуса с несколькими линиями. Средство запуска Taira всегда вызывается с этим флагом.

## FastPQ переопределяет {#fastpq-overrides}

`--fastpq-execution-mode <MODE>` и `--fastpq-poseidon-mode <MODE>` принимают только `cpu` или `gpu`. Остальные варианты переопределяют метки телеметрии:

- `--fastpq-device-class <LABEL>`
- `--fastpq-chip-family <LABEL>`
- `--fastpq-gpu-kind <LABEL>`

Например:

```shell
iroha3d --fastpq-execution-mode gpu \
  --fastpq-poseidon-mode cpu \
  --fastpq-device-class apple-m4 \
  --fastpq-chip-family m4 \
  --fastpq-gpu-kind integrated
```

## Созданная помощь {#generated-help}

Сводка параметров выше соответствует определениям аргументов `iroha3d` в закреплённом коммите Iroha. Чтобы посмотреть точную справку для вашей рабочей копии, выполните:

```shell
cargo run --locked -p irohad --bin iroha3d -- --help
```
