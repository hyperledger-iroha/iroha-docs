# Название конгрессов {#naming-conventions}

Когда вы называете счета, домены или активы, вы должны иметь в виду следующие конвенции, используемые в Iroha:

1. Существует ряд резервированных сепараторов, которые используются для конкретных типов конструкций:

   - `@` зарезервировано для анонимных имен счетов и форм с учетной записью/общественным ключом
   - `#` зарезервировано для алфавитов на определение активов и буквы баланса активов
   - `::` зарезервирована для контрактных псевдоним
   - `.` предназначена для квалификации доменов и пространства данных
   - `$` зарезервировано для текстовых форм с разрешением на запуск
   - `%` зарезервировано для текстовых форм, проверенных валидатором.

2. Максимальное количество символов (включая символы UTF-8), которые может иметь название, ограничивается двумя факторами: `[0, u32::MAX]` и распределенным в настоящее время пространством на стеке.

## Попробуй на Taira {#try-it-on-taira}

Разрешить прозвище публичного актива в его каноническом определении активов ID:

```bash
curl -fsS https://taira.sora.org/v1/assets/aliases/resolve \
  -H 'content-type: application/json' \
  -d '{"alias":"usd#wonderland"}' \
  | jq '{alias, asset_definition_id, asset_name, status: .alias_binding.status}'
```

Сравните это с списком определения активов:

```bash
curl -fsS 'https://taira.sora.org/v1/assets/definitions?limit=20' \
  | jq -r '.items[] | select(.alias != null) | [.alias, .id, .name] | @tsv'
```

Характер `#` отделяет псевдоним актива от контекста домена. Держите его подальше от простых имен, если вы не намеренно пишете псевдониму актива или буквальный баланс активов.
