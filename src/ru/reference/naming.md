# Название конгрессов {#naming-conventions}

Когда вы называете аккаунты, домены или активы, вы должны иметь в виду
следующие конвенции, используемые в Iroha:

1. Существует ряд резервированных разделителей, которые используются для конкретных
   типы конструкций:

   - `@` зарезервировано для фамилий счетов и форм с учетом целевой аудитории/государственного ключа
   - `#` предназначен для алфавитов определения активов и букв баланса активов
   - `::` зарезервировано для контрактных псевдоним
   - `.` зарезервировано для квалификации домена и пространства данных
   - `$` предназначен для текстовых форм с разрешением на запуск
   - `%` зарезервировано для текстовых форм, проверенных валидатором

2. Максимальное количество символов (включая UTF-8 символы) может быть название
   уменьшается двумя факторами: `[0, u32::MAX]` и в настоящее
   распределенное пространство на стеке.

## Попробуй . Taira {#try-it-on-taira}

Разрешить прозвище публичного актива в его каноническом определении активов ID:

```bash
curl -fsS https://taira.sora.org/v1/assets/aliases/resolve \
  -H 'content-type: application/json' \
  -d '{"alias":"usd#wonderland"}' \
  | jq '{alias, asset_definition_id, asset_name, status: .alias_binding.status}'
```

Сравните это с списком определения активов:

```bash
curl -fsS 'https://taira.sora.org/v1/assets/definitions?limit=20' \
  | jq -r '.items[] | select(.alias != null) | [.alias, .id, .name] | @tsv'
```

Сборник `#` Характер отделяет псевдоним актива от контекста домена.
простых имен, если вы не намеренно пишете фамилию актива или актив
баланс буквально.
