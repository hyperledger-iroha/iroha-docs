# Токены разрешений {#permission-tokens}

На этой странице перечислены типы токенов разрешений по умолчанию, доступные в текущей модели данных исполнителя Iroha. Для концептуального руководства по ролям и разрешениям смотрите [Разрешения](/ru/blockchain/permissions.md).

Проверки разрешений выполняются активным проверяющим времени выполнения программного обеспечения. Названия типов токенов ниже описывают стандартную политику, но сеть может настроить проверку времени выполнения программного обеспечения, обновив исполнитель.

## Собственность {#ownership}

Токены разрешений, чувствительные к владельцу, должны ссылаться на канонические идентификаторы объектов, используемые текущей моделью данных. Например, разрешения учетной записи ссылаются на канонические идентификаторы учетных записей без домена, а разрешения домена ссылаются на `domain.dataspace` идентификаторы домена, и разрешения на активы относятся к каноническому определению актива или идентификаторам актива.

Когда транзакция не проходит из-за ошибки авторизации, проверьте обе стороны:

- учетная запись, подписывающая транзакцию, является ожидаемой канонической учетной записью
- токен разрешения или роль были предоставлены для точного идентификатора объекта, использованного в инструкции
