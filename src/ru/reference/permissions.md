# Токены разрешения {#permission-tokens}

На этой странице представлен список типов разрешений по умолчанию , выявленных в текущем Iroha Для концептуального руководства по ролям и разрешениям см. [Разрешения](/ru/blockchain/permissions.md).

Проверка разрешений выполняется активным валидатором запуска. Названия типов токенов ниже описывают стандартную поверхность политики, но сеть может настроить проверку запуска путем обновления исполнителя.

## Собственность {#ownership}

Токены разрешений, чувствительные к владельцу, должны относиться к каноническому объекту IDs, используемому в текущей модели данных. Например, разрешения учетной записи относятся к канонической учетной записи без домена IDs, разрешения домена - к домену `domain.dataspace` IDs; и разрешения на активы относятся к каноническому определению активов или активам IDs.

Когда транзакция проваливается с ошибкой в разрешении, проверьте обе стороны:

- учетный счет, подписывающий транзакцию, является ожидаемым каноническим учетом
- Токен разрешения или роль была предоставлена для точного объекта ID, использованного в инструкции.
