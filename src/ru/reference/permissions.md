# Токены разрешения {#permission-tokens}

На этой странице приведен список типов разрешений по умолчанию , выявленных текущим
Iroha для концептуального руководства по ролям и разрешениям,
Смотрите [Разрешения](/ru/blockchain/permissions.md).

Проверки разрешений выполняются активным валидатором времени запуска.
ниже названия описывают стандартную политическую поверхность, но сеть может настроить
валидация времени запуска путем обновления исполнителя.

## Собственность {#ownership}

Токены разрешений , чувствительные к владельцу , должны сопровождаться каноническим объектом IDs используется
Например, разрешения на учетные записи относятся к каноническим
учетная запись без домена IDs, Доменные разрешения относятся к `domain.dataspace` домен
IDs, и разрешения на активы относятся к каноническому определению или активу IDs.

Если транзакция не работает с ошибкой в разрешении, проверьте обе стороны:

- счет, подписывающий транзакцию, является ожидаемым каноническим счетом
- Токен или роль разрешения была предоставлена для точного объекта ID используется в
  инструкции
