# Запросы {#queries}

Iroha запросы считывают состояние распределённого реестра блокчейна без его изменения. Текущая модель данных предлагает две основные формы запросов:

- единственные запросы, которые возвращают один объект или одно значение
- итерируемые запросы, которые возвращают поток или коллекцию и могут комбинироваться с фильтрацией, сортировкой, проекцией и пагинацией, там где это поддерживает тип запроса

Используйте типизированные построители SDK или CLI вместо ручного создания контейнеров данных запроса. Ниже приведены названия текущих типов запросов, доступных через `iroha_data_model::query`.

## Фильтрация и постраничная навигация {#filtering-and-pagination}

Итерабельные запросы могут предоставлять поддержку предикатов и селекторов. Используйте типизированные фильтры, специфичные для запроса, из SDK, чтобы входные данные фильтра соответствовали типу вывода запроса. Для больших наборов результатов используйте параметры запроса, такие как курсор и лимит, вместо того чтобы извлекать все строки сразу.
