# SDK Dərsliklər {#sdk-tutorials}

Bu səhifələr əsas iş sahəsindən göndərilən Iroha 3 müştəri giriş nöqtələrini ümumiləşdirir, burada vahid protokol-standart paket adları, quraşdırma yolları və minimal başlanğıc nöqtələri daxil olmaqla.

## Tövsiyə olunan Sıra {#recommended-order}

1. [Iroha 3 Quraşdır](/az/get-started/install-iroha.md)
2. [Başlat Iroha 3](/az/get-started/launch-iroha.md)
3. Bir SDK seçin:
   - [Rust](/az/guide/tutorials/rust.md)
   - [Python](/az/guide/tutorials/python.md)
   - [JavaScript / TypeScript](/az/guide/tutorials/javascript.md)
   - [Kotlin, Android və Java](/az/guide/tutorials/kotlin-java.md)
   - [Swift və iOS](/az/guide/tutorials/swift.md)
4. [nümunə tətbiqlər](/az/guide/tutorials/sample-apps.md)-ə baxın, əgər tam müştəri tətbiqi istinadına ehtiyacınız varsa.
5. Öz tətbiqinizə cüzdan dəstəyi olan audio/video iclaslar əlavə etmək istədiyiniz zaman [Yerləşdir Kaigi](/az/guide/tutorials/kaigi.md) istifadə edin.
6. Yenidən istifadə oluna bilən Kotodama mənbə kitabxanalarına ehtiyacınız olduqda və zəncirdəki qeydiyyat asılılıqları möhkəmləndirilmişsə, [Musubi paketlər](/az/guide/tutorials/musubi.md)-dən istifadə edin.

## Nümunələr {#samples}

Yuxarı axın iş sahəsi JavaScript reseptləri və Swift/iOS nümunə layihələrini ehtiva edir. Android üçün Kotlin SDK modulları və onların testləri ilə başlayın.

- [Nümunə tətbiqlərin icmalı](/az/guide/tutorials/sample-apps.md)
- [Kaigi ilə JavaScript tətbiqində yerləşdirin](/az/guide/tutorials/kaigi.md)

## Həqiqətin Mənbəyi {#source-of-truth}

Bütün SDK səhifələr burada mövcud yuxarı axın iş sahəsindən götürülür:

- `crates/iroha`
- `python/iroha_python`
- `javascript/iroha_js`
- `kotlin`
- `java/iroha_android` (Kotlin-ilk Android səthin Java güzgüsü)
- `IrohaSwift`
- `crates/musubi`

Şübhə olduqda, həmin kataloqlardakı README və paket metadatasını seçin; onlar sizin tikdiyiniz mənbə versiyasını təsvir edir.
