# Iroha 3 {#iroha-3}

Iroha 3 ilk buraxılış Hyperledger Iroha platformasıdır. O, özünü hosted şəbəkələri və bir deterministik kod bazasından çox məlumat məkanı SORA Nexus tətbiq modelini dəstəkləyir.

Yüksək səviyyədə Iroha 3 aşağıdakıları birləşdirir:

- Deterministik icra və saxlama
- portativ ağıllı müqavilələr üçün Iroha Virtual Maşın (IVM)
- Norito kanonik tel formatı kimi
- Torii müştəri, operator və tətbiqlə üzləşən üçün APIs
- Sumeragi məcburi məlumatların mövcudluğu və etibarlı yayımla razılaşmaq
- ayrı-ayrı bağlanmış, insan tərəfindən oxuna bilən adları olan domensiz kanonik hesablar
