# Iroha 3 {#iroha-3}

Iroha 3 Hyperledger Iroha platformasının ilk buraxılışıdır. Eyni deterministik kod bazası həm öz infrastrukturlarında yerləşdirilən şəbəkələri, həm də çoxməlumat-məkanlı SORA Nexus yerləşdirmə modelini dəstəkləyir.

Yüksək səviyyədə, Iroha 3 birləşdirir:

- deterministik icra və saxlanma
- Iroha Virtual Maşın (IVM) portativ ağıllı müqavilələr üçün
- Norito tək protokol-standart serializasiya formatı olaraq
- Torii müştəri, operator və tətbiqə qarşı APIs
- Sumeragi məcburi məlumat mövcudluğu və etibarlı yayım ilə razılaşma
- ayrı-ayrı bağlı insan tərəfindən oxunan təxəllüslərlə domensiz tək protokol-standart hesablar
