# Һорауҙар {#queries}

Ваҡиға абоненттары һәм фильтрҙар блокчейн хәлендәге үҙгәрештәрҙе күҙәтә ала. Ағымдағы торошҡа туранан-тура ҡарау кәрәк булһа, һорау ҡулланығыҙ.

Һорауҙар - бәләкәй инструкция һымаҡ объекттар. Iroha пирына бер-береһен ебәреп, уның хәҙерге донъя хәле тураһындағы ҡарашы тураһында мәғлүмәт ала.

Селтәр башҡа мәғлүмәтте лә аса ала. Һорау мөмкин булған world-state мәғлүмәте — һәр Iroha селтәрендә булыуы гарантияланған берҙән-бер төр.

Iroha һәр урынлаштырыу өсөн башҡа мәғлүмәт булыуы мөмкин. Мәҫәлән, телеметрия мәғлүмәттәрен алыу селтәр администраторҙарына бәйле. Бүләктәрҙе бүлеп бирергәме, юҡмы - улар үҙҙәре хәл итә. эште эҙләү өсөн эшкәртеү ҡеүәте, ә уны ғәмәлдәге эште башҡарыу өсөн ҡулланыу урынына. Киреһенсә, ҡайһы бер функциялар һәр ваҡыт талап ителә, мәҫәлән, иҫәбенең балансына инеү мөмкинлеге.

Һорауҙарҙың һөҙөмтәләре бер үк ваҡытта [](#sorting), [paginated](#pagination) һәм [ peer-side ](#filters) фильтрланған була. Фильтрлау төрлө принциптар буйынса башҡарыла ала, доменға ярашлы (индивидуаль IP адрес фильтры битлектәре) һәм логик операциялар ярҙамында берләштерелгән `begins_with` кеүек субсыбыҡлы ысулдары.

## Taira менән һынап ҡарағыҙ. {#try-it-on-taira}

Taira дөйөм ресурстар өсөн JSON өҫтөндә уҡырға ғына һорау ярҙамсыларын асыҡлай. Уларҙы SDK менән бәйләнешкә ингәнгә тиклем битләү һәм яуаптар менән эш итеүҙе күнекмәләргә ҡулланығыҙ:

```bash
TAIRA_ROOT=https://taira.sora.org

curl -fsS "$TAIRA_ROOT/v1/accounts?limit=3" \
  | jq '{total, ids: [.items[].id]}'

curl -fsS "$TAIRA_ROOT/v1/domains?limit=3" \
  | jq '{total, domains: [.items[].id]}'

curl -fsS "$TAIRA_ROOT/v1/assets/definitions?limit=3" \
  | jq '{total, assets: [.items[] | {id, name, total_quantity}]}'
```

Программалар диагностикаһы өсөн был тәмәке тикшереүҙәрен ҡул ҡуйылған транзакция һынауҙарынан айырып тороғоҙ. Тик уҡырға ғына бирелгән һорауҙар уңышһыҙлығы, ғәҙәттә, имзалаусы ҡулайлаштырыуҙы күрһәткәнгә тиклем, һуңғы пункттың барлығын, селтәрҙең барып етеүсәнлеген йәки маршрутҡа яраҡлашыуын күрһәтә.

## Һорау яһау {#create-a-query}

SDK йәки CLI нан типланған һорау төҙөүселәрҙе ҡулланығыҙ. Мәҫәлән, ғәмәлдәге мәғлүмәттәр моделе исемлеккә индереү өсөн иҫәптәр өсөн `FindAccounts` аса:

```rust

```

Бында Alice-тың мөлкәтен таба алған һорауҙың миҫалы килтерелә:

```rust
let alice_id = load_canonical_account_id_from_client_config()?;
let query = FindAssetsByAccountId::new(alice_id);
```

## Страничкалар {#pagination}

Берҙән-бер һорауҙар һәм бәләкәй ҡабатлана торған һорауҙар өсөн һеҙ `client.request` ҡулланып, һорауҙы тапшыра алаһығыҙ һәм һөҙөмтәне бер юлы алаһығыҙ.

Әммә `FindAccounts`, `FindAssets` йәки `FindBlocks` кеүек киң iterable queries ҙур result set ҡайтара ала. Peer һәм client йөктәрен кәметеү өсөн pagination ҡулланығыҙ.

`Pagination` төҙөү өсөн һеҙ `client.request_with_pagination(query, pagination)` тип саҡырырға тейешһегеҙ, унда `pagination` түбәндәге рәүешле төҙөлгән:

```rust
let starting_result: u32 = _;
let limit: u32 = _;
let pagination = Pagination::new(Some(starting_result), Some(limit));
```

## Фильтрҙар {#filters}

Һорау яһағанда, һеҙ фильтр менән күрһәтелгән фильтрға тап килгән һөҙөмтәләрҙе генә кире ҡайтарырға мөмкин.

Һорауҙар буйынса фильтрҙар үҙенсәлекле. Мәҫәлән, иҫәп-хисап һорауҙары иҫәбенең идентификацияһы йәки метамәғлүмәттәре менән ҡыҫҡартыла ала, ә актив һорауҙарын активтар менән ҡыҫҡара алалар SDK типтағы һорау төҙөүселәрен мөмкин булған һайын ҡулланығыҙ, шуға күрә фильтр тибы һорау сығарыу тибына тап килә.

## Төрләү {#sorting}

Iroha элементтарын [](/ba/blockchain/metadata.md) метамәғлүмәттәре менән лексикографик рәүештә рәтләй ала, әгәр һеҙ һорауҙы төҙөү барышында рәтләү өсөн асҡыс бирһәгеҙ. Ғәҙәттә ҡулланыу осрағы - иҫәптәрҙең `registered-on` метамәғлимәттәр индереүе була, ул рәтләнгәс, иҫәп яҙмаһының тарихын ҡарарға мөмкинлек бирә.

Сортировка бары тик [ метамәғлүмәттәре булған субъекттарға ғына ҡағыла](/ba/blockchain/metadata.md), сөнки метамәғлимәттәр клавишаһы һорау һөҙөмтәләрен sortлау өсөн ҡулланыла.

Сортылауҙы битләү һәм фильтрҙар менән берләштерә алаһығыҙ. Иҫегеҙгә төшөрөгөҙ, сортировка - һайлап алыу функцияһы, битләү менән бәйле һорауҙарҙың күбеһендә был кәрәкмәйәсәк.
