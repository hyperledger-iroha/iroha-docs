# Ваҡиғалар {#events}

Ваҡиғалар блокчейн эсендә билдәле бер ваҡиғалар булғанда ебәрелә, мәҫәлән, яңы иҫәп яҙмаһы булдырыла йәки блоктар ҡуйыла.

- трубопровод ваҡиғалары
- мәғлүмәт ваҡиғалары
- ваҡыт ваҡиғалары
- башҡарған ваҡиғаларҙы ҡуҙғатыу

## Төҙөүсе үткәргес торбалар {#pipeline-events}

Төҙөүсе торба ваҡиғалары бер блокҡа тапшырылған, башҡарылған йәки йөкмәтелгән транзакцияларҙа сыға. Pipeline ваҡиғаһы түбәндәге мәғлүмәтте үҙ эсенә ала: ваҡиғаға сәбәпсе булған субъекттың төрө (транзакция йәки блок), уның хәш һәм статусы. Статусы булыуы мөмкин `Validating` (тәүгерешле раҫлау), `Rejected`, йәки `Committed`. Әгәр предприятиены кире ҡаҡһалар, уны кире ҡағыу сәбәбе күрһәтелә.

### Taira менән һынап ҡарағыҙ. {#try-it-on-taira}

Йәмәғәт торбаһы ваҡиға ағымы ҡуйылғанлығын тикшерегеҙ:

```bash
curl -fsSI https://taira.sora.org/v1/events/sse \
  | sed -n '1,12p'
```

Асыҡ ағымды һаҡламайынса тикшерергә мөмкин булған фотоһүрәт өсөн, һуңғы тикшеренеүселәрҙең транзакцияларын уҡығыҙ:

```bash
curl -fsS 'https://taira.sora.org/v1/explorer/transactions?page=1&per_page=5' \
  | jq '{pagination, txs: [.items[] | {hash, block, status, executable}]}'
```

SSE маршрутын терминалда асығыҙ, әгәр һеҙгә тура ваҡиғалар кәрәк:

```bash
curl -fsS -N https://taira.sora.org/v1/events/sse
```

Әгәр ағым асыҡ булған ваҡытта бер ниндәй ҙә транзакция тапшырылмай икән, маршрут сәләмәт булһа ла, команда шым ғына ҡала ала.

## Мәғлүмәт ваҡиғалары {#data-events}

Мәғлүмәт ваҡиғалары бухгалтер мәғлүмәттәренә бәйле үҙгәрештәр булғанда сығарыла, мәҫәлән, тиҫтерҙәр, домендар, иҫәптәр, активтар, актив билдәләмәләре, NFTs, триггерҙар, ролдәр, селтәрҙәге конфигурация, башҡарыусы дәүләте, иҫбатламалар, йәшерен активтар, күперҙәр, йәки SORA/Nexus-белгесле объекттар. Был төр ваҡиғалар [ мәғлүмәт ваҡиғалары фильтрҙарында ҡулланыла](./filters.md#data-event-filters).

## Ваҡытлы ваҡиғалар {#time-events}

Ваҡыт ваҡиғалары донъя хәле күренеше [ ваҡыт ҡуҙғытыусыларын](./triggers.md#time-triggers) эшкәртергә әҙер булғанда сығарыла.

## Үтә торған ваҡиғалар {#trigger-execution-events}

[`ExecuteTrigger`](./instructions.md#executetrigger) инструкцияһы үтәлгәс, ҡуҙғатыуҙы башҡарыу ваҡиғалары ебәрелә. Трижерҙы тамамлау ваҡиғалары ҡуҙғатҡыс хәрәкәте тамамланғандан һуң сығара.
