# FastPQ {#fastpq}

FastPQ — һайланған үтәү эффекттары өсөн Iroha-ның STARK иҫбатлау юлы. Ул ғәҙәти транзакция үтәлешен йәки консенсусты алмаштырмай. Транзакциялар элеккесә ISI, IVM һәм Sumeragi аша үтәлә; FastPQ ярҙам ителгән эффекттарҙы һуңынан, блок үтәлеше теркәгән сығанаҡ яҙмаһы нигеҙендә иҫбатлай.

Хәҙерге хост интеграцияһында ике төп юл бар:

- төйөндөң иҫбатлау һыҙаты иҫбатлаған, финалланған блоктарҙың һанлы актив эффекттары
- `fastpq_binding` ҡиммәте FastPQ бәйләнешен йөрөткән SORA Nexus AXT иҫбат ҡапламалары

## Шаһиттарҙы күсергә {#transfer-witness-path}

Прозрачные числовые переводы создают структурированный транскрипт передачи, когда инструкция мутирует балансы.

- сығанаҡ иҫәбе, маҡсат иҫәбенә, актив билдәләмәһе һәм сумма
- ебәреүсе менән ҡабул итеүсенең балансы тапшырыу алдынан һәм унан һуң
- транзакцияға инеү нөктәһе хэшиғы партияһы хэшигы булараҡ ҡулланыла
- тапшырыу иҫәбенән алынған хоҡуҡ сығанағы
- бер дельталы транскрипттар өсөн Poseidon дигесты
- ебәреүсе һәм ҡабул итеүсе баланстары өсөн һирәк Меркл яңыртыу шаһиттары

Партия күсереүҙәрендә бер транскрипт һәм күп кенә дельталар ҡулланыла. Ундай осраҡта бер дельталы Посейдон дайджесты юҡ.

Блок үтәлеше транскрипттарҙы уларҙы сығарған үтәү саҡырыуы буйынса төркөмләй һәм блоктың FastPQ сығанаҡ яҙмаһы менән бергә һаҡлай. AXT күсереү белдереүендә һәр күсереү дельтаһы ике күсеү рәтенә әйләнә:

| Рәт | Асҡыс | Алдағы ҡиммәт | Һуңғы ҡиммәт |
| --------------- | --------------------------------------------------------------------- | ----------------------- | ---------------------- |
| Ебәреүсенән сығым | Актив билдәләмәһе һәм сығанаҡ иҫәбе өсөн `FastpqBalanceKeyV1` | күсереүгә тиклем ебәреүсенең балансы | күсереүҙән һуң ебәреүсенең балансы |
| Ҡабул итеүсе иҫәбенә инеү | Актив билдәләмәһе һәм маҡсат иҫәбе өсөн `FastpqBalanceKeyV1` | күсереүгә тиклем ҡабул итеүсенең балансы | күсереүҙән һуң ҡабул итеүсенең балансы |

Һәр асҡыс — `FastpqBalanceKeyV1` структураһының каноник Norito кадры; уны `transfer_balance_key` типлы актив билдәләмәһенән һәм доменһыҙ иҫәптән төҙөй. Иҫәп псевдонимдары һәм күрһәтеү формалары бер ҡасан да асҡыс материалы булмай.

## Үтәү эффекттары {#execution-effects}

Иҫбатлау һыҙаты тулы үтәү эффекты белдереүҙәрен иҫбатлай. Һәр белдереү бер үтәү яҙмаһының бөтә күләм эффекттарын үтәү тәртибендә үҙ эсенә ала:

| Эффект | Яңыртылған ҡиммәттәр | Ҡағиҙә |
| -------- | ------------------------------ | ------------------------------------------------------------------- |
| Күсереү | сығанаҡ һәм маҡсат балансы | сумма бер активтың ике балансы араһында күсә |
| Сығарыу | баланс һәм дөйөм күләм | икеһе лә бер үк нулдән айырмалы суммаға арта |
| Яндырыу | баланс һәм дөйөм күләм | икеһе лә бер үк суммаға кәмей |
| Әйләнештән сығарыу | дөйөм күләм һәм йәшәү циклы | дөйөм күләм нуль булып ҡала, ә активтың булыуы берҙән нулгә үҙгәрә |

Дөйөм күләм бер ҡасан да баланстан түбән төшмәй. Һәр асҡыс `iroha:fastpq:execution-quantity-key:v1` доменынан, NUL байтынан һәм `FastpqExecutionQuantityKeyV1` баланс, дөйөм күләм йәки йәшәү циклы асҡысының Norito кодлауынан тора. Роль биреү, ролде кире алыу һәм башҡа операциялар иҫбатланмай.

Үтәү эффекты һәм AXT күсереү белдереүҙәрендәге ҡиммәттәр — активтың унлыҡ масштабындағы теүәл, тиҫкәре булмаған бөтөн һанлы берәмектәр (`FastpqQuantityUnits`), шуға күрә улар `u64` менән сикләнмәй. Белдереүҙе төҙөү масштаб тап килмәүен, тиҫкәре айырманы һәм теләһә ниндәй арифметик йәки тәртип ярашһыҙлығын кире ҡаға; ул бер ҡасан да асыҡ ҡиммәтте төҙәтмәй.

## Йәмәғәт иғәнәләре {#public-inputs}

Һәр FastPQ белдереүе иҫбатты блокка һәм үтәү контексына бәйләүсе асыҡ инеү ҡиммәттәрен йөрөтә:

|Ҡалыптар |Мәғәнәһе |
| ------------- | ------------------------------------------------------------------------------------ |
| `dsid` | Мәғлүмәт киңлеге идентификаторы: уның кесе байттан башланған тәртиптәге `u64` ҡиммәте, унан һуң һигеҙ нуль байт |
| `slot` | Блоктың булдырылыу ваҡыты наносекундтарҙа, миллисекунд теүәллеге менән |
| `old_root` | Белдереүгә тиклем ҡағылған асҡыстарҙың һирәк Меркл ағасы тамыры |
| `new_root` | Белдереүҙән һуң ҡағылған асҡыстарҙың һирәк Меркл ағасы тамыры |
| `perm_root` | Үтәүсе тороштоң роль-рөхсәт таблицаһына йөкләмә |
| `tx_set_hash` | Блоктың транзакцияларының тапшырыу кодлауҙарына блок тәртибендә йөкләмә |

`old_root` һәм `new_root` белдереү ҡағылған асҡыстарҙы ғына үҙ эсенә ала. Улар һаҡланған донъя торошо тамыры түгел.

`perm_root` — Iroha-ның `fastpq:v1:permission-table:blake2b-256` доменынан, кесе байттан башланған `u64` рәүешендәге яҙмалар һанынан һәм сортланған яҙмаларҙан иҫәпләнгән 32 байтлы `Hash` ҡиммәте. Һәр яҙма роль ID-һының хешынан, уның рөхсәттәренең береһенең хешынан һәм шул рөхсәттең кесе байттан башланған `u64` рәүешендәге эпохаһынан тора. Буш таблица 32 нуль байтҡа беркетелә. Был роль һәм рөхсәт контексы ғына; ул иҫәп ағзалығын йәки авторизацияны иҫбатламай.

`tx_set_hash` — Iroha-ның `iroha:axt:ordered-transaction-wire-set:v1` доменынан, NUL байтынан, транзакциялар һанынан һәм блок тәртибендә һәр транзакция өсөн уның тапшырыу оҙонлоғонан һәм тулы тапшырыу байттарынан иҫәпләнгән `Hash` ҡиммәте. Һан һәм оҙонлоҡтар — кесе байттан башланған `u64` ҡиммәттәре. Транзакциялар сортланмай һәм ҡабатланыуҙарҙан таҙартылмай, ә ҡултамғалар прообразда ҡала.

Iroha-ның `Hash` функцияһы — һуңғы байтының иң түбәнге бите бергә ҡуйылған Blake2b-256. Белдереү шулай уҡ тәртип хешын һәм үҙенең тулы каноник рәттәрен һәм сығанаҡ факттарын йөрөтә; иҫбат уларҙың барыһын да бәйләй.

Каноник FastPQ артефакттары — Goldilocks ҡыры өҫтөндә 4-се дәрәжәле киңәйтеү менән төҙөлгән маскаланған DEEP иҫбатлауҙары. Саҡырыусылар ғәҙәти йәки AXT белдереүен һәм ресурс сиктәрен һайлай. Улар схемаларҙы, тикшереү асҡыстарын, һорауҙар һанын йәки транскрипттың эске өлөштәрен һайламай. Ғәҙәти маршрут — `offline_compact::prove_quantity_ordinary_artifact`; AXT маршруты — `offline_compact::prove_quantity_axt_artifact`, уны `prove_axt_bound_batch` бәйләнгән партиялар өсөн урап ала. Үтә күренмәле `Prover`, `Proof` һәм ҡабаттан уйнатыу өсөн `verify` API-һы тестарҙа һәм `dev-tools` йыйылмаларында ғына бар.

## Иҫбат нимәне тикшерә {#what-the-proof-checks}

Теләһә ниндәй йәшерен эш алдынан етештереүсе асыҡ белдереүҙе әҙерләй. Ул иҫәптәрҙе, суммаларҙы, ҡиммәттәрҙе, осраҡтар һанын, тотороҡло асҡыс тәртибен һәм асҡыс бүлеүҙе тикшерә һәм асыҡ факттары бер-береһенә тап килмәгән белдереүҙе кире ҡаға. Унан һуң мөһөрләнгән мөнәсәбәт һәр сегментта бер эффекттың йәки бер күсереү осрағының ике тулы 32 кимәлле һирәк Меркл яңыртыуын иҫбатлай. Стандарт сиктәр бер артефактта иң күбе ике сегментҡа рөхсәт итә.

Һәр эҙҙә 65,536 рәт бар. Етештереүсе 301 йәшерен бағанаға йөкләмә ҡуя, ә тикшереүсе 41 асыҡ бағананы үҙаллы ҡабаттан төҙөй. Яңы криптографик энтропия эҙ бағаналарын, өлөштө һәм айырым йөкләмә ҡуйылған композиция күпбыуынын маскалай. Өлөштө табыу өсөн бүлеү ҡалдыҡһыҙ булырға тейеш. Етештереүсе үҙ артефактын ҡайтарыр алдынан уны үҙе тикшерә.

Асыҡ белдереү ҡиммәттәре йәшерелмәй. Операцияның тапшырыу форматында булыуы уны ҡабул итеүгә нигеҙ түгел: мөнәсәбәттәр юғарыла һанап кителгән эффекттар өсөн генә бар, ә AXT белдереүҙәре шаһитлы күсереүҙәрҙе генә ҡабул итә.

## Проверка Лейн {#prover-lane}

Kura `init_mode = "fast"` менән старт алмаһа, `iroha3d` төйөн эшләй башлағанда, Torii ебәреүҙәрҙе ҡабул итә башлағансы, бер FastPQ иҫбатлау эшсе процесын старт итә. Эшсе процесс үҙ бэкендын фонда инициализациялай, шуға күрә инициализация уңышһыҙ булһа ла старт дауам итә; был осраҡта һыҙат һүндерелгән килеш ҡала.

Эшсе процесс төйөндөң финалланған торошон һәм Kura һаҡлағысын даими һорап тора. Һәр финалланған блок өсөн ул аутентификацияланған сығанаҡты ала (сығанаҡ һаҡланмаған булһа, урындағы үтәүҙе ҡабаттан уйнатып) һәм блоктың тулы белдереүҙәрен ғәҙәти маршрут менән берәмләп иҫбатлай. Ҡабаттан старттан һуң ул аутентификацияланған префиксты беркетелгән ҡултамғалы генезистан ҡабаттан төҙөй. Һәр артефактты Kura-ның сикләнгән FastPQ һаҡлағысында һаҡлай. Һаҡланған артефакт — иғлан ғына: артабанғы блокка күсер алдынан етештереүсе сығанаҡты аутентификациялай һәм артефактты ҡабаттан тикшерә.

Иҫбат етештереү төйөн эсендә генә бара. Ул транзакцияны ҡабул итеү йәки консенсус шлюзы түгел: үтәү, беркетеү һәм финаллыҡ иҫбатты көтмәй. Ҡабатлап була торған хата эште һуңыраҡ ынтылышҡа ҡалдыра, һәм һәр процеста бер етештереүсе эшләй.

## Тикшереү {#verification}

Тикшереүсе артефактты үҙенең аутентификацияланған белдереүенән сығарылған көтөлгән ҡиммәттәр менән сағыштыра; был ҡиммәттәр бер ҡасан да тикшерелгән артефакттың үҙенән алынмай. Тикшереү һәр сегментты сиктәр эсендә бер тапҡыр декодлай, AIR-ҙы домендан тыш нөктәлә бер тапҡыр баһалай, һәр асылған рәтте, өлөш япрағын һәм FRI епселен, шулай уҡ тулы FRI терминалын йөкләмә ҡуйылған тамырҙарға ҡаршы аутентификациялай һәм иң күбе 385 бөкләү тикшереүен башҡара. Ул бер ниндәй ҙә йәшерен шаһит, эҙ йәки тулы түбән дәрәжәле киңәйтеү төҙөмәй.

Уңышлы тикшереү саҡырыусының көтөлгән ҡиммәттәре менән тап килеүҙе раҫлай. Ул бер ниндәй ҙә үтәү вәкәләтен, сығанаҡ финаллығын, ҡабаттан уйнатыуға рөхсәт йәки AXT сарыф итеү авторизацияһын бирмәй.

Ғәҙәти маршрут та ҡулланған `offline_compact::VerificationLimits` эсендәге стандарт сиктәр:

|Сикләү |Дефолт |
| ------------------------------- | ------------: |
| Бер артефакттағы сегменттар | 2 |
| Артефакттың тапшырыу байттары | 1 MiB |
| Эске иҫбат кадры | 500,084 байт |
| Бөтә сегменттар буйынса белдереү байттары | 512 KiB |
| Бер сегменттағы һорауҙар | 77 |
| Бөтә сегменттар буйынса һорауҙар | 154 |

Төйөн һыҙаты артефакттың тапшырыу байттарын өҫтәмә рәүештә `zk.fastpq.proof_sidecar_max_bytes` ҡиммәте һәм Kura-ның FastPQ объект сиге менән сикләй. Декодлауға тиклем AXT иҫбат блобы иң күбе 2 MiB, ә уның эсендәге FastPQ файҙалы йөгө иң күбе 1 MiB була ала.

## SORA Nexus AXT иҫбат ҡапламалары {#sora-nexus-axt-proof-envelopes}

SORA Nexus AXT иҫбат ҡапламалары `AxtFastpqBinding`-ты үҙ эсенә ала ала. AXT ҡапламаларын блок кимәлендә тикшереү, IVM хостының AXT ҡапламаһы тикшереүҙәре һәм `RegisterVerifiedFeeSponsorVaultAllocation` ҡапламаның `fastpq_binding` ҡиммәтен талап итә, уны көтөлгән раҫлау менән сағыштыра һәм ҡаплама менән уның эсендәге иҫбатлау өсөн FastPQ тикшереүсеһен саҡыра. Бәйләнеш булмаһа йәки тикшереү уңышһыҙ тамамланһа, операция кире ҡағыла.

Тикшереүсе шаһитлы күсереү раҫлауҙарын ғына, йәғни `tx_predicate` һәм `value_conservation` раҫлауҙарын ҡабул итә. `authorization` һәм `compliance` раҫлау төрҙәре — күсереү мөнәсәбәте булмаған, эсе үтә күренмәгән эффект контейнерҙары, һәм тикшереү уларҙы кире ҡаға. Блок валидацияһы шулай уҡ алыҫ сарыф итеүҙәрҙе йөрөткән ҡапламаларҙы кире ҡаға, ә IVM хосты үҙаллы `AXT_VERIFY_DS_PROOF` ҡабул итеүен кире ҡаға. Финалланған сығанаҡ тамырҙарын, транзакциялар йыйылмаһын һәм эмитент авторизацияһын аутентификацияларлыҡ булғанға тиклем икеһе лә мөмкин түгел.

### AXT бәйләнеше {#axt-binding}

SORA Nexus AXT ҡапламалары өсөн `AxtFastpqBinding` иҫбатлау һәм тикшереү алдынан каноник формаға килтерелә:

- `parameter`, `source_dataspace`, `source_receipt_id` һәм `verified_effect_type` ситке бушлыҡтарҙан таҙартыла һәм буш булмаҫҡа тейеш
- `source_tx_commitment`, `claim_digest`, `witness_commitment` һәм `policy_commitment` бәләкәй хәрефтәргә күсерелә һәм 32 байттың ун алтылы кодлауы булырға тейеш
- `verifier_id` ҡиммәте `fastpq`, ә `verifier_version` ҡиммәте `v1` булырға тейеш
- `claim_type` ситке бушлыҡтарҙан таҙартыла, бәләкәй хәрефтәргә күсерелә һәм юғарылағы дүрт раҫлау төрөнөң береһен атарға тейеш
- `target_dsids` буш булмаҫҡа һәм ҡәтғи үҫеү тәртибендә булырға тейеш
- `remote_spend_intent_commitments` ҡәтғи үҫеү тәртибендә һәм беренсе релиз сиге эсендә булырға тейеш

Тикшереү теүәл каноник форманы талап итә; ул саҡырыусы исеменән бәйләнеште нормалләштермәй.

Бәйләнеш блок үтәлеше инде теркәгән партияға беркетелә; ул күсеүҙәр булдырмай. Партияла кәмендә бер торош күсеүе булырға һәм бәйләнештең параметрҙар йыйылмаһы (`fastpq-state-transition-stark-v1`) аталырға тейеш. Уның `entry_hash` метамәғлүмәте `source_tx_commitment` ҡиммәтенә тигеҙ булырға, ә асыҡ `dsid` ҡиммәте бәйләнештең `source_dsid` ҡиммәтен кодларға тейеш. Күсереү раҫлауы кәмендә бер күсереү транскриптын йөрөтөргә, ә һәр транскрипттың партия хешы `source_tx_commitment` ҡиммәтенә тигеҙ булырға тейеш.

Унан һуң бәйләү процесы партияға иҫбатҡа бәйле метамәғлүмәт яҙа: каноник бәйләнеште, уның дүрт дайджестын, `source_receipt_id`, `target_dsids`, `verified_effect_type` ҡиммәттәрен, буш булмаған `corridor` ҡиммәтен, нулдән айырмалы манифест тамырын, мотлаҡ булмаған DA йөкләмәһен, мотлаҡ булмаған нулдән айырмалы йөкләнгән сумманы һәм ваҡыт сығыу слотын (нуль ваҡыт сикләнмәгәнде аңлата). Аҙаҡ ул бәйләнеш һәм мөһөрһөҙ партия өҫтөнән мөһөр өҫтәй:

$$
\operatorname{seal} =
\operatorname{Hash}(
\texttt{fastpq:axt:batch-seal:v1}\|
E(\operatorname{binding})\|
E(\operatorname{batch})
)
$$

Бында $E$ — каноник Norito кодлауы. Бәйләүҙән һуң партияны, бәйләнеште йәки иҫбатҡа бәйле теләһә ниндәй ҡиммәтте үҙгәртеү тикшереүҙең уңышһыҙ тамамланыуына килтерә. Тикшереүсе шулай уҡ ҡапламаның мәғлүмәт киңлеген, манифест тамырын, DA йөкләмәһен, йөкләнгән суммаһын һәм ваҡыт сығыуын иҫбатҡа бәйле ҡиммәттәр менән сағыштыра.

Тикшерелгән ҡаплама үҙенең иҫбатланған `old_root`, `new_root` һәм `tx_set_hash` ҡиммәттәрен, шулай уҡ белдереү дайджестын хәбәр итә. Дайджест ҡапламаның кесе байттан башланған `u64` рәүешендәге мәғлүмәт киңлеген, уның манифест тамырын, булған осраҡта DA йөкләмәһен, бәйләнеште һәм белдереүҙе үҙ эсенә ала:

$$
\operatorname{statement\_digest} =
\operatorname{Hash}(
\texttt{fastpq:axt:statement:v1}\|
\operatorname{le64}(\operatorname{dsid})\|
\operatorname{manifest\_root}\|
\operatorname{da\_commitment}\|
E(\operatorname{binding})\|
E(\operatorname{statement})
)
$$

AXT партияһы манифестаты SHA-256 каноник бәйләнештең Norito кодировкаһы өҫтөндә:

$$
\operatorname{manifest\_digest} =
\operatorname{SHA256}(E(\operatorname{canonical\_binding}))
$$

## Параметрҙар йыйылмаһы {#parameter-sets}

Беренсе релизда теүәл бер параметрҙар йыйылмаһы бар: `fastpq-state-transition-stark-v1`. Партиялар һәм AXT бәйләнештәре уны атай, ә AXT иҫбатлауы теләһә ниндәй башҡа исемде кире ҡаға. DEEP протокол контракты сығарылған артефакт геометрияһын билдәләй:

| Элемент | Ҡиммәт |
| -------------------------- | ----------------------------------------------------- |
| Ҡыр | Goldilocks `p = 2^64 - 2^32 + 1`, киңәйтеү `u^4 - 7` |
| Эҙ рәттәре | 65,536 |
| Баһалау рәттәре | 8,388,608 (киңәйтеү коэффициенты 128) |
| FRI бөкләү тармаҡланыу дәрәжәләре | `[16, 16, 8, 8, 4]` |
| Һорауҙар | 77 төрлө позиция |
| Гриндинг | юҡ |
| Йөкләмәләр һәм транскрипт | SHA3-256 һәм SHAKE256 |

Етештереү квалификацияһы әлегә мөмкин түгел. Был конструкцияның дөрөҫлөгөнә, йәшереү үҙенсәлегенә һәм Fiat-Shamir үҙгәртеүенә бәйһеҙ тикшеренеүҙәр әле тамамланмаған, ә беркетелгән [етештереүгә әҙерлек яҙмаһы](https://github.com/hyperledger-iroha/iroha/blob/c8c872461e92f04325c350cdd952f4276e96f9dc/specs/fastpq_production_readiness.md) эш күләменә ҡарап нормалләштерелгән бер ниндәй ҙә хәүефһеҙлек раҫлауы яһамай.

## Конфигурация {#configuration}

FastPQ конфигурацияһы `zk.fastpq` аҫтында ҡуйылған.

```toml
[zk.fastpq]
execution_mode = "cpu"
poseidon_mode = "cpu"
proof_sidecar_queue_cap = 1024
proof_sidecar_max_retries = 16

# Optional telemetry labels.
device_class = "apple-m4"
chip_family = "m4"
gpu_kind = "integrated"

# Optional Metal backend tuning.
metal_queue_fanout = 3
metal_queue_column_threshold = 24
metal_max_in_flight = 5
metal_threadgroup_width = 128
metal_trace = false
metal_debug_enum = false

[zk.fastpq.producer]
poll_interval_ms = 1000
step_timeout_ms = 30000
max_native_steps = 16
max_source_entries = 65536
max_source_statements = 16384
```

Ике режим да `cpu` йәки `gpu` ҡиммәтен генә ҡабул итә һәм ғәҙәттә `cpu` була. Уларҙың теләһә ҡайһыһын `gpu` итеп ҡуйыу иҫбат хешлауы өсөн ҡоролманы мотлаҡ итә: macOS-та Metal, башҡа системаларҙа CUDA. GPU ярҙамы компиляцияланмаһа йәки ҡоролма алдан тикшереүҙе үтмәһә, иҫбатлау һыҙаты һүндерелгән килеш ҡала; ул бер ҡасан да CPU-ға кире күсмәй. Ҡоролма Меркл япраҡтарын һәм түбәнге кимәлдәге ата-инә төйөндәрен күпләп хешлауҙы башҡара; транскрипт, тәртипкә һалынған өҫкө ағас һәм эҙ арифметикаһы CPU-ла ҡала. `poseidon_mode = "gpu"` булғанда, айырым алдан тикшереү уңышлы үтһә, төйөн транскрипттың Poseidon дайджестарын да GPU-ла партиялап иҫәпләй; юғиһә уларҙы CPU-ла иҫәпләй.

`proof_sidecar_max_bytes` төйөн һаҡлаған һәм тикшергән кодланған артефакттың күләмен сикләй һәм ғәҙәттә иҫбатлаусының иң ҙур иҫбат кадрына тигеҙ. `producer` таблицаһы һәр иҫбатлау ынтылышын сикләй: уның тикшереп тороу интервалын, ваҡыт бюджетын, урындағы ҡабаттан уйнатыу аҙымдарын (1-ҙән 64-кә тиклем), шулай уҡ хәтер бүлеү алдынан ҡабул ителгән сығанаҡ яҙмаларын һәм белдереүҙәрҙе. `metal_queue_fanout` 1-ҙән 4-кә тиклем ҡиммәт ҡабул итә.

Режим һәм телеметрия билдәһе көйләүҙәрен `iroha3d` аша ла ҡабаттан билдәләргә мөмкин:

```shell
iroha3d --fastpq-execution-mode gpu
iroha3d --fastpq-poseidon-mode cpu
iroha3d --fastpq-device-class apple-m4
iroha3d --fastpq-chip-family m4
iroha3d --fastpq-gpu-kind integrated
```

`iroha3d` конфигурация файлын уҡығанда тирә-яҡ мөхит үҙгәреүсәндәрен иҫәпкә алмай, шуға күрә был ҡиммәттәрҙе TOML-да йәки юғарылағы опциялар менән ҡуйығыҙ.

## Статистика {#metrics}

Телеметрия ҡабыҙылғанда, FastPQ бэкенд һайлау, иҫбаттарҙы һаҡлау һәм Metal башҡарыу мөхитенең тәртибе өсөн метрикалар экспортлай:

|Метрик |Мәғәнәһе |
| ----------------------------------- | --------------------------------------------------------------------------- |
|`fastpq_execution_mode_total` |Заказ ителгән һәм хәл ителгән башҡарыу режимы арттағы һәм ҡулайлама этикеткалары буйынса |
|`fastpq_poseidon_pipeline_total` |Посейдон pipeline юлы буйынса һоралған һәм хәл ителгән |
| `fastpq_gpu_disable_total` | Тиҙләткес, сәбәп һәм ҡоролма билдәләре буйынса GPU тиҙләткесен һүндереү ваҡиғалары |
| `fastpq_gpu_parity_failure_total` | Тиҙләткес, сәбәп һәм ҡоролма билдәләре буйынса һайлап алынған GPU тап килеү хаталары |
| `fastpq_proof_sidecar_queue_depth` | Сиратта торған FastPQ иҫбат ҡушымтаһын беркетеүҙәр |
| `fastpq_proof_sidecar_events_total` | Ваҡиға төрө буйынса иҫбат ҡушымтаһын һаҡлау ваҡиғалары |
|`fastpq_metal_queue_depth` |Metal сираты сиге, бер үк ваҡытта башҡарылған операцияларҙың максималь һаны, ебәреүҙәр һаны һәм өлгө алыу тәҙрәһе|
|`fastpq_metal_queue_ratio` |Металл сираттағы мәшғүллек һәм ҡапма-ҡаршылыҡ нисбәттәре |
|`fastpq_zero_fill_duration_ms` |Металл йүгереүҙәр өсөн тулыландырыу ваҡыты |
|`fastpq_zero_fill_bandwidth_gbps` |Асылған нуль тултырыу диапазоны |

Режим, GPU, Metal сираты һәм нуль менән тултырыу метрикалары `extended` йәки `full` телеметрия профилен талап итә һәм Kura `init_mode = "fast"` менән старт алғанда экспортланмай. Metal сираты һәм нуль менән тултырыу метрикалары шулай уҡ macOS-та `fastpq-gpu` йыйылмаһын талап итә.

Дөйөм күрһәткестәргә ҡарап, уларҙы [ Эшмәкәрлек һәм үлсәүҙәр](/ba/guide/advanced/metrics.md) бүлегендә күрһәтелгән консенсус һәм сират сигналдары менән ҡулланығыҙ.
