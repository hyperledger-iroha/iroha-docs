- Iroha [конфигурация параметрҙары](/ba/guide/configure/client-configuration.md)
- теркәлгән пирҙары
- теркәлгән домендар
- теркәлгән [теггерҙар ](/ba/blockchain/triggers.md)
- теркәлгән [ ролдәр](/ba/blockchain/permissions.md#permission-groups-roles)

Домендар, пирҙары йәки ролдәр теркәлгәндә йәки теркәлмәгәндә `World` (un) register [ инструкцияһының маҡсаты булып тора](/ba/blockchain/instructions.md).

## Донъя хәле күренеше (WSV) {#world-state-view-wsv}

Донъя торошон ҡарау — хәҙерге блокчейн торошоноң хәтерҙәге сағылышы. Ул `World`, commit ителгән блок hash-тарын, transaction индекстарын һәм ағымдағы epoch өсөн һайланған peer-ҙарҙы үҙ эсенә ала. Тулы block payload-тары үҙгәреүсән WSV мәғлүмәте итеп ҡабатланмай, ә Kura-нан бирелә.

WSV — query-ҙар уҡый һәм block execution үҙгәртә торған хәл. Ул үҙе генә оҙайлы truth source түгел. Оҙайлы тарих [Kura](#kura-storage)-ла һаҡлана, ә WSV Kura блоктарынан яңынан төҙөлә йәки state snapshot-тан йөкмәтелеп, һуңыраҡ яңы Kura блоктарын replay итеү менән ҡыуып етә ала.

### WSV эҙҙәре нимәлә {#what-the-wsv-tracks}

WSV объект `World` объектына ҡарағанда киңерәк, ғәмәлдә ул:

- `World`: параметрҙар, пирҙар, домендар, иҫәптәр, активтар, NFTs, ролдәр, рөхсәттәре, ҡуҙғатыуҙар, башҡарыусы мәғлүмәт һәм башҡа теркәлгән мәғлүмәттәр моделе объекттары.
- Ҡатнашылған блок-хашистар һәм иң һуңғы commit бейеклек
- Һорауҙар һәм квитанциялар менән ҡулланылған транзакция-блок индекстары
- консенсус буйынса ҡулланылған ағымдағы һәм элекке commit topology
- Ҡатнашылған блоктарҙан алынған иҫтәлекле индекстар, мәҫәлән, мәғлүмәттәр менән тәьмин итеү буйынса йөкләмәләр, ҡабул итеү курсорҙары, пин-интенттар һәм һорау проекцияһы билдәләре
- Дитерминистик блоктарҙы үтәү өсөн кәрәкле, криптография, идара итеү, pipeline, йөкмәтке, иҫәп-хисап һәм Nexus параметрҙары кеүек хәрәкәт ваҡыты конфигурацияһы һыҙаттары

Queries ғәҙәттә был структуралар өҫтөндә read-only `StateView` ала. View query execution өсөн consistent snapshot булып тора; ул WSV-ны туранан-тура үҙгәртергә рөхсәт итмәй.

### WSV нисек үҙгәрә? {#how-the-wsv-changes}

WSV үҙгәрештәре commit ителгәнгә тиклем staging-та тора. Блок үтәлеше block-scoped state overlay булдыра, ә һәр ҡабул ителгән transaction үҙенең instruction-дарын transaction-scoped overlay эсендә ҡуллана. Артабанғы transaction-дар шул уҡ блок контексында һөҙөмтәләрҙе күрә. Time trigger-ҙар блоктағы transaction эффекттарынан һуң баһалана.

Консенсус блокты commit иткәндән һуң, пир тәүәләп commit ителгән блокты Kura сиратына ҡуя. Был аҙым уңышһыҙ булһа, WSV алға күсмәй, ә консенсус циклы блок payload-ын ҡабаттан һынай йәки сиратҡа кире ҡуя. Блок Kura сиратына ҡабул ителгәс, Iroha үтәлештән һуңғы блок эффекттарын ҡуллана, сығарылған индекстарҙы яңырта һәм state-view йоҙағы аҫтында этапланған WSV үҙгәрештәрен commit итә. Шулай итеп, уҡыусылар өлөшләтә commit ителгән блокты күрә алмай.

Консенсус-критик ҡағиҙә - пирҙар бер үк WSV шул уҡ commit ителгән блоктарҙан килеп етергә тейеш. WSV мәғлүмәттәрҙе ситләтеү күрһәтмәләренә урындағы төҙәтмәләр тура килтереү һәм пирҙарҙы раҫлау йәки ҡабаттан уйнатыу ваҡытында ризаһыҙлыҡ тыуҙырасаҡ.

### Старт һәм ҡабаттан уйнау {#startup-and-replay}

Эш башлағанда Iroha тәүҙә Kura-ны асып, һаҡланған block height-ты билдәләй. Шунан state snapshot-ты йөкләргә тырыша. Snapshot булмаһа йәки кире ҡайтарыла торған хата менән кире ҡағылһа, Iroha genesis state-ты төҙөй һәм Kura-нан commit ителгән блоктарҙы replay итә. Snapshot яраҡлы, ләкин Kura-нан артта булһа, тик етмәгән height диапазоны replay ителә.

Реплей һәр һаҡланған блокты раҫлай, шул бейеклек өсөн commit реестрын реконструкциялай, блок эффекттарын WSV-ға ҡуллана һәм һөҙөмтәле торошто commit итә. Был Kura - WSV өсөн тергеҙеү юлы, ә мгновенные снимки бөтә сылбырҙы ҡабаттан уйнауҙан ҡаса торған оптимизация булып тора.

## Kura Һаҡланыу {#kura-storage}

Kura - Iroha-ның даими блок һаҡлауы. Ул ҡул ҡуйылған блоктарҙы һәм тергеҙеү метамәғлүмәттәрен һаҡлай. WSV-нең икенсе үҙгәреүсән күсермәһен һаҡламай

Kura һаҡлағысы [`kura.store_dir`](/ba/reference/peer-config/params.md#param-kura-store-dir) адресында тамырлана. Был тамыр эсендә блок мәғлүмәттәре трасса йәки сегментҡа бүленә.

|Юл |Маҡсат |
| --- | --- |
|`blocks/<segment>/blocks.data` |Norito менән бер рәттән төҙөлгән ҡул ҡуйылған блок йөкләмәләре. |
|`blocks/<segment>/blocks.index` |Билдәле ҙурлыҡтағы `(start, length)` яҙмалары карта блогы бейеклеге менән байттарҙа `blocks.data`. |
|`blocks/<segment>/blocks.hashes` |Тиҙ эҙләү һәм старт раҫлау өсөн бейеклеге буйынса блок хештары. |
|`blocks/<segment>/blocks.count.norito` |Күп кенә блоктар индексы яҙмалары ҡулланыу өсөн хәүефһеҙ икәнен теркәгән һаҡсыл commit marker. |
|`blocks/<segment>/da_blocks/` |Диск-бюджет үтәү иҫке кәүҙәләрҙе эҫе файлдан сығара торған ваҡытта `blocks.data` ситтә тотолған блок файҙалы йөкләмәләр. |
|`blocks/<segment>/pipeline/sidecars.norito` һәм `sidecars.index` |Блок бейеклеге буйынса клавиатуралы pipeline-дарҙы тергеҙеү ярҙамсы яҙмалары. |
|`blocks/<segment>/pipeline/roster_sidecars.norito` һәм `roster_sidecars.index` |Блок синхронлаштырыу һәм ҡабаттан уйнатыу өсөн ҡулланылған яңы commit-roster sidecars. |
|`merge_ledger/<segment>.log` |Ҡатнашылған блоктар менән һыҙыҡ өҫтөнә алынған берләшмә иҫәп-хисап яҙмалары. |
|`commit-rosters.norito` |Һуңғы блоктар өсөн commit сертификаттары һәм раҫлаусы контроль пункттары һаҡлана. |

Kura сылбыр өсөн ваҡ хәтер векторын һаҡлай: һәр бейеклектә блок хэшиғы һәм, мөмкин булһа, блок корпусы бар. Генезис блогы кэш булып ҡала, ә һуңғы [`kura.blocks_in_memory`](/ba/reference/peer-config/params.md#param-kura-blocks-in-memory) генезис булмаған блоктары үҙҙәренең органдарын хәтерҙә тоталар. Иҫке блоктарҙың кәүҙәләре хәтерҙән төшөрөлгән һәм кәрәк саҡта Kura файлдарынан ҡабаттан тултырылған.

Инициализация ваҡытында `strict` режимы блоктарҙан һаҡланған блоктарҙы раҫлай һәм кәрәк булһа хэш файлын яңынан яҙа. `fast` режимы һаҡланған хэш/индекс метамәғлүмәтенән башлана һәм, әгәр был метамәғлимәттәр эҙмә-эҙлекле икән, ҡаты инициализацияға кире төшә. Әгәр Kura боҙолған ҡойроҡто асыҡлаһа, ул һаҡлауҙы һуңғы раҫланған блокҡа тиклем һөртә.

Kura яңы блоктарҙы фоновый яҙыусы аша яҙа. Яҙыусы блоктарҙың файҙалы йөкләмәләрен, хештарын һәм индекс яҙмаларын ҡуша, һуңынан конфигурацияланған fsync сәйәсәте буйынса оҙайлы иҫәп билдәһен алға сығара. Диск-бюджет үтәлеше әүҙем булғанда, Kura ҡулланыуҙан сығарылған сегменттарҙы таҙарта йәки иҫке блоктарҙы `da_blocks/` эсенә ҡыуып сығара ала, шул уҡ ваҡытта хештар һәм индекс яҙмалары раҫлау һәм эҙләү өсөн ҡулланыла.
