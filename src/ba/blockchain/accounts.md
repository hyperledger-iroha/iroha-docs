# Иҫәпкә алыуҙар {#accounts}

Иҫәп — транзакцияларға ҡул ҡуя һәм реестр торошона эйә була алған вәкәләтле субъект. Хәҙерге Iroha 3 мәғлүмәт моделендә `AccountId` каноник һәм доменһыҙ: ул иҫәп контроллерынан алына һәм каноник рәүештә [I105](/ba/reference/i105.md) итеп кодлана. Кеше уҡый алған домен һәм мәғлүмәт киңлеге контексы айырым иҫәп псевдонимдары бәйләнештәренә ҡарай.

## Структураһы {#structure}

`Account` теркәлгән исемлектә:

- `id`: каноник `AccountId`
- `metadata`: үҙаллы иҫәпкә алыу метамәғлүмәттәре
- `label`: факультатив стабилный псевдоним
- `uaid`: SORA Nexus эш ағымдарында ҡулланылған өҫтәмә универсаль иҫәп идентификаторы
- `opaque_ids`: иҫәбенең UAID менән бәйләнгән үтә күренмәле идентификаторҙар

Хисапты булдырыу өсөн ҡулланылған транзакция файҙалы йөкләмәһе `NewAccount`. Ул теркәлгән иҫәптә ҡулланылған шул уҡ идентификация, метамәғлүмәттәр, этикетка, UAID һәм үтә күренмәгән ID өлкәләре менән.

`uaid` каноник `AccountId`-ны тулыландыра, әммә уны алмаштырмай. SORA Nexus хеҙмәттәренә мәғлүмәт киңлектәре араһында тотороҡло ҡулланыусы йәки ойошма идентификаторы, хосусилыҡты һаҡлаған теркәү йә хеҙмәт мөмкинлектәрен эҙләү кәрәк булғанда уны ҡулланығыҙ. Башҡарыу мөхите UAID менән иҫәп араһында бергә-бер индекс һаҡлай, мәғәнәһе асыҡланмаған идентификаторҙарҙы UAID аша беркетеүҙе талап итә һәм ҡабатланған йә бер-береһенә тура килгән шундай идентификаторҙарҙы кире ҡаға. SORA Nexus хеҙмәт ҡатламының эш ағымы өсөн [FHE һәм UAID](/ba/blockchain/sora-nexus-services.md#fhe-and-uaid) бүлеген ҡарағыҙ.

## Иҫәптәр контролеры {#account-controllers}

Контроллер аккаунттың ғәмәлгә нисек рөхсәт итеүен билдәләй. Дефолт клиент ағымы Ed25519 төймә парын ҡуллана, әммә мәғлүмәттәр моделе шулай уҡ күп имзалы сәйәсәт контроллеры кеүек бай контролде хуплай.

Клиент конфигурацияһы ҡул ҡуйыу хоҡуғын бер-береһенән айырып һаҡлай:

```toml
[account]
profile = "taira"
public_key = "ed0120..."
private_key_file = "/absolute/path/to/private.key"
```

[клиент конфигурацияһы](/ba/guide/configure/client-configuration.md) һәм [һүҙле генерация](/ba/guide/security/generating-cryptographic-keys.md) хәҙерге төп форматтар өсөн ҡарағыҙ.

## Taira менән һынап ҡарағыҙ. {#try-it-on-taira}

Йәмәғәт Taira тест селтәрендәге IDs бер нисә канон иҫәбенә исемлек килтерегеҙ:

```bash
curl -fsS 'https://taira.sora.org/v1/accounts?limit=5' \
  | jq -r '.items[] | [.id, (.primary_alias // "-")] | @tsv'
```

Бухгалтер иҫәбенең активтарын тикшерер өсөн, иҫәпте күсер ID тәүге саҡырылыштан һәм URL- уны юлға һалғансы кодлай. Python беренсе иҫкә алынған иҫәп өсөн snippet шулай эшләй:

```bash
python3 - <<'PY'
import json
import urllib.parse
import urllib.request

root = "https://taira.sora.org"
accounts = json.load(urllib.request.urlopen(f"{root}/v1/accounts?limit=1"))["items"]
account_id = accounts[0]["id"]
encoded = urllib.parse.quote(account_id, safe="")
assets = json.load(
    urllib.request.urlopen(f"{root}/v1/accounts/{encoded}/assets?limit=5")
)

print(json.dumps({"account_id": account_id, "assets": assets["items"]}, indent=2))
PY
```

Былар — асыҡ уҡыу ғәмәлдәре. Иҫәпте булдырыу йәки яңыртыу ҡул ҡуйылған транзакция булып тора һәм [SORA Nexus мәғлүмәт киңлектәренә тоташыу](/ba/get-started/sora-nexus-dataspaces.md) бүлегендә тасуирланған, һынау аҡсаһы биреү хеҙмәте аша аҡсаландырылған Taira көйләүен талап итә.

## Теркәлеше һәм рөхсәттәре {#registration-and-permissions}

Иҫәп яҙмалары дөйөм [`Register` һәм `Unregister`](/ba/blockchain/instructions.md#un-register) инструкциялары ярҙамында теркәлә һәм теркәүҙән сығарыла. Әүҙем башҡарыу мөхите валидаторы кемдең иҫәп яҙмаларын булдыра алыуын һәм ниндәй рөхсәт токендары йәки ролдәр кәрәклеген билдәләй.

Теркәлгәндән һуң иҫәб:

- транзакцияларҙы яҙыу
- тотоу активтары
- үҙ биләмәләре
- ролдәрҙе һәм рөхсәт билдәләрен алыу
- һаҡланған метамәғлүмәттәр
- тейешле мөмкинлектәр ҡабыҙылғанда псевдоним, асҡысты алмаштырыу, тергеҙеү һәм SORA Nexus идентификацияһы эш ағымдарында ҡатнашыу

## Билдәлелек мәсьәләләрен хәл итеү {#troubleshooting-identity-issues}

Әгәр ҙә операция көтөлмәгәндә кире ҡағылһа, тикшерегеҙ:

- клиенттың асыҡ асҡысы ҡултамғалау өсөн ҡулланылған шәхси асҡыс менән тап килә
- иҫәб генезиста теркәлгән йәки килешеү төҙөлгән
- вәкәләтле иҫәп инструкция буйынса талап ителгән рөхсәттәре бар
- строгие учетные поля используют канонический I105 счет ID, ә уҡый торған исемдәр актив иҫәп-хисап ҡушаматы аша хәл ителә.
