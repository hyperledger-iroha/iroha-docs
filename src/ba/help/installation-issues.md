# Ойоштороу проблемаларын хәл итеү {#troubleshooting-installation-issues}

Был бүлектә Iroha 3 ҡуйыу өсөн проблемаларҙы хәл итеү буйынса кәңәштәр бирелә. Әгәр һеҙ кисергән мәсьәлә бында һүрәтләнмәгән икән, беҙгә [Telegram](https://t.me/hyperledgeriroha) аша мөрәжәғәт итегеҙ.

## Тиҙ тикшереүҙәр {#quick-checks}

Күпселек ҡоролмалар етешһеҙлектәре дүрт урындарҙың береһенән килә:

- Rust инструменттар сылбыры өҫкө ағымындағы эш майҙаны ҡуйып ҡуйған версияға ҡарағанда олораҡ
- `cargo` йәки `rustc` башҡа ҡулайламаға күсереү `rustup`
- missing system build tools such as a C compiler, `pkg-config`, or CMake
- сығанаҡ үҙгәрештәренән һуң иҫкергән сығарылған өҙөктәр йәки урындағы төҙөлөш артефакттары

Iroha сығанағы иҫәбенән:

```bash
rustup show
cargo --version
rustc --version
cargo metadata --no-deps
```

Әгәр `cargo metadata` уңышҡа өлгәшмәй, эшләгәнгә тиклем урындағы инструменттар сылбырын төҙәтергә `pnpm refresh:iroha --source /path/to/iroha`, сөнки яңыртыу саҡыра ала Kagami хәҙерге мәғлүмәттәр моделе схемаһын булдырыу өсөн.

### Rust версияһын тикшер {#check-rust-version}

Һеҙҙең һәм беҙҙең һаулығыбыҙҙы һаҡлап ҡалыу хаҡына, дөрөҫ версияға эйә булыуҙарығыҙға инанығыҙ. `cargo` дөрөҫ версияһы менән парланған `rustc`. Хәҙерге өҫкө ағымы эш урыны белдерә `rust-version = "1.92"` һәм ҡулланма сылбыр каналы инеп `rust-toolchain.toml`. Версиялар күрһәтеү өсөн, эшләй

```bash
$ cargo -V
$ cargo 1.93.1 (...)
```

һәм һуңынан

```bash
$ rustc --version
$ rustc 1.93.1 (...)
```

Әгәр һеҙ юғары версиялар бар, һеҙ яҡшы. әгәр һеҙ түбән версиялар, һеҙ уны яңыртыу өсөн түбәндәге команданы эшләй алаһығыҙ:

```bash
$ rustup toolchain update stable
```

### Инсталляция урынын тикшерегеҙ {#check-installation-location}

Әгәр һеҙ түбән версиялар һаны ала һәм һеҙ инструменттар сылбыр яңыртып һәм ул эшләмәгән... Әйҙәгеҙ, был ябай проблема тип әйтергә, әммә ул уртаҡ сиселеше юҡ.

Беренсенән, һеҙ ҡулланырға теләгән версияның ҡайҙа ҡуйылғанлығын асыҡларға тейеш:

```bash
$ rustup which rustc
$ rustup which cargo
```

Ҡулланыусы ҡорамалдар селтәрҙәренең ҡоролмалары, ғәҙәттә, `~/.rustup/toolchains/stable-*/bin/`. Әгәр был осраҡта, һеҙ

```bash
$ rustup toolchain update stable
```

һәм был һеҙҙең проблемаларығыҙҙы хәл итергә тейеш.

### Rust дефолт версияһын ҡарағыҙ {#check-the-default-rust-version}

Икенсе вариант - һеҙҙә яңыртылған `stable` инструменттар сылбыры бар, әммә ул алдан билдәләнмәгән булып ҡуйылмаған.

```bash
$ rustup default stable
```

Әгәр һеҙ `nightly` версияһын ҡуйһағыҙ йәки Rust версияһын билдәләһәгеҙ, ләкин уны ҡуҙғатырға онотһағыҙ, был була ала.

### Башҡа Rust версиялары бармы-юҡмы икәнен тикшерегеҙ {#check-if-there-are-other-rust-versions}

Ҡош-ҡорҙоң проблемаларын хәл итеүҙе дауам итһәк, беҙ шулай уҡ ҡушаматтарға эйә булыр инек:

```bash
$ type rustc
$ type cargo
```

Әгәр был һеҙ күрһәткән урындарҙан башҡа урынға йүнәлтһә `rustup which *`, тимәк, һеҙҙең проблема бар.

```bash
$ alias rustc "~/.rustup/toolchains/stable-*/bin/rustc"
$ alias cargo "~/.rustup/toolchains/stable-*/bin/cargo"
```

сөнки эске логика боҙолорға мөмкин, нисек кенә үҙгәртеп ҡуймағыҙ ҙа.

Иң ябай ысул - ҡулланылмаған версияларҙы алып ташлау.

Шулай ҙа был эште башҡарыуҙан да еңелерәк, сөнки ул бөтә версияларҙы ла күҙәтеүҙе талап итә. rustup ғәҙәттә, ике генә бар: система пакеттары менеджер версияһы һәм һеҙҙең йорт папкаһында стандарт урынға ҡуйылған саҡта был инструкция башында ҡушҡан команда.`apt remove rust`). Һуңғыһы өсөн:

```bash
$ rustup toolchain list
```

Һәм һуңынан, һәр `<toolchain>` өсөн (көйөш бәйләнештәреһеҙ, әлбиттә):

```bash
$ rustup remove <toolchain>
```

Шунан һуң, был

```bash
$ cargo --help
```

һөҙөмтәһендә команда табылмаған хата, йәғни һеҙҙә актив Rust инструменттар сылбырһы ҡуйылмаған. Һуңынан:

```bash
$ rustup toolchain install stable
```

## Проблемаларҙы хәл итеү Python ҡорамалдар сылбыры {#troubleshooting-python-toolchain}

Әгәр һеҙ урынлаштырыу Python Тимерле тәгәрмәстәрҙә [Python клиент ҡоролмаһы](/ba/guide/tutorials/python.md), "Ироха" тигән хата менән осрашырға мөмкин._питон-*.whl был платформала ярҙам итеүсе тәгәрмәсе түгел".

Был хата pip иҫкергән тигәнде аңлата, шуға күрә уны яңыртырға кәрәк. Беренсенән, һеҙҙең OS яңыртыуҙар өсөн тикшереү һәм системаны яңыртыу үткәреү тәҡдим ителә.

Әгәр был эшләмәй икән, һеҙ ҡулланыусылар каталогы өсөн `pip` яңыртыу тырыша алаһығыҙ.

`python -m pip install --upgrade pip`

Быға инанырға тырышығыҙ `pip` был һеҙҙең йорт каталогы ҡуйылған. Был эшләргә, йүгерергә `whereis pip` һәм тикшерергә `/home/username/.local/bin/pip` Юлдар араһында. Әгәр юҡ икән, снарядты яңыртып ҡуйығыҙ `PATH` үҙгәреүсән.

Әгәр проблема дауам итһә, [ беҙгә ](/ba/help/) шылтыратып, һөҙөмтәләр тураһында хәбәр итегеҙ.

```
python --version
python3 --version
pip --version
pip3 --version
```
