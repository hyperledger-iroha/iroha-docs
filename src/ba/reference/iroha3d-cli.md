# `iroha3d` CLI {#iroha3d-cli}

`iroha3d` — Iroha 3 төйөнөнөң стандарт фон хеҙмәте. Cargo пакеты `irohad` тип атала, шуға күрә башҡарылыусы файлды сығанаҡ код каталогынан былай саҡырығыҙ:

```shell
cargo run -p irohad --bin iroha3d -- --config path/to/config.toml
```

Йәмәғәт Taira тест селтәре өсөн, сығарыу һүрәте `iroha3d_taira` ҡулланыла. Ул шул уҡ CLI ҡабул итә. Ул шулай уҡ Taira кананик селтәрен, валидатор йыйылмаһын, һаҡлау көйләүҙәрен һәм ғәмәлгә ашырыу ваҡытын ҡултамғалау сымдарын үтәй. Taira конфигурацияһын асыҡламайынса раҫлағыҙ:

```shell
iroha3d_taira --sora \
  --config /etc/iroha/taira/config.toml \
  --check-config
```

Каноник Taira профиленең оператор әҙерләгән формаһын ҡулланығыҙ; репозиторийҙағы шаблонда әле лә урынлаштырыу урын тотҡостары бар. Taira менән һынағанда уны дөйөм SORA Nexus йәки етештереү SoraFS көйләүҙәре менән алмаштырмағыҙ.

## `--config` {#arg-config}

- Тип: файл юлы
- Исеме: `-c`

[Тиңдәш конфигурацияһына](/ba/reference/peer-config/index.md) юл.

## `--genesis-manifest-json` {#arg-genesis-manifest-json}

- Тип: файл юлы

Һайланма генез манифесты JSON консенсус менән раҫлау өсөн ҡулланыла.

## `--check-config` {#arg-check-config}

Ҡабул ителгән конфигурацияны һәм бар генез материалын раҫлау, һуңынан бәйләүсе селтәр инеүлектәрһеҙ сығыу.

## `--json` {#arg-json}

- **Төрө:** флаг
- **Талап итә:** `--check-config`

Был йыйылманың һәм конфигурацияның ярашлылыҡ ҡиммәттәрен `Ready` йәки `Pending` юлы урынына бер Norito JSON объекты итеп баҫтырыу.

## `--check-storage` {#arg-check-storage}

- **Төрө:** флаг
- **Бергә ҡулланылмай:** `--check-config`

Туҡтатылған төйөндөң Kura һаҡлағысын һәм иң яңы торош күсермәһен ошо йыйылманың декодерҙары менән тик уҡыу режимында тикшереү, һөҙөмтәне бер Norito JSON объекты итеп баҫтырыу һәм уңышһыҙлыҡта нулдән айырмалы код менән сығыу. Тикшереү Kura һаҡлағыс тамырының йоҙағын ала, шуға күрә эшләгән төйөн биләгән һаҡлағысты кире ҡаға. Ул һаҡлағысты бер ҡасан да үҙгәртмәй һәм башҡарыу ваҡыты өсөн генә булған серҙәрҙе бер ҡасан да асмай.

## `--check-replay` {#arg-check-replay}

- **Төрө:** флаг
- **Бергә ҡулланылмай:** `--check-config`, `--check-storage`

Туҡтатылған төйөн һаҡлағысының күсермәһен ошо йыйылма менән ҡабат башҡарыу һәм һөҙөмтәне бер Norito JSON объекты итеп баҫтырыу. Команда блоктарҙы ваҡытлы каталогҡа күсерә, унда иң яңы торош күсермәһен тергеҙә йәки ҡул ҡуйылған genesis-ты ҡабат башҡара, һуңынан һәр һуңғыраҡ блокты ҡабат башҡара. Блок үҙенең сертификатланған һөҙөмтәһен ҡабатлай алмаһа йәки кәрәкле блок тәне етмәһә, ул нулдән айырмалы код менән сыға; ул бер ҡасан да һаҡлағысҡа яҙмай һәм башҡарыу ваҡыты өсөн генә булған серҙәрҙе асмай.

## `--require-genesis-inrou-deployment-authority` {#arg-require-genesis-inrou-deployment-authority}

- **Төрө:** иҫәп идентификаторы
- **Талап итә:** `--check-config`

Офлайн тикшереүҙә, теүәл ҡул ҡуйылған genesis башҡарылғандан һуң, ошо теркәлгән иҫәптең SoraCloud урынлаштырыу вәкәләтен һаҡлауын талап итеү.

## `--sumeragi-assert-fresh-key` {#arg-sumeragi-assert-fresh-key}

- **Төрө:** флаг

Тик ошо эшләтеүҙә генә төйөндөң консенсус асҡыстарының был сылбыр өсөн бер ҡасан да ҡул ҡуймағанын раҫлау. Sumeragi һәр асҡыс өсөн хәүефһеҙлек яҙмаһы һаҡлай; яҙма булмаһа, уның юғалмағанына иҫбат алғансы бер нәмәгә лә ҡул ҡуймай. Был флагты яңы асҡысты тәүге эшләтеүҙә бер тапҡыр ғына бирегеҙ һәм мәғлүмәт юғалтыуҙан һуң бер ҡасан да ҡулланмағыҙ.

## `--trace-config` {#arg-trace-config}

- Тип: флаг
- Тирә-яҡ мөхит: `TRACE_CONFIG`

Конфигурация ҡатламдары уҡылып, анализланған саҡта эҙҙәр журналын булдырыу.

## `--config-blake3` {#arg-config-blake3}

- Тип: 64-шәр һанлы BLAKE3 гексадецимал биҙрәлеү
- **Талап итә:** `--config`

Конфигурация файлы байттарҙы тәьмин ителгән дигес менән тап килеү өсөн кәрәк. Берҙәмлек менән бәйләнгән файл яҫыланырға тейеш; ул `extends` эсенә инә алмай.

## `--terminal-colors` {#arg-terminal-colors}

- Тип: `--terminal-colors=true` йәки `--terminal-colors=false` тип күрһәтелгән булеан
- Дефолт: терминалдың һәләтен асыҡлау
- Тирә-яҡ мөхит: `TERMINAL_COLORS`

Контроль ANSI төҫтәге сығарыу.

## `--language` {#arg-language}

- Тип: ҡыл

Демон хәбәрҙәре өсөн ҡулланылған система теленә өҫтөнлөк бирегеҙ.

## `--sora` {#arg-sora}

- Тип: флаг
- Тирә-яҡ мөхит: `IROHA_SORA_PROFILE`

SoraFS, SoraNet ҡул ҡыҫышыуы һәм күп һыҙатлы консенсус ҡулланған SORA Nexus профилен әүҙемләштереү. Taira эшләтеүсеһе һәр ваҡыт ошо флаг менән саҡырыла.

## FastPQ өҫтөнлөклө {#fastpq-overrides}

`--fastpq-execution-mode <MODE>` һәм `--fastpq-poseidon-mode <MODE>` тик `cpu` йәки `gpu` билдәләрен генә ҡабул итә.

- `--fastpq-device-class <LABEL>`
- `--fastpq-chip-family <LABEL>`
- `--fastpq-gpu-kind <LABEL>`

Мәҫәлән:

```shell
iroha3d --fastpq-execution-mode gpu \
  --fastpq-poseidon-mode cpu \
  --fastpq-device-class apple-m4 \
  --fastpq-chip-family m4 \
  --fastpq-gpu-kind integrated
```

## Төҙөлгән ярҙам {#generated-help}

Юғарылағы параметрҙар йомғағы беркетелгән Iroha commit-ындағы `iroha3d` аргумент билдәләмәләренә ярашлы. Үҙ эш күсермәһенең теүәл ярҙамын ҡарау өсөн эшләтегеҙ:

```shell
cargo run --locked -p irohad --bin iroha3d -- --help
```
