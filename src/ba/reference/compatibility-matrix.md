# Тейешлелек матрицаһы {#compatibility-matrix}

Совместимость матрицаһы сағылдыра SDK ағымдағы сценарийҙар өсөн ҡаплау Iroha 3 Документтар йыйылмаһы. По умолчанию, биттәрҙе загружает тупланма снайп-шоты булдырылған pinned [`hyperledger-iroha/iroha`](https://github.com/hyperledger-iroha/iroha) ревизия.

Матрица түбәндәгеләрҙән тора:

- Тәүге колонкалағы хикәйәләр
- SDKs ҡалған бағаналар буйлап
- Күрелгән, өҙөлгән һәм юғалған мәғлүмәттәр өсөн статус символдары

Тик яңыртыу эш ағымы менән раҫланған һөҙөмтәләр генә ҡапланған йәки уңышһыҙ тип хәбәр ителә.
