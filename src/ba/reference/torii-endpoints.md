# Torii Оҙаҡҡы һыҙаттар {#torii-endpoints}

Torii был HTTP, SSE, һәм WebSocket ҡапҡаһы өсөн Iroha 3. Ул икеләтә лә иҫәп-хисапҡа ҡараған APIs һәм операторҙың һуңғы нөктәләре.

Хәҙерге протокол ҡағиҙәләре:

- Ҡанунлы бинар форматы Norito
- JSON бик күп һуңғы нөктәләр ҙә ярҙам итә, һеҙ `Accept: application/json` ебәргәндә
- метрикалар Prometheus форматында күрһәтелгән

Формат мәғлүмәттәре, йөкмәтке менән һөйләшеү, плагин билдәләре, схема хэштегтары һәм Norito RPC күрһәтмәһе өсөн [Norito шиғырын ҡарағыҙ](/ba/reference/norito.md).

Тоғро өҫкө йөҙө һаман да төҙөлөш үҙенсәлектәренә һәм хәрәкәт итеү ваҡыты конфигурацияһы бәйле. ## Taira тура юлдарҙы һынап ҡарағыҙ {#try-live-taira-routes}

Йәмәғәт Taira тест селтәре ҡулланыу клиенттары уҡыу өсөн генә эҙләнеү өсөн ҡулланған шул уҡ Torii JSON өҫкө йөҙөн аса. Был командалар өсөн асҡыстар кәрәкмәй:

```bash
TAIRA_ROOT=https://taira.sora.org

curl -fsS -H 'Accept: application/json' "$TAIRA_ROOT/status" \
  | jq '{blocks, txs_approved, txs_rejected, queue_size, peers}'

curl -fsS "$TAIRA_ROOT/openapi.json" \
  | jq -r '.paths | keys[]' \
  | grep '^/v1/' \
  | head -n 20

curl -fsS -H 'Accept: application/json' \
  "$TAIRA_ROOT/v1/node/capabilities" \
  | jq '{abi_version, data_model_version, query: .query.aggregate.supported_resources}'
```

Хәҙерге донъя хәленә ҡарап сығайыҡ:

```bash
curl -fsS "$TAIRA_ROOT/v1/domains?limit=5" \
  | jq -r '.items[].id'

curl -fsS "$TAIRA_ROOT/v1/assets/definitions?limit=5" \
  | jq -r '.items[] | [.id, .name, .total_quantity] | @tsv'
```

Әгәр асыҡ тест селтәре маршруты кире ҡайта `502`, ваҡыттарҙы өҙөп, йәки туйынған сират тураһында хәбәр итһә, уны һуңғы нөктәлә булыу проблемаһы тип ҡарағыҙ һәм клиент кодын дебэглауҙан алда тағы ла тырышығыҙ.

## Аккаунт аутентификацияһы, күренеүсәнлек һәм Explorer cursors {#account-authentication-visibility-and-explorer-cursors}

### Ҡулланма иҫәп-хисапҡа мөрәжәғәт итеү протоколы {#app-account-request-protocol}

Ҡулланыуға ҡараған маршруттарҙа аутентификация башлыҡтары юҡ, бер тура бер төймәле иҫбатлау йәки бер күп һанлы шаһит ҡабул ителә. Һәр аутентификациялау башлығы бер тапҡыр ғына күрһәтелергә тейеш.

Тура иҫбатлау өсөн, дүрт башлыҡты ла бергә ебәр:

- `X-Iroha-Account`: тура каноник бәләкәй хәрефле `0x` иҫәп-хисап адресы шэкс йәки актив каноник ASCII иҫәбенең ҡушаматы. I105 тексы HTTP яланының баһаһы булараҡ хәүефһеҙ түгел; был хисап өсөн каноник шестер яҙыу ҡулланығыҙ.
- `X-Iroha-Signature`: ҡәтғи тултырылған-база64 ҡултамға файҙалы йөкләмә.
- `X-Iroha-Timestamp-Ms`: конфигурацияланған кәүҙәлелек тәҙрәһендә миллисекундтарҙа каноник имзаланмаған унсылыҡ Unix ваҡыт маркаһы.
- `X-Iroha-Nonce`: 1 - 256 баҫыла торған ASCII байт (`0x21` - `0x7e`), ҡабаттан уйнатыу тәҙрәһендә үҙенсәлекле.

Теркәлгән яңғыҙ асҡыс контроллеры ошо теүәл байттарҙы билдәләй:

```text
iroha.app.request.network.v1\0 || <genesis-derived network_id[32]> ||
<UPPERCASE_METHOD>\n
```

### Ҡатнашыусыларға рөхсәт һәм йәшәү циклы хужалығы {#participant-authorization-and-lifecycle-ownership}

Оператор асҡыстары һәм финанс идентификаторҙары берҙән-бер ҡатнашыусыға ҡарамай. `audit_admin_keys` айырым көйләгеҙ; аудитор-админ асҡысы шулай уҡ ҡатнашыусы мутация асҡысы була алмай.

ISO маршруттары өсөн яңы оператор ҡултамғаһы кәрәк. `pacs.008`, `pacs.009`, `sese.023` йәки `colr.012` тәүге тапшырыуҙар өсөн раҫланған оператор заявка башлығы менән билдәләнгән ҡатнашыусыға эйә булырға тейеш `From` финанс шәхесе . `To` идентификацияһы `counterparty` роле менән конфигурацияланған ҡатнашыусыға хәл ителергә тейеш, ә һайланған профиль ике яҡ өсөн дә рөхсәт ителергә тейеш. Оҙайлы ҡабул итеү авторҙы, контрагентты, ҡабул итеүсе ҡатнашыусы һәм оператор асҡысын, шулай уҡ оригиналь профилде һәм индерелгән ҡултамғалар сәйәсәтен яҙҙыра.

Тормош циклы менән таныштырыу был үҙгәрешһеҙ яҙманан түгел, ә саҡырыусы тарафынан һайланған ҡиммәттәрҙән алына:

|Тормош циклы хәбәрҙәре |Кәрәкле ҡатнашыусы |
| ---------------------------------------------- | -------------------------------------------------- |
|`pacs.002`, `pacs.004`, `sese.024`, `sese.025` |`counterparty` роленә эйә булған төп контрагент |
|`camt.056` |`originator` роле менән төп автор |

Тәүге профиль һәм ҡултамға сәйәсәте тотош өсөн ҡамасаулана ғүмере циклы, шуға күрә шылтыратҡан кеше яңыртыу өсөн көсһөҙ профилде һайлай алмай. `pacs.002` иҫәп алыуҙы күрһәткән код (`ACSC`, `ACCP`, `SETT`, йәки `SETTLED`) тәүге иҫәбен түләүгә үҙгәртә, тик Torii килешеүҙәрҙең иҫбатланыуын раҫлай.

Берәр төп ҡатнашыусы үҙенең хәбәрҙәр яҙмаһын һәм булдырылған аутбокс документтарын уҡый ала. Аудит аҙағы пункты тик аутентификацияланған ҡатнашыусының автор йәки контрагент булған яҙмаларҙы ғына ҡайтара. Айырым рәүештә конфигурацияланған аудитор администраторы глобаль уҡыу өсөн генә аудитор ҡарашын ала һәм хәбәрҙәр тапшыра йәки үҙгәртә алмай. Билдәһеҙ ҡатнашыусылар һәм бәйләнешһеҙ хәбәр идентификаторҙары асылмай.

### Оҙайлы ҡабаттан уйнатыу идентификацияһы һәм ҡул ҡуйылған аутбокс документтары {#durable-replay-identity-and-signed-outbox-documents}

Torii уҡырға ярамаған, ҙур булмаған, формалашмаған, дөрөҫ аталмаған, ҡапма-ҡаршылыҡ тыуҙырған йәки асыҡтан-асыҡ тап килмәгән ҡәбер ташы өсөн старт яһай. Ул шулай уҡ асыҡтан-асыҡ яраҡһыҙ схема версияһы, ҡатнашыусы, профиль йәки ҡултамға сәйәсәте булған бай яҙма өсөн аборт яһай, йәки ғәмәлдәге конфигурациянан ситтә ҡалған йәки тап килмәгән тере ҡәбер ташы.

Башҡа бай яҙмаларҙағы зыян башҡаса эшкәртелә: уҡый алмаусы йәки ҙур булмаған файлдар, ғәмәлһеҙ JSON, ғәмәлһеҙ ағымдағы схемалар яҙмалары, каноник булмаған файл исемдәре һәм ҡапма-ҡаршылыҡлы ҡабатлау идентификациялары теркәлә йәки ситтә ҡалдырыла. Һаҡланған яҙмаларҙан уҡыу мөмкин булмаған йәки ғәмәлһеҙ ағымдағы версия аудиты индексы регенерациялана; тик асыҡтан-асыҡ яраҡһыҙ ревизия индексы версияһы ғына стартҡа сығара. Стартап журналдарын күҙәтеп тороу һәм регенерацияланған аудит манифестын көйләү урынына, һәр боҙоҡ бай яҙма файлы узелды хеҙмәтләндереүҙән һаҡлай тип фаразлау.

Һәр һаҡланған бай яҙма ҡатнашыусыларҙың килеп сығышын үҙгәртә алмай. ID, файҙалы йөкләмә хэшигы, бизнес хәбәр ID, һәм UETR тулы дедубликация өсөн TTL хатта бай яҙмалар тураһында ентекле мәғлүмәт тупланғандан һуң да.

Torii реплей ҡабул итеү дауам итә ул ҡултамға йәки эшкәртеүгә тиклем ғүмер циклы хәбәр. Ул бер ҡасан да юҡҡа сығара иҫкермәгән реплей идентификацияһын. әгәр булдырылған ҡеүәт ҙе тулыһынса һаҡланған яҙмалар йәки иҫкермәгән ҡабатлау идентификациялары менән биҙәлгән, тапшырыуҙар ғүмере циклы йәки бухгалтерлыҡ торошо үҙгәрмәйенсә кире ҡайтарылырға мөмкин `503 Service Unavailable` ала.

Һәр `pacs.002`, `pacs.004`, `camt.029`, `sese.024` йәки `sese.025` документтар кире ҡайтарыла `application/xml` тип яуап башлыҡтары менән:

## Kaigi Сессиялар {#kaigi-sessions}

Kaigi түләүле, ысын ваҡытлы аудио/видео бүлмәләре менән тәьмин итә SORA Nexus. Ҡулланырға кәрәк, әгәр ҡушымтаға иҫәп яҙмаһы ярҙамында сессия булдырыу, реестры үҙгәрештәрен, эстафетаны манифестар, шифрланған сигнализация һәм ҡулланыу өлгөһө урынына тотоноу өсөн бөтә конференц-хәллеген сит сылбырҙан.

Китапҡа ҡараған тормош циклы:

- `CreateKaigi`: домен аҫтында шылтыратыу булдырыу һәм уның сәйәсәтен, графигын, метамәғлүмәттәрен һәм ирекле эстафетаны һаҡлау.
- `JoinKaigi` һәм `LeaveKaigi`: саҡырыуҙар исемлеген яңыртыу. Шәхси режимда ҡатнашыусылар, туранан-тура ҡатнашыусы иҫәбенә IDs асыу урынына, йөкләмәләр, ғәмәлдән сығарыусылар һәм исемлек иҫбатлауҙары ҡулланалар.
- `RecordKaigiUsage`: иҫәпләнгән ваҡыт һәм газ суммаһын өҫтәгеҙ.
- `EndKaigi`: сессияны ябып, һуңғы ваҡыт билдәһен яҙығыҙ.

Torii эстафета телеметрияһы түбәндәге `/v1/kaigi/relays`, `/v1/kaigi/relays/{relay_id}`, `/v1/kaigi/relays/health`, һәм `/v1/kaigi/relays/events` әгәр ҡушымта API һәм телеметрия үҙенсәлектәре булдырылған. сессия торошо Kaigi өлкә ваҡиғалары, мәҫәлән `KaigiRosterSummary`, `KaigiRelayManifestUpdated`, `KaigiRelayHealthUpdated`, һәм `KaigiUsageSummary`.

### CLI Тәмәке һынауы {#cli-smoke-test}

`iroha kaigi` CLI менән башлағыҙ, әгәр һеҙ Torii һуңғы нөктәһенең Kaigi транзакцияларын ҡабул итеүен тикшерергә теләһәгеҙ, UI тоташтырыу алдынан. Quickstart командаһы актив Torii һуңғы нөктәһенә ҡаршы ваҡытлыса бүлмә булдыра һәм шылтыратыу идентификаторы, ҡушылыу командаһы һәм SoraNet скрупуляция иҫкәрмәһе менән йомғаҡ яһай:

```bash
iroha kaigi quickstart --auto-join-host --summary-out kaigi-summary.json
```

Сценарийлы ағымдар өсөн бүлмәләрҙең йәшәү циклын асыҡтан-асыҡ идара итеү:

```bash
iroha kaigi create \
  --domain streaming \
  --call-name daily \
  --host <i105-account-id> \
  --privacy-mode transparent \
  --room-policy authenticated

iroha kaigi join --domain streaming --call-name daily --participant <i105-account-id>
iroha kaigi leave --domain streaming --call-name daily --participant <i105-account-id>

iroha kaigi record-usage \
  --domain streaming \
  --call-name daily \
  --duration-ms 120000 \
  --billed-gas 1500

iroha kaigi end --domain streaming --call-name daily
```

Ҡулланыу `--room-policy public` Камералар өсөн, эфирҙа тамашасы билеттары булмаһа ла, эфирға сығырға мөмкин, йәки `--room-policy authenticated` ҡасан сығыу өсөн тамашасы аутентификация талап ителә. `--privacy-mode zk-roster-v1` тик селтәрҙең Kaigi исемлек һәм ҡулланыуҙы раҫлау сымдары конфигурацияланған; башҡаса ҡушылған, япраҡ, һәм шәхси ҡулланыу яҙмалары детерминистик тикшереү ваҡытында юҡҡа сыға.

### JavaScript демоһы менән һынау {#testing-with-the-javascript-demo}

[soramitsu/iroha-demo-javascript](https://github.com/soramitsu/iroha-demo-javascript) десктоп демоһын ҡулланып, аяҡтан аяҡҡа портфель һынау үткәрә. Демо электрон һәм Vue ҡушымтаһы булып тора, ул урындағы `@iroha/iroha-js` бәйләнеше аша туранан-тура Torii менән һөйләшә һәм браузерға туған бер-бер медиа өсөн `/kaigi` маршрутын үҙ эсенә ала.

Демо менән ҡулланырға [`@iroha/iroha-js`](https://github.com/hyperledger-iroha/iroha/tree/0010c5a70039eac101a4846499ba9ceaf43eb65c/javascript/iroha_js) Ссылка на сайт Iroha сығанаҡ репозиторияһы. демо пин SDK аша `file:../iroha/javascript/iroha_js`, Шуға күрә ике кассаны ла ошо ҡусты-ҡустыһы планда һаҡлағыҙ:

Node.js 20 йәки унан яңыһын һәм Rust ҡорамалдар сылбырын ҡулланығыҙ, шуға күрә урындағы `iroha_js_host` модулен төҙөй алаһығыҙ. Сығанағын үҙгәрткәндән һуң туғандаш Iroha кассаһында SDK ҡабаттан төҙөгөҙ; таҙа пакеттың макетында `npm run build:native` кәрәкле йөк эш урыны юҡ.

Контрольле һынау өсөн, Kaigi һәләтле Torii һуңғы нөктәһенә күрһәткестәр ҡуйырға:

1. SORA/Kaigi ҡушымтаһына ҡараған APIs ҡулайлаштырылған Iroha узелын башларға, йәки кәрәкле Kaigi өҫкө йөҙҙәрен асыҡлаусы йәмәғәт һуңғы нөктәһен ҡулланырға.
2. `/health` менән төп барып етеүсәнлекте тикшерегеҙ, һуңынан тере маршрут өҫтөнлөктәрен `/openapi` йәки `/openapi.json` менән тикшерегеҙ. Ҡайһы бер урынлаштырыуҙарҙа шулай уҡ `/v1/health` асыҡлана, әммә `/health` - портатив йәшәүсәнлек контроле.
3. TAIRA өсөн, тере осрашыуҙы һынар алдынан эстафета телеметрияһы маршруттарын тикшерегеҙ:

   ```bash
   TAIRA=https://taira.sora.org
   curl -fsS "$TAIRA/health"
   curl -fsS "$TAIRA/v1/kaigi/relays"
   curl -fsS "$TAIRA/v1/kaigi/relays/health"
   ```

Был тикшеренеүҙәр Torii һәм Kaigi телеметрияһына барып етеү мөмкинлеген иҫбатлай. Улар осрашыу тыуҙырмай; `CreateKaigi` һәм `JoinKaigi` өсөн финансланған аҡса янсыҡтары һәм ҡул ҡуйылған транзакциялар тапшырыу кәрәк.
4. Демонстрацияны асығыҙ, Һайлауҙарға барығыҙ, Torii URL билдәһен ҡуйығыҙ һәм ҡушымтаға сик нөктәһенән ID сылбырҙы һәм селтәр префиксын йөкмәтергә рөхсәт итегеҙ.
5. Демонстрацияла ике урындағы аҡса янсығын булдырыу йәки тергеҙеү. Хост менән ҡунаҡтың аҡса янсығы торошо айырым булһын өсөн, айырым ҡушымта тәҙрәләре, профилдәрен йәки машиналарҙы ҡулланығыҙ.

Kaigi UI һынау өсөн:

1. Ҡунаҡсы тәҙрәһендә Kaigi асығыҙ, осрашыу башлауҙы һайлағыҙ, исемде билдәләгеҙ һәм Шәхси саҡырыу йәки Асыҡ саҡырыуны һайлағыҙ.
2. WebRTC урындағы киң мәғлүмәт саралары булған өсөн камера һәм микрофонды ҡуйып ҡуйырға.
3. Утырыш бәйләнешен булдырыуҙы һайлағыҙ. Тере аҡса янсығы `CreateKaigi` тапшыра; һуңынан ҡушымта `iroha://kaigi/join?call=...&secret=...` саҡырыу һәм `#/kaigi?...` кире маршрутты күрһәтә.
4. Ҡунаҡтың тәҙрәһен асыҡ тот һәм саҡырыуҙы ҡунаҡ менән уртаҡлаш.
5. Ҡунаҡ тәҙрәһендә саҡырыуҙы асығыҙ йәки уны осрашыуҙа ҡатнашырға йәбештерегеҙ, урындағы киң мәғлүмәт сараларын эшләтегеҙ һәм осрашыуҙа ҡатнашыуығыҙҙы һайлағыҙ. Тере аҡса янсығы Torii-ҙан шифрланған хост тәҡдимен ала һәм `JoinKaigi` шифрлы яуап метамәғлүмәттәре менән тапшыра.
6. Ҡунаҡсы беренсе яуапты Kaigi шылтыратыу сигналдарын трансляциялау йәки тауыш биреү аша автомат рәүештә ҡулланырға тейеш. Ике тәҙрә лә тоташҡан медиа һәм яңыртылған бәйләнеш мәғлүмәттәре күрһәтергә тейеш.
7. Сеансты хосттан тамамлау, йәки шул уҡ шылтыратыу өсөн CLI `iroha kaigi end` командаһын ҡулланыу ID.

Шәхси Kaigi кәрәк-яраҡтары һаҡланған XOR шәхси инеү нөктәһе түләү өсөн. әгәр демо хәбәр итә Kaigi кәрәк-яраҡтары һаҡланған XOR, ҡушымталағы үҙаллы эскидты ҡулланыу һәм ҡабаттан булдырыу йәки ҡушылыу хәрәкәтен эшләргә тырышыу. Әгәр дә иҫбатлау генерацияһы, шәхси финанслау йәки тере сигналдар булмаһа, демонстрация үтә күренмәле / ҡулдан үткәрелгән ағымға күсә ала. Ундай осраҡта Advanced Signaling-ты асығыҙ, тәҡдимде йәки яуап пакетын күсерәгеҙ һәм уны икенсе тәҙрәгә ябып ҡуйығыҙ.

Демо репола автоматлаштырылған тикшереүҙәр өсөн, эшләй:

```bash
npm test -- tests/kaigiView.spec.ts tests/preloadKaigiBridge.spec.ts
npm run e2e:ui
npm run verify
```

Үҙәкләштерелгән Vitest Suite-тар Kaigi осрашыуҙар һылтанмаһын булдырыуҙы, компакт саҡырыу йөкләүҙе, шәхси булдырыу / ҡушылыу / тамамлау күпер шылтыратыуҙарын, үҙаллы ҡалҡау ҡуҙғатыуҙарҙы, ҡулдан күсереүҙәрҙе һәм яуап биреүҙе ҡаплай. UI төтөн һынауы өҫтәлмә һәм мобиль ҙурлыҡтағы порттарҙа `/kaigi` маршрутын үҙ эсенә ала. Ике портфель араһында тере медиа әле лә ике тәҙрә һынау кәрәк, сөнки браузер камераһы / микрофон рөхсәттәре һәм тиҫтер-медиа ағымдары тирә-яҡ мөхиткә ҡарата үҙенсәлекле.

Үрнәк интеграция коды өсөн ҡарағыҙ [Үҙ ҡушымтаһында Kaigi индерелгән JavaScript App](/ba/guide/tutorials/kaigi.md).

## Статус һәм метрикалар {#status-and-metrics}

Статусы һәм өлгөһө һуңғы пункттары - Dashboard-тарға беренсе әйберҙәр:

- `/status` юғары кимәлдәге тиңдәш, блок, сират һәм консенсус өлкәләрен аса.
- `/metrics` Prometheus счетчиктары, өлгөһө һәм гистограммалар аса

Nexus менән тәьмин ителгән узелдарҙа, статус сығанағы шулай уҡ трасса һәм мәғлүмәт арауығын күҙәтеүсе секцияларҙы үҙ эсенә ала. `nexus.enabled = false` ваҡытында был секциялар ситләтелә.

## JSON vs Norito {#json-vs-norito}

Бер нисә оператор һуңғы пункттары кире ҡайтыу Norito финиш нөктәһе ярҙам иткәндә JSON, ебәреү:

```http
Accept: application/json
```

Был бигерәк тә файҙалы:

- `/v1/sumeragi/status`
- `/v1/sumeragi/qc`
- `/v1/sumeragi/commit_qc/{hash}`

Әгәр һуңғы пункт Norito тип туранан-тура ҡабул итә йәки кире ҡайтара икән, `application/x-norito` йөкмәтке тибы йәки өҫтөнлөклө `Accept` ҡиммәте булараҡ ҡулланығыҙ. Транспорт мәғлүмәттәре өсөн ҡарағыҙ [Norito](/ba/reference/norito.md#torii-and-norito-rpc).
