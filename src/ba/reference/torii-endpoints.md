# Torii Оҙаҡҡы һыҙаттар {#torii-endpoints}

Torii был HTTP, SSE, һәм WebSocket ҡапҡаһы өсөн Iroha 3. Ул икеләтә лә иҫәп-хисапҡа ҡараған APIs һәм операторҙың һуңғы нөктәләре.

Хәҙерге протокол ҡағиҙәләре:

- Ҡанунлы бинар форматы Norito
- JSON бик күп һуңғы нөктәләр ҙә ярҙам итә, һеҙ `Accept: application/json` ебәргәндә
- метрикалар Prometheus форматында күрһәтелгән

Формат мәғлүмәттәре, йөкмәтке менән һөйләшеү, плановый байраҡтар, схема хэштегтары һәм Norito RPC етәкселек, ҡарағыҙ [Norito ссылка](/ba/reference/norito.md).

## Taira тура юлдарҙы һынап ҡарағыҙ {#try-live-taira-routes}

Йәмәғәтселек Taira тест селтәре шул уҡ асыҡлай Torii JSON Программа клиенттары уҡырға ғына өйрәнеү өсөн ҡулланылған өҫкө йөҙө.

```bash
TAIRA_ROOT=https://taira.sora.org

curl -fsS "$TAIRA_ROOT/status" \
  | jq '{blocks, txs_approved, txs_rejected, queue_size, peers}'

curl -fsS "$TAIRA_ROOT/openapi.json" \
  | jq -r '.paths | keys[]' \
  | grep '^/v1/' \
  | head -n 20

curl -fsS "$TAIRA_ROOT/v1/node/capabilities" \
  | jq '{abi_version, data_model_version, query: .query.aggregate.supported_resources}'
```

Хәҙерге донъя хәленә ҡарап сығайыҡ:

```bash
curl -fsS "$TAIRA_ROOT/v1/domains?limit=5" \
  | jq -r '.items[].id'

curl -fsS "$TAIRA_ROOT/v1/assets/definitions?limit=5" \
  | jq -r '.items[] | [.id, .name, .total_quantity] | @tsv'
```

Әгәр асыҡ тест селтәре маршруты кире ҡайта `502`, ваҡыттарҙы өҙөп, йәки туйынған сират тураһында хәбәр итһә, уны һуңғы нөктәлә булыу проблемаһы тип ҡарағыҙ һәм клиент кодын дебэглауҙан алда тағы ла тырышығыҙ.

## ISO 20022 күпер {#iso-20022-bridge}

Torii асыҡлай ISO 20022 күпер аҫтында `/v1/iso20022/*` әгәр ҡушымтаға ҡараған API һәм күпер хәрәкәте ваҡыты булдырылған. Күпер маҡсатлы масштаблы: ул дөйөм тәғәйенләнешле түгел ISO 20022 клиринг шлюзы, әммә һайлап алынған түләү хәбәрҙәрен ҡул ҡуйылғанға әйләндереү өсөн ярҙам ителгән төркөмсә. Iroha күсереүҙәр һәм уларҙың бухгалтер статусын күҙәтеү өсөн.

Ссылка мәғлүмәттәрен конфигурациялағанда, күпер шулай уҡ тикшереү BIC, IBAN, һәм ISO Булдырылған транзакция үткәргескә ингәнгә тиклем 4217 валюта аша үтә.

`pacs.009` тапшырыуҙар эшлекле хәбәр бирергә тейеш ID, хәбәрҙең билдәләмәһе ID, барлыҡҡа килтереү ваҡыты, банктар араһындағы иҫәп-хисап күләме, валюта, иҫәп-хисабы датаһы, йөкләмә биреүсе һәм йөкләмә бирелгән агенттар BICs, һәм бурыслы һәм кредитор IBANs. Әгәр хәбәрҙә `Purp`, Хәҙерге ваҡытта күпер ҡиммәтле ҡағыҙҙар өсөн генә финанслау ҡабул итә: `Purp=SECU`.

Ҡоролтай `pacs.008` һәм `pacs.009` тапшырыуҙың һуңғы пункттары ҡабул ителә XML ISO күпер һынауҙарында ҡулланылған яҫы майҙан форматы йәки конверттар. `SplmtryData` баҫыуҙар маҡсат ҡуйырға мөмкин Iroha бухгалтер иҫәбе, сығанаҡ һәм маҡсатлы иҫәп IDs йәки адрес һәм активтар билдәләмәһе ID. Яуап: `202 Accepted` менән `message_id`, `transaction_hash`, `status`, `pacs002_code`, һәм хәл ителгән иҫәп-хисап / иҫәб / актив контексты.

## Kaigi Сессиялар {#kaigi-sessions}

Kaigi түләүле, ысын ваҡытлы аудио/видео бүлмәләре менән тәьмин итә SORA Nexus. Ҡулланырға кәрәк, әгәр ҡушымтаға иҫәп яҙмаһы ярҙамында сессия булдырыу, реестры үҙгәрештәрен, эстафетаны манифестар, шифрланған сигнализация һәм ҡулланыу өлгөһө урынына тотоноу өсөн бөтә конференц-хәллеген сит сылбырҙан.

Китапҡа ҡараған тормош циклы:

- `CreateKaigi`: домен аҫтында шылтыратыу булдырыу һәм уның сәйәсәтен, графигын, метамәғлүмәттәрен һәм ирекле эстафетаны һаҡлау.
- `JoinKaigi` һәм `LeaveKaigi`: саҡырыуҙар исемлеген яңыртыу. шәхси режимда ҡатнашыусылар ҡатнашыусылар иҫәбенә асыу урынына йөкләмәләр, юҡҡа сығарыусылар һәм исемлек иҫбатлауҙарын ҡулланалар IDs туранан-тура.
- `RecordKaigiUsage`: иҫәпләнгән ваҡыт һәм газ суммаһын өҫтәгеҙ.
- `EndKaigi`: ултырышты ябып, һуңғы ваҡыт билдәһен яҙҙыр.

Torii эстафета телеметрияһы түбәндәге `/v1/kaigi/relays`, `/v1/kaigi/relays/{relay_id}`, `/v1/kaigi/relays/health`, һәм `/v1/kaigi/relays/events` әгәр ҡушымта API һәм телеметрия үҙенсәлектәре булдырылған. сессия торошо Kaigi өлкә ваҡиғалары, мәҫәлән `KaigiRosterSummary`, `KaigiRelayManifestUpdated`, `KaigiRelayHealthUpdated`, һәм `KaigiUsageSummary`.

### CLI Тәмәке һынауы {#cli-smoke-test}

Һөйләү менән башларға `iroha kaigi` CLI әгәр һеҙ тикшерергә теләһәгеҙ, Torii сикләү пункты ҡабул итә Kaigi транзакциялар бәйләнеше UI. Тиҙ старт командаһы активға ҡаршы ваҡытлыса бүлмә булдыра Torii сикләү пункты һәм шылтыратыу идентификаторы менән йомғаҡ баҫтырыу, ҡушыу командаһы, һәм SoraNet скрупулевая намека:

```bash
iroha kaigi quickstart --auto-join-host --summary-out kaigi-summary.json
```

Сценарийлы ағымдар өсөн бүлмәләрҙең йәшәү циклын асыҡтан-асыҡ идара итеү:

```bash
iroha kaigi create \
  --domain streaming \
  --call-name daily \
  --host <i105-account-id> \
  --privacy-mode transparent \
  --room-policy authenticated

iroha kaigi join --domain streaming --call-name daily --participant <i105-account-id>
iroha kaigi leave --domain streaming --call-name daily --participant <i105-account-id>

iroha kaigi record-usage \
  --domain streaming \
  --call-name daily \
  --duration-ms 120000 \
  --billed-gas 1500

iroha kaigi end --domain streaming --call-name daily
```

Ҡулланыу `--room-policy public` Камералар өсөн, эфирҙа тамашасы билеты булмаһа ла, эфирға сығыу мөмкин, йәки `--room-policy authenticated` ҡасан сығыу өсөн тамашасы аутентификация талап ителә. `--privacy-mode zk-roster-v1` тик селтәрҙең Kaigi реестр һәм ҡулланыу менән раҫлау асҡыстары конфигурацияланған; башҡаса берләшмәләр, биттәр һәм шәхси ҡулланыу яҙмалары детерминистик тикшереү ваҡытында юҡҡа сыға.

### JavaScript демоһы менән һынау {#testing-with-the-javascript-demo}

Демо менән ҡулланырға [`@iroha/iroha-js`](https://github.com/hyperledger-iroha/iroha/tree/main/javascript/iroha_js) Ссылка на сайт Iroha сығанаҡ репозиторияһы. демо пин SDK аша `file:../iroha/javascript/iroha_js`, Шуға күрә ике кассаны ла ошо ҡусты-ҡустыһы планда һаҡлағыҙ:

```bash
mkdir iroha-wallet-workspace
cd iroha-wallet-workspace
```

Ҡулланыу Node.js 20 йәки яңы һәм Rust инструмент цехы шулай итеп туғандаш `iroha_js_host` модуль төҙөй ала. SDK һеңлеһе менән Iroha сығанағын үҙгәрткәндән һуң иҫкәртеү; таҙа пакеттың төҙөлөшө йөк өсөн кәрәкле эш урыны `npm run build:native`.

Контрольле һынау өсөн, Kaigi һәләтле Torii һуңғы нөктәһенә күрһәткестәр ҡуйырға:

1. Башларға Iroha узел менән SORA/Kaigi ҡушымтаға ҡарау APIs булдырылған, йәки асыҡ һуңғы нөктәне ҡулланыу Kaigi Һеҙгә кәрәк булған өҫкө йөҙҙәр.
2. Төп мөмкинлектәрен тикшерегеҙ `/health`, һуңынан тере маршрут өҫкө йөҙөн тикшерегеҙ `/openapi` йәки `/openapi.json`. Ҡайһы бер урынлаштырыуҙар шулай уҡ асып `/v1/health`, әммә `/health` күсермәле йәшәүсәнлек контроле.
3. TAIRA өсөн, тере осрашыуҙы һынар алдынан эстафета телеметрияһы маршруттарын тикшерегеҙ:

   ```bash
   TAIRA=https://taira.sora.org
   curl -fsS "$TAIRA/health"
   curl -fsS "$TAIRA/v1/kaigi/relays"
   curl -fsS "$TAIRA/v1/kaigi/relays/health"
   ```

   Был тикшереүҙәр иҫбатлай Torii һәм Kaigi эстафета телеметрияһы барып етә. Улар осрашыу тыуҙырмай; `CreateKaigi` һәм `JoinKaigi` Әлегә аҡсалы портфелдәр һәм ҡул ҡуйылған транзакциялар тапшырыу кәрәк.
4. Демонстрацияны асығыҙ, Һайлауҙарға барығыҙ, ҡушымтаны ҡуйығыҙ Torii URL, һәм ҡушымта селтәрҙе йөкмәтергә ID һәм һуңғы нөктәһенән селтәр префиксы.
5. Демонстрацияла ике урындағы аҡса янсығын булдырыу йәки тергеҙеү. Хост менән ҡунаҡтың аҡса янсығы торошо айырым булһын өсөн, айырым ҡушымта тәҙрәләре, профилдәрен йәки машиналарҙы ҡулланығыҙ.

Kaigi UI һынау өсөн:

1. Ҡунаҡсы тәҙрәһендә Kaigi асырға, осрашыу башлауҙы һайларға, исем ҡуйырға һәм шәхси саҡырыу йәки үтә күренмәле саҡырыу һайларға.
2. WebRTC урындағы киң мәғлүмәт саралары булған өсөн камера һәм микрофонды ҡуйып ҡуйырға.
3. Һайла: осрашыуҙар өсөн ссылка булдырыу. `CreateKaigi`; ҡушымтанан һуң күрһәтелә `iroha://kaigi/join?call=...&secret=...` саҡырыу һәм `#/kaigi?...` Төшөп ҡайтыу юлы.
4. Ҡунаҡтың тәҙрәһен асыҡ тот һәм саҡырыуҙы ҡунаҡ менән уртаҡлаш.
5. Ҡунаҡ тәҙрәһендә саҡырыуҙы асығыҙ йәки уны осрашыуҙа ҡатнашырға йәбештерегеҙ, урындағы киң мәғлүмәт сараларын эшләтегеҙ һәм осрашыуҙа ҡатнашыуығыҙҙы һайлағыҙ. Тере аҡса янсығы Torii-ҙан шифрланған хост тәҡдимен ала һәм `JoinKaigi` шифрлы яуап метамәғлүмәттәре менән тапшыра.
6. Ҡунаҡсы беренсе яуапты Kaigi шылтыратыу сигналдарын трансляциялау йәки тауыш биреү аша автомат рәүештә ҡулланырға тейеш. Ике тәҙрә лә тоташҡан медиа һәм яңыртылған бәйләнеш мәғлүмәттәре күрһәтергә тейеш.
7. Сессияны хосттан тамамлау, йәки CLI `iroha kaigi end` шул уҡ саҡырыу өсөн команда ID.

Шәхси Kaigi кәрәк-яраҡтары һаҡланған XOR шәхси инеү нөктәһе түләү өсөн. әгәр демо хәбәр итә Kaigi кәрәк-яраҡтары һаҡланған XOR, ҡушымталағы үҙаллы һаҡлау саҡырыуын ҡулланығыҙ һәм ҡабаттан булдырығыҙ йәки ҡушылығыҙ. Әгәр дә иҫбатлау генерацияһы, шәхси финанслау йәки тере сигналдар булмаһа, демо үтә күренмәле / ҡулдан килгән ағымға кире төшә ала.

Демо репола автоматлаштырылған тикшереүҙәр өсөн, эшләй:

```bash

```

Витест фатирҙары ҡапҡаһы Kaigi осрашыуҙар-ссылкалар булдырыу, компакт саҡырыу йөкләү, шәхси булдырыу / ҡушылыу / тамамлау күпер шылтыратыуҙары, үҙ-ишетеү иҫкәрмәләре, ҡулдан ҡайтарыу һәм яуап һорау алыу. UI төтөн һынауы үҙ эсенә `/kaigi` Өҫтәл һәм мобиль күләмле ҡарау порттарында маршрут. ике аҡса янсығы араһында тере медиа әле лә ҡулдан ике тәҙрә тестҡа мохтаж, сөнки браузер камераһы/микрофонға рөхсәттәре һәм тиңдәш медиа ағымдары тирә-яҡ мөхиткә ҡарата үҙенсәлекле.

## JSON vs. Norito {#json-vs-norito}

Бер нисә оператор һуңғы пункттары кире ҡайтыу Norito финиш нөктәһе ярҙам иткәндә JSON, ебәреү:

```http
Accept: application/json
```

Был бигерәк тә файҙалы:

- `/v1/sumeragi/status`
- `/v1/sumeragi/qc`
- `/v1/sumeragi/commit_qc/{hash}`

Ахыр нөктәһе ҡабул иткәндә йәки типографияны кире ҡайтарғанда Norito туранан-тура, ҡулланыу `application/x-norito` йөкмәтке тибы йәки өҫтөнлөклө `Accept` ҡиммәте. [Norito](/ba/reference/norito.md#torii-and-norito-rpc) транспорт мәғлүмәттәре өсөн.
