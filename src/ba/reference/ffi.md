# Сит функциялар интерфейстары (FFI) {#foreign-function-interfaces-ffi}

Ҡоролтай `iroha_ffi` crate C сығарыу өсөн макролар һәм һыҙаттар бирә ABI бәйләнештәр Rust APIs. Унда ҡулланыла: Iroha Типтар аша сығырға кәрәк FFI сиктәре, мәҫәлән: SDK бәйләнештәр йәки ҡабул итеүсе интеграциялар.

## Ни өсөн FFI {#why-ffi}

Функция абстракт берәмек булып тора, һәм күпселек телдәр функцияның нимә эшләргә тейешлеге менән килешһә лә, Функцияларҙың сағылыш алымы бик төрлө. Rust, Функцияны саҡырыуҙың эҙемтәләре һәм уға эшләргә рөхсәт ителгән нәмәләр ҙә төрлө. Rust APIs икенсе телдән йәки башҡа ҡабул итеү мөхитенән саҡырырға кәрәк, Iroha сит функциялар интерфейсын ҡуллана (FFI) уйындарҙы тигеҙләү өсөн.

Хәҙерге ваҡытта ҡулланылған төп стандарт - C ҡушымтаһы бинар интерфейсы. Ул ябай, киң таралған һәм тотороҡло. Принцип буйынса, һеҙ барыһын да ҡул менән эшләй алаһығыҙ, әммә Iroha тәьмин итә `iroha_ffi` яһау өсөн crate FFI- ғәмәлдә булған функциялар буйынса Rust API.

Әлбиттә, быны үҙегеҙсә лә эшләй алаһығыҙ. `iroha_ffi` crate-ы барыбер яҙырға кәрәк булған кодты ғына булдыра. Кәрәкле өлгө кодын ҡулдан яҙыу ҙур иғтибар һәм тәртип талап итә. FFI сиген үткән һәр функция саҡырыуы `unsafe` һәм билдәләнмәгән тәртипкә килтереүе мөмкин. Был мәсьәләне **ныҡлы** `repr(C)` типтарын ҡулланып хәл иттек.

::: info

Берҙән-бер айырыу - күрһәткестәр. Һис мәғәнәһеҙ тикшереү һәм бойондороҡһоҙлоҡ бөтә донъя күләмендә үтәлмәй, шуға күрә сей күрһәткестәр (әленән-әле) тик ғәҙәти осраҡтарҙа ғына ҡулланыла. Iroha мәғлүмәттәр моделендә объекттың һәр миҫалын программа wrapper-ҙары бирелгәнгә күрә, һиҙгерҙәрҙе бөтөнләй ҡулланырға кәрәкмәйәсәк.

:::

## Миҫал {#example}

Бында бәйләнеште булдырыу миҫалы килтерелә:

```rust
#[derive(FfiType)]
struct DaysSinceEquinox(u32);

#[ffi_export]
impl DaysSinceEquinox {
    pub fn update_value(&mut self, a: &u8) {
        self.0 = *a as u32;
    }
}
```

Өҫтәге миҫал `DaysSinceEquinox` асыҡ булмаған күрһәткес итеп күрһәтелгән түбәндәге бәйләнеште булдыра:

```rust
pub extern fn DaysSinceEquinox__update_value(handle: *mut DaysSinceEquinox, a: *const u8) -> FfiReturn {
    // function implementation
}
```

## FFI Ҡатмарлы быуын {#ffi-binding-generation}

`iroha_ffi` crateһы FFI аша саҡырылырға мөмкин булған функциялар тыуҙырыу өсөн ҡулланыла. `Rust` структураларын һәм ысулдарын иҫәпкә алғанда, улар бәйләү сиген үтеү өсөн кәрәкле `unsafe` кодын булдыра.

А Rust тип ныҡлы әйләндерелә `repr(C)` тип аша сығырға мөмкин FFI сиктәре менән `FfiType::into_ffi`. Был шулай уҡ кире яҡҡа бара: FFI `ReprC` типҡа әйләндерелә `Rust` тип аша `FfiType::try_from_ffi`.

::: warning

Иҫегеҙгә төшөрәбеҙ, кире конверсия хаталы һәм билдәләнмәгән тәртипкә килтерә ала. Беҙ иң асыҡ хаталарҙы булдырмаҫҡа мөмкин булғандың барыһын да эшләй алабыҙ, әммә һеҙ программаның дөрөҫлөгөн тәьмин итергә тейешһегеҙ.

:::

Төп һыҙаттар - `ReprC`, `FfiType` һәм `FfiConvert`.

|Төҙөлөш |Тасуирлау |
| ------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
|`ReprC` |Был һыҙат C ABI тибына ярашлы ныҡлы типты сағылдыра. Тип FFI сиктәрендә хәүефһеҙ рәүештә бүленә ала. |
|`FfiType` | Был һыҙат тейешле билдәләй `ReprC` бирелгән типҡа `Rust` тип. билдәләнгән `ReprC` тип ҡулланыла алмаштырыу `Rust` типта яҙылған API барлыҡҡа килгән FFI функцияһы. |
|`FfiConvert` |Был үҙенсәлек `into_ffi` һәм `try_from_ffi` ысулдарын билдәләй, улар `Rust` тибын `ReprC` типҡа йәки унан күсереү өсөн ҡулланыла. |

Иҫегеҙгә төшөрәбеҙ, хужалыҡтың FFI Өҙгөһөҙ күрһәткес тибынан тыш. башҡа төрҙәрҙең барыһы ла, мәҫәлән `Vec<T>`, клонлаштырылған.

### Исеме Манглинг {#name-mangling}

FFI объекттарының барлыҡҡа килгән исемдәрендә икеләтә һыҙыҡлы билдәләр ҡулланылғанлығын иҫкә төшөрәйек:

- `StructName` структураһында билдәләнгән `inherent_fn` ысулы өсөн, FFI исеме `StructName__inherent_fn` булыр.
- `StructName` структураһындағы `TraitName` һыҙаттан `MethodName` ысулы өсөн FFI исеме `StructName__TraitName__MethodName` булыр ине.
- `StructName` структураһындағы `field_name` яланы билдәләү өсөн FFI функцияһы исеме `StructName__set_field_name` була.
- `StructName` структураһында `field_name` яланы алыу өсөн, FFI функцияһының исеме `StructName__field_name` булыр.
- `StructName` структураһында үҙгәреүсән `field_name` яланы алыу өсөн, FFI функцияһының исеме `StrucuName__field_name_mut` булыр.
- Үҙаллы торған `module_name::fn_name` өсөн FFI исеме `module_name::__fn_name` булыр.
- FFI (ҡара: `Clone` түбәндә) дөйөм булмаған һәм уларҙы тормошҡа ашырыуҙы уртаҡлаштырырға мөмкинлек биргән һыҙаттар өсөн, FFI исеме `module_name::__clone` булыр.

  ```rust
  impl Clone for Type1 {
      fn clone(&self) -> Self;
  }
  impl Clone for Type2 {
      fn clone(&self) -> Self;
  }
  ```
