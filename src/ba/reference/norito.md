## Кодировка ҡағиҙәләре {#encoding-rules}

Norito Iroha мәғлүмәт моделендә күрһәтелгән дөйөм мәғлүмәттәр формалары өсөн детерминистик схемалар ҡуллана:

- Һылтанмалар `[len][utf8-bytes]`; `len` ҡулайлаштырылған осраҡта `COMPACT_LEN` артынан килә.
- Әгәр `COMPACT_LEN` ҡуйылған икән, тигеҙлек буйынса оҙонлоҡтарҙа компактлы варинттар ҡулланыла, башҡаса 8 байтлыҡ бәләкәй ендиан `u64` билдәләнгән.
- Сиквенция оҙонлоғо башлыҡтары 8-байт аҙ ендиан `u64` v1 фиксирован.
- `Vec<u8>` бер байтҡа бер оҙонлоҡҡа түгел, ә `[len_u64][raw-bytes]` тип кодлана.
- Баҫтырылған эҙмә-эҙлектәре ҡулланыу `(len + 1)` monotonic `u64` компенсацияһы, һуңынан конкатенат элементтар файҙалы йөкләнеүҙәр.
- Карталар яҙма һанын `u64` менән кодлай һәм детерминистик клавиша тәртибен ҡуллана. `HashMap` яҙыуҙар кодлауҙан алда клавиша буйынса sortлана; `BTreeMap` уның тәбиғи тәртибен ҡулланған.
- `BigInt` `u32` байт оҙонлоғо һәм 512-битлы япмаһы менән ҙур булмаған ике биттең тулыландырыу байттарын ҡуллана.
- `Numeric` `(mantissa, scale)` тип кодлана, унда мантисса бөтөн һандар ҡиммәтен һәм масштаб өлөшлө цифрҙар һанын һаҡлай.

Был ҡағиҙәләр ҡултамғалар һәм хештар өсөн мөһим. ике SDKs бер үк логик транзакция төҙөргә тейеш шул уҡ каноник байттар сығараһы.

|`json-std-io` |Уҡыусы һәм яҙыусы ярҙамсылары JSON стекҡа ҡатламы менән ҡуйылған. |
|`metal-stage1`, `cuda-stage1` |Факультатив GPU JSON структура индексы битлектәре. |
|`metal-stage2` |JSON конструкция таҫмаһы өсөн металл метаданмалар классификацияһы. |
|`metal-crc64`, `cuda-crc64` |GPU CRC64 ярҙамсылары ҙур йөк өсөн. |
|`gpu-compression` |Вариантлы металл йәки CUDA Zstd тиҙләтеү ҙур файҙалы йөк өсөн. |
|`stage1-validate` |Тиҙерәкләштерелгән JSON структура индекстарын скаляр сығанаҡ менән сағыштырыусы дебаг раҫлау.|

SDKs һәм релиз профилдәре араһында үҙенсәлектәре булыуы мөмкин. Сел форматы урындағы төҙөлөш флагтары түгел, ә баш бит һәм схема менән идара ителә.

## Torii һәм Norito RPC {#torii-and-norito-rpc}

Torii күп оператор маршруттары өсөн JSON асыра, әммә типланған бинар маршруттарҙа Norito ҡулланыла. ток типланған Norito HTTP корпустары өсөн медиа тибы `application/x-norito`.

Norito тип яҙылған йомғаҡлау пункты ҡабул иткәндә йәки кире ҡайтарғанда ошо башлыҡтарҙы ҡулланығыҙ:

```http
Content-Type: application/x-norito
Accept: application/x-norito
```

Әгәр һуңғы пункт ике күрһәткесте лә хуплай икән, клиенттар асыҡ өҫтөнлөк исемлеген ебәрә ала:

```http
Accept: application/x-norito, application/json
```

Декодлау етешһеҙлектәре тип яҙылғанса барлыҡҡа килә . Torii хаталар һәм телеметрия буйынса иҫәпләнгән. Ғәҙәттә сәбәптәр иҫәбенә: ялған сихыр, ярҙамһыҙ версия, ярҙамһыҙ функциялы флаг, иҫәбенә тура килмәгән, формаһы боҙолған UTF-8, валид Enum билдәһе, һәм схема буйынса тап килмәй.

Norito RPC транспорты транспорт конфигурацияһы аша һайлана. Оператор панелдәрендә үтенестәрҙең кисектерелеүе, өҙлөгөүҙәр, актив бәйләнештәр, яуап байттары һәм `torii_norito_decode_failures_total` трафигы JSON трафигынан айырым күҙәтелә тейеш.

## Norito Ағымлаштырыу {#norito-streaming}

Norito Стриминг шул уҡ детерминистик алымды медиа һәм реаль ваҡыт транспорты өҫкө йөҙҙәренә киңәйтә. Уның төп өлөштәрен:

|Стриминг функцияһы |Маҡсат |
| --- | --- |
|Манифесттар |Сегмент йөкләмәләрен, хосусилыҡ маршруттарын, мөмкинлектәрен, кодек профилен, шифрлау комплекттарын һәм контент төп метамәғлүмәттәрен белдерә. |
|Сегмент башлыҡтары |Бинд сегмент номеры, оҙайлығы, киҫәк һанын, ваҡытын, энтропия режимын, аудио йомғаҡлауҙы һәм Меркл тамырҙарын. |
|Ваҡытлы йөкләмәләр |Тамашасыларға һәм эстафеталарҙы хеҙмәтләндереүгә йәки декодлауға тиклем манифестҡа ҡарата файҙалы йөклөктө тикшерергә рөхсәт итегеҙ. |
|Контроль кадрҙары |Манифест иғлан, фекер алышыуҙар, төп яңыртыуҙар һәм мөмкинлектәре буйынса һөйләшеүҙәр алып барыу. |
|HPKE төп яңылыҡтар |Транспорт серҙәрен килешеүҙәр буйынса һәм монотонно арта торған счетчиктар ярҙамында әйҙәгеҙ. |
|Мөмкинлек буйынса һөйләшеү |Ҡатнашыусы функциялар биттәре, датаграмма сикләүҙәре, кире ҡайтыу циклы һәм хосусилыҡ талаптары. |
|FEC һәм фекер алышыу |Детерминистик ҡабул итеүсе отчеттары һәм юғалтыу реаль ваҡыт юлдары өсөн паритет ҡарарҙары ҡулланыла. |
|Тейешлек векторҙары |Телдәр араһындағы ҡушымталар SDKs шул уҡ манифесттарҙы, сегменттарҙы һәм энтропия ағымдарын декодлауын иҫбатлай. |

Стриминг-специфик кодектар һәм энтропия профилдәре төп Norito транзакция / һорау форматынан айырылып тора, әммә уларҙың манифесттары һәм идара итеү мәғлүмәттәре һаман да Norito ҡуллана, шуға күрә маршрутизация, иҫәпләү, ҡабаттан уйнатыу һәм аудит иҫбатлауҙары ҡабатланмаҫ булып ҡала .

## Операция буйынса күрһәтмәләр {#operational-guidance}

- SDK төҙөүселәрҙе һәм ҡул менән эшләнгән Norito байтҡа ҡарағанда барлыҡҡа килгән бәйләнештәрҙе өҫтөнлөк биреү.
- Схеманың тап килмәүен версия йәки ҡоролма проблемаһы булараҡ ҡарағыҙ, ваҡытлыса селтәр боҙолоуы тип түгел.
- `.nrt`, `.norito` әйберҙәрен һаҡлап ҡалығыҙ һәм уларҙы барлыҡҡа килтергән иреккә сығарыу йәки инцидент төркөмө менән бергә күрһәтегеҙ.
- Дашбордтар һәм ҡул менән тикшереү өсөн JSON проекцияларын ҡулланығыҙ, әммә имзаланған, хэштегланған йәки һаҡланып ҡалған мәғлүмәттәр өсөн дөрөҫлөктөң сығанағы итеп Norito ты тотоғоҙ.
- Яңы типланған Torii һуңғы нөктәһен өҫтәгәндә, ул JSON, Norito йәки икеһен дә ҡабул итәме-юҡмы икәнен документта ҡалдырығыҙ һәм `/openapi` буйынса ярҙам ителгән йөкмәтке төрҙәрен күрһәтегеҙ.
- Ускортырғыстарҙы эшләткәндә, тиҙләткесте файҙалы йөкләү семантикаһын алмаштырыу урынына, тиҙләтеүсе етешһеҙлектәрен яҡшыраҡ хәл итергә кәрәк.
