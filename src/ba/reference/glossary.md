## Блокчейн бухгалтерҙары {#blockchain-ledgers}

Блокчейн реестрҙары - финанс яҙмаларын һаҡлау өсөн блокчейн технологияларын ҡулланған цифрлы иҫәп-хисап системаһы.

Урта быуаттар осоронда иҫәп-хисап китаптары йәмәғәтселек өсөн асыҡ була. Был идея блокчейнға нигеҙләнгән системаларҙа сағылыш таба.

## Тиҫтерҙәр {#peer}

Бер яҡташы Iroha тигәнде аңлата Iroha башҡа процессы инстанцияһы Iroha процесстар һәм клиент ҡушымталары тоташа ала. бер машина бер нисә Iroha Тиҫтерҙәр үҙ ресурстары һәм мөмкинлектәренә ҡарата тигеҙ, бер мөһим сиселеш менән: бары тик бер тиҫтерҙәр генез блогын башлау этабында эшләй Iroha селтәрендә.

Башҡа блокчейндар узел йәки валидатор кеүек үк төшөнсәгә һылтана ала.

Бер-береһе менән бер рәттән үҙ хужаһы системаһындағы процестар була ала. Docker контейнер һәм Кубернетес капсулаһы.

## Активтар {#asset}

Блокчейн контексында актив - ул блокчейнда ҡиммәтле объекттың сағылышы.

Дополнительная информация о активах доступна [здесь](/ba/blockchain/assets.md).

### Функциональ активтар {#fungible-assets}

Бындай активтарҙы бер үк типтағы башҡа активтарға алмаштырырға мөмкин, сөнки улар үҙ-ара алмашынырға мөмкин.

Мәҫәлән, бер үк валютаның бөтә берәмектәренең хаҡы тигеҙ һәм улар тауарҙар һатып алыу өсөн ҡулланыла ала.

### Ҡатмарлы булмаған активтар {#non-fungible-assets}

Фунгибл булмаған активтар үҙенсәлекле һәм ҡиммәтле, сөнки уларҙың үҙенсәлектәре һәм һирәклеге бар; уларҙы башҡа активтар менән сағыштырырға мөмкин түгел.

- Һындың ҡиммәте рәссамға, уның төшөрөлгән ваҡытына һәм халыҡтың уға ҡыҙыҡһыныуына бәйле була.
- Бер урамдағы ике йорттоң хеҙмәтләндереү кимәле төрлө булырға мөмкин.
- Биҙәүестәр етештереүселәр, ғәҙәттә, төрлө дизайн тәҡдим итә.

### Һаҡлана торған активтар {#mintable-assets}

Бер үк тибындағы активтар бер нисә тапҡыр сығарылһа, улар эшләп сығарыла.

### Яҡшы булмаған активтар {#non-mintable-assets}

Әгәр активтың башланғыс күләме бер тапҡыр билдәләнһә һәм үҙгәрмәһә, ул юғалтылмаҫлыҡ һанала.

[Башланмыш блогы](/ba/guide/configure/genesis.md) был мәғлүмәтте Iroha конфигурацияһы өсөн ҡуя.

## Iroha компоненттары {#iroha-components}

Rust модулдәрендә Iroha функцияһы бар.

### Sumeragi (император) {#sumeragi-emperor}

Iroha модуле - консенсус өсөн яуаплы.

### Torii (ҡапҡа) {#torii-gate}

[ peer](#peer) өсөн килгән һорауҙар менән идара итеү логикаһы булған модуль. Ул килгән инструкцияларҙы һәм HTTP һорауҙарҙы ҡабул итеү, ҡабул итеү һәм маршрутлаштырыу өсөн, шулай уҡ хәрәкәт ваҡыты конфигурацияһы яңыртыуҙары өсөн ҡулланыла .

### Kura (Хәзинә) {#kura-warehouse}

Бер туҡтауһыҙ блоктарҙы һаҡлау. Kura ҡул ҡуйылған блоктарҙы, блок хэштегтарын, бейеклек индекстарын, тергеҙеү ситтәрен һәм дискта commit-roster метамәғлүмәттәрен һаҡлай. [Донъяға ҡараш](#world-state-view-wsv) үҙгәртеп ҡоролған Kura блоктар, әгәр дәүләт фотоһүрәттәре юҡ йәки урындағы блок магазины артында. [Kura һаҡлау](/ba/blockchain/world.md#kura-storage).

### Kagami(Уҡытыусы һәм өлгөһө һәм/йәки көҙгө) {#kagami-teacher-and-exemplar-and-or-looking-glass}

Йыш ҡулланылған мәғлүмәттәр өсөн генератор. Ул криптографик асҡыс парҙарын, генез блоктарын, документацияны һ.б.

### Меркл ағасы (хаш ағасы) {#merkle-tree-hash-tree}

Һәр блок бейеклегендә дәүләтте раҫлау һәм тикшереү өсөн ҡулланылған мәғлүмәттәр структураһы. Iroha ны ғәмәлгә ашырыу бинар ағас булып тора. тулыраҡ мәғлүмәт өсөн [Википедия](https://en.wikipedia.org/wiki/Merkle_tree) ҡарағыҙ.

### Аҡыллы килешеүҙәр {#smart-contracts}

Аҡыллы килешеүҙәр - блокчейн нигеҙендә программалар, улар билдәле бер шарттар йыйылмаһы үтәлгәндә эшләй. Iroha аҡыллы килешеүҙәр ҡулланыу менән тормошҡа ашырыла [ядроһы Iroha махсус күрһәтмәләр](#core-iroha-special-instructions).

### Ҡатҡандар {#triggers}

Һәйкәл тибы, ул саҡырыу мөмкинлеге бирә Iroha айырым блок commit, ваҡыт (ҡайһы бер иҫкәртеү менән), һ.б. буйынса махсус инструкция [бында](/ba/blockchain/triggers.md).

### Версиялаштырыу {#versioning}

Һәр ғариза менән билдәләнгән API Ул төрлө бинар версиялар комбинацияһын рөхсәт итә. Iroha клиент/партнер программаһы үҙ-ара эш итә, был үҙ сиратында программа яңыртыу мөмкинлек бирә Iroha селтәрендә.

### Хижири (тәңреле абруй системаһы) {#hijiri-peer-reputation-system}

Iroha Исеме системаһы. Был аралашыу өҫтөнлөк биреү мөмкинлеге бирә [тиҫтерҙәре](#peer) яҡшы трек-рекордҡа эйә, һәм зарарлы булыуы мөмкин зыян кәметеү [тиҫтерҙәре](#peer).

Аҡыллы килешеүҙәр китапханаһы Iroha. Улар транзакциялар йәки теркәлгән ваҡиға тыңлаусылары аша телгә алына ала. ISI [бында](/ba/blockchain/instructions.md).

#### Яҡшылыҡ Iroha Махсус күрһәтмәләр {#utility-iroha-special-instructions}

Был йыйылмаһы [ссылка](#iroha-special-instructions-isi) логик күрһәтмәләрҙе үҙ эсенә ала: `If`, I / O менән бәйле кеүек `Notify` һәм композициялар кеүек `Sequence`. Улар башлыса ҡулланыла [үҙенсәлекле күрһәтмәләр](#custom-iroha-special-instruction).

### Үҙәк Iroha Махсус күрһәтмәләр {#core-iroha-special-instructions}

### Доменға ҡағылышлы Iroha Махсус күрһәтмәләр {#domain-specific-iroha-special-instructions}

Доменға ҡағылышлы эшмәкәрлек буйынса күрһәтмәләр: активтар, иҫәптәр, домендар, тиңдәштәре менән идара итеү). Улар [World State View](#world-state-view-wsv)-ҡа хәүефһеҙ һәм хәүефһеҙ рәүештә үҙгәрештәр яһар өсөн кәрәкле инструменттар бирә.

### Ғәҙәттән тыш Iroha Махсус инструкция {#custom-iroha-special-instruction}

Инструкция [Iroha Модулдар](#iroha-modules), Клиенттар йәки өсөнсө яҡтар тарафынан төҙөлгән. [Төп күрһәтмәләр](#core-iroha-special-instructions). Форкинг һәм үҙгәртеп ҡороу Iroha сығанаҡ коды тәҡдим ителмәй, сөнки махсус инструкциялар менән килешеү [тиҫтерҙәре](#peer) бер Iroha урынлаштырыу хаталар тип ҡараласаҡ, шуға күрә [тиҫтерҙәре](#peer) үҙгәртелгән экземплярҙы эшләгәндә, уларға инеү мөмкинлеге кире ҡағыласаҡ.

## Күҙәтеү үҙгәреше {#view-change}

Консенсусҡа өлгәшеүҙә уңышһыҙлыҡ осрағында үткәрелә торған процесс. Ғәҙәттә был яңы [Лидер](#leader) һайлауҙы үҙ эсенә ала.

## Донъя дәүләте ҡарашы (WSV) {#world-state-view-wsv}

Хәҙерге блокчейн хәлен иҫтәлектәге һүрәтләү. WSV үҙ эсенә `World`, Ҡатнашылған блоктар, транзакция индекстары, консенсус топологияһы һәм һорауҙар менән ҡулланылған сығарылған индекстар. Ул бары тик commited блоктар аша яңыртыла [Kura](#kura-warehouse). Күрәһегеҙме [Донъяға ҡараш](/ba/blockchain/world.md#world-state-view-wsv).
