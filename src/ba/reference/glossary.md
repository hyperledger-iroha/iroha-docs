## Блокчейн бухгалтерҙары {#blockchain-ledgers}

Блокчейн реестрҙары — финанс яҙмаларын һаҡлау өсөн blockchain технологияһын ҡулланған һанлы иҫәп системалары. Был атама хаҡтарҙы, яңылыҡтарҙы һәм transaction мәғлүмәттәрен теркәгән боронғо иҫәп реестрҙарынан килә.

Урта быуаттарҙа иҫәп реестрҙары йәмәғәт ҡарауы һәм теүәллекте тикшереү өсөн асыҡ булған. Был идея һаҡланған data-ның дөрөҫлөгөн тикшерә алған blockchain системаларында сағылыш таба.

## Пирҙар {#peer}

Iroha-ла пир — ул башҡа Iroha процестары һәм клиент ҡушымталары тоташа алған Iroha процесс экземпляры. Бер машинала бер нисә Iroha пиры эшләргә мөмкин. Пирҙар ресурстары һәм мөмкинлектәре буйынса тиң, әммә мөһим бер айырма бар: Iroha селтәрен башланғыс йөкләү ваҡытында генезис блогын пирҙарҙың береһе генә башҡара.

Башҡа блокчейндар узел йәки валидатор кеүек үк төшөнсәгә һылтана ала.

Бер-береһе менән бер рәттән үҙ хужаһы системаһындағы процестар була ала. Docker контейнер һәм Кубернетес капсулаһы.

## Активтар {#asset}

Блокчейн контексында актив - ул блокчейнда ҡиммәтле объекттың сағылышы.

Дополнительная информация о активах доступна [здесь](/ba/blockchain/assets.md).

### Функциональ активтар {#fungible-assets}

Бындай активтарҙы бер үк типтағы башҡа активтарға алмаштырырға мөмкин, сөнки улар үҙ-ара алмашынырға мөмкин.

Мәҫәлән, бер үк валютаның бөтә берәмектәренең хаҡы тигеҙ һәм уларҙы тауар һатып алыу өсөн ҡулланырға мөмкин. Ғәҙәттә, банкноталар һәм тәңкәләрҙә ҡулланыуҙан тыш, күсемһеҙ милектең тышҡы ҡиәфәте бер үк.

### Ҡатмарлы булмаған активтар {#non-fungible-assets}

Фунгибл булмаған активтар үҙенсәлекле һәм ҡиммәтле, сөнки уларҙың үҙенсәлектәре һәм һирәклеге бар; уларҙы башҡа активтар менән сағыштырырға мөмкин түгел.

- Һындың ҡиммәте рәссамға, уның төшөрөлгән ваҡытына һәм халыҡтың уға ҡыҙыҡһыныуына бәйле була.
- Бер урамдағы ике йорттоң хеҙмәтләндереү кимәле төрлө булырға мөмкин.
- Биҙәүестәр етештереүселәр, ғәҙәттә, төрлө дизайн тәҡдим итә.

### Mintable asset-тар {#mintable-assets}

Бер үк төрҙән өҫтәмә күләм сығарып булһа, asset mintable була.

### Non-mintable asset-тар {#non-mintable-assets}

Asset-тың башланғыс күләме бер тапҡыр билдәләнеп, һуңынан үҙгәрмәһә, ул non-mintable тип иҫәпләнә.

[Башланмыш блогы](/ba/guide/configure/genesis.md) был мәғлүмәтте Iroha конфигурацияһы өсөн ҡуя.

## BFT Византияның хаталарға ҡарата толерантлығы {#byzantine-fault-tolerance-bft}

Яуыз эш итеүселәрҙең билдәле бер процентын үҙ эсенә алған селтәр менән дөрөҫ эшләй алыу үҙенсәлеге. Iroha үҙ селтәрендә зыянлы эшмәкәрҙәрҙең 33% тиклем менән эш итә ала.

## Iroha компоненттары {#iroha-components}

Rust модулдәрендә Iroha функцияһы бар.

### Sumeragi (император) {#sumeragi-emperor}

Iroha модуле - консенсус өсөн яуаплы.

### Torii (ҡапҡа) {#torii-gate}

[ peer](#peer) өсөн килгән һорауҙар менән идара итеү логикаһы булған модуль. Ул килгән инструкцияларҙы һәм HTTP һорауҙарҙы ҡабул итеү, ҡабул итеү һәм маршрутлаштырыу өсөн, шулай уҡ хәрәкәт ваҡыты конфигурацияһы яңыртыуҙары өсөн ҡулланыла .

### Kura (Хәзинә) {#kura-warehouse}

Даими блок һаҡлағысы. Kura ҡултамғалы блоктарҙы, block hash-тарын, height индекстарын, recovery sidecar-ҙарын һәм commit-roster metadata-һын дискта һаҡлай. State snapshot булмаһа йәки урындағы block store-ҙан артта ҡалһа, [Донъя торошон ҡарау](#world-state-view-wsv) Kura блоктарынан яңынан төҙөлә. [Kura һаҡлау](/ba/blockchain/world.md#kura-storage) бүлеген ҡарағыҙ.

### Kagami(Уҡытыусы һәм өлгөһө һәм/йәки көҙгө) {#kagami-teacher-and-exemplar-and-or-looking-glass}

Йыш ҡулланылған мәғлүмәттәр өсөн генератор. Ул криптографик асҡыс парҙарын, генез блоктарын, документацияны һ.б.

### Меркл ағасы (хаш ағасы) {#merkle-tree-hash-tree}

Һәр block height-та торошто раҫлау һәм тикшереү өсөн ҡулланылған мәғлүмәт структураһы. Iroha уны binary tree итеп ғәмәлгә ашыра. Ентеклерәк мәғлүмәт өсөн [Wikipedia](https://en.wikipedia.org/wiki/Merkle_tree)-ны ҡарағыҙ.

### Аҡыллы килешеүҙәр {#smart-contracts}

Аҡыллы килешеүҙәр - блокчейнға нигеҙләнгән программалар, улар билдәле бер шарттарҙы үтәгәндә эшләй. Iroha-ла аҡыллы килешеүҙәрҙе [күҙәк Iroha махсус инструкциялар](#core-iroha-special-instructions) ярҙамында тормошҡа ашыралар.

### Ҡатҡандар {#triggers}

Һәйкәл тибы, ул саҡырыу мөмкинлеге бирә Iroha айырым блок commit, ваҡыт (ҡайһы бер иҫкәртеү менән), һ.б. буйынса махсус инструкция [бында](/ba/blockchain/triggers.md).

### Версиялаштырыу {#versioning}

Һәр үтенесе API версияһы менән билдәләнә. Ул Iroha клиент / пир программаһының төрлө бинар версиялары комбинацияһын үҙ-ара эш итергә мөмкинлек бирә, был иһә Iroha селтәрендә программаларҙы яңыртыу мөмкинлегенә эйә.

### Хижири (тәңреле абруй системаһы) {#hijiri-peer-reputation-system}

Iroha ның абруйлы системаһы. Ул [ peers](#peer) менән аралашыуҙы өҫтөнлөккә һалырға һәм зарарлы [ peers](#peer) арҡаһында килтерелгән зыянды кәметергә мөмкинлек бирә.

## Iroha Модулдар {#iroha-modules}

Өсөнсө яҡтың Iroha киңәйтеүҙәре, был үҙенсәлекле функциялар менән тәьмин итә.

## Iroha Махсус күрһәтмәләр (ISI) {#iroha-special-instructions-isi}

Аҡыллы килешеүҙәр китапханаһы Iroha. Улар транзакциялар йәки теркәлгән ваҡиға тыңлаусылары аша телгә алына ала. ISI [бында](/ba/blockchain/instructions.md).

#### Яҡшылыҡ Iroha Махсус күрһәтмәләр {#utility-iroha-special-instructions}

[isi](#iroha-special-instructions-isi) был йыйылмаһында логик күрһәтмәләр бар, мәҫәлән, `If`, I/O менән бәйле, мәҫәлән `Notify` һәм `Sequence` кеүек композициялар. Улар башлыса [кастом күрһәтмәләре булараҡ ҡулланыла](#custom-iroha-special-instruction).

### Үҙәк Iroha Махсус күрһәтмәләр {#core-iroha-special-instructions}

[Һәр Iroha урынлаштырыуҙа бирелгән махсус инструкциялар](#iroha-special-instructions-isi). Улар араһында ҡайһы бер [ доменға ярашлы](#domain-specific-iroha-special-instructions), шулай уҡ [ файҙаланыу күрһәтмәләре](#utility-iroha-special-instructions).

### Доменға ҡағылышлы Iroha Махсус күрһәтмәләр {#domain-specific-iroha-special-instructions}

Доменға ҡағылышлы эшмәкәрлек буйынса күрһәтмәләр: активтар, иҫәптәр, домендар, пирҙары менән идара итеү). Улар [Донъя торошон ҡарау](#world-state-view-wsv)-ҡа хәүефһеҙ һәм хәүефһеҙ рәүештә үҙгәрештәр яһар өсөн кәрәкле инструменттар бирә.

### Ғәҙәттән тыш Iroha Махсус инструкция {#custom-iroha-special-instruction}

[Iroha модулдәре](#iroha-modules), client-тар йәки third party-лар биргән инструкциялар. Уларҙы тик [Core Instructions](#core-iroha-special-instructions) ҡулланып төҙөргә мөмкин. Iroha source code-ын fork итеп үҙгәртеү тәҡдим ителмәй: Iroha deployment-ындағы [peer](#peer)-ҙар килешмәгән special instruction-дар fault тип һанала, шуға modified instance эшләткән [peer](#peer)-ҙарҙың access-ы revoke ителә.

## Iroha Һорау {#iroha-query}

Был күренеште үҙгәртмәйенсә "Донъя хәле ҡарашы"н уҡырға тәҡдим итеү. Һорауҙар тураһында күберәк бында [](/ba/blockchain/queries.md).

## Күҙәтеү үҙгәреше {#view-change}

Консенсусҡа өлгәшеүҙә уңышһыҙлыҡ осрағында үткәрелә торған процесс. Ғәҙәттә был яңы [Лидер](#leader) һайлауҙы үҙ эсенә ала.

## Донъя торошон ҡарау (WSV) {#world-state-view-wsv}

Хәҙерге блокчейн хәлен иҫтәлектәге һүрәтләү. WSV үҙ эсенә `World`, Ҡатнашылған блок хештары, транзакция индекстары, консенсус топологияһы һәм һорауҙарҙа ҡулланылған сығарылған индекстар. Ул яңыртыла ғына, commit ителгән блоктар аша һәм реконструкциялана ала [Kura](#kura-warehouse). Күрәһегеҙме [Донъяға ҡараш](/ba/blockchain/world.md#world-state-view-wsv).

## Етәксе {#leader}

Iroha селтәрендә бер төйөн осраҡлы рәүештә һайлана һәм киләһе блокты төҙөү өсөн махсус хоҡуҡ ала. [Византия хаталарына тотороҡлолоҡҡа](#byzantine-fault-tolerance-bft) өлгәшкән селтәрҙәрҙә был хоҡуҡты [ҡарашты алмаштырыу](#view-change) аша кире алырға мөмкин.
