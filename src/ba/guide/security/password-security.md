# Парольдәр хәүефһеҙлеге {#password-security}

Паролдәр оператор консольдарын, йәшерен магазиндарҙы, резервтарҙы һәм урындағы файлдарҙы һаҡлай ала. Пароль - бары тик бер контроль. Уны хәүефһеҙ асҡыстар һаҡланыуы, инеү контролдәре һәм күп факторлы аутентификация менән бергә ҡулланығыҙ.

## Үҙенсәлекле парольдар ҡулланығыҙ {#use-unique-generated-passwords}

- Һәр аккаунт һәм мөхит өсөн икенсе пароль булдырыу.
- Оҙон осраҡлы паролдәр булдырыу һәм һаҡлау өсөн пароль менеджерын ҡулланығыҙ.
- Күп һүҙле пароль фразаһын шул уҡ ваҡытта ғына ҡулланығыҙ, әгәр уның һүҙҙәрен ярайһы ҙур исемлектән осраҡлы рәүештә һайлап алһалар.
- Исемдәрҙе, даталарҙы, адрестарҙы, цитаталарҙы, клавиатура өлгөләрен һәм ҡабаттан ҡулланылған фрагменттарҙы паролдәрҙән һаҡлағыҙ.
- Әгәр сервис был ысулды хуплай икән, кеше индергән пароль урынына хеҙмәт тыуҙырған символды йәки криптографик асҡысты ҡулланығыҙ.

Оҙонлоғо һәм көтөлмәгәнлек декоратив алмаштырыуҙарҙан мөһимерәк. Һүҙгә бер символ өҫтәү һөҙөмтәне хәүефһеҙ итмәй.

## Парольдар менән иҫәп яҙмаларын һаҡлағыҙ {#protect-password-based-accounts}

- Фишингҡа ҡаршы күп факторлы аутентификацияны булдырыу, әгәр был мөмкин булһа.
- Күп тапҡыр ҡабатланған аутентификация хаталарына ҡарата ставкалар сикләүҙәрен, ябыу ҡағиҙәләрен һәм иҫкәртеүҙәрҙе ҡулланырға кәрәк.
- Паролдәрҙе аутентификацияланған, шифрланған каналдар аша ғына ебәреү.
- Паролдәрҙе һәм тергеҙеү кодтарын журналдарға, команда юлдарына, сығанаҡ репозиторийҙарына, конфигурация файлдарына, тикеттарға һәм чатҡа индермәгеҙ.
- Сервер яғында пароль тикшереүселәрҙе тоҙло, хәтер ҡаты пароль һешлау функцияһы һәм файҙаланыуға ярашлы параметрҙар менән һаҡларға.

## Һаҡлау, тергеҙеү һәм уны алмаштырыу {#storage-recovery-and-replacement}

- Шифрланған, һыналған резервные копии менән аудит үткән пароль менеджерын ҡулланығыҙ.
- Ҡайтарыу кодтарын улар ҡайтара торған ҡоролманан айырым һаҡлағыҙ. Һаҡланған офлайн ҡағыҙ күсермәһе файҙаланыу материалдары өсөн урынлы була.
- Пароль идарасыһы экспортына һәм резерв медиаһына инеү мөмкинлеген сикләү.
- Паролдең фаш ителеүенә шик тыуғас, рөхсәтһеҙ ҡабат ҡулланылғандан һуң йәки уны алмаштырыуҙы талап иткән сәйәсәт ваҡиғаһынан һуң алмаштырығыҙ.
- Производство башланыр алдынан иҫәп-хисап алыу процедураларын һынап ҡара.

::: warning

Шәхси асҡысты аса торған пароль шул асҡыстың фаш ителгән күсермәһен хәүефһеҙ итә алмай. Шәхси асҡыстың фаш ителеүенә шик тыуһа, урынлаштырыуҙағы асҡысты алмаштырыу йәки кире ҡайтарыу процедураһын үтәгеҙ.

:::
