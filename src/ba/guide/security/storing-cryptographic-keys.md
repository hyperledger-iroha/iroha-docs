### ҡулланыу SSH һәм SSH Агент. {#using-ssh-and-ssh-agent}

Secure Shell Protocol (`SSH`) - виртуаль ҡапҡа булып хеҙмәт иткән криптографик селтәр протоколы, ул SSH клавишалары аҡшылыҡ таныҡлыҡтары ярҙамында алыҫтағы машиналарға хәүефһеҙ инеү мөмкинлеген бирә. `SSH` был контекста ике төп аутентификация механизмын тәҡдим итә: ғәҙәти пароль нигеҙендәге алым һәм хәүефһеҙерәк дәүләт-шәхси асҡыс пар ысулы.

Өҫтәмә мәғлүмәт өсөн `SSH`, ҡарағыҙ [ҡағылышлы SSH Академия темаһы](https://www.ssh.com/academy/ssh).

Уңайлаштырыу өсөн логин процесы һәм ҡабатланғыс инеү кәрәклеген ситтә тотоу өсөн, мөмкин `SSH` асҡыстар менән SSH Агент (`ssh-agent`) ярҙамсы программаһы иҫтә тота һеҙҙең `SSH` Ключтар һәм/йәки пароль ваҡыты өсөн сеанс. Был ҡоролма `SSH` башҡа машиналар менән бәйләнешкә ингән һәр саҡ асҡыстарға еңел генә инеү өсөн ҡапҡа.

Эш ағымы түбәндәгесә: һеҙ үҙегеҙҙең асыҡ асҡысығыҙҙы алыҫ системала һаҡлайһығыҙ һәм шәхси асҡыстарығыҙҙы хәүефһеҙ тотаһығыҙ. `ssh-agent` инеү системаһына асыҡ асҡысыңды тапшырыу өсөн баҫалар. [проблемаһы](https://en.wikipedia.org/wiki/Challenge%E2%80%93response_authentication) тик һеҙҙең шәхси серҙәрегеҙ генә дөрөҫ яуап бирә ала. `ssh-agent` был проблеманы һеҙҙең шәхси асҡысы ҡулланыу менән хәл итә һәм дөрөҫ яуапты кире алыҫ системаһына ебәрә. Әгәр реакция системаһы көткәнсә тап килә, һеҙ инеү хоҡуғы бирелә.

`ssh-agent`тың матурлығы шунда: ул сеанс ваҡытында шәхси асҡысығыҙҙы һаҡлай, шуға күрә йыраҡтан торған системаға тоташҡан һайын паролегеҙҙе йәки шәхси асҡыстың пароль фразаһын индерергә кәрәкмәй.

Өҫтәмә мәғлүмәт алыу өсөн `ssh-agent`, ҡарағыҙ [ҡағылышлы SSH Академия темаһы](https://www.ssh.com/academy/ssh/agent).

::: info Иҫкәрмә

Тулыраҡ күҙәтеү өсөн `SSH` протокол һәм `ssh-agent` инструмент, түбәндәгеләрҙе ҡарағыҙ: [SSH Академия](https://www.ssh.com/academy) темалар:

## Криптографик асҡыстарҙы физик яҡтан һаҡлау {#storing-cryptographic-keys-physically}

### Хардвер асҡысын ҡулланыу {#using-a-hardware-key}

Шулай ҙа, күп брендлы аппарат асҡыстары булғанлыҡтан, уларҙың һәр береһе үҙенсәлекле APIs Һеҙҙең ихтыяждарығыҙға иң яраҡлы асҡысты табыу өсөн баҙарҙа тикшереү мөһим.

Шулай ҙа, күҙ уңында тотоу өсөн бер проблема бар.
