### SSH һәм SSH агентын ҡулланып {#using-ssh-and-ssh-agent}

Secure Shell Protocol (`SSH`) - виртуаль ҡапҡа булып хеҙмәт иткән криптографик селтәр протоколы, ул SSH клавишалары аҡшылыҡ таныҡлыҡтары ярҙамында алыҫтағы машиналарға хәүефһеҙ инеү мөмкинлеген бирә. `SSH` был контекста ике төп аутентификация механизмын тәҡдим итә: ғәҙәти пароль нигеҙендәге алым һәм хәүефһеҙерәк дәүләт-шәхси асҡыс пар ысулы.

Кулланыу процесын яйға һалыу һәм ҡабатланғыс инеү кәрәклеген ситләтеү өсөн `SSH` төймәләрен SSH агенты (`ssh-agent`) сессия дауамында `SSH` төймәләрегеҙҙе һәм/йә паролегеҙҙе хәтерләүсе ярҙамсы программаһы менән парлау мөмкин. Был ҡоролма `SSH` ҡапҡаһына башҡа машиналар менән тоташҡан һайын асҡыстарға еңел генә инеү мөмкинлеген бирә.

Эш ағымы түбәндәгесә: һеҙ асыҡ асҡысығыҙҙы ситтән тотош системала һаҡлайһығыҙ һәм шәхси асҡысығыҙ хәүефһеҙлектә ҡала. Әгәр һеҙ дистанцион системаһына инеү теләһәгеҙ, `ssh-agent` инеү системаһына асыҡ асҡысыңды тапшырыу өсөн баҫалар. [проблемаһы](https://en.wikipedia.org/wiki/Challenge%E2%80%93response_authentication) тик һеҙҙең шәхси серҙәрегеҙ генә дөрөҫ яуап бирә ала. `ssh-agent` был проблеманы һеҙҙең шәхси асҡысығыҙ менән хәл итә һәм дөрөҫ яуапты дистанцион системаға ебәрә. Әгәр реакция системаның көткәненә тап килһә, һеҙгә инеү мөмкинлеге бирелә.

`ssh-agent`тың матурлығы шунда: ул сеанс ваҡытында шәхси асҡысығыҙҙы һаҡлай, шуға күрә йыраҡтан торған системаға тоташҡан һайын паролегеҙҙе йәки шәхси асҡыстың пароль фразаһын индерергә кәрәкмәй.

`ssh-agent` тураһында тулыраҡ мәғлүмәт өсөн ҡарағыҙ: [, SSH Академияһы темаһы](https://www.ssh.com/academy/ssh/agent).

## Криптографик асҡыстарҙы физик яҡтан һаҡлау {#storing-cryptographic-keys-physically}

### Хардвер асҡысын ҡулланыу {#using-a-hardware-key}

Беҙҙең команда аппарат асҡыстарын иң яҡшы хәүефһеҙлек сараларының береһе тип һанай. Шулай ҙа, күп брендлы аппарат асҡыстары булғанлыҡтан, уларҙың һәр береһе үҙенсәлекле APIs Һеҙҙең ихтыяждарығыҙға иң яраҡлы асҡысты табыу өсөн баҙарҙа тикшереү мөһим.

Әлегә беҙҙең команда үҙ аллы тикшереп ҡараны [YubiKey 5С](https://www.yubico.com/il/product/yubikey-5c/) аппарат асҡысы күп ыңғай үҙенсәлектәре, шул иҫәптән күп яҡлы булыуы асыҡланған API функционаллеге.

Шулай ҙа, күҙ уңында тотоу өсөн бер проблема бар. [HMAC һынау-һөжүм менән таныштырыу](https://en.wikipedia.org/wiki/Challenge%E2%80%93response_authentication) һәм был яуап өсөн тейешле шәхси асҡыс һаҡлап ҡалыу хәүефһеҙлек тыуҙыра. Был ҡоролма һөжүм итеүселәргә иҫкәртмәле фараздар яһарға мөмкинлек бирә ала. YubiKey 5С иҫтәлеге, шуның менән дөйөм хәүефһеҙлекте боҙоу.

Идея - YubiKey 5C-ҙы ҡулланыу һәм криптографик һәм `SSH` асҡыстарығыҙҙы һаҡлаған KeePassXC мәғлүмәт базаһына хәүефһеҙ инеү. ### Мнемоник һүҙбәйләнеш ҡулланыу {#using-a-mnemonic-phrase}

Шулай уҡ һеҙ шәхси асҡысты бер нисә һүҙ рәүешендә ятлай алаһығыҙ. Күп кенә аҡса янсыҡтарында ҡулланылған был ысул 25 һүҙҙе иҫтә тотоуҙы талап итә. Күбеһе пароль менеджерҙары, шул иҫәптән элек ҡаралған KeePassXC, mnemonic пароль фразы генерацияһы тәҡдим итә.
