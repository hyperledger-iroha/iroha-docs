# Пирҙар менән идара итеү {#peer-management}

Әгәр ҙә һеҙ телгә ҡағылышлы күрһәтмәләрҙең берәйһенә эйәргән булһағыҙ, хәҙер һеҙҙә яҡшы эшләй торған селтәр бар, һәм кешеләр уға ҡушылырға теләй.

## Дөйөм блокчейн {#public-blockchain}

Асыҡ селтәрҙә, пирҙар ҡабул итеү һаман да сылбыр сәйәсәте ҡарары булып тора. Нод дөрөҫ программаны эшләй ала һәм Torii менән тоташа ала, әммә ул үҙ-ара килешеүгә тик селтәр үҙенең пир шәхесен танығандан һуң ғына ҡатнаша.

## Шәхси блокчейн {#private-blockchain}

Банк мөхитендә, һәр кемдең үҙ теләге менән ҡушылырға рөхсәт итеү хәүефһеҙлек хәүефе булып тора. Iroha Деployments ғәҙәттә peer topology конфигурация һәм генезис урынына асыҡ асыуға таяна.

### Яҡташтарҙы теркәү {#registering-peers}

Сетигә пир өҫтәү өсөн, ул ҡулдан теркәлергә тейеш. Әйҙәгеҙ, был процесты тамамлар өсөн ниндәй аҙымдар яһарға кәрәклеген ҡарап сығайыҡ.

#### 1. Ҡулланыусыға рөхсәт бирегеҙ {#_1-grant-the-user-permissions}

Берҙәмлекте теркәгән иҫәптә тейешле `Permission` булырға тейеш, был `Role` аша йәки туранан-тура рөхсәт биреү рәүешендә бирелә ала.

Ваҡыт уҙыу менән бер иҫәптә пирҙар менән идара итеүгә роль бирегеҙ. Бер тапҡыр теркәлеү өсөн туранан-тура рөхсәт биреү менән файҙаланығыҙ, башҡаса пирҙар менән идара итмәгән иҫәп.

::: info

Профиль буйынса башҡарыусы `CanManagePeers` рөхсәт билдәһен теркәү һәм теркәлмәү өсөн ҡуллана.

:::

[ айырым бүлегендә ](/ba/blockchain/permissions.md) рөхсәт һәм ролдәр тураһында ентеклерәк фекер алышабыҙ.

#### 2. Пирҙы көйләү {#_2-set-up-a-peer}

Яңы пиргә рөхсәт бирелгәндән һуң, уны булдырырға кәрәк.

Node-ты admission-ға алыр алдынан уның ағымдағы peer configuration-ын һорағыҙ. Torii бының өсөн node parameter һәм capability endpoints тәҡдим итә. Peer bootstrap был values-ты автоматик рәүештә килешмәй: operators timeouts, batch sizes һәм башҡа consensus-relevant settings network менән тап килеүен тикшерергә тейеш.

Процессты ябайлаштырыу өсөн, һеҙ селтәр администраторынан `config.toml`ның үҙгәртелгән версияһын һорай алаһығыҙ, был мәғлүмәт өҫтөнлөклө мәғлүмәттәрҙе, мәҫәлән, шәхси асҡыстарҙы индермәй.

#### 3. Инструкцияны тапшырығыҙ {#_3-submit-the-instruction}

Пирығыҙ эшләгәндән һуң, _register peer_ инструкцияһын тапшырығыҙ. Пир ҡул ҡыҫыу процесын үтә һәм селтәр менән аралаша башлай.

::: tip

Пирҙар менән теркәлеү тураһында инструкция тапшырыу яңы пирҙар процесын яйға һала алмай (һәм ул мөмкин түгел).

:::

### Теркәлмәгән йәштәштәре {#unregistering-peers}

Һаҡлыҡ сәбәптәре менән был процесс бер яҡлы. селтәр үҙ-ара килешеү төҙөй: ул үҙ-үҙенә пир алып ташларға теләй, әммә кем дә булһа уның менән ни өсөн һөйләшмәй икәнлеге тураһында үҙе күп нәмә белмәй.

Күпселек осраҡта, әгәр һеҙ бер яҡташығыҙҙы теркәүҙән баш тартырға теләһәгеҙ, был византия хатаһы булғанға күрә эшләргә кәрәк. Был пирығыҙҙы "ҡонһондороу" ғына телевидениелағы яуыз актёрҙың тормошон ҡыйынлаштыра.
