# Йәмәғәт һәм шәхси блокчейндар {#public-and-private-blockchains}

Iroha төрлө конфигурацияларҙа эшләй ала. үҙ селтәренең администраторы булараҡ, һеҙ ниндәй башҡарыусы һәм рөхсәт сәйәсәте транзакция ҡабул ителәме икәнен билдәләргә ҡарар итәһегеҙ.

Дөйөм профилдәр - шәхси рөхсәт ителгән селтәрҙәр һәм асыҡ йәмәғәт селтәрҙәре. Икеһе лә айырым узел бинарҙары аша түгел, ә генезис дәүләте һәм башҡарыусы сәйәсәте аша конфигурациялана.

Артабан беҙ был ике ҡулланыу осрағында төп айырмалыҡтарҙы һүрәтләйбеҙ.

## Разрешениелар {#permissions}

Йәмәғәт блокчейнда күпселек аккаунттар бер үк рөхсәт йыйылмаһына эйә. Шәхси блокчейнҙа, әгәр уларға тейешле рөхсәт бирелмәһә, иҫәптәрҙең күбеһе уларға бирелгән властан тыш бер нәмә лә эшләй алмай тип фараз ителә.

::: мәғлүмәт

Тулыраҡ мәғлүмәт өсөн [ махсус бүлеген ҡарағыҙ рөхсәттәре тураһында](/ba/blockchain/permissions.md).

:::

## Дуҫтар {#peers}

Йәмәғәт блокчейн-ында тиңдәш ҡабул итеү селтәр сәйәсәтенең бер өлөшө булып тора. Шәхси блокчейн өсөн, урынлаштырыуҙар ғәҙәттә конфигурацияла һәм генезиста ышаныслы тиңдәш йыйылмаһын билдәләйҙәр.

::: мәғлүмәт

Тулыраҡ мәғлүмәт өсөн [ peer management](peer-management.md) тигәнде ҡарағыҙ.

## Иҫәптәрҙе теркәү {#registering-accounts}

Нисек ҡарар итеүегеҙгә ҡарап [генезис блогы (`genesis.json`)](genesis.md), иҫәп яҙҙырыу процесы ике ысулдың береһе менән бара ала. Ни өсөн быны аңлау өсөн, әйҙәгеҙ, тәүҙә рөхсәт тураһында һөйләшәйек.

Һайланған башҡарыусы ниндәй рөхсәт тикшереүҙәре ҡулланыла икәнен билдәләй. Әҙиптәге [ рөхсәт билдәләрен](/ba/blockchain/permissions.md) шәхси, администратор менән идара ителгән селтәрҙе йәки асыҡраҡ селтәрҙе формалаштырыу өсөн бирә алаһығыҙ. Был рөхсәттәр әүҙем булғандан һуң иҫәп яҙмаларын теркәү процесы икенсе төрлө.

Иҫәптәрҙе теркәүҙә дәүләт һәм шәхси блокчейн түбәндәге айырмаларға эйә:

- Йәмәғәт блокчейн, һәр кем иҫәбенә теркәлергә тейеш[^1]. Шулай итеп, теоретик яҡтан, бөтә кәрәкле клиент, ярҙамлы алгоритм өсөн шәхси асҡыс сығарыу ысулы һәм рөхсәт сәйәсәте теркәү ҡабул итеүсе.

- Шәхси блокчейнда иҫәп яҙмаһы булдырыу өсөн теләһә ниндәй процесс үтәлергә мөмкин: теркәлеү инструкцияһын конкрет иҫәб аша тапшырырға кәрәк, йәки башҡа мәғлүмәттәрҙе һораған аҡыллы килешеү менән. Бәлки, шәхси блокчейнда яңы иҫәптәрҙе теркәү тик билдәле даталарҙа ғына мөмкин буласаҡ, йәки был сикләнмәгән (оҙаҡлы) токен менән генә мөмкин.

- Типик шәхси блокчейнда, йәғни иҫәп яҙҙырыу өсөн бер ниндәй ҙә уникаль процестар булмаған блокчейнҙа, икенсе иҫәбте теркәү өсөн иҫәпкә кәрәк.

Үҙенсәлекле рөхсәт раҫлаусылары типик шәхси блокчейн ҡулланыу осрағын ҡаплай.

::: мәғлүмәт

Йәмәғәт һәм шәхси режимдар айырым узел бинарҙары түгел, ә сәйәсәт профилдәр. Асыҡ селтәрҙе эшләтер алдынан ебәрелгән башҡармасы һәм генез рөхсәттәре тикшерегеҙ.

:::

[ күрһәтмәләре](/ba/blockchain/instructions.md#un-register) бүлегенән `Register<Account>` күрһәтмәләре тураһында тулыраҡ мәғлүмәт алырға була.

[^1]: `Register<Account>` каноник, доменһыҙ `AccountId` өсөн иҫәп яҙмаһы торошон булдыра; домен маршрутизацияһы һәм ҡушаматтар айырым идара ителә.
