# SDK Дәреслектәре {#sdk-tutorials}

Был биттәрҙә төп эш урынынан ебәрелгән Iroha 3 клиентҡа инеү нөктәләре, шул иҫәптән каноник пакеттар исемдәре, ҡуйыу юлдары һәм минималь башланғыс нөктәләр килтерелгән.

## Тәҡдим ителгән тәртип {#recommended-order}

1. [Iroha 3](/ba/get-started/install-iroha.md) ҡуйыу
2. [Пуск Iroha 3](/ba/get-started/launch-iroha.md)
3. SDK билдәһен һайлағыҙ:
   - [Rust](/ba/guide/tutorials/rust.md)
   - [Python](/ba/guide/tutorials/python.md)
   - [JavaScript / TypeScript](/ba/guide/tutorials/javascript.md)
   - [Kotlin, Android, һәм Java](/ba/guide/tutorials/kotlin-java.md)
   - [Swift һәм iOS](/ba/guide/tutorials/swift.md)
4. [ өлгөләге ҡушымталарҙы](/ba/guide/tutorials/sample-apps.md) тикшереп ҡарағыҙ, әгәр тулы клиент ҡушымтаһы шиғырын теләйһегеҙ икән.
5. [Embed Kaigi](/ba/guide/tutorials/kaigi.md) ҡуллан, әгәр һеҙ үҙ ҡушымтаһына аҡса янсығы менән тәьмин ителгән аудио / видео осрашыуҙар өҫтәргә теләйһегеҙ.
6. Ҡулланығыҙ [Musubi пакеттары](/ba/guide/tutorials/musubi.md), әгәр һеҙ кәрәк ҡабаттан ҡулланыла торған Kotodama сығанаҡ китапханалары менән бәйләнгән сылбырлы реестр бәйлелектәре.

## Үлсәүҙәр {#samples}

Өҫкө ағымындағы эш майҙанында JavaScript рецепттар һәм Swift/iOS проект өлгөһө. Android, менән башларға Kotlin SDK модулдәр һәм уларҙың һынауҙары.

- [Үрнәк ҡушымталар күҙәтеүе](/ba/guide/tutorials/sample-apps.md)
- [Ҡатнашылған Kaigi а JavaScript ҡушымта](/ba/guide/tutorials/kaigi.md)

## Хәҡиҡәттең сығанағы {#source-of-truth}

SDK биттәренең барыһы ла хәҙерге өҫкө йүнәлештәге эш урынынан алынған:

- `crates/iroha`
- `python/iroha_python`
- `javascript/iroha_js`
- `kotlin`
- `java/iroha_android` (Java оинаһы Kotlin- тәүҙә Android өҫкө йөҙ)
- `IrohaSwift`
- `crates/musubi`

Шик булғанда, был каталогтарҙа README һәм пакет метамәғлүмәтенә өҫтөнлөк бирегеҙ; улар һеҙ төҙөгән сығанаҡ ревизияһын һүрәтләй.
