# Үлсәүҙәр һәм рецепттар {#samples-and-recipes}

Iroha сығанаҡ репозиторияһы SDK рецепттары һәм тест-суиттарҙы үҙ эсенә ала, улар узел менән бер үк ревизияны күҙәтә.

## JavaScript Рецепттар {#javascript-recipes}

[`javascript/iroha_js/recipes`](https://github.com/hyperledger-iroha/iroha/tree/0010c5a70039eac101a4846499ba9ceaf43eb65c/javascript/iroha_js/recipes) Детерминистик транзакцияларҙы партиялаштырыу буйынса маҡсатлы миҫалдар бар, Nexus ҡушымталар күсереүҙәре, NFT һәм хисап иҫәбен ҡабатлау, ISO күпер ағымы, һәм Torii Һәр рецепт документтар, ул офлайн эшләйме йәки тере кәрәкме Torii һуңғы нөктә.

## Swift һәм iOS {#swift-and-ios}

Ҡулланыу `IrohaSwift/Tests/IrohaSwiftTests` Хәҙерге ваҡытта раҫланған миҫалдар өсөн Swift SDK. Күрәһегеҙме [Swift һәм iOS](/ba/guide/tutorials/swift.md) пакет һәм күпер ҡуйыу өсөн.

## Android {#android}

Яңы Android эштәр өсөн Kotlin-иң беренсе `core-jvm`, `client-android` һәм `offline-wallet-android` модулдәрен ҡулланығыҙ, улар [Kotlin, Android һәм Java](/ba/guide/tutorials/kotlin-java.md). Kotlin SDK - Android ҡулланыусылар өсөн каноник башланғыс.
