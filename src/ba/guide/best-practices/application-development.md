# Ҡулланыусыларҙы үҫтереү {#application-development}

Iroha ҡушымталары транзакция тәртибен асыҡландырырға, ҡултамға торошон һаҡларға һәм һорауҙарҙы һәм ваҡиғаларҙы етештереүҙә күҙәтеүе еңел булғанса ҡулланырға тейеш.

## Клиентты булдырыу {#client-setup}

- Ҡушымтаның сығанаҡ кодынан тыш клиент конфигурацияһын һаҡлағыҙ. ID, Torii URL сылбырҙарын, ҡул ҡуйыу аккаунтын һәм транзакциялар көйләүҙе тирә-яҡ мөхиткә ҡағылышлы конфигурацияһынан йөкләгеҙ.
- Һаҡлағыҙ `client.toml` localnet өсөн айырым файлдар, Taira, Minamoto, һәм шәхси селтәрҙәр. Копияланған тест селтәре имзалаусыһы бер ҡасан да төп селтәр имзалаусының береһе булырға тейеш түгел.
- Транзакция ваҡытын һәм статус ваҡытын аңлы рәүештә билдәләгеҙ. Бик ҡыҫҡа ваҡыт нормаль селтәр хәрәкәттәре ваҡытында тамамлана ала, ә бик оҙон ваҡыт ҡабатланма тапшырыуҙарҙы фекер йөрөтөүҙе ҡатмарлаштыра ала.
- Ҡабатланған транзакцияларҙың hash-тары айырым булырға тейеш булғанда ғына `nonce = true` ҡулланығыҙ. Idempotent business operation өсөн application request ID-ны һаҡлағыҙ һәм ҡабат ҡулланығыҙ, шулай retry-ҙарҙы күҙәтеп була.

[Клиент конфигурацияһы](/ba/guide/configure/client-configuration.md) хәҙерге TOML майҙансыҡтары өсөн ҡарағыҙ.

## Транзакциялар {#transactions}

- Мөмкин булғанда, операцияларҙы SDK типтағы инструкциянан сыман JSON йәки сылбырҙар менән йыйылған файҙалы йөкләмәләр урынына төҙөргә.
- Preflight мөһим уҡырға ғына һорауҙар менән яҙа: иҫәбенең булыуы, активтар балансы, рөхсәт дәүләте, түләүҙәрҙең активы булыу мөмкинлеге һәм маҡсатлы объект дәүләте.
- Транзакция хешын, хакимиәт иҫәбен, инструкциялар йомғаҡлауын һәм көтөлгән дәүләт үҙгәрештәрен тапшырыуҙан алда яҙығыҙ.
- `Rejected`, `Expired` менән мөғәмәлә итегеҙ, һәм ваҡытлы үтеү һөҙөмтәләре төрлөсә. ваҡытлы үтүш клиенттың һуңғы торошон күҙәтмәүен аңлата; ул селтәрҙең транзакцияны һанға һуҡмағанлығын иҫбат итмәй.
- Уңышлы яҙыуҙан һуң, килеп сыҡҡан хәлде бизнес-операцияға тап килгән һорау йәки ваҡиға контроле пункты менән тикшерегеҙ.

Транзакция механикаһы өсөн [Транзакциялар](/ba/blockchain/transactions.md) ҡарағыҙ.

## Һорауҙар һәм ваҡиғалар {#queries-and-events}

- Үҙгәреш белдереүҙәр өсөн ағымдағы дәүләт һәм ваҡиға ағымдары буйынса һорауҙарҙы ҡулланығыҙ. Ваҡиғалар менән идара итеүҙе ҡабатланған киң һорауҙар менән алмаштырмағыҙ.
- Яҡшы ҡабатлана торған һорауҙарҙы, мәҫәлән, иҫәп яҙмаһын, активты һәм блок исемлеген биттәренә яҙыу.
- Подпискалар һәм триггерҙар өсөн тар фильтрҙар өҫтөнлөк итә. Киң фильтрҙар диагностика өсөн файҙалы, әммә кәрәкһеҙ башҡарыу һәм клиент яғында эшкәртеү өҫтәй ала.
- Уҡыу өсөн генә тәғәйенләнгән тәмәке тикшереүҙәрен ҡул ҡуйылған транзакция һынауҙарынан айырып ҡалдырығыҙ, һөҙөмтәлә һуңғы пункттың булыуы диагностикалау еңелерәк буласаҡ.

Ҡарағыҙ [ Һорауҙар](/ba/blockchain/queries.md), [Үҙгәрештәр](/ba/blockchain/events.md) һәм [Фильтрҙар](/ba/blockchain/filters.md).

## Агент ярҙамында үҫеш {#agent-assisted-development}

- Агенттарға транзакция кодын яҙыуҙы һорар алдынан документтарҙы, SDK кодын һәм уҡырға ғына мөмкин булған селтәрҙе тикшерергә рөхсәт итегеҙ.
- `TAIRA_LIVE=1` кеүек тирә-яҡ мөхит флагы артында тере селтәрҙәге һынауҙар үткәреүҙе һайлап алыу.
- Шәхси асҡыстарҙы, иҫәпте тергеҙеү материалын, API токендәрҙе йәки авторҙың башлыҡтарын саҡырыуҙарға алмаштырмағыҙ.
- Берәй агент тере testnet транзакцияһын ебәрер алдынан транзакция планы талап итегеҙ. Планда селтәр, authority, күрһәтмәләр, комиссия активы, алдан тикшереү уҡыуҙары, көтөлгән һөҙөмтә һәм ҡабаттан һынау тәртибе күрһәтелергә тейеш.

Taira MCP эш ағымы өсөн ҡарағыҙ [Үҙгәртергә SORA 3: Taira һәм Minamoto](/ba/get-started/sora-nexus-dataspaces.md#taira-mcp-for-agents).

## SDK Гигиена {#sdk-hygiene}

- Пин SDK һәм бинар версиялар бергәләп [Контактлылыҡ матрицаһы](/ba/reference/compatibility-matrix.md) ҡулланып.

- Транзакция төҙөү өсөн берәмек һынауҙары һәм иң бәләкәй уҡыу-яҙау юлдары өсөн интеграция һынауҙары ҡушымта бәйле.
