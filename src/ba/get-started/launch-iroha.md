# Башлау Iroha 3 {#launch-iroha-3}

Ябыҡ мөхиттә интеграцияны һынау өсөн бер Linux виртуаль машинаһында (VM) дүрт Iroha 3 валидаторын эшләтеп ебәрегеҙ. Ҡултамға ҡуйылған транзакцияны ебәрегеҙ, бер валидаторҙы туҡтатығыҙ һәм ҡалған өсәүһенең киләһе транзакцияны раҫлай алғанын тикшерегеҙ. Шулай итеп ҡатнашыу өсөн рөхсәт талап иткән айырым реестр төҙөлә. Уны идара ителгән мәғлүмәт киңлеге итеп SORA Nexus селтәренә тоташтырыу өсөн айырым көйләү кәрәк.

## VM әҙерлә {#prepare-the-vm}

Linux x86_64 системаһында Docker Engine, Buildx, Compose v2, Python 3.8 йәки яңыраҡ версия һәм `unzip` программаһын ҡулланығыҙ. Һеҙҙең иҫәп яҙмаһына Docker менән эшләү рөхсәте кәрәк. Тәүге йыйыу өсөн GitHub, Docker Hub, Debian пакеттарының көҙгө серверҙарына һәм crates.io сайтына HTTPS аша сығыу мөмкинлеге талап ителә.

Беҙ ҡорамалдар комплектын VM өҫтөндә алты vCPU һәм 32 GiB RAM менән төҙөнөбөҙ һәм тест үткәрҙебеҙ, бер нисә синтетик транзакциялар ҡулланылды. Үҙ эш ауырлығығыҙға һәм һаҡлау осорона яраҡлы һаҡлау күләмен билдәләгеҙ. Һәр Docker двигателе өсөн комплекттың бер нөсхәһен файҙаланығыҙ һәм 18080–18083 циклды порттарҙы буш тотоғоҙ.

[Дүрт-валидация комплектын йөкләгеҙ](/downloads/iroha-trade-poc.zip). Унда лаунчер, блокланған бәйлелектәр исемлеге һәм шул уҡ билдәле Iroha версияһынан валидатор һәм клиент төҙөү өсөн ҡулланылған patch-тар инә. Йөкләп алынған директориянан уны тикшерегеҙ һәм пакеты асылығыҙ.

```sh
echo 'b12d450f9f15c0126dfe5eca83cdfad8bc420c779a78f916d374f433a2b3da0e  iroha-trade-poc.zip' | sha256sum --check
unzip iroha-trade-poc.zip
cd iroha-trade-poc
```

## Барлыҡ дүрт валидацияны башлағыҙ һәм тикшерегеҙ {#start-and-verify-all-four-validators}

```sh
python3 poc.py up
python3 poc.py verify
```

Тәүге эшләтеп ебәреүҙә контейнер образы йыйыла, виртуаль машинала (VM) сылбыр идентификаторы, асҡыстар һәм ҡултамғалы башланғыс блок булдырыла. Һәр валидаторҙың үҙенең даими һаҡлау томы бар. Тикшереү программаһы һынау транзакцияһына ҡул ҡуя һәм дүрт валидаторҙың һәр береһе өс күрше төйөн менән тоташыуын һәм яңы блоктың бер үк хешын хәбәр иткәнен көтә. Башланғыс блокка өлгө иҫәп яҙмалары инә. Яһалма мәғлүмәт ҡулланығыҙ һәм APIs интерфейстарын тик локаль loopback адресында ғына асығыҙ.

VM адресынан тәүге валидаторҙың статусы менән танышыу өсөн JSON һорауын асыҡ күрһәтеп ебәрегеҙ.

```sh
curl -fsS -H 'Accept: application/json' http://127.0.0.1:18080/status
```

## Валидатор хатаһын тикшерегеҙ {#test-a-validator-failure}

```sh
python3 poc.py failover
```

Һынау бер валидаторҙы туҡтата, яңы транзакция ебәрә һәм ҡалған өс валидаторҙа раҫланған блоктың хешын тикшерә. Артабан ул дүртенсе валидаторҙы яңынан эшләтеп ебәрә һәм уның шул уҡ блокҡа еткәнен көтә. Виртуаль машина (VM) сафтан сыҡһа, дүрт валидатор ҙа туҡтай. Бер физик хосттың сафтан сығыуын һынау өсөн дүрт бойондороҡһоҙ хосттың һәр береһенә бер валидатор урынлаштырығыҙ.

## Туҡтат һәм ҡабат башла {#stop-and-resume}

```sh
python3 poc.py down
python3 poc.py up
```

Ике команданы ла бер үк сығарылған директориянан эшләтеп ебәрегеҙ. Уның `state/` директорияһын һәм дүрт Docker томон бергә һаҡлағыҙ, шулай итеп яңынан эшләүсе валидаторҙар шул уҡ блокчейн журналын асып буласаҡ. Әгәр старт туҡтап ҡала икән, `python3 poc.py logs` шул урынға эшләтеп ебәрегеҙ.

## Дөйөм API өс сисеменә тотонап ҡарағыҙ {#try-the-public-endpoint}

Ҡушымта реестр өсөн айырым виртуаль машина (VM) эшләтеп ебәрмәйенсә Taira селтәрендәге SORA Nexus универсаль мәғлүмәт киңлеген уҡый ала. `curl` һәм `jq` булған эш станцияһынан һынау селтәренә мәғлүмәт уҡыу өсөн түбәндәге һорауҙы ебәрегеҙ.

```sh
curl -fsS -H 'Accept: application/json' https://taira.sora.org/status \
  | jq '{peers, blocks, txs_approved, queue_size}'
```

Яуап эҙләгән төйөнөң тоташтырылған селтәр күршеләре, тамамланған блоктар, раҫланған операциялар һәм ҡатмарлы операциялар тураһында хәбәр итә. Йәшереп ебәреүҙе планлаштырыу өсөн [Тармаҡ таратыу](/ba/guide/best-practices/network-deployment.md)-гә ҡарағыҙ.
