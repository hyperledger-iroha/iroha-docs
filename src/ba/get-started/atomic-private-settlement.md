## Протоколдың йәшергәндәре {#what-the-protocol-hides}

## Ҡулланыуға ҡуйылған талаптар {#deployment-requirements}

3. һәр мәғлүмәт киңлегендә идара итеүгә буйһонған йәшерен иҫәпләшеү пулы һәм башланғыс тамыр

Аудитор шулай уҡ валидатор менән файҙалана ала, әммә улар айырым консенсус, аудитор ҡултамғаһы һәм аудитор шифрлау асҡыстарын ҡулланырға тейеш. Регулятив һаҡланыу осоро өсөн сығарылған шифрлама асҡыстарҙы һаҡлап ҡалырға йәки уларҙы сығарыр алдынан контроль һәм тест капсулаһын ҡабаттан тултырырға тейеш.

Манифесттың `authority_context_height` бейеклегендә һәр валидатор консенсус торошонан һыҙат/мәғлүмәт киңлегенең теүәл тәртипле исемлеген һәм һыҙаттың әүҙем инкарнацияһын таба, табылған бейеклектең тап килеүен талап итә һәм дүрт BLS асҡысын, шулай уҡ уларға эйә булыу иҫбаттарын тикшерә. Йөкләү, Prepare һәм һуңғы квитанцияны ҡабул итеү бер үк тарихи вәкәләтте ҡуллана.

## Ярҙәмсе мәғлүмәттәрҙе һаҡлауҙы көйләү {#configure-sidecar-custody}

## Тейешләү эш ағымдары {#settlement-workflow}

Клиент локаль рәүештә иҫбатлауҙар һәм шифрланған капсулалар төҙөй. Йәшерен шаһиттар native аҡса янсығында йәки native эшселә һаҡланырға тейеш; уларҙы заявка журналдарына, Python объекттарына, HTTP ғаризаларына йәки оҙайлы координация яҙмаларына сериялаштырмағыҙ.

Капсуланың һәм һәр аудитор өсөн DEK төргәгенең аутентификацияланған мәғлүмәтенә торошҡа бәйләнгән аныҡ комитет дайджесты һәм `authority_context_height`, шулай уҡ селтәр, маршрут һәм инкарнация, тупланма, операция өлөшө, сәйәсәт, асҡыс эпохаһы һәм асыҡ тексҡа йөкләмә инә. Төрөлгән асҡысты башҡа исемлеккә йәки тарихи вәкәләт контексына күсереп булмай.

Һәр каноник этап өсөн координатор был эҙмә-эҙлеклелекте үтәй:

1. Ваҡытлы шифрланған материалды дүрт раҫлаусыға ла йөкмәгеҙ һәм 3-тән 4-кә тулы һанлы документ алыу.
2. Хакимиәттәге аудиторға уның капсулаһын йыйып алырға, уны шифрландырырға, асыҡ бәйләнештәрҙе ҡабаттан иҫәпкә алырға, урындағы сәйәсәт буйынса эш итергә һәм рөхсәт бирергә ҡуш.
3. Дүрт раҫлаусының тауыш биреүҙәрен әҙерләгеҙ. Һәр раҫлаусы үҙ аллы тауыш биреү алдынан дельтаны тикшерә һәм уны даими рәүештә баҫып ала. Һәр этаплы респондентҡа 3-тән 4-кә әҙерлек сертификаты тапшырығыҙ.
4. Һәр этап әҙерлек сертификатына эйә булғандан һуң, үҙгәрешһеҙ тулы әҙерлек барьерын төҙөгөҙ. Каноник 4-тән 3 Commit сертификаттарын һорағыҙ һәм даими һаҡлағыҙ. Координатор яңынан эшләтеп ебәрелһә, ҡатнашыусы төйөндәрҙән уларҙа урындағы тотороҡло һаҡланған Prepare һәм Commit сертификаттарын һорағыҙ. Шул уҡ кворумға тиң каноник сертификатты һайлағыҙ һәм дауам итер алдынан уны яңынан таратығыҙ; сертификатты аутентификация үтмәгән урындағы кэштан бер ҡасан да тергеҙмәгеҙ.
5. Manifest sponsor теүәл бер global carrier transaction-ға ҡул ҡуйып, уны ебәрергә тейеш. Carrier transaction эсендә бер `FinalizeAtomicPrivateSettlementV1` instruction-ы һәм теүәл тулы certified bundle була. Coordinator һәм WSV preflight тулы encapsulated finalization instruction-ын, шул иҫәптән registered-instruction framing-ты, үлсәй. Torii һәм core one-shot carrier transaction-transaction binding sponsor ҡул ҡуйған теүәл canonical transaction-ға — authority, metadata, fee intent һәм signature менән бергә — `max_carrier_bytes` сикләүен ҡуллана. Torii carrier transaction-ды authority context-ынан алда, expiry-ға тиклем finality-ға өлгөрә алған һуңғы ingress height-та йәки унан һуң, йә governed expiry span-дан тыш булһа кире ҡаға.
6. Глобаль тамамланғанға тиклем йәмәғәт бандл статусын һәм ҡабул итеүен һорағыҙ. Был үҙгәрешһеҙ глобаль терминал рекордын яраштырғанға тиклем урындағы ярҙәмсе яҙманы ваҡытлыса хәл итегеҙ.

Rust клиенты был ағымды, шул иҫәптән `certify_and_upload_private_settlement_legs_v1`, `prepare_private_settlement_bundle_v1`, `commit_private_settlement_bundle_v1` һәм `submit_private_settlement_bundle_v1` ысулдары ярҙамында асыҡлай. Яңынан эшләтеп ебәреүгә хәүефһеҙ координация `recover_or_prepare_private_settlement_bundle_v1` һәм `recover_or_commit_private_settlement_bundle_v1` ҡуллана. Комитетҡа һәм аудиторға саҡырыуҙар өсөн асыҡтан-асыҡ роль таныҡлыҡтары талап ителә; улар ябай иҫәп яҙҙырыуына ҡул ҡуйған кешене ҡабаттан файҙаланмай.

## Аудиторҙар сәйәсәтен хәүефһеҙ көйләү {#rotate-an-auditor-policy-safely}

Хосусилыҡ менән идара итеүгә рөхсәт ителгән `RotatePrivateSettlementPoolPolicyV1` инструкцияһын ҡулланығыҙ. Ул ғәмәлдәге идара итеүҙең теүәл дигестын атамаларға, бер үк маршрутты, тупланманы һәм активтарҙы бәйләү йөкләмәһен һаҡларға, идара итеүҙе яңыртыуҙы бер тапҡыр арттырырға, яңы төп эпоханы һәм сәйәсәт / идара итеүҙең төрлө дигестәрен ҡулланырға тейеш, һәм әйләнеште үҙ эсенә алған блокта әүҙемләштерә. Баҡса сиге, тамырҙар, юҡҡа сығарыусылар, сығанаҡтар, ҡабаттан уйнау йыйылмалары һәм тамамланған квитанциялар һаҡлана.

Пулдың асыҡ проекцияһы алмаштырылған сәйәсәт ревизияларының тулы сығыш тарихын һаҡлай. Шуға күрә ротацияға тиклем финаллаштырылған квитанция яңынан эшләткәндән һуң да ғәмәлдә ҡала, ә тап шул квитанцияны ҡабат башҡарыу идемпотент булып ҡала. Был тарих тамамланмаған эшкә рөхсәт бирмәй: активлаштырыу сиген үткән иҫке сәйәсәт тупланмаһы глобаль торош үҙгәргәнгә тиклем кире ҡағыла. Һаҡланған капсулаларҙы асыу өсөн кәрәкле бөтә иҫке шифр асыу асҡыстарын һаҡлағыҙ, йәки уларҙы юҡ итер алдынан идара итеү раҫлаған һәм һыналған капсулаларҙы яңынан төрөүҙе тамамлағыҙ.

Энтропиялы сей loopback яҙмаһы һәм төрөлгән сикләнгән сығанаҡ архивы — ҙурлыҡ ҡағиҙәһенән асыҡтан-асыҡ иҫкәрмәләр; улар өсөн пакет бәйләнеше төрө, һәр пакет оҙонлоғо, сикләнгән сығанаҡ идентификаторҙары һәм даими формалы юл оҙонлоҡтары сағыштырыла. Һәр Torii һорауы/яуабы, асыҡ/сикләнгән P2P пакеты, блок, һорау, ваҡиға, журнал һәм телеметрия трафигы һаны ла тап килергә тейеш.
