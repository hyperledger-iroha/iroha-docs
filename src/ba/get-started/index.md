# Iroha 3 {#iroha-3}

Iroha 3 беренсе тапҡыр сығарылған Hyperledger Iroha Платформа. Ул үҙ-хост селтәрҙәрен һәм күп-мәғлүмәттәр киңлеген тәьмин итә. SORA Nexus ҡулланыу моделе бер детерминистик код базаһынан.

Юғары кимәлдә Iroha 3 берләштерә:

- детерминистик башҡарыу һәм һаҡлау
- Iroha Виртуаль машина (IVM) портатив аҡыллы килешеүҙәр өсөн
- Norito каноник сериализация форматында
- Torii клиенттар, операторҙар һәм ҡушымталар өсөн APIs
- Sumeragi мотлаҡ мәғлүмәттәр һәм ышаныслы тапшырыуҙар менән килешеү
- айырым бәйләнгән, кеше уҡый торған ҡушаматтар менән доменһыҙ канон иҫәбтәре
