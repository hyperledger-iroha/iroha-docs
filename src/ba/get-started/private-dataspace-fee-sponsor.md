# Шәхси мәғлүмәт киңлеге өсөн комиссияларҙы бағыусы аша түләү {#sponsor-fees-for-a-private-data-space}

SORA Nexus комиссия бағыусылығы программаһы шәхси мәғлүмәт киңлегенә йүнәлтелгән талаптарға ярашлы транзакцияларҙың глобаль башҡарыу комиссияларын түләй ала. Ҡулланыусы барыбер тулы транзакцияға ҡул ҡуя. Уның типлаштырылған `FeePaymentIntent` ҡиммәте теүәл бағыусы программаһын һәм үҙгәрешһеҙ ревизияһын, кәрәк булғанда газ сиген һәм иң ҙур түләүҙәрҙе һайлай.

Мәғлүмәт киңлеге каталогындағы яҙма үҙаллы ҡул ҡуйылған тамыр булдырмай. Үҙаллы мәғлүмәт киңлеге тамырының үҙ раҫланған комиссия валютаһы һәм сәйәсәте бар; асыҡ бағыусы һаҡлағыстары уның шәхси тамыр комиссияларына вәкәләт бирә алмай. Бағыусылыҡты проектлар алдынан башҡарыу тамырын билдәләгеҙ.

## 1. Раҫланған комиссия сәйәсәтен билдәләү {#_1-establish-the-committed-fee-policy}

Ҡул ҡуйылған genesis `RootFeePolicy`-ны үҙ эсенә алған бер `root_fees_v1` махсус параметрын билдәләй. Ул комиссия валютаһын, комиссия ҡабул итеүсеһен, бағыусының һаҡлау иҫәбен, талаптар өсөн ташламаларҙы һәм ставкаларҙы бәйләй. Һәр ғәҙәти блок һәм хаҡ тәҡдиме үҙе өсөн алынған раҫланған сәйәсәтте ҡуллана. Рөхсәт ителгән сәйәсәт яңыртыуҙары киләһе блоктан ғәмәлгә инә.

Глобаль башҡарыуҙа натив комиссия селтәр өсөн ҡултамға менән билдәләнгән теүәл XOR валютаһын яндыра. Был валютаны бағыусы программаһының һаҡлағысы бирә. Төйөн көйләүҙәре һәм транзакция метамәғлүмәттәре түләүсене һайламай һәм бағыусылыҡты әүҙемләштермәй.

Селтәрҙең каноник валюта һәм иҫәп идентификаторҙарын ҡулланығыҙ. Псевдонимды асыҡлау раҫланған валюта, һаҡлау йәки комиссия ҡабул итеүсе идентификаторҙарын башҡа яҡҡа йүнәлтмәҫкә тейеш.

## 2. Бағыусы программаһын булдырыу һәм аҡсаландырыу {#_2-create-and-fund-a-sponsor-program}

Программа идентификаторы `<canonical-sponsor-account>/<program-name>` формаһында була. Уны ағымдағы SDK һәм мәғлүмәт моделе тәҡдим иткән типлаштырылған инструкциялар аша булдырығыҙ:

| Инструкция | Маҡсат |
| --- | --- |
| `CreateFeeSponsorProgram` | Әҙерлеккә ҡуйылған программаны уның мотлаҡ сығарыу иҫәбе менән булдырыу. |
| `StageFeeSponsorProgramRevision` | Яраҡлылыҡ, ғәмәлдәр һәм бюджет өсөн бер үҙгәрешһеҙ сәйәсәт билдәләү. |
| `EnrollFeeSponsorBeneficiary` | Талаптарға ярашлы файҙа алыусыны сылбырҙа теркәү. |
| `FundFeeSponsorProgram` | Активтарҙы һаҡлауға күсереү һәм теүәл программа һаҡлағысының балансын арттырыу. |
| `ActivateFeeSponsorProgramRevision` | Әҙерлеккә ҡуйылған ревизияның иң иртә әүҙемләшеү бейеклеген планлаштырыу. |

Программаны идара итеүгә бағыусы йә теүәл вәкәләт бирелгән идарасы рөхсәт бирә. Аҡса сығарыу бағыусының үҙен талап итә һәм программа паузала йә ябылыу барышында булғанда ғына аҡсаны программаның теркәлгән сығарыу иҫәбенә ҡайтара.

Һәр ревизия түбәндәгеләрҙе күрһәтә:

- аныҡ теркәү, йәки теркәү менән бергә маршрут буйынса рөхсәт ителгән ғәҙәти яраҡлылыҡ;
- натив инструкцияларҙың теүәл сым форматындағы идентификаторҙары йә контракт адрестары, код хэштары һәм инеү нөктәләре буйынса рөхсәт һәм тыйыу ҡағиҙәләре;
- һәр актив өсөн транзакция, блок, программа эпохаһы һәм файҙа алыусы эпохаһы сиктәре;
- резервтың иң түбән кимәле һәм детерминистик эпоха оҙонлоғо.

Тыйыу ҡағиҙәһе рөхсәт ҡағиҙәһенән өҫтөн. Мәғлүмәт киңлегенең `fee_sponsor_program_id` ҡиммәте әүҙем ревизия рөхсәт иткәндә генә маршрут буйынса ғәҙәти яраҡлылыҡ бирә; транзакция барыбер үҙенең теүәл программаһын һәм ревизияһын атарға тейеш. Әүҙемләштереүҙе алдағы ревизиянан ҡалған бүленгән ресурстарҙың ваҡыты сыҡҡансы кисектерергә мөмкин.

Бағыусы һаҡлағысының активтары `Global` баланс сәйәсәтен ҡулланырға тейеш. Бағыусының ғәҙәти иҫәбен генә аҡсаландырыу айырым программа һаҡлағысын аҡсаландырмай, һәм бер программа икенсе программаның балансын сарыф итә алмай.

## 3. Теүәл транзакцияға хаҡ тәҡдиме алыу, ҡул ҡуйыу һәм ебәреү {#_3-quote-sign-and-submit-the-exact-transaction}

SDK интеграцияһы түбәндәге аҙымдарҙы башҡара:

1. Вәкәләтле иҫәп, башҡарыла торған йөкмәтке, ваҡыт тамғалары, бер тапҡырлыҡ ҡиммәт, метамәғлүмәттәр, бағыусы программаһының теүәл ревизияһы һәм кәрәкле газ сиге менән ҡул ҡуйылмаған `TransactionPayload` төҙөгөҙ. Иң ҙур түләү ҡиммәттәре башта буш була ала.
2. `{"payload": <payload>}` менән `POST /v1/fees/quote` һорауына иҫәп исеменән ҡул ҡуйығыҙ. Һорауға ҡул ҡуйыусы транзакцияның вәкәләтле иҫәбе булырға тейеш.
3. Күҙәтелгән бейеклекте, асыҡланған мәғлүмәт киңлеге маршрутын, комиссия өлөштәрен, аҡса алыу сығанағын һәм бағыусының һыйҙырышлылығын тикшерегеҙ. Яуап һайланған түләүсене, ревизияны һәм газ сиген һаҡлауын раҫлағыҙ.
4. `payload.fee_payment` ҡиммәтен генә тәҡдим ителгән ниәткә алмаштырығыҙ, һуңынан ошо теүәл мәғлүмәт йөгөнә ҡул ҡуйып ебәрегеҙ.
5. Транзакцияны торош буйынса билдәләнгән `Applied` һуңғылығына тиклем күҙәтегеҙ һәм уның квитанцияһын, шул иҫәптән ғәмәлдә ҡулланылған бағыусы программаһын, ревизияны һәм түләүҙе һаҡлағыҙ.

Хаҡ тәҡдиме реестрҙы күҙәтә, әммә һыйҙырышлылыҡты резервламай. Сиратҡа ҡабул итеү яраҡлылыҡты ҡабат тикшерә һәм ҡул ҡуйылған иң ҙур ҡиммәттәрҙе резервлай. Бағыусы баш тартһа, транзакция ҡулланыусыны түләүгә күсермәйенсә кире ҡағыла.

CLI шул уҡ комиссия сығанағын аныҡ күрһәтә. Мәҫәлән, программа ошо теүәл актив күсереүенә рөхсәт биргәндән һәм иҫәп талаптарға ярашлы булғандан һуң:

```bash
iroha --config ./user.client.toml \
  --fee-payer sponsor \
  --fee-program '<SPONSOR_CANONICAL_I105>/team-payments' \
  --fee-program-revision 1 \
  ledger asset transfer \
  --definition '<ASSET_DEFINITION_BASE58>' \
  --account '<USER_CANONICAL_I105>' \
  --to '<RECIPIENT_CANONICAL_I105>' \
  --quantity 1
```

Үҙ селтәрегеҙҙең әүҙем ревизияһын һәм теүәл идентификаторҙарын ҡулланығыҙ. Ҡулланыусы конфигурацияһында шул ҡулланыусының ҡул ҡуйыусыһы ғына бар; талаптарға ярашлы бағыусы түләгән транзакцияны ебәреү өсөн бағыусының шәхси асҡысы кәрәкмәй.

## 4. Ҡулланыусы ҡушымта комиссияһын түләйме икәнен хәл итеү {#_4-decide-whether-the-user-pays-an-application-fee}

Ҡушымта ҡулланыусынан бер нәмә лә алмағанда ла, бағыусы глобаль комиссияларҙы ҡаплай ала. Ҡушымта урындағы токенды йыйһа, шул күсереүҙе йә контракт ҡағиҙәһен ҡулланыусы ҡул ҡуйған башҡарыла торған йөкмәткелә аныҡ билдәләгеҙ. Һәр ғәмәлде бағыусы ревизияһының сәйәсәтенә индерегеҙ һәм тулы мәғлүмәт йөгө өсөн хаҡ тәҡдимен тикшерегеҙ. Селтәр комиссияһы ниәтенән ҡушымта токены күсерелеүен һығымта итеп сығармағыҙ.

## Баш тартыуҙы диагностикалау {#diagnose-a-refusal}

Төйөн ҡайтарған тотороҡло комиссия кодын һәм төҙәтеү мәғлүмәттәрен ҡулланығыҙ:

| Код | Нимәне тикшерергә |
| --- | --- |
| `program_not_found` | Теүәл каноник программа идентификаторы. |
| `revision_not_active`, `program_not_active` | Ревизия әүҙемләшеүе һәм программа йәшәү циклы. |
| `beneficiary_not_eligible` | Теркәү йәки маршрут буйынса рөхсәт ителгән ғәҙәти яраҡлылыҡ. |
| `operation_not_allowed`, `operation_denied` | Һәр теүәл ҡул ҡуйылған ғәмәл һәм тыйыу ҡағиҙәһе. |
| `invalid_gas_limit`, `signed_limit_exceeded` | Яңы хаҡ тәҡдименә ярашлы газ сиге һәм ҡул ҡуйылған иң ҙур ҡиммәттәр. |
| `vault_insufficient` | Был программаның теүәл валюта һаҡлағысындағы аҡсаландырылған баланс. |
| Бюджет бөтөү кодтары | Транзакция, блок, программа эпохаһы һәм файҙа алыусы эпохаһы һыйҙырышлылығы. |

Һөҙөмтәһе аныҡ булмаған ебәреүҙе тикшергәндә тәүге транзакция хэшын һәм комиссияны кире ҡағыу мәғлүмәттәрен һаҡлағыҙ. Алмаштырыусы транзакция төҙөр алдынан уның торошон раҫлағыҙ.
