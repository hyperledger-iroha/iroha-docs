# Iroha 3 Қолданбалар кітабы {#iroha-3-application-cookbook}

Қарсылық орнату Iroha 3 Кішкентай, тексеруге болатын рецепттермен Taira сынақ желісі және сақтау Minamoto Тек оқуға арналған рецепт. Әр рецептте ол жұртшылыққа оқылады ма, жоқ па, Әдеттегі қаржыландырылған шот жазуы, немесе рұқсатпен бекітілген операция. I105 есеп IDs, айқын алым таңдау, және мінез-құлық тексеріледі Iroha міндеттеу [`0010c5a70039eac101a4846499ba9ceaf43eb65c`](https://github.com/hyperledger-iroha/iroha/tree/0010c5a70039eac101a4846499ba9ceaf43eb65c).

Сөйтіп бастаңыз [Қосылу Taira](./connect-to-taira.md). Бұл клиенттің конфигурациясы мен алымның метамәдени деректерін қайта пайдаланады командалық жол рецепттері. ID осы құжаттамадан: оны ағымдағы Taira кранға жауап беру.

## Қолжетімділік деңгейлері {#access-levels}

- Қоғамдық  қолтаңбалаушы немесе желілік рұқсат қажет емес.
- Жазуға дайын  қаржыландырылған Taira сынақ шотын, айрықша алым төлеуші және кран арқылы қайтарылған ағымдағы алым активін пайдалану.
- Рұқсат қажет  Taira атаулы орындалу уақыты рұқсатын немесе реттелетін атау кеңістігін беруі тиіс. Бұл грант жоқ кезде құрылған жергілікті желіді пайдалану; жергілікті жетістік Taira өкілеттігін бермейді.

Minamoto дегенге бірде-бір рецепт жібермейді.
