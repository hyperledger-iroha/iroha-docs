# Орнату мәселелерін шешу {#troubleshooting-installation-issues}

Бұл бөлім Iroha 3 орнату үшін ақауларды жою кеңестерін ұсынады. Егер сізге туындаған мәселе мұнда сипатталмаған болса, бізбен [Телеграм](https://t.me/hyperledgeriroha) арқылы хабарласыңыз.

## Жылдам тексерулер {#quick-checks}

Көбінесе орнату сәтсіздіктері төрт жердің бірінен туындайды:

- жоғары жұмыс кеңістігімен бекітілген нұсқадан ескі Rust құралдар тізбегі
- `cargo` немесе `rustc` `rustup` мәнінен өзгеше орнатуға шешілуде
- C компиляторы, `pkg-config` немесе CMake сияқты жүйелік құрастыру құралдары жоқ
- дереккөз өзгерістерін өзгертуден кейін ескі жасалған үзінділер немесе жергілікті құрастыру өнімдері

Iroha бастапқы кодының жұмыс істейтін көшірмесінен бастаңыз:

```bash
rustup show
cargo --version
rustc --version
cargo metadata --no-deps
```

`cargo metadata` сәтсіз болса, `pnpm refresh:iroha --source /path/to/iroha` орындамас бұрын жергілікті құрал-саймандар жиынтығын түзетіңіз, өйткені жаңарту ағымдағы деректер-модель схемасын генералдауға Kagami шақыруы мүмкін.

## Ақаулықтарды жою Rust Құрал-сыртқы тізбек {#troubleshooting-rust-toolchain}

Кейде істер жоспар бойынша жүрмейді. Әсіресе, егер сіздің жүйеңізде біраз уақыт бұрын `rust` орнатылған болса, бірақ жаңартылмаған болса. Ұқсас проблема Python-де де туындауы мүмкін: XKCD мұның қандай көрініс алатынына әйгілі мысал ұсынады:

### Rust нұсқасын тексеру {#check-rust-version}

Сіздің де, біздің де ақыл-есі сақталуын қамтамасыз ету үшін, `cargo` дұрыс нұсқасы `rustc` дұрыс нұсқасымен жұпталғанына көз жеткізіңіз. Қазіргі жоғары деңгейлі жұмыс кеңістігі `rust-version = "1.92"` деп жариялайды және құралдар арнасының нұсқасын `rust-toolchain.toml` белгілейді. Нұсқаларды көрсету үшін, орындаңыз

```bash
$ cargo -V
$ cargo 1.93.1 (...)
```

және кейін

```bash
$ rustc --version
$ rustc 1.93.1 (...)
```

Егер сізде жоғарғы нұсқалар болса, бәрі жақсы. Егер сізде төменгі нұсқалар болса, оны жаңарту үшін келесі команданы іске қоса аласыз:

```bash
$ rustup toolchain update stable
```

### Орнату орнын тексеріңіз {#check-installation-location}

Егер сіз төменірек нұсқаларды алсаңыз және құралдар жиынтығын жаңартқаныңызда ол жұмыс істемесе… жалпы айтқанда, бұл жиі кездесетін проблема, бірақ оған ортақ шешім жоқ.

Біріншіден, қолданғыңыз келетін нұсқаның қай жерде орнатылғанын анықтауыңыз керек:

```bash
$ rustup which rustc
$ rustup which cargo
```

Құралдар жинақтарын пайдаланушы орнатулары әдетте `~/.rustup/toolchains/stable-*/bin/` мекенжайында орналасады. Егер жағдай солай болса, сіз іске қоса алуыңыз керек

```bash
$ rustup toolchain update stable
```

және бұл сіздің мәселелеріңізді шешуі керек.

### Әдепкі Rust нұсқасын тексеріңіз {#check-the-default-rust-version}

Тағы бір нұсқа – сізде қазіргі заманауи `stable` құралдар жинағы бар, бірақ ол әдепкі ретінде орнатылмаған. Жүгіру:

```bash
$ rustup default stable
```

`nightly` нұсқасын орнату немесе нақты Rust нұсқасын орнату және кейін оны өшірмеу бұл мәселені тудыруы мүмкін.

### Басқа Rust нұсқалары бар-жоғын тексеріңіз {#check-if-there-are-other-rust-versions}

Шешім іздеудің тағы да тереңіне түскенде, бізде шелл алиастар болуы мүмкін:

```bash
$ type rustc
$ type cargo
```

Егер бұл көрсеткіштер `rustup which *` іске қосқан кезде көрген орныңыздан басқа орындарды нұсқаса, онда сізде проблема бар. Мұндай атауларды қосу жеткіліксіз екенін ескеріңіз:

```bash
$ alias rustc "~/.rustup/toolchains/stable-*/bin/rustc"
$ alias cargo "~/.rustup/toolchains/stable-*/bin/cargo"
```

Шелл альясын қалай орналастырсаңыз да, ішкі логика әлі де бұзылуы мүмкін.

Ең қарапайым шешім — қолданбайтын нұсқаларды жою болар еді.

Дегенмен, мұны айту оңай, орындау қиын, себебі бұл сізге орнатылған және қолжетімді барлық rustup нұсқаларын бақылауды қажет етеді. Әдетте, тек екі нұсқа ғана болады: жүйе пакет менеджерінің нұсқасы және осы оқулықты бастаған кезде пәрменді орындағанда үй қалтаңыздың стандартты орнына орнатылған нұсқасы. Алдыңғысы үшін өзіңіздің (Linux) таралымыңыздың нұсқаулығына қараңыз, (`apt remove rust`). Кейінгісі үшін мына пәрменді орындаңыз:

```bash
$ rustup toolchain list
```

Содан кейін әрбір `<toolchain>` үшін (әрине бұрыштық жақшаларсыз):

```bash
$ rustup remove <toolchain>
```

Құралдар жинақтарын алып тастағаннан кейін, бұл команда command-not-found қатесін көрсетуі керек:

```bash
$ cargo --help
```

Ол қате ешқандай белсенді Rust құралдар жиынтығының орнатылмағанын растайды. Содан кейін орындаңыз:

```bash
$ rustup toolchain install stable
```

## Құралдар тізбегін Python ақауларын жою {#troubleshooting-python-toolchain}

[Python клиентті баптау](/kk/guide/tutorials/python.md) кезінде pip арқылы Python Wheel пакетін орнатқанда, сіз келесі қателікке кезігуіңіз мүмкін: "iroha_python-*.whl осы платформада қолдау көрсетілетін wheel емес".

Бұл қате pip ескіргенін білдіреді, сондықтан оны жаңарту қажет. Ең алдымен, жаңартулар үшін өзіңіздің OS тексеру және жүйені жаңарту ұсынылады.

Егер бұл жұмыс істемесе, пайдаланушы каталогыңыз үшін `pip` жаңартуды сынап көре аласыз.

`python -m pip install --upgrade pip`

Үй каталогыңызға `pip` орнатылғанын тексеріңіз. Мұны істеу үшін `whereis pip` пәрменін іске қосып, `/home/username/.local/bin/pip` жолдар арасында бар-жоғын тексеріңіз. Егер жоқ болса, шеллінің `PATH` айнымалысын жаңартыңыз.

Егер мәселе сақталса, өтінеміз [бізбен байланысыңыз](/kk/help/) орындап, нәтижелерді хабарлаңыз.

```
python --version
python3 --version
pip --version
pip3 --version
```
