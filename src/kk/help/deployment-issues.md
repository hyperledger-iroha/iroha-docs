# Орнату мәселелерін шешу {#troubleshooting-deployment-issues}

Бұл бөлім Iroha 3 енгізулеріне арналған ақауларды жою кеңестерін ұсынады. Егер сізге туындаған мәселе мұнда сипатталмаған болса, бізбен [Телеграм](https://t.me/hyperledgeriroha) арқылы хабарласыңыз.

## Жасалған артефактілерден бастаңыз {#start-with-generated-artifacts}

Жергілікті және тестілеу орнатылымдары үшін қолмен жазылған желілік түйін файлдарына қарағанда Kagami жасаған артефактілерді таңдаңыз:

```bash
cargo run --bin kagami -- localnet --peers 4 --out-dir ./localnet
```

Жасалған каталог желілік түйін конфигурацияларын, блокчейннің басын материалдарын, бастау скрипттерін және Iroha 3 жинақ желісі үшін README қамтиды.

## желі әріптесі басталмайды {#peer-does-not-start}

Алдымен осы заттарды тексеріңіз:

- `iroha3d --config <path>` желідегі тараптың өзінің TOML файлына нұсқайды.
- Желідегі тараптағы `public_key` және `private_key` бір кілт жұбына жатады.
- `genesis.public_key` блокчейннің алғашқы (генезис) транзакциясын қол қою үшін қолданылған кілтке сәйкес келеді.
- валидатор желісі серіктес идентификаторлары BLS-Қалыпты кілттерді пайдаланады, ал `trusted_peers_pop` жергілікті кілт пен сенімді желі серіктестері үшін меншік дәлелі жазбаларын қамтиды.
- Torii және P2P порттары басқа процесс арқылы бұрыннан байланыстырылмаған.
- Kura дүкен каталогы бірдей желіге жатады және басқа желі профилінен көшірілген емес.

Демон бірнеше TOML қабатты оқығанда конфигурацияны бақылауды қолданыңыз:

```bash
cargo run -p irohad --bin iroha3d -- --config ./config.toml --trace-config
```

## Docker және Құрастыру {#docker-and-compose}

Ағымдағы Kagami localnet нәтижесінен Compose жасаңыз, сонда командалық жол аргументтері мен конфигурация файлдары тексерілген кодқа сәйкес болады:

```bash
cargo run --bin kagami -- localnet --peers 4 --out-dir ./localnet
cargo run --bin kagami -- docker --peers 4 --config-dir ./localnet --image hyperledger/iroha:dev --out-file ./docker-compose.yml --force
docker compose -f ./docker-compose.yml up
```

Егер compose орналастыру басталып, кейін тоқтап қалса, демон журналдарын тексеріңіз:

- сәйкес келмейтін `chain`
- бір желілік түйін әртүрлі блокчейн бастапқы транзакциясын немесе техникалық манифесті қолданады
- тек контейнер желісінің ішінде жұмыс істейтін жарнамаланған P2P мекенжайлар
- блокчейн генезисін қалпына келтіргеннен кейін жергілікті көлемді қайта пайдалану

Жаңа блокчейн генезисін тестілеу кезінде стекті қайта іске қоспас бұрын ескі Kura көлемдерін алып тастаңыз. Ескі блок сақтауын жаңа блокчейн генезисімен сақтау ойнатуды сәтсіз қылады.

## Kubernetes {#kubernetes}

Kubernetes үшін әрбір валидациялаушыны күйге тәуелді инфрақұрылым ретінде қарастырыңыз:

- әрбір желілік теңсарпына тұрақты сәйкестендіру кілтін және тұрақты сақталатын көлемін беріңіз
- кластер ішінен басқа желілік тараптар шеше алатын P2P мекенжайларын көрсету
- роллаут үшін өзгермейтін конфигурация ретінде конфигурация мен блокчейн генезис файлдарын орнатыңыз
- барлық блокчейннің генезисі немесе топологиясын өзгерістерді автоматты конфигурациялық кестені жаңартуы ретінде емес, әдейі енгізіңіз

Егер под үздіксіз қайта іске қосылса, подтағы көрсетілген конфигурацияны күтілгенімен салыстырыңыз [`peer.template.toml`](/kk/reference/peer-config/index.md#template) және желідегі әріптестің ескілерін қайта ойнатып жатқанын тексеру Kura деректер.

## Сора профилі {#sora-profile}

Жеке немесе жергілікті Iroha 3 орналастырулар, Nexus, SoraFS немесе көпжолақты ағындарды қолданатын болса, стандартты демонды Sora профилімен қосылған түрде іске қосуы керек:

```bash
cargo run -p irohad --bin iroha3d -- --config ./config.toml --sora
```

Бірдей желідегі валидаторларда бір профильді үнемі қолданыңыз.

Қоғамдық Taira тексерушілері арнайы іске қосқышты пайдаланады, ол Taira-нің дәл тізбегін, тізімін, өшірілген кіріктірілген-SoraFS сақтауды және іске қосу қолтаңба профилін қолдануды қамтамасыз етеді. Оны бастамас бұрын көрсетілген Taira конфигурациясын тексеріңіз:

```bash
iroha3d_taira --sora \
  --config /etc/iroha/taira/config.toml \
  --check-config
```

Қоғамдық бастама жасамаңыз Taira жалпы тексеруші `iroha3d`; көріңіз [`iroha3d` CLI сілтеме](/kk/reference/iroha3d-cli.md) мықтап тағайындалған профиль үшін.
