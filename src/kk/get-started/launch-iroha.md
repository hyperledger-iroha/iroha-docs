# Iroha 3 іске қосу {#launch-iroha-3}

Жабық ортадағы интеграцияны тексеру үшін бір Linux виртуалды машинасында (VM) төрт Iroha 3 валидаторын іске қосыңыз. Қол қойылған транзакцияны жіберіңіз, бір валидаторды тоқтатыңыз да, қалған үшеуі келесі транзакцияны растай алатынын тексеріңіз. Осылайша қатысуға рұқсат қажет жеке тізілім жасалады. Оны басқарылатын деректер кеңістігі ретінде SORA Nexus желісіне қосу үшін бөлек баптау қажет.

## VM дайындаңыз {#prepare-the-vm}

Linux x86_64 жүйесінде Docker Engine, Buildx, Compose v2, Python 3.8 немесе одан жаңа нұсқасын және `unzip` құралын пайдаланыңыз. Тіркелгіңізде Docker-ді пайдалану құқығы болуы керек. Алғашқы құрастыру үшін GitHub, Docker Hub, Debian пакеттерінің айна серверлеріне және crates.io торабына HTTPS арқылы шығыс қосылым қажет.

Біз VM құрамында алты vCPU және 32 GiB RAM бар жинақты бірнеше синтетикалық транзакциялар арқылы құрып, сынадық. Өз жұмысыңызға арналған жүктеме және сақтау мерзіміне сәйкес сақтау көлемін анықтаңыз. Әр Docker қозғалтқышқа жинақтың бір көшірмесін пайдаланыңыз және loopback порттарын 18080–18083 қолжетімді етіп сақтаңыз.

[Төрт тексеруші жиынтығын жүктеп алыңыз](/downloads/iroha-trade-poc.zip). Бұл іске қосқышты, құлыпталған тәуелділік тізімін және дәл сол Iroha нұсқасынан валидатор мен клиентті құру үшін қолданылатын патчтарды қамтиды. Жүктелген қалтадан тексеріп, оны шығарып алыңыз.

```sh
echo 'b12d450f9f15c0126dfe5eca83cdfad8bc420c779a78f916d374f433a2b3da0e  iroha-trade-poc.zip' | sha256sum --check
unzip iroha-trade-poc.zip
cd iroha-trade-poc
```

## Барлық төрт валидациялық бағдарламаны іске қосып, тексеріңіз {#start-and-verify-all-four-validators}

```sh
python3 poc.py up
python3 poc.py verify
```

Алғаш іске қосылғанда контейнер бейнесі құрастырылады, ал виртуалды машинада (VM) тізбек идентификаторы, кілттер және қол қойылған бастапқы блок жасалады. Әр валидатордың жеке тұрақты сақтау томы бар. Тексеру бағдарламасы сынақ транзакциясына қол қояды да, төрт валидатордың әрқайсысы үш көрші түйінге қосылғанын және жаңа блоктың хэші бірдей екенін хабарлағанша күтеді. Бастапқы блокқа үлгі тіркелгілер кіреді. Жасанды деректерді қолданыңыз және APIs-ді тек жергілікті loopback интерфейсінде ашыңыз.

VM-ден бірінші валидатордың мәртебесін оқу үшін, JSON-ге нақты сұрау жасаңыз.

```sh
curl -fsS -H 'Accept: application/json' http://127.0.0.1:18080/status
```

## Растаушының қателігін тексеру {#test-a-validator-failure}

```sh
python3 poc.py failover
```

Сынақ бір валидаторды тоқтатып, жаңа транзакция жібереді және жұмыс істеп тұрған үш валидатордағы расталған блоктың хэшін салыстырады. Содан кейін төртінші валидаторды қайта іске қосып, оның сол блокқа жетуін күтеді. Виртуалды машина (VM) істен шықса, төрт валидатор да тоқтайды. Бір физикалық хосттың істен шығуын тексеру үшін төрт тәуелсіз хосттың әрқайсысына бір валидатордан орналастырыңыз.

## Тоқтату және жалғастыру {#stop-and-resume}

```sh
python3 poc.py down
python3 poc.py up
```

Екі пәрменді де жинақ ашылған бір каталогтан орындаңыз. Қайта іске қосылған валидаторлар сол тізілімді аша алуы үшін `state/` каталогы мен төрт Docker томын бірге сақтаңыз. Іске қосу кідірсе, сол каталогта `python3 poc.py logs` пәрменін орындаңыз.

## Қоғамдық API тіркелу нүктесін байқап көріңіз {#try-the-public-endpoint}

Қолданба тізілімге арналған виртуалды машинасы (VM)з Taira желісіндегі SORA Nexus әмбебап деректер кеңістігін оқи алады. `curl` және `jq` орнатылған жұмыс станциясынан сынақ желісіне мына оқу сұрауын жіберіңіз.

```sh
curl -fsS -H 'Accept: application/json' https://taira.sora.org/status \
  | jq '{peers, blocks, txs_approved, queue_size}'
```

Жауап сұралған түйіннің қосылған желідегі әріптестерін, аяқталған блоктарды, мақұлданған транзакциялар мен кезектегі транзакцияларды хабарлайды. Орнату жоспарлау үшін [Желіні орналастыру](/kk/guide/best-practices/network-deployment.md) қараңыз.
