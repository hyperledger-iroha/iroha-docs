# Iroha 3 {#iroha-3}

Iroha 3 - бірінші релиз Hyperledger Iroha платформасы. Ол өзіндік хостингтік желілерді және көп деректер кеңістігін қолданады SORA Nexus бір детерминистік код базасынан іске қосылған модель.

Жоғары деңгейде Iroha 3 құрамында:

- детерминистік орындау және сақтау
- портативті ақылды келісімшарттар үшін Iroha Виртуалды машинасы (IVM)
- Norito каноникалық сым форматы ретінде
- Torii клиент, оператор және қосымшаға қарасты APIs үшін
- Sumeragi мiндеттi деректердiң болуы мен сенiмдi хабар таратумен келiсу
- Доменсіз, жеке байланысқан адам оқитын аты-жөндері бар каноникалық шоттар
