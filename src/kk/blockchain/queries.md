# Сұраулар {#queries}

Оқиға жазылушылары мен сүзгілер блокчейн күйіндегі өзгерістерді қадағалай алады. Ағымдағы күйді тікелей көру қажет болса, сұранымды пайдаланыңыз.

Сұраулар — кішкентай нұсқаулық сияқты объектілер. Ағымдағы әлем күйін көрсетуінен мәлімет алу үшін біреуін Iroha желілік әріптеске жіберіңіз.

Желі басқа ақпаратты көрсетуі мүмкін. Сұрау салуға болатын әлемдік күй ақпараты ғана әр Iroha желісінде қолжетімді болатыны кепілдендірілген ақпарат түрі болып табылады.

Iroha әрбір орналастыру үшін басқа қолжетімді ақпарат болуы мүмкін. Мысалы, телеметрия деректерінің қолжетімділігі желі әкімшілеріне байланысты болады. Олар жұмысты орындауға емес, жұмыс процесін қадағалауға есептеу қуатын бөлгісі келетін немесе келмейтіндігі туралы шешімді толық өздері қабылдайды. Керісінше, кейбір функциялар әрдайым қажет, мысалы, есеп шотыңыздағы қалдыққа қол жеткізу.

Сұраныстардың нәтижелері бір уақытта [сұрыпталған](#sorting), [беттелген](#pagination) және [сүзілген](#filters) әріптес жағында болуы мүмкін. Сұрыптау метадеректер кілттері бойынша лексикографиялық түрде жасалады. Сүзу жасауға болады түрлі принциптерге негізделген, доменге тән (жеке IP мекенжай сүзгі маскалары) әдістерден логикалық операцияларды қолдану арқылы біріктірілген `begins_with` сияқты ішкі жол әдістеріне дейін.

## Осы жұмыс ағынын Taira бойынша іске қосыңыз {#try-it-on-taira}

Taira жалпы ресурстарға арналған JSON үстінде тек оқу режиміндегі сұрау көмекшілерін ұсынады. Оларды парақтау мен жауап өңдеуді тәжірибе ету үшін пайдаланыңыз, содан кейін SDK қосыңыз:

```bash
TAIRA_ROOT=https://taira.sora.org

curl -fsS "$TAIRA_ROOT/v1/accounts?limit=3" \
  | jq '{total, ids: [.items[].id]}'

curl -fsS "$TAIRA_ROOT/v1/domains?limit=3" \
  | jq '{total, domains: [.items[].id]}'

curl -fsS "$TAIRA_ROOT/v1/assets/definitions?limit=3" \
  | jq '{total, assets: [.items[] | {id, name, total_quantity}]}'
```

Қосымшаны диагностикалау үшін осы қарапайым тексерулерді қол қойылған транзакция тесттерінен бөлек ұстаңыз. Тек оқу режиміндегі сұрау сәтсіздігі әдетте криптографиялық қолтаңба орнатылуына қарағанда алдымен API ұштастыру нүктесінің қолжетімділігін, желінің қолжетімділігін немесе маршрут үйлесімділігін білдіреді.

## Сұрау жасау {#create-a-query}

SDK немесе CLI тізімделген сұрау құрастырушыларын пайдаланыңыз. Мысалы, ағымдағы деректер моделі есепшоттарды тізімдеу үшін `FindAccounts` көрсетеді:

```rust
let query = FindAccounts;
```

Міне, Alice-тің активтерін табатын сұраудың мысалы:

```rust
let alice_id = load_canonical_account_id_from_client_config()?;
let query = FindAssetsByAccountId::new(alice_id);
```

## Беттерлеу {#pagination}

Жекелей сұраулар және кішігірім қайталанатын сұраулар үшін, сұрауды бірден жіберіп, нәтижені бірден алу үшін `client.request` қолдануға болады.

Алайда, `FindAccounts`, `FindAssets` немесе `FindBlocks` сияқты кең ауқымды қайталанатын сұраулар үлкен нәтиже жиынтықтарын қайтара алады. Желідегі әріптес пен клиентке түсетін жүктемені азайту үшін беттік көрсетуді (pagination) пайдаланыңыз.

`Pagination`-ны құру үшін, сіз `client.request_with_pagination(query, pagination)`-ді шақыруыңыз қажет, мұнда `pagination` келесі түрде құрылады:

```rust
let starting_result: u32 = _;
let limit: u32 = _;
let pagination = Pagination::new(Some(starting_result), Some(limit));
```

## Сүзгілер {#filters}

Сұрау жасаған кезде тек көрсетілген сүзгіге сәйкес келетін нәтижелерді қайтару үшін сүзгіні қолдануға болады.

Сүзгілер сұрау бойынша ерекшеленеді. Мысалы, есеп шот сұраулары есеп шоттың тұлғасы немесе метадеректері бойынша шектелуі мүмкін, ал актив сұраулары актив бойынша шектелуі мүмкін анықтама, иесінің шоты немесе доменнің проекциясы. Фильтр түрі сұрау нәтижесінің түрімен сәйкес болу үшін мүмкін болса, SDK типтелген сұрау құрастырушыларын пайдаланыңыз.

## Сұрыптау {#sorting}

Iroha сұрауды құру кезінде сұрыптау үшін кілт берсеңіз, элементтерді [метадеректер](/kk/blockchain/metadata.md) лексикографиялық тәртіппен сұрыптай алады. Қолданудың типтік мысалы – есептік жазбаларда `registered-on` метадеректер енгізуі болуы, ол сұрыпталғанда есептік жазба тіркелу тарихын көруге мүмкіндік береді.

Сұрыптау тек [метадеректер](/kk/blockchain/metadata.md) бар бірліктерге ғана қолданылады, себебі метадеректер кілті сұрау нәтижелерін сұрыптау үшін қолданылады.

Сіз сұрыптауды беттілеу және сүзгілермен біріктіре аласыз. Сұрыптау опционалды функция екенін ескеріңіз, беттілеуі бар көп сұрауларда оған қажеттілік болмайды.
