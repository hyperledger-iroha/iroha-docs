# Оқиғалар {#events}

Іс-шаралар блокчейн ішінде белгілі бір нәрселер болған кезде шығарылады, мысалы, жаңа шот құрылады немесе блок басталады. Іс-шаралардың әр түрлі түрлері бар:

- құбыр желісі оқиғалары
- деректер оқиғалары
- уақыт оқиғалары
- орындау іс-шараларын іске қосу

## Құбыр желісі оқиғалары {#pipeline-events}

Құбыр құбыры оқиғалары бір блокқа транзакциялар жіберілгенде, орындалғанда немесе тапсырылған кезде шығарылады. Құбыр құбырының оқиғасы мынадай ақпаратты қамтиды: іс-шараның (транзакция немесе блоктың) себебін келтірген субъектінің түрі, оның хэші және мәртебесі. Статус `Validating` (қолданыстағы жарамдылық), `Rejected` немесе `Committed` болуы мүмкін. Егер субъект қабылданбаған болса, одан бас тартудың себебі ұсынылады.

### Taira арқылы сынап көріңіз. {#try-it-on-taira}

Қоғамдық құбырдың оқиға ағынының орнатылғанын тексеріңіз:

```bash
curl -fsSI https://taira.sora.org/v1/events/sse \
  | sed -n '1,12p'
```

Ағынды ашық ұстамай-ақ тексеруге болатын шұғыл сурет үшін, соңғы Explorer транзакцияларын оқыңыз:

```bash
curl -fsS 'https://taira.sora.org/v1/explorer/transactions?page=1&per_page=5' \
  | jq '{pagination, txs: [.items[] | {hash, block, status, executable}]}'
```

Тікелей оқиғалар қажет болған кезде SSE маршрутын терминалда ашу:

```bash
curl -fsS -N https://taira.sora.org/v1/events/sse
```

Егер ағын ашық болған кезде бірде-бір транзакция жасалмаса, маршрут дұрыс болса да, команда тыныш бола алады.

## Деректер оқиғалары {#data-events}

Деректер оқиғалары бухгалтерлік кітапша деректерімен байланысты өзгерістер болған кезде шығарылады, мысалы, теңгерімдер, домендер, шоттар, активтер, активтердің анықтамалары, NFTs, триггерлер, рөлдер, тізбектегі конфигурация, орындаушы мемлекет, дәлелдемелер, құпия активтер, көпірлер немесе SORA/Nexus-белгілі объектілер. Бұл оқиғалардың түрлері [дета оқиғаларының сүзгілері ](./filters.md#data-event-filters)-де қолданылады.

## Уақыт оқиғалары {#time-events}

Уақыт оқиғалары әлем жағдайы көрінісі [ уақытты триггерлерді](./triggers.md#time-triggers) басқаруға дайын болған кезде жіберіледі.

## Триггерлік орындау оқиғалары {#trigger-execution-events}

[`ExecuteTrigger`](./instructions.md#executetrigger) нұсқау орындалған кезде триггерді орындау оқиғалары шығарылады. Қозғалтқыш аяқталу оқиғалары қозғалтқыш әрекет аяқталғаннан кейін шығарылады.
