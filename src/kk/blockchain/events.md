# Оқиғалар {#events}

Typed оқиғалар туралы хабарламалар блокчейн ішінде белгілі бір нәрселер болған кезде жіберіледі, мысалы, жаңа есептік жазба құрылғанда немесе блок аяқталған кезде. Оқиғалардың әртүрлі түрлері бар:

- бағдарламалық қамтамасыз ету процестерінің жұмыс ағыны оқиғалары
- деректер оқиғалары
- уақытқа негізделген оқиғалар туралы хабарламалар
- орындау оқиғаларын қосуды іске қосу

## бағдарламалық қамтамасыз етуді өңдеу жұмыс ағыны оқиғалары {#pipeline-events}

Бағдарламалық қамтамасыз ету өңдеу жұмысы оқиғалары транзакциялар жіберілгенде, орындалғанда немесе блокта аяқталған кезде шығарылады. Бағдарламалық қамтамасыз ету өңдеу жұмысы оқиғасы келесі ақпаратты қамтиды: оқиғаны тудырған субъектінің түрі (транзакция немесе блок), оның криптографиялық хэші және статусы. Статус келесі болуы мүмкін: `Validating` (тексеру жүргізілуде), `Rejected`, немесе `Committed`. Егер бірлік қабылданбаған болса, қабылданбау себебі көрсетіледі.

### Осы жұмыс ағынын Taira бойынша іске қосыңыз {#try-it-on-taira}

Қоғамдық бағдарламалық қамтамасыз ету өңдеу жұмыс процесінің оқиға ағыны орнатылғанын тексеріңіз:

```bash
curl -fsSI https://taira.sora.org/v1/events/sse \
  | sed -n '1,12p'
```

Уақытша деректер көрінісі үшін, ағынды ашық ұстамай қарау үшін соңғы шолушы транзакцияларын оқыңыз:

```bash
curl -fsS 'https://taira.sora.org/v1/explorer/transactions?page=1&per_page=5' \
  | jq '{pagination, txs: [.items[] | {hash, block, status, executable}]}'
```

Тірі оқиғалар қажет болғанда SSE маршрутын терминалда ашыңыз:

```bash
curl -fsS -N https://taira.sora.org/v1/events/sse
```

Ағын ашық кезінде ешқандай транзакциялар жіберілмесе, маршрут сау болғанына қарамастан, команда үнсіз қалуы мүмкін.

## Деректер оқиғалары {#data-events}

Деректер оқиғалары блокчейн тіркеу деректеріне байланысты өзгеріс болғанда шығарылады, мысалы, желілік серіктестер, домендер, аккаунттар, активтер, активтер анықтамалары, NFTs, триггерлер, рөлдер, тізбектегі конфигурация, орындаушының күйі, дәлелдер, құпия активтер, көпірлер немесе SORA/Nexus-ге тән объектілер. Бұл типтегі оқиғалар [деректер оқиғаларын сүзгілер](./filters.md#data-event-filters)-де қолданылады.

## уақытқа негізделген оқиғалар туралы хабарламалар {#time-events}

уақытқа байланысты оқиға туралы хабарламалар әлемнің күй көрінісі [уақыт триггерлері](./triggers.md#time-triggers) өңдеуге дайын болған кезде шығарылады.

## Триггерді орындау оқиғалары {#trigger-execution-events}

Триггерді орындау оқиғалары шығарылған кезде [`ExecuteTrigger`](./instructions.md#executetrigger) нұсқаулық орындалады. Триггер әрекеті аяқталғаннан кейін триггер аяқталу оқиғалары шығарылады.
