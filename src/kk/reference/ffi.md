# Шетелдік функция интерфейстері (FFI) {#foreign-function-interfaces-ffi}

Қауымдастық `iroha_ffi` коробка C өндірісі үшін макролар мен қасиеттерді ұсынады ABI байланыстар Rust APIs. Бұл жерде қолданылады: Iroha түрлер арқылы өту керек FFI шекарасы, мысалы SDK байланыстар немесе қоректендіру интеграциялары.

## Неге FFI {#why-ffi}

Функция - бұл абстрактты бірлік, және көпшілік тілдер функцияның не істеу керектігі туралы келісе тұра, функциялардың бейнелену тәсілі өте өзгеше. Rust, Функцияны шақырудың салдары және оған рұқсат етілген нәрселер де әртүрлі. Rust APIs басқа тілден немесе басқа қонақ ортадан шақыру қажет, Iroha сыртқы функция интерфейсін пайдаланады (FFI) ойын шарттарын теңестіру.

Қазіргі кезде қолданылатын негізгі стандарт - C қолданбалары бинарлық интерфейс. Ол қарапайым, кеңінен қол жетімді және тұрақты. Iroha қамтамасыз етеді `iroha_ffi` тудыруға арналған сандық FFI-қалыпталған функциялар Rust API.

Әрине, сіз мұны өзіңіздің тәсіліңізбен жасай аласыз. `iroha_ffi` Қажетті қазандық плитасын жазу өте көп қатаң және тәртіпті қажет етеді. FFI шекарасы `unsafe` Біз оны шешудің әдісі, мықты `repr(C)` үлгілері.

::: ақпарат

Бірден-бір ерекшелік - көрсеткіштері. Нөлдік тексеру мен жарамдылық жалпыға бірдей қолданылмайды, сондықтан сырьелі көрсеткіштер (әдеттегідей) тек ерекше жағдайларда қолданылады. Біз Iroha деректер моделіндегі нысанның кез-келген үлгісіне қаптамалар ұсынатындықтан, сіз шикі көрсеткіштерді қолданбауыңыз керек.

:::

## Мисал {#example}

Мұнда бұзылуды құрудың мысалы келтірілген:

```rust
#[derive(FfiType)]
struct DaysSinceEquinox(u32);

#[ffi_export]
impl DaysSinceEquinox {
    pub fn update_value(&mut self, a: &u8) {
        self.0 = *a as u32;
    }
}
```

Жоғарыда келтірілген мысал `DaysSinceEquinox` арқылы ашық емес көрсеткіш ретінде көрсетілген келесі байланысты туғызады:

```rust
pub extern fn DaysSinceEquinox__update_value(handle: *mut DaysSinceEquinox, a: *const u8) -> FfiReturn {
    // function implementation
}
```

## FFI Байланысты ұрпақ {#ffi-binding-generation}

Қауымдастық `iroha_ffi` коробка арқылы шақырылатын функцияларды тудыру үшін қолданылады FFI. Берілген `Rust` құрылымы мен әдістері, олар `unsafe` сілтемелі шекараны кесіп өту үшін қажет код.

А Rust үлгісі берік түрге айналады `repr(C)` түрін аша алатын FFI шекарасы `FfiType::into_ffi`. Бұл да керісінше: FFI `ReprC` түрін а `Rust` түрі арқылы `FfiType::try_from_ffi`.

::: ескерту

Кері айналымның қате екенін және анықталмаған мінез-құлықтарға әкелуі мүмкін екенін ескеріңіз. Біз ең анық қателерді болдырмау үшін барынша күш сала аламыз, бірақ сіз бағдарламаның дұрыстығын қамтамасыз етуіңіз керек.

:::

Байланыс тудыруға мүмкіндік беретін негізгі қасиеттер: `ReprC`, `FfiType`, және `FfiConvert`.

|қасиеттер |Бейнелеу |
| ------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
|`ReprC` |Бұл қасиет C ABI сәйкес келетін берік типті білдіреді. Тип FFI шекараларында қауіпсіз бөлінеді. |
|`FfiType` | Бұл қасиет сәйкес келетін `ReprC` белгілі бір түрі `Rust` үлгісі. `ReprC` үлгісі `Rust` түрінде API өндірілген FFI функциясы. |
|`FfiConvert` | Бұл қасиет екі әдісті анықтайды: `into_ffi` және `try_from_ffi` Алушыларды қайта өңдеу үшін пайдаланылатын `Rust` түрін немесе `ReprC` түрінде.                                |

Байқаңыз, оған иелік етудің берілуі жоқ FFI Өткінші индикатор түрлерін қоспағанда, басқа да меншік иелері бар типтер: `Vec<T>`, клондалған.

### Атын Манглинг {#name-mangling}

FFI нысандарының генериленген атауларында қос қосалқы белгілер қолданылуын ескеріңіз:

- Бұл үшін `inherent_fn` Бұл әдіс `StructName` құрылымы, FFI атауы болады `StructName__inherent_fn`.
- Бұл үшін `MethodName` әдісі `TraitName` ерекшеліктері `StructName` құрылымы, FFI атауы болады `StructNameTraitNameMethodName`.
- Орындау үшін `field_name` өрісте `StructName` құрылымы, FFI функцияның атауы: `StructName__set_field_name`.
- алу үшін `field_name` өрісте `StructName` құрылымы, FFI функцияның атауы: `StructName__field_name`.
- Өзгерістерді алу үшін `field_name` өрісте `StructName` құрылымы, FFI функцияның атауы: `StrucuName__field_name_mut`.
- Тәуелсіздер үшін `module_name::fn_name`, Атап айтқанда FFI атауы болады `module_name::__fn_name`.
- Жалпыға бірдей емес және олардың іске асырылуын ортақтастыруға мүмкіндік беретін белгілер үшін FFI (бkz) `Clone` төмендегілер) FFI атауы болады `module_name::__clone`.

  ```rust
  impl Clone for Type1 {
      fn clone(&self) -> Self;
  }
  impl Clone for Type2 {
      fn clone(&self) -> Self;
  }
  ```
