# Жылыстардың атаулары {#naming-conventions}

Есепшоттарды, домендерді немесе активтерді атағанда Iroha қолданылатын келесі конвенцияларды есте ұстауыңыз керек:

1. Конструкциялардың белгілі бір түрлеріне арналған бірқатар бөлгіштер бар:

   - `@` тіркелгі аты-жөндері мен ауқымдағы шоттар/жалпы кілт нысандары үшін арналған
   - `#` активтерді анықтауға арналған атаулар және активтердің балансы мәтіндеріне арналған
   - `::` келісімшарт аты-жөндеріне арналған
   - `.` домендер мен деректер кеңістігінің біліктілігіне арналған
   - `$` тегiлiк түрлерiне арналған
   - `%` растаушының ауқымы бойынша мәтіндік нысандарға арналған

2. Атауында болуы мүмкін таңбалардың ең көп саны (соның ішінде UTF-8 таңбалары) екі фактормен шектеледі: `[0, u32::MAX]` және қазіргі уақытта бөлінген ұялы кеңістік.

## Taira арқылы сынап көріңіз. {#try-it-on-taira}

Қоғамдық активтердің аты-жөнін оның каноникалық активтер анықтамасы ID құрамына енгізу:

```bash
curl -fsS https://taira.sora.org/v1/assets/aliases/resolve \
  -H 'content-type: application/json' \
  -d '{"alias":"usd#wonderland"}' \
  | jq '{alias, asset_definition_id, asset_name, status: .alias_binding.status}'
```

Оны активтерді анықтау тізімімен салыстырып көрейік:

```bash
curl -fsS 'https://taira.sora.org/v1/assets/definitions?limit=20' \
  | jq -r '.items[] | select(.alias != null) | [.alias, .id, .name] | @tsv'
```

`#` таңбасы активтің аты-жөнін домен контекстінен ажыратады. Егер сіз қасақана активтердің аты-жөні немесе активтер балансын сөзбен айтқанда жазып жатсаңыз, оны жай атаулардан сақтаңыз.
