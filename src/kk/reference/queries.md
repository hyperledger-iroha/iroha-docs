# Сұраулар {#queries}

Iroha сұраулар блокчейн тіркелімінің күйін өзгеріссіз оқиды. Қазіргі деректер моделі екі негізгі сұрау түрін ұсынады:

- бір объектіні немесе бір мәнді қайтаратын дара сұраныстар
- итерацияланатын сұраулар, олар ағын немесе коллекцияны қайтарады және егер сұрау түрі рұқсат етсе, фильтрациялау, сұрыптау, проекция және беттілеу арқылы біріктірілуі мүмкін

Сұрау деректер контейнерлерін қолмен құрудың орнына SDK типіндегі құрастырғыштарды немесе CLI қолданыңыз. Төменде көрсетілген атаулар - бұл `iroha_data_model::query` арқылы ашылатын ағымдағы сұрау түрлері.

## Сүзу және беттеу {#filtering-and-pagination}

Итерленетін сұраулар предикат және селектор қолдауын көрсете алады. Фильтр енгізу сұрау шығару түріне сәйкес болатындай етіп, SDK арнайы типтелген фильтрлерді қолданыңыз. Үлкен нәтиже жиынтықтар үшін әр жолды бірден алу орнына курсор және шектеу сияқты сұрау параметрлерін пайдаланыңыз.
