# Қолданба әзірлеу {#application-development}

Iroha қосымшалары транзакция мінез-құлқын айқын көрсетуі, қол қою күйін жабық ұстауы және өндірісте бақылауға оңай болатын тәсілмен сұраулар мен оқиғаларды қолдануы керек.

## Клиентті баптау {#client-setup}

- Қолданба бастапқы кодынан тыс жерде клиент конфигурациясын сақтаңыз. Тізбек идентификаторын, Torii URL, қол қойғыш есепшотын және транзакция параметрлерін ортаға тән конфигурациядан жүктеңіз.
- Жергілікті желі, Taira, Minamoto және жеке желілер үшін `client.toml` файлдарын бөлек сақтаңыз. Көшірілген тестнет криптографиялық қолтаңбашы ешқашан негізгі желінің криптографиялық қолтаңбашысына айналмауы керек.
- Транзакцияның өмір сүру уақытын және күйдің уақытынан шығуын аңғарылған түрде орнатыңыз. Өте қысқа өмір сүру уақыты қалыпты желілік діріл кезінде аяқталуы мүмкін, ал өте ұзақ өмір сүру уақыты қайталанатын жіберулерді түсінуді қиындатады.
- Қайталаған транзакциялар әртүрлі криптографиялық хэштерге ие болуы керек болғанда ғана `nonce = true` қолданыңыз. Идемпотентті бизнес операциялары үшін қолданба сұраныс идентификаторын сақтап, қайталануларын бақылау мүмкін болатындай етіп қайта пайдаланыңыз.

Қазіргі TOML өрістерін көру үшін [Клиент конфигурациясы](/kk/guide/configure/client-configuration.md) қараңыз.

## Келісім-шарттар {#transactions}

- Мүмкін болған жағдайда таза JSON немесе жолдардан жинақталған жүктемелердің орнына терілген SDK нұсқаулардан транзакцияларды құрыңыз.
- Ұшар алдындағы маңызды жазбалар тек оқу сұраулары арқылы: аккаунттың бар-жоғын, активтер баланстарын, рұқсат күйін, алым активтерінің бар-жоғын және нысан күйін тексеру.
- Транзакцияның криптографиялық хэшін, авторизациялау негізгі есепшотын, нұсқаулық қысқаша мазмұнын және күтілетін күй өзгерісін жібермес бұрын жазып алыңыз.
- `Rejected`, `Expired` және уақыттың біту нәтижелерін әртүрлі қарастыру керек. Уақыттың бітуі клиенттің соңғы мәртебені көрмегенін білдіреді; бұл желінің транзакцияны елемегенін дәлелдемейді.
- Сәтті жазудан кейін бизнестік операцияға сәйкес сұрау немесе оқиға чекпоинті арқылы нәтижелік күйді тексеріңіз.

Транзакция механикасы үшін қараңыз [Келісім-шарттар](/kk/blockchain/transactions.md).

## Сұраулар мен оқиғалар {#queries-and-events}

- Өзгерістер туралы хабарламалар үшін ағымдағы күй және оқиғалар ағындарына сұрауларды пайдаланыңыз. Оқиғаларды өңдеуді қайталанатын кең сұраулармен алмастырудан аулақ болыңыз.
- Есепшот, актив және блок тізімдері сияқты кең ауқымды қайталанатын сұрауларды бетке бөлу.
- Жазылулар мен триггерлер үшін тар сүзгілерді таңдаңыз. Кең сүзгілер диагностикалық үшін пайдалы, бірақ қажетсіз орындау мен клиенттік өңдеуді қосуы мүмкін.
- Оқуға арналған тек тексерулерді қол қойылған транзакция тесттерінен бөлек ұстаңыз, сонда API нүктесінің қолжетімділігін анықтау оңай болады.

Қараңыз [Сұраулар](/kk/blockchain/queries.md), [Оқиғалар](/kk/blockchain/events.md), және [Сүзгілер](/kk/blockchain/filters.md).

## Агент көмегімен даму {#agent-assisted-development}

- Агенттерге транзакция кодын жазуын сұраудан бұрын құжаттарды, SDK кодын және тек оқуға арналған желі күйін тексеруге рұқсат беріңіз.
- Тірі желідегі тесттерді `TAIRA_LIVE=1` сияқты орта жалаушасының артында таңдау бойынша қалдырыңыз.
- Жеке кілттерді, есептік жазбаны қалпына келтіру материалдарын, API токендерін немесе алдыңғы рұқсат тақырыптарын сұрауларға қоймаңыз.
- Кез келген агент тікелей тест желісіне транзакция жібермес бұрын транзакция жоспарын талап етіңіз. Жоспарда желінің атауы, рұқсат ету субъектісі, нұсқаулар, төлем активі, алдын ала оқулар, күтілетін нәтиже және қайтадан әрекет ету тәртібі көрсетілуі керек.

Taira MCP жұмыс ағыны үшін [SORA 3: Taira және Minamoto негізінде құрыңыз](/kk/get-started/sora-nexus-dataspaces.md#taira-mcp-for-agents) қараңыз.

## SDK Гигиена {#sdk-hygiene}

- [Сәйкестік матрицасы](/kk/reference/compatibility-matrix.md) пайдаланып, PIN SDK және екілік нұсқаларды бірге қосыңыз.
- Жасалған клиент коды, фрагменттері және мысалдарын бекітілген жоғарғы деңгейдегі жұмыс кеңістігінің нұсқасымен синхронда ұстаңыз.
- Транзакция құру кодына арналған бірлік тесттерін және қосымшаңыз тәуелді ең кіші оқу және жазу жолдарына арналған интеграциялық тесттерді қосыңыз.
