# SDK Оқулықтар {#sdk-tutorials}

Бұл беттер негізгі жұмыс кеңістігінен жіберілген Iroha 3 клиенттің кіру нүктелерін, соның ішінде бір протокол-стандартты пакет атауларын, орнату жолдарын және минималды бастау нүктелерін қысқаша сипаттайды.

## Ұсынылатын реттік {#recommended-order}

1. [Iroha 3 орнатыңыз](/kk/get-started/install-iroha.md)
2. [Жіберу Iroha 3](/kk/get-started/launch-iroha.md)
3. Таңдаңыз SDK:
   - [Rust](/kk/guide/tutorials/rust.md)
   - [Python](/kk/guide/tutorials/python.md)
   - [JavaScript / TypeScript](/kk/guide/tutorials/javascript.md)
   - [Kotlin, Android, және Java](/kk/guide/tutorials/kotlin-java.md)
   - [Swift және iOS](/kk/guide/tutorials/swift.md)
4. Толық клиенттік қосымшаның анықтамасын қажет етсеңіз, [мысал қолданбалар](/kk/guide/tutorials/sample-apps.md) қараңыз.
5. Өз қолданбаңызға әмиянмен қамтамасыз етілген аудио/видео кездесулерді қосқыңыз келгенде [Орнату Kaigi](/kk/guide/tutorials/kaigi.md) пайдаланыңыз.
6. Қайта қолдануға болатын Kotodama бастапқы кітапханаларға қажет болғанда тізімге тіркелген блокчейн тәуелділіктерімен бірге [Musubi қаптамалар](/kk/guide/tutorials/musubi.md) қолданыңыз.

## Үлгілер {#samples}

Жоғарыдағы жұмыс кеңістігінде JavaScript рецептер және Swift/iOS үлгі жобалары бар. Android үшін Kotlin SDK модульдері мен олардың тесттерінен бастаңыз.

- [Үлгі қосымшаларға шолу](/kk/guide/tutorials/sample-apps.md)
- [JavaScript қосымшасында Kaigi кірістіру](/kk/guide/tutorials/kaigi.md)

## Шындықтың көзі {#source-of-truth}

Мұндағы барлық SDK беттер ағымдағы жоғары ағысты жұмыс кеңістігінен алынған:

- `crates/iroha`
- `python/iroha_python`
- `javascript/iroha_js`
- `kotlin`
- `java/iroha_android` (Kotlin-бірінші Android бетінің Java айнасы)
- `IrohaSwift`
- `crates/musubi`

Күмәндансаңыз, сол каталогтардағы README және пакет метадеректерін таңдаңыз; олар сіздің құрып жатқан дереккөз ревизияңызды сипаттайды.
