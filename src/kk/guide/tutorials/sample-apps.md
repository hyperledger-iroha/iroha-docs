# Үлгілер мен рецепттер {#samples-and-recipes}

Iroha дерекқорында түйінмен бірдей нұсқаны бақылайтын SDK рецептер мен тест жинақтары бар.

## JavaScript Рецептер {#javascript-recipes}

[`javascript/iroha_js/recipes`](https://github.com/hyperledger-iroha/iroha/tree/c8c872461e92f04325c350cdd952f4276e96f9dc/javascript/iroha_js/recipes) анық транзакциялық топтастыру үшін бағытталған мысалдарды қамтиды, SORA Nexus қосымша аударымдары, NFT және есептік қайталау, ISO көпір ағады, және Torii ағынды тарату. Әрбір рецепт оның офлайн жұмыс істейтінін немесе тікелей қажет екенін көрсетеді Torii API соңғы нүкте.

## Swift және iOS {#swift-and-ios}

Қазіргі Swift SDK бойынша тексерілген мысалдар үшін `IrohaSwift/Tests/IrohaSwiftTests` пайдаланыңыз. Пакет пен көпірді орнату үшін [Swift және iOS](/kk/guide/tutorials/swift.md) қараңыз.

## Android {#android}

Жаңа Android жұмысына [Kotlin, Android, және Java](/kk/guide/tutorials/kotlin-java.md)-те сипатталған Kotlin-бірінші `core-jvm`, `client-android`, және `kagemusha-wallet-android` модульдерді пайдаланыңыз. Kotlin SDK Android тұтынушылары үшін бірегей протокол-стандартты бастапқы нүкте болып табылады.
