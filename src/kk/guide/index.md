# Кіріспе {#guide}

Бұл бөлімді Iroha арқылы құру, пайдалану немесе интеграциялау кезінде пайдаланыңыз. Бірінші клиент үшін SDK оқулықтарымен бастаңыз, содан кейін ортақ желіге қарсы іске асырудан бұрын үздік тәжірибелер мен оператордың анықтамаларына өтуіңіз керек.

## Бөлімдер {#sections}

|Бөлім |Оны пайдаланыңыз .|
| ------------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------- |
| [SDK Оқушылар](/kk/guide/tutorials/) |Тілге арналған клиент орнату және қолданба үлгісі |
| [Ең жақсы тәжірибелер](/kk/guide/best-practices/) |Өндіріске, іске асыруға, операцияларға, қауіпсіздікке және шығарылымдарға арналған өндірістік нұсқаулық |
| [Конфигурация және басқару](/kk/guide/configure/overview.md) |Жергілікті теңгерімдік конфигурация, генезис, клиент конфигурациясы, кілттер және теңгерімді басқару |
| [Қауіпсіздік](/kk/guide/security/)|Кілттерді басқару, операциялық қауіпсіздік, VPNs, алдамшылықтарды бақылау және рұқсат беру гигиенасы |
| [Уақытша операциялар](/kk/guide/advanced/metrics.md) |Метрикалар, өнімділік тексерулері, хаос сынаулары, ыстық қайта жүктеу және жалаңаш металл жұмыс істеу |

## Ұсынылған жол {#recommended-path}

1. [Iroha 3](/kk/get-started/install-iroha.md) және [ жергiлiктi желiн іске қосу ](/kk/get-started/launch-iroha.md).
2. [SDK оқу құралын таңдаңыз](/kk/guide/tutorials/) және шағын транзакцияны тапсырыңыз.
3. Тексеру [Қолданбаларды әзірлеу](/kk/guide/best-practices/application-development.md) және [Деректерді модельдеу](/kk/guide/best-practices/data-modeling.md) өтiнiш жасалмас бұрын API.
4. Пайдалану [Желіде іске асыру](/kk/guide/best-practices/network-deployment.md), [Операциялар](/kk/guide/best-practices/operations.md), және [Қауіпсіздік және қол жеткізу](/kk/guide/best-practices/security-and-access.md) ортақ немесе өндірістік желілерді іске қосудан бұрын.
5. Жергiлiктi дамудан Taira, Minamoto немесе басқа да тiкелей орналастыруға жылжыту кезiнде [Release Readiness](/kk/guide/best-practices/release-readiness.md)-ды орындаңыз.
