## Файлдар {#files}

Жоғарыдағы репозиторий `defaults/genesis.json` мекенжайында әдепкі техникалық манифесті жеткізеді. Kagami-генерацияланған желілер өздерінің техникалық манифестін және қол қойылған транзакциясын шығыс каталогына жазады:

```bash
cargo run --bin kagami -- localnet --peers 4 --out-dir ./localnet
```

Сол каталогта жасалған `README.md` таңдалған профиль үшін нақты файлдар мен іске қосу командаларын тіркейді.

## торап әріптесін баптау {#peer-configuration}

желі әріптестері `config.toml` бөліміндегі `[genesis]` жерде қол қойылған блокчейн генезис транзакциясын көрсетеді:

```toml
[genesis]
file = "./genesis.signed.nrt"
public_key = "ed0120..."
```

Желідегі барлық желілік түйіндер қол қойылған блокчейннің бастапқы транзакциясы мен блокчейннің бастапқы ашық кілті бойынша келісуі қажет.

## Блокчейн генерациясын қол қою {#signing-genesis}

Егер сіз техникалық манифесті қолмен өңдесеңіз, желі серіктестерін бастамас бұрын оны тексеріп, қол қойыңыз:

```bash
cargo run --bin kagami -- genesis validate ./genesis.json
cargo run --bin kagami -- genesis sign ./genesis.json \
  --private-key-file "$GENESIS_PRIVATE_KEY_FILE" \
  --out-file ./genesis.signed.nrt
```

`GENESIS_PRIVATE_KEY_FILE` иеленуші ұстаған режим-`0600`, бір ғана протокол стандартты жеке кілт мультихешін және соңғы жаңа жолды қамтитын бір сілтемелі тұрақты файл болуы керек. Kagami символдық сілтемелерді қабылдамайды және командалық жолда ешқашан таза блокчейн генезис жеке кілтін қабылдамайды.

NPoS немесе Nexus профильдері үшін, жасалған профиль талап ететін топологияны және BLS Құралым-Дәлелдерді қоса көрсетіңіз. Kagami `localnet`, `wizard` және профиль жасау командалары бұл мәліметтерді автоматты түрде өңдейді.

## Блокчейннің бастамасын қайта міндеттеу {#recommitting-genesis}

Желідегі серіктес өз сақтауы бос болғанда ғана блокчейннің генезисін аяқтайды. Жаңа блокчейн генезисін қолданылған жергілікті желіде тексеру үшін, желідегі серіктестерді тоқтатыңыз, олардың жасалған күй каталогын жойып, жаңа қол қойылған блокчейн генезисінен бастаңыз. Егер барлық валидатор бірдей көші-қонды үйлестірмейтін болса, жұмыс істеп тұрған желідегі блокчейн генезисін алмаңыз.
