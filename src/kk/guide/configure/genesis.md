# Жаратылыс {#genesis}

Genesis бастапқы тізбек күйін анықтайды.Өңделетін дереккөз а JSON манифест,
және а Iroha 3 түйін қолтаңбаны тұтынады Norito транзакция файлы.

## Файлдар {#files}

Жоғарғы репозиторий әдепкі манифестті жібереді `defaults/genesis.json`.
Kagami-құрылған желілер өздерінің манифесті мен қол қойылған транзакцияға жазады
шығыс каталогы:

```bash
cargo run --bin kagami -- localnet --peers 4 --out-dir ./localnet
```

Жасалған `README.md` сол каталогта нақты файлдарды жазып, іске қосады
таңдалған профильге арналған пәрмендер.

## Бірдей конфигурациясы {#peer-configuration}

Құрдастары қол қойылған генезистік транзакцияны көрсетеді `[genesis]` бөлімі
`config.toml`:

```toml
[genesis]
file = "./genesis.signed.nrt"
public_key = "ed0120..."
```

Желідегі барлық әріптестер қол қойылған генезистік транзакция мен келісім бойынша келісуі керек
генезистің ашық кілті.

## Жаратылыс кітабына қол қою {#signing-genesis}

Егер манифестті қолмен өңдесеңіз, әріптестерді бастамас бұрын оны тексеріп, қол қойыңыз:

```bash
cargo run --bin kagami -- genesis validate ./genesis.json
cargo run --bin kagami -- genesis sign ./genesis.json \
  --private-key-file "$GENESIS_PRIVATE_KEY_FILE" \
  --out-file ./genesis.signed.nrt
```

`GENESIS_PRIVATE_KEY_FILE` иесінің режимі болуы керек`0600`, бір буынды
бір канондық жеке кілтті мультихэш пен финалды қамтитын қалыпты файл
жаңа жол. Kagami символдық сілтемелерді жоққа шығарады және ешқашан шикі генезистік жекені қабылдамайды
пәрмен жолындағы пернені басыңыз.

NPoS үшін немесе Nexus профильдер, топологияны қамтиды және BLS Иелік куәлігі
жасалған профиль талап етеді. Kagami `localnet`, `wizard`, және профиль
генерациялау командалары бұл мәліметтерді автоматты түрде өңдейді.

## Жаратылыс кітабын қайталау {#recommitting-genesis}

Сақтау орны бос болғанда ғана тең генезис жасайды.Жаңа генезисті сынау үшін
бір реттік жергілікті желі, құрдастарды тоқтатыңыз, олардың жасалған күй каталогын жойыңыз,
және жаңа қол қойылған генезистен бастаңыз.Жүгіру кезінде генезисті ауыстырмаңыз
егер әрбір валидатор бірдей тасымалдауды үйлестірмесе, желі.
