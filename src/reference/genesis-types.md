# Genesis Types

A genesis manifest is the JSON form of a
[`RawGenesisTransaction`](#rawgenesistransaction). This reference lists that
type and every type it contains, generated from the pinned Iroha source. For
every ledger type, fetch your node's schema as described in the
[data model schema](/reference/data-model-schema.md) reference.
