# Iroha 3 {#iroha-3}

Iroha 3 は,最初のリリースである Hyperledger Iroha プラットフォームです. これは単一の決定的なコードベースから自主ホストされたネットワークとマルチデータスペース (multi-data space) の SORA Nexus 展開モデルをサポートします.

高いレベルでは, Iroha 3 は:

- 決定的な実行と保管
- Iroha 携帯スマート契約のための仮想マシン (IVM)
- Norito は,法典的なワイヤル形式として
- Torii クライアント,オペレーター,およびアプリ面向する APIs
- Sumeragi 強制的なデータ利用性と信頼性の高い放送との合意
- 人に読める異名詞を別々に結合したドメインレス・カノニカルアカウント
