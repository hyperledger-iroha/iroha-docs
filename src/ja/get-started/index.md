# Iroha 3 {#iroha-3}

Iroha 3 は初回リリースの Hyperledger Iroha プラットフォームです。自己ホスト型ネットワークおよび単一の決定的なコードベースからのマルチデータスペース SORA Nexus デプロイメントモデルをサポートします。

大まかに言うと、Iroha 3 は次のものを組み合わせています：

- 決定論的な実行と保存
- ポータブルスマートコントラクトのための Iroha 仮想マシン (IVM)
- Norito を正規のシリアライズ形式として
- Torii クライアント、オペレーター、アプリ向け APIs
- Sumeragi 必須のデータ可用性と信頼できるブロードキャストを伴うコンセンサス
- ドメインなしの正規アカウントと、別々に紐付けられた人間が読めるエイリアス
