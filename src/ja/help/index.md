# サポートを受ける {#receive-support}

時々、Iroha について詳しく他の人と話し合いたいと思うことがあるかもしれません。私たちのコミュニティとすぐに連絡を取る方法は、Telegram、Discord、そして GitHub の3つあります。

コミュニティはコミュニケーションのために[テレグラム](https://t.me/hyperledgeriroha)と[LF Decentralized Trust Discord](https://discord.gg/hyperledger)を使用します。プロジェクトに関する質問は`iroha`チャンネルを使用してください。

最後に、ドキュメントの更新依頼であれ、コアチームへの提案であれ、見つけたバグであれ、あなたは[GitHub の問題を作成する](https://github.com/hyperledger-iroha/iroha/issues/new/choose)できます。
