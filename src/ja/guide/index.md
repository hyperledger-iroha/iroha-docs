# ガイド {#guide}

Iroha を構築,運用または統合する際はこのセクションを使用します.最初のクライアントのための SDK チュートリアルから始め,共有ネットワークに対して展開する前にベストプラクティスとオペレーター参照に移ります.

## セクション {#sections}

|セクション|使うよ|
| ------------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------- |
| [SDK チュートリアル](/ja/guide/tutorials/) |言語特有のクライアント設定とサンプルアプリケーション|
| [最良の実践](/ja/guide/best-practices/) |開発,データモデリング,部署,運用,セキュリティ,リリース準備によってグループ化された生産指針|
| [構成と管理](/ja/guide/configure/overview.md) |ローカルピア・コンフィギュレーション,生成,クライアントのコンフィギューレーション,キー,ピア・マネジメント|
| [安全性](/ja/guide/security/) |VPNs,詐欺監視,許可衛生 |
| [高度な操作](/ja/guide/advanced/metrics.md)|メトリックス 性能チェック 混沌テスト 熱再充電 裸金属操作 |

## 推奨された道 {#recommended-path}

1. [インストール Iroha 3](/ja/get-started/install-iroha.md) そして [ローカルネットワークを起動する](/ja/get-started/launch-iroha.md).
2. [SDK のチュートリアル](/ja/guide/tutorials/)を選択して,小さな取引を提出します.
3. レビュー [応用開発](/ja/guide/best-practices/application-development.md) そして [データモデリング](/ja/guide/best-practices/data-modeling.md) 申請書の作成前に API.
4. 共有または生産ネットワークを実行する前に [ネットワーク部署](/ja/guide/best-practices/network-deployment.md), [オペレーション](/ja/guide/best-practices/operations.md),および [セキュリティとアクセス](/ja/guide/best-practices/security-and-access.md)を使用します.
5. 地元の開発から Taira,Minamoto,または他のライブ展開に移行する際に [Release Readiness](/ja/guide/best-practices/release-readiness.md)をフォローします.
