# 応用開発 {#application-development}

Iroha アプリケーションは,トランザクション行動を明示し,署名状態を保持し,クエリやイベントを生産で容易に観察できる方法で使用すべきである.

## クライアントの設定 {#client-setup}

- アプリケーションのソースコードの外にクライアント設定を保存します.環境特有の構成からチェーン ID, Torii URL,サインアカウント,トランザクション設定を読み込みます.
- `client.toml` ファイルをローカルネット, Taira,Minamoto,およびプライベートネットワークに別々に保管します.コピーされたテストネット署名者は決してメインネット署名者になることはありません.
- トランザクションライフタイムとステータスタイムアウトを意図的に設定する.非常に短い寿命は通常のネットワーク緊張下で終了し,非常に長い時間は複製された送信を推論するのが困難になる可能性があります.
- `nonce = true` は,繰り返し取引が異なるハッシュを持つ場合のみ使用する.無効なビジネス操作では,アプリケーションリクエスト ID を保存し再利用するので,再試行は追跡可能である.

現在の TOML フィールドについては,[クライアント設定](/ja/guide/configure/client-configuration.md)を参照してください.

## 取引 {#transactions}

- 可能な限り,原材料 JSON または文字列で組み立てられた有用な負荷ではなく,入力された SDK 指示からトランザクションを作成します.
- プレフライト・インフォントは読み込みのみのクエリ:アカウントの存在,資産バランス,許可状態,料金の資産利用可能性,ターゲットオブジェクト状態で記述します.
- 送信する前にトランザクションハッシュ,権限アカウント,指示概要,および予想される状態変更を記録します.
- `Rejected`, `Expired`を扱って,タイムアウトの結果は違います. タイムアウトとはクライアントが最終的な状態を見ていないことを意味し,ネットワークが取引を無視したことを証明するものではありません.
- 成功した書き込み後,ビジネス操作に一致するクエリまたはイベントチェックポイントで結果の状態を確認します.

取引メカニズムについては, [トランザクション](/ja/blockchain/transactions.md)を参照してください.

## 疑問と出来事 {#queries-and-events}

- 変更通知では,現在の状態とイベントストリームのクエリを使用します. イベント処理を繰り返される幅広いクエリで置き換えるのを避ける.
- アカウント,資産,ブロックリストなどの広範なリターン可能なクエリをページにまとめます.
- サブスクリプションとトリガーの場合は狭いフィルタが好ましい. 広いフィルターは診断に役立つが,不必要な実行やクライアント側処理を追加することができます.
- エンドポイントの可用性診断が容易になるように,読みに限定された煙検査を署名したトランザクションテストから別にしておく.

[質問](/ja/blockchain/queries.md), [イベント](/ja/blockchain/events.md),および [フィルター](/ja/blockchain/filters.md)を参照.

## 代理人支援開発 {#agent-assisted-development}

- SDK コードと 読み込みのみのネットワーク状態を ドックスをチェックして 取引コードを書くように頼む前に
- `TAIRA_LIVE=1`などの環境フラッグの後ろにライブネットワークテストを選択してください.
- API トークン,または転送された著作権ヘッダを提示に貼ってはいけません.
- エージェントがライブテストネット取引を提出する前に,トランザクションプランを要求する.このプランにはネットワーク,権限,指示,料金の資産,フライト前読み込み,予想結果,再試行動の名前が必要である.

Taira MCP のワークフローについては, [Build on SORA 3: Taira と Minamoto](/ja/get-started/sora-nexus-dataspaces.md#taira-mcp-for-agents)を参照してください.

## SDK {#sdk-hygiene}

- ピン SDK とバイナリバージョンは,互換性マトリックス [を使用して一緒に使用する](/ja/reference/compatibility-matrix.md).
- 作成されたクライアントコード,スニッペット,例をアップストリームワークスペースリビジョンと同期する.
- トランザクション構築コードのユニットテストと,アプリケーションが依存する最小の読み書き経路のための統合テストを追加します.
