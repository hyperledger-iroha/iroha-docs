# セキュリティ {#security}

Iroha または他のブロックチェーンのレジを活用する際には 金融機関にとってセキュリティは極めて重要です それは敏感な金融データと取引が日常的に行われている業界における信頼の基盤を形成しているからです悪意のある当事者による安全侵害が成功すると,あなたにとって壊滅的な結果をもたらす可能性があります.したがって,あなたの敏感なデータの誠実さと機密性を保護するために予防的セキュリティ対策を確立することが不可欠です.

### 航行 {#navigation}

このセクションでは Iroha ネットワークのセキュリティに関する様々な側面について学びます.詳細を学ぶために,以下のテーマの一つを選択してください.

- [安全原則](./security-principles):

個人や組織が個人データを保護し,漏洩のリスクを減らすために採用できる基本的なセキュリティ原則.

- [仮想プライベートネットワーク](./vpn.md):

VPN を利用してピアツーパー, Torii,および個人またはコンソーシアム部署におけるオペレーターのアクセスを制限する方法.

- [運用安全](./operational-security.md):

アクセス制御,モニタリング,インシデント対応,ブラウザの使用などを含むネットワークの日常操作を安全にするための最善の実践

- [詐欺監視](./fraud-monitoring.md):

疑いのある活動を検知し,応答証拠を保存するために レジ事件,クエリ,許可,および運用信号を使用する方法

- [パスワードセキュリティ](./password-security.md):

パスワードのエントロピーに深く潜り 強力なパスワードを作成し パスワード脆弱性を回避します

- [公開鍵暗号化](./public-key-cryptography.md):

公開鍵暗号化,暗号化,署名とブロックチェーン内の安全な通信を確立する役割への導入

  - [暗号鍵を生成する](./generating-cryptographic-keys.md):

暗号鍵の生成と使用方法に関する説明書 `kagami` (Iroha と共に発送されたサポートツール).

  - [暗号鍵の保存](./storing-cryptographic-keys.md):

暗号鍵のセキュリティに関するベストプラクティスは,複数の異なるアプローチで組み合わせることもできます.
