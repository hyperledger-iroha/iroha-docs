# 公開鍵暗号化 {#public-key-cryptography}

公钥暗号化は,安全な通信とデータ保護のための手段を提供し,オンライン取引の安全性,暗号化された電子メール通信などの活動を可能にします.

パブリックキー暗号化は,オンラインネットワークを通じて情報を送信する非常に安全な方法を作成するために,パブリックキーとプライベートキーを2つの暗号鍵を使用します.

プライベートキーから公開鍵を作るのは簡単ですが,その逆はかなり難しいです.それは不可能ではありません.これは物事を安全に保つのです.私钥を危険にさらさずに自由に公開鍵を共有することができます.

## 暗号化と署名 {#encryption-and-signatures}

公钥暗号化は,個人によって暗号化されたメッセージとデータを送信することが可能であり,それに対応するプライベートキーを保有する意図された受信者がのみ解読できる.言い換えれば,公開鍵はロックとして機能し,プライベート鍵は暗号化されたデータを解き放す 独自の鍵として機能します.

この暗号化プロセスは,敏感な情報のプライバシーと機密性を確保するだけでなく,送信者の認証も確立します.送信者のプライベートキーと公開鍵を組み合わせることで,デジタル署名が作成されます.この署名は,送信者の身分と転送されたデータの有効性を確認するデジタル承認章として機能します. 公開鍵を持っている人は誰でも,取引を開始した人があなたのプライベートキーを使用していたことを確認できます.

## 顧客側にある鍵 {#keys-on-the-client-side}

すべての取引はアカウント当局によって署名されなければなりません.その機関のためのプライベートキーまたはコントローラー資料は秘密のままに保持されなければならないので,クライアントソフトウェアは安全なストレージとサインの責任を負います.

::: 警告

すべてのクライアントは異なるが,平文クライアントの構成は開発および制御テストネットワークのみに適している.生産統合には秘密マネージャー,ハードウェアサポートされたキーストレージ,または他の監査された署名境界を使用する必要があります.

:::

新しいアカウントの登録には,Ed25519キーペアなどのコントローラー資料を生成し,公開部分をネットワークに送信する必要があり,そのアカウントからの後の取引は,対応したプライベートキーまたは設定されたアカウントコントローラーポリシーによって署名する必要があります.

公開鍵の暗号化が有効に機能するためには 新しい鍵を指定する必要があるときに再利用する鍵を避ける必要があります.それを行うのを止めることは何もありませんが,公開鍵は公開です. つまり攻撃者が同じ公開鍵が使用されていることを見ると,密钥も同じだと知ることになるでしょう

密钥はパスワードとは少し異なる原則に基づいているが,できるだけランダムにするためのアドバイスは適用されます. 決して暗号化されていない状態で保存し,いかなる状況下でも誰にも共有しないでください.
