# 安全原則 {#security-principles}

Iroha 装置との安全な相互作用を確保するために組織と個々のユーザが協力する必要がある.このトピックでは,この協力を裏付ける基本的な原則を説明します.

## 一般的な安全原則 {#general-security-principles}

1. A を使用する [仮想プライベートネットワーク](./vpn.md) (VPN):

    - 敏感なデータやリソース,特に公共ネットワークを通じてアクセスするときは,あなたの情報を保護する安全な接続を確立するために <abbr title="Virtual Private Network">VPN</abbr>を使用してください.

2. ネットワーク保護のためにファイアウォールを使用します:

    - ファイアウォールを設置することで家庭および/またはオフィスネットワークを強化し,不正アクセスを防止し,接続されたデバイスをウイルスやマルウェアから保護します.

3. 物理的およびデジタル情報のセキュリティ:

    - 機密情報を含む物理文書を安全な場所に保管し,デジタル文書が暗号化されパスワードで保護されたフォルダーに保存されることを確保する.

4. データを定期的にバックアップする

    - 重要な情報のコピーを常に安全な場所に保存してください. このようにして,データが失われるか何かが間違っている場合は,すぐにすべてを再現できます. これらのバックアップは通常データを保管している場所から別の安全な場所に保持します.

## 個人 用人 の 安全 原則 {#security-principles-for-individual-users}

1. 強力な認証ルールを採用する:

    - すべてのアカウントに強力な,ユニークなパスワードを使用してください.

    - パスワードを二度と使わないでください.

    - 可能な限り <abbr title="Two-Factor Authentication">2FA</abbr> を設定します. <abbr title="Two-Factor Authentication">2FA</abbr> はパスワードだけでなく, <abbr title="One-Time Password">OTP</abbr>,指紋,または第三者のアプリベースの認証 (例えばGoogle Authenticator) のような追加要素によって全体的なセキュリティを改善します.

    - SMS 認証を第二の要因として使用することを避けましょう.悪意のあるソフトウェアがすべての SMS メッセージを監視していないという保証はありません.例えば, Android アプリケーションは,それらのために特別に意図されたメッセージのみにアクセスすることに限定されることはできません.

2. デジタル通信における注意を図る: - 受信されたすべてのメールの署名と検証のための電子メールクライアントを設定する.送信者の住所を偽装したり,銀行として振る舞うことも可能であるが,署名を偽造することは不可能です.- HTML メッセージと外部リソースを未知または検証されていないアドレスから読み込みの両方を無効にします.

    - 疑わしいメールやリンク,個人情報の要求を認識し回避するための一般的なフィッシング技術について学びましょう.

    - 受け取ったすべてのメールの署名を確認するための電子メールクライアントを設定します. 送信者の住所を偽装し 銀行としてさえ振る舞うことは可能ですが サインを偽造することはできません

3. 個人情報の保護:

    - 知らない 人 と,特に 電話 や インターネット で コミュニケーション を する 時,私 的 な 情報 を 共有 する こと に 注意 し て い ます.

    - 通信する個人や組織を独立して調査し その人格の正当性を確認してください.

    - ソーシャルメディアで共有する個人情報については注意してください.悪意のある当事者がこの情報を利用できるからです.

## 組織のための安全原則 {#security-principles-for-organisations}

1. 明確なセキュリティポリシーと手続きを確立する:

    - 繊細なデータに対応するすべての従業員のためのよく定義されたセキュリティポリシーとプロトコルを開発し,これらのガイドラインに準拠することを徹底的に訓練し,怠慢のリスクを軽減します.

    - セキュリティポリシーがすべての従業員に利用可能であり,変化する安全保障環境を反映するために定期的にレビューおよび更新されることを確保します.

    - セキュリティポリシーに例やシナリオを提示し,従業員にとってより理解可能で実行可能なようにする.

2. 従業員の意識を高める:

    - 従業員にデータ及び運用安全対策について教育する.組織安全保障を強化するために,より高い意識と包括的な訓練が不可欠です.

    - 従業員に,疑わしい活動やセキュリティ上の懸念を直ちに報告するよう促してください.

3. 物理的なインフラを保護する

    - サーバーやインフラへの物理的なアクセスを制限する. 許可を受けた職員のみが制限された領域に入ることを許すアクセス制御を設定する.

    - アクセス制御の措置が定期的に検討され,セキュリティーニーズに合わせて更新されることを確保する.

    - 物理的な安全性を高めるため,敏感な領域にバイオメトリックのアクセス制御を導入することを検討する.

4. セキュリティモニタリングを展開する

    - 活動を徹底的に調査し,潜在的なセキュリティ侵害を特定する包括的なセキュリティモニタリングシステムを執行すること.

    - 自動警報を導入し,安全職員に異常なまたは許可のない活動について直ちに通知する.

    - 機械学習アルゴリズムを使用して,異常や潜在的な脅威を検出するシステムの能力を向上させる.

    - データベースのセキュリティを監視し,ソフトウェアの脆弱性を特定し,追跡し,対処し,承認されたリストに含まれていない未認可ソフトウェアの存在を批判的なマシンで定期的にチェックするスタッフまたは指定したスタッフを雇う.

5. 定期的なセキュリティ監査を実施する:

    - 脆弱性を評価し,既定のセキュリティ対策が一般に受け入れられた基準と規制に適合していることを確認するために定期的な安全監査を実施する.

    - 組織の安全状況について公正な評価を得るために 定期的にセキュリティ専門家を雇うことを検討します

6. アクセス制御システムを導入する:

    - 職務に基づくアクセス制御システムを設置し,従業員が職務に必要なリソースと情報のみにアクセスできるようにします.

7. 継続 的 な 改善 を 受け入れる:

    - セキュリティは継続的なプロセスであることを認識するセキュリティ対策の継続的な評価を維持し,新たな脅威と課題に対処するために積極的に強化する.

    - 継続的な改善の文化を育むように,従業員がセキュリティを改善するための提案を提供することを奨励するフィードバックループを構築することを検討してください.
