# Norito {#norito}

Norito ነው Iroha ይህ የካኖኒካል ተከታታይነት ንብርብሮች ነው.
እኩዮችም ሲኾኑ፣ SDKs, CLI መሳሪያዎች፣ Torii, Kura, የተፈጠሩ ጥንታዊ ዕቃዎችም ተስማምተው መስማማት አለባቸው
በትክክል ተመሳሳይ ጥቅማጥቅሞች ላይ.

አጠቃቀም Norito መረጃው የስምምነት፣ የምስክር ወረቀት መፈረም፣ ሃሽ ማድረግ፣ መቋቋም፣
ወይም መስቀል-SDK መስተጋብር። JSON አንድ መጨረሻ ነጥብ በግልጽ
ለኦፕሬተሮች፣ ዳሽቦርዶች ወይም ፈጣን ማረም የሚቻል የሰው ሊነበብ የሚችል ፕሮጀክት።

## የደረጃ ባንዲራዎች {#layout-flags}

Norito የመጨረሻው ራስጌ ባይት ውስጥ አቀማመጥ ምርጫዎች ያስቀምጣል.
ማሰራጨት `COMPACT_LEN` (`0x02`) ለኮምፓክት በዋጋ ርዝመት ቅድመ-እይታዎች
ቋሚ ስፋት ርዝመት ቅድመ ቅጂዎች ጠሪዎች ኮድ ጊዜ ሊነበብ ይቀጥላል
`flags = 0x00`.

| --- | ---: | --- | --- |
| `PACKED_SEQ` | `0x01` | የተደገፈ | ተለዋዋጭ መጠን ያላቸው ስብስቦችን ከኦፕሴት ሰንጠረዥ እና ከአጠገብ ያለው የመረጃ ብሎክ ጋር ያካትታል. |
| `COMPACT_LEN` | `0x02` | ነባሪ | በዋጋ ርዝመት ቅድመ-እርምጃዎች ላይ ካኖኒካል ያልተፈረሙ ቀለበቶችን ይጠቀማል. |
| `PACKED_STRUCT` | `0x04` | የተደገፈ | ኮዶች የተገኙት-የተፈጠረ structs እንደ የታሸጉ የመስክ ጥቅማጥቅሞች. |

| `FIELD_BITSET` | `0x20` | መስፈርቶች ድጋፍ | የተሸፈኑ አሠራሮች አንድ ቢት ስብስብ ይጨምራል ስለዚህ ግልጽ መጠኖች የሚያስፈልጋቸው መስኮች ብቻ መጠን ቅድመ ማስያዣዎችን ይይዛሉ. `PACKED_STRUCT` እና `COMPACT_LEN`. |

ባንዲራዎቹ ግልፅ ናቸው። ዲኮደሮች አቀማመጥን ከጠቅላላ ጭነት ቅርጽ አይወስኑም
የማይታወቁ ወይም ልክ ያልሆኑ ጥምረት ውድቅ ናቸው
ሁሉም እኩዮች አንድን ሸክም በተመሳሳይ መንገድ ይተረጉማሉ።

## የኮዲንግ ደንቦች {#encoding-rules}

Norito ውስጥ የሚታዩትን የተለመዱ የመረጃ ቅርጾችን ለዲተሪሚኒስት አቀማመጦች ይጠቀማል
የ Iroha የመረጃ ሞዴል

- ገመዶች ናቸው `[len][utf8-bytes]`; `len` የሚከተለው ነው `COMPACT_LEN` የሚቻል ከሆነ።
- በዋጋ መጠን ርዝመቶች ውስብስብ ቫሪንቶችን ይጠቀማሉ `COMPACT_LEN` ተዘጋጅቷል፣ አለበለዚያ
  ቋሚ 8-ባይት ትንሽ-አንድያን `u64`.
- ቅደም ተከተል ርዝመት ራስጌዎች ቋሚ ናቸው 8-ባይት ትንሽ-የተለጠፈ `u64` በ v1.
- `Vec<u8>` እንደ `[len_u64][raw-bytes]` በአንድ ባይት አንድ ርዝመት ይልቅ።
- የታሸጉ ቅደም ተከተል አጠቃቀም `(len + 1)` አሰልቺ `u64` የሽያጭ ክፍያዎች
  የተጣራ ቁሳቁስ ጥቅማጥቅሞች።
- ካርታዎች ቋሚ ጋር የመግቢያ ቁጥሮች ይኮድ `u64` እና ተወስኖ ቁልፍ ቅደም ተከተል ይጠቀሙ.
  `HashMap` መዝገቦቹ ከመቀየራቸው በፊት ቁልፉ መሠረት ይደረጋሉ። `BTreeMap` ይጠቀማል
  ተፈጥሯዊ ሥርዓት።
- `BigInt` አነስተኛ-ኢንዲያን ሁለት-የተሟላ ባይት ይጠቀማል `u32` የባይት ርዝመት
  እና 512 ቢት ካፕ.
- `Numeric` እንደ `(mantissa, scale)`, ማንቲሳው
  የጠቅላላው እሴት እና መጠነ-ሰፊው የአንፃራዊ አሃዞችን ብዛት ያስቀምጣል።

እነዚህ ደንቦች ለፊርማዎችና ለሃሽስ አስፈላጊ ናቸው። SDKs ተመሳሳይ ነገር የሚገነቡ
ምክንያታዊ ግብይቱ ተመሳሳይ የካኖኒክ ባይት ማምረት አለበት።

## የቅጥያ ሃሽስ {#schema-hashes}

የተጻፈ Norito ጥቅማጥቅሞች በዕውቀት ውስጥ 16-ባይት ስክሪም ሃሽ ይይዛሉ.
ሃሽ ከሙሉ በሙሉ ብቁ የሆነ የታይፕ ስም የተገኘ ነው።
መዋቅራዊ መርሃግብር ሃሽንግ በምትኩ ከካኖኒካል መርሃ ግብር ሃሽ ያመነጫል።

የተዘጋጁት ዲኮደሮች የሥርዓቱን አለመጣጣም ይክዳሉ። ይህ ደንበኞችን ከድንገት
ትክክለኛውን Norito ክፈፍ እንደ የተሳሳተ አይነት እና የተለመደው አለመሳካት ሁነታ ነው
አንድ ጊዜ SDK የአሳታሚው ክምችት ከቆንጆ መረጃ ሞዴል ይለወጣል።

## መጭመቂያ እና ፍጥነት {#compression-and-acceleration}

Norito ምክንያታዊውን ሳይቀይር ግልፅ እና ተጣጣፊ መጭመቂያ ይደግፋል
የስራ ጭነት:

| ባህሪ | ዓላማ |
| --- | --- |
| `to_bytes` | ያልተጨመረው የርዕሰ-ጉዳዩ ክፈፍ የተሸከመውን ጭነት በማስመሰል. |
| `to_compressed_bytes` | Zstd ጋር ኢንኮድ እና ራስጌ ውስጥ የመጭመቂያ መለያ መቅዳት. |
| `to_bytes_auto` | መጭመቅ ጠቃሚ እንደሆነ ለመወሰን የዴተሪሚኒስት ሄውሪስቲክ ዘዴዎችን ይጠቀሙ። |
| CRC64 ማፋጠን | ተንቀሳቃሽ አጠቃቀሞች CRC64-XZ በየትኛውም ቦታ CLMUL በ x86 ላይ_64 ወይም PMULL በ aarch64 ላይ ይገኛል። |
| GPU CRC64 እና መጭመቂያ | አማራጭ ብረት ወይም CUDA ረዳቶች ትላልቅ ጥቅማጥቅሞችን ሊያፋጥኑ እና ከዚያ ወደ CPU መንገዶችን። |

የሃርድዌር ማፋጠን የተገለጸውን ይዘት በጭራሽ አይለውጥም. CRC እና JSON
አሽከርካሪዎች ተንቀሳቃሽ የውጤት ቢት-ለ-ቢት ማዛመድ አለባቸው።
መካከል ይለያያል CPU እና GPU ኮዴሮች, ነገር ግን የተገለጸውን ጥቅማጥቅሞች እና Norito አርእስት
ሜታዳታ ለትክክለኛነት ወሳኝ ሆኖ ይቆያል።

## JSON ድጋፍ {#json-support}

Norito አንድ ተወላጅ ያካትታል JSON አስፈላጊ ለሆኑ መጨረሻ ነጥቦች እና መሳሪያዎች የሚሆን መደርደሪያ JSON
ከ Norito የመሳሪያ ስርዓት።

| JSON ባህሪ | የአጠቃቀም ጉዳይ |
| --- | --- |
| `norito::json::{to_json, from_json}` | የተወሰነ ዓይነት JSON ኮድ / ዲኮድ ማድረግ። |
| ቆንጆ እና ጸሐፊ ረዳቶች | CLI ውፅዓት፣ ማያ ገጾች እና ዥረት `std::io` ውህደት. |
| DOM እሴቶች | የፕሮግራም ማነቃቂያ Norito ነው JSON የዋጋ ሞዴል. |
| ፈጣን ጽሑፍ JSON | ለሙቅ የሥነ-ሕንፃ ቴፕ ላይ የተመሠረተ ዲኮድ / ኮድ DTO መንገዶችን። |
| የዜሮ ኮፒ አንባቢ | በተቻለ መጠን ከግቤት ገመድ የተበደሉ የማሳያ ምልክቶች። |
| የደረጃ 1 ማፋጠሪያዎች | አማራጭ AVX2, NEON, ብረት ወይም CUDA የሥነ-ሕንፃ ኢንዴክሰሪንግ ከስካላር ውድቀት ጋር። |

Iroha ኮድ ይመርጣል `norito::json` ለትራፊክ ረዳቶች API ጥቅማጥቅሞች።
ቀለል ያለ `serde_json` ለምርቱ መንገዶች ከሥርዓቱ የሚለዩ አደጋዎች እና
የሜዳ አያያዝ ባህሪ SDKs እና Torii የማስወጫ መሳሪያዎች።

## የመነሻ ድጋፍ {#derive-support}

Rust የውሂብ ዓይነቶች በአጠቃላይ በእጅ ኮዴክ ኮድ ይልቅ የተወሰዱ ማክሮዎችን ይጠቀማሉ።
የተገኘው ንብርብሮች ማመንጨት ይችላሉ Norito የሁለትዮሽ ኮዴኮች፣ ስኬሞች እና JSON ረዳቶች።

የተለመዱ የመስክ ባህሪዎች የሚከተሉት ናቸው:

| ባህሪ | ተጽእኖ |
| --- | --- |
| `#[norito(rename = "other")]` | ለሥርዓቱ እና JSON ተኳሃኝነት። |
| `#[norito(skip)]` | መስክ ያስወግዳል እና ይሞላል `Default` በዲኮዲንግ ጊዜ። |
| `#[norito(default)]` | አጠቃቀሞች `Default` የተገለጸው ጥቅማጥቅሞች ጭነት ሜዳውን የማይሸከምበት ጊዜ። |
| `#[norito(skip_serializing_if = "...")]` | መስኮችን ያስወግዳል JSON የዲተሪሚኒስት ዲኮዲንግ ነባሪዎችን በመጠበቅ ላይ ሲሆኑ፣ የፕሬዲኬቱ መስፈርት የሚስማማ ነው። |

ውርዶች ደግሞ የኮድ ርዝመት ጥቆማዎች እና ትክክለኛ ርዝመት ስሌቶች ያሳያሉ
ኮዴሮች እነዚህን ፍንጮች ተጠቅመው ተጨማሪ ቅጂዎችን ለማስወገድ የመጠባበቂያ ማከማቻዎችን ይጠቀማሉ።

## የሳጥን ባህሪ ቤተሰቦች {#crate-feature-families}

በግንባታ ወቅት Iroha ወይም SDK ከምንጭ የሚመጡ ትስስር፣ Norito ባህሪያት የትኛውን ይምረጡ
ረዳቶች እና ማፋጠሪያዎች ይገኛሉ

| ባህሪያት ቤተሰብ | ምን ያስችለዋል |
| --- | --- |
| `derive` | ዳግም የተላኩ የሂደታዊ ማክሮዎች ለሁለትዮሽ ፣ ስክሪም እና JSON የሚመነጭ ነው። |
| `compression` | የ Header-framed ጥቅማጥቅሞች Zstd ድጋፍ. |
| `packed-seq` | የማጣቀሻ ሰንጠረዦችን በመጠቀም የተሸከሙ የስብሰባ አቀማመጦች. |
| `packed-struct` | የተሸፈኑ በዋናነት የሚመነጩ የስትራክቸር አቀማመጥ። |
| `compact-len` | የቫሪንት በዋጋ ርዝመት ቅድመ-እይታዎች. |
| `columnar` | Norito አምድ ብሎኮች ፣ ተጣጣፊ AoS/NCB ረድፍ ኮዴኮች እና ለስካን ከባድ መንገዶች የተበደሉ እይታዎች; በነባሪው ውስጥ ተካትተዋል `node-codec` ባህሪያት ስብስብ. |
| `strict-safe` | ስህተት መንገዶች ውስጥ የድንጋጤዎች ዲኮድ ወደ የተዋቀሩ ስህተቶች ይቀይራል. |
| `simd-accel` | CPU በተቻለ መጠን ፍጥነት ያለው መጨመር፣ በዲተሪሚኒስት ውድቀት። |
| `json` | ተወላጅ JSON ተንታኝ፣ ጸሐፊ፣ DOM, የተጻፉና ፈጣን መንገዶች። |
| `json-std-io` | አንባቢ እና ጸሐፊ ረዳቶች JSON ተሰብስቦ። |
| `metal-stage1`, `cuda-stage1` | አማራጭ GPU JSON መዋቅራዊ መረጃ ጠቋሚዎች የኋላ ታሪክ. |
| `metal-stage2` | አማራጭ ሜታል ሜታዳታ ምድብ JSON መዋቅራዊ ቴፕ። |

ባህሪያት ተደራሽነት SDKs እና መገለጫዎችን ይለቀቁ.
ቅርጸቱ በአካባቢያዊ የግንባታ ባንዲራዎች ሳይሆን በራስጌ እና በሂደቱ ይገዛል።

## Torii እና Norito RPC {#torii-and-norito-rpc}

Torii የተጋለጡ JSON ለብዙ ኦፕሬተሮች መንገዶች, ነገር ግን የተጻፈ ባናሪ መስመሮች መጠቀም
Norito. የወቅቱ አይነት የሚዲያ Norito HTTP አካላት
`application/x-norito`.

አንድ መጨረሻ ነጥብ ተቀባይነት ሲሰጥ ወይም ሲመለስ እነዚህን ራስጌዎች ይጠቀሙ Norito:

```http
Content-Type: application/x-norito
Accept: application/x-norito
```

አንድ መጨረሻ ነጥብ ሁለቱንም ውክልናዎች የሚደግፍ ከሆነ, ደንበኞች ግልፅ መላክ ይችላሉ
ምርጫ ዝርዝር:

```http
Accept: application/x-norito, application/json
```

የዲኮድ ስህተቶች እንደተጻፉ ይታያሉ Torii ስህተቶች እና በቴሌሜትሪ የተቆጠሩ.
የተለመዱ ምክንያቶች አሉታዊ አስማት፣ ያልተደገፈ ስሪት፣ ያልተደገፈው ባህሪ
ባንዲራ፣ የቼክ አኃዝ መዛባት፣ የተበላሸ UTF-8, ልክ ያልሆነ enum መለያ፣ እና የሥርዓቱ አለመጣጣም።

Norito RPC ትራንስፖርት የሚመረጠው በትራንስፖርት ውቅር አማካኝነት ነው።
ዳሽቦርዶች ጥያቄዎችን መዘግየት፣ ውድቀቶች፣ ንቁ ግንኙነቶች መከታተል አለባቸው፤
የምላሽ ባይት፣ እና `torii_norito_decode_failures_total` በተናጠል ከ JSON
ትራፊክ.

## የአሠራር መመሪያ {#operational-guidance}

- ይመርጣል። SDK የግንባታ ሠራተኞች እና የተፈጠሩ ትይዩዎች በእጅ የተሠሩ Norito ባይት
- የሥርዓቱ አለመመሳሰል እንደ ስሪት ወይም ቋሚ ችግር እንጂ እንደ ጊዜያዊ አይደለም
  የአውታረ መረብ ውድቀት.
- ይቀጥሉ `.nrt`, `.norito`, እና ከተለቀቀው ወይም ከደረሰበት ክስተት ጋር የተገለጹ ቅርሶች
  ያፈራቸው ባንድ ነው።
- አጠቃቀም JSON ለዳሽቦርድ እና በእጅ ቁጥጥር የሚደረጉ ትንበያዎች, ነገር ግን ይያዙ Norito እንደ
  ለተፈረሙ፣ ለሃሽ የተደረጉ ወይም የቀጠሉ መረጃዎች የእውነት ምንጭ።
- አዲስ የተጻፈ ሲጨምር Torii የመጨረሻ ነጥብ፣ ተቀባይነት ያለው መሆኑን የሚያረጋግጥ ሰነድ JSON,
  Norito, ወይም ሁለቱም, እና የተደገፉ ይዘት አይነቶች በ `/openapi`.
- አሽከርካሪዎችን በሚፈቅድበት ጊዜ ከስካላር ውፅዓት ጋር የፓርተሪነት ሙከራዎችን ያካሂዱ
  የማፋጠን ስህተቶች ከመቀየር ይልቅ በንጹህ ሁኔታ ወደ ኋላ መመለስ አለባቸው
  የዋጋ ጭነት ትርጓሜ።
