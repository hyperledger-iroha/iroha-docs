# የተኳኋኝነት ማትሪክስ {#compatibility-matrix}

የተኳኋኝነት ማትሪክስ መስቀልን ያሳያል-SDK ለአሁኑ ሁኔታ ሽፋን Iroha 3 ሰነዶች ተዘጋጅተዋል. በነባሪነት፣ ገጹ ከተሰካው የተፈጠረውን የተጠቀለለ ነጥብ-በጊዜ ውሂብ እይታ ይጭናል [`hyperledger-iroha/iroha`](https://github.com/hyperledger-iroha/iroha) ክለሳ.

ማትሪክስ የሚከተሉትን ያጠቃልላል

- በመጀመሪያው አምድ ውስጥ ያሉ ታሪኮች
- SDKs በቀሪዎቹ ዓምዶች ላይ
- ለተሸፈነ፣ ያልተሳካ እና የጎደለ ውሂብ የሁኔታ ምልክቶች

በማደስ የስራ ሂደት የተረጋገጡ ውጤቶች ብቻ እንደተሸፈኑ ወይም እንዳልተሳካላቸው ሪፖርት ይደረጋሉ። ለተሰካው ክለሳ ማስረጃ የሌላቸው ሁኔታዎች ከሌላ ምንጭ ክለሳ ውጤቶችን ከመውረስ ይልቅ እንደ ጎደለው ውሂብ ይታያሉ።
