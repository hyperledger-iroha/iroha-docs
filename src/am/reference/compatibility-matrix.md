# ተኳሃኝነት ማትሪክስ {#compatibility-matrix}

የ ተኳሃኝነት ማትሪክስ የአሁኑን Iroha 3 ሰነዶች ስብስብ መስቀለኛ-SDK ሁኔታ ሽፋን ያሳያል ። በነባሪነት ፣ ገጹ ከታሸገው [ `hyperledger-iroha/iroha`](https://github.com/hyperledger-iroha/iroha) ግምገማ የተፈጠረውን የታጠፈ ቅጽበታዊ ገጽ እይታ ይጫናል.

ማትሪክስ የሚከተሉትን ያካትታል:

- በመጀመሪያው አምድ ውስጥ ያሉ ታሪኮች
- SDKs በቀሪዎቹ አምዶች ላይ
- የተሸፈኑ ፣ ያልተሳኩ እና የጎደሉ መረጃዎች የሁኔታ ምልክቶች

በማዘመን የስራ ፍሰት የተረጋገጡ ውጤቶች ብቻ እንደተሸፈኑ ወይም አልተሳኩም ተብለው ሪፖርት ይደረጋሉ። ለተቀላጠፈው ማሻሻያ ማስረጃ የሌላቸው ሁኔታዎች ከሌላ ምንጭ ማሻሻያ ውጤት ይልቅ እንደ የጎደሉ መረጃዎች ይታያሉ።
