# ተኳሃኝነት ማትሪክስ {#compatibility-matrix}

ተኳሃኝነት ማትሪክስ መስቀለኛ-SDK የአሁኑ ሁኔታ
Iroha 3 ሰነዶች ስብስብ. በነባሪነት, ገጹ የተፈጠረውን የታጠቁ ቅጽበታዊ ገጽ ይጫናል
ከተጨናነቁ [`hyperledger-iroha/iroha`](https://github.com/hyperledger-iroha/iroha)
ማሻሻያ

ማትሪክስ የሚከተሉትን ያካትታል:

- **ታሪኮች** በመጀመሪያው አምድ ውስጥ
- **SDKs** በቀሪዎቹ አምዶች ላይ
- **የሁኔታ ምልክቶች** የተሸፈኑ፣ ያልተሳኩ እና የጎደሉ መረጃዎች

በአድማጭነት የስራ ፍሰት የተረጋገጡ ውጤቶች ብቻ እንደተሸፈኑ ሪፖርት ይደረግባቸዋል ወይም
የተጣራውን ማሻሻያ የሚያረጋግጡ ማስረጃዎች የሌሉበት ሁኔታ እንደ
ከሌላ ምንጭ ማሻሻያ የተገኙ ውጤቶችን ከመውረስ ይልቅ የጎደሉ መረጃዎች።
