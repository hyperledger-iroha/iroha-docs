# Iroha 3 መተግበሪያ የተግባር መመሪያ ስብስብ {#iroha-3-application-cookbook}

ላይ ይገንቡ Iroha 3 በ ላይ የሚጀምሩ ትናንሽ እና ሊረጋገጡ ከሚችሉ የተግባር መመሪያዎች ጋር Taira Testnet እና አቆይ Minamoto Mainnet ተነባቢ ብቻ። እያንዳንዱ የተግባር መመሪያ ይፋዊ ንባብ መሆኑን ይገልጻል ፣ መደበኛ የገንዘብ ድጋፍ የተደረገለት መለያ መፃፍ፣ ወይም በፍቃድ የተዘጋ ክዋኔ። ትዕዛዞች የአሁኑን ይጠቀማሉ I105 የመለያ መታወቂያዎች፣ ግልጽ የክፍያ ምርጫ እና የተፈተሸው ባህሪ በ Iroha ፕሮቶኮል ማጠናቀቂያ [`0010c5a70039eac101a4846499ba9ceaf43eb65c`](https://github.com/hyperledger-iroha/iroha/tree/0010c5a70039eac101a4846499ba9ceaf43eb65c).

በ [ከ Taira ጋር ይገናኙ](./connect-to-taira.md) ይጀምሩ። በትእዛዝ መስመር የተግባር መመሪያዎች እንደገና ጥቅም ላይ የዋለውን የደንበኛ ውቅር እና የክፍያ ሜታዳታ ይፈጥራል። ከዚህ ሰነድ የክፍያ ንብረት መታወቂያ በጭራሽ አይቅዱ አሁን ካለው Taira የቴስትኔት የገንዘብ ድጋፍ አገልግሎት ምላሽ ያግኙት።

## የመዳረሻ ደረጃዎች {#access-levels}

- ይፋዊ - ምንም ምስጠራ ፈራሚ ወይም የአውታረ መረብ ፈቃድ አያስፈልግም።
- ለመፃፍ ዝግጁ - በገንዘብ የተደገፈ Taira የሙከራ መለያ፣ ግልጽ ክፍያ ከፋይ እና በቴስትኔት የገንዘብ ድጋፍ አገልግሎት የተመለሰውን የአሁኑን የክፍያ ንብረት ይጠቀሙ።
- ፈቃድ ያስፈልጋል - Taira የተሰየመውን የሶፍትዌር ማስፈጸሚያ አካባቢ ፍቃድ ወይም የሚተዳደር የስም ቦታ መስጠት አለበት። ያ ስጦታ በማይገኝበት ጊዜ የመነጨ የአካባቢ አውታረ መረብ ይጠቀሙ; የአካባቢ ስኬት Taira የፈቃድ ባለቤት አይሰጥም።

የትኛውም የተግባር መመሪያ ለ Minamoto የመጻፍ ክዋኔ አይልክም።
