# Iroha 3 {#iroha-3}

Iroha 3 የመጀመሪያው የተለቀቀው Hyperledger Iroha መድረክ ነው።. በራስ የሚስተናገዱ አውታረ መረቦችን እና ባለብዙ-ዳታ ቦታ SORA Nexus የማሰማራት ሞዴልን ከአንድ ዲተርሚኒስቲክ ኮድ ቤዝ ይደግፋል።

በከፍተኛ ደረጃ Iroha 3 ያጣምራል -

- ዲተርሚኒስቲክ አፈፃፀም እና ማከማቻ
- የ Iroha ቨርቹዋል ማሽን (IVM) ለተንቀሳቃሽ ስማርት ኮንትራቶች
- Norito እንደ ነጠላ ፕሮቶኮል-መደበኛ ተከታታይ ቅርጸት
- Torii ለደንበኛ፣ ኦፕሬተር እና መተግበሪያ ፊት ለፊት APIs
- Sumeragi ከግዴታ የውሂብ ተገኝነት እና አስተማማኝ ስርጭት ጋር መግባባት
- ጎራ አልባ ነጠላ ፕሮቶኮል-መደበኛ መለያዎች በተናጠል የታሰሩ በሰው ሊነበቡ የሚችሉ ተለዋጭ ስሞች
