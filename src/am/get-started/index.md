# Iroha 3 {#iroha-3}

Iroha 3 ለመጀመሪያ ጊዜ የተለቀቀው Hyperledger Iroha መድረክ ነው ። የራስ-አስተናጋጅ አውታረ መረቦችን እና ከአንድ ቆራጥ ኮድ መሠረት ላይ ባለብዙ የውሂብ ቦታ SORA Nexus የማሰማራት ሞዴልን ይደግፋል ።

በከፍተኛ ደረጃ Iroha 3 የሚከተሉትን ያጣምራል-

- የተወሰነ አፈፃፀም እና ማከማቻ
- የ Iroha ቨርቹዋል ማሽን (IVM) ለተንቀሳቃሽ ስማርት ኮንትራት
- Norito በካኖኒክ ገመድ ቅርጸት
- Torii ለደንበኛ ፣ ለአስተናጋጅ እና ለመተግበሪያ-ተኮር APIs።
- Sumeragi የግዴታ መረጃዎች ተደራሽነት እና አስተማማኝ ስርጭት ጋር ስምምነት
- በግለሰብ ሊነበብ የሚችል ቅጽል ስም ያላቸው ጎራ የሌላቸው የካኖኒክ መለያዎች
