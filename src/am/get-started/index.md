# Iroha 3 {#iroha-3}

Iroha 3 የመጀመሪያው እትም ነው Hyperledger Iroha መድረክ ይደግፋል
ራስን የሚያስተናግዱ አውታረ መረቦች እና ባለብዙ የውሂብ ቦታ SORA Nexus የመተግበሪያ ሞዴል
አንድ የተወሰነ ኮድ መሠረት።

በከፍተኛ ደረጃ፣ Iroha 3 ያጠቃልላል

- የተወሰነ አፈፃፀም እና ማከማቻ
- የ Iroha ምናባዊ ማሽን (IVM) ለተንቀሳቃሽ ስማርት ኮንትራቶች
- Norito እንደ ቀኖናዊ ገመድ ቅርጸት
- Torii ለደንበኛ ፣ ለአስተናጋጅ እና ለመተግበሪያ-ተኮር APIs
- Sumeragi የግዴታ መረጃዎች ተደራሽነት እና አስተማማኝ ስርጭት ጋር የተያያዘ ስምምነት
- ለሰው የሚነበብ ስያሜዎች በተናጠል የተጣመሩባቸው ጎራ የሌላቸው የካኖኒክ መለያዎች
