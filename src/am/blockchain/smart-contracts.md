# ብልህ ኮንትራት {#smart-contracts}


Iroha ግብይቶች የ `Executable` ጥቅማጥቅሞች ይተገበራሉ። የአሁኑ የመረጃ ሞዴል የሚከተሉትን ይደግፋል:

- `Executable::Instructions`: የተደራጀ የ Iroha ልዩ መመሪያዎች ስብስብ
- `Executable::ContractCall`: ለተተገበረ የውል ቅጽበት የሚደረገውን የማጣቀሻ ጥሪ
- `Executable::Ivm`: Iroha VM የባይት ኮድ
- `Executable::IvmProved`: Iroha VM የባይት ኮድ ከቅድመ ማስላት መመሪያ ሽፋን እና የማረጋገጫ ግዴታዎች ጋር

Kotodama ነው Iroha የከፍተኛ ደረጃ ስማርት ኮንትራት ቋንቋ ነው። `.ko` ምንጭ ፋይል ወደ የተወሰነ ያጠናቅቃል IVM ባይት ኮድ፣ በተለምዶ እንደ አንድ `.to` ለመተግበር የታሰበ ጥንታዊ ዕቃ። Kotodama ግቦች IVM ብቻ ነው. RISC-V ወይም WebAssembly.

የመጀመሪያው ስሪት ABI ስሪት ብቻ ይደግፋል 1. የ syscall እና ጠቋሚ-ABI ፖሊሲ በቅበላ እና አፈፃፀም የሚተገበር አንድ ያለ ቅድመ ሁኔታ V1 ውል ነው; አማራጭ የአሂድ ጊዜ ሁነታ የለም.

## ስማርት ኮንትራቶችን መጠቀም የሚቻልበት ጊዜ {#when-to-use-smart-contracts}

ግብይቱ በቀጥታ ሊገለጽ በሚችልበት ጊዜ መደበኛ መመሪያዎችን ይጠቀሙ:

- የተመዘገቡት ወይም ያልተመዘገቡ ዕቃዎች
- የክፍያ፣ የማቃጠል ወይም የማስተላለፊያ ንብረት
- የማዘመን ሜታዳታ
- ፈቃድ መስጠት ወይም መሰረዝ
- አስነሳ
- በሰንሰለት ላይ የተቀመጡ መለኪያዎች

ግብይቱ እንደ ቋሚ የትእዛዝ ቅደም ተከተል ለመግለጽ አስቸጋሪ የሆነ የታሸገ ሎጂክ ሲያስፈልገው ወይም የተተገበረ የኮንትራት ምሳሌ በመጥቀስ ሊጠራ በሚገባበት ጊዜ ብልህ ውል ይጠቀሙ።

## IVM ፈፃሚዎች {#ivm-executables}

`Executable::Ivm` ጥሬ IVM ባይት ኮድ ይይዛል። ኖዶች ያንን የባይት ኮድ ለሰንሰለት በተዋቀሩ የአሂድ ጊዜ ገደቦች ውስጥ ያካሂዳሉ። ባይት ኮዱን አነስተኛ እና ቆራጥ ያድርጉት ፣ ውል የግብይት አፈፃፀም አካል ናቸው እናም ስለሆነም ስምምነት ላይ ተጽዕኖ ያሳድራሉ ።

`Executable::IvmProved` ለመከላከያ ተሸካሚ ፍሰቶች የታሰበ ነው:

- IVM የባይት ኮድ
- የመወሰን መመሪያ ሽፋን
- የአፈፃፀም ክስተቶች ግዴታ
- የጋዝ ፖሊሲ ግዴታ

ማስረጃው ከፈፀመው ባይት ኮድ ጋር ሽፋን ይያዛል። በፓይፕላይን ፖሊሲ ላይ በመመርኮዝ ማረጋገጫ ሰጪዎች ማስረጃውን ማረጋገጥ እና እንደ ተጨማሪ የደህንነት ፍተሻ እንደገና መጫወት ይችላሉ ።

## የተሰማሩ የውል ጥሪዎች {#deployed-contract-calls}

`Executable::ContractCall` የተተገበረውን የውል ምሳሌ በአድራሻ ይጠቀማል ። ይህ ስምምነት ኮድ በተናጠል ሲመዘገብ እና ግብይቶች በየጊዜው ባይት ኮዱን ከመያዝ ይልቅ በማጣቀሻ ሊጠሩበት ይገባል ።

## የውል የሕይወት ዑደት እና ባለቤትነት {#contract-lifecycle-and-ownership}

እያንዳንዱ የተሰማራ አድራሻ `ContractLifecycleControlV1` መዝገብ ይይዛል፣ ይህም ውልው ንቁ በሚሆንበት ጊዜም ጭምር። መዝገቡ የመጀመሪያውን ማሰማራት የማይቀየር መነሻ፣ የአሁኑ እና የሚቀጥለውን ባለቤት፣ ማንኛውንም ሊሰረዝ የሚችል የፓርላማ ተልእኮ፣ ንቁ ኮድ ሃሽ፣ ዜሮ ያልሆነ የማወዳደርና ልውውጥ ግምገማ ያካትታል፣ አንድ ቀጥተኛ ማሰማራት የማሰማራት ሂሳቡን ይመዘግባል። አንድ የፓርላማ ማሰማራት አቅራቢውን ፣ ሀሳብ ይዘቱን ID እና የተሳካ የአስተዳደር ሙከራውን ID ይመዘግባል ።

የህይወት ዑደት ባለቤት አንድ መለያ ወይም ፓርላማ ነው። የመለያ ባለቤትነት ለውጦች በተለየ ቅናሽ እና ተቀባይነት ይጠቀማሉ፤ ቅናሹን መቀበል ማንኛውንም የፓርላማ ውክልና ያጸድቃል። አንድ የሂሳብ ባለቤት ፓርላማን ውልውን እንዲያነቃ ወይም እንዲያሰናክል ሊፈቅድለት ይችላል ፣ ከዚያ ያንን ተልዕኮ እንዲሰርዝ ሊያደርግ ይችላል ፣ ግን ተልዕክቱ መቼም ቢሆን ፓርላማው የባለቤትነት መብቱን እንዲያስተላልፍ አይፈቅድም ።

ጥሬ `ActivateContractInstance` እና `DeactivateContractInstance` መመሪያዎቹ ለሂደት ሂሳብ ባለቤት ብቻ ይገኛሉ ። `expected_revision`; የሂደት ጊዜ የዘመኑ ወይም ዜሮ ማሻሻያዎችን ይክዳል. የህይወት ዑደት መዝገብ፣ እና የተመዘገበውን አርቴፋክት ፣ ማኒፌስት እና ABI ከመቀየሩ በፊት `active_code_hash`. ማሰናከል ንቁውን ኮድ ሃሽ ያስወግዳል ነገር ግን የባለቤትነት እና የመነሻ ቦታን ይቀጥላል። እያንዳንዱ የተሳካ የሕይወት ዑደት ሽግግር ግምገማውን ያሻሽላል እናም ሙሉውን የፖስታ ሁኔታ ያወጣል ።

ማነቃቂያ ደግሞ አንድ manifest-የተገለጸው የሕይወት ዑደት አሻራ መድረክ ይችላል. `EntryPointKind::Hajimari` የመግቢያ ነጥብ (`hajimari`/`始まり`) ደረጃዎች `Hajimari`. አንድን ንቁ አድራሻ ወደ ኮድ መልሶ ማገናኘት `EntryPointKind::Kaizen` የመግቢያ ነጥብ (`kaizen`/`改善`) ደረጃዎች `Kaizen`. አስገዳጅነት ወዲያውኑ ይለወጣል, ነገር ግን ውል ዝግጁ አይደለም: እያንዳንዱ `Kotoage` እና `View` ትክክለኛውን ደረጃ የተሰጠው ማንጠልጠያ እስኪሳካ ድረስ ጥሪው ውድቅ ተደርጓል ። አንድ ማንጠልጠያው በሚቆይበት ጊዜ ሌላ ማግበርም ውድቅ ተደርጎበታል።

በደረጃው ላይ ያለውን ማንጠልጠያ `Executable::ContractCall` ተመሳሳይ የውል አድራሻ እና አዲስ ኮድ ሃሽ, ትክክለኛውን በመጠቀም `hajimari` ወይም `kaizen` የመግቢያ ነጥብ እና በፕሮግራሙ ውስጥ የተገለጹት ክርክሮች። `CanInvokeContractEntrypoint` በመጠባበቅ ላይ ያለው ምልክት አሂድ ጊዜ-የተፈጠረ, የተወሰነ `transition_id` እና አዲሱ `code_hash`; ሀ `Kaizen` ማርከር ደግሞ ይዟል `previous_code_hash`. ደንበኞች አያሰላሱም ወይም አያቀርቡም `transition_id`. ስኬታማ የሆነ ጠመዝማዛ ምልክት ማድረጊያውን በአቶሚክ የሚጠቀም ሲሆን የተሳካለት ጠመዝማዣ ደግሞ ለቀጣይ ዳግም ሙከራ ይጠብቃል.

የአስቸኳይ ጊዜ ደረጃ የፓርላማው ፕሮፖዛል ወቅታዊውን ማሻሻያ ፣ ኮድ ሃሽ እና ዜሮ ያልሆነ ክስተት ዳይጀስት ሲያስገድድ እስከ 3,600 ብሎኮች ድረስ መቆየት ይችላል ። ጥሪዎች ከመጫን ከፍታ እስከ ማጠናቀቂያ ከፍታ ድረስ ተከልክለዋል። ጊዜ ማብቂያ አፈፃፀሙን ይመልሳል ነገር ግን መቆለፊያውን አይሰርዝም። የተረጋገጠ `CompleteEmergencyHoldRetrospective` እርምጃ በኋላ ላይ ትክክለኛውን መቆለፊያን IDs ማያያዝ እና መዝገብ ከመሰረዙ በፊት ከዜሮ ያልሆነ የማግኘት ሥር ጋር መፍጨት አለበት ። ያ ዳግመኛ መቆጠብ የሚቀጥልበት ጊዜ ሊተገበር አይችልም ።

አፕሊኬሽኑ API ሲነቃ, የተያዘውን ሁኔታ በ `GET /v1/gov/contracts/{contract_address}` ያንብቡ. የእሱ `found` መስክ ማለት የአኗኗር ዑደት መዝገብ አለ ማለት ነው, እና አድራሻው በአሁኑ ጊዜ ንቁ ኮድ አለው ማለት አይደለም.

## የአሠራር አቅጣጫ {#operational-guidance}

- የኮንትራት ባህሪ በአካባቢያዊ የግድግዳ ሰዓት ሰዓት, በአስተናጋጅ ፋይሎች ስርዓት ሁኔታ, በኔትወርክ ጥሪዎች ወይም በሌሎች የአቻ-አከባቢ ግብዓቶች ላይ የተመካ መሆን የለበትም.
- ትልቅ ባይቶ ኮድ የግብይት መጠንን እና የብሎክ ማስፋፊያ ወጪን ይጨምራል።
- ለቀላል መቁጠሪያ ለውጦች የተጻፉ መመሪያዎችን ይመርጣሉ። ለመፈተሽ ቀላል እና ለመፈፀም ርካሽ ናቸው ።
- የውል ማሻሻያ እና የምዝገባ ፍቃዶችን ከፍተኛ አደጋ ያለው የአሠራር ቁጥጥር አድርገው ይመለከቱ።
