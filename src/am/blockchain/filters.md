# ማጣሪያዎች {#filters}

የአሁኑ ከፍተኛ ደረጃ
ክስተት ማጣሪያ `EventFilterBox`, እነዚህ ክስተቶች ቤተሰቦች ጋር ሊዛመዱ ይችላሉ:

- `Pipeline`
- `Data`
- `Time`
- `ExecuteTrigger`
- `TriggerCompleted`

ከስራ ፍሰት ጋር የሚስማማ በጣም ጠባብ ማጣሪያ ይጠቀሙ።
`DataEventFilter::Any` ለምርመራ ጠቃሚ ናቸው, ነገር ግን እያንዳንዱን ክስተት ያደርጉታል
የሽያጭ ወጪን ወይም የደንበኝነት ተመዝጋቢ ማዛመድ.

## የመረጃ ክስተት ማጣሪያዎች {#data-event-filters}

`DataEventFilter` የሂሳብ መቁጠሪያ መረጃ ክስተቶች ጋር ይዛመዳል. የአሁኑ ልዩነቶች የሚከተሉትን ያካትታሉ:

| ልዩነት | የዝግጅት ቤተሰብ |
| --- | --- |
| `Any` | ማንኛውም መረጃ ክስተት |
| `Peer` | የእኩዮች የህይወት ዑደት ክስተቶች |
| `Domain` | የጎራ የሕይወት ዑደት እና ሜታዳታ ክስተቶች |
| `Account` | የሂሳብ የሕይወት ዑደት፣ ሜታዳታ፣ የማዕረግ ስም እና ማንነት ክስተቶች |
| `Asset` | የንብረት ሚዛን እና ሜታዳታ ክስተቶች |
| `AssetDefinition` | የአክሲዮን ትርጉም የሕይወት ዑደት፣ ፖሊሲ እና ሜታዳታ ክስተቶች |
| `Nft` | NFT የሕይወት ዑደት እና ሜታዳታ ክስተቶች |
| `Rwa` | የእውነተኛ ዓለም ንብረት የሕይወት ዑደት ክስተቶች |
| `Trigger` | የማስነሳት የሕይወት ዑደት እና ሜታዳታ ክስተቶች |
| `Role` | የህይወት ዑደት ክስተቶች |
| `Configuration` | በሰንሰለት ላይ የኮንፊግሬሽን ክስተቶች |
| `Executor` | የስራ ሰዓት አስፈፃሚ ክስተቶች |
| `Proof` | የምስክርነት ማረጋገጫ የሕይወት ዑደት ክስተቶች |
| `Confidential` | ምስጢራዊ ንብረት ክስተቶች |
| `VerifyingKey` | የማረጋገጫ ቁልፍ መዝገብ ክስተቶች |
| `RuntimeUpgrade` | የስራ ሰዓት ማሻሻያ ክስተቶች |
| `Soradns` | የመቆጣጠሪያ ማውጫ አስተዳደር ክስተቶችን መፍታት |
| `Sorafs` | SoraFS የጌትዌይ ተገዢነት ክስተቶች |
| `SpaceDirectory` | የቦታ ማውጫ የሕይወት ዑደት ክስተቶችን ይገልጻል |
| `Escrow` | ግልፅ የሆነ የአገሬው ነዋሪ ንብረት ኤስኮር የሕይወት ዑደት ክስተቶች |
| `Offline` | ከመስመር ውጪ የሚደረጉ የፍርድ ሂሳቦች |
| `Oracle` | የኦራክል ምግብ ክስተቶች |
| `Social` | የቫይራል ማበረታቻ ክስተቶች |
| `Bridge` | ድልድይ ክስተቶች |
| `Governance` | የአስተዳደር ባህሪው በተነቃቀበት ጊዜ የመስተዳድር ክስተቶች |

አብዛኛዎቹ የኮንክሪት ማጣሪያዎች እንዲሁ አማራጭን ይፈቅዳሉ ID ማቻር እና የዝግጅት ማስክ።
ለምሳሌ አንድ የንብረት ማጣሪያ ከአንድ ንብረት ወይም ከአንድ የንብረት ክስተቶች ክፍል ጋር ሊዛመድ ይችላል ፣
አንድ ማስነሻ ማጣሪያ ማስነሻ ጋር ሊዛመድ ይችላል ID እና አስነሳሽ ክስተት ስብስብ.

## የቧንቧ ማጣሪያዎች {#pipeline-filters}

የቧንቧ ማጣሪያዎች እንደ ብሎክ ፣ ግብይት ፣ ውህደት ፣
ለስራ ምዝገባዎች፣ ለብሎክ ማቀነባበሪያ
ዳሽቦርዶች፣ እና የመረጃ መለያ መረጃዎች ይልቅ የፓይፕላይን ሁኔታ ምላሽ የሚሰጡ አስነሳሾች
ዕቃዎች።

## የመነሻ ማጣሪያዎች {#trigger-filters}

ማስነሻዎች ሁኔታቸውን እንደ `EventFilterBox`. በተጨማሪም አንድ አስነሳሽ እርምጃ
መደብሮች

- ተጨባጭ
- የመድገም ፖሊሲ
- ባለሥልጣን መለያ
- አማራጭ የጊዜ ማነሳሻ ዳግም ሙከራ ፖሊሲ
- ሜታዳታ

አስጀማሪው ባለስልጣን በፈፃሚው የሚጠየቁትን ፍቃዶች ሊኖረው ይገባል።
ለረጅም ጊዜ የሚቆዩ ተነሳሽነቶች የተወሰኑ ቴክኒካዊ ሂሳቦችን ይመርጣሉ።

## የጥያቄ ማጣሪያዎች {#query-filters}

መጠይቅ ማጣሪያዎች ከዝግጅት ማጣሪያዎች የተለዩ ናቸው. ሊለወጡ የሚችሉ መጠይቆች ሊያጋልጡ ይችላሉ
ለጥያቄው የተወሰኑ የታይፕ ማጣሪያዎችን ከ SDK
ስለዚህ የማጣሪያ ግብዓት ጥያቄ ውፅዓት አይነት ጋር ይዛመዳል.
