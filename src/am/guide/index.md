# መመሪያ {#guide}

ከ Iroha ጋር ሲገነቡ፣ ሲሰሩ ወይም ሲዋሃዱ ይህንን ክፍል ይጠቀሙ። ለመጀመሪያው ደንበኛ በ SDK አጋዥ ስልጠናዎች ይጀምሩ፣ ከዚያ በጋራ አውታረ መረብ ላይ ከማሰማራትዎ በፊት ወደ ምርጥ ልምዶች እና ኦፕሬተር ማጣቀሻዎች ይሂዱ።

## የሚመከር መንገድ {#recommended-path}

1. [Iroha 3 ን ጫን](/am/get-started/install-iroha.md) እና [የአካባቢ አውታረ መረብ ያስጀምሩ](/am/get-started/launch-iroha.md)።
2. [SDK አጋዥ ስልጠና](/am/guide/tutorials/) ይምረጡ እና ትንሽ ግብይት ያስገቡ።
3. መተግበሪያን API ከመቅረጽዎ በፊት [የመተግበሪያ ልማት](/am/guide/best-practices/application-development.md) እና [የውሂብ ሞዴሊንግ](/am/guide/best-practices/data-modeling.md)ን ይገምግሙ።
4. የተጋራ ወይም የምርት አውታረ መረብን ከማስኬድዎ በፊት [የአውታረ መረብ ማሰማራት](/am/guide/best-practices/network-deployment.md)፣ [ሎጀስቲክስ ኦፕሬሽን](/am/guide/best-practices/operations.md) እና [ደህንነት እና መዳረሻ](/am/guide/best-practices/security-and-access.md) ይጠቀሙ።
5. ከአካባቢያዊ ልማት ወደ Taira፣ Minamoto ወይም ሌላ የቀጥታ ማሰማራት ሲያስተዋውቁ [የመልቀቂያ ዝግጁነት](/am/guide/best-practices/release-readiness.md)ን ይከተሉ።
