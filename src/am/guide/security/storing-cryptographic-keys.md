# የምስጠራ ቁልፎችን ማከማቸት {#storing-cryptographic-keys}

የእርስዎ ስሜታዊ መረጃ የግል ሆኖ የሚቆየው እርስዎ ከተቀበሉ ብቻ ነው <abbr title="Operational Security">OPSEC</abbr> የማኅበራዊ ኢንጂነሪንግ ስጋቶች፣ ባለሥልጣን የሆነ ሰው በመምሰል የግል ምስጢራዊ ቁልፍዎን እንዲሰጣቸው ለመጠቀም የሚሞክሩበት ጊዜ እውነተኛ ናቸው። ሁልጊዜ ጥንቃቄ ያድርጉ እና የግል ቁልፍዎን ከማጋራት ይቆጠቡ፤ የቤታችሁ ቁልፎች ለታመኑ ግለሰቦች ብቻ የተያዙ እንደሆኑ አድርጋችሁ ትይዟቸው።

ተጨማሪ መረጃ ለማግኘት <abbr title="Operational Security">OPSEC</abbr> እና ምርጥ ልምዶች, ተመልከት [የአሠራር ደህንነት](./operational-security).

## ምስጢራዊ ቁልፎችን በዲጂታል ማከማቸት {#storing-cryptographic-keys-digitally}

ምስጢራዊ ቁልፎችን በዲጂታል ለመጠበቅ ሲመጣ, በአብዛኛው ሁለት አቀራረቦች ብቻ ናቸው[SSH](https://www.ssh.com/) እና [GPG](https://www.gnupg.org/)የሚገኙ ናቸው። እነዚህ ዘዴዎች ወደ ምስጢራዊ ቁልፎችዎ ያልተፈቀደ መዳረሻን ለመከላከል የደህንነት ንብርብሮች ይሰጣሉ።

ብዙዎች Iroha የሥነ ሕንፃው ውሳኔዎች በሥነ ህንፃው መርሆዎች ተጽዕኖ የተደረገባቸው **ደህንነቱ የተጠበቀ ሼል** (`SSH`) ፕሮቶኮል ፣ ለዚህም ነው ይህ ክፍል በዋናነት `SSH` የክሪፕቶግራፊ ቁልፎችን በመተግበሪያው ውስጥ ለማከማቸት ፕሮቶኮሉን ውጤታማ በሆነ መንገድ እንዴት ተግባራዊ ማድረግ እንደሚቻል መመሪያዎችን በመስጠት Iroha ሥነ ምህዳር.

### በመጠቀም SSH እና SSH ወኪል {#using-ssh-and-ssh-agent}

**ደህንነቱ የተጠበቀ የሻል ፕሮቶኮል** (`SSH`) እንደ ምናባዊ መግቢያ ሆኖ የሚያገለግል የክሪፕቶግራፊ አውታረመረብ ፕሮቶኮል ነው ፣ ይህም በጣም ደህንነቱ የተጠበቀ ባልሆኑ አውታረ መረቦች አማካኝነት በር ላይ ደህንነቱ በተጠበቀ መንገድ ወደ ሩቅ ማሽኖች መዳረሻን ያስችላል። SSH ቁልፎችየመዳረሻ የምስክር ወረቀቶች. ይህ አካላዊ መገኘትን ሳያስፈልግ ከስርዓቶች ጋር በርቀት ለመስተጋብር ውጤታማ መንገድ ይሰጣል. በዚህ አውድ ውስጥ, `SSH` ሁለት ዋና የማረጋገጫ ዘዴዎችን ያቀርባል-በተለመደው የይለፍ ቃል ላይ የተመሠረተ አቀራረብ እና የበለጠ ደህንነቱ የተጠበቀ የህዝብ-የግል ቁልፍ ጥንድ ዘዴ።

ተጨማሪ መረጃ ለማግኘት `SSH`, ተመልከት [የተዛመዱ SSH የአካዳሚ ርዕሰ ጉዳይ](https://www.ssh.com/academy/ssh).

የመግቢያ ሂደቱን ለማመቻቸት እና ተደጋጋሚ ግብዓት አስፈላጊነትን ለማስወገድ ፣ `SSH` ቁልፎች **SSH ወኪል** (`ssh-agent`)የእርስዎን የሚያስታውስ ረዳት ፕሮግራም `SSH` የጊዜ ሰሌዳውን ቆይታ የሚቆጣጠሩ ቁልፎች እና/ወይም የይለፍ ቃል። `SSH` ከሌሎች ማሽኖች ጋር በሚገናኝበት ጊዜ ሁሉ ቁልፎቹን በቀላሉ ለመድረስ በር።

እዚህ ያለው የስራ ፍሰት እንደሚከተለው ነው: የእርስዎ የህዝብ ቁልፍ በርቀት ስርዓት ላይ የተከማቸ እና የግል ቁልፍዎን ደህንነቱ የተጠበቀ ያድርጉ. `ssh-agent` የእርስዎን ለማስተላለፍ እርምጃዎች _የሕዝብ_ የርቀት ስርዓት ከዚያም መልሶ አንድ [ፈተና](https://en.wikipedia.org/wiki/Challenge%E2%80%93response_authentication) ይህ ብቻ ነው _የግል_ ቁልፉ በትክክል ምላሽ መስጠት ይችላል. `ssh-agent` ይህንን ፈተና በመጠቀም _የግል_ ቁልፍ እና ትክክለኛውን ምላሽ ወደ የርቀት ሥርዓት መልሶ ይልካል.

የ ውበት `ssh-agent` በስብሰባዎ ወቅት የግል ቁልፉን ይይዛል ፣ ስለሆነም ወደ ሩቅ ስርዓት በሚያገናኙበት ጊዜ ሁሉ የይለፍ ቃልዎን ወይም የግል ቁልፍ የይለፍ ሐረግዎን ማስገባት አያስፈልግም ።

ተጨማሪ መረጃ `ssh-agent`, ተመልከት [የተዛመዱ SSH የአካዳሚ ርዕሰ ጉዳይ](https://www.ssh.com/academy/ssh/agent).

::: info ማስታወሻ

ለዝርዝር አጠቃላይ እይታ `SSH` ፕሮቶኮል እና `ssh-agent` መሳሪያ፣ የሚከተለውን ተመልከት [SSH አካዳሚ](https://www.ssh.com/academy) ርዕሰ ጉዳዮች

  - [ምንድን ነው SSH (የደህንነት ሼል) ?](https://www.ssh.com/academy/ssh)
  - [ssh-ወኪል: እንዴት ssh-ውኪል, ወኪል ማስተላለፍ, እና ወኪል ፕሮቶኮል ለማዋቀር](https://www.ssh.com/academy/ssh/agent)

:::

### የይለፍ ቃል አስተዳዳሪ ፕሮግራም ማከል {#adding-a-password-manager-program}

የአንተን `SSH` ቁልፎችን በፓስዎርድ በመጠበቅ፣ ይህም የእርስዎን ስሜታዊ መረጃ ለማግኘት በሚፈልጉ ተንኮለኛ አካላት መንገድ ላይ ተጨማሪ እንቅፋት ሆኖ ያገለግላል።

የተለያዩ የይለፍ ቃል አስተዳዳሪዎች የተጠቃሚ የይለፍ ቃሎችን ለማከማቸት ሊጠቀሙባቸው ይችላሉ `SSH` ቁልፎችን ለጊዜው. [KeePass](https://keepass.info/) እንደ ምሳሌ የይለፍ ቃል አስተዳዳሪ ሆኖ ጥቅም ላይ ይውላል ፣ በተለይም [KeePassXC](https://keepassxc.org/) በሊኑክስ ላይ በተመሰረቱ ስርዓተ ክወናዎች ላይ የሚሰራ ወደብ።

እንዴት ማዋቀር እንደሚቻል መመሪያ ለማግኘት KeePassXC ተመልከት [ማዋቀር KeePassXC](#configuring-keepassxc) ከዚህ በታች ያለውን ክፍል.

![KeePassXC: `Main` ማያ ገጽ UI](../../../img/KeePassXC.png)

KeePassXC ይህ መተግበሪያ የተሻሻለ ደህንነት፣ ተለዋዋጭነት እና ቁጥጥርን ያቀርባል። `SSH` ቁልፎችን ለማከማቸት ሲጠቀሙ ይህ የይለፍ ቃል አስተዳዳሪ `ssh-agent` ከተከማቹት ቁልፎች ጋር, ከዚያም ወዲያውኑ ትውስታ ከወሰዱ በኋላ KeePassXC መስኮቱ ተዘግቷል።

::: tip

በንድፈ ሀሳብ, KeePass ወደቦች [በይፋዊ ድረ ገጽ ላይ የተዘረዘሩ](https://keepass.info/download.html) ለቁልፍ ማከማቻ ዓላማዎች ሊያገለግል ይችላል።
የሚከተሉትን እንመክራለን፦ [KeePassX](https://www.keepassx.org/) ወይም [KeePassXC](https://keepassxc.org/).

:::

#### ማዋቀር KeePassXC {#configuring-keepassxc}

ለማዋቀር KeePassXC, የሚከተሉትን እርምጃዎች ይከተሉ:

1. ማስጀመሪያ KeePassXC, ከዚያም ወደ **መሳሪያዎች** > **ቅንብሮች**, ወይም የ **መሳሪያ** አዝራር ከላይ UI ፓነል.

2. በ **የመተግበሪያ ቅንብሮች** የሚታየው ትር፣ ይምረጡ **SSH ወኪል** ከግራ ምናሌ, እና ከዚያ ይምረጡ **ማግበር SSH የአጋንንት ውህደት** የቼክ ሳጥን.

   ::: info የማጣቀሻ ቅጽበታዊ ገጽ እይታን አሳይ

   ![KeePassXC `SSH Agent` ትር: ማግበር SSH ወኪል](../../../img/keepassxc_ssh_agent.png)

   :::

3. አዲስ ይፍጠሩ KeePassXC የመረጃ ቋት. [KeePassXC የተጠቃሚ መመሪያ > የመጀመሪያ የመረጃ ቋትዎን መፍጠር](https://keepassxc.org/docs/KeePassXC_UserGuide#_creating_your_first_database).

4. በእያንዳንዱ ቁልፍ ውስጥ ማከማቸት የሚፈልጉ KeePassXC የፈጠርከው የመረጃ ቋት የሚከተሉትን እርምጃዎች ይከተሉ

   - በመረጃ ቋቱ ውስጥ አዲስ መግቢያ ይጨምሩ. [KeePassXC የተጠቃሚ መመሪያ > የመጀመሪያ የመረጃ ቋትዎን መፍጠር](https://keepassxc.org/docs/KeePassXC_UserGuide#_creating_your_first_database).

   - አዲስ ጽሑፍ ሲጨምሩ የሚከተለውን በማድረግ ቁልፉን የያዘውን ፋይል ያያይዙ **የላቀ** ከግራ ምናሌ ውስጥ, ከዚያም ይምረጡ **ያክሉ** በ **ተያያዥነት** ክፍል, በ ውስጥ የተፈለገውን ፋይል ይምረጡ **ፋይሎችን ይምረጡ** የሚታይ መስኮት።

   - አዲስ አተገባበር ሲጨምሩ ይምረጡ **SSH ወኪል** ከግራ ምናሌ, ከዚያም ከመደብሮች ውስጥ የጨመረውን ቁልፍ ፋይል ይምረጡ **ተያይዞ** ምናሌ ውስጥ **የግል ቁልፍ** ክፍል፤ ከዚያም የሚከተሉትን ቼክ ሳጥኖች ይምረጡ

      - **የመረጃ ቋቱ ሲከፈት/እንደሚከፈት ለኤጀንት ቁልፍ ይጨምሩ**

      - **የመረጃ ቋቱ በሚዘጋ/በተቆለፈበት ጊዜ ቁልፉን ከኤጀንት ያስወግዱ**

      - **ይህ ቁልፍ ሲጠቀሙ የተጠቃሚ ማረጋገጫ ይጠይቁ**

   - አስፈላጊ ሆኖ ሲገኝ ሌሎች ለውጦችን ማድረግ።

   - ዝግጁ ሲሆኑ ይምረጡ **OK** መግቢያውን ለማስቀመጥ.

   ::: details የማጣቀሻ ቅጽበታዊ ገጽ እይታዎችን አሳይ

   ![KeePassXC `Advanced` ትር: የግል ቁልፍ አባሪ ማከል](../../../img/keepassxc_private_key.png)

   ![KeePassXC `SSH Agent` ትር: የግል ቁልፍ አባሪ ማከል](../../../img/keepassxc_pk_agent.png)

   :::

##### የሚጠበቁ ውጤቶች {#expected-results}

- ምስጢራዊ እና `shh` ቁልፎቹ በ KeePassXC የመረጃ ቋት KeePassXC መስኮቱ ክፍት ነው።

- የተከማቸ የክሪፕቶግራፊ እና `ssh` ቁልፎቹ ለፍቃድ ሲያስፈልጉ በማንኛውም ጊዜ ሊጠቀሙባቸው ይችላሉ።

- የተከማቸ የክሪፕቶግራፊ እና `ssh` ቁልፎች ከ `ssh-agent` አንድ ጊዜ KeePassXC መስኮቱ ተዘግቷል።

::: info ማስታወሻ

የ **ይህ ቁልፍ ሲጠቀሙ የተጠቃሚ ማረጋገጫ ይጠይቁ** አማራጩ `ssh-agent` የይለፍ ቃል አስተዳዳሪው ሂደት በማልዌር ወይም በሲስተም አገልግሎት አማካኝነት ከተቋረጠ `SIGKILL` ሲግናል, ቁልፉ ምናልባት በ ውስጥ ይቆያል `ssh-agent`, የዩኒክስ ሥርዓት ፕሮግራሞች መቋቋም ስለማይችሉ `SIGKILL`.

:::

## የክሪፕቶግራፊ ቁልፎችን በአካል ማስቀመጥ {#storing-cryptographic-keys-physically}

ከመስመር ውጪ ከፍተኛውን የደህንነት ደረጃ ለሚፈልጉ ሰዎች ፣ ምስጢራዊ ቁልፎችን የማከማቸት አማራጭ ቁልፎቹ ከዲጂታል አውታረመረቦች ሙሉ በሙሉ እንደተገለሉ ያረጋግጣል ፣ ስለሆነም ያልተፈቀደ መዳረሻ አደጋን በመቀነስ ። አካላዊ አማራጩን መገንዘብ የተለያዩ የደህንነት ፍላጎቶችን ለማሟላት ያለንን ቁርጠኝነት ያጎላል ።

### የሃርድዌር ቁልፍ መጠቀም {#using-a-hardware-key}

የእኛ ቡድን የሃርድዌር ቁልፎች ምርጥ የደህንነት እርምጃዎች አንዱ እንደሆነ ያምናሉ. USB ይህ ማሽን ጋር ከተገናኘ ጊዜ ብቻ የደህንነት ጋር የተያያዙ ክስተቶችን ያካሂዳል. ይህ በቀላሉ የደህንነት ጥሰት ሁኔታ ውስጥ መሣሪያውን ለማቋረጥ ያስችልዎታል, ወይም በቀላሉ አስፈላጊ በሚሆንበት ጊዜ ወደ ሌላ ማሽን እንደገና ለማገናኘት.

ሆኖም ፣ ብዙ የምርት ስሞች ስላሉ የሃርድዌር ቁልፎችእያንዳንዳቸው APIs የእርስዎን ፍላጎቶች በጣም የሚስማማውን ቁልፍ ለማግኘት የገበያ ምርምር ማድረግ አስፈላጊ ነው።

እስካሁን ድረስ ቡድናችን [YubiKey 5C](https://www.yubico.com/il/product/yubikey-5c/) የሃርድዌር ቁልፍ ይህም በርካታ አዎንታዊ ባህሪያት, ጨምሮ ተለዋዋጭ API ተግባራዊነት።

ይሁን እንጂ ሊታሰብበት የሚገባ አንድ ችግር አለ። [HMAC ፈተና-መልስ ማረጋገጫ](https://en.wikipedia.org/wiki/Challenge%E2%80%93response_authentication) እና ተመጣጣኝ የሆነ _የግል_ ለዚህ ምላሽ ቁልፍ አንድ ተጋላጭነት ሊፈጥር ይችላል. ይህ ቅንብር ጠላፊዎች በድንገት ውስጥ የተከማቹ መረጃዎችን በተመለከተ የተማሩ ግምቶችን እንዲያደርጉ ያስችላቸዋል YubiKey የ 5C ማህደረ ትውስታ፣ በዚህም አጠቃላይ የደህንነትን አደጋ ላይ ይጥላል።

እንደ እድል ሆኖ ፣ ይህንን ተጋላጭነት ለመጠቀም አማራጭ አቀራረብን በመከተል ሊቀንስ ይችላል YubiKey 5C. ሀሳቡ መጠቀም ነው YubiKey 5C ደህንነቱ የተጠበቀ መዳረሻ KeePassXC የእርስዎን ምስጢራዊ እና `SSH` ይህ ዘዴ ጠቃሚ ሆኖ ሊቆጠር ይችላል, ምክንያቱም አብዛኛዎቹ የይለፍ ቃሎችን ደህንነት ስለሚበልጥ እና በሃርድዌር ቁልፎችዎ ላይ ጥቃት በሚያሳድርበት ጊዜ ለጠላፊው አስፈላጊ ነው. KeePassXC የመረጃ ቋቱ ተለቅቋል።

### የአእምሮ ሐረግ መጠቀም {#using-a-mnemonic-phrase}

እንደ አማራጭ, አንድ የግል ቁልፍ በመባል የሚታወቀው ቃል ተከታታይ ሆኖ ማስታወስ ይችላሉ _የማንሜኒክ ሐረግ_. ይህ ዘዴ በበርካታ የኪስ ቦርሳዎች ውስጥ ጥቅም ላይ የሚውል ሲሆን 25 ገደማ የተወሰኑ ቃላትን ማስታወስ ይጠይቃል። ቀደም ሲል የተወያዩትን ጨምሮ አብዛኛዎቹ የይለፍ ቃል አስተዳዳሪዎች KeePassXC, የኤምኔሞኒክ የይለፍ ቃል ማመንጨት ያቀርባሉ.
