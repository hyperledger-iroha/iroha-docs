# ከኢዛናሚ ጋር ትርምስ ሙከራ {#chaos-testing-with-izanami}

ኢዛናሚ በላይኛው ተፋሰስ Iroha የስራ ቦታ ውስጥ ያለው ትርምስ ኦርኬስትራ ነው። ሊጣል የሚችል የአካባቢ Iroha ክላስተር ይጀምራል፣ ሊዋቀር የሚችል የስራ ጫና ያቀርባል እና በተመረጡ የአውታረ መረብ እኩዮች ላይ ስህተቶችን ያስገባል ስለዚህ ኦፕሬተሮች አውታረ መረቡ ቁጥጥር በሚደረግበት ውድቀት እድገት ማድረጉን ያረጋግጡ።

ለቅድመ-ምርት የመቋቋም ፍተሻዎች፣ የመልሶ ማቋቋም ማባዛት እና የጋራ መግባባት ማስተካከያ ኢዛናሚን ይጠቀሙ። ወደ ምርት አውታር አይጠቁሙ መሳሪያው የተነደፈ ነው የአውታረ መረብ አቻ ዳግም ማስጀመር፣ የማከማቻ መጥረጊያዎች፣ ጊዜያዊ የታመኑ-አቻ ክፍልፋዮች እና የአካባቢ CPU ወይም የዲስክ ግፊትን ጨምሮ የሚጀምረውን የአውታረ መረብ እኩዮች ባለቤት ለመሆን ነው።

## ቅድመ ሁኔታዎች {#prerequisites}

ኢዛናሚን ከ[Iroha ምንጭ ማከማቻ](https://github.com/hyperledger-iroha/iroha) ያሂዱ እንጂ ከዚህ የሰነድ ማከማቻ አይደለም -

```bash
git clone https://github.com/hyperledger-iroha/iroha.git
cd iroha
cargo build -p izanami
```

ሁለትዮሽ በኔትወርክ የተገናኙ የአውታረ መረብ እኩዮችን እንዲፈጥር እና እንዲቆጣጠር በግልፅ መፍቀድ አለበት። ለእያንዳንዱ TUI ያልሆነ ሩጫ `--allow-net`ን ይለፉ ወይም በ TUI ውስጥ `allow_net`ን ያንቁ።

```bash
cargo run -p izanami -- --allow-net --peers 4 --faulty 1 --duration 120s
```

በይነተገናኝ አሂድ ውቅር -

```bash
cargo run -p izanami -- --tui --allow-net
```

ኢዛናሚ በተጠቃሚ ውቅር ማውጫ ስር TUI እና CLI ቅንብሮችን ይቀጥላል። የመጀመሪያ-ልቀት ፋይል አንድ ግልጽ V1 አቀማመጥ ባይት አለው; ቅድመ-መለቀቅ ወይም በሌላ መንገድ ያልተገለበጡ ቅንጅቶች ውድቅ ተደርገዋል እና ከመሰደድ ይልቅ እንደገና መፈጠር አለባቸው። የአሁኑን መገለጫ እንደገና ከመጠቀምዎ በፊት የሚታዩትን ቅንብሮች ይገምግሙ።

## የመነሻ መስመር አሂድ {#baseline-run}

ከባድ ስህተቶችን ከመጨመራቸው በፊት በአንድ ሊባዛ በሚችል መነሻ ይጀምሩ -

```bash
cargo run -p izanami -- \
  --allow-net \
  --peers 4 \
  --faulty 1 \
  --duration 5m \
  --target-blocks 100 \
  --progress-interval 15s \
  --progress-timeout 120s \
  --latency-p95-threshold 2s \
  --tps 15 \
  --max-inflight 32 \
  --submitters 1 \
  --seed 42
```

ይህ ሩጫ የሚሳካው ክላስተር የተጠየቀው የብሎክ ኢላማ ላይ ከደረሰ፣ በጊዜው ማብቂያ ጊዜ ውስጥ እድገት ማድረጉን ከቀጠለ እና ከአማራጭ p95 የብሎክ ክፍተት ገደብ በታች ከቆየ ብቻ ነው።

ትዕዛዙን፣ ዘርን፣ Iroha የፕሮቶኮል ማጠናቀቂያውን፣ የአውታረ መረብ አቻ ብዛትን፣ የተሳሳተ የአቻ ብዛትን፣ የስራ ጫና መገለጫውን፣ ዒላማ TPS እና የመዘግየት ገደብን ከምዝግብ ማስታወሻዎች ጋር ይመዝግቡ። እነዚህ እሴቶች ከሌሉ ሌላ ኦፕሬተር ተመሳሳይ የውድቀት ንድፍ እንደገና ማጫወት አይችልም።

## የስራ ጫና መገለጫዎች {#workload-profiles}

ኢዛናሚ ሁለት የስራ ጫና መገለጫዎች አሉት -

|ባንድ በኩል የሆነ መልክ|ለ ተጠቀምበት|ማስታወሻዎች|
| -------- | -------------------------------------------------- | -------------------------------------- |
|`stable`|ረጅም የመጥለቅለቅ ሩጫዎች እና ሊባዙ የሚችሉ የአፈጻጸም ፍተሻዎች|አፈፃፀም-አስተማማኝ የተግባር መመሪያዎችን ይደግፋል|
|`chaos`|የውድቀት-መንገድ ሽፋን|ሆን ተብሎ ልክ ያልሆኑ የተግባር መመሪያዎችን ያካትታል|

መጀመሪያ የተረጋጋውን መገለጫ ይጠቀሙ -

```bash
cargo run -p izanami -- --allow-net --workload-profile stable --seed 42
```

መነሻ መስመሩ አስቀድሞ ሲረዳ ወደ ትርምስ መገለጫ ይቀይሩ -

```bash
cargo run -p izanami -- --allow-net --workload-profile chaos --seed 42
```

በግልጽ ካልተፈቀደ በስተቀር የኮንትራት ማሰማራት የተግባር መመሪያዎች በተረጋጋ ሩጫዎች ተሰናክለዋል -

```bash
cargo run -p izanami -- \
  --allow-net \
  --workload-profile stable \
  --allow-contract-deploy-in-stable
```

ሩጫው ከላይ ካለው የስራ ቦታ የተከተተውን SORA Nexus ነባሪዎችን መጠቀም ሲኖርበት `--nexus` ይጠቀሙ።

## የስህተት መቆጣጠሪያዎች {#fault-controls}

`--faulty` ከዜሮ በላይ ሲሆን ቢያንስ አንድ የስህተት ሁኔታ መንቃት አለበት። የስህተት ነባሪውን ወደ ነቃ ይቀያይራል፣ እና የቡሊያን ባንዲራዎች በ`=false` ሊሰናከሉ ይችላሉ።

|ጥፋት|CLI ባንዲራ|ምን ይለማመዳል|
| ------------------------ | ------------------------------------------ | ------------------------------------------ |
|ብልሽት እና እንደገና ያስጀምሩ|`--fault-enable-crash-restart`|የአውታረ መረብ አቻ ሂደት መጥፋት እና መልሶ ማግኛ|
|ማከማቻን ይጥረጉ እና እንደገና ያስጀምሩ|`--fault-enable-wipe-storage`|ከጠፋ የአካባቢ ሁኔታ ማገገም|
|ልክ ያልሆነ የግብይት አይፈለጌ መልእክት|`--fault-enable-spam-invalid-transactions`|የመግቢያ እና ውድቅ መንገዶች|
|የአውታረ መረብ መዘግየት|`--fault-enable-network-latency`|ዘገምተኛ ሐሜት እና የዘገዩ የጋራ ስምምነት መልዕክቶች|
|የአውታረ መረብ ክፍልፍል|`--fault-enable-network-partition`|ጊዜያዊ የታመነ-አቻ ማግለል|
| CPU ውጥረት               |`--fault-enable-cpu-stress`|የአካባቢ ማረጋገጫ እና የመርሐግብር ግፊት|
|የዲስክ ሙሌት|`--fault-enable-disk-saturation`|የአካባቢ ማከማቻ ግፊት|

ለአውታረ መረብ-ክፍልፍል-ብቻ አሂድ -

```bash
cargo run -p izanami -- \
  --allow-net \
  --peers 4 \
  --faulty 1 \
  --duration 5m \
  --fault-window-start 60s \
  --fault-window-end 180s \
  --tps 15 \
  --submitters 1 \
  --max-inflight 32 \
  --fault-enable-crash-restart=false \
  --fault-enable-wipe-storage=false \
  --fault-enable-spam-invalid-transactions=false \
  --fault-enable-network-latency=false \
  --fault-enable-network-partition=true \
  --fault-enable-cpu-stress=false \
  --fault-enable-disk-saturation=false \
  --seed 42
```

ከተወጋው ውድቀት በፊት እና በኋላ ቁጥጥር የሚደረግበት ቋሚ ሁኔታን ለመጠበቅ `--fault-window-start` እና `--fault-window-end` ይጠቀሙ። ይህ የጅምር ድምጽን ከስህተቱ ውጤት ለመለየት ቀላል ያደርገዋል።

## የ ትዕይንት ቅርጾች {#scenario-shapes}

የላይኛው ተፋሰስ ኢዛናሚ ካታሎግ የተለመዱ የብሎክቼይን ግንኙነት-ውድቀት ቅርጾችን ወደ CLI መገለጫዎች ያቀርባል። በተመሳሳይ ባንዲራዎች እነሱን መቅረጽ ይችላሉ -

|ሁኔታ|የተለመደ ቅርጽ|
| --------------------- | ------------------------------------------------------------------------------------------------------------------------ |
|ዒላማ የተደረገ ጭነት|`--faulty 0`፣ ከፍተኛ `--tps`፣ አንድ አስራሚ፣ ከፍተኛ `--max-inflight`|
|ጊዜያዊ ውድቀት|ብልሽት/ዳግም ማስጀመርን አንቃ በተገደበ የስህተት መስኮት ውስጥ ብቻ|
|ማቆም እና ማገገም|ከብልሽት/ዳግም ማስጀመር ጋር ትልቅ የተሳሳተ የአቻ ህዝብ ይጠቀሙ|
|መሪ ማግለል|በትክክል አንድ የተሳሳተ የአውታረ መረብ አቻ በኔትወርክ-ክፍልፋይ ስህተት ብቻ ይጠቀሙ; ኢዛናሚ Sumeragi መሪ ቴሌሜትሪ ይከተላል|

በአንድ ጊዜ አንድ ተለዋዋጭ ቋሚ ያድርጉት። የአውታረ መረብ አቻ ብዛት፣ የስራ ጫና መገለጫ፣ የስህተት መስኮት እና TPS በተመሳሳይ ሩጫ ከቀየሩ ውጤቱን ለመተርጎም አስቸጋሪ ነው።

## ምን መታየት አለበት {#what-to-watch}

በሩጫው ወቅት፣ ለአፈጻጸም ማረጋገጫ የሚያገለግሉ ተመሳሳይ ምልክቶችን ይመልከቱ -

- በእያንዳንዱ የሩጫ አውታረ መረብ አቻ ላይ የብሎክ-ቁመት እድገት
- የገቡ፣ የተቀበሉ፣ ውድቅ የተደረጉ እና ጊዜ ያለፈባቸው ግብይቶች
- የወረፋ ጥልቀት፣ የወረፋ ሙሌት እና API የመጨረሻ ነጥብ የኋላ ግፊት
- ለውጦችን፣ የመልሶ ማግኛ መንገዶችን፣ የጎደሉ ብሎኮችን እና የጎደሉ የምልአተ ጉባኤ የምስክር ወረቀቶችን ይመልከቱ
- የተፈረመ RS16 ተገኝነት የኋላ መዝገብ፣ በመጠባበቅ ላይ ያሉ ክፍለ-ጊዜዎች እና የዘገየ የጋራ መግባባት ትራፊክ
- CPU፣ ማህደረ ትውስታ፣ ዲስክ እና የአውታረ መረብ ሙሌት የአውታረ መረብ እኩዮችን በሚያሄድ አስተናጋጅ ላይ

ለማረጋገጫ-መዘግየት ትንተና፣ ዋና-ሉፕ ማረም ምዝግብ ማስታወሻዎችን አንቃ -

```bash
RUST_LOG=iroha_core::sumeragi::main_loop=debug \
  cargo run -p izanami -- --allow-net --seed 42
```

እያንዳንዱ ብሎክ `block validation timings` በ`stateless_ms`፣ `execution_ms` እና `total_ms` መልቀቅ አለበት። የጋራ መግባባት ሰዓት ቆጣሪዎችን ከመቀየርዎ በፊት እነዚያን ጊዜዎች ከ p95 የብሎክ ክፍተቶች፣ የእይታ ለውጥ ቆጣሪዎች እና ወረፋ ግፊት ጋር ያወዳድሩ።

## ውጤቶችን መተርጎም {#interpreting-results}

ሁሉም የተመረጡ የአውታረ መረብ እኩዮች ብሎኮችን ማጠናቀቃቸውን ሲቀጥሉ፣ የኋላ መዝገብ ያለምንም ገደብ አያድግም እና የተዋቀረው መስኮት ካለቀ በኋላ ስህተቶች አዲስ የመልሶ ማግኛ እንቅስቃሴ መፍጠር ሲያቆሙ ሩጫን እንደ ጤናማ አድርገው ይያዙት።

ሩጫን እንደ ውድቀት ይያዙት -

- ከ `--progress-timeout` የሚረዝሙ የሂደት ማቆሚያዎችን ብሎክ
- የአውታረ መረብ አቻ ከፍታዎች ይለያያሉ እና እንደገና አይሰበሰቡም
- P95 መዘግየት ይበልጣል `--latency-p95-threshold`
- የስህተት መስኮት ከተዘጋ በኋላ ወረፋዎች ለቀሪው ሩጫ ያድጋሉ
- ውድቅ የተደረጉ ወይም ጊዜው ያለፈባቸው ግብይቶች በተመረጠው የስራ ጫና አይገለጹም
- የአውታረ መረብ አቻ ዳግም ማስጀመር፣ ማከማቻ መጥረግ ወይም ክፍልፍል መልሶ ማግኛ በእጅ ማጽዳት ያስፈልገዋል

ከውድቀት በኋላ፣ በተመሳሳዩ ዘር እና አንድ ያነሰ የስህተት አይነት እንደገና ያሂዱ። ይህ የውድቀቱን ወለል በሚጠባበት ጊዜ የስራ ጫናውን እና ጊዜውን እንደገና እንዲባዛ ያደርገዋል።
