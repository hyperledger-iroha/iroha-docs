# SDK ትምህርቶች {#sdk-tutorials}

የስራ ቦታ፣ የካኖኒክ ፓኬጅ ስሞችን፣ የመጫኛ መንገዶችን እና አነስተኛውን
የመነሻ ነጥቦች።

4. የ [ናሙና መተግበሪያዎች](/am/guide/tutorials/sample-apps.md) አንድ

6. አጠቃቀም [Musubi ጥቅሎች](/am/guide/tutorials/musubi.md) ዳግም ጥቅም ላይ የሚውል ሲያስፈልግ
