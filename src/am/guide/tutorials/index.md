# SDK አጋዥ ሥልጠናዎች {#sdk-tutorials}

እነዚህ ገፆች ነጠላ ፕሮቶኮል-መደበኛ የጥቅል ስሞችን፣ የመጫኛ መንገዶችን እና አነስተኛ መነሻ ነጥቦችን ጨምሮ ከዋናው የስራ ቦታ የተላኩትን Iroha 3 የደንበኛ መግቢያ ነጥቦችን ያጠቃልላሉ።

## የሚመከር ትዕዛዝ {#recommended-order}

1. [Iroha 3 ን ጫን](/am/get-started/install-iroha.md)
2. [አስጀምር Iroha 3](/am/get-started/launch-iroha.md)
3. SDK ን ይምረጡ -
   - [Rust](/am/guide/tutorials/rust.md)
   - [Python](/am/guide/tutorials/python.md)
   - [JavaScript / TypeScript](/am/guide/tutorials/javascript.md)
   - [Kotlin፣ Android እና ጃቫ](/am/guide/tutorials/kotlin-java.md)
   - [Swift እና iOS](/am/guide/tutorials/swift.md)
4. የተሟላ የደንበኛ ማመልከቻ ማጣቀሻ ሲፈልጉ [ናሙና መተግበሪያዎች](/am/guide/tutorials/sample-apps.md) ን ይገምግሙ።
5. በኪስ ቦርሳ የተደገፉ የድምጽ/ቪዲዮ ስብሰባዎችን ወደ እራስዎ መተግበሪያ ማከል ሲፈልጉ [መክተት Kaigi](/am/guide/tutorials/kaigi.md) ን ይጠቀሙ።
6. እንደገና ጥቅም ላይ ሊውሉ የሚችሉ Kotodama የምንጭ ቤተ-መጻሕፍት በሰንሰለት ላይ በተሰኩ የመመዝገቢያ ጥገኞች ሲፈልጉ [Musubi ጥቅሎች](/am/guide/tutorials/musubi.md) ይጠቀሙ።
