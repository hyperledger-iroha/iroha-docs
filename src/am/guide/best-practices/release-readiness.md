# ለመልቀቅ ዝግጁ መሆን {#release-readiness}

አንድ Iroha አፕሊኬሽን ወይም የአውታረ መረብ ለውጥ, ባህሪውን ያረጋግጡ
አስፈላጊውን አደጋ ሊያጋልጥ በሚችል አነስተኛ አካባቢ ውስጥ, ከዚያ ይንቀሳቀሱ
በጋራ የሙከራ አውታረመረብ እና በምርት መግቢያዎች በኩል ሆን ተብሎ።

## የአካባቢው አውታረ መረብ በር {#localnet-gate}

- ተመሳሳይ ጋር አንድ ነጠላ አካባቢያዊ አውታረ መረብ ማስጀመር Iroha ትራክ እና
  የቅርብ ተግባራዊ ማረጋገጫዎች ብዛት.
- ለግብይት ገንቢዎች የአንድነት ሙከራዎችን ያካሂዱ ፣ የጥያቄ ማጣሪያ ፣ ውድቅ
  ማቀናበር እና መጫን ማዋቀር.
- አነስተኛውን ስኬታማ ማንበብ እና መጻፍ መንገዶችን በመለማመድ
  SDK ወይም CLI አፕሊኬሽኑ በኋላ ላይ የሚጠቀምበት ቅርጽ።
- የሚጠበቁትን የግብይት ሃሽ, ሁኔታዎችን, ክስተቶችን, እና ሁኔታን ያግኙ
  የሙከራ ዕቃዎች።

ተመልከት [ማስጀመሪያ Iroha 3](/am/get-started/launch-iroha.md) እና
[SDK ትምህርቶች](/am/guide/tutorials/).

## የተጋራ የሙከራ መረብ በር {#shared-testnet-gate}

- አጠቃቀም Taira ወይም ሌላ የተጋራ የሙከራ አውታረመረብ ለኤንድፖይንት ባህሪ ፣ ክፍያዎች ፣ መለያ
  የገንዘብ ድጋፍ፣ መዘግየት እና የአሠራር ልምምዶች።
- የቀጥታ ሙከራኔት ይጻፋል opt- ውስጥ ስለዚህ መደበኛ የሙከራ ሩጫዎች ላይ የሚወሰን አይደለም
  የአውታረ መረብ ተደራሽነት ወይም የሙከራ አውታረ መረቡን የሚጠቀሙበት ገንዘብ።
- የፊርማውን የገንዘብ ድጋፍ፣ የክፍያ አክሲዮን ሜታዳታ፣ የስልጣን ፍቃዶችን ማረጋገጥ፤
  እያንዳንዱን የቀጥታ የሙከራ ግብይት ከማቅረብዎ በፊት የሚጠበቀው ሁኔታ።
- አንድ የጨረር ሁኔታ ይጠብቁ, ከዚያም አንድ ጋር የተገኘው ሁኔታ ማረጋገጥ
  የንባብ ብቻ ጥያቄ።

ተመልከት
[አቋራጭ ሁን SORA 3: Taira እና Minamoto](/am/get-started/sora-nexus-dataspaces.md).

## ዋናው አውታረመረብ ወይም የምርት በር {#mainnet-or-production-gate}

- የተለያዩ የምርት ፊርማዎችን፣ የገንዘብ ድጋፍ፣ ጎራዎች እና የማዋቀር መንገዶችን ይጠቀሙ።
  የሙከራ አውታረ መረብ ቁልፎችን ወይም የቧንቧ ግምቶችን አያስተዋውቁም ።
- ማረጋገጫ SDK, CLI, የአቻ እና አውታረ መረብ ተኳሃኝነት
  [ተኳሃኝነት ማትሪክስ](/am/reference/compatibility-matrix.md).
- የመተንተን ፈቃዶች፣ የክፍያ ስፖንሰርነት፣ የዋጋ ገደቦች፣ ክትትል፣ ምትኬ
  ሁኔታ እና የመልቀቂያ መስኮት ከመጀመሩ በፊት የማስመለስ መመዘኛዎች።
- ከፍተኛ ተጽዕኖ ላላቸው ጽሁፎች የጽሑፍ ግብይት ወይም የስደት ዕቅድ ይጠይቁ ።

## ወደ ኋላ መመለስና መልሶ ማግኛ {#rollback-and-recovery}

- የትኞቹን ለውጦች በኮድ ማሰማራት ሊተገበሩ የሚችሉትን፣
  በሰንሰለት ላይ የሚደረግ ግብይት ሲሆን ይህም በቀጥታ ሊስተጓጎል አይችልም።
- በሰንሰለት ላይ ለሚደረጉ የውሂብ ለውጦች ማካካሻ ግብይቶችን ወይም ፍልሰት ያዘጋጁ
  የመጀመሪያውን ምርት ከመጻፍዎ በፊት ስክሪፕቶችን ይፃፉ.
- ለኔትወርክ ለውጦች, የቀደመውን የሁለትዮሽ ጠብቁ, ማዋቀር ጥቅል, የተፈረመ
  በፈቃደኝነት ወቅት የሚገኝ የአሠራር መደርደሪያ።
- በኦጀኬቲቭ ምልክቶች ላይ በመመርኮዝ ልውውጡን ለማቋረጥ ውሳኔ የሚሰጥበት ቦታ ያዘጋጁ
  እንደ ውድቀት መጠን፣ ረድፍ እድገት፣ መዘግየት ወይም የእኩዮች ጤንነት።

## የመጨረሻው የምርመራ ዝርዝር {#final-checklist}

- ውቅር ለአካባቢው የተወሰነ ሲሆን ለሙከራዎች ብቻ አይሆንም
  ሚስጥሮች።
- የግብይት ዳግም ሙከራ ባህሪ የማይቻል ወይም በግልጽ የተገደበ ነው.
- ማመልከቻው ውድቅ፣ ጊዜ ማብቂያ፣ የጊዜ ገደብ እና መጨረሻ ነጥብ መለያየት ይችላል
  ተደራሽነት አለመሳካት.
- ክትትል የመተላለፊያ ይዘትን፣ መዘግየትን፣ ረድፍ ጥልቀት፣ ውድቀቶችን፣ እይታዎችን ይሸፍናል
  ለውጦች እና አግባብነት ያላቸው የንግድ ክስተቶች።
- ኦፕሬተሮች የሚጠበቁ የክፍያ ሁነቶችን ለመከታተል የመሮጫ መጽሐፍት አሏቸው.
- የደህንነት ግምገማው ቁልፍ ጥበቃን ፣ ፍቃዶችን ፣ የአውታረ መረብ ተጋላጭነትን እና
  አውቶማቲክ ባለስልጣን.
