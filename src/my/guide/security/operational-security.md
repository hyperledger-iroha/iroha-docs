# လုပ်ငန်းလုံခြုံရေး {#operational-security}

လုပ်ငန်းလုံခြုံရေး (OPSEC) သည်လုံခြုံရေးနှင့်အန္တရာယ်စီမံခန့်ခွဲမှုအတွက် စနစ်တကျ ချဉ်းကပ်မှုတစ်ခုဖြစ်ပြီး အဓိကအားဖြင့် ခွင့်ပြုချက်မဲ့ဝင်ရောက်ခြင်းနှင့် ဒေတာသွန်လျှံမှုကို တားဆီးရန် ရည်ရွယ်၍ သီးခြားအသုံးပြုမှုကိစ္စရပ်များအတွက် ကျင့်သုံးသော နည်းဗျူဟာများနှင့် အကြံပေးချက်များကို စုစည်းထားသည်။

<abbr title="Operational Security">OPSEC</abbr> ကုမ္ပဏီ အများစုအတွက် သူတို့ရဲ့ အရင်းအမြစ်တွေရဲ့ တည်ငြိမ်မှုနဲ့ ရရှိနိုင်မှုကို အာမခံဖို့ ပုံမှန်လေ့ကျင့်ခန်းပါ။ ဒါက ရုပ်ပိုင်းလုံခြုံရေး (ဥပမာ၊ စောင့်ကြည့်မှုမရှိတဲ့ post-it မှတ်တမ်းတွေမှာ အန္တရာယ်ရှိတဲ့ အချက်အလက်တွေ မပါဝင်တာ သေချာအောင်လုပ်ခြင်း) ၊ လုံခြုံတဲ့ ဆက်သွယ်ရေး ပရိုတိုကောတွေ (ဥပမာ။ သဲလွန်စတွေကို ကုဒ်မသွင်းဘဲ ပို့တာမျိုးမဟုတ်တဲ့ အချက်အလက်တွေကို ထည့်တွက်ခြင်းတို့ ပါဝင်ပါတယ်။ SMS), ခြိမ်းခြောက်မှုလေ့လာခြင်း (ဥပမာ၊ ဖြစ်နိုင်ခြေရှိတဲ့ မကောင်းဆိုးဝါးပါတီတွေကို ဖော်ထုတ်ခြင်း၊ နောက်ဆုံးသော တိုက်ခိုက်နည်းလမ်းများအကြောင်း သင်ယူခြင်း) ၊ ဝန်ထမ်းသင်တန်း (ဥပမာ။ <abbr title="Operational Security">OPSEC</abbr> အစီအစဉ်များ၊ _အမည်_, (ဥပမာ) Hard Drive တွေကို encrypt လုပ်ခြင်းနဲ့ USB ကိရိယာများ) ။

အဲဒီကတည်းက Iroha ငွေကြေးစာရင်းအဖြစ် အသုံးပြုဖို့ အလားအလာရှိတယ် <abbr title="Operational Security">OPSEC</abbr> ဒီအကြောင်းအရာက တစ်ဦးချင်းတွေနဲ့ အဖွဲ့အစည်းတွေက သုံးတဲ့ နည်းဗျူဟာနဲ့ ချဉ်းကပ်မှုတွေကို သရုပ်ဖော်ပါတယ်။ Iroha သူတို့ရဲ့ လုပ်ငန်းစဉ်တွေမှာ လုံခြုံရေး ပရိုတိုကလုရဲ့ အစိတ်အပိုင်းအဖြစ် ထည့်သွင်းသုံးသပ်သင့်ပါတယ်။

ဤအကြောင်းအရာ၏ လမ်းညွှန်ချက်များကို လိုက်နာပြီး လက်ခံခြင်းသည် အပြည့်အဝ လုံခြုံမှုရရှိရန် လိုအပ်သော အဆင့်တစ်ခုဖြစ်သော်လည်း ၎င်းဘာသာ မလုံလောက်ပါ။ [လုံခြုံရေး](./index.md) ကဏ္ဍနှင့် အထူးသဖြင့် အောက်ပါ အကြောင်းအရာများ:

- [လုံခြုံရေး မူဝါဒများ](./security-principles.md)
- [စကားဝှက်လုံခြုံမှု](./password-security.md)

## အကြံပြုချက် OPSEC တိုင်းတာချက်များ {#recommended-opsec-measures}

- သတိထားပါ။ [ဖြစ်နိုင်ခြေအများဆုံး](https://arxiv.org/pdf/2209.08356.pdf) blockchain ထဲမှာ သူတို့ရဲ့ အရင်းအမြစ်တွေကို ဆုံးရှုံးနိုင်တဲ့ နည်းလမ်းက သူတို့ရဲ့ အာရုံခံတဲ့ အချက်အလက်တွေကို ပေးခြင်းပါ။

- စကေးကို ကုဒ်သွင်းခြင်းအားဖြင့် တိုက်ခိုက်သူတစ်ဦးဟာ Hardware ကို ဝင်ရောက်ခွင့်ရခဲ့တောင်မှ ၎င်းတို့ကို သင့်ဒေတာကို ကာကွယ်နိုင်စေပါတယ်။ သင့်ရဲ့ Portable device တွေအတွက် ဒါကိုလုပ်ခြင်းဟာ နှစ်ဆ ပိုအရေးကြီးတယ်။

- ယုံကြည်မှုရှိတဲ့ ဆော့ဝဲကို သုံးပါ။ ပြန်လည်ဖန်တီးနိုင်တဲ့ ဘိုင်နရီ build တွေကနေ သယ်ဆောင်လာတဲ့ software ကို source ကနေ တည်ဆောက်တာဟာ အယုံအကြည်ဆုံးပါ။ ပိုင်ဆိုင်ထားတဲ့ (သို့) open-source software ကို စစ်ဆေးမထားသေးတာက အစစ်အမှန်ယူဖို့လိုတဲ့ အလားအလာရှိတဲ့ အရဲစွန့်မှုတစ်ခုပါ။

- အာရုံခံတဲ့ ဒေတာတွေပါတဲ့ မိုဘိုင်းကိရိယာတွေကို ဘယ်တော့မှ စောင့်ကြည့်မှုမရှိဘဲ မထားပါနဲ့။

- Binary packages တွေမှာ လက်မှတ်တွေကို စစ်ဆေးပါ။ ဒါက public key cryptography နဲ့ သိပ်မခြားနားပါဘူး။ Iroha.

- အမိန့်မဲ့ ဝင်ရောက်မှုကို တားဆီးရန် သင့်လက်ပ်တော့ပ် (သို့) ကွန်ပြူတာကို စောင့်ကြည့်မှုမရှိဘဲ ထားတဲ့အခါ အမြဲလုံခြုံပါ။ ခိုင်မာတဲ့ စကားဝှက်တွေ သုံးပြီး ဖန်သားပြင်ကို ပိတ်ထားပြီး ကိရိယာတွေကို လုံခြုံဖို့ အကောင်းဆုံးနည်းလမ်းတွေကို လိုက်နာပါ။

- လုံခြုံရေးကို တည်ထောင်ပါ။ [လေအပေါက်များ](https://en.wikipedia.org/wiki/Air_gap_(networking)(၁) သင့်ရဲ့ သော့တွေကို ရှာဖွေတဲ့နေရာ။ ပထမဦးဆုံးအနေနဲ့ သော့တွေကို ကုဒ်သွင်းပြီး _အွန်လိုင်းမှသာ_ အီလက်ထရောမဂ္ဂနီစီယမ်ကာကွယ်မှု တပ်ဆင်ထားသော ကိရိယာ။ [Hardware သော့များ](./storing-cryptographic-keys.md#using-a-hardware-key) ဒီရည်ရွယ်ချက်အတွက် အထူးပြုလုပ်ထားတာပါ။

- ကွန်ပျူတာနှင့်ဖုန်းများအပါအဝင် ကိရိယာအားလုံးတွင် မိမိ၏ ဆော့ဝဲကို နောက်ဆုံးပေါ်ဗားရှင်းသို့ အမြဲတမ်း မွမ်းမံထားပါ။ ပုံမှန် update များက vulnerabilities ကို patch လုပ်ရန်ကူညီပေးပြီး ထို vulnerabilities တွေကို ဖော်ထုတ်မခံရမီတောင်မှ သက်တမ်းကုန်သော software နှင့် ဆက်စပ်သည့် ဖြစ်နိုင်ချေရှိသော အန္တရာယ်များကို အနိမ့်ဆုံးအထိ လျှော့ချပေးသည်။

- Password များနှင့် cryptographic key များကို ပုံမှန် update ပြုလုပ်ရန်အတွက် အကျင့်တစ်ခုကို ဖွံ့ဖြိုးတိုးတက်စေပါ။ ဤ proactive ချဉ်းကပ်မှုက လှုပ်ရှားနေသော ပစ်မှတ်တစ်ခုခုကို ထိခိုက်ဖို့ ပိုခက်ခဲတာကြောင့် ယေဘုယျလုံခြုံရေးအနေအထားကို မြှင့်တင်ရာမှာ သိသိသာသာ ပါဝင်ပါတယ်။

## Browser များကို အသုံးပြုခြင်း {#using-browsers}

လျှောက်လွှာတစ်ခုနှင့် ချိတ်ဆက်ထားလျှင် Iroha web ကိုပါ ၀ င်သည်။ UI, သင့် browser က လုံခြုံမှုကို ကူညီနိုင်တယ် ဒါမှမဟုတ် ခြိမ်းခြောက်မှု ဖြစ်နိုင်တယ်ဆိုပါစို့။ အထူးသဖြင့် သင်တပ်ဆင်ဖို့ ရွေးချယ်တဲ့ plugins တွေအတွက်တော့ သတိထားဖို့လိုပါတယ်။

သင်၏ ရှာဖွေရေး လုံခြုံမှုကို မြှင့်တင်ရန် အောက်ပါ နည်းလမ်းများကို စဉ်းစားကြည့်ပါ။

- လုံခြုံမှု မကောင်းတဲ့ ပုံစံတွေရှိပြီး သုံးစွဲသူတွေရဲ့ ဒေတာတွေကို သွင်းပေးတာလို့ သိကြတဲ့ ရှာဖွေရေးကိရိယာတွေကို အသုံးပြုဖို့ ရှောင်ရှားပါ။
  
  ကိုယ်ရေးအချက်အလက် ချိုးဖောက်မှုတွေနဲ့ လုံခြုံရေး ပြဿနာတွေကို ဘယ် browser မှာမဆို ရှာနိုင်ပါတယ်။ ဥပမာ [ဒီဆောင်းပါးက Browser Privacy အကြောင်းပါ။](https://www.unixsheikh.com/articles/choose-your-browser-carefully.html) Chrome, Safari, Opera, Vivaldi, Edge စသည်တို့ကဲ့သို့သော ပိုင်ဆိုင်သော ရှာဖွေရေးကိရိယာများတွင် ၎င်းတို့၏ကုဒ်များကို အများပြည်သူထံမှ ဖုံးကွယ်ထားခြင်းကြောင့် စစ်ဆေးရန် အလွန်ခက်ခဲကြောင်း သတိပြုပါ။

- သုံးစွဲသူတွေရဲ့ သီးသန့်ဘဝနဲ့ လုံခြုံမှုကို တန်ဖိုးထားကာ ကာကွယ်တဲ့ သမိုင်းကို ကောင်းမွန်စွာ မှတ်သားထားတဲ့ ရှာဖွေရေးစနစ်တွေကို ဦးစားပေးပါ။
  - [လစ်ဗြော့ဖ်](https://librewolf.net/), [ရေခဲကြောင်](https://www.gnu.org/software/gnuzilla/), [မီးရှို့ခြင်း](https://github.com/dr460nf1r3/firedragon-browser), စသည်ဖြင့် Mozilla Firefox ၏ ကောင်းမွန်စွာတည်ထောင်ထားသော fork များနှင့် လုံခြုံရေးအချက်အလက်များ ထပ်မံဖြည့်စွက်ခြင်း။
  - [မျက်စိမမြင်သော ခရိုမီယမ်](https://github.com/ungoogled-software/ungoogled-chromium)  Google Chrome ၏ အလွန်စစ်ဆေးထားသော Open Source ဗားရှင်းတစ်ခုဖြစ်ပြီး လုံခြုံရေးအတိုးမြှင့်ချက်များနှင့်အတူ တိုးတက်လာပြီး Google နှင့်သက်ဆိုင်သော ဝက်ဘ် ၀ န်ဆောင်မှုအားလုံးကို ဖယ်ရှားထားသည်။
  - [သတ္တိရှိတယ်](https://brave.com/)  အလွန်စစ်ဆေးထားသော Open Source ဗားရှင်း [Google Chromium](https://www.chromium.org/Home/) နောက်ထပ် လုံခြုံရေး အကူအညီတွေနဲ့ တိုးမြှင့်ထားတာပါ။ <abbr title="Virtual Private Network">VPN</abbr> ပြီးတော့ ကြော်ငြာပိတ်တဲ့ လုပ်ဆောင်ချက်ပါ။
  - [Falkon](https://www.falkon.org/)  open-source Qt အခြေခံ web browser ကို (တည်ဆောက်ထားသည် `QtWebEngine`, အိတ်တစ်ထည် [Google Chromium](https://www.chromium.org/Home/)) တွင် လုံခြုံမှု မှတ်တမ်းရှိပြီး ၎င်း၏ [KDE ဆိုင်စာမျက်နှာ](https://store.falkon.org/browse/).
  - [Qutebrowser](https://qutebrowser.org/)  open-source Qt အခြေခံ web browser ကို (တည်ဆောက်ထားသည် `QtWebEngine`, အိတ်တစ်ထည် [Google Chromium](https://www.chromium.org/Home/)) ကိုလုံခြုံမှု မှတ်တမ်းသိရှိ; ကီးဘုတ်ကိုအာရုံစိုက်တဲ့ ထူးခြားတဲ့နည်းလမ်းတစ်ခုနဲ့ minimalist GUI; လုံခြုံရေး ကျွမ်းကျင်သူ အများအပြားအတွက် ရွေးချယ်စရာ ရှာဖွေရေးကိရိယာအဖြစ် သတ်မှတ်ထားတယ်။

- အတတ်နိုင်အောင်လုပ်တာ ရှောင်ပါ `JavaScript` လိုအပ်တာမဟုတ်ရင်ပေါ့။

- Plugins တွေအတွက် browser ထဲက built-in confinement mechanism ကို အသုံးပြုပြီး install လုပ်ထားတဲ့ plugins တွေမှာရှိတဲ့ access rights တွေကို ကန့်သတ်ပေးပါ။

- အရေးကြီးတဲ့ လုပ်ငန်းတွေ မလုပ်ခင်နဲ့ ပြီးရင် ကွတ်ကီးတွေကို ရှင်းလင်းပါ။ **ကျွန်မကို လက်မှတ်ရေးထိုးထားပါ** ဒါမှမဟုတ် **ကျွန်မကို မှတ်မိပါ** တချို့ ဝက်ဘ်ဆိုဒ်တွေမှာ ဒီ feature ကို default လုပ်ထားတာကို သတိရပါ။

- ကြော်ငြာပိတ်စက်ကို အသုံးပြုပါ။ ဒါတွေက ကြော်ငြားတွေကို ပိတ်လိုက်ရုံတင်မက ဝက်ဆိုဒ် ခြေရာခံတဲ့ လုပ်ဆောင်ချက်တွေကိုလည်း ပိတ်ထားတယ်။ သင်သုံးတဲ့ ရှာဖွေရေးကိရိယာပေါ် မူတည်ပြီး ကြော်ငြାပိတ်စက်ဟာ ထည့်သွင်းထားတဲ့ လုပ်ဆောင်ချက်မဟုတ်လောက်ပါဘူး။

- တူညီတဲ့ ဇာတ်ကောင်တွေကို သတိထားပါ။ (ဥပမာ။ `0`, `θ`, `O`, `О`, `ዐ` နှင့် `߀` ဒီလို အသေးစိတ်တွေကို အာရုံစိုက်ခြင်းက သင်ဟာ Phishing တိုက်ခိုက်မှုကနေ ကယ်တင်နိုင်မှာပါ။

- ဝက်ဘ်ကို ရှောင်ရှားပါ။ UI အီးမေးလ် client ကို desktop client တွေအတွက် အသုံးပြုပါ။ မသုံးခင်မှာ လက်မှတ်ထိုးပြီး စစ်ဆေးဖို့ desktop email client ကို set up လုပ်လိုက်ပါ။ GPG အဓိက လက်မှတ်တွေ။

- အွန်လိုင်းအခြေခံ စာတိုပို့ဆောင်ရေး ဝန်ဆောင်မှုများကို အသုံးပြုခြင်းမှ ရှောင်ရှားပါ။ ဥပမာ, Discord (အသိဆိုးဝါးတဲ့ `electron` Framework) သည် Discord ၏ ဝက်ဘ်ဗားရှင်းဖွင့်ထားသော Google Chromium ပြူတင်းပေါက်ကဲ့သို့သော တိုက်ခိုက်မှုများစွာကို ခံနိုင်ရည်ရှိသည်။

- နောက်ဆုံးပေါ်ဗားရှင်းကို တတ်နိုင်သလောက် Update လုပ်ပါ။ Update တွေမှာ အန္တရာယ်များတဲ့ လုံခြုံရေး patches တွေ ပါဝင်ပါတယ်။

- သင် install လုပ်တဲ့ browser extension တွေကို သတိပြုပါ။ နာမည်ကြီးရင်းမြစ်တွေကနေ သိသာပြီး ယုံကြည်ရတဲ့ extension တွေပဲ သုံးပါ။ Rogue extension တွေက သင့်ရဲ့ data နဲ့ privacy ကို ထိခိုက်စေနိုင်ပါတယ်။

- နေ့စဉ် ရှာဖွေရေးအတွက် သီးခြား browser profile များကို ဖန်တီးပါ။ နေ့စဉ်ရှာဖွေရေးအတွက် profile တစ်ခုကို အသုံးပြုပြီး လုံခြုံမှုမြင့်မားနဲ့ အာရုံခံအချက်အလက်များ ပါဝင်တဲ့ လုပ်ဆောင်ချက်များအတွက် နောက်တစ်ခုကို သုံးပါ။ ဒီနည်းဖြင့် နေ့စဉ်ရှာရှုရေးအတွက် profile ပေါ်တွင် တပ်ဆင်ထားသော extension တွေဟာ လုံခြုံတဲ့ တစ်ခုမှ အာရုံခံ အချက်အလက်များကို ဝင်ရောက် မရနိုင်ပါ။

- သင့် browser ကို portable version ကို အသုံးပြုပြီး USB Flash Drive: ဤနည်းလမ်းသည် လုံခြုံရေးအမှားတစ်ခုက တပ်ဆင်ထားသော plugins တစ်ခုကို profile များအကြား ဒေတာသို့ ဝင်ရောက်ခွင့်ပေးသော်လည်း လုံခြုံမှုနှင့်သက်ဆိုင်သည့် သင်၏ profile သည် သီးခြားပြီး ဖယ်ရှားနိုင်သော ကိရိယာတွင်ရှိနေသည်ကို သေချာစေသည်။

- သင့်ကိရိယာမှာ မတော်တဆ သိမ်းဆည်းထားနိုင်တဲ့ ဖြစ်နိုင်ခြေရှိတဲ့ အန္တရာယ်များတဲ့ ဒေတာတွေကို ဖယ်ရှားဖို့ သင့် browser ရဲ့ cache နဲ့ cookie တွေကို ပုံမှန်ရှင်းလင်းပါ။

## ပြန်လည်ထူထောင်ရေး အစီအစဉ် {#recovery-plan}

အန္တရာယ်များသော အခြေအနေများတွင် လုံခြုံရေး ချိုးဖောက်မှု သို့မဟုတ် သော့တစ်ချောင်း ဆုံးရှုံးခြင်းတို့ဖြင့် ကြိုတင်ပြင်ဆင်ထားပြီး ကောင်းမွန်စွာ တည်ဆောက်ထားသည့် ပြန်လည်ထူထောင်ရေး အစီအစဉ်သည် အရေးပါသည်။

အဖွဲ့အစည်းတွေဟာ သူတို့ရဲ့ ပြန်လည်ထူထောင်ရေး အစီအစဉ်ကို ပြုစုရာတွင် အောက်ပါ အဓိက ရှုထောင့်တွေကို ထည့်သွင်းစဉ်းစားသင့်ပါတယ်။

- Key loss (သို့) အခြားလုံခြုံရေးဖြစ်စဉ်များတွင် လိုက်နာရမည့် အဆင့်ဆင့် လုပ်ငန်းစဉ်များကို ဖော်ပြပါ။ အသုံးပြုသူများနှင့်/သို့မဟုတ် ဝန်ထမ်းများအနေဖြင့် ဤလုပ်ငန်းစဉ်များကို အလွယ်တကူရရှိနိုင်ပြီး နားလည်နိုင်အောင် သေချာစေရန်။

- လုံခြုံရေး ချိုးဖောက်မှုတွေနဲ့ လစ်လပ်သွားတဲ့ (သို့) ပျောက်ဆုံးသွားတဲ့ သော့နဲ့ စကားဝှက်လို ဖြစ်နိုင်ခြေရှိတဲ့ ခြိမ်းခြောက်မှုတွေကို ချက်ချင်း အစီရင်ခံဖို့ အသုံးပြုနိုင်တဲ့ ဆက်သွယ်ရေး လမ်းကြောင်းတစ်ခု ထူထောင်ပါ။

- Hardware key တွေကို သုံးရင် (ဥပမာ၊ [YubiKey](https://www.yubico.com/products/) ဒါမှမဟုတ် [SoloKeys တစ်ကိုယ်တော်](https://solokeys.com/collections/all)) လုံခြုံရေးအစီအစဉ်တစ်ခုအဖြစ် redundancy နည်းဗျူဟာကို လက်ခံဖို့ စဉ်းစားပါ။ သော့နှစ်ခုကို သိမ်းထားပါ၊ တစ်ခုက နေ့စဉ်သုံးပြီး နောက်တစ်ခုက ဘေးကင်းတဲ့နေရာမှာ သိုလှောင်ထားတယ်။ အဓိကသော့ကို ထိခိုက်ခံရတာ (သို့) ဆုံးရှုံးသွားရင်တောင် ဒီကာကွယ်မှုနည်းလမ်းက ဝင်ရောက်မှုကို အာမခံပေးပါတယ်။

- လုံခြုံရေး ချိုးဖောက်မှု (သို့) ပေါက်ကြားမှု အစီရင်ခံတဲ့အခါ ထိခိုက်ခံရတဲ့ သော့များနှင့် စကားဝှက်များကို အစားထိုးခြင်း သို့မဟုတ် ပိတ်ခြင်းဖြင့် ချက်ချင်း တုံ့ပြန်ပါ။ ဒီလက်တွဲတုံ့ပြန်မှုက ဖြစ်နိုင်ခြေရှိတဲ့ အန္တရာယ်နဲ့ ပျက်စီးမှုကို အနိမ့်ဆုံးအထိ လျှော့ချပေးပါတယ်။

- သင့်ရဲ့ ပြန်လည်ထူထောင်ရေး အစီအစဉ်ကို ပုံမှန်ပြန်လည်သုံးသပ်ပြီး မွမ်းမံပေးပါ။ ဒါက သင့်လုံခြုံမှု ရှုခင်း ပြောင်းလဲလာတာနဲ့အမျှ အစီအစဉ်ဟာ ဆက်လက် သက်ဆိုင်ပြီး ထိရောက်နေတာကို အာမခံပါတယ်။

::: warning

ပြန်လည်ထူထောင်ရေး အစီအစဉ်ဟာ နောက်ထပ်စာရွက်စာတမ်းတစ်ခုသာ မဟုတ်ဘဲ မျှော်လင့်မထားတဲ့ စိန်ခေါ်မှုများကို ကျော်လွှားဖို့ ကူညီပေးတဲ့ အသက်ကယ်လိုင်းတစ်ခုဖြစ်တာကို သတိရပါ။ ဖြစ်နိုင်ခြေရှိတဲ့ အခြေအနေတွေကို ကြိုတင်ခန့်မှန်းပြီး လုပ်ဆောင်ချက်အတွက် ရှင်းလင်းတဲ့ လမ်းညွှန်ချက်ကို ချမှတ်ခြင်းအားဖြင့် သင့်ရဲ့ လုပ်ငန်းလုံခြုံမှုကို ခိုင်မာစေကာ လုံခြုံရေး ဖြစ်ရပ်တိုင်းကို ထိရောက်စွာ တုံ့ပြန်ဖို့ သင့်ပြင်ဆင်မှုကို မြှင့်တင်ပါတယ်။

:::
