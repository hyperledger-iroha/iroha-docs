# လုံခြုံရေး မူဝါဒများ {#security-principles}

အဖွဲ့အစည်းများနှင့် တစ်ဦးချင်း အသုံးပြုသူများသည် လုံခြုံသော တုံ့ပြန်ဆက်သွယ်မှုများကို သေချာစေရန် ပူးပေါင်းဆောင်ရွက်ရန် လိုအပ်ပါသည်။ Iroha ဒီဆွေးနွေးပွဲမှာ ဒီပူးပေါင်းဆောင်ရွက်မှုရဲ့ အခြေခံမူတွေကို ရှင်းပြထားပါတယ်။

## အထွေထွေလုံခြုံရေးမူဝါဒများ {#general-security-principles}

1. A ကိုသုံးပါ [Virtual Private Network ကို](./vpn.md) (VPN):

    - အထူးသဖြင့် အများသုံးကွန်ရက်များမှတဆင့် ထိခိုက်လွယ်သော ဒေတာ သို့မဟုတ် အရင်းအမြစ်များကို ဝင်ရောက်ကြည့်ရှုရာတွင် <abbr title="Virtual Private Network">VPN</abbr> သင့်ရဲ့ အချက်အလက်တွေကို ကာကွယ်ပေးမယ့် လုံခြုံတဲ့ ဆက်သွယ်မှုကို ထူထောင်ဖို့ပါ။

2. ကွန်ရက်ကာကွယ်ရေးအတွက် firewall ကို အသုံးပြုပါ။

    - အမိန့်မဲ့ဝင်ရောက်မှုကို တိုက်ဖျက်ရန်နှင့် ချိတ်ဆက်ထားသော ကိရိယာများကို ဗိုင်းရပ်စ်များနှင့် မော်လ်ဝဲမှ ကာကွယ်ပေးရန် မီးသတ်နံရံကို တပ်ဆင်ခြင်းဖြင့် အိမ်နှင့်/သို့မဟုတ်ရုံးကွန်ရက်များကို အားဖြည့်ပါ။

3. ရုပ်ပိုင်းနှင့် ဒစ်ဂျစ်တယ် အချက်အလက်များကို လုံခြုံစေရန်။

    - စိတ်ချရတဲ့ အချက်အလက်တွေပါတဲ့ ရုပ်ပိုင်း စာရွက်စာတမ်းတွေကို လုံခြုံတဲ့ နေရာမှာ ကာကွယ်ပေးပြီး ဒစ်ဂျစ်တယ် စာရွက်စာရွက်တွေကို စကားဝှက်နဲ့ ကာကွယ်ထားတဲ့ folder တွေထဲမှာ ကုဒ်သွင်းထားပြီး သိမ်းဆည်းထားတာ သေချာစေပါ။

4. ဒေတာကို ပုံမှန် Backup လုပ်ပါ။

    - သင့်ရဲ့ အရေးကြီးတဲ့ အချက်အလက်တွေရဲ့ မိတ္တူတွေကို လုံခြုံတဲ့ နေရာမှာ အမြဲ သိမ်းထားပါ။ ဒီနည်းနဲ့ သင်ဟာ ဒေတာတွေ ဆုံးရှုံးသွားရင် (သို့) တစ်ခုခု မှားသွားရင် အရာရာကို အမြန် ပြန်လည်ထိန်းသိမ်းနိုင်တာပါ။ ဒီနောက်ခံအချက်အလက်တွေကို ပုံမှန် ထိန်းသိမ်းထားတဲ့နေရာကနေ ခြားနားတဲ့ ဘေးကင်းတဲ့နေရာမှာ သိမ်းထားပါ။

## တစ်ဦးချင်း အသုံးပြုသူများအတွက် လုံခြုံရေး မူဝါဒများ {#security-principles-for-individual-users}

1. ခိုင်မာတဲ့ စစ်ဆေးရေး စည်းမျဉ်းတွေကို လက်ခံပါ။

    - အကောင့်အားလုံးအတွက် ခိုင်မာပြီး ထူးခြားတဲ့ စကားဝှက်တွေ သုံးပါ။

    - စကားဝှက်တွေကို ဘယ်တော့မှ ပြန်မသုံးပါနဲ့။

    - တပ်ဆင်ထားပါ <abbr title="Two-Factor Authentication">2FA</abbr> ဖြစ်နိုင်သမျှတိုင်းပါ။ <abbr title="Two-Factor Authentication">2FA</abbr> Password လိုတာတင်မဟုတ်ပဲ နောက်ထပ်အချက်တစ်ခုလို <abbr title="One-Time Password">OTP</abbr>, လက်ဗွေရာ၊ ဒါမှမဟုတ် တတိယဖက် app based authentication (ဥပမာ Google Authenticator)

    - အသုံးပြုခြင်းကို ရှောင်ရှားပါ။ SMS အတည်ပြုချက်က ဒုတိယအချက်ပါ။ မကောင်းဆိုးဝါး ဆော့ဝဲက သင့်ရဲ့ SMS ဥပမာ၊ Android လျှောက်လွှာတွေဟာ သူတို့အတွက် သီးသန့် ရည်ရွယ်ထားတဲ့ သတင်းအချက်အလက်တွေကိုသာ ဝင်ရောက်ခွင့်ပြုဖို့ ကန့်သတ်လို့မရဘူး။

2. ဒစ်ဂျစ်တယ် ဆက်သွယ်ရေးမှာ သတိထားပါ။
    - လက်မှတ်ထိုးပြီး အီးမေးလ်တွေအားလုံးရဲ့ လက်မှတ်တွေကို စစ်ဆေးဖို့ email client ကို ဖန်တီးပါ။ ပေးပို့သူရဲ့လိပ်စာကို ဟန်ဆောင်ပြီး ဘဏ်တစ်ခုအဖြစ်တောင် ကိုယ်စားပြုနိုင်ပေမဲ့ လက်မှတ်တုလုပ်တာတော့ မဖြစ်နိုင်ပါဘူး။
    - နှစ်ခုစလုံးကို ပိတ်လိုက်ပါ HTML မသိတဲ့ (သို့) စစ်ဆေးမထားတဲ့ လိပ်စာတွေကနေ ပြင်ပ ရင်းမြစ်တွေကို ပို့ပေးခြင်း။

    - သံသယရှိတဲ့ အီးမေးလ်တွေ၊ လင့်ခ်တွေနဲ့ ကိုယ်ရေးအချက်အလက်တောင်းဆိုချက်တွေကို သိရှိဖို့နဲ့ ရှောင်ရှားဖို့ အများသုံးတဲ့ phishing နည်းစနစ်တွေအကြောင်း လေ့လာပါ။

    - လက်မှတ်ထိုးပြီး အီးမေးလ်တွေအားလုံးရဲ့ လက်မှတ်တွေကို စစ်ဆေးဖို့ email client ကို ဖန်တီးပါ။ ပေးပို့သူရဲ့လိပ်စာကို ဟန်ဆောင်ပြီး ဘဏ်တစ်ခုအဖြစ်တောင် ကိုယ်စားပြုနိုင်ပေမဲ့ လက်မှတ်တုလုပ်တာတော့ မဖြစ်နိုင်ပါဘူး။

3. ကိုယ်ရေးအချက်အလက်ကို ကာကွယ်ပေးရန်

    - သင့်ရဲ့ကိုယ်ပိုင်အချက်အလက်ကို မျှဝေခြင်း

    - ကိုယ်ဆက်သွယ်နေတဲ့ လူပုဂ္ဂိုလ် (သို့) အဖွဲ့အစည်းတွေကို လွတ်လပ်စွာ သုတေသနပြုပြီး သူတို့ရဲ့ ကိုယ်ပိုင်လက္ခဏာကို အတည်ပြုဖို့ စဉ်းစားပါ။

    - လူမှုမီဒီယာတွေပေါ်မှာ မျှဝေတဲ့ ကိုယ်ရေးအချက်အလက်တွေကို သတိထားပါ၊ မကောင်းဆိုးဝါးတဲ့ အဖွဲ့အစည်းတွေက ဒီသတင်းအချက်အလက်ကို စွဲသုံးနိုင်လို့ပါ။

## အဖွဲ့အစည်းများအတွက် လုံခြုံရေးမူဝါဒများ {#security-principles-for-organisations}

1. ရှင်းလင်းသော လုံခြုံရေး မူဝါဒများနှင့် လုပ်ငန်းစဉ်များကို ဖော်ထုတ်ရန်။

    - ထိခိုက်လွယ်သော ဒေတာနှင့် ပတ်သက်၍ တာဝန်ရှိသူအားလုံးအတွက် လုံခြုံရေး မူဝါဒများနှင့် ပရိုတိုကောများကို ကောင်းကောင်း သတ်မှတ်ထားပြီး ဝန်ထမ်းများကို ဤညွှန်ကြားချက်များကို လိုက်နာရန် ကျယ်ပြန့်စွာ သင်ကြားပေးခြင်းဖြင့် လျော့ကျသည့် အလျင်အမြန် လုပ်ဆောင်မှုအန္တရာယ်ကို လျှော့ချနိုင်သည်။

    - လုံခြုံရေး မူဝါဒများသည် ဝန်ထမ်းအားလုံးအတွက် ရယူနိုင်ပြီး ပြောင်းလဲနေသော လုံခြုံရေး ရှုခင်းများကို ထင်ဟပ်စေရန် ပုံမှန် ပြန်လည်သုံးသပ်ခြင်းနှင့် မွမ်းမံခြင်းကို သေချာစေရမည်။

    - လုံခြုံရေး မူဝါဒများကို ဝန်ထမ်းများအတွက် ပိုမိုသိရှိနားလည်နိုင်စေရန် နမူနာများနှင့် စင်တီယာများဖြင့် ပေးပါ။

2. ဝန်ထမ်းများအတွက် အသိပညာပေးခြင်း။

    - ဝန်ထမ်းများအား အချက်အလက်များနှင့် လုပ်ငန်းလုံခြုံရေးဆိုင်ရာ အစီအစဉ်များကို သင်ကြားပေးရန်။

    - ဝန်ထမ်းတွေကို သံသယရှိတဲ့ လှုပ်ရှားမှု (သို့) လုံခြုံရေးဆိုင်ရာ စိုးရိမ်မှုတွေ ရှိသမျှကို ချက်ချင်း တိုင်ကြားဖို့ အားပေးပါ။

3. ရုပ်ပိုင်း အခြေခံအဆောက်အအုံကို ကာကွယ်ပေးပါ။

    - ဆာဗာများနှင့် အခြေခံအဆောက်အအုံများကို ရုပ်ပိုင်းဝင်ရောက်မှုကို ကန့်သတ်ပါ။ ခွင့်ပြုထားသော ဝန်ထမ်းများသာ ကန့်သတ်ထားတဲ့ နေရာများသို့ ဝင်ခွင့်ပြုသည့် ဝင်ရောက်မှုထိန်းချုပ်မှုများကို သတ်မှတ်ပါ။

    - လုံခြုံရေး လိုအပ်ချက်များ ပြောင်းလဲလာခြင်းနှင့်အညီ ဝင်ရောက်ထိန်းချုပ်မှုဆိုင်ရာ အစီအစဉ်များကို ပုံမှန် ပြန်လည်သုံးသပ်ပြီး အပေါ်လွင်စေရန်။

    - ရုပ်ပိုင်းလုံခြုံမှုကို မြှင့်တင်ဖို့ အာရုံခံတဲ့ နေရာတွေအတွက် ဇီဝမီတာဝင်ရောက်မှု ထိန်းချုပ်မှုတွေ အကောင်အထည်ဖော်ဖို့ စဉ်းစားပါ။

4. လုံခြုံရေး စောင့်ကြည့်မှုကို စေလွှတ်ပါ။

    - လုပ်ဆောင်ချက်များကို စစ်ဆေးပြီး လုံခြုံရေး ချိုးဖောက်မှု ဖြစ်နိုင်ခြေကို ဖော်ထုတ်တဲ့ အပြည့်အဝ လုံခြုံရေး စောင့်ကြည့်ရေးစနစ်ကို အကောင်အထည်ဖော်ပါ။

    - ပုံမှန်မဟုတ်တဲ့ (သို့) ခွင့်ပြုချက်မရှိတဲ့ လှုပ်ရှားမှုတစ်ခုခုကို လုံခြုံရေးဝန်ထမ်းတွေကို အမြန် အသိပေးဖို့ အလိုအလျောက် သတိပေးချက်တွေ အကောင်အထည်ဖော်ပါ။

    - စက်သင်ယူမှု အယ်လ်ဂိုရစ်သမ်တွေကို သုံးပြီး စနစ်ရဲ့ ထူးခြားချက်တွေနဲ့ အလားအလာရှိတဲ့ ခြိမ်းခြောက်မှုတွေကို ဖော်ထုတ်နိုင်စွမ်းကို မြှင့်တင်ဖို့ စဉ်းစားပါ။

    - ဒေတာဘေ့စ် လုံခြုံမှုကို ကြီးကြပ်ဖို့ ဝန်ထမ်းများ (သို့) တာဝန်ပေးသူများကို ခန့်အပ်ခြင်း၊ ဆော့ဝဲ အားနည်းချက်များကို ဖော်ထုတ်ခြင်း၊ ခြေရာခံခြင်းနှင့် ဖြေရှင်းရန်၊ ခွင့်ပြုထားသောစာရင်းတွင် မပါ ၀ င်သည့် ခွင့်ပြုချက်မဲ့ ဆော့ဝိုင်းရှိမရှိကို သိရှိရန် အရေးပါတဲ့ စက်များအပေါ် ပုံမှန် စစ်ဆေးမှုများ ပြုလုပ်ရန်။

5. အကြိမ်ကြိမ် လုံခြုံရေး စစ်ဆေးမှုများ ပြုလုပ်ခြင်း

    - ချို့ယွင်းချက်များကို အကဲဖြတ်ရန်နှင့် တည်ထောင်ထားသော လုံခြုံရေးဆိုင်ရာ အစီအစဉ်များသည် အများပြည်သူ လက်ခံသည့် စံနှုန်းများနှင့် စည်းမျဉ်းစည်းကမ်းများနှင့် ကိုက်ညီကြောင်း အတည်ပြုရန် ပုံမှန်လုံခြုံရေး စစ်ဆေးမှုများ ပြုလုပ်ပါ။

    - သင့်အဖွဲ့အစည်းရဲ့ လုံခြုံရေးအခြေအနေကို ဘက်မလိုက်ဘဲ အကဲဖြတ်နိုင်ဖို့ အပြင်ဘက်လုံခြုံရေး ကျွမ်းကျင်သူတွေကို ခဏခဏ အကဲဖြတ်ဖို့ ငှားကြည့်ပါ။

6. ဝင်ရောက်မှုထိန်းချုပ်ရေးစနစ်ကို အကောင်အထည်ဖော်ခြင်း

    - ဝန်ထမ်းများအနေဖြင့် ၎င်းတို့၏ အခန်းကဏ္ဍအတွက် လိုအပ်သော အရင်းအမြစ်နှင့် သတင်းအချက်အလက်များကိုသာ ရယူနိုင်စေရန် အတွက် ရာထူးအခြေခံဝင်ရောက်မှုထိန်းချုပ်ရေးစနစ်ကို ထူထောင်ပါ။

7. ဆက်လက်တိုးတက်မှုကို လက်ခံကြပါ။

    - လုံခြုံရေးသည် ဆက်လက်ဖြစ်စဉ်တစ်ခုဖြစ်ကြောင်း အသိအမှတ်ပြုခြင်း၊ လုံခြုံရေးဆိုင်ရာ အစီအစဉ်များအား ဆက်လက် အကဲဖြတ်ခြင်းနှင့် ပေါ်ပေါက်လာသော ခြိမ်းခြောက်မှုများနှင့် စိန်ခေါ်မှုများကို ဖြေရှင်းရန် ၎င်းတို့အား ပရိုကက်တစ်နည်းဖြင့် မြှင့်တင်ခြင်း။

    - လုံခြုံရေးတိုးတက်မှု အကြံပြုချက်များကို ပေးပို့ရန် ဝန်ထမ်းများအား တိုက်တွန်းစေသော တုံ့ပြန်ဆက်သွယ်မှု စက်ဝန်းကို ထူထောင်ရန် စဉ်းစားကြပါ။
