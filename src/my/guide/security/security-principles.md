# လုံခြုံရေး မူဝါဒများ {#security-principles}

Iroha တပ်ဆင်မှုတွေနဲ့ လုံခြုံတဲ့ တုံ့ပြန်ဆက်သွယ်မှုကို အာမခံဖို့ အဖွဲ့အစည်းတွေနဲ့ တစ်ဦးချင်း သုံးစွဲသူတွေ ပူးပေါင်းဆောင်ရွက်ဖို့လိုပါတယ်။ ဒီဆွေးနွေးပွဲမှာ ဒီပူးပေါင်း ဆောင်ရွက်မှုရဲ့ အခြေခံမူတွေကို ရှင်းပြထားပါတယ်။

## အထွေထွေလုံခြုံရေးမူဝါဒများ {#general-security-principles}

1. [Virtual Private Network ](./vpn.md) (VPN) ကို အသုံးပြုပါ။

    - အထူးသဖြင့် အများသုံးကွန်ရက်များမှတဆင့် ထိခိုက်လွယ်သော ဒေတာ သို့မဟုတ် အရင်းအမြစ်များကို ဝင်ရောက်နိုင်ပါက <abbr title="Virtual Private Network">VPN</abbr> ကို အသုံးပြု၍ သင့်သတင်းအချက်အလက်ကို ကာကွယ်ပေးသည့် လုံခြုံသော ချိတ်ဆက်မှုတစ်ခုကို ထူထောင်ပါ။

2. ကွန်ရက်ကာကွယ်ရေးအတွက် firewall ကို အသုံးပြုပါ။

    - အိမ်နှင့်/သို့မဟုတ်ရုံးကွန်ရက်များကို ခွင့်ပြုချက်မရှိသော ဝင်ရောက်မှုကို တိုက်ဖျက်ရန်နှင့် ချိတ်ဆက်ထားသော ကိရိယာများကို ဗိုင်းရပ်စ်များနှင့် မော်လ်ဝဲမှ ကာကွယ်ရန် ကူညီသည့် firewall ကို တပ်ဆင်ခြင်းဖြင့် အားဖြည့်ပေးပါ။

3. ရုပ်ပိုင်းနှင့် ဒစ်ဂျစ်တယ် အချက်အလက်များကို လုံခြုံစေရန်:

    - ထိခိုက်လွယ်တဲ့ အချက်အလက်တွေပါတဲ့ ရုပ်ဝတ္ထုစာရွက်စာတမ်းတွေကို လုံခြုံတဲ့ နေရာမှာ ကာကွယ်ပေးပြီး ဒစ်ဂျစ်တယ် စာရွက်စာတမ်းတွေဟာ စကားဝှက်နဲ့ကာကွယ်ထားတဲ့ folder တွေထဲမှာ ကုဒ်သွင်းထားပြီး သိမ်းဆည်းထားတာကို သေချာစေပါ။

4. ဒေတာကို ပုံမှန် Backup လုပ်ပါ။

    - သင့်ရဲ့ အရေးကြီးတဲ့ အချက်အလက်တွေရဲ့ မိတ္တူတွေကို လုံခြုံတဲ့ နေရာမှာ အမြဲ သိမ်းထားပါ။ ဒီနည်းနဲ့ သင်ဟာ ဒေတာတွေ ဆုံးရှုံးသွားရင် (သို့) တစ်ခုခု မှားသွားရင် အားလုံးကို အမြန် ပြန်လည်ထိန်းသိမ်းနိုင်တာပါ။ ဒါတွေကို ပုံမှန် ထိန်းသိမ်းထားတဲ့နေရာကနေ ခြားနားတဲ့ လုံခြုံတဲ့နေရာမှာ သိမ်းထားပါ။

## တစ်ဦးချင်း သုံးစွဲသူများအတွက် လုံခြုံရေးမူဝါဒများ {#security-principles-for-individual-users}

1. ခိုင်မာတဲ့ စစ်ဆေးရေး စည်းမျဉ်းတွေကို ချမှတ်ပါ။

    - အကောင့်အားလုံးအတွက် ခိုင်မာပြီး ထူးခြားတဲ့ စကားဝှက်တွေ သုံးပါ။

    - စကားဝှက်တွေကို ဘယ်တော့မှ ပြန်မသုံးပါနဲ့။

    - <abbr title="Two-Factor Authentication">2FA</abbr> ကို တတ်နိုင်သလောက် တပ်ဆင်ပါ။ <abbr title="Two-Factor Authentication">2FA</abbr> သည် စကားဝှက်လိုအပ်ရုံသာမက <abbr title="One-Time Password"> OTP </abbr>, လက်ဗွေရာ၊ (သို့) တတိယဖက် app-based authentication (ဥပမာ Google Authenticator) ကဲ့သို့သော ထပ်မံအချက်တစ်ခုမှတစ်ဆင့် အထွေထွေလုံခြုံမှုကိုတိုးတက်စေသည်။

    - SMS အထောက်အထားကို ဒုတိယအချက်အဖြစ် အသုံးပြုခြင်းကို ရှောင်ရှားပါ။ မကောင်းတဲ့ ဆော့ဖ်ဝဲက သင့်ရဲ့ SMS စာတိုအားလုံးကို စောင့်ကြည့်နေခြင်းမရှိကြောင်း အာမခံချက်မရှိဘူး။ ဥပမာ၊ Android အက်ပ်တွေဟာ သူတို့အတွက် အထူးရည်ရွယ်တဲ့ စာတိုတွေကိုသာ ဝင်ရောက်ခွင့်ပြုဖို့ ကန့်သတ်လို့မရပါဘူး။

2. ဒစ်ဂျစ်တယ်ဆက်သွယ်မှုတွင် သတိထားသင့်သည်- လက်ခံရရှိသည့် အီးမေးလ်အားလုံး၏ လက်မှတ်များကို လက်မှတ်ထိုးပြီး စစ်ဆေးရန် အီးမေလ် Client ကို တည်ထောင်ပါ။ ပေးပို့သူ၏လိပ်စာကို ဟန်ဆောင်နိုင်သော်လည်း ဘဏ်တစ်ခုအဖြစ်တောင် ကိုယ်စားပြုနိုင်သော်လည်း လက်မှတ်တုလုပ်ခြင်းမရှိပါ။ - HTML သတင်းတိုများနှင့် ပြင်ပအရင်းအမြစ်များကို မသိသော (သို့) စစ်ဆေးမထားသောလိပ်စာများမှ တင်ခြင်း နှစ်ခုစလုံးကို ပိတ်ပစ်ပါ။

    - သံသယရှိသည့် အီးမေးလ်များ၊ လင့်ခ်များနှင့် ပုဂ္ဂိုလ်ရေး အချက်အလက်တောင်းဆိုချက်များကို သိရှိရန်နှင့် ရှောင်ရှားရန် အများသုံးသော phishing နည်းစနစ်များအကြောင်း လေ့လာပါ။

    - လက်မှတ်ထိုးပြီး အီးမေးလ်တွေအားလုံးရဲ့ လက်မှတ်တွေကို စစ်ဆေးဖို့ e-mail ဖောက်သည်တစ်ခုကို ဖန်တီးပါ။ ပေးပို့သူရဲ့လိပ်စာကို ဟန်ဆောင်ပြီး ဘဏ်တစ်ခုအဖြစ်တောင် ကိုယ်စားပြုဖို့ ဖြစ်နိုင်ပေမဲ့ လက်မှတ်တုလုပ်တာတော့ မဖြစ်နိုင်ဘူး။

3. ကိုယ်ရေးအချက်အလက်ကို ကာကွယ်ပေးရန်-

    - သင့်ကိုယ်ပိုင်သတင်းအချက်အလက်များကို မျှဝေရန် သတိပြုပါ။

    - လူပုဂ္ဂိုလ် (သို့) အဖွဲ့အစည်းတွေကို လွတ်လပ်စွာ သုတေသနပြုပြီး သူတို့ရဲ့ ကိုယ်ပိုင်လက္ခဏာကို အတည်ပြုဖို့ စဉ်းစားကြည့်ပါ။

    - လူမှုမီဒီယာတွေပေါ်မှာ မျှဝေတဲ့ ကိုယ်ရေးအချက်အလက်တွေကို သတိထားပါ၊ မကောင်းဆိုးဝါးတဲ့ အဖွဲ့အစည်းတွေက ဒီသတင်းအချက်အလက်ကို စွဲသုံးနိုင်လို့ပါ။

## အဖွဲ့အစည်းများအတွက် လုံခြုံရေးမူဝါဒများ {#security-principles-for-organisations}

1. ရှင်းလင်းသော လုံခြုံရေး မူဝါဒများနှင့် လုပ်ငန်းစဉ်များကို သတ်မှတ်ပေးရန်။

    - ထိခိုက်လွယ်သော အချက်အလက်များနှင့် ပတ်သက်သည့် ဝန်ထမ်းအားလုံးအတွက် လုံခြုံရေး မူဝါဒများနှင့် ပရိုတိုကုတ်များကို ကောင်းမွန်စွာ သတ်မှတ်ရန်၊ ဤညွှန်ကြားချက်များကို လိုက်နာရန် ဝန်ထမ်းများကို ကျယ်ကျယ်ပြန့်စွာ လေ့ကျင့်ပေးရန်၊ လျစ်လျူရှုမှုဆိုင်ရာ အန္တရာယ်ကို လျှော့ချရန်။

    - လုံခြုံရေး မူဝါဒများသည် ဝန်ထမ်းအားလုံးအတွက် ရယူနိုင်ပြီး ပြောင်းလဲနေသော လုံခြုံရေး ရှုခင်းများကို ထင်ဟပ်စေရန် ပုံမှန် ပြန်လည်သုံးသပ်ခြင်းနှင့် မွမ်းမံခြင်းတို့ကို သေချာစေရမည်။

    - လုံခြုံရေး မူဝါဒများကို ဝန်ထမ်းများအတွက် ပိုမို သိရှိနားလည်နိုင်စေရန် နမူနာများနှင့် စင်တီယာများဖြင့် ပေးပို့ပါ။

2. ဝန်ထမ်းများအား အသိပညာပေးရန်:

    - ဝန်ထမ်းများအား အချက်အလက်များနှင့် လုပ်ငန်းလုံခြုံရေးဆိုင်ရာ အကောင်အထည်ဖော်မှုများကို အသိပညာပေးခြင်း။ အဖွဲ့အစည်းလုံခြုံရေးကို ခိုင်မာစေရန်အတွက် အသိပညာတိုးမြှင့်ခြင်း၊ ကျယ်ပြန့်သော သင်တန်းပေးခြင်းတို့သည် အဓိကကျသည်။

    - ဝန်ထမ်းတွေကို သံသယရှိတဲ့ လှုပ်ရှားမှု (သို့) လုံခြုံရေးဆိုင်ရာ စိုးရိမ်မှုတွေ ရှိသမျှကို ချက်ချင်း တိုင်ကြားဖို့ အားပေးပါ။

3. ရုပ်ပိုင်း အခြေခံအဆောက်အအုံကို ကာကွယ်ပေးရန်-

    - ဆာဗာများနှင့် အခြေခံအဆောက်အအုံများသို့ ရုပ်ပိုင်းဝင်ရောက်မှုကို ကန့်သတ်ပါ။ ခွင့်ပြုထားသော ဝန်ထမ်းများကိုသာ ကန့်သတ်ထားတဲ့ နေရာများသို့ ဝင်ခွင့်ပြုသည့် ဝင်ရောက်မှုထိန်းချုပ်မှုများ သတ်မှတ်ပေးပါ။

    - လုံခြုံရေးလိုအပ်ချက်များနှင့် လိုက်လျောညီထွေအောင် ဝင်ရောက်ထိန်းချုပ်မှုဆိုင်ရာ အစီအစဉ်များကို ပုံမှန် ပြန်လည်သုံးသပ်ပြီး မွမ်းမံပေးရန် သေချာစေရန်။

    - ရုပ်ပိုင်းလုံခြုံမှုကို မြှင့်တင်ဖို့ အာရုံခံတဲ့ နေရာတွေအတွက် ဇီဝမီတာဝင်ရောက်မှု ထိန်းချုပ်မှုတွေ အကောင်အထည်ဖော်ဖို့ စဉ်းစားပါ။

4. လုံခြုံရေး စောင့်ကြည့်မှုကို ဖြန့်ချိပါ။

    - လုပ်ဆောင်ချက်များကို စိစစ်ပြီး လုံခြုံရေး ချိုးဖောက်မှု ဖြစ်နိုင်ခြေကို ဖော်ထုတ်သည့် အပြည့်အဝ လုံခြုံရေး စောင့်ကြည့်ရေးစနစ်ကို အကောင်အထည်ဖော်ပေးပါ။

    - ပုံမှန်မဟုတ်တဲ့ (သို့) ခွင့်ပြုချက်မရှိတဲ့ လှုပ်ရှားမှုတစ်ခုခုကို လုံခြုံရေး ဝန်ထမ်းတွေကို ချက်ချင်း အသိပေးဖို့ အလိုအလျောက် သတိပေးချက်တွေ အကောင်အထည်ဖော်ပါ။

    - စက်သင်ယူမှု အယ်လ်ဂိုရစ်သမ်တွေကို သုံးပြီး စနစ်ရဲ့ anomalies နဲ့ ဖြစ်နိုင်ခြေရှိတဲ့ ခြိမ်းခြောက်မှုတွေကို ဖော်ထုတ်နိုင်စွမ်းကို မြှင့်တင်ဖို့ စဉ်းစားပါ။

    - ဒေတာဘေ့စ်လုံခြုံရေးကို ကြီးကြပ်ရန်၊ ဆော့ဝဲ အားနည်းချက်များကို ဖော်ထုတ်ရန်၊ ခြေရာခံရန်နှင့် ဖြေရှင်းရန် ဝန်ထမ်းများအား ခန့်အပ်ခြင်း၊ ခွင့်ပြုထားသောစာရင်းတွင် မပါဝင်သည့် ခွင့်ပြုချက်မရှိသော ဆော့ဝိုင်းများရှိမှုအတွက် အရေးပါတဲ့ စက်များအပေါ် ပုံမှန် စစ်ဆေးမှုများ ပြုလုပ်ရန် တာဝန်ပေးရမည်။

5. အကြိမ်ကြိမ်သော လုံခြုံရေး စစ်ဆေးမှုများ ပြုလုပ်ခြင်း၊

    - ချို့ယွင်းချက်တွေကို အကဲဖြတ်ဖို့ ပုံမှန် လုံခြုံရေး စစ်ဆေးမှုတွေ လုပ်ပြီး သတ်မှတ်ထားတဲ့ လုံခြုံရေး تدابیرတွေဟာ အများသဘောတူတဲ့ စံတွေနဲ့ စည်းကမ်းတွေနဲ့ ကိုက်ညီတယ်ဆိုတာကို အတည်ပြုပါတယ်။

    - သင့်အဖွဲ့အစည်းရဲ့ လုံခြုံရေးအခြေအနေကို ဘက်မလိုက်ဘဲ အကဲဖြတ်နိုင်ဖို့ အပြင်ဘက်လုံခြုံရေး ကျွမ်းကျင်သူတွေကို ခဏခဏ အကဲဖြတ်ဖို့ ငှားရန် စဉ်းစားကြည့်ပါ။

6. ဝင်ရောက်မှုထိန်းချုပ်ရေးစနစ်ကို အကောင်အထည်ဖော်ခြင်း

    - ဝန်ထမ်းများအနေဖြင့် ၎င်းတို့၏ အခန်းကဏ္ဍအတွက် လိုအပ်သော အရင်းအမြစ်နှင့် သတင်းအချက်အလက်များကိုသာ ရယူနိုင်စေရန် အတွက် ရာထူးအခြေခံဝင်ရောက်မှုထိန်းချုပ်ရေးစနစ်ကို တည်ဆောက်ပါ။

7. အဆက်မပြတ် တိုးတက်မှုကို လက်ခံပါ။

    - လုံခြုံရေးသည် ဆက်လက်ဖြစ်စဉ်တစ်ခုဖြစ်ကြောင်း အသိအမှတ်ပြုခြင်း၊ လုံခြုံရေးဆိုင်ရာ အစီအစဉ်များကို တချိန်လုံး အကဲဖြတ်ခြင်းနှင့် ပေါ်ပေါက်လာသော ခြိမ်းခြောက်မှုများနှင့် စိန်ခေါ်မှုများကို ဖြေရှင်းရန် ၎င်းတို့အား ပရိုကက်တစ်နည်းဖြင့် မြှင့်တင်ပေးခြင်း။

    - ဝန်ထမ်းတွေကို လုံခြုံရေး တိုးတက်မှု အကြံပြုချက်တွေ ထည့်သွင်းပေးဖို့ တိုက်တွန်းတဲ့ အပြန်အလှန် ပြန်ကြားချက် စက်ဝန်းတစ်ခု ထူထောင်ဖို့ စဉ်းစားပါ၊ ဆက်လက်တိုးတက်မှုရဲ့ ယဉ်ကျေးမှုကို အားပေးပါ။
