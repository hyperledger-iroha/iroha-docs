# အများသုံး သော့စာရေးခြင်း {#public-key-cryptography}

အများသုံး သော့ဝဲကို ဖုံးချုပ်ခြင်းသည် လုံခြုံသော ဆက်သွယ်ရေးနှင့် ဒေတာကာကွယ်မှုအတွက် နည်းလမ်းများ ဖြစ်စေပြီး အွန်လိုင်း ငွေကြေးဆိုင်ရာ ချုပ်ဆိုမှုများ၊ ကုဒ်သွင်းထားသော အီးမေးလ် ဆက်သွယ်ရေး စသည့် လုပ်ဆောင်ချက်များကို ခွင့်ပြုပေးသည်။

Public key cryptography မှာ cryptographic key တွေကို အသုံးပြုပါတယ်။ _အများပြည်သူ_ key နဲ့ a _ပုဂ္ဂလိက_ keyအွန်လိုင်းကွန်ရက်များမှတဆင့် သတင်းအချက်အလက်လွှဲပြောင်းရေးအတွက် အလွန်လုံခြုံသောနည်းလမ်းတစ်ခု ဖန်တီးရန်။

ပုဂ္ဂလိက သော့ကနေ အများသုံး သော့ကို ဖန်တီးဖို့ လွယ်ပါတယ်၊ ဒါပေမဲ့ ဆန့်ကျင်ဘက်ကတော့ ခက်ခဲတယ်၊ မဖြစ်နိုင်ဘူးဆိုရင်ပေါ့။ ဒါက အရာတွေကို ဘေးကင်းအောင် ထိန်းထားတယ်။ ကိုယ်ပိုင် သော့ကို အန္တရာယ်မပေးပဲ လွတ်လပ်စွာ မျှဝေနိုင်ပါတယ်။ ဒါက လုံခြုံနေတုန်းပါ။

## ကုဒ်သွင်းခြင်းနှင့် လက်မှတ်ထိုးခြင်း {#encryption-and-signatures}

Public key cryptography ကတော့ လူပုဂ္ဂိုလ်တွေကို သူတို့ပိုင်ဆိုင်တဲ့ private key ကို ပိုင်ဆိုင်ထားတဲ့ ရည်ရွယ်ချက်ရှိတဲ့ လက်ခံသူကသာ ဖေါ်ထုတ်နိုင်မယ့် encrypted messages နဲ့ data တွေကို ပို့ခွင့်ပေးပါတယ်။ တစ်နည်းပြောရရင် public key ဟာ lock အဖြစ် လုပ်ဆောင်ပြီး private key ကတော့ encrypting data တွေကို ဖွင့်ပေးတဲ့ တကယ့် unique key အဖြစ် လုပ်ဆောင်ပါတယ်။

ဒီကုဒ်ဝှက်ခြင်း လုပ်ငန်းစဉ်က အာရုံခံသိသာတဲ့ အချက်အလက်တွေရဲ့ သီးသန့်လွတ်လပ်မှုနဲ့ လျှို့ဝှက်မှုကို အာမခံရုံမက ပို့သူရဲ့ စစ်မှန်မှုကိုလည်းတည်ဆောက်ပါတယ်။ _လက်မှတ်ထိုး_ ဒီလက်မှတ်က လက်မှတ်ရေးထိုးတဲ့ ဒစ်ဂျစ်တယ် တံဆိပ်တစ်ခုအဖြစ် လုပ်ဆောင်ပြီး ပေးပို့သူရဲ့ ကိုယ်ပိုင်လက္ခဏာနဲ့ လွှဲပြောင်းထားတဲ့ အချက်အလက်တွေရဲ့ သက်တမ်းကို စစ်ဆေးပါတယ်။ _အများပြည်သူ_ key က ငွေကြေးပူးပေါင်းမှုကို စလုပ်သူက သင့်ရဲ့ _ပုဂ္ဂလိက_ သော့ပါ။

## ဖောက်သည်ဘက်က သော့များ {#keys-on-the-client-side}

ငွေပေးချေမှုတစ်ခုစီကို အကောင့်အာဏာပိုင်က လက်မှတ်ထိုးဖို့လိုပါတယ်။
ဒီအာဏာပိုင်အတွက် ထိန်းချုပ်ရေး ပစ္စည်းတွေဟာ လျှို့ဝှက်နေဖို့လိုတယ်၊ ဒီတော့ ဝယ်သူ ဆော့ဖ်ဝဲက
လုံခြုံစွာ သိမ်းဆည်းထားခြင်းနဲ့ လက်မှတ်ရေးထိုးမှုအတွက် တာဝန်ရှိသူပါ။

::: warning

Client တွေအားလုံးက မတူကြပေမဲ့ Plain-Text client ကို configuration ကသာ သင့်တော်ပါတယ်။
စီမံကိန်းနှင့် ထိန်းချုပ် စမ်းသပ်ရေးကွန်ရက်များအတွက်
လျှို့ဝှက် မန်နေဂျာ၊ Hardware ထောက်ပံ့ထားတဲ့ သော့တွေ သိမ်းဆည်းခြင်း (သို့) အခြား စစ်ဆေးတဲ့ လက်မှတ်ထိုးမှုတစ်ခု သုံးပါ။
နယ်နိမိတ်။

:::

Registering Account အသစ်တစ်ခုဟာ Controller Material ကို ထုတ်ပေးခြင်း ဖြစ်ပါတယ်
Ed25519 သော့စုံနဲ့ အများပြည်သူရဲ့ အပိုင်းကို ကွန်ရက်မှာ တင်ပေးတယ်။ နောက်တော့
အဲဒီစာရင်းထဲက ငွေလဲလှယ်မှုများကို လိုက်ဖက်တဲ့ ပုဂ္ဂလိက သော့ဖြင့် (သို့)
configured account controller policy ကို အသုံးပြုရန်။

Public key cryptography ကို ထိရောက်စွာ အလုပ်လုပ်စေရန်အတွက် သော့သစ်ကို သတ်မှတ်ဖို့လိုတဲ့အခါ သော့တွေကို ထပ်မံသုံးတာ ရှောင်ရှားပါ။ ဒါကိုလုပ်တာကို တားဆီးစရာ ဘာမှမရှိပေမဲ့ အများသုံးသော့တွေက _အများပြည်သူ_, ဆိုလိုတာက တိုက်ခိုက်သူက တူညီတဲ့ အများသုံး သော့ကို သုံးနေတာကို မြင်ရင် ပုဂ္ဂလိက သော့တွေလည်း တူတာ သိသွားမှာပါ။

ဒါပေမဲ့ _ပုဂ္ဂလိက_ Key တွေဟာ Password တွေထက် နည်းနည်းလေး ခြားနားတဲ့ မူဝါဒတွေပေါ်မှာ လုပ်ဆောင်တယ်*ဖြစ်နိုင်သလောက် ကျပန်းဖြစ်အောင် လုပ်ဖို့၊ ဘယ်တော့မှ ကုဒ်မတပ်ဘဲ သိုလှောင်ဖို့နဲ့ ဘယ်အခြေအနေမှာမဆို ဘယ်သူ့ကိုမှ မျှဝေဖို့ပါ။* အသုံးဝင်ပါတယ်။
