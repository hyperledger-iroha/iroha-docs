# စကားဝှက်လုံခြုံမှု {#password-security}

Blockchain လုံခြုံရေးမှာ စကားဝှက်တွေကို ကာကွယ်ဖို့ အရေးပါပါတယ်။ သင့်ရဲ့ ဒေတာနဲ့ ကိုယ်စားပြုတဲ့ အရာတိုင်းဟာ ခွင့်မပြုထားတဲ့ ဝင်ရောက်မှုအတွက် ခံနိုင်ရည်မရှိအောင် ဆက်ရှိနေစေဖို့ စကားဝှက်လုံခြုံမှုရဲ့ နျူးနယူးနစ်တွေကို နက်ရှိုင်းစွာ လေ့လာကြရအောင်။

## စကားဝှက်အား {#password-strength}

ဖြစ်နိုင်ခြေရှိတာက သင်ဟာ အရင်က အကြံပြုချက်တွေနဲ့ ကြုံဖူးလောက်တယ်။ _ခိုင်မာ_ Password. ဤအချက်များသည် password ၏ အနိမ့်ဆုံးအရှည်၊ အထူးစာလုံးများ ထည့်သွင်းခြင်း စသည်တို့ကဲ့သို့သော အကြံပြုချက်များကို ပါဝင်စေနိုင်သည်။ ဤအကြံပေးချက်များသည် entropy ကိုအခြေခံသည့်သင်၏ password ၏အားကို မြှင့်တင်ရန် ရည်ရွယ်ထားသည်၊ ဆိုလိုသည်မှာ password ၏ ကျပန်းမှုဖြစ်သည်။

ဒီတော့ ဘာက A ကို သတ်မှတ်လဲ။ _ခိုင်မာသော စကားဝှက်_? ခိုင်မာတဲ့ စကားဝှက်က _အင်ထရိုပီမြင့်_.

စကားဝှက်ရဲ့ entropy ကို တွက်ချက်ဖို့ **အင်ထရိုပီနည်း**:

::: tip အင်ထရိုပီနည်း

$L$  စကားဝှက်အလျား၊ စကားဝှက်ထဲက သင်္ကေတအရေအတွက်။
$S$  စာလုံးစု၊ ထူးခြားတဲ့ ဖြစ်နိုင်ခြေရှိတဲ့ သင်္ကေတတွေရဲ့ အစုရဲ့ အရွယ်အစား။\
$S^L$  ဖြစ်နိုင်ခြေရှိတဲ့ ပေါင်းစပ်မှုအရေအတွက်။

$$Entropy=log_2(S^L)$$

ရလာတဲ့ ကိန်းဂဏန်းက စကားဝှက်တစ်ခုထဲမှာ entropy bits တွေရဲ့ ပမာဏပါ။ နံပါတ်က ပိုမြင့်လေ၊ စကားဝှက်ကို ကျိုးဖောက်ဖို့ ပိုခက်လေပါ။

entropy value ကိုသိရှိခြင်းဖြင့် စကားဝှက်ကိုပြောသော entropy ဖြင့် brute-force လုပ်ရန်လိုအပ်သည့်ကြိုးပမ်းမှုအရေအတွက်ကို အောက်ပါနည်းလမ်းကို အသုံးပြု၍ ရယူနိုင်သည်

$$S^L=2^Entropy$$

Password entropy ဘယ်လောက်မြင့်မားသင့်သလဲဆိုတာအတွက် အထွေထွေအဖြေမရှိပါဘူး။ ငွေကြေးအဖွဲ့အစည်းများအတွက်တော့ သူတို့ရဲ့ password entropy ကို `64` သို့ `127` bits (`128` (သို့) ပိုများသော bits များကို အများအားဖြင့် overkill အဖြစ် သတ်မှတ်ထားသည်။ <abbr title="Graphics Processing Unit">GPU</abbr>password တွေကို ဖောက်ထွင်းဖို့ လိုအပ်တဲ့ အချိန်ဟာ အချိန်နဲ့အမျှ လျော့ကျနေဆဲပါ။

:::

Following entropy formula ကို အောက်ပါ ဥပမာ နှစ်ခုကို နှိုင်းယှဉ်ကြည့်ရအောင်။

  1. လက်ရှိ အင်္ဂလိပ်အက္ခရာစာလုံး (၂၆ စာလုံး) ၏ အက္ခရာငယ်များကိုသာ အသုံးပြုသော စာလုံးစုနှင့်အတူ ၁၆ စာလုံးပါ စကားဝှက်သည် ၄၃ သိန်းခန့်ကို ရရှိစေသည်။$43*10^21$) ဖြစ်နိုင်ချေရှိတဲ့ ပေါင်းစပ်မှု

    $$Entropy=log_2(26^{16})=log_2(43,608,742,899,428,874,059,776)=75.20703...$$

  2. စာလုံးပေါင်း ၁၆ လုံးပါတဲ့ စကားဝှက်ကို ၉၆ လုံးအထိ တိုးချဲ့ပေးထားပြီး အက္ခရာကြီးတွေနဲ့ အထူး သင်္ကေတတွေပါ ၀ င်ကာ ဖြစ်နိုင်ခြေရှိတဲ့ ပေါင်းစပ်မှုအရေအတွက်ကို အံ့သြစရာ ၅၂ သန်းအထိ မြင့်တက်စေပါတယ်။$52*10^30$), entropy ကို သိသိသာသာ တိုးတက်စေပါတယ်။

    $$Entropy=log_2(96^{16})=log_2(52,040,292,466,647,269,602,037,015,248,896)=105.35940... $$

မြင်တဲ့အတိုင်း၊ သင်္ကေတစုကို ၂၆ ကနေ ၉၆ အထိသာ တိုးချဲ့ခြင်းဖြင့်တောင်မှ မကောင်းဆိုးဝါးပါတီတစ်ခုက bruteforce လုပ်ဖို့ လိုအပ်တဲ့ ဖြစ်နိုင်ခြေရှိတဲ့ ပေါင်းစပ်မှုအရေအတွက်ဟာ $1.1933*10^9$ တစ်ခါတစ်လေ။

Password ရဲ့အရှည်ကို တိုးချဲ့ပေးခြင်းအားဖြင့် ဖြစ်နိုင်ခြေရှိတဲ့ ပေါင်းစပ်မှုအရေအတွက်ကို ပိုမိုတိုးတက်စေပြီး ဒါကြောင့် password ရဲ့ entropy  strength ကို မြှင့်တင်ပေးပါလိမ့်မယ်။

ဒါပေမဲ့ ရှုပ်ထွေးမှုတွေနဲ့ ရုန်းကန်မယ့်အစား စကားဝှက် စီမံခန့်ခွဲရေး ပရိုဂရမ်ကို သုံးဖို့ အကြံပြုပါတယ်။ [KeePassXC](https://keepassxc.org/) (အသေးစိတ်အတွက် ကြည့်ပါ) _[Password Manager Program ကိုထည့်သွင်းခြင်း](./storing-cryptographic-keys.md#adding-a-password-manager-program)_ နှင့် _[ဖွဲ့စည်းခြင်း KeePassXC](./storing-cryptographic-keys.md#configuring-keepassxc)_) သင်၏ စကားဝှက်များကို ဖန်တီးရန်နှင့် လုံခြုံစွာ သိုလှောင်ရန်။

::: tip

တစ်ချို့ ဝက်ဘ်ဆိုက်တွေဟာ စကားဝှက်တွေရဲ့ အများဆုံး ဖြစ်နိုင်ခြေရှိတဲ့ အင်ထရိုပီကို ကန့်သတ်ပေးတယ်၊ ဆိုလိုတာက အမြင့်ဆုံး စကားဝှက်အလျား (သို့) လက်ခံတဲ့ စာလုံးစုကို ကန့်သတ်တာ (သို့) နှစ်ခုစလုံးပါ။

ဤကဲ့သို့သော ဝက်ဘ်ဆိုဒ်များကို အသုံးပြုရာတွင် ဤအချက်ကို သတိထား၍ မိမိ၏ စကားဝှက်များအား ပုံမှန်ပြုပြင်ရန် ရည်ရွယ်ပါ။

:::

## စကားဝှက်အားနည်းချက်များ {#password-vulnerabilities}

စကားဝှက်တွေဟာ အကြမ်းဖက် တိုက်ခိုက်မှုတွေရဲ့ သားကောင်ဖြစ်လာနိုင်တယ်။ GPUs (၁) လူတစ်ဦးရဲ့ မွေးနေ့၊လိပ်စာ၊ဖုန်းနံပါတ်များ သို့မဟုတ် လူမှုရေးအာမခံနံပါတ္များလို ပုဂ္ဂိုလ်ရေးအချက်အလက်မဲ့ ထူးခြားသော စကားဝှက်ကို ဖန်တီးပါ။ တိုက်ခိုက်သူများကို လွယ်ကူစွာခန့်မှန်းနိုင်သည့် အချက်ပြချက်များကို မပေးပါနဲ့။

ဒီတော့ ခေတ်သစ် စကားဝှက်ကို ဖောက်ခွဲဖို့ ဘယ်လောက်ခက်ခဲလဲ။ ဒါက ဘယ်သူ့ကို မေးလဲဆိုတာ တကယ်ပဲ မူတည်တယ်။

ဒီလို ဖွဲ့စည်းချက်နဲ့ [Kevin Mitnick](https://en.wikipedia.org/wiki/Kevin_Mitnick)ဒါက [cluster setup](https://twitter.com/kevinmitnick/status/1649421434899275778?s=20) နေအိမ် ၂၄ NVIDIA® GeForce RTX ၄၀၉၀ နဲ့ ၆ NVIDIA® GeForce RTX ၂၀၈၀ နှစ်တွေ အားလုံး ပြေးနေကြတယ်။ [ဟက်စတိုပိုလီစ်](https://github.com/hashtopolis) ဆော့ဖ်ဝဲတစ်ခုမှာ သူဟာ လတစ်ဝက်အတွင်း တစ်နှစ်ကြာတဲ့ စကားဝှက်တွေကို ဖောက်ခွဲနိုင်ခဲ့တယ်။

ဒါပေမဲ့ ဒါကို တစ်ပုဒ်နဲ့ ယှဉ်ကြည့်ရအောင်။ RTX ၄၀၉၀၊ ၃၀၀ အထိ ပြုပြင်နိုင်စွမ်းရှိသည် <abbr title="Hashes per second">H/s</abbr> အသုံးပြုခြင်း [`NTLM`](https://www.tarlogic.com/cybersecurity-glossary/ntlm-hash) 200 နဲ့ <abbr title="Hashes per second">H/s</abbr> အသုံးပြုခြင်း [`bcrypt`](https://en.wikipedia.org/wiki/Bcrypt), ပြဌာန်းထားသလို [ဒီ tweet ကို](https://twitter.com/Chick3nman512/status/1580712040179826688).

ကျွန်တော်တို့ရဲ့ ယခင် entropy တွက်ချက်မှုတွေရဲ့ တိုးချဲ့အဖြစ် အောက်ပါ ပြတ်တောက်ချိန်တွေကို လေ့လာကြည့်ရအောင်။

  1. ဒါတွေရှိတယ် $31,540,000$ စကန့်တစ်နှစ်မှာ ပုံမှန်မဟုတ်တဲ့ ခုန်ခါမှု နှစ်ပါ။ အဆိုးဝါးဆုံးဖြစ်ရပ်ကို ယူဆပြီး `NTLM`, အမြန်နှုန်းနဲ့ $300*10^9$ <abbr title="Hashes per second">H/s</abbr>, ဒါက တစ်ပုဒ်ပဲ လိုလိမ့်မယ်။ RTX ၄၀၉၀ ခန့် $4,608.83$ ခေတ်သစ် အင်္ဂလိပ် အက္ခရာရဲ့ စာလုံး ၂၆ လုံးပါတဲ့ စာလုံးစုနဲ့ ၁၆ စာလုံး စကားဝှက်ကို ဖောက်ဖျက်ဖို့ နှစ်တွေကြာခဲ့တယ်။

  2. ဒီအစား `NTLM` ကျွန်တော်တို့ သုံးတဲ့ `bcrypt`, ဒါကြောင့် iteration အမြန်နှုန်းကို $200*10^3$ <abbr title="Hashes per second">H/s</abbr>, အက္ခရာအကြီးတွေနဲ့ အထူး သင်္ကေတတွေပါ ၀ င်တဲ့ စာလုံးစုကို ၉၆ အထိ တိုးချဲ့ပေးနေချိန်မှာ crack လုပ်ဖို့ အချိန်ဟာ $8,249,887,835,549,662,270.456$ စကြ၀ဠာရဲ့ အသက်ကို လွန်ကဲတဲ့ နှစ်တွေရှိခဲ့တယ်။

ဒီတော့ ပိုမြင့်တဲ့ entropy ကို ရွေးရုံနဲ့ password တစ်ခုကို မရှင်းလင်းနိုင်တဲ့ ကိန်းဂဏန်းတွေအထိ crack လုပ်ဖို့ အချိန်တိုးလာတယ် GPUs, ဒါပေမဲ့ ဒီနည်းလမ်းက [XKCD ချဉ်းကပ်မှု](https://xkcd.com/538/).

စာလုံးအစုကြီးဟာ အင်ထရိုပီမြင့်မားဖို့ အမြဲတမ်းလိုအပ်တာမဟုတ်တာကို သတိထားမိဖို့ အရေးကြီးပါတယ်။ စကားဝှက်များစွာ (သို့) အထူးသဖြင့် ဝါကျရှည်တွေကို အသုံးပြုပြီး ရယူနိုင်တာပါ။ [XKCD ကာတွန်း](https://xkcd.com/936/) ဒီစိတ်ကူးကို ပြသပေးတယ်။

::: warning

password ကို ဘယ်နေရာမဆို ရေးမထားပါ။ password recovery phrase ကို လုံခြုံစွာ သိမ်းဆည်းပါ။ စကားစုက အရမ်းရှည်တယ်ဆိုရင် ဒါကိုရေးပြီး နောက်ပိုင်း ဖတ်နိုင်အောင် ရိုက်ထည့်နိုင်ပါတယ်။ စကားစုရဲ့ ရုပ်ပိုင်းမူကွဲကို ဘေးကင်းတဲ့ နေရာနဲ့/သို့မဟုတ် ကွန်တိန်နာမှာ သိမ်းဆည်းလိုက်ပါ။

:::
