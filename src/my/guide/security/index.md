# လုံခြုံရေး {#security}

ဒီကိစ္စအတွက် Iroha သို့မဟုတ် အခြား blockchain ledger တစ်ခုကို အသုံးပြုတဲ့အခါ လုံခြုံမှုဟာ ငွေရေးကြေး အဖွဲ့အစည်းတွေအတွက် အရေးပါပါတယ်၊ အကြောင်းက ထိခိုက်လွယ်တဲ့ ဘဏ္ဍာရေးဒေတာနဲ့ ငွေပေးချေမှုတွေက ပုံမှန်ဖြစ်နေတဲ့ လုပ်ငန်းတစ်ခုမှာ ယုံကြည်မှုရဲ့ အခြေခံကို ဖွဲ့စည်းလို့ပါ။ မကောင်းဆိုးဝါးပါတီတစ်ခုက အောင်မြင်စွာ လုံခြုံရေး ချိုးဖောက်မှုသည် သင့်အတွက် ပျက်စီးဖွယ် အကျိုးဆက်များကို ဖြစ်စေနိုင်သည်။ ထို့ကြောင့် သင့်ရဲ့ အာရုံခံအချက်အလက်များ၏ စင်ကြယ်မှုနဲ့ လျှို့ဝှက်မှုကို ကာကွယ်ရန် ကြိုတင်ကာကွယ်ရေး အစီအမံများကို ချမှတ်ရန် မရှိမဖြစ်လိုအပ်ပါသည်။

### ရေကူးရေး {#navigation}

Iroha ကွန်ယက်ကို လုံခြုံရေးအတွက် အချက်အလက်အမျိုးမျိုးကို လေ့လာနိုင်ပါသည်။

- [လုံခြုံရေးမူများ ](./security-principles):

တစ်ဦးချင်းတွေနဲ့ အဖွဲ့အစည်းတွေက သူတို့ရဲ့ ဒေတာတွေကို ကာကွယ်ဖို့နဲ့ ချိုးဖောက်မှုနဲ့/သို့မဟုတ် လိပ်ပြာမှု ဖြစ်နိုင်ခြေကို လျှော့ချဖို့ ကျင့်သုံးနိုင်တဲ့ အဓိက လုံခြုံရေး မူဝါဒတွေ။

- [Virtual Private Networks](./vpn.md):

VPN ကို ပုဂ္ဂလိက (သို့) ပူးပေါင်းဆောင်ရွက်မှုများတွင် peer-to-peer, Torii နှင့် operator access များကို ကန့်သတ်ရန် အသုံးပြုပုံ။

- [လုပ်ငန်းလုံခြုံရေး ](./operational-security.md):

သင့်ကွန်ရက်ရဲ့ နေ့စဉ်လုပ်ဆောင်မှုတွေကို လုံခြုံစေဖို့ အကောင်းဆုံးကျင့်သုံးမှုတွေ၊ ဝင်ရောက်ထိန်းချုပ်မှု၊ စောင့်ကြည့်ခြင်း၊ ဖြစ်ရပ်တုံ့ပြန်မှု၊ ရှာဖွေရေးကိရိယာတွေ အသုံးပြုခြင်း စတာတွေကိုပါ ပါဝင်ပါတယ်။

- [လိမ်လည်မှု စောင့်ကြည့်ခြင်း ](./fraud-monitoring.md):

သံသယရှိတဲ့အလုပ်ကို ရှာဖွေဖို့နဲ့ တုံ့ပြန်မှုသက်သေတွေကို ထိန်းသိမ်းဖို့ Ledger အဖြစ်အပျက်တွေ၊ မေးမြန်းချက်တွေ၊ ခွင့်ပြုချက်တွေနဲ့ လုပ်ဆောင်တဲ့ အချက်ပြမှုတွေကို ဘယ်လိုသုံးရမလဲ။

- [Password Security ](./password-security.md):

စကားဝှက် entropy ကို နက်ရှိုင်းစွာ စူးစမ်းခြင်း၊ ခိုင်မာတဲ့ စကားဝှက်တွေ ဖန်တီးခြင်းနဲ့ စကားဝှက်အားနည်းချက်တွေကို ရှောင်ရှားခြင်း။

- [Public Key Cryptography](./public-key-cryptography.md):

အများသုံးသော့ကုဒ်ဝှက်မှု၊ ကုဒ်ဝှက်ခြင်း၊ လက်မှတ်များနှင့် blockchain အတွင်းတွင် လုံခြုံစွာ ဆက်သွယ်ရေးကို တည်ထောင်ရာမှာ ၎င်းတို့၏အခန်းကဏ္ဍကို စတင်ပြခြင်း။

  - [Cryptographic Key များကို ထုတ်လုပ်ခြင်း ](./generating-cryptographic-keys.md):

`kagami` ကို အသုံးပြုခြင်းနှင့် ပရိုဂရမ်ဖန်တီးခြင်းဆိုင်ရာ ညွှန်ကြားချက်များ (အထောက်အပံ့ ကိရိယာတစ်ခုသည် Iroha နှင့်အတူတင်ပို့ထားသည်။

  - [Cryptographic Keys ကို သိုလှောင်ခြင်း ](./storing-cryptographic-keys.md):

သင်၏ cryptographic key များကို ပေါင်းစပ်နိုင်သော နည်းလမ်းအမျိုးမျိုးဖြင့် လုံခြုံစေရန် အကောင်းဆုံးကျင့်သုံးမှုများ။
