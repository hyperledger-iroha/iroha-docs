# Metadata နှင့် Ledger Storage ရွေးချယ်မှုများ {#metadata-and-ledger-storage-choices}

Iroha 3 ဒေတာမော်ဒယ်မှာ အလိုလို key-value ဒေတာအတွက် သီးခြား `Store` အရင်းအမြစ်အမျိုးအစားမရှိပါ။ အောက်ပါ သိုလှောင်မှု ရွေးချယ်မှုကို အသုံးပြုပါ။

## မီတာဒေတာ {#metadata}

[ metadata](/my/blockchain/metadata.md) ကို ledger object တစ်ခုထဲ ပါဝင်တဲ့ JSON ကွင်းငယ်များအတွက် အသုံးပြုပါ။

- အမည်များနှင့် တံဆိပ်များကို ပြသရန်
- ပေါင်းစပ်ခြင်း IDs
- မူဝါဒအသေးစား အလံများ
- URIs၊ CIDs သို့မဟုတ် SoraFS လမ်းကြောင်းများဖြင့် ပိုကြီးမားသော အသုံးဝင် ဝန်ဆောင်မှုများကို ညွှန်ပြနိုင်ပါသည်။

metadata သည် world state ၏ အစိတ်အပိုင်းတစ်ခုဖြစ်ပြီး ၎င်းကိုပိုင်ဆိုင်သော အရာဝတ္ထုနှင့်အတူပြန်လာသည်။ သော့များအား တည်ငြိမ်စေရန်၊ တန်ဖိုးများကို ညှိနှိုင်းထားရန်နှင့် ခွင့်ပြုချက်များကို ရှင်းလင်းစွာ သိမ်းဆည်းရန်။ စာရွက်စာတမ်းကြီးများ၊ မှတ်ပုံတင်မှတ်တမ်းများ သို့မဟုတ် high-churn application state ကို metadata တွင် တိုက်ရိုက်မသိမ်းပါ။

## ဂဏန်းအရင်းအမြစ်များနှင့် NFTs {#numeric-assets-and-nfts}

[အရင်းအမြစ်များ](/my/blockchain/assets.md) နှင့် [NFTs](/my/blockchain/nfts.md) ကို အသုံးပြုပါ-

- ဖောက်ထွင်းနိုင်သော ငွေကြေးစာရင်းများအတွက် ကိန်းဂဏန်းအရင်းအမြစ်များ
- NFTs တစ်ခုတည်းသောပိုင်ဆိုင်မှု မှတ်တမ်းများအတွက်
- [RWAs](/my/blockchain/rwas.md) နှင့် Active Data Model မှ ထုတ်လွှင့်သည့် ဒေသဆိုင်ရာ အခြားအရာဝတ္ထုများ

အရင်းအမြစ်များနှင့် NFTs တို့မှာ ကိုယ်ပိုင် IDs ၊ သက်တမ်း စက်ဝန်းဖြစ်စဉ်များ၊ လွှဲပြောင်းမှုအပြုအမူများနှင့် ခွင့်ပြုချက် စစ်ဆေးမှုများရှိသည်။ ပိုင်ဆိုင်မှု၊ ရှားပါးမှု သို့မဟုတ် လွှဲပြောင်းရေးသမိုင်းကိစ္စတွင် metadata ထက်ပိုကောင်းသည်။

## ကွင်းဆက်ပြင်ပ အချက်အလက်များ {#off-chain-data}

ကြီးမားတဲ့ (သို့) ပြောင်းလဲနိုင်တဲ့ အသုံးဝင် ဝန်ဆောင်မှုအတွက် သံကြိုးပြင် သိုလှောင်မှုကို အသုံးပြုပါ။ သံကြိုးပေါ်တွင် တည်ငြိမ်သော ရည်ညွှန်းချက်တစ်ခုတည်းကိုသာ သိမ်းဆည်းပါ၊ ဥပမာ:

- အကြောင်းအရာ hash
- a URI
- SoraFS လမ်းကြောင်း (သို့) အထောက်အထားပြချက်
- လျှောက်လွှာသက်သေဖြင့် အသုံးပြုသော ကန့်သတ်ချက်တစ်ခု

WSV ကို သေးငယ်စွာ ထိန်းထားပြီး အစဉ်အတန်းအပြင် အသုံးဝင် ဝန်ဆောင်မှုသည် သံကြိုးပေါ်က ရည်ညွှန်းချက်နှင့် ကိုက်ညီကြောင်း အတည်ပြုနိုင်စေခြင်း။

## နေရာကို ရွေးချယ်ခြင်း {#choosing-a-location}

ဒီနမူနာကို သုံးပါ။

- စာရင်းအင်း အရာဝတ္ထုရဲ့ အသေးစား အရည်အသွေးတစ်ခုဆိုရင် metadata ကို အသုံးပြုပါ။
- တန်ဖိုးရှိ (သို့) လွှဲပြောင်းနိုင်တယ်ဆိုလျှင် အရင်းအမြစ်တစ်ခု၊ NFT သို့မဟုတ် နယ်ပယ်ဆိုင်ရာ အရာဝတ္ထုတစ်ခုအဖြစ် ပုံစံထုတ်ပါ။
- WSV အပြင်မှာ သိမ်းထားပြီး စစ်ဆေးလို့ရတဲ့ ရည်ညွှန်းချက်တစ်ခု ချိတ်ဆက်ပေးပါ။

metadata ခွင့်ပြုချက်များအတွက် [ Permission Tokens ](/my/reference/permissions.md) ကို ကြည့်ပါ။
