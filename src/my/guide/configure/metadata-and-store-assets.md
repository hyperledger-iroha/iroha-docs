# Metadata နှင့် Ledger Storage ရွေးချယ်မှုများ {#metadata-and-ledger-storage-choices}

နိုင်ငံခြားရေး Iroha 3 ဒေတာပုံစံမှာ သီးခြားမရှိဘူး။ `Store` ကျင့်သုံးမှုအတွက် အရင်းအမြစ်အမျိုးအစား
Key-value data တွေကို အောက်ပါ storage options ကို သုံးပါ။

## မီတာဒေတာ {#metadata}

အသုံးပြုခြင်း [metadata များ](/my/blockchain/metadata.md) သေးငယ်တဲ့အတွက် JSON ပါဝင်သော ကွင်းများ
စာရင်းအင်းအရာဝတ္ထုအတွက်:

- အမည်များနှင့် တံဆိပ်များကို ပြသရန်
- ပေါင်းစည်းခြင်း IDs
- နိုင်ငံရေး အလံငယ်များ
- ဟက်ရှ်၊ URIs, CIDs, ဒါမှမဟုတ် SoraFS ပိုကြီးမားတဲ့ အသုံးဝင် ဝန်ဆောင်မှုများကို ညွှန်ပြသော လမ်းကြောင်းများ

metadata က world state ရဲ့ အစိတ်အပိုင်းဖြစ်ပြီး ပိုင်ဆိုင်တဲ့ အရာဝတ္ထုနဲ့အတူ ပြန်ပို့တယ်။
key တွေကို တည်ငြိမ်အောင်၊ တန်ဖိုးတွေကို ညှိထားပြီး ခွင့်ပြုချက်တွေကို ရှင်းလင်းစွာ ထားပါ။
ကြီးမားတဲ့ စာရွက်စာတမ်းတွေ၊ မှတ်စုတွေ (သို့) high-churn application state ကို တိုက်ရိုက် store လုပ်ပါ။
metadata တွေ။

## ကိန်းဂဏန်းအရင်းအမြစ်များနှင့် NFTs {#numeric-assets-and-nfts}

အသုံးပြုခြင်း [အရင်းအမြစ်](/my/blockchain/assets.md) နှင့် [NFTs](/my/blockchain/nfts.md) ဘယ်အချိန်မှာ
နိုင်ငံတော်က တန်ဖိုးရှိတယ်

- ငွေကြေးငွေများအတွက် အရေအတွက်အရင်းအမြစ်များ
- NFTs တစ်ကိုယ်ရေပိုင် မှတ်တမ်းများအတွက်
- [RWAs](/my/blockchain/rwas.md) အခြားဒေသသတ်မှတ်တဲ့ အရာဝတ္ထုတွေကို
  Active data model က သူတို့ကို ဖေါ်ပြပေးတယ်။

အရင်းအမြစ်များနှင့် NFTs သူတို့ကိုယ်ပိုင် IDs, ဘဝပတ်ဝန်းကျင် ဖြစ်ရပ်တွေ၊ လွှဲပြောင်းမှု အပြုအမူတွေ၊
ပြီးတော့ ခွင့်ပြုချက် စစ်ဆေးမှုတွေလည်း လုပ်နိုင်ပါတယ်၊ ၎င်းတို့ဟာ ပိုင်ဆိုင်မှုမှာ metadata ထက် ပိုကောင်းပါတယ်။
ရှားပါးမှု (သို့) လွှဲပြောင်းရေး သမိုင်း ကိစ္စတွေပါ။

## ကွင်းဆက်ပြင်ပ ဒေတာ {#off-chain-data}

ကြီးမားတဲ့ (သို့) ပြောင်းလဲနိုင်တဲ့ အသုံးဝင်ဝန်ဆောင်မှုအတွက် သံကြိုးအပြင် သိုလှောင်မှုကို အသုံးပြုပါ။
ချိတ်ဆက်ထားသော အချက်အလက်များ၊ ဥပမာ-

- Content hash တစ်ခု
- (က) URI
- (က) SoraFS လမ်းကြောင်း (သို့) ပြတ်သားတဲ့ ရည်ညွှန်းချက်
- လျှောက်လွှာသက်သေတစ်ခုဖြင့် အသုံးပြုသော ကတိပြုချက်

ဒါက WSV သေးငယ်ပေမဲ့ လျှောက်လွှာတွေကို စစ်ဆေးဖို့ ခွင့်ပြုထားတာပါ။
ချိတ်ဆက်မှုအပြင် အသုံးဝင်ဝန်ဆောင်မှုက ချိတ်ဆက်ခြင်းအပေါ်မှာ ရည်ညွှန်းချက်နဲ့ ကိုက်ညီပါတယ်။

## နေရာကို ရွေးချယ်ခြင်း {#choosing-a-location}

ဒီနည်းကို သုံးပါ။

- စာရင်းအင်းတစ်ခုရဲ့ အသေးစိတ် အရည်အသွေးဆိုရင် metadata ကိုသုံးပါ။
- တန်ဖိုးရှိ (သို့) လွှဲပြောင်းနိုင်တယ်ဆိုရင် အရင်းအမြစ်တစ်ခုအဖြစ် ပုံစံထုတ်ပါ။ NFT, ဒါမှမဟုတ်
  ဒိုမင်အလိုက် သီးသန့်အရာဝတ္ထု။
- ကြီးမားတဲ့၊ အပူချိန်မြင့်တဲ့ (သို့) application-private ဖြစ်ရင်
  WSV စစ်ဆေးလို့ရတဲ့ ရည်ညွှန်းချက်ကို ချိတ်ဆက်ပေးပါ။

metadata ခွင့်ပြုချက်များအတွက် ကြည့်ပါ
[ခွင့်ပြုချက် လက်မှတ်များ](/my/reference/permissions.md).
