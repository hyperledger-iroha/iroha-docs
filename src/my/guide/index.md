# လမ်းညွှန် {#guide}

ဒီအပိုင်းကို တည်ဆောက်၊ လည်ပတ်၊ (သို့) ပေါင်းစပ်တဲ့အခါ သုံးပါ။
Iroha. စပြီး SDK ပထမဦးဆုံး ဖောက်သည်အတွက် သင်ခန်းစာများ၊
အကောင်းဆုံးကျင့်သုံးမှုနှင့် အသုံးပြုသူအသိအမှတ်ပြုချက်များကို မျှဝေသော
ကွန်ရက်။

## အကြံပြုလမ်းကြောင်း {#recommended-path}

1. [တပ်ဆင်ခြင်း Iroha 3](/my/get-started/install-iroha.md) နှင့်
   [ဒေသတွင်းကွန်ရက်ကို စတင်ရန်](/my/get-started/launch-iroha.md).
2. ရွေးချယ်ပါ။ [SDK သင်ခန်းစာ](/my/guide/tutorials/) အနည်းငယ်ကို တင်ပြပါ
   ငွေပေးချေမှု။
3. ပြန်လည်သုံးသပ်ခြင်း
   [အသုံးချမှု ဖွံ့ဖြိုးတိုးတက်ရေး](/my/guide/best-practices/application-development.md)
   နှင့် [ဒေတာပုံစံထုတ်ခြင်း](/my/guide/best-practices/data-modeling.md) အရင်က
   လျှောက်လွှာကို ပုံသွင်းခြင်း API.
4. အသုံးပြုခြင်း [ကွန်ရက် ဖြန့်ချိခြင်း](/my/guide/best-practices/network-deployment.md),
   [လုပ်ငန်းများ](/my/guide/best-practices/operations.md), နှင့်
   [လုံခြုံရေးနှင့် ဝင်ရောက်ခွင့်](/my/guide/best-practices/security-and-access.md)
   မျှဝေထားတဲ့ (သို့) ထုတ်လုပ်ရေးကွန်ရက်ကို မဖွင့်ခင်
5. နောက်လိုက်ပါ [လွတ်မြောက်ရန် အသင့်ရှိ](/my/guide/best-practices/release-readiness.md)
   ဒေသတွင်း ဖွံ့ဖြိုးတိုးတက်မှုမှ Taira, Minamoto, ဒါမှမဟုတ် အခြား
   တိုက်ရိုက် တပ်ဆင်မှု။
