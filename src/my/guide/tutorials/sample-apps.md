# နမူနာများနှင့် ချက်ပြုတ်ချက်များ {#samples-and-recipes}

နိုင်ငံခြားရေး Iroha အရင်းအမြစ် သိုလှောင်စာရင်းမှာ ပါဝင်ပါတယ်။ SDK ဆေးညွှန်းတမ်းများနှင့် စမ်းသပ်မှုအစီအစဉ်များ
node နဲ့အတူတူတည်းဖြတ်မှုပါ။

## JavaScript ချက်ပြုတ်နည်းများ {#javascript-recipes}

[`javascript/iroha_js/recipes`](https://github.com/hyperledger-iroha/iroha/tree/main/javascript/iroha_js/recipes)
အချိုးသတ်ချက်ဆိုင်ရာ ငွေကြေးပူးပေါင်းဆောင်ရွက်မှုအတွက် အဓိကကျတဲ့ နမူနာတွေပါဝင်တယ်။ Nexus app ကို
ငွေလွှဲပြောင်းမှု NFT အကောင့်ကို ပြန်လည်သုံးသပ်ခြင်း ISO တံတားစီးကြောင်းများ၊ Torii စီးဆင်းနေတာပါ။
အွန်လိုင်းမှာ ပြသတာ (သို့) တိုက်ရိုက်လိုအပ်တာတိုင်း စာရွက်စာတမ်းတစ်ခုစီ Torii အဆုံးအသတ်မှတ်ချက်ပါ။

Swift SDK. ကြည့်ပါ။ [Swift ပြီးတော့ iOS](/my/guide/tutorials/swift.md) အိတ်နဲ့ တံတားအတွက်

## Android {#android}

အသစ်များအတွက် Android အလုပ်ကိုသုံးပြီး Kotlin- ပထမ `core-jvm`, `client-android`, နှင့်
`offline-wallet-android` မော်ဂျူးများ
[Kotlin, Android, ဂါဗာ](/my/guide/tutorials/kotlin-java.md). နိုင်ငံခြားရေး Kotlin SDK ရှိသည်
