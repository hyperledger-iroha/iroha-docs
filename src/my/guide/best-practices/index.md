# အကောင်းဆုံး ကျင့်ဝတ်များ {#best-practices}

Iroha အက်ပ်များနှင့် ကွန်ရက်များအတွက် ထုတ်လုပ်မှု ဦးစားပေး လမ်းညွှန်ချက်များကို ဤအခန်းတွင် စုစည်းထားသည်။ ၎င်းကို အကောင်အထည်ဖော်ရန် ဖြစ်ပေါ်သော လက္ခဏာမဟုတ်ဘဲ သင်လုပ်ရမည့် ဆုံးဖြတ်ချက်ဖြင့် စီစဉ်ထားပါသည်။

မျှဝေထားတဲ့ testnet လေ့ကျင့်ခန်း၊ ထုတ်လုပ်မှု မိတ်ဆက်မှု (သို့) အဓိက ဖောက်သည် ထုတ်လွှင့်မှုမတိုင်ခင် ဒါကို စစ်ဆေးစာရင်းအဖြစ် အသုံးပြုပါ။

## ကွင်းဆက်ဖြတ်တောက်မှု စည်းမျဉ်းများ {#cross-cutting-rules}

- ဒေသတွင်း ဖွံ့ဖြိုးတိုးတက်မှု၊ မျှဝေထားတဲ့ စမ်းသပ်ရေးကွန်ရက်နဲ့ ထုတ်လုပ်မှု ဖွဲ့စည်းမှုကို သီးခြားထားပါ။
- မျိုးစေ့ဖြစ်စဉ်၊ တူညီတဲ့ topology၊ အကောင်အထည်ဖော်သူ မူဝါဒနဲ့ အဓိက ပစ္စည်းတွေကို ထိန်းချုပ်ထားတဲ့ ဖြန့်ချိမှု လက်ရာတွေအဖြစ် ကုသပါ။
- Model durable ledger state ကို ရည်ရွယ်ချက်ရှိပြီး မက်တာဒေတာကို ကြီးမားတဲ့၊ ပုဂ္ဂလိက (သို့) မြင့်မားတဲ့ ဒေတာအတွက် စွန့်ပစ်မြေအဖြစ် မသုံးပါနဲ့။
- ငြင်းပယ်ခြင်း၊ သက်တမ်းကုန်ဆုံးခြင်း၊ ထပ်မံစမ်းသပ်ခြင်းနှင့် နောက်ကျနေသည့် အခြေအနေကို ကိုင်တွယ်နိုင်သော idempotent workflows များမှတစ်ဆင့် ငွေပေးချေမှုများကိုတင်ပါ။
- ကျဉ်းမြောင်းသော ခွင့်ပြုချက်များ၊ သီးသန့် နည်းပညာ အကောင့်များနှင့် ရှင်းလင်းစွာ လုပ်ဆောင်မှု runbooks များကို အုပ်ချုပ်ရေးမှူးဝင်ခွင့်ကျယ်ပြန့်ထက် ပိုနှစ်သက်သည်။
- တစ်ကြိမ်သုံးနိုင်တဲ့ ဒေသတွင်းကွန်ရက်တစ်ခုမှာ ပထမဆုံး ပြုမူပုံကို သက်သေပြပြီး နောက်တော့ Taira (သို့) အခြားမျှဝေထားတဲ့ စမ်းသပ်ရေးကွန်ရက်ကို အဓိကကွန်ရက် လုပ်ဆောင်မှုတစ်ခုမှ မတိုင်မီ လေ့ကျင့်ပါ။
