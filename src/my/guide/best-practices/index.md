# အကောင်းဆုံး ကျင့်ဝတ်များ {#best-practices}

ဤအပိုဒ်တွင် ထုတ်လုပ်မှု ဦးစားပေး ညွှန်ကြားချက်များကို စုစည်းထားသည် Iroha လျှောက်လွှာများ
ဒါက သင်လုပ်ဖို့လိုတဲ့ ဆုံးဖြတ်ချက်နဲ့ စည်းရုံးတာပါ။
ဒါကို အကောင်အထည်ဖော်ဖို့ ဖြစ်ပျက်တဲ့ feature တစ်ခုပါ။

မျှဝေထားတဲ့ testnet လေ့ကျင့်ခန်းမတိုင်ခင် ဒါကို စစ်ဆေးစာရင်းအဖြစ် သုံးပါ။
လွှတ်တင်ခြင်း (သို့) အဓိက ဖောက်သည်လွတ်မြောက်မှုပါ။

## ကန့်သတ်ချက်များ {#cross-cutting-rules}

- ဒေသတွင်း ဖွံ့ဖြိုးတိုးတက်မှု၊ မျှဝေထားတဲ့ စမ်းသပ်ရေးကွန်ရက်နဲ့ ထုတ်လုပ်ရေး ညှိနှိုင်းမှုကို ထိန်းသိမ်းပါ။
  ခွဲခြားထားပါ။
- ဘီဘီစီ၊ တန်းတူ Topology, အကောင်အထည်ဖော်ရေးမူဝါဒနဲ့ အဓိကပစ္စည်းတွေကို
  ထိန်းချုပ်ထားတဲ့ တပ်ဆင်မှု လက်ရာတွေ
- မီတာဒေတာကို
  ကြီးမားတဲ့၊ ပုဂ္ဂလိက သို့မဟုတ် အန္တရာယ်များတဲ့ ဒေတာအတွက် စွန့်ပစ်မြေပါ။
- ကိုင်တွယ်နိုင်သော idempotent workflows များမှတဆင့် ငွေကြေးလွှာများကို တင်သွင်းပါ
  ငြင်းပယ်မှု၊ သက်တမ်းကုန်ဆုံးခြင်း၊ ထပ်မံကြိုးစားခြင်းနဲ့ နောက်ကျနေတဲ့ အခြေအနေ။
- သေးငယ်တဲ့ ခွင့်ပြုချက်တွေ၊ ရည်စူးထားတဲ့ နည်းပညာ အကောင့်တွေနဲ့ ရှင်းလင်းတဲ့
  ကျယ်ပြန့်တဲ့ စီမံအုပ်ချုပ်ရေးမှူး ဝင်ရောက်မှုအတွက် လုပ်ဆောင်ချက် runbooks များ။
- တစ်ခါသုံး ဒေသတွင်းကွန်ရက်မှာ ပထမဆုံး အပြုအမူကို သက်သေပြပြီး နောက်မှာ လေ့ကျင့်ပါ။
  Taira (သို့) အဓိကကွန်ရက်ကို မလုပ်ခင် အခြားမျှဝေထားတဲ့ စမ်းသပ်ရေးကွန်ရက်တစ်ခုခု။
