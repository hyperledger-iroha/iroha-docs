# ကွန်ရက် ဖြန့်ချိခြင်း {#network-deployment}

ကုသမှု Iroha ကွန်ရက်ကို ညှိနှိုင်းထားတဲ့ စနစ်တစ်ခုအဖြစ် သတ်မှတ်ပေးရပါမယ်။
ဘီဘီစီ၊ ထိပ်တန်းပညာ၊ ယုံကြည်ရတဲ့ အဖော်တွေနဲ့ သဘောတူညီချက်နဲ့ သက်ဆိုင်တဲ့ ဖွဲ့စည်းပုံ
ကွန်ရက်က မစနိုင်ခင်နဲ့ ဘလော့တွေကို အဆုံးသတ်နေတုန်းပါ။

## ပတ်ဝန်းကျင်ခွဲခြားခြင်း {#environment-separation}

- ဒေသတွင်းဖွံ့ဖြိုးရေးအတွက် သီးခြား ကွန်ပြူတာများကို ထိန်းသိမ်းခြင်း၊ မျှဝေသော စမ်းသပ်ရေးကွန်ရက်များ၊
  စင်ရေး၊ ထုတ်လုပ်မှု။
- တစ်ကြိမ်သုံးလို့မရတဲ့ ပတ်ဝန်းကျင်တိုင်းအတွက် သော့သစ်တွေ ထုတ်လုပ်ပါ။ ပြန်မသုံးပါနဲ့
  localnet သို့မဟုတ် Taira ထုတ်လုပ်မှုမှာ အဓိက ပစ္စည်းပါ။
- Peer config၊ client config၊ လက်မှတ်ထိုးထားတဲ့ genesis, script တွေနဲ့ deployment ကို ထိန်းထားပါ။
  စာသားတွေ စုပေါင်းပြီး ထုတ်ပြန်ထားတဲ့ လက်ရာတစ်ခုအဖြစ် ပြန်လည်ထုတ်ဝေတယ်။
- ပုဂ္ဂလိက သော့တွေကို repositories နဲ့ deployment templates တွေအပြင်မှာ သိမ်းထားပါ။

ကြည့်ပါ။
[ကွန်ရက် ဖြန့်ချိမှုအတွက် သော့ချက်များ](/my/guide/configure/keys-for-network-deployment.md).

## Genesis နှင့် Topology {#genesis-and-topology}

- အတည်ပြုသူတိုင်းကို လက်မှတ်ထိုးထားတဲ့ Genesis Transaction တစ်ခုတည်းကို သုံးခိုင်းပါ။
  peer set, topology, and validator Proof-of-Possession when the profile
  ဒါတွေကို လိုအပ်ပါတယ်။
- အနည်းဆုံး Byzantine fault-tolerance အတွက် validator လေးခုလောက် သုံးပါ။
  တပ်ဆင်ရေး။
- ကွဲပြားသော အတည်ပြုသူများနှင့် စွမ်းအင် စီမံကိန်းတွင် လေ့လာသူများ
  မဲပေးတာ၊ အဆိုပြုတာ (သို့) စုဆောင်းတာဆိုပေမဲ့ သိုလှောင်မှု၊ ဘလော့ကော်မတီကို သုံးစွဲနေတုန်းပါ။
  ပြီးတော့ ကွန်ရက်ရဲ့ bandwidth ပါ။
- မျိုးရိုးဗီဇ၊ အကောင်အထည်ဖော်သူနဲ့ ထိပ်ပိုင်းဆိုင်ရာ ပြောင်းလဲမှုတွေကို ညှိနှိုင်းထားတဲ့ ရွှေ့ပြောင်းမှုအဖြစ် ကုသပါ။
  တစ်တူတည်းတည်းဖြတ်ခြင်းထက်ပါ။

ကြည့်ပါ။ [ဇင်နဝါရီ](/my/reference/genesis.md),
[တန်းတူညီမျှမှု စီမံခန့်ခွဲခြင်း](/my/guide/configure/peer-management.md), နှင့်
[စွမ်းဆောင်ရည်နှင့် မက်ထရစ်များ](/my/guide/advanced/metrics.md#node-count-and-quorum).

## Torii ကွန်ရက်ဝင်ရောက်မှု {#torii-and-network-access}

- ထားပါ Torii အပြင်ဘက်မှာ ပိတ်မိနေတဲ့အခါ နောက်ပြန်အော်ပရော်ကေး (သို့) firewall တစ်ခုရဲ့နောက်ကွယ်မှာ
  အိမ်ရှင် (သို့) ပုဂ္ဂလိက ကွန်ရက်။
- အဆုံးသတ်ခြင်း TLS အခြေခံအတည်ပြုချက်၊နှုန်းသတ်မှတ်ချက်တွေကို သုံးပြီး
  တပ်ဆင်မှုအတွက် လိုအပ်တဲ့ အနားမှာ request size controls တွေကို သုံးပါ။
- ပတ်ဝန်းကျင်အတွက် လိုအပ်တဲ့ အဆုံးသတ်မှတ်ချက်တွေကိုသာ ထုတ်ဝေပါ။
  တယ်လီမီထရီလမ်းကြောင်းတွေဟာ အများပြည်သူ ဖတ်လို့သာရတဲ့ လမ်းကြောင်းတွေထက် ပိုပြီး ကန့်သတ်သင့်ပါတယ်။
- အဖော်များ မလုပ်သင့်သော host-local interfaces များသို့ နားဆင်သူလိပ်စာများကို ချိတ်ဆက်ပါ။
  ဝေးလံတဲ့ ယာဉ်ကို တိုက်ရိုက် လက်ခံပါ။

ကြည့်ပါ။ [Torii နောက်ဆုံးအချက်များ](/my/reference/torii-endpoints.md) နှင့်
[Virtual Private Networks များ](/my/guide/security/vpn.md).

## သဘောတူညီချက်နှင့် အရည်အသွေး {#consensus-and-capacity}

- အညီအခံ အချိန်ဆွဲချိန်ကို ညှိပေးခြင်းမတိုင်မီ ဖြန့်ချိမှုကို တိုင်းတာပါ။
  ကွန်ရက်၊ သိုလှောင်ရေးနဲ့ လုပ်ဆောင်မှု အလွှာတွေ လိုက်နာနေစဉ်မှာသာ နှောင့်နှေးမှုကို လျှော့ချပါ။
- သတ္တုထွက်နှုန်းရဲ့ နမူနာတိုလေးတွေတင်မဟုတ်ပဲ တန်းစီကို ကြည့်ပါ။
  မြင့်မားတဲ့ ဝန်ဆောင်မှုရှိစဉ်မှာ ကြီးထွားလာတယ်ဆိုတာက ကွန်ရက်ဟာ အလျှံအစီးဖြစ်နေတာကို ဆိုလိုတာပါ။
- သက်ရောက်မှု မှတ်တမ်းတင်ခြင်း Sumeragi ပမာဏများ၊ တယ်လီမီထရီပရိုဖိုင်း၊ validator count
  ကွန်ရက် RTT, Workload ပုံစံနဲ့ benchmark တစ်ခုစီအတွက် hardware အသေးစိတ်တွေ
- အစုလိုက်အပြုံလိုက်ကိုတိုးမြှင့်ရန် latency, traffic နှင့်
  အပြန်အလှန်ဖိအား အချက်ပြမှု။

ကြည့်ပါ။ [စွမ်းဆောင်ရည်နှင့် မက်ထရစ်များ](/my/guide/advanced/metrics.md).

## Bare-Metal နှင့် Process Management ကို အသုံးပြုခြင်း {#bare-metal-and-process-management}

- လူတိုင်းရဲ့ တူညီမှုတွေကို ထိန်းထားပါ။ `config.toml`, ပုဂ္ဂလိက သော့၊ သိုလှောင်စာရင်းနဲ့ ဆိပ်ကမ်း
  ခွဲခြားထားပါ။
- Process Manager တွေကို အသုံးပြုပါ။ systemd ရှင်းလင်းစွာ ပြန်လည်စတင်ခြင်း၊ မှတ်တမ်းတင်ခြင်းနှင့်
  အရင်းအမြစ် မူဝါဒများ။
- ထုတ်လုပ်ထားသော ထိန်းသိမ်းမှု README command တွေကို start လုပ်လိုက်ပါ Kagami ဒေသတွင်းကွန်ရက် ဘက်လ်များ
  စမ်းသပ်မှု topology ကို စီမံခန့်ခွဲထားတဲ့ host တွေကို ဘာသာပြန်တဲ့အခါမှာ

ကြည့်ပါ။
