# လုံခြုံရေးနှင့် ဝင်ရောက်ခွင့် {#security-and-access}

လုံခြုံရေးဆိုင်ရာ ကျင့်ဝတ်များ Iroha ကျဉ်းမြောင်းတဲ့ အာဏာကို အခြေခံပြီး ထိန်းချုပ်သင့်ပါတယ်။
key custody, explicit network exposure နဲ့ စစ်ဆေးလို့ရတဲ့ ပြောင်းလဲမှုတွေပေါ့။

## အဓိက ထိန်းသိမ်းမှု {#key-custody}

- ထုတ်လုပ်မှုအဆင့် entropy နှင့်အတူထုတ်လုပ်ရေး key များကိုဖန်တီးပြီး သီးသန့်သိုလှောင်
  Repository တွေအပြင်က Key များ၊ Issue Tracker များ၊ Prompts များ၊ Chat logs များနှင့် CI
  ထုတ်ကုန်။
- ဖောက်သည်များအတွက် သီးခြားသော့ပစ္စည်းကို အသုံးပြုပါ။
  validator တွေ၊ fee sponsor တွေနဲ့ technical accounts တွေပေါ့။
- စာရေးသားတဲ့ လုပ်ငန်းစဉ်တစ်ခုအတိုင်း ခလုတ်တွေကို လှည့်ပြီး ပြန်လည်ထူထောင်ဖို့ လေ့ကျင့်ပါ။
  တိုက်ရိုက်ဖြစ်ရပ်ပါ။
- တန်ဖိုးမြင့် ပစ္စည်းများအတွက် Hardware သို့မဟုတ် Operating System ထောက်ပံ့ထားတဲ့ Storage ကို အသုံးပြုပါ။
  လက်မှတ်ရေးထိုးတဲ့ သော့တွေကို ဖြန့်ချိမှုအန္တရာယ်က အကြောင်းပြချက်ပေးတဲ့အခါမှာပါ။

ကြည့်ပါ။
[Cryptographic Key များကို ထုတ်လုပ်ခြင်း](/my/guide/security/generating-cryptographic-keys.md)
နှင့်
[Cryptographic Key များကို သိမ်းဆည်းခြင်း](/my/guide/security/storing-cryptographic-keys.md).

## ခွင့်ပြုချက်များ {#permissions}

- Workflow ကို ထောက်ပံ့တဲ့ အသေးဆုံး ခွင့်ပြုချက် အမှတ်တံဆိပ် (သို့) ကဏ္ဍကို ပေးပါ။
- ဝန်ဆောင်မှုများ၊ trigger များ၊ agent များအတွက် အထူးပြုသော နည်းပညာစာရင်းများကို ပိုနှစ်သက်သည်။
  အော်တိုမိတ်စနစ်ကို ကိုယ်ရေးကိုယ်တာ
  လုပ်ငန်းရှင်စာရင်း
- Peer Management, metadata mutation, minting အတွက် အခွင့်အရေးတွေကို ပြန်လည်သုံးသပ်ပါ။
  မီးရှို့ခြင်း၊ trigger မှတ်ပုံတင်ခြင်း၊ အကောင်အထည်ဖော်သူ ပြောင်းလဲခြင်းများ SORA/Nexus
  ထုတ်လုပ်မှု မစတင်ခင် အုပ်ချုပ်ရေး
- ထိန်းသိမ်းရေး ပြတင်းပေါက် (သို့) ရွှေ့ပြောင်းပြီးနောက် ယာယီ ခွင့်ပြုချက်တွေကို ပယ်ဖျက်ပါ။
  အဲဒါဟာ သူတို့ကို လိုအပ်ခဲ့တယ်။

ကြည့်ပါ။ [ခွင့်ပြုချက်များ](/my/blockchain/permissions.md) နှင့်
[ခွင့်ပြုချက် လက်မှတ်များ](/my/reference/permissions.md).

## ကွန်ရက်ဆိုင်ရာ ထိတွေ့မှု {#network-exposure}

- တန်းတူလူချင်းကို ကန့်သတ်ပေးပါ။ Torii, တယ်လီမီထရီနှင့် operator လမ်းကြောင်းများ
  အများပြည်သူ ဖတ်ရှုခွင့်သည် အများပြည်သူ ရေးသားခြင်း သို့မဟုတ်
  အော်ပရေတာဝင်ရောက်မှု။
- အသုံးပြုခြင်း VPNs, firewall တွေ၊ reverse proxies တွေ၊ TLS ရပ်ဆိုင်းခြင်းနှင့်နှုန်းသတ်မှတ်ချက်များ
  နေရာချထားမှုအတွက် သင့်လျော်ပါက
- အခြေခံ စာရင်းအင်း မှတ်ပုံတင်၊ ကိုယ်စားလှယ်လက္ခဏာများနှင့် ပြန်ပို့သော ခေါင်းစဉ်များကို
  အမိန့်ချမှတ်ထားတယ်။
- ခွင့်ပြုချက်မရှိတဲ့ ဖောက်သည်တွေဟာ ကန့်သတ်ထားတဲ့ လမ်းကြောင်းတွေကို မရောက်နိုင်တာကို စမ်းသပ်ပါ။

ကြည့်ပါ။ [Virtual Private Networks များ](/my/guide/security/vpn.md) နှင့်
[Torii နောက်ဆုံးအချက်များ](/my/reference/torii-endpoints.md).

## လှည့်စားမှုနှင့် မတရားပြုကျင့်မှုကို စောင့်ကြည့်ခြင်း {#fraud-and-abuse-monitoring}

- မမျှော်လင့်တဲ့ အရင်းအမြစ်အတွက် Ledger ဖြစ်ရပ်များနှင့် လုပ်ငန်းအချက်ပြများကို စောင့်ကြည့်ခြင်း
  ရွေ့လျားမှု၊ ခွင့်ပြုချက်ပေးခြင်း၊ အစပျိုးပြောင်းလဲခြင်းတွေ၊ အဖော်များ ပြောင်းလဲခြင်းတွေနဲ့ ထပ်ခါထပ်ခါ
  ပယ်ချထားသော ငွေကြေးလုပ်ငန်းများ
- ငွေပေးချေမှု ဟက်ရှ်တွေ၊ ဘလော့ အမြင့်တွေ၊ ဖြစ်ရပ် မှတ်တမ်းတွေကို သိမ်းထားပါ။
  မှတ်တမ်းတွေ၊ အခြေအနေ snapshots တွေပါ။
- လုံခြုံရေး၊ လုပ်ငန်းများနှင့် စီးပွားရေးလုပ်ငန်းရှင်များကို လမ်းကြောင်း သတိပေးချက်များ
  သက်ရောက်တဲ့ အရင်းအမြစ်များ (သို့) အလုပ်ခွင်များအတွက်။

ကြည့်ပါ။ [လှည့်စားမှု စောင့်ကြည့်ခြင်း](/my/guide/security/fraud-monitoring.md).

## Agent နှင့် Automation Guardrails များ {#agent-and-automation-guardrails}

- ဖတ်လို့သာ ခွင့်ပြုချက်တွေနဲ့ အလိုအလျောက်လုပ်မှုကို စတင်ပြီး ရေးသားခွင့်ကိုပဲ ထည့်သွင်းပါ။
  အလုပ်ဖြစ်စဉ်ကို ပြန်လည်သုံးသပ်ပြီးနောက်ပါ။
- သက်ရှိကွန်ရက်မှ အပြောင်းအလဲများအတွက် လူသား၏ တိကျတဲ့ ခွင့်ပြုချက် လိုအပ်သည်
  အလိုအလျောက်လုပ်ခြင်းဟာ ရည်ရွယ်ချက်ရှိပြီး ဖြန့်ချိထားတဲ့ ထုတ်လုပ်ရေး ဝန်ဆောင်မှုပါ။
- ကိုယ်ရေးကိုယ်တာ သော့တွေကို Agent တွေရဲ့ အမိန့်တွေကို မဖွင့်ပါနဲ့။ ဒေသတွင်းကုဒ်ကို သုံးပြီး
  ပတ်ဝန်းကျင် ပြောင်းလဲမှုတွေ၊ keychains တွေ၊ hardware signers တွေရဲ့ လျှို့ဝှက်ချက်တွေ ဒါမှမဟုတ်
  ဖိုင်တွေကို လျစ်လျူရှုခဲ့တယ်။
- စာရင်းအင်းကို မသွန်သင်ဘဲ စစ်ဆေးမှုကို ထောက်ပံ့တဲ့နည်းနဲ့ မှတ်တမ်း အလိုအလျောက် ဆုံးဖြတ်ချက်ချခြင်း
  လျှို့ဝှက်ပစ္စည်းပါ။
