# လုံခြုံရေးနှင့် ဝင်ရောက်ခွင့် {#security-and-access}

Iroha မှာ လုံခြုံရေးလေ့ကျင့်ခန်းက ကျဉ်းမြောင်းတဲ့ ခွင့်ပြုချက် မူဝါဒ၊ ထိန်းချုပ်ထားတဲ့ သော့ထိန်းသိမ်းမှု၊ ရှင်းလင်းတဲ့ ကွန်ရက် ထိတွေ့မှုတွေနဲ့ စစ်ဆေးလို့ရတဲ့ အပြောင်းအလဲတွေကို အခြေခံသင့်ပါတယ်။

## အဓိက ထိန်းသိမ်းမှု {#key-custody}

- ထုတ်လုပ်သုံးစွဲရေးကီးများကို ထုတ်လုပ်သုံးစွဲရန် လုံလောက်သော ကျပန်းအရည်အသွေးဖြင့် ထုတ်လုပ်ပြီး ကိုယ်ပိုင်ကီးများကို repository များ၊ ပြဿနာခြေရာခံစနစ်များ၊ ညွှန်ကြားစာများ၊ စကားပြောမှတ်တမ်းများနှင့် CI ရလဒ်ပြင်ပတွင် သိမ်းပါ။
- client များ၊ peer များ၊ genesis လက်မှတ်ထိုးခြင်း၊ validator များ၊ အခကြေးငွေကိုယ်စားပေးသူများနှင့် နည်းပညာဆိုင်ရာအကောင့်များအတွက် သီးခြားကီးအချက်အလက်များကို သုံးပါ။
- ရေးသားတဲ့ လုပ်ငန်းစဉ်တစ်ခုအရ ခလုတ်တွေကို လှည့်လိုက်ပြီး တိုက်ရိုက်ဖြစ်ရပ်မတိုင်ခင် ပြန်လည်ထူထောင်မှုကို လေ့ကျင့်ပါ။
- Deployment အန္တရာယ်အရ သင့်လျော်လျှင် တန်ဖိုးမြင့် လက်မှတ်ထိုးကီးများအတွက် ဟာ့ဒ်ဝဲ သို့မဟုတ် လည်ပတ်စနစ်က ပံ့ပိုးကာကွယ်သော သိုလှောင်မှုကို သုံးပါ။

[Cryptographic Key များကို ထုတ်လုပ်ခြင်း](/my/guide/security/generating-cryptographic-keys.md) နှင့် [Cryptographic Key ကို သိုလှောင်ခြင်း](/my/guide/security/storing-cryptographic-keys.md) ကိုကြည့်ပါ။

## ခွင့်ပြုချက်များ {#permissions}

- Workflow ကို ထောက်ပံ့တဲ့ အသေးဆုံး ခွင့်ပြုချက် အမှတ်တံဆိပ် (သို့) အခန်းကဏ္ဍကို ပေးပါ။
- ဝန်ဆောင်မှုများ၊ trigger များ၊ အေဂျင့်များနှင့် အလိုအလျောက်လုပ်ရေးအတွက် ရည်စူးထားသော နည်းပညာစာရင်းများကို ဦးစားပေးပါ။ ကိုယ်ရေးကိုယ်တာ operator အကောင့်မှတစ်ဆင့် သက်တမ်းကြာမြင့်တဲ့ အလိုအလျားလုပ်ဆောင်မှုကို ရှောင်ရှားပါ။
- ထုတ်လုပ်သုံးစွဲမှု မစတင်မီ peer စီမံခန့်ခွဲခြင်း၊ metadata ပြောင်းလဲခြင်း၊ ပိုင်ဆိုင်မှုထုတ်ခြင်း၊ ဖျက်သိမ်းခြင်း၊ trigger မှတ်ပုံတင်ခြင်း၊ executor ပြောင်းလဲခြင်းနှင့် SORA Nexus အုပ်ချုပ်မှုအတွက် ခွင့်ပြုချက်များကို ပြန်လည်သုံးသပ်ပါ။
- ယာယီခွင့်ပြုချက်များ လိုအပ်ခဲ့သော ပြုပြင်ထိန်းသိမ်းမှုကာလ သို့မဟုတ် ပြောင်းရွှေ့မှု ပြီးဆုံးလျှင် ထိုခွင့်ပြုချက်များကို ရုပ်သိမ်းပါ။

[ခွင့်ပြုချက်များ](/my/blockchain/permissions.md) နှင့် [ခွင့်ပြုချက် လက်မှတ်များ](/my/reference/permissions.md) ကိုကြည့်ပါ။

## ကွန်ရက်ထိတွေ့မှု {#network-exposure}

- ပတ်ဝန်းကျင်အလိုက် peer-to-peer, Torii, telemetry နှင့် operator routes များကို ကန့်သတ်ပါ။ အများပြည်သူ ဖတ်ရှုခွင့်သည် အများပြည်သူ ရေးသားခြင်း သို့မဟုတ် operator access ကို မဆိုလိုပါ။
- VPNs, firewalls, reverse proxies, TLS termination တွေကို အသုံးပြုပြီး ဖြန့်ချိမှုအတွက် သင့်လျော်တဲ့နှုန်းသတ်မှတ်ချက်တွေကို သုံးပါ။
- အရင်းအမြစ် ထိန်းချုပ်မှုမှာ သိမ်းထားတဲ့ အခြေခံ မူပိုင်ခွင့် ခွင့်ပြုချက်တွေ၊ ကိုယ်စားလှယ်လက်မှတ်တွေနဲ့ လွှဲပြောင်းတဲ့ ခေါင်းစီးတွေကို ဖွဲ့စည်းမှုကနေ ထုတ်ထားပါ။
- ခွင့်ပြုချက်မရှိတဲ့ ဖောက်သည်တွေ ကန့်သတ်ထားတဲ့ လမ်းကြောင်းတွေကို မရောက်နိုင်တာကို စမ်းသပ်ပါ။

[Virtual Private Networks များ](/my/guide/security/vpn.md) နှင့် [Torii API အဆုံးသတ်မှတ်ချက်များ](/my/reference/torii-endpoints.md) ကိုကြည့်ပါ။

## လှည့်စားမှုနှင့် အဓမ္မပြုကျင့်မှုကို စောင့်ကြည့်ခြင်း {#fraud-and-abuse-monitoring}

- မမျှော်လင့်သော ပိုင်ဆိုင်မှုရွှေ့ပြောင်းမှု၊ ခွင့်ပြုချက်ပေးအပ်မှု၊ trigger ပြောင်းလဲမှု၊ peer ပြောင်းလဲမှုနှင့် ထပ်ခါတလဲလဲ ပယ်ချသော transaction များအတွက် လယ်ဂျာဖြစ်ရပ်များနှင့် လည်ပတ်ရေးအချက်ပြများကို စောင့်ကြည့်ပါ။
- Transaction ဟက်ရှ်များ၊ ဘလော့ခ်အမြင့်များ၊ ဖြစ်ရပ်မှတ်တမ်းများ၊ log များနှင့် အခြေအနေ snapshot များပါသော အထောက်အထားကို ထိန်းသိမ်းပါ။
- ထိခိုက်ခံရတဲ့ အရင်းအမြစ်များ (သို့) အလုပ်ဖြစ်စဉ်များအတွက် တာဝန်ရှိသူ လုံခြုံရေး၊ လုပ်ငန်းများနှင့် စီးပွားရေးလုပ်ငန်းရှင်များကို လမ်းကြောင်း သတိပေးချက်များ။

[လိမ်လည်မှု စောင့်ကြည့်ခြင်း](/my/guide/security/fraud-monitoring.md) ကို ကြည့်ပါ။

## Agent နှင့် Automation Guardrails များ {#agent-and-automation-guardrails}

- အလိုအလျောက်လုပ်ဆောင်မှုကို ဖတ်ရှုခွင့်သာဖြင့် စတင်ပြီး လုပ်ငန်းစဉ်ကို ပြန်လည်သုံးသပ်ပြီးမှသာ ရေးသားခွင့် ထည့်ပါ။
- အလိုအလျောက်လုပ်ခြင်းသည် ရည်ရွယ်ချက်ရှိစွာ ဖြန့်ချိထားသော ထုတ်လုပ်ရေး ဝန်ဆောင်မှုမှတစ်ပါးမဟုတ်ပါက သက်ဆိုင်ရာကွန်ရက်သို့ ကူးပြောင်းမှုများအတွက် လူသား၏ တိကျတဲ့ ခွင့်ပြုချက်ကို တောင်းဆိုပါ။
- ကိုယ်ပိုင်ကီးများကို agent အားပေးသည့် ညွှန်ကြားစာများထဲတွင် မဖော်ပြပါနှင့်။ ပတ်ဝန်းကျင်ကိန်းရှင်များ၊ keychain များ၊ ဟာ့ဒ်ဝဲလက်မှတ်ထိုးကိရိယာများ သို့မဟုတ် version control မှ ဖယ်ထားသော ပြင်ဆင်သတ်မှတ်ဖိုင်များမှ လျှို့ဝှက်ချက်များကို ဖတ်ယူသော စက်တွင်းကုဒ်ကို သုံးပါ။
- လျှို့ဝှက်ပစ္စည်းတွေ မပြသဘဲ စစ်ဆေးမှုကို ထောက်ခံတဲ့နည်းနဲ့ မှတ်တမ်း အလိုအလျောက် ဆုံးဖြတ်ချက်ချခြင်း။
