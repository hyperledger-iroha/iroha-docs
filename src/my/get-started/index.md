# Iroha 3 {#iroha-3}

Iroha 3 ပထမဆုံး ထုတ်ဝေမှုပါ။ Hyperledger Iroha Platform ကို ထောက်ခံပါတယ်။
Self-hosted ကွန်ရက်များနှင့် multi-data space များ SORA Nexus စေလွှတ်မှုပုံစံ
deterministic code base တစ်ခုပါ။

အဆင့်မြင့်မှာ Iroha 3 ပေါင်းစပ်ထားသည်-

- အတည်ပြုမှုနှင့် သိုလှောင်ခြင်း
- ကော်မတီ Iroha ဗစ်တိုးရီးယားစက် (IVM) ကိုင်တွယ်နိုင်သော စမတ်ဖုန်းစာချုပ်များအတွက်
- Norito Canonical cable format အဖြစ်
- Torii Client၊ Operator နဲ့ App ကို မျက်နှာပြုလုပ်တဲ့အတွက် APIs
- Sumeragi အမိန့်ချမှတ်ထားသော ဒေတာရရှိနိုင်မှုနှင့် ယုံကြည်စိတ်ချရတဲ့ ထုတ်လွှင့်ခြင်းတို့နှင့် ပတ်သက်၍ သဘောတူညီချက်
- သီးခြား ချိတ်ဆက်ထားသော လူဖတ်လို့ရတဲ့ အမည်မဖော်လိုသည့် domainless canonical accounts များ
