## Blockchain ledgers များ {#blockchain-ledgers}

Blockchain ledgers တွေဟာ blockchain ကို အသုံးပြုတဲ့ ဒစ်ဂျစ်တယ် မှတ်တမ်းတင်စနစ်တွေပါ။
ငွေကြေး မှတ်တမ်းတွေ သိမ်းဖို့ နည်းပညာပါ။
ဘဏ္ဍာရေးမှတ်တမ်းများအတွက် အသုံးပြုသော စာအုပ်များ၊ စျေးနှုန်းများ၊ သတင်းများနှင့်
ငွေလဲလှယ်မှု အချက်အလက်များ။

အလယ်ခေတ်ကာလအတွင်းမှာ စာအုပ်စာအုပ်တွေဟာ အများပြည်သူအတွက် ဖွင့်ထားပြီး
တိကျမှု စစ်ဆေးခြင်း။ ဒီစိတ်ကူးကို blockchain အခြေခံတဲ့
သိုလှောင်ထားသော ဒေတာများ၏ သက်ရောက်မှုကို စစ်ဆေးနိုင်သည့် စနစ်များ။

## တူညီသူ {#peer}

တစ်မျိုးတည်း Iroha ဆိုလိုသည်မှာ Iroha Process instance ကို အခြား Iroha လုပ်ငန်းစဉ်များ
client application တွေက ဆက်သွယ်နိုင်တယ်
တစ်စက်တည်းမှာ အတော်များများကို သိမ်းဆည်းနိုင်တယ် Iroha အဖော်တွေပေါ့။
တူညီတဲ့ အရင်းအမြစ်နဲ့ စွမ်းပကားတွေရှိတယ်
အရေးပါတဲ့ ခြွင်းချက်တစ်ခုနဲ့အတူ: တူညီသူတစ်ဦးပဲ ပြိုင်
Genesis Block ကို bootstrapping အဆင့်မှာ Iroha ကွန်ရက်။

အခြား blockchains တွေဟာ node သို့မဟုတ် validator နဲ့ တူတဲ့ သဘောတရားကို ရည်ညွှန်းနိုင်ပါတယ်။

အဖော်တွေဟာ ၎င်းရဲ့ အိမ်ရှင်စနစ်မှာ ဖြစ်စဉ်တစ်ခုဖြစ်နိုင်တယ်။
၎င်းသည်လည်း Docker container နဲ့ Kubernetes capsule တစ်ခုပါ။

## အရင်းအမြစ်များ {#asset}

ဘလော့ခ်ချိုင်းများတွင် အရင်းအမြစ်သည် တန်ဖိုးရှိ
blockchain ပေါ်မှာရှိတဲ့ အရာဝတ္ထုပါ။

အရင်းအမြစ်များနှင့် ပတ်သက်၍ ထပ်မံအချက်အလက်ရရှိနိုင်ပါသည်။
[ဒီမှာ](/my/blockchain/assets.md).

### ငွေကြေးအထောက်အပံ့များ {#fungible-assets}

ထိုအရင်းအမြစ်များကို အခြား အရင်းအမြစ်များအတွက် အလွယ်တကူ လဲလှယ်နိုင်သည်
၎င်းတို့ဟာ အပြန်အလှန် လဲလှယ်လို့ရတယ်။

ဥပမာ တူညီတဲ့ ငွေကြေးရဲ့ ယူနစ်အားလုံးဟာ တန်ဖိုးနဲ့တူပြီး
ကုန်ပစ္စည်းဝယ်ယူရန် အသုံးပြုနိုင်သည်။
ငွေကြေးစက္ကူများနှင့် ငွေစက္ကူများကို အဝတ်လျှော်ခြင်းမှလွဲ၍

### မဖြစ်နိုင်တဲ့ အရင်းအမြစ်များ {#non-fungible-assets}

မှိုမဖြစ်နိုင်တဲ့ အရင်းအမြစ်တွေဟာ ထူးခြားပြီး တန်ဖိုးရှိတာက ၎င်းတို့ရဲ့ သီးသန့်
၎င်းတို့၏တန်ဖိုးကို အခြားလက်ဝယ်များနှင့် ယှဉ်၍ မရနိုင်ပါ။

- ပန်းချီကားရဲ့ တန်ဖိုးဟာ အနုပညာရှင်၊ ၎င်းရဲ့ အချိန်ကာလကို အခြေခံပြီး ပြောင်းလဲနိုင်ပါတယ်။
  ပန်းချီကားနဲ့ အများပြည်သူရဲ့ စိတ်ဝင်စားမှုပါ။
- တစ်လမ်းတည်းမှာရှိတဲ့ အိမ်နှစ်ခုဟာ ထိန်းသိမ်းမှု အဆင့်ကွဲပြားနိုင်ပါတယ်။
- ရတနာထုတ်လုပ်သူတွေဟာ မကြာခဏဆိုသလို ပုံစံအမျိုးမျိုးကို ပေးကြတယ်။

### ထိန်းသိမ်းနိုင်သော ပိုင်ဆိုင်မှုများ {#mintable-assets}

အရင်းအမြစ်တစ်ခုဟာ တူညီတဲ့ အမျိုးအစားထက်ပိုပြီး ထုတ်လွှင့်နိုင်တယ်ဆိုရင် ထုတ်လုပ်နိုင်တာပါ။

### မထုတ်နိုင်သော ပိုင်ဆိုင်မှု {#non-mintable-assets}

asset ရဲ့ အစပိုင်းအရေအတွက်ကို တစ်ကြိမ် သတ်မှတ်ပြီး မပြောင်းလဲဘူးဆိုရင်
မသောက်နိုင်ဘူးလို့ ယူဆတယ်။

နိုင်ငံခြားရေး [Genesis Block ကို](/my/guide/configure/genesis.md) ဒီသတင်းအချက်အလက်ကို
ကော်မတီ Iroha ဖွဲ့စည်းမှု။

## ဗစ်ဇာနိတ်အမှားခံနိုင်ရည် (BFT) {#byzantine-fault-tolerance-bft}

ကွန်ရက်တစ်ခုနဲ့အတူ စနစ်တကျ လုပ်ဆောင်နိုင်ခြင်းရဲ့ အရည်အသွေး
မကောင်းဆိုးဝါးတဲ့ သရုပ်ဆောင်တွေရဲ့ ရာခိုင်နှုန်းတစ်ခုခုပါ။ Iroha အလုပ်လုပ်နိုင်တယ်
၎င်းရဲ့ peer-to-peer ကွန်ရက်မှာ မကောင်းဆိုးဝါးတဲ့ ပါဝင်သူ ၃၃ ရာခိုင်နှုန်းအထိရှိတယ်။

## Iroha အစိတ်အပိုင်းများ {#iroha-components}

Rust ပါဝင်သော မော်ဂျူးများ Iroha လုပ်ဆောင်မှု။

### Sumeragi (အင်ပါယာ) {#sumeragi-emperor}

နိုင်ငံခြားရေး Iroha သဘောတူညီမှုအတွက် တာဝန်ရှိတဲ့ မော်ဒူးပါ။

### Torii (ဂိတ်) {#torii-gate}

Module နှင့်အတူ incoming request ကိုကိုင်တွယ် logic for the [တူညီသူ](#peer). ဒါကို သုံးပြီး
ဝင်ရောက်လာသော ညွှန်ကြားချက်များကို လက်ခံ၊ လက်ခံပြီး လမ်းညွှန်ပေးခြင်း၊ HTTP မေးမြန်းချက်များလည်း
Run-time configuration update တွေလိုပါ။

### Kura (သိုလှောင်ရုံ) {#kura-warehouse}

အဆက်မပြတ် ဘလော့ဂ် သိုလှောင်ခြင်း။ Kura လက်မှတ်ရေးထိုးထားတဲ့ ဘလော့များ၊ ဟက်ရှ်ဘလော့များ၊ အမြင့်
အညွှန်းကိန်းများ၊ ပြန်လည်ထူထောင်ရေး ဘက်ထရီများနှင့် disk ပေါ်က commit-roster metadata များကို
[ကမ္ဘာ့အမြင်](#world-state-view-wsv) ပြန်လည်တည်ဆောက်ထားသည် Kura blocks when a
state snapshot ကိုမရနိုင်ဘူး ဒါမှမဟုတ် ဒေသတွင်း block store နောက်မှာရှိတယ်
[Kura သိုလှောင်ခြင်း](/my/blockchain/world.md#kura-storage).

### Kagami(ဆရာမနှင့် နမူနာနှင့်/သို့မဟုတ် မှန်) {#kagami-teacher-and-exemplar-and-or-looking-glass}

မကြာခဏသုံးတဲ့ ဒေတာအတွက် Generator ကို ဖန်တီးနိုင်ပါတယ်
ဘီလူးများ၊ စာရွက်စာတမ်းများ စသည်တို့။

### Merkle သစ်ပင် (ဟက်ရှ်သစ်ပင်) {#merkle-tree-hash-tree}

ဘလော့တစ်ခုချင်းစီရဲ့ အခြေအနေကို အတည်ပြုပြီး စစ်ဆေးဖို့ အသုံးပြုတဲ့ ဒေတာ တည်ဆောက်မှု
အမြင့်။ Iroha လက်ရှိ အကောင်အထည်ဖော်မှုက နှစ်ထပ်ပင်ပါ။
[ဝီကီပီးဒီးယား](https://en.wikipedia.org/wiki/Merkle_tree) ပိုမို အသေးစိတ် သိလိုပါက။

### စမတ်စာချုပ်များ {#smart-contracts}

Smart contracts ဆိုတာ blockchain ကို အခြေခံတဲ့ ပရိုဂရမ်တွေပါ။
အခြေအနေတွေ ပြည့်မီတယ်။ Iroha Smart contracts တွေကို အသုံးပြုပြီး အကောင်အထည်ဖော်ပါတယ်။
[core ကို Iroha အထူးညွှန်ကြားချက်များ](#core-iroha-special-instructions).

### နှိုးဆော်မှု {#triggers}

(၁၀) ဖြစ်ရပ်အမျိုးအစား Iroha အထူးသင်ကြားချက်
Block commit, time (အချို့ caveats များနှင့်အတူ) စသည်တို့ကို trigger များအကြောင်းပို
[ဒီမှာ](/my/blockchain/triggers.md).

### ဗားရှင်းထုတ်ခြင်း {#versioning}

တောင်းဆိုချက်တိုင်းမှာ API ၎င်းနဲ့ ပတ်သက်တဲ့ ဗားရှင်းပါ။
ကွဲပြားခြားနားတဲ့ ဘိုင်နရီဗားရှင်းတွေရဲ့ ပေါင်းစပ်မှုကို ခွင့်ပြုပါတယ်။ Iroha ဖောက်သည်/တူညီသူ
ဆော့ဝဲကို တုံ့ပြန်ဆက်သွယ်နိုင်ရန်အတွက်၊
Iroha ကွန်ရက်။

### ဟီဂျီးရီ (အချင်းချင်း ဂုဏ်သိက္ခာစနစ်) {#hijiri-peer-reputation-system}

Iroha ဒီစနစ်က လူသိများမှုကို ဦးစားပေးချမှတ်ဖို့ အခွင့်အလမ်းပေးတယ်။ [တူညီသူများ](#peer)
ကောင်းမွန်တဲ့ track record ရှိပြီး ဘေးထွက်ဆိုးကျိုးတွေကို လျော့နည်းစေပါတယ်။
မကောင်းဆိုးဝါး [တူညီသူများ](#peer).

## Iroha မော်ဂျူးများ {#iroha-modules}

တတိယနိုင်ငံမှ ဖြန့်ချိချက်များ Iroha custom functionality တွေကို ပေးပါတယ်။

## Iroha အထူးညွှန်ကြားချက် (ISI) {#iroha-special-instructions-isi}

လက်မှတ်ရေးထိုးထားသော စာကြည့်တိုက်များ Iroha. ဤအချက်များကို

## ကမ္ဘာ့အမြင် (WSV) {#world-state-view-wsv}

လက်ရှိ blockchain အခြေအနေကို မှတ်ဉာဏ်ထဲမှာ တင်ပြခြင်း WSV ပါဝင်ပါတယ်။
ကော်မတီ `World`, commited block hashes, transaction index များ၊ consensus topology များ၊
မေးမြန်းချက်များတွင် အသုံးပြုသော ရယူကိန်းညွှန်းကိန်းများ။
blocks တွေနဲ့ ပြန်လည်တည်ဆောက်လို့ရတယ်။ [Kura](#kura-warehouse). ကြည့်ပါ။
[ကမ္ဘာ့အမြင်](/my/blockchain/world.md#world-state-view-wsv).
