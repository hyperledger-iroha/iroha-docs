# ဂျင်နီဆစ် အမျိုးအစားများ {#genesis-types}

ဂျင်နီဆစ် ဖော်ပြချက်သည် [`RawGenesisTransaction`](#rawgenesistransaction) ၏ JSON ပုံစံ ဖြစ်သည်။ ဤရည်ညွှန်းချက်သည် ထိုအမျိုးအစားနှင့် ၎င်းတွင် ပါဝင်သော အမျိုးအစားအားလုံးကို စာရင်းပြုစုထားပြီး သတ်မှတ်ထားသော Iroha ရင်းမြစ်ကုဒ်မှ ထုတ်လုပ်ထားသည်။ စာရင်းဇယားမှတ်တမ်း၏ အမျိုးအစားအားလုံးအတွက် [ဒေတာပုံစံ အစီအစဉ်](/my/reference/data-model-schema.md) တွင် ဖော်ပြထားသည့်အတိုင်း သင့် node မှ schema ကို ရယူပါ။
