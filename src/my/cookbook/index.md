# Iroha 3 လျှောက်လွှာစာအုပ် {#iroha-3-application-cookbook}

ဆန့်ကျင်ပြီး တည်ဆောက်ပါ။ Iroha 3 အသေးစား၊ စစ်ဆေးလို့ရတဲ့ ချက်ပြုတ်ချက်တွေနဲ့ Taira testnet နဲ့ keep Minamoto စာဖတ်လို့သာ ရနိုင်တယ်ဆိုတဲ့အချက်အလက်တိုင်းမှာ အများပြည်သူ ဖတ်လို့ရလားဆိုတာ ဖော်ပြထားတယ်။ ပုံမှန် ငွေကြေးထောက်ပံ့ထားတဲ့ အကောင့် စာရင်း (သို့) ခွင့်ပြုချက် ကန့်သတ်ထားတဲ့ လုပ်ဆောင်မှုပါ။ Commands တွေမှာ Current ကိုသုံးပါတယ်။ I105 အကောင့် ID တွေ၊ ရှင်းလင်းတဲ့ အခွန် ရွေးချယ်မှု နဲ့ Iroha ပရိုတိုကောလ် အပြီးသတ်ခြင်း [`0010c5a70039eac101a4846499ba9ceaf43eb65c`](https://github.com/hyperledger-iroha/iroha/tree/0010c5a70039eac101a4846499ba9ceaf43eb65c).

[Taira သို့ ချိတ်ဆက်ပါ။](./connect-to-taira.md) မှစပါ။ ၎င်းသည်ဖောက်သည်ကွန်ပျူတာ configuration နှင့် fee metadata ကို command-line recipes များတွင်ပြန်လည်အသုံးပြုသည်။ ဤစာရွက်စာတမ်းမှ fee asset ID ကို ဘယ်တော့မှ ကူးမယူပါ၊ လက်ရှိ Taira testnet ဘဏ္ဍာရေးဝန်ဆောင်မှု တုံ့ပြန်မှုမှရယူပါ။

## ဝင်ရောက်မှု အဆင့်များ {#access-levels}

- အများပြည်သူ  လျှို့ဝှက်လက်မှတ်ထိုးသူ (သို့) ကွန်ရက် ခွင့်ပြုချက် မလိုပါ။
- စာရေးရန် အသင့်ရှိ  ငွေကြေးထောက်ပံ့ထားသော Taira စမ်းသပ်စာရင်း၊ ရှင်းလင်းစွာ အခွန်ပေးသွင်းသူနှင့် testnet ဘဏ္ဍာရေးဝန်ဆောင်မှုမှ ပြန်လည်ပို့သည့် လက်ရှိ အခွန်လက်ဝယ်ကို အသုံးပြုပါ။
- ခွင့်ပြုချက်လိုအပ်သည်  Taira သည်အမည်ပေးထားသော ဆော့ဖ်ဝဲ အကောင်အထည်ဖော်မှု ပတ်ဝန်းကျင် ခွင့်ပြုချက်ကို (သို့) အုပ်ချုပ်သော နာမ်ဇိုင်းကို ပေးရမည်ဖြစ်သည်။ အဆိုပါ ထောက်ပံ့ငွေမရှိတဲ့အခါ ဖန်တီးထားတဲ့ ဒေသတွင်းကွန်ရက်ကိုအသုံးပြုပါ။ ဒေသတွင်းအောင်မြင်မှုက Taira ခွင့်ပြုမှု မူလစာရင်းကိုမပေးပါဘူး။

Minamoto သို့ ချက်ပြုတ်စာအုပ်တစ်ခုမှ စာမပို့နိုင်ပါ။
