# စကားလုံးများ၊ အခြေအနေများ၊ ဆင်ခြင်တုံတရား {#expressions-conditionals-logic}

[Iroha အထူးညွှန်ကြားချက်များ](./instructions.md) အားလုံးသည်အဓိပ္ပါယ်ဖွင့်ဆိုချက်များကိုအသုံးပြုသည်။အဓိပ္ပာယ်ဖွင့်ဆိုမှုတစ်ခုစီမှာ `EvaluatesTo` ရှိပြီး ညွှန်ကြားချက် အကောင်အထည်ဖော်ရာတွင် အသုံးပြုသည်။ အကောင့်နာမည်ကို တိုက်ရိုက်သတ်မှတ်နိုင်သော်လည်းသင်ဟာ သင်္ချာ သို့မဟုတ် string operation တစ်ချို့မှတစ်ဆင့် ID အကောင့်ကိုလည်းသတ်မှတ်နိုင်သည်။ အကောင့်တစ်ခုက blockchain မှာ မှတ်ပုံတင်ထားလားဆိုတာလည်း စစ်ဆေးနိုင်ပါတယ်။

`EvaluatesTo<bool>` ကို အကောင်အထည်ဖော်တဲ့ ဖော်ပြချက်တွေကို အသုံးပြုပြီး အခြေအနေဆိုင်ရာ ဆင်ခြင်တုံတရားကို သတ်မှတ်နိုင်ပြီး ချိတ်ဆက်မှုမှာ ပိုရှုပ်ထွေးတဲ့ လုပ်ငန်းစဉ်တွေ လုပ်ဆောင်နိုင်ပါတယ်။ ဥပမာ၊ သီးခြားစာရင်းတစ်ခု မှတ်ပုံတင်ထားရင်သာ `Mint` ညွှန်ကြားချက်ကို ပေးပို့နိုင်တယ်။

ဒါကို မေးမြန်းချက်တွေနဲ့ ပေါင်းစပ်နိုင်ပြီး blockchain ကို အံ့ဖွယ်အရာတွေ လုပ်ဖို့ ပရိုဂရမ်လုပ်လို့ရတာကို သတိရပါ။ ဒါကတော့ ကျွန်တော်တို့ခေါ်တဲ့ စမတ်ကွန်ထရက်တွေပါ၊ blockchain နည်းပညာရဲ့ အဆင့်မြင့် အသုံးပြုမှုရဲ့ အဓိပ္ပါယ်ဖွင့်တဲ့ လက္ခဏာတစ်ခုပါ။
