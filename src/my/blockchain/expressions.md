# စကားလုံးများ၊ အခြေအနေများ၊ ဆင်ခြင်တုံတရား {#expressions-conditionals-logic}

[Iroha သင်ကြားမှု လုပ်ငန်းများ](./instructions.md) အားလုံးဟာ Expressions ပေါ်မှာ အလုပ်လုပ်ကြပါတယ် Expression တစ်ခုချင်းစီမှာ `EvaluatesTo` ရှိပြီး ဒါက instruction execution မှာ သုံးပါတယ်။ အကောင့်အမည်ကို သတ်မှတ်နိုင်ပေမဲ့ အကောင့် ID ကို သင်္ချာ (သို့) string operation တစ်ခုမှတဆင့် သတ်မှတ်နိုင်ပါတယ်။ အကောင့်တစ်ခုဟာ blockchain မှာလည်း မှတ်ပုံတင်ထားလားဆိုတာ စစ်ဆေးနိုင်ပါတယ်။

`EvaluatesTo<bool>` ကို အကောင်အထည်ဖော်တဲ့ အမူအရာတွေကို အသုံးပြုပြီး အခြေအနေဆိုင်ရာ ဆင်ခြင်တုံတရားကို သတ်မှတ်နိုင်ပြီး ချိတ်ဆက်မှုမှာ ပိုရှုပ်ထွေးတဲ့ လုပ်ငန်းတွေ လုပ်ဆောင်နိုင်ပါတယ်။ ဥပမာ၊ သီးခြားစာရင်းတစ်ခု မှတ်ပုံတင်ထားရင်သာ `Mint` ညွှန်ကြားချက်ကို ပေးပို့နိုင်ပါတယ်။

ဒါကို မေးမြန်းချက်တွေနဲ့ ပေါင်းစပ်နိုင်ပြီး blockchain ကို အံ့ဖွယ်အရာတွေ လုပ်ဖို့ ပရိုဂရမ်လုပ်လို့ရတာကို သတိရပါ။ ဒါကတော့ ကျွန်တော်တို့ခေါ်တဲ့ စမတ်ကွန်ထရက်တွေပါ၊ blockchain နည်းပညာရဲ့ အဆင့်မြင့် အသုံးပြုမှုရဲ့ အဓိပ္ပါယ်ဖွင့်တဲ့ လက္ခဏာတစ်ခုပါ။
