# དྲི་བཀོད་ཚུ་ {#queries}

བྱུང་ལས་ཀྱི་ མཁོ་མངགས་འབད་མི་དང་ ཚགས་མ་ཚུ་གིས་ བཀག་ཆ་གནས་སྟངས་ནང་ བསྒྱུར་བཅོས་ཚུ་ རྗེས་སུ་འཇུག་ཚུགས། ཁྱོད་ལུ་ད་ལྟོའི་གནས་སྟངས་ཀྱི་ཐད་ཀར་མཐོང་སྣང་དགོཔ་ད་ འདྲི་དཔྱད་ཅིག་ལག་ལེན་འཐབ།

དྲི་བཀོད་འདི་ བརྡ་སྟོན་དང་འདྲཝ་འབད་མི་ འདྲ་མཉམ་ཆུང་ཀུ་ཚུ་ཨིན། ཁྱོད་ཀྱིས་ Iroha མཐུད་མཚམས་ཅིག་ལུ་ བཏང་ཞིནམ་ལས་ འཛམ་གླིང་གི་གནས་སྟངས་ཀྱི་མཐོང་སྣང་དེ་ གསལ་ཏོག་ཏོ་སྦེ་ཐོབ་འོང་།

དྲ་རྒྱ གིས་ བརྡ་དོན་གཞན་ཡང་བཏོན་ཚུགས། འདྲི་དཔྱད འབད་ཚུགས་པའི་ འཛམ་གླིང་གནས་སྟངས བརྡ་དོན་འདི་ Iroha དྲ་རྒྱ རེ་རེ་ནང་ཐོབ་ཚུགས་ཟེར་ཁས་ལེན་ཡོད་པའི་དབྱེ་བ་གཅིག་པུ་ཨིན།

Iroha གི་ལག་ལེན་འཐབ་མི་རེ་ལུ་ བརྡ་དོན་གཞན་ཚུ་ཡང་ ཡོད་པའི་གནས་ཚུལ། དཔེར་ན་ གློག་ཐག་ར་བ་གི་ གནད་སྡུད་ཚུ་ ལག་ལེན་འཐབ་ནི་དེ་ ལས་འཛིན་གྱི་ཁ་ཐུག་ལས་ཨིན། ལས་ཀ་དེ་ལག་ལེན་འཐབ་ནིའི་ཚབ་ལུ་ ལཱ་གི་རྒྱབ་སྐྱོར་འབད་ནིའི་དོན་ལུ་ རང་གིས་རང་རང་གིས་ གྲོས་ཐག་བཅད་དགོ་དོ་ཡོདཔ་ཨིན་ན་མེན་ན་ འདི་ཁོ་རའི་ཁ་ཐུག་ལས་ཨིན། དེ་དང་འཁྲིལཝ་ད་ འགན་ཁུར་ལ་ལུ་ཅིག་ ཨ་རྟག་རང་ དགོཔ་ཨིན་ དཔེར་ན་ ཁྱོད་ཀྱིས་རྩིས་ཐོ་གི་ལྷག་ལུས་ལུ་ ཐོ་ལེན་འབད་ཚུགས་ནི་ཡོདཔ་ཨིན།

ཞིབ་འཚོལ་གྱི་ གྲུབ་འབྲས་ཚུ་ [སྦེ་དབྱེ་ཞིབ་འབད་ཚུགས་](#sorting), [ཤོག་དབྱེ་ཡོད](#pagination)དང་ [ཚགས་ཡོད](#filters) མཉམ་རོགས-ཟུར འདི་ཡང་ཅིག་ཁར་ཨིན། དབྱེ་བ་ཕྱེ་ནི་དེ་ ཟུར་གནས་གནད་སྡུད ལྡེ་མིག ལུ་ ཚིག་མཛོད་རིམ་པའབདཝ་ཨིན། ཐིག་ཁྲམ་ཚུ་ མངའ་ཁོངས་དམིགས་བསལ (རྐྱང་གི་ IP ཁ་བྱང ཚགས་མ ཁེབས) ལས་ `begins_with`བཟུམ་ ཡིག་རྒྱུན་ཆ་ཤས ཐབས་ལམ་ཚུ་ རྒྱུ་མཚན་ལས་རིམ བཀོལ་སྤྱོད་ཚུ ལག་ལེན་འཐབ་ཐོག་ལས་བསྡོམས་ཏེ་འབད་ཚུགས།

## Taira ལུ་ བརྟག་དཔྱད་རྐྱབས། {#try-it-on-taira}

Taira གིས་ ཀློག་རྐྱང་གི་དྲི་བཀོད་གྲོགས་རམ་ཚུ་ JSON གི་ཐོག་ལས་ སྤྱིར་བཏང་ཐོན་ཁུངས་ཚུ་གི་དོན་ལུ་ གསལ་སྟོན་འབདཝ་ཨིན། ཁྱོད་ཀྱིས་ SDK སྒྲིག་འཇུག་མ་བཙུགས་པའི་ཧེ་མར་ ཤོག་ལེབ་བཟོ་ནི་དང་ ལན་སློང་ལག་ལེན་འབད་ནིའི་དོན་ལུ་ ལག་ལེན་འཐབ་ཨིན།

```bash
TAIRA_ROOT=https://taira.sora.org

curl -fsS "$TAIRA_ROOT/v1/accounts?limit=3" \
  | jq '{total, ids: [.items[].id]}'

curl -fsS "$TAIRA_ROOT/v1/domains?limit=3" \
  | jq '{total, domains: [.items[].id]}'

curl -fsS "$TAIRA_ROOT/v1/assets/definitions?limit=3" \
  | jq '{total, assets: [.items[] | {id, name, total_quantity}]}'
```

མཉེན་ཆས་བརྟག་དཔྱད་ཀྱི་དོན་ལུ་ འ་ནི་ཐ་མག་བརྟག་དཔྱད་ཚུ་ མཚན་རྟགས་བཀོད་ཡོད་པའི་ཚོང་འབྲེལ་བརྟག་དཔྱད་ཚུ་ལས་སོ་སོ་སྦེ་བཞག། ལྷག་རྐྱངམ་ཅིག་འདྲི་དཔྱད་འཐུས་ཤོར་འདི་གིས་ སྤྱིར་བཏང་ལུ་ མཚན་རྟགས་བཀོད་མི་གཞི་སྒྲིག་ལུ་མ་སྟོན་པའི་ཧེ་མ་ མཐའ་མཚམས་འཐོབ་ཚུགས་མི་དང་ ཡོངས་འབྲེལ་ལྷོད་ཚུགས་མི་ ཡང་ན་ འགྲུལ་ལམ་མཐུན་སྒྲིག་ལུ་ བརྡ་སྟོནམ་ཨིན།

## དྲི་བཀོད་བཟོ་ནི། {#create-a-query}

SDK ཡང་ན་ CLI ལས་ ཐོ་བཀོད་ཅན་གྱི་དྲི་བཀོད་བཟོ་མི་ལག་ལེན་འཐབ་། དཔེར་ན་ད་ལྟོའི་གནས་སྡུད་དཔེ་རྙིང་འདི་གིས་ `FindAccounts` ལུ་ཐོ་ཡིག་གི་རྩིས་ཐོ་ཚུ་གི་དོན་ལུ་ གསལ་སྟོན་འབདཝ་ཨིན།

```rust
let query = FindAccounts;
```

འདི་Alice་གི་ རྒྱུ་དངོས་ཚུ་འཚོལ་བའི་དྲི་བཀོད་གི་དཔེ་ཨིན།

```rust
let alice_id = load_canonical_account_id_from_client_config()?;
let query = FindAssetsByAccountId::new(alice_id);
```

## ཤོག་ལེབ་ཚུ་ {#pagination}

འདྲི་དཔྱད་རྐྱང་པ་དང་ བསྐྱར་ལོག་འབད་བཏུབ་པའི་འདྲི་དཔྱད་ཆུང་ཀུ་ཚུ་གི་དོན་ལུ་ ཁྱོད་ཀྱིས་ `client.request` ལག་ལེན་འཐབ་སྟེ་ འདྲི་དཔྱད་ཅིག་བཙུགས་ཏེ་ གྲུབ་འབྲས་འདི་ གཅིག་ཁར་ཐོབ་ཚུགས།

དེ་འབདཝ་ད་ `FindAccounts`, `FindAssets`, ཡང་ན་ `FindBlocks` བཟུམ་གྱི་ བསྐྱར་ལོག་འབད་བཏུབ་པའི་འདྲི་དཔྱད་རྒྱ་ཆེ་བ་ཚུ་གིས་ གྲུབ་འབྲས་ཆ་ཚན་སྦོམ་ཚུ་སླར་ལོག་འབད་ཚུགས། མཉམ་རོགས་དང་ མཁོ་སྤྲོད་འབད་མི་གུ་མངོན་གསལ་མར་ཕབ་འབད་ནི་ལུ་ ཤོག་ལེབ་བཟོ་ནི་ལག་ལེན་འཐབ།

`Pagination` བཟོ་བསྐྲུན་འབད་ནི་ལུ་ ཁྱོད་ཀྱིས་ `client.request_with_pagination(query, pagination)` འདི་ `pagination` འདི་གཤམ་གསལ་ལྟར་བཟོ་བསྐྲུན་འབད་ཡོད་ས་ལུ་འབོ་དགོཔ་ཨིན།

```rust
let starting_result: u32 = _;
let limit: u32 = _;
let pagination = Pagination::new(Some(starting_result), Some(limit));
```

## གློག་ཐིག་ཚུ་ {#filters}

ཁྱོད་ཀྱིས་འདྲི་དཔྱད་ཅིག་གསར་བསྐྲུན་འབད་བའི་སྐབས་ གསལ་བཀོད་འབད་ཡོད་པའི་ཚགས་མ་དང་མཐུན་པའི་གྲུབ་འབྲས་ཚུ་རྐྱངམ་ཅིག་སླར་ལོག་འབད་ནི་ལུ་ ཚགས་མ་ཅིག་ལག་ལེན་འཐབ་བཏུབ།

གློག་ཐིག་ཚུ་ འདྲི་དཔྱད་ལུ་དམིགས་ཏེ་ཨིན། དཔེར་ན་རྩིས་ཐོ་གི་དྲི་བཀོད་འདི་རྩིས་ཐོའི་ངོ་རྟགས་དང་ མེ་ཊ་ཌེ་ཊ་ལས་བཏངམ་ད་ རྒྱུ་དངོས་གི་དྲི་བཀོད་དེ་ རྒྱུ་དངོས་ལས་བཏངམ་ཨིན། དོན་འགྲེལ་, ལག་ལེན་པ་གི་རྩིས་ཐོ་, ཡང་ན་ ཌོ་མ་ནེཨའི་འཆར་གཞི། འབད་ཚུགས་པ་ཅིན་ SDK གིས་ ཐོ་བཀོད་འབད་ཡོད་པའི་དྲི་བཀོད་བཟོ་སྐྲུན་པ་དེ་ཚུ་ལག་ལེན་འཐབ་ནི་དེ་གི་དོན་ལུ་ གློག་ཐིག་དབྱེ་བ་འདི་ དྲི་བཀོད་ཐོན་སྐྱེད་དབྱེ་བ་དང་མཐུནམ་སྦེ་འབདཝ་ཨིན།

## དབྱེ་བ་ཕྱེ་ཐབས། {#sorting}
