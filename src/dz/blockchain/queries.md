མ་གཞི་ blockchain གི་གནས་སྟངས་གི་སྐོར་ལས་ བརྡ་དོན་མང་ཤོས་ཅིག་ ང་བཅས་ཀྱིས་ སྔོན་ལས་སྟོན་དོ་བཟུམ་སྦེ་ འབྱུང་རྐྱེན་གྱི་ subscriber དང་ filter ལག་ལེན་འཐབ་ཐོག་ལས་ འབྱུང་རྐྱེན་ཚུ་གི་ཁྱབ་ཚད་ལུ་ ཕན་ཁྱད་ཅན་ཅིག་ལུ་ མར་ཕབ་འབད་ཚུགས་རུང་ འཕྲལ་འཕྲལ་ར་ ཁྱོད་ཀྱིས་ ཐད་ཀར་དུ་འབྲེལ་བ་འཐབ་དགོཔ་ཨིན། དྲི་བ་ཚུ་བཙུགས་དགོ།

དྲི་བཀོད་འདི་ བརྡ་སྟོན་དང་འདྲཝ་ཨིན་པའི་ གནད་དོན་ཆུང་ཀུ་ཅིག་ཨིནམ་ད་ དེ་ཡང་ Iroha ཆ་རོགས་ལུ་ བཏང་ཞིནམ་ལས་ ད་ལྟོའི་འཛམ་གླིང་གི་གནས་སྟངས་ཀྱི་མཐོང་སྣང་ནང་ལས་ དབྱེ་ཁག་ཚུ་དང་གཅིག་ཁར་ ལན་སློག བཙུགས་འོང་།

འ་ནི་ བརྡ་དོན་འདི་ ཐད་ཀར་དུ་ འབྲེལ་བ་ཡོད་པའི་བརྡ་དོན་ངོ་མ་མེན་ དེ་འབདཝ་ད་ འདི་ བརྡ་དོན་གི་རིགས་གཅིག་པུ་ཨིན་ འདི་གིས་ འགྲུལ་འཕྲིན་ཡོངས་འབྲེལ་ལུ་ ཕན་ཐོགས་འབྱུང་ཚུགས་པའི་ ཉེན་ཁ་ཡོདཔ་ཨིན།

Iroha གི་ལག་ལེན་འཐབ་མི་རེ་ལུ་ བརྡ་དོན་གཞན་ཚུ་ཡང་ ཡོད་པའི་གནས་ཚུལ། དཔེར་ན་ གློག་ཐག་ར་བ་གི་ གནད་སྡུད་ཚུ་ ལག་ལེན་འཐབ་ནི་དེ་ ལས་འཛིན་གྱི་ཁ་ཐུག་ལས་ཨིན། ལས་ཀ་དེ་ལག་ལེན་འཐབ་ནིའི་ཚབ་ལུ་ ལཱ་གི་རྒྱབ་སྐྱོར་འབད་ནིའི་དོན་ལུ་ རང་གིས་རང་རང་གིས་ གྲོས་ཐག་བཅད་དགོ་དོ་ཡོདཔ་ཨིན་ན་མེན་ན་ འདི་ཁོ་རའི་ཁ་ཐུག་ལས་ཨིན། དེ་དང་འཁྲིལཝ་ད་ འགན་ཁུར་ལ་ལུ་ཅིག་ ཨ་རྟག་རང་ དགོཔ་ཨིན་ དཔེར་ན་ ཁྱོད་ཀྱིས་རྩིས་ཁྲ་གི་ལྷག་ལུས་ལུ་ ཐོ་ལེན་འབད་ཚུགས་ནི་ཡོདཔ་ཨིན།

ཞིབ་འཚོལ་གྱི་ གྲུབ་འབྲས་ཚུ་ [སྦེ་དབྱེ་ཞིབ་འབད་ཚུགས་](#sorting), [paginated](#pagination)དང་ [filtered](#filters) peer-side འདི་ཡང་ཅིག་ཁར་ཨིན། དབྱེ་བ་ཕྱེ་ནི་དེ་ metadata key ལུ་ lexicographicallyའབདཝ་ཨིན། ཐིག་ཁྲམ་ཚུ་ domain-specific (རྐྱང་གི་ IP address filter masks) ལས་ `begins_with`བཟུམ་ substring ཐབས་ལམ་ཚུ་ logic operations ལག་ལེན་འཐབ་ཐོག་ལས་བསྡོམས་ཏེ་འབད་ཚུགས།

## Taira ལུ་ བརྟག་དཔྱད་རྐྱབས། {#try-it-on-taira}

Taira གིས་ ཀློག་རྐྱང་གི་དྲི་བཀོད་གྲོགས་རམ་ཚུ་ JSON གི་ཐོག་ལས་ སྤྱིར་བཏང་ཐོན་ཁུངས་ཚུ་གི་དོན་ལུ་ གསལ་སྟོན་འབདཝ་ཨིན། ཁྱོད་ཀྱིས་ SDK སྒྲིག་འཇུག་མ་བཙུགས་པའི་ཧེ་མར་ ཤོག་ལེབ་བཟོ་ནི་དང་ ལན་སློང་ལག་ལེན་འབད་ནིའི་དོན་ལུ་ ལག་ལེན་འཐབ་ཨིན།

```bash
TAIRA_ROOT=https://taira.sora.org

curl -fsS "$TAIRA_ROOT/v1/accounts?limit=3" \
  | jq '{total, ids: [.items[].id]}'

curl -fsS "$TAIRA_ROOT/v1/domains?limit=3" \
  | jq '{total, domains: [.items[].id]}'

curl -fsS "$TAIRA_ROOT/v1/assets/definitions?limit=3" \
  | jq '{total, assets: [.items[] | {id, name, total_quantity}]}'
```

ཨེཔ་གི་བརྟག་དཔྱད་འབད་ནིའི་དོན་ལུ་ ལག་ལེན་ལག་ལེན་གྱི་བརྟག་དཔྱད་ཚུ་ ཐོ་བཀོད་ཅན་གྱི་ བརྟག་ཞིབ་ལས་སོ་སོར་སྦེ་བཞག་དགོ། ཀློག་རྐྱང་བའི་དྲི་བཀོད་མ་ཐོབ། འདི་ཡང་ མང་ཤོས་ར་ མཐའ་མཇུག་གི་སྒོ་སྒྲིག་ཚུ་དང་ མཐོང་ཚུགསཔ་བཟོ་ནི་དང་ ཕྲང་ལམ་མཐུན་རྐྱེན་ཚུ་ ཐོ་བརྡ་སྤྲོད་ནི་ལས་ སྔོན་འགོག་ལུ་ བརྡ་སྟོན་འབདཝ་ཨིན།

## དྲི་བཀོད་བཟོ་ནི། {#create-a-query}

SDK ཡང་ན་ CLI ལས་ ཐོ་བཀོད་ཅན་གྱི་དྲི་བཀོད་བཟོ་མི་ལག་ལེན་འཐབ་། དཔེར་ན་ད་ལྟོའི་གནས་སྡུད་དཔེ་རྙིང་འདི་གིས་ `FindAccounts` ལུ་ཐོ་ཡིག་གི་རྩིས་ཁྲ་ཚུ་གི་དོན་ལུ་ གསལ་སྟོན་འབདཝ་ཨིན།

```rust
let query = FindAccounts;
```

འདི་ཨ་ལིསི་གི་ རྒྱུ་དངོས་ཚུ་འཚོལ་བའི་དྲི་བཀོད་གི་དཔེ་ཨིན།

```rust
let alice_id = load_canonical_account_id_from_client_config()?;
let query = FindAssetsByAccountId::new(alice_id);
```

## ཤོག་ལེབ་ཚུ་ {#pagination}

ཨང་གཅིག་ཅན་གྱི་དྲི་བ་དང་ བསྐྱར་ཞིབ་འབད་བཏུབ་པའི་དྲི་བ་ཆུང་ཀུ་ཚུ་གི་དོན་ལུ་ ཁྱོད་ཀྱིས་ `client.request` ལག་ལེན་འཐབ་སྟེ་དྲི་བ་འདི་བཙུགས་ཏེ་ གྲུབ་འབྲས་དེ་ དུས་ཡུན་དུམ་གྲ་ཅིག་ནང་ཐོབ་ཚུགས།

ཨིན་རུང་ `FindAccounts`, `FindAssets` ཡང་ན་ `FindBlocks`བཟུམ་ བསྐྱར་ཞིབ་འབད་བཏུབ་པའི་དྲིས་ལམ་སྦོམ་ཚུ་གིས་ གྲུབ་འབྲས་ཀྱི་སྡེ་ཚན་སྦོམ་ཅིག་སླར་ལོག་འབད་ཚུགས། འདྲན་འདྲ་དང་མགྲོན་པ་ལུ་དཀའ་ངལ་མར་ཕབ་འབད་ནིའི་དོན་ལས་ pagination ལག་ལེན་འཐབ་ཨིན།

`Pagination` བཟོ་སྐྲུན་འབད་ནིའི་དོན་ལུ་ ཁྱོད་ཀྱིས་ `client.request_with_pagination(query, pagination)` ལུ་འབོ་དགོཔ་ཨིན། འདི་ནང་ལུ་ `pagination` བཟོ་སྐྲན་འདི་ အောက်ལུ་བཀོད་ཡོདཔ་ཨིན།

```rust
let starting_result: u32 = _;
let limit: u32 = _;
let pagination = Pagination::new(Some(starting_result), Some(limit));
```

## གློག་ཐིག་ཚུ་ {#filters}

ཁྱོད་དྲི་བ་བཀོད་པའི་སྐབས་ལུ་ ཁྱོད་ཀྱིས་ ཕི་ལཊར་ལག་ལེན་འཐབ་སྟེ་ གྲུབ་འབྲས་ཚུ་རྐྱངམ་གཅིག་ བཏོན་གཏང་ཚུགས། འདི་ཚུ་ ཁ་གསལ་འབད་མི་ ཕི་ལཱཊར་དང་མཐུད།

གློག་ཐིག་ཚུ་ འདྲི་དཔྱད་ལུ་དམིགས་ཏེ་ཨིན། དཔེར་ན་རྩིས་ཁྲ་གི་དྲི་བཀོད་འདི་རྩིས་ཁྲའི་ངོ་རྟགས་ ཡང་ན་ མེ་ཊ་ཌེ་ཊ་ལས་བཏངམ་ད་ རྒྱུ་དངོས་གི་དྲི་བཀོད་དེ་ རྒྱུ་དངོས་གི་འགྲེལ་བཤད་དང་ བདག་འཛིན་པའི་རྩིས་ཁྲ་ དེ་ལས་ ས་ཁོངས་ཀྱི་འཆར་སྣང་ལས་བཏངམ་ཨིན། SDK གིས་ ཐོ་བཀོད་འབད་ཡོད་པའི་དྲི་བཀོད་བཟོ་སྐྲུན་པ་དེ་ཚུ་ ལག་ལེན་འཐབ་པ་ཅིན་ ཕི་ལཱར་གི་དབྱེ་བ་དེ་ དྲི་བཀོད་ཐོན་སྐྱེད་དབྱེ་བ་དང་མཐུནམ་འབྱུང་འོང་།

## དབྱེ་བ་ཕྱེ་ཐབས། {#sorting}

Iroha གིས་ [ metadata](/dz/blockchain/metadata.md) དང་གཅིག་ཁར་ ཨང་གྲངས་དབྱེ་ཞིབ་འབད་ཚུགས་པ་ཅིན་ ཁྱོད་ཀྱིས་དྲི་བ་བཀོད་པའི་སྐབས་ལུ་ དབྱེ་བ་ཕྱེ་ནིའི་ལྡེ་མིག་ཅིག་བཙུགསཔ་ཨིན། སྤྱིར་བཏང་ལག་ལེན་གྱི་གནད་དོན་འདི་རྩིས་ཁྲ་ཚུ་གི་དོན་ལུ་ `registered-on` metadata ནང་ཐིག་ཡོད་མི་འདི་ཨིན་ འདི་ཡང་དབྱེ་ཞིབ་འབད་བའི་བསྒང་ལས་ ཁྱོད་ཀྱིས་རྩིས་ཁྲ་གི་ཐོ་ཡིག་ལུ་བལྟ་ཚུགས།

དབྱེ་བ་ཕྱེ་ནི་དེ་ [ metadata](/dz/blockchain/metadata.md) ཡོད་པའི་ཚོགས་སྡེ་ཚུ་གི་དོན་ལུ་རྐྱངམ་གཅིག་ ལག་ལེན་འཐབ་དོ་ཡོདཔ་ད་ བརྟག་ཞིབ་གི་གྲུབ་འབྲས་ཚུ་ sortingགི་དོན་ལུ་ metadata key འདི་ལག་ལེན་འཐབ་ཡོདཔ་ཨིན།

ཁྱོད་ཀྱིས་ ཐོ་བཀོད་འབད་ཐངས་འདི་ pagination དང་ filter ཚུ་དང་གཅིག་ཁར་བསྡོམས་བཏུབ། འདི་ཡང་ ཐོ་བཀོད་ཀྱི་ཁྱད་ཆོས་འདི་ གདམ་ཁ་རྐྱབས་ཅིག་ཨིནམ་ལས་ pageage ཡོད་པའི་དྲི་བ་མང་ཤོས་ཅིག་ལུ་ དགོས་མཁོ་མེད་ཟེར་ངོས་ལེན་འབད་དགོ།
