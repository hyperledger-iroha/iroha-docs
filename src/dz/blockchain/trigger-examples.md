# འབྱུང་རྐྱེན་འབྱུང་ནིའི་དཔེ་ཡིག {#event-trigger-example}

དཔེ་འདི་ནང་ Iroha 3 ཌའི་ཊ་གི་རྣམ་གཞག་ནང་ལུ་ རྫོང་ཁའི་རྩིས་ཁྲ་མེད་པའི་ IDs དང་ འཆར་གཞི་ཅན་གྱི་བཅའ་ཡིག་ཚུ་ལག་ལེན་འཐབ་ཡོདཔ་ཨིན།

མཐུད་སྦྲེལ་ནང་:

- ཨ་ལིསི་གི་ལྡེ་མིག་གིས་ བཀག་འཛིན་འབད་མི་ སྒྲིག་གཞི་གཅིག་
- Mad Hatter གི་ལྡེ་མིག་གིས་ ཚད་འཛིན་འབད་མི་ སྒྲིག་གཞི་ཅིག་ཨིན།
- རྒྱུ་དངོས་གི་འགྲེལ་བཤད་འདི་ `tea` གི་འོག་ལས་ `wonderland.universal`སྦེ་བཀོད་རྒྱ་འབད་ཡོདཔ་ཨིན།
- རྩིས་ཁྲ་རེ་རེའི་ནང་ཡོད་པའི་ རྒྱུ་དངོས་ཀྱི་ལྷག་ལུས་

དམིགས་གཏད་དེ་ ཨ་ལིསི་གི་ ཊི་ཡི་དངུལ་རྩིས་ལུ་ ལྟ་རྟོག་འབད་མི་ ཐིག་ཁྲམ་ཅིག་ ཐོ་བཀོད་འབད་ཞིནམ་ལས་ Mad Hatter རྩིས་ཁྲ་ནང་ལས་ བསྒྱུར་བཅོས་ཚུ་ བཏབ་ནི་ཨིནམ་ད་ འབྱུང་རྐྱེན་དང་བསྟུན་པའི་ གནད་དོན་འདི་ བཏབ་ཨིན།

## རྩིས་ཁྲ་དང་ རྒྱུ་དངོས་ཚུ་ གྲ་སྒྲིག་འབད་ {#_1-prepare-accounts-and-assets}

འགོ་དང་པ་ བཅའ་མར་གཏོགས་མི་རྩིས་དང་ རྒྱུ་དངོས་གི་འགྲེལ་བཤད་ཚུ་ ཐོ་བཀོད་འབད། ད་ལྟོའི་ Iroha ནང་། རྩིས་ཁྲ་IDs གིས་རྩིས་ཁྲ་འཛིན་སྐྱོང་པ་ཚུ་ལས་འོང་དོ་ཡོདཔ་ད་ གྲུབ་འབྲས་ཐོན་པའི་ས་ཁོངས་ཚུ་གིས་ `domain.dataspace` གི་བཟོ་རྣམ་ལག་ལེན་འཐབ་དོ་ཡོདཔ་ཨིན།

```text
domain: wonderland.universal
asset definition projection: tea in wonderland.universal
holder accounts: AccountId(controller=alice_key), AccountId(controller=mad_hatter_key)
```

རྒྱུ་དངོས་གི་འགྲེལ་བཤད་ནང་ལུ་ དྭངས་འཕྲོས་མེད་མི་ཁ་བྱང་ཅིག་ར་ཡོད། ཐོ་བཀོད་ཚར་བའི་ཤུལ་ལས་ ཁ་བྱང་འདི་བརྐོ་ཞིནམ་ལས་ བཏོན་གཏང་ནི་དང་ ལག་ལེན་འཐབ་ནི་ཨིན།

## 2. འགོ་བཙུགས་ནིའི་དབང་འཛིན་འདི་ གདམ་ཁ་རྐྱབས། {#_2-choose-the-trigger-authority}

ཐིག་ཁྲམ་བཟོ་ནིའི་ལག་ལེན་གྱི་རྩིས་དེ་ དམིགས་གཏད་ཅན་གྱི་རྩིས་ཁྲམ་ཅིག་ལུ་ གཞི་བཙུགས་འབད་ཚུགསཔ་ཨིན། དམིགས་གཏད་དེ་བཀོད་ཡོད་པའི་རྩིས་ཁྲམ་འདི་གིས་ ཐིག་ཁྲམ་གྱི་ལག་ལེན་ཚུ་ ག་ཅི་གི་དོན་ལུ་ དགོས་མཁོ་ཡོདཔ་ཨིན་ན་ གསལ་ཏོག་ཏོ་སྦེ་སྟོན་ནི་ཨིནམ་མ་ཚད་ གློག་ཐག་འདི་ ལག་ལེན་འཐབ་མི་གི་ ངོ་རྐྱང་གི་རྟགས་མཚན་ལྡེ་མིག་དང་གཅིག་ཁར་ མཐུད་སྦྲེལ་འབད་ནི་སྤང་སྟེ་བཞག་ཡོདཔ་ཨིན།

ཁྱད་རིག་གི་རྩིས་ཁྲ་དེ་ ཧེ་མ་ལས་ཡོད་དགོཔ་ཨིནམ་མ་ཚད་ སྒྲིག་གཞི་ཚུ་ འགོ་བཙུགས་ནིའི་ནང་བཙུགས་ནི་གི་ གོ་སྐབས་ཐོབ་དགོཔ་ཨིན།

## 3. ལག་ལེན་འབད་ཚུགས་མི་འདི་ ངེས་གཏན་བཟོ། {#_3-define-the-executable}

འགོ་བཙུགས་ཚུགས་ནི་དེ་ བྱ་བ་འབྱུང་ནིའི་ཐིག་ཁྲམ་འདི་ བཀྲམ་སྤེལ་འབད་བའི་སྐབས་ལུ་ གློག་ཐག་གིས་ བཏང་མི་བསླབ་བྱ་ཚུ་ཨིན། དཔེ་འདི་ནང་ལུ་ ཨེབ་གཏང་རིམ་གཅིག་ཡོདཔ་ཨིན།

```text
Transfer(
  source = AssetId(tea_definition, mad_hatter_account),
  value = Numeric(1),
  destination = AssetId(tea_definition, alice_account)
)
```

ལག་ལེན་འཐབ་ནི་ SDK ད་ལྟོའི་སྣོད་ཆས་བཟོ་སྐྲུན་འབད་མི་ཚུ་ མཐའ་མཇུག་གི་ཚོང་འབྲེལ་གྱི་ཁེ་ཕན་གྱི་དོན་ལུ་ ཨེབ་གཏང་འབདཝ་ཨིན། དཀའཝ་སྤྱད་མི་ཡིག་འབྲུ་རྙིང་པ་ IDs trigger code འདི་ནང་ལུ་; parse ཡང་ན་ query canonical IDs ཨེག་སི་ཊི་བཱེལ་བཟོ་མ་ཚར་བའི་ཧེ་མ་།

## 4. འབྱུང་རྐྱེན་བརྟག་དཔྱད་འབད་མི་འདི་ ངེས་གཏན་རྐྱབས། {#_4-define-the-event-filter}

གནས་སྡུད་-བྱུང་རྐྱེན་བརྟག་དཔྱད་འདི་ལག་ལེན་འཐབ་ནི་དེ་ ཁྱོད་ཀྱིས་ཚ་གྱང་ལང་མི་ གནད་དོན་ལུ་བྱུང་རྐྱེན་ཚུ་ མར་ཕབ་འབད་འབདཝ་ཨིན།

```text
EventFilterBox::Data(
  DataEventFilter for asset changes involving
  AssetId(tea_definition, alice_account)
)
```

གློག་ཐིག་ཚུ་ ལག་ལེན་ཅན་ཅིག་སྦེ་བཞག་ནི། `AcceptAll` གློག་ཐིགཔ་འདི་ བརྟག་ཞིབ་འབད་ནི་ལུ་ཕན་ཐོགས་ཡོདཔ་ཨིན་རུང་ འདི་འབདཝ་ལས་ འབྱུང་རྐྱེན་འདྲ་མཉམ་རེ་གིས་ ཐིམ་ཕུག་བརྟག་དཔྱད་ཀྱི་དོན་ལུ་ ཟད་འགྲོ་སྤྲོད་ནི་ཨིན་མས།

## 5. གློག་ཐག་འདི་ ཐོ་བཀོད་འབད། {#_5-register-the-trigger}

- ཟུར་བཞག་ཁང་ `TriggerId`
- འགོ་བཙུགས་ཚུགས་པའི་ བརྡ་བཀོད་གི་རིམ་པ་
- `Repeats::Indefinitely` ཡང་ན་ `Repeats::Exactly(n)`
- ཁྱད་རིག་གི་རྩིས་ཁྲ།
- འབྱུང་རྐྱེན་བརྟག་དཔྱད་
- ཁ་ optional metadata

trigger ཐོ་བཀོད་འདི་ རང་བཞིན་གྱི་ཚོང་འབྲེལ་ཅིག་ཨིནམ་ལས་ ཐོ་བཀོད་ཀྱི་རྩིས་ཁྲ་འདི་གིས་ trigger ཐོ་ལེན་འབད་དགོ་འོང་། ཁྱད་རིག་གི་རྩིས་ཁྲ་འདི་གིས་ ཐིག་ཁྲམ་འདི་ལག་ལེན་འབད་ཚུགས་པའི་དོན་ལུ་ དགོས་མཁོ་ཅན་གྱི་ཆོག་ཐམ་དགོཔ་ཨིན།

## ཁྲིམས་སྲུང་འགག་པའི་བཀའ་རྒྱ་ {#execution-order}

བཀྲམ་སྤེལ་འབད་ཐངས་འདི་:

1. སྤྱིར་བཏང་གི་ཚོང་འབྲེལ་གྱི་བསླབ་བྱ་ཚུ་ འགོ་དང་པ་ལག་ལེན་འཐབ་ཨིན།
2. གནད་དོན་དེའི་ཐོག་ལས་ ཐོན་སྐྱེད་འབད་མི་ གནས་སྡུད་ཚུ་ བསྡུ་ལེན་འབད་ཡོདཔ་ཨིན།
3. ཐིག་ཁྲམ་ཚུ་ འབྱུང་རྐྱེན་ཚུ་དང་འདྲན་འདྲ་འབད་ཡོད་པའི་ གློག་ཐག་ཚུ་ བཙུགས་ཚར་ཡོདཔ་ཨིན།
4. trigger-produced effects འདི་ block execution pipeline ནང་ལུ་ལག་ལེན་འཐབ་དོ་ཡོདཔ་ལས་ Restricted recursive trigger execution འབད་མ་ཚུགསཔ་ཨིན།

གློག་ཐག་ཅིག་གིས་ `Repeats::Exactly(n)` ལག་ལེན་འཐབ་པ་ཅིན་ གློག་ཐག་གསརཔ་དེ་ བརྩིས་ཚར་ཞིནམ་ལས་ བྱ་སྤྱོད་དེ་ ལོག་འབད་དགོ་པའི་སྐབས་ ཐོ་བཀོད་འབདཝ་ཨིན།
