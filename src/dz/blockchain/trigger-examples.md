# འབྱུང་རྐྱེན་འབྱུང་ནིའི་དཔེ་ཡིག {#event-trigger-example}

དཔེ་འདི་ནང་ Iroha 3 ཌའི་ཊ་གི་རྣམ་གཞག་ནང་ལུ་ རྫོང་ཁའི་རྩིས་ཐོ་མེད་པའི་ IDs དང་ འཆར་གཞི་ཅན་གྱི་བཅའ་ཡིག་ཚུ་ལག་ལེན་འཐབ་ཡོདཔ་ཨིན།

དྲ་རྒྱ་ཅིག་ལུ་ཡོད་ཟེར་བ་ཅིན་:

- Alice་གི་ལྡེ་མིག་གིས་ བཀག་འཛིན་འབད་མི་ སྒྲིག་གཞི་གཅིག་
- Mad Hatter གི་ལྡེ་མིག་གིས་ ཚད་འཛིན་འབད་མི་ སྒྲིག་གཞི་ཅིག་ཨིན།
- རྒྱུ་དངོས་ངེས་ཚིག་འདི་ `tea` གི་འོག་ལུ་ `wonderland.universal` སྦེ་ ཚོད་དཔག་འབད་ཡོདཔ་ཨིན།
- རྩིས་ཐོ་རེ་རེ་གིས་ བདག་འཛིན་འཐབ་མི་ རྒྱུ་དངོས་དེ་གི་ལྷག་ལུས་ཅིག

དམིགས་གཏད་དེ་ Alice་གི་ ཊི་ཡི་དངུལ་རྩིས་ལུ་ ལྟ་རྟོག་འབད་མི་ ཐིག་ཁྲམ་ཅིག་ ཐོ་བཀོད་འབད་ཞིནམ་ལས་ Mad Hatter རྩིས་ཐོ་ནང་ལས་ བསྒྱུར་བཅོས་ཚུ་ བཏབ་ནི་ཨིནམ་ད་ འབྱུང་རྐྱེན་དང་བསྟུན་པའི་ གནད་དོན་འདི་ བཏབ་ཨིན།

## རྩིས་ཐོ་དང་ རྒྱུ་དངོས་ཚུ་ གྲ་སྒྲིག་འབད་ {#_1-prepare-accounts-and-assets}

འགོ་དང་པ་ བཅའ་མར་གཏོགས་མི་རྩིས་དང་ རྒྱུ་དངོས་གི་འགྲེལ་བཤད་ཚུ་ ཐོ་བཀོད་འབད། ད་ལྟོའི་ Iroha ནང་། རྩིས་ཐོ་IDs གིས་རྩིས་ཐོ་འཛིན་སྐྱོང་པ་ཚུ་ལས་འོང་དོ་ཡོདཔ་ད་ གྲུབ་འབྲས་ཐོན་པའི་ས་ཁོངས་ཚུ་གིས་ `domain.dataspace` གི་བཟོ་རྣམ་ལག་ལེན་འཐབ་དོ་ཡོདཔ་ཨིན།

```text
domain: wonderland.universal
asset definition projection: tea in wonderland.universal
holder accounts: AccountId(controller=alice_key), AccountId(controller=mad_hatter_key)
```

རྒྱུ་དངོས་གི་འགྲེལ་བཤད་ནང་ལུ་ དྭངས་འཕྲོས་མེད་མི་ཁ་བྱང་ཅིག་ར་ཡོད། ཐོ་བཀོད་ཚར་བའི་ཤུལ་ལས་ ཁ་བྱང་འདི་བརྐོ་ཞིནམ་ལས་ བཏོན་གཏང་ནི་དང་ ལག་ལེན་འཐབ་ནི་ཨིན།

## 2. འགོ་བཙུགས་ནིའི་དབང་འཛིན་འདི་ གདམ་ཁ་རྐྱབས། {#_2-choose-the-trigger-authority}

ཐིག་ཁྲམ་བཟོ་ནིའི་ལག་ལེན་གྱི་རྩིས་དེ་ དམིགས་གཏད་ཅན་གྱི་རྩིས་ཐོམ་ཅིག་ལུ་ གཞི་བཙུགས་འབད་ཚུགསཔ་ཨིན། དམིགས་གཏད་དེ་བཀོད་ཡོད་པའི་རྩིས་ཐོམ་འདི་གིས་ ཐིག་ཁྲམ་གྱི་ལག་ལེན་ཚུ་ ག་ཅི་གི་དོན་ལུ་ དགོས་མཁོ་ཡོདཔ་ཨིན་ན་ གསལ་ཏོག་ཏོ་སྦེ་སྟོན་ནི་ཨིནམ་མ་ཚད་ གློག་ཐག་འདི་ ལག་ལེན་འཐབ་མི་གི་ ངོ་རྐྱང་གི་རྟགས་མཚན་ལྡེ་མིག་དང་གཅིག་ཁར་ མཐུད་སྦྲེལ་འབད་ནི་སྤང་སྟེ་བཞག་ཡོདཔ་ཨིན།

འཕྲུལ་རིག་རྩིས་ཐོ་འདི་ཧེ་མ་ལས་རང་ཡོདཔ་དགོཔ་དང་ ཊི་རི་གཱར་ལག་ལེན་འཐབ་བཏུབ་པའི་ནང་ བཀོད་རྒྱ་ཚུ་བཙུགས་ནིའི་གནང་བ་དགོཔ་ཨིན།

## 3. ལག་ལེན་འབད་ཚུགས་མི་འདི་ ངེས་གཏན་བཟོ། {#_3-define-the-executable}

འགོ་བཙུགས་ཚུགས་ནི་དེ་ བྱ་བ་འབྱུང་ནིའི་ཐིག་ཁྲམ་འདི་ བཀྲམ་སྤེལ་འབད་བའི་སྐབས་ལུ་ གློག་ཐག་གིས་ བཏང་མི་བསླབ་བྱ་ཚུ་ཨིན། དཔེ་འདི་ནང་ལུ་ ཨེབ་གཏང་རིམ་གཅིག་ཡོདཔ་ཨིན།

```text
Transfer(
  source = AssetId(tea_definition, mad_hatter_account),
  value = Numeric(1),
  destination = AssetId(tea_definition, alice_account)
)
```

ལག་ལེན་འཐབ་ནི་ SDK ད་ལྟོའི་སྣོད་ཆས་བཟོ་སྐྲུན་འབད་མི་ཚུ་ མཐའ་མཇུག་གི་ཚོང་འབྲེལ་གྱི་ནང་དོན་གནད་སྡུད་གྱི་དོན་ལུ་ ཨེབ་གཏང་འབདཝ་ཨིན། དཀའཝ་སྤྱད་མི་ཡིག་འབྲུ་རྙིང་པ་ IDs སྐུལ་རྟེན ལས་རིམ་ཨང་རྟགས འདི་ནང་ལུ་; དབྱེ་དཔྱད ཡང་ན་ འདྲི་དཔྱད ཚད་ལྡན IDs ཨེག་སི་ཊི་བཱེལ་བཟོ་མ་ཚར་བའི་ཧེ་མ་།

## 4. འབྱུང་རྐྱེན་བརྟག་དཔྱད་འབད་མི་འདི་ ངེས་གཏན་རྐྱབས། {#_4-define-the-event-filter}

ཁྱོད་ཀྱིས་བརྩི་མཐོང་ཡོད་པའི་དངོས་པོ་ལུ་བྱུང་ལས་ཚུ་ཕྲང་ཕྲངམ་བཟོ་མི་ གནད་སྡུད་བྱུང་ལས་ཚགས་མ་ལག་ལེན་འཐབ།

```text
EventFilterBox::Data(
  DataEventFilter for asset changes involving
  AssetId(tea_definition, alice_account)
)
```

ཚགས་མ་ཚུ་ ལག་ལེན་འཐབ་བཏུབ་པའི་ དམིགས་བསལ་སྦེ་བཞག། `AcceptAll` ཚགས་མ་འདི་རྐྱེན་སེལ་འབད་ནི་ལུ་ཕན་ཐོགས་ཡོདཔ་ཨིན་རུང་ མཐུན་སྒྲིག་བྱུང་ལས་ག་ར་གིས་ འབྱུང་རིམ་བརྟག་ཞིབ་ཀྱི་འགྲོ་སོང་སྤྲོད་བཅུགཔ་ཨིན།

## 5. གློག་ཐག་འདི་ ཐོ་བཀོད་འབད། {#_5-register-the-trigger}

འཕྲུལ་ཆས་འདི་ འདི་དང་གཅིག་ཁར་ ཐོ་བཀོད་འབད།

- བརྟན་ཏོག་ཏོ་ `TriggerId` ཅིག།
- ལག་ལེན་འཐབ་བཏུབ་པའི་བཀོད་རྒྱ་གོ་རིམ།
- `Repeats::Indefinitely` ཡང་ན་ `Repeats::Exactly(n)`
- ཁྱད་རིག་གི་རྩིས་ཐོ།
- བྱུང་ལས་ཚགས་མ།
- གདམ་ཁ་ཅན་གྱི་མེ་ཊ་ཌེ་ཊ།

སྐུལ་རྟེན ཐོ་བཀོད་འདི་ རང་བཞིན་གྱི་ཚོང་འབྲེལ་ཅིག་ཨིནམ་ལས་ ཐོ་བཀོད་ཀྱི་རྩིས་ཐོ་འདི་གིས་ སྐུལ་རྟེན ཐོ་ལེན་འབད་དགོ་འོང་། ཁྱད་རིག་གི་རྩིས་ཐོ་འདི་གིས་ ཐིག་ཁྲམ་འདི་ལག་ལེན་འབད་ཚུགས་པའི་དོན་ལུ་ དགོས་མཁོ་ཅན་གྱི་ཆོག་ཐམ་དགོཔ་ཨིན།

## ལག་བསྟར་གོ་རིམ་ {#execution-order}

སྡེབ་ཚན་ཅིག་གིས་ ལག་ལེན་འཐབ་པའི་སྐབས།

1. སྤྱིར་བཏང་གི་ཚོང་འབྲེལ་གྱི་བསླབ་བྱ་ཚུ་ འགོ་དང་པ་ལག་ལེན་འཐབ་ཨིན།
2. གནད་དོན་དེའི་ཐོག་ལས་ ཐོན་སྐྱེད་འབད་མི་ གནས་སྡུད་ཚུ་ བསྡུ་ལེན་འབད་ཡོདཔ་ཨིན།
3. ཚགས་མ་ཚུ་ བྱུང་ལས་དེ་ཚུ་དང་མཐུན་སྒྲིག་འབད་མི་ འབྱུང་རིམ་ཚུ་ དུས་ཚོད་བཀོད་ཡོདཔ་ཨིན།
4. ཊི་གར་གྱིས་ཐོན་སྐྱེད་འབད་མི་ནུས་པ་ཚུ་ ཚད་མེད་བསྐྱར་ལོག་ཊི་གར་ལག་ལེན་འཐབ་མ་བཅུག་པར་ སྡེབ་ཚན་ལག་ལེན་འཐབ་ཐངས་ཀྱི་མདོང་ལམ་ནང་ འཛིན་སྐྱོང་འཐབ་ཨིན།

གལ་སྲིད་ ཊི་གར་ཅིག་གིས་ `Repeats::Exactly(n)` ལག་ལེན་འཐབ་པ་ཅིན་ གྱངས་ཁ་འདི་ མཇུག་བསྡུ་ཞིནམ་ལས་ སྤྱོད་ལམ་གཅིགཔོ་འདི་ ལོག་སྟེ་དགོཔ་ཐོན་པའི་སྐབས་ ཊི་གར་གསརཔ་ཅིག་ ཐོ་བཀོད་འབད།
