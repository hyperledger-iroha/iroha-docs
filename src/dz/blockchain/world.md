## འཛམ་གླིང་རྒྱལ་ཁབ་ཀྱི་མཐོང་སྣང་ (WSV) {#world-state-view-wsv}

འཛམ་གླིང་གནས་སྟངས་མཐོང་ཐངས་འདི་ ད་ལྟོ་གི་ blockchain གནས་སྟངས་ཀྱི་ ནང་དྲན་གྱི་ངོ་ཚབ་ཨིན། འདི་ནང་ལུ་ `World`, committed block hashes, transaction indexes, and peers བཙག་འཐུ་འབད་ཡོདཔ་ད་ ད་ལྟོའི་དུས་སྐབས་ཀྱི་དོན་ལུ་ཨིན། Full block payloads འདི་ Kura ལས་ལག་ལེན་འཐབ་དོ་ཡོདཔ་ལས་ འདྲ་བཤུས་སྦེ་འགྱུར་བཅོས་འབད་མི་ WSV ཌའི་ཊ་ཚུ་ཨིན།

WSV འདི་ ཀྲུང་གོའི་དྲི་བ་ཚུ་ བསྐྱར་ཞིབ་འབད་ཞིནམ་ལས་ བཀྲམ་སྤེལ་འབད་ནི་ལུ་ འགྱུར་བ་འབྱུང་ནིའི་གནས་སྟངས་ཨིན། འདི་བདེན་པ་གི་ གཞི་རྟེན་ངོ་མ་མེདཔ། དུས་རྒྱུན་གྱི་ལོ་རྒྱུས་འདི་ [Kura](#kura-storage)ནང་ལུ་བཞག་ཡོདཔ་ཨིན། དེ་ལས་ WSV འདི་ Kura སྦྲག་ཚུ་ནང་ལས་ བཟོ་སྐྲུན་འབད་ནི་དང་ ཡང་ན་ state snapshot ལས་གློག་མེ་གཏུགས་འབད་ཞིནམ་ལས་ གསར་འགྱུར་གྱི་ Kura སྦྲགས་ཚུ་ སླར་ལོག་རྐྱབ་ཐོག་ལས་ བཏོན་གཏང་ཚུགས།

### WSV གིས་ག་འཚོལ་དོ་ཡོདཔ་ {#what-the-wsv-tracks}

WSV འདི་ `World` འདྲ་ཕབ་དང་ཕྱདཔ་ད་ དྭངས་འཕྲོས་འཕྲོས་རང་ཨིན། འདི་ནང་ལུ་:

- `World`: ཚད་གཞི། དབྱེ་ཐང་། ས་ཁོངས་། རྩིས་ཁྲིད། རྒྱུ་ཆ། NFTs འགན་འཁྲི་དང་ཆོག་ཐབས། གློ་བུར་འབད། ལག་ལེན་བསྟར་སྤྱོད་འབད་མི་ཚུ་དང་ ཐོ་བཀོད་ཅན་གྱི་ གནད་སྡུད་དཔེ་ཆ་གཞན་ཚུ་
- བཀྲམ་སྤེལ་འབད་ཡོད་པའི་ཧེཤ་ཚུ་དང་ མཇུག་བསྡུཝ་ད་ ཁས་བླངས་འབད་མི་མཐོ་ཚད་
- ཐོ་བཀོད་དང་ བསྡུ་ལེན་ཚུ་ནང་ ལག་ལེན་འཐབ་མི་ སྦྲེལ་མཐུད་ཀྱི་ཚོང་འབྲེལ་གྱི་ཐོ་ཡིག་ཚུ་
- གྲོས་བསྟུན་འབད་ཐོག་ལས་ ལག་ལེན་འཐབ་མི་ commit topology ད་ལྟོའི་དང་ ཧེ་མ་གི་
- ཌའི་བི་ཨེན་ཌེ་ཀསི་ (in-memory indexes) འདི་ committed blocks ལས་ཐོན་ཡོདཔ་ཨིན། དཔེར་ན་ data availability commitments, receipt cursors, pin intent, and query projection markers
- ཌེ་ཊར་ནིསི་ཀཱོལ་ལག་ལེན་གྱི་དོན་ལུ་ དགོས་མཁོ་ཅན་གྱི་ runtime སྒྲིག་འཇུག་གི་ snapshots དཔེར་ན་ cryptography, governance, pipeline, content, settlement, and Nexus setting

བརྒྱུད་འཕྲིན་འདི་ འཕྲལ་འཕྲལ་སྦེ་ར་ ཀློག་རྐྱངམ་ཅིག་ `StateView` ཚུ་ཐོ་བཀོད་འབདཝ་ཨིན། བརྒྱུད་འཕྲིན་དེ་ བརྒྱུད་འཕྲིན་ལག་ལེན་གྱི་དོན་ལུ་ ཡུན་བརྟན་གྱི་གློག་བརྙན་ཨིན། དེ་གིས་ WSV གི་ཐད་ཀར་དུ་འགྱུར་བཅོས་འབད་མ་ཚུགསཔ་ཨིན་མས།

### WSV གིས་ག་དེ་སྦེ་བསྒྱུར་བཅོས་འབདཝ་ཨིན། {#how-the-wsv-changes}

WSV བསྒྱུར་བཅོས་ཚུ་ བརྩོན་ཤུགས་མ་བསྐྱེད་པའི་ཧེ་མར་ གྲལ་སྒྲིག་འབདཝ་ཨིན། བཀྲམ་སྤེལ་འབད་ཐངས་འདི་གིས་ བཀྲམ་དབྱངས་ཅན་གྱི་གནས་སྟངས་བཟོ་དོ་ཡོདཔ་དང་ ངོས་ལེན་འབད་མི་ཅ་ཆས་སོ་སོ་གིས་ ཁོ་རའི་བསླབ་བྱ་ཚུ་ རྩིས་སྤྲོད་ཀྱི་གནས་ཚད་ནང་ ལག་ལེན་འཐབ་དོ་ཡོདཔ་ཨིན། འདི་བཟུམ་གྱི་ཅ་ཆས་ཚུ་གིས་ འགོ་བཙུགས་མི་ ཌའི་ཊི་ཨར་ཚུ་ དུམ་གྲ་གཅིག་ནང་ལག་ལེན་འཐབ་ཨིན། དུས་ཚོད་སེལ་འཐུ་འབད་མི་ཚུ་ བཀྲམ་སྤེལ་གྱི་དོན་ལུ་ ཕྱིར་ཚོང་གི་གྲུབ་འབྲས་ཚུ་གི་ཤུལ་ལུ་ བརྟག་ཞིབ་འབདཝ་ཨིན།

གྲོས་བསྟུན་གྱིས་ བཀྲམ་སྤེལ་ཚར་བའི་ཤུལ་ལས་, འདྲེན་པ་གིས་འགོ་དང་པ་ Kura ནང་ལུ་ ཁས་བླངས་འབད་ཡོད་པའི་ བཀྲམ་ཕུལཝ་ཨིན། གལ་སྲིད་ འ་ནི་ བཀྲམ་སྟོན་ཐངས་འདི་མ་གྲུབ་པ་ཅིན་, WSV འདི་ཡར་རྒྱས་འགྱོ་མི་ཅིག་ཨིན་ དེ་ལས་ གྲོས་བསྟུན་གྱི་ ལྡེ་མིག་འདི་གིས་ བཀྲམ་མོལ་གི་འགན་ཁུར་དེ་ སླར་ལོག་འབད་ནི་དང་ ཡང་ན་ བཏོན་གཏང་ཚུགས། སྦྲག་འདི་ Kura གི་གྲལ་ཐིག་ནང་ལུ་ འཛུལ་ཞུགས་འབད་ཚརཝ་ད་ Iroha གིས་ བཀྲམ་སྤེལ་ཚར་བའི་ཤུལ་ལུ་ བཀྲམ་སྟོན་འབད་ཡོད་པའི་སྦྲག་གི་གྲུབ་འབྲས་ཚུ་ལག་ལེན་བསྟར་སྤྱོད་འབད་ནི་དང་ ཨེབ་གཏང་འབད་ཡོད་མི་ ཌེ་བི་ཨེན་ཌེསི་ཚུ་ ད་ལྟོའི་བར་ན་ཡང་ གསར་གཏོད་འབད་ནི་ དེ་ལས་ གནས་སྟངས་མཐོངམ་གི་ལྡེ་མིག་འོག་ལུ་ WSV གི་རིམ་རིམ་སྒྲིག་ཅན་གྱི་འགྱུར་བཅོས་ཚུ་ བསྡུ་སྒྲིག་འབདཝ་ཨིན། འདི་གིས་ལྷག་མི་ཚུ་གིས་ ཆ་ཤས་ཅིག་སྦེ་ བཀྲམ་འཇོག་འབད་མི་སྦྲག་ཅིག་ མཐོང་ནི་ལས་བཀག་ཚུགས།

གྲོས་ཆོད་གི་འགན་ཁུར་ཅན་གྱི་ཁྲིམས་འདི་ དབྱེ་ཁག་གཞན་ཚུ་གིས་ བཀྲམ་སྤེལ་འབད་ཡོད་མི་ཚུ་ནང་ལས་ WSV འདྲ་མཉམ་ལུ་ལྷོད་དགོཔ་ཨིན། WSV ཌའི་ཊ་བཱསི་བརྡ་སྟོན་ཚུ་ནང་ ས་གནས་ཀྱི་འགྱུར་བཅོས་ཚུ་ ཐོ་བཀོད་འབད་ནི་དང་ ཆ་མེད་གཏང་ནི་དང་ ཡང་བསྐྱར་རྐྱབ་པའི་སྐབས་ལུ་ དབྱེ་ཚན་གཞན་ཚུ་ལུ་ ངོས་ལེན་མེད་པར་བཟོ་ནི་ཨིན་མས།

### འགོ་བཙུགས་ནི་དང་ ལོག་སྤྱོད་འབདཝ་ཨིན། {#startup-and-replay}

འགོ་འབྱེད་འབད་བའི་སྐབས་ལུ་ Iroha གིས་འགོ་དང་པ་ Kura འགོ་བཙུགས་ཞིནམ་ལས་ ཐོ་བཀོད་འབད་ཡོད་པའི་སྦྲག་མཐོ་ཚད་ཤེས་འོང་། དེ་ཤུལ་ལས་ གནས་སྟངས་ཀྱི་གློག་བརྙན་འདི་ཨེབ་གཏང་འབད་ནི་ལུ་ བརྩོན་ཤུགས་བསྐྱེད་དོ་ཡོདཔ་ཨིན། གལ་སྲིད་ གློག་བརྙན་དེ་མེད་པ་ཅིན་ ཡང་ན་ གློག་བརྙན་གྱི་གློག་བརྙན། འདི་སླར་གསོ་འབད་ཚུགསཔ་སྦེ་ ཆ་མ་བཞག་པ་ཅིན་ Iroha གིས་ འགོ་ཐོག་གི་གནས་སྟངས་བཟོ་སྟེ་ Kura ལས་ committed blocks སླར་ལོག་འབདཝ་ཨིན། གལ་སྲིད་གློག་བརྙན་འདི་བདེན་རུང་ Kura གི་རྒྱབ་ལུ་ཡོད་པ་ཅིན་ ཚད་མཐོ་ཚད་མེད་མི་དེ་རྐྱངམ་གཅིག་ ལོག་སྤྱོད་འབད་འོང་།

སླར་ལོག་གློག་བརྙན་འདི་ བཀྲམ་སྤེལ་འབད་ཡོད་པའི་པཱལཀརེ་རེ་ལུ་ བདེན་ཁུངས་བསྐྱངས་ཏེ་ བཟོ་སྐྲུན་འབད་ཞིནམ་ལས་ ཚད་དེ་གི་དོན་ལུ་ commit roster སླར་ལོག་བཟོཝ་ཨིན། པཱལཀགི་གྲུབ་འབྲས་ཚུ་ WSV ལུ་ལག་ལེན་བསྟར་སྤྱོད་འབདཝ་ཨིན། འདི་གིས་འབད་བ་ཅིན་ Kura འདི་ WSV གི་ཕྱིར་བཏོན་ལམ་ཨིན་པའི་ཁར་ snapshots གིས་ ལྕགས་ཐག་ཆ་མཉམ་ སླར་ལོག་རྐྱབ་ནི་ལས་ བཀག་ཐབས་འབད་འོང་།
