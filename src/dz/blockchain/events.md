# འབྱུང་རྐྱེན་ཚུ་ {#events}

གནད་དོན་ཚུ་ བཀྲམ་སྤེལ་འབད་དོ་ཡོདཔ་ད་ blockchain གི་ནང་འཁོད་ལུ་ གནད་དོན་ལ་ལུ་ཅིག་འབྱུང་ནི་ཨིནམ་ད་ དཔེར་ན་ རྩིས་ཁྲ་གསརཔ་ཅིག་ བཟོ་སྐྲུན་འབད་ནི་དང་ ཡང་ན་ བཀག་ཆ་འབད་ནི་ཨིན། གནད་དོན་སྣ་ཚོགས་ཡོད་:

- གློག་ཐག་ར་བ་གི་བྱུང་རྐྱེན་ཚུ་
- གནད་དོན་ཚུ་
- དུས་རྒྱུན་གྱི་བྱུང་རྐྱེན་
- འགོ་བཙུགས་ནིའི་དོན་ལས་བྱུང་རྐྱེན་ཚུ་

## གློག་སྣུམ་འཁོར་ལམ་གྱི་ གནད་དོན་ཚུ་ {#pipeline-events}

གློག་ཐག་ར་བ་གི་བྱུང་རྐྱེན་ཚུ་ བཀྲམ་སྤེལ་འབད་དོ་ཡོདཔ་ད་ རིན་བསྡུར་གྱི་ཅ་ལ་ཚུ་ བཏང་ནི་དང་ བསྡུ་ལེན་འབད་ནི་དང་ ཡང་ན་ སྦྲག་ལུ་ ཁས་བླངས་འབད་བའི་སྐབས་ཨིན། གློག་ཐག་ར་བ་གི་བྱུང་རྐྱེན་ནང་ འོག་གི་ བརྡ་དོན་ཚུ་ཡོདཔ་ཨིན། ལས་འཛིན་གྱིས་བྱུང་རྐྱེན་ (གླ་ཆའི་གནས་གོང་ ཡང་ན་ བཀག་དམ་) བྱུང་རྐྱེན་ལུ་ གནོད་སྐྱོན་རྐྱབ་ཡོདཔ་ཨིན་པའི་དབྱེ་བ་ཨིན། གནས་གོང་འདི་ ཡང་ན་ `Validating` (ལག་ལེན་བསྟར་སྤྱོད་འབད་བའི་བསྒང་ཡོདཔ་) `Rejected`, ཡང་ན་ `Committed`. ལས་སྡེ་ཅིག་ལུ་ ཆ་མེད་བཏང་པ་ཅིན་ ཆ་མེད་གཏང་པའི་རྒྱུ་མཚན་ཚུ་སྟོན་བྱིན་དགོ།

### Taira ལུ་ བརྟག་དཔྱད་རྐྱབས། {#try-it-on-taira}

མི་མང་གི་སྣུམ་འཁོར་གྱི་འབྱུང་གནས་རྒྱུན་ལམ་འདི་ གཞི་བཙུགས་འབད་ཡོད་པའི་བརྟག་དཔྱད་འབད།

```bash
curl -fsSI https://taira.sora.org/v1/events/sse \
  | sed -n '1,12p'
```

རྒྱུགས་ཆུ་ཁ་ཕྱེཝ་མ་བཞག་པར་ བརྟག་ཞིབ་འབད་ཚུགས་པའི་ གློག་འཕྲོད་མཐོང་གི་དོན་ལུ་ འདས་པའི་ཉོ་ཚོང་འཐབ་མི་ཚུ་ལུ་ ཀློག་སྟེ་བལྟ་:

```bash
curl -fsS 'https://taira.sora.org/v1/explorer/transactions?page=1&per_page=5' \
  | jq '{pagination, txs: [.items[] | {hash, block, status, executable}]}'
```

SSE ཕྲང་ལམ་འདི་ སེལ་འཐུ་འབད། ཁྱོད་ཀྱིས་དུས་སྟོན་ཚུ་འབད་དགོ་པའི་སྐབས་:

```bash
curl -fsS -N https://taira.sora.org/v1/events/sse
```

རྒྱུགས་ཆུ་འདི་ཁ་ཕྱེཝ་སྡོད་པའི་བར་ན་ ཚོང་འབྲེལ་ཚུ་མ་བཙུགས་པ་ཅིན་ ལམ་དེ་འཇམ་ཏོང་ཏོ་ཡོད་རུང་ བཀའ་རྒྱ་དེ་གིས་ ཁུ་སིམ་སི་སྦེ་སྡོད་ཚུགས།

## གནད་དོན་འབྱུང་ཁུངས། {#data-events}

ཌེ་ཊ་གི་བྱུང་རྐྱེན་ཚུ་ ལྡོག་ཕྱོགས་ཡིག་ཚང་ནང་ གནས་སྡུད་ཚུ་དང་འབྲེལ་བའི་འགྱུར་བཅོས་ཅིག་འབྱུང་པའི་སྐབས་ལུ་ བཏབ་དོ་ཡོདཔ་ཨིན། དཔེར་ན་ དངོས་རིགས་, ས་ཁོངས་,རྩིས་ཁྲ་, རྒྱུ་དངོས་, རྒྱུ་དངོས་འགྲེལ་བཤད་, NFTs, trigger, འགན་འཁྲི་, on-chain སྒྲིག་ལམ་,ལག་ལེན་གྱི་གནས་སྟངས་, གྲུབ་རྟགས་, གསང་རྟོག་ཅན་གྱི་རྒྱུ་དངོས་, མཐོང་ལྡིང་། ཡང་ན་ SORA/Nexus-specific objects. འདི་བཟུམ་གྱི་བྱུང་རྐྱེན་ཚུ་ [data event filter](./filters.md#data-event-filters)ནང་ལུ་ལག་ལེན་འཐབ་ཨིན།

## དུས་སྐབས་ཀྱི་བྱུང་རྐྱེན་ {#time-events}

དུས་སྐབས་ཀྱི་བྱུང་རྐྱེན་ཚུ་ འཛམ་གླིང་གི་གནས་སྟངས་མཐོང་ཐངས་འདི་ [དུས་སྐབས་གྱི་ trigger](./triggers.md#time-triggers) འདི་ལག་ལེན་འབད་ནིའི་དོན་ལུ་ གྲ་སྒྲིག་རྐྱབ་པའི་སྐབས་ལུ་ བཏོན་འབདཝ་ཨིན།

## ཐིག་ཁྲམ་ལག་ལེན་གྱི་འབྱུང་ཁུངས། {#trigger-execution-events}

ཐིག་ཁྲ་ལག་ལེན་གྱི་བྱུང་རྐྱེན་འདི་ [`ExecuteTrigger`](./instructions.md#executetrigger) བཀའ་རྒྱ་དེ་ལག་ལེན་འཐབ་པའི་བསྒང་ལས་ བཏོན་ཨིན། ཐིག་ཁྲམ་ལག་ལེན་མཇུག་བསྡུ་བའི་ཤུལ་ལས་ ཐིག་ཁྲᱟལག་ལེན་ཚུ་ བཏོན་འོང་།
