# འབྱུང་རྐྱེན་ཚུ་ {#events}

བཀག་ཆའི་ནང་འཁོད་ལུ་ དངོས་པོ་ལ་ལུ་ཅིག་འབྱུང་པའི་སྐབས་ བྱུང་ལས་ཚུ་ བཏོན་གཏངམ་ཨིན་ དཔེར་ན་ རྩིས་ཐོ་གསརཔ་ཅིག་གསར་བསྐྲུན་འབད་ཡོདཔ་ ཡང་ན་ སྡེབ་ཚན་ཅིག་ཁས་བླངས་འབད་ཡོདཔ་ཨིན། བྱུང་རིམ་མི་འདྲ་བ་ཡོད།

- མདོང་ལམ་བྱུང་རིམ།
- གནད་སྡུད་བྱུང་ལས།
- དུས་ཚོད་བྱུང་རིམ།
- འགོ་བཙུགས་ལག་ལེན་འཐབ་ནིའི་བྱུང་ལས་ཚུ།

## རྒྱུན་རིམ་བྱུང་རྐྱེན། {#pipeline-events}

ཚོང་འབྲེལ་ཚུ་བཙུགས་པའི་སྐབས་དང་ ལག་ལེན་འཐབ་པའི་སྐབས་ ཡང་ན་ སྡེབ་ཚན་ཅིག་ལུ་ ཁས་བླངས་འབད་བའི་སྐབས་ མདོང་ལམ་བྱུང་ལས་ཚུ་ བཏོན་གཏངམ་ཨིན། པའིཔ་ལའིན་བྱུང་ལས་ཅིག་ནང་ འོག་གི་བརྡ་དོན་ཚུ་ཡོདཔ་ཨིན་: བྱུང་ལས་ཅིག་འབྱུང་བཅུག་མི་ངོ་བོ་གི་དབྱེ་བ་ (ཚོང་འབྲེལ་ཡང་ན་སྡེབ་ཚན་) དེ་གི་ཧེཤ་དང་གནས་ཚད། གནས་ཚད་འདི་ `Validating` (བདེན་དཔྱད་འབད་བའི་བསྒང་ཡོདཔ་) `Rejected` ཡང་ན་ `Committed` ཡང་ཅིན་འོངམ་ཨིན། གལ་སྲིད་ ངོ་བོ་ཅིག་ ངོས་ལེན་མ་འབད་བ་ཅིན་ ངོས་ལེན་མ་འབད་བའི་ རྒྱུ་མཚན་འདི་ བཀོད་དེ་ཡོདཔ་ཨིན།

### Taira ལུ་ བརྟག་དཔྱད་རྐྱབས། {#try-it-on-taira}

མི་མང་མདོང་ལམ་བྱུང་ལས་རྒྱུན་ལམ་འདི་སྦྱར་བརྩེགས་འབད་ཡོདཔ་ཨིན་ན་ཞིབ་དཔྱད་འབད།

```bash
curl -fsSI https://taira.sora.org/v1/events/sse \
  | sed -n '1,12p'
```

ཁྱོད་ཀྱིས་ རྒྱུན་ལམ་ཁ་ཕྱེ་མ་བཞག་པར་ བརྟག་ཞིབ་འབད་ཚུགས་པའི་ པར་ཅིག་གི་དོན་ལུ་ འཕྲལ་གྱི་འཚོལ་ཞིབ་འབད་མི་ཚོང་འབྲེལ་ཚུ་ལྷག།

```bash
curl -fsS 'https://taira.sora.org/v1/explorer/transactions?page=1&per_page=5' \
  | jq '{pagination, txs: [.items[] | {hash, block, status, executable}]}'
```

SSE ཕྲང་ལམ་འདི་ སེལ་འཐུ་འབད། ཁྱོད་ཀྱིས་དུས་སྟོན་ཚུ་འབད་དགོ་པའི་སྐབས་:

```bash
curl -fsS -N https://taira.sora.org/v1/events/sse
```

གལ་སྲིད་ རྒྱུན་ལམ་ཁ་ཕྱེ་སྟེ་ཡོད་པའི་སྐབས་ ཚོང་འབྲེལ་ག་ནི་ཡང་ མ་བཙུགས་པ་ཅིན་ བརྡ་བཀོད་འདི་ ལམ་འདི་ གསོ་བའི་གནས་སྟངས་ལེགས་ཤོམ་ཡོད་རུང་ ཁུ་སིམ་སིམ་སྦེ་སྡོད་ཚུགས།

## གནད་དོན་འབྱུང་ཁུངས། {#data-events}

ཌེ་ཊ་གི་བྱུང་རྐྱེན་ཚུ་ ལྡོག་ཕྱོགས་ཡིག་ཚང་ནང་ གནས་སྡུད་ཚུ་དང་འབྲེལ་བའི་འགྱུར་བཅོས་ཅིག་འབྱུང་པའི་སྐབས་ལུ་ བཏབ་དོ་ཡོདཔ་ཨིན། དཔེར་ན་ དངོས་རིགས་, ས་ཁོངས་,རྩིས་ཐོ་, རྒྱུ་དངོས་, རྒྱུ་དངོས་འགྲེལ་བཤད་, NFTs, སྐུལ་རྟེན, འགན་འཁྲི་, སྡེབ་ཐག་གུ སྒྲིག་ལམ་,ལག་ལེན་གྱི་གནས་སྟངས་, གྲུབ་རྟགས་, གསང་རྟོག་ཅན་གྱི་རྒྱུ་དངོས་, མཐོང་ལྡིང་། ཡང་ན་ SORA/Nexus-དམིགས་བསལ དངོས་པོ་ཚུ. འདི་བཟུམ་གྱི་བྱུང་རྐྱེན་ཚུ་ [གནད་སྡུད བྱུང་ལས ཚགས་མ](./filters.md#data-event-filters)ནང་ལུ་ལག་ལེན་འཐབ་ཨིན།

## དུས་སྐབས་ཀྱི་བྱུང་རྐྱེན་ {#time-events}

དུས་སྐབས་ཀྱི་བྱུང་རྐྱེན་ཚུ་ འཛམ་གླིང་གི་གནས་སྟངས་མཐོང་ཐངས་འདི་ [དུས་སྐབས་གྱི་ སྐུལ་རྟེན](./triggers.md#time-triggers) འདི་ལག་ལེན་འབད་ནིའི་དོན་ལུ་ གྲ་སྒྲིག་རྐྱབ་པའི་སྐབས་ལུ་ བཏོན་འབདཝ་ཨིན།

## ཐིག་ཁྲམ་ལག་ལེན་གྱི་འབྱུང་ཁུངས། {#trigger-execution-events}

ཐིག་ཁྲ་ལག་ལེན་གྱི་བྱུང་རྐྱེན་འདི་ [`ExecuteTrigger`](./instructions.md#executetrigger) བཀའ་རྒྱ་དེ་ལག་ལེན་འཐབ་པའི་བསྒང་ལས་ བཏོན་ཨིན། ཐིག་ཁྲམ་ལག་ལེན་མཇུག་བསྡུ་བའི་ཤུལ་ལས་ ཐིག་ཁྲམ་ལག་ལེན་ཚུ་ བཏོན་འོང་།
