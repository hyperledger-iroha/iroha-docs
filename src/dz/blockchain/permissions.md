# ངོས་ལེན་ཚུ་ {#permissions}

རྩིས་ཐོ་ཚུ་ལུ་ བཀག་ཆ་ཅན་གྱི་བྱ་བ་སྣ་ཚོགས་ཀྱི་དོན་ལུ་ གནང་བ་རྟགས་མཚན་དགོཔ་ཨིན། དཔེར་ན། རྒྱུ་དངོས་བཏོན་ནི་དང་ ཡང་ན་ མེ་བཏང་ནི།

མི་མང་དང་ སྒེར་གྱི་ སྡེབ་ཐག གི་བར་ན་ ཁྱད་པར་ཅིག་ཡོདཔ་ད་ ལག་ལེན་པ་ཚུ་ལུ་བྱིན་མི་ཆོག་ཐོའི་ཐད་ལུ་ཨིན། མི་མང་གི་ སྡེབ་ཐགནང་ལུ་རྩིས་ཐོ་མང་ཤོས་ཅིག་གིས་ཆོག་ཐོའི་སྡེ་ཚན་དེ་འདྲ་མཉམ་ཡོདཔ་ཨིན། སྒེར་གྱི་ སྡེབ་ཐགནང་ལུ་རྩིས་ཐོ་མང་ཤོས་ཅིག་གིས་ ཁོང་ལུ་བྱིན་མི་དབང་ཤུགས་ཀྱི་ཕྱི་ཁར་ ག་ནི་ཡང་འབད་མ་ཚུགསཔ་སྦེ་ བལྟ་དོ་ཡོདཔ་མ་གཏོགས་ འབྲེལ་ཡོད་ཆོག་ཐམ་འདི་ གསལ་ཏོག་ཏོ་སྦེ་མ་བྱིན་པར་ཨིན།

གནད་དོན་ག་ཅི་ར་འབད་རུང་ འབད་ཆོག་པའི་ ངོས་ལེན་ཡོད་པའི་དོན་ལས་ ཁྱོད་ཀྱིས་རྩིས་ཐོ་དེ་ནང་ `Permission` འདུག་ཟེར་ཨིན་པས། ངོས་ལེན་ཚུ་ ཐད་ཀར་དུ་ ཡང་ན་ [`Role`](#permission-groups-roles) གྱི་ཐོག་ལས་བྱིན་ཚུགས། འདི་ཡང་ ངོས་ལེན་གི་སྡེ་ཚན་ཅིག་ཨིན། ངོས་ལེན་འདི་ `Grant` བཀའ་རྒྱ་དང་གཅིག་ཁར་བྱིན་ཡོདཔ་ཨིན། ངོས་ལེན་དང་ འགན་འཁྲི་ཚུ་ དུས་ཡུན་མ་རྫོགས་པར་ཡོདཔ་ལས་ `Revoke` བརྡ་བཀོད་དང་གཅིག་ཁར་བཏོན་གཏང་དགོ།

## ངོས་ལེན་རྟགས་ཚུ་ {#permission-tokens}

གནང་བ་ཊོ་ཀེན་ཚུ་ ཤུགས་ལྡན་ལག་ལེན་འཐབ་མི་གིས་ངེས་འཛིན་འབད་ཡོད་པའི་ཡིག་དཔར་རྐྱབས་ཡོད་པའི་དངོས་པོ་ཚུ་ཨིན། ཊོ་ཀེན་ལ་ལུ་ཅིག་ འཛམ་གླིང་ཡོངས་ཁྱབ་ཨིན་ དཔེར་ན་ `CanManagePeers` དང་ གཞན་མི་ཚུ་ རྩིས་ཐོ་ རྒྱུ་དངོས་ རྒྱུ་དངོས་ངེས་ཚིག་ མངའ་ཁོངས་ NFT འགན་ཁུར་ ཡང་ན་ འབྱུང་ཁུངས་བཟུམ་གྱི་ དམིགས་བསལ་བཀག་ཆ་ཅན་གྱི་ ལག་དེབ་དངོས་པོ་ལུ་ ཁྱབ་ཚད་ཡོདཔ་ཨིན།

གནང་བ་ཊོ་ཀེན་སྣ་ཚོགས་ཀྱི་དོན་ལུ་ལག་ལེན་འཐབ་མི་ཚད་བཟུང་ཚུ་གི་དཔེ་ལ་ལུ་ཅིག་འདི་ནང་ཡོདཔ་ཨིན།

- དམིགས་བསལ་གྱི་རྩིས་ཐོ་ཅིག་གི་དོན་ལུ་ མེ་ཊ་ཌེ་ཊ་ལེགས་བཅོས་འབད་ནི་གི་གནང་བ་བྱིན་མི་ ཊོ་ཀེན་འདི་གིས་ `account` ས་སྒོ་ཅིག་འབག་འོང་།

  ```json
  {
    "account": "<AccountId>"
  }
  ```

- དམིགས་བསལ་གྱི་རྒྱུ་དངོས་ངེས་ཚིག་ཅིག་གི་དོན་ལུ་ རྒྱུ་དངོས་སྤོ་བཤུད་འབད་ནི་གི་གནང་བ་བྱིན་མི་ ཊོ་ཀེན་འདི་གིས་ `asset_definition` ས་སྒོ་ཅིག་འབག་འོང་།

  ```json
  {
    "asset_definition": "<AssetDefinitionId>"
  }
  ```

- `CanManagePeers` བཟུམ་གྱི་ཡོངས་ཁྱབ་བརྡ་མཚོན་ལུ་ ས་སྒོ་མེདཔ་ཨིན།

  ```json
  {}
  ```

### སྔོན་སྒྲིག་དབང་ཆའི་རྟགས་མ་ཚུ་ {#pre-configured-permission-tokens}

ཁྱོད་ཀྱིས་ སྔོན་རིམ་སྒྲིག་འབད་ཡོད་པའི་གནང་བ་ཊོ་ཀེན་ཚུ་གི་ཐོ་ཡིག་འདི་ [གཞི་བསྟུན་](/dz/reference/permissions) ལེའུ་ནང་ལུ་འཚོལ་ཚུགས།

## གོ་སྐབས་ཐོབ་མི་སྡེ་ཚན་ (འགན་ཁུར་) {#permission-groups-roles}

ངོས་ལེན་གྱི་སྡེ་ཚན་ཅིག་ལུ་ འགན་འཁྲི་ཟེར་སླབ་ཨིན། ངོས་ལེན་གི་རྟགས་མཚན་དང་འདྲཝ་སྦེ་ འགན་ཁུར་ཚུ་ `Grant` བཀའ་རྒྱ་ལག་ལེན་འཐབ་སྟེ་བྱིན་ནི་དང་ `Revoke` བཀའ་རྒྱ་ལག་ལེན་ཐོག་ལས་ ཆ་མེད་གཏང་ནི་ཨིན་མས།

རྩིས་ཐོ་ཅིག་ལུ་ འགན་ཁུར་མ་བྱིན་པའི་ཧེ་མ་ འགན་ཁུར་འདི་ དང་པ་ ཐོ་བཀོད་འབད་དགོ།

འགན་འཁྲི་འདི་ ཕན་ཐོགས་ཅན་ཅིག་ཨིན་པའི་སྐབས་ རྩིས་ཐོ་མང་ཤོས་ཅིག་གིས་ ངོས་ལེན་ཐོ་བཀོད་གཅིག་རང་ཐོབ་དགོཔ་ཨིན། འགན་འཁྲུལ་དེ་ ཐོ་བཀོད་ཚར་གཅིག་འབད་ཞིནམ་ལས་ འགན་འཁྲིའི་དོན་ལུ་ ངོས་ལེན་ཚུ་བྱིན་ཞིནམ་ལས་ རང་རྐྱང་གི་རྩིས་ཐོ་ཚུ་གི་དོན་ལུ་ འགན་འཁྲིདཔ་བྱིན་ནི་དང་ ཡང་ན་ ཆ་མེད་གཏང་ནི་ཨིན་པས།

### འགན་འཁྲི་གསརཔ་ཅིག་ནང་ ཐོ་བཀོད་འབད་ {#register-a-new-role}

ང་བཅས་ཀྱིས་ འགན་འཁྲི་གསརཔ་ཅིག་ ཐོ་བཀོད་འབད་གེ། འདི་གནང་པ་ཅིན་ རྩིས་ཐོ་གཞན་ཅིག་གིས་ Mouse གི་རྩིས་ཐོ་ནང་གི་ [ཟུར་གནས་གནད་སྡུད](/dz/blockchain/metadata.md) ལུ་ འཛུལ་སྤྱོད་འབད་ཚུགས་འོང་།

```rust
let role_id = RoleId::from_str("ACCESS_TO_MOUSE_METADATA")?;
let role = iroha_data_model::role::Role::new(role_id.clone(), mouse_id.clone())
    .add_permission(CanModifyAccountMetadata {
        account: mouse_id.clone(),
    });
let register_role = Register::role(role);
```

### འགན་འཁྲི་བྱིན་ {#grant-a-role}

འགན་འཁྲི་འདི་ ཐོ་བཀོད་ཚར་བའི་ཤུལ་ལས་ Mouse གིས་ Alice ལུ་བྱིན་ཚུགས།

```rust
let grant_role = Grant::account_role(role_id, alice_id);
let grant_role_tx = TransactionBuilder::new(chain_id, mouse_id)
    .with_instructions([grant_role])
    .sign(mouse_private_key);
```

## ངོས་ལེན་ལག་ཁྱེར་ཚུ་ {#permission-validators}

ངོས་ལེན་ཚུ་ཡོདཔ་ལས་ དགོས་མཁོ་ཅན་གྱི་ ངོས་ལེན་རྟགས་ཡོད་པའི་རྩིས་ཐོ་རྐྱངམ་གཅིག་གིས་ སྲུང་སྐྱོབ་འབད་བཏུབ་ཨིན། སྔོན་སྒྲིག་ལག་ལེན་འཐབ་མི་གིས་བཀོད་རྒྱ་དང་དྲི་བཀོད་ དེ་ལས་ གསལ་སྟོན་ལག་ལེན་གྱི་སྐབས་ལུ་ ངོས་ལེན་འདི་ཚུ་ བརྟག་ཞིབ་འབདཝ་ཨིན།

སྔོན་སྒྲིག་བདེན་དཔྱད་འབད་མི་ཁ་ཐོག་འདི་ ལེ་ཇར་མངའ་ཁོངས་ཀྱིས་སྡེ་ཚན་བཟོཝ་ཨིན།

- མཉམ་རོགས་འཛིན་སྐྱོང་།
- མངའ་ཁོངས་དང་རྩིས་ཐོ།
- རྒྱུ་དངོས་ཚུ་ NFTs དང་ གཏན་འཁེལ་གྱི་ཁྲལ་ཚུ་
- འབྱུང་ཁུངས།
- འགན་ཁུར་དང་གནང་བ་ཚུ།
- ལག་བསྟར་སྤྱོད་/ལག་ལེན་གྱི་དུས་ཚོད་དང་ བརྟག་ཞིབ་ཚུ་ དེ་ལས་ SORA/Nexus ཚད་གཞག་ཚུ་

བརྡ་མཚོན་ཐོ་ཡིག་ངོ་མ་འདི་ [གནང་བ་བརྡ་མཚོན་གཞི་བསྟུན་](/dz/reference/permissions.md) ནང་ལུ་འབྱུང་ཁུངས་རྒྱབ་སྐྱོར་འབད་ཡོདཔ་ཨིན།

### འགྲུལ་སྐྱོད་དུས་ཚོད་བརྟག་དཔྱད་འཕྲུལ་ཆས་ཚུ་ {#runtime-validators}

གནང་བ་ཞིབ་དཔྱད་ཚུ་ ཤུགས་ལྡན་ལག་ལེན་འཐབ་མི་གིས་ བསྟར་སྤྱོད་འབདཝ་ཨིན། སྔོན་སྒྲིག་བཀོལ་སྤྱོད་པ་གིས་ ནང་འཁོད་གནང་བ་བདེན་དཔྱད་འབད་མི་དང་ ཊོ་ཀེན་ངེས་ཚིག་ཚུ་བྱིནམ་ཨིནམ་དང་ ཡོངས་འབྲེལ་ཅིག་གིས་ ལག་ལེན་འཐབ་མི་ བཀོལ་སྤྱོད་པ་འདི་ཡར་འཕར་འབད་ཐོག་ལས་ སྲིད་བྱུས་བསྒྱུར་བཅོས་འབད་ཚུགས།

བདེན་དཔྱད་འབད་མི་ཚུ་གིས་ **བདེན་དཔྱད་ཀྱི་ཐག་བཅད་** ཅིག་སླར་ལོག་འབདཝ་ཨིན། བདེན་དཔྱད་འབད་མི་ཅིག་གིས་ བཀོལ་སྤྱོད་ཅིག་ གནང་བ་བྱིན་ཚུགས་ནི་དང་ རྒྱུ་མཚན་ཅིག་དང་གཅིག་ཁར་ ངོས་ལེན་མ་འབད་བར་ ཡང་ན་ བཀོལ་སྤྱོད་འདི་ བདེན་དཔྱད་འབད་མི་དེ་གི་ཁྱབ་ཚད་ཀྱི་ཕྱི་ཁར་ཨིན་པ་ཅིན་ གོམ་འགྱོ་ཚུགས། སེལ་འཐུ་འབད་ཡོད་པའི་དྲང་དཔོན་གྱིས་ བཀོད་རྒྱ་དང་འདྲི་དཔྱད་ ཡང་ན་ བརྡ་སྟོན་ཚུ་ འཕྲོ་མཐུད་དེ་འགྱོ་ཚུགས་ག་མི་ཚུགས་ག་ ཐག་བཅད་ནི་ལུ་ ཐག་བཅད་དེ་ཚུ་ མཉམ་སྡེབ་འབདཝ་ཨིན།
