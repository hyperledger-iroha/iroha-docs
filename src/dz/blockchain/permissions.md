# ངོས་ལེན་ཚུ་ {#permissions}

རྩིས་ཁྲ་ཚུ་གིས་ blockchainནང་ལུ་ བྱ་བ་སྣ་ཚོགས་འབད་ནི་གི་དོན་ལུ་ ངོས་ལེན་གི་རྟགས་མཚན་ཚུ་ དགོཔ་ཨིན། དཔེར་ན་ རྒྱུ་དངོས་ཚུ་བཟོ་ནི་དང་ མེ་གཏང་ནི་ཨིན་མས།

མི་མང་དང་ སྒེར་གྱི་ blockchain གི་བར་ན་ ཁྱད་པར་ཅིག་ཡོདཔ་ད་ ལག་ལེན་པ་ཚུ་ལུ་བྱིན་མི་ཆོག་ཐོའི་ཐད་ལུ་ཨིན། མི་མང་གི་ blockchainནང་ལུ་རྩིས་ཁྲ་མང་ཤོས་ཅིག་གིས་ཆོག་ཐོའི་སྡེ་ཚན་དེ་འདྲ་མཉམ་ཡོདཔ་ཨིན། སྒེར་གྱི་ blockchainནང་ལུ་རྩིས་ཁྲ་མང་ཤོས་ཅིག་གིས་ ཁོང་ལུ་བྱིན་མི་དབང་ཤུགས་ཀྱི་ཕྱི་ཁར་ ག་ནི་ཡང་འབད་མ་ཚུགསཔ་སྦེ་ བལྟ་དོ་ཡོདཔ་མ་གཏོགས་ འབྲེལ་ཡོད་ཆོག་ཐམ་འདི་ གསལ་ཏོག་ཏོ་སྦེ་མ་བྱིན་པར་ཨིན།

གནད་དོན་ག་ཅི་ར་འབད་རུང་ འབད་ཆོག་པའི་ ངོས་ལེན་ཡོད་པའི་དོན་ལས་ ཁྱོད་ཀྱིས་རྩིས་ཁྲ་དེ་ནང་ `Permission` འདུག་ཟེར་ཨིན་པས། ངོས་ལེན་ཚུ་ ཐད་ཀར་དུ་ ཡང་ན་ [`Role`](#permission-groups-roles) གྱི་ཐོག་ལས་བྱིན་ཚུགས། འདི་ཡང་ ངོས་ལེན་གི་སྡེ་ཚན་ཅིག་ཨིན། ངོས་ལེན་འདི་ `Grant` བཀའ་རྒྱ་དང་གཅིག་ཁར་བྱིན་ཡོདཔ་ཨིན། ངོས་ལེན་དང་ འགན་འཁྲི་ཚུ་ དུས་ཡུན་མ་རྫོགས་པར་ཡོདཔ་ལས་ `Revoke` བརྡ་བཀོད་དང་གཅིག་ཁར་བཏོན་གཏང་དགོ།

## ངོས་ལེན་རྟགས་ཚུ་ {#permission-tokens}

permission tokens འདི་ active executor གིས་དབྱེ་ཞིབ་འབད་ཡོད་པའི་ objects ཨིན། tokens ལ་ལོ་ཅིག་ globalཨིན་པའི་དཔེར་ན་ `CanManagePeers` དང་གཞན་ཚུ་ account, asset, asset definition, domain, NFT, role, or triggerབཟུམ་ལུ་དམིགས་ཏེ་ specific ledger object ལུ་ scopeedཡོདཔ་ཨིན།

### སྔོན་སྒྲིག་འབད་ཡོད་པའི་ Authorization Tokens {#pre-configured-permission-tokens}

## གོ་སྐབས་ཐོབ་མི་སྡེ་ཚན་ (འགན་ཁུར་) {#permission-groups-roles}

ངོས་ལེན་གྱི་སྡེ་ཚན་ཅིག་ལུ་ འགན་འཁྲི་ཟེར་སླབ་ཨིན། ངོས་ལེན་གི་རྟགས་མཚན་དང་འདྲཝ་སྦེ་ འགན་ཁུར་ཚུ་ `Grant` བཀའ་རྒྱ་ལག་ལེན་འཐབ་སྟེ་བྱིན་ནི་དང་ `Revoke` བཀའ་རྒྱ་ལག་ལེན་ཐོག་ལས་ ཆ་མེད་གཏང་ནི་ཨིན་མས།

རྩིས་ཁྲ་ལུ་ འགན་འཁྲི་བྱིན་པའི་ཧེ་མར་ འགན་འཁྲུལ་དེ་ ཐོ་བཀོད་འབད་དགོཔ་ཨིན།

འགན་འཁྲི་འདི་ ཕན་ཐོགས་ཅན་ཅིག་ཨིན་པའི་སྐབས་ རྩིས་ཁྲ་མང་ཤོས་ཅིག་གིས་ ངོས་ལེན་ཐོ་བཀོད་གཅིག་རང་ཐོབ་དགོཔ་ཨིན། འགན་འཁྲུལ་དེ་ ཐོ་བཀོད་ཚར་གཅིག་འབད་ཞིནམ་ལས་ འགན་འཁྲིའི་དོན་ལུ་ ངོས་ལེན་ཚུ་བྱིན་ཞིནམ་ལས་ རང་རྐྱང་གི་རྩིས་ཁྲ་ཚུ་གི་དོན་ལུ་ འགན་འཁྲིདཔ་བྱིན་ནི་དང་ ཡང་ན་ ཆ་མེད་གཏང་ནི་ཨིན་པས།

### འགན་འཁྲི་གསརཔ་ཅིག་ནང་ ཐོ་བཀོད་འབད་ {#register-a-new-role}

ང་བཅས་ཀྱིས་ འགན་འཁྲི་གསརཔ་ཅིག་ ཐོ་བཀོད་འབད་ཡོདཔ་ད་ འདི་གནང་པ་ཅིན་ རྩིས་ཁྲ་གཞན་ཅིག་གིས་ [metadata](/dz/blockchain/metadata.md) ལུ་ ངོས་ལེན་འབད་ཚུགས་འོང་།

```rust
let role_id = RoleId::from_str("ACCESS_TO_MOUSE_METADATA")?;
let role = iroha_data_model::role::Role::new(role_id.clone(), mouse_id.clone())
    .add_permission(CanModifyAccountMetadata {
        account: mouse_id.clone(),
    });
let register_role = Register::role(role);
```

### འགན་འཁྲི་བྱིན་ {#grant-a-role}

འགན་འཁྲི་འདི་ ཐོ་བཀོད་ཚར་བའི་ཤུལ་ལས་ Mouse གིས་ Alice ལུ་བྱིན་ཚུགས།

```rust
let grant_role = Grant::account_role(role_id, alice_id);
let grant_role_tx = TransactionBuilder::new(chain_id, mouse_id)
    .with_instructions([grant_role])
    .sign(mouse_private_key);
```

## ངོས་ལེན་ལག་ཁྱེར་ཚུ་ {#permission-validators}

ངོས་ལེན་ཚུ་ཡོདཔ་ལས་ དགོས་མཁོ་ཅན་གྱི་ ངོས་ལེན་རྟགས་ཡོད་པའི་རྩིས་ཁྲ་རྐྱངམ་གཅིག་གིས་ སྲུང་སྐྱོབ་འབད་བཏུབ་ཨིན། སྔོན་སྒྲིག་ལག་ལེན་འཐབ་མི་གིས་བཀོད་རྒྱ་དང་དྲི་བཀོད་ དེ་ལས་ གསལ་སྟོན་ལག་ལེན་གྱི་སྐབས་ལུ་ ངོས་ལེན་འདི་ཚུ་ བརྟག་ཞིབ་འབདཝ་ཨིན།

ཌེ་པཱལཊ་ཨའི་ཝེ་ལི་ཊར་གྱི་ ས་ཁུདཔ་འདི་ མདོ་ཆེན་གྱི་ས་ཁོངས་ལས་སྡེ་སྦེ་བཟོ་ཡོདཔ་ཨིན།

- གྲྭ་ཚང་གི་འཛིན་སྐྱོང་
- ས་ཁོངས་དང་རྩིས་ཁྲ་ཚུ་
- རྒྱུ་དངོས་ཚུ་ NFTs དང་ གཏན་འཁེལ་གྱི་ཁྲལ་ཚུ་
- ཐིག་ཁྲམ་ཚུ་
- འགན་ཁུར་དང་ ངོས་ལེན་ཚུ་
- ལག་བསྟར་སྤྱོད་/ལག་ལེན་གྱི་དུས་ཚོད་དང་ བརྟག་ཞིབ་ཚུ་ དེ་ལས་ SORA/Nexus ཚད་གཞག་ཚུ་

འདི་ཡང་ [Permission Tokens Reference](/dz/reference/permissions.md)ནང་ལུ་ གཞི་རྟེན་གི་རྒྱབ་སྐྱོར་ལུ་བརྟེན་ཨིན།

### འགྲུལ་སྐྱོད་དུས་ཚོད་བརྟག་དཔྱད་འཕྲུལ་ཆས་ཚུ་ {#runtime-validators}

ངོས་ལེན་བརྟག་དཔྱད་འདི་ ལག་རྩལ་ཅན་གྱི་ལག་བསྟར་མ་གིས་ བཏོན་དོ་ཡོདཔ་ཨིན། སྔོན་སྒྲིག་ལག་བསྟར་མི་འདི་གིས་ ནང་འཁོད་ལུ་ ངོས་ལེན་ཆ་འཛིན་དང་ ཐོ་བཀོད་རྟགས་ཀྱི་འགྲེལ་བཤད་ཚུ་ བྱིན་དོ་ཡོདཔ་མ་ཚད་ གྲོག་ཐིག་ཅིག་གིས་ ལག་ལེན་འཐབ་མི་ལག་བསྟར་རིམ་དེ་ ཡར་དྲག་གཏང་ཐོག་ལས་ སྲིད་བྱུས་འདི་ བསྒྱུར་བཅོས་འབད་ཚུགས།

བརྟན་དཔྱད་འབད་མི་ཚུ་གིས་ བརྟན་ཞིབ་ཀྱི་ཁྲིམས་ཐག་བཅད། བརྟན་རྟགས་དཔྱད་འབད་མི་ཚུ་གིས་ བྱ་བ་སྤྱོད་ལམ་ཅིག་ལུ་ ངོས་ལེན་འབད་ཚུགས། བརྟན་བཅོས་འབད་མི་ཚུ་གིས་ གནད་དོན་ག་ཅི་གི་ཐད་ཁར་འབད་རུང་ ཆ་མེད་གཏང་ནི་དང་ བཀག་ཆ་འབད་ནི་དང་ ཡང་ཅིན་ ལས་འགུལ་དེ་ བརྟན་གྲུབ་ཅན་གྱི་ ཁྲིམས་སྲུང་འགག་པ་གིས་ ལག་ལེན་འཐབ་མ་བཏུབ་པ་ཅིན་ དེ་སེལ་འཐུ་འབད་ཚུགས། བཙག་འཐུ་གྲུབ་མི་ དྲང་དཔོན་གྱིས་ འཁྲུན་ཆོད་ཚུ་གཅིག་ཁར་བསྡོམས་ཏེ་ བཀའ་རྒྱ་དང་དྲི་བཀོད་ ཡང་ན་ གསལ་སྟོན་འདི་ འཕྲོ་མཐུད་འབད་ཚུགས་ཨིན་ན་མེན་ན་ གྲོས་ཐག་བཅད་ཚུགས།
