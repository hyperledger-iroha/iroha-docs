# གློག་ཐིག་ཚུ་ {#filters}

བྱུང་ལས་རྒྱུན་ལམ་དོག་པོ་དང་ འབྱུང་ཁུངས་གནས་སྟངས་ཚུ་ཚགས་མ་བཙུགསཔ་ཨིན། ད་ལྟོའི་མཐོ་རིམ་བྱུང་ལས་ཚགས་མ་འདི་ `EventFilterBox` ཨིན་ དེ་གིས་བྱུང་ལས་བཟའ་ཚང་འདི་ཚུ་མཐུན་སྒྲིག་འབད་ཚུགས།

- `Pipeline`
- `Data`
- `Time`
- `ExecuteTrigger`
- `TriggerCompleted`

ལཱ་གི་རྒྱུན་རིམ་དང་མཐུན་པའི་ཚགས་མ་རྒྱ་ཆུང་ཤོས་འདི་ལག་ལེན་འཐབ། `DataEventFilter::Any` བཟུམ་གྱི་ཚགས་མ་རྒྱ་ཆེ་བ་ཚུ་ བརྟག་དཔྱད་ཀྱི་དོན་ལུ་ཕན་ཐོགས་ཡོདཔ་ཨིན་ དེ་འབདཝ་ད་ དེ་ཚུ་གིས་ བྱུང་ལས་ག་ར་ལུ་ ཊི་གཱར་ཡང་ན་ མཁོ་མངགས་འབད་མི་མཐུན་སྒྲིག་འབད་ནིའི་འགྲོ་སོང་སྤྲོད་བཅུགཔ་ཨིན།

## གནས་སྡུད་བྱུང་རྐྱེན་ཚུ་ བཀྲམ་སྟོན་འབདཝ་ཨིན། {#data-event-filters}

`DataEventFilter` གིས་ ལེ་ཇར་གནད་སྡུད་བྱུང་ལས་ཚུ་དང་མཐུན་སྒྲིག་འབདཝ་ཨིན། དེའི་ད་ལྟོའི་འགྱུར་ལྡོག་ཚུ་ཡང་།

| འགྱུར་ཅན་ | བྱུང་རིམ་བཟའ་ཚང་། |
| --- | --- |
| `Any` | གནད་སྡུད་བྱུང་རིམ་གང་རུང་ |
| `Peer` | མཉམ་རོགས་ཀྱི་མི་ཚེ་འཁོར་རིམ་བྱུང་རིམ། |
| `Domain` | མངའ་ཁོངས་ཀྱི་མི་ཚེ་འཁོར་རིམ་དང་ མེ་ཊ་ཌེ་ཊ་བྱུང་ལས་ |
| `Account` | རྩིས་ཐོའི་མི་ཚེ་འཁོར་རིམ་དང་ མེ་ཊ་ཌེ་ཊ་ མིང་གཞན་ དེ་ལས་ ངོ་རྟགས་བྱུང་ལས་ཚུ་ |
| `Asset` | རྒྱུ་དངོས་ལྷག་ལུས་དང་ མེ་ཊ་ཌེ་ཊ་བྱུང་ལས་ |
| `AssetDefinition` | རྒྱུ་དངོས་ངེས་ཚིག་མི་ཚེ་འཁོར་རིམ་དང་ སྲིད་བྱུས་ དེ་ལས་ མེ་ཊ་ཌེ་ཊ་བྱུང་ལས་ཚུ་ |
| `Nft` | NFT མི་ཚེ་འཁོར་རིམ་དང་ མེ་ཊ་ཌེ་ཊ་བྱུང་ལས་ |
| `Rwa` | དངོས་ཡོད་འཛམ་གླིང་རྒྱུ་ནོར་གྱི་མི་ཚེ་འཁོར་རིམ་གྱི་བྱུང་རིམ། |
| `Trigger` | མི་ཚེ་འཁོར་རིམ་དང་ མེ་ཊ་ཌེ་ཊ་བྱུང་ལས་ཚུ་ འགོ་བཙུགས་ |
| `Role` | འགན་ཁུར་གྱི་མི་ཚེ་འཁོར་རིམ་བྱུང་ལས། |
|`Configuration` |ལྕགས་ཐག་ནང་ལུ་ གཞི་སྒྲིག་གི་བྱུང་རྐྱེན་ཚུ་ |
| `Executor` | གཡོག་བཀོལ་བའི་དུས་ཚོད་ལག་ལེན་འཐབ་མི་བྱུང་ལས་ཚུ་ |
| `Proof` | བདེན་དཔང་བདེན་དཔང་མི་ཚེ་འཁོར་རིམ་བྱུང་ལས། |
| `Confidential` | གསང་བའི་རྒྱུ་དངོས་བྱུང་རིམ། |
| `VerifyingKey` | བདེན་དཔྱད་-ལྡེ་མིག་ཐོ་བཀོད་བྱུང་ལས་ཚུ་ |
| `RuntimeUpgrade` | གཡོག་བཀོལ་དུས་ཚོད་ཡར་བསྐྱེད་བྱུང་ལས་ཚུ་ |
|`Soradns` |སེལ་བྱེད སྣོད་ཐོ གཞུང་སྐྱོང་གི་བྱུང་རྐྱེན་ཚུ་ འདི་སེལ་འཐུ་འབད་ |
|`Sorafs` |SoraFS སྒོ་ལམ འཁྲི་མཐུན་བྱུང་རིམ་ཚུ |
| `SpaceDirectory` | བར་སྟོང་སྣོད་ཐོ་གསལ་སྟོན་མི་ཚེ་འཁོར་རིམ་བྱུང་ལས་ |
| `Escrow` | དྭངས་གསལ་གྱི་ས་གནས་ཀྱི་རྒྱུ་དངོས་ བར་གཏོགས་བདག་ཉར མི་ཚེ་འཁོར་རིམ་བྱུང་རིམ། |
| `Offline` | དྲ་རྒྱའི་ཕྱི་རོལ་གྱི་གཞིས་ཆགས་བྱུང་རིམ། |
| `Oracle` | ཨོ་རེ་ཁེལ་ཕིཌི་བྱུང་རིམ་ |
| `Social` | ནད་ཡམས་སྐུལ་སློང་བྱེད་སྒོ། |
| `Bridge` | ཟམ་པའི་བྱུང་རིམ། |
| `Governance` | གཞུང་སྐྱོང་ཁྱད་རྣམ་ལྕོགས་ཅན་བཟོ་བའི་སྐབས་ གཞུང་སྐྱོང་བྱུང་ལས། |

བརྟན་པོའི་ཚགས་མ་མང་ཤོས་ཅིག་གིས་ གདམ་ཁ་ཅན་གྱི་ཨའི་ཌི་མཐུན་སྒྲིག་དང་ བྱུང་ལས་གཞི་སྒྲིག་འབད་ནིའི་ཁ་རས་ཡང་ འབད་བཅུགཔ་ཨིན། དཔེར་ན་ རྒྱུ་དངོས་ཚགས་མ་ཅིག་གིས་ རྒྱུ་དངོས་གཅིག་ཡང་ན་ རྒྱུ་དངོས་བྱུང་ལས་ཚུ་གི་དབྱེ་རིམ་གཅིག་མཐུན་སྒྲིག་འབད་ཚུགས་ དེ་འབདཝ་ད་ ཊི་གར་ཚགས་མ་གིས་ ཊི་གར་ཨའི་ཌི་དང་ ཊི་གར་བྱུང་ལས་ཆ་ཚན་ཅིག་མཐུན་སྒྲིག་འབད་ཚུགས།

## གློག་སྣུམ་གྱི་ཐིག་ཁྲམ་ཚུ་ {#pipeline-filters}

མདོང་ལམ་ཚགས་མ་ཚུ་གིས་ སྡེབ་ཚན་དང་ ཚོང་འབྲེལ་ མཉམ་བསྡོམས་ དེ་ལས་ དཔང་པོ་བྱུང་ལས་ཚུ་བཟུམ་གྱི་ ལས་སྦྱོར་བྱུང་ལས་ཚུ་དང་མཐུན་སྒྲིག་འབདཝ་ཨིན། བཀོལ་སྤྱོད་ཀྱི་མཁོ་སྒྲུབ་དང་ སྡེབ་ཚན་ལས་སྦྱོར་གྱི་ཌེཤ་བོརཌི་ དེ་ལས་ ལེ་ཇར་གནད་སྡུད་དངོས་པོ་ཚུ་མེན་པར་ པའིཔ་ལའིན་གནས་སྟངས་ལུ་ ལན་གསལ་འབད་མི་ འབྱུང་ཁུངས་ཚུ་གི་དོན་ལུ་ལག་ལེན་འཐབ།

## ཐིག་ཁྲམ་ཚུ་ {#trigger-filters}

ཊི་གར་ཚུ་གིས་ ཁོང་རའི་གནས་སྟངས་འདི་ `EventFilterBox` ཅིག་སྦེ་གསོག་འཇོག་འབདཝ་ཨིན། འབྱུང་བྱེད་བྱ་བ་ཅིག་གིས་ཡང་གསོག་འཇོག་འབདཝ་ཨིན།

- བཀོལ་སྤྱོད་འབད་བཏུབ་མི།
- བསྐྱར་ཟློས་ཀྱི་སྲིད་བྱུས།
- ཁྲི་འཛིན་གྱི་རྩིས་ཐོ་
- གདམ་ཁ་ཅན་གྱི་དུས་ཚོད་-འབྱུང་ཁུངས་བསྐྱར་འབད་འབད་ནིའི་སྲིད་བྱུས།
- ཟུར་གནས་གནད་སྡུད

སྐུལ་རྟེན དབང་ཚད འདི་ ལག་བསྟར་བཏུབ གིས་ དགོས་པའི་ ངོས་ལེན་ཚུ་ཡོད་དགོཔ་ཨིན། དམིགས་གཏད་ཅན་གྱི་ལག་རྩལ་རྩིས་ཐོ་འདི་ ཡུན་རིང་གི་ སྐུལ་རྟེན ཚུ་གི་དོན་ལུ་ གདམ་ཁ་རྐྱབ་ཡོདཔ་ཨིན།

## འདྲི་དཔྱད་ཐིག་ཁྲ། {#query-filters}

ཐད་ཀར་ཐོ་ཚུ་ འབྱུང་རྐྱེན་ཐད་ཀར་ལས་སོ་སོ་ཨིན། བསྒྱུར་བཅོས་འབད་བཏུབ་པའི་དྲི་བ་ཚུ་གིས་ ཆ་རྐྱེན དང་ སེལ་བྱེད རྒྱབ་སྐྱོར་བཏོན་ཚུགས། SDK ལས་ འདྲི་དཔྱད-དམིགས་བསལ དབྱེ་བ་གསལ་བཀོད་ཅན་གྱི་ ཚགས་མ ལག་ལེན་འཐབ་ དེ་འབདཝ་ལས་ ཚགས་མ ཨིན་པུཊ འདི་ འདྲི་དཔྱད ཐོན་འབྲས དབྱེ་བ ལུ་འཕྲོདཔ་ཨིན།
