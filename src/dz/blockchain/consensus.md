འགྲེམ་ཐོག་ཚོགས་རྒྱན་འདི་ གྲོས་མཐུན་གྱི་ བརྡ་དོན་ཆུང་ཀུ་ཅིག་ཨིན་ འདི་ནང་ བཀྲམ་སྤེལ་འབད་ཡོད་པའི་ཨང་གྲངས་དང་ མཐོ་ཚད་ དེ་ལས་ མཐོང་སྣང་ དེ་ལས་ ངོས་འཛིན་འབད་མི་གི་ ངོ་རྟགས་ཚུ་བཀོད་ཡོདཔ་ཨིན། ཚོགས་རྒྱན་བསྡུ་ལེན་པ་ཚུ་གིས་ ཨང་གྲངས་ཀྱི་ལག་ཁྱེར་ ཡང་ན་ ཁས་བླངས་ཀྱི་ལག་འཁྱེར་ནང་ལུ་ ཨང་གྲངས་བསྡོམས་འབདཝ་ཨིན། གྲུབ་རྟགས་འདི་ དངོས་གྲུབ་ཅན་ཅིག་ལུ་ བརྟག་ཞིབ་འབད་མི་ཚུ་གིས་ same block གི་དོན་ལུ་ གྲུབ་འབྲས་དེ་འདྲ་ཐོབ་ཡོདཔ་སྦེ་ བདེན་ཁུངས་བཀལ་ཚུགསཔ་ཨིན།

### ཚོགས་ཆུང་དང་ བསྡུ་ལེན་འབད་མི་དང་ ལྟ་རྟོག་འབད་མི་ {#quorum-collectors-and-observers}

ཚོགས་རྒྱན་གཏན་འབེམ་གྱི་གྲངས་རྩིས་ `n` གིས་ བི་ཛིན་ཊི་ཡཱན་གི་འཛོལ་བ་འཆར་དངུལ་ཚུ་ གསལ་བཀོད་འབདཝ་ཨིན། ཚད་འཛིན་༤ ལས་མ་བརྒལ་ཡོད་པའི་དྲ་རྒྱ་ཚུ་གི་དོན་ལུ་ འཆར་དངུལ་འདི་ `f = floor((n - 1) / 3)` དང་བཅའ་ཡིག་ཚང་དེ་ `2f + 1`ཨིན། ༡ ལས་ ༣ གི་རིང་ལུ་ བརྟན་དཔྱད་འབད་མི་ཚུ་ག་ར་ commitགི་དོན་ལུ་ དགོཔ་ཨིན་ འདི་ཡང་ གོང་འཕེལ་གྱི་དོན་ལུ་ ཕན་ཐོགས་ཅན་ཅིག་ཨིན་རུང་ ལག་ལེན་འཐབ་མ་བཏུབ་པའི་ offline slack མིན་འདུག་།

བསྡུ་ལེན་འབད་མི་ཚུ་འདི་ ཕན་ནུས་ཅན་གྱི་ཨོ་པི་ཊི་མའི། བསྡུ་བསྒྱོམ་འབད་མི་ཚུ་གིས་ ཚོགས་རྒྱན་ཆ་མཉམ་དེ་ གཞན་ཚོགས་རྒྱན་ཆ་མཉམ་ལུ་བཏང་མི་ཚབ་ལུ་ Sumeragi གིས་ མཐོ་ཚད་གི་དོན་ལུ་ བསྡུ་འཛིན་འབད་མི་གཅིག་ ཡང་ན་མང་ཤོས་ཅིག་ གདམ་འཐུ་འབད་ཚུགས། བསྡུ་བསྡུ་མི་ཚུ་གིས་ ཚོགས་རྒྱན་ཚུ་གཅིག་ཁར་སྤུངས་ཞིནམ་ལས་ ཨང་གྲངས་ཉུང་མཐར་ཁྱབ་བསྒྲགས་འབད་ནི་དང་ ཚོགས་རྒྱན་ལོག་ལྡོག་གི་རྒྱུན་འགྲུལ་མར་ཕབ་འབད་འོང་། དངོས་གྲུབ་ཅན་གྱི་སྒྲོམ་སྒྲོམ་ཚུ་ `GET /v1/sumeragi/collectors` གི་ཐོག་ལས་བཏོན་ཡོདཔ་ད་ CLI གྱི་ `ops sumeragi telemetry` གློག་བརྙན་འདི་ ད་ལྟོའི་སྒྲོམ་སྒྲོམ་གྱི་གྲངས་རྩིས་ལུ་ སྙན་ཞུ་འབདཝ་ཨིན།

ལྟ་རྟོག་པ་ཚུ་གིས་ བཀྲམ་སྤེལ་འབད་ཡོད་པའི་ སྦྲག་ཚུ་ དུས་མཐུན་བཟོ་ཚུགས། ཨིན་རུང་ ཁོང་གིས་ གྲོས་འཆར་བཀོད་ནི་དང་ ཚོགས་རྒྱན་བཙུགས་ནི་ དེ་ལས་ ཚོགས་རྒྱན་བསྡུ་ལེན་འབད་ནི་ ཡང་ན་ commit quorum ལུ་རྩིས་རྐྱབ་མི་ཚུགས། སྒྲིག་གཞི་ཅིག་གིས་ ས་གནས་ཀྱི་དྲི་བའི་ལྕོགས་གྲུབ་དང་ indexing, monitoring, ཡང་ན་ ལུང་ཕྱོགས་ block replication དགོཔ་ཨིན་པ་ཅིན་ ལག་ལེན་འཐབ་སྟེ་ ལྟ་རྟགས་འབད་མི་ཚུ་ ལག་ལེན་འཐབ་དགོ།

### བསྒྱུར་བཅོས་དང་ ལོག་སྤྱོད་ཚུ་བལྟ་ནི། {#view-changes-and-recovery}

མཐོང་སྣང་འདི་ Sumeragi གིས་ གྲོས་འཆར་དང་ དུས་ཡུན་འཆར་གཞིའི་ཐོག་ལས་ མཐོ་ཚད་གཅིག་ མཇུག་བསྡུ་ནིའི་ དཔའ་བཅམ་ཨིན། གལ་སྲིད་ གྲོས་འཆར་, ཁེ་ཕན་གྱི་ལཱ་, ཚོགས་རྒྱན་བཙུགས་ནི་, ཡང་ན་ གྲུབ་འབྲས་ཚུ་ བསྡུ་སྒྲིག་འབད་ཡོད་པ་ཅིན་, པི་སི་མཱཔ་འདི་གིས་མཐོ་ཚད་དེ་ཤུལ་མའི་མཐོངམ་ལུ་ སྤོ་བཤུད་འབད་ཚུགས། མཐོང་སྣང་བསྒྱུར་བཅོས་ཀྱིས་ committed block འདི་ཡང་ཡིག་སྒྱུར་མི་འབདཝ་ཨིན། འདི་གིས་བརྟག་དཔྱད་འབད་མི་ཚུ་གིས་ ཁས་བླངས་མ་འབད་མི་ མཐོ་ཚད་འདི་ མཇུག་བསྡུ་ནི་ལུ་ དཔའ་བཅམ་མི་ཐབས་ལམ་ལུ་ བསྒྱུར་བཅོས་འབདཝ་ལས་ ཤེས་རྟོགས་ཡོད་མི་ གྱངས་ཁ་མཐོ་ཤོས་དེ་ ཕར་དང་ཚུར་འབག་འགྱོ་ནི་དང་ ཡང་ན་ བདེན་ཁུངས་བཀལ་ནི་ཨིནམ་ལས་ དབྱེ་ཅན་ཚུ་གིས་ མགུ་འཐོམ་པའི་ སྦྲག་ཚུ་ མཇུག་བསྡུ་མི་ཚུགས་ཟེར་ཨིན་པས།

ཁེ་ཕན་གྱི་ཁེ་རྒུད་སླར་གསོ་འབད་ཐངས་འདི་ མཐའ་མཇུག་གི་ གྲོས་ཐག་ལས་སོ་སོ་ཨིན། འབའ་ཚང་ཅིག་གིས་ ཁེ་རྒུད་ཀྱི་ཁེ་རྒུདཔ་མ་ཐོབ་པའི་ཧེ་མ་ལས་ quorum ཡང་ན་ commit certificate ཐོབ་ཚུགས། འདི་ནང་ལུ་, འབའ་ཐང་འདི་གིས་ ཁེ་ཕན་ཆེ་བའི་ཁེ་རྒུ་སླར་གསོ་འབད་ནིའི་དོན་ལུ་ ཡིད་ཆེས་ཅན་གྱི་བརྡ་བརྒྱུད་ (RBC) ཡང་ན་ block sync ལག་ལེན་འཐབ་སྟེ་ ཨེབ་གཏང་འབད་ཡོད་པའི་ཧེཤ་ཚུ་དང་བསྟུན་ བརྟག་ཞིབ་འབདཝ་ཨིན། དང་པ་ར་ འཛམ་གླིང་རྒྱལ་ཁབ་དང་ Kura ལུ་ བཀྲམ་སྤེལ་འབད་ནི་ཨིན།

### གྲོས་བསྟུན་གྱི་ ཐབས་ལམ་ཚུ་ {#consensus-modes}

## མང་སྡེ་ཚན་གྱི་མཐུན་ལམ་ {#multilane-consensus}

Iroha གི་ མང་ལམ་མཐུན་རྐྱེན་ལམ་དེ་ Nexus ལེན་དང་ ཌེ་ཊ་ས་པི་སི་གི་སྒྲིག་གཞི་བརྒྱུད་དེ་ལག་ལེན་བསྟར་སྤྱོད་འབད་ཡོདཔ་ཨིན། དེ་གིས་ ལེན་རེ་གི་དོན་ལུ་ ཁྱད་པར་ཅིག་མཐུན་རྐྱེན་གྱི་ལེའུ་མ་འགོ་འདྲེན་འཐབ་ཚུགས། Sumeragi འདི་ཡང་ བཀྲམ་སྤེལ་འབད་ཡོད་པའི་ ཕྲང་ལམ་གཅིག་ མཇུག་བསྡུ་བཞུགསཔ་ཨིན། ཕྲང་ཐིག་ཚུ་གིས་ transaction དེ་ནང་ག་དེ་སྦེ་ routed, scheduled, accounted, and storedའབདཝ་ཨིན་ན་ གསལ་བཀོད་འབདཝ་ཨིན།

འགྲུལ་ལམ་གྱི་དུས་ཚོད་བཟོ་ཐངས་དེ་ ལེན་ཝིན་གནས་སྟངས་ཀྱི་དུམ་བུ་གསུམ་ བཟོ་ཡོདཔ་ཨིན།

- `lane_catalog`: གྱངས་ཁ་སྒྲིག་པའི་ལམ་, གཅིག་གིས་གཅིག་ཨང་གྲངས་ཀྱི་ `LaneId`, alias, data space, མཐོང་སྣང་, སྒྲིང་སྒྲི་བཟོ་རྣམ་, བརྟག་དཔྱད་འཆར་གཞི་, དང་ metadata.
- `dataspace_catalog`: གཞི་སྒྲིག་འབད་ཡོད་པའི་ data spaces འདི་ཆ་མཉམ་ལུ་ཨང་གྲངས་ `DataSpaceId` དང་ འབྲེལ་མཐུད་ཚོགས་ཆུང་གི་ཚད་འཇལ་བའི་དོན་ལུ་ལག་ལེན་འཐབ་མི་ fault tolerance value ཡོདཔ་ཨིན།
- `routing_policy`: default lane/data space pair དང་ orders routing rules དེ་ཚུ་ account ཡང་ན་ instruction paths དང་གཅིག་ཁར་བསྡོམས་ཚུགསཔ་ཨིན།

ཚོང་འབྲེལ་དེ་གྲལ་ཐིག་ནང་འཛུལ་བའི་སྐབས་ ཕྲང་ལམ་ལམ་གྱི་ལམ་སྟོན་འདི་གིས་ `RoutingDecision { lane_id, dataspace_id }` ལུ་སེལ་འཐུ་འབདཝ་ཨིན། ཐབས་ལམ་རྐྱང་ལམ་ལུགས་ནང་ལུ་ འདི་དུས་རྒྱུན་དུ་ ཕྲང་རིང་ `0` དང་ ཡོངས་ཁྱབ་གནས་སྡུད་ཚུ་ཨིན། Nexus ཐབས་ལམ་ནང་ལུ་ གཞི་སྒྲིག་འབད་མི་ རུ་ཊར་འདི་གིས་ ཌེ་ཊ་ས་པི་སི་གི་གནས་ཚད་དང་འཁྲིལ་ཏེ་ ཁྲིམས་ལུགས་ཚུ་ ལག་ལེན་འཐབ་ནི་ དེ་ལས་ ཟད་འགྲོ་བཏང་ནིའི་ལམ་ལུགས་དང་རྩིས་ཁྲའི་ཁྲིམས་ལུགས་ དེ་ལས་ གསལ་སྟོན་ཅན་གྱི་ ལམ་ལུགས་ དེ་ལས་མཐའན་མཇུག་ལུ་ རང་བཞིན་གྱི་ལམ་ལུགས་འདི་ ལག་ལེན་འཐབ་འོང་། གྲོས་ཐག་བཅད་མི་ ཕྲང་ལམ་དང་ གནས་སྡུད་ས་སྟོང་འདི་ ཁོང་རའི་ཡིག་སྣོད་ནང་ཡོད་དགོཔ་ཨིན། དེ་ལས་ ས་སྟོང་དེ་ གྲོས་ཐག་བཅད་པའི་ གནས་སྡུད་ ས་སྟོང་དང་གཅིག་ཁར་བསྡོམས་དགོཔ་ཨིན། དེ་མེན་པ་ཅིན་ ཚོང་འབྲེལ་དེ་གྲལ་རིམ་མ་བཙུགས་པའི་ཧེ་མ་ ཆ་མེད་གཏང་འོང་།

གྲལ་ཐིག་འདི་ བརྒྱུད་ལམ་གྱི་ཁ་ཐུག་གི་ཐག་བཅད་དེ་ ཌེ་བི་ཊཱན་གྱི་ཧེཤ་དང་གཅིག་ཁར་ བཞག་སྟེ་ཡོདཔ་ལས་ཤུལ་མའི་གནས་ཚད་ཚུ་ནང་ ལོག་སྟེ་ར་ འོང་དགོཔ་མེད་ཟེར་ཨིནམ་ད་ གྲོས་འཆར་བཟོ་སྐྲུན་འབད་མི་དེ་ ལེན་ཌའི་ཊ་ལུ་ ཐབས་ལམ་གཉིས་ཀྱི་ཐོག་ལས་ ལག་ལེན་འཐབ་ཨིན།

- ཚོང་འབྲེལ་གྱི་ལཱ་ཚུ་ ཕྲང་ལམ་ལས་བརྒལ་ཏེ་ བསྡུ་བསྒྱོམ་འབད་དོ་ཡོདཔ་ལས་ ཕྲང་ཐིག་ཅིག་གིས་ དུམ་གྲ་རེ་ནང་ འཛུལ་ཞུགས་འབད་མ་ཚུགསཔ་ ག་ཅི་སྨོ་ཟེར་བ་ཅིན་ ཚོང་འབྲེལ་དེ་ འགོ་དང་པ་སྦེ་གྲལ་སྒྲིག་འབདཝ་ཨིན་མས།
- ཕྲང་ལམ་གྱི་ཐད་ལུ་ ཚོང་འབྲེལ་ལག་ལེན་བསྟར་སྤྱོད་སྡེ་ཚན་ (TEU) གི་ཚད་འཛིན་ཚུ་ ལག་ལེན་འཐབ་ཨིན། ཐབས་ལམ་ཅིག་གིས་ གཞི་སྒྲིག་འབད་ཡོད་པའི་ སྒྲིང་སྒྲི་ལས་བརྒལ་འོང་མི་ ཚོང་འབྲེལ་ཚུ་ བཏོན་གཏང་ནི་དང་ བཙུགས་གཏང་ནི་མ་གཏོགས་ ཐབས་ལམ་གཅིག་གི་དོན་ལུ་ ཁྱབ་སྤེལ་ཆེ་བའི་ ཚོང་འབྲེལ་འགོ་དང་པ་ འགོ་བཙུགས་ཚུགསཔ་སྦེ་ བཟོ་སྟེ་ བཞག་ཚུགས།

## བརྒྱུད་འཕྲིན་བརྟན་ཏོག་ཏོ་ (RBC) {#reliable-broadcast-rbc}

བརྒྱུད་འཕྲིན་ཡིད་རྟོན་རུང་ཅན་ (RBC) འདི་ Sumeragi གི་ ཁེ་ཕན་གྱི་ཁེ་ཕན་ཁྱབ་སྤེལ་དང་སླར་གསོ་འབད་ནི་གི་ལམ་ཨིན། འདི་གིས་ གྲོས་འདེབས་དང་ ལྟ་རྟོག་པ་ཚུ་ལུ་ ཁེ་ཕན་ཅན་གྱི་ཁེ་ཕན་གྱི་ཡིག་གཟུགས་ཐོབ་ནི་ལུ་ཆ་རོགས་འབད། དམིགས་བསལ་དུ་ `BlockCreated` ཀྱི་ བརྡ་དོན་, ཁེ་ཕན་གི་ཁེ་ཕན་ལུ་ དུས་མཐུན་བཟོ་བཀོད་འབད་ནི་དང་ ཡང་ཅིན་ ཐད་ཀར་དུ་ ཁེ་ཕན་ཆེ་བའི་ཁེ་ཕན་སྤྲོད་ནི་ཚུ་ མཚམས་འགོར་སོང་པའི་སྐབས་ ཡང་ན་ རྩ་མེད་སོང་པའི་སྐབས་ལུ་ཨིན།

RBC གིས་ ཁེ་ཕན་གྱི་ཐོ་བཀོད་གནས་ཚད་ནང་ལུ་ལཱ་འབད་ཡོདཔ་ཨིན། གྲོས་འདེབས་བཙུགས་མི་དེ་གིས་ RBC སྒྲིག་འཇུག་གི་རིང་ཚད་དང་མཐོངམ་ དེ་ལས་ ཁེ་ཕན་ཅན་གྱི་ཐོ་བཀོད་ཀྱི་ཧེཤ་གི་དོན་ལུ་ གསལ་བསྒྲགས་འབད་ཞིནམ་ལས་ ཁེ་ཕན་ཆེ་བའི་ཐོ་བཀོད་པ་ཚུ་ commit topology ནང་བཏང་འོང་། གྲྭ་ཚང་ཚུ་གིས་ ཤོག་ལེབ་ཀྱི་ཐོབ་ཐངས་ཚུ་ བརྟག་ཞིབ་འབད་ཞིནམ་ལས་ གསལ་བསྒྲགས་འབད་ཡོད་པའི་ ཧེཤ་དང་ཕྱདཔ་ད་ ལོག་ཐོབ་པའི་ ཁེ་ཕན་གྱི་ཁེ་རྒུད་དེ་ བདེན་ཁུངས་བཀལ་ཏེ་ `READY` དང་ `DELIVER` རྟགས་མཚན་ཚུ་ བརྗེ་སོར་འབད་ཚར་བའི་ཤུལ་ལུ་ ཁེ་ཕན་གི་ཁེ་རྒོད་དེ་ དངོས་ལེན་འབད་མི་ཚུ་གིས་ ལྟ་རྟོག་འབད་ཚར་ནུག གྲོས་བསྡུར་འདི་ TTL ཀྱིས་མཚམས་သတ်ཡོདཔ་ལས་ བཀྲམ་སྤེལ་འབད་ནིའི་རྒྱུན་འགྲུལ་འཐབ་ནི་དེ་ ངེས་གཏན་སྦེ་ཡར་སེང་འགྱོ་མི་ཚུགས་པས།

RBC འདི་སོ་སོ་གི་གྲོས་མཐུན་གྱི་ གྲོས་ཐག་ཅིག་མེན་དང་ commit certificate གི་ཚབ་ཡང་མེདཔ། བཀྲམ་སྤེལ་འབད་མི་དེ་ད་ལྟོ་ར་ རྐྱངམ་གཅིག་མཇུག་བསྡུ་དོ་ཡོདཔ་ད་ peer གྱིས་ valid commit certificate དང་ matching payload ས་གནས་ནང་ཡོད་པའི་སྐབས་རྐྱངམ་གཅིག་ཨིན། RBC གིས་ དགོས་མཁོ་ཅན་གྱི་ལག་ལེན་དང་ ཁེ་ཕན་གྱི་ཐེག་པ་སླར་ལོག་འབད་ནི་གི་ གྲུབ་འབྲས་འཐོབ་དོ་ཡོདཔ་ད་ commit རྒྱས་གོང་འཕེལ་འདི་ commit certificate plus local payload ལུ་བརྟེན་ཨིན། གལ་སྲིད་ certificate འདི་ useful load གི་ཧེ་མ་ལས་ལྷོད་པ་ཅིན་ peer གིས་ RBC ཡང་ན་ block syncབརྒྱུད་དེ་ payload ལོག་ཐོབ་སྟེ་ commit འབད་ཚུགས།
