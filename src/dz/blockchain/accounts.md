# རྩིས་ཁྲ་ {#accounts}

རྩིས་ཁྲ་འདི་ འབྲེལ་གཏད་ལག་ལེན་དང་ རང་སོའི་རྩིས་དེབ་ཀྱི་ གནས་སྟངས་ནང་ ཐོ་བཀོད་འབད་ཚུགས་མི་དབང་འཛིན་ཅིག་ཨིན། ད་ལྟོའི་ Iroha 3 ཌེ་ཊའི་གི་དཔེ་ནང་ལུ་ `AccountId` འདི་ ཀ་ནོ་ནིསི་དང་ དོ་ཡིནམ་མེད་པའི་ཨིན། འདི་རྩིས་ཁྲ་འཛིན་སྐྱོང་ལས་བཏོན་ཏེ་ ཀ་ནཱོ་ནིསི་སྦེ་ [I105](/dz/reference/i105.md) ཨིན་པས། མི་གིས་བཀླག་ཚུགས་མི་ ས་ཁོངས་དང་ གནད་སྡུད་ས་ཁོངས་ཀྱི་ གནས་སྟངས་འདི་ རང་སོ་སོ་སྦེ་རྩིས་ཁྲ་-alias འབྲེལ་མཐུད་འབད་ནིའི་ནང་ཚུདཔ་ཨིན།

## བཟོ་བཀོད་ {#structure}

ཐོ་བཀོད་འབད་མི་ `Account` ནང་འཁོད་ནང་ལུ་:

- `id`: ཀ་ནོ་ཀཱན་གྱི་ཡིག་ཆ་ `AccountId`
- `metadata`: རང་འདོད་ཅན་གྱི་རྩིས་ཁྲ་གི་ མེ་ཊ་ཌའི་ཊཱ།
- `label`: རང་བཞིན་གནས་གོང་གི་མིང་།
- `uaid`: གདམ་ཁ་རྐྱབས་ཀྱི་ Universal Account ID གིས་ Nexus རྒྱུན་འགྲུལ་འཐབ་ཚུགས།
- `opaque_ids`:རྩིས་ཁྲ་གི་ UAID ལུ་བཅའ་མར་གཏོགས་མི་ དྭངས་འཕྲོས་འཕྲོས་ཅན་གྱི་ངོ་རྟགས་ཚུ་

རྩིས་ཁྲ་བཟོ་ནིའི་དོན་ལུ་ལག་ལེན་གྱི་ཁེ་ཕན་འདི་ `NewAccount`ཨིན། འདི་ནང་ ངོས་འཛིན་, metadata,label, UAID དང་ དྭངས་གསལ་མེད་མི་ ID fields ལག་ལེན་འཐབ་མི་ ཐོ་བཀོད་འབད་ཡོད་པའི་རྩིས་ཁྲ་དེ་ཡང་ཡོདཔ་ཨིན།

`uaid` གིས་ `AccountId` སྒྲིག་གཞི་འདི་ བསྡུ་སྒྲིག་འབདཝ་ཨིན། འདི་གིས་འདི་ཚབ་མ་བཟོཝ་ཨིན། ཁྱོད་ཀྱིས་ Nexus ཞབས་ཏོག་ཚུ་ནང་ ཌེ་ཊ་ས་པི་སི་ཚུ་ནང་ལུ་ ལག་ལེན་འཐབ་མི་ ཡང་ན་ ལས་སྡེ་ཚུ་གི་གནས་བརྟན་ཅིག་ དགོས་མཁོ་ཡོདཔ་ད་ གསང་སྤྱོད་ལུ་སྲུང་སྐྱོབ་འབད་མིའི་ ཐོ་བཀོད་དང་ ཡང་ན་ ཞབས་ཏོག་གི་ནུས་ཤུགས་འཚོལ་བའི་སྐབས་ལག་ལེན་འཐབ་འོང་། རྩིས་ཁྲ་དང་འབྲེལ་བའི་ཐོ་བཀོད་འདི་ UAID ལས་ ༡ ཚུན་བཞག་དོ་ཡོདཔ་ལས་ དྭངས་གསལ་ཅན་གྱི་ ངོས་འཛིན་ཚུ་ UAID གྱི་ཐོག་ལས་ མཐུད་སྦྲེལ་འབད་དགོཔ་སྦེ་ དགོཔ་ཨིན་ དེ་ལས་ དྭངས་འཕྲོས་མེད་ཀྱི་ ངོས་འཛིན་འབད་མི་ གཉིས་ཆ་ར་ ཡང་ན་ མགུ་འཐོམ་འགྱོ་མི་ཚུ་ལུ་ ཆ་མེད་གཏང་ནི་ཨིན་མས། [FHE དང་ UAID](/dz/blockchain/sora-nexus-services.md#fhe-and-uaid) ལུ་བལྟ་བ་ཅིན་ Nexus ཞབས་ཏོག་གི་གནས་ཚད་གི་དོན་ལུ་ཨིན།

## རྩིས་ཁྲ་འཛིན་སྐྱོང་པ་ཚུ་ {#account-controllers}

Controller གིས་རྩིས་ཁྲ་གིས་སྤྱོད་ལམ་ཚུ་ ག་དེ་སྦེ་ལག་ལེན་འབད་ནི་ཨིན་ན་ ངེས་འཛིན་འབདཝ་ཨིན། སྔོན་སྒྲིག་ client flow འདི་ Ed25519 key pair ལག་ལེན་འཐབ་དོ་ཡོདཔ་ཨིན་རུང་ data model འདི་ཡང་ multisignature policy controllersབཟུམ་ཅིག་སྦེ་ Richer controllers ཚུ་ རྒྱབ་སྐྱོར་འབད་ཡོདཔ་ཨིན།

སྲིད་འཛིན་གྱི་སྒྲིག་གཞི་གིས་ ལག་ལེན་རྟགས་བཀོད་པའི་དབང་ཤུགས་འདི་ གྲྭ་ཚང་གི་སྒྲིག་གཞི་ལས་སོ་སོར་སྦེ་བཞག་ཡོདཔ་ཨིན།

```toml
[account]
public_key = "ed0120..."
private_key = { digest_function = "ed25519", payload = "..." }
```

ད་ལྟོའི་ལྡེ་མིག་བཟོ་རྣམ་ཚུ་གི་དོན་ལུ་ [ client configure](/dz/guide/configure/client-configuration.md) དང་ [key generation](/dz/guide/security/generating-cryptographic-keys.md) ལུ་བལྟ་དགོ།

## Taira ལུ་ བརྟག་དཔྱད་རྐྱབས། {#try-it-on-taira}

མི་མང་གི་ Taira བརྟག་དཔྱད་དྲ་རྒྱ་ནང་ལས་ ཀ་ནོ་ནི་ཀཱན་གྱི་རྩིས་ཁྲ་ IDs གི་གྲངས་ཉུང་ཅིག་བཏོན་དགོ།

```bash
curl -fsS 'https://taira.sora.org/v1/accounts?limit=5' \
  | jq -r '.items[] | [.id, (.primary_alias // "-")] | @tsv'
```

རྩིས་ཁྲ་གི་ རྒྱུ་དངོས་ཚུ་བརྟག་དཔྱད་འབད་ནིའི་དོན་ལུ་ ཨང་དང་པ་འབོ་པའི་ནང་ལས་ ID རྩིས་ཡིག་འདི་ ཡིག་སྣོད་སྦེ་ བཏོན་ཞིནམ་ལས་ URL-code དེ་ལམ་ནང་བཙུགས་མ་ཚར་བའི་ཧེ་མར་ བཏོན་གཏང་། འ་ནི་ Python ཤོག་ལེབ་འདི་གིས་ ཨང་དང་པ་བཀོད་ཡོད་པའི་རྩིས་ཁྲ་གི་དོན་ལུ་ འདི་འབདཝ་ཨིན།

```bash
python3 - <<'PY'
import json
import urllib.parse
import urllib.request

root = "https://taira.sora.org"
accounts = json.load(urllib.request.urlopen(f"{root}/v1/accounts?limit=1"))["items"]
account_id = accounts[0]["id"]
encoded = urllib.parse.quote(account_id, safe="")
assets = json.load(
    urllib.request.urlopen(f"{root}/v1/accounts/{encoded}/assets?limit=5")
)

print(json.dumps({"account_id": account_id, "assets": assets["items"]}, indent=2))
PY
```

འདི་ཚུ་ མི་མང་གིས་ལྷག་སྟེ་ཡོདཔ་ཨིན། རྩིས་ཁྲ་བཟོ་ནི་དང་ ད་ལྟོའི་གནས་སྟངས་འདི་ ངོ་རྟགས་བཀོད་མི་ཞལ་འདེབས་ཅིག་ཨིནམ་ལས་ Taira སྒྲིག་གཞི་འདི་ [ནང་གསལ་སྟོན་འབད་ཡོད་པའི་ ཐོ་བཀོད་དེ་ དགོཔ་ཨིན། SORA Nexus ཌེ་ཊའི་བེསི་](/dz/get-started/sora-nexus-dataspaces.md) ལུ་འབྲེལ་མཐུད་འབདཝ་ཨིན།

## ཐོ་བཀོད་དང་ ངོས་ལེན་ {#registration-and-permissions}

རྩིས་ཁྲ་ཚུ་ ཐོ་བཀོད་འབད་ནི་དང་ ཐོ་བཀོད་ཀྱི་མ་འབད་མི་འདི་ [`Register` དང་ `Unregister`](/dz/blockchain/instructions.md#un-register) བརྡ་བཀོད་དང་གཅིག་ཁར་ཨིན། རྒྱུགས་རྩེད་དུས་བརྟག་དཔྱད་འཕྲུལ་ཆས་འདི་གིས་ རྩིས་ཁྲལ་བཟོ་ཚུགས་མི་དང་ ངོས་ལེན་རྟགས་མཚན་དང་ འགན་འཁྲི་ཚུ་ ག་དགོཔ་ཨིན་ན་ གྲོས་ཐག་བཅད་འོང་།

ཐོ་བཀོད་ཚར་བའི་ཤུལ་ལས་ རྩིས་ཁྲ་འདི་:

- ཚོང་འབྲེལ་ཚུ་གུ་ མཚན་རྟགས་བཀོད་ནི།
- རྒྱུ་དངོས་ཚུ་བཞག་ནི།
- རང་སོའི་ས་ཁོངས་
- འགན་འཁྲི་དང་ ངོས་ལེན་རྟགས་ཚུ་ཐོབ་ནི་
- གསོག་འཇོག་འབད་ཡོད་པའི་ metadata
- འགན་འཁྲི་མེད་མི་ཅིག་གིས་ Nexus ངོས་འཛིན་གྱི་རྒྱུགས་ཆུའི་ནང་ བཅའ་མར་གཏོགས་ནི་ཨིནམ་ད་ དེ་ཚུ་སེལ་འཐུ་འབད་ཚུགས་ཨིན།

## ངོས་འཛིན་གྱི་གནད་དོན་ཚུ་ སེལ་འཐུ་འབད་ {#troubleshooting-identity-issues}

ཚོང་འབྲེལ་འདི་མ་སྒུག་པར་ ཆ་མེད་གཏང་པ་ཅིན་ ལྟ་རྟོག་འབད་:

- སྒེར་གྱི་ལྡེ་མིག་དེ་ ཐོ་བཀོད་འབད་ནིའི་དོན་ལུ་ ལག་ལེན་འཐབ་མི་སྒེར་གྱི་ལྡི་མིག་དང་འདྲ་ཨིན།
- རྩིས་ཁྲ་འདི་ འབྱུང་གནས་ནང་ ཡང་ན་ ཁས་བླངས་ཅན་གྱི་ཚོང་འབྲེལ་ཐོག་ལས་ ཐོ་བཀོད་འབད་ཡོདཔ་ཨིན།
- ཁྲི་འཛིན་གྱིས་བཀའ་རྒྱ་ནང་ དགོས་མཁོ་ཅན་གྱི་ ངོས་ལེན་ཚུ་ཡོདཔ་ཨིན།
-  strict account fields གིས་ canonical I105 account ID འདི་ལག་ལེན་འཐབ་དོ་ཡོདཔ་ད་ ཀློག་ཚུགས་པའི་མིང་འདི་ active account-alias binding གྱི་ཐོག་ལས་ སེལ་འཐུ་འབད།
