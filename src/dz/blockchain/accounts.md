# རྩིས་ཐོ་ {#accounts}

རྩིས་ཐོ་འདི་ འབྲེལ་གཏད་ལག་ལེན་དང་ རང་སོའི་རྩིས་དེབ་ཀྱི་ གནས་སྟངས་ནང་ ཐོ་བཀོད་འབད་ཚུགས་མི་དབང་འཛིན་ཅིག་ཨིན། ད་ལྟོའི་ Iroha 3 ཌེ་ཊའི་གི་དཔེ་ནང་ལུ་ `AccountId` འདི་ ཀ་ནོ་ནིསི་དང་ དོ་ཡིནམ་མེད་པའི་ཨིན། འདི་རྩིས་ཐོ་འཛིན་སྐྱོང་ལས་བཏོན་ཏེ་ ཀ་ནཱོ་ནིསི་སྦེ་ [I105](/dz/reference/i105.md) ཨིན་པས། མི་གིས་བཀླག་ཚུགས་མི་ ས་ཁོངས་དང་ གནད་སྡུད་ས་ཁོངས་ཀྱི་ གནས་སྟངས་འདི་ རང་སོ་སོ་སྦེ་རྩིས་ཐོ་-མིང་གཞན འབྲེལ་མཐུད་འབད་ནིའི་ནང་ཚུདཔ་ཨིན།

## བཟོ་བཀོད་ {#structure}

ཐོ་བཀོད་འབད་ཡོད་པའི་`Account` ནང་།

- `id`: ཀ་ནོ་ཀཱན་གྱི་ཡིག་ཆ་ `AccountId`
- `metadata`: རང་འདོད་ཅན་གྱི་རྩིས་ཐོ་གི་ མེ་ཊ་ཌའི་ཊཱ།
- `label`: གདམ་ཁ་ཅན་གྱི་གཏན་འཇགས་མིང་གཞན་ཅིག
- `uaid`: Nexus གིས་ལག་ལེན་འཐབ་མི་ གདམ་ཁ་ཅན་གྱི་ཡོངས་ཁྱབ་རྩིས་ཐོའི་ཨའི་ཌི་ཅིག་བཞུར་འགྱོཝ་ཨིན།
- `opaque_ids`:རྩིས་ཐོ་གི་ UAID ལུ་བཅའ་མར་གཏོགས་མི་ དྭངས་འཕྲོས་འཕྲོས་ཅན་གྱི་ངོ་རྟགས་ཚུ་

རྩིས་ཐོ་བཟོ་ནིའི་དོན་ལུ་ལག་ལེན་གྱི་ནང་དོན་གནད་སྡུད་འདི་ `NewAccount`ཨིན། འདི་ནང་ ངོས་འཛིན་, ཟུར་གནས་གནད་སྡུད,ཁ་ཡིག, UAID དང་ དྭངས་གསལ་མེད་མི་ ID ས་སྒོ་ཚུ ལག་ལེན་འཐབ་མི་ ཐོ་བཀོད་འབད་ཡོད་པའི་རྩིས་ཐོ་དེ་ཡང་ཡོདཔ་ཨིན།

`uaid` གིས་ `AccountId` སྒྲིག་གཞི་འདི་ བསྡུ་སྒྲིག་འབདཝ་ཨིན། འདི་གིས་འདི་ཚབ་མ་བཟོཝ་ཨིན། ཁྱོད་ཀྱིས་ Nexus ཞབས་ཏོག་ཚུ་ནང་ ཌེ་ཊ་ས་པི་སི་ཚུ་ནང་ལུ་ ལག་ལེན་འཐབ་མི་ ཡང་ན་ ལས་སྡེ་ཚུ་གི་གནས་བརྟན་ཅིག་ དགོས་མཁོ་ཡོདཔ་ད་ གསང་སྤྱོད་ལུ་སྲུང་སྐྱོབ་འབད་མིའི་ ཐོ་བཀོད་དང་ ཡང་ན་ ཞབས་ཏོག་གི་ནུས་ཤུགས་འཚོལ་བའི་སྐབས་ལག་ལེན་འཐབ་འོང་། རྩིས་ཐོ་དང་འབྲེལ་བའི་ཐོ་བཀོད་འདི་ UAID ལས་ ༡ ཚུན་བཞག་དོ་ཡོདཔ་ལས་ དྭངས་གསལ་ཅན་གྱི་ ངོས་འཛིན་ཚུ་ UAID གྱི་ཐོག་ལས་ མཐུད་སྦྲེལ་འབད་དགོཔ་སྦེ་ དགོཔ་ཨིན་ དེ་ལས་ དྭངས་འཕྲོས་མེད་ཀྱི་ ངོས་འཛིན་འབད་མི་ གཉིས་ཆ་ར་ ཡང་ན་ མགུ་འཐོམ་འགྱོ་མི་ཚུ་ལུ་ ཆ་མེད་གཏང་ནི་ཨིན་མས། [FHE དང་ UAID](/dz/blockchain/sora-nexus-services.md#fhe-and-uaid) ལུ་བལྟ་བ་ཅིན་ Nexus ཞབས་ཏོག་གི་གནས་ཚད་གི་དོན་ལུ་ཨིན།

## རྩིས་ཐོ་འཛིན་སྐྱོང་པ་ཚུ་ {#account-controllers}

ཚད་འཛིན་པ་གིས་ རྩིས་ཐོ་འདི་གིས་ བྱ་བ་ཚུ་ ག་དེ་སྦེ་གནང་བ་བྱིནམ་ཨིན་ན་ ངེས་འཛིན་འབདཝ་ཨིན། སྔོན་སྒྲིག་མཁོ་སྤྲོད་འབད་མི་རྒྱུན་རིམ་འདི་གིས་ Ed25519 ལྡེ་མིག་ཆ་གཅིག་ལག་ལེན་འཐབ་ཨིན་ དེ་འབདཝ་ད་ གནད་སྡུད་དཔེ་ཚད་འདི་གིས་ སྣ་མང་མིང་རྟགས་སྲིད་བྱུས་ཚད་འཛིན་བཟུམ་གྱི་ ཚད་འཛིན་ཕྱུགཔོ་ཚུ་ལུ་ཡང་རྒྱབ་སྐྱོར་འབདཝ་ཨིན།

མཁོ་སྤྲོད་པ་རིམ་སྒྲིག་གིས་ མིང་རྟགས་བཀོད་ནི་གི་དབང་ཚད་འདི་ མཉམ་རོགས་རིམ་སྒྲིག་ལས་སོ་སོ་སྦེ་གསོག་འཇོག་འབདཝ་ཨིན།

```toml
[account]
public_key = "ed0120..."
private_key = { digest_function = "ed25519", payload = "..." }
```

ད་ལྟོའི་ལྡེ་མིག་བཟོ་རྣམ་ཚུ་གི་དོན་ལུ་ [ ཞབས་ཏོག་ལེན་མི རིམ་སྒྲིག་འབད](/dz/guide/configure/client-configuration.md) དང་ [ཨེབ་ལྡེ་མིག་ཚུ་ བཟོ་སྐྲུན་འབདཝ་ཨིན།](/dz/guide/security/generating-cryptographic-keys.md) ལུ་བལྟ་དགོ།

## Taira ལུ་ བརྟག་དཔྱད་རྐྱབས། {#try-it-on-taira}

མི་མང་གི་ Taira བརྟག་དཔྱད་དྲ་རྒྱ་ནང་ལས་ ཚད་ལྡན་གྱི་རྩིས་ཐོ་ IDs གི་གྲངས་ཉུང་ཅིག་བཏོན་དགོ།

```bash
curl -fsS 'https://taira.sora.org/v1/accounts?limit=5' \
  | jq -r '.items[] | [.id, (.primary_alias // "-")] | @tsv'
```

རྩིས་ཐོ་གི་ རྒྱུ་དངོས་ཚུ་བརྟག་དཔྱད་འབད་ནིའི་དོན་ལུ་ ཨང་དང་པ་འབོ་པའི་ནང་ལས་ ID རྩིས་ཡིག་འདི་ ཡིག་སྣོད་སྦེ་ བཏོན་ཞིནམ་ལས་ URL-ལས་རིམ་ཨང་རྟགས དེ་ལམ་ནང་བཙུགས་མ་ཚར་བའི་ཧེ་མར་ བཏོན་གཏང་། འ་ནི་ Python ཤོག་ལེབ་འདི་གིས་ ཨང་དང་པ་བཀོད་ཡོད་པའི་རྩིས་ཐོ་གི་དོན་ལུ་ འདི་འབདཝ་ཨིན།

```bash
python3 - <<'PY'
import json
import urllib.parse
import urllib.request

root = "https://taira.sora.org"
accounts = json.load(urllib.request.urlopen(f"{root}/v1/accounts?limit=1"))["items"]
account_id = accounts[0]["id"]
encoded = urllib.parse.quote(account_id, safe="")
assets = json.load(
    urllib.request.urlopen(f"{root}/v1/accounts/{encoded}/assets?limit=5")
)

print(json.dumps({"account_id": account_id, "assets": assets["items"]}, indent=2))
PY
```

འདི་ཚུ་ མི་མང ཀློག་ལེན ཨིན། རྩིས་ཐོ བཟོ་ནི་ཡང་ན་ དུས་མཐུན འབད་ནི་འདི་ མིང་རྟགས་བཀོད་ཡོད ཚོང་འབྲེལ ཨིནམ་ལས་ [SORA Nexus གནས་སྡུད་བར་སྟོང་ཚུ](/dz/get-started/sora-nexus-dataspaces.md) ནང་བཤད་ཡོད་མི་ བརྟག་དཔྱད་ཊོ་ཀེན་ཞབས་ཏོག-མ་དངུལ་བཙུགས་ཡོདཔ Taira གཞི་སྒྲིག དགོ།

## ཐོ་བཀོད་དང་ ངོས་ལེན་ {#registration-and-permissions}

རྩིས་ཐོ་ཚུ་ ཐོ་བཀོད་འབད་ནི་དང་ ཐོ་བཀོད་ཀྱི་མ་འབད་མི་འདི་ [`Register` དང་ `Unregister`](/dz/blockchain/instructions.md#un-register) བརྡ་བཀོད་དང་གཅིག་ཁར་ཨིན། རྒྱུགས་རྩེད་དུས་བརྟག་དཔྱད་འཕྲུལ་ཆས་འདི་གིས་ རྩིས་ཐོལ་བཟོ་ཚུགས་མི་དང་ ངོས་ལེན་རྟགས་མཚན་དང་ འགན་འཁྲི་ཚུ་ ག་དགོཔ་ཨིན་ན་ གྲོས་ཐག་བཅད་འོང་།

ཐོ་བཀོད་འབད་བའི་ཤུལ་ལས་ རྩིས་ཐོ་ཅིག་གིས་ འདི་བཟུམ་འབད་ཚུགས།

- ཚོང་འབྲེལ་ཚུ་གུ་ མཚན་རྟགས་བཀོད་ནི།
- རྒྱུ་ནོར་འཛིན་པ།
- རང་གི་མངའ་ཁོངས།
- འགན་ཁུར་དང་གནང་བ་རྟགས་མཚན་ཚུ་ཐོབ།
- མེ་ཊ་ཌེ་ཊ་གསོག་འཇོག་འབད།
- འགན་འཁྲི་མེད་མི་ཅིག་གིས་ Nexus ངོས་འཛིན་གྱི་བྱ་རིམའི་ནང་ བཅའ་མར་གཏོགས་ནི་ཨིནམ་ད་ དེ་ཚུ་སེལ་འཐུ་འབད་ཚུགས་ཨིན།

## ངོས་འཛིན་གྱི་གནད་དོན་ཚུ་ སེལ་འཐུ་འབད་ {#troubleshooting-identity-issues}

གལ་སྲིད་ ཚོང་འབྲེལ་ཅིག་ རེ་བ་མེད་པར་ ངོས་ལེན་མ་འབད་བ་ཅིན་ ཞིབ་དཔྱད་འབད།

- མཁོ་སྤྲོད་འབད་མི་མི་མང་ལྡེ་མིག་འདི་ མིང་རྟགས་བཀོད་ནིའི་དོན་ལུ་ལག་ལེན་འཐབ་མི་ སྒེར་གྱི་ལྡེ་མིག་དང་མཐུན་སྒྲིག་འབདཝ་ཨིན།
- རྩིས་ཐོ་འདི་ རིགས་མཚན་ནང་ ཡང་ན་ ཁས་བླངས་ཚོང་འབྲེལ་གྱི་ཐོག་ལས་ ཐོ་བཀོད་འབད་ཡོདཔ་ཨིན།
- དབང་འཛིན་ལུ་ བཀོད་རྒྱ་དང་འཁྲིལ་དགོ་པའི་གནང་བ་ཚུ་ཡོདཔ་ཨིན།
-  དམ་དྲག རྩིས་ཐོ ས་སྒོ་ཚུ གིས་ ཚད་ལྡན I105 རྩིས་ཐོ ID འདི་ལག་ལེན་འཐབ་དོ་ཡོདཔ་ད་ ཀློག་ཚུགས་པའི་མིང་འདི་ ཤུགས་ལྡན རྩིས་ཐོའི་མིང་གཞན མཐུད་སྦྲེལ གྱི་ཐོག་ལས་ སེལ་འཐུ་འབད།
