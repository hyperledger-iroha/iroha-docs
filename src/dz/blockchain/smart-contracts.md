- `Executable::ContractCall`: བཙུགས་ཚར་མི་ ཁག་འབགཔ་ཅིག་ལུ་ བགོ་བཀྲམ་འབད་དགོ་པའི་བརྡ་དོན་གྱི་མིང་།

## རིག་རྩལ་ཅན་གྱི་ཞལ་འཆེས་ཚུ་ ལག་ལེན་འཐབ་དགོ་པའི་དུས་ཚོད་ {#when-to-use-smart-contracts}

གནད་དོན་འདི་ཐད་ཀར་དུ་ གསལ་སྟོན་འབད་ཚུགས་པའི་སྐབས་ སྤྱིར་བཏང་བཀོད་རྒྱ་ཚུ་ལག་ལེན་འཐབ་དགོ།

- ཐོ་བཀོད་འབད་ནི་དང་མ་ཐོ་བཀོད་འབད་མི་ཚུ་
- དངུལ་ཁང་དང་འབྲེལ་བའི་མཐུན་རྐྱེན་ཚུ་
- ད་ལྟོའི་བརྡ་དོན་ཚུ་
- ངོས་ལེན་ཚུ་བྱིན་ནི་དང་ ཆ་མེད་གཏང་ནི་
- གློག་ཐག་ཅིག་བཏོན་
- ལྕགས་ཐག་ནང་གི་ཚད་འཛིན་ཚུ་ གཞི་སྒྲིག་འབདཝ་ཨིན།

ལག་ལེན་འབད་ནིའི་དོན་ལས་ ཌའི་ལོག་གི་ལག་ལེན་འདི་ བསྡུ་སྒྲིག་འབད་དགོ་པའི་ གནད་དོན་ཅིག་ཨིན་རུང་ དེ་ཚུ་ སྒྲིག་འཇུག་གི་རིམ་པ་སྦེ་ གསལ་སྟོན་འབད་ནི་ལུ་ ལཱ་ཁག་འདུག་ཟེར་ཨིནམ་ད་ ཡང་ན་ ལག་ལེན་འཐབ་མི་ལག་ལེན་གྱི་ལག་ལེན་དེ་ ཐོ་བཀོད་ཐོག་ལས་འབོ་དགོཔ་ཨིན།

## IVM བརྩོན་ཤུགས་ཅན་ཚུ་ {#ivm-executables}

`Executable::Ivm` གིས་ raw IVM bytecode འབག་ཡོདཔ་ཨིན། node འདི་ runtime limits གི་ནང་འཁོད་ལུ་ལག་ལེན་བསྟར་སྤྱོད་འབདཝ་ཨིན། བའི་ཊི་ཀོ་ཌ་འདི་ཆུང་དྲགས་སྦེ་དང་ deterministicསྦེ་བཞག་དོ་ཡོདཔ་ད་ རིན་བསྡུར་འབད་མི་ཚུ་ཡང་ transaction execution གི་ཆ་ཤས་ཅིག་ཨིནམ་ལས་ འདི་འབདཝ་ལས་ consensus ལུ་ གནོད་སྐྱོན་རྐྱབ་ཨིན།

`Executable::IvmProved` འདི་ བརྟག་དཔྱད་འབད་ནིའི་དོན་ལུ་ཨིན། འདི་ནང་ལུ་:

- IVM བའི་ཊི་ཀོཌ་
- deterministic instruction overlay འདི་
- འཁྲུན་ཆོད་ཚུ་དང་འབྲེལ་བའི་ ཁས་བླངས་
- ས་སྣུམ་གྱི་ སྲིད་བྱུས་ཀྱི་ ཁས་བླངས་

ཐུབ་སྟོན་འདི་གིས་ བའི་ཊི་ཀོཌ་ལག་ལེན་འབད་མི་འདི་ལུ་ གྱལ་ཁུག་བསྡུགསཔ་ཨིན། pipeline སྲིད་བྱུས་དང་འཁྲིལ་ཏེ་ validatorཚུ་གིས་ ཐུབ་སྟོན་དང་ལོག་བསྐྱར་བཟོའི་ལག་ལེན་དེ་ ཉེན་སྲུང་གི་བརྟག་དཔྱད་གཞན་ཅིག་སྦེ་ བརྟག་ཞིབ་འབད་ནི་ཨིན།

## གླ་འཐུས་གྱི་ཅ་ལ་ཚུ་ བཏོན་གཏང་ནི། {#deployed-contract-calls}

`Executable::ContractCall` གིས་ཁ་བྱང་གི་ཐོག་ལས་ལག་ལེན་འཐབ་མི་གན་རྒྱ་ཡིག་ཆའི་ལེའུ་ཅིག་ བཏོན་དོ་ཡོདཔ་ཨིན། གན་རྒྱ་ཡིག་རྟགས་འདི་སོ་སོར་སྦེ་ ཐོ་བཀོད་འབད་ཞིནམ་ལས་ ཕྱིར་ཚོང་འཐབ་མི་ཚུ་ལུ་ བི་ཊ་ཀོ་ཌ་དེ་ཨ་རྟག་རང་འབག་མ་བཞག་པར་ བི་ཊར་ཀོཌ་གི་ཐོག་ལས་འབོ་དགོཔ་ཨིན།

## ལས་འཛིན་གྱི་ལམ་སྟོན་ཚུ་ {#operational-guidance}

- གྲོས་ཆོད་ཚུ་ ངེས་གཏན་སྦེ་བཞག་ནི། གྲོས་ཆོད་ཀྱི་སྤྱོད་ལམ་འདི་ ས་གནས་ཀྱི་ Wall-clock དུས་ཚོད་དང་ host filesystem state དེ་ལས་ network calls ཡང་ན་ peer-local inputs ཚུ་ལས་བརྟེན་མི་དགོ།
- ཁེ་ཕན་གྱི་ཅ་ལ་ཚུ་ ཉམ་ཆུང་སྦེ་བཞག་དོ་ཡོདཔ་ཨིན། བའི་ཊི་ཀོཌ་སྦོམ་ཅིག་གིས་ ཕྱིར་ཚོང་གི་རྒྱ་ཁྱོན་དང་ ཨེབ་གཏང་ཀྱི་གོང་ཚད་ཡར་སེང་འགྱོ་དོ་ཡོདཔ་ཨིན།
- ཐོ་བཀོད་འབད་ནིའི་བསླབ་བྱ་འདི་ ལེ་ཌཇར་ལུ་འགྱུར་བཅོས་འབད་ནིའི་དོན་ལུ་ གདམ་ཁ་རྐྱབ་ཨིན། འདི་ཚུ་ དབྱེ་ཞིབ་འབད་ནི་འཇམ་ཏོང་ཏོ་དང་ ལག་ལེན་འཐབ་ནི་ལུ་ ཟད་འགྲོ་ཕོགཔ་ཨིན།
- ཟད་འགྲོ་བཏང་ནི་དང་ ཐོ་བཀོད་འབད་ནིའི་ཆོག་ཐམ་ཚུ་ ཉེན་ཁ་ཅན་གྱི་ལག་ལེན་གྱི་ལམ་ལུགས་ཅིག་སྦེ་ ལག་ལེན་འཐབ་དགོ།
