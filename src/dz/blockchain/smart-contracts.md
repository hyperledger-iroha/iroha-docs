## རིག་རྩལ་ཅན་གྱི་ཞལ་འཆེས་ཚུ་ ལག་ལེན་འཐབ་དགོ་པའི་དུས་ཚོད་ {#when-to-use-smart-contracts}

- མིན་ཊི་ མེ་བཏང་ ཡང་ན་ རྒྱུ་ནོར་སྤོ་བཤུད།
- མེ་ཊ་ཌེ་ཊ་དུས་མཐུན་བཟོ།
- གནང་བ་སྤྲོད་ནི་ཡང་ན་ཆ་མེད་གཏང་ནི།

- རིམ་སྒྲིག་ཚད་གཞི་ཚུ་གཞི་སྒྲིག་འབད།

ཚོང་འབྲེལ་འདི་ལུ་ གནས་སྟངས་བཀོད་རྒྱ་གོ་རིམ་སྦེ་གསལ་བཀོད་འབད་ནི་ལུ་ མ་བདེཝ་ཡོད་པའི་ ཐུམ་སྒྲིལ་ཚད་མ་དགོཔ་ཨིན་པ་ཅིན་ ཡང་ན་ བཀྲམ་སྤེལ་འབད་ཡོད་པའི་གན་རྒྱ་གི་དཔེ་ཚད་འདི་ གཞི་བསྟུན་གྱི་ཐོག་ལས་ འབོ་དགོཔ་ད་ རིག་པ་ཅན་གྱི་གན་རྒྱ་ལག་ལེན་འཐབ།

གློག་རིམ་ API ལྕོགས་ཅན་བཟོ་བའི་སྐབས་ `GET /v1/gov/contracts/{contract_address}` དང་ཅིག་ཁར་ བཀག་བཞག་ཡོད་པའི་གནས་སྟངས་འདི་ལྷག། དེ་གི་ `found` ས་སྒོ་འདི་གིས་ ཁ་བྱང་འདི་ལུ་ད་ལྟོ་ཤུགས་ལྡན་ཨང་རྟགས་ཡོདཔ་སྦེ་མེན།

## ལས་འཛིན་གྱི་ལམ་སྟོན་ཚུ་ {#operational-guidance}

- གྲོས་ཆོད་ཚུ་ ངེས་གཏན་སྦེ་བཞག་ནི། གྲོས་ཆོད་ཀྱི་སྤྱོད་ལམ་འདི་ ས་གནས་ཀྱི་ དུས་ཚོད་ངོ་མ དུས་ཚོད་དང་ མགྲོན་སྐྱོང་གློག་འཕྲུལ ཡིག་སྣོད་རིམ་ལུགས གནས་སྟངས དེ་ལས་ དྲ་རྒྱ ལས་རིམ་འབོད་ཚུ ཡང་ན་ མཉམ་རོགས-ས་གནས ནང་འཇུག ཚུ་ལས་བརྟེན་མི་དགོ།
- ནང་དོན་གནད་སྡུད་གྱི་ཅ་ལ་ཚུ་ ཉམ་ཆུང་སྦེ་བཞག་དོ་ཡོདཔ་ཨིན། བའི་ཊི་ཀོཌ་སྦོམ་ཅིག་གིས་ ཕྱིར་ཚོང་གི་རྒྱ་ཁྱོན་དང་ ཨེབ་གཏང་ཀྱི་གོང་ཚད་ཡར་སེང་འགྱོ་དོ་ཡོདཔ་ཨིན།
- རྩིས་ཐོ་བསྒྱུར་བཅོས་འཇམ་ཏོང་ཏོ་ཚུ་གི་དོན་ལུ་ ཡིག་དཔར་རྐྱབ་ཡོད་པའི་བཀོད་རྒྱ་ཚུ་དགའ་གདམ་འབད། དེ་ཚུ་ རྩིས་ཞིབ་འབད་ནི་ལུ་འཇམ་ཏོང་ཏོ་དང་ ལག་ལེན་འཐབ་ནི་ལུ་ ཁེ་ཏོག་ཏོ་ཡོདཔ་ཨིན།
- ཟད་འགྲོ་བཏང་ནི་དང་ ཐོ་བཀོད་འབད་ནིའི་ཆོག་ཐམ་ཚུ་ ཉེན་ཁ་ཅན་གྱི་ལག་ལེན་གྱི་ལམ་ལུགས་ཅིག་སྦེ་ ལག་ལེན་འཐབ་དགོ།
