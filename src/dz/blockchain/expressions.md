# གསུངས་ཚིག་དང་ གནས་སྟངས་ དེ་ལས་ མནོ་བསམ་གཏང་ཐངས་ {#expressions-conditionals-logic}

[Iroha དམིགས་བསལ་བསླབ་བྱ་ཚུ་ ](./instructions.md) གིས་ གསལ་སྟོན་ཚུ་གུ་ལཱ་འབད་ཡོདཔ་ཨིན། གསལ་བཤད་རེ་རེ་ལུ་ `EvaluatesTo` ཡོད་པའི་ཁར་ འདི་ཡང་བཀོད་རྒྱ་ལག་ལེན་ནང་ལུ་ ལག་ལེན་འཐབ་ཨིན། ཁྱོད་ཀྱིས་རྩིས་མིང་འདི་ ཐད་ཀར་དུ་གསལ་སྟོན་འབད་ཚུགས་རུང་ ཁྱོད་ཀྱིས་རྩིས་དང་ཡང་ན་ཐིག་ཕྲ་ལག་ལེན་གྱི་ཐོག་ལས་རྩིས་ ID ཡང་གསལ་སྟོན་འབད་ཚུགས། ཁྱོད་ཀྱིས་ ཐོ་བཀོད་འབད་ཡོད་པའི་རྩིས་ཁྲ་དེ་ཡང་ བཀྲིས་སྒང་ནང་ཡོད་མེད་ བལྟ་ཚུགས།

ཁྱོད་ཀྱིས་ `EvaluatesTo<bool>` ལག་ལེན་འཐབ་པའི་བརྡ་དོན་ཚུ་ལག་ལེན་འཐབ་ཐོག་ལས་ གནས་སྟངས་ཀྱི་ མནོ་བསམ་གཏང་ནི་དང་ ལྕགས་ཐག་ནང་ལུ་ བྱ་སྒོ་ཁག་ཆེ་ཤོས་ཅིག་འབད་ཚུགས། དཔེར་ན་ ཁྱོད་ཀྱིས་ `Mint` གི་བསླབ་བྱ་འདི་ ཐོ་བཀོད་འབད་བ་ཅིན་རྐྱངམ་གཅིག་ འབྲི་ཚུགས།

འདི་གི་སྐོར་ལས་ དྲི་བ་ཚུ་དང་བསྡོམས་ཏེ་ བཀྲམ་སྤེལ་འབད་ཚུགས་ཟེར་ དྲན་པ་བཏོན་གཏང་དགོ་ དེ་བཟུམ་སྦེ་ བཀྲ་སྤེལ་གྱི་ལཱ་ཚུ་ཡང་ ཧ་ལས་པའི་ལཱ་ཚུ་འབད་ནི་ལུ་ བཀྲམ་སྟོན་ཚུགསཔ་ཨིན། འདི་གི་དོན་ལུ་ ང་བཅས་ཀྱིས་ རིག་རྩལ་ཅན་གྱི་འཆམ་ཡིག་ཅིག་ཟེར་སླབ་དོ་ཡོདཔ་ད་ འདི་གིས་ བཀྲ་སྒེལ་གི་ འཕྲུལ་རིག་ལག་ལེན་འཐབ་ཐངས་ཡར་རྒྱས་འགྱོ་མིའི་ ཁྱད་ཆོས་ངོ་མ་ཅིག་ཨིན་མས།
