# གསུངས་ཚིག་དང་ གནས་སྟངས་ དེ་ལས་ མནོ་བསམ་གཏང་ཐངས་ {#expressions-conditionals-logic}

[Iroha དམིགས་བསལ་བསླབ་བྱ་ཚུ་ ](./instructions.md) གིས་ གསལ་སྟོན་ཚུ་གུ་ལཱ་འབད་ཡོདཔ་ཨིན། གསལ་བཤད་རེ་རེ་ལུ་ `EvaluatesTo` ཡོད་པའི་ཁར་ འདི་ཡང་བཀོད་རྒྱ་ལག་ལེན་ནང་ལུ་ ལག་ལེན་འཐབ་ཨིན། ཁྱོད་ཀྱིས་རྩིས་མིང་འདི་ ཐད་ཀར་དུ་གསལ་སྟོན་འབད་ཚུགས་རུང་ ཁྱོད་ཀྱིས་རྩིས་དང་ཡང་ན་ཐིག་ཕྲ་ལག་ལེན་གྱི་ཐོག་ལས་རྩིས་ ID ཡང་གསལ་སྟོན་འབད་ཚུགས། ཁྱོད་ཀྱིས་ ཐོ་བཀོད་འབད་ཡོད་པའི་རྩིས་ཐོ་དེ་ཡང་ བཀྲིས་སྒང་ནང་ཡོད་མེད་ བལྟ་ཚུགས།

`EvaluatesTo<bool>` ལག་ལེན་འཐབ་མི་ གསལ་བརྗོད་ཚུ་ལག་ལེན་འཐབ་ཐོག་ལས་ ཁྱོད་ཀྱིས་ གནས་སྟངས་ཚད་མ་གཞི་སྒྲིག་འབད་ཚུགས་ནི་དང་ རིམ་སྒྲིག་གུ་ལུ་ མགུ་རྙོག་དྲགས་ཅན་གྱི་བཀོལ་སྤྱོད་ཚུ་ ལག་ལེན་འཐབ་ཚུགས། དཔེར་ན་ ཁྱོད་ཀྱིས་ དམིགས་བསལ་གྱི་རྩིས་ཐོ་ཅིག་ཐོ་བཀོད་འབད་དེ་ཡོད་པ་ཅིན་རྐྱངམ་ཅིག་ `Mint` བཀོད་རྒྱ་ཅིག་ཕུལ་ཚུགས།

འདི་གི་སྐོར་ལས་ དྲི་བ་ཚུ་དང་བསྡོམས་ཏེ་ བཀྲམ་སྤེལ་འབད་ཚུགས་ཟེར་ དྲན་པ་བཏོན་གཏང་དགོ་ དེ་བཟུམ་སྦེ་ བཀྲ་སྤེལ་གྱི་ལཱ་ཚུ་ཡང་ ཧ་ལས་པའི་ལཱ་ཚུ་འབད་ནི་ལུ་ བཀྲམ་སྟོན་ཚུགསཔ་ཨིན། འདི་གི་དོན་ལུ་ ང་བཅས་ཀྱིས་ རིག་རྩལ་ཅན་གྱི་འཆམ་ཡིག་ཅིག་ཟེར་སླབ་དོ་ཡོདཔ་ད་ འདི་གིས་ བཀྲ་སྒེལ་གི་ འཕྲུལ་རིག་ལག་ལེན་འཐབ་ཐངས་ཡར་རྒྱས་འགྱོ་མིའི་ ཁྱད་ཆོས་ངོ་མ་ཅིག་ཨིན་མས།
