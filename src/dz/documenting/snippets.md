## རིག་རྩལ་གསརཔ་ཚུ་ Iroha {#refreshing-iroha-artifacts}

Iroha-བཏོན་ཡོད ཡིག་དུམ ཚུ་ བརྟག་ཞིབ་འབདཝ་ལས་ སྤྱིར་བཏང་ས་ཁོངས་བཟོ་བསྐྲུན་ཚུ་ལུ་ ཡོངས་འབྲེལ་འཛུལ་སྤྱོད་ཡང་ན་ སྤུན་ཆའི་མཛོད་ཁང་དགོཔ་མེདཔ་ཨིན། དེ་ཚུ་གསལ་ཏོག་ཏོ་སྦེ་གསར་བསྐྲུན་འབད།

```bash
pnpm refresh:iroha --source /path/to/iroha
```
