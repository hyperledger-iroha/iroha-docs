# ཀོ་ཌ་ ཤོག་ལེབ་ཚུ་ {#code-snippets}

བཟོ་སྐྲུན་འབད་ཡོད་པའི་ ཨེབ་ལྡེ་ཚུ་ ཀི་ཌོག་གི་ཨེབ་ལྡེ་དང་ བསྡུ་སྒྲིག་ དེ་ལས་ ལེགས་བསྒྱུར་འབད་མི་ Iroha ལས་ དཔེ་སྟོན་ཚུ་བཟུང་སྟེ་བཞག་ཡོདཔ་ཨིན།

## རིག་རྩལ་གསརཔ་ཚུ་ Iroha {#refreshing-iroha-artifacts}

Iroha ལས་འབྱུང་འོང་མི་ ཨེབ་ལྡེ་ཚུ་ སྤྱིར་བཏང་གི་ས་ཁོངས་བཟོ་སྐྲུན་ནང་ལུ་ བརྟག་ཞིབ་འབདཝ་ཨིན། འདི་གི་དོན་ལུ་ འབྲེལ་མཐུད་འབད་ནིའི་དོན་ལས་ ཡང་ན་ སྤུན་ཆ་ཡིག་མཛོད་མ་དགོཔ་ཨིན། དེ་དག་ལུ་ གསལ་ཏོག་ཏོ་སྦེ་ གསར་བསྐྲུན་འབད་:

```bash
pnpm refresh:iroha --source /path/to/iroha
```

ཐོ་བཀོད་འབད་མི་ [`etc/refresh-iroha.ts`](https://github.com/hyperledger-iroha/iroha-docs/blob/main/etc/refresh-iroha.ts) སྒྲིག་འཇུག་ཐོ་བཀོད་འདི་གཙང་མ་ཐོན་ཁུངས་གི་རྒྱབ་སྐྱོར་ལུ་བརྟག་དཔྱད་འབདཝ་ཨིན། `provenance/iroha.json`, སླར་ལོག་འབདཝ་ཨིན། `/src/snippets` དེ་ལས་ Torii OpenAPI གློག་བརྙན་དང་ ད་ལྟོའི་གནས་སྟངས་ཚུ་ SHA-256 hashes ཚུ་ བསྐྱར་ཞིབ་འབད་དོ་ཡོདཔ་ཨིན། ནང་དོན་དང་འབྱུང་ཁུངས་ཀྱི་འགྱུར་བཅོས་ཚུ་མཉམ་བསྡོམས་འབདཝ་ཨིན། རང་བཞིན་གྱི་འབྲེལ་བ་གཞི་བཙུགས་འབད་ནི་དང་ VitePress བཟོ་སྐྲུན་གྱིས་ ཡིག་སྣོད་ཚུ་ བསྒྱུར་བཅོས་འབད་ཚུགས་པའི་ ཡན་ལག་མ་ལེན་པར་ ཟད་འགྲོ་གཏང་དོ་ཡོདཔ་ཨིན།
