# གནས་སྡུད་བཟོ་རྣམ་ {#data-modeling}

Ledger ཌའི་ཊ་ཚུ་ བདག་དབང་དང་ བསྒྱུར་བཅོས་འབད་ནིའི་ སྤྱོད་ལམ་ དེ་ལས་ ངོས་ལེན་གྱི་ས་མཚམས་ དེ་ལས་ དྲི་བཀོད་གི་རྣམ་གཞག་ཚུ་གི་མཐའ་འཁོར་ལུ་ བཟོ་དགོཔ་ཨིན། འཛིན་སྐྱོང་ཐིག་ནང་ལུ་ ཉུང་ཆུང་ཤོས་ཅིག་ གདམ་ཁ་རྐྱབས་ནི་འདི་གིས་ དབྱེ་ཞིབ་འབད་ནི་དང་ ཐད་ངེས་ཅན་གྱི་ལག་ལེན་འཐབ་ནི་ལུ་ རྒྱབ་སྐྱོར་འབད་ཚུགས།

## ས་ཁོངས་དང་རྩིས་ཁྲ་ཚུ་ {#domains-and-accounts}

- ས་ཁོངས་ཚུ་ ལག་ལེན་འཐབ་སྟེ་ འཛིན་སྐྱོང་དང་ སྲིད་བྱུས་ཀྱི་མཐའ་མཚམས་ཚུ་ ངོ་ཚབ་སྦེ་བཟོ། ས་ཁོངས་གི་མིང་ཚུ་ སྒྲིང་སྒྲི་སྦེ་བཞག་དགོ་ ག་ཅི་འབད་ཟེར་བ་ཅིན་ ཁོང་གིས་རྩིས་ཁྲ་དང་ རྒྱུ་དངོས་ངོ་རྟགས་ཚུ་ནང་ལུ་མཐོང་ཡོདཔ་ཨིན།
- རང་རྐྱང་གི་རྩིས་ཁྲ་ཅིག་ལུ་ འགན་ཁུར་དང་འབྲེལ་བ་མེདཔ་སྦེ་ མཚམས་འཇོག་མ་འབད། ལག་ལེན་པ་ཚུ་གི་དོན་ལུ་ སྒེར་གྱི་རྩིས་ཁྲ་སོ་སོ་ལག་ལེན་འཐབ་། ཞབས་ཏོག་ཚུ་དང་ གློ་བུར་སྤྱོད་འབད་མི་ཚུ་ དེ་ལས་ རྩིས་ཁྲ་རྒྱབ་སྐྱོར་འབད་མི་གི་དོན་ལུ་ སྒེར་གྱི་ཡིག་ཆ་སོ་སོ་ལག་ལེན་འཐབ་དགོ།
- སྒྲིག་གཞི་དང་བརྟག་དཔྱད་ཚུ་ནང་ལུ་ ཀ་ནོ་ནི་ཀཱན་གྱི་རྩིས་ཁྲ་དང་ ས་ཁོངས་ངོ་རྟགས་ཚུ་ལག་ལེན་འཐབ་ཨིན། Iroha མིང་འདི་ ཀ་ནོའི་ཀཱ་ནོ་ནིཀཱན་གྱི་ བརྟག་ཞིབ་འབད་བའི་ཤུལ་ལུ་ གནད་དོན་ཚུ་ལུ་ གནོདཔ་བཀལ་དོ་ཡོདཔ་ཨིན།
- བརྟག་དཔྱད་དང་ བཟོ་སྐྲུན་གྱི་ ངོ་རྟགས་ཚུ་ མིང་, domain དང་ configure file paths ལུ་མཐོང་ཚུགསཔ་སྦེ་དབྱེ་ཞིབ་འབད་དགོཔ་ཨིན།

## རྒྱུ་དངོས་དང་ NFTs {#assets-and-nfts}

- ཨང་གྲངས་ཀྱི་རྒྱུ་དངོས་ཚུ་ ལག་ལེན་འཐབ་ནི་ Fungible Balances དང་ Transferable Quantities གི་དོན་ལུ་ཨིན།
- NFTs ཡང་ན་ domain-specific ობიექტიཚུ་ ལག་ལེན་འཐབ་ནི་ རང་རྐྱང་གི་བདག་འཛིན་གྱི་ཐོ་ཡིག་ཚུ་གི་དོན་ལུ་།
- གནས་གོང་ཅན་གྱི་གནས་སྟངས་འདི་ metadataནང་ལུ་རྐྱངམ་ཅིག་ ཨེན་ཀོ་ཌ་འབད་ནི་སྤར་གཏང་། རྒྱུ་དངོས་དང་ NFTs གིས་ མི་ཚེ་འཁོར་གྱི་བྱུང་རྐྱེན་ཚུ་ རྒྱུན་འགྲུལ་འཐབ་ནི་ དེ་ལས་ semantics བཏང་ནི་དང་ ངོས་ལེན་བརྟག་དཔྱད་འབད་དོ་ཡོདཔ་ད་ metadata འདི་མ་འབདཝ་ཨིན་མས།
- ཅ་དངོས་ཚུ་ལག་ལེན་གྱི་དོན་ལུ་ ཁྱབ་སྤེལ་མ་འབད་བའི་ཧེ་མར་ དབྱེ་ཞིབ་དང་ གྲོང་གསེབ་གི་ སྲིད་བྱུས་དང་ དངུལ་ཁང་གི་འགན་ཁུར་ དེ་ལས་ མེ་རླུང་རྒྱ་རྫི་/མེ་ཏིག་གི་དབང་འཛིན་ཚུ་ ངེས་གཏན་བཟོ་ནི།

མཐོང་དགོ་ [རྒྱུ་དངོས་ཚུ་](/dz/blockchain/assets.md), [NFTs](/dz/blockchain/nfts.md), དང་ [RWAs](/dz/blockchain/rwas.md).

## གཞི་རྟེན་འབྱུང་ཁུངས་ {#metadata}

- ཐོ་བཀོད་ཐོ་ཡིག་གི་དངོས་ཆས་ཚུ་གི་དོན་ལུ་ metadata ལག་ལེན་འཐབ་ནི་ དཔེར་ན་ Labels, integration IDs, policy flags, hashes, URIs ཡང་ན་ content-addressed referencesཚུ་ཨིན།
- metadata key འདི་བརྟན་ཏོག་ཏོ་དང་ ཡིག་ཐོག་སྦེ་བཞག་ནི། ཀི་ལེནཌ་གི་མིང་འདི་བསྒྱུར་བཅོས་འབད་ཞིནམ་ལས་ client དེ་ཚུ་གུ་བཅའ་མར་གཏོགས་པའི་ཤུལ་ལུ་ གནས་སྤོ་དཀའ་ངལ་འབྱུང་འོང་།
- ཡིག་ཆ་སྦོམ་དང་ ཐོ་བཀོད་ཐོ་ཡིག་ དེ་ལས་ རང་སོའི་ལག་ལེན་འཐབ་མི་གི་ གནད་དོན་ཚུ་ ཡང་ན་ གནས་སྡུད་ཀྱི་གནས་ཚད་མཐོ་ཤོས་ལུ་ ཐད་ཀར་དུ་ metadata ནང་མ་བཞག་ပါ။
- གནས་སྡུད་ཚུ་ འབྲེལ་མཐུད་འབད་མ་བཏུབ་པའི་ གནས་སྡུད་ལུ་ བཏོན་པ་ཅིན་ དབྱེ་ཞིབ་འབད་ཚུགས་མི་ གནས་སྡུད་ཅིག་ དཔེར་ན་ Content hash འདི་ གཏང་དགོ། URI, SoraFS ཐབས་ལམ་, མངོན་གསལ་ཁ་ཐོ་བཀོད་འབད་ནི་དང་ ཡང་ན་ ཁས་བླངས་ཀྱི་སྒོ་ལས་ཨིན།

## ཐོ་བཀོད་དང་འཁྲིལཝ་ད་ བཟོ་རྣམ་དང་འཁྲིལ་ཏེ་ {#permissions-by-model}

- ཚོང་འབྲེལ་གྱི་ལཱ་ཚུ་གི་མཐའ་འཁོར་ལུ་ བཟོ་བཀོད་གི་འགན་ཁུར་འདི་ ལག་ལེན་འཐབ་ནིའི་གོ་སྐབས་ཀྱི་མཐའ་འཁོར་ལུ་མེན། ལཱ་དང་ཞབས་ཏོག་གི་མིང་བཏགས་མི་ འགན་ཁུར་དེ་ འཕྲུལ་རིག་གི་ལྕོགས་གྲུབ་སྦོམ་ཡོད་མི་ལས་ དབྱེ་ཞིབ་འབད་ནི་འཇམ་ཏོང་ཏོ་ཨིན།
- སྒྲིག་འཇུག་ཐོ་བཀོད་འབད་ནིའི་ གོ་སྐབས་གི་རྟགས་མཚན་ཚུ་ ལས་རིམ་ནང་ གྲུབ་འབྲས་བཏོན་མི་ འདྲ་མཉམ་ཆུང་ཤོས་ལུ་ བཏོན་གཏང་།
- Mining, burning, peer management, executor changes, trigger management, and metadata mutation གི་དོན་ལུ་ ངོས་ལེན་ཚུ་ནང་ལུ་ གནོད་འགེལ་སྦོམ་ཡོད་པའི་ ངོས་ལེན་ཅིག་སྦེ་བརྩི་དགོ།
- གནས་སྐབས་ཀྱི་ ངོས་ལེན་ཚུ་གི་དོན་ལུ་ གསལ་ཏོག་ཏོ་སྦེ་ ཆ་མེད་གཏང་ནི་དང་ བསྒྱུར་བཅོས་འབད་ནི་གི་ བྱ་རིམ་ཚུ་ ཁ་སྐོང་རྐྱབས།

## དྲི་བཀོད་གི་རྣམ་གཞག་ {#query-shape}

- ངོས་འཛིན་དང་ metadataལྡེ་མིག་ཚུ་ གདམ་ཁ་རྐྱབས་ཏེ་ ཁྱོད་ཀྱི་ལག་ལེན་ལུ་ མང་ཤོས་ར་ དགོས་མཁོ་ཡོད་མི་དྲི་བ་ཚུ་ རྒྱབ་སྐྱོར་འབད་འོང་།
- གྲུབ་འབྲས་ཀྱི་ཐོ་བཀོད་རྒྱ་ཆེ་ཏོག་ཏོ་ཚུ་ བསྡུ་སྒྲིག་འབད་ཞིནམ་ལས་ ལག་ལེན་འཐབ་མི་ཡིག་ལྟེ་ཚུ་ བཀག་ཆ་འབད་དོ་ཡོདཔ་ད་ སྤྱིར་བཏང་ལག་ལེན་ཚུ་གི་དོན་ལུ་ ཐོ་བཀོད་མ་བཏུབ་པའི་ ལྡོག་ཕྱོགས་རྩིས་དཔྱད་ཚུ་ དགོཔ་ཨིན།
- ཐོ་བཀོད་འབད་མ་བཏུབ་པའི་ ཌའི་ལོག་ཚུ་ ལེ་ཇར་གི་ གནད་སྡུད་དང་བྱུང་རྐྱེན་ཚུ་ལས་ བཟོ་སྐྲུན་འབད་ཚུགསཔ་སྦེ་ བཞག་ནི་ འདི་ཡང་ གལ་གནད་ཅན་གྱི་ ལག་ལེན་སྤྱོད་ལམ་གྱི་དོན་ལུ་ ལག་ལེན་འཐབ་ཨིན།
