# མཐུན་རྐྱེན་ཚུ་ལག་ལེན་འཐབ་ནི་ {#network-deployment}

ཁྱོད་ཀྱིས་ Iroha ネットワークའདི་ མཉམ་འབྲེལ་ཅན་གྱི་ལམ་ལུགས་ཅིག་སྦེ་ལག་ལེན་འབད་དགོཔ་ཨིན། བརྟག་ཞིབ་འབད་མི་ཚུ་གིས་ སྒྲིག་གཞི་ཚུ་འགོ་འདྲེན་འཐབ་ནི་དང་ མཇུག་བསྡུ་ནི་མ་འགོ་བཙུགས་པའི་ཧེ་མ་ འབྱུང་ཁུངས། ཐོ་བཀོད་ཐངས་དང་ བློ་གཏད་ཚུགས་མི་མཉམ་རུབ་ དེ་ལས་ གྲོས་ཆོད་དང་འབྲེལ་བའི་སྒྲིག་གཞི་ཚུ་གི་སྐོར་ལས་ གྲོས་བསྟུན་འབད་དགོ་འོང་།

## མཐའ་འཁོར་གནས་སྟངས་ཀྱི་དབྱེ་བ་ {#environment-separation}

- ས་གནས་གོང་འཕེལ་གྱི་དོན་ལུ་ ཁྱད་སོ་སོ་སྦེ་ བསྡུ་སྒྲིག་འབད་ཡོད་པའི་སྦ་སྒོར་ཚུ་ བཞག་དགོཔ། དབྱེ་ཁག་ཅན་གྱི་བརྟག་དཔྱད་དྲ་རྒྱུགས་དང་ སྒྲིག་གཞི་བཟོ་ནི་དང་ བཟོ་སྐྲུན་འབད་ནི་ཚུ་ འབད།
- ཕྱིར་བཏོན་བཏུབ་མི་ གནས་སྟངས་རེ་རེའི་དོན་ལུ་ ཀི་མིག་གསརཔ་བཟོ། བཟོ་སྐྲུན་ནང་ལུ་ localnet ཡང་ན་ Taira ཀི་མིག་གི་ཅ་ཆས་ཚུ་ ལོག་ལག་ལེན་འཐབ་ནི་མི་འོང་།
- འདྲན་འདྲ་བཟོ་རྣམ་དང་ client config ཡི་གུ་བཀོད་མི་ genesis དང་ scripts དེ་ལས་ deployment notes འདི་ཚུ་ versioned release artifactསྦེ་གཅིག་ཁར་བཞག་དགོ།
- སྒེར་གྱི་ལྡེ་མིག་ཚུ་ གསོག་འཇོག་འབད་སའི་ གནས་ཁང་དང་ བཙུགས་ནི་གི་ ཐོ་བཀོད་ཚུ་ནང་ལས་ཕྱི་ཁར་བཞག་ནི།

[དྲ་ལམ་ལག་ལེན་གྱི་ལྡེ་མིག་ཚུ་ ](/dz/guide/configure/keys-for-network-deployment.md)བལྟ་དགོ།

## འབྱུང་ཁུངས་དང་ གནས་གོང་རིག་པ་ {#genesis-and-topology}

- འ་ནི་བརྟག་དཔྱད་འབད་མི་ཆ་མཉམ་ལུ་ ཐོ་བཀོད་ཅན་གྱི་འབྱུང་ཁུངས་ཀྱི་ལག་ལེན་དང་ དངོས་པོ་གི་མཐུན་རྐྱེན་ཚུ་ ལག་ལེན་འཐབ་བཅུགཔ་ཨིན། འདི་ཡང་ དངོས་པོ་འདི་ དགོས་མཁོ་ཡོད་པའི་སྐབས་ལུ་ ཆ་འཇོག་གྲུབ་མི་ ཌོག་ཊར་དང་ དངོས་འཛིན་ཅན་ཚུ་གིས་ ལག་ལེན་འཐབ་དགོ།
- Byzantine-fault-tolerant deployment གི་དོན་ལུ་ ཉུང་ཤོས་རང་ validator བཞི་ཅིག་ལག་ལེན་འཐབ་དགོ།
- བལྟ་བཤལཔ་ཚུ་གིས་ ཚོགས་རྒྱན་བཙུགས་ནི་དང་ གྲོས་འཆར་བཀོད་ནི་ ཡང་ན་བསྡུ་ལེན་འབད་ནི་མེད་རུང་ ཁོང་རང་གིས་ གནས་སྡུད་དང་ བཀྲམ་སྤེལ་འབད་ཐངས་ དེ་ལས་ ཡོངས་འབྲེལ་ bandwidth ལག་ལེན་འཐབ་དོ་ཡོདཔ་ཨིན།
- འབྱུང་ཁུངས། བསྒྱུར་བཅོས་འབད་ཐངས་དང་ ཐོ་པོ་ལཱསི་ཚུ་ གཅིག་ལས་གཅིག་བསྒྱུར་བཅོས་མ་འབད་བར་ གནས་སྤོ་སོར་གྱི་གནས་སྟངས་ཅིག་སྦེ་ ལག་ལེན་འཐབ་དགོ།

[འ་ནི་ལས་འགོ་བཙུགསཔ་](/dz/reference/genesis.md), [མཉམ་འབྲེལ་འཛིན་སྐྱོང་](/dz/guide/configure/peer-management.md)དང་ [གྲུབ་འབྲས་དང་རྩིས་ཐིག་](/dz/guide/advanced/metrics.md#node-count-and-quorum)ཚུ་བལྟ་དགོ།

## Torii དང་ མཐུན་རྐྱེན་ཚུ་ {#torii-and-network-access}

- Torii འདི་ host ཡང་ན་ སྒེར་གྱི་དྲ་ལམ་ལས་ཕྱི་ཁར་བཏོན་པའི་སྐབས་ back-proxy ཡང་ན་ firewall གི་རྒྱབ་ལུ་བཞག་དགོ།
- TLS མཇུག་བསྡུ་ཞིནམ་ལས་ གཞི་རྟེན་ཨའི་ཏེན་ཊི་ཀཱ། རེ་རེ་ཚད་འཛིན་དང་ དགོས་མཁོ་གི་ཚད་འཛིན་ཚུ་ བགོ་བཀྲམ་འབད་པའི་སྐབས་ ལག་ལེན་འཐབ་དགོ།
- མཐའ་འཁོར་གྱི་དོན་ལུ་ དགོས་མཁོ་ཅན་གྱི་མཐའ་མཇུག་གི་སྒོ་ཚུ་རྐྱངམ་གཅིག་ཁྱབ་སྤེལ་འབད་དགོ ས ་ ལས་འཛིན་དང་ ཊེ་ལེ་མེ་ཊི་རི་ལམ་ལུགས་ཚུ་ མི་མང་གིས་ལྷག་པའི་ཁ་ཐུག་ལུ་མ་གཏོགས་ བཀག་དམ་ཐེབས་སྦེ་བཞག་དགོཔ་ཨིན།
- ཉན་མི་གི་ཁ་བྱང་ཚུ་ host-local interfaces ལུ་ bond when peers should not accept remote traffic directly.

[Torii མཇུག་བསྡུ་ཐོ་བཀོད་](/dz/reference/torii-endpoints.md)དང་ [Virtual Private Networks](/dz/guide/security/vpn.md) ལུ་བལྟ་དགོ།

## གྲོས་འཆམ་དང་ ཐོན་སྐྱེད་འབད་ཐངས་ {#consensus-and-capacity}

- གྲོས་བསྟུན་གྱི་དུས་ཚོད་ཚུ་ བསྒྱུར་བཅོས་མ་འབད་བའི་ཧེ་མར་ རྒྱུན་སྐྱོང་ཚད་འཇལ་ཚུགས། དུས་ཡུན་ཐུང་ཀུ་ཉུང་སུ་འདི་ ཡོངས་འབྲེལ་, གསོག་འཇོག་དང་ལག་ལེན་གནས་རིམ་ཚུ་ ཡར་དྲག་གཏང་པའི་སྐབས་རྐྱངམ་ཅིག་ མར་ཕབ་འབད་ཚུགས་ཨིན།
- ཐིམ་ཕུག་གི་ཐིག་ཚད་ཐུང་ཀུ་ཚུ་རྐྱངམ་གཅིག་བལྟ་ནི་མེན་པར་ ཐིམ་ཕུག་ལུ་ གྱངས་ཁ་ཡར་སེང་འགྱོ་པ་ཅིན་ གློག་ཐག་དེ་ མང་སུ་སྦེ་ བསྡུ་ཚུགས་འོང་།
- ཕན་ནུས་ཅན་གྱི་ Sumeragi ཚད་གཞི། གློག་ཐག་ར་བ་གི་ཁ་བྱང་། ངོས་ལེན་འབད་མི་ཚུ་གི་གྱངས་ཁ་། གྲལ་ཐིག་ RTT སྒྲིང་སྒྲི་དང་ ལཱ་འགན་ལྗིད་ཀྱི་བཟོ་དབྱིབས་ དེ་ལས་ བརྟག་དཔྱད་ཚད་གཞིའི་དོན་ལུ་ རིན་གོང་ཅན་ལག་ཆས་ཚུ་གི་དོན་ལས་ཐོ་ཡིག་རྐྱབས།
- བསྡུ་ལེན་འབད་ནིའི་ནུས་ཤུགས་འདི་ ཡར་སེང་རྐྱབས་ནི་ ཚོད་བསྲེ་དང་རྒྱུན་འགྲུལ་ དེ་ལས་ backpressure བརྡ་སྟོན་ཚུ་བསྡུར་འབད་བའི་ཤུལ་ལས་ཨིན།

[གྲུབ་འབྲས་དང་རྩིས་ཐོ་བཀོད་](/dz/guide/advanced/metrics.md)བལྟ་དགོ།

## Bare-Metal དང་ བྱ་རིམ་འཛིན་སྐྱོང་ {#bare-metal-and-process-management}

- དངོས་པོ་སོ་སོ་གི་ `config.toml`, སྒེར་གྱི་ལྡེ་མིག་, ཐོ་བཀོད་ཐོ་དང་སྒོ་ར་སྒོ་སོ་སོ་སྦེ་བཞག་དགོ།
- བྱ་རིམ་འཛིན་སྐྱོང་པ་ཚུ་ལག་ལེན་འཐབ་ནི་ དཔེར་ན་ systemd གིས་ གསལ་ཏོག་ཏོ་སྦེ་ ལོག་འགོ་བཙུགས་ནི་དང་ ཐོ་བཀོད་དང་ ཐོན་ཁུངས་ཀྱི་ སྲིད་བྱུས་ཚུ་ ལག་ལེན་འཐབ་ཨིན།
- བཟོ་སྐྲུན་འབད་ཡོད་པའི་གནས་གོང་ README དང་ལས་འགོ་བཙུགས་བཀའ་རྒྱ་ཚུ་ Kagami localnet སྦ་སྒོར་ཚུ་ བརྟག་དཔྱད་ཀྱི་དབྱེ་ཞིབ་འདི་ འཛིན་སྐྱོང་འབད་མི་ hosts ལུ་བསྒྱུར་བཅོས་འབད་བའི་སྐབས་ཨིན།
