# གྲ་སྒྲིག་འབད་ནི་ {#release-readiness}

Iroha ལག་ལེན་ཅིག་ཡང་ན་ དྲ་རྒྱའི་བསྒྱུར་བཅོས་གོང་འཕེལ་མ་གཏང་པའི་ཧེ་མར་ འབྲེལ་ཡོད་ཉེན་ཁ་མངོན་ཚུགས་པའི་མཐའ་འཁོར་ཆུང་ཤོས་ནང་སྤྱོད་ལམ་འདི་བདེན་ཁུངས་བཀལ། དེ་ལས་ མཉམ་སྤྱོད་བརྟག་དཔྱད་དྲ་རྒྱ་དང་ ཐོན་སྐྱེད་སྒོ་ར་ཚུ་བརྒྱུད་དེ་དོ་སྣང་ཐོག་ལས་སྤོ།

## ས་གནས་ཀྱི་དྲ་སྒོ་ {#localnet-gate}

- འདི་བཟུམ་སྦེ་ Iroha རྒྱུན་ལམ་དང་ ཉེ་འདབས་ལུ་ཡོད་པའི་ལག་ལེན་ཅན་གྱི་བརྟག་དཔྱད་འཕྲུལ་ཆས་གི་གྲངས་རྩིས་དང་གཅིག་ཁར་ ཐོ་བཀོད་འབད་བཏུབ་པའི་ ས་གནས་ཀྱི་ཁ་ཐུག་ལུ་ མཐུད་སྦྲེལ་འབད་ནི་ཨིན།
- ཚོང་འབྲེལ་བཟོ་བསྐྲུན་པ་དང་ འདྲི་དཔྱད་དབྱེ་དཔྱད་ ངོས་ལེན་འཛིན་སྐྱོང་ དེ་ལས་ རིམ་སྒྲིག་མངོན་གསལ་ཚུ་གི་དོན་ལུ་ ཡུ་ནིཊི་བརྟག་དཔྱད་ཚུ་གཡོག་བཀོལ།
- ཁྱོད་ཀྱིས་ SDK ཡང་ན་ CLI བཟོ་བཀོད་འབད་མི་དེ་ ཤུལ་ལས་ལག་ལེན་དེ་གིས་ ལག་ལེན་འཐབ་ནི་ཨིན་པའི་ ཐབས་ལམ་དེ་བརྒྱུད་དེ་ ཀློག་ཐེངསམ་འབྲི་ནི་ལུ་ གྲུབ་འབྲས་ཉུང་ཤོས་ཅིག་བཏོན་དགོ།
- བརྟག་དཔྱད་ལག་ཆས་ཚུ་ནང་ལུ་ ཌའི་ལོག་གི་གནས་ཚད་དང་ གནས་སྟངས་ དེ་ལས་ གནད་དོན་ཚུ་ བསྡུ་འཛིན་འབད་འོང་།

[གཞི་བཙུགས་འབད་ནི་ Iroha 3](/dz/get-started/launch-iroha.md)དང་ [SDK སྦྱོང་བརྡར་ཚུ་ ](/dz/guide/tutorials/).

## མཉམ་སྤྱོད་བརྟག་ཞིབ་དྲ་རྒྱའི་སྒོ་ {#shared-testnet-gate}

- Taira ཡང་ན་ མཐའ་མཇུག་གི་སྒོ་སྒྲིག་གི་ སྤྱོད་ལམ་, དངུལ་ཕོགས་,རྩིས་ཐོ་དངུལ་, དུས་ཡུན་ཐུང་ཀུ་དང་ ལག་ལེན་གྱི་ཉམས་མྱོང་ཚུ་གི་དོན་ལུ་བགོ་བཤའ་རྐྱབ་ཡོད་པའི་ བརྟག་དཔྱད་དྲ་རྒྱ་གཞན་ཅིག་ལག་ལེན་འཐབ་།
- བརྟག་དཔྱད་ནེཊ་གིས་ སྤྱིར་བཏང་བརྟག་དཔྱད་ཚུ་ ཡོངས་འབྲེལ་ཐོབ་ཚུགས་མི་དང་ ཡང་ན་ བརྟག་དཔྱད་ནེཊ་གི་མ་དངུལ་ཚུ་ ཟད་འགྲོ་བཏང་མི་ལུ་ བརྟེན་མི་བཏུབ།
- མིང་རྟགས་བཀོད་མི་གི་མ་དངུལ་དང་ འཐུས་རྒྱུ་དངོས་མེ་ཊ་ཌེ་ཊ་ དབང་འཛིན་གནང་བ་ དེ་ལས་ རེ་བ་བསྐྱེད་པའི་གནས་སྟངས་ཚུ་ ཐད་རི་བ་རི་བརྟག་དཔྱད་ཚོང་འབྲེལ་རེ་རེ་བཞིན་དུ་ མ་བཙུགས་པའི་ཧེ་མ་ བདེན་དཔྱད་འབད།
- ཊར་མི་ནཱལ་གནས་ཚད་ཅིག་ལུ་སྒུག་ཞིནམ་ལས་ ལྷག་ནི་རྐྱངམ་ཅིག་འདྲི་དཔྱད་དང་གཅིག་ཁར་ གྲུབ་འབྲས་གནས་སྟངས་འདི་བདེན་དཔྱད་འབད།

[SORA ༣ ལུ་གཞི་བཙུགས་འབད་: Taira དང་ Minamoto](/dz/get-started/sora-nexus-dataspaces.md).

## གློག་ཐག་ར་བ་ ཡང་ན་ བཟོ་སྐྲུན་སྒོ་ར་སྒོ་ {#mainnet-or-production-gate}

- ཐོན་སྐྱེད་མིང་རྟགས་བཀོད་མི་དང་ མ་དངུལ་ མངའ་ཁོངས་ དེ་ལས་ རིམ་སྒྲིག་འགྲུལ་ལམ་ཚུ་ སོ་སོ་སྦེ་ལག་ལེན་འཐབ། བརྟག་དཔྱད་ནེཊི་ལྡེ་མིག་ཚུ་ཡང་ན་ བརྟག་དཔྱད་ཊོ་ཀེན་ཞབས་ཏོག་གྱི་བསམ་ཚུལ་ཚུ་ ཡར་དྲག་མ་གཏང་།
- ཁྱོད་ཀྱིས་ [མཐུན་རྐྱེན་མ་ཊིཀསི་](/dz/reference/compatibility-matrix.md) དང་གཅིག་ཁར་ དགོས་མཁོ་ཅན་གྱི་ SDK སྣ་མང་བར གནས་སྟངས་ཚུ་ བརྟག་ཞིབ་འབད་ཞིནམ་ལས་ ཐོ་བཀོད་འབད་བའི་སྐབས་ལག་ལེན་འཐབ་མི་ CLI ཏག་ཏག་, མཉམ་རོགས གཉིས་ལྡན, རིམ་སྒྲིག་འབད, དང་ དྲ་རྒྱ གསར་བཏོན་ འདི་སོ་སོ་སྦེ་ཐོ་བཀོད་དང་བརྟག་དཔྱད་འབདཝ་ཨིན།
- བསྐྱར་ཞིབ་གནང་བ་དང་ འཐུས་རྒྱབ་སྐྱོར་ གོང་ཚད་ཚད་གཞི་ ལྟ་རྟོག་ རྒྱབ་ཐག་གནས་རིམ་ དེ་ལས་ གསར་བཏོན་སྒོ་སྒྲིག་མ་འབད་བའི་ཧེ་མ་ བསྐྱར་ལོག་ཚད་གཞི་ཚུ།
- གནོད་པ་ཆེ་བའི་བྲིས་ཚུ་གི་དོན་ལུ་ ཡིག་ཐོག་གི་ཚོང་འབྲེལ་ཡང་ན་ གནས་སྤོ་འཆར་གཞི་དགོཔ་ཨིན།

## རྒྱབ་སྐྱོར་དང་ ལོག་ཐོབ་ཐབས། {#rollback-and-recovery}

- བསྒྱུར་བཅོས་ག་འདི་ གསང་ཡིག་བཀྲམ་སྤེལ་གྱི་ཐོག་ལས་ ལོག་བཤུད་འབད་ཚུགསཔ་ཨིན་ན་ ངེས་འཛིན་འབད་ དེ་ལུ་ རིམ་སྒྲིག་ཚོང་འབྲེལ་དགོཔ་ཨིན་ དེ་ལས་ ག་ཅི་འདི་ ཐད་ཀར་དུ་ ཕྱིར་འཐེན་འབད་མ་ཚུགསཔ་ཨིན།
- རིམ་སྒྲིག་གནད་སྡུད་བསྒྱུར་བཅོས་ཚུ་གི་དོན་ལུ་ ཐོན་སྐྱེད་འགོ་དང་པ་འབྲི་མ་ཚར་བའི་ཧེ་མ་ རྒུད་འཐུས་ཚོང་འབྲེལ་ཡང་ན་ གནས་སྤོ་ཡིག་ཆ་ཚུ་གྲ་སྒྲིག་འབད།
- ཡོངས་འབྲེལ་བསྒྱུར་བཅོས་ཚུ་གི་དོན་ལུ་ ཧེ་མའི་གཉིས་ལྡན་དང་ རིམ་སྒྲིག་བང་སྒྲིག་ མིང་རྟགས་བཀོད་ཡོད་པའི་རིགས་མཚན་ དེ་ལས་ ལག་ལེན་གྱི་ རན་བུཀ་ཚུ་ གསར་བཏོན་འབད་བའི་སྐབས་ འཐོབ་ཚུགསཔ་སྦེ་བཞག།
- བཀག་ཆ་འབད་ནིའི་ཚད་གཞི་དང་ བང་རིམ་ཡར་འཕར་ འགོར་འགྱངས་ ཡང་ན་ མཉམ་རོགས་ཀྱི་གསོ་བ་བཟུམ་གྱི་ དམིགས་དོན་བརྡ་མཚོན་ཚུ་ལུ་གཞི་བཞག་སྟེ་ བཀྲམ་སྤེལ་འབད་ནི་འདི་ བཀག་ཆ་འབད་ནིའི་དོན་ལུ་ ཐག་བཅད་ས་ཚིགས་ཅིག་གཞི་སྒྲིག་འབད།

## མཐའ་མའི་དཔྱད་ཡིག་ {#final-checklist}

- རིམ་སྒྲིག་འདི་མཐའ་འཁོར་དམིགས་བསལ་ཨིནམ་དང་ བརྟག་དཔྱད་རྐྱངམ་ཅིག་གི་གསང་བ་ཚུ་མེདཔ་ཨིན།
- ཚོང་འབྲེལ་ལོག་སྟེ་འབད་རྩོལ་སྤྱོད་ལམ་འདི་ ནུས་མེད་ཡང་ན་ གསལ་ཏོག་ཏོ་སྦེ་ ཚད་འཛིན་འབད་ཡོདཔ་ཨིན།

- ལྟ་རྟོག་འདི་གིས་ ཐོན་འབྲས་དང་ འགོར་འགྱངས་ བང་རིམ་གཏིང་ཚད་ ངོས་ལེན་མ་འབད་མི་ མཐོང་སྣང་བསྒྱུར་བཅོས་ དེ་ལས་ འབྲེལ་ཡོད་ཚོང་འབྲེལ་བྱུང་ལས་ཚུ་ ཁྱབ་ཚུགསཔ་ཨིན།
