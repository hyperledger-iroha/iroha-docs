# གྲ་སྒྲིག་འབད་ནི་ {#release-readiness}

ཁྱོད་ཀྱིས་ Iroha ཌོག་ཊར་ལག་ལེན་དང་ལྡནམ་སྦེ་བསྒྱུར་བཅོས་མ་གཏང་པའི་ཧེ་མར་ གནས་སྟངས་ཆུང་ཤོས་ནང་ བྱ་སྤྱོད་དེ་བཏོན་དགོཔ་ད་ ཉེན་ཁ་ཅན་གྱི་གནས་སྟངས་ལུ་ བརྟག་ཞིབ་འབད་ཞིནམ་ལས་ དབྱེ་བ་ཡོད་པའི་བརྟག་དཔྱད་དྲ་ལམ་དང་ བཟོ་སྐྲུན་སྒོ་ར་སྒོ་ཚུ་ནང་ལུ་ ཐབས་ཤེས་ཐོག་འགྱོ་དགོ།

## ས་གནས་ཀྱི་དྲ་སྒོ་ {#localnet-gate}

- འདི་བཟུམ་སྦེ་ Iroha རྒྱུན་ལམ་དང་ ཉེ་འདབས་ལུ་ཡོད་པའི་ལག་ལེན་ཅན་གྱི་བརྟག་དཔྱད་འཕྲུལ་ཆས་གི་གྲངས་རྩིས་དང་གཅིག་ཁར་ ཐོ་བཀོད་འབད་བཏུབ་པའི་ ས་གནས་ཀྱི་ཁ་ཐུག་ལུ་ མཐུད་སྦྲེལ་འབད་ནི་ཨིན།
- ཚོང་འབྲེལ་བཟོ་སྐྲུན་འབད་མི་ཚུ་གི་དོན་ལུ་ ཡུ་ནིཊ་བརྟག་དཔྱད་ཚུ་ བཏོན་གཏང་། དྲི་བཀོད་ལུ་ བརྟག་ཞིབ་འབད་ནི་དང་ ངོས་ལེན་ལག་ལེན་འཐབ་ནི་ དེ་ལས་ བསྡུ་སྒྲིག་བཀང་ཐབས།
- ཁྱོད་ཀྱིས་ SDK ཡང་ན་ CLI བཟོ་བཀོད་འབད་མི་དེ་ ཤུལ་ལས་ལག་ལེན་དེ་གིས་ ལག་ལེན་འཐབ་ནི་ཨིན་པའི་ ཐབས་ལམ་དེ་བརྒྱུད་དེ་ ཀློག་ཐེངསམ་འབྲི་ནི་ལུ་ གྲུབ་འབྲས་ཉུང་ཤོས་ཅིག་བཏོན་དགོ།
- བརྟག་དཔྱད་ལག་ཆས་ཚུ་ནང་ལུ་ ཌའི་ལོག་གི་གནས་ཚད་དང་ གནས་སྟངས་ དེ་ལས་ གནད་དོན་ཚུ་ བསྡུ་འཛིན་འབད་འོང་།

## བཀྲམ་སྤེལ་འབད་ཡོད་པའི་ Testnet Gate {#shared-testnet-gate}

- Taira ཡང་ན་ མཐའ་མཇུག་གི་སྒོ་སྒྲིག་གི་ སྤྱོད་ལམ་, དངུལ་ཕོགས་,རྩིས་ཁྲ་དངུལ་, དུས་ཡུན་ཐུང་ཀུ་དང་ ལག་ལེན་གྱི་ཉམས་མྱོང་ཚུ་གི་དོན་ལུ་བགོ་བཤའ་རྐྱབ་ཡོད་པའི་ བརྟག་དཔྱད་དྲ་རྒྱ་གཞན་ཅིག་ལག་ལེན་འཐབ་།
- live testnet ལུ་འབྲི་ནི་འདི་ opt-in སྦེ་བཞག་དགོ། དེ་འབདཝ་ལས་ རྒྱུན་ལྡན་གྱི་བརྟག་དཔྱད་ཚུ་ network availability ལུ་མི་བརྟེན་ ཡང་ན་ testnet funds ཟད་འགྲོ་མི་གཏང་།
- ཐོ་བཀོད་འབད་མི་གི་དངུལ་རྩིས་དང་འཐུས་སྤྲོད་ཡོད་པའི་ རྒྱུ་དངོས་ཚུ་གི་ བརྡ་དོན་ཚུ་ བརྟག་ཞིབ་འབད་དགོ འབྲེལ་ཡོད་དབང་འཛིན་གྱི་ ངོས་ལེན་དང་ བརྟག་དཔྱད་འབད་ནིའི་གནས་གོང་ཚུ་ ངོ་རྐྱང་གི་བརྟག་དཔྱད་ཀྱི་ཞལ་འདེབས་མ་བཙུགས་པའི་ཧེ་མ་ བརྟག་དཔྱད་འབད།
- མཐའན་མཇུག་གི་གནས་སྟངས་ལུ་སྒུག་སྟེ་ བལྟ་ཞིནམ་ལས་ འཐོན་པའི་ གནས་སྟངས་དེ་ ཀློག་རྐྱང་གི་དྲི་བཀོད་ཐོག་ལས་ བདེན་དཔྱད་འབད་ཚུགས།

[SORA ༣ ལུ་གཞི་བཙུགས་འབད་: Taira དང་ Minamoto](/dz/get-started/sora-nexus-dataspaces.md).

## གློག་ཐག་ར་བ་ ཡང་ན་ བཟོ་སྐྲུན་སྒོ་ར་སྒོ་ {#mainnet-or-production-gate}

- production གྱི་དོན་ལུ་ signers, funding, domains དང་ config paths རང་སོ་སོར་ལག་ལེན་འཐབ། testnet keys ཡང་ན་ faucet assumptions འདི་ production ལུ་མ་སྤེལ།
- ཁྱོད་ཀྱིས་ [ Compatibility Matrix ](/dz/reference/compatibility-matrix.md) དང་གཅིག་ཁར་ དགོས་མཁོ་ཅན་གྱི་ cross-SDK གནས་སྟངས་ཚུ་ བརྟག་ཞིབ་འབད་ཞིནམ་ལས་ ཐོ་བཀོད་འབད་བའི་སྐབས་ལག་ལེན་འཐབ་མི་ exact CLI, peer binary, configure, and network release འདི་སོ་སོ་སྦེ་ཐོ་བཀོད་དང་བརྟག་དཔྱད་འབདཝ་ཨིན།
- བསྐྱར་ཞིབ་གི་ཆོག་ཐམ་, དངུལ་ཕོགས་རྒྱབ་སྐྱོར་, གོང་ཚད་ཀྱི་ཐོ་བཀོད་, ལྟ་རྟོག་, རྒྱབ་སྣོན་གནས་གོང་, ཕྱིར་སྐྲུན་འབད་ནི་གི་ སྒོ་སྒྲིག་མ་ལྷོད་པའི་ཧེ་མ་ལོག་འགྱོ་བའི་གནད་དོན་ཚུ་.
- ཤུགས་ཆེ་བའི་ཡིག་ཚང་ཚུ་གི་དོན་ལུ་ ཡིག་ཐོག་གི་ ཚོང་འབྲེལ་དང་ གནས་སྤོ་འཆར་གཞི་ཅིག་ དགོཔ་ཨིན།

## རྒྱབ་སྐྱོར་དང་ ལོག་ཐོབ་ཐབས། {#rollback-and-recovery}

- ཀི་ཌོག་གི་ལག་ལེན་འཐབ་ཐོག་ལས་ བསྒྱུར་བཅོས་འབད་ཚུགས་པའི་ ཐབས་ཤེས་ཚུ་ ངེས་གཏན་བཟོ་ནི་ འདི་ཚུ་ཡང་ ལྕགས་ཐག་ནང་ལུ་ ཕྱིར་ཚོང་འཐབ་དགོཔ་སྦེ་ཡོདཔ་དང་ དེ་ཚུ་ ཐད་ཀར་དུ་ བསྒྱུར་བཅོས་འབད་མི་ཚུགས།
- གྲལ་ཐིག་ནང་ཡོད་པའི་ གནད་དོན་ཚུ་ བསྒྱུར་བཅོས་འབད་ནིའི་དོན་ལས་ བཟོ་སྐྲུན་གྱི་ལཱ་འགོ་དང་པ་མ་རྐྱབ་པའི་ཧེ་མར་ ཟད་འགྲོ་དངུལ་ཀྲམ་སྤྲོད་ལེན་འབད་ནི་དང་ ཡང་ན་ གནས་སྤོ་སོའི་ཡིག་འབྲུ་ཚུ་ གྲ་སྒྲིག་རྐྱབས་དགོ།
- འབྲེལ་མཐུད་ཀྱི་འགྱུར་བཅོས་ཚུ་གི་དོན་ལུ་ སྔོན་བྱོན་གི་ བའི་ནརི་, གཞི་སྒྲིག་མཐུན་རྐྱེན་, ཡིག་རྟགས་བཀོད་མི་འབྱུང་ཁུངས། དེ་ལས་ལག་ལེན་གྱི་ལམ་སྟོན་ཚུ་ པར་སྐྲུན་འབད་བའི་སྐབས་ལུ་ ལག་ལེན་འཐབ་ཚུགསཔ་སྦེ་བཞག་ནི།
- གྲོས་ཐག་བཅད་ནིའི་གནད་དོན་ཅིག་ གཞི་བཙུགས་འབད་ནི། དཔེར་ན་ ཁ་བཟེད་ཐངས་དང་ གྱངས་ཁ་ཡར་སེང་ དེ་ལས་ དུས་ཡུན་ཐུང་ཀུ་ ཡང་ན་ ཉམས་མྱོང་ཅན་གི་བརྡ་སྟོན་ཚུ་ལུ་གཞི་བཞག་སྟེ་

## མཐའ་མའི་དཔྱད་ཡིག་ {#final-checklist}

- བཟོ་བཀོད་དེ་ གནས་སྟངས་ལུ་དམིགས་ཏེ་ཡོདཔ་ལས་ བརྟག་དཔྱད་རྐྱངམ་གཅིག་འབད་མི་ གསང་བ་ཚུ་མི་བཀོད།
- ཚོང་འབྲེལ་བསྐྱར་ཞིབ་འབད་ནིའི་ སྤྱོད་ལམ་འདི་ ཐབས་མེད་པར་འབད་ནི་དང་ ཡང་ཅིན་ ངེས་པར་དུ་ བཀག་འཛིན་འབདཝ་ཨིན།
- ལག་ལེན་འདི་གིས་ ཆ་མེད་གཏང་ཐངས་དང་ དུས་ཡུན་ཚང་ཐངས་ དེ་ལས་ མཐའ་མཇུག་གི་སྒོ་སྒྲིག་ལག་ལེན་འཐབ་ཐངས་ཚུ་དབྱེ་ཞིབ་འབད་ཚུགས།
