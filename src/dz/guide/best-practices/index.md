# ལག་ལེན་ལེགས་ཤོམ་ཚུ་ {#best-practices}

འ་ནི་ཆ་ཤས་འདི་ Iroha གི་ལག་ལེན་དང་དྲ་རྒྱ་ཚུ་གི་དོན་ལུ་ བཟོ་སྐྲུན་ལུ་གཞི་བཞག་སྟེ་ལམ་སྟོན་ཚུ་བསྡུ་བཀོདཔ་ཨིན། འདི་ཁྱོད་ཀྱིས་འབད་དགོ་པའི་ གྲོས་ཐག་གིས་གོ་སྒྲིག་འབདཝ་ཨིན། ལག་ལེན་དེ་ འགོ་འདྲེན་འཐབ་མི་གི་འགན་ཁུར་ལས་མེན་པས།

བརྗེ་སོར་འབད་ཡོད་པའི་བརྟག་དཔྱད་ནེཊ་སྦྱོང་བརྡར་དང་ བཟོ་བསྐྲུན་འགོ་བཙུགས་ ཡང་ན་ མཁོ་མངགས་འབད་མི་གཙོ་བོ་ཅིག་ གསར་བཏོན་འབད་བའི་ཧེ་མ་ བརྟག་ཞིབ་ཐོ་ཡིག་སྦེ་ལག་ལེན་འཐབ།

## དབྱེ་བ་ཕྱེ་ནིའི་ལམ་ལུགས་ {#cross-cutting-rules}

- ས་གནས་གོང་འཕེལ་དང་ བརྗེ་སོར་བརྟག་དཔྱད་ནེཊ་ དེ་ལས་ བཟོ་བསྐྲུན་རིམ་སྒྲིག་ཚུ་ སོ་སོ་སྦེ་བཞག།
- རིགས་མཚན་དང་ མཉམ་རོགས་ཀྱི་ ཊོ་པོ་ལོ་ཇི་ ལག་ལེན་འཐབ་མི་སྲིད་བྱུས་ དེ་ལས་ གཙོ་བོ་རྒྱུ་ཆ་ཚུ་ ཚད་འཛིན་འབད་བའི་ བཀྲམ་སྤེལ་གྱི་ ཅ་ཆས་སྦེ་ བརྩི་འཇོག་འབད།
- དཔེ་སྟོན་ཐུབ་ཚད་ཅན་གྱི་རྩིས་ཐོའི་གནས་སྟངས། གནད་སྡུད་སྦོམ་དང་སྒེར་གྱི་ ཡང་ན་ མཐོ་དྲགས་ཅན་གྱི་ གནད་སྡུད་ཚུ་གི་དོན་ལུ་ བཀོ་བཞག་སའི་ས་སྒོ་སྦེ་ མེ་ཊ་གནད་སྡུད་ལག་ལེན་མ་འཐབ།
- བཀག་ཆ་དང་ དུས་ཚོད་རྫོགས་ནི་ ལོག་སྟེ་དཔའ་བཅམ་ནི་ དེ་ལས་ ཕྱིར་འགྱངས་གནས་ཚད་ཚུ་ འཛིན་སྐྱོང་འཐབ་ཚུགས་པའི་ ནུས་མེད་ལཱ་གི་རྒྱུན་རིམ་ཚུ་བརྒྱུད་དེ་ ཚོང་འབྲེལ་ཚུ་བཙུགས།
- བདག་སྐྱོང་པ་རྒྱ་ཆེ་བའི་འཛུལ་སྤྱོད་ལས་ གནང་བ་དོགཔོ་དང་ བློ་གཏད་ཅན་གྱི་འཕྲུལ་རིག་རྩིས་ཐོ་ དེ་ལས་ གསལ་ཏོག་ཏོ་བཀོལ་སྤྱོད་རན་བུཀ་ཚུ་ དགའ་གདམ་འབད།
- འགོ་དང་པ་ ལག་ལེན་འཐབ་བཏུབ་པའི་ ས་གནས་ཁ་ཐུག་ལུ་ སྤྱོད་ལམ་སྟོན་འབད་ཞིནམ་ལས་ Taira ཡང་ན་ མཉམ་འབྲེལ་ཅན་གྱི་བརྟག་དཔྱད་འཕྲུལ་ཆས་གཞན་ཅིག་ལུ་ གཞི་རྟེན་འཕྲུལ་ཆས་ལག་ལེན་མ་འཐབ་གོང་ལུ་ བརྟག་ཞིབ་འབདཝ་ཨིན།
