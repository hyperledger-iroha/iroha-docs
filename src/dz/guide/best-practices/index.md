# ལག་ལེན་ལེགས་ཤོམ་ཚུ་ {#best-practices}

འ་ནི་ཆ་ཤས་འདི་ Iroha གི་ལག་ལེན་དང་དྲ་རྒྱ་ཚུ་གི་དོན་ལུ་ བཟོ་སྐྲུན་ལུ་གཞི་བཞག་སྟེ་ལམ་སྟོན་ཚུ་བསྡུ་བཀོདཔ་ཨིན། འདི་ཁྱོད་ཀྱིས་འབད་དགོ་པའི་ གྲོས་ཐག་གིས་གོ་སྒྲིག་འབདཝ་ཨིན། ལག་ལེན་དེ་ འགོ་འདྲེན་འཐབ་མི་གི་འགན་ཁུར་ལས་མེན་པས།

བཀྲམ་སྤེལ་འབད་ཡོད་པའི་བརྟག་དཔྱད་འཕྲུལ་ཆས་ཀྱི་ སྔོན་འགོག་དང་ བཟོ་སྐྲུན་འགོ་བཙུགས་པའི་ཧེ་མར་ ཡང་ན་ ཚོང་མགྲོན་པ་ཚུ་གི་དོན་ལུ་ འཛིན་སྐྱོང་ཐོ་སྦེ་ ལག་ལེན་འཐབ་ནི།

## དབྱེ་བ་ཕྱེ་ནིའི་ལམ་ལུགས་ {#cross-cutting-rules}

- ས་གནས་ཀྱི་གོང་འཕེལ་དང་ བརྟག་ཞིབ་འབད་ཐངས་དང་ བཟོ་སྐྲུན་གྱི་སྒྲིག་གཞི་ཚུ་སོ་སོར་སྦེ་བཞག་ནི།
- འབྱུང་ཁུངས། དངོས་པོ་དབྱེ་ཞིབ་འབད་ཐངས་། སྲིད་བྱུས་ལག་ལེན་དང་ གཞི་རྟེན་རྫས་ཚུ་ ལག་ལེན་འཐབ་ཐངས་འཛིན་བཟུང་འབད་མི་སྦེ་ ལག་ལེན་འཐབ་དགོ།
- མཚམས་འཇོག་འབད་ཚུགས་པའི་ ལྡོག་ཕྱོགས་རྩིས་ཁྲ་གི་རྣམ་གཞག་འདི་ དམིགས་གཏད་ཅན་སྦེ་ ལག་ལེན་འཐབ་མ་བཅུག སྦོམ་དང་ སྒེར་གྱི་ ཡང་ན་ ཡོངས་གྲགས་ཆེ་བའི་ གནས་སྡུད་ཚུ་གི་དོན་ལུ་ མེ་ཊ་ཌའི་ཊཱ། ལག་ལེན་འཐབ་མ་དགོ།
- ཕྱིར་ཚོང་འབད་མི་ཚུ་ idempotent workflows གི་ཐོག་ལས་ བཏང་དོ་ཡོདཔ་ད་ འདི་ཚུ་ reject, expiry, retries, and delayed status འདི་ཚུ་ལག་ལེན་འཐབ་ཚུགས།
- འཛིན་སྐྱོང་པ་ཡོངས་ཁྱབ་ཀྱི་ ཐོབ་ཐངས་ལས་ དགོས་མཁོ་ཅན་གྱི་ཆོག་ཐམ་དང་ དམིགས་གཏད་ཅན་གྱི་ ཁྱད་རིག་གི་རྩིས་ཁྲ་ཚུ་ དེ་ལས་ གསལ་བཀོད་འབད་ཡོད་པའི་ལག་ལེན་གྱི་གནས་དེབ་ཚུ་ གདམ་ཁ་རྐྱབ་ཨིན།
- འགོ་དང་པ་ ལག་ལེན་འཐབ་བཏུབ་པའི་ ས་གནས་ཁ་ཐུག་ལུ་ སྤྱོད་ལམ་སྟོན་འབད་ཞིནམ་ལས་ Taira ཡང་ན་ མཉམ་འབྲེལ་ཅན་གྱི་བརྟག་དཔྱད་འཕྲུལ་ཆས་གཞན་ཅིག་ལུ་ གཞི་རྟེན་འཕྲུལ་ཆས་ལག་ལེན་མ་འཐབ་གོང་ལུ་ བརྟག་ཞིབ་འབདཝ་ཨིན།
