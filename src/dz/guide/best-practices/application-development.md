## ཚོང་འབྲེལ་ཚུ་ {#transactions}

- གནད་དོན་འདི་ JSON ཡང་ན་ string-assembled payloads གི་ཚབ་ལུ་ SDK typeed instruction ཚུ་ལས་བཟོ།
- Preflight ཁག་ཆེ་ཤོས་གིས་ ཀློག་རྐྱང་གི་དྲི་བ་ཚུ་བཀོད་དོ་ཡོདཔ་ཨིན། རྩིས་ཁྲ་གི་གནས་གོང་། རྒྱུ་དངོས་ཀྱི་ལྷག་ལུས་ཚད། ངོས་ལེན་གྱི་གནས་གོང་། དངུལ་ཕོགས་ཅན་གྱི་རྒྱུ་དངོས་ཚུ་གི་གནས་གོང་དང་ དམིགས་གཏད་ཅན་གྱི་དངོས་པོ་གི་གནས་ཚུལ།
- བཏང་མ་ཚར་བའི་ཧེ་མ་ ཕྱིར་ཚོང་གི་ཧེཤ་དང་དབང་འཛིན་རྩིས་ཁྲ་ དེ་ལས་ བརྡ་བཀོད་གྱི་མཐའ་བསྡུར་དང་ གནས་སྟངས་ལུ་འགྱུར་བཅོས་འབད་ནིའི་རེ་བ་ཚུ་ཡིག་ཐོག་ལུ་བཙུགས་དགོ།
- `Rejected`དང་ `Expired` དེ་ལས་དུས་ཡུན་གྱི་གྲུབ་འབྲས་འདི་ཁྱད་པར་ཅན་ཅིག་ཨིན། དུས་ཡུན་ཐུང་ཀུ་འདི་གིས་ བལྟ་བ་ཅིན་མགྲོན་པ་གིས་ མཐའ་མཇུག་གི་གནས་གོང་མ་མཐོང་པས་ཟེར་ སྟོན་མི་མེན། ལས་འཛིན་གྱིས་ ཚོང་འབྲེལ་ལུ་སྣང་མེད་བརྩིས་ཏེ་བཞག་ནུག་ཟེར་ཨིན་མས།
- གྲུབ་འབྲས་ལྡན་པའི་ཡིག་འབྲུ་མཇུག་བསྡུ་ཞིནམ་ལས་ བརྟག་དཔྱད་འབད་ཡོད་པའི་ གནས་སྟངས་འདི་ ལས་འཛིན་གྱི་ལཱ་དང་མཐུནམ་སྦེ་ དྲི་བཀོད་ ཡང་ན་ འབྱུང་རྐྱེན་བརྟག་དཔྱད་ས་སྒོ་ཅིག་གིས་ བཏོན་གཏང་འོང་།
