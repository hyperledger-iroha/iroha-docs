- `client.toml` ཌའི་ལོག་ཚུ་ ས་གནས་བརྟག་དཔྱད་དྲ་རྒྱ, Taira, Minamoto དང་ སྒེར་གྱི་དྲ་ལམ་ཚུ་གི་དོན་ལུ་སོ་སོར་སྦེ་བཞག་དགོ། བརྟག་ཞིབ་འབད་ཐངས་ཀྱི་ཡིག་སྣོད་འདི་ དྲ་རྒྱ་གཙོ་བོ ཡིག་སྣོད་ཅིག་ལུ་འགྱུར་མི་དགོ་

## ཚོང་འབྲེལ་ཚུ་ {#transactions}

- གནད་དོན་འདི་ JSON ཡང་ན་ ཡིག་རྒྱུན-བསྡུ་སྒྲིག་འབད་ཡོདཔ ནང་དོན་གནད་སྡུད་ཚུ གི་ཚབ་ལུ་ SDK གི་ དབྱེ་བ་གསལ་བཀོད་ཅན་གྱི་ བཀོད་རྒྱ ཚུ་ལས་བཟོ།
- སྔོན་འགྲོའི་འཕུར་སྐྱོད་ཁག་ཆེ་བའི་འབྲི་བ་ཚུ་ ལྷག་རྐྱངམ་ཅིག་འདྲི་དཔྱད་ཚུ་དང་གཅིག་ཁར་ རྩིས་ཐོའི་གནས་ལུགས་དང་ རྒྱུ་དངོས་ལྷག་ལུས་ གནང་བ་གནས་སྟངས་ འཐུས་རྒྱུ་དངོས་ཐོབ་ཚུལ་ དེ་ལས་ དམིགས་གཏད་དངོས་པོའི་གནས་སྟངས།
- མ་བཙུགས་པའི་ཧེ་མ་ ཚོང་འབྲེལ་གྱི་ཧ་ཤི་དང་ དབང་འཛིན་རྩིས་ཐོ་ བཀོད་རྒྱ་བཅུད་བསྡུས་ དེ་ལས་ རེ་བ་བསྐྱེད་པའི་གནས་སྟངས་བསྒྱུར་བཅོས་ཚུ་ ཐོ་བཀོད་འབད།
- `Rejected` དང་ `Expired` དེ་ལས་ དུས་ཚོད་རྫོགས་པའི་གྲུབ་འབྲས་ཚུ་ སོ་སོ་སྦེ་ བརྩི་འཇོག་འབད། དུས་ཚོད་རྫོགས་ཟེར་མི་འདི་ མཁོ་མངགས་འབད་མི་གིས་ མཐའ་དཔྱད་གནས་རིམ་ཅིག་ བལྟ་མ་ཚུགས་ཟེར་སླབ་ཨིན། འདི་གིས་ ཡོངས་འབྲེལ་གྱིས་ ཚོང་འབྲེལ་འདི་ སྣང་མེད་བཞག་ཡོདཔ་སྦེ་ བདེན་ཁུངས་བཀལ་མི་བཏུབ།
- མཐར་འཁྱོལ་ཅན་གྱི་འབྲི་ཚར་བའི་ཤུལ་ལས་ ཚོང་འབྲེལ་བཀོལ་སྤྱོད་དང་མཐུན་པའི་འདྲི་དཔྱད་ཡང་ན་བྱུང་ལས་ཞིབ་དཔྱད་ས་ཚིགས་དང་གཅིག་ཁར་ གྲུབ་འབྲས་གནས་སྟངས་འདི་བདེན་དཔྱད་འབད།

- རྩིས་ཐོ་དང་རྒྱུ་དངོས་ དེ་ལས་ སྡེབ་ཚན་ཐོ་ཡིག་ཚུ་བཟུམ་གྱི་ བསྐྱར་ལོག་འབད་བཏུབ་པའི་འདྲི་དཔྱད་རྒྱ་ཆེཝ་ཚུ་ ཤོག་ལེབ་བཟོ།
- མཐུད་ལམ་དང་ འབྱུང་ཁུངས་ཚུ་གི་དོན་ལུ་ ཚགས་མ་དོག་པོ་ཚུ་ དགའ་གདམ་འབད། རྒྱ་ཆེ་བའི་ཚགས་མ་ཚུ་ བརྟག་དཔྱད་ཀྱི་དོན་ལུ་ཕན་ཐོགས་ཡོདཔ་ཨིན་རུང་ དགོས་མཁོ་མེད་པའི་ལག་ལེན་འཐབ་ནི་དང་ མཁོ་སྤྲོད་འབད་མི་ཕྱོགས་ཀྱི་ལས་སྦྱོར་ཚུ་ཁ་སྐོང་བརྐྱབ་ཚུགས།
- ལྷག་རྐྱངམ་ཅིག་གི་ཐ་མག་བརྟག་དཔྱད་ཚུ་ མཚན་རྟགས་བཀོད་ཡོད་པའི་ཚོང་འབྲེལ་བརྟག་དཔྱད་ཚུ་ལས་སོ་སོ་སྦེ་བཞག་དགོཔ་ལས་ མཐའ་མཇུག་ཐོབ་ཚུགས་མི་འདི་ བརྟག་དཔྱད་འབད་ནི་ལུ་འཇམ་ཏོང་ཏོ་ཨིན།
