# སྒྲིག་ཆས་རྐྱང་པ་གུ་ Iroha ལག་ལེན་འཐབ་ནི་ {#running-iroha-on-bare-metal}

ཁྱོད་ཀྱིས་ Docker Compose བརྒྱུད་དེ་མེན་པར་ ཧོསིཊི་ཚུ་གུ་ཐད་ཀར་དུ་ ཡོངས་འབྲེལ་གྱི་ཆ་རོགས་ཚུ་གཡོག་བཀོལ་དགོ་པའི་སྐབས་ ལཱ་གི་རྒྱུན་རིམ་འདི་ལག་ལེན་འཐབ། ད་ལྟོའི་འབྱུང་ཁུངས་ཤིང་གིས་ Kagami མཐུན་སྒྲིག་ཅན་གྱི་བཀག་ཆ་རིགས་མཚན་དང་ ཡོངས་འབྲེལ་མཉམ་རོགས་རིམ་སྒྲིག་ མཁོ་སྤྲོད་རིམ་སྒྲིག་ དེ་ལས་ འགོ་བཙུགས་/བཀག་ཆ་ཡིག་གཟུགས་ཚུ་བྲིས་མི་ བཟོ་བསྐྲུན་པ་ཚུ་བྱིནམ་ཨིན།

## ༡ ཌའི་ལོག་ཚུ་བཟོ་ནི། {#_1-build-the-binaries}

Iroha ལས་འགུལ་གྱི་ས་ཁོངས་ནང་ལས་:

```bash
cargo build --release \
  -p irohad --bin iroha3d \
  -p iroha_cli --bin iroha \
  -p iroha_kagami --bin kagami
```

འདིས་ཐོན་སྐྱེད་བྱེད།

- མཉམ་རོགས་ཌེ་མཱོན་གྱི་དོན་ལུ་ `target/release/iroha3d`
- `target/release/iroha` གྱི་དོན་ལུ་ CLI
- ལྡེ་མིག་དང་རིགས་མཚན་ དེ་ལས་ ལོ་ཀཱལ་ནེཊ་མི་རབས་ཀྱི་དོན་ལུ་ `target/release/kagami`

## 2. ས་གནས་ཀྱི་དྲ་ལམ་བཟོ་ནི། {#_2-generate-a-local-network}

ཌའི་ལོག་གི་ས་སྒོ་ནང་ Iroha 3 བཞི་ལྡེ་མིག་ཅིག་བཟོ་ནི།

```bash
target/release/kagami localnet --peers 4 --out-dir ./localnet
```

ཐོན་འབྲས་སྣོད་ཐོ་ནང་ བཟོ་བཏོན་འབད་ཡོད་པའི་ `genesis.json`, `genesis.signed.nrt`, མཉམ་རོགས་ `config.toml` ཡིག་སྣོད་ `client.toml`, གྲོགས་རམ་ཡིག་ཆ་ཚུ་ དེ་ལས་ བཱན་ཌལ་བརྡ་བཀོད་དེ་གི་དོན་ལུ་ བཟོ་བཏོན་འབད་ཡོད་པའི་ `README.md` ཚུ་ཡོདཔ་ཨིན།

## ༣. དོ་འགྲན་འབད་མི་འགོ་ཚུགས། {#_3-start-peers}

བཟོ་བཏོན་འབད་ཡོད་པའི་བཀོལ་སྤྱོད་འབད་བཏུབ་པའི་ལོ་ཀཱལ་ནེཊི་གི་དོན་ལུ་ བཟོ་བཏོན་འབད་ཡོད་པའི་ཡིག་ཚུགས་འདི་ལག་ལེན་འཐབ།

```bash
./localnet/start.sh
```

ཁྱོད་ཀྱིས་ མཉམ་རོགས་རེ་རེ་བཞིན་དུ་ systemd བཟུམ་གྱི་བྱ་རིམ་འཛིན་སྐྱོང་པ་ཅིག་ནང་ ཝའིར་འབད་དགོ་པ་ཅིན་ མཉམ་རོགས་རེ་རེ་གི་དོན་ལུ་ `./localnet/README.md` ནང་ཐོ་བཀོད་འབད་ཡོད་པའི་ འགོ་བཙུགས་བརྡ་བཀོད་འདི་ལག་ལེན་འཐབ། མཉམ་རོགས་རེ་རེ་གི་ `config.toml` དང་ སྒེར་གྱི་ལྡེ་མིག་ གསོག་འཇོག་སྣོད་ཐོ་ དེ་ལས་ འདྲེན་ལམ་ཚུ་སོ་སོ་སྦེ་བཞག།

## 4.དྲ་རྒྱ་འདི་ལག་ལེན་འཐབ་དགོ། {#_4-operate-the-network}

བཟོ་བཏོན་འབད་ཡོད་པའི་ མཁོ་སྤྲོད་རིམ་སྒྲིག་ལག་ལེན་འཐབ།

```bash
target/release/iroha --config ./localnet/client.toml ledger domain list all
target/release/iroha --config ./localnet/client.toml --output-format text ops sumeragi status
```

བཟོ་བཏོན་འབད་ཡོད་པའི་ལོ་ཀཱལ་ནེཊི་འདི་ འདི་དང་གཅིག་ཁར་བཀག་བཞག:

```bash
./localnet/stop.sh
```

## 5. བཟོ་སྐྲུན་གྱི་ཐོ་ཚུ་ {#_5-production-notes}

- བཟོ་བསྐྲུན་གྱི་དོན་ལུ་ སྒེར་གྱི་ལྡེ་མིག་གསརཔ་ཚུ་བཟོ་བཏོན་འབད་དེ་ མཛོད་ཁང་གི་ཕྱི་ཁར་གསོག་འཇོག་འབད།
- མཐུད་མཚམས་མཉམ་པ་ཆ་མཉམ་ལུ་ ཡི་གུ་བཀོད་མི་ འབྱུང་ཁུངས། ཚོང་འབྲེལ་གྱི་ཐད་ཁར་ གྲོས་བསྟུན་འབད་བཅུགཔ་ཨིན། ཐོ་བཀོད་དང་ཡིད་རྟོན་རུང་བའི་མཐུད་མཚམས་ཚུ་ དེ་ལས་ བདེན་ཁུངས་བཀལ་མི་འདི་ PoPs
- མཉམ་རོགས འདི འཕྲུལ༌ཆས༌ གཞན་ལས་འཛུལ་མ་ཚུགསཔ་བཟོ་དགོ་པའི་སྐབས་རྐྱངམ་གཅིག ཉན་མཁན ཁ༌འབྱང༌ ཚུ ཧོསིཊི་-ས་གནས་ཀྱི་ ངོས་འདྲ་བ ལུ བཅིངས འབད།
- Torii ཚོར་སྣང་, གཞི་རྟེན་ བདེན་དཔྱད, TLS དང་ རེ་རེ་ཚད་འཛིན་གི་དོན་ལུ་ རྒྱབ་ལོག་བརྡ་ཚབ་ ཡང་ན་ ཉེན་སྲུང་གི་ལྕགས་རི་ལག་ལེན་འཐབ་ནི།
- རིགས་མཚན་ཡང་ན་ མོས་མཐུན་གྱི་ཊོ་པོ་ལོ་ཇི་ལུ་བསྒྱུར་བཅོས་ཚུ་ མཉམ་རོགས་ཡིག་སྣོད་ཞུན་དག་མེན་པར་ མཉམ་འབྲེལ་གྱི་གནས་སྤོ་སྦེ་ བརྩི་འཇོག་འབད།

སྣོད་ནང་བཙུགས་པ ས་གནས་གོང་འཕེལ་གྱི་དོན་ལུ་ [Iroha 3 འགོ་བཙུགས་ནི།](../../get-started/launch-iroha.md) Docker Compose ཀྱི་ལཱ་རྒྱུན་ལམ་ལག་ལེན་འཐབ་དགོ།
