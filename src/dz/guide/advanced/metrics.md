# གྲུབ་འབྲས་དང་ ཐབས་བྱུས་ཚུ་ {#performance-and-metrics}

Iroha གྱི་གྲུབ་འབྲས་འདི་ ལཱ་གི་ལཱ་ཁེ་རྒུད་དང་ བརྟན་དཔྱད་འཕྲུལ་ཆས་ཀྱི་ཐོ་བཀོད་ དེ་ལས་ གྲོས་བསྟུན་ཅན་གྱི་གནས་སྟངས་ལུ་བརྟེན་ཨིན། འདི་འབདཝ་ལས་ TPS གྱངས་ཁ་གཅིག་རྐྱངམ་ཅིག་ ཕན་ཐོགས་འབྱུང་ནི་དེ་ གཞི་སྒྲིག་འབད་ཡོད་པའི་ benchmark run ལུ་བཅའ་མར་གཏོགས་པའི་སྐབས་རྐྱངམ་གཅིག་ཨིན།

སྒྲིང་སྒྲི་འཆར་གཞིའི་དོན་ལུ་ ལཱ་གི་གྲུབ་འབྲས་ཚུ་ ལག་ལེན་གྱི་ཁེབས་ཅིག་སྦེ་བརྩི་དགོ།

- འབྲེལ་མཐུད་དེ་ཅིག་གིས་ དགོས་མཁོ་ཅན་གྱི་ཚོང་འབྲེལ་གོང་ཚད་འདི་ ཆ་འཇོག་འབད་ཡོདཔ་ཨིན།
- དམིགས་གཏད་འཆར་དངུལ་གྱི་ནང་འཁོད་ལུ་ དུས་ཡུན་འགོར་བའི་དུས་ཚོད་ཚུ་ བསྡུ་ལེན་འབད་ནི།
- ཚོང་འབྲེལ་གྱི་གྲལ་ཐིག་ཚུ་ ངེས་གཏན་སྦེ་བཞག་ནི།
- མཐུན་ལམ་འདི་ བསྐྱར་ཞིབ་འབད་ཐངས་ཀྱི་འགྱུར་བཅོས་འབད་ནི་དང་ ལོག་སྤྱོད་འབད་ཐངས་ཚུ་ལུ་ གཞི་བཞག་སྟེ་མེདཔ།

འ་ནི་ཤོག་ལེབ་འདི་ལག་ལེན་འཐབ་སྟེ་ ཐོ་བཀོད་འབད་མི་འདི་ node count, network latency threshold དང་ target TPS གི་དོན་ལུ་ high, medium, or low performance stateནང་ལུ་ཡོད་མེད་ གཏན་འཁེལ་འབད་ནི་ཨིན།

## དབྱེ་ཞིབ་འབད་དགོ་པའི་གནད་དོན་ {#what-to-measure}

ལས་འཛིན་གྱི་ས་ཁོངས་འདི་ Torii གིས་བཏོན་མི་ནང་ལས་འགོ་བཙུགས་དགོ།

```bash
export TORII=http://127.0.0.1:8180

curl -s -H 'Accept: application/json' "$TORII/status" | jq .
curl -s -H 'Accept: application/json' "$TORII/v1/sumeragi/status" | jq .
curl -s "$TORII/v1/sumeragi/phases" | jq .
curl -s "$TORII/v1/sumeragi/rbc" | jq .
curl -s "$TORII/v1/sumeragi/params" | jq .
curl -s "$TORII/metrics" > metrics.prom
```

ཁྱོད་ཀྱིས་ public Taira ལུ་བལྟ་ནིའི་དོན་ལུ་ དཔེ་སྒྲོམ་འདི་རང་ བརྟག་དཔྱད་འབད་ཚུགས།

```bash
TAIRA=https://taira.sora.org

curl -fsS -H 'Accept: application/json' "$TAIRA/status" \
  | jq '{blocks, txs_approved, txs_rejected, queue_size, peers}'

curl -fsS "$TAIRA/v1/time/status" \
  | jq '{healthy: .health.healthy, peers, samples_used, rtt_count: .rtt.count}'

curl -fsS "$TAIRA/metrics" \
  | grep -E '^(block_height|queue_size|sumeragi_tx_queue_depth|txs|view_changes)' \
  | head -n 20
```

མི་མང་གི་ Taira མེ་ཊིག་འདི་ བརྡ་དོན་གྱི་མིང་ཚུ་ཤེས་ནི་ལུ་ ཕན་ཐོགས་ཅན་ཨིན། འདི་ཚུ་ རང་སོའི་ལག་ལེན་གྱི་དོན་ལུ་ བཟོ་སྐྲུན་ཤུགས་ཀྱི་གྲངས་རྩིས་སྦེ་ ལག་ལེན་འཐབ་མ་བཅུག།

གྲོས་བསྟུན་གྱི་ snapshots འདི་ཡང་ CLI ནང་ལུ་མཐོང་ཚུགསཔ་ཨིན།

```bash
iroha --config ./localnet/client.toml --output-format text ops sumeragi status
iroha --config ./localnet/client.toml --output-format text ops sumeragi phases
iroha --config ./localnet/client.toml --output-format text ops sumeragi telemetry
iroha --config ./localnet/client.toml ops sumeragi params
```

Telemetry མཐོང་ཚུགསཔ་བཟོ་ནི་དེ་ གཞི་སྒྲིག་འབད་ཡོད་པའི་ཡིག་གཟུགས་ལས་བརྟེན་ཨིན། ཁྱོད་ཀྱིས་ `/metrics` དགོཔ་ད་ `extended` ལག་ལེན་འཐབ་དང་ ཁྱོད་ཀྱིས་བརྟག་དཔྱད་འབད་བའི་སྐབས་ལུ་ `full` ལག་ལེན་འཐབ་ད་ ཁྱོད་ཀྱིས་ Sumeragi ལས་འཛིན་གྱི་ལམ་སྟོན་ཚུ་ཡང་ དགོཔ་ཨིན།

```toml
telemetry_enabled = true
telemetry_profile = "full"
```

## སྒྲུབ་ཐངས་ཚུ་ {#performance-bands}

དམིགས་གཏད་ཀྱི་ཐོག་ལས་ བརྟག་ཞིབ་འབད་ནིའི་དོན་ལུ་ འ་ནི་ bands འདི་ལག་ལེན་འཐབ་ནི། `Y` TPS དེ་ལས་ དུས་ཡུན་འགོར་བའི་ འཆར་དངུལ་ `L` མིལིས་ཀི་ལོ་མི་ཊར་ཚུ་ནང་ ལཱ་འབད་ཐངས་འདི་ དུས་ཡུན་རིངམོ་སྦེ་ བརྩོན་ཤུགས་བསྐྱེད་ནི་དེ་ འཚོ་བ་དང་གནས་སྟངས་བརྟན་ཏོག་ཏོ་ དེ་ལས་ མཇུག་མཐའན་མཇུག་གི་ལཱ་འབད་ཐངས་ཀྱི་ དུས་ཡུན་ཉུང་ཤོས་ཅིག་ཡང་ སྟོནམ་ཨིན།

|སྒྲ་དབྱངས་ |གནས་སྟངས་ཚུ་ |དོན་དག་ |
| --- | --- | --- |
|མཐོ་དྲགས་ཡོདཔ་ཨིན།|ངོས་ལེན་འབད་ཐངས་འདི་ `Y` ཡང་ན་དེ་ལས་བརྒལ་ཨིན། p95 commit latency འདི་ `0.8 * L` ལས་བརྒལ་ཨིན། ཐིམ་ཕུག་གི་གྲལ་རིམ་ཚུ་ བརྒྱ་ཆ་༡༠ གྱི་འོག་ལུ་གནས་ཏེ་ཡོདཔ་མ་ཚད་ མཐོང་སྣང་བརྗེ་སོར་/སླར་གསོ་ counters འདི་ flat འབདཝ་ཨིན་མས།|བགོ་བཀྲམ་འབད་ཐངས་ནང་ དགོས་མཁོ་ཅན་གྱི་ལཱ་གི་འགན་ཁུར་གི་དོན་ལུ་ ས་སྟོང་ཡོད་ |
|དམངས་གཙོའི་རིང་ཚད་ |ངོས་ལེན་འབད་ཐངས་དེ་ `Y` གྱི་སྦོ་ལོགས་ཁར་ཡོདཔ་ད་ p95 commit latency འདི་ `L` ཀྱི་འོག་ལུ་ཡོདཔ་ལས་ ཐིམ་ཕུག་གི་གྲལ་རིམ་ཚུ་ བརྒྱ་ཆ་༥༠ ལས་བརྒལ་མེད་ དེ་ལས་ མཐོང་སྣང་འགྱུར་བཅོས་འདི་ དཀོན་དྲགས་ཨིན་མས། |བཏོན་ཐངས་འདི་ལཱ་འབད་ཡི་ དེ་འབདཝ་ད་ རླུང་ཤུགས་ཉུང་སུ་ཅིག་ཡོདཔ་ཨིན།|
|ཉམ་ཆུང་ |ངོས་ལེན་འབད་མི་ཐོན་ཐངས་འདི་ `Y` གྱི་འོག་ལུ་ཡོདཔ་ད་ p95 commit latency འདི་ `L` ལས་བརྒལ་ཡོདཔ་ད་ ལྕང་ལཱ་རྐྱབ་པའི་སྐབས་ ཐིམ་ཕུག་གི་གྲལ་རིམ་ཚུ་ ཡར་སེང་འགྱོ་དོ་ཡོདཔ་ཨིན། ཡང་ན་ མཐོང་སྣང་འགྱུར་བཅོས་/རྒྱབ་ཕྱོགས་ཨེབ་རྟ་ཚུ་ ཨ་རྟག་ར་ཡར་སེང་འགྱོ་དོ་ཡོདཔ་ཨིན་པས།|དགོས་མཁོ་ཅན་གྱི་ ལཱ་གི་འགན་ཁུར་དེ་ མཚམས་ཚོད་གཅིག་ལས་བརྒལ་མེདཔ། |

ལམ་ལུགས་ངོ་མ་འདི་གྲལ་ཐིག་གི་ཁ་ཐུག་ཨིན། ག་དེམ་ཅིག་སྦེ་ TPS བཏང་མི་འདི་ ཁས་བླངས་འབད་མི་དེ་ལས་ TPS སྦོམ་ཡོདཔ་དང་གྲལ་ཐིག་དེ་ཡར་སེང་འགྱོ་དོ་ཡོདཔ་ལས་ ཟད་འགྲོ་བཏབ་ནི་དེ་ ཡུདཔ་ཐེངས་ཅིག་ནང་ཡང་ གསལ་ཏོག་ཏོ་ཡོདཔ་སྦེ་མཐོང་སྟེ་ཡོད་པ་ཅིན་ཡང་ མཚམས་འཇོག་འབད་ནི་ལུ་ ཐོ་ཕོག་ཡོདཔ་ཨིན།

## node count དང་ quorum {#node-count-and-quorum}

མནོ་བསམ་གཏང་ཐངས་མང་ཤོས་ཅིག་གིས་ སྐྱོན་སེལ་ཐབས་ལུ་ ཡར་དྲག་བཏང་དོ་ཡོདཔ་ཨིན་རུང་ གཅིག་མཐུན་བཟོ་ནི་དང་ ངོས་འཛིན་འབད་ནི་ དེ་ལས་ ཡོངས་འབྲེལ་ཐོན་སྐྱེད་ཀྱི་གོང་ཚད་ཡར་སེང་འབད་དོ་ཡོདཔ་ཨིན། ད་ལྟོའི་ Sumeragi ལག་ལེན་ནང་ལུ་:

- ངོས་འཛིན་གྱི་གྲངས་རྩིས་ `n` ལས་འཛོལ་བ་འཆར་དངུལ་ `f = floor((n - 1) / 3)` ཐོན་སྐྱེད་འབདཝ་ཨིན།
- `n >= 4`གི་དོན་ལུ་ བསྡུ་སྒྲིག་གི་འགན་ཁུར་དེ་ `2f + 1`ཨིན།
- `n <= 3`གི་དོན་ལུ་ ཁས་བླངས་འབད་ནིའི་དོན་ལུ་ ཆ་འཇོག་གྲུབ་མི་ཆ་མཉམ་ དགོཔ་ཨིན།
- ལྟ་བཤལཔ་མཉམ་རུབ་ཚུ་གིས་ བཀྲམ་སྤེལ་འབད་དོ་ཡོདཔ་ཨིན་རུང་ ཚོགས་རྒྱན་བཙུགས་ནི་དང་ གྲོས་འཆར་བཀོད་ནི་ དེ་ལས་བསྡུ་ལེན་འབད་ནི་མེདཔ།

- CPU, དྲན་ཐོ། ཌིས་ཀིསི་དང་ལྡནམ་སྦེ་ ལག་ལེན་འཐབ་མི་ཁ་ཐིག་ཚུ་

འ་ནི་གསལ་སྟོན་ཚུ་མེད་པ་ཅིན་ TPS ཨང་གྲངས་འདི་ སྟབས་མ་བདེཝ་ཅིག་སྦེ་བཞག་དགོཔ་ཨིན།
