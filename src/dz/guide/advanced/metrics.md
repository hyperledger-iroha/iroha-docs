# གྲུབ་འབྲས་དང་ ཐབས་བྱུས་ཚུ་ {#performance-and-metrics}

Iroha གྱི་གྲུབ་འབྲས་འདི་ ལཱ་གི་ལཱ་ཁེ་རྒུད་དང་ བརྟན་དཔྱད་འཕྲུལ་ཆས་ཀྱི་ཐོ་བཀོད་ དེ་ལས་ གྲོས་བསྟུན་ཅན་གྱི་གནས་སྟངས་ལུ་བརྟེན་ཨིན། འདི་འབདཝ་ལས་ TPS གྱངས་ཁ་གཅིག་རྐྱངམ་ཅིག་ ཕན་ཐོགས་འབྱུང་ནི་དེ་ གཞི་སྒྲིག་འབད་ཡོད་པའི་ གཞི་བསྡུར་ཚད ལཱ་འབད་ནི་ ལུ་བཅའ་མར་གཏོགས་པའི་སྐབས་རྐྱངམ་གཅིག་ཨིན།

ལྕོགས་གྲུབ་འཆར་གཞིའི་དོན་ལུ་ ལཱ་འགན་འདི་ བཀོལ་སྤྱོད་ཡིག་ཤུབས་ཅིག་སྦེ་བརྩི་དགོ།

- ཡོངས་འབྲེལ་གྱིས་ཞུ་བ་འབད་ཡོད་པའི་ཚོང་འབྲེལ་གྱི་གོང་ཚད་འདི་ངོས་ལེན་འབདཝ་ཨིན།
- དམིགས་གཏད་འཆར་དངུལ་གྱི་ནང་འཁོད་ལུ་ འགོར་འགྱངས་འབད་ནི།
- ཚོང་འབྲེལ་གྲལ་ཐིག་ཚུ་ཚད་འཛིན་འབད་དེ་སྡོད།
- མོས་མཐུན་འདི་བསྐྱར་ལོག་མཐོང་སྣང་བསྒྱུར་བཅོས་ཡང་ན་སླར་གསོའི་འགྲུལ་ལམ་ལུ་བརྟེན་མི་བཏུབ།

འ་ནི་ཤོག་ལེབ་འདི་ལག་ལེན་འཐབ་སྟེ་ ཐོ་བཀོད་འབད་མི་འདི་ མཐུད་མཚམས གྲངས་བརྩི, དྲ་རྒྱ ཕྱིར་འགྱངས ཚད་གཞི དང་ དམིགས་གཏད TPS གི་དོན་ལུ་ སྦོམ་, བར་ན༌སྐོརམ༌, ཡང་ན་ ལཱ་ཤུགས་དམའ་བ་ གནས་སྟངསནང་ལུ་ཡོད་མེད་ གཏན་འཁེལ་འབད་ནི་ཨིན།

## དབྱེ་ཞིབ་འབད་དགོ་པའི་གནད་དོན་ {#what-to-measure}

སྤྱིར་བཏང་ མཐུད་མཚམས གནས་སྟངས་འདྲ་བཤུས དང་ Prometheus བསྡུ་ལེན ལས་འགོ་བཙུགས་ཞིནམ་ལས་ བཀོལ་སྤྱོད་པ-བདེན་དཔྱད་ཡོད གྲོས་མཐུན གནས་སྟངས གི་དོན་ལུ་ CLI ལག་ལེན་འཐབ་དགོ། བཀོལ་སྤྱོད་པ ལྡེ་མིག འདི་ དམིགས་གཏད མཐུད་མཚམས གིས་བཟོ་བཅུག་དགོཔ་ཨིན། དེ་ ལག་བསྟར་མཉེན་ཆས ལུ་རྐྱངམ་ཅིག་ འཇུགའབདཝ་ཨིན།

```bash
export TORII=http://127.0.0.1:8180
export OPERATOR_KEY_FILE=./secrets/operator.key

curl -s -H 'Accept: application/json' "$TORII/status" | jq .
curl -s "$TORII/metrics" > metrics.prom

iroha --config ./localnet/client.toml \
  --operator-private-key-file "$OPERATOR_KEY_FILE" \
  --output-format json ops sumeragi status
iroha --config ./localnet/client.toml \
  --operator-private-key-file "$OPERATOR_KEY_FILE" \
  --output-format json ops sumeragi diagnostics
iroha --config ./localnet/client.toml \
  --operator-private-key-file "$OPERATOR_KEY_FILE" \
  --output-format json ops sumeragi qc
iroha --config ./localnet/client.toml \
  --operator-private-key-file "$OPERATOR_KEY_FILE" \
  --output-format json ops sumeragi params
```

མི་མང་གི་ Taira འདི་ཨན་ནེམ་ཅན་ མཐུད་མཚམས གནས་སྟངས་འདྲ་བཤུས་ཚུ གི་བཟོ་དབྱིབས་ཤེས་ནི་ལུ་ཕན་ཐོགས་ཡོད། ལས་འཛིན་གྱི་བརྟག་དཔྱད་འདི་ Taira ལས་འཛིན་ལྡེ་མིག་མེད་པ་ཅིན་ མཁོ་འདོད་མེད་པར་མི་ཐོབ་ཨིན།

```bash
TAIRA=https://taira.sora.org

curl -fsS -H 'Accept: application/json' "$TAIRA/status" \
  | jq '{blocks, txs_approved, txs_rejected, queue_size, peers}'

curl -fsS "$TAIRA/v1/time/now" \
  | jq '{now_ms, offset_ms}'
```

ཁྱོད་རའི་བཀྲམ་སྤེལ་གྱི་དོན་ལུ་ མི་མང་-བརྟག་དཔྱད་ཡོངས་འབྲེལ་བལྟ་བརྟོག་ཚུ་ ཐོན་སྐྱེད་ནུས་ཤུགས་ཨང་གྲངས་སྦེ་ལག་ལེན་མ་འཐབ།

རྒྱང་ཚད་གནད་སྡུད མཐོང་ཚུགསཔ་བཟོ་ནི་དེ་ གཞི་སྒྲིག་འབད་ཡོད་པའི་ཡིག་གཟུགས་ལས་བརྟེན་ཨིན། `operator` གིས་ གནས་སྟངས་དང་བརྟག་དཔྱད་གྱི་གནས་སྟངས་འདྲ་བཤུས་ཚུ་བཟོཝ་ཨིན། `extended` གིས་ `/metrics` དང་ ཟད་འགྲོ་ཆེ་བའི་དུས་ཚོད་ཚུ་ ཁ་སྐོང་རྐྱབ་ཨིན། འདི་བཟུམ་སྦེ་ `developer` གིས་ འགོ་ཁྲིད་པ, QC, ཚད་བཟུང་ཚུ, དང་ བདེན་ཁུངས འདི་བཟུམ་གྱི་ བཟོ་མི གནས་སྟངས་འདྲ་བཤུས་ཚུ ཚུ་བཙུགས་ནི་དེ་ཡང་ `/metrics` འབད་མ་ཚུགསཔ་ལས་ ལག་ལེན་འཐབ་ཨིན། ཁྱོད་ཀྱིས་ ལཱ་འབད གཅིག་ནང་ ཆ་ཚན གཉིས་ཆ་ར་ དགོས་པའི་སྐབས་ `full` ལག་ལེན་འཐབ་ཨིན། `telemetry_profile`འདི་ འགོ་དང་པ་བཏང་མི་ རྒྱང་ཚད་གནད་སྡུད བརྗེ་བརྐྱངམ་ཅིག་ཨིན།

```toml
telemetry_profile = "full"
```

## སྒྲུབ་ཐངས་ཚུ་ {#performance-bands}

དམིགས་གཏད་ཐོན་འབྲས་ `Y` TPS དང་ འཕྲོ་བརླག་འཆར་དངུལ་ `L` མི་ལི་སྐར་ཆ་ཚུ་ནང་ བལྟ་བརྟོག་འབད་ཡོད་པའི་རྒྱུག་འགྲན་གྱི་དོན་ལུ་ བང་རིམ་འདི་ཚུ་ལག་ལེན་འཐབ། ལཱ་གི་འབབ་ཚད་འདི་ དྲོད་བཏགས་དང་ བརྟན་ཏོག་ཏོ་གནས་སྟངས་ དེ་ལས་ རེ་བ་བསྐྱེད་པའི་ མཐོ་ཤོས་འབབ་ཚད་ཀྱི་དུས་ཡུན་ཉུང་མཐའ་གཅིག་ བཙུགས་ནིའི་དོན་ལུ་ ཡུན་རིངམོ་སྦེ་ གཡོག་བཀོལ།

|སྒྲ་དབྱངས་ |གནས་སྟངས་ཚུ་ |དོན་དག་ |
| --- | --- | --- |
| མཐོ་ | ངོས་ལེན་འབད་ཡོད་པའི་ཐུམ་སྒྲིལ་འདི་ `Y` ལུ་ཡང་ན་དེ་ལས་ལྷག་སྟེ་ཨིན་ p95 ཁས་བླངས་འགོར་ཚད་འདི་ `0.8 * L` གི་འོག་ལུ་ཨིན་ བང་རིམ་ཚུ་ ལྕོགས་གྲུབ་ཀྱི་བརྒྱ་ཆ་༡༠ གི་འོག་ལུ་ལུསཔ་ཨིན་ དེ་ལས་ མཐོང་སྣང་བསྒྱུར་བཅོས་/སླར་གསོ་གྱངས་ཁ་ཚུ་ ཕྲང་ཏང་ཏ་ཨིན། | བཀྲམ་སྤེལ་འདི་ལུ་ ཞུ་བ་འབད་ཡོད་པའི་ལཱ་གི་མངོན་གསལ་གྱི་དོན་ལུ་ མགུ་ཏོ་གི་ས་སྒོ་ཡོདཔ་ཨིན། |
| བར་མ། | ངོས་ལེན་འབད་ཡོད་པའི་ཐུམ་སྒྲིལ་འདི་ `Y` དང་ཉེ་འདབས་ལུ་ཡོདཔ་ཨིན་ p95 ཁས་བླངས་འགོར་ཚད་འདི་ `L` གི་འོག་ལུ་ཡོདཔ་ཨིན་ བང་རིམ་ཚུ་ ལྕོགས་གྲུབ་བརྒྱ་ཆ་༥༠ གི་འོག་ལུ་བརྟན་ཏོག་ཏོ་ཡོདཔ་དང་ མཐོང་སྣང་བསྒྱུར་བཅོས་ཚུ་ དཀོན་དྲགས་ཡོདཔ་ཨིན། | བཀྲམ་སྤེལ་འདི་ལཱ་འབདཝ་ཨིན་རུང་ འབར་རྫས་བཟོད་བསྲན་ཚད་འཛིན་ཡོདཔ་ཨིན། |

ལམ་ལུགས་ངོ་མ་འདི་གྲལ་ཐིག་གི་ཁ་ཐུག་ཨིན། ག་དེམ་ཅིག་སྦེ་ TPS བཏང་མི་འདི་ ཁས་བླངས་འབད་མི་དེ་ལས་ TPS སྦོམ་ཡོདཔ་དང་གྲལ་ཐིག་དེ་ཡར་སེང་འགྱོ་དོ་ཡོདཔ་ལས་ ཟད་འགྲོ་བཏབ་ནི་དེ་ ཡུདཔ་ཐེངས་ཅིག་ནང་ཡང་ གསལ་ཏོག་ཏོ་ཡོདཔ་སྦེ་མཐོང་སྟེ་ཡོད་པ་ཅིན་ཡང་ མཚམས་འཇོག་འབད་ནི་ལུ་ ཐོ་ཕོག་ཡོདཔ་ཨིན།

## གཏན་འཁེལ་གྱི་ ལཱ་འབད་ཐངས་ {#estimation-workflow}

1. གནས་སྟངས་འདི་ ངེས་པར་དུ་བཤད་ནི།
- བདེན་དཔྱད་འབད་མི་གྱངས་ཁ་དང་ བལྟ་རྟོག་པ་གྱངས་ཁ།
- མོས་མཐུན་ཐབས་ལམ།
   - དམིགས་གཏད་ TPS
- p95 དང་ p99 ཁས་ལེན་-འགོར་འགྱངས་འཆར་དངུལ།
- ཚོང་འབྲེལ་སླ་བསྲེ།
   - རེ་བ་ཡོད་པའི་ དྲ་རྒྱ RTT, དུས་འགྱུར དང་ རྒྱུན་ཞེང
2. དངོས་གྲུབ་ཅན་གྱི་བཟོ་དབྱིབས་འདི་ཡིག་སྣོད་འབད་:

   ```bash
   iroha --config ./localnet/client.toml \
     --operator-private-key-file "$OPERATOR_KEY_FILE" \
     --output-format json ops sumeragi params \
     > artifacts/sumeragi-params.json
   iroha --config ./localnet/client.toml \
     --operator-private-key-file "$OPERATOR_KEY_FILE" \
     --output-format json ops sumeragi status \
     > artifacts/sumeragi-status.json
   iroha --config ./localnet/client.toml \
     --operator-private-key-file "$OPERATOR_KEY_FILE" \
     --output-format json ops sumeragi diagnostics \
     > artifacts/sumeragi-diagnostics.json
   ```

3. ལས་འགུལ་གྱི་འགན་ཁུར་དེ་ དམིགས་གཏད་ TPS ལུ་ལག་ལེན་འཐབ་དགོ།
4. རྒྱུགས་བསྡོམས་ཀྱི་ འགོ་བཙུགས་དང་ བར་མཚམས་ དེ་ལས་ མཇུག་བསྡུ་བའི་སྐབས་ གནས་སྟངས་དང་ ཐོ་བཀོད་ཚུ་བཟུང་།
5. རྒྱུགས་ཚད་འདི་ གྲུབ་འབྲས་ རྒྱུན་ཁྱབ གི་ལྕོག་སྒྲིའི་ཐོག་ལས་དབྱེ་ཞིབ་འབད་དགོ།
6. གལ་ཏེ་ བང་རིམ་འདི་ བར་མ་ཡང་ན་ དམའ་བ་ཨིན་པ་ཅིན་ དུས་མཉམ་ལུ་ ཆ་རྐྱེན་གཅིག་བསྒྱུར་བཅོས་འབད་དེ་ བསྐྱར་ལོག་འབད།

## བརྟག་ཞིབ་སྙན་ཞུ་ འདྲ་ཕབ། {#benchmark-report-template}

ལཱ་འགན་ཨང་གྲངས་ཚུ་ ལོག་སྟེ་བཏོན་ནིའི་དོན་ལུ་ སྐབས་དོན་ལངམ་སྦེ་ཡོད་མི་རྐྱངམ་ཅིག་ དཔར་བསྐྲུན་འབད།

- Iroha གཏན་འཁེལ, གསར་བཏོན དང་ ཁྱད་ཆོས་ གདམ་རྟགས ཚུ་ ཚུ་ བཏོན་གཏང་ནི་
- བདེན་དཔྱད་འབད་མི་དང་བལྟ་རྟོག་འབད་མི་གི་གྱངས་ཁ།
- གྲོས་བསྟུན་གྱི་གནས་སྟངས་དང་ བཀྲམ་སྤེལ་འབད་ཡོད་པའི་ སྦྲག་སྒྲོམ་ དེ་ལས་ DA བཟོ་བཀོད་
- ཏག་ཏག་ `3f + 1` ཚོགས་ཆུང་དང་ ཚོགས་གྲངས་ དེ་ལས་ བལྟ་རྟོག་པའི་ཐོ་གཞུང་།
- `sumeragi.block`, `sumeragi.queues`, `sumeragi.limits`, ཡོངས་འབྲེལ་-ནང་འཛུལ་, དང་ ཚོང་འབྲེལ་-གྲལ་ཐིག་མཐའ་མཚམས་ཚུ།
- བརྡ་འཕྲིན་ཚད་འཇལ་གྱི་གསལ་སྡུད།
- མཐུན་རྐྱེན་དང་གསོག་འཇོག་ དེ་ལས་ OS ཁ་གསལ།
- དྲ་རྒྱ་ RTT, ཇི་ཊར་, གྱོང་གུན་, དང་བང་རིམ་ཚོད་དཔག
- ཚོང་འབྲེལ་སླ་བསྲེ་དང་ འབབ་ཁུངས་ཚད།
- TPS དང་ རྒྱུན་འགྲུལ་གྱི་རིང་ཚད་
- ངོས་ལེན་/མ་བཏུབ་ TPS
- p50/p95/p99 ཁས་ལེན་འགོར་འགྱངས།
- བང་རིམ་གཏིང་ཚད་དང་ཚིལ་ཚད།
- བསྒྱུར་བཅོས་ཚུ་བལྟ། བཀོག་བཞག་ཡོད་པའི་འཕྲིན་དོན་ཚུ་ བརླག་སྟོར་ཤོར་མི་-སྡེབ་ཚན་ལེན་ཐངས་ཚུ་དང་ DA-གཱེཊི་གྱངས་ཁ་བརྐྱབ་མི་ཚུ་ཨིན།
- CPU, དྲན་ཐོ། ཌིས་ཀིསི་དང་ལྡནམ་སྦེ་ ལག་ལེན་འཐབ་མི་ཁ་ཐིག་ཚུ་
