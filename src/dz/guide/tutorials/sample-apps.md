# དཔེ་ཚད་ལག་ལེན་ཚུ་དང་ ལག་ལེན་ལམ་སྟོན་ཚུ་ {#samples-and-recipes}

Iroha འབྱུང་ཁུངས་མཛོད་ཁང་ནང་ SDK བཀོད་སྒྲིག་དང་བརྟག་དཔྱད་ཆ་ཚང་ཚུ་ཡོདཔ་ད་ དེ་ཚུ་གིས་ མཐུད་མཚམས་བཟུམ་སྦེ་ བསྐྱར་ཞིབ་གཅིག་མཚུངས་སྦེ་ བརྟག་ཞིབ་འབདཝ་ཨིན།

## JavaScript ལག་ལེན་ལམ་སྟོན་ཚུ་ {#javascript-recipes}

[`javascript/iroha_js/recipes`](https://github.com/hyperledger-iroha/iroha/tree/0010c5a70039eac101a4846499ba9ceaf43eb65c/javascript/iroha_js/recipes) ཌེ་ཊི་མཱནསི་ཊི་གི་ཚོང་འབྲེལ་གྱི་ བཀྲམ་སྤེལ་འབད་ནིའི་དོན་ལས་ དཔེ་སྟོན་ཚུ་བཀོད་ཡོད་པའི་གནས་ཚུལ། Nexus གློག་ཐག་ར་བ་ཚུ་ བསྒྱུར་བཅོས་འབད་བ། NFT རྩིས་ཐོ་ལོག་བཤུད་འབད་ནི་དང་ ISO བྱ་རིམའི་ཐངས་དང་ Torii བཀྲམ་སྤེལ་འབད་ཐངས་: བཀྲམ་སྟོན་ཐངས་རེ་རེ་གིས་ ཡིག་ཆ་འདི་ ཨོ་ཕ་ལཱིན་ལས་འཕར་སོང་རུང་ ཡང་ན་ ཕྲ་འཕྲོས་ཅིག་ དགོཔ་འབད་རུང་ Torii མཐའ་མཇུག་གི་ཐིག་ཁྲ།

## Swift དང་ iOS {#swift-and-ios}

Swift SDK ད་ལྟོ་ གྱི་ཐད་ཁར་བརྟག་དཔྱད་འབད་ཡོད་པའི་དཔེ་སྟོན་ཚུ་གི་དོན་ལུ་ `IrohaSwift/Tests/IrohaSwiftTests` ལག་ལེན་འཐབ་ཨིན། བསྡུ་སྒྲིག་དང་ལྡནམ་བཟོ་ནིའི་དོན་ལས་ [Swift དང་ iOS](/dz/guide/tutorials/swift.md) ལུ་བལྟ་དགོ།

## Android {#android}

Android གསརཔ་གི་ལཱ་གི་དོན་ལུ་ [Kotlin, Android, དང་ Java](/dz/guide/tutorials/kotlin-java.md) ནང་བཤད་ཡོད་པའི་ Kotlin-དང་པ `core-jvm`, `client-android`, དང་ `offline-wallet-android` ཚད་གཞི ཚུ་ལག་ལེན་འཐབ། Kotlin SDK འདི་ Android ལག་ལེན་པ་ཚུ་གི་དོན་ལུ་ ཚད་ལྡན འགོ་བཙུགས་ས་ཨིན།
