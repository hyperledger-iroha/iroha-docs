# བཟོ་སྐྲུན་དང་ འཛིན་སྐྱོང་ {#configuration-and-management}

Iroha བཟོ་བཀོད་འདི་ ཁྱད་ཚད་ཅན་གྱི་གནས་རིམ་གཉིས་ཡོདཔ་ཨིན།

- གནས་སྐབས་ཀྱི་ འདྲ་མཉམ་དང་ མགྲིན་ཚབ་བཟོ་རྣམ་ཚུ་ TOML ཡིག་སྣོད་ནང་ལུ་བཞག་ཞིནམ་ལས་ བྱ་རིམ་འགོ་འབྱེད་འབད་བའི་སྐབས་ལུ་ བསྐྱར་ཞིབ་འབདཝ་ཨིན།
- ལྕགས་ཐག་ནང་བཟོ་སྐྲུན་འབད་མི་དེ་ [ `SetParameter`](/dz/blockchain/instructions.md#setparameter) གྱི་ཐོག་ལས་ བསྒྱུར་བཅོས་འབད་ཡོདཔ་ཨིན།

གནས་སྡུད་བཟོ་རྣམ་ཚུ་ ལག་ལེན་འཐབ་ནི་ འདི་ནོཌ་གི་ ངོ་རྟགས་དང་ ཡི་གུ་ དེ་ལས་ ཐོ་བཀོད་འབད་ཐངས་ དེ་ལས་ མགྲིན་འགྲུལ་ལེན་པའི་ལྡེ་མིག་ཚུ་གི་དོན་ལུ་ཨིན། གྲལ་ཐིག་ནང་ གཞི་སྒྲིག་འབད་ཐངས་འདི་ ལག་ལེན་འཐབ་ནི་དེ་ ཕྲང་ལམ་གྱིས་ ངོས་ལེན་འབད་དགོ་མི་དང་ ཡང་བསྐྱར་སྦེ་ བསྐྱར་གསོ་འབདཝ་ཨིན།

བཟོ་སྐྲུན་གྱི་ བྱ་སྤྱོད་འདི་ གཞི་སྒྲིག་གི་གནས་ཚད་ལས་ འོང་དགོཔ་ཨིན། མཐའ་འཁོར་གྱི་འགྱུར་ལྡནམ་ཚུ་ ས་གནས་ཀྱི་ལག་ཆས་ཚུ་ལུ་ བརྟག་ཞིབ་ནང་འཛུལ་ནིའི་དོན་ལས་ སྟབས་བདེཝ་འབྱུང་ནི་ཨིན་རུང་ དེ་དག་གིས་ བཟོ་སྐྲན་གི་ཁྱད་ཆོས་ཀྱི་སྒོ་ར་མ་འབདཝ་མ་ཚད་ ཁས་བླངས་ཅན་གྱི་གཞི་སྒྲིག་དེ་ཡང་ བསྒྱུར་བཅོས་མི་འབད་ཡོདཔ་ཨིན།
