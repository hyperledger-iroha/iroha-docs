# མཐུན་རྐྱེན་ལག་ལེན་གྱི་དོན་ལུ་ Key {#keys-for-network-deployment}

ཡོངས་འབྲེལ་ཆ་མཉམ་ལུ་ མཁན་པོ་ཚུ་གི་དོན་ལུ་ ཁྱད་པར་ཅན་ལྡེ་མིག་ཚུ་ དགོས་མཁོ་ཡོདཔ་ད་ རིག་པ་ཚུ་དང་ genesis signing དེ་ལས་ NPoS ཡང་ན་ Nexus profiles གི་དོན་ལུ་ BLS validator identities འདི་ཚུ་ཡང་ དགོཔ་ཨིན་མས།

## ལག་ལེན་འཐབ་སའི་ལྡེ་མིག་ཚུ་ {#where-keys-are-used}

- ཚོང་མགྲོན་པ་ཚུ་གི་མིང་ཐོ་བཀོད་ཀྱི་ལྡེ་མིག་ཚུ་ `client.toml` གི་འོག་ལུ་བཞག་ཡོདཔ་ཨིན། `[account]`.
- གྲྭ་ཚང་གི་ངོ་རྟགས་ཀྱི་ལྡེ་མིག་ཚུ་ `config.toml` ལུ་ `public_key` དང་ `private_key`སྦེ་བཞག་ཡོདཔ་ཨིན།
- འདྲན་འདྲ་ མཐོང་ཐངས་འདི་ `trusted_peers`ནང་ལུ་འདྲན་འདྲ་ཚུ་གི་གཞུང་ལྡེ་མིག་ཚུ་ལག་ལེན་འཐབ་ཨིན།
- BLS validator NPoS Profilesགི་དོན་ལུ་ ཐོབ་དབང་གི་ཁུངས་ཚུ་ `trusted_peers_pop` ལུ་བཞག་ཡོདཔ་ཨིན།
- Genesis signage གིས་ `[genesis].public_key` འདི་ peer config ནང་ལུ་ལག་ལེན་འཐབ་དོ་ཡོདཔ་མ་ཚད་ manifest ལུ་རྟགས་བཀོད་འབད་བའི་སྐབས་ སྒེར་གྱི་ལྡེ་མིག་འདི་ཡང་ ལག་ལེན་འཐབ་དོ་ཡོདཔ་ཨིན།

ས་གནས་ཀྱི་ ཡང་ན་ བརྟག་དཔྱད་ལག་ལེན་ཚུ་གི་དོན་ལུ་ Kagami གིས་ འ་ནི་ཡིག་སྣོད་ཚུ་ གཅིག་ཁར་སྤེལ་གཏང་དགོ།

```bash
cargo run --bin kagami -- localnet --build-line iroha3 --peers 4 --out-dir ./localnet
```

ད་ལྟོའི་ཐོ་བཀོད་འབད་ཡོད་པའི་དྲ་ལམ་དང་འབྲེལ་བའི་ཡིག་གཟུགས་ཚུ་གི་དོན་ལུ་ འགྲུལ་བསྐྱོད་ལམ་སྟོན་ལག་ལེན་འཐབ་དགོ།

```bash
cargo run --bin kagami -- wizard --profile nexus
```

## རང་རྐྱང་གི་ལྡེ་མིག་གཉིས་བཟོ་ནི། {#generate-individual-key-pairs}

`kagami keys` ལག་ལེན་འཐབ་ནི་ རང་རང་སོ་སོ་གི་ལྡེ་མིག་གི་དོན་ལུ་:

```bash
cargo run --bin kagami -- keys --algorithm ed25519 --json
```

BLS ཚོད་བསྲེ་སྣོད་ཚུ་གི་དོན་ལུ་ ལག་ལེན་གྱི་རྟགས་མཚན་ཚུ་ ඇතුළත්འབད་:

```bash
cargo run --bin kagami -- keys --algorithm bls_normal --pop --json
```

`--seed` ལག་ལེན་འཐབ་ནི་འདི་ སླར་ལོག་འབད་ཚུགས་པའི་བཟོ་སྐྲུན་འཕྲུལ་ཆས་ཚུ་གི་དོན་ལུ་རྐྱངམ་གཅིག་ཨིན། བཟོ་སྐྲུན་གྱི་ལཱ་ཚུ་ འགོ་འདྲེན་འཐབ་ནིའི་དོན་ལུ་ ལྕེ་མིག་གསརཔ་བཟོ། དེ་ལས་ སྒེར་གྱི་ལྡེ་མིག་ཚུ་ སྒྲིང་ཁྱིམ་གི་ཕྱི་ཁར་བཞག་དགོ།

## འདྲན་འདྲ་གི་མཐུན་ལམ་ {#peer-consistency}

བརྟན་རྟགས་དཔྱད་འབད་མི་ཆ་མཉམ་གྱིས་ genesis གྱི་མཐུན་རྐྱེན་, topology, trusted peer public keys, and validator PoPs གི་སྐོར་ལས་ གྲོས་བསྟུན་འབད་དགོཔ་ཨིན། གཅིག་ལས་མེད་མི་ ཡང་ན་མ་འདྲ་བའི་ peer key གིས་དྲ་རྒྱ་འདི་ འགོ་བཙུགས་ནི་ལས་ བཀག་འཛིན་འབད་ཚུགས། ཡང་ན་མཐུན་ལམ་ལུ་ ལྷོད་ཚུགསཔ་ཨིན།

བི་ཛིན་ཊི་ཡཱན་གི་འཛོལ་བ་ལུ་བཟོད་པ་བསྒོམ་མི་ ལག་ལེན་འཐབ་ནིའི་དོན་ལས་ ཉུང་ཤོས་རང་ འདྲན་འདྲ་བཞི་ཅིག་ལག་ལེན་འཐབ་དགོ། རིག་འཛིན་རེ་གིས་ རང་སོའི་ སྒེར་གྱི་ལྡེ་མིག་ཡོད་དགོཔ་ཨིན། ཨིན་རུང་ རིག་འཛིན་རེ་རེ་གི་དོན་ལུ་ དངོས་པོ་ཆ་མཉམ་གྱིས་ བློ་གཏད་ཚུགས་པའི་ རིག་འཛིན་གཅིག་ དགོཔ་ཨིན།

## ཚོང་མགྲོན་པ་ཚུ་གི་རྩིས་ཁྲ་ {#client-accounts}

`client.toml` ནང་གི་མགྲོན་པ་རྩིས་ཁྲ་འདི་ ཧེ་མ་ལས་འབྲེལ་མཐུད་ནང་ཡོད་དགོཔ་ཨིན། འདི་ genesis manifest ཡང་ན་ཤུལ་ལས་གྱི་ཞལ་འདེབས་ཅིག་གིས་ ཐོ་བཀོད་འབད་ཚུགས། genesis signing identityའདི་ དུས་ཡུན་རིང་པོའི་ལག་ལེན་རྩིས་ཁྲ་སྦེ་ ལག་ལེན་འཐབ་མ་བཅུག། genesis ཐོབ་ཐངས་འདི་ genesis round གི་སྐབས་ལུ་རྐྱངམ་གཅིག་ ལག་ལེན་འཐབ་དོ་ཡོདཔ་ད་ བཟོ་སྐྲུན་གྱི་མགྲོན་པ་ཚུ་གིས་ ཁོང་རའི་རྩིས་ཁྲ་དང་ འགན་འཁྲི་ཚུ་ལག་ལེན་འཐབ་དགོཔ་ཨིན།
