# མཐུན་རྐྱེན་ལག་ལེན་གྱི་དོན་ལུ་ ལྡེ་མིག {#keys-for-network-deployment}

ཡོངས་འབྲེལ་ག་ར་ལུ་ མཁོ་མངགས་འབད་མི་དང་ མཉམ་རོགས་ རིགས་མཚན་མཚན་རྟགས་བཀོད་ནི་དང་ NPoS ཡང་ན་ Nexus གསལ་སྡུད་ཚུ་གི་དོན་ལུ་ BLS བདེན་དཔྱད་འབད་མི་ངོ་རྟགས་ཚུ་གི་དོན་ལུ་ ལྡེ་མིག་རྒྱུ་ཆ་སོ་སོ་དགོཔ་ཨིན།

## ལག་ལེན་འཐབ་སའི་ལྡེ་མིག་ཚུ་ {#where-keys-are-used}

- མཁོ་སྤྲོད་འབད་མི་མིང་རྟགས་ལྡེ་མིག་ཚུ་ `client.toml` གི་འོག་ལུ་ `[account]` ནང་གསོག་འཇོག་འབད་ཡོདཔ་ཨིན།
- མཉམ་རོགས་ངོ་རྟགས་ལྡེ་མིག་ཚུ་ མཉམ་རོགས་རེ་རེ་ནང་ `config.toml` `public_key` དང་ `private_key` སྦེ་གསོག་འཇོག་འབད་ཡོདཔ་ཨིན།
- མཉམ་རོགས་འཚོལ་ཞིབ་འདི་གིས་ `trusted_peers` ནང་ལུ་ མཉམ་རོགས་རེ་རེ་གི་མི་མང་ལྡེ་མིག་ལག་ལེན་འཐབ་ཨིན།
- BLS བདེན་དཔྱད་འབད་མི་ བདག་དབང་གི་བདེན་ཁུངས་ཚུ་ NPoS གསལ་སྡུད་ཚུ་གི་དོན་ལུ་ `trusted_peers_pop` ནང་ལུ་གསོག་འཇོག་འབད་ཡོདཔ་ཨིན།
- ཇེ་ནིསི་མིང་རྟགས་བཀོད་མི་འདི་གིས་ མཐུན་སྒྲིག་རིམ་སྒྲིག་ནང་ `[genesis].public_key` དང་ གསལ་བསྒྲགས་མིང་རྟགས་བཀོད་པའི་སྐབས་ མཐུན་སྒྲིག་སྒེར་གྱི་ལྡེ་མིག་ལག་ལེན་འཐབ་ཨིན།

ས་གནས་ཀྱི་ ཡང་ན་ བརྟག་དཔྱད་ལག་ལེན་ཚུ་གི་དོན་ལུ་ Kagami གིས་ འ་ནི་ཡིག་སྣོད་ཚུ་ གཅིག་ཁར་སྤེལ་གཏང་དགོ།

```bash
cargo run --bin kagami -- localnet --peers 4 --out-dir ./localnet
```

ད་ལྟོ་ཡོད་པའི་ཡོངས་འབྲེལ་ཡང་ན་གསལ་སྡུད་ཅིག་གི་དོན་ལུ་ ལམ་སྟོན་འབད་ཡོད་པའི་རྒྱུན་རིམ་འདི་ལག་ལེན་འཐབ།

```bash
cargo run --bin kagami -- wizard
```

## རང་རྐྱང་གི་ལྡེ་མིག་གཉིས་བཟོ་ནི། {#generate-individual-key-pairs}

རང་དབང་ལྡེ་མིག་རྒྱུ་ཆའི་དོན་ལུ་ `kagami keys` ལག་ལེན་འཐབ།

```bash
cargo run --bin kagami -- keys --algorithm ed25519 \
  --out-dir ./client-key
```

BLS བདེན་དཔྱད་པ གི་ནང་དོན་གི་དོན་ལུ་ བདག་དབང་བདེན་ཁུངས བཙུགས།

```bash
cargo run --bin kagami -- keys --algorithm bls_normal --pop \
  --out-dir ./validator-key
```

`--seed-hex` འདི་ལོག་སྟེ་གྲུབ་འབྲས་གཅིག་པའི་ གསར་སྤེལ བརྟག་དཔྱད་གནས་སྡུད གི་དོན་ལུ་ ཏག་ཏག་ 32-བཱའིཊི བཅུ་དྲུག་རྟེན གསང་བ དང་གཅིག་ཁར་རྐྱངམ་ཅིག་ལག་ལེན་འཐབ། ཐོན་སྐྱེད་བཙུགས་སྒྲིག་ གི་དོན་ལུ་ Kagami གིས་ བཀོལ་སྤྱོད་རིམ་ལུགས གང་བྱུང་ཚད ལག་ལེན་འཐབ་ནིའི་དོན་ལུ་འདི་མ་བཙུགས། དེ་ལས་གསང་བཟོ་མ་འབད་བའི་ སྒེར-ལྡེ་མིག ཕྱིར་འདྲེན འདི་ཆ་འཇོག་ཡོད་པའི་ཉེན་སྲུང་བཞག་སའི་མཚམས་ནང་སྤོ། བཀའ་རྒྱ གིས་ སྒེར ལྡེ་མིག་ཚུ ནམ་ཡང་དཔར་མི་བསྐྲུན།

## མཐུད་མཚམས་གི་མཐུན་ལམ་ {#peer-consistency}

བདེན་དཔྱད་པ ཆ་མཉམ་གྱིས་ འགོ་ཐོག ཚོང་འབྲེལ གཅིག་པ་ དྲ་བཀོད དང་ བློ་གཏད་ཅན མཉམ་རོགས གི་ མི་མང ལྡེ་མིག ཚུ་དང་ བདེན་དཔྱད་པ PoPs ཚུ་གུར་མོས་མཐུན་འབད་དགོ། མཉམ་རོགས ལྡེ་མིག གཅིག་བྱང་ནི་ཡང་ན་མ་མཐུན་པ་ཅིན་ དྲ་རྒྱ འགོ་བཙུགས་མ་ཚུགསཔ་ཡང་ན་ གྲོས་མཐུན ལུ་ལྷོད་མ་ཚུགསཔ་འབད་ཚུགས།

ཉུང་མཐའ་བཱའི་ཛན་ཊིན་-འཛོལ་བ་བཟོད་བསྲན་ཅན་གྱི་བཀྲམ་སྤེལ་གྱི་དོན་ལུ་ ཉུང་མཐའ་མཉམ་རོགས་བཞི་ལག་ལེན་འཐབ། མཉམ་རོགས་རེ་ལུ་ རང་སོའི་སྒེར་གྱི་ལྡེ་མིག་དགོཔ་ཨིན་ དེ་འབདཝ་ད་ མཉམ་རོགས་རིམ་སྒྲིག་རེ་རེ་ལུ་ བློ་གཏད་ཅན་གྱི་མཉམ་རོགས་ཆ་ཚན་གཅིག་དགོཔ་ཨིན།

## ཚོང་མགྲོན་པ་ཚུ་གི་རྩིས་ཐོ་ {#client-accounts}

`client.toml` ནང་ལུ་ཡོད་པའི་ མཁོ་སྤྲོད་རྩིས་ཐོ་འདི་ ཧེ་མ་ལས་རང་ རིམ་སྒྲིག་གུ་ཡོདཔ་དགོ། འདི་ཡང་ རིགས་མཚན་གྱི་གསལ་བསྒྲགས་དང་ ཡང་ན་ ཤུལ་ལས་ ཚོང་འབྲེལ་གྱི་ཐོག་ལས་ ཐོ་བཀོད་འབད་ཚུགས། རིགས་མཚན་མཚན་རྟགས་ངོ་རྟགས་འདི་ ཡུན་རིངམོ་སྦེ་ ལག་ལེན་འཐབ་ནིའི་རྩིས་ཐོ་ཅིག་སྦེ་ ལག་ལེན་འཐབ་ནི་ལས་ འཛེམ་དགོ། རིགས་མཚན་གྱི་ཐོབ་དབང་འདི་ རིགས་མཚན་གྱི་སྐབས་ལུ་རྐྱངམ་ཅིག་ ལག་ལེན་འཐབ་དོ་ཡོདཔ་ད་ བཟོ་བསྐྲུན་གྱི་ཚོང་མགྲོན་པ་ཚུ་གིས་ ཁོང་རའི་རྩིས་ཐོ་དང་འགན་ཁུར་ཚུ་ ལག་ལེན་འཐབ་དགོཔ་ཨིན།
