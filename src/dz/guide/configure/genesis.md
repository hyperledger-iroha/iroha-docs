## ཡིག་སྣོད་ཚུ། {#files}

## Genesis མཚན་རྟགས་བཀོད་དོ། {#signing-genesis}

ཁྱོད་ཀྱིས་ ལག་ཐོག་ལས་ གསལ་སྟོན་ཅིག་ཞུན་དག་འབད་བ་ཅིན་ ཆ་རོགས་ཚུ་འགོ་མ་བཙུགས་པའི་ཧེ་མ་ ནུས་ལྡན་བཟོ་ཞིནམ་ལས་ མིང་རྟགས་བཀོད་དགོ།

```bash
cargo run --bin kagami -- genesis validate ./genesis.json
cargo run --bin kagami -- genesis sign ./genesis.json \
  --private-key-file "$GENESIS_PRIVATE_KEY_FILE" \
  --out-file ./genesis.signed.nrt
```

`GENESIS_PRIVATE_KEY_FILE` ཇོ་བདག་གིས་འཛིན་པའི་ཐབས་ལམ་ཅིག་འོང་དགོ།`0600`, འབྲེལ་མཐུད་རྐྱང་པ།
དུས་རྒྱུན་གྱི་ཡིག་སྣོད་ནང་ ཀེ་ནོ་ནིཀ་སྒེར་གྱི་ལྡེ་མིག་མལ་ཊི་ཧེཤ་གཅིག་དང་ མཐའ་མཇུག་ཅིག་ཡོདཔ་ཨིན།
གྲལ་ཐིག་གསརཔ། Kagami བརྡ་མཚོན་གྱི་འབྲེལ་ལམ་ཚུ་ ངོས་ལེན་མ་འབད་བར་ རིགས་མཚན་སྒེར་གྱི་སྒེར་གྱི་ ནམ་ཡང་ ངོས་ལེན་མི་འབད།
བརྡ་བཀོད་གྲལ་ཐིག་གུ་ལྡེ་མིག།

NPoS གི་དོན་ལུ་ ཡང་ན་ Nexus གསལ་སྡུད་ཚུ་ ཊོ་པོ་ལོ་ཇི་དང་ BLS བདག་དབང་གི་བདེན་ཁུངས།
