## ཡིག་སྣོད་ཚུ། {#files}

ཡར་འཕེལ་གྱི་མཛོད་ཁང་གིས་ སྔོན་སྒྲིག་གསལ་སྟོན་ཅིག་ ༡ ལུ་གཏངམ་ཨིན། `defaults/genesis.json`. Kagami-བཟོ་བཏོན་འབད་ཡོད་པའི་ཡོངས་འབྲེལ་ཚུ་གིས་ ཁོང་རའི་གསལ་སྟོན་དང་མིང་རྟགས་བཀོད་ཡོད་པའི་ཚོང་འབྲེལ་འདི་ ནང་ལུ་བྲིས། ཐོན་འབྲས་སྣོད་ཐོ་འདི་:

```bash
cargo run --bin kagami -- localnet --peers 4 --out-dir ./localnet
```

སྣོད་ཐོ་དེ་ནང་ བཟོ་བཏོན་འབད་ཡོད་པའི་ `README.md` གིས་ སེལ་འཐུ་འབད་ཡོད་པའི་གསལ་སྡུད་ཀྱི་དོན་ལུ་ ཡིག་སྣོད་གཏན་གཏན་ཚུ་ཐོ་བཀོད་འབདཝ་ཨིནམ་དང་ བརྡ་བཀོད་ཚུ་འགོ་བཙུགསཔ་ཨིན།

## མཐུད་མཚམས་རིམ་སྒྲིག། {#peer-configuration}

`[genesis]` གི་ `config.toml` དབྱེ་ཚན་ནང་ མིང་རྟགས་བཀོད་ཡོད་པའི་རིགས་མཚན་ཚོང་འབྲེལ་ལུ་ མཉམ་འབྲེལ་པ་ཚུ་གིས་ བརྡ་སྟོནམ་ཨིན།

```toml
[genesis]
file = "./genesis.signed.nrt"
public_key = "ed0120..."
```

ཡོངས་འབྲེལ་ནང་ལུ་ཡོད་པའི་ མཉམ་རོགས་ཆ་མཉམ་གྱིས་ མཚན་རྟགས་བཀོད་ཡོད་པའི་ རིགས་མཚན་ཚོང་འབྲེལ་དང་ རིགས་མཚན་མི་མང་ལྡེ་མིག་ལུ་ མོས་མཐུན་འབད་དགོ།

## འགོ་ཐོག མཚན་རྟགས་བཀོད་དོ། {#signing-genesis}

ཁྱོད་ཀྱིས་ལག་ཐོག་ལས་ གསལ་བསྒྲགས་ཅིག་ཞུན་དག་འབད་བ་ཅིན་ མཉམ་རོགས་འགོ་མ་བཙུགས་པའི་ཧེ་མ་ བདེན་དཔྱད་འབད་དེ་ མིང་རྟགས་བཀོད་དགོ།

```bash
cargo run --bin kagami -- genesis validate ./genesis.json
cargo run --bin kagami -- genesis sign ./genesis.json \
  --private-key-file "$GENESIS_PRIVATE_KEY_FILE" \
  --out-file ./genesis.signed.nrt
```

`GENESIS_PRIVATE_KEY_FILE` ཇོ་བདག་གིས་འཛིན་པའི་ཐབས་ལམ་ཅིག་འོང་དགོ།`0600`, འབྲེལ་མཐུད་རྐྱང་པ། དུས་རྒྱུན་གྱི་ཡིག་སྣོད་ནང་ ཚད་ལྡན་སྒེར་གྱི་ལྡེ་མིག་མལ་ཊི་ཧེཤ་གཅིག་དང་ མཐའ་མཇུག་ཅིག་ཡོདཔ་ཨིན། གྲལ་ཐིག་གསརཔ། Kagami བརྡ་མཚོན་གྱི་འབྲེལ་ལམ་ཚུ་ ངོས་ལེན་མ་འབད་བར་ རིགས་མཚན་སྒེར་གྱི་སྒེར་གྱི་ ནམ་ཡང་ ངོས་ལེན་མི་འབད། བརྡ་བཀོད་གྲལ་ཐིག་གུ་ལྡེ་མིག།

NPoS གི་དོན་ལུ་ ཡང་ན་ Nexus གསལ་སྡུད་ཚུ་ ཊོ་པོ་ལོ་ཇི་དང་ BLS བདག་དབང་གི་བདེན་ཁུངས། བཟོ་བཏོན་འབད་ཡོད་པའི་གསལ་སྡུད་ཀྱིས་དགོཔ་ཨིན། Kagami `localnet`, `wizard`, དང་གསལ་སྡུད། བཟོ་སྐྲུན བརྡ་བཀོད་ཚུ་གིས་ ཁ་གསལ་དེ་ཚུ་ རང་བཞིན་གྱིས་ འཛིན་སྐྱོང་འཐབ་ཨིན།

## འབྱུང་ཁུངས་བསྐྱར་དུ་ཁས་ལེན་འབད་དོ། {#recommitting-genesis}

མཉམ་རོགས་ཀྱིས་ དེ་གི་གསོག་འཇོག་སྟོངམ་སྦེ་ཡོད་པའི་སྐབས་ལུ་རྐྱངམ་ཅིག་ རིགས་མཚན་འབདཝ་ཨིན། བཀོ་བཞག་བཏུབ་པའི་ ས་གནས་ཀྱི་དྲྭ་རྒྱ་ནང་ལུ་ རིགས་མཚན་གསརཔ་བརྟག་དཔྱད་འབད་ནི་གི་དོན་ལུ་ མཉམ་རོགས་ཚུ་བཀག་ཞིནམ་ལས་ ཁོང་གིས་བཟོ་མི་ མངའ་སྡེ་གི་སྣོད་ཐོ་འདི་བཏོན་བཏང་ཞིནམ་ལས་ མིང་རྟགས་བཀོད་མི་ རིགས་མཚན་གསརཔ་ལས་ འགོ་བཙུགསཔ་ཨིན། བདེན་དཔྱད་འབད་མི་ག་ར་གིས་ གནས་སྤོ་འགྱོ་མི་གཅིག་མཚུངས་སྦེ་ མཉམ་འབྲེལ་མ་འབད་ཚུན་ཚོད་ གཡོག་བཀོལ་བའི་ཡོངས་འབྲེལ་ནང་ རིགས་མཚན་ཚབ་མ་བཙུགས།
