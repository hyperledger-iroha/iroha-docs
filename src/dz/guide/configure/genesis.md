## ཡིག་སྣོད་ཚུ། {#files}

འབྱུང་ཁུངས་མཛོད་ནང་ `defaults/genesis.template.json` ལུ་སྔོན་སྒྲིག་འབྱུང་ཁུངས་དཔེ་གཞི་ཡོད། དཔེ་གཞི་འདི་ཆ་ཚང་མེནམ་ལས་ `kagami genesis materialize` གིས་གསལ་སྟོན་ཡིག་ཆ་ལུ་མ་བསྒྱུར་ཚུན་ བདེན་དཔྱད་ མིང་རྟགས་བཀོད་ནི་ ཡང་ན་མཐུད་གནས་ཀྱིས་ལག་ལེན་འཐབ་མི་ཚུགས། Kagami གིས་བཟོ་པའི་དྲ་ལམ་ཚུ་གིས་ རང་གི་གསལ་སྟོན་ཡིག་ཆ་དང་མིང་རྟགས་ཅན་གྱི་ཚོང་འབྲེལ་འདི་ཕྱིར་འདོན་སྣོད་ཐོ་ནང་བྲིཝ་ཨིན།

```bash
cargo run --bin kagami -- localnet generate --peers 4 --out-dir ./localnet
```

སྣོད་ཐོ་དེ་ནང་ བཟོ་བཏོན་འབད་ཡོད་པའི་ `README.md` གིས་ སེལ་འཐུ་འབད་ཡོད་པའི་གསལ་སྡུད་ཀྱི་དོན་ལུ་ ཡིག་སྣོད་གཏན་གཏན་ཚུ་ཐོ་བཀོད་འབདཝ་ཨིནམ་དང་ བརྡ་བཀོད་ཚུ་འགོ་བཙུགསཔ་ཨིན།

## མཐུད་མཚམས་རིམ་སྒྲིག། {#peer-configuration}

མཐུད་གྲོགས་ཚུ་གིས་ `config.toml` གི་ `[genesis]` དབྱེ་ཚན་ནང་མིང་རྟགས་ཅན་གྱི་འགོ་ཐོག་ཚོང་འབྲེལ་ལུ་གཞི་བཞགཔ་ཨིནམ་དང་ དེའི་རེ་བ་ཡོད་པའི་བསྡུས་རྟགས་འདི་ཡིག་སྣོད་སོ་སོ་ནང་གཏན་འཁེལ་བཞགཔ་ཨིན།

```toml
[genesis]
file = "./genesis.signed.nrt"
public_key = "ed0120..."
expected_hash_file = "./genesis.expected_hash"
```

དྲ་ལམ་ནང་གི་མཐུད་གྲོགས་ག་ར་ མིང་རྟགས་ཅན་གྱི་འགོ་ཐོག་ཚོང་འབྲེལ་དང་འགོ་ཐོག་གནས་སྟངས་ཀྱི་མི་མང་ལྡེ་མིག་ལུ་མཐུན་དགོ། རེ་བ་ཡོད་པའི་བསྡུས་རྟགས་ཡིག་སྣོད་འདི་ འགོ་བཙུགས་གསརཔ་དང་ལོག་འགོ་བཙུགས་གཉིས་ཆ་ར་ལུ་དགོ། `kagami genesis sign --expected-hash-out` གིས་འདི་བྲིཝ་ཨིན།

## འགོ་ཐོག མཚན་རྟགས་བཀོད་དོ། {#signing-genesis}

ཁྱོད་ཀྱིས་ལག་ཐོག་ལས་ གསལ་བསྒྲགས་ཅིག་ཞུན་དག་འབད་བ་ཅིན་ མཉམ་རོགས་འགོ་མ་བཙུགས་པའི་ཧེ་མ་ བདེན་དཔྱད་འབད་དེ་ མིང་རྟགས་བཀོད་དགོ།

```bash
cargo run --bin kagami -- genesis validate ./genesis.json
cargo run --bin kagami -- genesis sign ./genesis.json \
  --private-key-file "$GENESIS_PRIVATE_KEY_FILE" \
  --out-file ./genesis.signed.nrt \
  --expected-hash-out ./genesis.expected_hash
```

`GENESIS_PRIVATE_KEY_FILE` ཇོ་བདག་གིས་འཛིན་པའི་ཐབས་ལམ་ཅིག་འོང་དགོ།`0600`, འབྲེལ་མཐུད་རྐྱང་པ། དུས་རྒྱུན་གྱི་ཡིག་སྣོད་ནང་ ཚད་ལྡན་སྒེར་གྱི་ལྡེ་མིག་མལ་ཊི་ཧེཤ་གཅིག་དང་ མཐའ་མཇུག་ཅིག་ཡོདཔ་ཨིན། གྲལ་ཐིག་གསརཔ། Kagami བརྡ་མཚོན་གྱི་འབྲེལ་ལམ་ཚུ་ ངོས་ལེན་མ་འབད་བར་ རིགས་མཚན་སྒེར་གྱི་སྒེར་གྱི་ ནམ་ཡང་ ངོས་ལེན་མི་འབད། བརྡ་བཀོད་གྲལ་ཐིག་གུ་ལྡེ་མིག།

NPoS ཡང་ན་ SORA Nexus གསལ་སྡུད་ཚུའི་དོན་ལུ་ བཟོ་པའི་གསལ་སྡུད་ཀྱིས་དགོ་པའི་མཐུད་ཚུལ་དང་ BLS བདག་དབང་གི་བདེན་ཁུངས་བཙུགས། Kagami གི་ `localnet generate`, `wizard`, དང་ `sora-network generate` བརྡ་བཀོད་ཚུ་གིས་ཁ་གསལ་དེ་ཚུ་རང་བཞིན་གྱིས་འབདཝ་ཨིན།

## འབྱུང་ཁུངས་བསྐྱར་དུ་ཁས་ལེན་འབད་དོ། {#recommitting-genesis}

ཡོངས་འབྲེལ་གསརཔ་ཅིག་ རང་གི་མཚན་རྟགས་བཀོད་པའི་འགོ་ཐོག་ཆ་སྡེ་ལས་འགོ་བཙུགསཔ་ཨིན། བཀོག་བཞག་ཆོག་པའི་ཉེ་གནས་ཡོངས་འབྲེལ་ནང་ འགོ་ཐོག་ཆ་སྡེ་སོ་སོ་ཅིག་བརྟག་ཞིབ་འབད་ནི་ལུ་ མཐུད་གྲོགས་ཚུ་བཀག་ཞིནམ་ལས་ དེ་ཚུ་གི་བཟོ་བའི་གནས་སྟངས་སྣོད་ཐོ་བཏོན་གཏང་སྟེ་ མཚན་རྟགས་བཀོད་པའི་འགོ་ཐོག་ཆ་སྡེ་གསརཔ་ལས་འགོ་བཙུགས། གཡོག་བཀོལ་བཞིན་པའི་ཡོངས་འབྲེལ་ཅིག་གིས་ འགོ་ཐོག་ཆ་སྡེ་བརྗེ་སོར་འབད་ནི་འདི་ཡར་སེང་གི་ཐབས་ལམ་སྦེ་ནམ་ཡང་ལག་ལེན་འཐབ་མི་ཆོག། གནས་ལུགས་ངེས་ཚིག་གི་འགྱུར་བ་ཚུ་ལུ་ སྐྱོང་སྲིད་ཀྱིས་དབང་ཆ་སྤྲོད་པའི་གདམ་ཁ་བསྒྱུར་བ་དང་ གདམ་ཁ་རྐྱབ་པའི་ངེས་ཚིག་དང་འགན་ཁུར་ཚུའི་དོན་ལུ་འོས་ཚད་ཞིབ་དཔྱད་དགོཔ་ཨིན།
