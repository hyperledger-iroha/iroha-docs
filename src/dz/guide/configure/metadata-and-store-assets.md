# Metadata དང་ Ledger སྒྲིང་སྒྲི་གི་ གདམ་ཁ་ཚུ་ {#metadata-and-ledger-storage-choices}

Iroha 3 ཌའི་ཊ་གི་དཔེ་ཚད་ནང་ རང་བཞིན་གྱི་ལྡེ་མིག་གོང་རྩིས་ཚུ་གི་དོན་ལུ་ ཁྱད་པར་ཅན་ `Store` རྒྱུ་དངོས་དབྱེ་བ་མེད་ཨིན། འ་ནི་གནས་སྡུད་ཀྱི་ གདམ་ཁ་ཚུ་ལག་ལེན་འཐབ་དགོ།

## གཞི་རྟེན་འབྱུང་ཁུངས་ {#metadata}

[metadata](/dz/blockchain/metadata.md) ལག་ལེན་འཐབ་ནི་ ལེ་ཌཇར་གི་དངོས་པོ་ནང་ཚུད་མི་ JSON field ཆུང་ཀུ་ཚུ་གི་དོན་ལུ་:

- མིང་དང་ ཐོ་བཀོད་ཚུ་སྟོན་ནི་
- འབྲེལ་མཐུད་འབད་ IDs
- སྲིད་བྱུས་ཀྱི་པདྨ་ཆུང་ཀུ་ཚུ་
- URIs, CIDs ཡང་ན་ SoraFS ཕྲང་ལམ་ཚུ་ནང་ སྦོམ་པའི་ ཁེ་ཕན་གྱི་ཁེ་རྒུད་ཚུ་ལུ་ བཏོན་དོ་ཡོདཔ་ཨིན།

metadata འདི་ world state གི་ཆ་ཤས་ཅིག་ཨིནམ་ལས་ འདི་ལུ་བདག་འཛིན་འཐབ་མི་ ობიექტიདང་གཅིག་ཁར་ལོག་གཏོགསཔ་ཨིན། ཀི་བཱའིན་ཌ་ཚུ་བརྟན་ཏོག་ཏོ་དང་ གནས་གོང་ཚུ་འཇམ་ཏོང་ཏོ་སྦེ་བཞག་ནི་དང་ ངོས་ལེན་ཚུ་ གསལ་ཏོག་ཏོ་སྦེ་བཞག་ནི། ཡིག་སྣོད་སྦོམ་དང་ ཐོ་བཀོད་ཡིག་སྣོད་ཚུ་ ཡང་ན་ ཡོངས་གྲགས་ཅན་གྱི་ལག་ལེན་གྱི་གནས་སྟངས་ཚུ་ ཐད་ཀར་དུ་ metadata ནང་མ་སྤེལད།

## ཨང་གྲངས་ཀྱི་རྒྱུ་དངོས་ཚུ་དང་ NFTs {#numeric-assets-and-nfts}

[རྒྱུ་དངོས་](/dz/blockchain/assets.md)དང་ [NFTs](/dz/blockchain/nfts.md)ཚུ་ ལག་ལེན་འཐབ་ནི་ཨིནམ་ད་ གནས་སྟངས་དེ་ ཚད་ལྡན་སྦེ་ཡོད་:

- ཨང་གྲངས་ཀྱི་རྒྱུ་དངོས་ཚུ་ སྦྲུལ་གཏད་མ་དངུལ་གྱི་དོན་ལུ་
- NFTs རང་རྐྱང་གི་བདག་འཛིན་གྱི་ཐོ་ཡིག་ཚུ་གི་དོན་ལུ་
- [RWAs](/dz/blockchain/rwas.md)དང་ ཌོ་མ་ནེསི་ཁེ་རྐྱང་གི་ གནད་དོན་གཞན་ཚུ་ད་ལྟོའི་གནས་སྟངས་ནང་ ལག་ལེན་འཐབ་མི་ གནས་སྡུད་དཔེ་རྙིང་འདི་གིས་ འདི་ཚུ་གི་སྐོར་ལས་ གསལ་སྟོན་འབད་འོང་།

རྒྱུ་དངོས་དང་ NFTs ལུ་ རང་སོའི་རང་སོའི་ IDs, སྲོལ་འཁོར་གྱི་བྱུང་རྐྱེན་ཚུ་, བསྒྱུར་བཅོས་འབད་ནིའི་ སྤྱོད་ལམ་, དང་ ངོས་ལེན་བརྟག་དཔྱད་ཚུ་ཡོདཔ་ཨིན། ཁོང་རའི་བདག་དབང་, དུམ་གྲ་, ཡང་ན་ བསྒྱུར་བཅོས་ཀྱི་ལོ་རྒྱུས་ནང་ གནད་དོན་འབྱུང་བའི་སྐབས་ metadata ལས་དྲག་ཤོས་ཨིན།

## གྲལ་ཐིག་ལས་ཕྱི་ཁར་ གནས་སྡུད་ཚུ་ {#off-chain-data}

མཁོ་ཆས་སྦོམ་དང་ ཡང་ཅིན་ བསྒྱུར་བཅོས་འབད་ཚུགས་པའི་ ཁེ་ཕན་གྱི་ཅ་ལ་ཚུ་གི་དོན་ལུ་ ལྕགས་ཐག་གི་ཕྱི་ཁར་བཞག་སའི་གནས་སྟངས་ལག་ལེན་འཐབ་། ལྕགས་chainནང་ལུ་ གནས་ཚད་བརྟན་ཏོག་ཏོ་ཅིག་རྐྱངམ་གཅིག་ལུ་བཞག་ནི། དཔེར་ན་:

- འོག་གི་ཤོག་ལེབ་ཚུ་
- URI
- SoraFS ཕྲང་ལམ་ ཡང་ན་ འགྲུལ་འཕྲིན་ཁ་བྱང་།
- ཐོ་བཀོད་ལག་ཁྱེར་གྱི་ཐོག་ལས་ ལག་ལེན་འཐབ་མི་ ཁས་བླངས་ཡིག་ཚང་

འདི་གིས་ WSV ཆུང་ཀུ་ཅིག་སྦེ་བཞག་པའི་ཁར་ ཐབས་ཤེས་ལག་ལེན་གྱིས་ ལྕགས་ཐག་ལས་ཕྱི་ཁར་ ཁེ་ཕན་གྱི་ཅ་ལ་དེ་ ལྕགས་ཀྱུའི་ནང་གཞི་བསྟུན་དང་མཐུནམ་ཨིན་ན་ བརྟག་ཞིབ་འབད་ཚུགསཔ་བཟོཝ་ཨིན།

## ས་གནས་ གདམ་ཁ་རྐྱབ་ནི་ {#choosing-a-location}

འ་ནཱ་གི་ཁྲིམས་འདི་ལག་ལེན་འཐབ་:

- ག་དེམ་ཅིག་སྦེ་འདི་ Ledger འདྲ་ཕབ་ཅིག་ཨིན་པ་ཅིན་ metadata ལག་ལེན་འཐབ་དགོ།
- གནས་གོང་ཅན་ ཡང་ན་ བརྗེ་སོར་འབད་ཚུགས་པ་ཅིན་ རྒྱུ་དངོས་ཅིག་སྦེ་ བཟོ་བཀོད་གཏང་། NFT ཡང་ན་ ཌོ་མ་ནེསི་ཁེ་རྐྱང་གི་དངོས་པོ་ཅིག་ཨིན།
- WSV གྱི་ཕྱི་ཁར་བཞག་ཞིནམ་ད་ དབྱེ་ཞིབ་འབད་ཚུགས་པའི་ བསྡུ་ཡིག་འདི་ ལྕགས་ཐག་ནང་ལུ་བཙུགས་ཏེ་ བཙུགས།
