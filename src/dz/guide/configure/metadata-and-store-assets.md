# གནས་བརྡ་དང་རྩིས་དེབ་གསོག་འཇོག་གི་གདམ་ཁ་ཚུ་ {#metadata-and-ledger-storage-choices}

Iroha 3 ཌའི་ཊ་གི་དཔེ་ཚད་ནང་ རང་བཞིན་གྱི་ལྡེ་མིག་གོང་རྩིས་ཚུ་གི་དོན་ལུ་ ཁྱད་པར་ཅན་ `Store` རྒྱུ་དངོས་དབྱེ་བ་མེད་ཨིན། འ་ནི་གནས་སྡུད་ཀྱི་ གདམ་ཁ་ཚུ་ལག་ལེན་འཐབ་དགོ།

## གཞི་རྟེན་འབྱུང་ཁུངས་ {#metadata}

[ཟུར་གནས་གནད་སྡུད](/dz/blockchain/metadata.md) ལག་ལེན་འཐབ་ནི་ ལེ་ཌཇར་གི་དངོས་པོ་ནང་ཚུད་མི་ JSON ས་སྒོ ཆུང་ཀུ་ཚུ་གི་དོན་ལུ་:

- མིང་དང་ཁ་ཡིག་བཀྲམ་སྟོན་འབད།
- མཉམ་བསྡོམས་ཨའི་ཌི་ཚུ།
- སྲིད་བྱུས་ཆུང་བའི་དར་ཆ།
- URIs, CIDs ཡང་ན་ SoraFS ཕྲང་ལམ་ཚུ་ནང་ སྦོམ་པའི་ ནང་དོན་གནད་སྡུད་གྱི་ཁེ་རྒུད་ཚུ་ལུ་ བཏོན་དོ་ཡོདཔ་ཨིན།

མེ་ཊ་ཌེ་ཊ་འདི་འཛམ་གླིང་གནས་སྟངས་ཀྱི་ཆ་ཤས་ཅིག་ཨིནམ་དང་ དེ་གི་བདག་དབང་འབད་མི་དངོས་པོ་དང་གཅིག་ཁར་སླར་ལོག་འབདཝ་ཨིན། ལྡེ་མིག་ཚུ་ བརྟན་ཏོག་ཏོ་དང་ གནས་གོང་ཚུ་ བསྡུ་སྒྲིག་འབད་དེ་ གནང་བ་ཚུ་ གསལ་ཏོག་ཏོ་སྦེ་བཞག། ཡིག་ཆ་སྦོམ་ཚུ་དང་ དྲན་ཐོ་ཚུ་ ཡང་ན་ མཐོ་དྲགས་གློག་རིམ་གནས་སྟངས་ཚུ་ ཐད་ཀར་དུ་ མེ་ཊ་ཌེ་ཊ་ནང་ གསོག་འཇོག་མ་འབད།

## ཨང་གྲངས་ཀྱི་རྒྱུ་དངོས་ཚུ་དང་ NFTs {#numeric-assets-and-nfts}

[རྒྱུ་དངོས་](/dz/blockchain/assets.md)དང་ [NFTs](/dz/blockchain/nfts.md)ཚུ་ ལག་ལེན་འཐབ་ནི་ཨིནམ་ད་ གནས་སྟངས་དེ་ ཚད་ལྡན་སྦེ་ཡོད་:

- བརྗེ་སོར་འབད་བཏུབ་པའི་ལྷག་ལུས་ཚུ་གི་དོན་ལུ་ཨང་གྲངས་ཀྱི་རྒྱུ་དངོས་ཚུ།
- གཞན་དང་མ་འདྲ་བའི་བདག་དབང་ཡོད་པའི་དྲན་ཐོའི་དོན་ལུ་ NFTs ཚུ།
- [RWAs](/dz/blockchain/rwas.md)དང་ ཌོ་མ་ནེསི་ཁེ་རྐྱང་གི་ གནད་དོན་གཞན་ཚུ་ད་ལྟོའི་གནས་སྟངས་ནང་ ལག་ལེན་འཐབ་མི་ གནས་སྡུད་དཔེ་རྙིང་འདི་གིས་ འདི་ཚུ་གི་སྐོར་ལས་ གསལ་སྟོན་འབད་འོང་།

རྒྱུ་དངོས་དང་ NFTs ལུ་ རང་སོའི་རང་སོའི་ IDs, སྲོལ་འཁོར་གྱི་བྱུང་རྐྱེན་ཚུ་, བསྒྱུར་བཅོས་འབད་ནིའི་ སྤྱོད་ལམ་, དང་ ངོས་ལེན་བརྟག་དཔྱད་ཚུ་ཡོདཔ་ཨིན། ཁོང་རའི་བདག་དབང་, དུམ་གྲ་, ཡང་ན་ བསྒྱུར་བཅོས་ཀྱི་ལོ་རྒྱུས་ནང་ གནད་དོན་འབྱུང་བའི་སྐབས་ ཟུར་གནས་གནད་སྡུད ལས་དྲག་ཤོས་ཨིན།

## གྲལ་ཐིག་ལས་ཕྱི་ཁར་ གནས་སྡུད་ཚུ་ {#off-chain-data}

སྦོམ་ཡང་ན་བསྒྱུར་བཅོས་འབད་བཏུབ་པའི་ འབབ་ཁུངས་ཚུ་གི་དོན་ལུ་ རིམ་སྒྲིག་ཕྱི་ཁའི་གསོག་འཇོག་ལག་ལེན་འཐབ། རིམ་སྒྲིག་གུ་གཞི་བསྟུན་གཏན་ཏོག་ཏོ་ཅིག་རྐྱངམ་ཅིག་གསོག་འཇོག་འབད་ དཔེར་ན་:

- ནང་དོན་ཧ་ཤི་ཅིག
- URI ཅིག་
- SoraFS ལམ༌ ཡང་ན་ གསལ་སྟོན་ཡིག་ཆ གཞི་བསྟུན ཅིག་
- ལག་ལེན་བདེན་དཔང་གིས་ལག་ལེན་འཐབ་མི་ ཁས་བླངས་བསྡུ་སྒྲིག་ཅིག

འདི་གིས་ WSV ཆུང་ཀུ་ཅིག་སྦེ་བཞག་པའི་ཁར་ ཐབས་ཤེས་ལག་ལེན་གྱིས་ ལྕགས་ཐག་ལས་ཕྱི་ཁར་ ནང་དོན་གནད་སྡུད་གྱི་ཅ་ལ་དེ་ ལྕགས་ཀྱུའི་ནང་གཞི་བསྟུན་དང་མཐུནམ་ཨིན་ན་ བརྟག་ཞིབ་འབད་ཚུགསཔ་བཟོཝ་ཨིན།

## ས་གནས་ གདམ་ཁ་རྐྱབ་ནི་ {#choosing-a-location}

ལམ་ལུགས་འདི་ལག་ལེན་འཐབ།

- གལ་སྲིད་ དེ་ ལེ་ཇར་དངོས་པོ་གི་ བསྡུ་སྒྲིག་ཁྱད་ཆོས་ཨིན་པ་ཅིན་ མེ་ཊ་ཌེ་ཊ་ལག་ལེན་འཐབ།
- གནས་གོང་ཅན་ ཡང་ན་ བརྗེ་སོར་འབད་ཚུགས་པ་ཅིན་ རྒྱུ་དངོས་ཅིག་སྦེ་ བཟོ་བཀོད་གཏང་། NFT ཡང་ན་ ཌོ་མ་ནེསི་ཁེ་རྐྱང་གི་དངོས་པོ་ཅིག་ཨིན།
- གལ་ཏེ་དེ་ཆེ་བ་ འགྱུར་བ་མང་བ་ ཡང་ན་ཉེར་སྤྱོད་ཀྱི་གསང་བ་ཡིན་ན་ WSV གི་ཕྱི་ཁར་བཞག་སྟེ་ བདེན་དཔྱད་འབད་ཚུགས་པའི་ཁུངས་སྐྱེལ་ཅིག་ལྕགས་ཐག་ཐོག་བཙུགས།

མེ་ཊ་ཌའི་ཊ་གི་ཆོག་ཐམ་གི་དོན་ལུ་ [ངོས་ལེན་རྟགས་ཚུ་](/dz/reference/permissions.md) ལུ་བལྟ་དགོ།
