# མི་མང་དང་སྒེར་གྱི་བཀག་རྡོག་རྒྱུན་ཐག་ཚུ་ {#public-and-private-blockchains}

Iroha སྒྲིག་གཞི་སྣ་ཚོགས་ནང་ལུ་ལག་ལེན་འཐབ་ཚུགསཔ་ཨིན། ཁྱོད་ཀྱི་དྲ་རྒྱ་གི་ བདག་འཛིན་པ་ཅིག་ཨིནམ་ད་ ཁྱོད་ཀྱིས་ བྱ་བ་སྤྱོད་མི་དང་ ངོས་ལེན་ལམ་ལུགས་ག་ཨིན་ན་ བརྗེ་སོར་འབད་ནི་ལུ་ གྲོས་ཐག་ཆོད་འབད་ཚུགས།

སྤྱིར་བཏང་གསལ་སྡུད་ཚུ་ _སྒེར་གྱི་_ གནང་བ་ཡོད་པའི་ཡོངས་འབྲེལ་དང་ མངམ་ཁ་ཕྱེ་ཡོད་པའི་ _མི་མང་_ ཡོངས་འབྲེལ་ཚུ་ཨིན། གཉིས་ཆ་ར་ རིགས་མཚན་གནས་སྟངས་དང་ ལག་ལེན་འཐབ་མི་གི་སྲིད་བྱུས་བརྒྱུད་དེ་ རིམ་སྒྲིག་འབད་དེ་ཡོདཔ་ད་ མཐུད་མཚམས་གཉིས་ལྡན་སོ་སོ་བརྒྱུད་དེ་མེན།

གཤམ་ལུ་ ང་བཅས་ཀྱིས་ ལག་ལེན་གྱི་གནད་དོན་གཉིས་ཀྱི་ཁྱད་པར་གཙོ་བོ་ཚུ་ བཀོད་དེ་ཡོད།

## ངོས་ལེན་ཚུ་ {#permissions}

མི་མང་གི་ སྡེབ་ཐག ནང་རྩིས་ཐོ་མང་ཤོས་ཅིག་ལུ་ ངོས་ལེན་འདྲ་མཉམ་ཡོདཔ་ཨིན། སྒེར་གྱི་ སྡེབ་ཐགནང་ལུ་རྩིས་ཐོ་རེ་ལུ་ ངོས་འཛིན་གསལ་ཏོག་ཏོ་རྐྱངམ་གཅིག་ཐོབ་ཨིན།

::: info

གནད་དོན་གཞན་གྱི་དོན་ལུ་ [གི་ཆ་རྐྱང་གི་ཁ་བྱང་ལུ་ ](/dz/blockchain/permissions.md)བལྟ་དགོ།

## མཐུད་མཚམས་ཚུ་ {#peers}

_མི་མང་_ བཀག་ཆའི་ནང་ མཉམ་རོགས་ཀྱི་འཛུལ་ཞུགས་འདི་ རིམ་སྒྲིག་སྲིད་བྱུས་ཀྱི་ཆ་ཤས་ཅིག་ཨིན། _སྒེར_ སྡེབ་ཐག གི་དོན་ལུ་ བཀྲམ་སྤེལ་ཚུ་གིས་ རིམ་སྒྲིག་དང་རིགས་མཚན་ནང་ བློ་གཏད་ཅན་གྱི་མཉམ་རོགས་ཆ་ཚན་འདི་ སྤྱིར་བཏང་ལུ་ པིན་འབདཝ་ཨིན།

::: info

གནད་དོན་གཞན་གྱི་དོན་ལུ་ [མཐུད་མཚམས་གི་འཛིན་སྐྱོང་](peer-management.md)ལུ་བལྟ་དགོ།

:::

## ཐོ་བཀོད་རྩིས་ཐོ་ཚུ་ {#registering-accounts}

ཁྱོད་ཀྱིས་ [འགོ་ཐོག སྡེབ་ཚན (`genesis.json`) (](genesis.md)) གཞི་བཙུགས་འབད་ནི་དེ་ ག་དེ་སྦེ་ ཐག་བཅད་ཡོདཔ་ཨིན་ནའི་གཞི་བསྟུན་ལུ་ ཐོ་བཀོད་འབད་ནིའི་ བྱ་རིམ་འདི་ ཐབས་ལམ་གཉིས་ལས་གཅིག་འགྱོ་ཚུགས། འདི་ག་དེ་སྦེ་ཨིན་ན་ ཧ་གོ་ནིའི་དོན་ལུ་ དང་པ་ར་ ངོས་ལེན་གྱི་སྐོར་ལས་སླབ་དགོ།

སེལ་འཐུ་འབད་ཡོད་པའི་ལག་ལེན་འདི་གིས་ ཐོབ་ཐངས་ཚུ་ བརྟག་ཞིབ་འབད་མི་འདི་ ངེས་གཏན་འབདཝ་ཨིན། ཁྱོད་ཀྱིས་ སྔོན་སྒྲིག་འདི་བྱིན་ཚུགས། [ངོས་ལེན་རྟགས་ཚུ་](/dz/blockchain/permissions.md) བཟོ་སྐྲུན་ནང་ལུ་ སྒེར་གྱི་ཁ་ཐུག་ལས་ འཛིན་སྐྱོང་འཐབ་མི་དྲ་ལམ་ ཡང་ན་ ཧེང་བཀལ་སྒོ་ཕྱེས་པའི་དྲ་ལམ་ཅིག་བཟོ་ནིའི་དོན་ལུ་ཨིན། འ་ནི་ཆོག་ཐམ་ཚུ་ འགོ་བཙུགས་པའི་ཤུལ་ལས་ ཐོ་བཀོད་འབད་ནི་གི་ བྱ་རིམ་འདི་སོ་སོ་ཨིན།

མི་མང་དང་སྒེར་གྱི་ཐོ་བཀོད་སྲིད་བྱུས་སྤྱིར་བཏང་ཁྱད་པར་ཡོད།

- _མི་མང_ ཐོ་བཀོད་སྲིད་བྱུས་འདི་གིས་ འོས་འབབ་ཅན་གྱི་ལག་ལེན་པ་གང་རུང་ཅིག་ལས་ རྩིས་ཐོ་ཐོ་བཀོད་ཚུ་ ངོས་ལེན་འབདཝ་ཨིན།[^1]. ལག་ལེན་པ་ལུ་འོས་འབབ་ཅན་གྱི་མཁོ་སྤྲོད་འབད་མི་དང་ རྒྱབ་སྐྱོར་འབད་ཡོད་པའི་ཨཱལ་གོ་རི་དམ་གྱི་དོན་ལུ་ སྒེར་གྱི་ལྡེ་མིག་ དེ་ལས་ སྲིད་བྱུས་ཀྱིས་ངོས་ལེན་འབད་མི་ ཐོ་བཀོད་ཀྱི་ཞུ་བ་ཚུ་དགོཔ་ཨིན།

- _སྒེར་གྱི་_ ཐོ་བཀོད་སྲིད་བྱུས་འདི་གིས་ ཐོ་བཀོད་ཚུ་བཙུགས་ནིའི་དོན་ལུ་ རྩིས་ཐོ་གཅིག་ཡང་ན་ རིག་རྩལ་ཅན་གྱི་གན་རྒྱ་གཅིག་ལུ་ དབང་ཚད་བྱིན་ཚུགས། སྲོལ་སྒྲིག་སྲིད་བྱུས་ཅིག་གིས་ ཐོ་བཀོད་འདི་དུས་ཚོད་སྒོ་སྒྲིག་ཅིག་ལུ་ཚད་འཛིན་འབད་ཚུགས། དེ་མ་ཚད་ དབང་འཛིན་ག་ལུ་ཡང་ དེ་ལས་ལྷག་སྟེ་ བཏོན་ནིའི་གནང་བ་མེདཔ་ལས་ བཀྲམ་སྤེལ་འབད་མི་གིས་ བཀྲམ་སྤེལ་གཏན་འཁེལ་བཟོ་ཡོད་པའི་ ཊོ་ཀེན་ཅིག་ ཟད་འགྲོ་བཏང་དགོཔ་འོང་།

- སྔོན་སྒྲིག་སྒེར་གྱི་ཡོངས་འབྲེལ་དཔེ་རིས་དང་གཅིག་ཁར་ ད་ལྟོ་ཡོད་པའི་རྩིས་ཐོ་ཅིག་གིས་ རྩིས་ཐོ་གསརཔ་རེ་རེ་གི་དོན་ལུ་ ཐོ་བཀོད་འདི་བཙུགསཔ་ཨིན།

སྔོན་སྒྲིག་གནང་བ་བདེན་དཔྱད་འབད་མི་ཚུ་གིས་ སྤྱིར་བཏང་སྒེར་གྱི་བཀག་ཆ་ལག་ལེན་གྱི་གནད་དོན་འདི་ཁྱབ་ཚུགས།
