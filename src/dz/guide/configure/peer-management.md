# གྲྭ་ཚང་གི་འཛིན་སྐྱོང་ {#peer-management}

ཁྱོད་ཀྱིས་ སྐད་ཡིག་དང་འབྲེལ་བའི་ ལམ་སྟོན་ཚུ་ཅིག་ལག་ལེན་འཐབ་པ་ཅིན་ ད་ལྟོ་ མི་སེར་ཚུ་གིས་ གྲལ་གཏོགས་འབད་དགོ་པའི་ ལྕོགས་གྲུབ་ཡོད་པའི་ བརྡ་བརྒྱུད་ལམ་ལུགས་ཡོད།

## མི་མང་གི་ Blockchain {#public-blockchain}

སྒོ་ཕྱེ་ཡོད་པའི་དྲ་ལམ་ནང་ལུ་ peer admmission འདི་ཡང་ ལྕགས་ཐག་གི་ སྲིད་བྱུས་ཀྱི་ གྲོས་ཐག་ཅིག་ཨིན་ཨིན། node གིས་བདེན་པའི་མཉེན་ཆས་ལག་ལེན་འཐབ་སྟེ་ Torii ལུ་ མཐུད་སྦྲེལ་འབད་ཚུགས། ཨིན་རུང་ netའདི་གིས་ peer ངོས་འཛིན་འབད་ཚར་བའི་ཤུལ་ལས་རྐྱངམ་གཅིག་ consensusནང་ བཅའ་མར་གཏོགས་ཡོདཔ་ཨིན།

## སྒེར་གྱི་ Blockchain {#private-blockchain}

དངུལ་ཁང་གི་གནས་སྟངས་ནང་ལུ་ མི་ག་ར་གིས་ རང་སོའི་རང་འདོད་ནང་ བཅའ་མར་གཏོགས་ཚུགསཔ་བཟོ་ནི་དེ་ ཉེན་སྲུང་ལུ་ ཉེན་ཁ་ཅན་ཅིག་ཨིན། ཉེན་སྲུང་གི་དོན་ལུ་ སྒེར་གྱི་ Iroha ཁྱབ་སྤེལ་འབད་མི་ཚུ་གིས་ སྤྱིར་བཏང་རང་ རང་སོའི་མཐའ་མའི་དབྱེ་བ་ཚུ་ གཞི་སྒྲིག་དང་འབྱུང་ཁུངས། དྭངས་གསལ་སྦེ་མཐོང་མི་ལུ་ བློ་གཏད་མ་བཏུབ་པར་ སྦྲགས་བཞག་ཡོདཔ་ཨིན།

### གྲྭ་ཚང་ཚུ་ ཐོ་བཀོད་འབད་ནི་ {#registering-peers}

གྲྭ་ཚང་ནང་ འདྲན་འདྲ་བཟོ་ནིའི་དོན་ལས་ འདི་ལག་ཐོག་ལུ་ ཐོ་བཀོད་འབད་དགོཔ་ཨིན། འ་ནི་ བྱ་རིམ་འདི་ མཇུག་བསྡུ་ནིའི་དོན་ལུ་ ཁྱོད་ཀྱིས་ ག་དེ་སྦེ་འབད་ནི་ཨིན་ན་ བལྟ་དགོ།

#### ལག་ལེན་པ་ལུ་ ངོས་ལེན་ཚུ་བྱིན་ནི། {#_1-grant-the-user-permissions}

གྲྭ་ཚང་གི་མིང་ཐོ་བཀོད་མི་རྩིས་ལུ་ འོས་འབབ་ཅན་གྱི་ `Permission` ཡོད་དགོཔ་ཨིན། འདི་ `Role` ཡང་ན་ ཐད་ཀར་དུ་ཆོག་ཐམ་སྤྲོད་ཐོག་ལས་བྱིན་ཚུགས།

རྩིས་ཁྲ་ཅིག་གིས་ དུས་ཡུན་འགོར་བའི་བསྒང་ལས་ འདྲན་འདྲ་ཚུ་ འཛིན་སྐྱོང་འཐབ་ནི་ཨིན་པ་ཅིན་ འགན་འཁྲི་བྱིན་དགོ། གཞན་མི་འདྲན་འདྲ་ཚུ་ལུ་ འཛིན་སྐྱོང་མ་འཐབ་པའི་རྩིས་ཁྲ་གིས་ ཐེངས་གཅིག་གི་དོན་ལུ་ ཐོ་བཀོད་འབད་ནིའི་དོན་ལུ་ འགྲེམ་ཐོག་ཐོག་ལས་ ངོས་ལེན་ལག་ལེན་འཐབ་དགོ།

::: info

ཐོ་བཀོད་དང་ ཐོ་བཀོད་ཀྱི་གྲལ་ཁར་མེད་མི་ཚུ་གི་དོན་ལུ་ default executor གིས་ `CanManagePeers` permission token ལག་ལེན་འཐབ་ཨིན།

:::

ངོས་ལེན་དང་འགན་ཁུར་ཚུ་ [ ལེའུ་སོ་སོ་ནང་ ](/dz/blockchain/permissions.md) གསལ་བཀོད་འབད་ཡོདཔ་ཨིན།

#### 2. དོ་འགྲན་འབད་མི་ཅིག་བཟོ་ {#_2-set-up-a-peer}

དབྱེ་བ་གསརཔ་ཅིག་ལུ་ ངོས་ལེན་ཐོབ་པའི་ཤུལ་ལས་ འདི་ གཞི་བཙུགས་འབད་དགོཔ་ཨིན།

མཚམས་འཇོག་འབད་ནིའི་སྔོན་ལུ་ ད་ལྟོའི་ འདྲ་མཉམ་བཟོ་ཐིག་འདི་ཞུ་དགོ། Torii འདི་གི་དོན་ལུ་ node parameters དང་ capability endpoints གསལ་སྟོན་འབདཝ་ཨིན། peer bootstrap གིས་ འ་ནི་གོང་ཚད་ཚུ་ རང་བཞིན་གྱི་ཐོག་ལས་ གྲོས་བསྟུན་མི་འབད་: ལག་ལེན་པ་ཚུ་གིས་ བརྟག་ཞིབ་འབད་དགོཔ་ཨིན། དུས་ཚོད་སེལ་འཐུ་འབད་ཐངས་དང་ བཀྲམ་སྤེལ་གྱི་ཚད་ཚུ་ དེ་ལས་ གྲོས་ཆོད་ལུ་ འབྲེལ་བ་ཡོད་པའི་ གཞི་སྒྲིག་གཞན་ཚུ་ཡང་ མཉམ་འབྲེལ་འབད་ཐངས་ནང་ མཐོང་ཚུགས་ཟེར་ཨིན་པས།

བྱ་རིམ་འདི་འཇམ་ཏོང་ཏོ་བཟོ་ནིའི་དོན་ལུ་ ཁྱོད་ཀྱིས་དྲ་ལམ་འཛིན་སྐྱོང་པ་ལུ་ `config.toml` གི་ བསྒྱུར་བཅོས་འབད་ཡོད་པའི་ ཝིན་ཌོ་ཅིག་ཞུ་ཚུགས་ནི་ཨིནམ་ད་ འདི་ནང་ལུ་ ཁྱད་ཆོས་ཅན་གྱི་ བརྡ་དོན་ཚུ་ དཔེར་ན་ རོགས་ཀྱི་ སྒེར་གྱི་ལྡེ་མིག་ཚུ་ བཀག་བཞག་ཡོདཔ་ཨིན།

#### 3. བཀའ་རྒྱ་འདི་ ཕུལ་དགོ། {#_3-submit-the-instruction}

ཁྱོད་རའི་མཉམ་རོགས་དེ་ བརྩོན་ཤུགས་བསྐྱེད་པའི་ཤུལ་ལས་ ཁྱོད་ཀྱིས་ Register peer instruction ཚུ་བཙུགས་དགོཔ་ཨིན། ཁྱོད་ཀྱི་མཉམ་རོགས་འདི་གིས་ལག་བརྡ་སྤྲོད་ཀྱི་ བྱ་རིམ་འདི་འབད་ཞིནམ་ལས་ ཁྱོད་ཀྱིས་དྲ་ལམ་དང་གཅིག་ཁར་ ཁ་སླབ་ནི་འགོ་བཙུགས་འོང་།

::: tip

གྲྭ་ཚང་གི་མིང་ཐོ་བཀོད་དགོ་པའི་བསླབ་བྱ་ཚུ་བཙུགས་ནི་དེ་ གྲྭ་ཚང་གསརཔ་གི་ བྱ་རིམ་ཅིག་ འགོ་འདྲེན་འཐབ་མ་ཚུགསཔ་ (དང་ འདི་ཡང་ འབད་མི་ཚུགས།)

:::

### ཐོ་བཀོད་མ་འབད་མི་ ཆ་རོགས་ཚུ་ {#unregistering-peers}

ཐོ་བཀོད་མ་འབད་མི་ འདྲན་འདྲ་ཚུ་གི་སྐོར་ལས་ ག་དེ་སྦེ་སླབ་ནི་ཨིན་ན? ཉེན་སྲུང་གི་རྒྱུ་རྐྱེན་ལུ་བརྟེན་ འ་ནི་ བྱ་རིམ་འདི་ གཅིག་སྒྲིལ་ཅིག་ཨིན་ཨིན། བརྒྱུད་འབྲེལ་འདི་གིས་ དངོས་སུ་ཅིག་བཏོན་དགོ་པའི་ གྲོས་བསྟུན་ལུ་ལྷོད་དོ་ཡོདཔ་ཨིན་རུང་ དངོས་སུ་དེ་གིས་ ག་ཅི་འབད་ ག་གིས་ཡང་ ཁོང་དང་གཅིག་ཁར་ ཁ་སླབ་མི་མེད་ཟེར་ ཧ་གོ་མི་ཚུགས་པས།

གནད་དོན་མང་ཤོས་ཅིག་ནང་ ཁྱོད་ཀྱིས་ དོགས་ཅན་ཅིག་ལུ་ ཐོ་བཀོད་མ་རྐྱབ་པར་ བཞག་དགོ་པ་ཅིན་ འདི་ར་ བི་ཛིན་ཊི་ཡཱན་གྱི་ཉེས་འཛོལ་བ་འབདཝ་ལས་བརྟེན་ཏེ་ཨིན། དོགས་ཅན་འདི་ "འ་དུལ་"འབད་ནི་འདི་གིས་ རྒྱང་སྒྲོག་གི་གནོད་པ་ཅན་གྱི་རྩེདམོ་རྩེད་མི་གི་མི་ཚེ་དེ་ ལཱ་ཁག་གཏང་འོང་།
