# མི་མང་གི་ལྡེ་མིག་བཟོ་ཐངས་ {#public-key-cryptography}

མི་མང་གི་ལྡེ་མིག་གི་ ཨེབ་གཏང་ནི་དེ་ ཉེན་སྲུང་ཅན་གྱི་ བརྡ་དོན་དང་ གནད་སྡུད་ཚུ་གི་ སྲུང་སྐྱོབ་ཀྱི་ ཐབས་ལམ་ཚུ་ཨིནམ་ལས་ ཉེན་སྲུང་ཅན་གྱི་ ཨེན་ལིན་ཊེནཌ་ཚོང་འབྲེལ་དང་ ཨེམ་ཨེེལ་བརྡ་དོན་ སྦྲགས་ཡོད་པའི་ཅོག་འཐདཔ་ཚུ་ འབད་ཚུགསཔ་བཟོ་ཡོདཔ་ཨིན།

མི་མང་གི་ལྡེ་མིག་བཟོ་སྐྲུན་ནང་ གསང་བའི་ལྡེ་མིག་གཉིས་ཆ་ར་ ལག་ལེན་འཐབ་དོ་ཡོདཔ་ཨིན། སྒེར་གྱི་ལྡེ་མིག་དང་ མི་མང་ལྡེ་མིག་ཚུ་ ཡོངས་འབྲེལ་ལམ་ལུགས་བརྒྱུད་དེ་ བརྡ་དོན་སྤེལ་ནི་གི་ ཐབས་ལམ་བརྟན་ཏོག་ཏོ་ཅིག་ བཟོ་ནིའི་དོན་ལུ་ཨིན།

སྒེར་གྱི་ལྡེ་མིག་ནང་ལས་ མི་མང་གི་ལྡེ་མིག་བཟོ་ནི་དེ་འཇམ་ཏོང་ཏོ་ཨིན་ དེ་འབདཝ་ད་ འདི་དང་འགལ་བ་ཅིན་ དཀའཝ་སྤྱད་ནི་དེ་ ལཱ་ཁག་ཅིག་ཨིན་ འདི་འབདཝ་ལས་ ཅ་ཆས་ཚུ་ ཉེན་སྲུང་ཅན་སྦེ་ བཞག་ཚུགསཔ་ཨིན། ཁྱོད་ཀྱིས་ སྒེར་སྡེའི་ལྡེ་མིག་འདི་ ཉེན་ཁ་མེད་པར་བགོ་བཤའ་བརྐྱབ་ཚུགས། ཁྱོད་ཀྱི་སྒེར་གྱི་ལྡི་མིག་འདི་ ཉེན་སྲུང་ཅན་ཅིག་སྦེ་རང་སྡོད་འོང་།

## ཨེབ་གཏང་དང་ ལག་རྟགས་ཚུ་ {#encryption-and-signatures}

མི་སེར་གྱི་ལྡེ་མིག་གི་ ཨེབ་གཏང་ཐངས་འདི་གིས་ མི་ཚུ་ལུ་ བརྡ་དོན་དང་ གནད་སྡུད་ཚུ་ སྦ་ཆག་བཏང་ཐོག་ལས་ བཏང་ནིའི་གོ་སྐབས་ཡོདཔ་ད་ འདི་ཚུ་ཡང་ ཁོང་རའི་ སྒེར་གྱི་ལྡེ་ཁུའི་ལག་ལེན་འཐབ་མི་རྐྱངམ་གཅིག་གིས་ ཁ་གསལ་འབད་ཚུགས་འོང་། དོན་དག་གཞན་ཚུ་ནང་ གསང་བའི་ལྡེ་མིག་འདི་ ལྕགས་ཟམ་སྦེ་ལཱ་འབད་དོ་ཡོདཔ་ད་ སྒེར་གྱི་ལྡེ་མིག་དེ་ ངོ་རྐྱང་གི་ལྡེ་མིག་ཅིག་ཨིནམ་ལས་ ཨེབ་གཏང་འབད་ཡོད་པའི་ ཌའི་ཊ་ལུ་ ཁ་ཕྱེ་ཚུགསཔ་ཨིན།

འ་ནི་སྦྲགས་ཐིག་གི་ བྱ་རིམ་དེ་གིས་ ཉམས་མྱོང་ཅན་གྱི་ བརྡ་དོན་ཚུ་གི་ གསང་བ་དང་ གསང་བའི་གནས་སྟངས་རྐྱངམ་ཅིག་མེན་པར་ བཏང་མི་གི་ བདེན་ཁུངས་ཡང་ མཐོང་ཚུགསཔ་ཨིན། བཏང་མིའི་ སྒེར་གྱི་ལྡེ་མིག་འདི་ མི་མང་ལྡེ་མིག་དང་གཅིག་ཁར་བསྡོམས་ཐོག་ལས་ ཨང་གྲངས་ཀྱི་རྟགས་མཚན་བཟོ་ཡོདཔ་ཨིན། འ་ནི་ཡིག་རྟགས་འདི་ ངོས་ལེན་གྱི་ ཌི་ཇི་ཊཱལ་ཐིམཀ་ཅིག་སྦེ་ ལག་ལེན་འཐབ་སྟེ་ བཏང་མི་གི་ ངོ་མཚན་དང་ བཏང་མིའི་ གནད་དོན་ཚུ་གི་བདེན་ཁུངས་ཚུ་ བདའ་ཟུན་ཚུགསཔ་ཨིན། ཁྱོད་ཀྱི་གཞུང་འབྲེལ་ལྡེ་མིག་ཡོད་མི་ ག་གིས་ཡང་ ཁྱོད་ཀྱི་སྒེར་སྡེའི་ལྡེ་མིག་ལག་ལེན་འཐབ་ཡོད་པའི་ངོས་འཛིན་འབད་ཚུགས།

## Key འདི་ Client གྱི་ཁ་ཐུག་ལས་ཨིན། {#keys-on-the-client-side}

ཚོང་འབྲེལ་ཆ་མཉམ་ལུ་ རྩིས་ཁྲ་དབང་འཛིན་གྱིས་ མཚན་རྟགས་བཀོད་དགོཔ་ཨིན། སྒེར་གྱི་ལྡེ་མིག་ (private key) ཡང་ན་ འ་ནི་དབང་འཛིན་ཚུ་གི་དོན་ལུ་ འཛིན་སྐྱོང་ཡིག་ཆ་ཚུ་ གསང་བ་སྦེ་བཞག་དགོཔ་ཨིན། འདི་འབདཝ་ལས་ ཞབས་ཏོག་མགྲོན་པ་ཚུ་གིས་ ཉེན་སྲུང་ཅན་གྱི་ གནས་སྡུད་དང་ མཚན་རྟགས་བཀོད་ནི་ལུ་འགན་ཁུར་བསྐྱེདཔ་ཨིན།

::: དྲན་བསྐུལ་

ཀའི་ལེནཌ་ཚུ་སོ་སོ་ཨིན་ དེ་འབདཝ་ད་ འཕྲུལ་ཆས་བཟོ་སྐྲུན་དང་ བརྟག་དཔྱད་འབད་ནིའི་དོན་ལུ་ བཟོ་སྐྲུན་གྱི་མཐུན་རྐྱེན་རྐྱངམ་ཅིག་ འོས་འབགཔ་ཨིན། བཟོ་སྐྲན་གི་མཐུན་རྐྱེན་ཚུ་གིས་ གསང་བའི་ འཛིན་སྐྱོང་པ་, སྟབས་མ་བདེཝ་ཅན་གྱི་ལྡོག་སྒྲོམ་ (hardware-backed key storage) ཡང་ན་ ཐོ་བཀོད་འབད་ཡོད་པའི་གནད་དོན་གཞན་གཅིག་ལག་ལེན་འཐབ་དགོ།

:::

རྩིས་ཁྲ་གསརཔ་ཅིག་གུ་ ཐོ་བཀོད་འབད་ནིའི་དོན་ལས་ ཨེཌི་༢༥༥༡༩ གི་ལྡེ་མིག་གི་རྣམ་པ་ཚུ་ བཟོ་སྐྲུན་འབད་ནི་དང་ མི་སེར་གྱི་ཆ་ཤས་དེ་ ཡོངས་འབྲེལ་ལུ་ བཏང་དགོཔ་ཨིན། དེའི་ཤུལ་ལས་ རྩིས་ཁྲའི་ནང་ལས་ འབྲེལ་བ་ཡོད་པའི་ སྒེར་སྡེའི་ལྡེ་མིག་ ཡང་ན་ གཞི་སྒྲིག་འབད་མི་རྩིས་ཁྲ་འཛིན་གྱི་ སྲིད་བྱུས་ཀྱི་ཐོག་ལས་ མཚམས་འཇོག་འབད་དགོཔ་ཨིན།

མི་མང་གི་ལྡེ་མིག་བཟོ་སྐྲུན་དེ་ དཀའཝ་སྤྱད་ཚུགསཔ་བཟོ་བའི་དོན་ལུ་ ཁྱོད་ཀྱིས་ལྡེ་མིག་གསརཔ་དེ་ གསལ་བཀོད་འབད་དགོ་པའི་སྐབས་ ལོག་སྟེ་ལག་ལེན་འཐབ་ནི་ལས་ བཀག་གི། མ་གཞི་ ཁྱོད་ལུ་ འདི་འབད་ནི་ལུ་ བཀག་ཆ་ག་ནི་ཡང་མེད་ ཨིན་རུང་ མི་མང་གི་ལྡི་མིག་ཚུ་ སྒོ་སྡེའི་ལྡེ་མིག་ཨིནམ་ལས་ ཉེན་ཁ་ཅན་གྱི་ལྡེ་མིག་འདི་ ལག་ལེན་འཐབ་ས་མཐོང་པ་ཅིན་ ཁོང་རའི་ལྡེ་མིག་ཚུ་ཡང་ གཅིག་མཚུངས་ཨིནམ་ཤེས་འོང་།

སྒེར་གྱི་ལྡེ་མིག་ཚུ་ Password ལས་དུམ་གྲ་ཅིག་ཁྱད་པར་ཅན་ཅིག་སྦེ་ ལག་ལེན་འཐབ་རུང་ འདི་ཚུ་ སྟབས་མ་བདེཝ་སྦེ་ བཟོ་ནི་གི་བསླབ་བྱ་འདི་ ལག་ལེན་འཐབ་ནི་ཨིནམ་ད་ དེ་ཚུ་ ཨེབ་གཏང་མ་འབད་བར་བཞག་ནི་དང་ ནམ་རང་འབད་རུང་ མི་གཞན་དང་གཅིག་ཁར་བགོ་བཤའ་རྐྱབ་མི་དགོ།
