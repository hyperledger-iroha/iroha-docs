# མི་མང་གི་ལྡེ་མིག་བཟོ་ཐངས་ {#public-key-cryptography}

མི་མང་ལྡེ་མིག་གསང་ཡིག་འདི་གིས་ འབྲེལ་ཡོད་མི་མང་ལྡེ་མིག་དང་སྒེར་གྱི་ལྡེ་མིག་ལག་ལེན་འཐབ་ཨིན། མི་མང་ལྡེ་མིག་འདི་རུབ་སྤྱོད་འབད་བཏུབ། སྒེར་གྱི་ལྡེ་མིག་འདི་ དབང་འཛིན་གྱི་ཚད་འཛིན་འོག་ལུ་སྡོད་དགོ། ཉེན་སྲུང་འདི་རྒྱབ་སྐྱོར་འབད་ཡོད་པའི་ཨཱལ་གོ་རི་དམ་ལག་ལེན་འཐབ་ནི་དང་ ཉེན་སྲུང་གང་བྱུང་དང་གཅིག་ཁར་ལྡེ་མིག་ཚུ་བཟོ་བཏོན་འབད་ནི་ དེ་ལས་ སྒེར་གྱི་ལྡེ་མིག་འདི་ཉེན་སྲུང་འབད་ནི་ཚུ་ལུ་རག་ལསཔ་ཨིན།

## ཌི་ཇི་ཊཱལ་གྱི་མིང་རྟགས་ཚུ་ {#digital-signatures}

མིང་རྟགས་བཀོད་མི་ཅིག་གིས་ སྒེར་གྱི་ལྡེ་མིག་དང་གཅིག་ཁར་ ཌི་ཇི་ཊཱལ་མིང་རྟགས་ཅིག་བཟོཝ་ཨིན། བདེན་དཔྱད་འབད་མི་ཅིག་གིས་ མཐུན་སྒྲིག་ཡོད་པའི་མི་མང་ལྡེ་མིག་དང་གཅིག་ཁར་ མིང་རྟགས་འདི་ཞིབ་དཔྱད་འབདཝ་ཨིན།

ཐོ་བཀོད་ཅན་གྱི་རྟགས་མཚན་གྱིས་ བའི་ཊི་ཚུ་བསྒྱུར་བཅོས་མ་འབདཝ་དང་ སྒེར་གྱི་ལྡེ་མིག་གི་ལག་ལེན་པ་གིས་ ངོས་འཛིན་འབད་ཡོདཔ་ལས་ ངོ་རྟགས་དེ་ རང་གིས་རང་ངོ་སྤྲོད་མི་འབདཝ་ཨིན། ངོ་རྟགས་འདི་ མི་མང་ལྡེ་མིག་ ཡང་ན་རྩིས་ཐོ་འཛིན་སྐྱོང་པ་ལུ་ ཐོ་བཀོད་ཀྱི་ལམ་ལུགས་དང་ ལམ་ལུགས་དང་འཁྲིལ་ཏེ་ཨིན་མས།

མིང་རྟགས་ཚུ་གིས་ ཆ་ཚང་བ་དང་ དབང་ཆ་བྱིན་པའི་དཔང་རྟགས་བྱིནམ་ཨིན། དེ་ཚུ་གིས་ མིང་རྟགས་བཀོད་པའི་ནང་དོན་ གསང་སྒྱུར མི་འབད།

## མི་མང་གི་ལྡེ་མིག་ཚུ་ ཨེབ་གཏང་འབད་ནི་ {#public-key-encryption}

མི་མང་ལྡེ་མིག་འཆར་གཞི་ལ་ལུ་ཅིག་གིས་ ཐོབ་མི་ཅིག་གི་ མི་མང་ལྡེ་མིག་གི་དོན་ལུ་ གནད་སྡུད་གསང་བཟོ་འབདཝ་ཨིན། ཐོབ་མི་གིས་ གནད་སྡུད་དེ་ འབྲེལ་ཡོད་སྒེར་གྱི་ལྡེ་མིག་དང་གཅིག་ཁར་ གསང་བཟོ་འབདཝ་ཨིན། གསང་བཟོ་དང་མིང་རྟགས་ཚུ་ བཀོལ་སྤྱོད་སོ་སོ་ཨིནམ་དང་ ལྡེ་མིག་ཡང་ན་ཨཱལ་གོ་རི་དམ་སོ་སོ་ཚུ་ལག་ལེན་འཐབ་འོང་།

Iroha ཚོང་འབྲེལ་གྱི་རྟགས་བཀོད་གིས་ མི་མང་གི་རྩིས་དེབ་ཀྱི་ གནད་དོན་ཚུ་ གསང་བ་ཅན་སྦེ་བཟོ་མི་ཚུགས། ལག་ལེན་འཐབ་ནིའི་ལག་ལེན་དེ་ ཆ་འཇོག་གྲུབ་པའི་ གསང་བའི་ལམ་ལུགས་འདི་ ལག་ལེན་འཐབ་ནི་ཨིནམ་ད་ ནང་དོན་གནད་སྡུད གི་ ནང་དོན་ཚུ་ སྒེར་སྡེའི་གནས་སྟངས་ལུ་ བཞག་དགོ།

## ལྡེ་མིག་འདི་མགྲོན་པོ་ལས་ཨིན་ {#keys-on-the-client-side}

ཚོང་འབྲེལ་རེ་རེ་གིས་ རིམ་སྒྲིག་འབད་ཡོད་པའི་རྩིས་ཐོ་-ཚད་འཛིན་སྲིད་བྱུས་འདི་ བསྒྲུབ་དགོ། རྩིས་ཐོ་འཇམ་སམ་ཅིག་གིས་ མིང་རྟགས་བཀོད་ནིའི་ལྡེ་མིག་གཅིག་ལག་ལེན་འཐབ་བཏུབ། གཞུང་སྐྱོང་རྩིས་ཐོ་གིས་ མགུ་རྙོག་དྲགས་ཅན་གྱི་ཚད་འཛིན་སྲིད་བྱུས་ལག་ལེན་འཐབ་བཏུབ།

མཁོ་སྤྲོད་མཉེན་ཆས་ཀྱིས་ སྒེར་གྱི་ལྡེ་མིག་དང་ གཞན་ཚད་འཛིན་རྒྱུ་ཆ་ཚུ་ ཉེན་སྲུང་འབད་དགོ། ཚིག་ཡིག་གཙང་མའི་མཁོ་སྤྲོད་རིམ་སྒྲིག་འདི་ ཉེ་གནས་གོང་འཕེལ་དང་ཚད་འཛིན་འབད་ཡོད་པའི་བརྟག་དཔྱད་ཚུ་གི་དོན་ལུ་རྐྱངམ་ཅིག་འོས་འབབ་ཡོདཔ་ཨིན། བཟོ་བསྐྲུན་མཉམ་བསྡོམས་ཚུ་གིས་ གསང་བའི་འཛིན་སྐྱོང་པ་དང་ མཐུན་རྐྱེན་རྒྱབ་སྐྱོར་ཡོད་པའི་ལྡེ་མིག་གསོག་འཇོག་ སོ་སོ་སྦེ་མིང་རྟགས་བཀོད་ནི་གི་ཞབས་ཏོག་ ཡང་ན་ རྩིས་ཞིབ་འབད་ཡོད་པའི་མིང་རྟགས་བཀོད་ནིའི་མཚམས་གཞན་ཅིག་ལག་ལེན་འཐབ་དགོ།

མཐའ་འཁོར་དང་དགོས་དོན་སོ་སོ་ཚུ་གི་དོན་ལུ་ ལྡེ་མིག་སོ་སོ་ལག་ལེན་འཐབ། ལྡེ་མིག་གཅིག་ལོག་སྟེ་ལག་ལེན་འཐབ་མི་འདི་གིས་ ལག་ལེན་དེ་ཚུ་འབྲེལ་མཐུད་འབདཝ་ཨིནམ་དང་ གདོང་ལེན་གྱི་གནོད་པ་འདི་ཡར་སེང་འབདཝ་ཨིན།
