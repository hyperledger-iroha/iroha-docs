# མི་མང་གི་ལྡེ་མིག་བཟོ་ཐངས་ {#public-key-cryptography}

མི་མང་ལྡེ་མིག་གི་ cryptography ནང་ འབྲེལ་ཡོད་པའི་མི་མང་ལྡེ་མིག་དང་ སྒེར་གྱི་ལྡེ་མིག་ལག་ལེན་འཐབ་ཨིན། མི་མང་ལྡེ་མིག་འདི་བགོ་བཤའ་རྐྱབ་ཆོག། སྒེར་གྱི་ལྡེ་མིག་འདི་ དབང་འཛིན་གྱི་ཚད་འཛིན་འོག་ལུ་རྐྱངམ་ཅིག་བཞག་དགོ། ཉེན་སྲུང་དེ་ རྒྱབ་སྐྱོར་འབད་མི་ algorithm ལག་ལེན་འཐབ་ནི་ ཉེན་སྲུང་ཅན་གྱི randomness ལས་ལྡེ་མིག་བཟོ་ནི་ དང་ སྒེར་གྱི་ལྡེ་མིག་སྲུང་ནི་ལུ་བརྟེནམ་ཨིན།

## ཌི་ཇི་ཊཱལ་གྱི་མིང་རྟགས་ཚུ་ {#digital-signatures}

ལག་ལེན་པ་ཅིག་གིས་ སྒེར་གྱི་ལྡེ་མིག་ལག་ལེན་འཐབ་ཐོག་ལས་ ཐོ་བཀོད་འབད་ཡོདཔ་ བཟོ་སྐྲུན་འབདཝ་ཨིན། བརྟག་ཞིབ་འབད་མི་ཅིག་གིས་ ཌི་ཇི་ཊཱལ་གི་ལྡེ་མིག་དེ་ ལག་ལེན་འཐབ་སྟེ་ དབྱེ་བ་དཔྱད་ཨིན།

ཐོ་བཀོད་ཅན་གྱི་རྟགས་མཚན་གྱིས་ བའི་ཊི་ཚུ་བསྒྱུར་བཅོས་མ་འབདཝ་དང་ སྒེར་གྱི་ལྡེ་མིག་གི་ལག་ལེན་པ་གིས་ ངོས་འཛིན་འབད་ཡོདཔ་ལས་ ངོ་རྟགས་དེ་ རང་གིས་རང་ངོ་སྤྲོད་མི་འབདཝ་ཨིན། ངོ་རྟགས་འདི་ མི་མང་ལྡེ་མིག་ ཡང་ན་རྩིས་ཁྲ་འཛིན་སྐྱོང་པ་ལུ་ ཐོ་བཀོད་ཀྱི་ལམ་ལུགས་དང་ ལམ་ལུགས་དང་འཁྲིལ་ཏེ་ཨིན་མས།

མིང་རྟགས་ཚུ་གིས་ ཆ་ཚང་བ་དང་ དབང་ཆ་བྱིན་པའི་དཔང་རྟགས་བྱིནམ་ཨིན། དེ་ཚུ་གིས་ མིང་རྟགས་བཀོད་པའི་ནང་དོན་ encrypt མི་འབད།

## མི་མང་གི་ལྡེ་མིག་ཚུ་ ཨེབ་གཏང་འབད་ནི་ {#public-key-encryption}

མི་མང་ལྡེ་མིག་གི་རིམ་ལུགས་ལ་ལུ་ཅིག་གིས་ ལེན་མིའི་མི་མང་ལྡེ་མིག་གི་དོན་ལུ་ གནས་སྡུད་ encrypt འབདཝ་ཨིན། ལེན་མི་གིས་ དེ་དང་འབྲེལ་བའི་སྒེར་གྱི་ལྡེ་མིག་གིས་ གནས་སྡུད་ decrypt འབདཝ་ཨིན། Encryption དང་མིང་རྟགས་གཉིས་ བྱ་སྒོ་སོ་སོ་ཨིནམ་ལས་ key ཡང་ན་ algorithm མ་འདྲཝ་ལག་ལེན་འཐབ་ཚུགས།

Iroha ཚོང་འབྲེལ་གྱི་རྟགས་བཀོད་གིས་ མི་མང་གི་རྩིས་དེབ་ཀྱི་ གནད་དོན་ཚུ་ གསང་བ་ཅན་སྦེ་བཟོ་མི་ཚུགས། ལག་ལེན་འཐབ་ནིའི་ལག་ལེན་དེ་ ཆ་འཇོག་གྲུབ་པའི་ གསང་བའི་ལམ་ལུགས་འདི་ ལག་ལེན་འཐབ་ནི་ཨིནམ་ད་ ཕན་ཐོགས་ཅན་གྱི་མཁོ་ཆས་ཚུ་གི་ ནང་དོན་ཚུ་ སྒེར་སྡེའི་གནས་སྟངས་ལུ་ བཞག་དགོ།

## Key འདི་ Client གྱི་ཁ་ཐུག་ལས་ཨིན། {#keys-on-the-client-side}

ཚོང་འབྲེལ་ཆ་མཉམ་གྱིས་ རྩིས་ཁྲ་འཛིན་སྐྱོང་འཐབ་མི་གི་ སྲིད་བྱུས་ཚུ་ བཀྲམ་སྟོན་འབད་དགོཔ་ཨིན། རྩིས་རྐྱང་ཅིག་གིས་ ཐོ་བཀོད་ལྡེ་མིག་གཅིག་ལག་ལེན་འཐབ་ཚུགས། རྩིས་ཁྲའི་འོག་ལུ་ཡོད་པའི་རྩིས་ཁྲ་གིས་ རྩིས་འཛིན་འཐབ་མི་གི་སྲིད་བྱུས་ཁག་ཆེ་ཤོས་ཅིག་ལག་ལེན་འཐབ་ཚུགས།

སྲོལ་འཛིན་གྱི་མཉེན་ཆས་ཚུ་གིས་ སྒེར་གྱི་ལྡེ་མིག་དང་ དབྱེ་ཞིབ་འཕྲུལ་ཆས་གཞན་ཚུ་ ཉེན་སྐྱོབ་འབད་དགོཔ་ཨིན། Plain-text སྲོལ་འཛིན་བཟོ་སྒྲིག་འདི་ ས་གནས་ནང་ལུ་ གོང་འཕེལ་གཏང་ནི་དང་ བརྟག་དཔྱད་འབད་ནི་ལུ་རྐྱངམ་གཅིག་ སྟབས་བདེ་ཏོག་ཏོ་ཨིན་མས། བཟོ་སྐྲུན་མཐུན་རྐྱེན་ཚུ་ནང་ གསང་བའི་འཛིན་སྐྱོང་པ་ཅིག་ ལག་ལེན་འཐབ་དགོཔ། Hardware-backed key storage, isolated signing service, or other audited signing boundary འདི་ལག་ལེན་འཐབ་དགོཔ།
