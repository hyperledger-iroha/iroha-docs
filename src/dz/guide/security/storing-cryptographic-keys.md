# ཨེབ་གཏང་འབད་ནིའི་ལྡེ་མིག་ཚུ་བཞག་ནི། {#storing-cryptographic-keys}

ཁྱོད་ཀྱིས་ <abbr title="Operational Security">OPSEC</abbr>གི་ ལག་ལེན་ཚུ་ལག་ལེན་འཐབ་པ་ཅིན་རྐྱངམ་གཅིག་ ཁྱོད་ཀྱི་ཚོར་བ་ཅན་གྱི་ གནད་སྡུད་དེ་ གསང་བའི་ལྡེ་མིག་ཚུ་གི་སྲུང་སྐྱོབ་འབད་ཚུགས། མི་སྡེ་བཟོ་རིག་གི་ ཉེན་ཁ་འདི་ རང་ལུ་དབང་ཡོད་པའི་མི་ཅིག་ཨིནམ་ལས་ ཁྱོད་རའི་ སྒེར་གྱི་ལྡེ་མིག་ཀྱི་ལྡེ་མིག་བྱིན་ནིའི་དོན་ལུ་ བསྒྱུར་བཅོས་འབད་ནི་གི་ དཔའ་བཅམ་དོ་ཡོདཔ་ད་ འདི་ཚུ་ངོ་མ་ཨིན། ཨ་རྟག་རང་ དྲན་པ་བཏོན་ཏེ་ ཁྱོད་རའི་ སྒེར་གྱི་ལྡེ་མིག་འདི་བགོ་བཤའ་རྐྱབ་མ་བྱིན་པར་བཞག་དགོ་ ཁྱོད་ཀྱིས་ཁྱིམ་གི་ལྡེ་མིག་ཚུ་ ཡིད་ཆེས་ཅན་ཚུ་གི་དོན་ལུ་རྐྱངམ་ཅིག་བཞག་དོཝ་བཟུམ་སྦེ་ ལག་ལེན་འཐབ་དགོ།

<abbr title="Operational Security">OPSEC</abbr>དང་ ལག་ལེན་ལེགས་ཤོམ་ཚུ་གི་སྐོར་གྱི་ བརྡ་དོན་གཞན་ཚུ་བལྟ་ནིའི་དོན་ལུ་ [Operational Security ](./operational-security)བལྟ་དགོ།

## ཨང་གྲངས་ཀྱི་ལྡེ་མིག་ཚུ་ ཐོ་བཀོད་འབདཝ་ཨིན། {#storing-cryptographic-keys-digitally}

ཨང་གྲངས་ཀྱི་ལྡེ་མིག་ཚུ་ ཉེན་སྲུང་འབད་ནིའི་དོན་ལས་ ཐབས་ལམ་གཉིས་རྐྱངམ་གཅིག་ ལག་ལེན་འཐབ་ཚུགསཔ་ཨིན། [SSH](https://www.ssh.com/)དང་ [GPG](https://www.gnupg.org/) འདི་ཚུ་གིས་ ཁྱོད་ཀྱི་ལྡེ་མིག་ལུ་ ངོས་ལེན་མ་འབད་མི་འཛུལ་ནི་ལས་ བཀག་ཐབས་འབད་ཚུགས།

Iroha བཟོ་རིག་གི་ གྲོས་ཐག་མང་ཤོས་ཅིག་གིས་ Secure Shell (`SSH`) གི་མཐུན་ལམ་གྱི་གཞི་རྩ་ཚུ་ལུ་ ཐོ་ཕོག་ཡོདཔ་ལས་ ད་རེས་ཀྱི་ཆ་ཤས་འདི་ དམིགས་བསལ་དུ་ `SSH`གི་ཐབས་ལམ་ལུ་ གཙོ་བོར་བཏོན་དོ་ཡོདཔ་ཨིན། ཁྱོད་ཀྱིས་ Iroha སྐྱེ་ལྡན་ལམ་ལུགས་ནང་ལུ་ ཁྱོད་ཀྱི་གདམ་ཁ་ལྡེ་མིག་ཚུ་བཞག་ནིའི་དོན་ལུ་ བྱ་རིམ་སྒྲིག་གཞི་དེ་ ག་དེ་སྦེ་ལག་ལེན་འཐབ་ནི་ཨིན་ནའི་བསླབ་བྱ་བྱིན་དོ་ཡོདཔ་ཨིན།

### SSH དང་SSH གི་ལག་ལེན་འཐབ་ཐངས་ཚུ་ {#using-ssh-and-ssh-agent}

Secure Shell Protocol (`SSH`) འདི་ ཀི་པི་ཊོ་རིག་གི་དྲ་ལམ་ཡིག་ཚང་ཅིག་ཨིནམ་ད་ འདི་གིས་ SSH key access credentials ལག་ལེན་འཐབ་ཐོག་ལས་ ཐག་རིང་གི་འཕྲུལ་ཆས་ཚུ་ནང་ ཉེན་སྲུང་ཅན་གྱི་འཛུལ་སྒོ་བྱིན་ཚུགསཔ་ཨིན། འདི་གིས་ physical presence དགོས་མཁོ་མེད་པར་ལམ་ལུགས་ཚུ་དང་གཅིག་ཁར་ རྒྱང་རིང་སྦེ་འབྲེལ་བ་འཐབ་ནི་གི་ཐབས་ལམ་ལེགས་ཤོམ་ཅིག་བཟོཝ་ཨིན། འ་ནི་གནས་སྟངས་ནང་ `SSH` གིས་ གཞི་རྟེན་བདེན་འཛིན་འབད་ནིའི་འཕྲུལ་ཆས་གཉིས་ ཞབས་ཏོག་གི་ཁ་བྱང་ལུ་གཞི་བཙུགས་འབད་མི་ལམ་ལུགས་དང་ ཉེན་སྲུང་ལྡན་པའི་ public-private key pair ཐབས་ལམ་ཚུ་ ཞབས་ཏོག་སྤྲོད་ནི་ཨིན་མས།

`SSH`གི་སྐོར་ལས་གསལ་སྒྲགས་འབད་ནིའི་དོན་ལས་ [དང་འབྲེལ་བའི་ SSH གཙུག་ལག་སློབ་སྡེ་གྱི་གནད་དོན་](https://www.ssh.com/academy/ssh)བལྟ་དགོ།

ཐོ་བཀོད་འབད་ནིའི་ བྱ་རིམ་དེ་ གསལ་ཏོག་ཏོ་སྦེ་བཟོ་ནི་དང་ སླར་ལོག་འབད་ནི་གི་ དགོས་མཁོ་མ་འབྱུང་ནིའི་དོན་ལུ་ `SSH`ལྡེ་མིག་ཚུ་ SSH ལས་འཛིན་ (`ssh-agent`) དང་གཅིག་ཁར་བསྡོམས་ཚུགསཔ་ཨིན། གྲོགས་རམ་ལས་རིམ་འདི་གིས་ ཁྱོད་ཀྱི་ `SSH`ལྡེ་མིག་དང་/ཡང་ན་ གནས་སྡུད་ཀྱི་རིང་ལུ་ ཉེན་ཁ་ཅན་གྱི་ལྡེ་མིག་འདི་ དྲན་པ་བཏོན་འོང་། འ་ནི་ གཞི་སྒྲིག་འདི་གིས་ `SSH` gateway ལུ་ འཕྲུལ་ཆས་གཞན་ཚུ་དང་མཐུད་འབྲེལ་འབད་བའི་སྐབས་ ལྕེ་མིག་ཚུ་ནང་ ཤུགས་མེད་པར་འཛུལ་ཚུགས་ཚུགསཔ་བཟོཝ་ཨིན།

འ་ནཱ་གི་ལཱ་ལམ་འདི་ འདི་བཟུམ་སྦེ་ཨིན། ཁྱོད་ཀྱིས་ ཁྱོད་ཀྱི་གཞུང་ལྡེ་མིག་དེ་ ཐག་རིང་གི་ལམ་ལུགས་ནང་ལུ་བཞག་ཡོདཔ་དང་ ཁྱོད་ཀྱི་སྒེར་གྱི་ལྡེ་མིག་འདི་ ཉེན་སྲུང་ཅན་སྦེ་བཞག་ཡོདཔ་ཨིན། ཁྱོད་ཀྱིས་ ཐག་རིང་གི་ ལམ་ལུགས་ཅིག་ནང་ འཛུལ་ཞུགས་འབད་དགོ་པའི་སྐབས་ལུ་ `ssh-agent` གིས་ ཁྱོད་ཀྱི་གཞུང་ལྡི་མིག་འདི་ འཛུལ་ཞུགས་འབད་མི་ལམ་ལུགས་ལུ་ བཏོན་གཏང་འོང་། ཐག་རིང་གི་ལམ་ལུགས་འདི་གིས་ [challenge](https://en.wikipedia.org/wiki/Challenge%E2%80%93response_authentication)འདི་ ལོག་བཏང་བཏངམ་ཨིན། ཁྱོད་ཀྱི་སྒེར་གྱི་ལྡེ་མིག་རྐྱངམ་གཅིག་གིས་ འདི་ལུ་ལན་བཏབ་ཚུགསཔ་ཨིན། ཁྱོད་ཀྱིས་ `ssh-agent` གིས་ ཁྱོད་ཀྱི་སྒེར་ཀྱི་ལྡེ་མིག་ལག་ལེན་འཐབ་སྟེ་ འ་ནི་དཀའ་ངལ་འདི་སེལ་འཐུ་འབད་ཞིནམ་ལས་ ལམ་ཐག་རིང་གི་ལམ་ལུགས་ལུ་ ཕྲང་བའི་ལན་ལོག་གཏང་འོང་། གལ་སྲིད་ གྲོས་འདེབས་དེ་ ལམ་ལུགས་གིས་རེ་བ་བསྐྱེད་མི་འདི་དང་མཐུནམ་ཡོད་པ་ཅིན་ ཁྱོད་ཀྱིས་ ཐབས་ལམ་ཐོབ་ཚུགས།

`ssh-agent` གི་མཛེས་སྡུག་འདི་ ཁྱོད་ཀྱི་ལས་རིམ་གྱི་སྐབས་ལུ་ ཁྱོད་ཀྱི་སྒེར་གྱི་ལྡེ་མིག་ལུ་བཞག་ནི་འདི་ཨིན་ དེ་འབདཝ་ལས་ ཁྱོད་ཀྱིས་ ཐག་རིང་གི་ལམ་ལུགས་ཅིག་གུ་ མཐུད་སྦྲེལ་འབད་པའི་སྐབས་ རྟག་བུ་རང་ ཁྱོད་ཀྱི་ལྡེ་མིག་ ཡང་ན་ སྒེར་གྱི་ལྡི་མིག་གི་ལྡེ་མིག་ནང་ ཐོ་བཀོད་འབད་དགོ་མི་འདུག

`ssh-agent` གྱི་སྐོར་ལས་གསལ་བྱའི་དོན་ལུ་ [དང་འབྲེལ་བའི་ SSH ཤེས་རིག་གཙུག་ལག་ཁང་གི་གནད་དོན་](https://www.ssh.com/academy/ssh/agent)ལུ་བལྟ་དགོ།

### Password འཛིན་སྐྱོང་འབད་ནིའི་ ལས་རིམ་བཙུགས་ནི། {#adding-a-password-manager-program}

## ཨེབ་གཏང་གི་ལྡེ་མིག་ཚུ་ གཟུགས་ཀྱི་རྣམ་པ་ལུ་བཞག་ནི། {#storing-cryptographic-keys-physically}

ཉེན་སྲུང་གི་གནས་ཚད་མཐོ་ཤོས་འཚོལ་མི་ཚུ་གི་དོན་ལུ་ ཨེན་ཌི་ཇི་ཨེཕ་ཨར་གྱི་ལྡེ་མིག་ཚུ་ གསོག་འཇོག་འབད་ནིའི་ གདམ་ཁ་འདི་གིས་ ཀི་པི་ཊོ་རིག་ལྡེ་མིག་འདི་ དངོས་སུ་སྦེ་ ཌི་ཇི་ཇི་ཨེཕ་ཡར་ལས་ ཡོངས་འབྲེལ་མེདཔ་སྦེ་ བཞག་ཚུགས་ནི་ཨིནམ་དང་ འདི་འབདཝ་ལས་ ངོས་ལེན་མ་འབད་མི་ ཐོབ་ཐངས་ཀྱི་ ཉེན་ཁ་དེ་ ཉུང་སུ་ཕབ་གཏང་ཚུགས། རང་བཞིན་གྱི་གདམ་ཁ་འདི་ངོས་ལེན་འབད་ནི་འདི་གིས་ ཉེན་སྲུང་གི་དགོས་མཁོ་མ་འདྲཝ་ཚུ་ལུ་ བལྟ་ནི་ལུ་ ང་བཅས་ཀྱིས་ ཁས་བླངས་འབད་མི་དེ་ གསལ་སྟོན་འབདཝ་ཨིན།

### དངོས་ཆས་ཀྱི་ལྡེ་མིག་ལག་ལེན་འཐབ་ནི་ {#using-a-hardware-key}

ང་བཅས་རའི་སྡེ་ཚན་གྱིས་ དངོས་ཆས་ཀྱི་ལྡེ་མིག་ཚུ་ ཉེན་སྲུང་གི་ཐབས་ལམ་ལེགས་ཤོམ་ཅིག་ཨིན་ཟེར་ མནོ་བསམ་བཏང་དོ་ཡོདཔ་ཨིན། དངོས་ཆས་ལྡེ་མིག་འདི་ USB ཝང་བརྒྱུད་དེ་ མཐུད་སྦྲེལ་འབད་ཡོད་པའི་ སྟབས་མ་བདེཝ་ཅིག་ཨིན་པའི་ཁར་ འདི་ལུ་ སྤྱིར་བཏང་གློག་མེ་ཌི་ཝང་བཟུམ་ཅིག་ཡོདཔ་ལས་ འཕྲུལ་ཆས་དང་འབྲེལ་བའི་ གནད་དོན་ཚུ་རྐྱངམ་གཅིག་ བྱ་བ་སྤྱོད་འབདཝ་ཨིན། འ་ནི་འདི་གིས་ སེལ་འཐུ་འབུམ་འདི་ ཉེན་སྲུང་གི་འཛོལ་བ་འབྱུང་པ་ཅིན་ འཕྲུལ་ཆས་དེ་འཇམ་ཏོང་ཏོ་སྦེ་བཏོན་གཏང་ནི་དང་ ཡང་ན་ དགོས་མཁོ་ཅན་གྱི་སྐབས་ འཕྲུལ་ཆས་གཞན་ཅིག་ལུ་ ལོག་མཐུད་སྦྲེལ་འབད་ཚུགས།

ཨིན་རུང་ ཧར་ཌའོར་ལྡེ་མིག་གི་ བཟོ་བཀོད་རྟགས་མང་རབས་ཅིག་ཡོདཔ་ལས་ ཁོང་རའི་ཁྱད་དུ་འཕགས་པའི་ APIs ་དེ་ ཁྱོད་ཀྱི་དགོས་མཁོ་ལུ་ འོས་འབབ་ཡོད་པའི་ལྡེ་མིག་འཚོལ་ནིའི་དོན་ལུ་ ཚོང་འབྲེལ་ནང་ལུ་ ཞིབ་འཚོལ་འབད་དགོཔ་འདི་ ཁག་ཆེ་ཡོདཔ་ཨིན།

ད་ལྟོ་ཚུན་ཚོད་ ང་བཅས་རའི་སྡེ་ཚན་གྱིས་ ནང་འཁོད་ལུ་ [YubiKey 5C](https://www.yubico.com/il/product/yubikey-5c/) ཝང་ལྡེ་མིག་དེ་ བརྟག་དཔྱད་འབད་ཡོདཔ་ད་ འདི་གིས་ ཕན་ཁྱད་ལེ་ཤ་ཡོད་པའི་ མངོན་གསལ་འདི་ཚུ་ཡོད་མི་དེ་ཡང་ ལེ་ཤ་ཅིག་ར་ API ལག་ལེན་འཐབ་ཚུགསཔ་ཨིན་མས།
