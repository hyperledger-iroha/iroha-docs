# ཨེབ་གཏང་འབད་ནིའི་ལྡེ་མིག་ཚུ་བཞག་ནི། {#storing-cryptographic-keys}

སྒེར་གྱི་ལྡེ་མིག་གིས་ དེ་གི་དབང་ཚད་ལུ་གནང་བ་བྱིན་ཡོད་པའི་བྱ་བ་ག་ར་ལུ་ གནང་བ་བྱིན་ཚུགས། སྒེར་གྱི་ལྡེ་མིག་ནམ་ཡང་བརྗེ་སོར་མ་འབད། སོན་རྒྱུ་ཆ་དང་ སླར་གསོའི་གསང་བ་ འབག་མི་རྟགས་མཚན་ དེ་ལས་ ཕྱིར་འདྲེན་འབད་ཡོད་པའི་ལྡེ་མིག་ཡིག་སྣོད་ཚུ་ བདག་འཛིན་ཅོག་འཐདཔ་སྦེ་ ཉེན་སྲུང་འབད།

བཟོ་སྐྲུན་འགོ་འདྲེན་འཐབ་པའི་ཧེ་མར་ སྲུང་སྐྱོབ་གི་འཆར་གཞི་འདི་ གདམ་ཁ་རྐྱབས། འཆར་གཞི་དེ་གིས་ ཉེན་ཁ་ཅན་གྱི་གོང་ཚད་དང་རྩིས་ཐོ་འཛིན་སྐྱོང་གི་ལམ་ལུགས་ དེ་ལས་ བཙུགས་ནིའི་ལཱ་དེ་ ལོག་སྤྱོད་འབད་ནི་གི་ བྱ་རིམ་ཚུ་དང་མཐུན་དགོ།

## སྲུང་སྐྱོབ་ཀྱི་ཚད་གཞི་ཚུ་ ངེས་གཏན་རྐྱབས། {#define-the-custody-boundary}

- དབང་འཛིན་རེ་རེ་དང་ མི་མང་ལྡེ་མིག་ བགོ་རྩིས་ མཐའ་འཁོར་ དམིགས་ཡུལ་ བདག་འཛིན་འཐབ་མི་ གསོག་འཇོག་ས་གནས་ རྒྱབ་ཐག་ དེ་ལས་ ཚབ་བཙུགས་ནིའི་བྱ་རིམ་ཚུ་གི་ ཐོ་གཞུང་བཞག།
- གོང་འཕེལ་དང་བརྟག་དཔྱད་ ཐོན་སྐྱེད་ དུས་རྒྱུན་གྱི་ཚོང་འབྲེལ་ གཞུང་སྐྱོང་ བཀྲམ་སྤེལ་ དེ་ལས་ ལོག་ཐོབ་ནིའི་དོན་ལུ་ ལྡེ་མིག་སོ་སོ་ཚུ་ལག་ལེན་འཐབ།
- མི་དང་བྱ་རིམ་ཚུ་ལུ་ ཁོང་རའི་འགན་ཁུར་ལུ་དགོ་པའི་ལྡེ་མིག་ཚུ་རྐྱངམ་ཅིག་འཛུལ་སྤྱོད་འབད་བཅུག།
- ཉེན་ཁ་དཔེ་ཚད་ལུ་དགོཔ་ད་ བརྩི་མཐོང་མཐོ་དྲགས་ཡང་ན་ གཞུང་སྐྱོང་མཚན་རྟགས་བཀོད་ནིའི་དོན་ལུ་ རང་དབང་གི་ཆ་འཇོག་དགོཔ།
- མིང་རྟགས་བཀོད་མི་ཅིག་གིས་ ཡོངས་འབྲེལ་དང་དབང་ཚད་ག་ཅི་ལག་ལེན་འཐབ་འོང་ག་ ཐོ་བཀོད་འབད། མིང་རྟགས་བཀོད་མི་ཞབས་ཏོག་ཅིག་གིས་ ཁྱབ་ཁོངས་དེ་གི་ཕྱི་ཁར་ ཞུ་བ་ཚུ་ ངོས་ལེན་མ་འབད་དགོ།

## གནས་སྡུད་བཞག་སའི་ ཐབས་ལམ་ཚུ་ གདམ་ཁ་རྐྱབས། {#choose-an-appropriate-storage-method}

ས་གནས་གོང་འཕེལ་དང་ ཚད་འཛིན་འབད་ཡོད་པའི་བརྟག་དཔྱད་ ཡང་ན་ ཉེན་སྲུང་ཅན་གྱི་ བདག་འཛིན་བཀྲམ་སྤེལ་གྱི་དོན་ལུ་ ལྡེ་མིག་ཅིག་ གནང་བ་བཀག་ཆ་འབད་ཡོད་པའི་ཡིག་སྣོད་ཅིག་ལུ་ ཕྱིར་འདྲེན་འབད་ཚུགས། རྒྱབ་སྐྱོར་འབད་ཡོད་པའི་ཡུ་ནིགསི་གཞི་རྟེན་གུ་ `kagami` དང་ཅིག་ཁར་ ལྡེ་མིག་སྣོད་ཐོ་གསརཔ་ཅིག་བཟོ་བཏོན་འབད།

སྒེར་གྱི་ལྡེ་མིག་ཡིག་སྣོད་འདི་གསང་བཟོ་མ་འབད་བའི་ཕྱིར་འདྲེན་ཅིག་ཨིན། འབྱུང་ཁུངས་ཚད་འཛིན་དང་ བརྗེ་སོར་འབད་ཡོད་པའི་སྣོད་ཐོ་ དྲན་ཐོ་ ཤོག་བྱང་ ཁ་སླབ་ དེ་ལས་ བཟོ་བསྐྲུན་གྱི་ཅ་ཆས་ཚུ་ལས་ ཕྱི་ཁར་བཞག། ཐོན་སྐྱེད་ལྡེ་མིག་ཅིག་ དེ་གི་ཆ་འཇོག་འབད་ཡོད་པའི་ བཀག་འཛིན་མཚམས་ལུ་ནང་འདྲེན་འབད་ཞིནམ་ལས་ བཀྲམ་སྤེལ་གྱི་བྱ་རིམ་དང་འཁྲིལ་ཏེ་ ཕྱིར་འདྲེན་འདི་བཏོན་གཏང་། ཐོན་སྐྱེད་ནང་ གོང་འཕེལ་ལྡེ་མིག་ཅིག་ ལོག་སྟེ་ལག་ལེན་མ་འཐབ།

ཐོན་སྐྱེད་ཀྱི་དོན་ལུ་ རྩིས་ཞིབ་འབད་ཡོད་པའི་ བདག་འཛིན་གྱི་ས་མཚམས་ དཔེར་ན།

- མཐུན་རྐྱེན་ཉེན་སྲུང་ཚད་གཞི་ཡང་ན་མཐུན་རྐྱེན་རྒྱབ་སྐྱོར་ལྡེ་མིག་མཛོད་ཅིག
- བཀོལ་སྤྱོད་རིམ་ལུགས་ཡང་ན་འགྲུལ་འཕྲིན་ལྡེ་མིག་མཛོད་ཁང་།
- རང་རྐྱང་དུ་མིང་རྟགས་བཀོད་པའི་ཞབས་ཞུ།
- དབང་སྤྲོད་འབད་ཡོད་པའི་ལཱ་གི་མངོན་གསལ་ལུ་རྐྱངམ་ཅིག་ལྡེ་མིག་ཅིག་བཏོན་མི་གསང་བའི་འཛིན་སྐྱོང་པ།

སེལ་འཐུ་འབད་ཡོད་པའི་མཉམ་བསྡོམས་འདི་གིས་ རྒྱུ་དངོས་དེ་ལུ་རྒྱབ་སྐྱོར་འབད་བའི་སྐབས་ ལྡེ་མིག་རྒྱུ་ཆ་ཕྱིར་འདྲེན་འབད་མ་བཏུབ་སྦེ་བཞག། བདག་འཛིན་རིམ་ལུགས་འདི་གིས་ Iroha གནང་བ་གཙོ་འཛིན་གྱིས་དགོ་པའི་ཨཱལ་གོ་རི་དམ་དང་མིང་རྟགས་བཀོལ་སྤྱོད་ལུ་རྒྱབ་སྐྱོར་འབདཝ་ཨིནམ་ངེས་གཏན་བཟོ།

ངལ་གསོ་ལུ་གསང་བཟོ་འབད་མི་འདི་གིས་ གསོག་འཇོག་འབད་ཡོད་པའི་འདྲ་བཤུས་ཅིག་ཉེན་སྲུང་འབདཝ་ཨིན། གནང་བ་མེད་པའི་ལས་སྦྱོར་ཡང་ན་བཀོལ་སྤྱོད་པ་གིས་ གསང་བཟོ་འབད་ཡོད་པའི་བཱའིཊི་ཚུ་ཐོབ་པའི་ཤུལ་ལས་ ལྡེ་མིག་ཅིག་ཉེན་སྐྱོབ་མི་འབད། ཧོསིཊི་འདི་སྲ་ཀྲག་བཟོ་སྟེ་ ལག་བསྟར་མཉེན་ཆས་འཛུལ་སྤྱོད་བཀག་ཆ་འབད་དེ་ མིང་རྟགས་བཀོད་ནིའི་ལས་སྣ་འདི་ལྟ་རྟོག་འབད།

གསང་བཟོ་ཡང་ན་ཆོག་ཡིག་གསརཔ་གིས་ འདྲ་བཤུས་རྐྱབ་ཡོད་པའི་སྒེར་གྱི་ལྡེ་མིག་འདི་ ལོག་སྟེ་ཉེན་སྲུང་འབད་མི་ཚུགས། འགྲེམ་སྟོན་གྱི་དོགས་པ་ཡོད་པའི་སྐབས་ ལྡེ་མིག་ལག་ལེན་འཐབ་ནི་འདི་བཀག་ཞིནམ་ལས་ ཆ་འཇོག་འབད་ཡོད་པའི་ཚབ་བཙུགས་ཡང་ན་ ཆ་མེད་གཏང་ནིའི་བྱ་རིམ་འདི་ ལག་ལེན་འཐབ།

:::
