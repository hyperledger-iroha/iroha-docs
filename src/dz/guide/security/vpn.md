# Virtual Private Networks {#virtual-private-networks}

<abbr title="Virtual Private Network">VPN</abbr>འདི་ འབྲེལ་མཐུད་ཀྱི་འཛིན་སྐྱོང་ཅིག་ཨིན་ འདི་གིས་ Iroha ཞབས་ཏོག་ཚུ་ ག་ལས་ཐོབ་ཚུགསཔ་ཨིན་ན་ བཀག་འཛིན་འབད་ཡོདཔ་ཨིན། འདི་ཡང་ སྒེར་གྱི་དང་ མཉམ་འབྲེལ་མཐུན་རྐྱེན་ཚུ་གི་དོན་ལུ་ ཕན་ཐོགས་ཆེ་ཤོས་ཡོདཔ་ད་ ལག་ལེན་འཕྲུལ་ཆས་ལག་ལེན་འཐབ་མི་ དེ་ལས་ ལག་ལེན་པ་ཚུ་གིས་ འགྲུལ་འཕྲིན་ཁ་ཐུག་ལུ་མེན་པར་ སྒེར་གྱི་ཁ་ཐུག་ལས་ བརྡ་སྤྲོད་འབད་དགོཔ་ཨིན།

VPN གིས་ Iroha འདྲན་འདྲ་ལྡེ་མིག་,རྩིས་ཁྲ་ལྡེ་མིག་ཚུ་, ངོས་ལེན་ཚུ་, མེ་ལོང་གི་ཁྲིམས་ལུགས་, ལྟ་རྟོག་འབད་ནི་, ཡང་ན་ ཉེན་སྲུང་ཅན་གྱི་ལྡེ་མིག་བཞག་སའི་ལྡེ་མིག་འདི་ཚབ་མ་གཏང་། འདི་ལག་ལེན་འཐབ་ནིའི་མཐའ་མཚམས་ནང་ ཚལ་གཅིག་སྦེ་འབད་: VPN གིས་ འབྲེལ་མཐུད་འབད་ནིའི་ལྕོགས་གྲུབ་ མར་ཕབ་འབད་ཡོདཔ་ད་ Iroha བཟོ་བཀོད་དང་ གཞུང་སྐྱོང་གིས་ ག་གི་ཆ་རོགས་དང་རྩིས་ཁྲ་ཚུ་ བློ་གཏད་ཚུགསཔ་ཨིན་ན་ གྲོས་ཐག་བཅད་དོ་ཡོདཔ་ཨིན།

## VPN ལག་ལེན་འཐབ་དགོ་པའི་དུས་ཚོད་ {#when-to-use-a-vpn}

ཁྱོད་ཀྱིས་ VPN ལག་ལེན་འཐབ་ད་:

- དངོས་ལེན་འབད་མི་ཚུ་ ལས་སྡེ་སོ་སོ་གིས་ལག་ལེན་འཐབ་དོ་ཡོདཔ་དང་ ཡང་ན་ གནས་སྟངས་སོ་སོ་ནང་ ལག་ལེན་འཐབ་དོ་ཡོདཔ་ཨིན།
- Torii གིས་ ལག་ལེན་རྒྱབ་སྐྱོར་འབད་མི་ཚུ་དང་ ལས་འཛིན་པ་ཚུ་ དེ་ལས་ ཡིད་ཆེས་ཅན་གྱི་ ཚོང་མགྲོན་པ་ཚུ་གིས་རྐྱངམ་གཅིག་ འཐོབ་ཚུགསཔ་བཟོ་དགོ།
- ཐོ་བཀོད་འབད་ཐབས། SSH, ཡང་ན་ འཛིན་སྐྱོང་མཇུག་གི་སྒོ་གཞན་ཚུ་ སྒེར་སྡེ་ལས་འཛིན་གྱི་དྲ་ལམ་ནང་ བཞག་དགོཔ་ཨིན།
- བརྟག་དཔྱད་འབད་ནི་དང་ བསྡུ་བསྒྱོམ་འབད་ནི་གི་ འབྲེལ་མཐུད་དེ་ གློག་ཐག་ར་བ་ཚུ་ བཟོ་སྐྲུན་འབད་ནིའི་ ཐབས་ལམ་སེལ་ཐབས་ལུ་ འོས་འབབ་ཡོདཔ་སྦེ་བཟོ་དགོ།

VPN འདི་ལག་ལེན་འཐབ་ནི་གི་དོན་ལས་མེན་ མི་སེར་གྱི་ཁ་ཐུག་གི་ཁ་ཐུག་ལུ་ Torii ཌེ་བི་ཊེཝི, Load Balancer, ཡང་ན་ Reverse Proxy ཚུ་བརྒྱུད་དེ་ ཐབས་ཤེས་བཏོན་དགོཔ་ཨིན། དེ་བཟུམ་ཅིག་འབད་བ་ཅིན་ཡང་ ལག་ལེན་པ་ཚུ་གིས་ རིམ་པ་གཅིག་ལས་ རིམ་པ་གཞན་གྱི་རྒྱུན་འགྲུལ་དང་ འཛིན་སྐྱོང་མཐའ་མཚམས་ཚུ་ ངེས་གཏན་འབད་ཚུགས་པ་ཅིན་ བཀག་དམ་ཅན་གྱི་ཁ་ཐུག་ལུ་བཞག་ཚུགས།

::: tip

བལྟ་བཤལཔ་ཅིག་གིས་ VPN འདི་ནང་ལས་རྐྱངམ་གཅིག་ འགྲུལ་བསྐྱོད་སྲུང་སྐྱོབ་འབདཝ་ཨིན། འདི་གིས་ `irohad`, CLI, SDK, SSH, metrics, ཡང་ན་ རྒྱབ་སྐྱོར་འགྲུལ་བསྐྱོད་ཚུ་ སྲུང་སྐྱོབ་མི་འབད་དོ་ཡོདཔ་ད་ དེ་བཟུམ་གྱི་ བྱ་རིམ་ཚུ་ སྒེར་གྱི་དྲ་ལམ་གཅིག་བརྒྱུད་དེ་ བཏོན་མ་ཚུགསཔ་ལས་མ་གཏོགས་ཨིན།

## ལག་ལེན་འཐབ་ནིའི་ ཐབས་ལམ་ {#deployment-pattern}

སྒེར་གྱི་ཨང་རྟགས་དཔྱད་འཕྲུལ་ཆས་ཚུ་གི་དོན་ལུ་ ཨང་རྟགས་བཀོད་འཕྲུལ་ཆས་རེ་ལུ་ གནས་བརྟན་ VPN ཡི་གུ་དང་ ཡང་ན་ སྒེར་གྱི་མིང་ DNS བྱིན་དགོ། གྲྭ་ཚང་ཚུ་ གཞི་སྒྲིག་འབད་ཞིནམ་ལས་ ཁོང་རའི་བརྡ་སྤྲོད་འབད་མི་ གྲྭ་ཚང་གི་བར་ནའི་ཁ་བྱང་ཚུ་ གཞན་མི་ཨང་རྟགས་ཞིབ་འཕྲུལ་ཆས་ཚུ་ལས་ འབྲེལ་བ་འཐབ་ཚུགསཔ་བཟོ་ནི།

```toml
trusted_peers = [
  "PUBLIC_KEY_1@10.20.0.11:1337",
  "PUBLIC_KEY_2@10.20.0.12:1337",
  "PUBLIC_KEY_3@10.20.0.13:1337",
  "PUBLIC_KEY_4@10.20.0.14:1337",
]

[network]
address = "10.20.0.11:1337"
public_address = "10.20.0.11:1337"

[torii]
address = "10.20.0.11:8080"
```

ད་ལྟོའི་མཉམ་རོགས་ལུ་ བཏང་མི་ཁ་བྱང་འདི་ ལག་ལེན་འཐབ་དགོ། `network.address` དང་ `network.public_address`. འདྲན་འདྲ་མཉམ་པ་ཚུ་གིས་ ཡིད་ཆེས་ཅན་གྱི་འདྲན་འདྲ་ངོ་རྟགས་ཚུ་བཀོད་དགོཔ་ཨིན་ དེ་འབདཝ་ད་ རང་སོའི་ཨེ་རེསི་ཚུ་ལས་ བཏོན་ཚུགསཔ་ཨིན། VPN ལམ་སྟོན་གྱི་ལྕོག་རྩེ་

ཚོང་མགྲོན་པ་དང་ CLI བཟོ་བཀོད་ཚུ་ A ལུ་བཏོན་དགོ། Torii མཐའ་མཇུག་གི་ས་སྒོ་འདི་ ཕྲང་ལམ་བརྒྱུད་ VPN ཡང་ན་ ཚད་འཛིན་ཅན་གྱི་ ནང་འཁོད་སྒོ་སྒྲིག་གི་ཐོག་ལས་:

```toml
torii_url = "http://10.20.0.11:8080"
```

Torii གིས་ VPN གྱི་ཕྱི་ཁར་ལག་ལེན་འཐབ་དགོཔ་ཨིན་པ་ཅིན་ དེ་གིས་ TLS འདི་གི་དོན་ལུ་ བདེན་ཁུངས་བཟོ་ནི་དང་ རེ་རེ་ཚད་འཛིན་འབད་ནི་དང་ ཐོ་བཀོད་འབད་ནི་གི་ ཉེན་ཁ་ཡོད་པའི་རྒྱབ་འགལ་ལས་འགུལ་ (reverse proxy or load balancer) གི་རྒྱབ་ཁར་བཞག་དགོ། གྲྭ་ཚང་གི་བར་ནའི་སྒོ་ར་ཚུ་ ཡང་ན་ ཞི་གཡོགཔ་ཚུ་གི་མཐའ་མཇུག་གི་སྒོ་ར་ཚུ་ འགྲེམ་ཐོག་ཐོག་ལས་ མི་མང་གི་ အင်တာနက်ལུ་ བཏོན་མ་བཅུགཔ་ཨིན་མས།

## ཉེན་སྲུང་གི་ཐིག་ཁྲམ་ཚུ་ {#firewall-rules}

VPN ཡོད་པའི་སྐབས་ཡང་ host དང་ cloud firewall གི་ལུགས་ཚུ་ལག་ལེན་འཐབ་དགོ།

|ཞབས་ཏོག་ |གྲོས་འཆར་ཅན་གྱི་འཛུལ་སྒོ་ |
| --- | --- |
|གྲྭ་ཚང་གི་བར་ནའི་སྒོ་ |གཞན་མི་ལག་ལེན་རྟགས་མ་ VPN འབྲི་ཤོག་ཚུ་རྐྱངམ་ཅིག་ཨིན།|
|Torii |ལག་ལེན་གྱི་རྒྱབ་སྐྱོར་, ལས་འཛིན་, ཡང་ན་ ཡིད་ཆེས་ཅན་གྱི་མགྲོན་པ་ VPN གི་ཁྱད་ཚད་ |
|ཚད་འཇལ་ཐངས་དང་ གསོ་བའི་བརྟག་དཔྱད་|ལས་འཛིན་གྱི་དྲ་ལམ་ནང་ལུ་ ལྟ་རྟོག་འབད་ཐངས་ |
|SSH དང་ གཞུང་སྐྱོང་ |Bastion host, privileged operator VPN range, ཡང་ན་ glass breaking process |
|རྒྱབ་སྐྱོར་དང་ གསོག་འཇོག་འབད་ཐངས་ |སྒེར་གྱི་ཁ་ཐུག་ལུ་ རྒྱབ་སྐྱོར་ལམ་ལུགས་ཚུ་ |

སྔོན་སྒྲིག་མ་བཏུབ་པའི་ལམ་ལུགས་འདི་ སྤྱིར་བཏང་གི་ཁྲིམས་ལུགས་ལས་ དབྱེ་ཞིབ་འབད་ནི་ལུ་འཇམ་ཏོང་ཏོ་ཨིན། གྲྭ་ཚང་གསརཔ་ཅིག་ཐོ་བཀོད་འབད་ཞིནམ་ལས་ འབྲེལ་བ་འཐབ་ད་ VPN གི་འཐུས་མི་ཡིག་ཆ་ཚུ་ ད་ལྟོའི་བར་ན་ཡང་ གསར་གཏོད་འབད་དགོ་ ཕའི་ཝའོར་གྱི་ཆོག་ཐམ་ཐོ་དང་ Iroha ཡིད་ཆེས་ཅན་གྱི་མཉམ་འབྲེལ་ཡིག་གཟུགས་དེ་ བསྒྱུར་བཅོས་གཅིག་སྦེ་བཟོ་དགོ།

## ལས་འགུལ་གྱི་བརྟག་དཔྱད་ཐོ་ {#operational-checklist}

- VPN ལག་ལེན་དེ་སེལ་འཐུ་འབད། དཔེར་ན་ WireGuard, IPsec, ཡང་ན་ ལས་སྡེ་གིས་ ངོས་འཛིན་འབད་ཡོད་པའི་ བདག་འཛིན་འཐབ་མི་ སྒེར་སྡེའི་ཁ་ཐུག་གི་ཁ་སྐོང་།
- host དང་ operator གི་དོན་ལུ་ ཁྱད་ཅན་ VPN credentials ལག་ལེན་འཐབ་། VPN keys འདི་ validator ཚུ་གི་བར་ན་མ་བགོ་བཤའ་འབད།
- VPN གི་མཚན་རྟགས་ཚུ་ Iroha སྒེར་གྱི་ལྡེ་མིག་དང་ genesis signing material ལས་སོ་སོ་སྦེ་བཞག་དགོ།
- VPN བརྟག་ཞིབ་འབད་ཐབས། ཕབ་ལེནཌ་རླག་གཏང་ཐབས། མཐུད་སྦྲེལ་འབད་ནི་དང་ལམ་གྱི་འགྱུར་བཅོས་ཚུ་ བལྟ་ཐབས། གྲོས་བསྟུན་འདི་ ཡུན་བརྟན་མེད་པའི་དྲ་རྒྱ་གི་གནས་སྟངས་ལུ་ གནོད་སྐྱོན་རྐྱབ་ཨིན།
- ཕན་ནུས་ཅན་གྱི་ MTU བརྟག་དཔྱད་འབད་ སྦ་སྒོར་དུམ་གྲ་ཅིག་གིས་ དུས་ཡུན་ཐུང་ཀུ་སྦེ་ འདྲཝ་འདྲ་མཉམ་ ཡང་ན་ Torii གི་འཛོལ་བ་བཟུམ་མཐོང་ཚུགས།
- ཡིག་སྣོད་དེ་ VPN གི་དབྱེ་བ་ཚུ་ རིམ་པ་ལས་ རིམ་པ་ལུ་བསླེབས་ཚུགས་ནི་ཨིནམ་དང་ Torii, metrics, SSH དེ་ལས་ backup endpoints.
- VPN ཁྱད་ཐོ་ཚུ་ host, operator account, ཡང་ན་ལས་སྡེ་ཅིག་གིས་དྲ་ལམ་སྤོ་འགྱོ་བའི་སྐབས་ལུ་ བསྒྱུར་བཅོས་འབད།.
- ཚད་འཛིན་འབད་མི་ཚུ་གི་བར་ན་ ཐབས་ལམ་གཅིག་སྦེ་ VPN gateway འདི་སྤང་དགོ། བཟོ་སྐྲུན་གྱི་དྲ་རྒྱ་ཚུ་གི་དོན་ལུ་ redundant gateways ཡང་ན་ site-to-site routes འཆར་འགོད་འབད།
- VPN བྱུང་རྐྱེན་ལུ་ལན་འདེབས་འབད་ནིའི་ བརྟག་ཞིབ་ནང་ལུ་ འཛོལ་བ་ཚུ་ཚུད་དེ་ཡོདཔ་ལས་ ལས་འཛིན་པ་ཚུ་གིས་ གྲོག་ཐིག་བགོ་བཀྲམ་འབད་ནི་དང་ Iroha བྱ་རིམ་འཛོལ་བ་ཚུ་ག་དེམ་ཅིག་སྦེ་དབྱེ་བ་ཕྱེ་དགོཔ་ཨིན་ན་ཤེས་འོང་།
