# རྟོག་བཟོའི་སྒེར་དྲ་རྒྱ་ཚུ་ {#virtual-private-networks}

<abbr title="Virtual Private Network">VPN</abbr>འདི་ འབྲེལ་མཐུད་ཀྱི་འཛིན་སྐྱོང་ཅིག་ཨིན་ འདི་གིས་ Iroha ཞབས་ཏོག་ཚུ་ ག་ལས་ཐོབ་ཚུགསཔ་ཨིན་ན་ བཀག་འཛིན་འབད་ཡོདཔ་ཨིན། འདི་ཡང་ སྒེར་གྱི་དང་ མཉམ་འབྲེལ་མཐུན་རྐྱེན་ཚུ་གི་དོན་ལུ་ ཕན་ཐོགས་ཆེ་ཤོས་ཡོདཔ་ད་ ལག་ལེན་འཕྲུལ་ཆས་ལག་ལེན་འཐབ་མི་ དེ་ལས་ ལག་ལེན་པ་ཚུ་གིས་ འགྲུལ་འཕྲིན་ཁ་ཐུག་ལུ་མེན་པར་ སྒེར་གྱི་ཁ་ཐུག་ལས་ བརྡ་སྤྲོད་འབད་དགོཔ་ཨིན།

VPN གིས་ Iroha མཐུད་མཚམས་ལྡེ་མིག་,རྩིས་ཐོ་ལྡེ་མིག་ཚུ་, ངོས་ལེན་ཚུ་, མེ་ལོང་གི་ཁྲིམས་ལུགས་, ལྟ་རྟོག་འབད་ནི་, ཡང་ན་ ཉེན་སྲུང་ཅན་གྱི་ལྡེ་མིག་བཞག་སའི་ལྡེ་མིག་འདི་ཚབ་མ་གཏང་། འདི་ལག་ལེན་འཐབ་ནིའི་མཐའ་མཚམས་ནང་ ཚལ་གཅིག་སྦེ་འབད་: VPN གིས་ འབྲེལ་མཐུད་འབད་ནིའི་ལྕོགས་གྲུབ་ མར་ཕབ་འབད་ཡོདཔ་ད་ Iroha བཟོ་བཀོད་དང་ གཞུང་སྐྱོང་གིས་ ག་གི་མཐུད་མཚམས་དང་རྩིས་ཐོ་ཚུ་ བློ་གཏད་ཚུགསཔ་ཨིན་ན་ གྲོས་ཐག་བཅད་དོ་ཡོདཔ་ཨིན།

## VPN ལག་ལེན་འཐབ་དགོ་པའི་དུས་ཚོད་ {#when-to-use-a-vpn}

ཁྱོད་ཀྱིས་ VPN ལག་ལེན་འཐབ་ད་:

- བདེན་དཔྱད་འབད་མི་ཚུ་ ལས་སྡེ་སོ་སོ་ཚུ་གིས་ ཡང་ན་ ཧོསིཊི་མཐའ་འཁོར་སོ་སོ་ཚུ་ནང་ ལག་ལེན་འཐབ་ཨིན།
- Torii གིས་ ལག་ལེན་རྒྱབ་སྐྱོར་འབད་མི་ཚུ་དང་ ལས་འཛིན་པ་ཚུ་ དེ་ལས་ ཡིད་ཆེས་ཅན་གྱི་ ཚོང་མགྲོན་པ་ཚུ་གིས་རྐྱངམ་གཅིག་ འཐོབ་ཚུགསཔ་བཟོ་དགོ།
- ཐོ་བཀོད་འབད་ཐབས། SSH, ཡང་ན་ འཛིན་སྐྱོང་མཇུག་གི་སྒོ་གཞན་ཚུ་ སྒེར་སྡེ་ལས་འཛིན་གྱི་དྲ་ལམ་ནང་ བཞག་དགོཔ་ཨིན།
- བརྟག་དཔྱད་ཡང་ན་ གནས་རིམ་ཡོངས་འབྲེལ་འདི་ མི་མང་མཐའ་མཚམས་ཚུ་ གསལ་སྟོན་མ་འབད་བར་ ཐོན་སྐྱེད་འཛུལ་སྤྱོད་ཚད་འཛིན་ཚུ་དང་ ཅོག་འཐདཔ་སྦེ་དགོ།

བཀྲམ་སྤེལ་རེ་རེ་ལུ་ A VPN དགོས་མཁོ་མེད། མི་མང་ཡོངས་འབྲེལ་ཚུ་གིས་ མི་མང་སྒོ་སྒྲིག་དང་ མངོན་གསལ་འབད་མི་ ཡང་ན་ རྒྱབ་འགལ་གྱི་ངོ་ཚབ་བརྒྱུད་དེ་ Torii ཤེས་བཞིན་དུ་ གསལ་སྟོན་འབད་ཚུགས། གནས་སྟངས་དེ་ནང་ཡང བདེན་དཔྱད་འབད་མི་ མཉམ་འབྲེལ་འགྲུལ་སྐྱོད་དང་ བདག་སྐྱོང་ API མཐའ་མཚམས་ཚུ་ བཀག་ཆ་འབད་ཡོད་པའི་ཡོངས་འབྲེལ་གུ་ ག་དེམ་ཅིག་འབད་ཚུགས་ཚུགསཔ་ཅིག་བཞག།

## ལག་ལེན་འཐབ་ནིའི་ ཐབས་ལམ་ {#deployment-pattern}

སྒེར་གྱི་ཨང་རྟགས་དཔྱད་འཕྲུལ་ཆས་ཚུ་གི་དོན་ལུ་ ཨང་རྟགས་བཀོད་འཕྲུལ་ཆས་རེ་ལུ་ གནས་བརྟན་ VPN ཡི་གུ་དང་ ཡང་ན་ སྒེར་གྱི་མིང་ DNS བྱིན་དགོ། མཐུད་མཚམས་ཚུ་ གཞི་སྒྲིག་འབད་ཞིནམ་ལས་ ཁོང་རའི་བརྡ་སྤྲོད་འབད་མི་ མཐུད་མཚམས་གི་བར་ནའི་ཁ་བྱང་ཚུ་ གཞན་མི་ཨང་རྟགས་ཞིབ་འཕྲུལ་ཆས་ཚུ་ལས་ འབྲེལ་བ་འཐབ་ཚུགསཔ་བཟོ་ནི།

```toml
trusted_peers = [
  "PUBLIC_KEY_1@10.20.0.11:1337",
  "PUBLIC_KEY_2@10.20.0.12:1337",
  "PUBLIC_KEY_3@10.20.0.13:1337",
  "PUBLIC_KEY_4@10.20.0.14:1337",
]

[network]
address = "10.20.0.11:1337"
public_address = "10.20.0.11:1337"

[torii]
address = "10.20.0.11:8080"
```

ད་ལྟོའི་མཐུད་མཚམས་ལུ་ བཏང་མི་ཁ་བྱང་འདི་ ལག་ལེན་འཐབ་དགོ། `network.address` དང་ `network.public_address`. མཐུད་མཚམས་མཉམ་པ་ཚུ་གིས་ ཡིད་ཆེས་ཅན་གྱི་མཐུད་མཚམས་ངོ་རྟགས་ཚུ་བཀོད་དགོཔ་ཨིན་ དེ་འབདཝ་ད་ རང་སོའི་ཨེ་རེསི་ཚུ་ལས་ བཏོན་ཚུགསཔ་ཨིན། VPN ལམ་སྟོན་གྱི་ལྕོག་རྩེ་

ཚོང་མགྲོན་པ་དང་ CLI བཟོ་བཀོད་ཚུ་ A ལུ་བཏོན་དགོ། Torii མཐའ་མཇུག་གི་ས་སྒོ་འདི་ ཕྲང་ལམ་བརྒྱུད་ VPN ཡང་ན་ ཚད་འཛིན་ཅན་གྱི་ ནང་འཁོད་སྒོ་སྒྲིག་གི་ཐོག་ལས་:

```toml
torii_url = "http://10.20.0.11:8080"
```

གལ་སྲིད་ Torii འདི་ VPN གི་ཕྱི་ཁར་འཐོབ་དགོཔ་ཨིན་པ་ཅིན་ TLS དང་ བདེན་བཤད་ ཚད་གཞི་ཚད་འཛིན་ དེ་ལས་ དྲན་ཐོ་བཀོད་ནི་ཚུ་བྱིན་མི་ རྒྱབ་འགལ་གྱི་ངོ་ཚབ་ཡང་ན་ མངོན་གསལ་ཚད་འཛིན་གྱི་རྒྱབ་ཁར་བཙུགས། མི་མང་ཡོངས་འབྲེལ་ལུ་ཐད་ཀར་དུ་ མཉམ་འབྲེལ་གྱི་མཐུད་ལམ་ཡང་ན་ བདག་སྐྱོང་ API མཐའ་མཚམས་ཚུ་ གསལ་སྟོན་འབད་ནི་ལས་འཛེམ་དགོ།

| --- | --- |

| SSH དང་བདག་སྐྱོང་ | བཙན་རྫོང་ ཧོསཊི་ ཐོབ་དབང་བཀོལ་སྤྱོད་པ་ VPN ཁྱབ་ཚད་ ཡང་ན་ ཤེལ་གྱི་བྱ་རིམ། |
| རྒྱབ་ཐག་དང་གསོག་འཇོག་འདྲ་བཤུས། | སྒེར་གྱི་ཡོངས་འབྲེལ་གུ་རྒྱབ་ཐག་རིམ་ལུགས་ཚུ། |

སྔོན་སྒྲིག་མ་བཏུབ་པའི་ལམ་ལུགས་འདི་ སྤྱིར་བཏང་གི་ཁྲིམས་ལུགས་ལས་ དབྱེ་ཞིབ་འབད་ནི་ལུ་འཇམ་ཏོང་ཏོ་ཨིན། མཐུད་མཚམས་གསརཔ་ཅིག་ཐོ་བཀོད་འབད་ཞིནམ་ལས་ འབྲེལ་བ་འཐབ་ད་ VPN གི་འཐུས་མི་ཡིག་ཆ་ཚུ་ ད་ལྟོའི་བར་ན་ཡང་ གསར་གཏོད་འབད་དགོ་ ཕའི་ཝའོར་གྱི་ཆོག་ཐམ་ཐོ་དང་ Iroha ཡིད་ཆེས་ཅན་གྱི་མཉམ་འབྲེལ་ཡིག་གཟུགས་དེ་ བསྒྱུར་བཅོས་གཅིག་སྦེ་བཟོ་དགོ།

## ལས་འགུལ་གྱི་བརྟག་དཔྱད་ཐོ་ {#operational-checklist}

- VPN ལག་ལེན་དེ་སེལ་འཐུ་འབད། དཔེར་ན་ WireGuard, IPsec, ཡང་ན་ ལས་སྡེ་གིས་ ངོས་འཛིན་འབད་ཡོད་པའི་ བདག་འཛིན་འཐབ་མི་ སྒེར་སྡེའི་ཁ་ཐུག་གི་ཁ་སྐོང་།
- ཧོསིཊི་དང་བཀོལ་སྤྱོད་པ་རེ་རེ་གི་དོན་ལུ་ གཞན་དང་མ་འདྲ་བའི་ VPN ཡིག་ཆ་ཚུ་ལག་ལེན་འཐབ། བདེན་དཔྱད་འབད་མི་ཚུ་གི་བར་ན་ VPN ལྡེ་མིག་ཚུ་ བརྗེ་སོར་མ་འབད།
- VPN གི་མཚན་རྟགས་ཚུ་ Iroha སྒེར་གྱི་ལྡེ་མིག་དང་ འགོ་ཐོག མིང་རྟགས་འགོད་ནི མཁོ་ཆས ལས་སོ་སོ་སྦེ་བཞག་དགོ།
- VPN བརྟག་ཞིབ་འབད་ཐབས། ཕབ་ལེནཌ་རླག་གཏང་ཐབས། མཐུད་སྦྲེལ་འབད་ནི་དང་ལམ་གྱི་འགྱུར་བཅོས་ཚུ་ བལྟ་ཐབས། གྲོས་བསྟུན་འདི་ ཡུན་བརྟན་མེད་པའི་དྲ་རྒྱ་གི་གནས་སྟངས་ལུ་ གནོད་སྐྱོན་རྐྱབ་ཨིན།
- ཕན་ནུས་ཅན་གྱི་ MTU བརྟག་དཔྱད་འབད་ ཆ་ཚན་དུམ་གྲ་ཅིག་གིས་ དུས་ཡུན་ཐུང་ཀུ་སྦེ་ འདྲཝ་འདྲ་མཉམ་ ཡང་ན་ Torii གི་འཛོལ་བ་བཟུམ་མཐོང་ཚུགས།
- ཡིག་ཆ་ VPN ཁྱབ་ཚད་ཚུ་ མཉམ་རོགས་ Torii དང་ མེ་ཊིགསི་ SSH དེ་ལས་ རྒྱབ་ཐག་ API མཐའ་མཚམས་ཚུ་ལུ་ལྷོད་བཅུགཔ་ཨིན།
- VPN ཁྱད་ཐོ་ཚུ་ མགྲོན་སྐྱོང་གློག་འཕྲུལ, བཀོལ་སྤྱོད་པ རྩིས་ཐོ, ཡང་ན་ལས་སྡེ་ཅིག་གིས་དྲ་ལམ་སྤོ་འགྱོ་བའི་སྐབས་ལུ་ བསྒྱུར་བཅོས་འབད།.
- བདེན་དཔྱད་འབད་མི་ཚུ་གི་བར་ན་ ལམ་གཅིག་རྐྱངམ་ཅིག་ VPN འཛུལ་སྒོ་འདི་ བཀག་བཞག། བཟོ་བསྐྲུན་ཡོངས་འབྲེལ་གྱི་དོན་ལུ་ མ་དགོ་པའི་འཛུལ་སྒོ་ཡང་ན་ ས་ཁོངས་ལས་ས་ཁོངས་ཀྱི་ལམ་ཚུ་འཆར་གཞི་བརྩམ།
- VPN བྱུང་རྐྱེན་ལུ་ལན་འདེབས་འབད་ནིའི་ བརྟག་ཞིབ་ནང་ལུ་ འཛོལ་བ་ཚུ་ཚུད་དེ་ཡོདཔ་ལས་ ལས་འཛིན་པ་ཚུ་གིས་ གྲོག་ཐིག་བགོ་བཀྲམ་འབད་ནི་དང་ Iroha བྱ་རིམ་འཛོལ་བ་ཚུ་ག་དེམ་ཅིག་སྦེ་དབྱེ་བ་ཕྱེ་དགོཔ་ཨིན་ན་ཤེས་འོང་།
