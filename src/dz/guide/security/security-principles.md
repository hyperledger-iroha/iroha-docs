# ཉེན་སྲུང་གི་གཞི་རྩ་ཚུ་ {#security-principles}

ལས་སྡེ་དང་མི་རྐྱང་གི་ལག་ལེན་འཐབ་མི་ཚུ་གིས་ Iroha མཐུན་རྐྱེན་ཚུ་དང་གཅིག་ཁར་ ཉེན་སྲུང་ཅན་སྦེ་ འབྲེལ་བ་འཐབ་ནི་ལུ་ མཉམ་འབྲེལ་འབད་དགོཔ་ཨིན། འ་ནི་གནད་དོན་འདི་ གྲོས་བསྟུན་ཚུ་གི་འོག་ལུ་ གཞི་རྟེན་གཞི་རྩ་ཚུ་ གསལ་སྟོན་འབདཝ་ཨིན།

## ཉེན་སྲུང་གི་གཞི་རྩ་ཚུ་ {#general-security-principles}

1. [Virtual Private Network ](./vpn.md) (VPN) ལག་ལེན་འཐབ་ནི་:

    - གནད་དོན་ཁག་ཆེ་ཤོས་དང་ མཐུན་རྐྱེན་ཚུ་ལག་ལེན་འཐབ་པའི་སྐབས་ལུ་ <abbr title="Virtual Private Network">VPN</abbr> ལག་ལེན་འཐབ་སྟེ་ ཁྱོད་ཀྱི་བརྡ་དོན་ཚུ་གི་ ཉེན་སྐྱོབ་འབད་ནིའི་དོན་ལུ་ ཉེན་སྲུང་ཅན་གྱི་འབྲེལ་བ་བཙུགས་དགོ།

2. འབྲེལ་མཐུད་སྲུང་སྐྱོབ་གི་དོན་ལུ་ ཉེན་སྲུང་གི་ཐོ་བཀོད་ལག་ལེན་འཐབ་:

    - ཁྱིམ་དང་ / ཡང་ན་ ཡིག་ཚང་གི་དྲ་རྒྱ་ཚུ་ སྒྲིང་སྒྲི་བཟོ་སྟེ་སྒྲིང་སྒྲི་བཟོ། འདི་ཡང་ ངོས་ལེན་མ་འབད་མི་འཛུལ་སྒོ་ཚུ་བཀག་ཐབས་ལུ་ ཕན་ཐོགས་འབྱུང་ནི་ཨིནམ་མ་ཚད་ འབྲེལ་མཐུད་འབད་ཡོད་པའི་འཕྲུལ་ཆས་ཚུ་ལུ་ ནད་འབུབ་དང་ malware ལས་སྲུང་སྐྱོབ་འབད་ནི་ཨིན།

3. རང་བཞིན་དང་ ཌི་ཇི་ཊཱལ་གྱི་ བརྡ་དོན་ཚུ་ ཉེན་སྲུང་འབད་ནི།

    - རང་བཞིན་གྱི་ཡིག་ཆ་ཚུ་ ཉེན་སྲུང་ཅན་གྱི་ ས་གནས་ནང་ལུ་ གསལ་ཏོག་ཏོ་ཡོད་པའི་བརྡ་དོན་ཚུ་ནང་ སྲུང་སྐྱོབ་འབད་དགོཔ་དང་ ཌི་ཇི་ཊཱལ་ཡིག་ཆ་ཚུ་ ཟིན་བྲིས་དང་ལྡནམ་སྦེ་ གནས་སྡུད་ཚུ་གི་ནང་ན་བཞག་དགོཔ་ཨིན།

4. གནས་སྡུད་ཚུ་ དུས་རྒྱུན་སྦེ་ རྒྱབ་སྐྱོར་འབད་:

    - ཨ་རྟག་རང་ ཁྱོད་ཀྱི་གལ་ཆེ་ཤོས་གི་ བརྡ་དོན་ཚུ་གི་འདྲ་བཤུས་ཚུ་ ཉེན་སྲུང་ཅན་གྱི་ས་གནས་ཅིག་ནང་བཞག་དགོ། འདི་བཟུམ་སྦེ་ ཁྱོད་ཀྱིས་ གནད་སྡུད་ཚུ་འབྱང་ད་ ཡང་ན་ གནད་དོན་ག་ཅི་ཡང་མ་བདེཝ་སྦེ་འགྱོ་པ་ཅིན་ དེ་ཚུ་ག་ར་མགྱོགས་པར་ ལོག་སྟེ་ལམ་ཁར་བཙུགས་ཚུགསཔ་ཨིན། ཁྱོད་ཀྱི་ཡིག་ཆ་འདི་ རང་གིས་རྒྱུན་ལས་བཟུང་སྡོད་སའི་ ས་གནས་གཞན་ནང་ལུ་ བཏོན་གཏང་།

## ལག་ལེན་འཐབ་མི་རྐྱང་ཚུ་གི་དོན་ལུ་ ཉེན་སྲུང་གི་གཞི་རྩ་ཚུ་ {#security-principles-for-individual-users}

1. དམ་ཚིག་ཅན་གྱི་ བདེན་ཁུངས་ཀྱི་ལམ་ལུགས་ཚུ་ལག་ལེན་འབད་:

    - རྩིས་ཁྲ་ཆ་མཉམ་གི་དོན་ལུ་ ཉེན་ཁ་ཅན་དང་ ཁྱད་དུ་འཕགས་པའི་ལྡེ་མིག་ཚུ་ལག་ལེན་འཐབ་དགོ།

    - རྟགས་མཚན་ཚུ་ ལོག་སྟེ་ནམ་ཡང་ལག་ལེན་འཐབ་ནི་མི་འོང་།

    - <abbr title="Two-Factor Authentication">2FA</abbr>འདི་ འོས་འབབ་ཡོད་སར་ གཞི་བཙུགས་འབདཝ་ཨིན། <abbr title="Two-Factor Authentication">2FA</abbr>གིས་ གནས་སྡུད་ཀྱི་ ཉེན་སྲུང་ཡར་དྲག་གཏང་ནི་ཨིནམ་ད་ འདི་གི་དོན་ལུ་ ལྡེ་ཡིག་རྐྱངམ་ཅིག་མ་དགོཔ་ལས་ ད་རུང་ གནད་དོན་གཞན་ཅིག་ཡང་ དགོཔ་ཨིན་ དཔེར་ན་ <abbr title="One-Time Password">OTP</abbr>,མཛུབ་རྟགས་དང་ ཡང་ན་ གསུམ་གྱི་ལག་ལེན་ལུ་གཞི་བཞག་སྟེ་ བདའ་ཟུན་ཚུགསཔ་ (དཔེར་ན་ Google Authenticator) ཨིན།

    - ཁྱོད་ཀྱིས་ SMS བདེན་ཁུངས་བཟོ་བཀོད་དེ་ གཉིས་པ་སྦེ་ལག་ལེན་འཐབ་མ་བཅུག། ཚུལ་ཆས་ངན་པ་དེ་གིས་ ཁྱོད་ཀྱི་ SMS བརྡ་བྱང་ཚུ་ བརྟག་ཞིབ་མ་འབད་བའི་ ཁེ་ཕན་མེདཔ་ཨིན། དཔེར་ན་, Android ལས་རིམ་ཚུ་གིས་ ཁོང་རའི་དོན་ལུ་ དམིགས་བསལ་དུ་བཀོད་རྒྱ་ཡོད་མི་ བརྡ་དོན་ཚུ་ལུ་རྐྱངམ་ཅིག་ ཐོ་ལེན་འབད་ནི་ལུ་ ངེས་འཛིན་འབད་མི་ཚུགས།

2. ཌི་ཇི་ཊཱལ་ བརྡ་དོན་ནང་ དྲན་པ་བཏོན་: - བརྒྱུད་འཕྲིན་ཨང་གྲངས། (e-mail client) གཞི་བཙུགས་འབད་ཞིནམ་ལས་ ཡོངས་འབྲེལ་ཨང་གྲངསཚུ་ ཐོ་བཀོད་དང་བརྟག་དཔྱད་འབད་ཚུགས། བརྒྱུད་འཕྲིན་བཏང་མི་གི་ཁ་བྱང་བཟོ་ནི་དང་ དངུལ་ཁང་ཅིག་སྦེ་བཟོ་བཅུག་ནི་ཡང་ འོང་སྲིད་ནི་ཨིན་རུང་ ངོ་རྟགས་རྫུས་མ་བཟོ་ནི་དེ་ མགྱོགས་དྲགས་ཨིན། - HTML བརྡ་དོན་གཉིས་ཆ་ར་དང་ ཕྱི་ཁའི་ཐོན་ཁུངས་ཚུ་ བཀྲམ་སྤེལ་འབད་མི་ཚུ་ ངོ་མ་ཤེས་མི་དང་ ཡང་ཅིན་ བདེན་དཔྱད་འབད་མ་ཚུགས་པའི་ ཡི་གུ་ཚུ་ལས་ རྩ་འགེངས་གཏང་།

    - དོགས་པ་ཅན་གྱི་ ཡོངས་འཕྲིན་ཨེམ་ཨེལ་དང་ འབྲེལ་མཐུད་ དེ་ལས་ རང་བཞིན་གྱི་ བརྡ་དོན་ཚུ་གི་དོན་ལུ་ ཞུ་བ་ཚུ་ ངོ་ཤེས་ནི་དང་ བཀག་ཐབས་འབད་ནིའི་དོན་ལུ་ སྤྱིར་བཏང་གི་ phishing ཐབས་རིག་ཚུ་གི་སྐོར་ལས་ ཤེས་ཡོན་ཐོབ་ཚུགས།

    - བརྒྱུད་འཕྲིན་ཨང་གྲངས། (email client) གཞི་བཙུགས་འབད་ཞིནམ་ལས་ ཡོངས་འབྲེལ་ཨང་གྲངསཀྱི་ཁ་བྱང་ཚུ་ ཐོ་བཀོད་དང་བརྟག་དཔྱད་འབད་ཚུགས། མ་གཞི་ བརྒྱུད་འཕྲིན་བཏང་མི་གི་ཁ་བྱང་བཟོ་ནི་དང་ དངུལ་ཁང་ཅིག་སྦེ་བཟོ་བཅུག་ནི་ཡང་ འོང་ནི་ཨིན་རུང་ ལག་རྟགས་རྫུས་མ་བཟོ་ནི་དེ་ འོང་མི་ཚུགས་པས།

3. རང་བཞིན་གྱི་ གནད་དོན་ཚུ་གི་ ཉེན་སྲུང་:

    - མི་ངོ་མ་ཤེས་མི་ཚུ་དང་ འབྲེལ་བ་འཐབ་པའི་སྐབས་ དམིགས་བསལ་དུ་ གློག་འཕྲིན་དང་ ཡོངས་འབྲེལ་ཐོག་ལས་ རོགས་ཀྱི་དོན་ལུ་ གསང་བའི་བརྡ་དོན་ཚུ་ བརྗེ་སོར་འབད་ནི་ལུ་ རིགཔ་བསྒྱིམ་སྡོད་དགོ།

    - ཁྱོད་ཀྱིས་ བརྡ་སླབ་མི་ མི་དང་ ལས་སྡེ་ཚུ་ལུ་ རང་དབང་ཐོག་ལས་ ཞིབ་འཚོལ་འབད་ཞིནམ་ལས་ ཁོང་གི་ངོ་རྟགས་ངོ་མ་དེ་ བདེན་པ་ཡོདཔ་ཨིན་ན་ བརྟག་ཞིབ་འབད་དེ་བལྟ་དགོ།

    - མི་སྡེ་བརྡ་བརྒྱུད་ཚུ་ནང་ ཁྱོད་ཀྱིས་བགོ་བཤའ་རྐྱབ་མི་ ངོ་རྐྱང་གི་ གནད་དོན་ཚུ་གི་སྐོར་ལས་ དྲན་པ་བཏོན་དགོ་ ག་ཅི་སྨོ་ཟེར་བ་ཅིན་ ངན་ལྷད་ཅན་ཚུ་གིས་ གནད་དོན་འདི་ལག་ལེན་འཐབ་ཚུགས།

## ལས་སྡེ་ཚུ་གི་དོན་ལུ་ ཉེན་སྲུང་གི་མཐུན་རྐྱེན་ཚུ་ {#security-principles-for-organisations}

1. ཉེན་སྲུང་གི་ སྲིད་བྱུས་དང་ བྱ་རིམ་ཚུ་ གསལ་ཏོག་ཏོ་སྦེ་བཟོ་ནི།

    - ཉེན་སྲུང་གི་ སྲིད་བྱུས་དང་ བྱ་རིམ་སྒྲིག་གཞི་ཚུ་ བཟོ་སྐྲུན་འབད་ནིའི་དོན་ལུ་ ལཱ་འབད་མི་ག་ར་ལུ་ གསལ་ཏོག་ཏོ་སྦེ་ གསལ་བཀོད་འབད་ཡོདཔ་མ་ཚད་ ཉམས་མྱོང་ཅན་གྱི་ གནས་སྡུད་དང་འབྲེལ་བའི་ གནད་དོན་ཚུ་གི་དོན་ལུ་ ཡང་དག་པ་སྦེ་ བརྩོན་ཤུགས་བསྐྱེད་དོ་ཡོདཔ་ད་ ལས་མི་ཚུ་ཡང་ ལམ་སྟོན་ཚུ་ལུ་ ཐབས་ཤེས་བཏོན་ཏེ་ བརྩོན་འགྲུས་མ་བསྐྱེད་ནི་གི་ ཉེན་ཁ་དེ་ མར་ཕབ་འབད་དགོཔ་ཨིན།

    - ཉེན་སྲུང་གི་ སྲིད་བྱུས་འདི་ ལས་བྱེདཔ་ག་ར་ལུ་ ཕན་ཐོགས་ཚུགསཔ་བཟོ་ནི་དང་ བསྒྱུར་བཅོས་འབད་མི་ ཉེན་སྲུང་གནས་སྟངས་ཚུ་ གསལ་སྟོན་འབད་ནིའི་དོན་ལུ་ འཕྲལ་མགྱོགས་ར་ བསྐྱར་ཞིབ་འབད་ནི་དང་ ད་ལྟོའི་བར་ན་ཡང་ འཕྲལ་མགྱོགས་སྦེ་ བསྐྱར་ཞིབ་འབད་དགོཔ།

    - ཉེན་སྲུང་གི་ སྲིད་བྱུས་ཚུ་ནང་ དཔེ་དང་ གནས་སྟངས་ཚུ་བཙུགས་ཏེ་ ལཱ་འབད་མི་ཚུ་གི་དོན་ལུ་ ཕན་ཐོགས་ཅན་བཟོ་ནི་དང་ ལག་ལེན་འཐབ་ཚུགསཔ་བཟོ་དགོ།

2. ལས་བྱེདཔ་ཚུ་གི་ཤེས་ཡོན་ཡར་དྲག་གཏང་ནི།

    - ལས་བྱེདཔ་ཚུ་ལུ་ གནས་སྡུད་དང་ ལག་ལེན་གྱི་ ཉེན་སྲུང་གི་ ཐབས་ལམ་ཚུ་གི་སྐོར་ལས་ ཤེས་ཡོན་བྱིན་ནི་ འདི་ཡང་ ལས་སྡེ་ཀྱི་ ཉེན་སྲུང་སྒྲིང་སྒྲི་བཟོ་ནིའི་དོན་ལུ་ ཡོངས་གྲགས་ཅན་གྱི་ཤེས་ཡོན་དང་ སྦྱོང་བརྡར་ཚུ་ ལེགས་བསྒྱུར་འབད་ནི་དེ་ གལ་ཆེ་ཟེར་ཨིན་པས།

    - ལས་བྱེདཔ་ཚུ་ལུ་ དོགས་པ་ཅན་གྱི་ལཱ་དང་ ཉེན་སྲུང་གི་གནད་དོན་ཚུ་ དེ་འཕྲོ་ལས་ སྙན་ཞུ་འབད་བཅུག་དགོ།

3. ཕྱིའི་མཐུན་རྐྱེན་ཚུ་གི་ ཉེན་སྲུང་:

    - ཞབས་ཏོག་དང་ གཞི་རྟེན་མཐུན་རྐྱེན་ཚུ་ནང་ གཟུགས་ཀྱི་སྒོ་ལས་འཛུལ་ནི་བཀག་དམ་འབད་ནི། འགྲོ་འགྲུལ་བཀག་དམ་འབད་ཡོད་པའི་ ས་ཁོངས་ཚུ་ནང་ལུ་ ཐོ་བཀོད་འབད་མི་ཆོག་པའི་ བདག་འཛིན་འཐབ་ཐངས་ཚུ་ གཞི་བཙུགས་འབདཝ་ཨིན།

    - ཐབས་ལམ་ཚུ་ བསྐྱར་ཞིབ་འབད་ནི་དང་ ད་ལྟོའི་བར་ན་ཡང་ འཕྲལ་འཕྲལ་ར་ མཐུན་རྐྱེན་ཚུ་གི་དོན་ལུ་ ལག་ལེན་འཐབ་དགོཔ་བཟོ་ནི།

    - གཟུགས་ཀྱི་བདེ་སྲུང་ཡར་དྲག་གཏང་ནིའི་དོན་ལུ་ ཉེན་ཁ་ཅན་གྱི་ ས་ཁོངས་ཚུ་གི་དོན་ལུ་ སྐྱེ་ལྡན་ཚད་འཛིན་གྱི་འཛུལ་སྒོ་ཚུ་ གཞི་བཙུགས་འབད་ནི་ལུ་ བརྩོན་ཤུགས་བསྐྱེད་དགོ།

4. ཉེན་སྲུང་གི་ ལྟ་རྟོག་འདི་ འགོ་འདྲེན་འཐབ་ནི།

    - ལས་སྣ་ཚུ་ཞིབ་དཔྱད་འབད་ཞིནམ་ལས་ ཉེན་སྲུང་དང་ལྡནམ་སྦེ་ འབྱུང་སྲིད་པའི་ གནད་དོན་ཚུ་ ངོས་འཛིན་འབད་ནིའི་དོན་ལུ་ ཉེན་སྲུང་གི་ ལྟ་རྟོག་ལམ་ལུགས་ཆ་མཉམ་ཅིག་ བཏོན་གཏང་དགོ།

    - ཉེན་སྲུང་གི་ལས་བྱེདཔ་ཚུ་ལུ་ ཨ་རྟག་ར་མ་འདྲ་བའི་ ལཱ་འབད་ནི་དང་ ཡང་ཅིན་ ངོས་ལེན་མེད་མི་ཚུ་ དེ་འཕྲོ་ལས་ སྙན་ཞུ་འབད་ནིའི་དོན་ལུ་ རང་བཞིན་གྱི་བརྡ་སྟོན་ཚུ་བཙུགས་དགོ།

    - འཕྲུལ་ཆས་སྦྱོང་བརྡར་གི་ ཨག་རི་ཏུམ་ཚུ་ ལག་ལེན་འཐབ་སྟེ་ ཐབས་ལམ་གྱི་ནུས་ཤུགས་ ཡར་དྲག་གཏང་ནི་དེ་ ཨ་ནོ་མཱལ་དང་ ཉེན་ཁ་འབྱུང་ནིའི་ཐབས་ལུ་ཨིན།

    - གཞི་རྟེན་གནས་སྡུད་ཀྱི་ ཉེན་སྲུང་ལུ་བལྟ་རྟོག་འབད་ནི་དང་ ཞབས་ཏོག་གི་ཞན་འཁེལ་ཚུ་ ངོས་འཛིན་འབད་ནི་དང་ བརྟག་ཞིབ་འབད་ནི་ དེ་ལས་ ངོས་ལེན་ཅན་གྱི་ཐོ་ཡིག་ནང་མ་ཚུད་མི་ ཞབས་ཏོག་ཚུ་ཡོད་མེད་ལུ་བརྟག་དཔྱད་འབད་ནིའི་དོན་ལུ་ ལས་བྱེདཔ་ཚུ་ལུ་ ལཱ་གཡོག་སྤྲོད་ནི་དང་ ཡང་ཅིན་ མི་ངོ་བསྐོ་གཞག་འབད་མི་ལུ་ ལཱ་གཡོག་སྤྲོད་ནི་ཨིན་མས།

5. འཕྲལ་འཕྲལ་ར་ ཉེན་སྲུང་གི་བརྟག་དཔྱད་ཚུ་འབད་:

    - ཉེན་སྲུང་གི་གནས་སྟངས་ཚུ་བརྟག་དཔྱད་འབད་ནི་དང་ གཞི་བཙུགས་འབད་ཡོད་པའི་ ཉེན་སྲུང་གི་ཐབས་ལམ་ཚུ་ སྤྱིར་བཏང་སྦེ་ ངོས་ལེན་ཅན་གྱི་ གནས་ཚད་དང་ སྒྲིག་གཞི་ཚུ་དང་གཅིག་ཁར་ འགྱུར་ཡོདཔ་ ངེས་བདེན་བཟོ་ནི་གི་དོན་ལུ་ ཉིན་བསྟར་གྱི་ ཉེན་སྲུང་རྩིས་ཞིབ་ཚུ་ འབད་དགོཔ།

    - ཁྱོད་ཀྱི་ཚོགས་སྡེའི་ ཉེན་སྲུང་གི་གནས་སྟངས་ལུ་ དམིགས་བསལ་མེད་པར་བརྟག་དཔྱད་འབད་ནིའི་དོན་ལུ་ འཕྲལ་འཕྲལ་ར་ ཉེན་སྲུང་མཁས་མཆོག་ཚུ་ བཙུགས་ཏེ་ བརྟག་ཞིབ་འབད་ནི་ལུ་ དཔྱད་བརྗོད་བཀོད་དགོ།

6. འགྲོ་འགྲུལ་བཀག་འཛིན་ལམ་ལུགས་ལག་ལེན་འཐབ་ནི།

    - འགན་འཁྲི་ལུ་གཞི་བཙུགས་འབད་མི་ འགྲུལ་སྐྱོད་བཀག་འཛིན་ལམ་ལུགས་ཅིག་ གཞི་བཙུགས་འབད་ཡོདཔ་ལས་ ལས་བྱེདཔ་ཚུ་གིས་ ཁོང་རའི་འགན་ཁུར་ཚུ་གི་དོན་ལུ་ དགོས་མཁོ་ཅན་གྱི་ ཐོན་ཁུངས་དང་ བརྡ་དོན་ཚུ་རྐྱངམ་གཅིག་ ཐོབ་ཚུགསཔ་བཟོ་ནི་ཨིན་མས།

7. འཕྲོ་མཐུད་དེ་ ཡར་དྲག་གཏང་ནི་ལུ་ གཙོ་བོ་བསྟེན་:

    - ཉེན་སྲུང་འདི་ ཡུན་བརྟན་གྱི་ བྱ་རིམ་ཅིག་ཨིན་ཟེར་ངོས་འཛིན་འབད་དགོཔ། ཉེན་སྲུང་གི་ཐབས་ལམ་ཚུ་ལུ་ བརྟག་ཞིབ་འབད་ནི་དང་ གདོང་ལེན་ཚུ་ སེལ་ཐབས་ལུ་ དེ་ཚུ་ ཧེང་སྐལ་ར་ ཡར་དྲག་གཏང་དགོ།

    - ལས་བྱེདཔ་ཚུ་ལུ་ ཉེན་སྲུང་ཡར་དྲག་གཏང་ནིའི་ གྲོས་འཆར་ཚུ་ གྲོགས་རམ་འབད་ནིའི་དོན་ལུ་ སེམས་ཤུགས་བསྐྱེད་བཅུག་མི་ རྒྱབ་སྐྱོར་ལམ་ལུགས་ཅིག་ གཞི་བཙུགས་འབད་ནི་ལུ་ བརྩོན་ཤུགས་བསྐྱེད་དོ་ཡོདཔ་ལས་ འཕྲོ་མཐུད་དེ་ར་ ཡར་དྲག་གཏང་ནི་གི་ ལམ་སྲོལ་ཡར་རྒྱས་འགྱོ་ནི་ཨིན་པས།
