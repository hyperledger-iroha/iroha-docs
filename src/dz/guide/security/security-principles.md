# ཉེན་སྲུང་གི་གཞི་རྩ་ཚུ་ {#security-principles}

Iroha བཀག་ཆའི་རྩིས་ཐོ་གིས་ མིང་རྟགས་བཀོད་ཡོད་པའི་བཀོད་རྒྱ་ཚུ་བདེན་དཔྱད་འབད་དེ་ གནང་བ་ཚུ་འཇུག་སྤྱོད་འབདཝ་ཨིན། འདི་གིས་ སྒེར་གྱི་ལྡེ་མིག་དང་ ཧོསིཊི་ གློག་རིམ་ བཀོལ་སྤྱོད་པ་ལཱ་གི་ས་ཁོངས་ ཡང་ན་ གཞུང་སྐྱོང་བྱ་རིམ་ཚུ་ ཉེན་སྲུང་མི་འབད། བཀྲམ་སྤེལ་འདི་གིས་ རིམ་ལུགས་དེ་ཚུ་ ཉེན་སྲུང་འབད་དགོ།

Iroha དྲ་རྒྱ་བཟོ་ནི་དང་ ལག་ལེན་འཐབ་པའི་སྐབས་ འ་ནི་གཞི་རྩ་ཚུ་ལག་ལེན་འཐབ་དགོ།

## དབང་ཚད་འདི་ ཉེན་སྲུང་གི་ས་མཚམས་ཅིག་སྦེ་བརྩི་དགོ། {#treat-authority-as-a-security-boundary}

- སྒེར་གྱི་ལྡེ་མིག་ཅིག་ཚད་འཛིན་འབད་མི་ མི་ངོ་ཡང་ན་བྱ་རིམ་ཅིག་གིས་ ལྡེ་མིག་དེ་ལུ་འགན་སྤྲོད་འབད་ཡོད་པའི་དབང་ཚད་དང་གཅིག་ཁར་ ལཱ་འབད་ཚུགས།
- གནས་སྟངས་དང་ ལས་སྣ་འགན་ཁག་རེ་རེ་ལུ་ དབང་ཚད་ཁྱད་པར་ཅན་ཅིག་བྱིན་ནི།
- ཐོན་སྐྱེད་ལྡེ་མིག་དང་སླར་གསོའི་ལྡེ་མིག་ཚུ་ དུས་རྒྱུན་གོང་འཕེལ་དང་བརྟག་དཔྱད་ཀྱི་ངོ་རྟགས་ཚུ་ལས་སོ་སོ་སྦེ་བཞག།
- དབང་འཛིན་རེ་རེ་གི་བདག་དབང་ག་ལུ་ཡོདཔ་ཨིན་ན་ དེ་གི་མིང་རྟགས་བཀོད་མི་འདི་ ག་ཏེ་ལུ་བཞག་ཡོདཔ་ཨིན་ན་ དེ་ལས་ ག་དེ་སྦེ་ཚབ་བཙུགས་ཚུགསཔ་ཨིན་ན་ ཡང་ན་ ཆ་མེད་བཏང་ཚུགསཔ་ཨིན་ན་ ཐོ་བཀོད་འབད།

[མི་མང་ལྡེ་མིག་གསང་སྡོམ](./public-key-cryptography.md)དང་ [གསང་སྡོམ་ལྡེ་མིག་ཉར་ཚགས](./storing-cryptographic-keys.md) ལུ་བལྟ་ཚུགས།

## ཉུང་ཤོས་ཐོབ་ཐངས་ཚུ་ ལག་ལེན་འཐབ་ {#apply-least-privilege}

- འགན་འཁྲི་ཅིག་ལུ་དགོ་པའི་ Iroha གནང་བ་ཚུ, མགྲོན་སྐྱོང་གློག་འཕྲུལ འཛུལ་སྤྱོད དང་ དྲ་རྒྱ འཛུལ་སྤྱོད རྐྱངམ་གཅིག་སྤྲོད་དགོ།
- གཞུང་སྐྱོང་དང་ བཀྲམ་སྤེལ་ དེ་ལས་ ལོག་ཐོབ་དབང་འཛིན་ལས་ དུས་རྒྱུན་གྱི་ཚོང་འབྲེལ་གྱི་ མཚན་རྟགས་སོ་སོ་སྦེ་ བཀོད་དགོ།
- བདེན་དཔྱད་འབད་མི་འཐུས་མི་དང་ ཐོབ་དབང་ཅན་གྱི་གནང་བ་ ཡང་ན་ གནས་གོང་མཐོ་བའི་རྒྱུ་དངོས་ཚུ་ལུ་ གནོད་པ་བརྐྱབ་ཚུགས་པའི་ བསྒྱུར་བཅོས་ཚུ་གི་དོན་ལུ་ རང་དབང་ཅན་གྱི་ཆ་འཇོག་དགོཔ་ཨིན།
- འགན་ཁུར་བསྒྱུར་བཅོས་འབད་བའི་ཤུལ་ལས་ འཛུལ་སྤྱོད་བསྐྱར་ཞིབ་འབད་ཞིནམ་ལས་ ད་ལས་ཕར་དགོཔ་མེད་པའི་འཛུལ་སྤྱོད་བཏོན་གཏང་།

## སྲུང་སྐྱོབ་ཀྱི་གོ་རིམ་ཚུ་ ལག་ལེན་འཐབ་ {#use-layers-of-protection}

- མིང་རྟགས་བཀོད་མི་དང་ ལག་ལེན་ བཀོལ་སྤྱོད་རིམ་ལུགས་ ཡོངས་འབྲེལ་ དེ་ལས་ དངོས་གཟུགས་འཛུལ་སྤྱོད་ཚུ་ ཉེན་སྲུང་འབད། ཚད་འཛིན་གཅིག་ལུ་བརྟེན་མི་བཏུབ།
- བགོ་བཀྲམ་གྱི་དོན་ལུ་དགོ་པའི་ Torii, མཉམ་རོགས, བལྟ་རྟོག དང་ གློག་རིམ རྒྱུན་ལམ་ཚུ ཚུ་རྐྱངམ་གཅིག་ཕྱིར་སྟོན་འབད་དགོ།
- བདག་སྐྱོང་འཛུལ་སྤྱོད་དང་ ཚོར་ཤུགས་ཅན་གྱི་གནས་སྡུད་ཀྱི་དོན་ལུ་ བདེན་བཤད་དང་གསང་བཟོ་འབད་ཡོད་པའི་རྒྱུ་ལམ་ཚུ་ལག་ལེན་འཐབ།
- རིམ་ལུགས་ཚུ་ ཐིག་ཁྲམ་བཟོ་སྟེ་བཞག་སྟེ་ བཀྲམ་སྤེལ་གྱིས་ལག་ལེན་མ་འཐབ་པའི་ཞབས་ཏོག་ཚུ་ ལྕོགས་མིན་བཟོ།
- འབྱུང་ཁུངས་ཚད་འཛིན་དང་བརྡ་བཀོད་གྲལ་ཐིག་ དྲན་ཐོ་ ཤོག་བྱང་ ཁ་སླབ་ དེ་ལས་ མི་མང་ཡིག་ཆ་ཚུ་ལས་ གསང་བ་བཞག།

## ལག་ལེན་ཚུ་ བསྐྱར་ཞིབ་འབད་ཚུགསཔ་བཟོ། {#make-deployments-reviewable}

- གསང་བ་མེན་པའི་རིམ་སྒྲིག་དང་ བཀྲམ་སྤེལ་རང་བཞིན་གྱིས་ ཐོན་རིམ་ཚད་འཛིན་ནང་བཞག།
- གཉིས་ལྡན་དང་རིམ་སྒྲིག་ རིགས་མཚན་རྒྱུ་ཆ་ བདེན་དཔྱད་འབད་མི་འཐུས་མི་ གནང་བ་ དེ་ལས་ མི་མང་ལམ་ལུགས་ཚུ་ལུ་ བསྒྱུར་བཅོས་ཚུ་བསྐྱར་ཞིབ་འབད།
- བཀྲམ་སྤེལ་མ་འབད་བའི་ཧེ་མ་ བཏོན་གཏང་བའི་ བརྡ་མཚོན་ཚུ་ བདེན་དཔྱད་འབད། ཆ་འཇོག་འབད་ཡོད་པའི་ཐོན་རིམ་ཚུ་དང་ ཧ་ཤི་ཚུ་ཐོ་བཀོད་འབད།
- ཐོན་སྐྱེད་ནང་ལུ་གཡོག་བཀོལ་ནི་ཨིན་མི་ གཉིས་ལྡན་དང་རིམ་སྒྲིག་མཉམ་བསྡོམས་གཏན་གཏན་འདི་བརྟག་དཔྱད་འབད།
- ཡོངས་འབྲེལ་གྱི་ གཏན་འབེབས་སྤྱོད་ལམ་འདི་ ཉམས་སྲུང་འབད། མཐུན་རྐྱེན་མགྱོགས་ཚད་འདི་གིས་ མཉམ་རོགས་མཐོང་ཚུགས་པའི་གྲུབ་འབྲས་ཚུ་བསྒྱུར་བཅོས་འབད་མི་བཏུབ།

## བལྟ་རྟོག་འབད་ནི་དང་ བདེན་དཔང་ཉར་ཚགས་འབད་དགོ། {#monitor-and-preserve-evidence}

- མཉམ་རོགས་ཀྱི་གསོ་བ་དང་ མོས་མཐུན་གྱི་ཡར་རྒྱས་ གནང་བ་བསྒྱུར་བཅོས་ ཐོབ་དབང་བཀོད་རྒྱ་ བདེན་བཤད་འཐུས་ཤོར་ དེ་ལས་ རེ་བ་མེད་པའི་རིམ་སྒྲིག་བསྒྱུར་བཅོས་ཚུ་ ལྟ་རྟོག་འབད།
- གནོད་སྐྱོན་བྱུང་ཡོད་པའི་ཧོསིཊི་ལུ་བརྟེན་མ་དགོ་པའི་རིམ་ལུགས་ལུ་ཁག་ཆེ་བའི་དྲན་སྐུལ་ཚུ་གཏང་།
- འབྲེལ་ཡོད་དྲན་ཐོ་དང་ ལེ་ཇར་གཞི་བསྟུན་ རིམ་སྒྲིག་པར་རིས་ དེ་ལས་ བློ་གཏད་ཅན་གྱི་དུས་ཚོད་མཚོན་རྟགས་ཚུ་དང་གཅིག་ཁར་ ཚོང་འབྲེལ་གྱི་ཧ་ཤི་ཚུ་ ཉམས་སྲུང་འབད།
- ལྟ་རྟོག་གནས་སྡུད་མེད་མི་འདི་ ཞིབ་དཔྱད་འབད་དགོ་པའི་ ལག་ལེན་གྱི་དཀའ་ངལ་ཅིག་སྦེ་ བརྩི་དགོ།

## འགོ་མ་བཙུགས་པའི་ཧེ་མར་ བསྐྱར་གསོ་གི་གྲ་སྒྲིག་འབད་ {#prepare-recovery-before-launch}

- བྱུང་རྐྱེན་ཅིག་ ག་གིས་གསལ་བསྒྲགས་འབད་ཚུགས་ག་དང་ ལོག་ཐོབ་ནིའི་བྱ་བ་ཚུ་ ག་གིས་ཆ་འཇོག་འབད་ཚུགས་ག་ ངེས་འཛིན་འབད།
- རྒྱབ་ཐག་བརྟག་དཔྱད་དང་ སླར་གསོ་ ལྡེ་མིག་ཚབ་བཙུགས་ གནང་བ་ཆ་མེད་གཏང་ནི་ དེ་ལས་ མཉམ་རོགས་སླར་གསོའི་བྱ་རིམ་ཚུ་ བརྟག་དཔྱད་འབད།
- བློ་གཏད་ཅན་གྱི་གསར་བཏོན་ཅ་ཆས་དང་ རིམ་སྒྲིག་ རིགས་མཚན་ཐོ་བཀོད་ དེ་ལས་ བྱུང་རྐྱེན་ཅིག་གི་སྐབས་ལུ་ ཐོབ་ཚུགས་པའི་ ཐོ་བཀོད་ཚུ་བཞག།
- ལྷག་ནི་དང་ལྟ་རྟོག་འབད་ནི་དང་པ་སླར་གསོ་འབད། སླར་གསོ་འབད་ཡོད་པའི་ཡོངས་འབྲེལ་དང་ བརྟེན་པའི་གློག་རིམ་ཚུ་གིས་ ཁོང་རའི་ཞིབ་དཔྱད་ཚུ་ བཏང་ཚར་བའི་ཤུལ་ལས་རྐྱངམ་ཅིག་ བསྐྱར་ལོག་འབྲིཝ་ཨིན།
- བྱུང་རྐྱེན་ག་ར་བསྐྱར་ཞིབ་འབད་དེ་ ཚད་འཛིན་དང་ རང་བཞིན་ དེ་ལས་ སྦྱོང་བརྡར་ཚུ་དུས་མཐུན་བཟོ།

::: warning

རྩིས་དེབ ལས་སྣ་ཚུ་ ལོག་བསྒྱུར་མ་ཚུགསཔ་འོང་། སླར་གསོ ཡང་ན་ གཞུང་སྐྱོང་ ཚོང་འབྲེལ མ་བཙུགས་པའི་ཧེ་མར་ སྔོན་ལས་བསྐྱར་ཞིབ་འབད་མི་བྱ་རིམ་ཚུ་ལག་ལེན་འཐབ་ཞིནམ་ལས་ དགོ་པའི་ངོས་ལེན་ཚུ་ལེན་དགོ།

:::
