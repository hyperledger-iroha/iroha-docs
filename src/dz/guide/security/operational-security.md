# ལས་འགུལ་གྱི་ ཉེན་སྲུང་ {#operational-security}

ལས་འཛིན་གྱི་བདེ་སྲུང་ (OPSEC) འདི་ ཉེན་སྲུང་དང་ ཉེན་སྲུང་གི་ འཛིན་སྐྱོང་ལུ་ ཐབས་བྱུས་ཅན་གྱི་ཐབས་ལམ་ཅིག་ཨིནམ་ད་ དེ་ཡང་ དམིགས་བསལ་གྱི་ལག་ལེན་གྱི་གནས་སྟངས་ཚུ་གི་དོན་ལུ་ ལག་ལེན་འཐབ་མི་ འཆར་གཞི་དང་ གྲོས་འདེབས་ཚུ་ བསྡུ་སྒྲིག་འབད་ཡོདཔ་ལས་ ངོས་ལེན་མ་འབད་མི་ ཐོབ་ཐངས་དང་ གནད་དོན་ཚུ་ ལེན་ནི་ལས་ བཀག་ཐབས་འབད་ནིའི་དོན་ལུ་ཨིན་པས།

<abbr title="Operational Security">OPSEC</abbr>འདི་ ལས་སྡེ་མང་ཤོས་ཅིག་གིས་ ཁོང་རའི་ རྒྱུ་དངོས་ཚུ་གི་གནས་ཚད་དང་སྒྲིང་སྒྲི་ལུ་ ཉེན་སྐྱོབ་འབད་ནིའི་དོན་ལུ་ སྤྱིར་བཏང་གི་ལག་ལེན་ཨིན། འདི་ནང་ གཟུགས་ཁམས་ཀྱི་བདེ་སྲུང་ (དཔེར་ན་ བལྟ་རྟོག་མ་མྱོང་མི་ post-it note ཚུ་ནང་ལུ་ གནད་དོན་ཁག་ཆེ་ཤོས་ཚུ་མེདཔ་སྦེ་བཟོ་བཞག་ནི་) དེ་བཟུམ་གྱི་གནད་དོན་ཚུ་ལུ་ སེམས་ཁར་བཞག་དགོ། ཉེན་སྲུང་ཅན་གྱི་ བརྡ་དོན་མཐུན་ལམ་ལུགས་ (དཔེར་ན་ ཚོར་བ་ཅན་གྱི་ གནད་སྡུད་ཚུ་ SMS གི་ཐོག་ལས་ བཏང་མ་ཚུགས།) གནོད་ཉེན་གྱི་དཔྱད་པ། (དཔེར་ན། ཕན་ནུས་ཅན་གནོད་འཚེ་ཅན་གྱི་སྡེ་ཚན་ཚུ་ལུ་ ངོས་འཛིན་འབད་བ། དགྲ་བྱང་ཕྱད་ཀྱི་ ཐབས་བྱུས་གསརཔ་ཚུ་གི་སྐོར་ལས་ཤེས་རིག།) ལས་མི་གི་སྦྱོང་བརྡར་ (དཔེར་ན་ཡང་ ལཱ་འབད་མི་གིས་ <abbr title="Operational Security">OPSEC</abbr> ལས་རིམ་ཚུ་ལག་ལེན་མ་འབད་བར་བཞག་དགོ། དེ་ཚུ་ མགྱོགས་པ་ར་མ་ལངམ་ཅིག་ དཀའཝ་སྤྱད་ནི་མེདཔ་སྦེ་སྟོན་འོང་།) དེ་ལས་ ཉེན་ཁ་མར་ཕབ་འབད་ (དཔེར་ན་ ཁྱོད་ཀྱི་ཧར་ཌི་ཌིསི་དང་ USB ཌའི་ཝེསི་ཚུ་ ཨེབ་གཏང་འབད་ནི་)

Iroha གིས་ དངུལ་འབྲེལ་རྩིས་དེབ་ཅིག་སྦེ་ ལག་ལེན་འཐབ་ནི་ཨིནམ་ལས་, <abbr title="Operational Security">OPSEC</abbr>གི་ཐབས་ལམ་དང་ལག་ལེན་ཚུ་ ཚ་གྱང་ལང་དགོཔ་ཨིན། འ་ནི་གནད་དོན་འདི་ མི་སེར་དང་ ལས་སྡེ་ཚུ་གིས་ ཁོང་རའི་ལཱ་ནང་ལུ་ Iroha ལག་ལེན་འཐབ་པའི་ ཐབས་བྱུས་དང་ཐབས་ལམ་ཚུ་ ཧ་གོ་དགོཔ་ཨིན་. ཉེན་སྲུང་གི་ ཐབས་ལམ་རྒྱ་ཆེ་དྲགས་ཡོདཔ་ཨིན།

གནད་དོན་འདི་ནང་ གྲོས་སྟོན་ཚུ་དང་བསྟུན་ཏེ་ ལག་ལེན་འཐབ་ནི་དེ་ ཉེན་སྲུང་གི་གནས་སྟངས་ལུ་ འོང་ཐབས་ལུ་ དགོས་མཁོ་ཅན་ཅིག་ཨིན་ ཨིན་རུང་ འདི་རྐྱངམ་གཅིག་གིས་མ་ལངམ་ཨིན་པས། ཁྱོད་ཀྱི་ ཉེན་སྲུང་ཡར་དྲག་གཏང་ནིའི་དོན་ལུ་ [Security](./index.md) གྱི་ཆ་ཤས་གཞན་ཚུ་ནང་ལུ་ ལྷབ་གསལ་སྦེ་ཤེས་དགོ་ དེ་ལས་ དམིགས་བསལ་དུ་ འ་ནི་གནད་དོན་ཚུ་:

## གྲོས་འཆར་ཅན་གྱི་ལས་སྣ་ཚུ་ OPSEC {#recommended-opsec-measures}

- དྲན་པ་བཏོན་ཏེ་སྡོད་དགོ། [མང་ཤོས་ཅིག་ར་](https://arxiv.org/pdf/2209.08356.pdf) ཐབས་ལམ་ཅིག་ལུ་ མི་གཅིག་གིས་ blockchainནང་ལུ་ རང་སོའི་རྒྱུ་དངོས་ཚུ་མེདཔ་གཏང་ནི་དེ་ ཁོང་གི་ཚོར་བ་ཅན་གྱི་ གནད་དོན་ཚུ་བྱིན་ཐོག་ལས་ཨིན།

- ཁྱོད་ཀྱི་ཌི་སི་ཀིཔ་ཚུ་ ཨེབ་གཏང་འབད། བཀྲམ་སྤེལ་འབད་ནིའི་ཅ་ཆས་ཚུ་གི་ ཨེབ་གཏང་ཐངས་འདི་གིས་ ཁྱོད་ཀྱི་གནས་སྡུད་ཚུ་ ཉེན་སྐྱོབ་འབད་ཚུགསཔ་བཟོཝ་ཨིན། དོགས་ཅན་ཅིག་གིས་ ཧར་ཌའཱེར་ལུ་ ཐོབ་ལམ་ཐོབ་རུང་། འདི་ཁྱོད་ཀྱི་ཕོར་ཊི་བིའི་ཅ་ཆས་ཀྱི་དོན་ལུ་འབད་ནི་འདི་ ཁག་ཆེ་དྲགས་སྦེ་ཡོདཔ་ཨིན།

- བློ་གཏད་ཚུགས་པའི་ གློག་རིག་ལག་ལེན་འཐབ་ ཌའི་ལོག་བཟོ་སྐྲུན་གྱི་ཐོག་ལས་ བཀྲམ་སྤེལ་འབད་ཚུགས་མི་ གློག་རིག་འདི་ གཞི་རྟེན་ལས་ བཟོ་སྐྲུན་འབད་མི་ དེ་ལས་ ཡིད་ཆེས་ཤོས་ཅིག་ཨིན། རང་དབང་ཅན་གྱི་ ཡང་ན་ སྒོ་ཕྱེ་ཐོན་ཁུངས་ཀྱི་ གློག་རིག་དེ་ དབྱེ་ཞིབ་མ་འབད་བར་ཡོད་མི་དེ་ ཉེན་ཁ་ཅན་ཅིག་ཨིན་ འདི་ལུ་ ཚ་གྱང་སྦོམ་སྦེ་ར་ལེན་དགོཔ་ཨིན།

- གནད་དོན་ཁག་ཆེ་ཤོས་ཡོད་མི་ཚུ་ སེལ་འཐུ་འབད་བཏུབ་པའི་ འཕྲུལ་ཆས་ཚུ་ བལྟ་མ་བཞག་པར་བཞག་ནི་མི་འོང་། དུས་ཡུན་དུམ་གྲ་ཅིག་གིས་ འཕྲུལ་ཆས་དེ་ ཨར་རྐུན་འབད་ནི་ལུ་ ཕན་ཐོགས་ཡོདཔ་ཨིན།

- ཌའི་ལོག་པེ་ཀེསི་གུ་ ཐོ་བཀོད་ཚུ་ བརྟག་ཞིབ་འབད་ཐབས། འདི་གིས་ Iroha ནང་ལག་ལེན་འཐབ་མི་ སྒེར་གྱི་ལྡེ་མིག་གི་ ཨེབ་གཏང་ལས་ ཁྱད་པར་ག་ནི་ཡང་མེད།

- ལག་ཆས་ཚུ་ ཉེན་སྲུང་དང་ལྡནམ་སྦེ་ བཞག་པ་ཅིན་ ཨ་རྟག་རང་ ཌི་སི་ཊོཔ་ ཡང་ན་ གློག་རིག་དེ་ ཉེན་སྲུང་ཅན་སྦེ་བཞག་དགོཔ་ཨིན། ཟུར་ཡིག་བརྟན་ཏོག་ཏོ་ལག་ལེན་འཐབ་སྟེ་ ཨེགསརན་བཀག་སྡོམ་འབད་ཞིནམ་ལས་ ལག་ཆས་ཚུ་གི་ ཉེན་སྲུང་གི་དོན་ལུ་ ལག་ལེན་ལེགས་ཤོམ་ལག་ལེན་འབད་དགོ།

- ཁྱོད་རའི་ལྡེ་མིག་ཚུ་གི་དོན་ལུ་ ཉེན་སྲུང་ཅན་གྱི་ [རླུང་གི་ལྡེ་མིག་ ](https://en.wikipedia.org/wiki/Air_gap_(networking) གཞི་བཙུགས་འབད་ དང་པ་ལྡེ་མིག་ཚུ་ ཨེབ་གཏང་ཞིནམ་ལས་ ལག་ལེན་འཐབ་མ་བཏུབ་པའི་ཅ་ཆས་ཅིག་ནང་བཞག་པ་ཅིན་ མཐུན་རྐྱེན་ལེགས་ཤོམ་སྦེ་ར་ གློག་མེ་འགོག་རྫས་བཀབ་སྟེ་བཞག་ཡོདཔ་ཨིན། [ཧར་ཌའེར་ལྡེ་མིག་](./storing-cryptographic-keys.md#using-a-hardware-key) འདི་གི་དོན་ལུ་ དམིགས་བསལ་དུ་བཟོ་ཡོདཔ་ཨིན།
