# ལས་འགུལ་གྱི་ ཉེན་སྲུང་ {#operational-security}

ལས་འགུལ་གྱི་ ཉེན་སྲུང་གིས་ Iroha གཞི་བཙུགས་ཀྱི་མཐའ་འཁོར་ལུ་ཡོད་མི་ མི་སེར་དང་ མགྲོན་སྡེ་ དེ་ལས་ ངོས་འཛིན་ཡིག་ཆ་ དེ་ལས་ བྱ་རིམ་ཚུ་ སྲུང་སྐྱོབ་འབད་དོ་ཡོདཔ་ཨིན། ལེ་ཇར་ནང་ ཡིག་ཆའི་གནས་སྟངས་འདི་ བསྒྱུར་བཅོས་འབད་ཡོདཔ་ལས་ ལག་ལེན་པ་ཚུ་གིས་ རང་རང་སོ་སོ་སྦེ་ རང་སོའི་ལཱ་ལྟེ་བ་དང་ ཐོ་བཀོད་ལྡེ་མིག་ཚུ་ དེ་ལས་ གནད་དོན་ཚུ་གི་ལན་འཇལ་ནིའི་ བྱ་རིམ་ཚུ་ ཉེན་སྲུང་འབད་དགོཔ་ཨིན་པས།

འོག་གི་ལག་ལེན་ཚུ་ ལག་ལེན་འཐབ་ནི་དེ་ གཞི་རྟེན་གནས་ཚད་ཅིག་སྦེ་ ལག་ལེན་འཐབ་ཨིན། དེ་ཚུ་ ཉེན་ཁ་ཅན་གྱི་གོང་ཚད་དང་ ལས་སྡེ་ཀྱི་ དགོས་མཁོ་དང་འཁྲིལ་ཏེ་ བསྒྱུར་བཅོས་འབད་དགོ།

## ལས་འགུལ་གྱི་གཞི་རྟེན་ གཞི་བཙུགས་འབད་ {#establish-an-operational-baseline}

- ངོས་འཛིན་འབད་མི་ hosts, peer identities, account authorities, signing devices, public endpoints, and responsible people གི་ཐོ་ཡིག་ཅིག་བཟོ་དགོ།
- གོང་འཕེལ་གཏང་ནི་དང་ བརྟག་དཔྱད་འབད་ནི་དང་ བཟོ་སྐྲུན་འབད་ནིའི་དོན་ལུ་ རང་སོ་སོར་གྱི་ ངོས་འཛིན་ལག་ལེན་ཚུ་ ལག་ལེན་འཐབ་དགོ། ཐོ་བཀོད་རྐྱབ་མི་རེ་རེ་དང་ ལག་ཁྱེར་འཆང་མི་ དེ་ལས་ སྒེར་གྱི་ལྡེ་མིག་ཚུ་ གནས་སྟངས་གཅིག་ལུ་ བྱིན་དགོ།
- བསྐྱར་ཞིབ་འབད་ཚུགས་པའི་ ཝིན་ཌིང་གི་སྒྲིག་གཞི་དང་ ལག་ལེན་འཐབ་ནིའི་ འཕྲུལ་ཆས་ཚུ་ སེལ་འཐུ་འབད། ངོས་ལེན་ཅན་གྱི་ གསང་བའི་ཚོང་ཁང་ ཡང་ན་ རྟགས་མཚན་རྟགས་བཀོད་འཕྲུལ་ཆས་ནང་ལས་ གསང་བ་ཚུ་ དུས་རྒྱུན་གྱི་བསྒང་ལས་བཙུགས་ཚུགས།
- ཐོ་བཀོད་འབད་དགོ་པའི་ ཧ་ཤེསི་དང་ ལག་ལེན་གྱི་མིང་ཐོ་བཀོད་ཚུ་ བཏོན་གཏང་ནི་དེ་ འགོ་འདྲེན་འཐབ་མ་ཚར་བའི་ཧེ་མར་ དབྱེ་བ་དཔྱད་འབད། སྦྲེལ་མཐུནམ་དང་ གཞི་རྟེན་འབྱུང་ཁུངས། སྒྲིག་སྒྲིག ་ ཡང་ན་ ཞབས་ཏོག་གི་འགྲེལ་བཤད་ཚུ་ བསྒྱུར་བཅོས་འབད་ཚུགས་མི་ཚད་འཛིན་འབད།
- ལས་འཛིན་གྱི་རྩིས་ཁྲ་ཚུ་དང་ Iroha ངོས་ལེན་དང་ གྲོག་ཐིག་བདག་སྐྱོང་ལུ་ ཁྱད་ཆོས་ཉུང་ཤོས་ཅིག་ལག་ལེན་འཐབ་དགོ། འགན་འཁྲི་རེ་ལུ་ དབང་ཚད་འདི་རྐྱངམ་གཅིག་བྱིན་ནི་ འདི་ཚུ་གི་ལཱ་དེ་ དགོཔ་ཨིན།
- production འགོ་བཙུགས་པའི་ཧེ་མ་ backup, restore, key replacement དང་ peer recovery བྱ་རིམ་ཚུ་ བརྟག་དཔྱད་འབད།

བསྐྱར་ཞིབ་འབད་ [བདེ་སྲུང་གི་གཞི་རྩ་](./security-principles.md)དང་ [སེལ་འཐུ་འབད་ནིའི་ གྲ་སྒྲིག་ነት](../best-practices/release-readiness.md) གཞི་རྟེན་གནས་ཚད་ཚུ་ གསལ་སྟོན་འབད་བའི་སྐབས་

## ལྡེ་མིག་དང་ ལག་རྟགས་ཚུ་ སྲུང་སྐྱོབ་འབད་ {#protect-keys-and-signers}

- སྒེར་གྱི་ལྡེ་མིག་ཚུ་ འཛུགས་སྐྱོང་འབད་མ་དགོ་པར་ བཞག་དགོ སྣུམ་འཁོར་གྱི་ཐོན་སྐྱེད་དང་ ལག་ལེན་པ་གི་རྟགས་མཚན་ དེ་ལས་ ངོས་འཛིན་གྱི་ཨེབ་རྟ་ དེ་ལས་ གསང་བའི་ཡིག་ཆ་ཚུ་ གཞི་རྟེན་འཛིན་སྐྱོང་ལས་ ཕྱི་ཁར་བཞག་དགོ སྣ་ཆས་ལག་ལེན་འཐབ་མི་ མཐུད་སྦྲེལ་ཐོ་བཀོད་འཕྲུལ་ཆས་ རྒྱུགས་གཏད་ཐོ་བཀོད་ཀྱི་ ཡིག་ཆ་དང་ འགྲུལ་འཕྲིན་བརྙན་དང་ མི་མང་གི་ཡིག་ཆ་ཚུ་
- གནས་གོང་ཆེ་བའི་དབང་འཛིན་ཚུ་གི་དོན་ལུ་ ལག་ཆས་ཀྱི་རྒྱབ་སྐྱོར་ ཡང་ན་ ངོ་རྐྱང་གི་རྟགས་བཀོད་ལག་ལེན་འཐབ་། བལྟ་བཤལཔ་ཚུ་དང་ སྤྱིར་བཏང་དོན་གྱི་ལག་ལེན་གྱི་ བྱ་རིམ་ཚུ་ནང་ལས་ ནང་འདྲེན་འབད་མ་བཏུབ་པའི་ རྒྱགས་གཏེར་ key དུམ་གྲ་ཅིག་ སྲུང་བཞག་པ་ཅིན་ མཁན་པོ་གིས་རྟགས་བཀོད་དེ་ བཅའ་མར་གཏོགས་ཚུགས།
- རྒྱུན་ལམ་གྱི་ཚོང་འབྲེལ་དང་ གཞུང་སྐྱོང་ དེ་ལས་ བགོ་བཀྲམ་འབད་ནི་དང་ ལོག་སྤྱོད་འབད་ནིའི་དོན་ལུ་ ཁྱད་པར་ཅན་གྱི་དབང་འཛིན་ཚུ་ལག་ལེན་འཐབ་དགོ།
- གསང་བའི་གནས་སྡུད་དང་ འདི་གི་རྒྱབ་སྐྱོར་ཚུ་ ཨེབ་ལྡིཌ་རྐྱབས། སྒེར་གྱི་ལྡེ་མིག་གི་ རྒྱབ་སྐྱོར་ལུ་ རང་སོའི་ལྡེ་མིག་དེ་བཟུམ་སྦེ་ འཛུལ་སྒོ་ལག་ལེན་འཐབ་དགོ།
- བརྟག་དཔྱད་འབད་ཡོད་པའི་ བསྒྱུར་བཅོས་འབད་ནི་དང་ ཆ་མེད་གཏང་ནི་གི་ བྱ་རིམ་ཚུ་ བཞག་ནི་ སྲིད་བྱུས་ནང་ དགོས་མཁོ་ཡོདཔ་ད་ ཡང་ན་ ཉེན་ཁ་ཡོད་མི་ལུ་ དོགས་པ་ཆགས་པའི་སྐབས་ལྡེ་མིག་འདི་ བསྒྱུར་བཅོས་འབད་ནི།
- དམ་ཚིག་བསྟེན་མི་གི་འཐུས་ཐོབ་ཐངས་ལུ་ བསྒྱུར་བཅོས་འབད་ནི་གི་དོན་ལས་ རང་དབང་ཅན་གྱི་ཞིབ་དཔྱད་འབད་དགོཔ་ཨིན། ཁྱད་དུ་འཕགས་པའི་འགན་ཁུར་ཚུ་ ཡང་ན་ གནས་གོང་ཆེ་བའི་རྒྱུ་དངོས་ཚུ་ཨིན།

## Harden Nodes དང་ Operator Access {#harden-nodes-and-operator-access}

- ད་ལྟོའི་བཙོང་མི་གིས་ རྒྱབ་སྐྱོར་འབད་མི་ ལེགས་བཅོས་འབད་ཡོད་པའི་ལམ་ལུགས་ཚུ་ནང་ལུ་ མཚམས་འཇོག་དང་ ལག་ལེན་འཕྲུལ་ཆས་ལག་ལེན་འཐབ་ཐབས། དགོས་མཁོ་མེད་པའི་ ཞབས་ཏོག་ཚུ་ རྩ་མེད་གཏང་།
- མིང་བཏགས་མི་ ལས་འཛིན་ཚུ་ལུ་ ཐོ་བཀོད་འབད་ཡོད་པའི་ ཐབས་ལམ་བརྒྱུད་དེ་རྐྱངམ་གཅིག་ འཛིན་སྐྱོང་འཐབ་ནིའི་ གོ་སྐབས་བྱིན་ནི།
- སྒེར་སྡེའི་བརྡ་བརྒྱུད་ཚུ་ སྒེར་གྱི་ཁ་ཐུག་ལུ་བཙུགས་ནི་ ཡང་ན་ [VPN](./vpn.md).
- Torii བརྟག་ཞིབ་དང་ལག་ལེན་གྱི་ལམ་ལུགས་ཚུ་རྐྱངམ་གཅིག་བཏོན་ནི་དེ་ ལག་ལེན་འཐབ་ཐོག་ལས་ དགོཔ་ཨིན།
