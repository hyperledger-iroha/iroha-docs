# མགུ་སྐོར་རྒྱབ་སྐྱོར་འབད་ནི་ {#fraud-monitoring}

Iroha ཕྱིར་སྤེལ་གྱི་དོན་ལུ་ མགུ་སྐོར་རྒྱབ་རྟོག་འབད་ནི་འདི་ ལག་ལེན་ཅན་གྱི་འཛིན་སྐྱོང་ཅིག་ཨིན་ འདི་གིས་ ལེ་ཌཇར་གི་བྱུང་རྐྱེན་ཚུ་དང་ དྲི་བཀོད་དང་ ངོས་ལེན་ དེ་ལས་ལག་ལེན་གྱི་གནས་སྟངས་ལུ་བརྟེན་ཨིན། Iroha གིས་ ཕུལ་ཡོདཔ་དང་ ཆ་འཇོག་འབད་ཡོདཔ་དང་ ཆ་མ་བཞག་མི་དང་ བརྩོན་ཤུགས་བསྐྱེད་མི་ཚུ་ ཐོ་བཀོད་འབདཝ་ཨིན། ཁྱོད་ཀྱི་ ལྟ་རྟོག་ལམ་ལུགས་འདི་གིས་ ཁྱོད་ཀྱི་ཚོང་འབྲེལ་གྱི་ བྱ་རིམ་ནང་ལུ་ དོགས་པ་ཅན་གི་རྣམ་གཞག་ཚུ་ ག་ཅི་ཨིན་ན་ གྲོས་ཐག་བཅད་དེ་ དེ་བཟུམ་གྱི་གནད་དོན་ཚུ་ བསྐྱར་ཞིབ་འབད་མི་དང་ ཡང་ན་ སྣུམ་འཁོར་གྱི་ལན་འཇལ་ནིའི་ལག་ལེན་ཚུ་ལུ་ བཏང་འོང་།

མགུ་སྐོར་རྒྱབ་རྟོག་འདི་ དམ་ཚིག་ཅན་ཅིག་ནང་ བཙུགས་ཡོད་པའི་ཁུངས་ཀྱི་ཚབ་ལུ་ ཞབས་ཏོག་སོ་སོ་སྦེ་འབད་དགོཔ་ཨིན། ཞབས་ཏོག་དེ་གིས་ ལྡེ་མིག་གི་ལཱ་འབད་ནི་ལུ་ ཐོ་བཀོད་འབད་དགོཔ། ལྕགས་ཐག་ལས་ཕྱི་ཁར་ ཉེན་ཁ་ཅན་གྱི་ གནས་སྟངས་དང་གཅིག་ཁར་ ཡར་རྒྱས་གཏང་དགོཔ། དཔྱད་ཡིག་ཚུ་ བརྟག་ཞིབ་འབད་དགོཔ། དང་ ལན་སླ་སྤྲོད་ལེན་ཚུ་ རྐྱངམ་གཅིག་རྐྱངམ་གཅིག་གིས་ ངོས་ལེན་གསལ་ཏོག་ཏོ་ཡོད་མི་རྩིས་ཁྲིས་བརྒྱུད་དེ་ གྲུབ་འབྲས་བཀོད་དགོ།

## ལྟ་རྟོག་གི་རྣམ་གཞག་ {#monitoring-model}

ལྟ་རྟོག་ལམ་ལུགས་ཕན་ཐོགས་ཅན་འདི་ ཚབས་ཆེན་༤ ཡོདཔ་ཨིན།

1. Torii འབྱུང་རྐྱེན་འབྱུང་ཁུངས། འདྲི་དཔྱད་དང་རྩིས་ཐོ་བཀོད་ལས་ ཐོ་བཀོད་དང་ ལག་ལེན་པ་བརྡ་སྟོན་ཚུ་ བསྡུ་བསྒྱོམ་འབད་།
2. འབྱུང་རྐྱེན་ཚུ་ ལྕགས་ཐག་ལས་ཕྱི་ཁར་ གནས་སྟངས་བཟུམ་ཅིག་སྦེ་ བཟོ་མི་གི་གནས་གོང་, མཉམ་འབྲེལ་ཚོགས་པ་ཚུ་གི་ཐོ་ཡིག་, ཞུ་གཏུགས་ཀྱི་དུས་ཚོད་ལུ་ ངོས་འཛིན་འབད་མི་ཚུ་, མཇུག་བསྡོམས་པའི་ཚད་གཞི་དང་ གནད་དོན་ IDs ཚུ་དང་གཅིག་ཁར་ ཡར་རྒྱས་གཏང་དགོ།
3. དོགས་པ་ཅན་གི་སྤྱོད་ཚུལ་ཚུ་ ངོས་འཛིན་གྱི་ཁྲིམས་ལུགས་དང་ བསྐྱར་ཞིབ་འབད་མི་ཚུ་གི་གྲལ་ཁར་ ཡང་ན་ ཉེན་ཁ་ཅན་གྱི་རྩིས་ཐོ་བཀོད་ཐོག་ལས་ བདའ་ཟུན་ཚུགས།
4. ལས་འཛིན་པ་ཚུ་ལུ་ དྲན་བསྐུལ་སྤྲོད་ནི་དང་ ལག་ལེན་གྱི་ལཱ་ལམ་རིམ་ཚུ་ བཀག་ཆ་འབད་ནི་དང་ དགོས་མཁོ་མེད་པའི་ ངོས་ལེན་ཚུ་ ཆ་མེད་གཏང་ནི་ དེ་ལས་ ཡང་ན་ ཁྱོད་རའི་གཞུང་སྐྱོང་གི་ བྱ་རིམ་གྱིས་ དེ་གི་དོན་ལུ་ གོ་སྐབས་བྱིན་པའི་སྐབས་ལུ་ བསྐྱིན་ཚབ་ཀྱི་ཚོང་འབྲེལ་ཚུ་བཙུགས་ཏེ་ ལན་སླབ་ཚུགས།

སྲིད་བྱུས་ཀྱི་ གྲོས་ཐག་ཚུ་ ངོས་ལེན་གྱི་ཕྱི་ཁར་བཞག་དགོ་ འདི་མ་གཏོགས་ ཆ་འཇོག་གྲུབ་མི་ཆ་མཉམ་གྱིས་ གྲོས་ཐག་དེ་ ལོག་སྤྱོད་འབད་དགོཔ་ཨིན། དུས་རྒྱུན་ལག་ལེན་འཐབ་པའི་སྐབས་ ཆ་འཇོག་འབད་ནི་གིས་ ངོས་ལེན་དང་ བྱ་སྟབས་མ་བདེཝ་ཚུ་གི་བདེན་ལུགས་ལུ་ བཏོན་གཏང་དགོ། མགུ་སྐོར་རྒྱབ་རྟོག་གིས་ ཉེན་ཁ་གསལ་སྟོན་དགོཔ། དཔྱད་ཡིག་ཚུ་ བཞག་དགོཔ་དང་ ལས་འཛིན་ཚུ་ལུ་མགྱོགས་དྲགས་སྦེ་ བྱ་རིམ་འགོ་འདྲེན་འཐབ་ནི་ལུ་ ཕན་ཐོགས་འོང་།

- འགན་འཁྲི་དང་ཆོག་ཐམ་ཚུ་ ཆ་མེད་གཏང་ནི་དེ་ ད་ལྟོའི་བར་ཆད་སེལ་ཐབས་ཀྱི་འཆར་གཞི་ལུ་ཆ་བཞག་མི་ཅིག་ཨིན།
- ཟད་འགྲོ་གི་ཐོ་ཡིག་ཚུ་ བརྟག་ཞིབ་འབད་ནིའི་དོན་ལུ་ ལག་ལེན་ཅན་གྱི་ གཞུང་སྐྱོང་ སྲིད་བྱུས་དང་ ངོས་ལེན་གྱི་རྣམ་གཞག་ཚུ་གིས་ གོ་སྐབས་བྱིན་པ་ཅིན་རྐྱངམ་གཅིག་ཨིན།
- རྟགས་མཚན་ཚུ་གིས་ མཚམས་འཇོག་འབད་མི་ཚུ་ལུ་ གྲོས་འདེབས་བཀོད་པའི་སྐབས་ ལི་ཝང་ཚུ་ བསྒྱུར་བཅོས་འབདཝ་ཨིན།

ལྟ་རྟོག་ཞབས་ཏོག་ལུ་ ཡིག་སྣོད་རྒྱ་ཆེ་དྲགས་སྦེ་བྱིན་མི་དགོ་ ལག་ལེན་འཐབ་ནི་ དམིགས་གཏད་ཅན་གྱི་ ཁྱད་རིག་གི་རྩིས་ཁྲམ་ཅིག་ཨིན་ འདི་ནང་ལུ་ ལན་གསལ་འབད་ནིའི་དོན་ལས་ དགོས་མཁོ་ཆེ་བའི་ཆོག་ཐངས་ཆུང་ཤོས་ཅིག་ཡོད། མི་གིས་ ངོས་ལེན་འབད་མི་དེ་ ལས་རིམ་གང་རུང་གི་ལཱ་རྒྱུན་ལམ་གྱི་ཆ་ཤས་ཅིག་སྦེ་ར་སྡོད་དགོཔ་ཨིན་ འདི་གིས་ རྒྱུ་དངོས་ཚུ་ སྤོ་བཤུད་འབད་ནི་དང་ ངོས་ལེན་ཚུ་ བསྒྱུར་བཅོས་འབད་ནི་ དེ་ལས་ ཡང་ཅིན་ སྒྲིག་གཞི་འདི་ ཆ་མེད་གཏང་མི་ལུ་ བསྒྱུར་བཅོས་འབད་ཚུགསཔ་ཨིན།

## དཔྱད་ཡིག་དང་བཞག་ཐབས། {#evidence-and-retention}

ལྟ་རྟོག་གི་དཔང་རྟགས་ཚུ་ སྒྲིག་འཇུག་མ་རྐྱངམ་གཅིག་ནང་བཞག་དོ་ཡོདཔ་ད་ འདི་ཡང་ བདེན་ཁུངས་བཀལ་མི་ ཌའི་ཊེ་རི་ལས་སོ་སོ་ཨིན། ཉེན་བརྡ་རེ་རེའི་ནང་:

- འབྱུང་རྐྱེན་འབྱུང་ཁུངས་གི་མིང་དང་ ཀུར་སོར་
- སྦྲག་མཐོ་ཚད་ ཡང་ན་ སྦྲགས་ཧེཤ་ཚུ་ ཐོབ་ཚུགས་པ་ཅིན་
- ཕྱིར་ཚོང་གི་ཧེཤ་དང་དབང་འཛིན་
- རྩིས་ཁྲ་, ས་ཁོངས་, རྒྱུ་དངོས་, འགན་འཁྲི་, ཐིག་ཁྲམ་ ཡང་ན་ སྒྲིག་གཞི་ ID
- raw event payload ཡང་ན་ འདི་གི་ canonical hash
- བརྒྱུད་འཕྲིན་འདི་ ཡར་རྒྱས་གོང་འཕེལ་གཏང་ནིའི་དོན་ལུ་ལག་ལེན་འཐབ་མི་ བརྒྱུད་འཕྲིན་གློག་བརྙན་ཚུ་
- སྒྲིག་གཞི་གི་མིང་། འདྲ་བཤུས་ཐོ་བཀོད་ཐོ་བཀོད། གྲུབ་འབྲས་དང་ དཔྱད་ཞིབ་འབད་མི་གིས་ གྲོས་ཐག་བཅད་ཡོདཔ་ཨིན།

གནད་དོན་ཁག་ཆེ་ཤོས་ཀྱི་ཞིབ་དཔྱད་ཡིག་ཚུ་ མི་མང་གི་རྩིས་དེབ་ནང་ གསལ་བཀོད་འབད་ཡོད་པའི་ གནས་སྡུད་སྦེ་མ་བཞག་པར་ རྩ་སྒྲིག་གི་ བརྡ་དོན་འཛིན་སྐྱོང་གི་ སྲིད་བྱུས་འདི་གསལ་ཏོག་ཏོ་སྦེ་ ངོས་ལེན་མ་འབད་བར་ བཞག་དགོ། གལ་སྲིད་ ཁྱོད་ཀྱིས་ འབྲེལ་བ་མེད་མི་ གནད་དོན་ཅིག་ལུ་ ནང་འཁོད་ཀྱི་ གནད་དོན་ཅིག་དང་འབྲེལ་མཐུད་འབད་དགོ་པ་ཅིན་ གནད་དོན་ངོ་རྟགས་ཅན་ཅིག་དང་ ཐོ་བཀོད་ཅན་གྱི་ དམ་བཅའ་ཡིག་ ཡང་ན་ སྒེར་གྱི་གནད་དོན་ཚུ་ གསལ་སྟོན་མ་འབད་མི་ ཧེཤ་ཁ་གཏད་ཚུ་ གདམ་ཁ་རྐྱབས་ཨིན།

## ལག་ལེན་གྱི་དཔྱད་ཡིག་ {#implementation-checklist}

- `/metrics`དང་ ལས་འཛིན་གྱི་ལམ་སྒོ་ཚུ་གི་དོན་ལུ་ དགོས་མཁོ་ཅན་གྱི་ གློག་ཐག་ར་བ་གི་ཐོ་ཡིག་འདི་ རྩ་སྒྲིག་འབདཝ་ཨིན།
- ཁྱོད་ཀྱིས་བརྟག་དཔྱད་འབད་ཡོད་པའི་དངོས་ཆས་ཚུ་གི་དོན་ལུ་ ཕྲ་རིང་གི་ཐིག་ཁྲམ་ཚུ་ཡོད་མི་ Torii ལས་རིམ་རྒྱུན་ལམ་ཚུ་ལུ་ ཐོ་བཀོད་རྐྱབས་ཚུགས།
- འབྱུང་རྐྱེན་གྱི་བརྡ་སྟོན་ཚུ་ འཕྲོ་མཐུད་འབད་ཡོདཔ་ལས་ གློག་ཐངས་འདི་ ཐེ་ཚོམ་མེད་པར་ ལོག་འགོ་བཙུགས་ཚུགསཔ་ཨིན།
- དུས་རྒྱུན་གྱི་དུས་ཚོད་ནང་ལུ་ རྒྱུགས་ཆུ་ཚུ་དང་ གློག་ཐིག་གི་དྲི་བ་ཚུ་ གཅིག་སྒྲིལ་འབད།
- ཉེན་ཁ་གི་ཐོ་བཀོད་ཚུ་བཞག་ནི་དང་ ཐོ་བཀོད་ཀྱི་སྒྲིག་གཞི་ནང་ལུ་ ཐོ་བཀོད་འབད་ནིའི་གོ་སྐབས་བྱིན་ནི།
- དཔྱད་རྩོམ་གྱི་བརྡ་སྟོན་ལམ་ལུགས་ཚུ་ ཐོ་བཀོད་འབད་མ་ཚར་བའི་ཧེ་མར་ རང་བཞིན་གྱི་ལག་ལེན་ཚུ་ ལག་ལེན་འཐབ་ཚུགསཔ་བཟོ་ནིའི་དོན་ལུ་ཨིན།
- གྲོས་འདེབས་ཚུ་གི་དོན་ལུ་ དམིགས་བསལ་གྱི་ ཁྱད་རིག་གི་རྩིས་ཐོ་ལག་ལེན་འཐབ་དགོ།
- བསྐྱར་ཞིབ་གི་འགན་ཁུར་དང་ ངོས་ལེན་ཚུ་ དུས་ཡུན་ཐུང་ཀུ་ཅིག་ཁར་ འཕྲལ་འཕྲལ་སྦེ་བྱིན་དོ་ཡོདཔ་ཨིན།
- བྱ་སྟབས་མ་བདེཝ་དང་འབྲེལ་བའི་ གནད་དོན་ཚུ་ བརྟག་ཞིབ་འབད་ནིའི་ ཉེན་བརྡ་ཚུ་ཡང་ འབྱུང་རྐྱེན་ལུ་ ཐོ་ཕོག་པའི་སྐབས་ ནང་ཚུད་དགོ།
