# མགུ་སྐོར་རྒྱབ་སྐྱོར་འབད་ནི་ {#fraud-monitoring}

Iroha བཀྲམ་སྤེལ་གྱི་མགུ་སྐོར་ལྟ་རྟོག་འདི་ རྩིས་ཐོའི་བྱུང་རྐྱེན་ དྲི་བཀོད་ གནང་བ་ དེ་ལས་ ལག་ལེན་གྱི་གནས་སྟངས་ལུ་གཞི་བཞག་པའི་བཀོལ་སྤྱོད་ཚད་འཛིན་ཅིག་ཨིན། Iroha གིས་ ཕུལ་མི་ ངོས་ལེན་འབད་མི་ ཆ་མེད་གཏང་མི་ དེ་ལས་ ཁས་བླངས་འབད་མི་ཚུ་ཐོ་བཀོད་འབདཝ་ཨིན། ཁྱོད་ཀྱི་ལྟ་རྟོག་ལམ་ལུགས་ཀྱིས་ ཚོང་འབྲེལ་བྱ་རིམ་ནང་དོགས་པ་ཅན་གྱི་རྣམ་གཞག་ཚུ་ཐག་བཅད་དེ་ གནད་དོན་ཚུ་བསྐྱར་ཞིབ་པ་ཡང་ན་ རང་འགུལ་ལན་འདེབས་ཚད་འཛིན་ལུ་བཏངམ་ཨིན།

མགུ་སྐོར་རྒྱབ་རྟོག་འདི་ དམ་ཚིག་ཅན་ཅིག་ནང་ བཙུགས་ཡོད་པའི་ཁུངས་ཀྱི་ཚབ་ལུ་ ཞབས་ཏོག་སོ་སོ་སྦེ་འབད་དགོཔ་ཨིན། ཞབས་ཏོག་དེ་གིས་ ལྡེ་མིག་གི་ལཱ་འབད་ནི་ལུ་ ཐོ་བཀོད་འབད་དགོཔ། ལྕགས་ཐག་ལས་ཕྱི་ཁར་ ཉེན་ཁ་ཅན་གྱི་ གནས་སྟངས་དང་གཅིག་ཁར་ ཡར་རྒྱས་གཏང་དགོཔ། དཔྱད་ཡིག་ཚུ་ བརྟག་ཞིབ་འབད་དགོཔ། དང་ ལན་སླ་སྤྲོད་ལེན་ཚུ་ རྐྱངམ་གཅིག་རྐྱངམ་གཅིག་གིས་ ངོས་ལེན་གསལ་ཏོག་ཏོ་ཡོད་མི་རྩིས་ཐོིས་བརྒྱུད་དེ་ གྲུབ་འབྲས་བཀོད་དགོ།

## ལྟ་རྟོག་གི་རྣམ་གཞག་ {#monitoring-model}

ཕན་ཐོགས་ཅན་གྱི་ལྟ་རྟོག་མདོང་ལམ་ལུ་གནས་རིམ་བཞི་ཡོདཔ་ཨིན།

1. Torii འབྱུང་རྐྱེན་འབྱུང་ཁུངས། འདྲི་དཔྱད་དང་རྩིས་ཐོ་བཀོད་ལས་ ཐོ་བཀོད་དང་ ལག་ལེན་པ་བརྡ་སྟོན་ཚུ་ བསྡུ་བསྒྱོམ་འབད་།
2. **ཕུན་སུམ་ཚོགས་པ** བྱུང་ལས་ཚུ་ ཚོང་མགྲོན་པའི་གནས་རིམ་དང་ མཉམ་འབྲེལ་ཐོ་ཡིག་ ལག་ལེན་ལཱ་ཡུན་ངོས་འཛིན་འབད་མི་ རེ་བ་བསྐྱེད་པའི་ཚད་གཞི་ དེ་ལས་ གནད་དོན་ཨའི་ཌི་ཚུ་བཟུམ་གྱི་ རྒྱུན་རིམ་ཕྱི་ཁའི་སྐབས་དོན་དང་གཅིག་ཁར་ ཕྱུགཔོ་བཟོ།
3. **བརྟག་དཔྱད་** དོགས་པ་ཅན་གྱི་སྤྱོད་ལམ་གཏན་འབེབས་ལམ་ལུགས་དང་བསྐྱར་ཞིབ་བང་རིམ་ ཡང་ན་ཉེན་ཁའི་གྲངས་ཐོ།
4. **ལན་** བཀོལ་སྤྱོད་པ་ཚུ་ལུ་ཉེན་བརྡ་འབད་དེ་ ལག་ལེན་ཕྱོགས་ཀྱི་ལཱ་གི་རྒྱུན་རིམ་ཚུ་ བར་མཚམས་འཇོག་སྟེ་ དགོས་མཁོ་མེད་པའི་གནང་བ་ཚུ་ ཆ་མེད་བཏང་སྟེ་ ཡང་ན་ ཁྱོད་རའི་གཞུང་སྐྱོང་བྱ་རིམ་གྱིས་ གནང་བ་བྱིན་པའི་སྐབས་ རྒུད་འཐུས་ཚོང་འབྲེལ་ཚུ་ བཙུགས་ཏེ་ཨིན།

བདེན་དཔྱད་འབད་མི་ག་ར་གིས་ གྲོས་ཐག་གཅིགཔོ་འདི་ ལོག་སྟེ་བཏོན་དགོཔ་མ་གཏོགས་ སྲིད་བྱུས་གྲོས་ཐག་ཚུ་ མོས་མཐུན་གྱི་ཕྱི་ཁར་བཞག་དགོ། གཡོག་བཀོལ་བའི་དུས་ཚོད་བདེན་དཔྱད་འདི་གིས་ གནང་བ་ཚུ་དང་ བརྗེ་སོར་གྱི་ནུས་ཅན་ཚུ་ བསྟར་སྤྱོད་འབད་དགོ། གཡོ་སྒྱུ་ལྟ་རྟོག་འབད་མི་འདི་གིས་ ཉེན་ཁ་འགྲེལ་བཤད་རྐྱབ་དགོཔ་དང་ སྒྲུབ་བྱེད་ཉམས་སྲུང་འབད་དགོཔ་ དེ་ལས་ བཀོལ་སྤྱོད་པ་ཚུ་ལུ་ མགྱོགས་པ་རང་ ལཱ་འབད་ནི་ལུ་ གྲོགས་རམ་འབད་དགོ།

## བརྡ་སྟོན་ཚུ་ བསྡུ་ལེན་འབད་ནི་ {#signals-to-collect}

| --- | --- | --- |
| ཚོང་འབྲེལ་གནས་ཚད། | མདོང་ལམ་བྱུང་རིམ། | བསྐྱར་ལོག་བཀག་ཆ་དང་ གནང་བ་བྱིན་ནིའི་དཔའ་བཅམ་འཐུས་ཤོར་ དེ་ལས་ སྤྱིར་བཏང་མེན་པའི་ཕུལ་བའི་དཔེ་རིས་ཚུ་ ཤེས་རྟོགས་འབད། |
| རྩིས་ཐོའི་མི་ཚེ་འཁོར་རིམ་དང་ མེ་ཊ་ཌེ་ཊ། | གནད་སྡུད་བྱུང་ལས་དང་རྩིས་ཐོའི་འདྲི་དཔྱད་ | རྩིས་ཐོ་གསརཔ་དང་ མིང་གཞན་བསྒྱུར་བཅོས་ ངོ་རྟགས་དུས་མཐུན་བཟོ་ནི་ དེ་ལས་ རེ་བ་མེད་པའི་ མེ་ཊ་ཌེ་ཊ་ཞུན་དག་ཚུ་ ཤེས་རྟོགས་འབད། |

- བྱུང་རྐྱེན་ལན་འདེབས་འཆར་གཞི་གིས་ བདེན་པ་མེད་པའི་འགན་ཁུར་ཡང་ན་ གནང་བ་ཚུ་ ཆ་མེད་གཏང་།
- གཞུང་སྐྱོང་སྲིད་བྱུས་དང་གནང་བ་དཔེ་སྟོན་གྱིས་ གནང་བ་བྱིན་པའི་སྐབས་རྐྱངམ་གཅིག་ རྗེས་འཇུག་རྩིས་ཐོའི་ཚོང་འབྲེལ་ཚུ་ བཙུགས།
- སྒྲུབ་བྱེད་ཀྱིས་མིང་རྟགས་བཀོད་མི་བདེ་སྒྲིག་བཟོ་བའི་བསམ་འཆར་བཀོད་པའི་སྐབས་ལྡེ་མིག་བསྒྱིར།

ལྟ་རྟོག་ཞབས་ཏོག་ལུ་ འབྲི་ནིའི་འཛུལ་སྤྱོད་རྒྱ་ཆེཝ་སྦེ་བྱིན་ནི་ལས་འཛེམ་དགོ། དེ་གིས་ ལཱ་འབད་བཅུག་མི་ ལན་འདེབས་བྱ་བ་ཚུ་གི་དོན་ལུ་དགོ་པའི་ གནང་བ་ཆ་ཚན་ཆུང་ཤོས་དང་གཅིག་ཁར་ བློ་གཏད་ཅན་གྱི་འཕྲུལ་རིག་རྩིས་ཐོ་ཅིག་ལག་ལེན་འཐབ། མི་ཡི་ཆ་འཇོག་འདི་ རྒྱུ་དངོས་ཚུ་སྤོ་བཤུད་འབད་ཚུགས་མི་དང་ གནང་བ་ཚུ་བསྒྱུར་བཅོས་འབད་ཚུགས་མི་ ཡང་ན་ བདེན་བཤད་འབད་མི་ལུ་གདོང་ལན་འབད་མི་རིམ་སྒྲིག་བསྒྱུར་བཅོས་འབད་ཚུགས་མི་ ལཱ་གི་རྒྱུན་རིམ་གང་རུང་ཅིག་གི་ཆ་ཤས་ཅིག་སྦེ་སྡོད་དགོ།

## དཔྱད་ཡིག་དང་བཞག་ཐབས། {#evidence-and-retention}

ལྟ་རྟོག་གི་དཔང་རྟགས་ཚུ་ སྒྲིག་འཇུག་མ་རྐྱངམ་གཅིག་ནང་བཞག་དོ་ཡོདཔ་ད་ འདི་ཡང་ བདེན་ཁུངས་བཀལ་མི་ ཌའི་ཊེ་རི་ལས་སོ་སོ་ཨིན། ཉེན་བརྡ་རེ་རེའི་ནང་:

- བྱུང་ལས་རྒྱུན་ལམ་མིང་དང་འོད་རྟགས་
- བཀག་ཆ་མཐོ་ཚད་ཡང་ན་བཀག་ཆ་ཧ་ཤི་ཐོབ་པའི་སྐབས་
- ཕྱིར་ཚོང་གི་ཧེཤ་དང་དབང་འཛིན་
- གནོད་སྐྱོན་ཕོག་པའི་རྩིས་ཐོ་ མངའ་ཁོངས་ རྒྱུ་དངོས་ འགན་ཁུར་ འབྱུང་ཁུངས་ ཡང་ན་ རིམ་སྒྲིག་ཨའི་ཌི་
- བྱུང་རིམ་སྔོ་མའི་པེ་ལོཌ་ཡང་ན་དེའི་ཚད་ལྡན་ཧེཤ་ཅིག
- དྲན་སྐུལ་ཕྱུགཔོ་བཟོ་ནི་ལུ་ལག་ལེན་འཐབ་ཡོད་པའི་འདྲི་དཔྱད་པར་རིས།
- ལམ་ལུགས་ཀྱི་མིང་དང་ཐོན་རིམ་ ཚད་གཞི་ སྐུགས་ དེ་ལས་ བསྐྱར་ཞིབ་འབད་མི་གི་ཐག་གཅོད།

ཡོངས་འབྲེལ་གྱི་གནས་སྡུད་གཞུང་སྐྱོང་སྲིད་བྱུས་ཀྱིས་ གསལ་ཏོག་ཏོ་སྦེ་ གནང་བ་མ་བྱིན་ཚུན་ཚོད་ ཚོར་ཤུགས་ཅན་གྱི་ཞིབ་དཔྱད་དྲན་ཐོ་ཚུ་ མི་མང་རྩིས་ཐོའི་གནས་སྡུད་སྦེ་ གསོག་འཇོག་མ་འབད། ཁྱོད་ཀྱིས་ རིམ་སྒྲིག་ཕྱི་ཁའི་གནད་དོན་ཅིག་ རིམ་སྒྲིག་གནས་སྟངས་ལུ་འབྲེལ་མཐུད་འབད་དགོ་པ་ཅིན་ གནད་དོན་ངོས་འཛིན་འབད་མི་ མིང་རྟགས་བཀོད་ཡོད་པའི་བདེན་བཤད་ ཡང་ན་ སྒེར་གྱི་ཁ་གསལ་ཚུ་ གསལ་སྟོན་མ་འབད་མི་ ཧེཤ་ཁས་བླངས་ཅིག་ གདམ་ཁ་རྐྱབ།

## ལག་ལེན་གྱི་དཔྱད་ཡིག་ {#implementation-checklist}

- `/metrics` དང་བཀོལ་སྤྱོད་འགྲུལ་ལམ་ཚུ་གི་དོན་ལུ་དགོ་པའི་ ཊེ་ལི་མི་ཊར་གསལ་སྡུད་འདི་ལྕོགས་ཅན་བཟོ།
- ཁྱོད་ཀྱིས་བརྟག་དཔྱད་འབད་ཡོད་པའི་དངོས་ཆས་ཚུ་གི་དོན་ལུ་ ཕྲ་རིང་གི་ཐིག་ཁྲམ་ཚུ་ཡོད་མི་ Torii ལས་རིམ་རྒྱུན་ལམ་ཚུ་ལུ་ ཐོ་བཀོད་རྐྱབས་ཚུགས།
- བྱུང་ལས་འོད་རྟགས་ཚུ་ རྟག་བརྟན་བཟོ་སྟེ་ བལྟ་རྟོག་པ་འདི་ བར་སྟོང་མེད་པར་ ལོག་འགོ་བཙུགས་ཚུགས།
- དུས་རྒྱུན་གྱི་ལས་རིམ་ནང་ ཤོག་ལེབ་ཅན་གྱི་འདྲི་དཔྱད་ཚུ་དང་གཅིག་ཁར་ རྒྱུན་ལམ་ཚུ་ མཐུན་སྒྲིག་འབད།
- ཉེན་ཁ་ཚད་གཞི་ཚུ་བཞག་སྟེ་ ཐོན་རིམ་ཚད་འཛིན་རིམ་སྒྲིག་ནང་ ཐོ་ཡིག་ཚུ་འབད་བཅུག།
- རང་བཞིན་བྱ་བ་ཚུ་ལྕོགས་ཅན་མ་བཟོ་བའི་ཧེ་མ་ བྱུང་རབས་སྡེབ་ཚན་ཚུ་ལུ་ ཉེན་བརྡའི་ལམ་ལུགས་ཚུ་བརྟག་དཔྱད་འབད།
- ལན་འདེབས་བྱ་བ་ཚུ་གི་དོན་ལུ་ བློ་གཏད་ཅན་གྱི་འཕྲུལ་རིག་རྩིས་ཐོ་ཚུ་ལག་ལེན་འཐབ།
- བསྐྱར་ཞིབ་འགན་ཁུར་དང་གནང་བ་གནང་བ་ཚུ་ བསྐྱར་ལོག་ལས་རིམ་ནང་།
- བྱུང་རྐྱེན་ལན་འདེབས་བྱ་རིམ་ནང་ གཡོ་སྒྱུ་ལྟ་རྟོག་ཉེན་བརྡ་ཚུ་ བཙུགས་དགོ།
