# ཉེན་སྲུང་ {#security}

Iroha གཞི་བཙུགས་འདི་ ཉེན་སྲུང་ཅན་བཟོ་ནི་ འདི་བཟུམ་སྦེ་ ཁྱོད་ཀྱིས་ ཚོར་བ་ཅན་གྱི་ གནད་སྡུད་དང་ གནས་གོང་ཚུ་ལག་ལེན་འབད་ནིའི་ལམ་ལུགས་གང་རུང་ཅིག་ལུ་ འབད་ཚུགས། ཐོ་བཀོད་ཀྱི་ལྡེ་མིག་ཚུ་ སྲུང་སྐྱོབ་འབད་, གྲོག་ཐིག་གི་འཛུལ་སྒོ་, མཚམས་འཇོག་འབད་མི་ལཱ་ཚུ་, ལྟ་རྟོག་འབད་ནི་དང་ བྱ་སྟབས་མ་བདེཝ་ཚུ་གི་ལན་འཇལ་བ། ལྡེ་སྒྲོམ་འདི་གིས་ འ་ནི་འཛིན་སྐྱོང་ཚུ་གི་ དགོས་མཁོ་རྩ་མེད་གཏང་མི་ཨིན།

### རྒྱ་མཚོ་བལྟ་བཤལ་ {#navigation}

འ་ནི་ཆ་ཤས་འདི་ནང་ལུ་ ཁྱོད་ཀྱིས་ Iroha འབྲེལ་མཐུད་དེ་སྲུང་སྐྱོབ་འབད་ནིའི་གནད་དོན་མ་འདྲཝ་ཚུ་གི་སྐོར་ལས་ཤེས་ཚུགས། ལྷག་པར་དུ་ཤེས་དགོ་པ་ཅིན་ འདི་ཚུ་གི་གྲལ་ལས་གཅིག་ གདམ་ཁ་རྐྱབས་དགོ།

- [ཉེན་སྲུང་གི་གཞི་རྩ་](./security-principles):

གནས་སྡུད་སྲུང་སྐྱོབ་དང་ ཁྲིམས་འགལ་གྱི་ཉེན་ཁ་མར་ཕབ་འབད་ནིའི་དོན་ལུ་ གཞི་རྩའི་གཞི་རྩ།

- [དངོས་མེད་སྒེར་གྱི་ཡོངས་འབྲེལ](./vpn.md):

VPN ལག་ལེན་འཐབ་ནིའི་ཐབས་ལམ་དེ་ རིམ་པ་ལས་ རིམ་པ་ལུ་ བཀག་འཛིན་འབད་ནི་དང་ Torii དེ་ལས་ སྒེར་གྱི་ ཡང་ན་ གྲོས་འཛོམས་ཀྱི་ལཱ་ཚུ་ནང་ བྱ་བ་སྤྱོད་མི་གི་ཐོབ་ཐངས་ཚུ་ བཀག་འཛིན་འབད་ནིའི་དོན་ལུ་ཨིན་མས།

- [ལས་འགུལ་གྱི་ ཉེན་སྲུང་ ](./operational-security.md):

འཛུལ་སྤྱོད་དང་ ལྟ་རྟོག་ བྱུང་རྐྱེན་ལན་འདེབས་ དེ་ལས་ བཀོལ་སྤྱོད་པ་ལཱ་འབད་སའི་ས་ཁོངས་ཚུ་གི་དོན་ལུ་ ཉིན་བསྟར་གྱི་ཚད་འཛིན་ཚུ།

- [མགུ་སྐོར་རྒྱབ་སྐྱོར་](./fraud-monitoring.md):

དོགས་པ་ཅན་གྱི་ལས་སྣ་ཚུ་ བརྟག་དཔྱད་འབད་ནི་དང་ ལན་གསལ་གྱི་སྒྲུབ་བྱེད་ཚུ་ ཉམས་སྲུང་འབད་ནི་ལུ་ ལེ་ཇར་བྱུང་ལས་དང་ འདྲི་དཔྱད་ གནང་བ་ དེ་ལས་ ལག་ལེན་བརྡ་མཚོན་ཚུ་ ལག་ལེན་འཐབ་ཐངས།

- [གསང་གྲངས་བདེ་འཇགས།](./password-security.md):

ཆོག་ཡིག་ཨེན་ཊོཔི་དང་ ཤུགས་ཅན་གྱི་ཆོག་ཡིག་བཟོ་བསྐྲུན་ དེ་ལས་ སྤྱིར་བཏང་འཐུས་ཤོར་ཐབས་ལམ་ཚུ་ཨིན།

- [མི་མང་ལྡེ་མིག་གསང་སྡོམ](./public-key-cryptography.md): གསང་སྤྱོད་ཀྱི་ལྡེ་མིག་ཚུ་

མི་མང་ལྡེ་མིག་གསང་བཟོ་དང་མིང་རྟགས་ དེ་ལས་ བདེན་བཤད་འབད་ཡོད་པའི་བརྒྱུད་འབྲེལ་ཚུ།

  - [གསང་ཡིག་ལྡེ་མིག་བཟོ་བཏོན་འབད་དོ།](./generating-cryptographic-keys.md):

`kagami` དང་ཅིག་ཁར་རྒྱབ་སྐྱོར་འབད་ཡོད་པའི་གསང་ཡིག་ལྡེ་མིག་ཚུ་བཟོ་བཏོན་འབད།

  - [ཐོ་བཀོད་ཀྱི་ལྡེ་མིག་](./storing-cryptographic-keys.md):

བཀྲམ་སྤེལ་ལུ་འོས་འབབ་ཡོད་པའི་བང་རིམ་ཚད་འཛིན་ཚུ་ལག་ལེན་འཐབ་སྟེ་ གསང་ཡིག་ལྡེ་མིག་ཚུ་གསོག་འཇོག་འབད།
