# ཉེན་སྲུང་ {#security}

གནད་དོན་འདི་གི་དོན་ལུ་ Iroha ཡང་ན་ གཞན་གྱི་ blockchain ledger ལག་ལེན་འཐབ་པའི་སྐབས་ ཉེན་སྲུང་དེ་ དངུལ་རྩིས་ཚོགས་སྡེ་ཚུ་གི་དོན་ལུ་ གལ་གནད་ཅན་ཅིག་ཨིནམ་ད་ དེ་ནང་ ཉམས་མྱོང་ཅན་གྱི་ དངུལ་འབྲེལ་ཡིག་ཆ་དང་ བྱ་སྤྱོད་ཚུ་ སྤྱིར་བཏང་གི་གནས་སྟངས་ནང་ལུ་ ཡིད་ཆེས་ཀྱི་གཞི་འགྱམ་བཟོ་ཡོདཔ་ཨིན། ཉེན་སྲུང་དང་ལྡནམ་སྦེ་ བཀྲམ་སྤེལ་འབད་ནིའི་དོན་ལུ་ ཉེན་སྲུང་གི་ཐབས་ལམ་ཚུ་ གཞི་བཙུགས་འབད་ནི་འདི་ གལ་ཆེཝ་ཨིན་ འདི་འབདཝ་ལས་ ཁྱོད་ཀྱི་ཚོར་བ་ཅན་གྱི་ གནད་དོན་ཚུ་གི་ ཡུན་བརྟན་དང་ གསང་བའི་གནས་སྟངས་ སྲུང་སྐྱོབ་འབད་ནིའི་དོན་ལུ་ཨིན།

### རྒྱ་མཚོ་བལྟ་བཤལ་ {#navigation}

འ་ནི་ཆ་ཤས་འདི་ནང་ལུ་ ཁྱོད་ཀྱིས་ Iroha འབྲེལ་མཐུད་དེ་སྲུང་སྐྱོབ་འབད་ནིའི་གནད་དོན་མ་འདྲཝ་ཚུ་གི་སྐོར་ལས་ཤེས་ཚུགས། ལྷག་པར་དུ་ཤེས་དགོ་པ་ཅིན་ འདི་ཚུ་གི་གྲལ་ལས་གཅིག་ གདམ་ཁ་རྐྱབས་དགོ།

- [ཉེན་སྲུང་གི་གཞི་རྩ་](./security-principles):

རང་རྐྱང་དང་ ལས་སྡེ་ཚུ་གིས་ ཁོང་གི་གནས་སྡུད་ཚུ་ ཉེན་སྐྱོབ་འབད་ནིའི་དོན་ལུ་ ལག་ལེན་འཐབ་ཚུགས་པའི་ གཞི་རྟེན་གྱི་ ཉེན་སྲུང་གི་གཞི་རྩ་དང་ ཡང་ཅིན་ ཁ་འབྱལ་འགྱོ་ནིའི་ གོ་སྐབས་ མར་ཕབ་འབད་ཚུགས།

- [Virtual Private Networks](./vpn.md):

VPN ལག་ལེན་འཐབ་ནིའི་ཐབས་ལམ་དེ་ རིམ་པ་ལས་ རིམ་པ་ལུ་ བཀག་འཛིན་འབད་ནི་དང་ Torii དེ་ལས་ སྒེར་གྱི་ ཡང་ན་ གྲོས་འཛོམས་ཀྱི་ལཱ་ཚུ་ནང་ བྱ་བ་སྤྱོད་མི་གི་ཐོབ་ཐངས་ཚུ་ བཀག་འཛིན་འབད་ནིའི་དོན་ལུ་ཨིན་པས།

- [ལས་འགུལ་གྱི་ ཉེན་སྲུང་ ](./operational-security.md):

ཁྱོད་ཀྱི་དྲ་རྒྱ་གི་ ཉིན་བསྟར་གྱི་ལཱ་ཚུ་ ཉེན་སྐྱོབ་འབད་ནིའི་དོན་ལུ་ ལག་ལེན་ལེགས་ཤོམ་ལག་ལེན་འཐབ་དོ་ཡོདཔ་ད་ དེ་ནང་འཛུལ་སྒོ་འཛིན་སྐྱོང་དང་ ལྟ་རྟོག་འབད་ནི་ དེ་ལས་ བྱ་སྟབས་མ་བདེཝ་ལུ་ ལན་སླབ་ནི་ དེ་ལས་ བལྟ་བཤལཔ་ཚུ་གི་ལག་ལེན་འཐབ་ཐངས་ཚུ་ བཅའ་མར་གཏོགས་འོང་།

- [མགུ་སྐོར་རྒྱབ་རྟོག་](./fraud-monitoring.md):

དོགས་པ་ཅན་གྱི་ལཱ་ཚུ་ བརྟག་ཞིབ་འབད་ནིའི་དོན་ལུ་ ལག་ལེན་འཐབ་ནིའི་ ཐབས་ཤེས་དང་ ཐབས་ལམ་དང་ བརྡ་དོན་ཚུ་

- [Password ཉེན་སྲུང་](./password-security.md):

Password entropyནང་ལུ་ deep diving བཟོ་ནི་དང་ strong passwords བཟོ་ནི་ དེ་ལས་ password vulnerabilities འདི་སྤང་ནི་ཨིན།

- [Public Key Cryptography](./public-key-cryptography.md): གསང་སྤྱོད་ཀྱི་ལྡེ་མིག་ཚུ་
