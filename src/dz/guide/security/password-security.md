# Password སྲུང་སྐྱོབ་ {#password-security}

blockchain ཉེན་སྲུང་གི་ས་ཁོངས་ནང་ལུ་ Password སྲུང་སྐྱོབ་འདི་ གལ་གནད་ཅན་ཅིག་ཨིན། ཁྱོད་ཀྱི་ data དང་ འདི་ནང་ཡོད་པའི་ཆ་མཉམ་དེ་ ངོས་ལེན་མ་འབད་མི་ལག་ལེན་ཚུ་གི་དོན་ལུ་ ངེས་བརྟན་སྦེ་ བཞག་ནིའི་དོན་ལུ་ ད་ Password ཉེན་སྲུང་གི་ གནད་དོན་ཚུ་ནང་ལུ་ཞིབ་དཔྱད་རྐྱབ།

## Password སྒྲིང་སྒྲི་ {#password-strength}

འདི་བཟུམ་སྦེ་ ཁྱོད་ཀྱིས་ ཧེ་མ་ཡང་ ཉེན་ཁ་ཅན་གྱི་ལྡེ་ཡིག་འདི་ ག་དེ་སྦེ་ བཟོ་ཚུགས་ནི་ཨིན་ནའི་ གྲོས་འདེབས་ཚུ་དང་འཕྱད་དེ་སྡོད་འོང་ འདི་ཚུ་གི་ནང་ འཛིན་སྐྱོང་འབད་དགོ་པའི་ གྲོས་འདེབས་ཚུ་ཡང་ འོག་གི་ཨང་གྲངས་ཉུང་མཐོའི་ལྡེ་ཡིག་ཚུའི་རིང་ཚད་དང་ དམིགས་བསལ་ཡིག་འབྲུ་ཚུ་བཙུགས་ནི་ དེ་ལས་གཞན་ཚུ་ཡོདཔ་ཨིན། འདི་བཟུམ་མའི་ གྲོས་འདེབས་ཚུ་གིས་ ཁྱོད་ཀྱི་ལྡེ་ཡིག་ཆུའི་ཤུགས་དེ་ ཡར་སེང་འབད་ནི་གི་དམིགས་གཏད་ཡོདཔ་ལས་ དེ་གིས་ ཨེན་ཏོརོ་པི་ལུ་བརྟེན་ཨིན། གནས་སྐབས་ཀྱི་ལྡེ་མིག་གི་མིང་།

འདི་འབདཝ་ལས་ སྟོབས་ལྡན་ལྡེ་ཡིག་འདི་ག་ཅི་ཨིནམ་ཨིན་ན? ཤུགས་ཅན་ལྡེ་ཡིག་དེ་ ཨེན་ཏྲོ་པི་མཐོ་དྲགས་ཡོད་མི་ལྡེ་ཡིག་ཨིན།

## Password vulnerabilities {#password-vulnerabilities}
