# Password སྲུང་སྐྱོབ་ {#password-security}

Password ཚུ་ ལག་ལེན་པ་ཚུ་གི་ consoles, གསང་བའི་ཚོང་ཁང་ཚུ་, རྒྱབ་སྐྱོར་དང་ ས་གནས་ཀྱི་ལྡེ་མིག་གི་ཡིག་སྣོད་ཚུ་ སྲུང་སྐྱོབ་འབད་ཚུགས། Password འདི་འཛིན་སྐྱོང་གཅིག་རྐྱངམ་ཅིག་ཨིན། ཉེན་སྲུང་ཅན་གྱི་ལྡེ་མིག་བདག་འཛིན་, འཛུལ་སྒོ་འཛིན་, དང་ multi-factor authentication ཚུ་དང་གཅིག་ཁར་ལག་ལེན་འཐབ་པ་ཅིན་ ལག་ལེན་འཐབ་འོང་།

## ཁྱད་དུ་འཕགས་དང་ བཟོ་སྐྲུན་འབད་མི་ Password ལག་ལེན་འཐབ་ {#use-unique-generated-passwords}

- རྩིས་ཁྲ་དང་ གནས་སྟངས་རེ་རེའི་དོན་ལུ་ Password ཁྱད་པར་ཅིག་བཟོ་དགོ།
- Password འཛིན་སྐྱོང་པ་ཅིག་ལག་ལེན་འཐབ་སྟེ་ དུས་ཡུན་རིང་པོའི་ random passwords བཟོ་ནི་དང་བཞག་ཚུགས།
- ཚིག་མང་པོའི་ལྡེ་ཡིག་འདི་ ལག་ལེན་འཐབ་ནི་དེ་ ཡོངས་ཐོ་སྦོམ་ཅིག་ནང་ལས་ ཚིག་ཚུ་ སྟབས་མ་བདེཝ་སྦེ་ གདམ་ཁ་རྐྱབ་པའི་སྐབས་རྐྱངམ་གཅིག་ཨིན།
- Password ཚུ་ནང་ མིང་ ཚེས་གྲངས་ ཁ་བྱང་ ལུང་འདྲེན་ Keyboard patterns དང་ ལོག་སྤྱོད་འབད་མི་དུམ་གྲ་ཚུ་ མ་བཙུགས།
- ཞབས་ཏོག་འདི་གིས་ ཐབས་ལམ་འདི་ རྒྱབ་སྐྱོར་འབད་ཡོད་པ་ཅིན་ མི་གིས་བཙུགས་མི་ལྡེ་ཡིག་གི་ཚབ་ལུ་ ཞབས་ཏོག་གིས་བཟོ་ཡོད་པའི་ token ཡང་ན་ cryptographic key འདི་ལག་ལེན་འཐབ་དགོ།

ཚད་རིངམ་དང་ མངོན་ཤེས་མ་འབྱུང་ནི་གི་དོན་ལས་ དབྱེ་བྲག་ཅན་གྱི་བརྡ་སྦྱོར་གྱི་དོན་ལས་མང་ཤོས་ཅིག་ཨིན། ཁྱོད་ཀྱིས་ སྔོན་བཤད་འབད་ཚུགས་པའི་ཚིག་ལུ་ རྟགས་མཚན་གཅིག་བཙུགས་པ་ཅིན་ གྲུབ་འབྲས་དེ་ ཉེན་ཁ་ཅན་སྦེ་མི་མཐོང་འོང་།

## Password Based Accounts སྲུང་སྐྱོབ་འབད། {#protect-password-based-accounts}

- ཕི་ཤིང་འབད་ནིའི་ནུས་པ་ཡོད་པའི་ མང་ཤོས་ཅིག་གི་ བདེན་ཁུངས་འདི་ ལག་ལེན་འཐབ་ཚུགསཔ་བཟོ་ནི།
- ཐོ་ཚད་བཀག་དམ་ སྲིད་བྱུས་དང་ ངོས་འཛིན་གྱི་འཛོལ་བ་ཐེངས་མང་རབས་ཅིག་གི་དོན་ལུ་ ཉེན་བརྡ་ཚུ་ ལག་ལེན་འཐབ་དགོ།
- Passwordཚུ་ authenticated, encrypted channels གི་ཐོག་ལས་རྐྱངམ་ཅིག་བཏང་དགོ།
- Password དང་ recovery codes ཚུ་ logs, command lines, source repositories, configuration files, tickets དང་ chat ནང་ལུ་མ་བཙུགས།
- ཞབས་ཏོག་གི་ཁ་ཐུག་གི་ལྡེ་ཌར་བརྟག་དཔྱད་འཕྲུལ་ཆས་ཚུ་ སྦྲེལ་གཏང་ནིའི་དོན་ལས་ འོས་འབབ་ཡོད་པའི་ གནས་སྡུད་དང་འབྲེལ་བའི་ འགན་འཁྲི་ལག་ལེན་འཐབ་ཐོག་ལས་བཞག་ནི།

## གནས་སྡུད་དང་ བསྐྱར་གསོ་ དེ་ལས་ བསྒྱུར་བཅོས་འབད་ནི་ {#storage-recovery-and-replacement}

- ཨེབ་ལྡེ་ཌར་དང་ བརྟག་དཔྱད་འབད་ཡོད་པའི་རྒྱབ་སྐྱོར་ཚུ་ཡོད་མི་ Password Manager ལག་ལེན་འཐབ་དགོ།
- བསྐྱར་གསོ་འབད་ནིའི་ ཀོ་ཌ་ཚུ་ བསྐྱར་གསོའི་འཕྲུལ་ཆས་ལས་སོ་སོར་སྦེ་བཞག་ནི། བསྐྱར་གསོ་བའི་འཕྲུལ་ཆས་གི་དོན་ལུ་ ཉེན་སྲུང་ཅན་གྱི་ ཕྱི་ཁ་གི་ཤོག་ལེབ་འདྲ་བཤུས་བཏུབ་ཨིན།
- Password-manager ཕྱིར་ཚོང་དང་ རྒྱབ་སྐྱོར་བརྡ་བརྒྱུད་ཚུ་ནང་ འཛུལ་ཞུགས་བཀག་དམ་འབད་ནི།
- ཉེན་སྲུང་གི་བརྡ་དོན་ཚུ་ བསྒྱུར་བཅོས་འབད་དགོ་པའི་ གནད་དོན་དང་འཁྲིལཝ་ད་ ཉེན་སྲུང་གི་ཁ་བྱང་འདི་ བསྒྱུར་བཅོས་འབད།
- བཟོ་སྐྲུན་འགོ་བཙུགས་པའི་ཧེ་མར་རྩིས་ཁྲ་ལོག་ལེན་གྱི་ བྱ་རིམ་ཚུ་ བརྟག་དཔྱད་འབད་ནི།
