# གསང་ཚིག་ཉེན་སྲུང་ {#password-security}

ཆོག་ཡིག་ཚུ་གིས་ བཀོལ་སྤྱོད་པའི་ ཀོན་སོལ་དང་ གསང་བའི་ཚོང་ཁང་ རྒྱབ་ཐག་ཚུ་ དེ་ལས་ ཉེ་གནས་ལྡེ་མིག་ཡིག་སྣོད་ཚུ་ ཉེན་སྲུང་འབད་ཚུགས། ཆོག་ཡིག་འདི་ཚད་འཛིན་གཅིག་རྐྱངམ་ཅིག་ཨིན། ཉེན་སྲུང་ལྡེ་མིག་བདག་འཛིན་དང་ འཛུལ་སྤྱོད་ཚད་འཛིན་ དེ་ལས་ འཐོབ་ཚུགས་ས་ལུ་ སྣ་མང་ཆ་རྐྱེན་བདེན་བཤད་ཚུ་དང་གཅིག་ཁར་ ལག་ལེན་འཐབ།

## གཞན་དང་མ་འདྲ་བའི་ཆོག་ཡིག་ཚུ་ལག་ལེན་འཐབ། {#use-unique-generated-passwords}

- རྩིས་ཐོ་དང་མཐའ་འཁོར་རེ་རེ་གི་དོན་ལུ་ཆོག་ཡིག་སོ་སོ་ཅིག་བཟོ་བཏོན་འབད།
- གང་བྱུང་ཆོག་ཡིག་རིངམོ་ཚུ་གསར་བསྐྲུན་འབད་ནི་དང་གསོག་འཇོག་འབད་ནི་ལུ་ ཆོག་ཡིག་འཛིན་སྐྱོང་པ་ལག་ལེན་འཐབ།
- མིང་ཚིག་སྣ་མང་ཆོག་ཡིག་འདི་ དེ་གི་མིང་ཚིག་ཚུ་ ཐོ་ཡིག་ལངམ་སྦེ་སྦོམ་ཡོད་མི་ལས་ གང་བྱུང་སྦེ་སེལ་འཐུ་འབད་བའི་སྐབས་རྐྱངམ་ཅིག་ ལག་ལེན་འཐབ།
- མིང་དང་ཚེས་གྲངས་ ཁ་བྱང་ ལུང་འདྲེན་ ལྡེ་སྒྲོམ་གྱི་དཔེ་རིས་ དེ་ལས་ ལོག་སྟེ་ལག་ལེན་འཐབ་ཡོད་པའི་ཆ་ཤས་ཚུ་ ཆོག་ཡིག་ནང་ལས་ བཏོན་བཞག།
- ཞབས་ཏོག་གིས་ ཐབས་ལམ་དེ་ལུ་རྒྱབ་སྐྱོར་འབད་བའི་སྐབས་ མི་གིས་བཙུགས་ཡོད་པའི་ཆོག་ཡིག་གི་ཚབ་ལུ་ ཞབས་ཏོག་གིས་བཟོ་ཡོད་པའི་ཊོ་ཀེན་ཡང་ན་ གསང་ཡིག་ལྡེ་མིག་ལག་ལེན་འཐབ།

རིང་ཚད་དང་སྔོན་དཔག་མ་ཚུགས་པའི་གནད་དོན་འདི་ མཛེས་རྒྱན་གྱི་ཚབ་མ་ལས་ལྷག་སྟེ་ གལ་ཆེཝ་ཨིན། སྔོན་དཔག་འབད་བཏུབ་པའི་མིང་ཚིག་ལུ་ བརྡ་མཚོན་གཅིག་ཁ་སྐོང་བརྐྱབ་མི་འདི་གིས་ གྲུབ་འབྲས་འདི་ཉེན་སྲུང་མི་བཟོ།

## གསང་ཚིག་ལུ་བརྟེན་པའི་རྩིས་ཐོ་ཚུ་སྲུང་སྐྱོབ་འབད་ནི་ {#protect-password-based-accounts}

- ཕི་ཤིང་ལུ་གདོང་ལེན་འབད་ཚུགས་པའི་ སྣ་མང་རྒྱུ་རྐྱེན་བདེན་བཤད་འདི་ འཐོབ་ཚུགས་ས་ལུ་ ལྕོགས་ཅན་བཟོ།
- བསྐྱར་ལོག་བདེན་བཤད་འཐུས་ཤོར་ཚུ་ལུ་ གོང་ཚད་ཚད་གཞི་དང་ ལྡེ་མིག་སྲིད་བྱུས་ དེ་ལས་ ཉེན་བརྡ་ཚུ་འཇུག་སྤྱོད་འབད།
- ཆོག་ཡིག་ཚུ་ བདེན་བཤད་འབད་ཡོད་པའི་ གསང་བཟོ་འབད་ཡོད་པའི་རྒྱུ་ལམ་ཚུ་བརྒྱུད་དེ་རྐྱངམ་ཅིག་གཏང་།
- ཆོག་ཡིག་དང་སླར་གསོའི་ཨང་རྟགས་ཚུ་ དྲན་ཐོ་དང་བརྡ་བཀོད་གྲལ་ཐིག་ འབྱུང་ཁུངས་མཛོད་ཁང་ རིམ་སྒྲིག་ཡིག་སྣོད་ ཤོག་བྱང་ དེ་ལས་ ཁ་སླབ་ཚུ་ལས་ ཕྱི་ཁར་བཞག།
- སར་བར་ཕྱོགས་ཀྱི་ཆོག་ཡིག་བདེན་དཔྱད་འབད་མི་ཚུ་ ཚྭ་ཅན་དང་དྲན་ཚད་སྲ་ཀྲག་ཆོག་ཡིག་ཧ་ཤིང་ལས་འགན་དང་ བཀྲམ་སྤེལ་ལུ་འོས་འབབ་ཡོད་པའི་ཚད་གཞི་ཚུ་དང་གཅིག་ཁར་ གསོག་འཇོག་འབད།

## གནས་སྡུད་དང་ བསྐྱར་གསོ་ དེ་ལས་ བསྒྱུར་བཅོས་འབད་ནི་ {#storage-recovery-and-replacement}

- གསང་བཟོས་བརྟག་དཔྱད་འབད་ཡོད་པའི་རྒྱབ་ཐག་ཚུ་དང་གཅིག་ཁར་ རྩིས་ཞིབ་འབད་ཡོད་པའི་ཆོག་ཡིག་འཛིན་སྐྱོང་པ་ཅིག་ལག་ལེན་འཐབ།
- སླར་གསོའི་ཨང་རྟགས་ཚུ་ ཁོང་གིས་སླར་གསོ་འབད་མི་ ཐབས་འཕྲུལ་ལས་སོ་སོ་སྦེ་ གསོག་འཇོག་འབད། ཉེན་སྲུང་འབད་ཡོད་པའི་ཨོཕ་ལ་ཡིན་ཤོག་ལེབ་འདྲ་བཤུས་འདི་ སླར་གསོའི་རྒྱུ་ཆའི་དོན་ལུ་འོས་འབབ་ཅན་འོངམ་ཨིན།
- ཆོག་ཡིག་འཛིན་སྐྱོང་པ་ཕྱིར་འདྲེན་དང་རྒྱབ་ཐག་བརྡ་བརྒྱུད་ཚུ་ལུ་འཛུལ་སྤྱོད་ཚད་འཛིན་འབད།
- དོགས་པ་ཅན་གྱི་གསལ་སྟོན་དང་ གནང་བ་མེད་པར་ལོག་ལག་ལེན་འཐབ་མི་ ཡང་ན་ ཚབ་བཙུགས་དགོ་པའི་ སྲིད་བྱུས་བྱུང་ལས་ཅིག་གི་ཤུལ་ལས་ ཆོག་ཡིག་ཅིག་ཚབ་བཙུགས།
- བཟོ་བསྐྲུན་འགོ་མ་བཙུགས་པའི་ཧེ་མ་ རྩིས་ཐོ་-སླར་གསོའི་བྱ་རིམ་ཚུ་བརྟག་དཔྱད་འབད།

::: warning

སྒེར་གྱི་ལྡེ་མིག་ཅིག་ལྡེ་མིག་ཕྱེ་མི་ཆོག་ཡིག་གིས་ ལྡེ་མིག་དེ་གི་ ཕྱིར་བཏོན་འབད་ཡོད་པའི་འདྲ་བཤུས་འདི་ ཉེན་སྲུང་འབད་མི་ཚུགས། སྒེར་གྱི་ལྡེ་མིག་གདོང་ཁར་ཐོན་ནི་གི་དོགས་པ་ཡོད་པ་ཅིན་ བཀྲམ་སྤེལ་གྱི་ལྡེ་མིག་ཚབ་བཙུགས་ནི་ཡང་ན་ ཆ་མེད་གཏང་ནིའི་བྱ་རིམ་འདི་ ལག་ལེན་འཐབ།
