# ལམ་སྟོན་ {#guide}

ཁྱོད་ཀྱིས་ Iroha ལུ་ བཟོ་སྐྲུན་འབད་ནི་དང་ལག་ལེན་འབད་ནི་ ཡང་ན་ འབྲེལ་མཐུད་འབད་ནིའི་སྐབས་ འ་ནི་ཆ་ཤས་འདི་ལག་ལེན་འཐབ་ཨིན། ཁྱོད་ཀྱིས་འགོ་དང་པ་གི་མགྲོན་པ་གི་དོན་ལུ་ SDK སློབ་སྟོན་ཚུ་ནང་ལས་འགོ་བཙུགས་ཞིནམ་ལས་ བརྗེ་སོར་མ་འབད་བའི་ཧེ་མར་ ལག་ལེན་ལེགས་ཤོམ་དང་ ལས་འཛིན་གྱི་ཁ་བྱང་ཚུ་ལུ་འགྱོ་དགོ།

## གྲོས་འཆར་ཅན་གྱི་ལམ་ {#recommended-path}

1. [Iroha 3](/dz/get-started/install-iroha.md) གཞི་བཙུགས་འབད་ཞིནམ་ལས་ [ ས་གནས་ཀྱི་ཁ་ཐུག་ལུ་ མཐུན་རྐྱེན་གཞི་བཙུགས་འབད་ ](/dz/get-started/launch-iroha.md).
2. [SDK ཊུ་རི་ཡཱན་](/dz/guide/tutorials/) གདམ་ཁ་རྐྱབས་ཞིནམ་ལས་ ཚོང་འབྲེལ་ཆུང་བ་ཅིག་བཙུགས་དགོ།
3. གློག་རིམ API མ་བཟོ་བའི་ཧེ་མ་ [ལག་ལེན་བཟོ་སྐྲུན་](/dz/guide/best-practices/application-development.md) དང་ [གནས་སྡུད་བཟོ་རྣམ་](/dz/guide/best-practices/data-modeling.md) བསྐྱར་ཞིབ་འབད།
4. ལག་ལེན་འཐབ་ནི་ [མཐུན་རྐྱེན་ཚུ་ལག་ལེན་འཐབ་ནི་](/dz/guide/best-practices/network-deployment.md), [བཀོལ་སྤྱོད་ཚུ](/dz/guide/best-practices/operations.md),དང་ [ཉེན་སྲུང་དང་འཛུལ་སྤྱོད](/dz/guide/best-practices/security-and-access.md) སྦྲེལ་མཐུད་ཡོད་པའི་ ཡང་ན་ བཟོ་སྐྲུན་འབད་སའི་དྲ་ལམ་མ་ལག་ལེན་འཐབ་པའི་ཧེ་མར་།
5. [གྲ་སྒྲིག་འབད་ནི་](/dz/guide/best-practices/release-readiness.md) གི་རྒྱབ་ལས་ ས་གནས་ཀྱི་གོང་འཕེལ་ལས་ Taira, Minamoto ཡང་ན་ འགྲེམ་ཐོག་ལག་ལེན་གཞན་ཅིག་ལུ་ ཡར་སེང་འབད་བའི་སྐབས་ལུ་ བརྟན་ཏོག་ཏོ་སྦེ་སྡོད་དགོ།
