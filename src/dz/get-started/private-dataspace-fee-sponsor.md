# སྒེར་གྱི་གནས་སྡུད་ཀྱི་དོན་ལུ་ རྒྱབ་སྐྱོར་འཐུས་ {#sponsor-fees-for-a-private-dataspace}

རྩིས་ཐོ་རྒྱབ་སྐྱོར་གིས་ ལག་ལེན་འཐབ་མི་ཚུ་ལུ་ XOR མ་བཟུང་པར་ སྒེར་གྱི་གནས་སྡུད་ཀྱི་ཚོང་འབྲེལ་ཚུ་བཙུགས་ཚུགསཔ་བཟོཝ་ཨིན། ལག་ལེན་པ་འདི་གིས་ཡང་ ཚོང་འབྲེལ་དེ་གུ་ མཚན་རྟགས་གཏངམ་ཨིན། ཚོང་འབྲེལ་གྱི་བརྡ་དོན་འདི་ རྒྱབ་སྐྱོར་རྩིས་ཐོ་ལུ་ཐོ་བཀོད་འབད་ཞིནམ་ལས་ རྒྱུན་འགྲུལ་འཐབ་པའི་དུས་ཚོད་དེ་གིས་ རྒྱབ་སྐྱོར་གྱི་དངུལ་ཀྲམ་ XOR ཕྲང་བའི་འཐུས་སྤྲོད་ནི་ཨིན་མས།

མཉམ་བསྡོམས་འདི་ལུ་འགུལ་སྐྱོད་ཅན་གྱི་ཆ་ཤས་གསུམ་ཡོདཔ་ཨིན།

1. མཐུད་མཚམས་ཀྱིས་འཐུས་རྒྱབ་སྐྱོར་བྱེད་ཆོག
2. རོགས་སྐྱོར་རྩིས་ཐོ་ཡོད་པ་དང་ XOR ཡོད།
3. ལག་ལེན་པ་རེ་རེར་རྒྱབ་སྐྱོར་པ་དེ་གི་དོན་ལུ་ `CanUseFeeSponsor` ཡོད།

དེ་གི་ཤུལ་ལས་ མ་དངུལ་རྒྱབ་སྐྱོར་འབད་མི་ ལག་ལེན་པའི་ཚོང་འབྲེལ་ག་ར་ལུ་ མེ་ཊ་ཌེ་ཊ་འདི་རྐྱངམ་ཅིག་དགོཔ་ཨིན།

```json
{
  "fee_sponsor": "<SPONSOR_ACCOUNT_I105>"
}
```

ཤོག་ངོས་འདིས་སྤྱིར་བཏང་གི་བཀོད་རིས་གཉིས་སྟོན་ཡོད།

- **རིན་མེད་ལག་ལེན་པ་གིས་བྲིས་**: རྒྱབ་སྐྱོར་པ་གིས་ XOR སྤྲོད་དགོཔ་དང་ ལག་ལེན་པ་གིས་ ག་ནི་ཡང་སྤྲོད་མི་བཏུབ།
- **ས་གནས་ཀྱི་ཊོ་ཀེན་འཐུས་**: ལག་ལེན་པ་གིས་ ཨེཔ་ཊོ་ཀེན་ནང་ལས་རྒྱབ་སྐྱོར་པ་ལུ་འཐུས་སྤྲོདཔ་ཨིནམ་ད་ རྒྱབ་སྐྱོར་པ་གིས་དྲ་རྒྱ་ལུ་ XOR ནང་ལས་འཐུས་སྤྲོདཔ་ཨིན།

དང་པ་ར་ Taira ཡང་ན་ སྒེར་གྱི་བརྟག་དཔྱད་འབད་ཐངས་ལག་ལེན་འཐབ་ཨིན། སྒེར་གྱི་གནས་སྡུད་གསརཔ་ཅིག་གིས་ ལག་ལེན་པ་དང་ལམ་ལུགས་བསྒྱུར་བཅོས་འབདཝ་ཨིན་ འདི་མཁོ་ཆས་ཀྱི་སྒྲིག་གཞི་ལུ་བརྟེན་ བཟོ་མི་ཚུགས།

## ༡ ཌེ་ཊ་ས་པི་འདི་ གྲ་སྒྲིག་འབད། {#_1-prepare-the-dataspace}

[ནང་ གསལ་བཀོད་འབད་ཡོད་པའི་ སྒེར་གྱི་གནས་སྡུད་ཡིག་ཐོ་དང་ལམ་སྟོན་ལས་འགོ་བཙུགས་ཏེ་ SORA Nexus ཌེ་ཊ་ས་ཁེསི་](/dz/get-started/sora-nexus-dataspaces.md#_8-provision-a-new-dataspace) ལུ་མཐུད་སྦྲེལ་འབདཝ་ཨིན། ལག་ལེན་པ་ཁ་ཐུག་གི་ཆ་ཤས་འདི་ འདི་བཟུམ་སྦེ་ཨིན།

```toml
[[nexus.lane_catalog]]
index = 5
alias = "team-private"
description = "Private team lane"
dataspace = "team"
visibility = "private"
metadata = {}

[[nexus.dataspace_catalog]]
alias = "team"
id = 42
description = "Private team dataspace"
fault_tolerance = 1

[[nexus.routing_policy.rules]]
lane = 5
dataspace = "team"
[nexus.routing_policy.rules.matcher]
account_prefix = "team."
description = "Route team domains to the private dataspace"
```

ལག་ལེན་པའི་ཚོང་འབྲེལ་ཚུ་ལུ་སྤོ་བཤུད་མ་འབད་བའི་ཧེ་མ་ ཞིབ་དཔྱད་འབད།

- སྒེར་གྱི་ལམ་འདི་ མཐུད་མཚམས་ `/status` ལན་གསལ་ནང་འབྱུངམ་ཨིན།
- ལག་ལེན་པའི་རྩིས་ཐོ་ཚུ་ཁྱོད་ཀྱི་སྒེར་གྱི་ཨོན་བོརཌིང་ཕོལོ་གིས་ ངོས་ལེན་འབད་ཡོདཔ་ཨིན།
- རྒྱབ་སྐྱོར་གྱི་རྩིས་ཐོ་དེ་ཡོདཔ་ཨིན།
- XOR གི་འཐུས་དངུལ་རྐྱང་དང་ དངུལ་རྐྱང་གི་རྩིས་ཐོ་ཚུ་ གྲོག་ཐིག་ནང་ལུ་ ཆ་གནས་ཡོད་ཨིན།

## ཌེ་ཊ་ས་པི་སི་ནང་ལུ་ རྒྱུ་དངོས་ཚུ་ ཐོ་བཀོད་འབདཝ་ཨིན། {#_2-register-assets-in-the-dataspace}

ཁྱོད་ཀྱིས་ གློག་རིམ་ཚད་མ་ནང་ལུ་ གློག་ཐག་མ་བཏང་པའི་ཧེ་མ་ ལག་ལེན་པ་ཚུ་གིས་ སྒེར་གྱི་གནད་སྡུད་ས་སྟོང་ནང་ལུ་ བཞག་ནི་ཨིན་མི་ རྒྱུ་དངོས་ངེས་ཚིག་ཚུ་ ཐོ་བཀོད་འབད། ཉེ་གནས་-ཊོ་ཀེན་འཐུས་དཔེ་རིས་ཀྱི་དོན་ལུ་ སློབ་སྟོན་འདི་གིས་ `usage#billing.team` ལག་ལེན་འཐབ་ཨིན།

```text
<asset-name>#<domain>.<dataspace>
usage#billing.team
```

དང་པ་རང་ རྒྱུ་དངོས མིང་ས་ཁོངས གི་ཇོ་བདག་ཨིན་པའི་ མངའ་ཁོངས དང་ SNS གླ་སྤྱོད གཞི་བཙུགས་འབད། `$BILLING_DOMAIN` གི་དོན་ལུ་གསང་བ་མེད་པའི་ `AliasSetupPlanRequestV1` དགོངས་དོན བཟོ། འདི་ནང་ `team` གི་ གནད་སྡུད་ས་སྟོང ID ཨང་གྲངས་ ཚད་ལྡན ཇོ་བདག་ གླ་སྤྱོད གི་དུས་ཡུན་དང་ གླ་ཡོན་གོང་ཚད སྲུང་སྐྱོབ ད་ལྟོའི་གོང་ཚད་ཚུ་བཙུགས།

```bash
iroha --config ./operator.client.toml \
  app alias setup plan \
  --intent-file ./billing-domain.intent.json \
  --plan-file ./billing-domain.plan.json

iroha --config ./operator.client.toml \
  app alias setup apply --plan-file ./billing-domain.plan.json
```

དེ་ལས་ རྒྱུ་དངོས་ངེས་ཚིག་ཐོ་བཀོད་འབད། ཚད་ལྡན་ `--id` འདི་ ཡོངས་འབྲེལ་གནས་རིམ་རྒྱུ་དངོས་ངེས་ཚིག་ཨའི་ཌི་ཨིན། མིང་གཞན་འདི་ གོང་འཕེལ་གཏང་མི་དང་ མཐའ་མཇུག་ལག་ལེན་པ་ཚུ་གིས་ གནད་སྡུད་ས་སྟོང་ཨང་རྟགས་ནང་ ལག་ལེན་འཐབ་དགོཔ་འདི་ཨིན།

```bash
iroha --config ./operator.client.toml \
  ledger asset definition register \
  --id "$LOCAL_FEE_ASSET_ID" \
  --name usage \
  --alias "$LOCAL_FEE_ASSET" \
  --scale 0
```

བརྡ་མཚོན་འདི་ ལག་ལེན་པ་ཅིག་ལུ་ བརྡ་རྟགས་བཀོད་པའི་སྐབས་ ཡང་ན་ སྤོ་བཤུད་འབད།

```bash
iroha --config ./operator.client.toml \
  ledger asset mint \
  --definition-alias "$LOCAL_FEE_ASSET" \
  --account "$USER" \
  --quantity 100
```

ལག་ལེན་པའི་ལྷག་ལུས་ཞིབ་དཔྱད་འབད།

```bash
iroha --config ./operator.client.toml \
  ledger asset get \
  --definition-alias "$LOCAL_FEE_ASSET" \
  --account "$USER"
```

- ཁ་པར་དང་གློག་འཕྲིན་གནས་གོང་ཚུ་ མིང་གཞན་དང་ མེ་ཊ་ཌེ་ཊ་ དྲན་ཐོ་ ཡང་ན་ ཚོང་འབྲེལ་གྱི་ ནང་དོན་གནད་སྡུད་ཚུ་ནང་ ནམ་ཡང་མི་འབྱུང་།
- རྩིས་ཐོ་འདི་ལུ་ སྒེར་གྱི་ངོས་འཛིན་འབད་མི་ཚུ་ ཐོབ་བརྗོད་བཀོད་པའི་ཧེ་མ་ `uaid` ཡོདཔ་ཨིན།

## 5. མཐུད་མཚམས་ལུ་རྒྱབ་སྐྱོར་ལཱ་ཡོདཔ་བཟོ་ནི་ {#_5-enable-sponsorship-on-the-node}

ཟད་འགྲོ་རྒྱབ་སྐྱོར་དེ་ མཐུད་མཚམས/ལག་བསྟར་མཉེན་ཆས སྲིད་བྱུས་ཨིན། Nexus ཟད་འགྲོ་བཏང་ནིའི་ལམ་ལུགས་ནང་ལུ་འདི་སེལ་འཐུ་འབད།:

གོང་འཕེལ་གཏོང་མཁན་གྱི་ཞིབ་དཔྱད་ཐོ་ཡིག:

1. ལག་ལེན་འཐབ་མི་གི་ རྒྱུན་ཆད་ཅན་གྱི་ཚོང་འབྲེལ་གྱི་ནང་དོན་གནད་སྡུད་འདི་ བསྒྱུར་བཅོས་མེད་པར་བཞག་ནི།
2. `fee_sponsor` དང་ཅིག་ཁར་ ཚོང་འབྲེལ་གྱི་མེ་ཊ་ཌེ་ཊ་ཁ་སྐོང་འབད།
3. ལག་ལེན་འཐབ་མི་སྦེ་རྟགས་བཀོད་རྐྱབས།
4. སྒེར་གྱི་གནས་སྡུད་ས་ཁོངས་ལམ་བརྒྱུད་དེ་ བཏང་གཏང་།

ལག་ལེན་འཐབ་མི་རྩིས་དེ་ དགོས་མཁོ་མེད་ XOR ཟད་འགྲོ་བཏང་མི་གི་རྩིས་ཐོ་དེ་ ལེ་ཤ་བཞག་དགོཔ་ཨིན། XOR བསྡུ་སྒྲིག་འབད་ཡོད་པའི་ Nexus འཐུས་སྤྲོད་ནི་ཨིན་མས།

## ཐབས་ལམ་༢: ལག་ལེན་པ་ཚུ་གིས་ ས་གནས་ཀྱི་བརྡ་རྟགས་སྤྲོད་ཨིན། {#pattern-2-users-pay-a-local-token}

འདི་ལག་ལེན་འཐབ་ནི་དེ་ ལག་ལེན་པ་ཚུ་གིས་ XOR མ་བཟུང་རུང་ ཌེ་ཊ་ས་པི་སི་གིས་ ད་ལྟོའི་བར་ན་ཡང་ ནང་འཁོད་གི་ ལག་ལེན་མཉེན་ཆས འཐུས, བུ་ལོན་ ཟད་འགྲོ་གཏང་ནི་, ཡང་ན་ བགོ་ཚད བརྡ་རྟགས དགོཔ་ཨིན།

འདི་ནང་ལུ་ ས་གནས་ཀྱི་རྟགས་མཚན་འདི་ ཐོ་བཀོད་གྱི་གླ་འཐུས་ཨིན། འདི་གིས་ གྲོག་ཐིག་གི་གླ་ཆ་མ་ཡིན། རྒྱབ་སྐྱོར་འདི་གིས་ XOR ལུ་ ཡོངས་འབྲེལ་གྱི་གླ་ཆ་སྤྲོད་དོ་ཡོདཔ་ཨིན།


1. ས་གནས་ཀྱི་རྟགས་མཚན་ཚུ་ ལག་ལེན་པ་ལས་ རྒྱབ་སྐྱོར་མི་ལུ་ བཏབ་ནི།
2. ཞུ་བ་འབད་ཡོད་པའི་ཨེཔ་བཀོལ་སྤྱོད་འདི་འབད།

ཉུང་མཐའ་ CLI འགོ་ཐོག བརྟག་དཔྱད་འདི་ XOR གིས་རྒྱབ་སྐྱོར་འབད་མི་ ས་གནས་ཀྱི་རྟགས་མཚན་སྤེལ་འབད་ནི་རྐྱངམ་གཅིག་ཨིན།

མ་དངུལ་རྒྱབ་སྐྱོར་འབད་མི་འདི་ དངུལ་ཁང་གི་རྩིས་ཐོ་ཅིག་སྦེ་བརྩི་དགོ།

- བརྟག་དཔྱད་ནེཊ་དང་ འཁྲབ་སྟོན་ དེ་ལས་ ནེཊ་གཙོ་བོ་ཚུ་གི་དོན་ལུ་ རྒྱབ་སྐྱོར་ལྡེ་མིག་སོ་སོ་བཞག།
- མ་དངུལ་རྒྱབ་སྐྱོར་འབད་མི་ XOR ལྷག་ལུས་འདི་ འཛུལ་ཞུགས་ཐོག་ཁར་མ་ལྷོད་པའི་ཧེ་མ་ ཉེན་བརྡ།
- འགྲུལ་སྐྱོད་འདི་ཁྱད་ཆོས་བཏོན་ཚར་བའི་ཤུལ་ལས་ ཀླད་ཀོར་མེན་པའི་ `sponsor_max_fee` མཐའ་མཚམས་ཅིག་གཞི་སྒྲིག་འབད།
- ཁྱོད་རའི་གློག་རིམ་ཡང་ན་སྒོ་སྒྲིག་ནང་ལུ་ ཚད་གཞི་རྒྱབ་སྐྱོར་འབད་མི་འབྲིཝ་ཨིན།
- ལག་ལེན་པ་ཚུ་གིས་ གནད་སྡུད་ས་སྟོང་བཞག་པའི་སྐབས་ `CanUseFeeSponsor` ཆ་མེད་གཏང་།
- ལག་ལེན་འཐབ་མི་ ཌེ་བི་ཊར་ནེགསི་ (བསྡུས་རྟགས་ཚུ) དང་ ས་གནས་ཀྱི་ ཐོ་ཀིན་སྤྲོད་ལེན་དང་ རྒྱབ་སྐྱོར་འབད་མི་ཚུ་ མཐུན་རྐྱེན་བཟོ་ནི། XOR དངུལ་ཕོགས་ཚུ་

ལག་ལེན་པ་ཅིག་གི་དོན་ལུ་ མ་དངུལ་རྒྱབ་སྐྱོར་འདི་ ཆ་མེད་གཏང་།

```bash
printf '{
  "name": "CanUseFeeSponsor",
  "payload": {
    "sponsor": "%s"
  }
}\n' "$SPONSOR" |
  iroha --config ./sponsor.client.toml \
    ledger account permission revoke --id "$USER"
```
