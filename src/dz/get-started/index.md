# Iroha 3 {#iroha-3}

Iroha 3 འདི་འགོ་དང་པ་བཏང་མི་ Hyperledger Iroha སྟབས་བདེ་ཐང་ཨིན། དེ་གིས་ རང་གིས་རང་ལུ་གཞི་བཙུགས་འབད་ཡོད་པའི་དྲ་ལམ་དང་ མང་ཤོས་ཀྱི་གནས་སྡུད་ SORA Nexus གཞི་རྟེན་གཞི་རྩ་ལས་ལག་ལེན་འཐབ་ནིའི་རྣམ་གཞག་ཚུ་ རྒྱབ་སྐྱོར་འབདཝ་ཨིན།

གནས་ཚད་མཐོ་ཤོས་ལུ་ Iroha 3 འདི་ནང་ལུ་:

- གཏན་འབེབས་ལག་བསྟར་དང་གསོག་འཇོག
-  Iroha གཟུགས་བརྙན་འཕྲུལ་ཆས་ (IVM) འཁྱེར་ཐུབ་པའི་རིག་རྩལ་གྱི་གན་རྒྱ་ཚུ་གི་དོན་ལུ་
- Norito འདི་ ཀ་ནོ་ནི་ཀཱལ་གྱི་གནས་སྤོ་རྩ་སྒྲིག རྩ་སྒྲིག་སྦེ་ཨིན།
- Torii ཚོང་མགྲོན་པ་དང་ ལས་འཛིན་པ་ དེ་ལས་ བརྒྱུད་འཕྲིན་ཁ་ཐུག་གི་དོན་ལུ་ APIs
- Sumeragi གྲོས་བསྟུན་འབད་དགོ་པའི་ གནས་སྡུད་ཚུ་དང་ ཡིད་ཆེས་ཅན་གྱི་ བརྒྱུད་འཕྲིན་ཚུ་
- མི་གིས་ལྷག་ཚུགས་པའི་མིང་གཞན་ཚུ་ སོ་སོ་སྦེ་བསྡམ་ཡོད་པའི་ མངའ་ཁོངས་མེད་པའི་ ཚད་ལྡན་རྩིས་ཐོ་ཚུ།
