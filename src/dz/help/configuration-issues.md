## Docker Compose གཞི་སྒྲིག་ནང་ལུ་ དུས་རྒྱུན་གྱི་འབྱུང་ཁུངས། {#outdated-genesis-on-a-docker-compose-setup}

ཁྱོད་ཀྱིས་ Iroha གི་ Docker Compose འདྲ་བཤུས་ལག་ལེན་འཐབ་པའི་སྐབས་ལུ་ ཁྱོད་ཀྱིས་ `Failed to deserialize raw genesis block` གྱི་འཛོལ་བ་དང་འབྲེལ་བའི་ འདྲན་འདྲ་ container ཅིག་གི་འཛོལ་བ་མཐོང་འོང་། འདི་གི་སྐོར་ལས་ མང་ཤོས་ར་ འདྲན་འདྲན་འདྲ་, ངོ་རྟགས་བཀོད་མི་ genesis transaction དང་ generated config བཟོ་སྐྲུན་འདི་ Iroha འདྲ་བཤུས། ཡང་ན་ profile ཚུ་གིས་བཟོཝ་ཨིན་མས།

གྲུབ་འབྲས་འདི་སེལ་འཐུ་འབད་ནིའི་ཐབས་ལམ་འདི་ཨིན:

1. `docker ps` ལག་ལེན་འཐབ་སྟེ་ ད་ལྟོའི་སྣོད་ཆས་ཚུ་ བརྟག་ཞིབ་འབད་ཚུགས། ཐོན་སྐྱེད་འབད་མི་གི་ཐོ་ཡིག་དང་འཁྲིལ་ཏེ་ ཁྱོད་ཀྱིས་ སྤྱིར་བཏང་ལུ་ `hyperledger/iroha:dev`སྣོད་ཆས་མཐོང་འོང་། སྔོན་སྒྲིག་ Docker Compose གི་ཐོ་ཡིག་ནང་ལུ་ འདྲན་འདྲ་སྣོད་ཆས་༤ ཡོདཔ་ཨིན་ ཨིན་རུང་ ཁྱོད་ཀྱིས་ ཐོན་སྐྱེད་འབད་མི་ `docker-compose.yml` འདི་སོ་སོ་སྦེ་འབྱུང་འོང་།

2. ཐོ་བཀོད་ཐོ་ཡིག་ཚུ་ བརྟག་ཞིབ་འབད་ཞིནམ་ལས་ `Failed to deserialize raw genesis block` གྱི་འཛོལ་བ་འཚོལ་ပါ။ ཁྱོད་ཀྱིས་ Iroha འདི་ Daemon Modeནང་ལུ་ `docker compose up -d` ལུ་འགོ་བཙུགས་པ་ཅིན་, `docker compose logs` བཀའ་རྒྱ་ལག་ལེན་འཐབ་དགོ།

གནད་དོན་འདི་སེལ་ནིའི་ཐབས་ལམ་དེ་ Iroha གི་ལག་ལེན་འཐབ་ཐངས་ལས་བབས་ཏེ་ཡོདཔ་ཨིན། འ་ནི་གཞི་རྟེན་དཔེ་སྟོན་ཅིག་ཨིན་པ་ཅིན་ ཁྱོད་ཀྱིས་ འདྲན་འདྲ་ཡིག་ཆ་ཚུ་བཞག་དགོཔ་མེད་པ་ཅིན་ localnet ཡང་ན་ Docker Compose སྦ་སྒོར་འདི་ Kagami ལུ་སླར་གསོ་འབད་:

```bash
cargo run --bin kagami -- localnet --build-line iroha3 --peers 4 --out-dir ./localnet
cargo run --bin kagami -- docker --peers 4 --config-dir ./localnet --image hyperledger/iroha:dev --out-file ./docker-compose.yml
```

དེ་ལས་ container གི་གནས་སྟངས་རྙིངམ་འདི་བཏོན་ཏེ་ སླར་ལོག་འབད་ཡོད་པའི་ `genesis.signed.nrt`, peer `config.toml` དང་ `client.toml` ཌའི་ལོག་ཚུ་ནང་ལས་འགོ་བཙུགས་འོང་།

ཁྱོད་ཀྱིས་ Iroha འདྲ་བཤུས་ཀྱི་གནས་སྡུད་སླར་གསོ་འབད་དགོ་པ་ཅིན་ འདི་བཟུམ་སྦེ་འབད་བ་ཅིན་:

1. ཨང་གཉིས་པ་ Iroha འདྲན་འདྲ་དེ་མཐུད་སྦྲེལ་འབད་ཞིནམ་ལས་ ཨང་དང་པ་གི་ (མ་གྲུབ་པའི་) འདྲན་ཚད་ལས་ བརྡ་དོན་ཚུ་ བཏོན་གཏང་འོང་།
2. གྲྭ་ཚང་གསརཔ་དེ་གིས་ གནད་དོན་ཚུ་ འགོ་དང་པ་གི་ གྲྭ་ཚང་དང་གཅིག་ཁར་ དུས་མཐུན་བཟོ་ནི་གི་དོན་ལུ་སྒུག་སྡོད་དགོ།

## སྒེར་གྱི་དང་ མི་མང་གི་ལྡེ་མིག་ཚུ་གི་ མલ્ટિ-ཧེཤ་བཟོ་རྣམ་ {#multihash-format-of-private-and-public-keys}

ཁྱོད་ཀྱིས་ [ client configure](/dz/guide/configure/client-configuration.md) ལུ་བལྟ་བ་ཅིན་ ཁྱོད་ཀྱིས་མཐོང་འོང་ འདི་ནང་ལུ་ལྡེ་མིག་ཚུ་ [multi-hash format](https://github.com/multiformats/multihash)ནང་ལུ་བཀོད་ཡོདཔ་ཨིན།

གལ་སྲིད་ ཁྱོད་ཀྱིས་ ཧེ་མ་ལས་ multi-hash ལག་ལེན་འཐབ་མ་མྱོང་པ་ཅིན་ ཁྱོད་ཀྱི་གཡས་ཁ་ཐུག་ལུ་ key bytes (byte ལུ་ རྟགས་མཚན་གཉིས་) གི་ hexadecimal ངོ་ཚབ་མེན་རུང་ ASCII (ཡང་ན་ UTF-8) ཟེར་བཀོད་ཡོད་པའི་ bytes ཨིན་ཟེར་ མནོ་བསམ་གཏང་ནི་དེ་ རང་བཞིན་ཅིག་ཨིན། དེ་ལས་ `public_key` དང་ `private_key` གཉིས་ཆ་ར་ནང་ string literal ལུ་ `from_hex` ལུ་འབོ་འབད།

འདི་བཟུམ་སྦེ་ `PrivateKey::try_from_str` ལུ་ བརྒྱུད་འབུད་འབད་བ་ཅིན་ ཨེབ་ལྡེ་འདི་བདེན་པའི་ལྡེ་མིག་རྐྱངམ་ཅིག་ཐོན་འོང་ཟེར་ མནོ་བསམ་གཏང་ནི་དེ་ཡང་ རང་བཞིན་ཨིན་ དེ་འབདཝ་ལས་ ཁྱོད་ཀྱིས་ལྡེ་མིག་ནང་ བི་ཊ་གི་གྱངས་ཁ་མ་བདེཝ་སྦེ་ཐོབ་པ་ཅིན་ དཔེར་ན་ 32 bytes vs 64, འདི་གིས་འཛོལ་བ་བརྡ་དོན་འབྱུང་འོང་།

འ་ནི་བསམ་ཚུལ་གཉིས་ཆ་ར་ཡང་མ་བདེཝ་ཨིན། ཚ་གྱང་ལང་སྟེ་འབད་བ་ཅིན་ འཛོལ་བ་གྱི་ བརྡ་དོན་ཚུ་གིས་ འདི་བཟུམ་གྱི་འཛོལ་བ་ཚུ་ སེལ་ནི་ལུ་ ཕན་ཐོགས་མི་འབྱུང་།

སེལ་འཐུ་འབད་ནིའི་ཐབས་ལམ་: `hex_literal` ལག་ལེན་འཐབ་ནི་ འདི་ཡང་ རྟགས་མཚན་གི་ཐིག་ཁྲམ་ཞེན་ལོག་ཅན་ཅིག་ལུ་ དྲུག་བཅུ་ལྡང་གི་ཨང་གྲངས་ཚུ་ཡོད་པའི་ལྕོག་སྒྲོམ་ཆུང་ཀུ་ཅིག་སྦེ་འགྱུར་འོང་།
