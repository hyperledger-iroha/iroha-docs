# གྲོས་སྒྲིག་གི་དཀའ་ངལ་སེལ་ཐབས། {#troubleshooting-configuration-issues}

འ་ནི་ཐིག་ཁྲམ་འདི་ Iroha 3 སྒྲིག་གཞི་གི་དོན་ལུ་ དཀའ་ངལ་སེལ་ཐབས་ཀྱི་བསླབ་བྱ་ཚུ་ གྲོས་འདེབས་འབདཝ་ཨིན། ཁྱོད་ཀྱིས་འགོ་དང་པ་ [ ལྡེ་མིག་](./overview.md#check-the-keys) བརྟག་ཞིབ་འབད་ཡོདཔ་ ངེས་བརྟན་བཟོ། ག་ཅི་སྨོ་ཟེར་བ་ཅིན་ འདི་གིས་ Iroha ནང་གི་དཀའ་ངལ་མང་ཤོས་ཅིག་ཨིན།

གལ་སྲིད་ ཁྱོད་ལུ་བྱུང་བའི་དཀའ་ངལ་འདི་ ནཱ་ལུ་མ་བཤད་པ་ཅིན་ [Telegram](https://t.me/hyperledgeriroha) ཟེར་མི་ཁ་ཐུག་ལས་ ང་བཅས་དང་གཅིག་ཁར་འབྲེལ་བ་འཐབ་དགོ།

## Docker Compose གཞི་སྒྲིག་ནང་ལུ་ དུས་རྒྱུན་གྱི་འབྱུང་ཁུངས། {#outdated-genesis-on-a-docker-compose-setup}

ཁྱོད་ཀྱིས་ Iroha གི་ Docker Compose འདྲ་བཤུས་ལག་ལེན་འཐབ་པའི་སྐབས་ལུ་ ཁྱོད་ཀྱིས་ `Failed to deserialize raw genesis block` གྱི་འཛོལ་བ་དང་འབྲེལ་བའི་ མཐུད་མཚམས་ སྣོད ཅིག་གི་འཛོལ་བ་མཐོང་འོང་། འདི་གི་སྐོར་ལས་ མང་ཤོས་ར་ མཐུད་མཚམསན་འདྲ་, ངོ་རྟགས་བཀོད་མི་ འགོ་ཐོག ཚོང་འབྲེལ དང་ བཟོ་སྐྲུན་འབད་ཡོད རིམ་སྒྲིག བཟོ་སྐྲུན་འདི་ Iroha འདྲ་བཤུས། ཡང་ན་ གསལ་སྡུད ཚུ་གིས་བཟོཝ་ཨིན་མས།

ངེས་དཔྱད་འབད་མི་ཚུ་གི་དྲན་ཐོ་བལྟ་ནིའི་དོན་ལུ་ ལག་ཆའི་སྣོད་ཐོ་ནང་ལས་ `python3 poc.py logs` ལག་ལེན་འཐབ། Docker ནང་གཞི་རྟེན་ཨང་རྟགས་ཀྱི་ཐོན་རིམ་གཅིག་ལས་བཟོ་ཡོད་པའི་ཡིག་སྣོད་ཚུ་ལག་ལེན་འཐབ་སྟེ་ ངེས་དཔྱད་འབད་མི་བཞི་འགོ་བཙུགས་ནིའི་དོན་ལུ་ [འགོ་བཙུགས Iroha 3](/dz/get-started/launch-iroha.md) ལམ་སྟོན་ལུ་གཟིགས།

ཡོངས་འབྲེལ་དེ་ཉིད་ལོག་འགོ་བཙུགས་ནིའི་དོན་ལུ་ `python3 poc.py down` དང་དེ་ལས་ `python3 poc.py up` ལག་ལེན་འཐབ། `state/` འདི་ Docker གི་གསོག་འཇོག་བཞི་དང་གཅིག་ཁར་བཞག།

::: info

ཐད་རི་བ་རི་ཡོངས་འབྲེལ་ནང་ རིགས་མཚན་ཚབ་བཙུགས་ནིའི་དོན་ལུ་ སྤྱིར་བཏང་རང་བཞིན་བསྐྱར་འབྲི་འགྲུལ་ལམ་མེདཔ་ཨིན། འདི་ལུ་ མཉམ་འབྲེལ་གྱི་གནས་སྤོ་ཅིག་སྦེ་ བརྩི་འཇོག་འབད་: གནས་སྟངས་རྙིངམ་འདི་ ཉམས་སྲུང་འབད་ནི་དང་ མཐུན་སྒྲིག་ཅན་གྱི་མཉམ་རོགས་ཚུ་འབག་འོང་ དེ་ལས་ བཀོལ་སྤྱོད་པ་ཚུ་གིས་ གནས་སྤོ་འཆར་གཞི་ལུ་ མོས་མཐུན་འབད་བའི་ཤུལ་ལས་ བདེན་དཔྱད་འབད་མི་ཚུ་ རིམ་སྒྲིག་གསརཔ་ལུ་རྐྱངམ་ཅིག་ སྤོ་བཤུད་འབད།

## སྒེར་གྱི་དང་ མི་མང་གི་ལྡེ་མིག་ཚུ་གི་ multihash་བཟོ་རྣམ་ {#multihash-format-of-private-and-public-keys}

ཁྱོད་ཀྱིས་ [ ཞབས་ཏོག་ལེན་མི རིམ་སྒྲིག་འབད](/dz/guide/configure/client-configuration.md) ལུ་བལྟ་བ་ཅིན་ ཁྱོད་ཀྱིས་མཐོང་འོང་ འདི་ནང་ལུ་ལྡེ་མིག་ཚུ་ [ཧེ་ཤི་སྣ་མང་རྣམ་གཞག](https://github.com/multiformats/multihash)ནང་ལུ་བཀོད་ཡོདཔ་ཨིན།

གལ་སྲིད་ ཁྱོད་ཀྱིས་ ཧེ་མ་ལས་ སྣ་མང-བསྡུས་རྟགས ལག་ལེན་འཐབ་མ་མྱོང་པ་ཅིན་ ཁྱོད་ཀྱི་གཡས་ཁ་ཐུག་ལུ་ ལྡེ་མིག བཱའིཊི་ཚུ (བཱའིཊི ལུ་ རྟགས་མཚན་གཉིས་) གི་ བཅུ་དྲུག་རྟེན ངོ་ཚབ་མེན་རུང་ ASCII (ཡང་ན་ UTF-8) ཟེར་བཀོད་ཡོད་པའི་ བཱའིཊི་ཚུ ཨིན་ཟེར་ མནོ་བསམ་གཏང་ནི་དེ་ རང་བཞིན་ཅིག་ཨིན། དེ་ལས་ `public_key` དང་ `private_key` གཉིས་ཆ་ར་ནང་ ཡིག་རྒྱུན ཐད་ཀར་གནས་གོང ལུ་ `from_hex` ལུ་འབོ་འབད།

ཡིག་རྒྱུན་ཚིག་ཡིག་གུ་ `PrivateKey::try_from_str` འབོ་མི་འདི་གིས་ ལྡེ་མིག་ངེས་བདེན་རྐྱངམ་ཅིག་ཐོན་འོང་ཟེར་ མནོ་བསམ་གཏང་ནི་འདི་ཡང་ རང་བཞིན་ཅིག་ཨིན། དེ་འབདཝ་ལས་ ཁྱོད་ཀྱིས་ ལྡེ་མིག་ནང་ བིཊི་གི་གྱངས་ཁ་འཛོལ་བ་ཐོབ་པ་ཅིན་ དཔེར་ན། 32 བཱའིཊི་ཚུ དང་གི་ཁྱད་པར 64, དེ་གིས་ འཛོལ་བའི་འཕྲིན་དོན་ཅིག་ ཡར་སེང་འབད་འོང་།

འ་ནི་བསམ་ཚུལ་གཉིས་ཆ་ར་ཡང་མ་བདེཝ་ཨིན། ཚ་གྱང་ལང་སྟེ་འབད་བ་ཅིན་ འཛོལ་བ་གྱི་ བརྡ་དོན་ཚུ་གིས་ འདི་བཟུམ་གྱི་འཛོལ་བ་ཚུ་ སེལ་ནི་ལུ་ ཕན་ཐོགས་མི་འབྱུང་།

**བདེ་སྒྲིག་འབད་ཐངས**: `hex_literal` ལག་ལེན་འཐབ། འདི་གིས་ ཡིག་འབྲུ་ཚུ་གི་ཡིག་རྒྱུན་མཛེས་མ་འདི་ གསལ་ཏོག་ཏོ་སྦེ་ ཧེག་ས་ཌི་སི་མཱལ་ཨང་གྲངས་ཚུ་གི་ ཐིག་ཁྲམ་ཆུང་ཀུ་ལེགས་ཤོམ་ཅིག་ལུ་ཡང་ བསྒྱུར་བཅོས་འབད་འོང་།

::: warning

`try_from_str` ལག་ལེན་འཐབ་མི་འདི་གིས་ཡང་ བྱིན་ཡོད་པའི་ཡིག་རྒྱུན་འདི་ ནུས་ཅན་`PrivateKey` ཨིན་པ་ཅིན་ བདེན་དཔྱད་འབད་མི་ཚུགས་ནི་ཨིནམ་དང་ དེ་མེན་པ་ཅིན་ ཁྱོད་ལུ་ཉེན་བརྡ་འབདཝ་ཨིན།

འདི་གིས་ མངོན་གསལ་ཅན་གྱི་འཛོལ་བ་ལ་ལུ་ཅིག་བཟུང་འོང་ དཔེར་ན། ཡིག་རྒྱུན་ནང་ལུ་ ནུས་མེད་བརྡ་མཚོན་ཅིག་ཡོད་པ་ཅིན་ཨིན། ཨིན་རུང་ ང་བཅས་ཀྱིས་ ལྡེ་མིག་རྩ་སྒྲིག་ལེ་ཤ་ཅིག་ལུ་རྒྱབ་སྐྱོར་འབད་ནི་ལུ་དམིགས་གཏད་བསྐྱེདཔ་ལས་ གཞན་ག་ནི་ཡང་འབད་མི་ཚུགས། ཁྱོད་ཀྱིས་བཀོད་རྒྱ་ཅིག་མ་བཙུགས་ཚུན་ཚོད་ ལྡེ་མིག་འདི་ བྱིན་ཡོད་པའི་རྩིས་ཐོ་_གི་དོན་ལུ་ _ངེས་བདེན_ སྒེར་གྱི་ལྡེ་མིག་_ཨིན་ན་མེན་ན་ སླབ་མི་ཚུགས།

:::

འདི་བཟུམ་གྱི་འཛོལ་བ་ཕྲ་མོ་ཚུ་ དཔེར་ན་ ཡིག་རྒྱུན་ཚིག་ཡིག་ཚུ་ལས་ ཐད་ཀར་དུ་ རིམ་སྒྲིག་འབད་ནི་དང་ ཡང་ན་ དེ་གིས་ དོན་དག་ཡོད་པའི་ས་ཁོངས་ཚུ་ནང་ ལྡེ་མིག་ཆ་གསརཔ་ཅིག་ བཟོ་བཏོན་འབད་ཐོག་ལས་ བཀག་ཚུགས།
