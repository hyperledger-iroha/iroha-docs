# མཐུན་རྐྱེན་གྱི་དཀའ་ངལ་སེལ་འཐུ་འབད་ {#troubleshooting-integration-issues}

འ་ནི་ཐིག་ཁྲམ་འདི་ནང་ལུ་ Iroha 3 འབྲེལ་གཏོགས་འབད་ནི་ལུ་ དཀའ་ངལ་སེལ་ཐབས་ཀྱི་བསླབ་བྱ་ཚུ་ གྲོས་འདེབས་འབདཝ་ཨིན། ཁྱོད་ཀྱིས་མྱོང་དོ་ཡོད་པའི་དཀའ་ངལ་འདི་འདི་འདི་ནང་ལུ་ གསལ་བཀོད་མེནམ་ཨིན་པ་ཅིན་ ང་བཅས་དང་གཅིག་ཁར་ [Telegram](https://t.me/hyperledgeriroha) གི་ཐོག་ལས་འབྲེལ་བ་འཐབ་གནང་།

## ཚོང་མགྲོན་པ་གིས་ བརྒྱུད་འབྲེལ་འབད་མ་ཚུགས། {#client-cannot-connect}

ཁྱོད་ཀྱིས་ ཞབས་ཏོག་ལེན་མི རིམ་སྒྲིག འདི་ མཉམ་རོགས གི་ Torii ཌའི་ལེནཌ་ལུ་ བཏོན་ཨིན་ན་བརྟག་དཔྱད་འབད་:

```toml
torii_url = "http://127.0.0.1:8080/"
```

CLI བརྟག་དཔྱད་ཚུ་གི་དོན་ལུ་ ཌའི་ལོག་གི་ཡིག་སྣོད་དེ་ གསལ་ཏོག་ཏོ་སྦེ་གཏང་དགོ།

```bash
cargo run --bin iroha -- --config ./localnet/client.toml ledger domain list all
```

ཡོངས་འབྲེལ་ཆ་རོགས་འདི་ Docker ཡང་ན་ Kubernetes ནང་ལུ་གཡོག་བཀོལ་བ་ཅིན་ མཁོ་སྤྲོད་འབད་མི་བྱ་རིམ་ལས་ ལྷོད་ཚུགས་པའི་ ཧོསིཊི་ཡང་ན་ ཞབས་ཏོག་ཁ་བྱང་འདི་ལག་ལེན་འཐབ། `127.0.0.1` ནང་ཁུལ་གྱི་དོས་ཁང་འདི་གཙོ་བོ་འཕྲུལ་ཆས་མིན།

མི་མང་གི་བརྟག་དཔྱད་ Taira གི་དོན་ལུ་ ཐོ་བཀོད་མ་འབད་མི་ མཐའ་མཇུག་གི་རྟགས་དཔྱད་འདི་འགོ་དང་པ་བཙུགས་དགོ།

```bash
curl -fsS -H 'Accept: application/json' https://taira.sora.org/status \
  | jq '{blocks, txs_approved, txs_rejected, queue_size, peers}'

curl -fsS 'https://taira.sora.org/v1/domains?limit=5' \
  | jq -r '.items[].id'
```

བརྡ་བཀོད་འདི་ཚུ་ `502`, TLS, DNS, ཡང་ན་ དུས་ཚོད་རྫོགས་པའི་འཛོལ་བ་ཚུ་དང་གཅིག་ཁར་ འཐུས་ཤོར་བྱུང་པ་ཅིན་ ཡོངས་འབྲེལ་ལྷོད་ཚུགས་མི་འདི་ བདེ་སྒྲིག་འབད་ ཡང་ན་ རྩིས་ཐོའི་ལྡེ་མིག་ཚུ་ ཡང་ན་ བརྗེ་སོར་གྱི་ནང་དོན་གནད་སྡུད་ཚུ་ རྐྱེན་སེལ་མ་འབད་བའི་ཧེ་མ་ མི་མང་བརྟག་དཔྱད་ནེཊི་མཇུག་སྣོད་ལུ་བསྒུག་སྡོད།

## ཚོང་འབྲེལ་ཚུ་མ་བཏུབ་བཟོ། {#transactions-are-rejected}

ཚོང་འབྲེལ་འཐུས་ཤོར་མང་ཤོས་རང་ངོ་རྟགས་ཡང་ན་གནང་བ་མི་མཐུན་པའི་རྐྱེན་གྱིས་བྱུང་ཡོད།

- མཁོ་སྤྲོད་འབད་མི་རིམ་སྒྲིག་ནང་ རྩིས་ཐོའི་མི་མང་ལྡེ་མིག་འདི་ མིང་རྟགས་བཀོད་ནིའི་དོན་ལུ་ལག་ལེན་འཐབ་མི་ སྒེར་གྱི་ལྡེ་མིག་དང་མཐུན་སྒྲིག་མི་འབད།
- རྩིས་ཐོ་འདི་ རིགས་མཚན་ནང་ ཡང་ན་ སྔོན་འགྲོའི་ཚོང་འབྲེལ་གྱི་ཐོག་ལས་ ཐོ་བཀོད་འབད་དེ་མེདཔ་ཨིན།
- རྩིས་ཐོ་འདི་ལུ་ རན་ཊའིམ་བདེན་བཤད་འབད་མི་གིས་དགོ་པའི་གནང་བ་ཊོ་ཀེན་ཡང་ན་འགན་ཁུར་མེདཔ་ཨིན།
- མངའ་ཁོངས་ཨའི་ཌི་ཅིག་ལུ་ `domain.dataspace` བཟུམ་གྱི་ གནད་སྡུད་ས་སྟོང་ཤེས་ཚད་མེདཔ་ཨིན།

ཁྱོད་ཀྱིས་ `--output-format text` ལག་ལེན་འཐབ་སྟེ་ CLI བཀའ་རྒྱ་ཚུ་ཉམས་བཅོས་འབད་བའི་སྐབས་ལུ་ འཛོལ་བ་ཚུ་ལྷག་ནི་ལུ་འཇམ་ཏོང་ཏོ་ཨིན།

```bash
cargo run --bin iroha -- --config ./localnet/client.toml --output-format text ledger transaction ping --msg "hello"
```

## ཞིབ་འཚོལ་འདི་གིས་ གྲུབ་འབྲས་སྟོང་པ་ཅིག་ བཏང་ཨིན། {#queries-return-empty-results}

འདྲི་དཔྱད་གྲུབ་འབྲས་སྟོངམ་འདི་གིས་ དུས་རྒྱུན་དུ་འདྲི་དཔྱད་འཐུས་ཤོར་བྱུང་ཡོདཔ་སྦེ་མི་སྟོན། དབྱེ༌ཞིབ:

- དངོས་པོ་གསར་བསྐྲུན་འབད་དགོ་པའི་ཚོང་འབྲེལ་འདི་ཁས་བླངས་འབད་ཡོདཔ་ཨིན།
- འདྲི་དཔྱད་འབད་ཡོད་པའི་མངའ་ཁོངས་ རྒྱུ་དངོས་ངེས་ཚིག་ ཡང་ན་ རྩིས་ཐོའི་ཨའི་ཌི་འདི་ ཚད་ལྡན་ཨིན།
- ཤོག་ལེབ་བཟོ་ནི་ཡང་ན་ཚགས་མ་ཚུ་ རེ་བ་བསྐྱེད་ཡོད་པའི་གྲལ་ཐིག་འདི་ཕྱིར་བཏོན་འབད་མི་བཏུབ།
- མཁོ་སྤྲོད་འབད་མི་འདི་ དམིགས་གཏད་ཅན་གྱི་ཡོངས་འབྲེལ་ལུ་མཐུད་དེ་ཡོདཔ་ཨིན་ གཞན་མི་ལོ་ཀཱལ་ནེཊི་ལུ་མེན།

མངའ་ཁོངས་ཞིབ་དཔྱད་ཚུ་གི་དོན་ལུ་ འདྲི་དཔྱད་རྒྱ་ཆེ་ཤོས་ལས་འགོ་བཙུགས།

```bash
cargo run --bin iroha -- --config ./localnet/client.toml ledger domain list all
```

## འབྱུང་རྐྱེན་དང་མ་མཐུན་པའི་རྒྱུན་ཚུ་ དུས་ཡུན་རིངམོ་སྦེ་མཚམས་འཇོག་འབདཝ་ཨིན། {#event-or-block-streams-stop-early}

བཀྲམ་སྤེལ་དང་ འབྱུང་རྐྱེན་འབྱུང་རིམ་གྱི་དཔེ་སྟོན་ཚུ་ Torii རྒྱུན་འགྲུལ་མཇུག་གི་ཐོ་བཀོད་ལུ་བརྟེན་ཨིན། མཐུད་མཚམས་དེ་ ད་ལྟོའི་བར་ན་ཡང་ལག་ལེན་འཐབ་སྟེ་ཡོདཔ་ཨིན་ན་བརྟག་དཔྱད་འབད་ཞིནམ་ལས་ དུས་ཡུན་འགོར་ཐོག་ལས་ བརྟག་དཔྱད་འབད་:

```bash
cargo run --bin iroha -- --config ./localnet/client.toml ledger blocks 1 --timeout 30s
cargo run --bin iroha -- --config ./localnet/client.toml ledger events block
```

HTTP འབྲེལ་མཐུད་ཚུ་གི་དོན་ལུ་ ཁྱོད་ཀྱི་མཐའ་མཇུག་གི་ཐིག་ལམ་འདི་ ད་ལྟོའི་ [Torii མཐའ་མཇུག་གི་ཐོ་བཀོད་དང་བསྡུར་འབད་](/dz/reference/torii-endpoints.md).
