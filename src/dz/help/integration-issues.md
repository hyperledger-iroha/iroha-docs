# མཐུན་རྐྱེན་གྱི་དཀའ་ངལ་སེལ་འཐུ་འབད་ {#troubleshooting-integration-issues}

འ་ནི་ཐིག་ཁྲམ་འདི་ནང་ལུ་ Iroha 3 འབྲེལ་གཏོགས་འབད་ནི་ལུ་ དཀའ་ངལ་སེལ་ཐབས་ཀྱི་བསླབ་བྱ་ཚུ་ གྲོས་འདེབས་འབདཝ་ཨིན། ཁྱོད་ཀྱིས་མྱོང་དོ་ཡོད་པའི་དཀའ་ངལ་འདི་འདི་འདི་ནང་ལུ་ གསལ་བཀོད་མེནམ་ཨིན་པ་ཅིན་ ང་བཅས་དང་གཅིག་ཁར་ [Telegram](https://t.me/hyperledgeriroha) གི་ཐོག་ལས་འབྲེལ་བ་འཐབ་གནང་།

## ཚོང་མགྲོན་པ་གིས་ བརྒྱུད་འབྲེལ་འབད་མ་ཚུགས། {#client-cannot-connect}

ཁྱོད་ཀྱིས་ client config འདི་ peer གི་ Torii ཌའི་ལེནཌ་ལུ་ བཏོན་ཨིན་ན་བརྟག་དཔྱད་འབད་:

```toml
torii_url = "http://127.0.0.1:8080/"
```

CLI བརྟག་དཔྱད་ཚུ་གི་དོན་ལུ་ ཌའི་ལོག་གི་ཡིག་སྣོད་དེ་ གསལ་ཏོག་ཏོ་སྦེ་གཏང་དགོ།

```bash
cargo run --bin iroha -- --config ./localnet/client.toml ledger domain list all
```

ཁྱོད་ཀྱིས་ Docker ཡང་ན་ Kubernetesནང་ལུ་ འདྲན་འདྲ་ལག་ལེན་འཐབ་པ་ཅིན་ host ཡང་ན་ ཞབས་ཏོག་གི་ཁ་བྱང་འདི་ client བྱ་རིམ་ནང་ལས་ཐོབ་ཚུགསཔ་སྦེ་ ལག་ལེན་འཐབ་ཨིན། container ནང་འཁོད་ལུ་ `127.0.0.1` འདི་ host machineམེདཔ།

མི་མང་གི་བརྟག་དཔྱད་ Taira གི་དོན་ལུ་ ཐོ་བཀོད་མ་འབད་མི་ མཐའ་མཇུག་གི་རྟགས་དཔྱད་འདི་འགོ་དང་པ་བཙུགས་དགོ།

```bash
curl -fsS -H 'Accept: application/json' https://taira.sora.org/status \
  | jq '{blocks, txs_approved, txs_rejected, queue_size, peers}'

curl -fsS 'https://taira.sora.org/v1/domains?limit=5' \
  | jq -r '.items[].id'
```

འ་ནི་བཀའ་རྒྱ་ཚུ་ `502`, TLS, DNS ཡང་ན་ དུས་ཡུན་མཚམས་འཛོལ་བ་མེད་པ་ཅིན་ འབྲེལ་བ་འཐབ་ནིའི་ནུས་ཤུགས་འདི་ སེལ་འཐུ་འབད། ཡང་ན་རྩིས་ཁྲ་གི་ལྡེ་མིག་དང་ བྱ་བ་སྤྱོད་ལམ་གྱི་ཁེ་ཕན་ཚུ་ བསྒྱུར་བཅོས་མ་འབད་བའི་ཧེ་མར་ public testnet endpoint སྒུག་སྡོད་འོང་།

## ཚོང་འབྲེལ་ཚུ་མ་བཏུབ་བཟོ། {#transactions-are-rejected}

གནད་དོན་མང་ཤོས་ཅིག་ལུ་ ངོས་འཛིན་དང་ ཡང་ན་ ངོས་ལེན་མ་མཐུན་མི་ལུ་བརྟེན་ ཕྱིར་ཚོང་འཐབ་མ་ཚུགས་པར་ཡོདཔ་ཨིན།

- སྒེར་གྱི་ལྡེ་མིག་ཚུ་ ཐོ་བཀོད་འབད་ནི་ལུ་ ལག་ལེན་འཐབ་མི་ སྒེར་གྱི་སྒོ་ངོ་མ་དང་མ་འདྲ་།
- རྩིས་ཁྲ་དེ་ སྔོན་བྱོན་གྱི་ཚོང་འབྲེལ་དང་འཁྲིལཝ་ད་ ཐོ་བཀོད་འབད་མི་མེན།
- རྩིས་ཁྲ་དེ་ནང་ འགྲུལ་བསྐྱོད་དུས་ཡུན་བརྟག་དཔྱད་འབད་མི་དེ་གིས་ དགོས་མཁོ་ཅན་གྱི་ ངོས་ལེན་རྟགས་མ་ ཡང་ན་ འགན་འཁྲི་མེད་
- གནས་སྡུད་ ID ཌའི་ཊ་ས་བཱལ་གྱི་ ཁྱད་ཚད་མེད་མི་ དཔེར་ན་ `domain.dataspace`

ཁྱོད་ཀྱིས་ `--output-format text` ལག་ལེན་འཐབ་སྟེ་ CLI བཀའ་རྒྱ་ཚུ་ཉམས་བཅོས་འབད་བའི་སྐབས་ལུ་ འཛོལ་བ་ཚུ་ལྷག་ནི་ལུ་འཇམ་ཏོང་ཏོ་ཨིན།

```bash
cargo run --bin iroha -- --config ./localnet/client.toml --output-format text ledger transaction ping --msg "hello"
```

## ཞིབ་འཚོལ་འདི་གིས་ གྲུབ་འབྲས་སྟོང་པ་ཅིག་ བཏང་ཨིན། {#queries-return-empty-results}

བསྡུ་ལེན་གྱི་ གྲུབ་འབྲས་སྟོངམ་འདི་ ཨ་རྟག་རང་ བསྡུ་དཔྱད་དེ་མ་གྲུབ་པའི་རྟགས་མཚན་མེན།

- གནད་དོན་འདི་བཟོ་དགོ་པའི་ ཕྱིར་ཚོང་འཐབ་ནི་དེ་ བསྡུ་སྒྲིག་འབད་ཡོདཔ་ཨིན།
- གནས་སྡུད་དང་རྩིས་ཁྲ་ ID ཚད་ལྡན་ཨིན།
- ཤོག་ལེབ་བཟོ་སྐྲུན་ ཡང་ན་ གློག་ཐིག་ཚུ་ མཇུག་མཐོངམ་གི་གྲལ་རིམ་འདི་ ཕྱི་ཁར་བཏོན་མི་ཚུགས།
- སྲུང་རྒྱབ་དེ་ གྲུབ་འབྲས་ལུ་ འབྲེལ་མཐུད་འབད་ཡོདཔ་མ་གཏོགས་ ས་གནས་ཀྱི་དྲ་ལམ་གཞན་ཅིག་ལུ་མེན་

ས་ཁོངས་བརྟག་དཔྱད་འབད་ནིའི་དོན་ལས་ དྲིས་ལན་ཐེངས་མང་ཤོས་ཅིག་ནང་ལས་འགོ་བཙུགས་དགོ།

```bash
cargo run --bin iroha -- --config ./localnet/client.toml ledger domain list all
```

## འབྱུང་རྐྱེན་དང་མ་མཐུན་པའི་ཆུ་རྒྱུན་ཚུ་ དུས་ཡུན་རིངམོ་སྦེ་མཚམས་འཇོག་འབདཝ་ཨིན། {#event-or-block-streams-stop-early}

བཀྲམ་སྤེལ་དང་ འབྱུང་རྐྱེན་འབྱུང་རིམ་གྱི་དཔེ་སྟོན་ཚུ་ Torii རྒྱུན་འགྲུལ་མཇུག་གི་ཐོ་བཀོད་ལུ་བརྟེན་ཨིན། གྲྭ་ཚང་དེ་ ད་ལྟོའི་བར་ན་ཡང་ལག་ལེན་འཐབ་སྟེ་ཡོདཔ་ཨིན་ན་བརྟག་དཔྱད་འབད་ཞིནམ་ལས་ དུས་ཡུན་འགོར་ཐོག་ལས་ བརྟག་དཔྱད་འབད་:

```bash
cargo run --bin iroha -- --config ./localnet/client.toml ledger blocks 1 --timeout 30s
cargo run --bin iroha -- --config ./localnet/client.toml ledger events block
```

HTTP འབྲེལ་མཐུད་ཚུ་གི་དོན་ལུ་ ཁྱོད་ཀྱི་མཐའ་མཇུག་གི་ཐིག་ལམ་འདི་ ད་ལྟོའི་ [Torii མཐའ་མཇུག་གི་ཐོ་བཀོད་དང་བསྡུར་འབད་](/dz/reference/torii-endpoints.md).
