# ཞབས་ཏོག་གི་དཀའ་ངལ་སེལ་ཐབས་ {#troubleshooting-deployment-issues}

འ་ནི་ཐིག་ཁྲམ་འདི་ནང་ལུ་ Iroha 3 ལག་ལེན་ཚུ་གི་དོན་ལུ་ དཀའ་ངལ་སེལ་ཐབས་ཀྱི་བསླབ་བྱ་ཚུ་ གྲོས་འདེབས་འབདཝ་ཨིན། ཁྱོད་ཀྱིས་མྱོང་དོ་ཡོད་པའི་དཀའ་ངལ་འདི་ ནཱ་ལུ་མི་བཤད་པ་ཅིན་ ང་བཅས་དང་གཅིག་ཁར་ [Telegram](https://t.me/hyperledgeriroha) ཟེར་མི་ཁ་ཐུག་ལས་འབྲེལ་བ་འཐབ་ཚུགས།

## བཟོ་སྐྲུན་འབད་མི་ལག་ཆས་ཚུ་ལས་འགོ་བཙུགས་ནི། {#start-with-generated-artifacts}

ས་གནས་དང་ བརྟག་དཔྱད་ལག་ལེན་ཚུ་གི་དོན་ལུ་ ལག་ཐོག་ལས་བྲིས་མི་ འདྲ་མཉམ་ཡིག་སྣོད་ཚུ་အစား Kagami གིས་ བཟོ་སྐྲུན་འབད་མི་ ཨེ་རེ་ཕ་ཀེཊ་ཚུ་ གདམ་ཁ་རྐྱབ་དགོ།

```bash
cargo run --bin kagami -- localnet --build-line iroha3 --peers 4 --out-dir ./localnet
```

བཟོ་སྐྲུན་འབད་མིའི་ཐོ་ཡིག་ནང་ འདྲན་འདྲ་བཟོ་ཐངས་ཚུ་, འབྱུང་ཁུངས་ཀྱི་དོན་ཆས་, འགོ་འདྲེན་འཐབ་ནིའི་ ཡིག་འབྲུ་ཚུ་ དེ་ལས་ README གི་དོན་ལུ་ Iroha 3 སྒྲིག་འཇུག་གི་ཐོ་བཀོད་ཡོདཔ་ཨིན།

## འདྲན་འདྲ་མཉམ་མི་འགོ་བཙུགས་ {#peer-does-not-start}

དང་པ་ འ་ནི་ ཅ་ཆས་ཚུ་ བརྟག་དཔྱད་འབད་:

- `irohad --config <path>` གྲྭ་ཚང་གི་ཡིག་སྣོད་ནང་ TOML ཐོ་བཀོད་འབད་ཡོདཔ་ཨིན།
- `public_key` དང་ `private_key` འདྲན་འདྲ་བཟོ་ཐངས་ནང་གི་ལྡེ་མིག་གཉིས་དེ་ཅིག་རང་ཨིན།
- `genesis.public_key` གིས་ genesis གྱི་ཚོང་འབྲེལ་གུ་ མཚན་རྟགས་བཀོད་ནིའི་དོན་ལུ་ལག་ལེན་འཐབ་མི་ལྡེ་མིག་དང་མཐུནམ་ཨིན།
- Validator peer identities གིས་ BLS-Normal keys ལག་ལེན་འཐབ་དོ་ཡོདཔ་ད་ `trusted_peers_pop` ནང་ལུ་ local key དང་ trusted peers གི་བདག་འཛིན་རྟགས་བཀོད་ཡོད་པའི་ནང་འཁོད་ཚུ་ཡོདཔ་ཨིན།
- Torii དང་ P2P གི་སྒོ་ར་སྒོ་ཚུ་ ད་ལྟོ་ཡང་ བྱ་རིམ་གཞན་ཅིག་གིས་བསྡམ་མི་བཞག་པས།
- Kura ཚོང་ཁང་གི་ཐོ་ཡིག་དེ་ ལྕགས་ཐག་གཅིག་གི་ནང་ཡོད་མི་དེ་དང་ ཁྱད་པར་ཅན་གྱི་དྲ་ལམ་ལས་ ཨེབ་གཏང་མ་འབད་བས།

 config tracing ལག་ལེན་འཐབ་ད་ daemon གིས་ TOML layer མང་ཤོས་ཅིག་བཀླག་ཨིན།

```bash
cargo run --bin irohad -- --config ./config.toml --trace-config
```

## Docker དང་ མཉམ་འབྲེལ་འབད་ {#docker-and-compose}

བཟོ་སྐྲུན་འབད་ ད་ལྟོའི་ Kagami localnet ཐོན་ཐོ་བཀོད་ནང་ལས་ བསྡུ་སྒྲིག་རྐྱབས་ དེ་འབདཝ་ལས་ བཀའ་རྒྱ་གི་གྲལ་རིམ་གྱི་ གྲོས་བསྡུར་དང་ གཞི་སྒྲིག་ཡིག་སྣོད་ཚུ་ ཐོ་བཀོད་འབད་ཚར་མི་ code ལུ་ сәйкесའོང་།

```bash
cargo run --bin kagami -- localnet --build-line iroha3 --peers 4 --out-dir ./localnet
cargo run --bin kagami -- docker --peers 4 --config-dir ./localnet --image hyperledger/iroha:dev --out-file ./localnet/docker-compose.yml --force
docker compose -f ./localnet/docker-compose.yml up
```

compose deployment འགོ་བཙུགས་ཞིནམ་ལས་ བཏུབ་པ་ཅིན་ daemon logs འདི་ནང་ལུ་བལྟ་དགོ།

- བཀྲམ་སྤེལ་འབད་མ་ཚུགས་མི་ `chain`
- འདྲ་མཉམ་ཅིག་གིས་ genesis ཌའི་ལོག་ལག་ལེན་དང་ཡང་ན་ manifest ལག་ལེན་འཐབ་ཨིན།
- P2P ཌའི་ལོག་ཚུ་ནང་གསལ་བསྒྲགས་འབད་དོ་ཡོདཔ་ད་ དེ་ཚུ་ container net གི་ནང་ན་རྐྱངམ་གཅིག་ལཱ་འབདཝ་ཨིན།
- འབྱུང་ཁུངས་སླར་གསོ་འབད་བའི་ཤུལ་ལས་ ས་གནས་ཀྱི་རྒྱ་ཁྱོན་སླར་ལོག་འབདཝ་ཨིན།

སྒྲིག་གཞི་གསརཔ་ཅིག་ བརྟག་དཔྱད་འབད་བའི་སྐབས་ལུ་ ཨེབ་ཐག་དེ་ ལོག་འགོ་བཙུགས་པའི་ཧེ་མར་ Kura ཤོག་སྒྲིལ་རྙིངམ་ཚུ་བཏོན་གཏང་དགོ། ཨེབ་ཐག་གསརཔ་དང་གཅིག་ཁར་ རྡོ་རྙིངམ་བཞག་པ་ཅིན་ སླར་ལོག་འབད་ནི་ལུ་ ཕན་ཐོགས་འབྱུང་འོང་།

## Kubernetes {#kubernetes}

Kubernetes གི་དོན་ལས་ སྒྲུབ་རྟགས་སོ་སོ་ཚུ་ stateful infrastructure སྦེ་བརྩི་དགོ།

- འདྲན་འདྲ་ཆ་མཉམ་ལུ་ ངོ་རྟགས་ཀྱི་ལྡེ་མིག་བརྟན་ཏོག་ཏོ་དང་ སྒྲོམ་བརྟན་ཏོག་ཏོ་བྱིན་ནི།
- P2P ཌའི་ལེསི་ཚུ་བཏོན་ནི་དེ་ གཞན་མི་ལས་བྱེདཔ་ཚུ་གིས་ ལྡོག་ཕྱོགས་ཀྱི་ནང་འཁོད་ནང་ལས་ སེལ་ཚུགས་འོང་།
- གཞི་སྒྲིག་དང་ genesis ཌའི་ལོག་ཚུ་ rolloutགི་དོན་ལུ་འགྱུར་བ་མེད་པའི་ configསྦེ་བཙུགས་དགོ།
- genesis ཡང་ན་ topology བསྒྱུར་བཅོས་ཚུ་ རང་བཞིན་གྱི་ config-map གསར་གཏོད་ཅིག་སྦེ་མེན་པར་ མཚམས་འཇོག་འབད་ཐོག་ལས་ལག་ལེན་འཐབ་དགོ།

གློག་ཐག་ཅིག་ ལོག་སྟེ་ར་འགོ་བཙུགསཔ་ཨིན་པ་ཅིན་ གློག་ཐག་ནང་གི་ སྒྲིག་གཞི་འདི་ ཕབ་ལེན་འབད་ཡོད་པའི་ [`peer.template.toml`](/dz/reference/peer-config/index.md#template)དང་ཕྱདཔ་ད་ ལྟ་རྟོག་འབད་བ་ཅིན་ གློག་ཐག་འདི་གིས་ ཧེ་མ་གི་ Kura ཌེ་ཊའི་ཚུ་ ལོག་སྤྱོད་འབདཝ་ཨིན་ན་མེན་ཟེར་ བལྟ་དགོ།

## Sora གི་ཐོ་ཡིག་ {#sora-profile}

Iroha 3 གཞི་བཙུགས་འབད་མི་ཚུ་ནང་ Nexus, SoraFS ཡང་ན་ ལྕང་ལམ་མང་རབས་ཅིག་གི་རྒྱུན་འགྲུལ་ཚུ་ ལག་ལེན་འཐབ་པ་ཅིན་ ཌའི་མཱོན་དེ་ Sora Profile enable འབད་ནི་ལུ་འགོ་བཙུགས་དགོ།

```bash
cargo run --bin irohad -- --config ./config.toml --sora
```

འབྲེལ་མཐུད་དེ་ཅིག་ནང་ འཛིན་སྐྱོང་འབད་མི་ཚུ་ལུ་ དུས་རྒྱུན་གྱི་དོན་ལུ་ ཕན་ཁྱད་གཅིག་རང་ ལག་ལེན་འཐབ་དགོ།
