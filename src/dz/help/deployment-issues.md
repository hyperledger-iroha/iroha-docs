# ཞབས་ཏོག་གི་དཀའ་ངལ་སེལ་ཐབས་ {#troubleshooting-deployment-issues}

འ་ནི་ཐིག་ཁྲམ་འདི་ནང་ལུ་ Iroha 3 ལག་ལེན་ཚུ་གི་དོན་ལུ་ དཀའ་ངལ་སེལ་ཐབས་ཀྱི་བསླབ་བྱ་ཚུ་ གྲོས་འདེབས་འབདཝ་ཨིན། ཁྱོད་ཀྱིས་མྱོང་དོ་ཡོད་པའི་དཀའ་ངལ་འདི་ ནཱ་ལུ་མི་བཤད་པ་ཅིན་ ང་བཅས་དང་གཅིག་ཁར་ [Telegram](https://t.me/hyperledgeriroha) ཟེར་མི་ཁ་ཐུག་ལས་འབྲེལ་བ་འཐབ་ཚུགས།

## བཟོ་སྐྲུན་འབད་མི་ལག་ཆས་ཚུ་ལས་འགོ་བཙུགས་ནི། {#start-with-generated-artifacts}

ས་གནས་དང་ བརྟག་དཔྱད་ལག་ལེན་ཚུ་གི་དོན་ལུ་ ལག་ཐོག་ལས་བྲིས་མི་ འདྲ་མཉམ་ཡིག་སྣོད་ཚུ་ཚབ་ལུ་ Kagami གིས་ བཟོ་སྐྲུན་འབད་མི་ ཨེ་རེ་ཕ་ཀེཊ་ཚུ་ གདམ་ཁ་རྐྱབ་དགོ།

```bash
cargo run --bin kagami -- localnet --peers 4 --out-dir ./localnet
```

བཟོ་སྐྲུན་འབད་མིའི་ཐོ་ཡིག་ནང་ མཐུད་མཚམས་བཟོ་ཐངས་ཚུ་, འབྱུང་ཁུངས་ཀྱི་དོན་ཆས་, འགོ་འདྲེན་འཐབ་ནིའི་ ཡིག་འབྲུ་ཚུ་ དེ་ལས་ README གི་དོན་ལུ་ Iroha 3 སྒྲིག་འཇུག་གི་ཐོ་བཀོད་ཡོདཔ་ཨིན།

## མཐུད་མཚམས་འགོ་མི་བཙུགས་ {#peer-does-not-start}

དང་པོ་འདི་དག་བརྟག་དཔྱད་བྱོས།

- `iroha3d --config <path>` མཐུད་མཚམས་གི་ཡིག་སྣོད་ནང་ TOML ཐོ་བཀོད་འབད་ཡོདཔ་ཨིན།
- མཉམ་འབྲེལ་རིམ་སྒྲིག་ནང་ལུ་ `public_key` དང་ `private_key` འདི་ ལྡེ་མིག་ཆ་གཅིག་ལུ་ཚུདཔ་ཨིན།
- `genesis.public_key` གིས་ རིགས་མཚན་ཚོང་འབྲེལ་ལུ་མིང་རྟགས་བཀོད་ནི་ལུ་ལག་ལེན་འཐབ་མི་ལྡེ་མིག་དང་མཐུན་སྒྲིག་འབདཝ་ཨིན།
- བདེན་དཔྱད་འབད་མི་ མཉམ་རོགས་ངོ་རྟགས་ཚུ་གིས་ BLS-སྤྱིར་བཏང ལྡེ་མིག་ཚུ་ལག་ལེན་འཐབ་ཨིནམ་དང་ `trusted_peers_pop` ནང་ ཉེ་གནས་ལྡེ་མིག་དང་ བློ་གཏད་ཅན་གྱི་མཉམ་རོགས་ཚུ་གི་དོན་ལུ་ བདག་དབང་གི་བདེན་ཁུངས་ཐོ་བཀོད་ཚུ་ཡོདཔ་ཨིན།
- Torii དང་ P2P གི་དོན་ལུ་འདྲེན་ལམ་ཚུ་ ཧེ་མ་ལས་རང་ བྱ་རིམ་གཞན་ཅིག་གིས་ མཐུད་དེ་མེདཔ་ཨིན།
- Kura ཚོང་ཁང་གི་ཐོ་ཡིག་དེ་ ལྕགས་ཐག་གཅིག་གི་ནང་ཡོད་མི་དེ་དང་ ཁྱད་པར་ཅན་གྱི་དྲ་ལམ་ལས་ ཨེབ་གཏང་མ་འབད་བས།

ཌེ་མཱོན་གྱིས་ TOML བང་རིམ་གཅིག་ལས་ལྷག་སྟེ་ལྷག་པའི་སྐབས་ རིམ་སྒྲིག་རྗེས་འདེད་ལག་ལེན་འཐབ།

```bash
cargo run -p irohad --bin iroha3d -- --config ./config.toml --trace-config
```

## Docker དང་ མཉམ་འབྲེལ་འབད་ {#docker-and-compose}

བཟོ་སྐྲུན་འབད་ ད་ལྟོའི་ Kagami ས་གནས་བརྟག་དཔྱད་དྲ་རྒྱ ཐོན་ཐོ་བཀོད་ནང་ལས་ བསྡུ་སྒྲིག་རྐྱབས་ དེ་འབདཝ་ལས་ བཀའ་རྒྱ་གི་གྲལ་རིམ་གྱི་ གྲོས་བསྡུར་དང་ གཞི་སྒྲིག་ཡིག་སྣོད་ཚུ་ ཐོ་བཀོད་འབད་ཚར་མི་ ལས་རིམ་ཨང་རྟགས ལུ་ མཐུན་པ་འོང་།

```bash
cargo run --bin kagami -- localnet --peers 4 --out-dir ./localnet
cargo run --bin kagami -- docker --peers 4 --config-dir ./localnet --image hyperledger/iroha:dev --out-file ./docker-compose.yml --force
docker compose -f ./docker-compose.yml up
```

གལ་སྲིད་ བརྩམ་སྒྲིག་བཀྲམ་སྤེལ་འགོ་བཙུགས་ཏེ་ དེ་ལས་ བཀག་ཆ་འབད་བ་ཅིན་ ཌེ་མཱོན་དྲན་ཐོ་ཚུ་ ཞིབ་དཔྱད་འབད།

- མཐུན་སྒྲིག་མེད་པའི་`chain`
- རིགས་མཚན་ཚོང་འབྲེལ་ཡང་ན་གསལ་སྟོན་སོ་སོ་ལག་ལེན་འཐབ་སྟེ་ མཉམ་རོགས་གཅིག།
- ཁྱབ་བསྒྲགས་འབད་ཡོད་པའི་ P2P ཁ་བྱང་ཚུ་ དོས་ཆས་ཡོངས་འབྲེལ་ནང་ལུ་རྐྱངམ་ཅིག་ལཱ་འབདཝ་ཨིན།
- རིགས་མཚན་བསྐྱར་གསོ་འབད་བའི་ཤུལ་ལས་ ས་གནས་ཀྱི་སྐད་ཤུགས་ལོག་སྤྱོད་འབད་ནི།

སྒྲིག་གཞི་གསརཔ་ཅིག་ བརྟག་དཔྱད་འབད་བའི་སྐབས་ལུ་ ཨེབ་ཐག་དེ་ ལོག་འགོ་བཙུགས་པའི་ཧེ་མར་ Kura ཤོག་སྒྲིལ་རྙིངམ་ཚུ་བཏོན་གཏང་དགོ། ཨེབ་ཐག་གསརཔ་དང་གཅིག་ཁར་ རྡོ་རྙིངམ་བཞག་པ་ཅིན་ སླར་ལོག་འབད་ནི་ལུ་ ཕན་ཐོགས་འབྱུང་འོང་།

## Kubernetes {#kubernetes}

ཀུ་བྷར་ནེཊིསི་གི་དོན་ལུ་ བདེན་དཔྱད་འབད་མི་རེ་རེ་བཞིན་དུ་ གནས་སྟངས་གཞི་རྟེན་སྦེ་བརྩི་དགོ།

- མཉམ་རོགས་རེ་རེ་ལུ་ བརྟན་ཏོག་ཏོ་ངོ་རྟགས་ལྡེ་མིག་དང་ བརྟན་ཏོག་ཏོ་ རྟག་བརྟན་སྐད་ཤུགས་བྱིན།
- མཉམ་རོགས་གཞན་ཚུ་གིས་ ཀླད་ཀོར་ནང་ན་ལས་ ཐག་བཅད་ཚུགས་པའི་ P2P ཁ་བྱང་ཚུ་ གསལ་སྟོན་འབད།
- རིམ་སྒྲིག་དང་རིགས་མཚན་ཡིག་སྣོད་ཚུ་ བཤུད་བརྙན་ཅིག་གི་དོན་ལུ་ བསྒྱུར་བཅོས་མ་འབད་བའི་རིམ་སྒྲིག་སྦེ་ སྦྱར་བརྩེགས་འབད།
- རིགས་མཚན་ཡང་ན་ ཊོ་པོ་ལོ་ཇི་བསྒྱུར་བཅོས་ཚུ་ཆ་མཉམ་རང་ རང་བཞིན་རིམ་སྒྲིག་སབ་ཁྲ་གསར་བསྐྲུན་འབད་མི་སྦེ་མེན་པར་ ཤེས་བཞིན་དུ་ བཏོན་གཏང་།

གློག་ཐག་ཅིག་ ལོག་སྟེ་ར་འགོ་བཙུགསཔ་ཨིན་པ་ཅིན་ གློག་ཐག་ནང་གི་ སྒྲིག་གཞི་འདི་ ཕབ་ལེན་འབད་ཡོད་པའི་ [`peer.template.toml`](/dz/reference/peer-config/index.md#template)དང་ཕྱདཔ་ད་ ལྟ་རྟོག་འབད་བ་ཅིན་ གློག་ཐག་འདི་གིས་ ཧེ་མ་གི་ Kura ཌེ་ཊའི་ཚུ་ ལོག་སྤྱོད་འབདཝ་ཨིན་ན་མེན་ཟེར་ བལྟ་དགོ།

## Sora གི་ཐོ་ཡིག་ {#sora-profile}

Nexus, SoraFS ཡང་ན་ ལེན་ལམ་མང་རབས་ཅིག་ལག་ལེན་འཐབ་མི་ སྒེར་གྱི་དང་ཡང་ན་ ས་གནས་ཀྱི་ Iroha 3 ལག་ལེན་གྱིས་ Sora གསལ་ཐོ ཤུགས་ཅན་སྦེ་སྤྱོད་ཐོག་ལས་ རང་བཞིན་གྱི་ ཌེ་མོན འགོ་བཙུགས་དགོ།

```bash
cargo run -p irohad --bin iroha3d -- --config ./config.toml --sora
```

ཡོངས་འབྲེལ་གཅིག་ནང་ བདེན་དཔྱད་འབད་མི་ཚུ་གི་བར་ན་ གསལ་སྡུད་གཅིགཔོ་འདི་ རྟག་བརྟན་སྦེ་ལག་ལེན་འཐབ།

མི་མང་གི་ Taira དམ་ཚིག་ཅན་ཚུ་གིས་ དམིགས་གཏད་ཅན་གྱི་ འགོ་འདྲེན་འཐབ་མི་ལག་ལེན་འཐབ་དོ་ཡོདཔ་ད་ འདི་གིས་ Taira གི་ ཡན་ཏན་ལྡེ་མིག་དང་ ཐོ་བཀོད་འབད་ཐངས་ དེ་ལས་ SoraFS ནང་འཁོད་ལུ་བཞག་ཡོད་མི་ སྒྲིང་སྒྲི་ཚུ་ ཆ་མེད་གཏང་ནི་དང་ རྒྱུན་འགྲུལ་འབད་བའི་དུས་ཚོད་ཀྱི་བརྡ་སྟོན་གྱི་ཡིག་གཟུགས་ཚུ་ བཏོན་ཚུགས། འདི་མ་འགོ་བཙུགས་པའི་ཧེ་མར་ Taira གཞི་སྒྲིག་འདི་ དམ་ཚིག་ཅན་བཟོ་ནི།

```bash
iroha3d_taira --sora \
  --config /etc/iroha/taira/config.toml \
  --check-config
```
