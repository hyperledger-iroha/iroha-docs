- Rust ལག་ཆས་ཀྱི་ཐོ་བཀོད་འདི་ ལས་རིམ་གོང་འཕེལ་གྱི་ལཱ་གི་ས་ཁོངས་ནང་བཙུགས་མི་ འདྲ་བཤུས་ལས་རྙིང་ཤོས་ཨིན།
- `cargo` ཡང་ན་ `rustc` `rustup` ལས་གཞི་བཙུགས་སོ་སོ་ཅིག་ལུ་ཐག་བཅད་དོ།

### Rust ཐོན་རིམ་ཞིབ་དཔྱད་འབད་ {#check-rust-version}

ཁྱོད་དང་ང་བཅས་རའི་བློ་རིག་གཉིས་ཆ་ར་ ཉམས་སྲུང་འབད་ནིའི་དོན་ལུ་ ཁྱོད་ལུ་ `cargo` གི་ཐོན་རིམ་འོས་འབབ་ཅན་འདི་ `rustc` གི་ཐོན་རིམ་འོས་འབབ་ཅན་དང་གཅིག་ཁར་ ཆ་སྒྲིག་འབད་དེ་ཡོདཔ་ངེས་གཏན་བཟོ། ད་ལྟོའི་ཡར་འཕེལ་གྱི་ལཱ་གི་ས་སྒོ་འདི་གིས་ `rust-version = "1.92"` གསལ་བསྒྲགས་འབདཝ་ཨིནམ་དང་ `rust-toolchain.toml` ནང་ལུ་ ལག་ཆས་རིམ་སྒྲིག་རྒྱུ་ལམ་འདི་ པིན་འབདཝ་ཨིན། ཐོན་རིམ་ཚུ་སྟོན་ནིའི་དོན་ལུ་ འབད།

```bash
$ cargo -V
$ cargo 1.93.1 (...)
```

དང་དེ་ནས།

```bash
$ rustc --version
$ rustc 1.93.1 (...)
```

ཁྱོད་ཀྱིས་ ཚད་མཐོ་ཤོས་ཡོད་པ་ཅིན་ ཁྱོད་དྲག་ཆེ། ཁྱོད་ཀྱིས་ ཚད་དམའ་བ་ཡོད་པ་ཅིན་ འདི་བཟོ་བཅོས་འབད་ནིའི་དོན་ལུ་ བཀའ་རྒྱ་འདི་ལག་ལེན་འཐབ་བཏུབ་ཨིན།

```bash
$ rustup toolchain update stable
```

### གཞི་བཙུགས་ས་སྒོ་ཚུ་ བརྟག་དཔྱད་འབད། {#check-installation-location}

ཁྱོད་ཀྱིས་ཐོན་རིམ་ཨང་གྲངས་དམའ་བ་ཐོབ་པ་ཅིན་ **དང་** ཁྱོད་ཀྱིས་ལག་ཆས་རྒྱུན་རིམ་དུས་མཐུན་བཟོ་སྟེ་ ལཱ་འབད་མ་ཚུགས་པ་ཅིན་... སྤྱིར་བཏང་གི་དཀའ་ངལ་ཅིག་ཨིན་ཟེར་སླབ་གེ་ཟེར་ཨིན་རུང་ སྤྱིར་བཏང་གི་ཐབས་ཤེས་མེདཔ་ཨིན།

དང་པ་རང་ ཁྱོད་ཀྱིས་ལག་ལེན་འཐབ་དགོ་མནོ་མི་ཐོན་རིམ་འདི་ ག་སྟེ་ལུ་གཞི་བཙུགས་འབད་ཡོདཔ་ཨིན་ན་ གཞི་བཙུགས་འབད་དགོ།

```bash
$ rustup which rustc
$ rustup which cargo
```

ལག་ཆས་ཐིག་ཁྲམ་ཚུ་གི་ལག་ལེན་འཐབ་མི་བཙུགས་ནི་ཚུ་ སྤྱིར་བཏང་ལུ་ `~/.rustup/toolchains/stable-*/bin/`ནང་ལུ་ཨིན། འདི་ཨིན་པ་ཅིན་ ཁྱོད་ཀྱིས་

```bash
$ rustup toolchain update stable
```

དང་དེ་གིས་ཁྱོད་ཀྱི་དཀའ་ངལ་ཚུ་སེལ་དགོ།

### གཞི་སྒྲིག་གི་ Rust འདྲ་བཤུས་ཚུ་ བརྟག་དཔྱད་འབད་ {#check-the-default-rust-version}

གདམ་ཁ་གཞན་མི་འདི་ ཁྱོད་ལུ་དུས་མཐུན་གྱི་`stable` ལག་ཆས་རིམ་སྒྲིག་ཡོདཔ་ཨིན་ དེ་འབདཝ་ད་ སྔོན་སྒྲིག་སྦེ་གཞི་སྒྲིག་མ་འབད་བས། རྒྱུག༌ནི:

```bash
$ rustup default stable
```

`nightly` འདྲ་བཤུས་ཅིག་བཙུགས་ནི་ ཡང་ན་ Rust འདྲ་བཤུས། འདི་མ་བཞག་པར་ གཞི་སྒྲིག་འབད་ནི་འདི་གིས་ དཀའ་ངལ་འདི་འབྱུང་ཚུགས།

### Rust འདྲ་བཤུས་གཞན་ཚུ་ཡོད་མེད་ བརྟག་དཔྱད་འབད་ {#check-if-there-are-other-rust-versions}

དཀའ་ངལ་སེལ་ཐབས་རི་བོང་གི་དོང་དེ་འཕྲོ་མཐུད་དེ་ ང་བཅས་ལུ་ ཤེལ་གྱི་མིང་གཞན་ཚུ་འོང་སྲིད།

```bash
$ type rustc
$ type cargo
```

འདི་ཚུ་གིས་ ཁྱོད་ཀྱིས་ `rustup which *` གཡོག་བཀོལ་བའི་སྐབས་མཐོང་མི་ ས་གནས་གཞན་ཚུ་ལུ་ བརྡ་སྟོན་འབད་བ་ཅིན་ ཁྱོད་ལུ་དཀའ་ངལ་འབྱུངམ་ཨིན། འདི་བཟུམ་མའི་མིང་གཞན་ཁ་སྐོང་བརྐྱབ་མི་འདི་གིས་ལངམ་སྦེ་མེདཔ་ཨིནམ་དྲན་འཛིན་འབད།

```bash
$ alias rustc "~/.rustup/toolchains/stable-*/bin/rustc"
$ alias cargo "~/.rustup/toolchains/stable-*/bin/cargo"
```

ཁྱོད་ཀྱིས་ཁྱོད་རའི་ཤེལ་གྱི་མིང་གཞན་ཚུ་ག་དེ་སྦེ་སྒྲིག་རུང་ ནང་འཁོད་ཚད་མ་འདི་ ད་ལྟོ་ཡང་ཆད་ཚུགས།

ཐབས་ཤེས་འཇམ་ཏོང་ཏོ་འདི་ ཁྱོད་ཀྱིས་ལག་ལེན་མ་འཐབ་པའི་ཐོན་རིམ་ཚུ་བཏོན་གཏང་ནི་འདི་ཨིན།

འདི་ _said_ ལས་ _done_ འཇམ་ཏོང་ཏོ་ཨིན། དེ་འབདཝ་ད་ དེ་གིས་ rustup གི་ཐོན་རིམ་ཆ་མཉམ་བཙུགས་ཏེ་ ཁྱོད་ལུ་ཐོབ་ཚུགསཔ་སྦེ་ བརྟག་ཞིབ་འབད་དགོཔ་ལས་ཨིན། སྤྱིར་བཏང་ལུ་ རིམ་ལུགས་ཐུམ་སྒྲིལ་འཛིན་སྐྱོང་པའི་ཐོན་རིམ་དང་ ཁྱོད་ཀྱིས་ སློབ་སྟོན་འདི་འགོ་བཙུགས་པའི་སྐབས་ བརྡ་བཀོད་འདི་གཡོག་བཀོལ་བའི་སྐབས་ ཁྱོད་རའི་ཁྱིམ་སྣོད་འཛིན་ནང་ ཚད་ལྡན་གནས་ཁོངས་ནང་ གཞི་བཙུགས་འབད་ཡོད་མི་འདི་ གཉིས་རྐྱངམ་ཅིག་ཡོདཔ་ཨིན། ཧེ་མའི་དོན་ལུ་ ཁྱོད་རའི་ (Linux) བཀྲམ་སྤེལ་གྱི་ལག་དེབ་ (`apt remove rust`) ལུ་བལྟ། ཤུལ་མམ་གྱི་དོན་ལུ་ གཡོག་བཀོལ་:

```bash
$ rustup toolchain list
```

དེ་ལས་ `<toolchain>` རེ་རེ་གི་དོན་ལུ་ (ཟུར་ཁུག་གུག་ཤད་མེད་པར་ ངེས་པར་དུ):

```bash
$ rustup remove <toolchain>
```

ལག་ཆས་རྒྱུན་རིམ་ཚུ་བཏོན་གཏང་པའི་ཤུལ་ལས་ བརྡ་བཀོད་འདི་གིས་ བརྡ་བཀོད་མ་ཐོབ་པའི་འཛོལ་བ་ཅིག་སྙན་ཞུ་འབད་དགོཔ་ཨིན།

```bash
$ cargo --help
```

འ་ནི་འཛོལ་བ་འདི་གིས་ Rust ཤུགས་ཅན་གྱི་ལག་ཆས་ཐིག་ཁྲམ་ཚུ་ གཞི་བཙུགས་འབད་མེད་ཟེར་བདེན་ཁུངས་བཀལཝ་ཨིན།

```bash
$ rustup toolchain install stable
```

## དཀའ་ངལ་སེལ་ཐབས། Python ལག་ཆས་སྤེལ་ཐིག་ {#troubleshooting-python-toolchain}

ཁྱོད་ཀྱིས་ Python ཐུམ་སྒྲིལ མཉེན་ཆས་ཐུམ་སྒྲིལ འདི་ [Python ཞབས་ཏོག་ལེན་མི སྒྲིག་འགོད](/dz/guide/tutorials/python.md) གི་སྐབས་ལུ་ pip ལག་ལེན་འཐབ་ཐོག་ལས་བཙུགས་པའི་སྐབས་ ཁྱོད་ཀྱིས་ "iroha_python-*.whl འདི་ འ་ནི་སྟེགས་བུ་ནང་ལུ་ རྒྱབ་སྐྱོར་འབད་མི་ འཁོར་ལམ་ཅིག་མེན་"བཟུམ་གྱི་འཛོལ་བ་མཐོང་ཚུགས།

འཛོལ་བ་འདི་གིས་ པིཔ་འདི་དུས་ཚོད་རྫོགས་ཡོདཔ་ལས་ ཁྱོད་ཀྱིས་དུས་མཐུན་བཟོ་དགོཔ་ཨིན། དང་པ་རང་ ཁྱོད་རའི་ OS འདི་དུས་མཐུན་བཟོ་ཡོདཔ་ཨིན་ན་ བརྟག་དཔྱད་འབད་དེ་ རིམ་ལུགས་ཡར་འཕར་འབད་དགོཔ་འདི་ གྲོས་འཆར་བཀོདཔ་ཨིན།

འདི་གིས་ལཱ་འབད་མ་ཚུགས་པ་ཅིན་ ཁྱོད་རའི་ལག་ལེན་པའི་སྣོད་ཐོ་གི་དོན་ལུ་ `pip` དུས་མཐུན་བཟོ་ནི་ལུ་དཔའ་བཅམ་ཚུགས།

`python -m pip install --upgrade pip`

ཁྱོད་ཀྱི་ཁྱིམ་སྣོད་ཐོ་ནང་གཞི་བཙུགས་འབད་ཡོད་པའི་ `pip` འདི་ངེས་གཏན་བཟོ། འདི་འབད་ནི་ལུ་ `whereis pip` གཡོག་བཀོལ་ཞིནམ་ལས་ `/home/username/.local/bin/pip` འདི་འགྲུལ་ལམ་ཚུ་གི་གྲལ་ཁར་ཡོདཔ་ཨིན་ན་ ཞིབ་དཔྱད་འབད། དེ་མེན་པ་ཅིན་ ཁྱོད་རའི་ཤེལ་གྱི་ `PATH` འགྱུར་ཅན་འདི་དུས་མཐུན་བཟོ།

གནད་དོན་འདི་ འཕྲོ་མཐུད་དེ་ར་ཡོད་པ་ཅིན་ ཁྱོད་ཀྱིས་ [ ལུ་ ང་བཅས་དང་ ](/dz/help/) འབྲེལ་བ་འཐབ་སྟེ་ གྲུབ་འབྲས་ཚུ་ སྙན་ཞུ་འབད་དགོ།

```
python --version
python3 --version
pip --version
pip3 --version
```
