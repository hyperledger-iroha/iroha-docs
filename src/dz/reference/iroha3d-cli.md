# `iroha3d` CLI {#iroha3d-cli}

`iroha3d` འདི་ཚད་ལྡན་ Iroha 3 ཡོངས་འབྲེལ་མཉམ་རོགས་ཌེ་མཱོན་ཨིན། Cargo ཐུམ་སྒྲིལ་འདི་ `irohad` ཟེར་མིང་བཏགས་ཡོདཔ་ལས་ འབྱུང་ཁུངས་ཨང་རྟགས་ལཱ་འབད་མི་འདྲ་བཤུས་ཅིག་ལས་ གཉིས་ལྡན་འདི་ འདི་དང་གཅིག་ཁར་ འབོ་དགོ།

```shell
cargo run -p irohad --bin iroha3d -- --config path/to/config.toml
```

མི་མང་གི་ Taira བརྟག་དཔྱད་འབད་ཐངས་ཀྱི་དོན་ལུ་ པར་འདི་ `iroha3d_taira` ལག་ལེན་འཐབ་ཡོདཔ་ཨིན། འདི་ཡང་ CLI དེ་བཟུམ་བཟོཝ་ཨིན། འདི་ཡང་ Taira ལྕགས་ཐག་དང་ བདེན་ཁུངས་སྐྱེལ་འཕྲུལ་ཆས་ གཞི་སྒྲིག་ དེ་ལས་ ཐོ་བཀོད་འབད་ཐངས་ཀྱི་ལྡེ་མིག་ཚུ་ བཏོན་དོ་ཡོདཔ་ཨིན། ཁྱོད་ཀྱིས་ Taira སྒྲིག་གཞི་འདི་ སྒོ་བསྡམ་ནིའི་དུས་ཚོད་ཀྱི་ ངོས་འཛིན་ཚུ་ ཁ་ཕྱེ་མ་བཅུག་པར་ རྩ་སྒྲིག་འབད་:

```shell
iroha3d_taira --sora \
  --config /etc/iroha/taira/config.toml \
  --check-config
```

ཚད་ལྡན་ Taira གི་སྔོན་སྒྲིག་འདི་ ལག་ལེན་འཛིན་སྐྱོང་པ་གིས་གནས་གོང་བཀང་སྟེ་བཟོ་བའི་རྣམ་པ་ལག་ལེན་འཐབ། མཛོད་ནང་བཞག་པའི་དཔེ་གཞི་ནང་ ད་ལྟོ་ཡང་བཀྲམ་སྤེལ་གྱི་ཚབ་ཡིག་ཚུ་ཡོད། Taira དང་གཅིག་ཁར་བརྟག་དཔྱད་འབད་བའི་སྐབས་ སྤྱིར་བཏང་ SORA Nexus ཡང་ན་དངོས་སྤྱོད་ SoraFS གི་སྒྲིག་སྟངས་ཚུ་ཚབ་སྦེ་མ་བཙུགས།

## `--config` {#arg-config}

- **དབྱེ་བ་:**ཡིག་སྣོད་འགྲོ་ལམ།
- **མིང་གཞན་:** `-c`

[མཉམ་རོགས་ཀྱི་སྒྲིག་འཇུག་](/dz/reference/peer-config/index.md) གི་ཡིག་སྣོད་ལམ།

## `--genesis-manifest-json` {#arg-genesis-manifest-json}

- **དབྱེ་བ་:**ཡིག་སྣོད་འགྲོ་ལམ།

གདམ་ཁའི་རིགས་མཚན་གསལ་སྟོན་ JSON མོས་མཐུན་བདེན་དཔྱད་ཀྱི་དོན་ལུ་ལག་ལེན་འཐབ་ཡོདཔ་ཨིན།

## `--check-config` {#arg-check-config}

ཐག་བཅད་ཡོད་པའི་རིམ་སྒྲིག་དང་འཐོབ་ཚུགས་པའི་རིགས་མཚན་རྒྱུ་ཆ་ཚུ་བདེན་དཔྱད་འབད་ཞིནམ་ལས་ ཡོངས་འབྲེལ་སོ་ཀེཊི་ཚུ་མ་བསྡམ་པར་ཕྱིར་འཐོན་འབད།

## `--json` {#arg-json}

- **དབྱེ་བ་:** གདམ་ཁའི་རྟགས
- **དགོཔ་:** `--check-config`

བཟོ་བསྐྲུན་འདི་དང་རིམ་སྒྲིག་གི་མཐུན་སྒྲིག་གནས་གོང་ཚུ་ `Ready` ཡང་ན་ `Pending` གྱི་གྱལ་ཚབ་ལུ་ Norito JSON དངོས་པོ་གཅིག་སྦེ་བཏོན།

## `--check-storage` {#arg-check-storage}

- **དབྱེ་བ་:** གདམ་ཁའི་རྟགས
- **མཉམ་སྦྲགས་མི་འབད་བ་:** `--check-config`

བཀག་བཞག་པའི་མཐུད་གནས་ཀྱི་ Kura མཛོད་དང་གནས་སྟངས་འདྲ་པར་གསར་ཤོས་འདི་ བཟོ་བསྐྲུན་འདིའི་ཨང་བཤུག་མ་ལག་གིས་ལྷག་ཙམ་སྦེ་ཞིབ་དཔྱད་འབད་ གྲུབ་འབྲས་འདི་ Norito JSON དངོས་པོ་གཅིག་སྦེ་བཏོན་ དེ་ལས་འཐུས་ཤོར་བྱུང་ན་ཀླད་ཀོར་མེན་པའི་ཨང་དང་གཅིག་ཁར་ཕྱིར་ཐོན་འབདཝ་ཨིན། ཞིབ་དཔྱད་ཀྱིས་ Kura མཛོད་རྩ་བའི་བཀག་སྡོམ་དབང་ཚད་ལེནམ་ལས་ ལཱ་འབད་བཞིན་པའི་མཐུད་གནས་ཀྱི་བདག་དབང་ནང་ཡོད་པའི་མཛོད་འདི་ངོས་ལེན་མི་འབད། འདི་གིས་མཛོད་ནང་ནམ་ཡང་བསྒྱུར་བཅོས་མི་འབད་ ལག་བསྟར་སྐབས་རྐྱངམ་ཅིག་གི་གསང་བ་ཚུ་ཡང་ནམ་ཡང་མི་ཁ་ཕྱེ།

## `--check-replay` {#arg-check-replay}

- **དབྱེ་བ་:** གདམ་ཁའི་རྟགས
- **མཉམ་སྦྲགས་མི་འབད་བ་:** `--check-config`, `--check-storage`

བཀག་བཞག་པའི་མཐུད་གནས་ཀྱི་མཛོད་འདྲ་བཤུས་ཅིག་ བཟོ་བསྐྲུན་འདི་གིས་ལོག་ལག་བསྟར་འབད་དེ་ གྲུབ་འབྲས་འདི་ Norito JSON དངོས་པོ་གཅིག་སྦེ་བཏོན། བཀོད་རྒྱ་གིས་སྡེབ་ཚན་ཚུ་གནས་སྐབས་སྣོད་ཐོ་ཅིག་ནང་འདྲ་བཤུས་འབད་ དེ་ཁར་གནས་སྟངས་འདྲ་པར་གསར་ཤོས་སླར་གསོ་འབད་ཡང་ན་མིང་རྟགས་བཀོད་པའི་འགོ་ཐོག་གནས་སྟངས་ལོག་ལག་བསྟར་འབད་ དེ་ལས་ཤུལ་མའི་སྡེབ་ཚན་རེ་རེ་ལོག་ལག་བསྟར་འབདཝ་ཨིན། སྡེབ་ཚན་ཅིག་གིས་དེའི་ངོས་སྦྱོར་ཅན་གྲུབ་འབྲས་ལོག་བཟོ་མ་ཚུགསཔ་ ཡང་ན་དགོ་པའི་སྡེབ་ཚན་ནང་དོན་མེདཔ་ད་ ཀླད་ཀོར་མེན་པའི་ཨང་དང་གཅིག་ཁར་ཕྱིར་ཐོན་འབདཝ་ཨིན། མཛོད་ནང་ནམ་ཡང་མི་འབྲི་ ལག་བསྟར་སྐབས་རྐྱངམ་ཅིག་གི་གསང་བ་ཚུ་ཡང་མི་ཁ་ཕྱེ།

## `--require-genesis-inrou-deployment-authority` {#arg-require-genesis-inrou-deployment-authority}

- **དགོཔ་:** `--check-config`

དྲ་མེད་བདེན་དཔྱད་སྐབས་ མིང་རྟགས་བཀོད་པའི་འགོ་ཐོག་གནས་སྟངས་ཏག་ཏག་ལག་བསྟར་འབད་ཚར་བའི་ཤུལ་ལུ་ ཐོ་བཀོད་འབད་བའི་རྩིས་ཐོ་འདི་གིས་ SoraCloud བཀྲམ་སྤེལ་གྱི་དབང་ཚད་བཞག་དགོཔ་སྦེ་བཟོ།

## `--sumeragi-assert-fresh-key` {#arg-sumeragi-assert-fresh-key}

- **དབྱེ་བ་:** གདམ་ཁའི་རྟགས

འགོ་བཙུགས་འདི་རྐྱངམ་ཅིག་ནང་ མཐུད་གནས་ཀྱི་མོས་མཐུན་ལྡེ་མིག་ཚུ་གིས་ སྡེབ་ཐག་འདིའི་དོན་ལུ་ཧེ་མ་ནམ་ཡང་མིང་རྟགས་མ་བཀོདཔ་སྦེ་ངེས་བདེན་བཀོད། Sumeragi གིས་ལྡེ་མིག་རེ་ལུ་ཉེན་སྲུང་ཐོ་ཡིག་རེ་བཞགཔ་ཨིནམ་དང་ ཐོ་ཡིག་མེད་ན་ དེ་བརླག་མ་སོང་བའི་སྒྲུབ་བྱེད་མ་ཐོབ་ཚུན་ག་ཅི་ལུ་ཡང་མིང་རྟགས་མི་བཀོད། ལྡེ་མིག་གསརཔ་གི་འགོ་བཙུགས་དང་པ་ལུ་ རྟགས་འདི་ཚར་གཅིག་བྱིན། གནད་སྡུད་བརླག་སོང་བའི་ཤུལ་ལུ་ནམ་ཡང་མ་བྱིན།

## `--trace-config` {#arg-trace-config}

- **དབྱེ་བ་:** དར་ཆ།
- མཐའ་འཁོར་གནས་སྟངས་: `TRACE_CONFIG`

རིམ་སྒྲིག་བང་རིམ་ཚུ་ལྷག་སྟེ་མིང་དཔྱད་འབད་བའི་སྐབས་ འཚོལ་ཞིབ་དྲན་ཐོ་ཚུ་ལྕོགས་ཅན་བཟོ།

## `--config-blake3` {#arg-config-blake3}

- **དབྱེ་བ་:** ༦༤-ཨང་གྲངས་བཅུ་དྲུག་ཅན་ BLAKE3 ཌའི་ཇེསཊ།
- **དགོས་མཁོ་:** `--config`

བཀྲམ་སྤེལ་འབད་ཡོད་པའི་ཌའི་ཇེསཊི་དང་མཐུན་སྒྲིག་འབད་ནི་ལུ་ རིམ་སྒྲིག་ཡིག་སྣོད་བཱའིཊི་ཚུ་དགོཔ་ཨིན། ཆིག་སྒྲིལ་-མཐུད་ཡོད་པའི་ཡིག་སྣོད་ཅིག་ ཕྲང་ཏང་ཏ་འབད་དགོཔ་ཨིན། དེ་ནང་ `extends` འོང་མི་ཚུགས།

## `--terminal-colors` {#arg-terminal-colors}

- **དབྱེ་བ་:** བུ་ལིན་, `--terminal-colors=true` ཡང་ན་ `--terminal-colors=false` སྦེ་སྤྲོད་ཡོདཔ་ཨིན།
- **སྔོན་སྒྲིག་:** ཊར་མི་ནཱལ་ལྕོགས་གྲུབ་བརྟག་དཔྱད།
- མཐའ་འཁོར་གནས་སྟངས་: `TERMINAL_COLORS`

ANSI-ཚོས་གཞི་ཐོན་འབྲས་ཚད་འཛིན་འབད།

## `--language` {#arg-language}

- **དབྱེ་བ་:** ཡིག་རྒྱུན།

ཌེ་མཱོན་འཕྲིན་དོན་ཚུ་གི་དོན་ལུ་ལག་ལེན་འཐབ་མི་རིམ་ལུགས་སྐད་ཡིག་འདི་བཀག་ཆ་འབད།

## `--sora` {#arg-sora}

- **དབྱེ་བ་:** དར་ཆ།
- མཐའ་འཁོར་གནས་སྟངས་: `IROHA_SORA_PROFILE`

SoraFS, SoraNet གི་འགོ་ཐོག་མཐུད་འབྲེལ་ དང་རྒྱུན་ལམ་མང་པོའི་མོས་མཐུན་ནང་ལག་ལེན་འཐབ་པའི་ SORA Nexus སྔོན་སྒྲིག་འདི་ལྕོགས་ཅན་བཟོ། Taira འགོ་བཙུགས་མ་ལག་འདི་ཨ་རྟག་ར་ རྟགས་འདི་དང་གཅིག་ཁར་འབོདཔ་ཨིན།

## FastPQ ཚད་འཛིན་འབད་ཐབས། {#fastpq-overrides}

`--fastpq-execution-mode <MODE>` དང་ `--fastpq-poseidon-mode <MODE>` གིས་ `cpu` ཡང་ན་ `gpu` རྐྱངམ་ཅིག་ངོས་ལེན་འབདཝ་ཨིན། ལྷག་ལུས་གདམ་ཁ་ཚུ་གིས་ ཊེ་ལི་མི་ཊི་རི་ཁ་ཡིག་ཚུ་ བཀག་ཆ་འབདཝ་ཨིན།

- `--fastpq-device-class <LABEL>`
- `--fastpq-chip-family <LABEL>`
- `--fastpq-gpu-kind <LABEL>`

དཔེར་ན་:

```shell
iroha3d --fastpq-execution-mode gpu \
  --fastpq-poseidon-mode cpu \
  --fastpq-device-class apple-m4 \
  --fastpq-chip-family m4 \
  --fastpq-gpu-kind integrated
```

## གྲོགས་རམ་ཐོན་ཡོདཔ་ཨིན། {#generated-help}

གོང་གི་གདམ་ཁའི་བཅུད་དོན་འདི་ གཏན་འཁེལ་བཞག་པའི་ Iroha བཟོ་བཅོས་ནང་གི་ `iroha3d` སྒྲུབ་རྟགས་ངེས་ཚིག་ཚུ་དང་འཁྲིལཝ་ཨིན། ཁྱོད་ཀྱི་ལས་ཀའི་འདྲ་བཤུས་དོན་ལུ་གྲོགས་རམ་ཏག་ཏག་ཞིབ་དཔྱད་འབད་ནི་ལུ་ འདི་གཡོག་བཀོལ།

```shell
cargo run --locked -p irohad --bin iroha3d -- --help
```
