# `iroha3d` CLI {#iroha3d-cli}

`iroha3d` འདི་ཚད་ལྡན་ Iroha 3 ཡོངས་འབྲེལ་མཉམ་རོགས་ཌེ་མཱོན་ཨིན། Cargo ཐུམ་སྒྲིལ་འདི་ `irohad` ཟེར་མིང་བཏགས་ཡོདཔ་ལས་ འབྱུང་ཁུངས་ཨང་རྟགས་ལཱ་འབད་མི་འདྲ་བཤུས་ཅིག་ལས་ གཉིས་ལྡན་འདི་ འདི་དང་གཅིག་ཁར་ འབོ་དགོ།

```shell
cargo run -p irohad --bin iroha3d -- --config path/to/config.toml
```

མི་མང་གི་ Taira བརྟག་དཔྱད་འབད་ཐངས་ཀྱི་དོན་ལུ་ པར་འདི་ `iroha3d_taira` ལག་ལེན་འཐབ་ཡོདཔ་ཨིན། འདི་ཡང་ CLI དེ་བཟུམ་བཟོཝ་ཨིན། འདི་ཡང་ Taira ལྕགས་ཐག་དང་ བདེན་ཁུངས་སྐྱེལ་འཕྲུལ་ཆས་ གཞི་སྒྲིག་ དེ་ལས་ ཐོ་བཀོད་འབད་ཐངས་ཀྱི་ལྡེ་མིག་ཚུ་ བཏོན་དོ་ཡོདཔ་ཨིན། ཁྱོད་ཀྱིས་ Taira སྒྲིག་གཞི་འདི་ སྒོ་བསྡམ་ནིའི་དུས་ཚོད་ཀྱི་ ངོས་འཛིན་ཚུ་ ཁ་ཕྱེ་མ་བཅུག་པར་ རྩ་སྒྲིག་འབད་:

```shell
iroha3d_taira --sora \
  --config /etc/iroha/taira/config.toml \
  --check-config
```

ལས་འཛིན་གྱིས་ ལག་ལེན་འཐབ་པའི་ཧེ་མར་ Taira གི་ཁྱད་ཐོ་ཚུ་བཏོན་དགོཔ་ཨིན། ཐོ་བཀོད་འབད་ཡོད་པའི་ དཔྱད་ཡིག་འདི་ནང་ལུ་ དཔེ་སྒྲོམ་ཚུ་ཡོདཔ་ཨིན། ལས་འཛིན་གྱིས་ དཔེ་སྟོན་བཀོད་ཐངས་ཚུ་ བསྒྱུར་བཅོས་འབད་དགོཔ་ཨིན། Nexus ཡང་ན་ བཟོ་སྐྲུན་གྱི་ SoraFS གཞི་སྒྲིག་ཚུ་ལག་ལེན་འཐབ་ནི་མི་འོང་། ཁྱོད་ཀྱིས་ Taira དང་གཅིག་ཁར་བརྟག་དཔྱད་འབདཝ་ད་

## `--config` {#arg-config}

- **དབྱེ་བ་:**ཡིག་སྣོད་འགྲོ་ལམ།
- **མིང་གཞན་:** `-c`

[མཉམ་རོགས་ཀྱི་སྒྲིག་འཇུག་](/dz/reference/peer-config/index.md) གི་ཡིག་སྣོད་ལམ།

## `--genesis-manifest-json` {#arg-genesis-manifest-json}

- **དབྱེ་བ་:**ཡིག་སྣོད་འགྲོ་ལམ།

གདམ་ཁའི་རིགས་མཚན་གསལ་སྟོན་ JSON མོས་མཐུན་བདེན་དཔྱད་ཀྱི་དོན་ལུ་ལག་ལེན་འཐབ་ཡོདཔ་ཨིན།

## `--check-config` {#arg-check-config}

ཐག་བཅད་ཡོད་པའི་རིམ་སྒྲིག་དང་འཐོབ་ཚུགས་པའི་རིགས་མཚན་རྒྱུ་ཆ་ཚུ་བདེན་དཔྱད་འབད་ཞིནམ་ལས་ ཡོངས་འབྲེལ་སོ་ཀེཊི་ཚུ་མ་བསྡམ་པར་ཕྱིར་འཐོན་འབད།

## Kagemusha ཁྱད་ཚད་ཀྱི་ལྡེ་མིག་ཚུ་ {#kagemusha-qualification-seals}

ཡིག་སྣོད་འགྲུལ་ལམ་གདམ་ཁ་འདི་ཚུ་ལུ་ `--check-config` དགོཔ་དང་ ཚད་ལྡན་མཚོན་རྟགས་མ་བྲིས་པའི་ཧེ་མ་ ཀ་གེ་མུ་ཤ་ཤེས་ཚད་ཆ་ཚང་འབད་དགོཔ་ཨིན།

- `--write-kagemusha-catalog-qualification-seal <PATH>` གིས་ ཐོ་གཞུང་འདི་ཤེས་ཚད་བཟོཝ་ཨིན།
- `--write-kagemusha-validator-qualification-seal <PATH>` གིས་ རིམ་སྒྲིག་འབད་ཡོད་པའི་མིང་རྟགས་བཀོད་ཡོད་པའི་ ཁྱབ་སྤེལ་བཀག་ཆ་ལུ་ ཉེ་གནས་བདེན་དཔྱད་འབད་མི་འདི་ ཤེས་ཚད་བཟོཝ་ཨིན།

མཚོན་རྟགས་གདམ་ཁ་གཉིས་གཅིག་གིས་གཅིག་ལུ་འགལ་འཛིང་འབདཝ་ཨིན།

## `--trace-config` {#arg-trace-config}

- **དབྱེ་བ་:** དར་ཆ།
- མཐའ་འཁོར་གནས་སྟངས་: `TRACE_CONFIG`

རིམ་སྒྲིག་བང་རིམ་ཚུ་ལྷག་སྟེ་མིང་དཔྱད་འབད་བའི་སྐབས་ འཚོལ་ཞིབ་དྲན་ཐོ་ཚུ་ལྕོགས་ཅན་བཟོ།

## `--config-blake3` {#arg-config-blake3}

- **དབྱེ་བ་:** ༦༤-ཨང་གྲངས་བཅུ་དྲུག་ཅན་ BLAKE3 ཌའི་ཇེསཊ།
- **དགོས་མཁོ་:** `--config`

བཀྲམ་སྤེལ་འབད་ཡོད་པའི་ཌའི་ཇེསཊི་དང་མཐུན་སྒྲིག་འབད་ནི་ལུ་ རིམ་སྒྲིག་ཡིག་སྣོད་བཱའིཊི་ཚུ་དགོཔ་ཨིན། ཆིག་སྒྲིལ་-མཐུད་ཡོད་པའི་ཡིག་སྣོད་ཅིག་ ཕྲང་ཏང་ཏ་འབད་དགོཔ་ཨིན། དེ་ནང་ `extends` འོང་མི་ཚུགས།

## `--terminal-colors` {#arg-terminal-colors}

- **དབྱེ་བ་:** བུ་ལིན་, `--terminal-colors=true` ཡང་ན་ `--terminal-colors=false` སྦེ་སྤྲོད་ཡོདཔ་ཨིན།
- **སྔོན་སྒྲིག་:** ཊར་མི་ནཱལ་ལྕོགས་གྲུབ་བརྟག་དཔྱད།
- མཐའ་འཁོར་གནས་སྟངས་: `TERMINAL_COLORS`

ANSI-ཚོས་གཞི་ཐོན་འབྲས་ཚད་འཛིན་འབད།

## `--language` {#arg-language}

- **དབྱེ་བ་:** ཡིག་རྒྱུན།

ཌེ་མཱོན་འཕྲིན་དོན་ཚུ་གི་དོན་ལུ་ལག་ལེན་འཐབ་མི་རིམ་ལུགས་སྐད་ཡིག་འདི་བཀག་ཆ་འབད།

## `--sora` {#arg-sora}

- **དབྱེ་བ་:** དར་ཆ།
- མཐའ་འཁོར་གནས་སྟངས་: `IROHA_SORA_PROFILE`

Sora Nexus འདྲ་བཤུས་འདི་སེལ་འཐུ་འབད། གནད་དོན་འདི་ SoraFS, SoraNet ལག་པའི་ལྕོགས་གྲུབ་དང་ ལེན་ལམ་མང་ཤོས་ཀྱི་མཐུན་རྐྱེན་ཚུ་ གཞི་སྒྲིག་འབད་ཡོདཔ་ཨིན། ཨ་རྟག་རང་འདི་ རྒྱལ༌དར༌ དང་གཅིག་ཁར་ Taira འགོ་འཛུགས་བྱེད བཏོན་གཏང་།

## FastPQ ཚད་འཛིན་འབད་ཐབས། {#fastpq-overrides}

`--fastpq-execution-mode <MODE>` དང་ `--fastpq-poseidon-mode <MODE>` གིས་ `cpu` ཡང་ན་ `gpu` རྐྱངམ་ཅིག་ངོས་ལེན་འབདཝ་ཨིན། ལྷག་ལུས་གདམ་ཁ་ཚུ་གིས་ ཊེ་ལི་མི་ཊི་རི་ཁ་ཡིག་ཚུ་ བཀག་ཆ་འབདཝ་ཨིན།

- `--fastpq-device-class <LABEL>`
- `--fastpq-chip-family <LABEL>`
- `--fastpq-gpu-kind <LABEL>`

དཔེར་ན་:

```shell
iroha3d --fastpq-execution-mode gpu \
  --fastpq-poseidon-mode cpu \
  --fastpq-device-class apple-m4 \
  --fastpq-chip-family m4 \
  --fastpq-gpu-kind integrated
```

## གྲོགས་རམ་ཐོན་ཡོདཔ་ཨིན། {#generated-help}

གོང་ལུ་ཡོད་པའི་གདམ་ཁའི་བཅུད་དོན་འདི་ ད་ལྟོའི་`iroha3d` སྒྲུབ་རྟགས་ངེས་ཚིག་ཚུ་ལུ་བདེན་དཔྱད་འབད་ཡོདཔ་ཨིན། བརྟག་ཞིབ་འབད་ཡོད་པའི་ བཟོ་བཏོན་འབད་ཡོད་པའི་གྲོགས་རམ་པར་འདི་ དེ་གི་འབྱུང་ཁུངས་གནས་རིམ་འདི་ བསྒུག་སྡོད་པའི་སྐབས་ ཤེས་བཞིན་དུ་ བཀྲམ་སྟོན་འབད་མི་བཏུབ། ཁྱོད་རའི་བརྟག་ཞིབ་ཀྱི་དོན་ལུ་ གྲོགས་རམ་ངེས་བདེན་ཞིབ་དཔྱད་འབད་ནི་ལུ་ གཡོག་བཀོལ་:

```shell
cargo run --locked -p irohad --bin iroha3d -- --help
```
