# ངོས་ལེན་རྟགས་ཚུ་ {#permission-tokens}

## ཚོང་འབྲེལ་འཐབ་ནི་ {#ownership}

བདག་འཛིན་འཐབ་མི་གི་དོན་ལུ་ གོ་སྐབས་གི་རྟགས་མཚན་ཚུ་གིས་ ད་ལྟོའི་གནས་སྡུད་བཟོ་རྣམ་ནང་ ལག་ལེན་འཐབ་མི་ ཀ་ནོ་ནི་ཀཱན་གྱི་དངོས་པོ་ IDs ལུ་ཁ་བསྒྱུར་འབད་དགོཔ་ཨིན། དཔེར་ན་རྩིས་ཁྲའི་ཆོག་ཐམ་ཚུ་ ཀ་ནོནོ་ནིཀཱན་གྱི་ས་ཁོངས་མེད་པའི་རྩིས་ཁྲ་ IDs དང་ ས་ཁོངས་ཀྱི་ཆོག་ཐམ་ཚུ་ `domain.dataspace` ས་ཁོངས་ IDs ལུ་ཁ་བསྒྱུར་འབདཝ་ཨིན། དང་ རྒྱུ་དངོས་གི་ཆོག་ཐམ་ཚུ་ ཀ་ནོ་ནི་ཀཱན་གྱི་ རྒྱུ་དངོས་གི་འགྲེལ་བཤད་ ཡང་ན་ རྒྱུ་དངོས་ IDs ལུ་ཁ་བསྒྱུར་འབདཝ་ཨིན།

ཚོང་འབྲེལ་ཅིག་ལུ་ ངོས་ལེན་གྱི་འཛོལ་བ་བྱུང་པའི་སྐབས་ ཕྱོགས་གཉིས་ཆ་རང་ལུ་ བརྟག་ཞིབ་འབད་:

- ཚོང་འབྲེལ་གྱི་མིང་རྟགས་བཀོད་མི་རྩིས་དེ་ རེ་བ་ཅན་གྱི་ཡིག་ཚང་གི་རྩིས་ཁྲམ་ཨིན།
- བཀའ་རྒྱ་ནང་ལག་ལེན་འཐབ་མི་ གནད་དོན་ངོ་མ་ ID གི་དོན་ལུ་ ངོས་ལེན་གྱི་རྟགས་མཚན་དང་ འགན་འཁྲི་བྱིན་ཡོདཔ་ཨིན།
