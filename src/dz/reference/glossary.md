## blockchain ledgers {#blockchain-ledgers}

Blockchain ledgers འདི་ དངུལ་རྩིས་ཀྱི་ཐོ་ཡིག་ཚུ་འཛིན་བཟུང་འབད་ནིའི་དོན་ལུ་ blockchain འཕྲུལ་རིག་ལག་ལེན་འཐབ་མི་ ཌི་ཇི་ཊཱལ་གྱི་ཐོ་ཡིག་བཀོད་ཐངས་ཚུ་ཨིན། འ་ནི་འདི་ཚུ་ དངུལ་འབྲེལ་གི་ཐོ་ཡིག་ཚུ་གི་དོན་ལུ་ ལག་ལེན་འཐབ་མི་ དཔེ་དེབ་རྙིང་པའི་མིང་སྦེ་བཏགས་ཡོདཔ་ཨིན། དཔེར་ན་ གོང་ཚད་དང་ གནས་ཚུལ་ དེ་ལས་ ཚོང་འབྲེལ་གྱི་ བརྡ་དོན་ཚུ་ཨིན་མས།

དུས་དཀྱིལ་དབུས་ཀྱི་དུས་སྐབས་ལུ་ མཁའ་འགྲོ་གི་དེབ་ཚུ་ མི་མང་གིས་བལྟ་ནི་དང་ དངོས་གྲུབ་བརྟག་དཔྱད་འབད་ནིའི་དོན་ལུ་ སྒོ་ཕྱེ་ཡོདཔ་ཨིན། འ་ནི་བསམ་འཆར་འདི་ blockchain གཞི་བཙུགས་འབད་མི་ལམ་ལུགས་ཚུ་ནང་ལུ་ གསལ་སྟོན་འབདཝ་ཨིན་ འདི་གིས་ གནས་སྡུད་དེ་ ཆ་གནས་ཡོད་མེད་ལུ་ བརྟག་ཞིབ་འབད་ཚུགས།

## འདྲན་འདྲ་ {#peer}

Iroha ནང་ལུ་ འདྲན་འདྲ་བཟོ་ནི་དེ་ Iroha བྱ་རིམ་གྱི་ལེའུ་ཨིནམ་ད་ གཞན་ Iroha བྱ་རིམ་དང་ མགྲིན་ཚབ་ཀྱི་ལག་ལེན་ཚུ་འབྲེལ་མཐུད་འབད་ཚུགསཔ་ཨིན། འཕྲུལ་ཆས་གཅིག་གིས་ Iroha གི་འདྲན་འདྲ་ཚོགས་མང་རབས་ཅིག་ལུ་གཞི་བཙུགས་འབད་ཚུགས། གྲྭ་ཚང་ཚུ་ ཁོང་རའི་ ཐོན་ཁུངས་དང་ལྕོགས་གྲུབ་ཀྱི་ཐད་ལུ་ འདྲན་འདྲ་ཨིན། ཁྱད་པར་སྦོམ་ཅིག་ལས་བརྒལ་མེད་: གྲྭ་ཚང་ཚུ་གི་གྲལ་ལས་གཅིག་རྐྱངམ་གཅིག་གིས་ genesis block འདི་ Iroha ネットワークགི་ bootstrapping stage ལུ་ལག་ལེན་འཐབ་དོ་ཡོདཔ་ཨིན།

གཞན་མི་ blockchains གིས་ node ཡང་ན་ validator ཚུ་དང་འདྲན་འདྲ་ཅིག་ལུ་ཁ་བསྒྱུར་འབད་ཚུགས།

འདི་ཡང་ Docker container དང་ Kubernetes pod ནང་བཙུགས་འབད་ཡོདཔ་ཨིན།

## རྒྱུ་དངོས་ཚུ་ {#asset}

blockchain གི་ནང་དོན་ནང་ལུ་ རྒྱུ་དངོས་འདི་ blockchain ནང་རིན་གོང་ཅན་གྱི་དངོས་པོ་ཅིག་གི་ངོ་ཚབ་ཨིན།

རྒྱུ་དངོས་ཚུ་གི་སྐོར་གྱི་ལྷག་པའི་ བརྡ་དོན་ཚུ་ [འདི་ནང་ལུ་ ](/dz/blockchain/assets.md) མཐོངམ་ཨིན།

### དངུལ་རྐྱང་གི་རྒྱུ་དངོས་ཚུ་ {#fungible-assets}

འདི་བཟུམ་མའི་ རྒྱུ་དངོས་ཚུ་ གཅིག་གིས་གཅིག་ལུ་ བརྗེ་སོར་འབད་ཚུགས་ནི་དེ་གིས་ དེ་བཟུམ་གྱི་རྒྱུ་དངོས་གཞན་གྱི་ཚབ་ལུ་ སྟབས་བདེ་དྲགས་སྦེ་ བསྒྱུར་བཅོས་འབད་ཚུགས།

དཔེ་གཅིག་འབད་བ་ཅིན་ དངུལ་རྐྱང་གི་ ཡུ་ནིཊ་ཆ་མཉམ་དེ་ ཁོང་རའི་གོང་ཚད་ནང་འདྲན་འདྲ་ཡོདཔ་ལས་ ཅ་ཆས་ཉོ་ནིའི་དོན་ལུ་ ལག་ལེན་འཐབ་ཚུགསཔ་ཨིན། སྤྱིར་བཏང་ལུ་དངུལ་ཀྲམ་དང་དངུལ་ཀྲམ་ཚུ་ མཚམས་འཇོག་འབད་མི་དེ་མ་གཏོགས་ མཐོང་སྣང་ནང་ལུ་ fungible assets འདྲ་མཚུངས་ཨིན།

### དངུལ་རྐྱང་གི་རྒྱུ་དངོས་ཚུ་ {#non-fungible-assets}

འགྱུར་བ་མེད་པའི་རྒྱུ་དངོས་ཚུ་ ཁོང་རའི་ཁྱད་ཆོས་དང་ ཉུང་མཐོངམ་ལུ་བརྟེན་ ཁྱད་དུ་འཕགས་ཏེ་ བརྩི་མཐོང་ཅན་ཨིན། ཁོང་གི་གོང་ཚད་འདི་ རྒྱུ་དངོས་གཞན་ཚུ་དང་གཅིག་ཁར་བསྡོམས་མི་ཚུགས།

- སྒྱུ་རྩལ་གྱི་རིན་གོང་འདི་ བཟོ་སྐྲུན་འབད་མི་དང་ དུས་ཡུན་ག་དེམ་ཅིག་ནང་ བཟོ་བཀོད་འབད་ཡོདཔ་ དེ་ལས་ མི་སེར་ཚུ་གིས་ སྤྲོ་བ་བསྐྱེད་མི་དང་འཁྲིལ་ཏེ་ ཁྱད་པར་ཅན་ཨིན།
- ཁྲོམ་ལམ་གཅིག་ནང་ཡོད་མི་ ཁྱིམ་གཉིས་ལུ་ བཟོ་སྐྲུན་གྱི་གནས་ཚད་ཁྱད་པར་ཅན་ཅིག་ཡོདཔ་ཨིན།
- རྒྱན་ཆས་བཟོ་སྐྲུན་འབད་མི་ཚུ་གིས་ མང་ཤོས་ར་ བཟོ་བཀོད་མ་འདྲཝ་ཚུ་ གྲ་སྒྲིག་འབདཝ་ཨིན།

### སྲུང་སྐྱོབ་འབད་ཚུགས་པའི་རྒྱུ་དངོས་ཚུ་ {#mintable-assets}

བྱ་རིམ་འདི་ གྲོས་བསྟུན་འབད་ནིའི་ དཔའ་བཅམ་མ་ཚུགས་པའི་སྐབས་ལུ་ འབྱུང་དོ་ཡོདཔ་ཨིན། འདི་ཨ་རྟག་རང་ [Leader](#leader) གསར་བཙུགས་འབད་དགོཔ་ཨིན།

## འཛམ་གླིང་གནས་སྟངས་ཀྱི་མཐོང་སྣང་ (WSV) {#world-state-view-wsv}

གནས་སྐབས་ཀྱི་ blockchain གི་གནས་སྟངས་ལུ་ ནང་དྲན་ནང་ལུ་ངོ་སྤྲོད་འབད་ཡོདཔ་ཨིན། WSV འདི་ནང་ `World`, commited block hashes, transaction index, consensus topology དང་ queries ཀྱིས་ལག་ལེན་འཐབ་མི་ derived indexཚུ་ ཡོདཔ་ཨིན། འདི་གིས་ ཁས་བླངས་ཅན་གྱི་ བཀྲམ་སྤེལ་གྱི་ཐོག་ལས་རྐྱངམ་གཅིག་ ད་ལྟོའི་བར་ན་ཡང་བཟོ་བཀོད་འབད་ཚུགས་ནི་ཨིནམ་ད་ [Kura](#kura-warehouse) མཐོང་ [World State View](/dz/blockchain/world.md#world-state-view-wsv)

## འགོ་དཔོན་ {#leader}

Iroha ネットワークནང་ལུ་ གྲྭ་ཚང་ཅིག་ རང་བཞིན་གྱིས་གདམ་ཁ་འབད་ཞིནམ་ལས་ བཀྲམ་སྤེལ་འབད་ནིའི་ ཁྱད་དུ་འཕགས་ཐོབ་སྐལ་ཐོབ་ཡོདཔ་ཨིན། འ་ནི་ཐོབ་ཐངས་འདི་ མཁོ་སྒྲུབ་འབད་ཚུགས་པའི་ འབྲེལ་མཐུད་ཚུ་ནང་ལུ་ [Byzantine fault-torelance](#byzantine-fault-tolerance-bft) བརྒྱུད་ལས་ [མཐོང་སྣང་བསྒྱུར་བཅོས་](#view-change).
