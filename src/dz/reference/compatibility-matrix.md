# མཐུན་རྐྱེན་མ་ཊིཀསི་ {#compatibility-matrix}

མཐུན་རྐྱེན་མ་ཊིརི་ཀསི་གིས་ ད་ལྟོའི་ Iroha 3 ཌོག་གི་བཅུད་ཀྱི་དོན་ལུ་ cross-SDK གནས་སྟངས་ཁྱབ་སྒྲགས་སྟོན་འབདཝ་ཨིན། སྔོན་སྒྲིག་ཐོག་ལས་, ཤོག་ལེབ་འདི་གིས་ [`hyperledger-iroha/iroha`](https://github.com/hyperledger-iroha/iroha) བསྐྱར་ཞིབ་ནང་ལས་ ཐོན་སྐྱེད་འབད་ཡོད་པའི་ གློག་བརྙན་གློག་འཕྲོད་འདི་ཨེབ་གཏང་འབདཝ་ཨིན།

རྩིག་ཁྲམ་འདི་ནང་ལུ་:

- ལོ་རྒྱུས་ཚུ་ ཀི་ལོ་མི་ཊར་༡ པའི་ནང་
- SDKs ཀི་ལོ་མི་ཊར་༡༠༠ གི་རིང་ལུ་
- གནས་སྟངས་ཀྱི་ རྟགས་མཚན་ཚུ་ སྦ་བཞག་མི་དང་ བརྗོད་མ་བྱུང་མི་ དེ་ལས་ མེདཔ་སོང་མི་ གནད་དོན་ཚུ་གི་དོན་ལུ་

བསྐྱར་ཞིབ་འབད་ཐངས་ལས་གྲུབ་པའི་ གྲུབ་འབྲས་ཚུ་རྐྱངམ་གཅིག་ བསྡུ་བསྒྱོམ་འབད་ནི་དང་ ཡང་ན་ བསྒྱུར་བཅོས་འབད་མི་སྦེ་ སྙན་ཞུ་འབད་ནི་ཨིན། བསྒྱུར་བཅོས་འབད་ཐངས་ལུ་ཁུངས་མེད་པའི་ གནས་སྟངས་འདི་ གཞི་རྟེན་བསྐྱར་བཅོས་གཞན་གྱི་ གྲུབ་འབྲས་འཐོབ་ནིའི་ཚབ་ལུ་ མ་ཐོབ་མི་ གནད་དོན་ཅིག་སྦེ་སྟོན་འོང་།
