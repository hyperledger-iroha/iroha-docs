# མཐུན་རྐྱེན་མ་ཊིཀསི་ {#compatibility-matrix}

མཐུན་སྒྲིག་མེ་ཊིགསི་གིས་ ད་ལྟོའི་ Iroha 3 ཡིག་ཆ་ཆ་ཚན་གྱི་དོན་ལུ་ ཕར་ཚུར་ SDK གནས་སྟངས་ཁྱབ་ཚད་སྟོནམ་ཨིན། སྔོན་སྒྲིག་གིས་ ཤོག་ལེབ་འདི་གིས་ པིན་འབད་ཡོད་པའི་ [`hyperledger-iroha/iroha`](https://github.com/hyperledger-iroha/iroha) བསྐྱར་ཞིབ་ལས་ བཟོ་བཏོན་འབད་ཡོད་པའི་ བཱན་ཌི་འབད་ཡོད་པའི་ དུས་ཚོད་ཀྱི་གནད་སྡུད་མཐོང་སྣང་འདི་ མངོན་གསལ་འབདཝ་ཨིན།

མེ་ཊིགསི་འདི་ལས་གྲུབ་ཡོད།

- **གཏམ་རྒྱུད།** ཀེར་ཐིག་དང་པོའི་ནང་།
- ཀེར་ཐིག་ལྷག་ལུས་ཚུ་བརྒལ་ཏེ་ **SDKs**
- **གནས་ཚད་བརྡ་མཚོན་** བཀབ་ཡོད་མི་དང་ འཐུས་ཤོར་བྱུང་མི་ དེ་ལས་ གནད་སྡུད་བརླག་སྟོར་ཞུགས་མི་ཚུ་གི་དོན་ལུ་

གསར་བསྐྲུན་ལཱ་གི་རྒྱུན་རིམ་གྱིས་བདེན་དཔྱད་འབད་ཡོད་པའི་གྲུབ་འབྲས་ཚུ་རྐྱངམ་ཅིག་ ཁྱབ་ཡོདཔ་ཡང་ན་ འཐུས་ཤོར་བྱུང་ཡོདཔ་སྦེ་སྙན་ཞུ་འབདཝ་ཨིན། བསྐྱར་ཞིབ་འབད་ནི་གི་དོན་ལས་ སྒྲུབ་བྱེད་མེད་པའི་གནས་སྟངས་ཚུ་ གཞན་མི་འབྱུང་ཁུངས་བསྐྱར་ཞིབ་ལས་ གྲུབ་འབྲས་ཚུ་ ཤུལ་འཛིན་འབད་ནི་མེན་པར་ གནས་སྡུད་མེདཔ་སྦེ་སྟོནམ་ཨིན།
