# Torii API ཀོ་ནི་ཟོལ {#torii-api-console}

གློག་ཐག་འདི་ལག་ལེན་འཐབ་ OpenAPI སྒྲིག་གཞི་ཅིག་ལས་ཐོན་ཡོདཔ་ཨིན། Torii མཐའན་མཇུག་གི་སྒོ་སྒྲིག་ཚུ་ བརྟག་ཞིབ་འབད་ནི་དང་ བརྟག་དཔྱད་གྱི་ཞུ་ཡིག་གཏང་ནི་ དེ་ལས་ ཨེབ་གཏང་འབད་ནི་ curl བཀའ་རྒྱ་ཚུ་ བཏོན་ཞིནམ་ལས་ ཁྱོད་ཀྱིས་ ཞབས་ཏོག་ལེན་མི ལས་རིམ་ཨང་རྟགས བཟོ་ཚུགས།

## དགོས་མཁོ་ཚུ་ {#requirements}

- Torii མཐའ་མཇུག་གི་ཐིག་ཁྲམ་ནང་ `/openapi.json` གསལ་སྟོན་འབད་དགོ།
- བརྡ་འཚོལ་བརྟག་དཔྱད་ལུ་ ཡིག་ཆ་འདི་འབྱུང་བཅུག་ནིའི་དོན་ལུ་ CORS དགོཔ་ཨིན།
- བརྡ་འཚོལ་འདི་ ཐད་ཀར་དུ་ མཐའ་མཚམས་ལུ་ལྷོད་ཚུགས་དགོ།
- ཀོ་ཌ་བཟོ་སྐྲུན་ལུ་ Node.js, pnpm དེ་ལས་ OpenAPI བཟོ་བྱེདགི་དོན་ལུ་ Java ལག་བསྟར་མཉེན་ཆས དགོཔ་ཨིན།

བཀོལ་སྤྱོད་སྒྲོམ འདི་ སྔོན་སྒྲིགསྦེ་ `https://taira.sora.org` ལུ་འབདཝ་ཨིན། ས་གནས་བཟོ་སྐྲུན་འདི་ འཕྲུལ་ཆས་ནང་ལུ་ ཁྱོད་ཀྱིས་ Torii རྒྱུག་པའི་སྐབས་ སྤྱིར་བཏང་ལུ་ `http://127.0.0.1:8080` ལུ་ལཱ་འབད་འོང་།

## དང་པ་ར་ Taira བརྟག་དཔྱད་འབད་ {#try-taira-first}

ཁྱོད་ཀྱིས་ ཞབས་ཏོག་ལེན་མི བཟོ་མ་ཚར་བའི་ཧེ་མར་ ཁྱོད་ཀྱིས་ མི་མང OpenAPI ཡིག་ཆ འདི་ཁྱོད་ཀྱི་འཕྲུལ་ཆས་ནང་ལས་ལག་ལེན་འཐབ་ཚུགསཔ་ཨིན་ན་བརྟག་དཔྱད་འབད་:

```bash
curl -fsS https://taira.sora.org/openapi.json -o /tmp/taira-openapi.json
jq '{title: .info.title, version: .info.version, paths: (.paths | length)}' \
  /tmp/taira-openapi.json
```

དེ་ལས་ `https://taira.sora.org/openapi.json` འདི་ བཀོལ་སྤྱོད་སྒྲོམ ནང སྦྱར འབད་ཞིནམ་ལས་ `GET /status`, `GET /v1/domains` ཡང་ན་ `GET /v1/assets/definitions` བཟུམ་གྱི ཀློག-ལྷག་ནི་རྐྱངམ་གཅིག་གི་ རྒྱུན་ལམ ཅིག་བརྟག་དཔྱད་འབད། མིང་རྟགས་བཀོད་ཡོད ཚོང་འབྲེལ དང་ སྒེར-ལྡེ་མིག བྱ་རིམ་ཚུ ཚུ་ ལག་བསྟར་མཉེན་ཆས མཐའ་འཁོར ནང་ལས གསང་བ ལེན་མི་ SDK ཡང་ན་ CLI ཞབས་ཏོག་ལེན་མི གི་དོན་ལུ་བཞག།

## བཟོ་སྐྲུན་འབད་མི་ ཚོང་མགྲོན་པ་ {#generated-clients}

ཇི་ནེ་རེ་ཊར་གྱི་བཀའ་རྒྱ་འདི་ བཀོལ་སྤྱོད་སྒྲོམ ལུ་ཨེབ་གཏང་འབད་ཡོད་པའི་ OpenAPI ཡིག་ཆ་དེ་རང་ ལག་ལེན་འཐབ་ཨིན། འདི་ JSON ལས་འཛིན་, འཚོལ་ཞིབ་ལས་རིམ, གློག་རིམ, དང་ རྒྱང་ཚད་གནད་སྡུད ཕྲང་ལམ་ཚུ་གི་དོན་ལུ་ཕན་ཐོགས་ཡོདཔ་ཨིན།

ཐོ་བཀོད་ཅན་གྱི་རྩིས་དེབ་ཕྱིར་ཚོང་ ཐོ་བཀོད་ཅན་གྱི་དྲི་བ་ དེ་ལས་ Norito རང་ལུགས་ཀྱི ནང་དོན་གནད་སྡུད ཚུ་གི་དོན་ལུ་ གཏན་འཁེལ་ཅན་གྱི Iroha SDKs གདམ་ཁ་རྐྱབས། OpenAPI ཚོང་མགྲོན་པ་ཚུ་གིས་ མཚན་རྟགས་བཟོ་ནི་ རྩིས་ཐོའི་ལྡེ་མིག་འཛིན་སྐྱོང་འབད་ནི་ ཡང་ན་ Norito ཚོང་འབྲེལ་གྱི་གཟུགས་ཚུ་ཨེན་ཀོཌ་འབད་མི་ཚུགས།

OpenAPI ཇི་ནེརེ་ཊར་གིས་ རྒྱབ་སྐྱོར་འབད་མི་ཇི་ནེརེ་ཚུ་ བརྟག་ཞིབ་འབད་ནིའི་དོན་ལུ་:

```bash
pnpm dlx @openapitools/openapi-generator-cli list
```
