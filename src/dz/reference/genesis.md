# འགོ་ཐོག་བཀག་རྡོག་གི་གཞི་བསྟུན་ {#genesis-reference}

ད་ལྟོའི་ Iroha 3 ལཱ་རིམ་ནང་ `genesis.json` གསལ་སྟོན་ཡིག་ཆ གིས་ དྲ་རྒྱ འགོ་བཙུགསཔ་ད་འཇུག་སྤྱོད་འབད་ནིའི་འགོ་ཐོག་ཚོང་འབྲེལ་དང་ཚད་བཟུང་ཚུ་བཤདཔ་ཨིན།

མཉམ་རོགས་ཚུ་ལུ་བཀྲམ་སྤེལ་འབད་ཡོད་པའི་མིང་རྟགས་བཀོད་ཡོད་པའི་དངོས་པོ་འདི་ `.nrt` གིས་བཟོ་མི་ Norito-ཨང་སྒྱུར་འབད་ཡོད `kagami genesis sign` ཡིག་སྣོད་ཨིན།

## ས་སྒོ་གཙོ་བོ། {#main-fields}

རིགས་མཚན་གསལ་སྟོན་གྱིས་ངེས་ཚིག་འགྲེལ་ཚུགས།

- རིམ་སྒྲིག་ངོས་འཛིན་འབད་མི་གི་དོན་ལུ་ `chain`
- གདམ་ཁ་ཅན་གྱི་ལག་ལེན་འཐབ་མི་ཡར་བསྐྱེད་བཱའིཊི་ཀོཌི་འགྲུལ་ལམ་གྱི་དོན་ལུ་ `executor`
- `ivm_dir` དོན་ལུ་ IVM ཊི་གར་དང་ཡར་བསྐྱེད་ཚུ་གིས་ལག་ལེན་འཐབ་མི་དཔེ་མཛོད་ཚུ།
- `consensus_mode` གསལ་སྟོན་གྱིས་ཁྱབ་བསྒྲགས་འབད་ཡོད་པའི་འགོ་ཐོག་ཐབས་ལམ་གྱི་དོན་ལུ་
- བཀོད་སྒྲིག་འབད་ཡོད་པའི་ཚད་གཞི་དུས་མཐུན་བཟོ་ནི་དང་ བཀོད་རྒྱ་ འབྱུང་ཁུངས་ཚུ་ དེ་ལས་ ཊོ་པོ་ལོ་ཇི་ཚུ་གི་དོན་ལུ་ `transactions`
- འགོ་ཐོག་ཀིརིཔ་ཊོ་པར་ལེན་གྱི་དོན་ལུ་ `crypto`

ནང་འཁོད `transactions`, ཊོ་པོ་ལོ་ཇི་ཐོ་བཀོད་ཚུ་ མཐུད་མཚམསའི་ཨའི་ཌི་ཚུ་དང་ PoPs གཅིག༌ཁར:

```json
{
  "peer": "ea0130...",
  "pop_hex": "0xabcd..."
}
```

## གསལ་སྟོན་ཅིག་བཟོ་བཏོན་འབད། {#generate-a-manifest}

ལག་ལེན་འཐབ་ནི Kagami ཊེམ་པེལེཊི་ཅིག་བཟོ་བཏོན་འབད་ནི་ལུ་:

```bash
cargo run -p iroha_kagami -- genesis generate \
  --consensus-mode npos \
  --ivm-dir defaults \
  --genesis-public-key <PUBLIC_KEY> > genesis.json
```

མི་མང་གི་དོན་ལུ། SORA Nexus གནད་སྡུད་ས་སྟོང་, `npos` འདི་ རེ་བ་བསྐྱེད་པའི་མོས་མཐུན་ཐབས་ལམ་ཨིན། གཞན Iroha 3 བཀྲམ་སྤེལ་ཚུ་གིས་ དམིགས་གཏད་ལུ་གཞི་བཞག་སྟེ་ གནང་བ་ཡོད་མི་ཡང་ན་ ཨེན་པི་ཨོ་ཨེསི་ལག་ལེན་འཐབ་བཏུབ། གདོང་ཤོག།

## ཁས་བླངས་གསལ་བསྒྲགས་ལུ་མིང་རྟགས་བཀོད། {#sign-the-manifest}

JSON ཞུན་དག་དང་བདེན་དཔྱད་འབད་བའི་ཤུལ་ལས་ བཀྲམ་སྤེལ་འབད་བཏུབ་པའི་ `.nrt` སྡེབ་ཚན་ནང་ལུ་ མིང་རྟགས་བཀོད།

```bash
cargo run -p iroha_kagami -- genesis sign genesis.json \
  --private-key-file <MODE_0600_PRIVATE_KEY_FILE> \
  --out-file genesis.signed.nrt
```

`kagami genesis sign` གིས་ འཕྲུལ་རིག་གསལ་བསྒྲགས་ལས་ བཀག་ཆ་རིགས་མཚན་གྱི་མི་མང་ལྡེ་མིག་ལྷག་སྟེ་ བཀྲམ་སྤེལ་འབད་བཏུབ་པའི་ མིང་རྟགས་བཀོད་ཡོད་པའི་སྡེབ་ཚན་བཟོ་ནིའི་དོན་ལུ་ ཇོ་བདག་གིས་ བདག་འཛིན་འཐབ་མི་ འབྲེལ་ལམ་གཅིག་པའི་ དུས་རྒྱུན་ཡིག་སྣོད་ལས་ སྒེར་གྱི་ལྡེ་མིག་ལག་ལེན་འཐབ་ཨིན། ཡིག་སྣོད་འདི་ནང་ ཚད་ལྡན་སྒེར་གྱི་ལྡེ་མིག་གཅིག་ multihash དེ་གི་ཤུལ་ལས་ གྲལ་ཐིག་གསརཔ་ཅིག་འོང་དགོ། Kagami གིས་ `0600` ལས་ལྷག་པའི་བརྡ་མཚོན་འབྲེལ་ལམ་དང་ཐབས་ལམ་ཚུ་ ངོས་ལེན་མི་འབད། བརྡ་བཀོད་གྲལ་ཐིག་གུ་ སྒེར་དོན་ལྡེ་མིག་སྔོ་མ་ཚུ་ ངོས་ལེན་མི་འབད། གྲུབ་འབྲས་འདི་ ཡོངས་འབྲེལ་ཆ་རོགས་ཚུ་གིས་ ཁོང་རའི་རིམ་སྒྲིག་ལས་ གཞི་བསྟུན་འབད་དགོ་པའི་ཡིག་སྣོད་འདི་ཨིན།

## རིམ་སྒྲིག་འབད། `iroha3d` {#configure-iroha3d}

མིང་རྟགས་བཀོད་ཡོད་པའི་རིགས་མཚན་སྡེབ་ཚན་ནང་ལུ་ ཌེ་མཱོན་འདི་སྟོན།

```toml
[genesis]
file = "genesis.signed.nrt"
public_key = "<PUBLIC_KEY>"
```
