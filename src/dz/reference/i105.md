## IDs བཟོ་ནི་དང་བརྟག་དཔྱད་འབད་ CLI དང་གཅིག་ཁར་ {#create-and-inspect-ids-with-the-cli}

མི་མང་ཡོངས་འབྲེལ་གྱི་དོན་ལུ་ མིང་བཏགས་ཡོད་པའི་གསལ་སྡུད་ཅིག་དགའ་གདམ་འབད།

```bash
PUBLIC_KEY='ed01203B6A27BCCEB6A42D62A3A8D02A6F0D73653215771DE243A63AC048A18B59DA29'

TAIRA_ACCOUNT_ID="$(
  iroha tools address convert --profile taira "$PUBLIC_KEY"
)"

MINAMOTO_ACCOUNT_ID="$(
  iroha tools address convert --profile minamoto "$PUBLIC_KEY"
)"
```

ཁ་བྱང་-ཀོ་ཌེཀ་སྤྱོད་ལམ་བརྟག་དཔྱད་འབད་བའི་སྐབས་ I105 ཨིན་པུཊི་ཅིག་ སྤྱིར་བཏང་བཟོ་ནི་དང་ག་བསྡུར་འབད།

```bash
NORMALIZED_ACCOUNT_ID="$(
  printf '%s\n' "$TAIRA_ACCOUNT_ID" \
    | iroha tools address normalize --profile taira
)"

test "$NORMALIZED_ACCOUNT_ID" = "$TAIRA_ACCOUNT_ID"
```

དྭངས་འཕྲོས་འཕྲོས་བཟོ་རྣམ་དང་ ཚད་ལྡན་གྱི་ བཅུ་དྲུག་རྟེན དེ་ལས་ གདམ་ཁ་རྐྱབ་མི་ དྲ་རྒྱ འབྲེལ་བའི་གནས་སྟངས་འདི་ JSON སྦེ་བརྟག་དཔྱད་འབད་:

```bash
iroha tools address convert \
  --profile taira \
  --format json \
```
