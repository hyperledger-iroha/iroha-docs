## IDs བཟོ་ནི་དང་བརྟག་དཔྱད་འབད་ CLI དང་གཅིག་ཁར་ {#create-and-inspect-ids-with-the-cli}

མི་མང་གི་དྲ་རྒྱ་གི་དོན་ལུ་ མིང་བཏགས་མི་ཡིག་གཟུགས་འདི་ གདམ་ཁ་རྐྱབས།

```bash
PUBLIC_KEY='ed01203B6A27BCCEB6A42D62A3A8D02A6F0D73653215771DE243A63AC048A18B59DA29'

TAIRA_ACCOUNT_ID="$(
  iroha tools address convert --profile taira "$PUBLIC_KEY"
)"

MINAMOTO_ACCOUNT_ID="$(
  iroha tools address convert --profile minamoto "$PUBLIC_KEY"
)"
```

Address-codec གི་སྤྱོད་ལམ་བརྟག་ཞིབ་འབད་བའི་སྐབས་ I105 གྱི་འཛུལ་སྒོ་ཚུ་ ངོ་རྒྱུན་དང་བསྡུར་འབད་:

```bash
NORMALIZED_ACCOUNT_ID="$(
  printf '%s\n' "$TAIRA_ACCOUNT_ID" \
    | iroha tools address normalize --profile taira
)"

test "$NORMALIZED_ACCOUNT_ID" = "$TAIRA_ACCOUNT_ID"
```

དྭངས་འཕྲོས་འཕྲོས་བཟོ་རྣམ་དང་ ཀ་ནོ་ནི་ཀཱན་གྱི་ hex དེ་ལས་ གདམ་ཁ་རྐྱབ་མི་ net འབྲེལ་བའི་གནས་སྟངས་འདི་ JSON སྦེ་བརྟག་དཔྱད་འབད་:

```bash
iroha tools address convert \
  --profile taira \
  --format json \
  "$TAIRA_ACCOUNT_ID"
```

newline-separated file གི་ཁ་བྱང་ codec བཟོ་བཀོད་འདི་ བརྟག་ཞིབ་འབད་ནི་ འདི་ལུ་ analyze failures མུ་ཏིག་སྦེ་མ་ལེན་པར་:

```bash
iroha tools address audit \
  --profile taira \
  --input account-ids.txt \
  --format json
```

::: caution CLI ཚད་འཛིན་གྱི་མཐའ་མཚམས་

འདི་ཚུ་ `convert`, `normalize`, དང་ `audit` བཀའ་རྒྱ་ཚུ་འོག་གི་གནས་ཚད་ནང་ལུ་ལག་ལེན་འཐབ་དོ་ཡོདཔ་ཨིན། `AccountAddress` codec འདི་

## ཨང་གྲངས་བཟོ་ཐངས་ {#encoding-algorithm}

Canonical encoders གིས་ འ་ནི་ལཱ་ཚུ་འབད་ཚུགས།

```text
canonical = header || controller
payload_digits = base_convert(canonical, base_256, base_105)
checksum_digits = bech32m_6(hrp = "snx", convert_8_to_5(canonical, pad = true))
literal = sentinel(discriminant) || alphabet[payload_digits || checksum_digits]
```

འགོ་ཐོག་གི་ zero bytes ཚུ་ zero-valued `base-105` digits སྦེ་ཉར་ཚགས་འབདཝ་ཨིན།

checksum གིས་ `Bech32` `polymod` ཇི་ནེརེ་ཊར་དང་ constant `0x2bc830a3` ལག་ལེན་འཐབ་ཡོདཔ་ཨིན།

checksumརྐྱངམ་ཅིག་ HRP འདི་ ASCII string `snx`ཨིན།

checksumརྐྱངམ་ཅིག་ HRP འདི་ཁ་བྱང་ནང་ལུ་ བྲིས་མི་བཏུབ་ཨིན།

checksum གྱངས་ཁ་དྲུག་དེ་ `0..31` གི་ནང་འཁོད་ལུ་ཡོདཔ་ད་ འདི་ཡང་ ཁེ་ཕན་གྱི་སྣོད་ཆས་དང་འདྲཝ་སྦེ་ I105 ཨེཕ་བེཊ་གི་ཐོག་ལས་སྟོན་འབདཝ་ཨིན།

### I105 ཡིག་འབྲུ་ {#i105-alphabet}

རྟགས་མཚན་༡༠༥ འདི་ འདི་ལྟར་དུ་བཀོད་སྒྲིག་འབད་ཡོདཔ་ཨིན།

གྲལ་ཐིག་གཉིས་པ་འདི་ནང་ ཨང་གྲངས་ `58..104` ཚུ་ཡོདཔ་ཨིན།

codec ལག་ལེན་འཐབ་པའི་སྐབས་ གྲལ་ཐིག་ཚུ་ Concatenate འབད།

ཨེཕ་བེཊི་འདི་ `Unicode` ཚོར་བ་ཅན་ཨིན།

འོག་གི་ཡིག་གཟུགས་འདི་ `compatibility-width` Japanese `kana` རྟགས་མཚན་དང་ `ヰ` དང་ `ヱ` གི་དོན་ལུ་སྟོན་ཡོད་པའི་ code points ཚུ་ལག་ལེན་འཐབ་ཨིན།

NFC, NFKC, width conversion, case folding, or look-like substitution འདི་ལག་ལེན་འཐབ་ནི་མི་འོང་།

## ཀ་ནོ་ནི་ཀཱན་གྱི་རྩིས་ཁྲ་གི་ཁེ་ཕན་གྱི་འགན་ཁུར་ {#canonical-account-payload}

`base-105` གི་གཟུགས་འདི་གིས་ ཌའི་ལོག་རྩིས་ཁྲ་གི་ཁེ་ཕན་གྱི་ལྡོག་སྒྲོམ་ཅིག་ལུ་ ཨེབ་གཏང་འབདཝ་ཨིན་ དེ་ public key stringམེན་ ཡང་ན་ Norito JSON ობიექტიམེན་:

```text

```

འོག་གི་ཨང་གྲངས་ཆ་མཉམ་མང་པི་ཊ་ཚུ་ ཐོ་བཀོད་མ་འབད་མི་དང་ `big-endian`ཨིན།

Domain, data space, alias, UAID, དང་རྩིས་ཁྲ་ metadata bytesཚུ་མེད་ཡོདཔ་ཨིན།
