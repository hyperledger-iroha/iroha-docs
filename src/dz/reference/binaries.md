# དང་གཅིག་ཁར་ལཱ་འབད་དོ། Iroha གཉིས་ལྡན་ཚུ། {#working-with-iroha-binaries}

ཚིག༌ཕྲད Iroha 3 བཀོལ་སྤྱོད་པའི་ལཱ་གི་རྒྱུན་རིམ་འདི་ གཞི་རྟེན་གཉིས་ལྡན་གསུམ་གྱི་མཐའ་འཁོར་ལུ་བསྐོར་ར་རྐྱབ་ཨིན།

- [`irohad`](https://github.com/hyperledger-iroha/iroha/tree/main/crates/irohad) མཉམ་རོགས་ཌེ་མཱོན་གཡོག་བཀོལ་ནིའི་དོན་ལུ།
- [`iroha`](https://github.com/hyperledger-iroha/iroha/tree/main/crates/iroha_cli) དོན་ལུ་ CLI དང་བཀོལ་སྤྱོད་པའི་བརྡ་བཀོད་ཚུ།
- [`kagami`](https://github.com/hyperledger-iroha/iroha/tree/main/crates/iroha_kagami) ལྡེ་མིག་དང་ རིགས་མཚན་ ལོ་ཀཱལ་ནེཊི་ དེ་ལས་ གསལ་སྡུད་ཚུ་གི་དོན་ལུ་

## འབྱུང་ཁུངས་ལས་བཟོ་བསྐྲུན། {#build-from-source}

ཡར་རྒྱུན་ལཱ་གི་ས་སྒོ་རྩ་བ་ལས་:

```bash
cargo build --release -p irohad -p iroha_cli -p iroha_kagami
```

དེ་ལས་ བཏོན་གཏང་གཉིས་ལྡན་ཚུ་ ༡ ནང་འཐོབ་ཚུགས། `target/release/`.

བརྡ་བཀོད་ཁ་ཐོག་འདི་ཞིབ་དཔྱད་འབད་ནི་ལུ་:

```bash
./target/release/irohad --help
./target/release/iroha --help
./target/release/kagami --help
```

## མཛོད་ཁང་ལས་ཐད་ཀར་དུ་གཡོག་བཀོལ། {#run-directly-from-the-repository}

ཁྱོད་ཀྱིས་ འཛམ་གླིང་ནང་ ག་ཅི་ཡང་ གཞི་བཙུགས་འབད་མ་དགོ་པ་ཅིན་ ལག་ལེན་འཐབ། `cargo run`:

```bash
cargo run --bin irohad -- --help
cargo run --bin iroha -- --help
cargo run --bin kagami -- --help
```

## Docker པར {#docker-image}

ཡར་རྒྱུན་གྱི་ལཱ་གི་ས་སྒོ་འདི་གིས་ ལག་ལེན་འཐབ་ཨིན། `kagami localnet` དང༌ `kagami docker` བཟོ་བཏོན་འབད་ནི།
Docker Compose བརྟག་ཞིབ་འབད་ཡོད་པའི་ཨང་རྟགས་དང་མཐུན་པའི་ཡིག་སྣོད་ཚུ།ཚིག༌ཕྲད `hyperledger/iroha:dev`
གཟུགས་བརྙན་འདི་ བཟོ་བཏོན་འབད་ཡོད་པའི་ཡིག་སྣོད་ཚུ་དང་གཅིག་ཁར་ལག་ལེན་འཐབ་བཏུབ།

གཡོག་བཀོལ། CLI དམ་སྦྱིས་ནང་:

```bash
docker run -t hyperledger/iroha:dev iroha --help
```

རྒྱུག༌ནི Kagami དམ་སྦྱིས་ནང་:

```bash
docker run -t hyperledger/iroha:dev kagami --help
```

མཉམ་རོགས་འགོ་བཙུགས་ནིའི་དོན་ལུ་ ལོ་ཀཱལ་ནེཊི་ཅིག་བཟོ་བཏོན་འབད་ཞིནམ་ལས་ དང་པ་རང་ ཡིག་སྣོད་བརྩམས།

```bash
cargo run --bin kagami -- localnet --build-line iroha3 --peers 4 --out-dir ./localnet
cargo run --bin kagami -- docker --peers 4 --config-dir ./localnet --image hyperledger/iroha:dev --out-file ./localnet/docker-compose.yml --force
docker compose -f ./localnet/docker-compose.yml up
```
