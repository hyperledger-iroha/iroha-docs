# འཛོམས་འདུ་གི་མིང་། {#naming-conventions}

ཁྱོད་ཀྱིས་རྩིས་ཐོ་དང་ ས་ཁོངས་ ཡང་ན་ རྒྱུ་དངོས་ཚུ་གི་མིང་བཏགས་པའི་སྐབས་ལུ་ ཁྱོད་ཀྱིས་ Iroha ནང་ལུ་ལག་ལེན་འཐབ་མི་ གྲོས་བསྟུན་འདི་སེམས་ཁར་བཞག་དགོཔ་ཨིན།

1. དམིགས་བསལ་གྱི་དབྱེ་བ་བཟོ་བཀོད་ཀྱི་དོན་ལུ་ལག་ལེན་འཐབ་མི་ བཀག་བཞག་ཡོད་པའི་དབྱེ་བྱེད་གྱངས་ཁ་ཡོདཔ་ཨིན།

- `@` འདི་ རྩིས་ཐོའི་མིང་གཞན་དང་ ཁྱབ་ཚད་ཡོད་པའི་རྩིས་ཐོ་/མི་མང་ལྡེ་མིག་འབྲི་ཤོག་ཚུ་གི་དོན་ལུ་ བཀག་བཞག་ཡོདཔ་ཨིན།
- `#` འདི་ རྒྱུ་དངོས་ངེས་ཚིག་མིང་གཞན་དང་ རྒྱུ་དངོས་ལྷག་ལུས་ཡིག་འབྲུའི་དོན་ལུ་ བཀག་བཞག་ཡོདཔ་ཨིན།
- `::` འདི་ གན་རྒྱ་མིང་གཞན་ཚུ་གི་དོན་ལུ་ བཀག་བཞག་ཡོདཔ་ཨིན།
- `.` འདི་ མངའ་ཁོངས་དང་ གནད་སྡུད་ས་སྟོང་ཤེས་ཚད་ཀྱི་དོན་ལུ་ བཀག་བཞག་ཡོདཔ་ཨིན།
- `$` འདི་ ཊི་གར་-ཁྱབ་ཚད་ཅན་གྱི་ཚིག་ཡིག་འབྲི་ཤོག་ཚུ་གི་དོན་ལུ་ གསོག་འཇོག་འབད་ཡོདཔ་ཨིན།
- `%` འདི་ བདེན་བཤད་འབད་མི་-ཁྱབ་ཚད་ཡོད་པའི་ཚིག་ཡིག་འབྲི་ཤོག་ཚུ་གི་དོན་ལུ་ བཀག་བཞག་ཡོདཔ་ཨིན།

2. མིང་ཚིག་ཅིག་ནང་ ཨང་གྲངས་ཉུང་ཤོས་ (ཨང་གྲངས་ UTF-8 ཡོད་པའི་རྩིས་ཏེ་) འདི་ཅ་ལ་གཉིས་ལས་བརྒལ་མེད་ཨིན། `[0, u32::MAX]`དང་ ད་ལྟོ་ བགོ་བཀྲམ་འབད་ཡོད་མི་ བང་བསྒྲིག ས་སྟོང ཚུ་ཨིན་མས།

## Taira ལུ་ བརྟག་དཔྱད་རྐྱབས། {#try-it-on-taira}

མི་མང་རྒྱུ་དངོས་མིང་གཞན་ཅིག་ དེ་གི་ཚད་ལྡན་རྒྱུ་དངོས་ངེས་ཚིག་ཨའི་ཌི་ནང་ལུ་སེལ་འཐུ་འབད།

```bash
curl -fsS https://taira.sora.org/v1/assets/aliases/resolve \
  -H 'content-type: application/json' \
  -d '{"alias":"usd#wonderland"}' \
  | jq '{alias, asset_definition_id, asset_name, status: .alias_binding.status}'
```

དེ་རྒྱུ་དངོས་ངེས་ཚིག་ཐོ་ཡིག་དང་ག་བསྡུར་འབད།

```bash
curl -fsS 'https://taira.sora.org/v1/assets/definitions?limit=20' \
  | jq -r '.items[] | select(.alias != null) | [.alias, .id, .name] | @tsv'
```

`#` ཡིག་འབྲུ་གིས་ རྒྱུ་དངོས མིང་གཞན འདི་ མངའ་ཁོངས སྐབས་དོན ལས་སོ་སོར་བཟོཝ་ཨིན། རྒྱུ་དངོས མིང་གཞན ཡང་ན་ རྒྱུ་དངོས ལྷག་ལུས ཐད་ཀར་གནས་གོང ཅིག་བསམ་བཞིན་དུ་འབྲི་བའི་སྐབས་མ་གཏོགས་ གསལ མིང ནང་ `#` མ་བཙུགས།
