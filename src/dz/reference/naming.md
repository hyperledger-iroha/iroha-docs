# འཛོམས་འདུ་གི་མིང་། {#naming-conventions}

ཁྱོད་ཀྱིས་རྩིས་ཁྲ་དང་ ས་ཁོངས་ ཡང་ན་ རྒྱུ་དངོས་ཚུ་གི་མིང་བཏགས་པའི་སྐབས་ལུ་ ཁྱོད་ཀྱིས་ Iroha ནང་ལུ་ལག་ལེན་འཐབ་མི་ གྲོས་བསྟུན་འདི་སེམས་ཁར་བཞག་དགོཔ་ཨིན།

1. བཟོ་སྐྲུན་གྱི་རིགས་ཚུ་གི་དོན་ལུ་ ལག་ལེན་འཐབ་མི་སྦྲགས་དབྱེ་ཁག་མང་རབས་ཅིག་ཡོདཔ་ཨིན།

   - `@` རྩིས་ཁྲ་གི་མིང་དང་ དམིགས་གཏད་ཅན་གྱི་རྩིས་ཁྲ་/གཞུང་འབྲེལ་ལྡེ་མིག་བཟོ་རྣམ་ཚུ་གི་དོན་ལུ་བཞག་ཡོདཔ་ཨིན།
   - `#` རྒྱུ་དངོས་གི་འགྲེལ་བཤད་ཀྱི་མིང་དང་ རྒྱུ་དངོས་གི་ལྷག་མ་ཡིག་ཆ་ཚུ་གི་དོན་ལུ་བཞག་ཡོདཔ་ཨིན།
   - `::` མཁོ་སྤྲོད་ཀྱི་མིང་རྟགས་ཚུ་གི་དོན་ལུ་ བསྡུ་སྒྲིག་འབདཝ་ཨིན།
   - `.` འདི་ domain དང་ data space qualification གི་དོན་ལུ་བཞག་ཡོདཔ་ཨིན།
   - `$` འདི་ཡང་ ཐིག་ཁྲམ་ལག་ལེན་འཐབ་ནིའི་དོན་ལས་ཨིན།
   - `%` ཐོ་བཀོད་འབད་ཡོད་པའི་ ཡིག་ཆ་ཚུ་གི་དོན་ལུ་ ཆ་བཞག་ཡོདཔ་ཨིན།

2. མིང་ཚིག་ཅིག་ནང་ ཨང་གྲངས་ཉུང་ཤོས་ (ཨང་གྲངས་ UTF-8 ཡོད་པའི་རྩིས་ཏེ་) འདི་ཅ་ལ་གཉིས་ལས་བརྒལ་མེད་ཨིན། `[0, u32::MAX]`དང་ ད་ལྟོ་ བགོ་བཀྲམ་འབད་ཡོད་མི་ Stack space ཚུ་ཨིན་མས།

## Taira ལུ་ བརྟག་དཔྱད་རྐྱབས། {#try-it-on-taira}

གཞུང་གི་རྒྱུ་དངོས་ཀྱི་མིང་རྟགས་འདི་ རྩ་ཁྲིམས་ཆེན་མོའི་རྒྱུ་དངོས་གི་འགྲེལ་བཤད་ནང་སེལ་འཐུ་འབད་ ID:

```bash
curl -fsS https://taira.sora.org/v1/assets/aliases/resolve \
  -H 'content-type: application/json' \
  -d '{"alias":"usd#wonderland"}' \
  | jq '{alias, asset_definition_id, asset_name, status: .alias_binding.status}'
```

འདི་ལུ་ རྒྱུ་དངོས་གི་འགྲེལ་བཤད་ཐོ་དང་བསྡུར་འབད།

```bash
curl -fsS 'https://taira.sora.org/v1/assets/definitions?limit=20' \
  | jq -r '.items[] | select(.alias != null) | [.alias, .id, .name] | @tsv'
```

`#` ཡིག་འབྲུ་འདི་གིས་ རྒྱུ་དངོས་གི་མིང་འདི་ ས་ཁོངས་ཀྱི་དོན་ལས་སོ་སོར་བཟོཝ་ཨིན། ཁྱོད་ཀྱིས་དམིགས་བསལ་གྱི་ རྒྱུ་དངོས་གི་མཚན་རྟགས་ ཡང་ན་ རྒྱུ་དངོས་མཐུན་རྐྱེན་ཡིག་འབྲུ་འབྲི་མ་བཏུབ་པ་ཅིན་ མིང་རྟགས་ངོ་མ་ཚུ་ནང་ལས་ཕྱི་ཁར་བཞག་དགོ།
