# Torii མཐའ་མཇུག་གི་གནས་ཚད་ཚུ་ {#torii-endpoints}

Torii འདི་ HTTP, SSE, དང་ WebSocket འཛུལ་སྒོ་གི་དོན་ལུ་ Iroha 3. འདི་གཉིས་ཆ་ར་ལུ་ Ledger-ཁ་ཐུག་གི་ཞབས་ཏོག་འབདཝ་ཨིན། APIs ལས་འཛིན་གྱི་མཐའ་མཇུག་གི་སྒོ་ཚུ་

ད་ལྟོའི་གཞུང་ལུགས་འདི་ འདི་ཚུ་ཨིན།

- ཀ་ནོ་ནི་ཀཱན་གྱི་ ཌའི་ལོག་བཟོ་རྣམ་འདི་ Norito ཨིན།
- མཐའ་མཇུག་གི་སྒོ་མང་ཤོས་ཅིག་གིས་ JSON འདི་ཡང་ རྒྱབ་སྐྱོར་འབད་དོ་ཡོདཔ་ད་ ཁྱོད་ཀྱིས་ `Accept: application/json` བཏང་བའི་སྐབས་ཨིན།
- ཐིག་ཁྲམ་ཚུ་ Prometheus གི་བཟོ་རྣམ་ནང་ལུ་བཏོན་ཡོདཔ་ཨིན།

ཐོ་བཀོད་བཟོ་ཐངས་ཀྱི་དོན་ལས་ དབྱེ་ཞིབ་འབད་ཐབས། སྒྲིག་གཞི་བཟོ་ཐངས་གི་སྒྲོན་མེའི་དོན་ལུ་ Norito དང་ RPC གི་ལམ་སྟོན་གི་དོན་ལུ་ [Norito 引用](/dz/reference/norito.md)བལྟ་དགོ།

```http
Accept: text/event-stream, application/json
```

Torii གིས་འགོ་དང་པ་ཞུ་ཡིག་གི་ཐིག་ཁྲམ་ནང་ JSON ཡང་ན་ Norito འདྲ་བཤུས་ཅིག་བཟོ་སྟེ་ གྲོས་བསྟུན་འབད་ཞིནམ་ལས་ རང་ལུགས་ཀྱི་ `text/event-stream` ལན་འདེབས་འདི་ བདེན་ཁུངས་བསྐྱེདཔ་ཨིན། འདི་འབདཝ་ལས་ `text/event-stream` རྐྱངམ་གཅིག་གཏང་ནི་དེ་ `406` ལུ་འདོར་བཏང་དོ་ཡོདཔ་ཨིན། [ stream-events recipe](/dz/cookbook/stream-events.md) གིས་ ཡོངས་འབྲེལ་གྱི་ཨེབ་རྟ་ལག་ལེན་འཐབ་ཨིན།

`/openapi` ཐོ་བཀོད་ནང་བཀོད་ཡོད་པའི་ འགྲོ་འགྲུལ་ལམ་གྱི་དོན་ལུ་ གཞི་རྟེན་བཟོ་སྐྲུན་འབད་མི་ ཁག་འབགཔ་ཨིན། དབྱེ་ཞིབ་འབད་ཐངས་ཀྱི་ཐོ་ཡིག་འདི་ ཡོངས་འབྲེལ་མེན། ད་ལྟོའི་ཡིག་ཆ་ནང་ `/livez` དང་ `/readyz`, དེ་ལས་ `/health` འགྲེལ་བཤད་འདི་ གྲ་སྒྲིག་གི་ལག་ལེན་པ་ལུ་ རྒྱབ་སྐྱོར་འབད་ཚུགས། ཐོ་བཀོད་ཡིག་ཆ་ནང་ལས་ལམ་གྱི་ client ཚུ་བཟོ། དེ་འབདཝ་ད་ བརྟག་ཞིབ་འབད་ནི་དང་ གྲ་སྒྲིག་འབད་ནི་ལུ་ ཐད་ཀར་དུ་ འགྲུལ་བསྐྱོད་འབད་ཐངས་དང་ འཛིན་བཟུང་འབད་མི་ ལག་ལེན་པ་ཚུ་གི་གདོང་ཐུག་ལས་ བཏོན་གཏང་དགོ། ཕྲང་གི་ས་ཁོངས། ད་ལྟོ་ཡང་བཟོ་སྐྲུན་གྱི་ཁྱད་ཆོས་དང་ བཙུགས་པའི་དུས་ཚོད་སྒྲིག་གཞི་ལས་བརྟེན་ཨིན། ལག་ལེན་འཐབ་ནི་ [Torii API console](/dz/reference/torii-api-console.md) ཐོ་བཀོད་འབད་ཡོད་པའི་ཡིག་ཆ་འདི་ བཙུགས་ནིའི་དོན་ལུ་ བརྟག་དཔྱད་འབདཝ་ཨིན། JSON འགྲོ་འགྲུལ་ལམ་, དཔེ་སྒྲོམ་ curl དགོས་མཁོ་ཚུ་འབད་ཞིནམ་ལས་ ད་ལྟོའི་འཆར་གཞི་ནང་ལས་ client code བཟོ་ཚུགས།

## Taira ཕྲང་ལམ་ཚུ་ བརྟག་དཔྱད་རྐྱབས། {#try-live-taira-routes}

public Taira testnet གིས་ applications client ཚུ་གིས་ལྷག་ཐངས་རྐྱངམ་ཅིག་འཚོལ་ནིའི་དོན་ལུ་ལག་ལེན་འཐབ་མི་ surface Torii JSON འདི་བཟུམ་སྦེ་བཏོན་དོ་ཡོདཔ་ཨིན། འ་ནི་བཀའ་རྒྱ་འདི་ཚུ་གི་དོན་ལུ་ key དགོས་མཁོ་མེད་ཨིན།

```bash
TAIRA_ROOT=https://taira.sora.org

curl -fsS -H 'Accept: application/json' "$TAIRA_ROOT/status" \
  | jq '{blocks, txs_approved, txs_rejected, queue_size, peers}'

curl -fsS "$TAIRA_ROOT/openapi.json" \
  | jq -r '.paths | keys[]' \
  | grep '^/v1/' \
  | head -n 20

curl -fsS -H 'Accept: application/json' \
  "$TAIRA_ROOT/v1/node/capabilities" \
  | jq '{abi_version, data_model_version, query: .query.aggregate.supported_resources}'
```

དཔྱད་ཡིག་འདི་ འཛམ་གླིང་གི་གནས་སྟངས་ལུ་བལྟ་བ་ཅིན་:

```bash
curl -fsS "$TAIRA_ROOT/v1/domains?limit=5" \
  | jq -r '.items[].id'

curl -fsS "$TAIRA_ROOT/v1/assets/definitions?limit=5" \
  | jq -r '.items[] | [.id, .name, .total_quantity] | @tsv'
```

མི་མང་གི་བརྟག་དཔྱད་དྲ་ལམ་ཅིག་གིས་ `502` སླར་ལོག་རྐྱབ་པ་ཅིན་ དུས་ཚོད་སེལ་འཐུ་འབད་མ་བཏུབ་ ཡང་ན་ བསྡུ་སྒྲིག་འབད་ཡོད་པའི་གྲལ་ཐིག་ཅིག་ སྙན་ཞུ་འབད་བ་ཅིན་ འདི་མཐའན་མཇུག་གི་སྒོ་སྒྲིག་ལག་ལེན་གྱི་གནད་དོན་ཅིག་སྦེ་བརྩི་ཞིནམ་ལས་ ཤུལ་ལས་ ཁྱོད་ཀྱིས་ client code འདི་ debug མ་འབད་པའི་ཧེ་མ་ ལོག་ལྟབ་སྦེ་ དཔྱད་བལྟ།

## JSON དང་ Norito {#json-vs-norito}

ལས་འཛིན་གྱི་མཐའ་མཇུག་གི་སྒོ་མང་ཤོས་ཅིག་གིས་ Norito འདི་ལོག་གཏངམ་ཨིན། མཐའ་མཇུག་གི་སྒོ་འདི་གིས་ JSON རྒྱབ་སྐྱོར་འབད་ཚརཝ་ད་, བཏང་:

```http
Accept: application/json
```

འདི་འདི་ དམིགས་བསལ་དུ་ ཕན་ཐོགས་ཅན་ཨིན།

- `/v1/sumeragi/status`
- `/v1/sumeragi/qc`
- `/v1/sumeragi/commit_qc/{hash}`

མཐའ་མཇུག་གི་སྒོ་ཅིག་གིས་ Norito ཐད་ཀར་དུ་ཐོ་བཀོད་འབད་ཞིནམ་ལས་ ཡང་ན་ བསྐྱལ་བའི་སྐབས་, ནང་དོན་དབྱེ་བ་དང་ཡང་ན་ གདམ་ཁ་ཅན་གྱི་ `Accept` གནས་གོང་སྦེ་ `application/x-norito` ལག་ལེན་འཐབ་དགོ། སྐྱེལ་འདྲེན་གྱི་གསལ་བཤད་ཚུ་གི་དོན་ལུ་ [Norito](/dz/reference/norito.md#torii-and-norito-rpc)བལྟ་དགོ།
