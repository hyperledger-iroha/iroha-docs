# Torii མཐའ་མཇུག་གི་གནས་ཚད་ཚུ་ {#torii-endpoints}

Torii འདི་ HTTP, SSE, དང་ WebSocket འཛུལ་སྒོ་གི་དོན་ལུ་ Iroha 3. འདི་གཉིས་ཆ་ར་ལུ་ རྩིས་དེབ-ཁ་ཐུག་གི་ཞབས་ཏོག་འབདཝ་ཨིན། APIs ལས་འཛིན་གྱི་མཐའ་མཇུག་གི་སྒོ་ཚུ་

ད་ལྟོའི་གཞི་སྒྲིག་ལམ་ལུགས་ཚུ་འདི་ཨིན།

- ཚད་ལྡན་གཉིས་ལྡན་རྩ་སྒྲིག་འདི་ **Norito** ཨིན།
- ཁྱོད་ཀྱིས་ `Accept: application/json` གཏང་པའི་སྐབས་ མཐའ་མཚམས་མང་ཤོས་ཅིག་གིས་ཡང་ JSON ལུ་རྒྱབ་སྐྱོར་འབདཝ་ཨིན།
- མེ་ཊིགསི་ཚུ་ པོརོ་མི་ཐིའུསི་རྩ་སྒྲིག་ནང་ གསལ་སྟོན་འབད་ཡོདཔ་ཨིན།

ཐོ་བཀོད་བཟོ་ཐངས་ཀྱི་དོན་ལས་ དབྱེ་ཞིབ་འབད་ཐབས། སྒྲིག་གཞི་བཟོ་ཐངས་གི་སྒྲོན་མེའི་དོན་ལུ་ Norito དང་ RPC གི་ལམ་སྟོན་གི་དོན་ལུ་ [Norito གཞི་བསྟུན་](/dz/reference/norito.md)བལྟ་དགོ།

SSE ཞུ་བ་གི་དོན་ལུ་ ཨའི་གི་རྒྱུན་དང་རྒྱབ་སྐྱོར་ཨེབ་གཏང་འབད་:

```http
Accept: text/event-stream, application/json
```

Torii གིས་འགོ་དང་པ་ཞུ་ཡིག་གི་ཐིག་ཁྲམ་ནང་ JSON ཡང་ན་ Norito འདྲ་བཤུས་ཅིག་བཟོ་སྟེ་ གྲོས་བསྟུན་འབད་ཞིནམ་ལས་ རང་ལུགས་ཀྱི་ `text/event-stream` ལན་འདེབས་འདི་ བདེན་ཁུངས་བསྐྱེདཔ་ཨིན། འདི་འབདཝ་ལས་ `text/event-stream` རྐྱངམ་གཅིག་གཏང་ནི་དེ་ `406` ལུ་འདོར་བཏང་དོ་ཡོདཔ་ཨིན། [རྒྱུན-བྱུང་ལས་ཚུ བཟོ་ཐབས།](/dz/cookbook/stream-events.md) གིས་ ཡོངས་འབྲེལ་གྱི་ཨེབ་རྟ་ལག་ལེན་འཐབ་ཨིན།

`/openapi.json` ལམ་ལུགས་ནང་ངོ་སྤྲོད་འབད་ཡོད་པའི་ལམ་འགྲུལ་ཚུ་གི་དོན་ལུ་ བཟོ་སྐྲུན་འབད་མི་ཆིངས་ཡིག་འདི་ཨིན། བྱ་བའི་བརྟག་དཔྱད་ཀྱི་ཐོ་ཡིག་འདི་ ཡོངས་བསྡོམས་འབད་ཡོདཔ་ཨིན། ད་ལྟོའི་ཡིག་ཆ་ནང་ `/livez` དང་ `/readyz`, དེ་ལས་ `/health` འགྲེལ་བཤད་འདི་ གྲ་སྒྲིག་གི་ལག་ལེན་པ་ལུ་ རྒྱབ་སྐྱོར་འབད་ཚུགས། ཐོ་བཀོད་ཡིག་ཆ་ནང་ལས་ལམ་གྱི་ ཞབས་ཏོག་ལེན་མི ཚུ་བཟོ། དེ་འབདཝ་ད་ བརྟག་ཞིབ་འབད་ནི་དང་ གྲ་སྒྲིག་འབད་ནི་ལུ་ ཐད་ཀར་དུ་ འགྲུལ་བསྐྱོད་འབད་ཐངས་དང་ འཛིན་བཟུང་འབད་མི་ ལག་ལེན་པ་ཚུ་གི་གདོང་ཐུག་ལས་ བཏོན་གཏང་དགོ། ཕྲང་གི་ས་ཁོངས། ད་ལྟོ་ཡང་བཟོ་སྐྲུན་གྱི་ཁྱད་ཆོས་དང་ བཙུགས་པའི་དུས་ཚོད་སྒྲིག་གཞི་ལས་བརྟེན་ཨིན། ལག་ལེན་འཐབ་ནི་ [Torii API ཚོད་བརྟག་སྒྲོམ](/dz/reference/torii-api-console.md) ཐོ་བཀོད་འབད་ཡོད་པའི་ཡིག་ཆ་འདི་ བཙུགས་ནིའི་དོན་ལུ་ བརྟག་དཔྱད་འབདཝ་ཨིན། JSON འགྲོ་འགྲུལ་ལམ་, དཔེ་སྒྲོམ་ curl དགོས་མཁོ་ཚུ་འབད་ཞིནམ་ལས་ ད་ལྟོའི་འཆར་གཞི་ནང་ལས་ ཞབས་ཏོག་ལེན་མི ལས་རིམ་ཨང་རྟགས བཟོ་ཚུགས།

ཐོ་བཀོད་རྒྱབ་སྐྱོར་འབད་མི་ OpenAPI ལས་འགུལ་ཆ་མཉམ་ནང་ `x-iroha-route-auth` འདྲ་ཕབ་ཅིག་ཡོདཔ་ཨིན། ཐོ་བཀོད་ཀྱི་རྒྱབ་སྐྱོར་ཐོབ་མི་ MCP ལག་ཆས་ཚུ་གིས་ `_meta["iroha/routeAuth"]` དང་འདྲན་འདྲ་གི་འཆམ་ཡིག་ཚུ་བཏོན་དོ་ཡོདཔ་ཨིན། ཕྱིར་སྟོན་གཉིས་ཆ་ར་ལུ་ `schemaVersion`, `stableRouteId`, `authentication` དེ་ལས་ `admission` ཚུ་ཡོདཔ་ཨིན། ཁྱོད་ཀྱིས་ `1` འདྲ་བཤུས་འདི་བདེན་པའི་འཆམ་ཡིག་ཅིག་སྦེ་ལག་ལེན་འབད་: རྒྱབ་སྐྱོར་མེད་མི་ `schemaVersion` འདི་ག་དེ་སྦེ་ བདེན་ཁུངས་འབད་ནི་དང་ འཛུལ་ཞུགས་ཀྱི་ཐོ་བཀོད་ཚུ་ ངེས་པར་དུ་བསྒྱུར་བཅོས་འབད་དགོཔ་ཨིན་ན་ ཧ་གོ་ནིའི་ཚབ་ལུ་ ཆ་མེད་གཏང་དགོ། ཐབས་ལམ་གྱི་ ཟུར་གནས་གནད་སྡུད གིས་ ཞུ་བ་ཀྱི་མཐའ་མཚམས་བཤད་དོ་ཡོདཔ་ལས་ འདི་གིས་ མཐའ་མཚམས་དེ་ནང་ དགོས་མཁོ་ཅན་གྱི་ ངོས་འཛིན་བརྡ་དོན་ཚུ་ བསྒྱུར་བཅོས་མ་འབད་བས།

## Taira ཕྲང་ལམ་ཚུ་ བརྟག་དཔྱད་རྐྱབས། {#try-live-taira-routes}

མི་མང Taira བརྟག་དཔྱད་དྲ་རྒྱ གིས་ གློག་རིམ་ཚུ ཞབས་ཏོག་ལེན་མི ཚུ་གིས་ལྷག་ཐངས་རྐྱངམ་ཅིག་འཚོལ་ནིའི་དོན་ལུ་ལག་ལེན་འཐབ་མི་ མཐུད་ངོས Torii JSON འདི་བཟུམ་སྦེ་བཏོན་དོ་ཡོདཔ་ཨིན། འ་ནི་བཀའ་རྒྱ་འདི་ཚུ་གི་དོན་ལུ་ ལྡེ་མིག དགོས་མཁོ་མེད་ཨིན།

```bash
TAIRA_ROOT=https://taira.sora.org

curl -fsS -H 'Accept: application/json' "$TAIRA_ROOT/status" \
  | jq '{blocks, txs_approved, txs_rejected, queue_size, peers}'

curl -fsS "$TAIRA_ROOT/openapi.json" \
  | jq -r '.paths | keys[]' \
  | grep '^/v1/' \
  | head -n 20
```

བལྟ་མི་ཤོག་བྱང་མེད་པར་ རི་ལེ་ཚུ་གིས་ ཕྱི་ཁར་ཐོན་ཚུགས་པའི་ཁང་མིག་ཚུ་གི་དོན་ལུ་ `--room-policy public` ཡང་ན་ ཕྱིར་ཐོན་ཚུ་ལུ་ བལྟ་མི་བདེན་བཤད་དགོཔ་ད་ `--room-policy authenticated` ལག་ལེན་འཐབ། ཡོངས་འབྲེལ་འདི་གིས་ Kaigi ཐོ་ཡིག་དང་ལག་ལེན་བདེན་དཔྱད་ལྡེ་མིག་ཚུ་རིམ་སྒྲིག་འབད་ཚར་བའི་ཤུལ་ལས་རྐྱངམ་ཅིག་ `--privacy-mode zk-roster-v1` ལག་ལེན་འཐབ། དེ་མེན་པ་ཅིན་ མཐུད་ལམ་དང་ འདབ་མ་ དེ་ལས་ སྒེར་གྱི་ལག་ལེན་དྲན་ཐོ་ཚུ་ གཏན་འབེབས་བདེན་དཔྱད་ཀྱི་སྐབས་ལུ་ འཐུས་ཤོར་བྱུངམ་ཨིན།

## གནས་གོང་དང་ ཐོ་བཀོད་ཚུ་ {#status-and-metrics}

གནས་ཚད་དང་ མེ་ཊིགསི་མཇུག་སྣོད་ཚུ་ ཌེཤ་བོརཌི་ཚུ་ནང་ གློག་ཐག་གཏང་ནིའི་དོན་ལུ་ འགོ་དང་པ་ཨིན།

- `/status` གིས་ མཐོ་རིམ་གནས་རིམ་གྱི་མཉམ་རོགས་ སྡེབ་ཚན་ གྲལ་ཐིག་ དེ་ལས་ མོས་མཐུན་ས་སྒོ་ཚུ་ གསལ་སྟོན་འབདཝ་ཨིན།
- `/metrics` གིས་ པོརོ་མི་ཐིའུསི་གྱངས་ཁ་བརྐྱབ་མི་དང་ འཇལ་ཚད་ དེ་ལས་ ཧིསི་ཊོ་གཱ་རམ་ཚུ་ གསལ་སྟོན་འབདཝ་ཨིན།

Nexus ཤུགས་ཅན་གྱི་ མཚམས་གྲངས་ཚུ་ནང་ གནས་གོང་ཐོན་ཐངས་དེ་ཡང་ བརྒྱུད་ལམ་དང་ བརྡ་དོན་གནས་སྟངས་ཀྱི་ཐད་ལུ་ ཡན་ལག་ཁག་ཚུ་ཚུད་ཡོདཔ་ཨིན། `nexus.enabled = false` ལུ་འབད་བ་ཅིན་ དེ་ཚུ་མ་བཏུབ་ཨིན།

## JSON དང་ Norito {#json-vs-norito}

ལས་འཛིན་གྱི་མཐའ་མཇུག་གི་སྒོ་མང་ཤོས་ཅིག་གིས་ Norito འདི་ལོག་གཏངམ་ཨིན། མཐའ་མཇུག་གི་སྒོ་འདི་གིས་ JSON རྒྱབ་སྐྱོར་འབད་ཚརཝ་ད་, བཏང་:

```http
Accept: application/json
```

འདི་དམིགས་བསལ་གྱི་ཕན་ཐོགས་ཡོད།

- `/v1/sumeragi/status`
- `/v1/sumeragi/qc`

མཐའ་མཇུག་གི་སྒོ་ཅིག་གིས་ Norito ཐད་ཀར་དུ་ཐོ་བཀོད་འབད་ཞིནམ་ལས་ ཡང་ན་ བསྐྱལ་བའི་སྐབས་, ནང་དོན་དབྱེ་བ་དང་ཡང་ན་ གདམ་ཁ་ཅན་གྱི་ `Accept` གནས་གོང་སྦེ་ `application/x-norito` ལག་ལེན་འཐབ་དགོ། སྐྱེལ་འདྲེན་གྱི་གསལ་བཤད་ཚུ་གི་དོན་ལུ་ [Norito](/dz/reference/norito.md#torii-and-norito-rpc)བལྟ་དགོ།

## རྒྱང་འཇལ་གྱི་གསལ་སྡུད་ཚུ་ {#telemetry-profiles}

མཐའ་མཚམས་མཐོང་སྣང་འདི་ མཐུད་མཚམས་ཀྱི་ `telemetry.profile` སྒྲིག་སྟངས་ལུ་རག་ལསཔ་ཨིན། ད་ལྟོའི་རིམ་སྒྲིག་འདི་གིས་ གསལ་སྡུད་གནས་རིམ་ལྔ་གསལ་སྟོན་འབདཝ་ཨིན།

| གསལ་སྡུད། | `/status` | `/metrics` | གོང་འཕེལ་གཏང་མིའི་ལམ་ཚུ། |
| ----------- | --------- | ---------- | ---------------- |
| `disabled` | མེད། | མེད། | མེད། |
| `operator` | ཨིན་ | མེད། | མེད། |
| `extended` | ཨིན་ | ཨིན་ | མེད། |
| `developer` | ཨིན་ | མེད། | ཨིན་ |
| `full` | ཨིན་ | ཨིན་ | ཨིན་ |

## CLI ཕྲང་ལམ་ཚུ་ {#cli-shortcuts}

`iroha` CLI གིས་ཧེ་མ་ལས་རང་ མཇུག་སྣོད་འདི་ཚུ་ལེ་ཤ་ཅིག་རང་ བསྡམ་བཞགཔ་ཨིན།

```bash
export IROHA_OPERATOR_KEY_FILE=/run/secrets/iroha/operator.key

iroha --config ./localnet/client.toml --operator-private-key-file "$IROHA_OPERATOR_KEY_FILE" \
  --output-format text ops sumeragi status
iroha --config ./localnet/client.toml --operator-private-key-file "$IROHA_OPERATOR_KEY_FILE" \
  --output-format text ops sumeragi diagnostics
iroha --config ./localnet/client.toml --operator-private-key-file "$IROHA_OPERATOR_KEY_FILE" \
  ops sumeragi params
iroha --config ./localnet/client.toml --operator-private-key-file "$IROHA_OPERATOR_KEY_FILE" \
  --output-format text ops sumeragi evidence count
```
