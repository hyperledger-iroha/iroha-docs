# Norito {#norito}

Norito འདི་འབདཝ་ཨིན། Iroha འདི་ ཚད་ལྡན རིམ་སྒྲིག་འབད་ནི རིམ༌པ༌ ཨིན། འདི་ བཱའིཊ རྩ་སྒྲིག འདི་ མཉམ་རོགས གི་སྐབས་ལུ་ལག་ལེན་འཐབ་ཡོདཔ་ཨིན། SDKs, CLI ལག་ཆས་ཚུ་ Torii, Kura, དེ་ལས་ བཟོ་སྐྲུན་འབད་ཡོད་པའི་ རིན་གོང་ཅན་གྱི་དངོས་ཆས་ཚུ་ དེ་འདྲ་མཉམ་པའི་ ནང་དོན་གནད་སྡུད་གྱི་ཅ་ལ་ཐོག་ལུ་ གྲོས་བསྟུན་འབད་དགོཔ་ཨིན།

གནད་སྡུད་འདི་ མོས་མཐུན་དང་ མཚན་རྟགས་ ཧ་ཤིང་ བརྟན་ཏོག་ཏོ་ ཡང་ན་ ཕར་ཚུར་ SDK ཕན་ཚུན་བཀོལ་སྤྱོད་ཀྱི་ཆ་ཤས་ཨིན་པའི་སྐབས་ Norito ལག་ལེན་འཐབ། API མཇུག་སྣོད་ཅིག་གིས་ བཀོལ་སྤྱོད་པ་དང་ ཌེཤ་བོརཌི་ ཡང་ན་ མགྱོགས་དྲགས་རྐྱེན་སེལ་གྱི་དོན་ལུ་ མི་གིས་ལྷག་ཚུགས་པའི་ པར་བརྙན་ཅིག་ གསལ་ཏོག་ཏོ་སྦེ་ བྱིནམ་ད་ JSON ལག་ལེན་འཐབ།

## ཐོ་བཀོད་ཧེཤ་ཚུ་ {#schema-hashes}

Norito བཟོ་བཀོད་འབད་ཐངས་ཀྱི་ཁེ་རྒུད་འདི་ མགོ་ཡིག་ནང་ལུ་ བི་ཊ་༡༦ གི་འཆར་གཞི་གི་ཧེཤ་ཅིག་ཡོདཔ་ཨིན། ཨང་མ་བདེཝ་ཨིན་པའི་ཧེཤ་དེ་ ཁྱད་ཚད་ཅན་བཟོ་རྣམ་གི་མིང་ནང་ལས་ འབྱུང་ཡོདཔ་ཨིན། སྒྲིག་གཞི་འདི་གིས་ བཟོ་བཀོད་ཀྱི་འཆར་གཞིའི་ཧེཤ་བཟོཝ་ཨིན། དེ་ཚབ་ལུ་ ཧེཤ་འདི་ ཚད་ལྡན་གྱི་འཆར་གཞིའི་ལས་ཐོབ་འོང་།

## Torii དང་ Norito RPC {#torii-and-norito-rpc}

Torii གིས་ བཀོལ་སྤྱོད་པའི་འགྲུལ་ལམ་མང་ཤོས་ཅིག་གི་དོན་ལུ་ JSON གསལ་སྟོན་འབདཝ་ཨིན་ དེ་འབདཝ་ད་ ཡིག་དཔར་རྐྱབ་ཡོད་པའི་གཉིས་ལྡན་འགྲུལ་ལམ་ཚུ་གིས་ Norito ལག་ལེན་འཐབ་ཨིན། ད་ལྟོ་ཡིག་དཔར་རྐྱབ་ཡོད་པའི་ Norito HTTP གཟུགས་ཚུ་གི་དོན་ལུ་ བརྡ་བརྒྱུད་དབྱེ་བ་འདི་ `application/x-norito` ཨིན།

མཐའ་མཇུག་གི་སྒོ་སྒྲིག་ཅིག་གིས་ Norito ཐོ་བཀོད་འབད་ཞིནམ་ལས་ ཡང་ན་ བཏུབ་པའི་སྐབས་ འ་ནི་ཨེབ་རྟ་ཚུ་ལག་ལེན་འཐབ་དགོ།

```http
Content-Type: application/x-norito
Accept: application/x-norito
```

མཐའ་མཚམས་ཅིག་གིས་ ངོ་ཚབ་གཉིས་ཆ་ར་ལུ་རྒྱབ་སྐྱོར་འབད་བའི་སྐབས་ མཁོ་སྤྲོད་འབད་མི་ཚུ་གིས་ གསལ་ཏོག་ཏོ་དགའ་གདམ་ཐོ་ཡིག་ཅིག་གཏང་ཚུགས།

```http
Accept: application/x-norito, application/json
```

ཌེ་ཀོཌ་འཛོལ་བ་འདི་ Torii ཐོ་བཀོད་འབད་ནི་དང་ སྐྱེལ་སྒྲིག་ར་བ་གིས་རྩིས་འབདཝ་ཨིན། གནད་དོན་མང་ཤོས་ཅིག་ནང་མ་བདེན་པའི་རྫུ་འཕྲུལ་, རྒྱབ་སྐྱོར་མེད་མི་བཟོ་བཅོས་, རྒྱབ་སྐྱུར་མེད་མི་ཁྱད་ཆོས་སྒྲོན་, ཞིབ་དཔྱད་བསྡོམས མ་མཐུནམ་, མགུ་འཐོམ་འབད་མི་ UTF-8, ཆ་མེད་ཡོད་པའི་ གྲངས་བཀོད་དབྱེ་བ རྟགས, དང་ གཞི་བཀོད མ་མཐུནམ་ཚུ་ཨིན་མས།

Norito RPC སྐྱེལ་འདྲེན་འདི་ སྐྱེལ་འདྲེན་སྒྲིག་གཞི་ཐོག་ལས་སེལཝ་ཨིན། བཀོལ་སྤྱོད་པའི་ཌེཤ་བོརཌ་གིས་ ཞུ་བའི་འགོར་ཡུན་ འཐུས་ཤོར་ ཤུགས་ལྡན་མཐུད་སྦྲེལ་ ལན་གྱི་བའིཊ་ དེ་ལས་ `torii_norito_decode_failures_total` ཚུ་ JSON རྒྱུན་འགྲུལ་ལས་སོ་སོར་རྗེས་འདེད་འབད་དགོ།

## ལས་འཛིན་གྱི་ལམ་སྟོན་ཚུ་ {#operational-guidance}

- SDK བཟོ་སྐྲུན་འབད་མི་ཚུ་དང་ ཐོན་སྐྱེད་འབད་མི་ བཅིངས་ཐག ཚུ་ ལག་པར་བཟོ་མི་ Norito བཱའིཊི གི་ཚབ་ལུ་ གདམ་ཁ་རྐྱབ་ཨིན།
- འཆར་གཞི་མ་མཐུན་མི་འདི་ ཐོན་རིམ་ཡང་ན་ བརྟན་ཏོག་ཏོ་གི་དཀའ་ངལ་ཅིག་སྦེ་ བརྩི་འཇོག་འབད་དགོཔ་ཨིན་ དེ་འབདཝ་ད་ དུས་ཐུང་ཡོངས་འབྲེལ་འཐུས་ཤོར་སྦེ་མེན།
- གཏན་མཛོད་ `.nrt`, `.norito`, དང་ དེ་ཚུ་བཟོ་མི་ གསར་བཏོན་ཡང་ན་ བྱུང་རིམ་གྱི་བང་སྒྲིག་ནང་ མངོན་གསལ་གྱི་ བརྡ་མཚོན་ཚུ་ཨིན།
- མིང་རྟགས་བཀོད་ཡོད་མི་དང་ ཧ་ཤི་ ཡང་ན་ གནས་ཏེ་ཡོད་མི་ གནད་སྡུད་ཀྱི་དོན་ལུ་ བདེན་པ་གི་འབྱུང་ཁུངས་སྦེ་ Norito ལག་ལེན་འཐབ། ཌེཤ་བོརཌི་དང་ལག་ཐོག་བརྟག་དཔྱད་ཀྱི་དོན་ལུ་ JSON དམིགས་ཚད་ཚུ་ལག་ལེན་འཐབ།
- ཁྱོད་ཀྱིས་ Torii ཚད་མཐའན་མཇུག་གི་སྒོ་སྒྲིག་གསརཔ་ཅིག་སྣེ་ལེན་འབད་བའི་སྐབས་ ཁྱོད་ཀྱིས་ JSON དང་ Norito ཡང་ན་ གཉིས་ཆ་ར་ལུ་ ཆ་འཇོག་འབད་ཡོདཔ་ཨིན་ན་ ཡིག་ཐོག་བཀོད་དེ་ `/openapi.json` ནང་ རྒྱབ་སྐྱོར་འབད་ཡོད་པའི་དོན་གྱི་དབྱེ་བ་ཚུ་བཏོན་དགོ།
- མགྱོགས་ཚད་ཅིག་ལྕོགས་ཅན་མ་བཟོ་བའི་ཧེ་མ་ ཨིསི་ཀེ་ལར་ཨའུཊི་པུཊི་ལུ་ ཆ་མཉམ་བརྟག་དཔྱད་ཚུ་གཡོག་བཀོལ། མགྱོགས་འཕྲུལ་ཅིག་འཐུས་ཤོར་བྱུང་པ་ཅིན་ གཏན་འབེབས་བཟོ་མི་ ཨིསི་ཀེ་ལར་ཕོལ་བེཀ་ལག་ལེན་འཐབ། ནང་དོན་གནད་སྡུད ཡིག་བརྡ་འདི་བསྒྱུར་བཅོས་མེད་པར་བཞག་དགོ།
