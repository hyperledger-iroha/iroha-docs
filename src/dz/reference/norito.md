## Torii དང་ Norito RPC {#torii-and-norito-rpc}

Torii གིས་ ལས་འཛིན་ལམ་མང་རབས་ཅིག་གི་དོན་ལུ་ JSON གསལ་སྟོན་འབད་དོ་ཡོདཔ་ཨིན་རུང་ ཐོ་བཀོད་ཅན་གྱི་སྦྲེལ་མཐུད་ལམ་ཚུ་ནང་ Norito ལག་ལེན་འཐབ་ཨིན། current typeed Norito HTTP གི་གཟུགས་ཚུ་གི་དོན་ལུ་ བརྡ་བརྒྱུད་གི་དབྱེ་བ་འདི་ `application/x-norito` ཨིན།

མཐའ་མཇུག་གི་སྒོ་སྒྲིག་ཅིག་གིས་ Norito ཐོ་བཀོད་འབད་ཞིནམ་ལས་ ཡང་ན་ བཏུབ་པའི་སྐབས་ འ་ནི་ཨེབ་རྟ་ཚུ་ལག་ལེན་འཐབ་དགོ།

```http
Content-Type: application/x-norito
Accept: application/x-norito
```

མཐའན་མཇུག་གི་སྒོ་ཅིག་གིས་ ངོ་ཚབ་གཉིས་ཆ་ར་ལུ་ རྒྱབ་སྐྱོར་འབད་ཡོདཔ་ད་ མགྲོན་པོ་ཚུ་གིས་ ཁ་གསལ་སྦེ་ རང་འདོད་གི་ཐོ་ཡིག་ཚུ་བཏང་ཚུགས།

```http
Accept: application/x-norito, application/json
```
