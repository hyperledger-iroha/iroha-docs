# ཕྱི་ཁའི་འགན་ཁུར་གྱི་འབྲེལ་མཐུད་འབད་ཐངས་ (FFI) {#foreign-function-interfaces-ffi}

འདི་ཚུ་ `iroha_ffi` ཀེར་ཐིག་གིས་ C བཟོ་སྐྲུན་འབད་ནིའི་དོན་ལུ་ མཁའ་འགྲོ་དང་ཁྱད་ཆོས་ཚུ་ བྱིན་དོ་ཡོདཔ་ཨིན། ABI འབྲེལ་མཐུད་ཚུ་ Rust APIs. འདི་ནང་ལུ་ ལག་ལེན་འཐབ་ཨིན། Iroha རིགས་དབྱེ་བ་ཚུ་བརྒལ་དགོཔ་ཨིན། FFI ས་མཚམས་ དཔེར་ན་ SDK མཐུད་སྦྲེལ་འབད་ནི་དང་ མགྲོན་སྐྱོང་གློག་འཕྲུལ འབྲེལ་མཐུད་འབད་ནི་ཚུ་

## ག་ཅི་འབད་ FFI {#why-ffi}

འགན་འཁྲི་འདི་ མང་ཤོས་ཀྱི་སྐད་ཡིག་ཚུ་ནང་ ལཱ་ག་ཅི་འབད་དགོཔ་ཨིན་ནའི་སྐོར་ལས་ ངོས་ལེན་ཡོདཔ་ཨིན་རུང་ འགན་འཁྲུལ་དེ་ ག་ཅི་སྦེ་ངོ་སྤྲོད་འབདཝ་ཨིན་ན་ འདི་ཡང་ ཁྱད་པར་སྦོམ་ཅིག་ཨིན་མས། དེ་མ་ཚད་ སྐད་ཡིག་ལ་ལུ་ཅིག་ནང་ དཔེར་ན་ Rust འདི་བཟུམ་སྦེ་ འགན་འཁྲི་ཅིག་ལུ་འབོ་པའི་གྲུབ་འབྲས་དང་ འབད་ཆོག་པའི་ལཱ་ཚུ་ཡང་ ཁྱད་པར་ཅན་ཨིན། ཁྱོད་ཀྱིས་ Rust APIs ལུ་ སྐད་ཡིག་གཞན་ལས་ ཡང་ན་ གནས་སྟངས་སོ་སོ་ནང་ལས་འབོ་དགོ་པ་ཅིན་ Iroha གིས་ རྩེད་འགྲན་གི་གནས་སྟངས་དེ་འདྲ་མཉམ་བཟོ་ནིའི་དོན་ལུ་ ཕྱི་ཁའི་འགན་ལེན་ཡིག་ལྟེ་ (FFI) ལག་ལེན་འཐབ་ཨིན།

ད་རེས་ལག་ལེན་འཐབ་མི་ གནས་ཚད་ངོ་མ་འདི་ C གློག་རིམ གཉིས་ལྡན མཐུད་ངོས ཨིན། འདི་འཇམ་ཏོང་ཏོ་དང་ ཁྱབ་ཚུགསཔ་ དེ་ལས་བརྟན་ཏོག་ཏོ་ཨིན། གཞི་རྩ་ནང་ ཁྱོད་ཀྱིས་ག་ར་ལག་ཐོག་ལུ་འབད་ཚུགས་ནི་ཨིན་རུང་ Iroha གིས་ `iroha_ffi` རསཊ་ཆ་ཚན་ཅིག་ བཟོ་སྟེ་ཡོདཔ་ད་ འདི་གིས་ ཧེ་མ་ལས་ཡོད་པའི་ Rust API ལས་ FFI མཐུན་པ ལས་འགན བཟོ་ཚུགས།

ཨིན་རུང་ ཁྱེད་ཀྱིས་འདི་རང་གི་ཐབས་ལམ་ཐོག་ལས་བཟོ་ཚུགས། `iroha_ffi` རསཊ་ཆ་ཚན གིས་ག་དེ་སྦེ་ཨིན་རུང་ཁྱེད་ཀྱིས་འབྲི་དགོ་པའི་ཀོཌ་དེ་རྐྱངམ་ཅིག་བཟོཝ་ཨིན། དགོས་མཁོའི་ཚད་ལྡན་ཀོཌ་ལག་པར་འབྲི་ནི་ལུ་དྲན་ཤེས་དང་སྒྲིག་ལམ་ལེ་ཤ་དགོ། FFI མཐའ་མཚམས་བརྒལ་བའི་ལས་འགན་འབོད་བརྡ་རེ་རེ་ `unsafe` ཨིནམ་ལས་ བྱ་སྤྱོད་མ་ངེས་པ་འབྱུང་སྲིད། དཀའ་ངལ་འདི་ **སྲ་བརྟན** གྱི་ `repr(C)` དབྱེ་བ་ཚུ་ལག་ལེན་འཐབ་སྟེ་སེལ་ཡི།

::: info

དམིགས་བསལ་འདི་རྐྱངམ་ཅིག་དཔག་བྱེད་ཚུ་ཨིན། ཀླད་ཀོར་ཞིབ་དཔྱད་དང་ ནུས་ཅན་འདི་ འཛམ་གླིང་ཡོངས་ཁྱབ་ལུ་ བསྟར་སྤྱོད་འབད་མི་བཏུབ་ དེ་འབདཝ་ལས་ དཔག་བྱེད་སྔོ་མ་ཚུ་ (དུས་རྒྱུན་བཟུམ་སྦེ་) ཁྱད་འཕགས་ཅན་གྱི་གནས་སྟངས་ཚུ་ནང་རྐྱངམ་ཅིག་ལག་ལེན་འཐབ་ཨིན། ང་བཅས་ཀྱིས་ Iroha གནད་སྡུད་དཔེ་ཚད་ནང་ དངོས་པོ་གི་གནས་སྟངས་ཧ་ལམ་ག་ར་གི་མཐའ་འཁོར་ལུ་ མཉེན་ཆས་མཐུན་སྒྲིག་འབད་མི་ཚུ་བྱིན་མི་ལུ་བརྟེན་ ཁྱོད་ཀྱིས་ དཔག་བྱེད་ངོ་མ་ཚུ་ ལག་ལེན་འཐབ་མི་དགོ།

:::

## དཔེ་གཅིག་ {#example}

འདི་ནང་ལུ་ བཱའིན་ཌིང་ཅིག་བཟོ་བཏོན་འབད་ནིའི་དཔེ་ཅིག་ཡོད།

```rust
#[derive(FfiType)]
struct DaysSinceEquinox(u32);

#[ffi_export]
impl DaysSinceEquinox {
    pub fn update_value(&mut self, a: &u8) {
        self.0 = *a as u32;
    }
}
```

གོང་གི་དཔེ་འདི་གིས་ འོག་གི་བཱའིན་ཌིང་འདི་ `DaysSinceEquinox` དང་ཅིག་ཁར་ དྭངས་གསལ་མེད་པའི་དཔག་བྱེད་སྦེ་ངོས་འཛིན་འབད་འོང་།

```rust
pub extern fn DaysSinceEquinox__update_value(handle: *mut DaysSinceEquinox, a: *const u8) -> FfiReturn {
    // function implementation
}
```

## FFI བཟོ་སྐྲུན་ {#ffi-binding-generation}

`iroha_ffi` རསཊ་ཆ་ཚན་འདི་ FFI གྱི་ཐོག་ལས་ ཀལ་འབད་བཏུབ་པའི་ འགན་ཁུར་ཚུ་ བཟོ་ནིའི་དོན་ལུ་ལག་ལེན་འཐབ་ཨིན། `Rust` གི་བཟོ་རྣམ་དང་ ཐབས་ལམ་ཚུ་བྱིན་ཞིནམ་ལས་ ཁྱོད་ཀྱིས་འབྲེལ་མཐུད་ཀྱི་མཐའ་མཚམས་བརྒལ་བའི་དོན་ལུ་ དགོས་མཁོ་ཅན་གྱི་ `unsafe` ལྡེ་མིག་ཚུ་བཟོ།

`Rust` དབྱེ་བ་ཅིག་ `FfiType::into_ffi` བརྒྱུད་དེ་ FFI མཐའ་མཚམས་ལས་སྲ་བརྟན་སྦེ་བརྒལ་ཚུགས་པའི་ `repr(C)` དབྱེ་བ་ལུ་བསྒྱུརཝ་ཨིན། བྱ་རིམ་འདི་ལོག་ཕྱོགས་ལུ་ཡང་འབད་ཚུགས། FFI `ReprC` དབྱེ་བ་ཅིག་ `FfiType::try_from_ffi` བརྒྱུད་དེ་ `Rust` དབྱེ་བ་ལུ་ལོག་བསྒྱུརཝ་ཨིན།

::: warning

ལྡོག་ཕྱོགས་བསྒྱུར་བཅོས་འདི་འཛོལ་བ་ཡོདཔ་ལས་ ངེས་ཚིག་མ་བཀོད་པའི་སྤྱོད་ལམ་འབྱུང་བཅུགཔ་ཨིནམ་དྲན་འཛིན་འབད། ང་བཅས་ཀྱིས་ མངོན་གསལ་ཅན་གྱི་འཛོལ་བ་ཚུ་ བཀག་ཐབས་ལུ་ བརྩོན་ཤུགས་བསྐྱེད་ཚུགས་རུང་ ཁྱོད་ཀྱིས་ ཁྱོད་རའི་མཇུག་ལུ་ ལས་རིམ་གྱི་ བདེན་པ་འདི་ ངེས་གཏན་བཟོ་དགོ།

:::

བཱའིན་ཌིང་བཟོ་བསྐྲུན་འབད་ཚུགས་པའི་ཁྱད་ཆོས་ངོ་མ་ཚུ་ `ReprC`, `FfiType`, དང་ `FfiConvert` ཚུ་ཨིན།

| རང་གཤིས་ | འགྲེལ་བཤད། |
| ------------ | ------------------------------------------------------------------------------- ----------------------------------------------------------------------------------- |
|`ReprC` |འ་ནི་ཁྱད་ཆོས་འདི་ C ABI དང་གཅིག་ཁར་མཐུན་ལམ་ཅན་ཅིག་ཨིནམ་ཨིན། བཟོ་བཀོད་འདི་ FFI གི་ས་མཚམས་ཚུ་ནང་ ཉེན་སྲུང་ལྡན་པའི་ཐོག་ལས་བགོ་བཤའ་རྐྱབ་ཚུགས། |
|`FfiType` |འ་ནི་ཁྱད་ཆོས་འདི་ `Rust` གི་དབྱེ་བ་ཅིག་གི་དོན་ལུ་ འོས་འབབ་ཅན་གྱི་ `ReprC` ཐིག་ཁྲམ་ཅིག་ ངེས་འཛིན་འབདཝ་ཨིན། བཟོ་བཀོད་འབད་ཡོད་པའི་ `ReprC` གྱི་དབྱེ་བ་དེ་ ཐོན་སྐྱེད་འབད་མི་ FFI འགན་ཁུར་གི་ API ནང་ `Rust` ཀྱི་ཚབ་ལུ་ ལག་ལེན་འཐབ་ཨིན། |
| `FfiConvert` | ཁྱད་ཆོས་འདི་གིས་ `into_ffi` དབྱེ་བ་འདི་ `try_from_ffi` དབྱེ་བ་ལུ་ཡང་ན་ དབྱེ་བ་ལས་གཞི་བསྒྱུར་འབད་ནི་ལུ་ལག་ལེན་འཐབ་མི་ `Rust` དང་ `ReprC` ཐབས་ལམ་གཉིས་ངེས་འཛིན་འབདཝ་ཨིན། |

FFI གི་ནང་འཁོད་ལུ་ སྦྱིན་བདག་གྱི་བགོ་བཤའ་དེ་མེད་ཟེར་དྲན་གསོ་འབད་དགོ་ དྭངས་གསལ་མེད་པའི་བརྡ་སྟོན་དབྱེ་བ་ཚུ་མ་གཏོགས་གཞན་ཨིན། གཞན་ཡང་སྦྱིན་བདག་གི་རིགས་ཚུ་ དཔེར་ན་ `Vec<T>` འདི་ཚུ་ ཀྲོན་འབདཝ་ཨིན།

### མིང་གཟུགས་བསྒྱུར་ནི་ {#name-mangling}

FFI དངོས་པོ་ཚུ་གི་བཟོ་བཏོན་འབད་ཡོད་པའི་མིང་ཚུ་ནང་ འོག་ཐིག་གཉིས་ལག་ལེན་འཐབ་མི་འདི་དྲན་འཛིན་འབད།

- `StructName` བཟོ་བཀོད་ནང་ལུ་ གསལ་བཀོད་འབད་ཡོད་མི་ `inherent_fn` ཐབས་ལམ་གྱི་དོན་ལུ་ FFI ཟེར་མི་མིང་འདི་ `StructName__inherent_fn` ཨིན་པས།
- `TraitName`གི་དབྱེ་བ་ལས་ `MethodName`གི་ཐབས་ལམ་གྱི་དོན་ལུ་ `StructName` བཟོ་བཀོད་ནང་ FFI གི་མིང་འདི་ `StructName__TraitName__MethodName` འབད་ནི་ཨིན།
- `StructName` བཟོ་བཀོད་ནང་ལུ་ `field_name` ས་ཁོངས་དེ་ གཞི་སྒྲིག་འབད་བ་ཅིན་ FFI འགན་ཁུར་གི་མིང་འདི་ `StructName__set_field_name` འབད་ནི་ཨིན།
- `StructName` བཟོ་བཀོད་ནང་ལུ་ `field_name` ས་ཁོངས་ཐོབ་ནིའི་དོན་ལུ་ FFI འགན་ཁུར་གི་མིང་འདི་ `StructName__field_name` འབད་ནི་ཨིན།
- `StructName` བཟོ་བཀོད་ནང་ལུ་འགྱུར་ལྡོག་ཅན་གྱི་ `field_name` ས་ཁོངས་ཐོབ་ནིའི་དོན་ལུ་ FFI འགན་ཁུར་གི་མིང་འདི་ `StrucuName__field_name_mut` འབད་ནི་ཨིན།
- རང་དབང་གནས་ཚད་ཅན་གྱི་ `module_name::fn_name`གི་དོན་ལུ་ མིང་འདི་ FFI འབད་ནི་ཨིན། `module_name::__fn_name`
- རིགས་དབྱེ་བ་ཚུ་ སྤྱིར་བཏང་མེནམ་དང་ ཁོང་རའི་ལག་ལེན་ནང་ བརྗེ་སོར་འབད་ནིའི་གོ་སྐབས་བྱིན་ FFI (བལྟ་ར) `Clone` འོག་གི་ཤོག་ལེབ་ཚུ་ FFI མིང་འདི་ `module_name::__clone`.
