# Iroha 3 འབྲི་ཤོག་ལག་ལེན་ལག་དེབ་ {#iroha-3-application-cookbook}

ཁྱོད་ཀྱིས་ Iroha 3 གྱི་རྒྱབ་འགལ་ལུ་བཟོ་ནི་ཨིནམ་ད་ བརྟག་ཞིབ་འབད་ཚུགས་མི་ བཀྲམ་སྟོན་རྫས་ཆུང་ཤོས་ཚུ་འདི་ Taira བཀྲམ་སྤེལ་འབད་ཐངས་ལས་འགོ་བཙུགས་ཏེ་ Minamoto མང་ཤོས་ཀྱི་བཀྲམ་སྤེལཔ་རྐྱངམ་ཅིག་བཀླགས་ཚུགསཔ་བཟོཝ་ཨིན། བཀྲམ་ཡིག་རེ་རེ་གི་ནང་ གསལ་བཀོད་འབད་བ་ཅིན་ མི་མང་གིས་ལྷག་སྟེ་ཡོད་མེད་ ཡང་ན་ དངུལ་ཕོགས་ཐོབ་མི་རྩིས་ཡིག་རྒྱུན་གྱི་ཐོག་ལས་བྲིས་ཡོདཔ་ཨིན་ན་ ཡང་ཅིན་ ངོས་ལེན་འབད་ཐངས་ཡོད་པའི་ལག་ལེན་འཐབ་ཐངས་ཨིན་མེན་ནམ། བཀའ་རྒྱ་ཚུ་ནང་ ད་ལྟོའི་ I105 རྩིས་ཐོ་IDs ལག་ལེན་འཐབ་དོ་ཡོདཔ་ད་ འགྲེལ་བཤད་ཅན་གྱི་འཐུས་གདམ་ཁ་དང་ བྱ་སྤྱོད་དེ་ Iroha ལུ་ འཛུལ་ཞུགས་འབད་ཡོདཔ་ཨིན། [`0010c5a70039eac101a4846499ba9ceaf43eb65c`](https://github.com/hyperledger-iroha/iroha/tree/0010c5a70039eac101a4846499ba9ceaf43eb65c).

## འོང་འབབ་ཀྱི་གནས་ཚད་ {#access-levels}

- **མི་མང་** — མིང་རྟགས་བཀོད་མི་དང་ ཡང་ན་ ཡོངས་འབྲེལ་གྱི་གནང་བ་དགོཔ་མེད།
- འབྲི་ནིའི་དོན་ལུ་གྲ་སྒྲིག་ — མ་དངུལ་ཡོད་པའི་ Taira བརྟག་དཔྱད རྩིས་ཐོ, གསལ་ཏོག་ཏོ་ཡོད་པའི་ གླ་ཡོན གླ་ཡོན་སྤྲོད་མི དང་ བརྟག་དཔྱད་ཊོ་ཀེན་ཞབས་ཏོག གིས་ལོག་སྤྲོད་མི་ད་ལྟོའི་ གླ་ཡོན རྒྱུ་དངོས ལག་ལེན་འཐབ།
- ངོས་ལེན་འདི་ དགོཔ་ཨིན།  Taira གིས་མིང་ཐོ་བཀོད་འབད་བའི་དུས་ཚོད་ལུ་ ངོས་ལེན་འབད་ནི་དང་ ཡང་ན་ མིང་གི་ས་སྟོང་ཚུ་བྱིན་དགོཔ་ཨིན། གྲོགས་རམ་འདི་མེད་པ་ཅིན་ འབྱུང་ཁུངས་ཡོད་པའི་ ས་གནས་ཀྱི་དྲ་རྒྱ་ལག་ལེན་འཐབ་དགོ། ས་གནས་ཀྱི་རྒྱལ་ཁ་གིས་ Taira གི་དབང་ཤུགས་བྱིན་མི་ཚུགས།

ལག་ལེན་ཐབས་དེབ ལག་ལེན་ཐབས གང་གིས་ཡང་ Minamoto ལུ་ འབྲི བཀོལ་སྤྱོད མི་བཏང་།
