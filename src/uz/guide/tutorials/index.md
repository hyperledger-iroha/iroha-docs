# SDK Darsliklar {#sdk-tutorials}

Ushbu sahifalar asosiy ish maydonidan yuborilgan Iroha 3 mijoz kirish nuqtalarini, jumladan kanonik paket nomlari, o‘rnatish yo‘llari va minimal boshlang‘ich nuqtalarni umumlashtiradi.

## Tavsiya etilgan tartib {#recommended-order}

1. [Iroha 3 ni o'rnatish](/uz/get-started/install-iroha.md)
2. [Ishga tushurish Iroha 3](/uz/get-started/launch-iroha.md)
3. Bir SDK ni tanlang:
   - [Rust](/uz/guide/tutorials/rust.md)
   - [Python](/uz/guide/tutorials/python.md)
   - [JavaScript / TypeScript](/uz/guide/tutorials/javascript.md)
   - [Kotlin, Android, va Java](/uz/guide/tutorials/kotlin-java.md)
   - [Swift va iOS](/uz/guide/tutorials/swift.md)
4. To‘liq mijoz dasturi havolasini xohlaganingizda [namuna ilovalar](/uz/guide/tutorials/sample-apps.md) ni ko‘rib chiqing.
5. Oʻz ilovangizga hamyon bilan qoʻllab-quvvatlanadigan audio/video uchrashuvlarni qoʻshmoqchi boʻlsangiz, [Joylashtirish Kaigi](/uz/guide/tutorials/kaigi.md) dan foydalaning.
6. [Musubi paketlar](/uz/guide/tutorials/musubi.md) dan qayta ishlatiladigan Kotodama manba kutubxonalari va zanjir ustidagi ro‘yxatga olingan bog‘liqliklar kerak bo‘lganda foydalaning.

## Namuna {#samples}

Yuqumli ish maydonchasida JavaScript retseptlar va Swift/iOS namuna loyihalari mavjud. Android uchun Kotlin SDK modullari va ularning testlari bilan boshlang.

- [Namuna ilovalarining umumiy ko'rinishi](/uz/guide/tutorials/sample-apps.md)
- [Kaigi ni JavaScript ilovasiga joylashtirish](/uz/guide/tutorials/kaigi.md)

## Haqiqat manbai {#source-of-truth}

Bu yerda barcha SDK sahifalar joriy yuqoridagi ish maydonchasidan olinadi:

- `crates/iroha`
- `python/iroha_python`
- `javascript/iroha_js`
- `kotlin`
- `java/iroha_android` (Kotlin-birinchi Android sirtining Java oynasi)
- `IrohaSwift`
- `crates/musubi`

Agar shubha bo‘lsa, ushbu kataloglardagi README va paket metama’lumotlarini afzal ko‘ring; ular siz qurayotgan manba reviziyasini tasvirlaydi.
