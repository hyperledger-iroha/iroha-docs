# 获得支持 {#receive-support}

有时,你可能会有问题 Iroha 有三种方法可以快速联系我们的社区:电讯,分歧和 GitHub.

社区使用 [电报](https://t.me/hyperledgeriroha) 并且
[LF Decentralized Trust 争议](https://discord.gg/hyperledger) 对于
通过 `iroha` 项目问题道.

最后,你能 [创建一个 GitHub 问题](https://github.com/hyperledger-iroha/iroha/issues/new/choose), 不管是要求更新文档, 对于核心团队的建议还是你发现的一个错误.
