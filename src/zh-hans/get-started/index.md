# Iroha 3 {#iroha-3}

Iroha 3 是首次发布的 Hyperledger Iroha 支持自主托管的网络和多数据空间 SORA Nexus 基于一个确定性代码基础的部署模型.

在高水平上, Iroha 3 结合:

- 确定性执行和存储
- Iroha 移动智能合同虚拟机 (IVM)
- Norito 作为法典电线格式
- Torii 用于客户端,运营商和应用程序面向 APIs
- Sumeragi 与强制性的数据可用性和可靠的广播达成一致
- 没有域名的可信账户,具有单独绑定的人类可读的号
