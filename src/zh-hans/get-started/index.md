# Iroha 3 {#iroha-3}

Iroha 3 是首次发布的 Hyperledger Iroha 它支持
自主托管网络和多数据空间 SORA Nexus 部署模式
一个确定性代码基础.

在一个高层次, Iroha 3 结合:

- 确定性执行和存储
- 在 Iroha 虚拟机 (IVM) 适用于便携式智能合同
- Norito 作为法典电线格式
- Torii 为客户端,运营商和应用程序面向 APIs
- Sumeragi 与强制性数据可用性和可靠的广播达成共识
- 无域名的可信账户,具有单独绑定的人类可读的称
