# 公共和私人区块链 {#public-and-private-blockchains}

Iroha 可以在各种配置中运行.作为您自己的网络的管理员,您决定哪个执行者和许可政策确定交易是否被接受

常见的配置文件是私人授权网络和更开放的公共网络.这两者都通过基因状态和执行程序政策进行配置,而不是通过单独的节点二进制.

下面我们概述了这两种使用情况的主要区别.

## 许可证 {#permissions}

在公共区块链中,大多数账户都有相同的权限.在私人区块链上,大部分帐户被假定除非明确授予相关许可,否则无法在获得权限之外做任何事情.

::: 信息

查看 [专用部分关于许可证](/zh-hans/blockchain/permissions.md)的详细信息.

:::

## 同龄人 {#peers}

在公共区块链中,同行录取是链条政策的一部分.对于私人区块链来说,部署通常将可信赖的同行设置定在配置和生成中.

::: 信息

查看[同行管理](peer-management.md)详细信息.

:::

## 登记账户 {#registering-accounts}

根据您决定如何设置[创始区块 (`genesis.json`) ](genesis.md),注册账户的过程可能是两种方式之一.

选择的执行器定义了哪些权限检查适用.您可以在创始中赋予默认的 [权限代币](/zh-hans/blockchain/permissions.md)来塑造一个私人,管理员管理的网络或更开放的网络.一旦这些权限被激活后,帐户注册过程是不同的.

在注册账户方面,公共区块链和私人区块链有以下不同:

- 在公共区块链中,任何人都应该能够注册一个帐户[^1].所以,理论上,你所需要的只是一个合适的客户端,一种方法来生成一个支持的算法的私钥,以及允许政策接受注册.

- 在私人区块链中,您可以设置帐户的任何过程:可能是通过特定账户提交注册说明,或者通过其他详情要求的智能合同.在私人区块链中,只能在特定的日期注册新账户,或者仅限于非可选 (有限) 代币.

- 在典型的私人区块链中,即没有任何独特的账户注册过程中的区块链,你需要一个账户,才能注册另一个帐户.

默认许可证验证器涵盖典型的私人区块链使用情况.

::: 信息

公共模式和私有模式是政策配置文件,而不是单独的节点二进制. 在运行开放网络之前,请检查您发送的执行器和创始权限

:::

查看 [指令](/zh-hans/blockchain/instructions.md#un-register)的部分,了解有关 `Register<Account>`指令的更多细节.

[^1]: `Register<Account>`为常规,无域名的 `AccountId`创建账本状态;域名路由和姓氏分别管理.
