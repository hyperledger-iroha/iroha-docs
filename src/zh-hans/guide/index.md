# 指南 {#guide}

在构建,运营或与 Iroha 集成时使用此节目.开始为第一个客户端使用 SDK 教程,然后在与共享网络部署之前转向最佳实践和操作员参考.

## 部分 {#sections}

|部分|用它来|
| ------------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------- |
| [SDK 教程](/zh-hans/guide/tutorials/) |语言特定的客户端设置和应用程序样本|
| [最好的实践](/zh-hans/guide/best-practices/) |开发,部署,运营,安全和发布的生产指南|
| [配置和管理](/zh-hans/guide/configure/overview.md) |当地对等节点配置,创世,客户端配置,键和对等节点管理 |
| [安全性](/zh-hans/guide/security/) |关键处理,运营安全, VPNs,欺诈监控和许可卫生 |
| [高级运营](/zh-hans/guide/advanced/metrics.md) |测量表,性能检查,混沌测试,热充电和裸金属操作|

## 建议的路径 {#recommended-path}

1. [安装 Iroha 3](/zh-hans/get-started/install-iroha.md)和 [启动本地网络](/zh-hans/get-started/launch-iroha.md).
2. 选择一个 [SDK 教程](/zh-hans/guide/tutorials/),并提交一个小交易.
3. 审查 [应用开发](/zh-hans/guide/best-practices/application-development.md) 和 [数据建模](/zh-hans/guide/best-practices/data-modeling.md) 在制定申请之前 API.
4. 在运行共享或生产网络之前,使用 [网络部署](/zh-hans/guide/best-practices/network-deployment.md), [操作](/zh-hans/guide/best-practices/operations.md)和 [安全与访问](/zh-hans/guide/best-practices/security-and-access.md).
5. 在从本地开发推广到 Taira, Minamoto 或其他现场部署时,遵循 [发布就绪](/zh-hans/guide/best-practices/release-readiness.md).
