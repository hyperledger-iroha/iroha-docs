# 指南 {#guide}

使用此部分,当您构建,运营或集成
Iroha. 首先, SDK 首先为一个客户提供教程,然后转移到
在部署之前,使用最佳实践和运营商参考
网络.

## 部分 {#sections}

| 部分                                                      | 用它来                                                                                                                  |
| ------------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------- |
| [SDK 教程](/zh-hans/guide/tutorials/)                           | 语言特定客户端设置和应用程序样本                                                                      |
| [最好的做法](/zh-hans/guide/best-practices/)                     | 基于开发,数据建模,部署,运营,安全和发布准备的生产指导 |
| [配置和管理](/zh-hans/guide/configure/overview.md) | 地方同行配置,起源,客户端配置,密钥和同行管理                                          |
| [安全](/zh-hans/guide/security/)                                 | 关键处理,运营安全 VPNs, 欺诈监测和许可卫生                                          |
| [高级运营](/zh-hans/guide/advanced/metrics.md)            | 测量,性能检查,混乱测试,热充电和裸金属操作                                            |

## 建议的路径 {#recommended-path}

1. [安装 Iroha 3](/zh-hans/get-started/install-iroha.md) 并且
   [启动本地网络](/zh-hans/get-started/launch-iroha.md).
2. 选择一个 [SDK 教程](/zh-hans/guide/tutorials/) 然后把一个小的
   交易.
3. 审查
   [应用开发](/zh-hans/guide/best-practices/application-development.md)
   并且 [数据建模](/zh-hans/guide/best-practices/data-modeling.md) 之前
   制定申请 API.
4. 使用 [网络部署](/zh-hans/guide/best-practices/network-deployment.md),
   [运营](/zh-hans/guide/best-practices/operations.md), 并且
   [安全与获取](/zh-hans/guide/best-practices/security-and-access.md)
   在运行共享或生产网络之前.
5. 接下来 [准备释放](/zh-hans/guide/best-practices/release-readiness.md)
   在从本地发展推广到 Taira, Minamoto, 或其他
   现场部署.
