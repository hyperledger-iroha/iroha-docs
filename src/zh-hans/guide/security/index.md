# 安全 {#security}

在使用时 Iroha 或任何其他区块链账本,对于金融组织来说,安全是至关重要的,因为它构成了敏感财务数据和交易常规行业的信任基础.恶意行为成功违反安全行为可能会对您带来毁灭性的后果.因此,建立预防性安全措施是保护您敏感数据的完整性和机密性至关重要的.
