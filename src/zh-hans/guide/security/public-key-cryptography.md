# 公共密钥加密 {#public-key-cryptography}

公共密钥加密提供了安全通信和数据保护的手段,使得安全在线交易,加密电子邮件通信等活动能够进行.

公共密钥加密技术采用一对加密密钥公钥和私钥,以创建通过网上网络传输信息的高度安全方法.

很容易从私钥中做出公共密钥,但相反是相当困难的,如果不是不可能的.这让事情保持安全.你可以自由地分享你的公钥,而不冒险你的私钥,它仍然安全.

## 加密和签名 {#encryption-and-signatures}

公共密钥加密允许个人发送加密信息和数据,这些信息只能由预期接收者拥有相应的私钥来解码.换句话说,公钥作为锁,而私钥作为一个真正的独特密钥来解锁加密的数据.

这种加密过程不仅确保了敏感信息的隐私和机密性,而且还确定了发送者的真实性.通过将发送人的私钥与公钥结合起来,创建了一个数字签名.这种签名作为一个数字认证盖章,验证发送人的身份和传输数据的有效性.任何持有公共密钥的人都可以验证创办交易的人是否使用您的私钥.

## 客户端的钥匙 {#keys-on-the-client-side}

每笔交易都必须由一个账户权威机构签署.该机构的私钥或控制器材料必须保持秘密,因此客户端软件负责安全存储和签字.

::: 警告

所有客户端都是不同的,但平文客户端配置仅适合开发和控制测试网络.生产集成应使用秘密管理器,硬件支持的关键存储或其他审计签名界限.

:::

登记新帐户需要生成控制器材料,例如Ed25519键对,并将公开部分提交给网络. 从该账户后续的交易必须通过相匹配的私钥或配置的帐户控制器政策签署.

为了使公钥加密有效地工作,在需要指定新密钥时避免重复使用密钥.虽然没有什么阻止你这样做,但公共密钥是公开的,这意味着如果攻击者看到相同的公钥被使用,他们会知道私钥也是相同的.

虽然私钥与密码略有不同,但建议要尽可能随机使用它们,永远不要将它们存储在未加密的状态下,也不会在任何情况下与任何人分享.
