# 安全原则 {#security-principles}

组织和个人用户需要共同努力,以确保与 Iroha 本主题解释了这种合作的基本原则.

## 安全总理 {#general-security-principles}

1. 使用一个 [虚拟私人网络](./vpn.md) (VPN):

    - 在访问敏感数据或资源时,特别是在公共网络上, <abbr title="Virtual Private Network">VPN</abbr> 建立一个安全的连接,以保护您的信息.

2. 使用防火墙来保护网络:

    - 通过设置防火墙来加强家庭和/或办公网络,帮助抵制未经授权访问并保护连接设备免受病毒和恶意软件攻击.

3. 安全的物理和数字信息:

    - 在安全位置保护含有敏感信息的物理文件,并确保数字文档加密并存储在密码保护的文件中.

4. 定期备份数据:

    - 总是保存重要信息的副本在安全的地方.这样,如果你丢失了数据或发生错误的话,你就可以快速恢复一切.

## 个人用户的安全原则 {#security-principles-for-individual-users}

1. 采用强有力的身份验证规则:

    - 使用所有帐户的强大和独特密码.

    - 不要再使用密码.

    - 设置 <abbr title="Two-Factor Authentication">2FA</abbr> 在可能的情况下. <abbr title="Two-Factor Authentication">2FA</abbr> 通过不仅需要密码,而且还需要一个额外的因素 <abbr title="One-Time Password">OTP</abbr>, 指纹或基于第三方应用程序的身份验证 (例如谷歌身份验证器).

    - 避免使用 SMS 没有任何保证恶意软件不会监控所有 SMS 例如: Android 应用程序不能仅限于访问专门针对其的信息.

2. 在数字通信时要谨慎:
    - 设置一个电子邮件客户端来签署和验证所有收到的电子邮件的签名.虽然可以假装发送者的地址,甚至假装是银行,但无法伪造签名.
    - 禁用两者 HTML 从未知或未经验证的地址传输信息和外部资源.

    - 了解常见的鱼技巧,以识别和避免可疑电子邮件,链接和请求个人信息.

    - 设置一个电子邮件客户端来签署和验证所有收到的电子邮件的签名.虽然可以假装发送者的地址,甚至假装是银行,但无法伪造签名.

3. 保护个人信息:

    - 当与陌生人,尤其是通过电话或网上交流时,请小心不分享私密信息.

    - 考虑独立研究你与沟通的个人或组织,以确认他们的身份.

    - 请注意您在社交媒体平台上分享的个人信息,因为恶意行为者可能会利用这些信息.

## 组织安全原则 {#security-principles-for-organisations}

1. 制定明确的安全政策和程序:

    - 为所有处理敏感数据的员工制定明确的安全政策和协议. 彻底训练员工遵守这些指导方针,减轻疏忽行为风险.

    - 确保所有员工都能获得安全政策,定期审查和更新以反映不断变化的安全环境.

    - 提供安全政策的例子和场景,使其更容易被员工了解并可操作.

2. 培养员工意识:

    - 培养员工了解数据和运营安全措施.提高认识和全面培训是加强组织安全的关键.

    - 鼓励员工立即报告任何可疑活动或安全问题.

3. 保护物理基础设施:

    - 限制服务器和基础设施的物理进入,设置只允许授权人员进入受限区域的访问控制.

    - 确保定期审查和更新访问控制措施,以适应不断变化的安全需求.

    - 考虑对敏感区域实施生物识别访问控制,以加强物理安全.

4. 部署安全监测:

    - 执行全面的安全监测系统,审查活动并确定潜在的安全漏洞.

    - 执行自动提醒,即时通知安全人员任何不寻常或未经授权的活动.

    - 考虑使用机器学习算法来提高系统检测异常和潜在威胁的能力.

    - 雇佣员工或指定人员监督数据库安全,识别,跟踪和解决软件漏洞,并定期检查关键机器是否存在未经批准的软件.

5. 进行反复的安全审计:

    - 进行常规的安全审计,以评估漏洞并确认已建立的安全措施符合公认的标准和法规.

    - 考虑聘请外部安全专家进行定期评估,以获得无偏见的评价.

6. 实施访问控制系统:

    - 建立一个基于角色的访问控制系统,以确保员工只能获得所需资源和信息.

7. 接受不断改善:

    - 确认安全是一个持续的过程.保持对安全措施的持续评估,并积极加强它们以应对新出现的威胁和挑战.

    - 考虑建立一个反循环,鼓励员工提供安全改进建议,促进不断增强的文化.
