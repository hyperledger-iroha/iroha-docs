# 样本和食谱 {#samples-and-recipes}

其他 Iroha 源存储库包含 SDK 配方和测试套件
同一个节点的修改.

## JavaScript 配方 {#javascript-recipes}

[`javascript/iroha_js/recipes`](https://github.com/hyperledger-iroha/iroha/tree/main/javascript/iroha_js/recipes)
包含确定性交易批量的专注示例, Nexus 应用程序
转让, NFT 和账户回复, ISO 桥梁流动,以及 Torii 在线播放.
每个食谱都记录了它是否在线运行或需要现场 Torii 终点.

## Swift 和iOS {#swift-and-ios}

使用 `IrohaSwift/Tests/IrohaSwiftTests` 对于与电流相比验证的例子
Swift SDK. 看看 [Swift 和iOS](/zh-hans/guide/tutorials/swift.md) 包装和桥梁
设置.

## Android {#android}

对于新品 Android 工作,使用 Kotlin- 首先 `core-jvm`, `client-android`, 并且
`offline-wallet-android` 描述在
[Kotlin, Android, 和Java](/zh-hans/guide/tutorials/kotlin-java.md). 其他 Kotlin SDK 是
圣经的起点 Android 消费者.
