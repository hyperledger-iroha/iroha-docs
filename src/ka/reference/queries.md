# კითხვები {#queries}

Iroha შეკითხვები ბლოკჩეინის რეესტრის მდგომარეობას უმოქმედებენ. მიმდინარე მონაცემთა მოდელი გამოყოფს ორ ფართო შეკითხვის ფორმას:

- ცალკეული მოთხოვნები, რომლებიც უბრუნებენ ერთ ობიექტს ან ერთ ღირებულებას
- იტერირებადი მოთხოვნები, რომელიც ბრუნდება ნაკადი ან კოლექცია და შეიძლება გაერთიანდეს ფილტრირება, დახარისხება, პროექტირება, და pagination სადაც მოთხოვნის ტიპი მხარს უჭერს მას

გამოიყენეთ SDK ტიპირებული კონსტრუქტორები ან CLI, იმის ნაცვლად, რომ შეკითხვის მონაცემების კონტეინერები ხელით შექმნათ. ქვემოთ მოცემული სახელები არის მიმდინარე შეკითხვების ტიპები, რომლებიც გამოქვეყნებულია `iroha_data_model::query`.

## ფილტრირება და გვერდების გაფორმება {#filtering-and-pagination}

იტერირებადი შეკითხვები შეიძლება გამოავლინოს პრედიკატისა და სელექტორის მხარდაჭერა. გამოიყენეთ შეკითხვის სპეციფიკური ტიპირებული ფილტრები SDK ისე, რომ ფილტრის შესავალი შეესაბამება შეკითხვის საგამოშვო ტიპს. დიდი შედეგების ნაკრებისთვის, გამოიყენეთ შეტყობინების პარამეტრები, როგორიცაა კურსორი და ლიმიტი ნაცვლად თითოეული რიგის ერთდროულად მოპოვების.
