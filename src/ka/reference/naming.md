# კონვენციების დასახელება {#naming-conventions}

ანგარიშების, დომენების ან აქტივების დასახელებისას უნდა გაითვალისწინოთ Iroha -ში გამოყენებული შემდეგი კონვენციები:

1. არსებობს რიგი რეზერვებული სეპარატორები, რომლებიც გამოიყენება კონკრეტული ტიპის კონსტრუქციებისათვის:

   - `@` განკუთვნილია ანგარიშის ანალიზებისთვის და ანგარიშის/საჯარო გასაღების ფორმებისათვის
   - `#` განკუთვნილია აქტივების განსაზღვრის ანალიზებისა და აქტივების ბალანსის ლიტერალებისთვის.
   - `::` განკუთვნილია ხელშეკრულების ანალიზებისთვის
   - `.` განკუთვნილია დომენის და მონაცემთა სივრცეების კვალიფიკაციისთვის.
   - `$` განკუთვნილია ტექსტური ფორმებისათვის, რომლებიც გააჩნია ტრიგერ-სკოპი.
   - `%` განკუთვნილია ვალიდატორის მიერ დამტკიცებული ტექსტური ფორმებისათვის

2. დასახელების მაქსიმალური სიმბოლოების რაოდენობა (მათ შორის UTF-8 სიმბოლოები) ორი ფაქტორით არის შეზღუდული: `[0, u32::MAX]` და ამჟამად განკუთვნილი სტაკის სივრცე.

## სცადეთ Taira {#try-it-on-taira}

საჯარო აქტივების ანალოგიური განსაზღვრა მისი კანონიკური აქტივების განმარტებაში ID:

```bash
curl -fsS https://taira.sora.org/v1/assets/aliases/resolve \
  -H 'content-type: application/json' \
  -d '{"alias":"usd#wonderland"}' \
  | jq '{alias, asset_definition_id, asset_name, status: .alias_binding.status}'
```

შეადარეთ ამას აქტივების განსაზღვრის სიასთან:

```bash
curl -fsS 'https://taira.sora.org/v1/assets/definitions?limit=20' \
  | jq -r '.items[] | select(.alias != null) | [.alias, .id, .name] | @tsv'
```

`#` ხასიათი განასხვავებს აქტივის საიდუმლოს დომენის კონტექსტიდან. შეინახეთ იგი უბრალო სახელებისგან, თუ თქვენ მიზანმიმართულად არ წერთ აქტივის საიდენს ან აქტივის ბალანსის ლიტერატურულ ასლს.
