# კონვენციების დასახელება {#naming-conventions}

როდესაც ანგარიშების, დომენების ან აქტივების დასახელებას აკეთებთ, უნდა გაითვალისწინოთ
შემდეგი კონვენციები გამოიყენება: Iroha:

1. არსებობს რიგი რეზერვებული სეპარატორები, რომლებიც გამოიყენება კონკრეტულ
   კონსტრუქციის ტიპები:

   - `@` განკუთვნილია ანგარიშის საიდუმლოებისათვის და ანგარიშის/საჯარო გასაღები ფორმებისათვის
   - `#` განკუთვნილია აქტივების განსაზღვრის ანალიზებისთვის და აქტივების ბალანსის ლიტერალურებისთვის
   - `::` კონტრაქტის საიდუმლოების გამოყენება
   - `.` განკუთვნილია დომენის და მონაცემთა სივრცის კვალიფიკაციისთვის
   - `$` განკუთვნილია ტექსტური ფორმებისათვის, რომლებიც გააჩნიათ გამშვები სკოპით
   - `%` განკუთვნილია დამტკიცების სკოპის ტექსტური ფორმებისთვის

2. ქაღალდების მაქსიმალური რაოდენობა (მათ შორის UTF-8 ხასიათები) სახელი შეიძლება
   აქვს ორი ფაქტორით შეზღუდული: `[0, u32::MAX]` და ამჟამად
   გათვალისწინებული სივრცე.

## სცადე. Taira {#try-it-on-taira}

საჯარო აქტივის ანალიზის განხილვა მისი კანონიკური აქტივების განსაზღვრაში ID:

```bash
curl -fsS https://taira.sora.org/v1/assets/aliases/resolve \
  -H 'content-type: application/json' \
  -d '{"alias":"usd#wonderland"}' \
  | jq '{alias, asset_definition_id, asset_name, status: .alias_binding.status}'
```

შეადარეთ ამას აქტივების განსაზღვრის სიასთან:

```bash
curl -fsS 'https://taira.sora.org/v1/assets/definitions?limit=20' \
  | jq -r '.items[] | select(.alias != null) | [.alias, .id, .name] | @tsv'
```

სააგენტო `#` ხასიათი აცალებს აქტივის საგნელს დომენის კონტექსტიდან. შეინახეთ იგი გარეთ
პირდაპირი სახელების, თუ თქვენ მიზანმიმართულად წერენ აქტივის alias ან აქტივი
ბალანსი ლიტერალურადაა.
