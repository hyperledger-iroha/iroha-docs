# ნებართვის ქაღალდები {#permission-tokens}

ეს გვერდი ასახავს ამჟამინდელი Iroha აღმასრულებლის მონაცემთა მოდელის მიერ გამოქვეყნებულ ნებაყოფლობითი ტოკენების ტიპებს. როლებისა და ნებართვების კონცეფციული სახელმძღვანელოსთვის იხილეთ [ ნებართვები](/ka/blockchain/permissions.md).

ნებართვის შემოწმებას ახორციელებს აქტიური runtime-ის ვალიდატორი. ქვემოთ მოცემული ტოქნის ტიპის სახელები აღწერს სტანდარტულ პოლიტიკურ ზედაპირს, მაგრამ ქსელს შეუძლია განახორციელოს runtime- ის ვალიდატირება აღმასრულებლის განახლებით.

## საკუთრება {#ownership}

მფლობელის მგრძნობიარე ნებართვის ტოკენები უნდა მიუთითონ კანონიკურ ობიექტს IDs, რომელიც გამოიყენება მიმდინარე მონაცემთა მოდელში. მაგალითად, ანგარიშის ნებართვები მიუთითებს კანონიკულ დომენის გარეშე ანგარიში IDs, დომენის ნებართვები ეხება `domain.dataspace` დომენს IDs და აქტივების ნებართვა ეხება კანონიკური აქტივის განსაზღვრა ან აქტივი IDs.

როდესაც ტრანზაქცია არ ხდება ავტორიზაციის შეცდომით, შეამოწმეთ ორივე მხარე:

- გარიგების ხელმოწერის ანგარიში არის მოსალოდნელი კანონიკური ანგარიში
- ინსტრუქციაში გამოყენებული ზუსტი ობიექტისთვის ID ნებართვის ტოკი ან როლი გაიცა.
