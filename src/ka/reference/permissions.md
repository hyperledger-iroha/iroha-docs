# ნებართვის ტოქნები {#permission-tokens}

ამ გვერდზე მოცემულია განსაზღვრული ნებართვის ნიშნის ტიპები, რომლებიც განთავსებულია მიმდინარე
Iroha აღმასრულებელი მონაცემთა მოდელი. როლებისა და ნებართვების კონცეფციული სახელმძღვანელოსთვის,
იხილეთ [ნებართვები](/ka/blockchain/permissions.md).

ნებართვის შემოწმება ახორციელებს აქტიური runtime validator.
ქვემოთ მოცემული სახელები აღწერენ სტანდარტული პოლიტიკის ზედაპირს, მაგრამ ქსელს შეუძლია მორგებული
გაშვების დროის ვალიდირება აღმასრულებლის განახლების გზით.

## მფლობელობა {#ownership}

მფლობელზე მგრძნობიარე ნებართვის ნიშნები უნდა მიუთითონ კანონიკურ ობიექტს IDs გამოყენებული
ამჟამინდელი მონაცემთა მოდელის მიხედვით. მაგალითად, ანგარიშის ნებართვები ეხება კანონიკურ
დომენის გარეშე ანგარიში IDs, დომენის ნებართვები ეხება `domain.dataspace` დომენი
IDs, და აქტივების ნებართვა ეხება კანონიკური აქტივის განსაზღვრას ან აქტივს IDs.

როდესაც ტრანზაქცია არ ხდება ავტორიზაციის შეცდომით, შეამოწმეთ ორივე მხარე:

- ტრანზაქციის ხელმოწერის ანგარიში არის მოსალოდნელი კანონიკური ანგარიში
- ნებართვის ტოკი ან როლი ზუსტ ობიექტისთვის იყო მინიჭებული ID გამოიყენება
  ინსტრუქცია
