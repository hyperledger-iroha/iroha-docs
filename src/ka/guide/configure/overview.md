# კონფიგურაცია და მართვა {#configuration-and-management}

Iroha კონფიგურაციას აქვს ორი ავტორიტეტული ფენა:

- ადგილობრივი პარტნიორი და კლიენტის კონფიგურაცია, შენახული TOML ფაილებში და წაიკითხულია პროცესის დაწყებისას.
- ქსელზე არსებული კონფიგურაცია, რომელიც შეიცვალა [`SetParameter`](/ka/blockchain/instructions.md#setparameter) საშუალებით განხორციელებული ოპერაციების შედეგად.

გამოიყენეთ ადგილობრივი კონფიგურაცია კვანძის იდენტობის, მისამართების, ჩანაწერის, შენახვისა და კლიენტის ხელმოწერის გასაღებისთვის. გამოიყენეთ ქსელზე არსებული კონფიგურიაცია იმ ღირებულებებისათვის, რომლებიც უნდა იყოს შეთანხმებული ქსელის მიერ და განსაზღვრული გზით გათამაშებული.

წარმოების ქცევა უნდა მოვიდეს ამ კონფიგურაციის ფენებიდან. გარემოს ცვლადი შეიძლება იყოს მოსახერხებელი ადგილობრივი ინსტრუმენტებისთვის ტესტის შემოტანის მიწოდებისთვის, მაგრამ ისინი არ არიან წარმოების მახასიათებლების კარიბჭეები და არ შეცვლიან ვალდებულ კონფიგურააციას.
