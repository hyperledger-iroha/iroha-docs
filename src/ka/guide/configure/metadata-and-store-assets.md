# მეტამონაცემები და ბლოკჩეინების რეესტრი შენახვის არჩევანი {#metadata-and-ledger-storage-choices}

Iroha 3 მონაცემთა მოდელს არ აქვს ცალკე `Store` აქტივის ტიპი კვანძური მნიშვნელობის მონაცემებისთვის. გამოიყენეთ შემდეგი შენახვის არჩევანი.

## მეტამონაცემები {#metadata}

გამოიყენეთ [მეტამონაცემები](/ka/blockchain/metadata.md) პატარა JSON ველებისთვის, რომლებიც ეკუთვნებიან ბლოკჩეინის რეესტრის ობიექტს:

- დასახელება და ეტიკეტები
- ინტეგრაციის ID-ები
- მცირე პოლიტიკური დროშები
- კრიპტოგრაფიული ჰეშები, URIs, CIDs ან SoraFS გზები, რომლებიც მიუთითებენ უფრო დიდ დატვირთვებზე

მეტამონაცემები არის მსოფლიო მდგომარეობის ნაწილი და დაბრუნდება ობიექტთან ერთად, რომელიც მას ფლობს. შეინახეთ გასაღები სტაბილური, ღირებულებები კომპაქტური და ნებართვები მკაფიო. არ ინახოთ დიდი დოკუმენტები, ლოგები ან მაღალი ჩერნის აპლიკაციის მდგომარეობა პირდაპირ მეტადი მონაცემებში.

## ციფრული აქტივები და NFTs {#numeric-assets-and-nfts}

გამოიყენეთ [აქტივები](/ka/blockchain/assets.md) და [NFTs](/ka/blockchain/nfts.md) იმ შემთხვევაში, თუ მდგომარეობა არის ღირებულების მქონე:

- ფუნქციონირებადი სალანდების რიცხვობრივი აქტივები
- NFTs უნიკალურ საკუთრებაში არსებული ჩანაწერებისთვის
- [RWAs](/ka/blockchain/rwas.md) და სხვა დომენის სპეციფიკური ობიექტები, როდესაც აქტიური მონაცემების მოდელი მათ ასახავს

აქტივებსა და NFTs აქვს საკუთარი ID, სიცოცხლის ციკლის მოვლენები, ტრანსფერის ქცევა და ნებართვის შემოწმება. ისინი უკეთესია მეტადატებზე, როდესაც საკუთრება, დეფიციტი ან ტრანსფერების ისტორია მნიშვნელოვანია.

## გარეთ ქსელის მონაცემები {#off-chain-data}

გამოყენება ქსელის გარეთ შენახვა დიდი ან ცვალებადი დატვირთვები. შეინახეთ მხოლოდ სტაბილური რეფერენციის ქსელში, როგორიცაა:

- შინაარსის კრიპტოგრაფიული ჰეში
- a URI
- SoraFS გზა ან ტექნიკური მანიფესტის მითითება
- კომპაქტური კრიპტოგრაფიული ვალდებულების ღირებულება, რომელიც გამოყენებულია განაცხადის დასამტკიცებლად

ამით WSV მცირდება, ამასთანავე საშუალებას აძლევს აპლიკაციებს დაადასტურონ, რომ ჯაჭვის გარეშე დატვირთვა შეესაბამება ჯაჭვზე არსებულ რეფერენციას.

## ადგილის არჩევა {#choosing-a-location}

გამოიყენეთ ეს წესი:

- თუ ეს არის კომპაქტური ატრიბუტი ბლოკჩეინ ლიდერის ობიექტში, გამოიყენეთ მეტამონაცემები.
- თუ ეს არის ღირებულების მქონე ან გადასატანი, მოდელირებული უნდა იყოს როგორც აქტივი, NFT, ან დომენის სპეციფიკური ობიექტი.
- იმ შემთხვევაში, თუ ეს არის დიდი, მაღალი მოცულობის ან აპლიკაციის პირადი, შეინახეთ იგი WSV გარეთ და დააყენეთ შემოწმებადი რეფერენცია ჯაჭვზე.

მეტამონაცემთა ნებართვისთვის იხილეთ [ნებართვის ტოკენები](/ka/reference/permissions.md).
