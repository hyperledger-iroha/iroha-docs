# სახელმძღვანელო {#guide}

გამოიყენეთ ეს განყოფილება, როდესაც აშენებთ, ოპერირებთ ან ინტეგრირებთ Iroha. დაიწყეთ პირველი კლიენტისათვის SDK სახელმძღვანელოებით, შემდეგ გადადით საუკეთესო პრაქტიკასა და ოპერატორის რეფერენციებზე, სანამ გაზიარებული ქსელის წინააღმდეგ ამოქმედდებით.

## რეკომენდებული გზა {#recommended-path}

1. [დამონტაჟება Iroha 3](/ka/get-started/install-iroha.md) და [დაიწყოს ადგილობრივი ქსელი](/ka/get-started/launch-iroha.md).
2. შეარჩიეთ [SDK მასწავლებელი](/ka/guide/tutorials/) და წარადგინეთ მცირე ოპერაცია.
3. განხილვა [აპლიკაციის შემუშავება](/ka/guide/best-practices/application-development.md) და [მონაცემთა მოდელირება](/ka/guide/best-practices/data-modeling.md) განაცხადის შედგენამდე API.
4. გამოიყენეთ [ქსელის განთავსება](/ka/guide/best-practices/network-deployment.md), [ოპერაციები](/ka/guide/best-practices/operations.md) და [უსაფრთხოება და ხელმისაწვდომობა](/ka/guide/best-practices/security-and-access.md) გაზიარებული ან წარმოების ქსელის განხორციელებამდე.
5. შეასრულეთ [მზადყოფნა გათავისუფლებისთვის](/ka/guide/best-practices/release-readiness.md) ადგილობრივი განვითარებიდან Taira, Minamoto ან სხვა პირდაპირი განთავსებისკენ გაწევრიანებისას.
