# სახელმძღვანელო {#guide}

გამოიყენეთ ეს განყოფილება, როდესაც აშენებთ, ოპერირებთ ან ინტეგრირებთ Iroha. დაიწყეთ პირველი კლიენტისათვის SDK სახელმძღვანელოებით, შემდეგ გადადით საუკეთესო პრაქტიკასა და ოპერატორის რეფერენციებზე, სანამ გაზიარებული ქსელის წინააღმდეგ ამოქმედდებით.

## რეკომენდებული გზა {#recommended-path}

1. [დააინსტალირეთ Iroha 3](/ka/get-started/install-iroha.md) და [გაუშვით ადგილობრივი ქსელი ](/ka/get-started/launch-iroha.md).
2. აირჩიეთ [SDK სახელმძღვანელო](/ka/guide/tutorials/) და წარადგინეთ მცირე ტრანზაქცია.
3. მიმოხილვა [აპლიკაციის განვითარება](/ka/guide/best-practices/application-development.md) და [ მონაცემთა მოდელირება](/ka/guide/best-practices/data-modeling.md) განაცხადის ჩამოყალიბებამდე API.
4. გამოიყენეთ [ ქსელის განთავსება](/ka/guide/best-practices/network-deployment.md), [ოპერაციები](/ka/guide/best-practices/operations.md) და [უსაფრთხოება და წვდომა](/ka/guide/best-practices/security-and-access.md) გაზიარებული ან საწარმოო ქსელის წარმართვის წინ.
5. მიჰყევით [Release Readiness](/ka/guide/best-practices/release-readiness.md) ადგილობრივი განვითარებიდან Taira, Minamoto ან სხვა პირდაპირი განთავსებისკენ.
