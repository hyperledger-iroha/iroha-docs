# ნიმუშები და რეცეპტები {#samples-and-recipes}

სააგენტო Iroha წყარო რეპოზიტორი შეიცავს SDK რეცეპტები და ტესტის სუიტები, რომლებიც თვალყურს ადევნებენ
იგივე რევიზია, რაც კვანძში.

## JavaScript რეცეპტები {#javascript-recipes}

[`javascript/iroha_js/recipes`](https://github.com/hyperledger-iroha/iroha/tree/main/javascript/iroha_js/recipes)
შეიცავს დეტერმინისტური ტრანზაქციების პარტინინგის ორიენტირებულ მაგალითებს, Nexus აპლიკაცია
გადარიცხვები, NFT და ანგარიშის განმეორება, ISO ხიდის ნაკადები და Torii ჟრანთვ.
თითოეული რეცეპტი დოკუმენტებს, თუ ის მუშაობს offline ან საჭიროებს ცოცხალი Torii საბოლოო წერტილი.

## Swift და iOS {#swift-and-ios}

გამოყენება `IrohaSwift/Tests/IrohaSwiftTests` დინამიკების შედარებით დადასტურებული მაგალითებისთვის
Swift SDK. იხილეთ [Swift და iOS](/ka/guide/tutorials/swift.md) პაკეტისა და ხიდისათვის
ოპვკრაჲ.

## Android {#android}

ახალი Android მუშაობა, გამოიყენეთ Kotlin- პირველი. `core-jvm`, `client-android`, და
`offline-wallet-android` მოდულები, რომლებიც აღწერილია:
[Kotlin, Android, და Java](/ka/guide/tutorials/kotlin-java.md). სააგენტო Kotlin SDK არის
კანონიკური საწყისი წერტილი Android მომხმარებელთა.
