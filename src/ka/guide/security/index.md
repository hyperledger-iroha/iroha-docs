# უსაფრთხოება {#security}

დაიცავით Iroha განთავსება ისევე, როგორც ნებისმიერი სისტემა, რომელიც მენეჯირებს მგრძნობიარე მონაცემებსა და ღირებულებებს. დაიცავით ხელმოწერის გასაღები, ქსელის წვდომა, კვანძების ოპერაციები, მონიტორინგი და ინციდენტების რეაგირება. ბლოკჩეინის რეესტრი არ აცილებს ამ კონტროლების საჭიროებას.

### ნავიგაცია {#navigation}

ამ განყოფილებაში შეგიძლიათ გაეცნოთ თქვენი Iroha ქსელის უსაფრთხოების სხვადასხვა ასპექტებს. მეტი ინფორმაციის მისაღებად, აირჩიეთ ერთ-ერთი შემდეგი თემა:

- [უსაფრთხოების პრინციპები](./security-principles):

მონაცემთა დაცვისა და დარღვევის რისკის შემცირების ძირითადი პრინციპები.

- [ვირტუალური კერძო ქსელები](./vpn.md):

როგორ გამოიყენოს VPN, რათა შეზღუდული იყოს პიერ-ტუ-პიერი, Torii, და ოპერატორის წვდომა კერძო ან კონსორციუმის განთავსებისას.

- [ოპერაციული უსაფრთხოება](./operational-security.md):

ყოველდღიური კონტროლი წვდომის, მონიტორინგის, ინციდენტების რეაგირების და ოპერატორის სამუშაო სადგურებისათვის.

- [თაღლითობის მონიტორინგი](./fraud-monitoring.md):

როგორ გამოვიყენოთ ბლოკჩეინის რეესტრი- ის მოვლენები, შეკითხვები, ნებართვები და ოპერაციული სიგნალები საეჭვო აქტივობის გამოვლენის და რეაგირების მტკიცებულებების შესანარჩუნებლად.

- [პაროლის დაცვა](./password-security.md):

პაროლი ენტროპია, ძლიერი პაროლის კონსტრუქცია და საერთო ჩავარდნის რეჟიმები.

- [საჯარო გასაღები კრიპტოგრაფია](./public-key-cryptography.md):

საჯარო გასაღები, ხელმოწერები და ავთენტური კომუნიკაცია.

  - [კრიპტოგრაფიული გასაღების გენერაცია](./generating-cryptographic-keys.md):

გენერირება მხარდაჭერილი კრიპტოგრაფიული გასაღები `kagami`.

  - [კრიპტოგრაფიული გასაღების შენახვა](./storing-cryptographic-keys.md):

კრიპტოგრაფიული გასაღები ინახება განთავსებისათვის შესაფერისი ფენაზე კონტროლის გამოყენებით.
