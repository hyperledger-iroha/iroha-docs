# უსაფრთხოება {#security}

გამოყენებისას Iroha ფინანსური ორგანიზაციებისთვის უსაფრთხოება უპირატესობაა, რადგან ის წარმოადგენს ნდობის საფუძველს იმ ინდუსტრიაში, სადაც მგრძნობიარე ფინანსური მონაცემები და ტრანზაქციები რუტინულია. მავნე მხარის მიერ უსაფრთხოების წარმატებული დარღვევა შეიძლება გამოიწვიოს კატასტროფული შედეგები თქვენთვის. შესაბამისად, თქვენი მგრძნობრივი მონაცემების მთლიანობისა და კონფიდენციალურობის დასაცავად აუცილებელია პრევენციული უსაფრთხოების ღონისძიებების მიღება.

### ნავიგაცია {#navigation}

ამ განყოფილებაში თქვენ შეგიძლიათ გაეცნოთ სხვადასხვა ასპექტებს თქვენი Iroha მეტი ინფორმაციის მისაღებად, აირჩიეთ ერთ-ერთი შემდეგი თემა:

- [უსაფრთხოების პრინციპები](./security-principles):

  უსაფრთხოების ძირითადი პრინციპები, რომელთა მიღებაც შეიძლება ინდივიდებსა და ორგანიზაციებს თავიანთი მონაცემების დასაცავად და გაჟონვის ან/და დარღვევის ალბათობის შესამცირებლად.

- [ვირტუალური კერძო ქსელები](./vpn.md):

  როგორ გამოიყენოთ VPN შეზღუდვა თანატოლთა შორის, Torii, და ოპერატორების წვდომა კერძო ან კონსორციუმის განთავსებაში.

- [ოპერაციული უსაფრთხოება](./operational-security.md):

  საუკეთესო პრაქტიკა თქვენი ქსელის ყოველდღიური ოპერაციების უზრუნველსაყოფად, მათ შორის წვდომის კონტროლი, მონიტორინგი, ინციდენტების რეაგირება, ბრაუზერის გამოყენება და ა.შ.

- [თაღლითობის მონიტორინგი](./fraud-monitoring.md):

  როგორ გამოვიყენოთ წიგნის მოვლენები, კითხვები, ნებართვები და ოპერაციული სიგნალები საეჭვო აქტივობის გამოვლენის და რეაგირების მტკიცებულებების შესანარჩუნებლად.

- [პაროლის დაცვა](./password-security.md):

  ღრმა ჩივილება პაროლის ენტროპიაში, ძლიერი პაროლების შექმნა და პაროლის დაუცველობის თავიდან აცილება.

- [საჯარო გასაღები კრიპტოგრაფია](./public-key-cryptography.md):

  საჯარო გასაღების კრიპტოგრაფიის, დაშიფვრის, ხელმოწერებისა და მათი როლის შესწავლა უსაფრთხო კომუნიკაციის დამყარებაში ბლოკჩეინში.

  - [კრიპტოგრაფიული გასაღები](./generating-cryptographic-keys.md):

    ინსტრუქციები კრიპტოგრაფიული გასაღების გენერირებისა და გამოყენების შესახებ `kagami` (დამახასიათებელი ინსტრუმენტი, რომელიც გადმოჰყავთ Iroha).

  - [კრიპტოგრაფიული გასაღების შენახვა](./storing-cryptographic-keys.md):

    საუკეთესო პრაქტიკა თქვენი კრიპტოგრაფიული გასაღების უსაფრთხოებისთვის სხვადასხვა მეთოდებით, რომლებიც ასევე შეიძლება გაერთიანდეს.
