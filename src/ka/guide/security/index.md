# უსაფრთხოება {#security}

ფინანსური ორგანიზაციებისათვის უსაფრთხოება უმნიშვნელოვანესია Iroha ან ნებისმიერი სხვა ბლოკჩეინ ლიდერის გამოყენებისას, რადგან იგი წარმოადგენს ნდობის საფუძველს იმ ინდუსტრიაში, სადაც მგრძნობიარე ფინანსური მონაცემები და ტრანზაქციები რუტინულია. მავნებლური მხარის მიერ უსაფრთხოების დარღვევის წარმატებით განხორციელებამ შეიძლება გამოიწვიოს დამღუპველი შედეგები თქვენთვის. შესაბამისად, აუცილებელია პრევენციული უსაფრთხოების ღონისძიებების დადგენა თქვენი სენსიტიური მონაცემების მთლიანობისა და კონფიდენციალურობის დასაცავად.

### ნავიგაცია {#navigation}

ამ განყოფილებაში შეგიძლიათ გაეცნოთ თქვენი Iroha ქსელის უსაფრთხოების სხვადასხვა ასპექტებს. მეტი ინფორმაციის მისაღებად, აირჩიეთ ერთ-ერთი შემდეგი თემა:

- [უსაფრთხოების პრინციპები](./security-principles):

უსაფრთხოების ძირითადი პრინციპები, რომლებსაც ფიზიკური პირები და ორგანიზაციები შეუძლიათ მიიღონ მათი მონაცემების დასაცავად და გაჟონვის ან/და დარღვევის ალბათობის შესამცირებლად.

- [ვირტუალური კერძო ქსელები](./vpn.md):

როგორ გამოიყენოს VPN, რათა შეზღუდული იყოს პიერ-ტუ-პიერი, Torii, და ოპერატორის წვდომა კერძო ან კონსორციუმის განთავსებისას.

- [საოპერაციო უსაფრთხოება](./operational-security.md):

საუკეთესო პრაქტიკა თქვენი ქსელის ყოველდღიური მუშაობის უზრუნველსაყოფად, მათ შორის წვდომის კონტროლი, მონიტორინგი, ინციდენტების რეაგირება, ბრაუზერების გამოყენება და ა.შ.

- [თაღლითობის მონიტორინგი](./fraud-monitoring.md):

როგორ გამოიყენოთ წიგნის მოვლენები, გამოკითხვები, ნებართვები და ოპერაციული სიგნალები საეჭვო აქტივობის გამოვლენის და რეაგირების მტკიცებულებების შესანახად.

- [პაროლი უსაფრთხოება](./password-security.md):

ღრმა ჩაძირვა პაროლების ენტროპიაში, ძლიერი პაროლების შექმნა და პაროლის დაუცველობის თავიდან აცილება.

- [საჯარო გასაღების კრიპტოგრაფია](./public-key-cryptography.md):

საჯარო საკვანძოების კრიპტოგრაფიის, დაშიფვრის, ხელმოწერებისა და მათი როლის შესწავლა უსაფრთხო კომუნიკაციის დამყარებაში ბლოკჩეინში.

  - [კრიპტოგრაფიული გასაღები](./generating-cryptographic-keys.md):

ინსტრუქციები კრიპტოგრაფიული გასაღებების გენერირებისა და გამოყენების შესახებ `kagami` (დამახასიათებელი ინსტრუმენტი, რომელიც გადაგზავნილია Iroha-ის გვერდით).

  - [კრიპტოგრაფიული გასაღების შენახვა](./storing-cryptographic-keys.md):

საუკეთესო პრაქტიკა თქვენი კრიპტოვალუტის გასაღების უსაფრთხოებისთვის სხვადასხვა მეთოდებით, რომლებიც ასევე შეიძლება გაერთიანდეს.
