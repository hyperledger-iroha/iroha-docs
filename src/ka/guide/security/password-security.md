# პაროლის დაცვა {#password-security}

ბლოკჩეინის უსაფრთხოების სფეროში პაროლების დაცვა უმნიშვნელოვანესია. იმისათვის, რომ თქვენი მონაცემები და ყველაფერი, რასაც ისინი წარმოადგენენ, დარჩეს უნებართვო წვდომისგან დაცული, მოდით გავიგოთ პაროლების უსაფრთხოების ნიუანსები.

## პაროლის სიმტკიცე {#password-strength}

სავარაუდოდ, თქვენ ადრეც შეგხვდით რეკომენდაციებს იმის შესახებ, თუ როგორ უნდა შეიქმნას ძლიერი პაროლი. ეს შეიძლება გულისხმობდეს ისეთ რჩევებს, როგორიცაა მინიმალური პაროლის ხანგრძლივობა, სპეციალური ასოების დამატება და ა.შ. ასეთი რეკომენდაციები მიზნად ისახავს თქვენი პაროლის სიმტკიცის გაზრდას, რომელიც დამოკიდებულია ენტროპიაზე, ანუ: პაროლის შემთხვევითობა.

რა განსაზღვრავს ძლიერი პაროლი? ძლიერი პაროლი არის პაროლი მაღალი ენტროპით.

პაროლის ენტროპიის გაანგარიშების მიზნით, შეგვიძლია მივყვეთ ენტროპის ფორმულას:

::: tip ენტროპის ფორმულა

$L$  პაროლის სიგრძე; პაროლში არსებული სიმბოლოების რაოდენობა.\ $S$  ხასიათის ნაკრები; უნიკალური შესაძლო სიმბოლოთა აუზის ზომა.\ $S^L$  შესაძლო კომბინაციების რაოდენობა .

$$Entropy=log_2(S^L)$$

რაც უფრო მაღალია, მით უფრო რთულია პაროლის გატეხა.

ენტროპიის მნიშვნელობის ცოდნისას, საჭირო მცდელობების რაოდენობა ამ ენტროპით პაროლის მოსაწესრიგებლად შეიძლება გამოიყოს შემდეგი ფორმულის გამოყენებით:

$$S^L=2^Entropy$$

არ არსებობს უნივერსალური პასუხი იმის შესახებ, თუ რამდენად მაღალი უნდა იყოს პაროლის ენტროპია. ფინანსური ორგანიზაციებისთვის მიზანშეწონილია მათი პაროლების ენტროპიის შენარჩუნება დიაპაზონში `64`-დან `127` ბიტამდე (`128` ბიტები ან მეტი, როგორც წესი, გადაჭარბებულად ითვლება). ამასთან, გახსოვდეთ, რომ <abbr title="Graphics Processing Unit">GPU</abbr>-ები მუდმივად ვითარდება და პაროლების გატეხვისთვის საჭირო დრო მცირდება დროთა განმავლობაში.

:::

ენტროპიის ფორმულის შემდეგ, შეადაროთ შემდეგი ორი მაგალითი:

  1. 16 ხასიათის პაროლი, რომელშიც გამოიყენება მხოლოდ თანამედროვე ინგლისური ანბანის მცირე ასოები (26 ხასიათი), დაახლოებით 43 სექსტილიონი ($43*10^21$) შესაძლო კომბინაციას იძლევა.

$$Entropy=log_2(26^{16})=log_2(43,608,742,899,428,874,059,776)=75.20703...$$

  2. 16 პერსონაჟის პაროლი, რომლის პერსონაჟი 96-მდე არის გაფართოებული, მათ შორის დიდი ასოები და სპეციალური სიმბოლოები, შესაძლო კომბინაციების რაოდენობას 52 არამილიონამდე ($52*10^30$) ამაღლებს, რაც მნიშვნელოვნად აუმჯობესებს ენტროპიას.

$$Entropy=log_2(96^{16})=log_2(52,040,292,466,647,269,602,037,015,248,896)=105.35940... $$

როგორც ჩანს, თუნდაც მხოლოდ 26 სიმბოლოდან 96 სიმბოლოზე გაფართოების გზით შესაძლო კომბინაციების რაოდენობა გაიზარდა $1.1933*10^9$ ჯერობით.

გარდა ამისა, პაროლის სიგრძის გაზრდა კიდევ უფრო გაზრდის შესაძლო კომბინაციების რაოდენობას და ამით გააძლიერებს პაროლის ენტროპიურ ძალას.

თუმცა, რთულობებთან ბრძოლის ნაცვლად, გირჩევთ გამოიყენოთ პაროლი მენეჯერის პროგრამაროგორც [KeePassXC](https://keepassxc.org/) (დამატებითი დეტალებისთვის იხილეთ [ პაროლის მენეჯერის პროგრამის დამატება ](./storing-cryptographic-keys.md#adding-a-password-manager-program) და [ კონფიგურაცია KeePassXC](./storing-cryptographic-keys.md#configuring-keepassxc))  თქვენი პაროლების წარმოქმნისა და უსაფრთხო შენახვისთვის.

::: სათქმელი

ზოგიერთი ვებგვერდი ზღუდავს პაროლების მაქსიმალურ შესაძლო ენტროპიას, ანუ შეზღუდავს პაროლის მაქსიმალური სიგრძეს ან მიღებული სიმბოლოების კომპლექტს, ან ორივე.

გაითვალისწინეთ ეს, როდესაც იყენებთ ამ ვებგვერდებს და მიზნად ისახავთ პერიოდულად განახლოთ თქვენი პაროლები.

:::

## პაროლის დაუცველობა {#password-vulnerabilities}

პაროლები შეიძლება დაეცემა მსხვერპლი brute-force თავდასხმები, ჩვეულებრივ შესრულებული გამოყენებით ძლიერი GPUs ერთად ლექსიკონების ან ამოწურავი iteration ყველა შესაძლებლობების. ამგვარი მცდელობების დასაძლევად, შექმენით უნიკალური პაროლი, რომელშიც არ არის მითითებული პირადი ინფორმაცია, როგორიცაა დაბადების დღეები, მისამართები, ტელეფონის ნომრები ან სოციალური დაცვის ნომრები.

მაშ, რამდენად რთულია თანამედროვე პაროლის ამოღება? ეს დამოკიდებულია იმაზე, თუ ვის ეკითხებით.

ეთანხმებით, [კევინ მიტნიკი](https://en.wikipedia.org/wiki/Kevin_Mitnick)აჟიოტაჟი [კლასტერის დაყენება](https://twitter.com/kevinmitnick/status/1649421434899275778?s=20) ბინები 24 NVIDIA® GeForce RTX 4090-იანი წლები და 6 NVIDIA® GeForce RTX 2080-იანი წლები, ყველა მათგანი რბის. [ჰაშტოპოლისი](https://github.com/hashtopolis) პროგრამული უზრუნველყოფა. ის იყენებდა პაროლებს, რომლებმაც მხოლოდ ნახევარ თვეში ერთი წელი დასჭირდათ.

თუმცა, ახლა შევადაროთ იგი ერთი RTX 4090, რომელსაც შეუძლია გადამუშავება 300 <abbr title="Hashes per second">H/s</abbr> გამოყენებით [`NTLM`](https://www.tarlogic.com/cybersecurity-glossary/ntlm-hash) და 200 <abbr title="Hashes per second">H/s </abbr> გამოყენებით [`bcrypt`](https://en.wikipedia.org/wiki/Bcrypt), როგორც აღწერილია [ ამ ტვიტში ](https://twitter.com/Chick3nman512/status/1580712040179826688).

ჩვენი წინა ენტროპული გამოთვლების გაგრძელების სახით, ახლა განვიხილოთ შემდეგი პროგნოზირებული დაშლის დროები:

  1. არსებობს $31,540,000$ წამები რეგულარულ არაკომპეტენტურ წელს. ვარაუდობთ, რომ ყველაზე ცუდი სცენარი არის `NTLM`, სიჩქარეზე $300*10^9$ <abbr title="Hashes per second">H/s</abbr> ერთ RTX 4090 წელიწადს დასჭირდება, დაახლოებით, $4,608.83$ 16 ხასიათის პაროლის გასაღებად თანამედროვე ინგლისური ანბანის 26 ასოების ქაღალდის ნაკრებით.

  2. თუ ამის მაგივრად `NTLM` ჩვენ ვიყენებთ `bcrypt`, აქედან გამომდინარე, იტერაციის სიჩქარის შემცირება $200*10^3$ <abbr title="Hashes per second">H/s</abbr>, ხოლო ასევე გაფართოების პერსონაჟი შედგენილი 96, მათ შორის დიდი ასოები და სპეციალური სიმბოლოები, დრო crack აღწევს დაახლოებით $8,249,887,835,549,662,270.456$ წლების განმავლობაში, რომელიც სამყაროს ასაკს ბევრად აღემატება.

ასე რომ, მხოლოდ უფრო მაღალი ენტროპის შეძენის შედეგად გაიზარდა პაროლის ამოღების დრო გაურკვეველი რიცხვებით. დიახ, პროცესი შეიძლება დაჩქარდეს მრავალჯერადი GPUs გამოყენებით, თუმცა ეს მეთოდი ბნელდება [XKCD მიდგომასთან შედარებით](https://xkcd.com/538/).

მნიშვნელოვანია აღინიშნოს, რომ ფართო პერსონაჟების ნაკრები ყოველთვის არ არის აუცილებელი მაღალი ენტროპის მისაღწევად. ეს შეიძლება მიღებული იყოს მრავალსიტყვითი პაროლების ან ხანგრძლივი წინადადებების გამოყენებით. კლასიკური [XKCD კომიქსი](https://xkcd.com/936/) ამ კონცეფციას ელეკვატურად ილუსტრირებს.

::: გაფრთხილება

თავიდან აიცილეთ პაროლის წერა ნებისმიერ ადგილას. შეინახეთ თქვენი პაროლის აღდგენის ფრაზა უსაფრთხოდ. თუ ფრაზა ძალიან გრძელია, შეგიძლიათ დაწეროთ იგი, რათა დარწმუნდეთ, რომ შეგიძლიათ წაიკითხოთ იგი და დააწეროთ ის მოგვიანებით. ინახეთ ფრაზის ფიზიკური ასლი უსაფრთხო ადგილზე და / ან კონტეინერში.

:::
