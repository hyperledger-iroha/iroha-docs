# პაროლის დაცვა {#password-security}

პაროლი შეიძლება დაიცვას ოპერატორის კონსოლები, საიდუმლო მაღაზიები, ბეკაპები და ადგილობრივი საკვანძო ფაილები. პაროლი არის მხოლოდ ერთი კონტროლი. გამოიყენეთ იგი უსაფრთხო გასაღების შენახვის, წვდომის კონტროლისა და მრავალფაქტორული ავთენტიფიკაციის ერთად, როდესაც ხელმისაწვდომია.

## გამოიყენეთ უნიკალური, შექმნილი პაროლი {#use-unique-generated-passwords}

- გენერირეთ სხვადასხვა პაროლი თითოეული ანგარიშისა და გარემოსთვის.
- გამოიყენეთ პაროლი მენეჯერი, რომ შექმნათ და შეინახოთ გრძელი შემთხვევითი პაროლები.
- გამოიყენეთ მრავალსიტყვითი პაროლი მხოლოდ მაშინ, როდესაც მისი სიტყვები საკმაოდ დიდი სიიდან შემთხვევითია შერჩეული.
- შეინახეთ პაროლების სახელები, თარიღები, მისამართები, ციტირებები, კლავიატურის მოდელები და განმეორებითი გამოყენებული ფრაგმენტები.
- გამოიყენეთ სერვისის მიერ შექმნილი ტოქენი ან კრიპტოგრაფიული გასაღები ადამიანის მიერ შეყვანილი პაროლის ნაცვლად, როდესაც სერვისი ამ მეთოდს მხარს უჭერს.

ხანგრძლივობა და გაუთვალისწინებლობა უფრო მნიშვნელოვანია, ვიდრე დეკორატიული შემცვლელები. ერთი სიმბოლოს დამატება წინასწარმეტყველებადი სიტყვისთვის შედეგს უსაფრთხო არ გახდის.

## დაიცავით პაროლით დაფუძნებული ანგარიშები {#protect-password-based-accounts}

- შესაძლებლობა გაეცეს ფისინგის წინააღმდეგობის მქონე მრავალფაქტორული ავთენტიფიკაცია, სადაც ეს ხელმისაწვდომია.
- შეამოქმედეთ საფასურის ლიმიტები, ჩაკეტვის პოლიტიკა და გაფრთხილებები ავთენტიფიკაციის განმეორებითი წარუმატებლობისთვის.
- გადმოაგზავნეთ პაროლები მხოლოდ ავთენტიფიცირებული და კოდირებული არხებით.
- შეინახეთ პაროლები და აღდგენის კოდები დღიურებში, ბრძანების ხაზებში, წყარო რეპოზიტორებში, კონფიგურაციის ფაილებში, ბილეთებსა და ჩატში.
- შეინახეთ სერვერის მხრიდან პაროლების ვერიფიკატორები მარილიანი, მეხსიერების გამყარების ფუნქციით და განთავსებისთვის შესაფერისი პარამეტრებით.

## შენახვა, აღდგენა და შეცვლა {#storage-recovery-and-replacement}

- გამოიყენეთ აუდიტირებული პაროლი მენეჯერი დაშიფრული, ტესტირებული სარეზერვო მონაცემებით.
- შეინახეთ აღდგენის კოდები მათ მიერ აღდგენილ მოწყობილობასგან ცალკე. აღდგენის მასალისათვის შეიძლება იყოს შესაბამისი დაცული ოფლაინ ქაღალდის ასლი.
- შეზღუდული წვდომა პაროლი მენეჯერის ექსპორტზე და სათადარიგო მედიაზე.
- შეცვალეთ პაროლი ეჭვმიტანილი გამოხატვის, უკანონო განმეორებითი გამოყენების ან პოლიტიკის მოვლენის შემდეგ, რომელიც საჭიროებს შეცვლას.
- წარმოების დაწყებამდე ანგარიშის აღდგენის პროცედურების გამოცდა.

::: warning

პაროლი, რომელიც კერძო გასაღების გახსნას ვერ ხდის ამ გასაღების გამოფენილი ასლის საშიშროებას. თუ ეჭვი არსებობს პირადი გასაღების ექსპოზიციის შესახებ, დაიცავით განთავსებული გასაღების შეცვლის ან მოხსნის პროცედურა.

:::
