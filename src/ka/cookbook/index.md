# Iroha 3 აპლიკაციის სახელმძღვანელო {#iroha-3-application-cookbook}

შექმენით Iroha 3-ის წინააღმდეგ პატარა, შემოწმებადი რეცეპტების გამოყენებით, რომლებიც იწყება Taira სატესტო ქსელზე და ინახავს Minamoto ძირითად ქსელს მხოლოდ წაკითხვისთვის. თითოეული რეცეპტი აცხადებს, არის თუ არა ეს საჯარო წაკითხვა, ჩვეულებრივი დაფინანსებული ანგარიშის წერა ან ნებართვით გათვალისწინებული ოპერაცია. ბრძანებები იყენებენ მიმდინარე I105 ანგარიშს IDs, მკაფიო საფასურის შერჩევა და ქცევა, რომელიც შემოწმებულია Iroha კომიტეტის [`0010c5a70039eac101a4846499ba9ceaf43eb65c`](https://github.com/hyperledger-iroha/iroha/tree/0010c5a70039eac101a4846499ba9ceaf43eb65c).

დაიწყეთ [დაკავშირდით Taira](./connect-to-taira.md). იგი ქმნის კლიენტის კონფიგურაციას და საფასურის მეტა მონაცემებს, რომლებიც განმეორებით გამოიყენება ბრძანების ხაზის რეცეპტებით. არასოდეს ასახელოთ საფასურის აქტივი ID ამ დოკუმენტაციიდან: გამოიყვანეთ ის მიმდინარე Taira ნაჟავის პასუხიდან.

## წვდომის დონე {#access-levels}

- საჯარო  ხელმოწერის ან ქსელის ნებართვის საჭიროება არ არის.
- წერისათვის მზად  გამოიყენეთ დაფინანსებული Taira სატესტო ანგარიში, მკაფიო გადასახადის გადამხდელი და საბანქარის მიერ დაბრუნებული მიმდინარე გადასახადების აქტივი.
- სავალდებულო ნებართვა  Taira უნდა მიანიჭოს დასახელებული runtime ნებართვის ან მართული სახელის სივრცე. გამოიყენეთ გენერირებული ადგილობრივი ქსელი, როდესაც ეს თანხა არ არის ხელმისაწვდომი; ადგილობრივი წარმატება არ აძლევს Taira უფლებამოსილება.

არანაირი სამზარეულო წიგნის რეცეპტი არ უგზავნის წერილს Minamoto.
