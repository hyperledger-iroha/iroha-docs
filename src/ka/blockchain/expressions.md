# გამოთქმები, პირობები, ლოგიკა {#expressions-conditionals-logic}

ყველა [Iroha სპეციალური ინსტრუქციები](./instructions.md) მოქმედებენ გამოთქმებზე.
თითოეულ გამოთქმას აქვს `EvaluatesTo`, რომელიც გამოიყენება ინსტრუქციაში
თუკი შეგიძლიათ პირდაპირ დაასახელოთ ანგარიშის სახელი,
ასევე დაასახელეთ ანგარიში ID რომელიმე მათემატიკური ან მავთულხლართების ოპერაციის საშუალებით.
შეგიძლიათ შეამოწმოთ, არის თუ არა ანგარიში რეგისტრირებული ბლოკჩეინზე.

გამოყენება გამონათქვამები, რომლებიც ახორციელებს `EvaluatesTo<bool>`, შეგიძლიათ დააყენოთ
პირობითი ლოგიკა და უფრო რთული ოპერაციების შესრულება ჯაჭვზე.
მაგალითად, შეგიძლიათ წარადგინოთ `Mint` ინსტრუქცია მხოლოდ იმ შემთხვევაში, თუ კონკრეტული ანგარიში
დარეგისტრირებულია.

გახსოვდეთ, რომ თქვენ შეგიძლიათ შეადგინოთ ეს კითხვებთან ერთად და ამდენად შეძლოთ პროგრამირება
ეს არის ის, რასაც ჩვენ ვუწოდებთ _ჭკვიანი
ხელშეკრულებები_, blockchain-ის მოწინავე გამოყენების განმსაზღვრელი მახასიათებელი
ტექნოლოგია.
