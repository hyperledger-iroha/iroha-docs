# მოვლენები {#events}

მოვლენები გამოშვებულია, როდესაც გარკვეული რამ ხდება ბლოკჩეინში, მაგალითად, ახალი ანგარიში იქმნება ან ბლოკი ჩატარდება. არსებობს სხვადასხვა ტიპის მოვლენები:

- მილსადენის მოვლენები
- მონაცემთა მოვლენები
- დროის მოვლენები
- გამოშვების მოვლენები

## მილსადენის მოვლენები {#pipeline-events}

მილსადენის მოვლენები გამოშვებულია მაშინ, როდესაც ტრანზაქციები წარედგინება, შესრულდება ან ჩართულია ბლოკზე. მილსადენი მოვლენა შეიცავს შემდეგ ინფორმაციას: იმ ორგანიზაციის ტიპს, რომელმაც გამოიწვია მოვლენა (ტრანზაქცია ან ბლოკი), მის ჰაშ-ს და სტატუსს . სტატუსი შეიძლება იყოს `Validating` (გამოწმება მიმდინარეობს), `Rejected` ან `Committed`. თუ სუბიექტს უარი უთხრეს, მითითებულია უარყოფის მიზეზი.

### სცადეთ Taira {#try-it-on-taira}

შეამოწმეთ, რომ საჯარო მილსადენის მოვლენების ნაკადი დამონტაჟებულია:

```bash
curl -fsSI https://taira.sora.org/v1/events/sse \
  | sed -n '1,12p'
```

სურათისთვის, რომელიც შეგიძლიათ შეამოწმოთ ნაკადის გახსნის გარეშე, წაიკითხეთ ბოლოდროინდელი ექსპლუატაციის ტრანზაქციები:

```bash
curl -fsS 'https://taira.sora.org/v1/explorer/transactions?page=1&per_page=5' \
  | jq '{pagination, txs: [.items[] | {hash, block, status, executable}]}'
```

გახსენით SSE მარშრუტი ტერმინალში, როდესაც საჭიროებთ ცოცხალი ღონისძიებების ჩატარებას:

```bash
curl -fsS -N https://taira.sora.org/v1/events/sse
```

თუ არანაირი ტრანზაქცია არ არის წარდგენილი, სანამ ნაკადი ღიაა, ბრძანება შეიძლება დარჩეს მშვიდად მიუხედავად იმისა, რომ მარშრუტი ჯანმრთელია.

## მონაცემთა მოვლენები {#data-events}

მონაცემთა მოვლენები გამოიცემა, როდესაც ხდება ცვლილება მთავრობის მონაცემებთან დაკავშირებული, როგორიცაა თანატოლები, დომენები, ანგარიშები, აქტივები, აქტივების განსაზღვრება, NFTs, გამომწვევი ფაქტორები, როლები, ქსელზე კონფიგურაცია, განმახორციელებელი მდგომარეობა, მტკიცებულებები, კონფიდენციალური აქტივები, ხიდები ან SORA/Nexus სპეციფიკური ობიექტები. ამ ტიპის მოვლენები გამოიყენება [ მონაცემთა მოვლენის ფილტრებში ](./filters.md#data-event-filters).

## დროის მოვლენები {#time-events}

დროის მოვლენები გამოშვებულია მაშინ, როდესაც მსოფლიო მდგომარეობის ხედვა მზად არის [ დროის გამომწვევი ფაქტორების](./triggers.md#time-triggers) მართვისთვის.

## ტრიგერების განხორციელების მოვლენები {#trigger-execution-events}

ტრიგერის შესრულების მოვლენები გამოიცემა, როდესაც [`ExecuteTrigger`](./instructions.md#executetrigger) ინსტრუქცია შესრულდება. ტრიგერის დასრულების მოვლენებია გამოშვებული მას შემდეგ, რაც გაშვების მოქმედება დასრულებულია.
