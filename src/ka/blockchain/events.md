# მოვლენები {#events}

მოვლენები გამოდის, როდესაც გარკვეული რამ ხდება ბლოკჩეინში, მაგალითად
ახალი ანგარიში შეიქმნება ან ბლოკი ჩატარდება. არსებობს სხვადასხვა ტიპის
მოვლენების შესახებ:

- მილსადენის მოვლენები
- მონაცემთა მოვლენები
- დროის მოვლენები
- განახორციელების მოვლენები

## მილსადენის მოვლენები {#pipeline-events}

გაზსადენის მოვლენები გამოშვებულია, როდესაც ტრანზაქციები წარმოდგენილია, შესრულებულია ან
ჩართული ბლოკზე. მილსადენის მოვლენა შეიცავს შემდეგ ინფორმაციას:
ორგანიზაციის ტიპი, რომელმაც გამოიწვია მოვლენა (ტრანზაქცია ან ბლოკი), მისი ჰაში
და სტატუსი. სტატუსი შეიძლება იყოს `Validating` (გამოწმება მიმდინარეობს),
`Rejected`, ან `Committed`. თუ საიტი უარყოფილია,
უარყოფა არის უზრუნველყოფილი.

### სცადე. Taira {#try-it-on-taira}

შეამოწმეთ, რომ საჯარო მილსადენის მოვლენების ნაკადი დამონტაჟებულია:

```bash
curl -fsSI https://taira.sora.org/v1/events/sse \
  | sed -n '1,12p'
```

სურათისთვის, რომელიც შეგიძლიათ შეამოწმოთ არ გააჩეროთ ნაკადი ღია, წაიკითხეთ ახლო
ექსპლუატორის ოპერაციები:

```bash
curl -fsS 'https://taira.sora.org/v1/explorer/transactions?page=1&per_page=5' \
  | jq '{pagination, txs: [.items[] | {hash, block, status, executable}]}'
```

გახსნა SSE ტრანზიტი ტერმინალში, როდესაც საჭიროა პირდაპირი ღონისძიებები:

```bash
curl -fsS -N https://taira.sora.org/v1/events/sse
```

თუ არანაირი ტრანზაქცია არ არის წარმოდგენილი, სანამ ნაკადი ღიაა, ბრძანება შეიძლება დარჩეს
მშვიდი, მიუხედავად იმისა, რომ გზა ჯანსაღია.

## მონაცემთა მოვლენები {#data-events}

მონაცემთა მოვლენები გამოიცემა მაშინ, როდესაც არსებობს ცვლილება დაკავშირებული მთავრობის მონაცემებთან
როგორც თანატოლები, დომენები, ანგარიშები, აქტივები, აქტივების განსაზღვრა, NFTs, საგამოძრავებელი,
როლები, ქსელზე კონფიგურაცია, განმახორციელებელი სტატუსი, მტკიცებულებები, კონფიდენციალური აქტივები;
ხიდები ან SORA/Nexus ამ ტიპის მოვლენები გამოიყენება
[მონაცემთა მოვლენების ფილტრები](./filters.md#data-event-filters).

## დროის მოვლენები {#time-events}

დროის მოვლენები გამოიცემა მაშინ, როდესაც მსოფლიო მდგომარეობის ხედვა მზად არის მოაგვაროს
[დროის გამომწვევი](./triggers.md#time-triggers).

## ტრიგერის განხორციელების მოვლენები {#trigger-execution-events}

ტრიგერის შესრულების მოვლენები გამოდის, როდესაც
[`ExecuteTrigger`](./instructions.md#executetrigger) ინსტრუქცია არის
გამოშვების პროცესის დასრულების მოვლენები გამოიყოფა გამოშვების მოქმედების შემდეგ
დასრულდება.
