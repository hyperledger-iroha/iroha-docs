# მოვლენები {#events}

ტიპირებული მოვლენების შეტყობინებები გამოიცემა, როდესაც გარკვეული რამ ხდება ბლოკჩეინის ფარგლებში, მაგალითად, ახალი ანგარიში იქმნება ან ბლოკი დასრულდება. არსებობს სხვადასხვა სახის მოვლენები.

- დამუშავების კონვეიერის მოვლენები
- მონაცემთა მოვლენები
- დროზე დაფუძნებული ღონისძიებების შეტყობინებები
- გამოშვების მოვლენები

## დამუშავების კონვეიერები მოვლენები {#pipeline-events}

დამუშავების კონვეიერის მოვლენები გამოიცემა, როდესაც ტრანზაქციები გზავნილია, შესრულებულია ან დასრულებულია ბლოკში. პროგრამული უზრუნველყოფი პროცესის სამუშაო ნაკადის ღონისძიება შეიცავს შემდეგ ინფორმაციას: ღონისძიების (ტრანზაქციის ან ბლოკის) ტრიგერი სუბიექტის ტიპი, მისი კრიპტოგრაფიული ჰეში და სტატუსი . სტატუსი შეიძლება იყოს `Validating` (გამოწმება მიმდინარეობს), `Rejected` ან `Committed`. თუ სუბიექტს უარი უთხრეს, მითითებულია უარყოფის მიზეზი.

### განახორციელეთ ეს სამუშაო პროცესი Taira {#try-it-on-taira}

შეამოწმეთ, არის თუ არა დამონტაჟებული საჯარო დამუშავების კონვეიერის მოვლენათა ნაკადი:

```bash
curl -fsSI https://taira.sora.org/v1/events/sse \
  | sed -n '1,12p'
```

პუნქტის დროში მონაცემების ხედვისთვის, რომელიც შეგიძლიათ შეამოწმოთ ნაკადის გახსნის გარეშე, წაიკითხეთ ბოლოდროინდელი Explorer- ის ტრანზაქციები:

```bash
curl -fsS 'https://taira.sora.org/v1/explorer/transactions?page=1&per_page=5' \
  | jq '{pagination, txs: [.items[] | {hash, block, status, executable}]}'
```

გახსენით SSE მარშრუტი ტერმინალში, როდესაც საჭიროებთ ცოცხალი ღონისძიებების ჩატარებას:

```bash
curl -fsS -N https://taira.sora.org/v1/events/sse
```

თუ არანაირი ტრანზაქცია არ არის წარდგენილი, სანამ ნაკადი ღიაა, ბრძანება შეიძლება დარჩეს მშვიდად მიუხედავად იმისა, რომ მარშრუტი ჯანმრთელია.

## მონაცემთა მოვლენები {#data-events}

მონაცემთა მოვლენები გამოიცემა, როდესაც არსებობს ცვლილება დაკავშირებული ბლოკჩეინის რეესტრის მონაცემებთან, როგორიცაა ქსელის კვანძები, დომენები, ანგარიშები, აქტივები, აქტივების განსაზღვრები, NFTs, ტრიგერი ფაქტები, როლები, ქსელზე კონფიგურაცია, აღსრულების სახელმწიფო, მტკიცებულებები, კონფიდენციალური აქტივები, ხიდები ან SORA/Nexus-ის სპეციფიკური ობიექტები. ამ ტიპის მოვლენები გამოიყენება [მონაცემთა მოვლენების ფილტრები](./filters.md#data-event-filters).

## დროზე დაფუძნებული ღონისძიებების შეტყობინებები {#time-events}

დროის მოვლენები მაშინ გამოიცემა, როდესაც მსოფლიო მდგომარეობის ხედი მზადაა [დროის ტრიგერების](./triggers.md#time-triggers) დასამუშავებლად.

## ტრიგერების განხორციელების მოვლენები {#trigger-execution-events}

ტრიგერის განხორციელების მოვლენები გამოიცემა, როდესაც [`ExecuteTrigger`](./instructions.md#executetrigger) ინსტრუქცია შესრულდება. ტრიგერის დასრულების მოვლენები გამოიცემა მას შემდეგ, რაც ტრიგერი მოქმედება დასრულდა.
