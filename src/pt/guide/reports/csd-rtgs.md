# CSD/RTGS ligações Prova de conceito {#csd-rtgs-linkages-proof-of-concept}

Neste documento, descreveremos o CSD/RTGS ligações PoC execução via Iroha. Este é um projeto que foi realizado em colaboração com o asiático Banco de Desenvolvimento e Fujitsu. Outros participantes usaram tecnologias como R3 Corda, Hyperledger Cacto (Cactos), Hyperledger Fabric e muitas outras soluções blockchain populares.
