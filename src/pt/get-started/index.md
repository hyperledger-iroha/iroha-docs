# Iroha 3 {#iroha-3}

Iroha 3 é a plataforma Hyperledger Iroha de primeira versão. Ela suporta redes auto-hospedadas e o modelo de implantação multi-dataspace SORA Nexus a partir de uma base de código determinística.

Em alto nível, Iroha 3 combina:

- execução e armazenamento determinísticos
- a Máquina Virtual Iroha (IVM) para contratos inteligentes portáteis
- Norito como o formato de serialização canônica
- Torii para cliente, operador e APIs voltado para o aplicativo
- Sumeragi consenso com disponibilidade obrigatória de dados e transmissão confiável
- contas canônicas sem domínio com aliases legíveis por humanos vinculados separadamente
