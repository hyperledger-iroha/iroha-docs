# Iroha 3 {#iroha-3}

Iroha 3 é a plataforma Hyperledger Iroha de primeira versão. Suporta redes auto-hospedadas e o modelo de implantação multi-espaço de dados SORA Nexus a partir de uma base de código determinista.

Em um nível elevado, Iroha 3 combina:

- Execução e armazenamento deterministas
- A máquina virtual Iroha (IVM) para contratos inteligentes portáteis
- Norito como formato de fio canônico
- Torii para o cliente, o operador e a aplicação APIs
- Sumeragi consenso com a disponibilidade obrigatória de dados e uma transmissão confiável
- Contas canônicas sem domínio com pseudónimos legíveis ao ser humano separadamente vinculados
