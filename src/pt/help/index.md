# Receber apoio {#receive-support}

De vez em quando, você pode ter perguntas sobre Iroha que gostaria de discutir detalhadamente com outros. Há três maneiras de entrar em contato rapidamente com a nossa comunidade: Telegram, Discord e GitHub.

A comunidade usa [Telegram](https://t.me/hyperledgeriroha) e [ LF Decentralized Trust Discord](https://discord.gg/hyperledger) para comunicação. Use o canal `iroha` para perguntas do projeto.

Finalmente, você pode [criar um problema GitHub](https://github.com/hyperledger-iroha/iroha/issues/new/choose), quer seja uma solicitação para atualizar documentação, uma sugestão para a equipe principal ou um bug que encontrou.
