# Tipos de gênese {#genesis-types}

Um manifesto de gênese é a forma JSON de um [`RawGenesisTransaction`](#rawgenesistransaction). Esta referência lista esse tipo e todos os tipos que ele contém, gerados a partir do código-fonte fixado do Iroha. Para todos os tipos do livro-razão, obtenha o esquema do seu nó conforme descrito na referência do [esquema do modelo de dados](/pt/reference/data-model-schema.md).
