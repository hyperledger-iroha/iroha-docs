# Iroha 3 {#iroha-3}

Iroha 3 է առաջին թողարկումը Hyperledger Iroha Պլատֆորմ. Այն աջակցում է ինքնուրույն հյուրընկալվող ցանցերի եւ բազմակողմանի տվյալների տարածքի SORA Nexus տեղակայման մոդելը մեկ դետերմինիստիկ կոդային հիմքից:

Բարձր մակարդակով Iroha 3 համադրում է հետեւյալը.

- վճռական կատարում եւ պահեստավորում
- բջջային խելացի պայմանագրերի համար Iroha վիրտուալ մեքենա (IVM)
- Norito-ն որպես կանոնական սերիականացման ձևաչափ
- Torii հաճախորդի, օպերատորի եւ ծրագրային ապահովման համար APIs
- Sumeragi համաձայնություն պարտադիր տվյալների մատչելիության եւ հուսալի հեռարձակման հետ
- դոմեյնային չկանոնիկ հաշիվներ, որոնք առանձին կապված են մարդու կողմից ընթերցելի կեղծանուններով
