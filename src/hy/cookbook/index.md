# Iroha 3 Ծրագրային խոհանոց {#iroha-3-application-cookbook}

Կառուցեք Iroha 3-ի դեմ ՝ օգտագործելով փոքր, ստուգելի բաղադրատոմսեր, որոնք սկսվում են Taira թեստային ցանցից եւ պահում են Minamoto հիմնական ցանցը միայն ընթերցման համար: Յուրաքանչյուր բաղադրատիպ նշում է, թե դա հանրային ընթերցանություն է, սովորական ֆինանսավորվող հաշիվի գրառում կամ թույլտվության հետ կապված գործողություն: Հրամանները օգտագործում են ընթացիկ I105 հաշիվը IDs, բացարձակ վճարային ընտրություն եւ վարքագիծը, որը ստուգվում է Iroha գրավում [`c8c872461e92f04325c350cdd952f4276e96f9dc`](https://github.com/hyperledger-iroha/iroha/tree/c8c872461e92f04325c350cdd952f4276e96f9dc).

Սկսեք [Միացում Taira-ին](./connect-to-taira.md) էջից։ Այն ֆինանսավորում է ստորագրողին և գրանցում վճարային ակտիվը, որը վերաօգտագործվում է հրամանի տողի բաղադրատոմսերում։ Երբեք մի՛ պատճենեք վճարային ակտիվի ID-ն այս փաստաթղթերից: կարդացեք այն Taira-ի faucet-ի ընթացիկ քաղաքականությունից։

## Հասանելիության մակարդակները {#access-levels}

- Հանրային  ոչ մի ստորագրող կամ ցանցի թույլտվություն չի պահանջվում:
- **Գրելու պատրաստ** — օգտագործեք ֆինանսավորված Taira թեստային հաշիվ, բացահայտորեն նշված վճարող և ընթացիկ վճարային ակտիվը, որը հրապարակում է faucet-ի քաղաքականությունը։
- Պահանջվող թույլտվությունը  Taira պետք է տրվի անվանված վազման ժամանակի թույլտվություն կամ կառավարված անունների տարածք: Օգտագործեք ստեղծված տեղական ցանց, երբ այդ շնորհումը մատչելի չէ. տեղական հաջողությունը չի տալիս Taira լիազոր հաշիվ:

Ոչ մի խոհանոցային գրքի բաղադրատոմս չի ուղարկում Minamoto հասցեին:
