# Iroha 3 Ծրագրային խոհանոց {#iroha-3-application-cookbook}

Կառուցեք Iroha 3-ի դեմ ՝ օգտագործելով փոքր, ստուգելի բաղադրատոմսեր, որոնք սկսվում են Taira թեստային ցանցից եւ պահում են Minamoto հիմնական ցանցը միայն ընթերցման համար: Յուրաքանչյուր բաղադրատիպ նշում է, թե դա հանրային ընթերցանություն է, սովորական ֆինանսավորվող հաշիվի գրառում կամ թույլտվության հետ կապված գործողություն: Հրամանները օգտագործում են ընթացիկ I105 հաշիվը IDs, բացարձակ վճարային ընտրություն եւ վարքագիծը, որը ստուգվում է Iroha գրավում [`0010c5a70039eac101a4846499ba9ceaf43eb65c`](https://github.com/hyperledger-iroha/iroha/tree/0010c5a70039eac101a4846499ba9ceaf43eb65c).

Սկսեք [Կապվեք Taira](./connect-to-taira.md): Այն ստեղծում է հաճախորդի կոնֆիգուրացիան եւ վճարային մետադատները, որոնք վերաօգտագործվում են հրամանատար գծի բաղադրատոմսերով: Երբեք չճանաչեք այս փաստաթղթից վճարային ակտիվը ID. վերցրեք այն ընթացիկ Taira ջրհեղեղենի արձագանքից։

## Հասանելիության մակարդակները {#access-levels}

- Հանրային  ոչ մի ստորագրող կամ ցանցի թույլտվություն չի պահանջվում:
- Գրելու պատրաստ  օգտագործեք ֆինանսավորվող Taira փորձարկման հաշիվ, բացարձակ վճարովի վճարող եւ գազանի կողմից վերադարձված ընթացիկ վճարային ակտիվը:
- Պահանջվող թույլտվությունը  Taira պետք է տրվի անվանված վազման ժամանակի թույլտվություն կամ կառավարված անունների տարածք: Օգտագործեք ստեղծված տեղական ցանց, երբ այդ շնորհումը մատչելի չէ. տեղական հաջողությունը չի տալիս Taira իշխանություն:

Ոչ մի խոհանոցային գրքի բաղադրատոմս չի ուղարկում Minamoto հասցեին:
