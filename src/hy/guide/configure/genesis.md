## Ֆայլեր {#files}

Վերին հոսքի պահոցը ուղարկում է լռելյայն մանիֆեստը `defaults/genesis.json`.
Kagami- ստեղծված ցանցերը գրում են իրենց սեփական մանիֆեստը և ստորագրված գործարքը
ելքային գրացուցակ.

```bash
cargo run --bin kagami -- localnet --peers 4 --out-dir ./localnet
```

Ստեղծվածը `README.md` այդ գրացուցակում գրանցում է ճշգրիտ ֆայլերը և գործարկում
հրամաններ ընտրված պրոֆիլի համար:

## Գործընկերների կոնֆիգուրացիա {#peer-configuration}

Գործընկերները մատնանշում են ստորագրված գենեզի գործարքը `[genesis]` բաժինը
`config.toml`:

```toml
[genesis]
file = "./genesis.signed.nrt"
public_key = "ed0120..."
```

Ցանցի բոլոր հասակակիցները պետք է համաձայնեն ստորագրված գենեզի գործարքի և
genesis հանրային բանալին:

## Ստորագրելով Ծննդոց {#signing-genesis}

Եթե ​​դուք խմբագրում եք մանիֆեստը ձեռքով, հաստատեք և ստորագրեք այն նախքան գործընկերները սկսելը.

```bash
cargo run --bin kagami -- genesis validate ./genesis.json
cargo run --bin kagami -- genesis sign ./genesis.json \
  --private-key-file "$GENESIS_PRIVATE_KEY_FILE" \
  --out-file ./genesis.signed.nrt
```

`GENESIS_PRIVATE_KEY_FILE` պետք է լինի սեփականատիրոջ կողմից պահվող ռեժիմ-`0600`, միայնակ կապ
սովորական ֆայլ, որը պարունակում է մեկ կանոնական մասնավոր բանալու մուլտիհեշ և վերջնական
նոր գիծ. Kagami մերժում է խորհրդանշական կապերը և երբեք չի ընդունում հում ծագման մասնավորը
բանալին հրամանի տողում:

NPoS-ի համար կամ Nexus պրոֆիլներ, ներառում են տոպոլոգիան և BLS Տիրապետման ապացույցներ
պահանջվում է ստեղծված պրոֆիլի կողմից: Kagami `localnet`, `wizard`, և պրոֆիլը
սերնդի հրամանները ավտոմատ կերպով մշակում են այդ մանրամասները:
