# Գլխավոր էջ {#guide}

Օգտագործեք այս բաժինը, երբ կառուցում եք, աշխատում եք կամ ինտեգրվում եք Iroha -ի հետ: Սկսեք առաջին հաճախորդի համար SDK դասընթացներից, այնուհետեւ անցեք լավագույն փորձերի եւ օպերատորների հղումների վրա ՝ նախքան տեղադրելը կիսված ցանցի դեմ:

## Առաջարկվող ուղին {#recommended-path}

1. [Կառուցեք Iroha 3](/hy/get-started/install-iroha.md) եւ [ տեղական ցանցի գործարկում ](/hy/get-started/launch-iroha.md).
2. Ընտրեք [SDK ձեռնարկը ](/hy/guide/tutorials/) եւ ներկայացրեք փոքր գործարք:
3. Վերանայեք [Հրավերների մշակումը](/hy/guide/best-practices/application-development.md) եւ [Տվյալների մոդելավորում](/hy/guide/best-practices/data-modeling.md), նախքան դիմումի ձեւավորումը API:
4. Օգտագործեք [ ցանցի տեղակայումը](/hy/guide/best-practices/network-deployment.md), [Օպերացիաները](/hy/guide/best-practices/operations.md) եւ [ Անվտանգությունը եւ մուտքը](/hy/guide/best-practices/security-and-access.md) նախքան բաշխվող կամ արտադրական ցանցը գործարկելը:
5. Հետեւեք [Release Readiness](/hy/guide/best-practices/release-readiness.md)-ին, երբ տեղական զարգացումից տեղափոխվում եք Taira, Minamoto կամ այլ կենդանի տեղակայման:
