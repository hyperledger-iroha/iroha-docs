# Միջոցառումներ {#events}

Միջոցառումներ են թողարկվում, երբ բլոկչեյնի ներսում տեղի են ունենում որոշակի իրեր, օրինակ՝ ստեղծվում է նոր հաշիվ կամ commit է արվում է բլոկ:

- մշակման շղթայի իրադարձություններ
- տվյալների իրադարձություններ
- ժամանակի իրադարձություններ
- գործարկման իրադարձությունները

## Փողովակատարի իրադարձությունները {#pipeline-events}

Pipeline- ի իրադարձությունները թողարկվում են այն ժամանակ, երբ գործարքները ներկայացվում են, կատարվում կամ հաստատված բլոկի վրա: Pipeline- ը պարունակում է հետեւյալ տեղեկությունները. Կազմակերպության կարգավիճակը կարող է լինել կամ `Validating` (վավերացման գործընթաց), `Rejected`, կամ `Committed`. Եթե կազմակերպությունը մերժվել է, ներկայացվում է մերժման պատճառը։

### Փորձեք այն Taira {#try-it-on-taira}

Ստուգեք, որ հանրային մշակման շղթայի իրադարձությունների հոսքը տեղադրված է.

```bash
curl -fsSI https://taira.sora.org/v1/events/sse \
  | sed -n '1,12p'
```

Որպեսզի կարողանաք ստուգել առանց հոսքի բաց պահելու, կարդացեք վերջին Explorer- ի գործարքները.

```bash
curl -fsS 'https://taira.sora.org/v1/explorer/transactions?page=1&per_page=5' \
  | jq '{pagination, txs: [.items[] | {hash, block, status, executable}]}'
```

Բացեք SSE երթուղին թերմինալում, երբ անհրաժեշտ է կենդանի իրադարձություններ:

```bash
curl -fsS -N https://taira.sora.org/v1/events/sse
```

Եթե հոսքը բաց է, ոչ մի գործարք չի կատարվում, ապա հրամանը կարող է լռել, չնայած երթուղին առողջ է:

## Տվյալների իրադարձություններ {#data-events}

Տվյալների իրադարձությունները թողարկվում են այն ժամանակ, երբ գրանցման տվյալների հետ կապված փոփոխություն է տեղի ունենում, ինչպիսիք են հանգույցները, տիրույթները, հաշիվները, ակտիվները, ակտիվների սահմանումները, NFTs, գործարկիչները, դերը, շղթայի վրա կազմվածքը, կատարողի վիճակը, ապացույցները, գաղտնի ակտիվները, կամուրջները կամ SORA/Nexus-հատուկ առարկաներ: Այս տեսակի իրադարձությունները օգտագործվում են [ տվյալների իրադարձությունների ֆիլտրներում](./filters.md#data-event-filters).
