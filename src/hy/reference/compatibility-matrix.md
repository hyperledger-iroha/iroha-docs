# Համատեղելիության մատրիկա {#compatibility-matrix}

Համատեղելիության մատrix- ը ցույց է տալիս ներկա Iroha 3 փաստաթղթերի հավաքածուի համար խաչմերուկային SDK սցենարի ծավալը: Ըստ նախապայմանի, էջը բեռնում է փաթեթավորված շտկված նկարը, որը ստեղծվել է պինացված [`hyperledger-iroha/iroha`](https://github.com/hyperledger-iroha/iroha) վերանայմանից:

Մատrix-ը բաղկացած է հետեւյալից.

- Պատմություններ առաջին սյունակում
- SDKs մնացած սյունակների վրա
- Բացահայտված, ձախողված եւ բացակայում տվյալների վիճակի խորհրդանիշները

Միայն թարմացման աշխատանքային հոսքի միջոցով ստուգված արդյունքները են հաշվետուվում որպես ընդգրկված կամ անհաջող: Սցենարները, որոնք առանց ապացույցների փաթեթավորված վերանայման համար, ցուցադրվում են որպես բացակայում տվյալներ, այլ ոչ թե ժառանգում են մեկ այլ աղբյուրի վերանայման արդյունքները:
