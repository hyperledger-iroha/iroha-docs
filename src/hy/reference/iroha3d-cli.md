# `iroha3d` CLI {#iroha3d-cli}

`iroha3d` է ստանդարտ Iroha 3 հանգույցային դեյմոն: Cargo փաթեթը կոչվում է `irohad`, այնպես որ հրավիրեք բինարային աղբյուրից ստուգման հետ:

```shell
cargo run -p irohad --bin iroha3d -- --config path/to/config.toml
```

Հասարակական Taira թեստային ցանցի համար, թողարկման պատկերն օգտագործում է `iroha3d_taira`: Այն ընդունում է նույնը CLI. Այն նաեւ ուժի մեջ է մտնում Taira կանոնիկ շղթան, վավերացնող հավաքածու, պահեստավորման կարգավորումները եւ գործնական ժամկետի ստորագրման բանալիները: Վավերացրեք Taira կոֆիգուրացիան առանց բացելու վարկային ժամանակահատվածի հավատարմագրեր, ինչպիսիք են հետեւյալը.

```shell
iroha3d_taira --sora \
  --config /etc/iroha/taira/config.toml \
  --check-config
```

Օգտագործեք կանոնական Taira պրոֆիլի՝ օպերատորի պատրաստած ձևը․ պահոցում գտնվող ձևանմուշը դեռ պարունակում է տեղակայման տեղապահեր։ Taira-ի դեմ փորձարկելիս այն մի՛ փոխարինեք ընդհանուր SORA Nexus կամ արտադրական SoraFS կարգավորումներով։

## `--config` {#arg-config}

- Տիպ: ֆայլերի ուղին
- Անանուններ: `-c`

Ճանապարհ դեպի [ հանգույցների կարգավորումը ](/hy/reference/peer-config/index.md).

## `--genesis-manifest-json` {#arg-genesis-manifest-json}

- Տիպ: ֆայլերի ուղին

Ընտրական գենեզի մանիֆես JSON, որն օգտագործվում է համաձայնության հաստատման համար:

## `--check-config` {#arg-check-config}

Վավերացրեք լուծված կոնֆիգուրացիան եւ մատչելի գեներիզային նյութը, ապա դուրս եկեք առանց կապելու ցանցային սոցետները:

## `--json` {#arg-json}

- **Տեսակ՝** դրոշակ
- **Պահանջում է՝** `--check-config`

Այս հավաքման և կարգավորման համատեղելիության արժեքները արտածում է մեկ Norito JSON օբյեկտով՝ `Ready` կամ `Pending` տողի փոխարեն։

## `--check-storage` {#arg-check-storage}

- **Տեսակ՝** դրոշակ
- **Անհամատեղելի է՝** `--check-config`

Այս հավաքման ապակոդավորիչներով միայն ընթերցման ռեժիմում ստուգում է կանգնեցված հանգույցի Kura պահոցն ու ամենավերջին ակնթարթային վիճակը, արդյունքն արտածում մեկ Norito JSON օբյեկտով և ձախողման դեպքում վերադարձնում ոչ զրոյական ելքի կոդ։ Ստուգումը վերցնում է Kura պահոցի արմատի կողպեքը, ուստի մերժում է գործող հանգույցի զբաղեցրած պահոցը։ Այն երբեք չի փոխում պահոցը և չի բացում միայն կատարման ժամանակ օգտագործվող գաղտնիքները։

## `--check-replay` {#arg-check-replay}

- **Տեսակ՝** դրոշակ
- **Անհամատեղելի է՝** `--check-config`, `--check-storage`

Այս հավաքմամբ կրկին կատարում է կանգնեցված հանգույցի պահոցի պատճենը և արդյունքն արտածում մեկ Norito JSON օբյեկտով։ Հրամանը բլոկները պատճենում է ժամանակավոր պանակում, այնտեղ վերականգնում ամենավերջին ակնթարթային վիճակը կամ կրկին կատարում ստորագրված ծագման վիճակը, ապա կրկին կատարում յուրաքանչյուր հաջորդ բլոկ։ Այն վերադարձնում է ոչ զրոյական ելքի կոդ, եթե բլոկը չի վերարտադրում իր հավաստագրված արդյունքը կամ անհրաժեշտ բլոկի բովանդակությունը բացակայում է․ այն երբեք չի գրում սկզբնական պահոցում և չի բացում միայն կատարման ժամանակ օգտագործվող գաղտնիքները։

## `--require-genesis-inrou-deployment-authority` {#arg-require-genesis-inrou-deployment-authority}

- **Տեսակ՝** հաշվի ID
- **Պահանջում է՝** `--check-config`

Անցանց ստուգման ընթացքում պահանջում է, որ ճշգրիտ ստորագրված ծագման վիճակի կատարումից հետո այս գրանցված հաշիվը պահպանի SoraCloud տեղակայման լիազորությունը։

## `--sumeragi-assert-fresh-key` {#arg-sumeragi-assert-fresh-key}

- **Տեսակ՝** դրոշակ

Միայն այս մեկնարկի համար հաստատում է, որ հանգույցի կոնսենսուսի բանալիները երբեք չեն ստորագրել այս շղթայի համար։ Sumeragi-ն յուրաքանչյուր բանալու համար պահում է անվտանգության գրառում և առանց դրա ոչինչ չի ստորագրում, մինչև ունենա ապացույց, որ գրառումը չի կորել։ Այս դրոշակը փոխանցեք մեկ անգամ՝ նոր բանալու առաջին մեկնարկին, և երբեք՝ տվյալների կորստից հետո։

## `--trace-config` {#arg-trace-config}

- Տիպ: դրոշ
- Շրջակա միջավայր. `TRACE_CONFIG`

Սեղմել հետագա արձանագրությունները, երբ կոմֆիգուրացիոն շերտերը ընթերցվում եւ վերլուծվում են.

## `--config-blake3` {#arg-config-blake3}

- Տիպ. 64 թվային հեքսադեկիմալ BLAKE3 դիժեսթ
- պահանջներ. `--config`

Պահանջել է կոնֆիգուրացիոն ֆայլի բայտները համապատասխանեն մատակարարված դիժեստին: Անկախության կապակցությամբ ֆայլը պետք է հարթացվի, այն չի կարող պարունակել `extends`.

## `--terminal-colors` {#arg-terminal-colors}

- Տիպ. Բուլյան, փոխանցվել է որպես `--terminal-colors=true` կամ `--terminal-colors=false`
- Նախադրյալ՝ վերջնական հնարավորությունների հայտնաբերում
- Շրջակա միջավայր. `TERMINAL_COLORS`

վերահսկողություն ANSI գույնի արտադրանքը:

## `--language` {#arg-language}

- Տիպ: շղթա

Հաշվի առեք դեյմոնային հաղորդագրությունների համար օգտագործվող համակարգի լեզուն:

## `--sora` {#arg-sora}

- Տիպ: դրոշ
- Շրջակա միջավայր. `IROHA_SORA_PROFILE`

Ակտիվացնում է SoraFS-ի, SoraNet կապի հաստատման և բազմագոտի կոնսենսուսի օգտագործած SORA Nexus պրոֆիլը։ Taira մեկնարկիչը միշտ կանչվում է այս դրոշակով։

## FastPQ վերաբացումներ {#fastpq-overrides}

`--fastpq-execution-mode <MODE>` եւ `--fastpq-poseidon-mode <MODE>`-ը ընդունում են միայն `cpu` կամ `gpu`: Մնացած տարբերակները գերազանցում են հեռաչափության տեքստերը.

- `--fastpq-device-class <LABEL>`
- `--fastpq-chip-family <LABEL>`
- `--fastpq-gpu-kind <LABEL>`

Օրինակ՝

```shell
iroha3d --fastpq-execution-mode gpu \
  --fastpq-poseidon-mode cpu \
  --fastpq-device-class apple-m4 \
  --fastpq-chip-family m4 \
  --fastpq-gpu-kind integrated
```

## Ծրագրված օգնություն {#generated-help}

Վերևի ընտրանքների ամփոփումը հետևում է ամրագրված Iroha commit-ի `iroha3d` արգումենտների սահմանումներին։ Ձեր աղբյուրի պատճենի ճշգրիտ օգնությունը տեսնելու համար գործարկեք․

```shell
cargo run --locked -p irohad --bin iroha3d -- --help
```
