# Գենեզիսի տիպեր {#genesis-types}

Գենեզիսի մանիֆեստը [`RawGenesisTransaction`](#rawgenesistransaction)-ի JSON ձևն է։ Այս տեղեկատուն թվարկում է այդ տիպը և դրա մեջ պարունակվող բոլոր տիպերը, որոնք ստեղծվել են Iroha-ի ամրագրված սկզբնական կոդից։ Մատյանի բոլոր տիպերի համար ստացեք ձեր հանգույցի սխեման, ինչպես նկարագրված է [տվյալների մոդելի սխեմայի](/hy/reference/data-model-schema.md) տեղեկատուում։
