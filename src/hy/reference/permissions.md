# Թույլտվության տոքեր {#permission-tokens}

Այս էջում ցուցակում են ներկայիս Iroha կատարողի տվյալների մոդելի կողմից բացահայտված թույլտվությունների նախնական տոկենների տեսակները: Դասերի եւ թույլտվության հասկացական ուղեցույցի համար դիտեք [Թույլտվություններ](/hy/blockchain/permissions.md).

Թույլտվությունների ստուգումները իրականացվում են ակտիվ վավերացնողի կողմից: Ստորեւ տրված տոքերների տիպի անունները նկարագրում են ստանդարտ քաղաքականության մակերեսը, բայց ցանցը կարող է կատարելագործողին թարմացնելով վավերացնել վավերացումը.

## Գույքի սեփականություն {#ownership}

Գնորդի համար զգայուն թույլտվության տոքերները պետք է հղում կատարեն ընթացիկ տվյալների մոդելի կողմից օգտագործվող կանոնիկական օբյեկտի IDs: Օրինակ, հաշիվների թույլտվությունները վերաբերում են կանոնական դոմեյնազուրկ հաշիվին IDs, դոմեյնի թույլտվություններն էլ վերաբերում են `domain.dataspace` դոմեային IDs, եւ ակտիվների թույլտվությունները վերաբերում են ակտիվի կանոնիկ սահմանմանը կամ ակտիվին IDs:

Եթե գործարքը ձախողվում է թույլտվության սխալով, ստուգեք երկու կողմերը.

- գործարքը ստորագրող հաշիվը ակնկալվող կանոնական հաշիվն է
- թույլտվության նշանը կամ դերը տրվել են հստակ առարկայի համար ID, որը օգտագործվել է հրահանգում:
