# Recibir apoyo {#receive-support}

De vez en cuando, es posible que tengas preguntas sobre Iroha que te gustaría discutir con otros en detalle. Hay tres formas de ponerte rápidamente en contacto con nuestra comunidad: Telegram, Discord y GitHub.

La comunidad utiliza [Telegram](https://t.me/hyperledgeriroha) y [ LF Decentralized Trust Discord](https://discord.gg/hyperledger) para la comunicación. Utilice el canal `iroha` para preguntas del proyecto.

Finalmente, puede [crear un problema GitHub ](https://github.com/hyperledger-iroha/iroha/issues/new/choose), ya sea una solicitud para actualizar la documentación, una sugerencia para el equipo central o un error que haya encontrado.
