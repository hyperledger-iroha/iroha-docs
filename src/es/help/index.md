# Recibir apoyo {#receive-support}

De vez en cuando, es posible que tenga preguntas sobre Iroha que le gustaría discutir en detalle con otros. Hay tres formas de ponerse en contacto rápidamente con nuestra comunidad: Telegram, Discord y GitHub.

La comunidad utiliza [Telegram](https://t.me/hyperledgeriroha) y [LF Decentralized Trust Discord](https://discord.gg/hyperledger) para la comunicación. Use el canal `iroha` para preguntas sobre el proyecto.

Finalmente, puedes [crear un problema GitHub](https://github.com/hyperledger-iroha/iroha/issues/new/choose), ya sea una solicitud para actualizar la documentación, una sugerencia para el equipo principal o un error que hayas encontrado.
