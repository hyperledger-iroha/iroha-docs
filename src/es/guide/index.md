# Guía {#guide}

Utilice esta sección cuando esté construyendo, operando o integrando con Iroha. Comience con los tutoriales SDK para un primer cliente, luego pase a las mejores prácticas y referencias para operadores antes de desplegar en una red compartida.

## Secciones {#sections}

| Sección |Úsalo para|
| ------------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------- |
| [SDK Tutoriales](/es/guide/tutorials/)                           |Configuración del cliente específica del idioma y aplicaciones de ejemplo|
| [Mejores prácticas](/es/guide/best-practices/)                     |Guía de producción para desarrollo, implementación, operaciones, seguridad y versiones|
| [Configuración y Gestión](/es/guide/configure/overview.md) |Configuración de pares de red local, génesis de blockchain, configuración del cliente, claves y gestión de pares de red|
| [Seguridad](/es/guide/security/)                                 |Manejo de llaves, seguridad operativa, VPNs, monitoreo de fraude y limpieza de permisos|
| [Operaciones Avanzadas](/es/guide/advanced/metrics.md)            |Métricas, verificaciones de rendimiento, pruebas de caos, recarga en caliente y operación en hardware desnudo|

## Camino recomendado {#recommended-path}

1. [Instalar Iroha 3](/es/get-started/install-iroha.md) y [lanzar una red local](/es/get-started/launch-iroha.md).
2. Elige un [tutorial de SDK](/es/guide/tutorials/) y envía una pequeña transacción.
3. Revise [Desarrollo de Aplicaciones](/es/guide/best-practices/application-development.md) y [Modelado de datos](/es/guide/best-practices/data-modeling.md) antes de dar forma a una aplicación API.
4. Use [Despliegue de red](/es/guide/best-practices/network-deployment.md), [Operaciones](/es/guide/best-practices/operations.md) y [Seguridad y Acceso](/es/guide/best-practices/security-and-access.md) antes de ejecutar una red compartida o de producción.
5. Sigue [Preparación para el Lanzamiento](/es/guide/best-practices/release-readiness.md) al promocionar desde el desarrollo local a Taira, Minamoto u otra implementación en vivo.
