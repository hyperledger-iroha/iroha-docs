# Guía {#guide}

Utilice esta sección cuando esté construyendo, operando o integrándose con Iroha. Comience con los tutoriales de SDK para un primer cliente, luego pasa a las mejores prácticas y referencias del operador antes de implementar contra una red compartida.

## Secciones {#sections}

|Sección |Utilizarlo para|
| ------------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------- |
| [SDK Tutoriales](/es/guide/tutorials/) |Configuración del cliente específico para el idioma y muestras de aplicaciones |
| [Las mejores prácticas](/es/guide/best-practices/) |Orientación orientada a la producción agrupada por desarrollo, modelado de datos, despliegue, operaciones, seguridad y disponibilidad para el lanzamiento |
| [Configuración y gestión ](/es/guide/configure/overview.md) |Configuración local de pares, génesis, configuración del cliente, claves y gestión de pares |
| [Seguridad](/es/guide/security/) |Manejo de las claves, seguridad operativa, VPNs, vigilancia del fraude y higiene de los permisos |
| [Operaciones avanzadas](/es/guide/advanced/metrics.md) |Métricas, controles de rendimiento, pruebas de caos, recarga en caliente y operación con metal desnudo |

## Camino recomendado {#recommended-path}

1. [Instalar Iroha 3](/es/get-started/install-iroha.md) y [ lanzar una red local ](/es/get-started/launch-iroha.md).
2. Seleccione un tutorial [SDK ](/es/guide/tutorials/) y envíe una pequeña transacción.
3. Revisar [Desarrollo de aplicaciones](/es/guide/best-practices/application-development.md) y [Modelado de datos ](/es/guide/best-practices/data-modeling.md) antes de dar forma a una aplicación API.
4. Utilización [Despliegue de la red](/es/guide/best-practices/network-deployment.md), [Operaciones](/es/guide/best-practices/operations.md), y [Seguridad y acceso](/es/guide/best-practices/security-and-access.md) antes de ejecutar una red compartida o de producción.
5. Sigue [Release Readiness](/es/guide/best-practices/release-readiness.md) cuando promueva desde el desarrollo local a Taira, Minamoto o otro despliegue en vivo.
