# Muestras y recetas {#samples-and-recipes}

El repositorio de fuentes Iroha contiene recetas y conjuntos de ensayos SDK que siguen la misma revisión que el nodo.

## Recetas JavaScript {#javascript-recipes}

[`javascript/iroha_js/recipes`](https://github.com/hyperledger-iroha/iroha/tree/0010c5a70039eac101a4846499ba9ceaf43eb65c/javascript/iroha_js/recipes) contiene ejemplos enfocados para el batchamiento de transacciones deterministas, Nexus transferencias de aplicaciones, NFT y la iteración de cuentas, ISO flujos de puentes, y Torii Cada receta documenta si se ejecuta fuera de línea o necesita un video en vivo Torii punto final.

## Swift y iOS {#swift-and-ios}

Utilización `IrohaSwift/Tests/IrohaSwiftTests` para ejemplos verificados con respecto a la corriente Swift SDK. Veamos . [Swift y iOS](/es/guide/tutorials/swift.md) para la instalación del paquete y el puente.

## Android {#android}

Para el nuevo Android el trabajo, utilizar la Kotlin-Primero `core-jvm`, `client-android`, y `offline-wallet-android` módulos descritos en: [Kotlin, Android, y Java](/es/guide/tutorials/kotlin-java.md). El Consejo Kotlin SDK es el punto de partida canónico para Android los consumidores.
