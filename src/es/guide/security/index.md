# Seguridad {#security}

Al utilizar Iroha o cualquier otro libro mayor de cadena de bloques para ese asuntola seguridad es fundamental para las organizaciones financieras, ya que constituye la base de la confianza en una industria donde los datos y transacciones financieras sensibles son rutinarias. Una violación exitosa de la seguridad realizada por una parte maliciosa puede llevar a consecuencias devastadoras para usted. Por lo tanto, es esencial establecer medidas preventivas de seguridad para proteger la integridad y confidencialidad de sus datos sensibles.
