# Seguridad {#security}

Asegurar una implementación Iroha como lo haría con cualquier sistema que maneje datos y valores sensibles. Proteger las claves de firma, acceso a la red, operaciones de nodos, monitoreo y respuesta a incidentes. Un libro mayor no elimina la necesidad de estos controles.

### Navegación {#navigation}

En esta sección podrá aprender acerca de varios aspectos de la seguridad de su red Iroha. Para obtener más información, elija uno de los siguientes temas:

- [Principios de seguridad](./security-principles):

Principios fundamentales para la protección de los datos y la reducción del riesgo de infracción.

- [Las redes privadas virtuales ](./vpn.md):

Cómo utilizar un VPN para restringir el acceso entre pares, Torii, y al operador en las implementaciones privadas o de consorcio.

- [Seguridad operativa ](./operational-security.md):

Controles diarios de acceso, monitoreo, respuesta a incidentes y estaciones de trabajo del operador.

- [Seguimiento de fraudes ](./fraud-monitoring.md):

Cómo usar eventos, consultas, permisos y señales operativas para detectar actividad sospechosa y preservar evidencia de respuesta.

- [Seguridad de contraseña ](./password-security.md):

Entropia de contraseña, construcción de contraseñas fuertes y modos comunes de falla.

- [Criptografía de llaves públicas ](./public-key-cryptography.md):

Encriptación de llave pública, firmas y comunicación autenticada.

  - [Generación de claves criptográficas ](./generating-cryptographic-keys.md):

Generar las claves criptográficas compatibles con `kagami`.

  - [Almacenamiento de las claves criptográficas ](./storing-cryptographic-keys.md):

Almacenar las claves criptográficas utilizando controles en capas adecuados para la implementación.
