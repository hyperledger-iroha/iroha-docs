# Iroha 3 {#iroha-3}

Iroha 3 es la plataforma Hyperledger Iroha de primera versión. Soporta redes autoalojadas y el modelo de despliegue de múltiples espacios de datos SORA Nexus desde una base de código determinista.

A un alto nivel, Iroha 3 combina:

- ejecución y almacenamiento deterministas
- la Máquina Virtual Iroha (IVM) para contratos inteligentes portátiles
- Norito como el formato de serialización canónico
- Torii para cliente, operador y APIs orientado a la aplicación
- Sumeragi consenso con disponibilidad de datos obligatoria y transmisión confiable
- cuentas canónicas sin dominio con alias legibles por humanos vinculados por separado
