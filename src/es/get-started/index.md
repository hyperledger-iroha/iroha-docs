# Iroha 3 {#iroha-3}

Iroha 3 es la plataforma de primer lanzamiento Hyperledger Iroha. Apoya las redes auto-alojadas y el modelo de implementación del espacio de datos múltiple SORA Nexus a partir de una base de código determinista.

En un nivel alto, Iroha 3 combina:

- la ejecución y el almacenamiento deterministas
- la máquina virtual Iroha (IVM) para los contratos inteligentes portátiles
- Norito en el formato de cable canónico
- Torii para el cliente, el operador y la aplicación orientada a APIs
- Sumeragi consenso con la disponibilidad obligatoria de datos y una difusión fiable
- cuentas canónicas sin dominio con alias legibles por el ser humano vinculados por separado
