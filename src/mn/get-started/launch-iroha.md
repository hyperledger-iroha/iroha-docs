# Эхлүүлэх Iroha 3 {#launch-iroha-3}

Хаалттай орчинд системүүдийн холболтыг туршихын тулд Linux үйлдлийн системтэй нэг виртуал машин (VM) дээр Iroha 3-ын дөрвөн баталгаажуулагчийг ажиллуулна. Гарын үсэг зурсан гүйлгээ илгээгээд нэг баталгаажуулагчийг зогсоож, үлдсэн гурав нь дараагийн гүйлгээг баталгаажуулж чадаж байгаа эсэхийг шалгана. Ингэснээр зөвшөөрөлтэй оролцогчтой бие даасан бүртгэл үүснэ. Үүнийг засаглалын дүрэмд захирагдах өгөгдлийн орон зай болгон SORA Nexus-д холбохын тулд тусад нь тохируулах шаардлагатай.

## VM-г бэлтгэ {#prepare-the-vm}

Linux x86_64 дээр Docker Engine, Buildx, Compose v2, Python 3.8 буюу түүнээс шинэ хувилбар болон `unzip` хэрэгслийг ашиглана. Таны бүртгэл Docker ашиглах эрхтэй байх ёстой. Анхны бүтээлтэд GitHub, Docker Hub, Debian багцын толин серверүүд болон crates.io руу HTTPS холболт үүсгэх шаардлагатай.

Бид хэд хэдэн нийцсэн гүйлгээг ашиглан зургаан vCPU ба 32 GiB RAM бүхий VM-д төхөөрөмжийг бүтээж тестлэсэн. Өөрийн ачаалал ба хадгалах хугацаанд зориулж агуулахын хэмжээ гарга. Docker хөдөлгүүр бүрт төхөөрөмжийн нэг хувилбарыг ашиглаж, loopback портууд 18080–18083-г чөлөөлсөн байлга.

[Дөрвөн баталгаажуулагчийн багцыг татаж авах](/downloads/iroha-trade-poc.zip). Үүнд лаунчер, түгжээтэй хамааралтын жагсаалт болон хэвлэсэн Iroha хувилбараас баталгаажуулагч ба клиентийг бүтээхэд ашигласан засварууд орно. Татаж авсан хавтсанд очиж, үүнийг шалгаж, задлаарай.

```sh
echo 'b12d450f9f15c0126dfe5eca83cdfad8bc420c779a78f916d374f433a2b3da0e  iroha-trade-poc.zip' | sha256sum --check
unzip iroha-trade-poc.zip
cd iroha-trade-poc
```

## Бүгд дөрвөн шалгагчийг эхлүүлж баталгаажуулна уу {#start-and-verify-all-four-validators}

```sh
python3 poc.py up
python3 poc.py verify
```

Анх ажиллуулахад контейнерийн дүрсийг бүтээж, виртуал машин (VM) дээр гинжний таних дугаар, түлхүүрүүд болон гарын үсэг зурсан эхний блокийг үүсгэнэ. Баталгаажуулагч бүр тусдаа байнгын хадгалах эзлэхүүнтэй. Шалгах програм туршилтын гүйлгээнд гарын үсэг зураад дөрвөн баталгаажуулагч тус бүр гурван зангилаатай холбогдсон бөгөөд шинэ блокийн хэш нь ижил болохыг мэдээлтэл хүлээнэ. Эхний блок жишээ дансууд агуулдаг. Туршилтын өгөгдөл ашиглаж, APIs-г зөвхөн дотоод loopback интерфэйс дээр нээнэ.

JSON -ийг тодорхойлон хүсэлт илгээн VM -оос эхний баталгаажуулагчийн төлвийг уншина уу.

```sh
curl -fsS -H 'Accept: application/json' http://127.0.0.1:18080/status
```

## Шалгагчийн алдааг туршиж үзэх {#test-a-validator-failure}

```sh
python3 poc.py failover
```

Туршилт нэг баталгаажуулагчийг зогсоож, шинэ гүйлгээ илгээх бөгөөд ажиллаж буй гурван баталгаажуулагч дээр баталгаажсан блокийн хэшийг шалгана. Дараа нь дөрөв дэх баталгаажуулагчийг дахин ажиллуулж, түүнийг мөн блокт хүрэхийг хүлээнэ. Виртуал машин (VM) доголдвол дөрвөн баталгаажуулагч бүгд зогсоно. Нэг физик хост доголдох нөхцөлийг туршихын тулд дөрвөн тусдаа хост тус бүр дээр нэг баталгаажуулагч байрлуулна.

## Зогсооод үргэлжлүүл {#stop-and-resume}

```sh
python3 poc.py down
python3 poc.py up
```

Хоёр командыг багцыг задалсан нэг хавтаснаас ажиллуулна. Дахин асаасан баталгаажуулагчид өмнөх бүртгэлээ нээж чадахаар `state/` хавтас болон Docker-ийн дөрвөн эзлэхүүнийг хамтад нь хадгална. Ажиллаж эхлэх явц гацвал тэр хавтсанд `python3 poc.py logs` командыг ажиллуулна.

## Олон нийтийн API төгсгөлийг туршиж үзнэ үү {#try-the-public-endpoint}

Бүртгэлд зориулж виртуал машин (VM) ажиллуулахгүйгээр Taira дээрх SORA Nexus-ийн универсал өгөгдлийн орон зайгаас програм мэдээлэл уншиж болно. `curl`, `jq` суулгасан ажлын станцаас туршилтын сүлжээнд дараах унших хүсэлтийг илгээнэ.

```sh
curl -fsS -H 'Accept: application/json' https://taira.sora.org/status \
  | jq '{peers, blocks, txs_approved, queue_size}'
```

Хариу нь асуултанд өртсөн зангилааны холбогдсон сүлжээний хамтрагчид, эцэслэгдсэн блокууд, батлагдсан гүйлгээ болон эгнээнд орсон гүйлгээг тайлагнана. Тархалтын төлөвлөгөө боловсруулахад [Сүлжээний байршуулах](/mn/guide/best-practices/network-deployment.md)-ыг үзнэ үү.
