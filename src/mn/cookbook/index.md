# Iroha 3 Судалгааны номын сан {#iroha-3-application-cookbook}

Iroha 3-ийн эсрэг бага, баталгаажуулж болох рецепт ашиглаж, Taira тест сүлжээгээр эхэлж, Minamoto гол сүлжээг зөвхөн уншдаг болгоно. Тус команд нь одоогийн I105 бүртгэл IDs, тодорхой төлбөрийн сонгон шалгаруулалт, Iroha [ `0010c5a70039eac101a4846499ba9ceaf43eb65c`](https://github.com/hyperledger-iroha/iroha/tree/0010c5a70039eac101a4846499ba9ceaf43eb65c) дээр тавих үйлдлийг ашиглана.

Анх нь: [Тэмцээ Taira](./connect-to-taira.md). Энэ нь үйлчлүүлэгчдийн конфигурацын болон төлбөрийн метабараа дахин ашигладаг команд шугамны рецептүүд. ID Энэ баримтлагаас: одоогийн Taira Тэмцээний хариу.

## Хэрэглээний түвшин {#access-levels}

- Олон нийтийн  Нийгмийн зөвшөөрөл болон гарын үсэг зурагч шаардлагагүй.
- Бүртгэл хийхэд бэлэн  санхүүжүүлсэн Taira туршилтын данс, тодорхой төлбөрийн төлөгч болон хангамжийн төлбөрийн актив ашиглах.
- Зөвшөөрөл шаарддаг  Taira нь нэрлэгдэж буй гүйлгээний хугацааны зөвшөөрлийг эсвэл зохицуулсан нэрийг олгох ёстой. Энэ дэмжлэг байхгүй үед үүсгэсэн орон нутгийн сүлжээ ашиглана; орон нутгийн амжилт нь Taira эрх мэдлийг олгодоггүй.

Minamoto -д ямар ч хоолны номын рецепт бичиг илгээдэггүй.
