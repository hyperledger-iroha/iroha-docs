# Гадаад функцийн интерфейс (FFI) {#foreign-function-interfaces-ffi}

Хөдөлмөрийн `iroha_ffi` C үйлдвэрлэлийн макро болон шинж чанаруудтай ABI
Зэвсэглэл Rust APIs. Энэ нь Iroha төрөлүүд нь нэг FFI
хязгаар, жишээ нь SDK холболт эсвэл халамжийн нэгтгэл.

## Яагаад? FFI {#why-ffi}

Функц бол харьцангуй ухамсарсан нэгж бөгөөд ихэнх хэлүүд
функц нь юу хийх ёстой вэ, функцын төлөөлөл ямар байх вэ
Үүнээс гадна, зарим хэл дээр Rust, үр дагаврыг
функцыг дуудах, үүнийг хийх зөвшөөрөлтэй зүйлүүд нь мөн
өөр. Rust APIs өөр хэлээр эсвэл
өөр орчин, Iroha гадаад функцын интерфейс ашигладаг (FFI)
Тоглооллын талбайг тэгш болгох.

Өнөөдрийн гол стандарт нь C аппликейшнүүдийн бинар интерфейс юм.
энгийн, өргөн хүрээнд ашиглах боломжтой, тогтвортой.
Бүх зүйл гар утаснаар, гэхдээ Iroha Энэ нь `iroha_ffi` үйлдвэрлэх хайрцаг
FFI-хэлэлцэж буй үйл ажиллагааны Rust API.

Мэдээж та үүнийг өөрийн гэсэн аргаар хийж болно. `iroha_ffi` зүгээр л хайрцаг
Ямар ч байсан үүсгэх шаардлагатай код бий болгодог.
Хэрэгжсэн бөмбөг нь маш их хичээл зүтгэлтэй, сахилгатай байх хэрэгтэй.
Бүх функцын дуудлага FFI хязгаар нь `unsafe` .
Бид үүнийг шийдсэн арга нь
ашиглаж эргэлздэг **хүчирхэг** `repr(C)` төрөл бүрийн.

::: info

Зөвхөн тодруулагчид л ялж байна.
дэлхийн хэмжээнд хэрэгжиж байгаа тул түүхий эдийг илтгэх (ихэнх үедээ) зөвхөн онцгой тохиолдолд ашигладаг
Бид бараг бүх тохиолдлын хүрээнд
төдийлөн Iroha Мэдээллийн загвар, та түүхий эдийг ашиглах хэрэггүй
Бүх зүйл.

:::

## Жишээлбэл {#example}

Энэ нь холболт үүсгэх жишээ юм:

```rust
#[derive(FfiType)]
struct DaysSinceEquinox(u32);

#[ffi_export]
impl DaysSinceEquinox {
    pub fn update_value(&mut self, a: &u8) {
        self.0 = *a as u32;
    }
}
```

Дээрх жишээ нь дараах холбоог үүсгэх болно
`DaysSinceEquinox` нэвтрүүлэгний тодруулагч:

```rust
pub extern fn DaysSinceEquinox__update_value(handle: *mut DaysSinceEquinox, a: *const u8) -> FfiReturn {
    // function implementation
}
```

## FFI Төгсгөлтэй үе {#ffi-binding-generation}

Хөдөлмөрийн `iroha_ffi` crate нь дамжуулан дуудлагдах функцыудыг үүсгэхэд ашиглагддаг
FFI. Үргэлт `Rust` Уул уурхайн салбарт үйл ажиллагаа явуулдаг `unsafe` код нь
Та холбоо баригч хязгаарыг даван туулахын тулд хэрэгтэй болно.

А Rust төрөл нь баттай `repr(C)` Энэ нь
FFI хязгаартай `FfiType::into_ffi`. Энэ нь эсрэгээр явагдаж байна
Эцэст нь хэлэхэд: FFI `ReprC` төрөл нь а `Rust` түвшин
`FfiType::try_from_ffi`.

::: warning

Бусад хэлбэлзэл нь алдаатай бөгөөд тодорхойгүй шалтгаан үүсгэх боломжтой гэдгийг анхаарна уу.
Бид хамгийн ил тод байдлыг салахын тулд чадах бүхнээ хийж чадна.
алдаатай бол програм нь зөв байх ёстой.

:::

The Зөгнөлийн үйлдвэрлэлийг боломжуулдаг үндсэн шинж чанар нь `ReprC`, `FfiType`, болон
`FfiConvert`.

| Хууль зүйн шинж чанар        | Тодруулга                                                                                                                                                                     |
| ------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `ReprC`      | Энэ шинж чанар нь C-д нийцсэн хүчирхэг хэлбэр ABI. Тус төрөл нь аюулгүйгаар хуваагдаж болно FFI Чингис.                                                                |
| `FfiType`    | Энэ шинж чанар нь холбогдох `ReprC` тухайн төрлийн `Rust` төрөл: тодорхойлсон `ReprC` төрөл нь `Rust` түрүүнд API үйлдвэрлэсэн FFI үйл ажиллагаа. |
| `FfiConvert` | Энэ шинж чанар нь хоёр арга барилыг тодорхойлдог `into_ffi` болон `try_from_ffi` Хөдөлмөрийн эргэлт хийхэд ашигладаг `Rust` төстэй `ReprC` Үргэлж.                                |

Үүнд эзэмшлийн шилжүүлэн суурьлах FFI үл ил тод үзүүлэлтээс бусад
бусад бүх төрлийн эзэмшилд ордог, жишээ нь: `Vec<T>`, Клонолж байна.

### Нэр Манглинг {#name-mangling}

Нүүр хуудас FFI эд зүйлс:

- Үүнээс өмнө `inherent_fn` Үндсэн хуулийн `StructName` Төрийн байгуулалтын байгууллага FFI
  нэр нь `StructName__inherent_fn`.
- Үүнээс өмнө `MethodName` УИХ-ын гишүүн `TraitName` тавилга
  `StructName` Төрийн байгуулалтын байгууллага FFI нэр нь
  `StructName__TraitName__MethodName`.
- Уулзалтын `field_name` талбайд `StructName` Төрийн байгуулалтын байгууллага FFI
  функцын нэр нь `StructName__set_field_name`.
- Энэ нь `field_name` талбайд `StructName` Төрийн байгуулалтын байгууллага FFI
  функцын нэр нь `StructName__field_name`.
- Үргэлттэй зүйлсийг авахын тулд `field_name` талбайд `StructName` Төрийн байгуулалтын байгууллага FFI
  функцын нэр нь `StrucuName__field_name_mut`.
- Эрх чөлөөтэй иргэдийн хувьд `module_name::fn_name`, УИХ-ын гишүүн FFI нэр нь
  `module_name::__fn_name`.
- Үргэлжгүй, хуваалцах боломжийг олгодог шинж чанарууд
  хэрэгжүүлэх FFI (цаах) `Clone` доор), FFI нэр нь
  `module_name::__clone`.

  ```rust
  impl Clone for Type1 {
      fn clone(&self) -> Self;
  }
  impl Clone for Type2 {
      fn clone(&self) -> Self;
  }
  ```
