# Нөхцөл байдлын матриц {#compatibility-matrix}

Нөхцөл байдлын матриц нь...SDK одоогийн нөхцөл байдлын талаарх Iroha 3 Документийн багц. Үндсэнээр, хуудас нь pinned-ээс үүсгэгдсэн снэп-шоутыг [`hyperledger-iroha/iroha`](https://github.com/hyperledger-iroha/iroha) шинэчлэл.

Матрица нь дараахьээс бүрдэнэ:

- Эхний багана дахь түүхүүд
- SDKs үлдсэн түвшний дагуу
- Тагнуулсан, алдаатай болон алдагдаагүй мэдээллийн статусын тэмдэгүүд

Шинэчлэлтийн ажлын урсгалаар баталгаажуулсан үр дүнг л хамрагдсан эсвэл алдаатай гэж мэдээлдэг. Төгссөн өөрчлөлтийн баримтгүй нөхцөл байдал нь өөр эх үүсвэрийн өөрчлөлтийн үр дүнг эзэмшүүлэхээс илүү дутагдаж байгаа өгөгдлийг харуулна.
