# Тохиромжийн Матриц {#compatibility-matrix}

Тохирох чадлын матриц нь хөндлөнг харуулдаг SDK одоогийн нөхцөл байдлын хамрах хүрээ Iroha 3 баримт бичиг тохируулагдсан. Анхны байдлаар хуудас нь наалттайгаас үүссэн багцалсан цаг үеийн өгөгдөл үзэлтийг ачаалдаг [`hyperledger-iroha/iroha`](https://github.com/hyperledger-iroha/iroha) засвар

Матриц нь дараах зүйлсээс бүрдэнэ:

- Эхний баган дахь түүхүүд
- SDKs үлдсэн баганануудад дамнан
- Хамгаалагдсан, амжилтгүй болсон, алга болсон өгөгдлийн төлөвийн тэмдэг

Зөвхөн шинэчлэх ажлын урсгалд батлагдсан үр дүнг хамарсан эсвэл бүтэлгүй болсон гэж мэдээлдэг. Тогтоосон хувилбарын нотлох баримтгүй тохиолдлуудыг өөр эх хувилбараас үр дүнг өвлөн авахын оронд мэдээлэлгүй гэж үзүүлдэг.
