# Уулзалтын нэр {#naming-conventions}

Хэтгэл, домен, эд хөрөнгийг нэрлэх үед анхаарах хэрэгтэй
дараах конвенциуд Iroha:

1. Тодорхой зориулалтаар ашигладаг хэд хэдэн тусгайлан
   барилга байгууламжийн төрөл:

   - `@` бүртгэлийн нууц нэр болон тодорхой хэмжээний бүртгэл/говийн ач холбогдол бүхий хэлбэрт зориулагдсан
   - `#` хөрөнгийн тодорхойлолт, хөрөнгө тэнцвэрт санхүүжилтийн нууцаар зориулагдсан
   - `::` гэрээний нууц нэрээр зориулагдсан
   - `.` домен, мэдээллийн орон зайг шалгах зорилгоор тусгагдсан
   - `$` цахилгаан хэрэглэгчид зориулсан бичгийн хэлбэрээр зориулагдсан
   - `%` баталгаажуулагчийн дугаарлалтай текст хэлбэрт зориулсан

2. Хамгийн их тооны тэмдэг (шууны дотор UTF-8 тэмдэг) нэр нь
   2 хүчин зүйлээр хязгаарлагдана: `[0, u32::MAX]` болон одоогийн
   Багасан орон зайг хуваарилах.

## Та үүнийг туршиж үзээрэй. Taira {#try-it-on-taira}

Төрийн хөрөнгийн алиасыг хуулийн хөрөнгийн тодорхойлолтоор оруулна ID:

```bash
curl -fsS https://taira.sora.org/v1/assets/aliases/resolve \
  -H 'content-type: application/json' \
  -d '{"alias":"usd#wonderland"}' \
  | jq '{alias, asset_definition_id, asset_name, status: .alias_binding.status}'
```

Үүнийг хөрөнгийн тодорхойлолтын жагсаалттай харьцуул:

```bash
curl -fsS 'https://taira.sora.org/v1/assets/definitions?limit=20' \
  | jq -r '.items[] | select(.alias != null) | [.alias, .id, .name] | @tsv'
```

Хөдөлмөрийн `#` Характер нь доменийн хүрээлэнгээс хөрөнгийн нууц нэрийг ангижруулдаг
Хэрэв та санаачлан хөрөнгө буюу хөрөнгийн нууц нэрийг бичиж байгаа бол
Тодорхой тэнцвэртэй.
