# Бага хурлын нэр {#naming-conventions}

Та Iroha -д ашигладаг дараах конвенциудыг санаж, данс, домен эсвэл хөрөнгийг нэрлэх үед:

1. Тухайн бүтээн байгуулалтын тодорхой төрөлд хэрэглэгддэг хэд хэдэн тусгайлан тусгасан хуваагч байдаг:

   - `@` бүртгэлийн нууц нэр болон тодорхой хэмжээний бүртгэл / олон нийтийн ач холбогдол бүхий бланк ашиглах боломжтой
   - `#` хөрөнгийн тодорхойлолт, хөрөнгийн тэнцвэрний утга зохиолд зориулагдсан.
   - `::` гэрээний нууц үсэгт зориулагдсан
   - `.` домен болон өгөгдлийн орон зайн шалгаруулалтад зориулсан
   - `$` цахилгаан хэрэглэгчдэд зориулсан бичгийн хэлбэр
   - `%` баталгаажуулагчийн дугаарлалтай текст хэлбэрт зориулсан

2. Нэг нэр нь UTF-8 гэсэн үсгүүрийн хамгийн их тоог хоёр хүчин зүйлээр хязгаарлагдана: `[0, u32::MAX]` болон одоогоор хуваарилсан багтрын орон зай.

## Taira дээр туршиж үзээрэй. {#try-it-on-taira}

Төрийн өмчит хөрөнгийн нэрэмжит тодорхойлолт ID -д нэвтрүүлнэ

```bash
curl -fsS https://taira.sora.org/v1/assets/aliases/resolve \
  -H 'content-type: application/json' \
  -d '{"alias":"usd#wonderland"}' \
  | jq '{alias, asset_definition_id, asset_name, status: .alias_binding.status}'
```

Үүнийг хөрөнгийн тодорхойлолтын жагсаалттай харьцуулаарай:

```bash
curl -fsS 'https://taira.sora.org/v1/assets/definitions?limit=20' \
  | jq -r '.items[] | select(.alias != null) | [.alias, .id, .name] | @tsv'
```

`#` шинж тэмдэг нь хөрөнгийн нууц нэрийг доменийн хүрээлэнгээс ангижруулдаг. Хэрэв та санаатайгаар хөрөнгийн алиас эсвэл хөрөнгийн тэнцвэрийг утгаараа бичихгүй бол энгийн нэрүүдээс зайлсхийх хэрэгтэй.
