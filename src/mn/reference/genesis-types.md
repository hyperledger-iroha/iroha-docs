# Генезисийн төрлүүд {#genesis-types}

Генезисийн манифест нь [`RawGenesisTransaction`](#rawgenesistransaction)-ийн JSON хэлбэр юм. Энэ лавлагаа тухайн төрөл болон түүнд агуулагдах бүх төрлийг жагсаадаг бөгөөд Iroha-гийн бэхэлсэн эх кодоос үүсгэсэн. Бүртгэлийн дэвтрийн бүх төрлийг [өгөгдлийн загварын схем](/mn/reference/data-model-schema.md)-ийн лавлагаанд тайлбарласны дагуу өөрийн зангилааны схемээс авна уу.
