# Torii Хөгжлийн чиглэл {#torii-endpoints}

Torii Энэ бол HTTP, SSE, болон WebSocket нэвтрүүлэг Iroha 3. Энэ нь хоёулаа хэрэглэдэг.
номын сан руу чиглэсэн APIs болон операторын төгсгөлд.

Одоогийн протоколын дүрэм нь:

- Каноникийн хошой формат нь **Norito**
- олон төгсгөл нь ч дэмждэг JSON та илгээх үед `Accept: application/json`
- метрик нь Prometheus хэлбэрээр илрүүлнэ

Формат, агуулгын хэлэлцээр, зохион байгуулалтын тэмдэг, схемын хэшүүд
Norito RPC удирдамж, [Norito дуудлага](/mn/reference/norito.md).

## Амьдрал хий Taira Замын хөдөлгөөн {#try-live-taira-routes}

Олон нийт Taira шинжилгээний сүлжээ нь ижил Torii JSON хэрэглээний давхарт
Хэрэглэгчид зөвхөн уншигч хайгуулын тулд ашигладаг. Эдгээр команд нь зай шаарддаггүй:

```bash
TAIRA_ROOT=https://taira.sora.org

curl -fsS "$TAIRA_ROOT/status" \
  | jq '{blocks, txs_approved, txs_rejected, queue_size, peers}'

curl -fsS "$TAIRA_ROOT/openapi.json" \
  | jq -r '.paths | keys[]' \
  | grep '^/v1/' \
  | head -n 20

curl -fsS "$TAIRA_ROOT/v1/node/capabilities" \
  | jq '{abi_version, data_model_version, query: .query.aggregate.supported_resources}'
```

Дэлхийн өнөөгийн нөхцөл байдлын эсрэг ресурс уншдаг:

```bash
curl -fsS "$TAIRA_ROOT/v1/domains?limit=5" \
  | jq -r '.items[].id'

curl -fsS "$TAIRA_ROOT/v1/assets/definitions?limit=5" \
  | jq -r '.items[] | [.id, .name, .total_quantity] | @tsv'
```

Олон нийтийн тест сүлжээний замыг эргэн шилжүүлсэн тохиолдолд `502`, цагийн хугацаа нь дуусч, эсвэл дүүрэн
түвшний хэсгийг хангахын тулд дараа нь дахин туршиж үзээрэй
Хэрэглэгчийн кодгоо татаж байна.

`pacs.008` илтгэл нь мэдээллийг хүргэх ёстой ID, банк хоорондын тохиргоо
хэмжээ, мөнгөн тэмдэгт, шийдвэрлэлийн өдөр, өрийн төлөгч болон итгэмжлэгч IBANs, болон өрийн төлөгч,
зээл олгогч BICs. Сэтгэцийн өгөгдлийг конфигуруулбал, гүүр нь мөн
BIC, IBAN, болон ISO 4217 валютын хилжилт үүссэн гүйлгээний өмнө
Хөгжлийн урсгалд орж байна.

`pacs.009` өргөн мэдүүлэг нь бизнесийн мэдээллийг хүргэх ёстой ID, мэдээний тодорхойлолт

сургалтын ажилтан BICs, болон өрийн төлөгч, зээл олгогч IBANs. Хэрэв
мэдээллийг багтаасан `Purp`, гүүр одоогоор үнэт цаасны зориулалттай санхүүжилтийг хүлээн авдаг
зөвхөн: `Purp=SECU`.

Хөдөлмөрийн `pacs.008` болон `pacs.009` өргөн мэдүүлэх эцсийн цэгүүд хүлээн зөвшөөрдөг XML ISO хуудас,
гүүрний туршилтын үеэр ашигласан талбайн формат. `SplmtryData` талбар
зорилгоо тавих боломжтой Iroha томоохон бүртгэл, эх үүсвэр болон зорилтот данс IDs эсвэл хаяг,
болон хөрөнгийн тодорхойлолт ID. Хариулт нь: `202 Accepted` хамтран `message_id`,
`transaction_hash`, `status`, `pacs002_code`, болон шийдвэрлэсэн
томоохон бүртгэл/хуульт/хөнгөн хөрөнгийн хүрээнд.

### Өндөр шинжилгээний болон газрын зурагчлалын дэмжлэг {#additional-parser-and-mapping-support}

Хөдөлмөрийн IVM ISO туслах нь мөн дараах мэдээг баталгаажуулж, биелүүлнэ
гэр бүлдээ баталгаажуулах, тосгоны зурагчлалт хийх эсвэл урсгалын дүнд зориулсан
Тэдэнд бие даасан Torii Залуудыг.

| Мэдээллийн гэр бүл | Одоогийн дэмжлэг |
| --- | --- |
| `head.001` | Бизнес өргөдлийн цолны баталгаажуулалт ISO бүрэлдэхүүнтэй, `BizMsgIdr`, `MsgDefIdr`, Бүтээгдэхүүний цаг хугацаа, сонголттой дамжуулагч/ хүлээн авагч BIC талбар |
| `pacs.007`, `pacs.028`, `pacs.029` | Төлбөрийн эргэлт, нөхцөл байдлын хүсэлтийг хангах, шалгалтын шийдвэрлэлтийн/хүний байдлын шинжилгээ хийх |
| `pain.001`, `pain.002` | Хэрэглэгчийн төлбөрийг эхлүүлэх, төлбөрийн байдлын тайланг баталгаажуулах |
| `camt.052`, `camt.053`, `camt.054` | Санхүүжилтийн тайлан, мэдүүлэг, мэдэгдэл батлах |

## Kaigi Хурлын хуралдаан {#kaigi-sessions}

Kaigi төлбөртэй, бодит цаг хугацааны аудио/видео өрөөнүүд SORA Nexus. Хэрэглэж болно
Хэрэглээний бүртгэлд дэмжлэг үзүүлэх сессийг бий болгох, жагсаалтыг өөрчлөх, дамжуулах шаардлагатай
нэвтрүүлэг, шифрлэгдсэн сигналын болон хэрэглээний хэмжилтийг хадгалахын оронд бүх
Төрийн дотоод зах зээлээс гадна зөвлөлдөх.

Тодруулгын бүртгэлтэй амьдралын мөчлөг нь:

- `CreateKaigi`: домен дор дуудлага гаргаж, түүний бодлогыг хадгалах;
  хуваарь, метабарууд болон сонголттой ээлжит манфист.
- `JoinKaigi` болон `LeaveKaigi`: Зудлагын жагсаалтыг шинэчлэх.
  оролцогчид үүрэг, хүчингүй болгох болон жагсаалтын баталгааг ашигладаг
  хувьцаа эзэмшигчдийн тооцоо IDs шууд.
- `RecordKaigiUsage`: хэмжүүлсэн хугацаа, газын нийт хэмжээг нэмнэ.
- `EndKaigi`: Уулзалтыг хааж, эцсийн цаг мөрийг бичнэ.

Torii Relay телеметрийг `/v1/kaigi/relays`,
`/v1/kaigi/relays/{relay_id}`, `/v1/kaigi/relays/health`, болон
`/v1/kaigi/relays/events` хэрэгсэл API телеметрийн функцүүд ашиглагдаж байна.
Хурлын нөхцөл байдал нь Kaigi domain үйл явдлууд
`KaigiRosterSummary`, `KaigiRelayManifestUpdated`,
`KaigiRelayHealthUpdated`, болон `KaigiUsageSummary`.

### CLI Түтгэрийн туршилтаар {#cli-smoke-test}

Энэ нь: `iroha kaigi` CLI Хэрэв та Torii эцсийн цэг
хүлээн зөвшөөрдөг Kaigi арилжаа UI. Удахгүй эхлэх команд
идэвхтэй Torii эцсийн тойм болон товчлогыг хэвлэх
дуудлагын тодруулгын дагуу командтай нэгдсэн, SoraNet Сүлжүүлэгч:

```bash
iroha kaigi quickstart --auto-join-host --summary-out kaigi-summary.json
```

Скриптийн урсгалын хувьд өрөөний амьдралын мөрийг тодорхой удирдах:

```bash
iroha kaigi create \
  --domain streaming \
  --call-name daily \
  --host <i105-account-id> \
  --privacy-mode transparent \
  --room-policy authenticated

iroha kaigi join --domain streaming --call-name daily --participant <i105-account-id>
iroha kaigi leave --domain streaming --call-name daily --participant <i105-account-id>

iroha kaigi record-usage \
  --domain streaming \
  --call-name daily \
  --duration-ms 120000 \
  --billed-gas 1500

iroha kaigi end --domain streaming --call-name daily
```

Хэрэглээ `--room-policy public` үзэгчгүйгээр дамжуулалт нь илрүүлэх боломжтой өрөөнд зориулсан
тавилга, эсвэл `--room-policy authenticated` гарч ирэхэд үзэгч шаарддаг
баталгаажуулах. `--privacy-mode zk-roster-v1` Зөвхөн сүлжээ
УИХ-ын гишүүн Kaigi жагсаалт, хэрэглээний баталгаажуулах түлхүүр тохируулсан; өөрөөр хэлбэл холболт, хуудас,
болон хувийн хэрэглээний бүртгэл нь тодорхойлолтын шалгалтын үеэр алдаатай байна.

### Эрдэм шинжилгээ JavaScript Тэмцээн {#testing-with-the-javascript-demo}

Хөдөлмөрийн
[soramitsu/iroha-demo-javascript](https://github.com/soramitsu/iroha-demo-javascript)
Desktop Demo нь Electron болон Vue
шууд хандах хэрэглээ Torii орон нутгийн `@iroha/iroha-js`
хамааралтай бөгөөд `/kaigi` Бrowser-native one-to-one хэвлэл мэдээллийн чиглэлийг.

Demo-ийг ашигла
[`@iroha/iroha-js`](https://github.com/hyperledger-iroha/iroha/tree/main/javascript/iroha_js)
УИХ-ын Iroha Эх сурвалжийн хадгаламж SDK дамжуулан
`file:../iroha/javascript/iroha_js`, Тиймээс энэ ах дүүгийн хоёр төлбөрийг хадгалах
зураг:

```bash
mkdir iroha-wallet-workspace
cd iroha-wallet-workspace
git clone https://github.com/hyperledger-iroha/iroha.git
git clone https://github.com/soramitsu/iroha-demo-javascript.git

cd iroha/javascript/iroha_js
npm install
npm run build:native
npm run build:dist

cd ../../../iroha-demo-javascript
npm install
npm run dev
```

Хэрэглээ Node.js 20 болон шинэ, Rust тоног төхөөрөмж зангилаа нь `iroha_js_host`
модулийг барьж болно. SDK ах дүүгийн хувьд Iroha өөрчлөлтийн дараа төлөх
эх үүсвэр; цэвэр багцын зураг төсөлд ачааны ажлын орон зай байхгүй
шаардлагатай `npm run build:native`.

Хяналтын шинжилгээний хувьд демонстраныг Kaigi-Шилдэг хүн Torii төгсгөл:

1. Сургууль эхлүүлнэ Iroha сэлбэг SORA/Kaigi хэрэгсэл рүү чиглэсэн APIs ашиглах боломжтой, эсвэл
   олон нийтийн төгсгөлийг илрүүлэх Kaigi Хэрэгжүүлэх түвшин.
2. Үндэсний хүртээмжтэй байдлыг шалгах `/health`, Дараа нь амьд замын гадаргуурыг шалгаарай
   хамтран `/openapi` эсвэл `/openapi.json`. Зарим ажиллагаанд бас
   `/v1/health`, Гэхдээ `/health` Энэ бол гар утасны амьжиргааны шалгалт.
3. Үүнд: TAIRA, шууд уулзалт хийхээс өмнө ээлжит телеметрийн замыг шалгах:

   ```bash
   TAIRA=https://taira.sora.org
   curl -fsS "$TAIRA/health"
   curl -fsS "$TAIRA/v1/kaigi/relays"
   curl -fsS "$TAIRA/v1/kaigi/relays/health"
   ```

   Эдгээр шалгалтууд нь Torii болон Kaigi Рэле телеметрийн хэрэгслийг ашиглах боломжтой.
   уулзалт байгуулахгүй байх; `CreateKaigi` болон `JoinKaigi` алиг ч санхүүжилт хэрэгтэй
   хөрөнгийн санхүүжилт, гарын үсэг зурсан гүйлгээний мэдүүлэг.
4. Демо нээгээд, **Байгаль**, тодотгож Torii URL, хэрэгслийг борлуулах
   зангилаа ID болон сүлжээний префикс нь төгсгөлөөс.
5. Өргөдлийн хувилбарт хоёр орон нутгийн мөнгөний санг бий болгох эсвэл сэргээх.
   Profiles, эсвэл машин тул хөтлөгч болон зочид буудлын бие даасан мөнгөн тэмдэгтийн байдалтай.

Энэ нь Kaigi UI:

1. Үйлчлүүлэгч дэлгэцэнд нээлттэй **Kaigi**, сонгох **Хурал эхэлнэ**, нэр дэвшүүлэг тогтоож,
   сонгож **Хувийн урилга** эсвэл **Ил тод урилга**.
2. Сонгон уу **Камера болон микрофонг идэвхжүүлнэ** Тиймээс WebRTC орон нутгийн хэвлэл мэдээллийн хэрэгсэлтэй.
3. Сонгон уу **Уулзалтын холбоог бий болгох**. Амьдралтын мөнгөн тэмдэгт `CreateKaigi`; УИХ-ын гишүүн
   цахим хуудас дараа нь `iroha://kaigi/join?call=...&secret=...` урьж,
   `#/kaigi?...` Хурдан буцах замыг.
4. Зохиоллын цонх нээлттэй байлгаж, зочтой хуваалцаарай.
5. Золуулагчны цонхид уриалтыг нээж, эсвэл тавиад **Хуралдаанд оролцох**, эргэлт
   орон нутгийн хэвлэл мэдээллийн хэрэгслээр, сонгож **Хуралдаанд оролцох**. Амьдралтай мөнгөөр
   Хэвлэл мэдээллийн хэрэгслийн нээлт Torii болон өргөн мэдүүлнэ `JoinKaigi` шифрлэгдсэн
   Мэдээлэл мэдээлэл хариулъя.
6. Үйлчлөгч нь эхний хариултыг шууд дамжуулан эсвэл санал асуулга явуулж хэрэглэх ёстой Kaigi
   дуудлагын сигнал. Хоёр цонх нь холбогдсон хэвлэл мэдээллийн хэрэгсэл болон шинэчилсэн
   холбооны дэлгэрэнгүй мэдээлэл.
7. Хэвлэлийн хөтөчээс суудал дуусгах, эсвэл CLI `iroha kaigi end` команд
   ижил дуудлага ID.

Хувь хүн Kaigi хамгаалалттай хэрэгцээ XOR хувийн нэвтрүүлгийн цэгт төлбөр тооцох.
demo тайлангаар хувийн Kaigi хамгаалалттай хэрэгцээ XOR, хэрэглээнд орсон
Өөрөө хамгаалах нь авчирч, бүтээх эсвэл нэгдсэн үйлдлийг дахин туршиж үзнэ.
хувийн санхүүжилт, эсвэл амьд сигнал нь байхгүй бол демо
ил тод/лэлгээний урсгал. Энэ тохиолдолд нээлттэй **Өргөтсөн сигнал өгөх**, хувилбар
түүхий санал эсвэл хариултын багц, нөгөө дэлгэц рүү тавих.

Demo repo-д автомат шалгалтын хувьд:

```bash
npm test -- tests/kaigiView.spec.ts tests/preloadKaigiBridge.spec.ts
npm run e2e:ui
npm run verify
```

"Витест" цогцолборын хуудас Kaigi уулзалтын холбоосыг бий болгох, компакт урилга
ачаалал, хувийн үүсгэх/сэргэлжих/хамсарлах шугамны дуудлага, өөрөө хамгаалах илтгэлийг, гарын авлага
Хөгжлийн хяналт тавих, санал асуулга хариулах. UI төмөр шинжилгээ нь `/kaigi` зам
Desktop болон гар утасны хэмжээний үзэгчдийн.
хөтөч камер/микрофонны зөвшөөрөлтэй тул хоёр ширээний дасан зохицуулалтын туршилт хэрэгтэй
Хэвлэл мэдээллийн урсгал нь байгаль орчинд тодорхой байдаг.

## Орчин байдал, үзүүлэлт {#status-and-metrics}

Статус болон метрикийн төгсгөл нь хамгийн түрүүнд дашборд руу холбогддог:

- `/status` дээд түвшний хамтарч, блок, шуурхай, тохиролцооны талбайг илрүүлнэ
- `/metrics` Prometheus-ийн тооллого, хэмжээнүүд, хистограммыг илрүүлнэ

Үүнд Nexus-Эрдэнэт үйлдвэрийн үйл ажиллагааг явуулж байгаа цэгүүд, статусын үр дүн нь мөн замын хөдөлгөөн болон мэдээллийн орон зайны талаар мэддэг
Үргэлт, `nexus.enabled = false`, Эдгээр хэсгүүд орхигджээ.

## JSON Х. Norito {#json-vs-norito}

Олон оператортын төгсгөлийн цэг эргэн ирнэ Norito Үндсэн цэг нь дэмждэг бол
JSON, ирүүлнэ:

```http
Accept: application/json
```

Энэ нь:

- `/v1/sumeragi/status`
- `/v1/sumeragi/qc`
- `/v1/sumeragi/commit_qc/{hash}`

Хөгжлийн төслийг хүлээн зөвшөөрч эсвэл түргэн өглөө Norito шууд, ашиглах
`application/x-norito` агуулгын төрөл болон сонгогдсон `Accept` үнэ цэнэ.
[Norito](/mn/reference/norito.md#torii-and-norito-rpc) тээврийн дэлгэрэнгүй мэдээллийг.
