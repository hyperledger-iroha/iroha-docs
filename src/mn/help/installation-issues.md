## Удахгүй шалгах {#quick-checks}

Ихэнх байгууламжийн алдаа нь дөрвөн байршлаас нэгээс үүдэлтэй:

- а Rust хэрэгслийн сүлжээ нь өмнөд хэсгийн ажлын орон зайд багтагдсан хувилбараас эрт байдаг
- `cargo` эсвэл `rustc` өөр төхөөрөмжтэй `rustup`
- системийн бүтээн байгуулалтын хэрэгсэл, жишээ нь C компилятор, `pkg-config`, эсвэл CMake
- эх үүсвэрийг өөрчлөсний дараа устаган үйлдвэрлэсэн үзэгдэл эсвэл орон нутгийн бүтээн байгуулалтын артефактууд

### Хяналт шалгах Rust хувилбар {#check-rust-version}

Таны болон бидний эрүүл мэндийг хадгалахын тулд та
зөв хувилбартай `cargo` зөв хувилбартай `rustc`.
Одоогийн томоохон ажлын орон зай `rust-version = "1.92"` болон сэлэнг
хэрэгслийн сүлжээний канал `rust-toolchain.toml`. Үргэлжүүдийг харуулж,

```bash
$ cargo -V
$ cargo 1.93.1 (...)
```

Дараа нь

```bash
$ rustc --version
$ rustc 1.93.1 (...)
```

Хэрэв та илүү өндөр хувилбартай бол зүгээр.
дараах командыг ашиглаж, шинэчлэх боломжтой:

```bash
$ rustup toolchain update stable
```

### Нэвтрүүлгийн байршлыг шалгах {#check-installation-location}

Хэрэв та бага хувилбарын дугаар авах бол **болон** та хэрэгслийн сүлжээг шинэчилсэн бөгөөд
ажилгүй байсан... зүгээр л энэ нь нийтлэг асуудал гэж хэлэхэд, гэхдээ энэ нь
Хамтын шийдэл.

Нэгдүгээрт, та ашиглаж буй хувилбарыг хаана байгааг тодорхойлох хэрэгтэй
Нэмэлт:

```bash
$ rustup which rustc
$ rustup which cargo
```

Хэрэглэгчийн хэрэгслийн сүлжээний инсталляцыуд _ихэвчлэн_ .д
`~/.rustup/toolchains/stable-*/bin/`. Хэрэв тийм бол та
гүйх чадвартай

```bash
$ rustup toolchain update stable
```

Энэ нь таны асуудлыг шийдэх ёстой.

### Хууль зүйн хэсгийг шалгана Rust хувилбар {#check-the-default-rust-version}

Өөр нэг сонголт бол та хамгийн сүүлийн үеийн `stable` хэрэгслийн сүлжээ, гэхдээ энэ
түлхүүрээр тохируулдаггүй.

```bash
$ rustup default stable
```

Хэрэв та `nightly` хувьсгал, эсвэл тодорхой
Rust Верзийг нэвтрүүлэхийг мартсан.

### Бусад нь байгаа эсэхийг шалгаарай Rust хувилбар {#check-if-there-are-other-rust-versions}

Үргэлжүүлэн шувууны нүх рүү үргэлжлүүлэн явж, бид шаргуутай байж болно

```bash

```

Хэрэв эдгээр нь гүйлтийн үеэр харсангаас өөр байршлын талаар заасан бол
`rustup which *`, Энэ нь хангалттай биш гэдгийг анхаараарай.
зүгээр л

```bash
$ alias rustc "~/.rustup/toolchains/stable-*/bin/rustc"
$ alias cargo "~/.rustup/toolchains/stable-*/bin/cargo"
```

Хоёр дахь нь системийн багц менежер хувилбар болон
Home folder-ийн стандарт байршил
Энэ сургалтын эхэнд.
хуваарилалтын гарын авлага (`apt remove rust`). Хоёрдугаарт:

## Хөгжлийн асуудлыг шийдвэрлэх Python хэрэгслийн сүлжээ {#troubleshooting-python-toolchain}

Хэрэв та Python Дугуйны багц нь [Python үйлчлүүлэгчний тохируулалт](/mn/guide/tutorials/python.md), та дараах алдаатай дурдаж болно:
"Ироха"_Питон-*.whl энэ платформын дээр дэмжлэг үзүүлэх эргэлт биш".

Энэ алдаа нь pip устарагдсан гэсэн үг юм, та үүнийг шинэчлэх хэрэгтэй.
Нэгдүгээрт, таны OS шинэчлэл хийх, системийн шинэчлэлийг гүйцэтгэх.

Хэрэв энэ нь ажиллахгүй бол, та шинэчлэх туршиж болно `pip` Хэрэглэгчийн номын жагсаалтад.

`python -m pip install --upgrade pip`

Энэ талаар анхаараарай `pip` Энэ нь таны гэр бүлийн захиалгаар байрлагдсан. `whereis pip` болон шалгах `/home/username/.local/bin/pip` Хэрэв тийм биш бол шарилгаа шинэчлээрэй. `PATH` хувьчлал.

Хэрэв асуудал үргэлжилсээр байгаа бол [Бидэнтэй холбоо бариарай](/mn/help/) болон үр дүнг мэдүүлнэ.

```
python --version
python3 --version
pip --version
pip3 --version
```
