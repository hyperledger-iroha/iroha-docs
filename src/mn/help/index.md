# Дэмжлэг авах {#receive-support}

Цаг үе өнгөрөх тусам та Iroha-ын талаар бусадтай дэлгэрэнгүй хэлэлцэхийг хүссэн асуултууд гарч ирж магадгүй. Манай нийгэмлэгтэй хурдан холбогдох гурван арга байна: Telegram, Discord, болон GitHub.

Нийгэмлэг харилцаанд [Телеграм](https://t.me/hyperledgeriroha) болон [LF Decentralized Trust Discord](https://discord.gg/hyperledger)-ыг ашигладаг. Төслийн асуултуудад `iroha` сувгийг ашигла.

Эцэст нь, та [GitHub асуудлыг үүсгэх](https://github.com/hyperledger-iroha/iroha/issues/new/choose) хийж болно, энэ нь баримт бичгийг шинэчлэх хүсэлт, үндсэн багруу өгсөн санаа эсвэл олж илрүүлсэн алдаа байсан ч болно.
