# Тархалтын асуудлыг шийдвэрлэх {#troubleshooting-deployment-issues}

Энэ хэсэг нь Iroha 3 шийдлүүдийг суурилуулах үед гарч болох асуудлыг шийдэх зөвлөмжийг санал болгодог. Хэрэв таны тулгарч буй асуудал энд дурдсанаас өөр бол, [Телеграм](https://t.me/hyperledgeriroha)-ээр бидэнтэй холбоо барина уу.

## Үүсгэсэн урлагийн зүйлээс эхэл {#start-with-generated-artifacts}

Орон нутгийн болон туршилтын байршуулалтын хувьд гараар бичсэн сүлжээний хөрш файлуудын оронд Kagami-аас үүсгэсэн бүтээлүүдийг ашиглахыг илүүд үзнэ:

```bash
cargo run --bin kagami -- localnet --peers 4 --out-dir ./localnet
```

Үүсгэсэн директор нь сүлжээний хөршийн тохиргоо, блокчэйн үүсэх материал, эхлүүлэх скриптүүд, мөн Iroha 3 барилгын шугамын README-ийг агуулна.

## сүлжээний хамтрагч эхлэхгүй байна {#peer-does-not-start}

Эдгээр зүйлсийг эхлээд шалгаарай:

- `iroha3d --config <path>` нь сүлжээний хамтрагчийн өөрийн TOML файлыг зааж байна.
- `public_key` ба `private_key` сүлжээний хамилагчийн тохиргоонд адил түлхүүрийн хосод харьяалагдана.
- `genesis.public_key` нь блокчейн генезис гүйлгээг гарын үсэг зурахад ашигласан түлхүүртэй таарч байна.
- баталгаажуулагч зангилааны таних мэдээлэл BLS-Normal түлхүүр ашигладаг бөгөөд `trusted_peers_pop` нь дотоод түлхүүр болон итгэмжлэгдсэн зангилаануудын эзэмшлийн нотолгооны бичлэгийг агуулдаг.
- Torii ба P2P портуудыг аль хэдийн өөр процесс бөглөөгүй байна.
- Kura дэлгүүрийн лавлах нь ижил сүлжээнд харъяалагддаг бөгөөд өөр сүлжээний профилаас хуулбарлагдсангүй.

Даемон нэгээс олон TOML давхаргыг уншиж байгаа үед тохиргооны мөрдлөгийг ашиглана уу:

```bash
cargo run -p irohad --bin iroha3d -- --config ./config.toml --trace-config
```

## Docker ба Бүрдүүлэх {#docker-and-compose}

Нэг эх кодын хувилбараас бүтээсэн хоёртын файлуудаар Docker дээр дөрвөн баталгаажуулагч ажиллуулахдаа [Эхлүүлэх Iroha 3](/mn/get-started/launch-iroha.md) зааврыг дагана уу.

Баталгаажуулагчдын бүртгэлийг харахын тулд багцын лавлахаас `python3 poc.py logs` командыг ажиллуулна уу.

Compose байршуулалт эхлээд дараа нь саатвал daemon логт дараах зүйлийг шалгана:

- зохицохгүй `chain`
- өөр блокчэйн эхлэл транзакц ба техник үзүүлэлтийг ашиглаж буй нэг сүлжээний хөтөч
- контейнерийн сүлжээний дотор л ажилладаг сурталчилсан P2P хаягууд
- blockchain-ийн эх үүсвэрийг дахин үүсгэсний дараа локаль хэмжээ дахин ашиглах

Шинэ эхлэлийн блок ашиглахын тулд зангилааны хадгалах сан хоосон байх ёстой. Ижил сүлжээг дахин эхлүүлэхдээ эхлээд `python3 poc.py down`, дараа нь `python3 poc.py up` командыг ажиллуулна уу. `state/` лавлахыг сүлжээний дөрвөн Docker ботьтой хамт хадгална уу.

## Кубернетес {#kubernetes}

Kubernetes-ийн хувьд, бүх нэгж баталгаажуулагчийг төлөвт суурилсан дэд бүтцийн нэг хэсэг гэж үз.

- тус бүрийн сүлжээний тавьцаалагчид тогтвортой таних түлхүүр болон тогтвортой байнгын эзлэхүүн олго
- бусад сүлжээний холбоотонууд кластерийн доторхоос нь шийдэж чадах P2P хаягуудыг илрүүлэх
- нэвтрүүлэлтэд зориулсан тохиргоо болон genesis файлыг өөрчлөгдөшгүй тохиргоо хэлбэрээр холбоно
- бүх блокчейн генезис эсвэл топологийн өөрчлөлтүүдийг санаатайгаар гаргах, автомат config-map шинэчлэлт шиг биш

Хэрэв под удаа дараа дахин эхэлж байвал, под дахь үүсгэсэн тохиргоог хүлээгдэж буй тохиргоотой харьцуул. [`peer.template.toml`](/mn/reference/peer-config/index.md#template) мөн сүлжээний хамтрагч хуучин мэдээллийг дахин тоглуулаж байгаа эсэхийг шалгана уу Kura өгөгдөл.

## SORA Nexus профайл {#sora-profile}

SORA Nexus, SoraFS эсвэл олон зурвас ашигладаг хувийн болон дотоод Iroha 3 орчинд энэ профайлыг идэвхжүүлж стандарт суурь үйлчилгээг эхлүүлнэ.

```bash
cargo run -p irohad --bin iroha3d -- --config ./config.toml --sora
```

Нэг сүлжээнд байгаа баталгаажуулагчдаар ижил профайлыг тогтмол ашиглаарай.

Олон нийтийн Taira баталгаажуулагчид зориулалтын эхлүүлэх програмыг ашигладаг бөгөөд энэ нь Taira-ийн яг энэ гинжин холбоо, бүртгэл, идэвхгүйжсэн суулгасан-SoraFS хадгалах сан болон ажиллах хугацааны гарын үсэг өгөгчийн профайлыг шаарддаг. Үүнийг эхлүүлэхийн өмнө гаргасан Taira тохиргоог шалгаарай:

```bash
iroha3d_taira --sora \
  --config /etc/iroha/taira/config.toml \
  --check-config
```

Олон нийтийн зүйлийг бүү эхлүүл Taira ерөнхий зориулалтын баталгаажуулагч `iroha3d`; харах [`iroha3d` CLI  лавлагаа ](/mn/reference/iroha3d-cli.md) албадлагын профайлд зориулсан.
