# Хөдөлмөрийн асуудлыг шийдвэрлэх {#troubleshooting-deployment-issues}

Энэ хэсгээс Iroha 3 Хэрэв асуудал үүссэн бол
та эдэлж байгаа зүйл энд тодорхойлдоггүй,
бидэнтэй холбоо бариарай [Телеграм](https://t.me/hyperledgeriroha).

## Барилгын бүтээлүүдээс эхлэнэ {#start-with-generated-artifacts}

Орон нутгийн болон туршилтын хэрэглээнд Kagami оронд
гарын үсэг зурсан ижил төстэй баримтуудаас:

```bash
cargo run --bin kagami -- localnet --build-line iroha3 --peers 4 --out-dir ./localnet
```

Бүтээгдэхүүний захиалгаар ижил хүйстэй холболт, генезис материал, эхлэл
бичиг баримт, README . Iroha 3 Барилгын шугам.

## Хөгжил нь эхлэхгүй {#peer-does-not-start}

Хамгийн түрүүнд эдгээр зүйлсийг шалгаарай:

- `irohad --config <path>` Эдгээрийнх нь оноо TOML Хөгжлийн баримт.
- `public_key` болон `private_key` ижил ач холбогдолтой
  Хосууд.
- `genesis.public_key` Женезис бүтээн байгуулалтын гарын үсэг зурахад ашигласан цөмтэй нийцдэг.
- баталгаажуулагч ижил хүйсийн тодруулгыг ашиглах BLS-Нормол түлхүүр, `trusted_peers_pop`
  орон нутгийн ач холбогдолтой болон итгэмжлэгдсэн хамтын ажиллагааны баримт бичиг эзэмшдэг.
- Газрын тосны Torii болон P2P аль хэдийн өөр үйл явцтай холбогдсонгүй.
- УИХ-ын гишүүн Kura дэлгүүрний захиалгыг ижил зангилааны нэг хэсэгт багтааж,
  бусад сүлжээний профил.

Daemon нь нэгээс дээш уншиж байхад конфигуратын заалтыг ашиглах TOML давхар:

```bash
cargo run --bin irohad -- --config ./config.toml --trace-config
```

## Docker ... {#docker-and-compose}

Одоогийн байдлаар үүсгэн байгуулах Kagami локаль сүлжээний гарааны дагуу команд шугам
аргумент, конфигурацийн файл нь шалгарсан кодтой нийцдэг:

```bash
cargo run --bin kagami -- localnet --build-line iroha3 --peers 4 --out-dir ./localnet
cargo run --bin kagami -- docker --peers 4 --config-dir ./localnet --image hyperledger/iroha:dev --out-file ./localnet/docker-compose.yml --force
docker compose -f ./localnet/docker-compose.yml up
```

Хэрэв Composite-ийн хэрэглээг эхлүүлж, дараа нь зогсоож байвал:

- үл тохиромжтой `chain`
- өөр генезис бүтээн байгуулалт эсвэл манифест ашиглаж байгаа нэг ижил төстэй
- зарласан P2P цорын ганц контейнерны сүлжээний дотор ажилладаг хаяг
- Гениз нөхөн сэргээлтийн дараа орон нутгийн хэмжээний дахин ашиглалт

Шинэ гениз шинжилгээ хийхэд хуучныг устгах Kura сэргээн сурвалжлахын өмнө
Шинэ генизтэй хуучин блок хадгалах нь тоглолт амжилтгүй болно.

## Кубернетис {#kubernetes}

Kubernetes-ийн хувьд тус бүр баталгаажуулагчдыг төрийн бүтэцтэй дэд бүтэц гэж үзээрэй:

- аль алинд нь тогтвортой тодруулгын ач холбогдол, тогтвортой хэвтлийн хэмжээ өгөх
- илрүүлнэ P2P бусад ижил төстэй хүмүүс цуглуултын дотроос шийдэх боломжтой хаяг
- монтаж конфигурац болон генезис файл нь нэвтрүүлэг хийхэд өөрчлөгдөхгүй конфигурациар
- бүх генез болон топологийн өөрчлөлтийг автомат бус
  конфигурацийн газрын зураг шинэчлэл

Хэрэв капсулаг дахин эхлүүлж байгаа бол капсулагийн дүрсэлсэн конфигуралыг
хүлээгдсэн [`peer.template.toml`](/mn/reference/peer-config/index.md#template) болон
дундаж тоглож байгаа эсэхийг шалгаарай Kura мэдээлэл.

## Сорагийн хувилбар {#sora-profile}

Iroha 3 ашиглаж буй хэрэглэгчид Nexus, SoraFS, эсвэл олон замын урсгал эхлэх ёстой
Sora профили бүхий даемон:

```bash
cargo run --bin irohad -- --config ./config.toml --sora
```

Нэг л сүлжээний баталгаажуулагчдын хооронд ижил профилийг тогтмол ашиглах.
