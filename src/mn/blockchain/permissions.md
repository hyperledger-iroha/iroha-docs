## Тусгай зөвшөөрлийн токенүүд {#permission-tokens}

Тусгай зөвшөөрлийн токенүүд нь идэвхтэй гүйцэтгэгчээр тодорхойлсон түрлэгдсэн объектууд юм.
токенүүд нь дэлхийн хэмжээний, жишээ нь `CanManagePeers`, бусад нь а
Тодруулбал, тухайн бүртгэлийн томоохон бүрэлдэхүүнд тооцогдох сан, хөрөнгө, хөрөнгийн тодорхойлолт, домен гэх мэт.
NFT, үүрэг гүйцэтгэх, эсвэл түлхэгч.

Энд олон төрлийн зөвшөөрлийн тэмдэгтүүдэд ашигладаг параметрүүдийн зарим жишээ байна:

- Тухайн дансын метадэтгэлийг өөрчлөх зөвшөөрөл олгодог токен
  тээвэрлэдэг `account` талбар:

  ```json
  {
    "account": "<AccountId>"
  }
  ```

- Тухайн хөрөнгийн хөрөнгийг шилжүүлэх зөвшөөрлийг олгодог токен
  тодорхойлолт нь `asset_definition` талбар:

  ```json
  {
    "asset_definition": "<AssetDefinitionId>"
  }
  ```

- Дэлхийн токен юм `CanManagePeers` ямар ч талбайгүй:

  ```json
  {}
  ```

### Урьдчилсан зөвшөөрлийн токенүүд {#pre-configured-permission-tokens}

Та урьдчилан тохируулсан зөвшөөрлийн токенүүдийн жагсаалтыг [Сэтгэлэг](/mn/reference/permissions) бүлэг.

## Тусгай зөвшөөрлийн бүлэгүүд (роль) {#permission-groups-roles}

Тус зөвшөөрлийн цуврал **үүрэг**. Зөвшөөрлийн тэмдэгтүүдтэй адил,
үүрэг гүйцэтгэгч нь `Grant` заавар өгч, дараах
`Revoke` сургалт.

Ахуйн нэгжэд үүрэг олгохын өмнө тухайн үүргийг эхлээд бүртгэх ёстой.

Олон бүртгэлд ижил зөвшөөрөл авах үед үүрэг нь ашигтай байдаг
нэг удаа үүргийг бүртгэж, тус үүрэгт зөвшөөрөл олгож, дараа нь
хувьчлалын бүртгэлийн үүргийг цуцлах.

### Шинэ үүргийг бүртгүүлэх {#register-a-new-role}

Шинэ үүргийг бүртгүүлэх болно.
Хөдөлмөрийн [металл мэдээлэл](/mn/blockchain/metadata.md) Маусын мэдээллээр:

```rust
let role_id = RoleId::from_str("ACCESS_TO_MOUSE_METADATA")?;
let role = iroha_data_model::role::Role::new(role_id.clone(), mouse_id.clone())
    .add_permission(CanModifyAccountMetadata {
        account: mouse_id.clone(),
    });
let register_role = Register::role(role);
```

### Хөдөлмөрийн үүрэг {#grant-a-role}

Роль бүртгэгдсний дараа, Маус Алисэд олгож болно:

```rust
let grant_role = Grant::account_role(role_id, alice_id);
let grant_role_tx = TransactionBuilder::new(chain_id, mouse_id)
    .with_instructions([grant_role])
    .sign(mouse_private_key);
```

## Тусгай зөвшөөрлийн баталгаажуулагч {#permission-validators}

Зөвшөөрөл байгаа тул зөвхөн зөвшөөрлийн тэмдэгттэй данс
хамгаалалттай үйлдлийг гүйцэтгэх боломжтой.
заавар, хайл, илэрхийлэлийг гүйцэтгэх үед.

Үндсэн хуулийн баталгаажуулагчийн гадаргуу нь номын сангийн талбайгаар бүлэгдсэн:

- Хөгжлийн хяналт
- домен, данс
- хөрөнгө, NFTs, болон хяналт тавих
- гадаргуулагч
- үүрэг, зөвшөөрөл
- гүйцэтгэгч/ажиллах цаг хугацаа, баталгаа, гүүр, SORA/Nexus модуль

Тухайн тэмдэгтийн жагсаалт нь эх үүсвэрээр баталгаажуулсан
[Тусгай зөвшөөрлийн токенүүд](/mn/reference/permissions.md).

### Хөдөлмөрийн цаг хугацааны баталгаажуулагч {#runtime-validators}

Тус зөвшөөрлийн шалгалтыг идэвхтэй гүйцэтгэгч хэрэгжүүлнэ.
гүйцэтгэгч нь зөвшөөрлийн баталгаажуулагч болон тэмдэгтийн тодорхойлолтыг бүрдүүлнэ,
Үүнд хэрэглэгддэг гүйцэтгэгчийг шинэчлэх замаар сүлжээ бодлогыг өөрчлөх боломжтой.

Үнэлгээний баталгаажуулагчид **баталгаажуулах тогтоол**. Багшигч нь
үйл ажиллагаа явуулж байгаа бол түүнийг үгүйсгэхгүй,
Сонгон шалгагдсан шүүгч эдгээр шүүх шийдвэрийг
заавар, асуулт, илэрхийлэл үргэлжлэх эсэхээ шийднэ.
