## Та үүнийг туршиж үзээрэй. Taira {#try-it-on-taira}

Taira зөвхөн уншигч асуултын туслалцааг илрүүлнэ JSON Хамтын нөөцэд зориулж ашиглах
цахим хувилбарыг нэвтрүүлэхээс өмнө SDK:

```bash
TAIRA_ROOT=https://taira.sora.org

curl -fsS "$TAIRA_ROOT/v1/accounts?limit=3" \
  | jq '{total, ids: [.items[].id]}'

curl -fsS "$TAIRA_ROOT/v1/domains?limit=3" \
  | jq '{total, domains: [.items[].id]}'

curl -fsS "$TAIRA_ROOT/v1/assets/definitions?limit=3" \
  | jq '{total, assets: [.items[] | {id, name, total_quantity}]}'
```

Хэрэглээний диагностикийн хувьд эдгээр дулааны хяналтыг гарын үсэг зурсан гүйлгээээс тусгаарлан байлгаарай
шалгалт. Зөвхөн уншигч асуултын алдаа нь ихэнхдээ төгсгөл тосны хүртээмжтэй болохыг харуулдаг,
холбооны хүртээмж, эсвэл гарын үсэг зурагч тохируулалтад хүрэхээс өмнө чиглэлийн нийцүүлэл.

## Судалгааг бий болгох {#create-a-query}

Тэмцээний хайлтын бүтэц ашиглах SDK эсвэл CLI. Жишээлбэл, одоогийн мэдээлэл
загварын илтгэл `FindAccounts` жагсаалтын бүртгэлд бүртгэгдсэн бүртгэлийн:

```rust
let query = FindAccounts;
```

Энд Алисийн эд хөрөнгийг олох асуултын жишээ байна:

```rust
let alice_id = load_canonical_account_id_from_client_config()?;
let query = FindAssetsByAccountId::new(alice_id);
```

## Сайнчилгаа {#pagination}

Ганцхан асуултууд болон жижиг эргэлтийн асуултуудад `client.request`
Та асуултыг хүргэж, үр дүнг нэг удаа авах болно.

Гэсэн хэдий ч, өргөн дахин давтагдах асуултууд `FindAccounts`, `FindAssets`, эсвэл
`FindBlocks` томоохон үр дүнгийн цуврал нь буцааж болно.
Эрдэнэт болон үйлчлүүлэгч.

Нүүр хуудас `Pagination`, та дууддаг байх хэрэгтэй
`client.request_with_pagination(query, pagination)`, . `pagination`
дараах байдлаар бүтэцтэй:

```rust
let starting_result: u32 = _;
let limit: u32 = _;
let pagination = Pagination::new(Some(starting_result), Some(limit));
```
