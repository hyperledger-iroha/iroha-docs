# Асуултууд {#queries}

Үйл явдлын захиалагчид болон шүүлтүүрүүд блокчейн-ийн төлөвийн өөрчлөлтийг дагаж болно. Одоогийн төлөвийг шууд харах хэрэгтэй бол асуулт ашигла.

Асуултууд нь жижиг зааварлаг шинжтэй объектууд юм. Түүний одоогийн дэлхийн байдалын хараанаас дэлгэрэнгүй мэдээлэл авахын тулд нэгийг нь Iroha сүлжээний хэрэглэгч рүү илгээнэ үү.

Сүлжээ нь бусад мэдээллийг ил болгох боломжтой. Асуух боломжтой дэлхийн төлөвийн мэдээлэл нь бүх Iroha сүлжээнд заавал байх ганц төрлийн мэдээлэл юм.

Iroha-ийг оруулсан бүртгэл бүрт бусад боломжит мэдээлэл байж болох юм. Жишээ нь, телеметрийн өгөгдлийн боломж хэвийн байдал нь сүлжээний администраторуудаас хамаарна. Тэдний хийсэн ажлыг хянахын тулд процессорын нөөцийг зарцуулах эсэх нь бүхэллээр тэдний шийдвэр юм, эсвэл үүний оронд бодит ажлыг хийхэд ашиглах эсэхийг. Харин зарим функцууд үргэлж шаардлагатай байдаг, жишээлбэл, дансны үлдэгдэлд хандах боломжтой байх.

Асуулгын үр дүнг нэг дор [эрэмбэлэгдсэн](#sorting), [хуудасласан](#pagination) ба [шүүлтүүрдсэн](#filters) зэрэг хамтын талд харж болно. Эрэмбэлэлт нь мета өгөгдлийн түлхүүрээр үсгийн дарааллаар хийгддэг. Шүүлт хийж болно Төрөл бүрийн зарчмууд дээр үндэслэн, салбар тусгай (жишээ нь хувь хүний IP хаягийн шүүлтүүр маск) болон логик үйлдлээр хослуулсан `begins_with` мэт хэсэг-стрингийн аргуудыг ашигладаг.

## Энэ урсгалыг Taira-д ажиллуулна уу {#try-it-on-taira}

Taira нь нийтлэг нөөц дээрх JSON-ийг уншиж болохуйц асуулгын туслахуудыг ил болгож өгдөг. SDK-ыг холбохоосоо өмнө хуудаслах ба хариу боловсруулах дадлага хийхийн тулд үүнийг ашиглаарай:

```bash
TAIRA_ROOT=https://taira.sora.org

curl -fsS "$TAIRA_ROOT/v1/accounts?limit=3" \
  | jq '{total, ids: [.items[].id]}'

curl -fsS "$TAIRA_ROOT/v1/domains?limit=3" \
  | jq '{total, domains: [.items[].id]}'

curl -fsS "$TAIRA_ROOT/v1/assets/definitions?limit=3" \
  | jq '{total, assets: [.items[] | {id, name, total_quantity}]}'
```

Программын оношлогоонд зориулж эдгээр жижиг шалгалтуудыг гарын үсэг зурсан гүйлгээний туршилтаас тусад нь хадгал. Зөвхөн унших боломжтой лавлагааны алдаа нь ихэвчлэн криптографын гарын үсэг тохиргоог заагахаас өмнө API төгсгөлийн цэгийн боломжит байдал, сүлжээний хандалт, эсвэл маршруттай нийцтэй байдлыг заадаг.

## Шалгалт үүсгэх {#create-a-query}

Төрсөн бичгийн асуулгын бүтээгчийг SDK эсвэл CLI-оос ашиглана уу. Жишээлбэл, одоогийн өгөгдлийн загвар нь дансуудыг жагсаахад `FindAccounts`-ийг ил гаргаж байна:

```rust
let query = FindAccounts;
```

Энд Alice-ийн хөрөнгийг олох асуулгын жишээ байна:

```rust
let alice_id = load_canonical_account_id_from_client_config()?;
let query = FindAssetsByAccountId::new(alice_id);
```

## Хуудаслах {#pagination}

Ганц асуулт ба жижиг давтагдах боломжтой асуултуудын хувьд та `client.request`-г ашиглан асуулт илгээж, үр дүнг нэг дор авч болно.

Гэсэн хэдий ч, `FindAccounts`, `FindAssets`, эсвэл `FindBlocks` гэх мэт өргөн хэвлэж болох асуултууд их хэмжээний үр дүнг буцааж болно. Сүлжээний хамтрагч ба хэрэглэгчийн ачааллыг бууруулахын тулд хуудсуудыг ашигла.

`Pagination`-ыг байгуулахын тулд та `client.request_with_pagination(query, pagination)`-ийг дуудах хэрэгтэй, энд `pagination`-ыг дараах байдлаар байгууладаг:

```rust
let starting_result: u32 = _;
let limit: u32 = _;
let pagination = Pagination::new(Some(starting_result), Some(limit));
```

## Шүүлтүүрүүд {#filters}

Та асуулт үүсгэх үед тодорхойлогдсон шүүлтүүртэй таарсан үр дүнгүүдийг л буцаах шүүлтүүрийг ашиглаж болно.

Шүүлтүүрүүд нь лавлагааны тодорхой хэрэгцээнд зориулагдсан байдаг. Жишээлбэл, дансны лавлагааг дансны таних тэмдэг эсвэл метадатаар нарийлж болох бол, хөрөнгийн лавлагааг хөрөнгөөр нарийлж болно. тодорхойлолт, дансны эзэмшигч, эсвэл домэйн төсөөлөл. Шүүлтүүрийн төрөл асуултын гаралттай тохирч байхын тулд боломжтой бол SDK-ын төрөлжүүлсэн асуулгын бүтээгчийг ашигла.

## Эрэмбэлэх {#sorting}

Iroha нь [метадата](/mn/blockchain/metadata.md)-ийглексикограф хэлбэрээр ангилах боломжтой бөгөөд хэрэв та асуулгыг бүтээх үед ангилах түлхүүрийг өгвөл. Ерөнхий хэрэглээ нь дансанд `registered-on` мета өгөгдлийн бичлэг байх явдал бөгөөд үүнийг ангилсан үед та дансны бүртгэлийн түүхийг харах боломжтой.

Эрэмбэлэлт нь зөвхөн [мета өгөгдөл](/mn/blockchain/metadata.md)-тай бүртгэлд хамаарах бөгөөд мета өгөгдлийн түлхүүр нь асуултын үр дүнг эрэмбэлэхэд ашиглагддаг.

Та ангилалтыг хуудаслах ба шүүлтүүртэй хослуулан ашиглаж болно. Ангилалт нь заавал хэрэглэх шаардлагатай функц биш гэдгийг анхаарна уу, ихэнх хуудаслахтай асуултуудын хувьд энэ шаардлагагүй.
