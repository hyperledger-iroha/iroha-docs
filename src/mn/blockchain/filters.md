# Сэтгэвэл {#filters}

Энэ нь үйл явдлын урсгалыг хязгаарлах, үүсгүүлэх нөхцөл байдлыг филтрлэнэ.
үйл явдлын филтр нь `EventFilterBox`, дараах үйл явдлын гэр бүлд нийцэж болно:

- `Pipeline`
- `Data`
- `Time`
- `ExecuteTrigger`
- `TriggerCompleted`

Ажлын урсгалд нийцсэн хамгийн жижиг филтр ашигла.
`DataEventFilter::Any` диагностикийн хувьд ашигтай боловч тэдгээр нь бүх үйл явдлыг
түлхүүжилтийн зардлыг төлнө.

## Мэдээллийн үйл явдлын филтр {#data-event-filters}

`DataEventFilter` томоохон бүртгэлийн мэдээллийн үйл явдлыг тохируулдаг.

| Үргэлт | Үйл ажиллагааны гэр бүл |
| --- | --- |
| `Any` | Мэдээллийн ямар ч үйл явдал |
| `Peer` | Өмнөх үеийн амьдралын мөрийн үйл явдлууд |
| `Domain` | Доменийн амьдралын мөчлөг, метадангийн үйл явдал |
| `Account` | Акунтын амьдралын мөчлөг, метадэтгэл, нууц үсэг, тодорхойлолтны үйл явдлууд |
| `Asset` | Ашигт малтмалын тэнцвэр, метадангийн үйл явдлууд |
| `AssetDefinition` | Ашигт малтмалын тодорхойлолтын амьдралын мөчлөг, бодлого, метадангийн үйл явдал |
| `Nft` | NFT Амьдралын мөрийн үйл явдлууд болон метабаярууд |
| `Rwa` | Байгалийн амьдралын мөрийн үйл явдлууд |
| `Trigger` | Триггер амьдралын мөчлөг болон метадангийн үйл явдлууд |
| `Role` | Роль амьдралын мөрийн үйл явдал |
| `Configuration` | Захиргааны конфигурацийн үйл явдлууд |
| `Executor` | Хөдөлмөрийн цагийн гүйцэтгэгч үйл явдлууд |
| `Proof` | Дашрамд сануулах амьдралын мөрийн үйл явц |
| `Confidential` | Үндэсний санхүүгийн үйл явц |
| `VerifyingKey` | Хяналтын гол бүртгэлийн үйл явдал |
| `RuntimeUpgrade` | Хөдөлмөрийн цаг хугацааг шинэчлэх үйл явдал |
| `Soradns` | Тогтоолын захиргааны үйл явдлыг шийдвэрлэх |
| `Sorafs` | SoraFS галт тэрэгний нийцүүлэл |
| `SpaceDirectory` | Газрын сүлжээнд амьдралын мөрийн үйл явдлыг илрүүлнэ |
| `Escrow` | Үндэсний хөрөнгийн хадгаламжийн амьдралын мөрийн үйл явдлууд |
| `Offline` | Онлайн төлбөрийн үйл явц |
| `Oracle` | Oracle хангамжийн үйл явдлууд |
| `Social` | Вирусний урамшуулалтын үйл явдлууд |
| `Bridge` | Уулзалтын үйл ажиллагаа |
| `Governance` | Удирдах үйл явдлууд, засаглалын шинж чанар идэвхтэй бол |

Ихэнх бетон филтр нь бас сонголттой ID Үргэлж, үйл явдлын маск.
Жишээлбэл, активын филтр нь нэг актив эсвэл нэг төрлийн актив үйл явдлыг тохируулж болно.
хэрэв хэрэглэгчийн хавсралтын фильтр нь хэрэглэгчийн ID болон үйл явдлын эх үүсвэр.

## Газрын тосны филтр {#pipeline-filters}

Хөрөгдөлний системүүд нь блок, гүйлгээ, нэгтгэх зэрэг боловсруулах үйл явдлуудтай нийцдэг
Хөдөлмөрийн бүртгэл, блок боловсруулах
Дашборд, түлхүүрний мэдээллийн сангаас илүү галт тэрэгний нөхцөлд хариу үйлдэл үзүүлдэг триггер
эд зүйлс.

## Триггер фильтр {#trigger-filters}

Тэггерүүд өөрийн нөхцөл байдлыг `EventFilterBox`. Бас үйл ажиллагааг эхлүүлэх
дэлгүүр:

- гүйцэтгэх боломжтой
- давтамжлах бодлого
- эрх мэдлийн сан
- цаг хугацааг дахин туршиж үзэх бодлого
- металл мэдээлэл

Тэглэмийн авлага нь гүйцэтгэхэд шаардагдах зөвшөөрөлтэй байх ёстой.
Удаан удаан хугацааны туршилт хийхэд зориулсан техникийн тооцоог сайжруулдаг.

## Судалгааны филтр {#query-filters}
