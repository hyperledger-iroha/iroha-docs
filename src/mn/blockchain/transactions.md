# Арилжаа {#transactions}

А **гүйлгээ** блокчейн дээр ажил гүйцэтгэх гарын үсэг зурсан хүсэлт.
Хөдөлмөрийн хэрэгслийг гүйцэтгэх нь
[заавар](./instructions.md), гэрээний дуудлага, IVM байт код, эсвэл
батлагдсан IVM Эрүүгийн хэрэгт холбогдох [Ухаалаг гэрээ](./smart-contracts.md) одоогийн
гэрээг гүйцэтгэх загвар.

Транзакцын үйл ажиллагаа нь нөхцөл байдлыг өөрчлөх эсвэл гүйцэтгэх ажлыг гүйцэтгэдэг.
гарын үсэг зурсан асуултууд эсвэл олон нийтийн уншлын төгсгөлийн цэгүүдийг ашигладаг бөгөөд гүйлгээг бий болгодоггүй.

Зохиогдох блок руу хүлээн зөвшөөрөгдсөн гүйлгээ нь гүйцэтгэлтэй хамт хадгалагддаг
Хөдөлмөрийн хэрэгслийн дэглэмтээс урьдчилан сэргийлэгдэх
зөвшөөрөл, жишээлбэл, хүчингүй хуудас эсвэл шуурхайт татгалзсан гүйлгээ;
нь блок дотор хадгалагдахгүй.

Хувийн байдлыг хадгалах хөрөнгийн хөдөлгөөнийг үзнэ үү
[Аноним бүтээн байгуулалтууд](./anonymous-transactions.md). Аноним
бүтээн байгуулалтад хадгаламжийн санхүүжилт, үүрэг гүйцэтгэл, хүчингүй болсоор тооцдог тэмдэглэлүүд,
Төрийн өмчийн бүртгэлийн тэнцвэрний өөрчлөлтийн оронд нөлөөгөөр мэдлэгийн баталгаа.

Сонгосон ил тод гүйцэтгэх үр дагаврыг баталгаажуулах баримтыг үзнэ үү
[FastPQ](./fastpq.md). FastPQ цаазын гэрчүүдийг хэвийн дараа хэрэглэдэг
гүйлгээний гүйцэтгэл болон дэмжлэг үзүүлэх тодорхойлох баталгааны хувилбаруудыг бий болгодог
Улсын шилжилт.

## Та үүнийг туршиж үзээрэй. Taira {#try-it-on-taira}

Эрдэнэт судлаачдын замыг ашиглаж, сүүлийн үеийн олон нийтийг шалгаж үзээрэй Taira блок, гүйлгээ
гарын үсэг зурах бүртгэлгүй статусууд:

```bash
curl -fsS 'https://taira.sora.org/v1/explorer/blocks?page=1&per_page=3' \
  | jq '{pagination, blocks: [.items[] | {height, hash, transactions_total, transactions_rejected}]}'

curl -fsS 'https://taira.sora.org/v1/explorer/transactions?page=1&per_page=5' \
  | jq '{pagination, txs: [.items[] | {hash, block, status, executable}]}'
```

Таны аппликейшнээс өмнө ирүүлсэн гүйлгээг дагаж мөрдөхийн тулд `hash` УИХ-ын
эрдэмтэн судлаачдын чиглэлийг жагсаалж, хяналт шалгах:

```bash
TX_HASH='<transaction-hash>'

curl -fsS "https://taira.sora.org/v1/explorer/transactions/$TX_HASH" \
  | jq '{hash, block, status, authority, executable}'
```

Энэ нь зөвхөн унших боломжтой. Norito
хуудас, зөв зангирал ID, төлбөрийн метадэтгэл, цөмөрээс санхүүжүүлсэн Taira Санхүүжилт.

Үргэлт төлөх жишээ Taira, цахилгаан замын туслах
[Тестнэт аваарай XOR цаашид Taira](/mn/get-started/sora-nexus-dataspaces.md#_4-get-testnet-xor-on-taira)
Үүнд `taira_faucet_claim.py`, Дараа нь гарын үсэг зурагчдаа олон нийтийн хувилбараас санхүүжүүлнэ
Нэгдүгээрт:

```bash
export TAIRA_ACCOUNT_ID='<TAIRA_I105_ACCOUNT_ID>'
export TAIRA_FEE_ASSET=6TEAJqbb8oEPmLncoNiMRbLEK6tw

curl -fsS https://taira.sora.org/v1/accounts/faucet/puzzle | jq .
python3 taira_faucet_claim.py "$TAIRA_ACCOUNT_ID"

iroha --config ./taira.client.toml ledger asset get \
  --definition "$TAIRA_FEE_ASSET" \
  --account "$TAIRA_ACCOUNT_ID"
```

Тэмцээний цогцолбоор эсвэл эрэлт замаар шилжих тохиолдолд `502`, өмнө хүлээгээд дахин туршиж үзээрэй
бүтээн байгуулалтын өөрөө алдаа гаргах.

Дараа нь Taira гүйлгээг өргөн мэдүүлэхдээ төлбөрийн активын метадэтгэл:

```bash
printf '{"gas_asset_id":"%s"}\n' "$TAIRA_FEE_ASSET" > taira.tx-metadata.json

iroha --config ./taira.client.toml \
  --metadata ./taira.tx-metadata.json \
  ledger transaction ping --msg "faucet-funded taira transaction"
```

## Онлайн гүйлгээ {#offline-transactions}

Iroha офлайн гүйлгээний хоёр ажлын урсгалтай:

- **Онлайн гарын үсэг зурах** гарын үсэг зурснаар хэвийн гарын үсгийн гүйлгээг бий болгодог
  хэрэгсэл нь буулгангүй байна.
  үйлчлүүлэгчид гарын үсэг зурсан хуудасыг Torii, Тиймээс энэ нь одоо ч хэрэгтэй
  зөв сүлжээ ID, эрх мэдэл, зөвшөөрөл, төлбөр, гүйлгээний хугацаа.
- **Кагемуша офлайн бэлэн мөнгө** Интернэт хэрэглэгдэж байх үед хөрөнгийн санхүүжилтийг нэмэгдүүлнэ
  хүлээн авагч эхлүүлсэн хөрөнгийн санхүүжилт, аль алинд нь
  нэвтрүүлэггүй, хүлээн авагч буцаж ирэхэд үүссэн тэмдэглэлийн байдлыг төлдөг
  Онлайн.

Torii Kagemusha-ийн бүрэн амьдралын мөрийг `/v1/offline/*`:

| Хэрэглээ, эцсийн цэг | Зорилго |
| --- | --- |
| `GET /v1/offline/readiness` | Kagemusha-ийн бэлтгэлээ үнэлгээгээрэй `asset_definition_id` |
| `POST /v1/offline/receiver-lineage` | Бэлэглэгчийн гарын үсэг зурсан хүсэлтэд баталгаатай үйл ажиллагаа явуулж буй бүртгэлийн төлөөлөгчийг шийдвэрлэх |
| `POST /v1/offline/top-up` | Онлайн-оффлайн нэмэлт үйлдлийг гарын үсэг зурна |
| `POST /v1/offline/redeem` | Газар буулгах төлбөрийн гарын үсэг зурсан операцыг хүргүүлнэ |
| `GET /v1/offline/operations/{operation_id}` | Өвөөг нэмэх, төлөх тухай хуулийн дүрмийн байдлыг уншина уу |

Офлайн үйл ажиллагаа явуулахын өмнө хөрөнгийн бэлэн байдлыг шалгах:

```bash
curl -fsS --get https://taira.sora.org/v1/offline/readiness \
  --data-urlencode 'asset_definition_id=<canonical_asset_definition_id>' \
  | jq '{ready, blockers, artifact_set}'
```

Одоогоор бэлэн байдал нь хөрөнгийг идэвхтэй гүүртэй холбоно ABI 21 болон баталгаажуулсан V4
Артефактын цуврал, нэмэлт болон төлбөр төлөх хүсэлтийг ашиглах
`application/x-norito` Архив, нөхөн сэргээлт `202 Accepted`
а `Location` үйл ажиллагааны эх үүсвэрийг зааж байгаа цөм;
0 биш үйлдэл ID Энэ нь тусгаар тогтнолын түлхэгийг хангадаг.

Үүнтэй холбоотой урсгал нь:

1. Та бэлэн байдалд шалгаарай, зогсоо `ready` хуурамч эсвэл ямар ч блокер хэрэглэдэг.
2. Хүрэлсүх Swift эсвэл JVM Canonical-ийн нэмэлт архивын бүтээн байгуулалтын мөнгөн тэмдэг,
   нэвтрүүлгийн тэмдэглэлийн байдал болон үйл ажиллагааг хадгалах ID цааш нь
   үйл ажиллагаа нь эцсийн зангилааны байдалд хүрдэг.
3. Хэрэгтэйгээр хүлээн авагч бүртгэлийн харааг шийдвэрлэх, бүтээн байгуулалт хийх
   Бүх дундаж дамжуулалтыг орон нутгаар шалгаж, нууцлагдсан тэмдэглэлийн байдлыг хэвээр үлдээх
   Хөдөлмөрийг хүлээн зөвшөөрөхөөс өмнө.
4. Тулгчийг онлайнаар хангахдаа Canonical Redemption архив байгуулаарай.
   Энэ асуудлыг танилцуулж, үйл ажиллагааны нөөцийг эцэслэн шалгаж байна.

Тодруулгын бүртгэл нь тэмдэглэлийн байдал хүртэл зөрчилдөж буй офлайн дамжуулалт ажиглахгүй
Онлайн амьдралын мөрийн үеэр эргэн ирдэг.
Тиймээс үнэ цэнэний хязгаар, хугацаа дууссан, хүлээн зөвшөөрөгдсөн эмитент, тогтвортой орон нутгийн
хадгаламж, эвлэрлийн цонх.

Энэ нь шинэ бүтээн байгуулалтын тухай жишээ юм `Grant`
Энэ бүтээн байгуулалтаар Маус Алис-д тодорхойлсон
үүрэг (`role_id`"Чек"
[бүрэн жишээ](./permissions.md#register-a-new-role).

```rust
let grant_role = Grant::account_role(role_id, alice_id);
let grant_role_tx = TransactionBuilder::new(chain_id, mouse_id)
    .with_instructions([grant_role])
    .sign(mouse_private_key);
```
