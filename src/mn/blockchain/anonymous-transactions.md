# Аноним бүтээн байгуулалтууд {#anonymous-transactions}

Анноним бүтээн байгуулалт Iroha нууц хөрөнгийн бүрэлдэхүүнээс баригдсан
Төрийн захиргааны санхүүжилт
олон нийтийн хэмжээний мөнгө, хөрөнгийн сан үнэ цэнийг гадаад төрд хадгалах бүртгэл рүү шилжүүлэн зарцуулдаг
Мэдээллийн нурууны баталгаатай ил тод тэмдэглэлүүд.

Олон нийтийн номонд нууц үйлдэл болсон гэж бүртгэгдэж байна.
үүрэг, хүчингүй болгох, баталгааны хэшүүд болон үйл явдлыг бүртгэнэ
тэмдэглэлийн эзэмшигч, хүлээн авагчийн тоог бүртгүүлнэ
Хөдөлмөр хөдөлгөөн. Худалдааны хэвийн хуудас нь аливаа
данс, тиймээс "аноним" гэдэг нь автомат бус мөнгөн хөрөнгийн хөдөлгөөн гэсэн үг
сүлжээний болон дансны түвшний аноним байдал.

## Барилгын блок {#building-blocks}

| Үндсэн ойлголт            | Тодруулгын жагсаалт                                                                                              |
| ------------------ | ------------------------------------------------------------------------------------------------------------------ |
| Зөөврийн тэмдэглэл      | Ашигт малтмал, хэмжээ, эзэмшигчийн мэдээлэл, санамжтай байдлыг агуулсан хувийн хөрөнгийн бүртгэл.                                   |
| Үүнд үүрэг гүйцэтгэх         | 32 байтын олон нийтийн үнэ цэнэ нь тэмдэглэлийн талбайдыг илрүүлэхгүйгээр нэгдсэн байна.                                        |
| Үргэлжүүлэгч          | Нота зарцуулахдаа үүссэн нийт 32 байтын үнэ цэнэ. Iroha Хоёр удаагийн зарцуулалтыг урьдчилан сэргийлэх зорилгоор давхар төлбөрийг үгүйсгэнэ. |
| Merkle түлх        | Мөнгөний үнийн сангийн дэргэдэх ургамлын сүүл нь мөнгөн тэмдэгт оршин тогтнож байгааг харуулдаг.                        |
| Дашрамдсан хавсралт   | А `ProofAttachment` баталгааны байт болон санхүүжүүлэгчний үсэг эсвэл гарын үсэгт санхүүжилтийн үсэгтэй.                 |
| Үндсэн нууц үйл явдал | Тодруулбал: `ConfidentialEvent::Shielded`, `Transferred`, эсвэл `Unshielded`.                              |

Гол даалгавар нь:

- `RegisterZkAsset`: хөрөнгийг ZK-хөхтэй, холбогдсон шилжилт,
  Шилт, шилтгүй баталгаажуулах товч.
- `Shield`: Төрийн тэнцвэрт төлбөрийг хадгаламжлах, хамгаалалттай тэмдэгтийн үүрэг гүйцэтгэх.
- `ZkTransfer`: цаасан тэмдэгтийг шинэ цаасан номын үүрэг гүйцэтгэгчдэд зарцуулдаг.
- `Unshield`: Хөрөнгө оруулалтын санхүүжилт
- `ScheduleConfidentialPolicyTransition` болон
  `CancelConfidentialPolicyTransition`: хөрөнгийн нууц байдлыг өөрчлөх
  Улс төр засаглал, удирдлага.

Мөн хөрөнгийн тодорхойлолт нь
[`AssetConfidentialPolicy`](/mn/reference/data-model-schema.md).
Захиргааны урсгалыг хянах бодлогын хэв маяг:

| Хэлэлцүүлэг              | Үр дүн                                                          |
| ----------------- | ---------------------------------------------------------------- |
| `TransparentOnly` | Зөвхөн нийтлэг үлдэгдэл болон шилжүүлэн суулгалыг хүлээн зөвшөөрдөг.          |
| `Convertible`     | Хэрэглэгчид үнэ цэнийг олон нийтийн тэнцвэрт болон хадгаламжтай тэмдэгтийн хооронд хөдөлгөх боломжтой. |
| `ShieldedOnly`    | Ашигт малтмалын гаргах болон шилжүүлэн суулгах үйл ажиллагаа нь гадваргүй номонд үлдэх ёстой.   |

## Хэрхэн ашиглах вэ? {#how-to-use-them}

1. Үнэлгээний цэгүүд дээр нууцлан дэмжлэг олгох.
   баталгаажуулагчийн хяналтын төгсгөл, идэвхтэй баталгаажуулах түлшүүд, Poseidon/Pedersen параметр
   IDs, Үндсэн цэгүүд нь
   Үндсэн нууцлалын шинж чанар нь зөрчигдсөн.
2. Хэвлэл мэдээллийн хэрэгслийн санхүүжилт
   Захиргаач, ажилчид нь нэгийг
   `VerifyingKeyId`, Жишээ нь `halo2/ipa:vk_transfer`.
3. Ашигт малтмалыг ZK-тай чадвартай `RegisterZkAsset`, эсвэл A үе шат
   бодлогын шилжилт `TransparentOnly` . `Convertible` эсвэл
   `ShieldedOnly`.
4. Төрийн санхүүгийн хамгаалалт `Shield`. Номын сан нь тэмдэглэлийн үүрэг гүйцэтгэдэг
   болон хүлээн авагчдаа зориулсан шифрлэгдсэн ашиг ачааллыг
   гүйлгээ.
5. Хувийн нээлт `ZkTransfer`. Мөнгөмбөг нь үүнийг баталгаажуулж байна
   нэвтрүүлгийн тэмдэглэлийг эзэмшдэг, нэвтрэх болон гарах үнэ цэнийг тэнцвэржүүлж,
   Хөдөлмөр хэрэглэгдэх бүртээ саяхан хийсэн гэрээний мод дээр хадгалдаг.
6. Зөвхөн хөрөнгийн бодлогын дагуу зөвшөөрөх үедээ тасалгаагүй байх. `Unshield` Энэ нь
   Төрийн өмчийн мөнгөн тэмдэгт, хүлээн авагчдын дансанд зарцуулдаг.
   Мөн хувийн өөрчлөлтийн үр дүнг бий болгох боломжтой.
7. Үндсэн хуулийн хэрэгсэл:
   Бэлэглэгдсэн асуултаар болон Torii эцсийн цэгүүд.

## CLI Жишээлбэл {#cli-examples}

Хөдөлмөрийн ZK CLI Тоног төхөөрөмж нь оператор болон туршилтын урсгалд зориулагдсан.
халамж нь үүрэг гүйцэтгэгч, шифрлэгдсэн хэрэглээний ачаалл,
Нүүр хуудас / номын сан нь дараах чиглэлийг хүргүүлээс өмнө.

Гибрид бүртгүүлэх ZK-хөнгөн хөрөнгө:

```bash
iroha app zk register-asset \
  --asset <asset-definition-id> \
  --allow-shield true \
  --allow-unshield true \
  --vk-transfer halo2/ipa:vk_transfer \
  --vk-unshield halo2/ipa:vk_unshield \
  --vk-shield halo2/ipa:vk_shield
```

Сэргэлттэй тэмдэглэлийн зориулалттай шифрлэгдсэн ашиг ачааны хувцас загварын хувилбар байгуулж:

```bash
iroha app zk envelope \
  --ephemeral-pubkey 0101010101010101010101010101010101010101010101010101010101010101 \
  --nonce-hex 020202020202020202020202020202020202020202020202 \
  --ciphertext-b64 AQIDBA== \
  --print-json \
  --output note-envelope.bin
```

Төрийн хөрөнгийн санхүүжилтийг хөрөнгө оруулалтын санхүүжилтийн санхүүжилтэд хадгалах:

```bash
iroha app zk shield \
  --asset <asset-definition-id> \
  --from <account-id> \
  --amount 1000 \
  --note-commitment ABABABABABABABABABABABABABABABABABABABABABABABABABABABABABABABAB \
  --enc-payload note-envelope.bin
```

## SDK Жишээлбэл {#sdk-example}

Тухайн баталгааны байт нь конфигургасан баталгааны хяналтын хэсгээс ирдэг.
транзакцын ашиг ачаалал нь зөвхөн олон нийтэд зориулсан өгөгдлийг болон баталгааны хавсралтыг шаарддаг:

```rust
use iroha_data_model::{
    isi::zk::{Unshield, ZkTransfer},
    prelude::{AccountId, AssetDefinitionId, InstructionBox},
    proof::{ProofAttachment, ProofBox, VerifyingKeyId},
};

fn transfer_instruction(
    asset: AssetDefinitionId,
    input_nullifier: [u8; 32],
    output_commitment: [u8; 32],
    anchor_root: [u8; 32],
    proof_bytes: Vec<u8>,
) -> InstructionBox {
    let backend = "halo2/ipa".into();
    let proof = ProofBox::new(backend, proof_bytes);
    let vk = VerifyingKeyId::new("halo2/ipa", "vk_transfer");
    let attachment = ProofAttachment::new_ref("halo2/ipa".into(), proof, vk);

    ZkTransfer::new(
        asset,
        vec![input_nullifier],
        vec![output_commitment],
        attachment,
        Some(anchor_root),
    )
    .into()
}

fn unshield_instruction(
    asset: AssetDefinitionId,
    recipient: AccountId,
    amount: u128,
    input_nullifier: [u8; 32],
    anchor_root: [u8; 32],
    proof_bytes: Vec<u8>,
) -> InstructionBox {
    let backend = "halo2/ipa".into();
    let proof = ProofBox::new(backend, proof_bytes);
    let vk = VerifyingKeyId::new("halo2/ipa", "vk_unshield");
    let attachment = ProofAttachment::new_ref("halo2/ipa".into(), proof, vk);

    Unshield::new(
        asset,
        recipient,
        amount,
        vec![input_nullifier],
        attachment,
        Some(anchor_root),
    )
    .into()
}
```

## Аноним хөрөнгийн хяналт тавих {#anonymous-asset-escrow}

Ашигт малтмалын хадгаламж нь мөн адил хамгаалалттай шилжүүлэн суулгах машиныг ашигладаг
Талууд болон тавилганы байдал нь одоо ч гэсэн
Хөрөнгө оруулалт, төлбөр тооцоо
хамгаалалттай хүчингүй болгох элементүүд болон гарааны үүрэг гүйцэтгэгчдийг ашиглах.

Тодорхой санхүүжилт ISI үйл ажиллагаа, жишээг үзнэ үү
[Үндэсний хөрөнгийн хяналт](/mn/blockchain/escrow.md#anonymous-escrow).

Амьдралын мөчлөг нь:

1. `OpenAnonymousAssetEscrow` санхүүжилтийн хяналтын тэмдэгтийг зарцуулж, нэг
   Хөрөнгө оруулалтын үүрэг.
2. `AcceptAnonymousAssetEscrow` худалдан авагчийг бүртгэж байна.
3. `MarkAnonymousEscrowPaymentSent` худалдан авагч төлбөрийг илгээсэн баримт
   Хадгалын гадаа.
4. `ReleaseAnonymousAssetEscrow` худалдан авагчдаа хадгаламжийн үүрэг гүйцэтгэгчээр зарцуулдаг
   үйлдвэрлэлийн үүрэг гүйцэтгэх.
5. `CancelAnonymousAssetEscrow` арилжааны төлбөрийг худалдан авагчдаа буцааж өгдөг
   төлбөрийг тэмдэглэхгүй тохиолдолд гаргах үүрэг гүйцэтгэнэ.
6. `OpenAnonymousEscrowDispute` болон `ResolveAnonymousEscrowDispute` гараа
   Үндсэн хуулиар батлагдсан баримт бичгийг баталгаажуулж, шийдвэрлэгчээр хяналттай хуваарилсан.

Үндсэн хуульд заасан нууц захиалгын асуултуудыг ашигла
[Судалгаа](/mn/reference/queries.md#escrow-and-proof-records) Хөрөнгө оруулалтын захиалгыг шалгах
бичиг баримт, статусууд.

## Математик {#math}

Дараах тэмдэглэл нь нууц хөрөнгийн урсгалыг тодорхойлдог.
идэвхтэй замыг болон параметр ашиглана IDs хөрөнгийн бодлого, санхүүжилтээс
бүртгэл, тиймээс үйлчлүүлэгчид үүрэг гүйцэтгэгч, хүчингүй болгох болон баталгааны байт
хөрөнгийн/сэлбэгний ил тод үр дүнтэй.

Сэргэлттэй тэмдэгтийг дараах байдлаар тодорхойлж болно:

$$
n = (\mathsf{asset}, \mathsf{amount}, \mathsf{owner}, \rho)
$$

хаана `owner` хүлээн авагчийн үзүүлэх, зарцуулах материалын үр дүнд үүссэн бөгөөд
`rho` Энэ нь маргаантай тохиолдол юм.

Номын үүрэг гүйцэтгэх нь нууцлан хийх үүрэг:

$$
C = \mathsf{Commit}(\mathsf{asset}, \mathsf{amount}, \mathsf{owner}, \rho)
$$

Одоогийн нууцлагдсан дамжуулах эргэлтэд олон нийтийн өгөгдлийн
тэмдэглэлт үүрэг, хүчингүй болгох, Merkle түлх, хөрөнгө тэмдэг, зангилын тэмдэг.
Тус дугуй нь ийм хэлбэртэй үүрэг гүйцэтгэх харилцааг хэрэгжүүлдэг:

$$
C = H_c(\mathsf{amount}, \rho, \mathsf{owner\_tag}, \mathsf{asset\_tag})
$$

Номыг зарцуулахад, мөнгөн тэмдэгт нь хүчингүй болгож өгдөг:

$$
N = H_n(\mathsf{spend\_key}, \rho, \mathsf{asset\_tag}, \mathsf{chain\_tag})
$$

`N` Энэ нь тэмдэглэлийг илрүүлэхгүй, гэхдээ энэ тэмдэглэлийн хувьд тогтвортой
болон сүлжээ, тийм ч Iroha Энэ нь мөн адил хүчингүй болгож чаддаг хоёр дахь зарцуулыг татгалзаж болно.

Зээлийн мод нь тэмдэглэлийн оршин тогтнолыг баталдаг.
`C_i`, Энэ баримт нь Merkle-ийн хувийн зам `C_i` сүүлийн үед
олон нийтийн үндэс:

$$
\mathsf{MerkleRoot}(C_i, \mathsf{path}) = R
$$

Шалгалттай шилжүүлэн суулгасан тохиолдолд нотлох нь мөн үнэ цэнэтэй
хамгаалах:

$$
\sum \mathsf{inputs} = \sum \mathsf{outputs}
$$

Нүүр хуудас:

$$
\sum \mathsf{inputs} = \mathsf{public\_amount} + \sum \mathsf{private\_change}
$$

Нэвтрүүлэгний дүгнэлтийг дараах байдлаар товчлуулж болно:

$$
\mathsf{Verify}(\mathsf{vk}, \mathsf{public\_inputs}, \pi) = \mathsf{true}
$$

хаана `public_inputs` үүрэг гүйцэтгэгч, хүчингүй болгож чаддаг, түлхүүр, хөрөнгийн тэмдэг,
Гэрч нь тэмдэглэлтэй.
Мөнгө, харамсалтай байдал, зарцуулах материал, Merkle зам.
үр дүнгийн үүрэг гүйцэтгэгчдийг хавсралтаар баталгаажуулж, дараа нь хувьсгалын номын жагсаалтыг өөрчлөх;
нэвтрүүлэгний хүчингүй болгох тэмдэгүүдийг зарцуулсан гэж тэмдэглэх.

## Олон нийтийн хэрэг {#what-is-public}

Аноним үйл ажиллагаа нь ажиглагдах бүх баримтыг нууц болгодоггүй.
дараах мэдээлэл хэвээр байх боломжтой:

- гүйлгээний хэш, блок өндөр, захиалгын
- өргөдлөө өргөн мэдүүлсэн гүйлгээний эрх баригч нь
  хувийн орох цэг эсвэл ээлжит хэв маяг
- ашиглаж буй хөрөнгийн тодорхойлолт
- Үргэлжүүлэгч, үр дүнгийн үүрэг
- баталгаажуулах хэшүүд, шалгаруулах түлхүүрний сүлжээнүүд, сонголттой хуудасны хэшүүд
- олон нийтийн хэмжээ, хүлээн авагчдын бүртгэл `Unshield`
- үл тодруулсан захиалгын худалдаалагч, худалдан авагч, байдал, цаг хугацааны тэмдэг, гэрчилгээний хэшүүд

Энэ олон нийтийн метадан нь бизнесийг илрүүлэхгүй байхын тулд дизайны хэрэглээ
Та хамгаалж байгаа харилцаа.
