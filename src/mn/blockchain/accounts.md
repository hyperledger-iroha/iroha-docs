# Санхүүжилт {#accounts}

Санхүүжилт бол бүтээн байгуулалтын гарын үсэг зурах, өөрийн томоохон бүртгэлтэй байгууллага юм.
Одоогийн байдлаар Iroha 3 Мэдээллийн загвар, `AccountId` хуулиар батлагдсан, доменгүй:
Энэ нь дансны хяналтын ажилтангаас үүдэлтэй бөгөөд Canonically code I105.
Хүний уншдаг домен, мэдээллийн орчны хүрээлэнгийн хүрээнд тусгай бүртгэлийн нууц нэр
хамааралтай.

## Структура {#structure}

Бүртгэлтэй `Account` дараах зүйлсийг агуулж байна:

- `id`: Каноникийн `AccountId`
- `metadata`: үл хөдлөх хөрөнгийн санхүүжилт
- `label`: сонголттой тогтвортой цогц
- `uaid`: сонголттой бүх нийтийн данс ID ашиглаж байна Nexus урсгал
- `opaque_ids`: Сангийн бүртгэлтэй холбогдсон ил тод тодорхойлолтууд UAID

Хэтгэлийг бий болгохын тулд ашигласан транзакцын нөөц нь `NewAccount`. Энэ нь
ижил нэр хүндрэл, метадэтгэл, тэмдэглэл; UAID, болон ил тод ID .
бүртгэлтэй данс.

`uaid` Каноникийн зохицуулалтыг нэмнэ `AccountId`; Энэ нь түүнийг солихгүй.
хэзээ Nexus үйлчилгээний хэрэглэгчийн эсвэл байгууллагын тогтвортой хяналт
Мэдээллийн орон тоо, хувийн хэвшлийг хадгалах бүртгэл, үйлчилгээний боломжийг хайх.
Хөдөлмөрийн цаг хугацаа нь нэгээс нэг UAID-сэтгэлийн индекс, ил тод тодорхойлогч шаарддаг
Хөгжлийн багаж хэрэглээний UAID, болон давхар эсвэл зөрөлдөөнд орсон, ил тод
тодруулгыг үзнэ үү
[FHE болон UAID](/mn/blockchain/sora-nexus-services.md#fhe-and-uaid) . Nexus
үйлчилгээний давхаргын урсгал.

## Нягтлан бодох бүртгэлийн хяналтын ажилтан {#account-controllers}

Хяналтын ажилтан нь дансны үйлдлийг хэрхэн зөвшөөрдөг вэ гэдгийг тодорхойлдог.
урсгал нь Ed25519 товчооны хосууд ашигладаг боловч мэдээллийн загвар нь мөн илүү баялаг
хяналтын хэрэгсэл, ялангуяа олон гарын үсэг зурах бодлогын хяналт тавих хэрэгсэл.

Клиентын конфигурац нь гарын үсэг зурах эрх мэдлийг өрсөлдөгчээс тусгаарлан хадгалдаг
бүтэц:

```toml
[account]
public_key = "ed0120..."
private_key = { digest_function = "ed25519", payload = "..." }
```

Та үзээрэй. [үйлчлүүлэгчдийн тохируулга](/mn/guide/configure/client-configuration.md) болон
[гол үеийн](/mn/guide/security/generating-cryptographic-keys.md) .
Одоогийн гол формат.

## Та үүнийг туршиж үзээрэй. Taira {#try-it-on-taira}

Хэдэн номны жагсаалт IDs олон нийтээс Taira туршилтын сүлжээ:

```bash
curl -fsS 'https://taira.sora.org/v1/accounts?limit=5' \
  | jq -r '.items[] | [.id, (.primary_alias // "-")] | @tsv'
```

Санхүүгийн хөрөнгийг шалгахын тулд санхүүгийн дансыг хуулбаруулна ID анхны дуудлагаас хойш URL- код
Энэ нь энэ замд байршуулахын өмнө Python Сниппет үүнийг анх удаа хийдэг
жагсаалтад бүртгэгдсэн сан:

```bash
python3 - <<'PY'
import json
import urllib.parse
import urllib.request

root = "https://taira.sora.org"
accounts = json.load(urllib.request.urlopen(f"{root}/v1/accounts?limit=1"))["items"]
account_id = accounts[0]["id"]
encoded = urllib.parse.quote(account_id, safe="")
assets = json.load(
    urllib.request.urlopen(f"{root}/v1/accounts/{encoded}/assets?limit=5")
)

print(json.dumps({"account_id": account_id, "assets": assets["items"]}, indent=2))
PY
```

Энэ нь олон нийтийн уншлын . Эвлэгийг бий болгох эсвэл шинэчлэх нь гарын үсэг зурсан гүйлгээ
болон галт тэрэгний санхүүжилт шаарддаг Taira Урьдчилсан
[Сэргэлт SORA Nexus Мэдээллийн газар](/mn/get-started/sora-nexus-dataspaces.md).
