# Данс {#accounts}

Данс нь гүйлгээ хийх эрхтэй бөгөөд блокчэйн бүртгэлийн төлөвийг эзэмших эрх бүхий зөвшөөрлийн үндсэн нэгж юм. Одоогийн Iroha 3 өгөгдлийн загвар дээр, `AccountId` нь нэг протоколын стандартыг дагаж, ямар ч домайнгүй байна: энэ нь дансны хянагчаас гаралтай бөгөөд [I105](/mn/reference/i105.md) гэж ганц протокол-стандартад кодлогдсон байдаг. Хүний уншиж болох домайн ба өгөгдлийн сангийн хүрээ нь тусдаа дансны хошуу нэрийн холболтод хамаарна.

## Бүтэц {#structure}

Бүртгэлтэй `Account` нь дараах зүйлийг агуулна:

- `id`: ганц протокол-стандарт `AccountId`
- `metadata`: дурын дансны мета өгөгдөл
- `label`: сонголтоор тогтвортой овог нэр
- `uaid`: Nexus урсгалаар ашиглаж болох сонголттой Нэгдсэн Дансны ID
- `opaque_ids`: дансны UAID-д хамаарсан тунгалаг бус тодорхойлогчид

Данс үүсгэхэд ашигласан гүйлгээний өгөгдөл нь `NewAccount` болно. Энэ нь бүртгэлтэй дансаар ашиглдаг ижил таних тэмдэг, мета өгөгдөл, шошго, UAID, болон бүрхэг ID талбаруудыг агуулна.

`uaid` нь ганц протокол стандарт `AccountId`-ийг нөхөж өгдөг; үүнийг орлуулдаггүй. Nexus үйлчилгээ нь дата сануудын даяар тогтвортой хэрэглэгч эсвэл байгууллагын танигч, нууцлал хамгаалсан бүртгэл, эсвэл үйлчилгээний чадварын хайлт хэрэгтэй үед ашиглана уу. Программ хангамжийг гүйцэтгэх орчин нь нэгээс нэг UAID-г дансанд холбосон индексийг хадгалдаг, бүдэг танигчдыг UAID-ээр дамжуулан наалдуулах шаардлагатай бөгөөд давхцаж байгаа эсвэл мөргөлдсөн бүдэг танигчдыг татгалздаг. Nexus үйлчилгээний давхаргын урсгалын талаар [FHE ба UAID](/mn/blockchain/sora-nexus-services.md#fhe-and-uaid)-ийг үзнэ үү.

## Данс хянагчид {#account-controllers}

Контроллер нь данс хэрхэн үйлдлүүдийг зөвшөөрдгийг тодорхойлно. Анхдагч клиент урсгал нь Ed25519 түлхүүрийн хосыг ашигладаг боловч өгөгдлийн загвар нь олон гарын үсгийн бодлогын контроллер зэрэг илүү баялаг контроллеруудыг мөн дэмждэг.

Клиентийн тохиргоо гарын үсэг зурах эрхийг сүлжээний хөршийн тохиргооноос тусад нь хадгалдаг:

```toml
[account]
public_key = "ed0120..."
private_key = { digest_function = "ed25519", payload = "..." }
```

Одоогийн түлхүүрийн форматуудыг харахын тулд [клиент тохиргоо](/mn/guide/configure/client-configuration.md) болон [түлхүүр үүсгэх](/mn/guide/security/generating-cryptographic-keys.md)-ийг үзнэ үү.

## Энэ урсгалыг Taira-д ажиллуулна уу {#try-it-on-taira}

Нийтлэг Taira туршилтын сүлжээнээс хэд хэдэн нэг протокол-стандарт дансны ID жагсаа:

```bash
curl -fsS 'https://taira.sora.org/v1/accounts?limit=5' \
  | jq -r '.items[] | [.id, (.primary_alias // "-")] | @tsv'
```

Дансны хөрөнгийг шалгахын тулд эхний техникийн дуудах ажиллагаанаас дансны ID-г хуулж, замд тавихаас өмнө URL кодчилгоотой болгоно. Энэ Python хэсэг нь жагсаасан эхний дансны хувьд үүнийг хийдэг:

```bash
python3 - <<'PY'
import json
import urllib.parse
import urllib.request

root = "https://taira.sora.org"
accounts = json.load(urllib.request.urlopen(f"{root}/v1/accounts?limit=1"))["items"]
account_id = accounts[0]["id"]
encoded = urllib.parse.quote(account_id, safe="")
assets = json.load(
    urllib.request.urlopen(f"{root}/v1/accounts/{encoded}/assets?limit=5")
)

print(json.dumps({"account_id": account_id, "assets": assets["items"]}, indent=2))
PY
```

Эдгээр нь олон нийтийн уншлага юм. Бүртгэл үүсгэж эсвэл шинэчлэх нь гарын үсэгтэй гүйлгээ бөгөөд [SORA Nexus өгөгдлийн сангуудтай холбогдох](/mn/get-started/sora-nexus-dataspaces.md) дотор тайлбарласан туршилтын сүлжээгээр санхүүжүүлсэн Taira тохиргоог шаарддаг.

## Бүртгэл ба зөвшөөрөл {#registration-and-permissions}

Дансууд нийтлэгтэй хамт бүртгэгдсэн ба бүртгэлгүй байна [`Register` болон `Unregister`](/mn/blockchain/instructions.md#un-register) заавар. Идэвхтэй програм хангамжийн гүйцэтгэлийн орчны баталгаажуулагч шийддэг хэн данс үүсгэж болох бөгөөд ямар эрхийн токенууд эсвэл үүрэг шаардлагатай болохыг.

Бүртгүүлсний дараа данс нь дараахыг хийх боломжтой:

- үйлдлийн баримт бичигт гарын үсэг зурах
- Өмч хөрөнгө хадгалах
- өөрийн домайнууд
- ролууд болон зөвшөөрөл тэмдгүүдийг хүлээн авах
- мета өгөгдөл хадгалах
- тэр функцүүд идэвхжсэн үед алиасын, дахин түлхүүрлэх, сэргээх, болон Nexus таних урсгалд оролцоно

## Таних асуудлыг шийдэх {#troubleshooting-identity-issues}

Хэрэв гүйлгээг гэнэтийн байдлаар татгалзсан бол дараах зүйлсийг шалгаарай:

- хэрэглэгчийн нийтийн түлхүүр нь гарын үсэг зурахдаа ашигласан хувийн түлхүүртэй таарах
- тус данс нь блокчейн генезис дээр эсвэл баталгаажсан гүйлгээгээр бүртгэгдсэн
- зөвшөөрөл олгогч нь зааварт шаардлагатай эрхтэй байна
- хатуу дансны талбарууд нь ганц протокол-стандарт I105 дансны ID-г ашигладаг бол уншигдах нэрсийг идэвхтэй дансны хэвшмэл товлосны холбоогоор шийддэг
