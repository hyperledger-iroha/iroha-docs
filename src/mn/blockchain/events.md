# Үйл явдал {#events}

Тодорхой хэлбэрийн үйл явдлын мэдэгдлүүд нь блокчэйн дотор тодорхой зүйлс болох үед гардаг, жишээлбэл шинэ данс үүссэн эсвэл блок эцэслэгдсэн тохиолдолд. Үйл явдалд янз бүрийн төрлүүд байдаг:

- программ хангамжийн боловсруулах ажлын процессын үйл явдлууд
- өгөгдлийн үйл явдлууд
- цаг хугацаанд суурилсан үйл явдлын мэдэгдэл
- гүйцэтгэлийн үйлдлүүдийг өдөөх

## программ хангамж боловсруулах урсгал үйл явдлууд {#pipeline-events}

програм хангамж боловсруулах урсгалын үйл явдлууд нь гүйлгээ илгээх, гүйцэтгэх, эсвэл блокт эцэслэгдэх үед үүсдэг. Програм хангамж боловсруулах урсгалын үйл явдалд дараах мэдээлэл агуулагддаг: үйл явдлыг үүсгэсэн объектын төрөл (гүйлгээ эсвэл блок), түүний криптографийн хэш болон төлөв. Төлөв нь `Validating` (баталгаажуулалт үргэлжилж буй), `Rejected`, эсвэл `Committed` байж болно. Хэрвээ нэгжийг татгалзсан бол татгалзсан шалтгааныг нь өгнө.

### Энэ урсгалыг Taira-д ажиллуулна уу {#try-it-on-taira}

Нийтийн програм хангамжийн боловсруулалтын ажлын урсгалын үйл явдлын урсгалыг холбосон эсэхийг шалгаарай:

```bash
curl -fsSI https://taira.sora.org/v1/events/sse \
  | sed -n '1,12p'
```

Цэгийн цагийн дата хөтөлбөрийг тандахдаа стрим нээлттэй хадгалахгүйгээр, сүүлийн үеийн судлаачийн гүйлгээг уншина уу:

```bash
curl -fsS 'https://taira.sora.org/v1/explorer/transactions?page=1&per_page=5' \
  | jq '{pagination, txs: [.items[] | {hash, block, status, executable}]}'
```

Амьд үйл явдлууд хэрэгтэй бол терминалд SSE маршрутыг нээнэ үү:

```bash
curl -fsS -N https://taira.sora.org/v1/events/sse
```

Хэрэв урсгалыг нээлттэй байх хугацаанд ямар ч гүйлгээ илгээгүй бол маршрут эрүүл хэвээр байгаа ч тушаал дуугүй байж болно.

## Өгөгдлийн үйл явдлууд {#data-events}

Дата үйл явдлууд нь сүлжээний хамтрагчид, домэйнүүд, дансууд, активууд, активын тодорхойлолтууд, NFTs, триггерүүд гэх мэт блокчэйн дансны өгөгдөлтэй холбоотой өөрчлөлт гарвал үүсдэг. үүрэг, гинжин дэх тохиргоо, гүйцэтгэгчийн төлөв, нотолгоонууд, нууц хөрөнгө, гүүрүүд, эсвэл SORA/Nexus-т зориулсан объектууд. Эдгээр төрлийн үйл явдлуудыг [өгөгдлийн үйл явдлын шүүлтүүрүүд](./filters.md#data-event-filters)-д ашигладаг.

## цаг хугацаанд суурилсан үйл явдлын мэдэгдэл {#time-events}

Дэлхийн төлөвийн харагдац [цагийн триггерүүдийг](./triggers.md#time-triggers) боловсруулахад бэлэн болоход цагийн үйл явдал гарна.

## Гүйцэтгэлийн үйлдлийг эхлүүлэх {#trigger-execution-events}

Триггер гүйцэтгэх үйл явдлууд нь үүссэн үед ялгардаг [`ExecuteTrigger`](./instructions.md#executetrigger) заавар хэрэгжиж байна. Триггер үйлдэл дууссаны дараа триггер дуусах үйл явдлууд үүсдэг.
