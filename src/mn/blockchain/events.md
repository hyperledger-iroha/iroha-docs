# Үргэлт {#events}

Блокчейн дотор тодорхой зүйл тохиолдсон тохиолдолд үйл явдлууд гарч ирнэ. жишээ нь, шинэ хуудас бий болгодог эсвэл блок үйлддэг байна.

- галт тэрэгний үйл явдал
- мэдээллийн үйл явдлууд
- цаг хугацааны үйл явдал
- гүйцэтгэх үйл явдлыг эхлүүлэх

## Газрын тосны үйл явдлууд {#pipeline-events}

Төмөр замын үйл явдлууд нь бүтээн байгуулалтыг өргөн мэдүүлсэн, гүйцэтгэсэн, эсвэл блок дээр үүрэг болгосон үед дамжуулагддаг. Үүнд `Validating` (ийлчилгээ явагдаж байна), `Rejected` эсвэл `Committed` гэсэн байр суурь байж болох юм.

### Taira дээр туршиж үзээрэй. {#try-it-on-taira}

Олон нийтийн урсгалын үйл явдлын шугам тохиож байгаа эсэхийг шалга:

```bash
curl -fsSI https://taira.sora.org/v1/events/sse \
  | sed -n '1,12p'
```

Та урсгалыг нээлттэй байлгахгүйгээр хяналт тавих боломжийг олж авахын тулд сүүлийн үеийн хайгуулын гүйлгээг уншина уу:

```bash
curl -fsS 'https://taira.sora.org/v1/explorer/transactions?page=1&per_page=5' \
  | jq '{pagination, txs: [.items[] | {hash, block, status, executable}]}'
```

SSE замыг шууд арга хэмжээний хэрэгцээтэй үед терминал дээр нээх:

```bash
curl -fsS -N https://taira.sora.org/v1/events/sse
```

Хэрэв урсгал нээлттэй байх хугацаандаа аливаа гүйлгээ хийгдээгүй бол маршрут эрүүл байгаа хэдий ч команд чимээгүй байж болно.

## Мэдээллийн үйл явдлууд {#data-events}

Мэдээллийн үйл явдлууд нь номын сангийн өгөгдөлтэй холбоотой өөрчлөлт орсон тохиолдолд, тухайн үеийнх, доменүүд, данс, хөрөнгө, хөрөнгийн тодорхойлолт, NFTs, триггер, үүрэг, зангилааны конфигурац, гүйцэтгэгчний байдал, баталгаа, нууцлаг эд хөрөнгө, гүүр, эсвэл SORA/Nexus-ийн онцгой объектуудтай холбоотой. Эдгээр төрлийн үйл явдлыг [ мэдээллийн үйл явдлын филтрүүд ](./filters.md#data-event-filters)-д ашигладаг.

## Цаг хугацааны үйл явдал {#time-events}

Цагийн үйл явдлыг дэлхийн нөхцөл байдлын үзэл нь [ цаг хугацааны триггерүүд ](./triggers.md#time-triggers)-ийг шийдвэрлэхэд бэлэн байх үед дамжуулдаг.

## Трижер гүйцэтгэх үйл явдлууд {#trigger-execution-events}

[`ExecuteTrigger`](./instructions.md#executetrigger) заалыг гүйцэтгэхэд триггер гүйцэтгэх үйл явдлууд гарч ирнэ.
