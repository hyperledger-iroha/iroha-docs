# Үргэлж {#events}

Блокчейн дотор тодорхой зүйл тохиолдсон үед үйл явц гарч байна.
Шинэ данс үүсч, эсвэл блок хийгдэж байна.
үйл явдлын тухай:

- галт тэрэгний үйл явдал
- Мэдээллийн үйл явдлууд
- цаг хугацааны үйл явдлууд
- гүйцэтгэх үйл явдлыг үүсгүүлэх

## Газрын тосны үйл явц {#pipeline-events}

Газрын тосны үйл явдлыг бүтээн байгуулалтыг өргөн мэдүүлэх, гүйцэтгэх эсвэл
Хөгжлийн үйл явц нь дараах мэдээллийг бүрдүүлнэ:
үйл явдлыг үүсгэсэн нэгжийн төрөл (транзакцын эсвэл блок), түүний хэш
Энэ байдал нь `Validating` (Эрдэнэт үйлдвэрлэлийн үйл ажиллагаа явуулж байгаа),
`Rejected`, эсвэл `Committed`. Хэрэв нэгж нь татгалзсан бол
татгалзсан байна.

### Та үүнийг туршиж үзээрэй. Taira {#try-it-on-taira}

Олон нийтийн урсгалын үйл явдлын шугам нь монтаж байгаа эсэхийг шалгаарай:

```bash
curl -fsSI https://taira.sora.org/v1/events/sse \
  | sed -n '1,12p'
```

Уул уурхайн урсгал нээлттэй байлгахгүйгээр шалгаж болох хүйтэн зураг авахын тулд саяхан унших
эрдэмтэн судлаачдын гүйлгээ:

```bash
curl -fsS 'https://taira.sora.org/v1/explorer/transactions?page=1&per_page=5' \
  | jq '{pagination, txs: [.items[] | {hash, block, status, executable}]}'
```

Үргэлжээ нээх SSE Амьдралын үйл ажиллагааны хэрэгцээтэй үед терминал дахь маршрут:

```bash
curl -fsS -N https://taira.sora.org/v1/events/sse
```

Хэрэв урсгал нээлттэй байх хугацаандаа аливаа гүйлгээ хийгдээгүй бол команд нь үлдэж болно
Хэдийгээр зам нь эрүүл байдаг ч чимээгүй байна.

## Мэдээллийн үйл явдал {#data-events}

Мэдээллийн үйл явдлууд нь номын сангийн
Үргэлт, домен, данс, хөрөнгө, хөрөнгийн тодорхойлолтууд NFTs, хөдөлгөөн үүсгэгч,
үүрэг гүйцэтгэх, зангилааны дотор тохируулалт, гүйцэтгэгчний байдал, баталгаа, нууц хөрөнгө,
гүүр, эсвэл SORA/Nexus Энэ төрлийн үйл явдлыг
[Мэдээллийн үйл явдлын филтр](./filters.md#data-event-filters).

## Цагийн үйл явдал {#time-events}

Цагийн үйл явдлыг дэлхийн нөхцөл байдлын үзэл баримтлал шийдвэрлэхэд гаргадаг
[цаг хугацааны хөдөлгөөн](./triggers.md#time-triggers).

## Триггер гүйцэтгэх үйл явц {#trigger-execution-events}

Триггер гүйцэтгэх үйл явц нь
[`ExecuteTrigger`](./instructions.md#executetrigger) заавар нь
Триггер гүйцэтгэх үйл явц нь триггер үйлдлийн дараа дамжуулагддаг
дуусч байна.
