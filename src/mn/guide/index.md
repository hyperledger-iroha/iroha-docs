# Далангуур {#guide}

Энэ хэсгийг Iroha -ийг барихад, ашиглахдаа эсвэл нэгтгэхэд ашигла. Эхний үйлчлүүлэгчд зориулсан SDK сургалтуудаас эхлээд хуваалцсан сүлжээний эсрэг хэрэглэхээс өмнө шилдэг арга зүй болон оператор-ын сүлжээнд шилжүүлээрэй.

## Зөвлөгөөний зам {#recommended-path}

1. [Iroha 3](/mn/get-started/install-iroha.md) болон [ орон нутгийн сүлжээг эхлүүлнэ ](/mn/get-started/launch-iroha.md).
2. [SDK сургалтыг ](/mn/guide/tutorials/) сонгож, жижиг гүйлгээг өргөн мэдүүлээрэй.
3. [Эрүүлэгний хөгжил](/mn/guide/best-practices/application-development.md) болон [Дэлхийн загварчлалыг ](/mn/guide/best-practices/data-modeling.md) шалгаж мөрдөх нь өмнө API.
4. Хэрэглээ [Сүлжээний хэрэгжилт](/mn/guide/best-practices/network-deployment.md), [Үйл ажиллагаа](/mn/guide/best-practices/operations.md), болон [Аюулгүй байдал, хүртээмж](/mn/guide/best-practices/security-and-access.md) хуваалцсан эсвэл үйлдвэрлэлийн сүлжээг ашиглахаас өмнө.
5. [Орон нутгийн хөгжлиас Taira, Minamoto эсвэл бусад амьд ашиглалтанд шилжүүлэхэд Release Readiness](/mn/guide/best-practices/release-readiness.md)-ийг дагаарай.
