# Хөтөч {#guide}

Та энэхүү хэсгийг Iroha-той барьж байгуулах, ажиллуулах эсвэл интеграц хийх үед ашиглана уу. Эхний хэрэглэгчийн хувьд SDK зааварчилгаагаар эхлээд, дараа нь шилдэг туршлага, операторын лавлахуудыг үзсэний дараа нийтлэг сүлжээ дээр байрлуулахыг зөвлөж байна.

## Зөвлөсөн зам {#recommended-path}

1. [Суурилуулна уу Iroha 3](/mn/get-started/install-iroha.md) ба [орчны сүлжээг эхлүүлэх](/mn/get-started/launch-iroha.md).
2. Нэг [SDK сургалт](/mn/guide/tutorials/) сонгож, жижиг гүйлгээ хийх.
3. API програм үүсгэхээсээ өмнө [Програм хангамжийн хөгжүүлэлт](/mn/guide/best-practices/application-development.md) ба [Өгөгдлийн загварчлал](/mn/guide/best-practices/data-modeling.md)-ийг хянаарай.
4. Хуваалцсан эсвэл үйлдвэрлэлийн сүлжээг ажиллуулахын өмнө [Сүлжээний байршуулах](/mn/guide/best-practices/network-deployment.md), [Үйл ажиллагаа](/mn/guide/best-practices/operations.md), болон [Аюулгүй байдал ба хандах эрх](/mn/guide/best-practices/security-and-access.md)-ыг ашиглаарай.
5. [Гаргалтанд бэлэн байх](/mn/guide/best-practices/release-readiness.md)-ыг нутгийн хөгжүүлэлтээс Taira, Minamoto эсвэл өөр амьд байршуулалтад шилжүүлэх үед дагана уу.
