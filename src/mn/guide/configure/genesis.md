## Файлууд {#files}

Дээд талын репозитор нь анхдагч манифест илгээдэг `defaults/genesis.json`.
Kagami-Үйлдвэрлэсэн сүлжээнүүд өөрсдийн манифест болон гарын үсэг зурсан гүйлгээгээ бичдэг
гаралтын лавлах:

```bash
cargo run --bin kagami -- localnet --peers 4 --out-dir ./localnet
```

Үүсгэсэн `README.md` тэр санд яг файлуудыг бичиж, ажиллуулна
сонгосон профайлын тушаалууд.

## Үе тэнгийн тохиргоо {#peer-configuration}

Үе тэнгийнхэн нь гарын үсэг зурсан генезийн гүйлгээг зааж байна `[genesis]` хэсэг
`config.toml`:

```toml
[genesis]
file = "./genesis.signed.nrt"
public_key = "ed0120..."
```

Сүлжээний бүх үе тэнгийнхэн гарын үсэг зурсан генезийн гүйлгээний талаар тохиролцох ёстой
генезийн нийтийн түлхүүр.

## Genesis-д гарын үсэг зурах {#signing-genesis}

Хэрэв та манифестыг гараар зассан бол үе тэнгийнхэндээ эхлэхээсээ өмнө баталгаажуулж, гарын үсэг зурна уу:

```bash
cargo run --bin kagami -- genesis validate ./genesis.json
cargo run --bin kagami -- genesis sign ./genesis.json \
  --private-key-file "$GENESIS_PRIVATE_KEY_FILE" \
  --out-file ./genesis.signed.nrt
```

`GENESIS_PRIVATE_KEY_FILE` эзэмшигчийн горим байх ёстой-`0600`, нэг холбоос
нэг каноник хувийн түлхүүрийн олон хэш болон эцсийн түлхүүр агуулсан ердийн файл
шинэ мөр. Kagami бэлгэдлийн холбоосыг үгүйсгэж, түүхий генезийн хувийн хэвшлийг хэзээ ч хүлээн зөвшөөрдөггүй
тушаалын мөрөнд товчлуур.

NPoS эсвэл Nexus профайл, топологи болон орно BLS Эзэмшлийн баталгаа
үүсгэсэн профайлд шаардлагатай. Kagami `localnet`, `wizard`, болон профайл
үеийн командууд нь эдгээр мэдээллийг автоматаар зохицуулдаг.

## Эхлэлийг дахин санал болгож байна {#recommitting-genesis}

Үе тэнгийнхэн нь агуулах нь хоосон байхад л генезис хийдэг.Шинэ генезийг туршихын тулд
нэг удаагийн локалнет, үе тэнгийнхнээ зогсоож, тэдгээрийн үүсгэсэн төрийн лавлахыг устгаж,
мөн шинэ гарын үсэг зурсан генезээс эхэлнэ.Гүйлт дээр генезисийг сольж болохгүй
баталгаажуулагч бүр ижил шилжилтийг зохицуулахгүй бол сүлжээ.
