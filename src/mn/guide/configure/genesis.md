Genesis нь эхлүүлэх зангилын орчинг тодорхойлдог. Тодруулж болох эх үүсвэр нь JSON манифест бөгөөд Iroha 3 түймэг Norito гүйлгээний гарын үсэг зурган файлыг хэрэглэдэг.

## Файлууд {#files}

Үүнээс дээш урсгалт хадгаламж `defaults/genesis.json` нэрийн дагуух манифест илгээдэг. Kagami-ийн үүсгэсэн сүлжээүүд өөрийн гэсэн манифест, гарын үсэг зурсан гүйлгээг гаргах каталогид бичнэ:

```bash
cargo run --bin kagami -- localnet --build-line iroha3 --peers 4 --out-dir ./localnet
```

Тухайн жагсаалтад үүсгэсэн `README.md` нь сонгогдсон хувилбарын тод файлуудыг болон эхлүүлэлтийн командуудыг бүртгэж байна.

## Нөхөр үеийнхний хувилбар {#peer-configuration}

`config.toml`-ийн `[genesis]` хэсэгт гарын үсэг зурсан эх үүсвэрийн бүтээн байгуулалтын талаарх ижил төстэй хүмүүс:

```toml
[genesis]
file = "./genesis.signed.nrt"
public_key = "ed0120..."
```

Сүлжээний бүх өрсөлдөгчид гарын үсэг зурсан генезисийн гүйлгээ болон генезисийн олон нийтийн түлхүүр дээр тохиролцсон байх ёстой.

## Эхлэлд гарын үсэг зурдаг {#signing-genesis}

Хэрэв та манифстийг гар утаснаар эхлүүлэхээс өмнө үүнийг баталгаажуулж, гарын үсэг зурна:

```bash
cargo run --bin kagami -- genesis validate ./genesis.json
cargo run --bin kagami -- genesis sign ./genesis.json \
  --private-key "$GENESIS_PRIVATE_KEY_HEX" \
  --algorithm ed25519 \
  --out-file ./genesis.signed.nrt
```

NPoS эсвэл Nexus хувилбарын хувьд, топологи болон үүсгэсэн хувилбараас шаардагдах Хуультай байдлын гэрчилгээг BLS бүртгүүлнэ. Kagami `localnet`, `wizard` болон хувилбарыг үүсгэх команд нь эдгээр мэдээллийг автомат хангах болно.

## Женезийг дахин эхлүүлэх {#recommitting-genesis}

Нөхөр нь зөвхөн хадгаламжгүй байх үедээ генез үйлдэж байна. Шинэ дэглэмийг нэг удаа ашиглах локаль сүлжээнд туршиж үзэхийн тулд өрсөлдөгчдийг зогсоож, үүсгэсэн төрийн захиалгыг арилгаж, Шинэ гарын үсэг зурсан эхлэлээс эхэлнэ. Бүх баталгаажуулагчаар ижил шилжилтийг зохицуулахгүй бол ажиллаж буй сүлжээний генезисийг алмашруулах хэрэггүй.
