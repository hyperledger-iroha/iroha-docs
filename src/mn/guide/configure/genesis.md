## Файлууд {#files}

Эх репозитор нь `defaults/genesis.json` дээр анхны техникийн мэдүүлгийг ачиж өгдөг. Kagami-ээр үүсгэсэн сүлжээ өөрийн техникийн мэдүүлэг болон гарын үсэгтэй гүйлгээг гаралтын хавтсанд бичнэ:

```bash
cargo run --bin kagami -- localnet --peers 4 --out-dir ./localnet
```

Тухайн хавтас дахь үүсгэсэн `README.md` нь сонгосон профайлд зориулсан яг ямар файлууд болон эхлүүлэх командуудыг бүртгэдэг.

## сүлжээний хамтрагчийн тохиргоо {#peer-configuration}

сүлжээний хамтрагчид `config.toml`-ийн `[genesis]` хэсэгт гарын үсэг зурсан блокчэйн генезис гүйлгээнд зааж өгдөг:

```toml
[genesis]
file = "./genesis.signed.nrt"
public_key = "ed0120..."
```

Сүлжээний бүх хамтрагчид гарын үсэг зурсан блокчэйн эхлэл транзакц болон блокчэйн эхлэл нийтийн түлхүүр дээр санал нэгдэх ёстой.

## Блокчэйн генезисийг гарын үсэг зурах {#signing-genesis}

Манифестыг гараар зассан бол зангилаануудыг эхлүүлэхээс өмнө шалгаж, гарын үсэг зурна:

```bash
cargo run --bin kagami -- genesis validate ./genesis.json
cargo run --bin kagami -- genesis sign ./genesis.json \
  --private-key-file "$GENESIS_PRIVATE_KEY_FILE" \
  --out-file ./genesis.signed.nrt
```

`GENESIS_PRIVATE_KEY_FILE` нь эзэндээ хамаарах горим-`0600` байх ёстой бөгөөд нэг протокол-стандартын хувийн түлхүүрийн олон хэш болон төгсгөлийн шинэ мөр агуулах нэг холбоостой энгийн файл байх ёстой. Kagami нь дүрс холбоосыг няцааж, командын мөрөнд цэвэр блокчэйн генезисын хувийн түлхүүрийг огт хүлээж авдаггүй.

NPoS эсвэл Nexus профайлд зориулж үүсгэсэн профайлд шаардлагатай топологийг болон BLS эзэмшлийн нотолгоог оруулаарай. Kagami `localnet`, `wizard`, болон профайл үүсгэх командууд эдгээр дэлгэрэнгүй мэдээллийг автоматаар удирдана.

## Блокчейн генезисийг дахин баталгаажуулах {#recommitting-genesis}

Зангилаа хадгалалт нь хоосон үед л genesis-ийг баталгаажуулна. Шинэ genesis-ийг түр localnet-д туршихдаа зангилаануудыг зогсоож, үүсгэсэн төлөвийн санг устгаад, шинэ гарын үсэгтэй genesis-ээс эхлүүлнэ. Бүх баталгаажуулагч шилжилтээ уялдуулаагүй бол ажиллаж буй сүлжээний genesis-ийг бүү солино.
