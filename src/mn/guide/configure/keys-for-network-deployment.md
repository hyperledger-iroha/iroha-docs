# Сүлжээний ашиглалтын ач холбогдол {#keys-for-network-deployment}

Бүх сүлжээний хэрэглэгчид, хамт олон, генезисийн гарын үсэг зурах,
болон НПОС-ийн хувьд эсвэл Nexus хувилбар, BLS баталгаажуулагчын тодруулгыг.

## Хүйцүүр ашигладаг газар {#where-keys-are-used}

- Хэрэглэгчийн гарын үсэг зурах түлхэгийг хадгалах `client.toml` доор `[account]`.
- Хэдэн үеийнхний тодруулгын товчлогыг аль нэг нь хадгалах `config.toml` Үүнд `public_key` болон
  `private_key`.
- Хөгжлийн ололт нь бүххний төрийн товчлогыг ашигладаг `trusted_peers`.
- BLS баталгаажуулагч Хуультай байдлын гэрчилгээ `trusted_peers_pop` НПУ-ын хувьд
  Profiles.
- Женезисийн гарын үсэг нь `[genesis].public_key` хамтын ажиллагааны байгууллага,
  Мэргэжилт бичигт гарын үсэг зурахад хувийн түлхүүртэй нийцнэ.

Орон нутгийн болон туршилтын хэрэглээнд Kagami эдгээр файлуудыг бүгд нэгтгэн бүтээх:

```bash
cargo run --bin kagami -- localnet --build-line iroha3 --peers 4 --out-dir ./localnet
```

Орчин үеийн сүлжээ эсвэл профилийн хувьд удирдуулсан урсгалыг ашигла:

```bash
cargo run --bin kagami -- wizard --profile nexus
```

## Тус дуудлаганы хосуулгыг бүтээх {#generate-individual-key-pairs}

Хэрэглээ `kagami keys` бие даасан гол материалын хувьд:

```bash
cargo run --bin kagami -- keys --algorithm ed25519 --json
```

Үүнд BLS баталгаажуулагч материал, эзэмшилийн гэрчилгээ:

```bash
cargo run --bin kagami -- keys --algorithm bls_normal --pop --json
```

Хэрэглээ `--seed` Зөвхөн дахин боловсруулах хөгжлийн тоног төхөөрөмжүүдэд зориулагдсан
нэвтрүүлэг, шинэхэн түлхүүр бий болгох, хувийн түлхүүдийг хадгалах.

## Хоёр үеийнхний тогтвортой байдал {#peer-consistency}

Бүх баталгаажуулагчид ижил генезисийн гүйлгээ, топологи, итгэмжлэгдсэн
олон нийтийн түлхүүр, баталгаажуулагч PoPs. Ганц хохирогч эсвэл тохиромжгүй дутагдал
сүлжээг эхлүүлж, тохиролцоонд хүргэхээс урьдчилан сэргийлэх.

Бизантийн гэмт хэргийг хүлээн зөвшөөрөх хамгийн бага хэрэглээнд дор хаяж дөрвөн өрсөлдөгч ашиглах хэрэгтэй.
Peer нь өөрийн гэсэн хувийн түлхүүртэй байх ёстой, гэхдээ бүх peer конфигурацын хувьд ижил хэрэгтэй
Итгэмжлэгдсэн өрсөлдөгч.

## Хэрэглэгчийн данс {#client-accounts}

Хэрэглэгчийн данс `client.toml` Энэ нь аль хэдийн л зангилаа дээр байх ёстой.
Женезис манифест эсвэл дараагийн гүйлгээгээр бүртгэгдсэн.
генезис-ийн гарын үсэг зурсан тодорхойлолт урт хугацааны хэрэглээний бүртгэл; генезисийн эрх
зөвхөн генезис шатны үед хэрэглэх бөгөөд үйлдвэрлэлийн үйлчлүүлэгчид өөрсдийнхөө
бүртгэл, үүрэг.
