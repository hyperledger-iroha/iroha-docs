# Сүлжээ байршуулалтын түлхүүрүүд {#keys-for-network-deployment}

Бүх сүлжээнд клиент, зангилаа, genesis-ийн гарын үсэг зурагч болон NPoS эсвэл Nexus профайлын BLS баталгаажуулагчийг таних түлхүүрийн материал шаардлагатай.

## Хэрэглэгдэх түлхүүр {#where-keys-are-used}

- Клиентийн гарын үсгийн түлхүүрийг `client.toml` файлын `[account]` хэсэгт хадгална.
- Зангилааны таних түлхүүрийг зангилаа бүрийн `config.toml` файлд `public_key` болон `private_key` болгон хадгална.
- Зангилаа илрүүлэлт нь `trusted_peers` дэх зангилаа бүрийн нийтийн түлхүүрийг ашиглана.
- NPoS профайлын BLS баталгаажуулагчийн эзэмшлийн нотолгоог `trusted_peers_pop`-д хадгална.
- Genesis-д гарын үсэг зурахдаа зангилааны тохиргооны `[genesis].public_key` болон манифестад гарын үсэг зурах тохирох хувийн түлхүүрийг ашиглана.

Орон нутгийн болон туршилтын хэрэглээний хувьд Kagami нь эдгээр файлуудыг нэгтгэн бүтээх болно:

```bash
cargo run --bin kagami -- localnet --peers 4 --out-dir ./localnet
```

Орчин үеийн сүлжээ эсвэл хувилбарын хувьд заасан урсгалыг ашиглах:

```bash
cargo run --bin kagami -- wizard
```

## Тусдаа түлхүүрийн хос үүсгэх {#generate-individual-key-pairs}

Бие даасан түлхүүрийн материалд `kagami keys` ашиглана:

```bash
cargo run --bin kagami -- keys --algorithm ed25519 \
  --out-dir ./client-key
```

BLS баталгаажуулагчийн материалд Proof-of-Possession оруулна:

```bash
cargo run --bin kagami -- keys --algorithm bls_normal --pop \
  --out-dir ./validator-key
```

`--seed-hex`-ийг зөвхөн дахин үүсгэж болох хөгжүүлэлтийн туршилтын өгөгдөлд, яг 32 байтын арван зургаатын нууцтай ашиглана. Үйлдвэрлэлийн байршуулалтад Kagami үйлдлийн системийн санамсаргүй утгыг ашиглахын тулд үүнийг орхиж, дараа нь шифрлээгүй хувийн түлхүүрийн экспортолсон файлыг зөвшөөрөгдсөн хадгалалтын хил рүү шилжүүлнэ. Тушаал хувийн түлхүүрийг хэзээ ч хэвлэхгүй.

## Эрдэмтдийн хамтын ажиллагаа {#peer-consistency}

Бүх баталгаажуулагчид ижил үүсэл бүтээн байгуулалтын, топологийн, итгэхэд зориулсан олон нийтийн түлхүүр болон баталгаажуулагч PoPs талаар тохиролцох ёстой. Ганц алдаатай эсвэл ижил төстэй ач холбогдолгүй нь сүлжээг эхлүүлж, тохиролцоонд хүрэхээс сэргийлж болно.

Бизантийн гэмт хэргээс урьдчилан сэргийлэх хамгийн бага хэрэглээнд дор хаяж дөрвөн зангилаа ашиглах хэрэгтэй. Зангилаа бүрийн өөрийн гэсэн хувийн түлхүүр байх ёстой, гэхдээ ижил итгэмжлэгдсэн зангилааны багц нь бүх зангилааны хэрэгтэй.

## Хэрэглэгчдийн данс {#client-accounts}

`client.toml`-ийн үйлчлүүлэгчдийн данс аль хэдийн сүлжээ дээр байх ёстой. Энэ нь генезисийн манифестээр эсвэл дараагийн гүйлгээгээр бүртгэгдэж болно. Генезисийн гарын үсэг зурах тавиланг удаан хугацааны хэрэглээний данс болгон ашиглахаас зайлсхийх; Женезис хувилбарыг зөвхөн Женезисийн шатны үеэр ашигладаг бөгөөд үйлдвэрлэлийн үйлчлүүлэгчид өөрийн бүртгэл, үүргийг ашиглах ёстой.
