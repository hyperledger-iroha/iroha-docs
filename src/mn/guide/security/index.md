# Аюулгүй байдал {#security}

Хэрэглээний үед Iroha Энэ нь санхүүгийн байгууллагуудад итгэлийг хангах үндсийг бүрдүүлж байгаа тул аюулгүй байдал чухал ач холбогдолтой.

### Газар суудлын {#navigation}

Энэ хэсэгт та өөрийн Iroha Олон нийтийн мэдээллийн хэрэгсэл.

- [Аюулгүй байдлын зарчим](./security-principles):

  Мэдээллийг хамгаалах, зөрчлийн болон/або урвалын эрсдлийг бууруулахын тулд хувь хүн болон байгууллагууд баталгаажуулж болох аюулгүй байдлын үндсэн зарчим.

- [Виртуал хувийн сүлжээ](./vpn.md):

  Асуултыг хэрхэн ашиглах VPN өрсөлдөгчдийн хоорондын харилцаанд хязгаарлалт тогтоох, Torii, хувийн болон консорциумын нэвтрүүлэгт үйл ажиллагаа явуулж буй үйлдвэрийн хэрэглэгчдийн хүртээмж.

- [Үйл ажиллагааны аюулгүй байдал](./operational-security.md):

  Таны сүлжээний өдөр тутмын үйл ажиллагааг хамгаалах сайн дасгалууд, тэр дундаа хангамжийн хяналт, хяналтын ажил, тохиолдлын хариу арга хэмжээ, браузер ашиглах гэх мэт.

- [Халуулгын хяналт](./fraud-monitoring.md):

  Хэрэглээний жагсаалтыг ашиглах, асуултууд, зөвшөөрөл, үйл ажиллагааны сигналыг эргэлзээтэй үйл ажиллагааг илрүүлэх, хариу үйлдлийн баримтыг хадгалах.

- [Хууль нууцын аюулгүй байдал](./password-security.md):

  Хууль нууцын энтропийг гүнзгийрүүлж, хүчтэй нууц үгсийг бий болгож, нууц үгний эмзэг байдлыг салах.

- [Олон нийтийн ач холбогдолтой криптограф](./public-key-cryptography.md):

  Олон нийтийн ач холбогдолтой криптографи, шифрлэлт, гарын үсэг зуралт болон блокчейн дотроо аюулгүй харилцаа холбоог байгуулж байх үүргээ танилцуулах.

  - [Криптографийн түлхүүр үүсгэх](./generating-cryptographic-keys.md):

    Криптографийн түлхүүр бий болгох, ашиглах талаар заавар `kagami` (Эрдэнэт үйлдвэрлэгчид Iroha).

  - [Криптографийн түлхүүр хадгалах](./storing-cryptographic-keys.md):

    Худалдааны нууц товчлогыг хамгаалхын тулд янз бүрийн арга замтай, мөн нэгтгэж болно.
