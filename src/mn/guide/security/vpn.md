## Хэвлэл хэрэглэх цаг VPN {#when-to-use-a-vpn}

A-ыг ашигла VPN дараах тохиолдолд:

- баталгаажуулагчдыг янз бүрийн байгууллагууд эсвэл өөр хостинг газарт ашигладаг
  байгаль орчин
- Torii Зөвхөн хэрэгслийн хяналт талууд, оператор эсвэл итгэхэд хүрэх байх ёстой
  үйлчлүүлэгчид
- метрик, бүртгэл, SSH, эсвэл бусад удирдлагын төгсгөл нь хувийн хэвшлийн
  операторны сүлжээ

## Хөдөлмөрийн загвар {#deployment-pattern}

Хувийн баталгаажуулагчийн машны хувьд, бүх баталгаажуучдад VPN хаяг эсвэл
хувийн DNS нэр. Үзэсгэлэнт дуудлагад орсон өрсөлдөгчдийн хаяг
бусад баталгаажуулагчдаас тухайн сүлжээгээр хүрэх боломжтой:

```toml
trusted_peers = [
  "PUBLIC_KEY_1@10.20.0.11:1337",
  "PUBLIC_KEY_2@10.20.0.12:1337",
  "PUBLIC_KEY_3@10.20.0.13:1337",
  "PUBLIC_KEY_4@10.20.0.14:1337",
]

[network]
address = "10.20.0.11:1337"
public_address = "10.20.0.11:1337"

[torii]
address = "10.20.0.11:8080"
```

Одоогийн дундад бүртгэгдсэн хаягийг ашигла `network.address` болон
`network.public_address`. Хоёр ч ижил итгэж буй хосуудын жагсаалтыг гаргах ёстой.
Гэхдээ өөрийнх нь хаягаар хүрэх боломжтой VPN Замын хүснэгт.

Хэрэглэгчийн болон CLI конфигурацыуд нь Torii Хөгжлийн тоонд хүрэх боломжтой
УИХ-ын гишүүн VPN эсвэл хяналтын дотоод даргыг дамжуулан:

```toml
torii_url = "http://10.20.0.11:8080"
```

Хэрэв Torii Уул уурхайн газраас гадаад VPN, үүнийг эргэн төлөөлөгчийн ард байрлуулна уу
ачаалал тэнцвэржүүлэгч TLS, Үнэнчлэгдэх, түвшинг хязгаарлах, бүртгэх.
Хөдөлмөрийн хэрэгслийн үр дүнд шууд халдварын хоолой
Олон нийтийн интернэт.

## Төмөр замын дүрэм {#firewall-rules}

Хост болон цагаан туяаны брандмауэр дүрэмүүдийг хэрэглэхийн тулд VPN байгаа:

| Үйлчилгээ | Зөвлөсөн хангамж |
| --- | --- |
| Хөдөлмөр зөөврийн | Өөр баталгаажуулагч VPN Зөвхөн хаяг |
| Torii | Хэрэглээний хяналт, оператор, эсвэл итгэх үйлчлүүлэгч VPN түвшин |
| Метрик болон эрүүл мэндийн хяналт | Үйлчлүүлэгчдийн сүлжээний хяналтын систем |
| SSH болон удирдлага | Бастийн хөтлөгч, эрхэмлэгдсэн оператор VPN гаралтай, эсвэл шилэн буулгах үйл ажиллагаа |
| Хөдөлмөрийн санхүүжилт, хадгаламж | Хувийн сүлжээний санхүүжилтийн систем |

Урьдчилсан хэрэгсэлээс татгалзсан дүрэмүүдийг хяналт шалгах нь өргөн цар хүрээний зөвшөөрөлтэй дүрэмүүдээс илүү амархан байдаг.
сүлжээнд нэгдэн орж, VPN гишүүнчлэл, гал түймрийн дугуйны зөвшөөрлийн жагсаалт, Iroha
Итгэмжлэгдсэн өрсөлдөөн нь нэг зохицуулсан өөрчлөлт.

## Үйл ажиллагааны шалгалтын жагсаалт {#operational-checklist}

- Хяналт шалгагдаж, идэвхтэй хадгалж байгаа нэгнийг сонгоно VPN хэрэгжүүлэх,
  WireGuard, IPsec буюу байгууллагын зөвшөөрөлтэй хувийн сүлжээ.
- Үндэсний хэрэглээ VPN Хост болон оператор бүрийн итгэлийг хуваалцахгүй VPN түлхүүр
  баталгаажуулагчдын хооронд.
- Хөрөөж байна VPN эрдэм шинжилгээ Iroha хувийн түлхүүр, эх үүсвэрийн гарын үсэг
  материал.
- Хяналт шалгаруулах VPN Хөгжил, пакетын алдагдал, дахин холболт, чиглэлийн өөрчлөлт.
  Төгсгөлтэй сүлжээний тогтворгүй байдалтай холбоотой эмзэг.
- Эффектив байдлыг шалгах MTU. Пакетын хуваагдал нь хоорондоо харилцан адил харагдаж болно
  эсвэл Torii алдаа.
- Энэ баримт бичиг VPN Бүрэн үеийнхэнд хүрэх хамааралтай, Torii, метрик,
  SSH, болон дэмжлэг үзүүлэх төгсгөлийн цэг.
- Хөгжүүлнэ VPN Үйлчлүүлэгч, операторын данс эсвэл байгууллага гарах үед хүлээн зөвшөөрөгдлийн мэдээлэл
  Сүлжээ.
- Ганцхан ч бүү хий. VPN Эрдэнэт үйлдвэрлэгчдийн хоорондын цорын ганц замыг хаалга гэж үздэг.
  үйлдвэрлэлийн сүлжээний зайлшгүй нэвтрүүлэг эсвэл газраас газар руу чиглэгдэх зам.
- Нэвтрүүлнэ VPN үйл явдлын хариу арга хэмжээний алдаатай тул оператор нар хэзээ хийхээ мэддэг
  сүлжээний хуваарийг Iroha үйл явцын алдаа.
