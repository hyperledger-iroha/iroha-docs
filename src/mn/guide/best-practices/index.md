# Хамгийн сайн заншил {#best-practices}

Энэ хэсэгт үйлдвэрлэлийн чиглэлээр чиглэсэн удирдамжийг цуглуулж байна Iroha өргөдөл
Энэ нь та хийх ёстой шийдвэрийн дагуу зохион байгуулагдана,
Үүнийг хэрэгжүүлэх шинж чанар.

Энэ нь хамтарсан тест-нет репетиц, үйлдвэрлэлийн өмнө шалгалтын жагсаалтад ашиглана.
Хөгжлийн хэрэглэгчийн нэвтрүүлэг, эсвэл томоохон төлөөлөл гаргах.

## Хөрсгөлтийн дүрэм {#cross-cutting-rules}

- Орон нутгийн хөгжил, хамтарсан тест сүлжээ, үйлдвэрлэлийн конфигурацийг хадгалах
  Ялгарах.
- Женезис, дундаж топологи, гүйцэтгэгч бодлого болон гол материалыг
  хяналт тавих артефактууд.
- Тогтвортой номын жагсаалтын загварын хэлцэл санаатай.
  том, хувийн болон өндөр хохиролтой мэдээллийн хаягдал.
- Хэрэг эрхлэх боломжтой ажил урсгалын дамжуулан гүйлгээг хүргүүлнэ
  Хөгжлийн хязгаарлалт, хугацаа дууссан байдал, дахин туршилтууд болон хохирсон байдал.
- Удахгүй зөвшөөрөл, зориулсан техникийн тооцоо, тодорхой
  удирдахчийн өргөн хүртээмжтэй үйл ажиллагааны ажиллагаанд зориулсан хөтөч.
- Эхлээд нэг удаа ашиглах орон нутгийн сүлжээний үйл ажиллагааг баталж, дараа нь
  Taira эсвэл ямар ч гол сүлжээний үйл ажиллагааны өмнө бусад хамтарсан туршилтын сүлжээ.
