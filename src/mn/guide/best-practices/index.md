# Шилдэг туршлага {#best-practices}

Энэ хэсэг нь Iroha програмууд ба сүлжээнүүдэд үйлдвэрлэлд чиглэсэн заавар зөвлөмжийг цуглуулдаг. Энэ нь хэрэгжүүлэх боломжтой онцлог шинж чанараар нь бус, таны гаргах шаардлагатай шийдвэрээрээ зохион байгуулсан.

Үүнийг хамтарсан тестнет-ийн дадлага, үйлдвэрлэлийн нээлт, эсвэл томоохон клиентэд зориулсан хувилбар гаргахын өмнө шалгах жагсаалт болгон ашигла.

## Хөндлөнгийн дүрэм {#cross-cutting-rules}

- Орон нутгийн хөгжүүлэлт, нийтлэг туршилтын сүлжээ, үйлдвэрлэлийн тохиргоог тусад нь байлга.
- Блокчейн генезис, сүлжээний түншийн топологи, гүйцэтгэгчийн бодлого болон түлхүүр материалыг хяналттай нэвтрүүлгийн баримт бичиг гэж үзээрэй.
- Моделикууд тэсвэртэй блокчейн бүртгэлийн төлөвийг зориуд бий болго. Том, хувийн эсвэл их эргэлттэй өгөгдлийг хадгалах газар болгон мета өгөгдөл ашиглаж болохгүй.
- Төлбөр төлөлтүүдийг татгалзалт, хугацаа дуусах, дахин оролт хийх болон хойшлуулсан төлөв байдлыг зохицуулж чадах идемпотент урсгалуудаар илгээнэ үү.
- Өргөн администраторын хандалттай харьцуулахад нарийн хандалтын эрхийг, тусгай зориулалтын техникийн дансуудыг, тодорхой ажиллагааны гарын авлагыг илүүд үзээрэй.
- Эхлээд хэрэглэсэн орон нутгийн сүлжээнд үйлдлийг батал, дараа нь аливаа mainnet үйлдлийн өмнө Taira эсвэл өөр нийтлэгдсэн тестнет дээр давталт хийгээрэй.
