# الدليل {#guide}

استخدم هذا القسم عندما تقوم ببناء أو تشغيل أو دمج Iroha. ابدأ مع دراسات SDK لعميل أول، ثم انتقل إلى أفضل الممارسات والإشارات للمشغل قبل نشرها ضد شبكة مشتركة.

## الأقسام {#sections}

|القسم |استخدمها لـ|
| ------------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------- |
| [SDK تعليمات](/ar/guide/tutorials/) |إعداد العميل المحدد للغة ومعينة التطبيقات |
| [أفضل الممارسات ](/ar/guide/best-practices/) |الإرشادات المستهدفة للإنتاج المجموعة حسب التطوير ونموذجية البيانات والتنفيذ والعمليات والأمن والاستعداد للانطلاق |
| [تشكيل وإدارة ](/ar/guide/configure/overview.md) |تكوين الأقران المحلي، والتكوين، وتكوين العملاء، والمفاتيح، وإدارة الأقران |
| [الأمن ](/ar/guide/security/) |إدارة المفاتيح والأمن التشغيلي، VPNs ، مراقبة الاحتيال، ونظافة الإذن |
| [العمليات المتقدمة](/ar/guide/advanced/metrics.md) |المقاييس، فحص الأداء، اختبار الفوضى، إعادة التحميل الساخن، والعمل مع المعادن العارية |

## الطريق الموصى به {#recommended-path}

1. [قم بتثبيت Iroha 3](/ar/get-started/install-iroha.md) و [إطلاق شبكة محلية ](/ar/get-started/launch-iroha.md).
2. اختر [SDK التعليمية ](/ar/guide/tutorials/) وتقديم معاملة صغيرة.
3. مراجعة [تنمية التطبيقات](/ar/guide/best-practices/application-development.md) و [نمذجة البيانات ](/ar/guide/best-practices/data-modeling.md) قبل تشكيل الطلبات API.
4. استخدم [تشغيل الشبكة](/ar/guide/best-practices/network-deployment.md)، [عمليات](/ar/guide/best-practices/operations.md)، و [أمن والوصول](/ar/guide/best-practices/security-and-access.md) قبل تشغيل شبكة مشتركة أو الإنتاج.
5. اتبع [استعداد الإفراج](/ar/guide/best-practices/release-readiness.md) عند الترويج من التنمية المحلية إلى Taira، Minamoto، أو نشر مباشر آخر.
