# الدليل {#guide}

استخدم هذا القسم عندما تقوم ببناء أو تشغيل
Iroha. ابدأ من SDK التعليمات للعميل الأول، ثم الانتقال إلى
أفضل الممارسات والإشارات للمشغلين قبل الانتشار مقابل
الشبكة

## الأقسام {#sections}

| القسم                                                      | استخدمها                                                                                                                  |
| ------------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------- |
| [SDK الدروس](/ar/guide/tutorials/)                           | إعداد العميل الخاص باللغة ومعينة من التطبيقات                                                                      |
| [أفضل الممارسات](/ar/guide/best-practices/)                     | الإرشادات المستهدفة للإنتاج المجموعة حسب التطوير وتصميم النماذج البيانية والتنفيذ والعمليات والأمن والاستعداد للإطلاق |
| [التكوين والإدارة](/ar/guide/configure/overview.md) | تكوين الأقران المحلي، والتكوين، وتكوين العميل، والمفاتيح، وإدارة الأقران                                          |
| [الأمن](/ar/guide/security/)                                 | إدارة المفاتيح والأمن التشغيلي VPNs, مراقبة الاحتيال ونظافة الإذن                                          |
| [العمليات المتقدمة](/ar/guide/advanced/metrics.md)            | المقاييس، فحص الأداء، اختبار الفوضى، إعادة التحميل الحار، والعمل مع المعادن العارية                                            |

## الطريق الموصى به {#recommended-path}

1. [التثبيت Iroha 3](/ar/get-started/install-iroha.md) و
   [إطلاق شبكة محلية](/ar/get-started/launch-iroha.md).
2. اختر واحدة [SDK التعليمات](/ar/guide/tutorials/) وقدموا قليل
   المعاملة
3. المراجعة
   [تطوير التطبيقات](/ar/guide/best-practices/application-development.md)
   و [نمذجة البيانات](/ar/guide/best-practices/data-modeling.md) قبل ذلك
   تشكيل طلب API.
4. الاستخدام [تنفيذ الشبكة](/ar/guide/best-practices/network-deployment.md),
   [العمليات](/ar/guide/best-practices/operations.md), و
   [الأمن والوصول](/ar/guide/best-practices/security-and-access.md)
   قبل تشغيل شبكة مشتركة أو الإنتاج.
5. اتبع [الاستعداد للإفراج](/ar/guide/best-practices/release-readiness.md)
   عند الترويج من التنمية المحلية إلى Taira, Minamoto, أو غيرها
   نشر مباشر.
