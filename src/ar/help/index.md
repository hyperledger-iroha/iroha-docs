# الحصول على الدعم {#receive-support}

من وقت لآخر، قد يكون لديك أسئلة حول Iroha هناك ثلاثة طرق للتواصل بسرعة مع مجتمعنا: تلغرام، Discord، و GitHub.

المجتمع يستخدم [تلغرام](https://t.me/hyperledgeriroha) و
[LF Decentralized Trust الخلافات](https://discord.gg/hyperledger) لـ
التواصل. `iroha` قناة للأسئلة المشروعية.

أخيراً، يمكنك [خلق GitHub الإصدار](https://github.com/hyperledger-iroha/iroha/issues/new/choose), سواء كان طلبًا لتحديث الوثائق أو اقتراحًا للفريق الأساسي، أو خطأ وجدت.
