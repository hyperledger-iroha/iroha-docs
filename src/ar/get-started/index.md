# Iroha 3 {#iroha-3}

Iroha 3 هو الإصدار الأول Hyperledger Iroha منصة. يدعم الشبكات المضيفة الذاتية ومجال البيانات المتعددة SORA Nexus نموذج النشر من قاعدة رمزية محددة واحدة.

في مستوى عال، Iroha 3 يجمع بين:

- التنفيذ والتخزين المحدد
- الآلة الافتراضية Iroha (IVM) لعقود ذكية محمولة
- Norito بصيغة الأسلاك القنونية
- Torii للعميل والمشغل والتي تواجه التطبيق APIs
- Sumeragi إجماع مع توفر البيانات الإلزامية والبث الموثوق به
- الحسابات القانونية بدون نطاق مع أسماء مستعار قابلة للقراءة من قبل الإنسان مرتبطة بشكل منفصل
