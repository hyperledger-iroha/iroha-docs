# Iroha 3 {#iroha-3}

Iroha 3 هو منصة Hyperledger Iroha الإصدار الأول. وهي تدعم الشبكات المستضافة ذاتيًا ونموذج النشر متعدد مساحات البيانات SORA Nexus من قاعدة كود واحدة حتمية.

على مستوى عالٍ، يجمع Iroha 3 بين:

- التنفيذ والتخزين الحتميان
- الآلة الافتراضية Iroha (IVM) للعقود الذكية المحمولة
- Norito كصيغة التسلسل المعيارية
- Torii للعميل، والمشغل، وواجهة التطبيق APIs
- Sumeragi توافق مع توفر البيانات الإلزامي والبث الموثوق
- حسابات معيارية بدون نطاق مع ألقاب قابلة للقراءة بشريًا مرتبطة بشكل منفصل
