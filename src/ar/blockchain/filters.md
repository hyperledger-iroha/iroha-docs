# الصفائح {#filters}

تصفية تدفقات الأحداث الضيقة وتشغيل الظروف.
فلتر الأحداث `EventFilterBox`, التي يمكن أن تتطابق مع هذه العائلات الحدث:

- `Pipeline`
- `Data`
- `Time`
- `ExecuteTrigger`
- `TriggerCompleted`

استخدم أصغر مرشح يتناسب مع سير العمل.
`DataEventFilter::Any` فهي مفيدة للتشخيص، لكنها تجعل كل حدث
دفع تكلفة تشغيل أو مطابقة المشترك.

## مرشحات الأحداث {#data-event-filters}

`DataEventFilter` تتطابق مع أحداث بيانات الكتيبة. وتشمل إختلافاتها الحالية:

| المتغيرات | عائلة الأحداث |
| --- | --- |
| `Any` | أي حدث بياني |
| `Peer` | أحداث دورة حياة الأقران |
| `Domain` | أحداث دورة حياة النطاق وميتاداتا |
| `Account` | دورة حياة الحساب، البيانات الأساسية، الاسم الخاطئ، وحوادث الهوية |
| `Asset` | حوادث ميزان الأصول و البيانات المعدنية |
| `AssetDefinition` | دورة حياة تعريف الأصول والسياسة وأحداث البيانات المعدنية |
| `Nft` | NFT أحداث دورة الحياة وميتاء البيانات |
| `Rwa` | أحداث دورة حياة الأصول في العالم الحقيقي |
| `Trigger` | أحداث دورة حياة المحفز والبيانات المعدنية |
| `Role` | أحداث دورة حياة الدور |
| `Configuration` | أحداث التكوين في السلسلة |
| `Executor` | أحداث تنفيذ الوقت التشغيلي |
| `Proof` | أحداث دورة حياة التحقق من الأدلة |
| `Confidential` | أحداث الأصول السرية |
| `VerifyingKey` | أحداث سجل المفاتيح التحقق |
| `RuntimeUpgrade` | أحداث تحديث الوقت التشغيلي |
| `Soradns` | الحل أحداث حوكمة السجلات |
| `Sorafs` | SoraFS الأحداث المتعلقة بموافقة البوابة |
| `SpaceDirectory` | دليل الفضاء إشارة أحداث دورة الحياة |
| `Escrow` | الأحداث الشفافة في دورة حياة الاحتفاظ بالأصول الأصلية |
| `Offline` | أحداث تسوية خارج الإنترنت |
| `Oracle` | أحداث تغذية Oracle |
| `Social` | أحداث التحفيز الفيروسية |
| `Bridge` | أحداث الجسر |
| `Governance` | أحداث الحوكمة عندما يتم تمكين ميزة الحوكمة |

معظم مرشحات الخرسانة تسمح أيضا اختياري ID و قناع من أجل الأحداث
على سبيل المثال، يمكن لمرشح الأصول أن يطابق أصل واحد أو فئة واحدة من أحداث الأصول.
في حين أن مرشح الزناد يمكن أن يطابق الزناد ID ومجموعة حوادث الزناد

## مرشحات خطوط الأنابيب {#pipeline-filters}

تصفيح خطوط الأنابيب تتطابق مع أحداث المعالجة مثل الكتل والمعاملات والانضمام
واستخدامها في الاشتراكات التشغيلية
لوحات التحكم والتحفيزات التي تتفاعل مع حالة خط الأنابيب بدلاً من بيانات الكتيبة
الأشياء.

## فلترات المحفز {#trigger-filters}

الاضطرابات تخزن حالتها كـ `EventFilterBox`. خطوة محفزة أيضا
المتاجر:

- مفعول
- سياسة التكرار
- حساب سلطة
- سياسة اختياريّة لإعادة تجربة محفز الوقت
- البيانات

يجب أن يكون لدى سلطة التشغيل الإذنات المطلوبة من قبل القابل للتنفيذ.
يفضلون حسابات تقنية مخصصة لتحفيرات طويلة العمر.

## مرشحات الأسئلة {#query-filters}

فلترات الاستطلاع منفصلة عن فلترات الأحداث. يمكن للاستفسارات المتكررة الكشف
دعم المواعيد والانتخابات. استخدم مرشحات محددة للطلب من SDK
لذا فإن مدخل المرشح يطابق نوع إصدار الاستطلاع.
