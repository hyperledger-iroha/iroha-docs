# انسٹالیشن کے مسائل کا حل {#troubleshooting-installation-issues}

اس سیکشن میں Iroha 3 تنصیب کے لئے خرابیوں کا سراغ لگانے کی تجاویز پیش کی جاتی ہیں۔ اگر آپ کو جو مسئلہ درپیش ہے وہ یہاں بیان نہیں کیا گیا ہے تو ، ہم سے رابطہ کریں [ٹیلیگرام](https://t.me/hyperledgeriroha).

## فوری چیک {#quick-checks}

زیادہ تر تنصیب کی ناکامیاں چار مقامات میں سے ایک سے آتی ہیں:

- ایک Rust ٹول چین جو اپ اسٹریم ورک اسپیس کی طرف سے منسلک ورژن سے پرانا ہے
- `cargo` یا `rustc` سے مختلف تنصیب میں حل کرنے والی `rustup`
- لاپتہ نظام کی تعمیر کے اوزار جیسے سی کمپائلر، `pkg-config` یا CMake
- ماخذ کی نظر ثانیوں کو تبدیل کرنے کے بعد پرانے بنائے گئے ٹکڑے یا مقامی تعمیراتی آثار

Iroha ذریعہ چیک آؤٹ سے، شروع کریں:

```bash
rustup show
cargo --version
rustc --version
cargo metadata --no-deps
```

اگر `cargo metadata` ناکام ہوجاتا ہے تو، `pnpm refresh:iroha --source /path/to/iroha` کو چلانے سے پہلے مقامی ٹولچین کو درست کریں، کیونکہ تازہ کاری موجودہ ڈیٹا ماڈل اسکیم پیدا کرنے کے لئے Kagami پر زور دے سکتی ہے.

## خرابیوں کا سراغ لگانا Rust ٹولچین {#troubleshooting-rust-toolchain}

کبھی کبھی ، چیزیں منصوبہ بندی کے مطابق نہیں چلتی ہیں۔ خاص طور پر اگر آپ کے پاس کچھ عرصہ پہلے `rust` تھا تو ، لیکن اپ گریڈ نہیں کیا تھا۔ اسی طرح کا مسئلہ Python میں ہوسکتا ہے: XKCD اس کی ایک مشہور مثال ہے کہ یہ کیسا لگ سکتا ہے۔

### Rust ورژن چیک کریں {#check-rust-version}

آپ کی صحت اور ہماری ذہنیت دونوں کو برقرار رکھنے کے مفاد میں ، اس بات کا یقین کریں کہ آپ کے پاس `cargo` کا صحیح ورژن ہے جو `rustc` کے صحیح ورژن کے ساتھ جوڑا ہوا ہے۔ موجودہ اپ اسٹریم ورک اسپیس `rust-version = "1.92"` کا اعلان کرتا ہے اور ٹولچین چینل کو `rust-toolchain.toml` میں پن کرتا ہے۔ ورژن دکھانے کے لئے ،

```bash
$ cargo -V
$ cargo 1.93.1 (...)
```

اور پھر

```bash
$ rustc --version
$ rustc 1.93.1 (...)
```

اگر آپ کے پاس اعلی ورژن ہیں تو، آپ ٹھیک ہیں. اگر آپ کو کم ورژن ہے تو، آپ اسے اپ ڈیٹ کرنے کے لئے مندرجہ ذیل کمانڈ چلائیں:

```bash
$ rustup toolchain update stable
```

### تنصیب کی جگہ چیک کریں {#check-installation-location}

اگر آپ کو کم ورژن نمبر ملتے ہیں اور آپ نے ٹول چین کو اپ ڈیٹ کیا ہے اور یہ کام نہیں کرتا ہے... چلو صرف یہ کہتے ہیں کہ یہ ایک عام مسئلہ ہے، لیکن اس کا کوئی مشترکہ حل نہیں ہے.

سب سے پہلے، آپ کو اس بات کی نشاندہی کرنا چاہئے کہ آپ جس ورژن کا استعمال کرنا چاہتے ہیں وہ کہاں نصب ہے:

```bash
$ rustup which rustc
$ rustup which cargo
```

ٹول چینز کے صارف تنصیبات عام طور پر `~/.rustup/toolchains/stable-*/bin/` میں ہیں. اگر ایسا ہے تو، آپ کو چلانے کے قابل ہونا چاہئے

```bash
$ rustup toolchain update stable
```

اور اس سے آپ کے مسائل کو حل کرنا چاہئے.

### ڈیفالٹ ورژن Rust چیک کریں {#check-the-default-rust-version}

ایک اور آپشن یہ ہے کہ آپ کے پاس تازہ ترین `stable` ٹولچین ہے ، لیکن یہ پہلے سے طے شدہ طور پر مقرر نہیں ہے۔ چلائیں:

```bash
$ rustup default stable
```

`nightly` ورژن انسٹال کرنا یا بعد میں اسے غیر ترتیب دینے کے بغیر ایک مخصوص Rust ورژن ترتیب دینا اس مسئلے کا سبب بن سکتا ہے۔

### چیک کریں کہ کیا Rust کے دیگر ورژن موجود ہیں {#check-if-there-are-other-rust-versions}

خرگوش کے سوراخ کی خرابیوں کا سراغ لگانا جاری رکھتے ہوئے، ہمارے پاس گولیوں کا عرفان ہو سکتا ہے:

```bash
$ type rustc
$ type cargo
```

اگر یہ `rustup which *` چلانے کے دوران آپ نے دیکھا اس سے مختلف مقامات کی طرف اشارہ کرتے ہیں، تو آپ کو ایک مسئلہ ہے. نوٹ کریں کہ ان طرح کے مستعار شامل کرنا کافی نہیں ہے۔

```bash
$ alias rustc "~/.rustup/toolchains/stable-*/bin/rustc"
$ alias cargo "~/.rustup/toolchains/stable-*/bin/cargo"
```

اندرونی منطق اب بھی ٹوٹ سکتا ہے اس سے قطع نظر کہ آپ اپنے شیل عرفات کو کس طرح ترتیب دیتے ہیں.

سب سے آسان حل یہ ہوگا کہ آپ ان ورژنوں کو ہٹا دیں جو آپ استعمال نہیں کرتے ہیں۔

تاہم یہ کہنا آسان مگر کرنا مشکل ہے، کیونکہ اس کے لیے نصب شدہ اور دستیاب `rustup` کے تمام ورژنز کا سراغ لگانا پڑتا ہے۔ عموماً صرف دو ہوتے ہیں: system package manager کا ورژن، اور وہ ورژن جو اس tutorial کے آغاز میں command چلانے پر آپ کے home folder کی معیاری جگہ میں نصب ہوا تھا۔ پہلے کے لیے اپنی Linux distribution کی manual دیکھیں (`apt remove rust`)؛ دوسرے کے لیے چلائیں:

```bash
$ rustup toolchain list
```

اور پھر، ہر `<toolchain>` کے لئے (کورس زاویہ brackets کے بغیر):

```bash
$ rustup remove <toolchain>
```

ٹول چینز کو ہٹانے کے بعد، اس کمانڈ کو ایک کمانڈ نہیں ملنے کی خرابی کی اطلاع دینی چاہئے:

```bash
$ cargo --help
```

یہ غلطی اس بات کی تصدیق کرتی ہے کہ کوئی فعال Rust ٹولچین انسٹال نہیں ہے. پھر چلائیں:

```bash
$ rustup toolchain install stable
```

## خرابیوں کا سراغ لگانا Python ٹولچین۔ {#troubleshooting-python-toolchain}

جب آپ Python وہیل پیکیج کو [Python کلائنٹ سیٹ اپ](/ur/guide/tutorials/python.md) کے دوران پائپ کا استعمال کرتے ہوئے انسٹال کرتے ہیں تو ، آپ کو ایک ایسی غلطی کا سامنا کرنا پڑ سکتا ہے جیسے: "iroha_python-*.whl اس پلیٹ فارم پر کوئی سپورٹ شدہ پہیا نہیں ہے۔".

اس غلطی کا مطلب ہے کہ pip پرانی ہے، لہذا آپ کو اسے اپ ڈیٹ کرنے کی ضرورت ہے۔ سب سے پہلے، یہ سفارش کی جاتی ہے کہ آپ اپنے OS کو تازہ کاریوں کے لئے چیک کریں اور سسٹم اپ گریڈ انجام دیں.

اگر یہ کام نہیں کرتا ہے تو، آپ کو اپنے صارف ڈائرکٹری کے لئے `pip` اپ ڈیٹ کرنے کی کوشش کر سکتے ہیں.

`python -m pip install --upgrade pip`

اس بات کو یقینی بنائیں کہ آپ کی ہوم ڈائرکٹری میں `pip` انسٹال ہے۔ ایسا کرنے کے لئے ، `whereis pip` چلائیں اور چیک کریں کہ آیا `/home/username/.local/bin/pip` راستے کے درمیان ہے۔ اگر نہیں ، تو اپنے شیل کے متغیر `PATH` کو اپ ڈیٹ کریں.

اگر مسئلہ جاری ہے تو، براہ کرم [ ہم سے رابطہ کریں ](/ur/help/) اور نتائج کی اطلاع دیں.

```
python --version
python3 --version
pip --version
pip3 --version
```
