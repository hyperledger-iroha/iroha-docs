# گائیڈ {#guide}

جب آپ Iroha کے ساتھ تعمیر ، آپریشن یا انضمام کرتے ہیں تو اس حصے کا استعمال کریں۔ پہلے کلائنٹ کے لئے SDK سبق سے شروع کریں ، پھر مشترکہ نیٹ ورک کے خلاف تعینات کرنے سے پہلے بہترین طریقوں اور آپریٹر ریفرنسز پر جائیں۔

## اقسام {#sections}

|سیکشن |اسے استعمال کریں |
| ------------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------- |
| [SDK سبق](/ur/guide/tutorials/) |زبان کے مخصوص کلائنٹ ترتیب اور نمونہ ایپلی کیشنز |
| [بہترین طریق کار](/ur/guide/best-practices/) |ترقی، تعیناتی، آپریشنز، سیکیورٹی اور ریلیز کے لیے پیداوار کی رہنمائی |
| [ترتیب اور انتظام](/ur/guide/configure/overview.md) |مقامی نیٹ ورک نوڈ ترتیب، ابتداء، کلائنٹ ترتیب، چابیاں، اور نیٹ ورک نوڈ انتظام |
| [سیکورٹی](/ur/guide/security/) |کلیدی ہینڈلنگ، آپریشنل سیکیورٹی، VPNs ، دھوکہ دہی کی نگرانی اور اجازتوں کی حفظان صحت |

## تجویز کردہ راستہ {#recommended-path}

1. [Iroha 3](/ur/get-started/install-iroha.md) انسٹال کریں اور [لوکل نیٹ ورک لانچ کریں](/ur/get-started/launch-iroha.md).
2. [SDK ٹیوٹوریل](/ur/guide/tutorials/) منتخب کریں اور ایک چھوٹا سا لین دین جمع کروائیں.
3. [ایپلی کیشن ڈویلپمنٹ](/ur/guide/best-practices/application-development.md) اور [ڈیٹا ماڈلنگ ](/ur/guide/best-practices/data-modeling.md) کا جائزہ لیں ایک درخواست کو تشکیل دینے سے پہلے API.
4. مشترکہ یا پیداوار کے نیٹ ورک کو چلانے سے پہلے [ نیٹ ورک کی تعیناتی](/ur/guide/best-practices/network-deployment.md)، [آپریشنز](/ur/guide/best-practices/operations.md)، اور [سیکیورٹی اینڈ رسائی](/ur/guide/best-practices/security-and-access.md) کا استعمال کریں۔
5. مقامی ترقی سے Taira، Minamoto، یا کسی اور براہ راست تعیناتی کو فروغ دیتے وقت [ریلیز ریڈنس](/ur/guide/best-practices/release-readiness.md) پر عمل کریں۔
